# 民法·民事责任·四维万能答题模型

> 验证「行为→归责→承担→免责」四维框架完全通用于三类民事责任，并展示主观题答题的踩分规律

## 核心发现

<!-- confidence: EXTRACTED -->
民事责任的四维框架是**法考命题的底层逻辑**，出题人、阅卷评分都严格按这四层设置：

| 维度 | 问题 | 答题操作 |
|------|------|---------|
| **① 行为形态** | 有没有产生责任的基础事实？ | 定性行为（是否违约/侵权/缔约失信） |
| **② 归责原则** | 满足什么条件才需要赔？ | 判断是否满足归责要件（过错/无过错等） |
| **③ 承担方式** | 对方能主张什么救济？ | 列举可能的责任形式（赔钱/继续履行等） |
| **④ 免责/减责** | 什么情况下不赔或少赔？ | 审查法定免责/减责事由 |

## 三类民事责任的统一验证

### 违约责任

<!-- confidence: EXTRACTED -->
| 维度 | 具体形式 |
|------|---------|
| 行为 | 预期违约、实际违约（不履行/迟延/不完全） |
| 归责 | ⭐ 原则无过错；特例（保管、委托）采过错责任 |
| 承担 | 继续履行、补救、赔偿、违约金、定金 |
| 免责 | 不可抗力；有效免责条款 |

### 侵权责任

<!-- confidence: EXTRACTED -->
| 维度 | 具体形式 |
|------|---------|
| 行为 | 单独侵权、数人侵权（共同/共同危险/分别） |
| 归责 | ⭐ 过错责任、无过错责任、公平补偿三种混合 |
| 承担 | 停止侵害、返还、赔偿、精神损害、消除影响 |
| 免责 | 受害人故意/重大过失、不可抗力、第三人原因 |

### 缔约过失责任

<!-- confidence: EXTRACTED -->
| 维度 | 具体形式 |
|------|---------|
| 行为 | 恶意磋商、隐瞒事实、泄密、违背诚信 |
| 归责 | ⭐ **单一过错责任**（必须有过错） |
| 承担 | **仅信赖利益损害赔偿**（不含违约金、继续履行） |
| 免责 | 自身无过错即可免责；无通用法定免责 |

## 关键发现：归责原则的三种组合

<!-- confidence: INFERRED -->
出题者测试的实际上是：考生能否快速**判断责任类型 → 识别该类型的归责规则 → 判断本案是否满足**

- **违约责任**：原则无过错（严格责任）
- **侵权责任**：三种并存（过错 + 无过错 + 公平补偿）
- **缔约过失**：单一过错责任

## 拓展视角：相同逻辑在其他责任中的应用

<!-- confidence: INFERRED -->
**刑事责任**：犯罪行为 → 四要件定罪标准 → 刑罚种类 → 违法阻却（正当防卫等）

**行政责任**：行政违法行为 → 违法认定规则 → 行政处罚 → 不予处罚/从轻事由

→ **底层逻辑一致，仅术语与细节差异**

## 主观题答题的踩分规律

<!-- confidence: EXTRACTED -->
阅卷老师严格按四层给分（每层通常占 25% 的分值）：

```
主观题总分 = 
  25% × 行为定性（是否构成XX责任）
  + 25% × 归责原则分析（本案是否满足）
  + 25% × 责任承担形式（能主张什么救济）
  + 25% × 免责/减责审查（有无法定事由）
```

**实用答题模板**：
1. **第一层**：定性行为（本案是违约/侵权/缔约过失？）
2. **第二层**：阐述本类责任的归责原则 + 判断本案是否满足
3. **第三层**：说明权利人可主张的具体救济方式
4. **第四层**：审查是否存在法定免责或减责情节，确定最终责任范围
