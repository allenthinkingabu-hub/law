# 民法·法律责任总纲

> 民法法律责任体系的答题模型框架，梳理民事责任三大分类及统一下钻维度

## 核心观点

<!-- confidence: EXTRACTED -->
民法法律责任分为四大类（民事、行政、刑事、违宪），其中民事责任又平级分为三类：**违约责任、侵权责任、缔约过失责任**。

<!-- confidence: EXTRACTED -->
三类民事责任采用**统一的下钻维度**拆解：①行为类型 ②归责规则 ③责任承担方式 ④免责/减责事由。

## 三大民事责任分类

### 违约责任
- **行为类型**：预期违约（明示/默示）、实际违约（履行不能/拒绝/迟延/不完全）
- **归责规则**：一般无过错责任（特定情形如保管、委托采过错责任）
- **责任承担**：继续履行、补救措施、赔偿损失、违约金、定金
- **免责事由**：不可抗力；有效免责条款

### 侵权责任
- **行为类型**：单独侵权、数人侵权（共同/共同危险/分别侵权）
- **归责规则**：过错责任（含过错推定）、无过错责任（高度危险/产品/环境/动物）、公平补偿
- **责任承担**：停止侵害、返还财产、赔偿损失、赔礼道歉、消除影响
- **免责/减责**：受害人故意、重大过失、不可抗力、第三人原因等法定事由

### 缔约过失责任
- **行为类型**：合同磋商阶段的过错行为（恶意磋商、隐瞒事实、泄露秘密、违背诚信）
- **归责规则**：过错责任（有过错才担责）
- **责任承担**：仅赔偿信赖利益损失（不含违约金、继续履行）
- **免责事由**：无统一法定免责，一般仅无过错可免责

## 层级关系

```
法律责任（最高层）
├─ 民事责任 ⭐
│  ├─ 违约责任
│  ├─ 侵权责任
│  └─ 缔约过失责任
├─ 行政责任
├─ 刑事责任
└─ 违宪责任
```

## 关键意义

<!-- confidence: INFERRED -->
统一的下钻维度便于考生快速定位：面对任何民事责任考题，都可按"行为→归责→承担→免责"四步走，避免混乱。
