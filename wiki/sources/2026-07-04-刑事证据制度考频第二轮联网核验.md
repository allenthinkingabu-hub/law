# 2026-07-04 [[刑诉-刑事证据制度-深度报告]] 考频第二轮联网核验

## 任务与方法

对 [[刑诉-刑事证据制度-深度报告]] 的"考频"星级评级做专项真实性核查，要求参照互联网、主流法考教培机构、国家权威机构的最新资料，不得编造。共分派 **18 路独立联网核查 agent**，覆盖：
1. 法发〔2024〕12号（五部门《排除非法证据规程》《庭前会议规程》）真实性（3路交叉核查）
2. 法释〔2021〕1号相关条文准确性（2路逐条核查）
3. 电子数据规定 + 刑诉法典本体条文
4. 2025/2026法考大纲官方信号（2路，含"2026大纲出版日期"专项复核）
5. 法发〔2024〕12号内部条号精确核实（2路，第一路+补漏路）
6. 四大板块（证据种类/非法证据排除/证据审查/证明责任）历年真题与教培机构考频实证（4路）
7. 核验过程中报告被并发扩容至40考点，追加2路核查新增16个考点的条号与考频

## 核心发现

### 1. 法发〔2024〕12号真实性 —— ✅ 确认存在，非虚构

3 路独立信源（最高法公报目录页 gongbao.court.gov.cn、律师站全文转载 wangkanglawyer.com/055110.com、地方政府网站转载 jinjiang.gov.cn、澎湃政务号全文转载）交叉印证：两高三部（最高法/最高检/公安部/国安部/司法部）联合发布《办理刑事案件排除非法证据规程》《办理刑事案件庭前会议规程》，同一文号**法发〔2024〕12号**，**施行日期2024-09-03**一致无误。原有"张冠李戴2017年旧规（法发〔2017〕15号）"的疑虑不成立——15号文是另一份真实的、仍现行有效的实体性规定，2024年12号文废止的是2017年11月的**另一份**《人民法院办理刑事案件排除非法证据规程（试行）》。

### 2. 条号系统性错位 —— ⚠️ 已订正

多路独立信源交叉确认，报告初版条号大量错误，根源是（a）法发〔2024〕12号内部条号误记，（b）法释〔2021〕1号新旧版本（2012年版 vs 2021年现行版）条号混淆。订正对照见 [[刑诉-刑事证据制度-深度报告]] 内"🔎 第二轮核验记录"完整表格，核心几处：

| 规则 | 原引 | 订正后 |
|---|---|---|
| 暴力/威胁/限制自由标准 | 2024规程§2-4 | 第一条第一款 |
| 重复性供述排除 | 2024规程§6 | 第一条第二款 |
| 侦查终结前核查 | 2024规程§14-15 | 第四条 |
| 申请材料线索 | 2024规程§19-20 | 第八条 |
| 举证责任 | 2024规程§27 | 第二十二条 |
| 证人证言绝对排除 | 法释2021§78-82 | §88-89（新旧版本条号混淆） |
| 辨认笔录排除 | 法释2021§107-108 | §103（勘验检查）+§105（辨认） |
| 数字化言词证据 | 电子数据规定§1第三款 | §1第四款 |
| 三阶段排非 | 刑诉法§56② | §56③ |
| 不能排除即排除 | 刑诉法§58 | §60 |

⚠️ **未完全解决**：「有专门知识的人出庭」条号（原引§197②）在核查中出现**两次独立结论冲突**——一路认为实际应为§192②，但该款已被另一路归为"警察目击作证"，存在矛盾，需第三方信源进一步核实（已在报告中如实标注为"待进一步核实"，未强行拍板）。「非法证据排除·决定排除的证据不得出示质证」条号（第二十八条）仅有单一信源支撑，置信度中等，也已如实标注。

### 3. 评级方法论问题 —— ⚠️ 已系统性下调

最重要的发现：报告把"新规/条文已被官方大纲或法典吸收、教培机构预测重要"等同于"历年真题反复验证的高频"。四路分板块真题/机构核查显示：
- **纯2024新规内容**（重复性供述、侦查终结前核查、庭审质证限制、庭前会议应当召开）：施行仅1-2个考试周期，**查无任何真题实证**，已从★★★★★降至★★★★/★★★。
- **"持有型犯罪举证责任例外"（巨额财产来源不明罪等）**：仅查到学理争议文章讨论"是否举证责任倒置"，**无真题实证**，是原报告中最明显的夸大项，★★★★★→★★★。
- **新增的2018年出庭制度条文**（§192证人应当出庭、§197专家辅助人）：条文真实但**未查到具体真题命中**，已从★★★★★/★★★★降至★★★。
- "背景概述"中"主观题几乎每年必考非法证据排除"系过度具体化，机构原文实为泛指"证据相关问题几乎年年必考"。

最终仅保留 **6 个**多年真题反复实证的顶级考点（§94供述排除、§98-99鉴定意见、§114电子数据、直接/间接证据学理判定、非法言词证据绝对排除标准、§55证明标准），其余原★★★★★考点按证据强度下调至★★★★或★★★，部分因确认真题（§12无罪推定2013年卷二64题、§88意见证据规则2023年卷一真题）而**上调**。

### 4. 2026年大纲 —— ✅ 出版日期真实，但"刑诉法未变动"论断未经官方确认

司法部官网+央广网报道交叉确认《2026年国家统一法律职业资格考试大纲》确于2026-05-15出版发行，与2025年大纲同期发布模式一致，并非误植。但报告称"官方科目修订未涉及刑诉法典变动、证据规则连续第三年保持稳定"——**未查到官方逐字确认**，公告/报道仅笼统提及科目范围调整，已在报告中改标为"合理推断，非官方明示"。

### 5. 试卷结构说法 —— ✅ 确认准确

2018年法考改革后客观题分试卷一（公法卷，含刑法/刑诉法/法理/宪法/行政法）、试卷二（私法卷，民商法类），刑诉法确在试卷一，报告表述准确。
