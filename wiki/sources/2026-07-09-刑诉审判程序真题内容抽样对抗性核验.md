# 2026-07-09 [[刑诉-审判程序-深度报告]] 真题内容抽样对抗性核验（与 [[2026-07-09-刑诉审判程序考频第二轮独立核验]] 并行独立完成）

## 背景与分工

本次与另一并行会话（见 [[2026-07-09-刑诉审判程序考频第二轮独立核验]]）独立开展同一任务："核查刑诉-审判程序-深度报告的考频是否准确真实"。两轮对"高检发〔2026〕5号"的核实结论**完全一致**（均判定为未获证实/高度疑似虚构），构成有效交叉印证。本轮聚焦对方未覆盖的两块：（1）补齐板块一"具体条号待逐条核验"的5处遗留缺口；（2）对报告中"某年卷二第N题"这类高精度真题出处声称做**对抗性内容核验**（不止确认"题目是否存在"，还核对题干/选项/答案是否与声称一致）。

## 方法

60-agent workflow（研究agent独立查找 → 2个独立"专门反驳"agent复核，参照 [[fakao-kaopin-rating-honesty]] 记忆里"2026-07-05刑诉证据顶级6项5个被证伪"的教训，不满足于单次WebSearch/WebFetch"确认"）。因中途触发session额度限制，分两批运行（第一批20个agent完成，40个失败；额度重置后全量重跑，60个全部成功）。

## 条号缺口核实结果（已写入报告对应表格行）

法释〔2021〕1号《刑诉解释》第十一章"单位犯罪案件的审理"（§335-§346）逐条核实：
- 诉讼代表人资格认定 → §336+§337
- 诉讼代表人诉讼权利边界 → §338（仅核实到"享有被告人诉讼权利+庭审席位安排"，"不得旁听同案人讯问"这一具体限制未在解释全文检索到对应条文，标注存疑）
- 单位分立/合并/注销 → §344+§345
- 单位财产查封扣押冻结追缴 → §341-343
- 追加起诉程序（法院仅有建议权） → §340

其他：
- 判决/裁定上诉抗诉期限差异（10日/5日） → §380（"判决实体、裁定程序"这一性质区别表述未见解释逐字条文对应，系教材归纳）
- 起诉与审判关系（受事实约束不受罪名约束） → 综合§295①(2)+§297（教义归纳，非单一条号）
- 近亲属范围 → 确认现行（2018修正）准确条号为**§108⑥**（"§106⑥"是2012旧版条号，内容未变仅顺延）

**发现一处实质性错误（非仅条号）**：报告原称"检察院撤回起诉后，法院准予撤诉的裁定不得上诉、抗诉"——核实《刑诉解释》**§378明确规定被告人/自诉人对准许撤回起诉等裁定享有上诉权**，与原表述直接矛盾，已删除该错误说法；"新证据可再行起诉"的准确依据是§219①(6)，原引§296只是撤诉审查的授权条款本身。
