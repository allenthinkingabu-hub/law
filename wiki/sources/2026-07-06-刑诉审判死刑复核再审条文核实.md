# 2026-07-06 刑诉·死刑复核与审判监督(再审) 条文核实

## 核准的条号（含对旧标注的纠错）

| 考点 | 正确条文 | 一句话内容 |
|---|---|---|
| 死刑立即执行核准 | **§246** | 死刑由最高人民法院核准 |
| 死刑复核路径 | §247 | 中院判死刑不上诉→高院复核后报请最高法核准 |
| 死缓核准 | **§248** | 中院判处死缓的，由高级人民法院核准 |
| 死刑不核准处理 | **§250** | 复核作核准/不核准**裁定**；不核准可**发回重审或改判** |
| 死刑复核律师权利 | **§251** | 复核死刑**应当讯问被告人**；辩护律师提出要求的**应当听取意见** |
| "办公场所听取意见" | 《办理死刑复核案件听取辩护律师意见的办法》**§6** | 当面听取应在最高法或地方法院办公场所进行（非 CPL 条文） |
| 申诉不停止执行 | **§252** | 当事人/法代/近亲属可申诉，但**不停止**判决裁定执行 |
| 应当重新审判五情形 | **§253** | 新证据/证据不实不足或矛盾/适用法律错误/违反程序/枉法裁判 |
| 提起再审主体 | **§254** | 院长提审委会/上级法院提审或指令再审/检察院抗诉 |

## 命题陷阱（考点眼）

1. **死缓 ≠ 报最高法**：死刑立即执行由最高法核准（§246），死缓由高级法院核准（§248）。互换即错。
2. **讯问被告人是"应当"**（§251），非"可以"、非"由合议庭视情决定"。
3. **"办公场所听取"出自《办法》§6，非§251本身**——命题人易张冠李戴到刑诉法条文上。
4. **申诉不停止执行（§252）**；且申诉≠必然再审，须符合 §253 情形并由法院/检察院依职权提起。
5. **§253（事由）vs §254（谁有权提起）** 别对调；**§250（不核准处理）在§251（讯问听取）之前**，勿颠倒。
6. **不核准≠一律发回**：最高法可发回重审，也可径行改判（§250②）。
