# 刑事诉讼全流程：编号体系与完整解析融合版

> 诉讼流程编号体系 + 全流程详细解析 | 2026 年法考综合学习素材

## 核心价值

本融合素材包含两个维度的完整信息：

### 维度一：编号规则与体系框架
- **「阶段码 + 序号」编号规则**：L(立案) / Z(侦查) / S(审查起诉) / Y1(一审) / Y2(二审) / Zh(执行)
- **异常分支标注**：「-E + 序号」标记从主流程分叉的所有例外情形
- **上下游链接**：每个节点标注前置条件与后置流向，形成完整诉讼网络

### 维度二：详细流程解析表格
- **六大阶段完整表格**：正常流程节点 + 异常分支节点，逐项标注负责主体、准入/准出条件、核心动作
- **考点关联映射**：每个节点与四大核心模块（强制措施、刑事证据、认罪认罚、审判程序）对应
- **七大特别程序**：独立于主流程的专门程序（附条件不起诉、犯罪记录封存、缺席审判等）

| 阶段 | 流程编号 | 正常主流程 | 异常分支 | 备注 |
|------|---------|---------|--------|------|
| **立案** | L01-L03 | 受理 → 审查 → 立案决定 | L03-E1/E2 | 不予立案、立案监督 |
| **侦查** | Z01-Z11 | 人身控制(Z01-Z05) + 取证(Z06-Z10) → 终结 | Z05-E1/Z11-E1/E2 | 强制措施、刑事证据核心阶段 |
| **审查起诉** | S01-S04 | 受理 → 审查 → 认罪认罚 → 公诉 | S02-E1/E2/E3/E4 | 认罪认罚制度落地、不起诉决定 |
| **一审** | Y1-01-Y1-04 | 庭前审查 → 会议 → 开庭 → 宣判 | Y1-03-E1/E2/E3/Y1-04-E1/E2 | 审判程序、非法证据排除核心 |

## 应试核心速查

### 「三大黄金链路」

#### 链路一：强制措施完整序列
Z01(拘传) → Z02(取保) → Z03(监视居住) → Z04(刑事拘留) → Z05(逮捕·审查批捕)
- **关键数字**：拘传12h/24h、取保12个月、监居6个月、拘留3日+延期、审查批捕7日、逮捕后讯问24h
- **决策权分置**：公安、检察、法院各有独立决定权；执行权多归公安

#### 链路二：不起诉三重奏
S02-E1(法定) → S02-E2(酌定) → S02-E3(存疑/证据不足)
- **法定**：无罪、过时效、特赦、自诉撤回、被告人死亡
- **酌定**：情节轻微，不需要判处刑罚或免除刑罚
- **存疑**：二次补侦后仍不足 / 一次补侦后无需补侦·检察长批准

#### 链路三：上诉期与发回限制
Y2-01(判决10日/裁定5日) → Y2-04-E1(发回重审**仅一次**)
- **应诉期限**：从**第二日**起计算
- **发回限制**：发回重审绝对禁止二次发回；重审再上诉二审必须自行裁判

### 「五大考点标志性数字」

| 数字 | 对应考点 | 备忘 |
|------|---------|------|
| **3日** | 拘留基本期限、扣押财物期限、沿革监外执行医疗保护期 | 记为"拘留铁律3日" |
| **7日** | 立案监督反馈期、庭前审查期、上诉申诉期 | 多个"7日"：要求/申请/反馈 |
| **10日/5日** | 上诉期（判决10日、裁定5日）| 判决更重，期限更长 |
| **24小时** | 讯问/通知家属（逮捕无例外，拘留仅国安恐怖例外） | "两个24小时"标准 |
| **1个月** | 审查期限、死刑停止通知期、侦查延期（单次） | 反复出现的基础期限单位 |

## 异常分支速判表

| 分支标记 | 触发条件 | 后续流向 | 考点风险 |
|---------|---------|--------|--------|
| **-E1** | 第一类异常（资格/要件不符、程序启动） | 释放/重新决定/启动救济 | 权限划分·程序合法性 |
| **-E2** | 第二类异常（事实证据变化） | 补充/重新审查/发回 | 证据认定·补充侦查机制 |
| **-E3** | 第三类异常（发现新情形） | 程序转换/中止/延期 | 程序灵活性·保障权利 |
| **-E4+** | 第四类及以上异常（救济通道） | 上级机关审查/另行处理 | 权利救济·监督制约 |

## 特别程序独立清单

**流程编号体系未覆盖的七大程序**：
1. **附条件不起诉**（未成年人）：6个月-1年考验期
2. **犯罪记录封存**（未成年人）：5年以下判刑后
3. **公诉案件当事人和解**：3年以下（民事）、7年以下（过失）
4. **缺席审判**（贪污贿赂、危害国安、恐怖）：被告人身在境外或逃匿
5. **违法所得没收**（贪污贿赂、恐怖）：通缉1年不到案或已死亡
6. **强制医疗**（精神病人）：依法不负刑事责任但有危害可能
