# 刑罚完整层级知识图谱

> 刑法总论中刑罚分类的完整体系（短内容，简化处理）

## 核心定义

**刑罚**：法院对罪犯适用的刑事处罚，分**主刑**与**附加刑**两类平行同级。

## 层级结构速记

```
刑罚
├─ 主刑（同级，一案只能判 1 个）
│  ├─ 管制
│  ├─ 拘役
│  ├─ 有期徒刑
│  ├─ 无期徒刑
│  └─ 死刑
└─ 附加刑（同级，可独立或附加）
   ├─ 罚金
   ├─ 剥夺政治权利
   ├─ 没收财产
   └─ 驱逐出境（仅外国人）
```

## 区分要点表

| 维度 | 主刑 | 附加刑 |
|------|------|--------|
| **一案数量** | 只能 1 个 | 可多个 |
| **应用方式** | 仅独立 | 可独立/可附加 |
| **判刑方式** | 主要处罚 | 补充处罚 |
| **种类** | 5 种 | 4 种 |

## 应试速判

- **主刑判断**：看是否含有"坐牢"性质（管制→拘役→有期→无期→死刑梯度递进）
- **附加刑判断**：看是否含有"罚金、剥夺权利、没收财产、驱逐出境"
- **单独还是搭配**：虚开增值税→罚金 5000 元（仅附加刑）；抢劫→5 年徒刑+罚金 2000 元（主+附）
