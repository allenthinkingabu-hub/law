# 合同总则 深度报告

> 综合自 2 篇素材 + 当前知识库 6 篇相关 wiki 页面 | 生成日期：2026-06-05

## 背景概述

**合同总则**是 [[民法典]] [[合同编]] 内部的第一个子板块，是整个**债法**的"通用规则层"。

在 [[民法典]] 的七编体例中：

```
民法典
  └─ 合同编（编 03 · 债法核心 · 全编分值之最）
       ├─ 合同总则    ← 本报告主题
       ├─ 典型合同
       └─ 准合同
```

它解决的是"**所有**合同共通的问题"——任何买卖、租赁、借款合同都要先过这一层规则。

## 核心观点

### 1. 合同总则的定位 = 债法通用规则层

[[合同编]] 由三块构成，其中合同总则是**抽象层**：

| 子板块 | 性质 | 包含内容 |
|---|---|---|
| **合同总则** | 通用规则（debt 通则的核心） | 订立 · 效力 · 履行 · 保全 · 转让 · 终止 · 违约责任 |
| **典型合同** | 具体合同类型 | 买卖、租赁、借款、保证、赠与、运输、技术等 19 种 |
| **准合同** | 类合同之债 | 无因管理、不当得利 |

来源：[[合同编]]、[[2026-06-05-民法目录级骨架]]

### 2. 合同总则的 7 个板块（动态生命周期）

合同总则按合同的**生命周期顺序**排列 7 个动作：

```
订立 → 效力 → 履行 → 保全 → 转让 → 终止 → 违约责任
 ↓     ↓     ↓     ↓     ↓     ↓     ↓
 怎么 怎么 怎么 怎么 怎么 怎么 怎么
 生   有   完   保   流   结   救
 出   效   成   全   转   束   济
```

| 板块 | 解决的问题 | 当前知识库覆盖 |
|---|---|---|
| **订立** | 合同怎么生出来？ | ✅ 已展开（[[合同订立流程]]） |
| **效力** | 已成立的合同有没有约束力？ | ⏳ 仅 [[合同生效]] 入门，效力瑕疵未覆盖 |
| **履行** | 怎么实际做到合同约定？ | ❌ 未覆盖 |
| **保全** | 债权人怎么防止债务人耍赖？（[[代位权]] / [[撤销权]]） | ❌ 未覆盖 |
| **转让** | 合同里的权利义务能不能转给别人？ | ❌ 未覆盖 |
| **终止** | 合同怎么了结？ | ❌ 未覆盖 |
| **违约责任** | 一方违约了怎么办？ | ❌ 未覆盖 |

来源：[[合同编]]、[[2026-06-05-民法目录级骨架]]

### 3. 为什么"订立"是入口考点

[[2026-06-05-考点精解-要约与承诺]] 明确：

> 合同订立**很少单独成大题**，但常是大案例的**第一环**——先认定合同是否成立、何时成立，才能往下谈效力、履行、违约。所以它是主观案例的"入口"。

→ 学合同总则的**节点逻辑**是固定的：先订立 → 再效力 → 再履行 → 再救济。订立是"地基"，后面 6 块都要建在它上面。

### 4. 合同总则与 [[请求权基础]] 的关系

合同请求权是 4 大请求权基础（[[请求权基础]]）之一。要主张合同请求权，必须经过合同总则的两道关：

1. [[合同成立]]（§483）—— 有合意吗？
2. [[合同生效]]（§502 / §158）—— 合意有约束力吗？

**两道关都过**，才有合同请求权可谈。否则请求权基础就要换（如改用不当得利、缔约过失）。

### 5. 合同总则的 2026 学习地位

- **2026 重点倾斜区**：[[合同编]] 在民法学科里**分值最高**，合同总则又是合同编的入口
- **活跃司法解释**：[[合同编通则司法解释]]（即"通则解释"）是 2026 民法的**活跃区**
- **学习顺序建议**：[[民法体系结构]] 中明确，合同编与 [[担保]]（[[物权编]] 担保物权 + 合同编保证）**合并学**效率最高
- **主观题地位**：合同编是 [[法考主观题]] 的核心来源；合同总则的"订立 → 效力"两步是大案例的固定开局

## 不同视角对比

知识库中两份素材对合同总则的描述角度不同：

| 维度 | [[2026-06-05-民法目录级骨架]] | [[2026-06-05-考点精解-要约与承诺]] |
|---|---|---|
| 视角 | 目录级 / 骨架视角 | 考点级 / 精解视角 |
| 对合同总则的描述 | 列出 7 个板块（订立·效力·履行·保全·转让·终止·违约责任）作为合同编内部展开 | 精细展开"订立"中的要约/承诺 + 一套可复用四格模板 |
| 与其他模块的关系 | 强调与 [[物权编]] [[担保]] 物权合并学（横跨编） | 强调"订立 → 效力"是主观题入口 |
| 信息层级 | L2 部门法级 | L3 考点级 |

→ 两份素材**互补不冲突**：骨架告诉你"7 块都在合同总则里"，精解告诉你"第 1 块怎么吃"。

### 接下来的复习路径（推荐）

按学习依赖排序：

1. **效力**（已成立的合同什么时候**无效**？什么时候可**撤销**？什么时候**效力待定**？）
2. **履行**（履行规则、抗辩权、代位 / 撤销保全机制）
3. **违约责任**（违约形式、责任承担、损害赔偿、定金、违约金）
4. **转让 / 终止**（综合性弱、性价比低，最后吃）
