# 侵权责任编 深度报告

> 综合自 2 篇核心法规源及 2026 年司法考试教培大纲 | 生成日期：2026-06-16

## 背景概述

**侵权责任编**是 [[民法典]] 的第七编（最后一编），是民法中保障私权、提供损害救济的“最终兜底层”。

在 [[民法典]] 的七编体例中：

```
民法典
  └─ 侵权责任编（编 07 · 损害救济 · 法定之债）
       ├─ 一般规定
       ├─ 损害赔偿
       ├─ 责任主体的特殊规定
       └─ 特殊侵权类型（产品、交通、医疗、环境、高度危险、动物、物件）
```

它解决的是损害发生后“由谁承担、承担多少、怎么承担”的问题——任何民事权益受侵害者在主张赔偿时，都必须经过这一层规则的检视。

## 核心观点

### 1. 归责原则的“三轨并行”体系
侵权责任的归责原则决定了侵权责任成立的构成要件与证明责任分配：

*   **过错责任（§1165Ⅰ）**：一般侵权的默认原则，要求受害人举证“四要件”（过错、违法行为、损害事实、因果关系）。
*   **过错推定（§1165Ⅱ）**：法定的举证责任倒置。行为人若不能证明自己无过错，则直接认定过错并担责（如 §1253 物件脱落坠落）。
*   **无过错责任（§1166）**：不以过错为要件。只要造成损害且无免责事由，即必须承担责任（如产品责任、烈性犬致害等）。

### 2. 多数人侵权的责任分担机制
二人以上共同或分别实施行为致损的责任划分：
*   **共同加害/教唆帮助/共同危险（§1168-§1170）**：承担**连带责任**。
*   **无意思联络的数人侵权（§1171-§1172）**：
    *   *足以造成全部损害*（§1171）：任一行为均可独立导致全部损害，承担**连带责任**。
    *   *结合造成损害*（§1172）：各行为独立不足以造成全部损害，结合后造成损害，承担**按份责任**。

### 3. 2024 年《侵权责任编解释（一）》的核心突破
《最高人民法院关于适用〈中华人民共和国民法典〉侵权责任编的解释（一）》（法释〔2024〕12号）针对实务痛点，作出了规则重构：
*   **监护人全责（§5）**：确立监护人承担侵权人应承担的“全部责任”，否定了监护人补充责任的抗辩，确立“先被监护人财产、后监护人支付”顺序，并保留被监护人生活教育费。
*   **补充责任程序（§14、§24）**：明确校园第三方侵权与高空抛物中物业过错责任属于“顺位在后的补充责任”，必须先依法强制执行具体侵权人财产。
*   **烈性犬零免责（§23）**：禁止饲养的烈性犬等危险动物致害，动物饲养人/管理人不得主张免责或减轻责任。

## 不同视角对比

知识库两篇核心源对侵权责任编的定位和侧重点不同：

| 维度     | 《民法典》第七编             | 《侵权责任编解释（一）》（法释〔2024〕12号）              |
| ------ | -------------------- | -------------------------------------- |
| 视角     | 立法骨架 / 实体权利规范        | 审判实务 / 程序与争议适用细化                       |
| 侧重点    | 搭建侵权责任的一般性体系与各特殊侵权框架 | 重点解决监护关系侵害、诉讼追加共同被告、交强险理赔顺位及补充责任强制执行顺序 |
| 与诉讼的关系 | 规定民事权利义务之债           | 明确规定哪些主体必须列为“共同被告”、如何释明追加、执行中如何扣减等诉讼程序 |
| 关键突破   | 首次以法典形式统一了侵权责任的归责体系  | 打碎了长期困扰司法实践的“执行补充责任人先于直接侵权人”等顽疾        |

### 与其他章节的连接点

- **物权请求权（物权编）**：[[物权的保护]] 中的物权请求权不问过错、不罹时效；而引致的侵权损害赔偿需看归责原则并适用3年时效。
