# 合同成立的最低必要条件 深度报告

> 综合自 2 篇素材 + 当前知识库 10+ 篇相关 wiki 页面 | 生成日期：2026-06-07
>
> **主题入口**：[[合同通则-多选-04]] · "认定合同成立的因素" → 同时是 [[合同成立]] 实体页"经典陷阱区"中的核心子问题。
>
> **本报告聚焦**：[[合同编通则司法解释]] §3 给出的"合同成立三要素"——**当事人姓名 / 名称、标的、数量**——为什么是最低限度？为什么价款不在内？三要素与"两要件"、"合同成立时点"分别是什么关系？

## 背景概述

[[合同成立]] 是合同生命周期的**起点**。在法考主观题大案例里，**第一步固定问题**就是"合同**成立没有 + 何时成立 + 是否生效**"——这一步答错，后面所有效力、履行、违约论证全部塌方（来源：[[2026-06-05-考点精解-要约与承诺]]）。

但"合同成立"本身又是个"叠加判断"：

```
合同成立 = ① 内容上够不够最低限度（本报告主题）
        + ② 时间上什么时候算合意达成
```

第 ② 个问题是 4 种成立时点（§483 / §490 / §490 / §491），第 ① 个问题就是本报告的"最低必要条件"——也是 [[合同编通则司法解释]] §3 给出的"三要素"标准。

> [[合同编通则司法解释]] 是 2026 年法考 [[民法]] 的**活跃区**——民法典本体稳定，但配套司法解释是命题重点。"合同成立三要素"正是司法解释把民法典 §470 操作化的产物。

## 核心观点

### 1. 三要素的法源 = §470 + 通则解释 §3 的"两层结构"

> 来源：[[2026-06-05-考点精解-要约与承诺]] · [[合同通则-多选-04]] · [[合同成立]]

| 层级 | 法条 | 表述 | 性质 |
|---|---|---|---|
| **基础层** | [[民法典]] §470 | 合同内容"**一般包括**"：当事人姓名 / 名称、标的、数量、质量、价款、履行期限 / 地点 / 方式、违约责任、争议解决方法 | 指引性（"一般包括"=不是强制） |
| **操作层** | [[合同编通则司法解释]] §3 | 当事人对合同是否成立有争议，能确定**当事人姓名 / 名称、标的、数量**的，**一般应当认定合同成立** | 司法认定标准 |

**关键理解**：§470 给的是"完整合同应包含什么"的清单，通则解释 §3 给的是"司法上能不能认定合同**已成立**"的最低门槛。两者不是同一个问题。

→ 主观题里，**§470 的 9 项缺失不必然不成立**；只要 §3 的 3 项能确定，法院**应当认定成立**。

### 2. 三要素 = 谁 + 什么 + 多少

> 来源：[[合同通则-多选-04]] · [[合同成立]] 实体页

| 要素 | 法律语言 | 通俗化 | 缺失后果 |
|---|---|---|---|
| **谁** | 当事人姓名 / 名称 | 主体可识别 | 合意无归属，合同不成立 |
| **什么** | 标的 | 交易对象 | 没有交易对象，合意空转 |
| **多少** | 数量 | 交易规模 | 履行边界完全不确定 |

**为什么这三项不可补救**：

- 谁 → 主体属于"合意双方"的本体，缺失意味着**根本没有合意主体**
- 什么 → 标的是合意的**核心客体**，缺失等于双方"没在谈同一件事"
- 多少 → 数量是履行的**度量基准**，缺失则 §510 / §511 也无法兜底（没有"标的物总量"可言）

→ 这三项构成 [[合同成立]] 的**不可降级底线**。

### 3. 为什么价款 / 履行期限 / 地点 / 方式不是必要条件？

> 来源：[[合同通则-多选-04]] · [[合同通则-多选-05]] · [[合同通则-单选-15]] · [[2026-06-05-考点精解-要约与承诺]]

**关键链条**：

```
§510（约定不明的补充规则）→ §511（具体兜底标准）
  第一档：补充协议
  第二档：合同有关条款 + 交易习惯
  第三档：法律规定（§511 详细规则）
```

| 缺失项 | 补救法条 | 补救方式 | 是否影响成立 |
|---|---|---|---|
| **价款** | §511(二) | 按订立时履行地市场价格 / 政府定价 | ❌ 不影响 |
| **履行期限** | §511(四) | 债务人可随时履行；债权人也可随时请求，但应给必要准备时间 | ❌ 不影响 |
| **履行地点** | §511(三) | 货币：接收方所在地；不动产：所在地；其他：履行义务方所在地 | ❌ 不影响 |
| **履行方式** | §511(五) | 有利于实现合同目的的方式 | ❌ 不影响 |
| **质量** | §511(一) | 国家标准 → 行业标准 → 通常标准 / 符合合同目的的特定标准 | ❌ 不影响 |

→ 多选-04 的"D. 价款"陷阱，本质是考生在"市场常识"和"法律规则"间的混淆：买卖没价钱在生活里不可想象，但在法律上 §511 可以兜底定价。

**统一逻辑**：凡是 §511 能兜底的项目，都**不构成成立要件**；§511 兜底不了的（人 / 标的物 / 数量），才是成立要件。

### 4. "三要素" vs "两要件" —— 父子关系，不是并列

> 来源：[[合同通则-单选-06]] · [[合同成立]]

法考很多人混淆两个"三要素 / 两要件"：

| 概念 | 法条 | 对象 | 内容 |
|---|---|---|---|
| **要约成立的两要件** | §472 | 判断一个意思表示是不是 [[要约]] | ① 内容具体确定 ② 表明经承诺即受约束 |
| **合同成立的三要素** | 通则解释 §3 | 判断合同**整体**有没有成立 | 当事人 + 标的 + 数量 |
| （特殊：超市场景下的"商品 + 标价 + 陈列"三要素） | §472 解释 | "要约要件①内容具体确定"在零售场景下的拆解 | 标的物 + 价款 + 受约束 |

关系图：

```
合同成立的三要素（§3）
  ├─ 当事人姓名 / 名称
  ├─ 标的         ─┐
  └─ 数量         │
                  │ "标的 + 数量 + 价款" 在要约层面也是
                  ▼ "要约两要件①内容具体确定"的实操化拆解
要约的两要件（§472）
  ├─ ① 内容具体确定 ── 超市场景拆为：商品 + 标价 + 陈列售卖
  └─ ② 经承诺即受约束
```

→ **三要素**在合同层是 [[合同成立]] 的最低限度；在要约层是 [[要约]] "内容具体确定"的具象化。两者本质上都在回答同一个问题：**"内容有没有具体到可执行"**。

### 5. 三要素 vs 合同成立时点（4 种）—— 维度不同

> 来源：[[2026-06-05-考点精解-要约与承诺]] · [[合同通则-单选-12]] · [[合同通则-单选-09]] · [[合同通则-单选-10]] · [[合同成立]]

考生第二大易混：**"三要素满足"和"合同成立时点"是同一件事吗？**

不是。它们是**两个不同的问题**：

| 问题 | 关心什么 | 法条依据 |
|---|---|---|
| **内容维度** | 合意够不够具体 → 三要素 | 通则解释 §3 |
| **时间维度** | 合意什么时候算成 → 4 种时点 | §483 / §490 / §490 / §491 |

只有**两个维度同时满足**，才能说"合同已成立"：

```
合同成立 = （三要素都能确定）AND （达到 4 种时点之一）
```

| 时点情形 | 法条 | 何时成立 | 真题 |
|---|---|---|---|
| 一般合同（要约 / 承诺） | §483 | 承诺生效时 | [[合同通则-单选-09]] 拍卖落槌 |
| 合同书 | §490 | 签名 / 盖章 / 按指印**任一**时 | [[合同通则-单选-12]] |
| 一方已履行 + 对方接受 | §490 | 履行时 | — |
| 电子合同 | §491 | 提交订单成功时 | [[合同通则-单选-10]] 双 11 |

→ [[合同通则-单选-12]] 是"时点维度"的反向陷阱：内容维度满足（甲乙对机床有合意），但因约定**合同书形式**，时点维度未到（没签字盖章）→ 合同未成立 → 走 [[缔约过失责任]]。

→ [[合同通则-多选-04]] 是"内容维度"的正面考查：能确定 ABC 三要素就成立。

## 不同视角对比

### 维度一：内容门槛 vs 时点门槛

| 维度 | 内容维度（三要素） | 时点维度（4 种成立时点） |
|---|---|---|
| 法条 | 通则解释 §3 | §483 / §490 / §491 |
| 关心问题 | "够不够具体" | "什么时候算成" |
| 失败结果 | 合意空转，合同不成立 | 合意没到达，合同未成立 |
| 真题主入口 | [[合同通则-多选-04]] | [[合同通则-单选-12]] / [[合同通则-单选-09]] / [[合同通则-单选-10]] |

### 维度二：成立 vs 生效（再强调一遍）

> 这是 [[合同成立]] 实体页"陷阱 1"，也是 [[合同通则-多选-15]] 的核心考点。

| 维度 | 合同成立 | [[合同生效]] |
|---|---|---|
| 性质 | **事实判断**（有没有合意） | **法律评价**（合意有约束力吗） |
| 内容要件 | 三要素（§3） | 不另行考查"内容要件" |
| 法条 | §483 / §490 / §491 | §502 默认成立即生效；§158 附条件 / 期限例外 |
| 典型反例 | 房屋买卖未登记 → **合同有效**（登记影响**物权变动**，不影响合同效力）—— [[合同通则-多选-15]] | 附年终奖到账才付款 → **成立但未生效**（[[合同成立]] 故事第四幕 4B） |

→ "未登记 → 合同未生效"是 50% 考生踩中的王牌陷阱（[[合同通则-多选-15]] A 项）。**登记 ≠ 合同生效要件**，登记是**物权变动**要件。

### 维度三：法源新旧对比（§470 vs §3）

旧法时代实务中长期争议："价款"是不是合同成立必要条件？

- **旧观点**：§470 把价款列为"一般内容" → 学说 / 部分判例认为价款也是必要条件
- **新规则**（[[合同编通则司法解释]] §3）：明确只要"姓名 / 名称、标的、数量"能确定，**一般应当认定成立**

→ 通则解释 §3 是对民法典 §470 的**最低门槛化操作**，把"完整合同清单"和"司法认定底线"分开。本报告涉及的 [[合同通则-多选-04]] 正是这条新规则的标准考查。

## 在主观题中的应用模板（§3 三要素如何落地）

> 来源：[[合同通则-单选-12]] · [[2026-06-05-考点精解-要约与承诺]] · [[结论先行答题法]]

```
Step 1（合意定性）：
  甲的【行为】构成 §472 要约 / §473 要约邀请。
  乙的【回复】构成 §479 承诺 / §488 新要约。

Step 2（内容维度 · 本报告核心）：
  能否确定【当事人 / 标的 / 数量】？
    ✅ 三项齐 → 内容维度过关
    ❌ 缺人 / 缺物 / 缺数 → 内容维度未过 → 合同不成立
    ⚠️ 缺价款 / 期限 / 地点 → §511 可补充 → 不影响成立

Step 3（时点维度）：
  按 4 种情形定位时点（§483 / §490 / §490 / §491）

Step 4（生效判断）：
  §502 默认即生效；§158 附条件 / 期限 / 需批准 → 例外
  → 报批义务条款独立有效

Step 5（反向陷阱）：
  合同未成立 ≠ 无责任 → [[缔约过失责任]]（§500）
```

## 尚待解决 / 可继续深挖的问题

下次搜集素材时可以重点关注：

1. **"数量"如何判定"可确定"** —— 完全不定（"若干")、估算（"约 X 件")、可推定（按以往交易），司法实务的分级？
2. **"标的"模糊到什么程度算"无法确定"** —— "二手车一辆"是不是足够？需不需要锁定具体车牌？
3. **司法解释 §3 "一般应当"的留白** —— 何种情形法院可以不认定成立？是否有反向判例？
4. **三要素与"实质性变更"7 项**（§488：标的、数量、质量、价款 / 报酬、履行期限 / 地点 / 方式、违约责任、争议解决方法）的关系：为什么"实质性变更 7 项"远多于"成立三要素 3 项"？—— 提示：一个判**形成承诺还是新要约**（动态过程），一个判**合同是否成立**（终局状态）；前者标准更严，后者门槛更低。
5. **通则解释 §3 与 §510 / §511 的衔接** —— 司法实务里如何在"价款约定不明"和"价款根本未约定"之间划线？
