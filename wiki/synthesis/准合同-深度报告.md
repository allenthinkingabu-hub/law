# 准合同 深度报告

> 综合自 [[合同编]] 第三分编 + 真题库 6 道 C3 真题 | 生成日期：2026-06-06

## 背景概述

**准合同**是 [[民法典]] [[合同编]] 内部的第三个子板块，与 [[合同总则]]、[[典型合同]] 并列：

```
合同编（[[合同编]]）
  ├─ 合同总则
  ├─ 典型合同
  └─ 准合同  ← 本报告主题
       ├─ [[无因管理]]（§979-§984）
       └─ [[不当得利]]（§985-§988）
```

**为什么叫"准"合同**？因为这两类**不是合同**（没有当事人合意），但因为产生类似于合同的**债权债务关系**，立法上**比照合同处理**，故称"准合同"（quasi-contract）。

> **分值定位**：客观题中分值约占合同编的 **5-10%**，但**考点高度集中** — 6 题真题已基本覆盖全部考点框架。

## 核心观点

### 1. 准合同的位置 = 债法的"补漏网"

[[债的发生原因]] 有 4 类：

| 发生原因 | 性质 | 章节 |
|---|---|---|
| **合同** | 法律行为（合意） | [[合同编]] 总则 + 典型合同 |
| **侵权** | 事实行为（违法） | [[侵权责任编]] |
| **无因管理** | 事实行为（合法管事） | 合同编 准合同 — [[无因管理]] |
| **不当得利** | 事件 / 行为（无法律原因获益） | 合同编 准合同 — [[不当得利]] |

→ 准合同 = 合同之外、侵权之外的"剩余债法"。

来源：[[合同编]]、[[2026-06-06-合同章真题库]]（C3-单选-01 即考查 4 大债的发生原因的分类）

### 2. [[无因管理]] 三要件 + 法律效果

#### 三要件（§979）

| 要件 | 内容 | 排除情形 |
|---|---|---|
| ① **管理他人事务** | 必须是他人的事务 | 自己的事务不构成 |
| ② **没有法定 / 约定义务** | 无义务而管理 | 监护人对被监护人 = 有义务 |
| ③ **为他人利益的意思** | 主观为他人 + 客观利他 | 纯为自己利益 ≠ 无因管理 |

**关键陷阱**：
- 即使**初衷有为自己利益**，但**同时**也为他人利益，仍可构成（C3-单选-03 经典案例：邻居为自家安全顺便加固对方房屋 = 仍属无因管理）
- 管理**违法 / 违背公德**事务 ≠ 无因管理（C3-单选-02 A 选项）
- 管理**他人本不必管的事务**（如代替朋友尽道德义务）≠ 无因管理（C3-单选-02 C 选项）

#### 法律效果（§980-§984）

| 效果 | 内容 | 法条 |
|---|---|---|
| **必要费用偿还**请求权 | 管理人有权请求受益人偿还**必要费用**+ 利息 | §979 |
| **管理引起的损失**赔偿请求权 | 管理人因管理受损 → 受益人在受益限度内补偿 | §979 |
| **管理事务不当**的责任 | 管理人**故意 / 重大过失** → 担责 | §982 |
| **紧急情况免责** | 紧急救助 + 一般过失 → 不担责 | §984 |

### 3. [[不当得利]] 四要件 + 法律效果

#### 四要件（§985）

| 要件 | 内容 |
|---|---|
| ① **一方获得利益** | 财产增加（积极得利 / 消极得利） |
| ② **他方受到损失** | 财产减少 |
| ③ **得利与损失之间有因果关系** | 同一原因导致 |
| ④ **没有法律根据** | 无合同 / 法律规定的合法原因 |

#### 不当得利 4 类**排除情形**（§985 但书）

| 类型 | 内容 | 真题 |
|---|---|---|
| ① 履行**道德义务**之给付 | 如赡养祖父母 | C3-单选-04 C |
| ② 给付**到期债务**（即使诉讼时效已过）| 自然债务的偿还 | C3-单选-04 B |
| ③ 明知**没有给付义务而给付** | 自愿给付 | — |
| ④ 因**不法原因**而给付（如赌博） | — | — |

#### 善意得利人 vs 恶意得利人（§986-§987）

| 维度 | 善意得利人 | 恶意得利人 |
|---|---|---|
| 返还范围 | **现存利益**（已不存在的不返还） | **全部利益**+ 损失赔偿 |
| 利息 | 不付 | 付 |

→ 区分善 / 恶在主观题中是关键。

### 4. 与 [[合同总则]] / [[侵权责任编]] / [[物权编]] 的边界

[[不当得利]] 在主观题中常与**其他请求权基础竞合**：

```
事实：A 拾得 B 的 100 元，用以清偿对 C 的债务
请求权梳理：
  ① C 是否善意？善意 = 债务清偿有效 → C 不还（保护善意第三人）
  ② B 对 A 有不当得利返还请求权（§985 — A 无法律根据获利）
  ③ B 对 A 也有侵权请求权（§1165 — 侵犯所有权）
  ④ 两个请求权竞合，B 择一
```

**4 大请求权基础**（[[请求权基础]]）覆盖：
1. 合同请求权 → 总则 + 典型合同
2. **不当得利返还请求权** → 准合同
3. **无因管理偿还请求权** → 准合同
4. 物权请求权 / 侵权请求权 → 物权编 / 侵权责任编

来源：[[请求权基础]] · [[合同章真题库]] C3-多选-01

## 尚待解决的问题

### 高优先级

1. **不当得利 4 类排除情形**：道德义务 / 自然债务 / 明知无义务 / 不法原因 — 客观题高频
2. **无因管理三要件**：他人事务 + 无义务 + 为他人意思 — 主观题入口

### 中优先级

3. **善意 / 恶意得利人**：返还范围差异 — 主观题计算题
4. **请求权竞合**：不当得利 vs 物权 vs 侵权 — 主观题归类

### 低优先级

5. 无因管理 vs **代理 / 代为履行**的边界
6. 不当得利与**合同无效返还**（§157）的关系

## 用法建议

- C3 题量虽少（6 道）但**覆盖度高**——把这 6 道吃透，准合同基本就够用
- 真题导向**反推考点**：6 道题已覆盖 4 类典型陷阱（道德义务给付 / 自然债务 / 紧急救助管理 / 初衷有自利但客观利他）
- 准合同**与合同总则的违约责任 / 物权编的善意取得**容易交叉考——主观题第二步要列举所有请求权
