# 典型合同 深度报告

> 综合自 [[合同编]] 第二分编 + 真题库 32 道 C2 真题 | 生成日期：2026-06-06

## 背景概述

**典型合同**是 [[民法典]] [[合同编]] 内部的第二个子板块，与 [[合同总则]]、[[准合同]] 并列：

```
合同编（[[合同编]]）
  ├─ 合同总则  ← 通用规则（已展开）
  ├─ 典型合同  ← 本报告主题（19 种具体合同 × 各自规则）
  └─ 准合同    ← 类合同之债
```

典型合同 = 民法典**逐章规定**了规则的合同类型。**非典型合同**（无名合同）则参照适用最相类似典型合同的规定。

> **分值定位**：典型合同在客观题中分值约占合同编的 **20-30%**，且**重点严重不均** — 买卖 / 租赁 / 保证 / 委托是核心，融资租赁 / 行纪 / 中介常出陷阱小题。

## 核心观点

### 2. 典型合同的体系定位 = "总则 + 特别法"

典型合同对应规则与 [[合同总则]] 是 **"特别法 + 一般法"** 关系：

```
具体合同纠纷
   ↓
①  先用典型合同章节的特别规则（如买卖的风险负担 §604）
   ↓ 无规定时
②  适用合同总则的通用规则（如违约责任 §577）
   ↓ 无规定时
③  适用总则编的法律行为规则（如可撤销 §147）
```

→ **解题入口**：识别题目对应的典型合同 → 找对应章节特别规则 → 再回退到总则。

### 3. 典型合同的 5 个"超高频陷阱区"

按真题密度排序：

#### ① 买卖合同 — 风险负担 + 标的物检验期 + 多重买卖

- **风险负担规则**（§604）：标的物毁损灭失风险**自交付时转移**。例外：
  - 出卖人违约 → 风险不转移
  - 买受人拒绝受领 → 风险自违约时转移给买受人（[[合同章真题库]] C2-单选-03）
- **标的物检验期**（§621-§623）：买受人合理期间未通知 → 视为合格；2 年极限保护
- **多重买卖顺位**：[[合同编通则司法解释]] 重要解释

#### ② 租赁合同 — 转租 / 买卖不破租赁 / 优先购买权

- **未经同意擅自转租**（§716）：出租人可解除，承租人 + 次承租人对损坏负责
- **买卖不破租赁**（§725）：租赁物所有权变动不影响租赁
- **承租人优先购买权**（§726）：同等条件优先

#### ③ 保证合同 — 一般保证 vs 连带责任保证 + 保证期间

- **2021 新规**：未约定 → **一般保证**（旧法是连带责任保证），重要变更
- **保证期间**：未约定 = 主债务履行期满 6 个月；约定不明 = 2 年
- **保证人资格**（§683）：公益机关法人不得作保证人，分支机构无主体资格
- **先诉抗辩权**（§687）：仅一般保证人享有，特定情形丧失

#### ④ 委托合同 vs 行纪 vs 中介

| 维度 | [[委托合同]] | [[行纪合同]] | [[中介合同]] |
|---|---|---|---|
| 行为目的 | 处理委托人事务（广） | 以行纪人**自己**名义为委托人买卖 | 报告订约机会 / 媒介订约 |
| 是否成约方 | 是（受托人为委托人代理）| 是（自己为合同方，与第三人订约）| 否（只牵线） |
| 报酬 | 可有偿可无偿 | 必有偿 | 必有偿 |
| 风险 | 委托人承担 | 行纪人先承担再转嫁 | 中介人不担保结果 |

→ 一致出现在题目中："以自己名义"=行纪，"促成订约"=中介。

#### ⑤ 客运合同 — 承运人责任 + 免票乘客

- **承运人对旅客伤亡的严格责任**（§823）：除自身健康原因 / 旅客故意 / 重大过失外，全部担责
- **免票乘客 + 持优惠票 + 经承运人许可搭乘**同样适用
- **旅客自身原因**（如突发心脏病、自杀）→ 不担责

来源：[[2026-06-06-合同章真题库]] 32 道 C2 真题归纳

### 4. 与 [[合同总则]] / [[准合同]] 的横向关系

| 横向考点 | 典型合同表现 | 总则 / 准合同对应 |
|---|---|---|
| 解除合同 | 各合同**特殊解除条件**（赠与人任意撤销 §658 / 委托人随时解除 §933） | 总则 [[解除]] §562-§565 |
| 违约救济 | 买卖瑕疵履行 → 修理 / 减价 / 退货 / 重做（§621-§623） | 总则 [[违约责任]] §577 |
| 不当得利 | 试用买卖未购买 → 返还（[[不当得利]] 边界） | 准合同 [[不当得利]] §985 |
| 缔约过失 | 中介报告虚假信息 → 缔约过失（§962） | 总则 [[缔约过失责任]] §500 |

### 5. 学习顺序建议

按"考点密度 × 难度"排：

1. **🔥 优先**：买卖（风险 / 检验期）+ 租赁（转租 / 买卖不破租赁）+ 保证（一般 vs 连带 + 期间）
2. **⚙️ 中等**：委托 / 行纪 / 中介 三类区分 + 客运（旅客伤亡责任）+ 赠与（任意撤销 + 法定撤销）
3. **📚 后期**：融资租赁（三方关系）+ 技术合同（权属分配）+ 物业服务（合同效力 / 解除）
4. **背景了解**：供用电 / 仓储 / 货运 / 行纪 / 保理 / 合伙

## 尚待解决的问题

### 高优先级（高频考点）

1. **买卖合同**：标的物风险负担、检验期、多重买卖
2. **租赁合同**：转租、买卖不破租赁、承租人优先购买权
3. **保证合同**：保证方式（一般 vs 连带）、保证期间、保证范围
4. **委托 / 行纪 / 中介 三类区分**

### 中优先级

5. **融资租赁**：三方关系，所有权移转
6. **客运合同**：承运人责任
7. **赠与合同**：任意撤销权 + 法定撤销权 + 公益赠与

### 低优先级

8. **建设工程合同**：实际施工人、垫资、停建
9. **承揽合同**：定作人任意解除权
10. **技术合同**：成果权属、保密义务
11. **物业服务合同**：业主大会解除权
