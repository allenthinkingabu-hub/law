# 合同总则考点 深度报告

> 综合自 2 篇素材 + 当前知识库 20+ 篇相关 wiki 页面 | 生成日期：2026-06-05

> **本报告聚焦"考点级"**：把 [[合同编]] 下 [[合同总则]] 的 7 个板块逐一拆成具体考点 + 法条 + 当前覆盖度 + 复习优先级。与 [[合同总则-深度报告]] 的区别是：那篇是"合同总则是什么"，本篇是"合同总则要考什么"。

## 背景概述

[[合同编]] 是 [[民法]] 分值之最（≈48 分中占大头），而其内部的 [[合同总则]] 又是合同编的"通用规则层"。法考的 [[合同编]] 客观题与主观题考点，**约 70%-80% 落在合同总则**（典型合同与准合同各占约 15%）—— 这个比例是 [[2026-06-05-民法目录级骨架]] 的强调，本报告以此为前提，逐块拆考点。

合同总则的 7 块按合同生命周期排列：

```
订立 → 效力 → 履行 → 保全 → 转让 → 终止 → 违约责任
```

下面的"核心观点"按这 7 块依次拆。

## 尚待解决的问题（推荐 ingest 优先级）

按"主观题命中频率 × 当前知识库缺口"排序：

### 🔥 高优先级（下次该吃的）

1. **合同效力四级区分**（无效 / 可撤销 / 效力待定 / 未生效）
   - 法条群：§144、§146-§154、§145、§171、§503、§502、§158
   - 为什么：主观题大案例**第二步**固定问题，且当前 [[合同生效]] 只到入门级
   - 建议素材：以"四格模板"风格做的合同效力精解

2. **违约责任**
   - 法条群：§577-§591
   - 为什么：主观题大案例**第二个终点**（救济阶段）；违约金与损害赔偿计算是高频
   - 建议素材：违约形式 + 责任方式 + §584 可预见性规则 + §585 违约金调整

3. **[[代位权]] / [[撤销权]]**
   - 法条群：§535-§542
   - 为什么：已知**断链**；与 [[物权编]] 善意取得易合考；构成要件高度抽象
   - 建议素材：合同保全制度专题

### ⚙️ 中优先级（地基补强）

4. **三大履行抗辩权**（同时 / 先 / 不安）
   - 法条群：§525-§528
   - 为什么：客观题高频；与典型合同结合密

5. **合同的解除**（约定 vs 法定 + 解除权）
   - 法条群：§562-§565
   - 为什么：高频；与各典型合同的特殊解除条件配套

## 用法建议

当你做下一次 ingest 时：

- **优先选高频考点**：先吃效力 + 违约责任，能"激活"知识库一半的合同总则区域
- **复用 [[考点四格模板]]**：每一块都用同样四格结构（是什么/易混 → 怎么考、坑 → 客观答 → 主观答），与现有 [[要约]] / [[承诺]] 的结构对齐
- **触发自动断链补齐**：消化"保全"那一刻，[[代位权]] / [[撤销权]] 的断链会自动闭合
