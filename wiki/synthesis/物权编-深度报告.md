# 物权编 深度报告

> 综合自联网权威源 + 当前知识库相关页面 | 生成日期：2026-06-14

## 背景概述

**物权编**是 [[民法典]] 第二编（编 02），是民法的**静态财产归属法 + 担保物权法**。

它回答的核心问题是：**"东西归谁、谁能对物做什么、物受侵害时怎么救济"**。如果说 [[合同编]] 是规范"财产怎么动起来"的**动态债法**，那么物权编就是规范"财产静下来归谁所有、在谁手上设了什么权利"的**静态财产法**——一动一静，分工互补，共同构成民法的财产法骨架。

在 [[民法典]] 的七编体例中，物权编与其五分编的位置如下：

```
民法典（七编）
  ├─ 编 01 总则编        （地基 · 法律行为效力 / 代理 / 时效）
  ├─ 编 02 物权编 ← 本报告主题（静态财产归属 + 担保物权 · §205–§462）
  │     ├─ 第一分编 通则       （§205–§239 · 物权变动总规则 + 物权保护）
  │     ├─ 第二分编 所有权     （§240–§322 · 共有 / 相邻 / 建筑物区分 / 善意取得）
  │     ├─ 第三分编 用益物权   （§323–§385 · 土地承包 / 建设用地 / 居住权 / 地役权）
  │     ├─ 第四分编 担保物权   （§386–§457 · 抵押 / 质押 / 留置）
  │     └─ 第五分编 占有       （§458–§462 · 对物的事实管领状态）
  ├─ 编 03 合同编        （动态债法 · 财产怎么流转）
  ├─ 编 04 人格权编
  ├─ 编 05 婚姻家庭编
  ├─ 编 06 继承编
  └─ 编 07 侵权责任编
```

物权编 = 民法典第二编，对应 §205–§462，下设**五分编、二十章**（条文范围已经多家政府/法院权威全文交叉核实，见正文"数据源表"）。

**静 / 动分工**：[[物权编]]（静）管"归属与支配"——所有权、用益物权、担保物权这三类物权各自划定"谁对物有什么权能"；[[合同编]]（动）管"流转与债务"——买卖、租赁、借款等如何使财产在主体之间移动。一个典型交易（如买房）必然同时落在两编上：买卖**合同**是债法事项（合同编），房屋**所有权移转**是物权变动事项（物权编），两者由 [[区分原则]]（§215）严格分层——这正是物权编与合同编最重要的接口。

## 核心观点

### 1. 物权编的定位 = 财产静态归属规则 + 担保物权

物权编与合同编恰成"静 / 动"对照：

| 维度 | [[物权编]]（静） | [[合同编]]（动） |
|---|---|---|
| 调整对象 | 财产的**归属与支配** | 财产的**流转与债务** |
| 权利性质 | **物权**（绝对权 · 对世 · 排他） | **债权**（相对权 · 对人 · 平等） |
| 核心问题 | 东西归谁、谁能支配、受侵害如何救济 | 谁向谁、依何约定、给付什么 |
| 时间属性 | 静态归属（一个时点上"谁是权利人"） | 动态过程（订立→履行→终止的生命周期） |
| 典型权利 | 所有权 / 用益物权 / 担保物权 / 占有 | 合同请求权 |

物权编内部又分两大功能区：

- **财产静态归属法**：第一至第三分编 + 第五分编（通则、所有权、用益物权、占有）——解决"物归谁、谁享有何种支配权能"。
- **担保物权法**：第四分编（§386–§457）——为债权实现服务，就特定财产**优先受偿**。担保物权是物权编里**最贴近债法**的部分，也是 2026 法考重点（详见后文与 [[担保]] 专题的关系）。

来源：[[2026-06-05-民法目录级骨架]]、[[物权编]]、联网权威源（见数据源表）。

### 2. 物权编五分编结构（一表概览）

| 分编 | 性质 | 条文 | 主要内容 |
|---|---|---|---|
| **第一分编 通则** | 总纲 · 变动规则 · 救济 | §205–§239 | 物权概念与原则（§205–§207）；物权变动总规则——不动产登记生效 / 动产交付生效 / 非基于法律行为的变动（§208–§232）；物权保护请求权体系（§233–§239） |
| **第二分编 所有权** | 最完整的物权 | §240–§322 | 所有权权能与征收征用（§240–§245）；三类所有权主体（§246–§270）；业主建筑物区分所有权（§271–§287）；相邻关系（§288–§296）；共有（§297–§310）；**所有权取得的特别规定（§311–§322，含善意取得§311、添附§322）** |
| **第三分编 用益物权** | 对他人之物的使用收益 | §323–§385 | 一般规定（§323–§329）；土地承包经营权（§330–§343）；建设用地使用权（§344–§361）；宅基地使用权（§362–§365）；**居住权（§366–§371，民法典新增）**；地役权（§372–§385） |
| **第四分编 担保物权** | 优先受偿 · 为债权服务 | §386–§457 | 一般规定（§386–§393）；抵押权（§394–§424，含最高额抵押）；质权（§425–§446，动产质权 + 权利质权）；留置权（§447–§457） |
| **第五分编 占有** | 对物的事实管领状态 | §458–§462 | 有权 / 无权占有；善意 / 恶意占有的法律后果（§459–§461）；占有保护请求权 + 一年除斥期间（§462） |

> 记忆口径：**通则定规则、所有权定归属、用益物权用别人的物、担保物权保债权、占有管事实状态**。前三 + 第五分编是"静态归属"，第四分编是"担保"。

来源：条文范围经上海规资局、广东自然资源厅、最高检官网民法典物权编全文交叉核实（见数据源表）。

### 3. 三大基本原则 + 区分原则

物权编受四条基本原理贯穿。前三条是"物权法定 / 一物一权 / 公示公信"三大原则，第四条 [[区分原则]] 是法考高频的"操作性原则"：

| 原则 | 法源 | 核心含义 | 核实状态 |
|---|---|---|---|
| **物权法定** | §116（**总则编**，非物权编） | 物权的**种类和内容由法律规定**，当事人不得自由创设——整个物权编的根本约束 | 条号位于总则编，通说确认；该条不在物权编内，标注时勿混淆 |
| **一物一权** | 无单一明文条号（学理原则） | 一物之上只能有一个所有权；物权客体须为**特定独立之物**（支配排他） | 学理通说，无单一对应法条，**（依据未核实为单一条号，待联网验真）** |
| **公示公信** | §208 / §209（登记）/ §224（交付）/ §311（善意取得） | 不动产以**登记**、动产以**交付**为公示方法；登记簿 / 占有有权利推定与公信力，善意第三人受保护 | 条文已核实 |
| **区分原则** | §215（物权编） | 设立 / 变更 / 转让 / 消灭不动产物权的**合同自成立时生效**，未办物权登记**不影响合同效力**——区分"债权合同效力（原因行为）"与"物权变动效果（处分行为）" | §215 原文已核实，法考高频考点 |

另有两条贯穿性效力规则：**平等保护原则**（§207：国家、集体、私人物权受法律平等保护）与**物权优先 / 追及效力**（物权优先于债权、定限物权优先于所有权；权利人可向占有人追及主张返还 §235，贯穿担保物权优先受偿 §386 与物权请求权 §233–§239）。

**[[区分原则]] 为何是法考第一抓手**：§215 把"合同效力"与"物权变动"切成两条独立轨道——合同自合意时生效（债权轨），物权自公示时变动（物权轨）。最经典的陷阱是"未登记 → 合同未生效"（错，违反 §215）。区分原则**≠ 物权行为无因性**，我国不采无因性立场。该原则已建独立 wiki 页 [[区分原则]]，是物权主观题分析的固定第一步。

来源：§215 原文经最高检物权编全文核实；物权法定 §116 位置与一物一权学理性质见数据源表"notes"。

### 4. 物权变动是"枢纽 / 入口"考点

物权编最核心的体系骨架是**物权变动**——它是连接合同编（原因行为）与物权归属（结果）的枢纽，也是客观题、主观题最密集的入口。物权变动按"是否基于法律行为"分两大类：

```
                       物权变动
                          │
          ┌───────────────┴───────────────┐
          ▼                               ▼
  基于法律行为的变动                 非基于法律行为的变动
  （买卖 / 赠与 / 抵押合同）          （§229–§232）
          │                               │
  ┌───────┴───────┐              ┌────────┼──────────┐
  ▼               ▼              ▼        ▼          ▼
不动产           动产         法律文书   继承     事实行为
§209 登记生效   §224 交付生效  / 征收决定  §230   §231（合法建造/拆除）
（§214 记载时）  ├ 简易交付§226 §229       自继承   成就时取得
                ├ 指示交付§227 生效时      开始时
                ├ 占有改定§228            取得
                └ 特殊动产 §225
                  （交付生效 + 登记对抗）
                                ⚠️ §232：此类不动产物权"处分时"须先登记
```

四个高频要点：

1. **基于法律行为**：不动产 §209 **登记生效**、动产 §224 **交付生效**——这是公示原则的落地。动产交付含四种方式：现实交付（§224）、简易交付（§226）、指示交付（§227）、占有改定（§228）。
2. **特殊动产**（船舶 / 航空器 / 机动车 §225）：**交付生效 + 登记对抗**（不是登记生效）。多重买卖顺位：先受领交付 > 先登记 > 合同先成立；"善意第三人"范围不含债权人（物权编解释一 §6）。
3. **非基于法律行为**（§229–§232）：法律文书 / 征收决定、继承、事实行为**自动生效**，不以登记 / 交付为要件；但**处分时**须先办登记（§232）。易错点：§229 法律文书限"形成判决"（如分割共有物判决），给付 / 确认判决不直接引起物权变动。
4. **区分原则贯穿全程**（§215）：合同有效 ≠ 物权变动完成。已建页 [[不动产登记]] 用"老王小李买房"四场景完整演示了这一窗口期。

→ 物权变动是物权编的"地基入口"：先定合同效力（债权轨）→ 再定物权是否变动（物权轨）→ 再定请求权基础。后续所有权、担保物权、占有的具体规则都建在这套变动逻辑上。

来源：§209 / §214 / §224–§228 / §229–§232 经最高检官网逐条核实；特殊动产 + 多重买卖规则见物权编解释一 §6 / §19（数据源表）。

### 5. 物权编与 [[请求权基础]] 的关系

[[请求权基础]] 是 [[法考主观题]] 民法题的统一分析框架——"谁能向谁、依据哪个请求权、主张什么"。**物权请求权（物上请求权）是四大请求权基础之一**（另三为合同、不当得利、侵权），其法源即物权编第三章"物权的保护"（§233–§239）：

| 物权请求权 | 法条 | 内容 |
|---|---|---|
| 确认物权 | §234 | 请求确认物权归属、内容 |
| **返还原物** | §235 | 对无权占有人请求返还（追及效力） |
| **排除妨害 / 消除危险** | §236 | 对妨害或可能妨害请求排除 / 消除 |
| 修理 / 重作 / 更换 / 恢复原状 | §237 | 物权受损时的修复类请求 |
| **损害赔偿** | §238 | 侵害物权造成损害的赔偿（本质为侵权请求权） |

§239：上述方式可**单独或合并**适用。

**三个衔接要点**：

1. **物权请求权 vs 债权请求权**：返还原物、排除妨害（§235 / §236）是物权请求权（仅凭权属即可主张）；损害赔偿（§238）本质是**侵权请求权**，与侵权责任编（§1164 起"侵害物权"责任）竞合衔接。
2. **与诉讼时效**：§196（总则编）规定排除妨害 / 消除危险 / 停止侵害请求权**绝对不适用**诉讼时效；返还原物则**视是否登记**区分——登记的不动产 / 特殊动产返还请求权不适用时效，未登记动产返还请求权适用时效。
3. **与占有保护请求权**：第五分编 §462 的占有保护请求权（返还原物 / 排除妨害 / 消除危险）仅凭"占有事实"即可主张，与 §235 物权返还请求权（须证明本权）性质不同，**可竞合并存**；但占有返还请求权有 **1 年除斥期间**（自侵占发生之日起算）。

来源：§233–§239 经最高检官网逐条核实；§196 经最高法民法典全文官方页核实（数据源表）。

### 6. 担保物权与 [[担保]] 专题：跨编合考

物权编第四分编**担保物权**（§386–§457）与合同编**保证合同**（§681–§702）共同构成 [[担保]] 制度的"物保 + 人保"两翼。法考的高效策略是**把这两块合并成一个"担保"专题**学习（[[2026-06-05-民法目录级骨架]] 称"省一半力气"），因为二者统一适用同一部头号司法解释。

```
                  担保制度（[[担保]] 专题）
                          │
          ┌───────────────┴───────────────┐
          ▼                               ▼
      物保（物权编 第四分编）            人保（合同编）
      §386–§457                        保证合同 §681–§702
          │                               │
   ┌──────┼──────┐                   一般保证 / 连带保证
   ▼      ▼      ▼                   保证期间 / 保证方式推定
 抵押权  质权   留置权
 §394   §425   §447
 (登记/  (动产/  (法定)
  对抗)   权利)
          │
          └──── 统一适用 ────┐
                            ▼
        《最高法关于适用民法典有关担保制度的解释》
        法释〔2020〕28 号 · 共 71 条 · 2021-01-01 施行
        （跨编整合人保与物保 · 担保专题头号司法解释）
```

**担保物权三大典型**：

| 类型 | 法条 | 公示 / 设立 | 关键特征 |
|---|---|---|---|
| **抵押权** | §394–§424 | 不动产登记生效（§402）；动产登记对抗（§403） | 不转移占有；含最高额抵押（§420–§424） |
| **质权** | §425–§446 | 动产交付生效（§429）；权利质多以登记 / 交付凭证设立 | 转移占有 / 权利凭证；含权利质权（§440–§446） |
| **留置权** | §447–§457 | 法定（合法占有债务人动产 + 债务到期未清偿） | 须与债权同一法律关系（企业间除外 §448） |

**通则要点**：从属性（§388 担保合同为从合同）、担保范围（§389）、物上代位（§390）、**禁止流押 / 流质**（§401 / §428：到期不履行约定担保物直接归债权人无效，只能折价 / 拍卖 / 变卖后**优先受偿**）、消灭事由（§393）。

**2021 新规与跨编合考热点**（依《担保制度解释》28 号 + 民法典本体）：抵押财产转让"通知非同意"+ 追及效力（§406 + 解释 §43）；混合担保的实现顺序与共同担保人内部追偿（§392 + 解释 §13 / §18）；公司对外担保的决议程序（§504 + 解释 §7–§9，民商合考）；价金超级优先权（§416 + 解释 §57）；担保物权竞存清偿顺序（§414 / §415 / §456）；让与担保等非典型担保纳入功能主义体系（§388 + 解释 §68）；保证方式推定为一般保证（§686，方向与原担保法相反）。

来源：担保制度解释 71 条经 court.gov.cn 官网核实；条文与解释条号经联网逐条核实（数据源表"第四分编"板块）。

> ⚠️ 跨编提示：担保物权的完整体系**必须与合同编保证、《担保制度解释》合并**才能闭环。本报告只给"物权编是什么"层面的骨架，担保物权的考点级深度展开建议另见 [[物权编考点 深度报告]] 与 [[担保]] 专题页。

### 7. 物权编的 2026 学习地位

- **梯队定位**：第一梯队 **T1**（与合同编、侵权责任编、总则编同列）。分值高 · 频率高 · 难度中高 · 主 + 客并考（[[2026-06-05-民法目录级骨架]]）。
- **担保物权常进主观**：第四分编担保物权是物权编里**最易进主观大题**的板块，且与合同编保证合并构成主观题"担保专题"。
- **善意取得是绝对头号高频**：§311 善意取得 + 物权编解释一 §14–§20 的系统配套，是物权编客观题出现率最高的考点（详见"尚待解决的问题"）。
- **活跃配套司法解释（2 部）**：
  - 《最高法关于适用民法典物权编的解释（一）》**法释〔2020〕24 号**，2021-01-01 施行——**经 court.gov.cn 官网全文核实实为 21 条**（"24"是文号序号，与条数无关；本知识库此前若标"24 条"应更正为 **21 条**）。
  - 《最高法关于适用民法典有关担保制度的解释》**法释〔2020〕28 号**，2021-01-01 施行，**共 71 条**（court.gov.cn 官网核实）。
- **近三年大纲口径稳定**：经联网核实 2024→2025→2026 司法部公告与大纲消息，**物权编 / 担保制度均未被列为大纲修订对象**（2026 大纲点名修订的是宪法 / 商法 / 环资 / 国际法 / 民诉等，民法未在修订之列）——物权编考查口径稳定，评级无需为大纲修订做年度调整。
- **官方不公布精确考频**（已知客观事实）：司法部 2021 公告明确"不公布试题及参考答案"，故任何"精确官方考频"数据均不存在；本报告涉及的高 / 低频判断均为多源权威综合可追溯判断，**未编造任何考频数字**。

来源：物权编解释一 21 条订正、担保制度解释 71 条、2024–2026 大纲稳定性证据链，均经联网核实（数据源表）。

### 推荐复习路径（按学习依赖排序）

物权编的高效复习顺序，应**先吃"入口枢纽"，再吃"高频取得规则"，再吃"易进主观的担保"，最后补"用益物权与占有"**：

```
1. 物权变动（入口枢纽）
   区分原则 §215 → 不动产登记 §209 → 动产交付 §224–§228
   → 特殊动产 §225 → 非基于法律行为变动 §229–§232
        ↓ 变动逻辑是后面所有规则的地基
2. 所有权特别取得（头号高频）
   善意取得 §311 + 解释一 §14–§20（绝对第一高频）
   → 遗失物排除 §312 → 添附 §322 → 共有优先购买权 §306
        ↓
3. 担保物权（最易进主观 · 与合同编保证合并学）
   一般规定（从属性 §388 · 禁止流押流质 §401/§428）
   → 抵押权 §394–§424（登记 §402/§403 · 转让 §406 · 竞存 §414/§415）
   → 质权 §425–§446 → 留置权 §447–§457
   → 配合《担保制度解释》28 号 + 合同编保证 §681–§702
        ↓
4. 用益物权（新增制度优先）
   居住权 §366–§371（2021 新增热点）
   → 建设用地使用权（房地一体 §356/§357）→ 土地承包三权分置 §330
   → 地役权 §372–§385
        ↓
5. 占有（收尾 · 边缘但易得分）
   善意/恶意占有效果 §459–§461 → 占有保护请求权 §462（1 年除斥期间）
```

> 在 [[考点四格模板]] 指导下，对每一块都用四格结构（是什么 / 易混 → 怎么考、坑 → 客观答 → 主观答）展开；主观题统一套用 [[结论先行答题法]] 与 [[请求权基础]] 框架。

### 与其它编的连接点

- **物权变动 ↔ [[合同编]]（区分原则 §215）**：物权变动以债权合同为原因行为（买卖 §595、赠与、抵押合同等），但合同有效 ≠ 物权变动完成，须再经登记 / 交付（§209 / §224）。合同效力规则与公示生效规则**分层适用**——这是两编最重要的接口。
- **担保物权 ↔ [[合同编]] 保证（[[担保]] 专题）**：第四分编担保物权（物保）与合同编保证（人保）统一适用《担保制度解释》28 号，跨编合考（详见核心观点 6）。
- **物权请求权 ↔ [[请求权基础]] / [[侵权责任编]]**：物权保护章 §233–§239 是物上请求权的法源；损害赔偿（§238）与侵权责任编 §1164 起"侵害物权"责任竞合。
- **善意取得 ↔ [[合同编]] 无权处分（§597）**：善意取得（§311）与无权处分买卖合同效力（§597：无权处分不影响买卖合同效力）共同决定无权处分情形下买受人能否取得所有权——与 [[区分原则]] 呼应。
- **用益物权 / 居住权 ↔ [[合同编]]**：土地承包经营权、建设用地使用权、居住权（设立须订立合同 §367 + 登记 §368）的设立均以合同为基础。

## 尚待解决的问题（建议下次搜集素材的方向）

物权编是当前知识库最大空白区（5 分编中仅通则有 2 页实体）。按板块列出待覆盖重点，并标注研究数据中得出的高频信号：

### 第二分编 所有权（含头号高频）

- **善意取得 §311 + 物权编解释一 §14–§20**（⭐ 绝对头号高频，研究判定 ★★★★★）：四要件（无权处分 + 受让人善意 + 合理价格 + 登记 / 交付完成）；经典陷阱——**占有改定 §228 不满足"交付"要件 → 不适用善意取得**；合同无效 / 被撤销不适用（解释一 §20，与区分原则呼应）。
- **遗失物善意取得排除 + 2 年回赎期 §312–§314**：遗失物原则不适用善意取得；2 年回赎为除斥期间；盗赃物通说准用遗失物规则。
- **业主建筑物区分所有权 §271–§287**：表决"双过半 / 四分之三"规则（§278，先过 2/3 参会门槛再算同意比例，两层计算易错）；车位车库归属（§275 约定优先 / "首先满足业主需要"）；共有部分收益（解释 §14）。
- **共有优先购买权 §305 / §306 + 解释一 §9–§13**：同等条件、15 日 / 6 个月 / 最长 1 年行使期间、共有人之间转让不适用。
- **相邻关系 §288–§296**：与地役权"约定 / 登记对抗 / 有偿"的对比（相邻关系为法定 / 无偿 / 不登记）。
- **添附 §322**（民法典新增制度）：加工 / 附合 / 混合的归属规则。

### 第三分编 用益物权（新增制度优先）

- **居住权 §366–§371**（⭐ 2021 新增热点，研究判定 ★★★★，本分编唯一经最高检官网点名支撑的高评级）：书面合同（§367）+ 登记生效（§368）+ 原则无偿、不得转让继承（§369，两个"除外"范围不同是陷阱）；遗嘱设立 §371；居住权与抵押 / 租赁竞存及执行涤除（最高法实务文章）。
- **建设用地使用权**：登记生效 §349；**房地一体** §356 / §357（地随房走 / 房随地走，跨担保物权 §397 合考）；70 年产权自动续期 §359。
- **土地承包经营权三权分置 §330 / §339–§342**：所有权（集体）—承包权（农户）—经营权（流转）三层；土地经营权流转 5 年以上登记对抗 §341。
- **地役权 §372–§385**：合同生效设立 + 登记对抗 §374；从属性与不可分性 §380–§383。

### 第四分编 担保物权（最易进主观 · 与担保专题合并）

- **抵押财产转让新规 §406 + 解释 §43**（⭐ 2021 头号新规）：抵押期间可自由转让，仅需"通知"非"同意"，抵押权追及效力不受影响。
- **担保物权竞存清偿顺序 §414 / §415 / §456**：多抵押按登记时间 / 已登记优先 / 均未登记按比例；抵押与质权按公示在先优先；留置权优先于抵押 / 质权（法定优先于意定）。
- **价金超级优先权 §416 + 解释 §57**："交付后十日内登记"+ "留置权人除外"。
- **共同担保人内部追偿 §392 + 解释 §13 / §18**；**物保人保并存实现顺序 §392**（债务人自物保优先于人保；第三人物保与人保平等）。
- **公司对外担保决议程序 §504 + 解释 §7–§9**（民商合考）。
- **禁止流押流质 §401 / §428**；**让与担保等非典型担保 §388 + 解释 §68**（功能主义）。
- **留置权成立要件 §447 / §448**（同一法律关系 + 企业间例外）；**宽限期 §453**（60 日以上）。
- **最高额抵押 §420–§424**；**权利质权 §440–§446**（应收账款质权 §445）。
- **《担保制度解释》28 号 71 条具体条文**：尚未逐条消化，是担保专题头号司法解释源。

### 第五分编 占有

- **善意 / 恶意占有效果三件套 §459–§461**：孳息、必要费用（**只有善意占有人能要回**，最爱设陷阱）、损害赔偿随善意 / 恶意而异。
- **占有保护请求权 §462**：返还原物 / 排除妨害 / 消除危险 + 损害赔偿；返还原物请求权 **1 年除斥期间**（自侵占发生之日起算，不中止 / 中断；排除妨害不受 1 年限制）；与 §235 物权请求权可竞合。

### 元数据与配套司法解释

- **物权编解释一条数订正**：本库若标"24 条"应更正为 **21 条**（"24"是文号序号）。
- **物权编解释一 21 条 + 担保制度解释 71 条**：逐条研读，是物权编最稳定的"必考"配套信号。

> 诚实声明：以上★级均来自联网研究的多源权威综合判断（司法解释体量 / 最高法答记者问立法导向 / 近三年大纲稳定性 / 头部机构综合判断），**非官方精确考频**（官方不公布）。部分用益物权考频依据在研究中标注"未能联网核实为权威高频信号、为框架推断"，建库时应据实标注。
