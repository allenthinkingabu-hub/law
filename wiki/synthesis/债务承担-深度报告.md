# 债务承担 · 深度报告

> 综合自 [[债务承担]] 实体页 · [[民法-合同-债务承担模型]] · [[合同总则考点-深度报告]] · 6 道关联真题 | 生成日期：2026-06-14

## 背景概述

债务承担是民法典合同编"债的转让"板块核心制度，与 [[债权转让]] 对称构成"债的主体双向流动"体系。§551-§554 为基本条文，§391/§697 联动担保，《合同编通则解释》§51 新设债务加入人追偿权（"9 大创新之一"）。**对法考考生的意义**：债务加入是《民法典》新设制度，通则解释又补充了追偿权，双重新制度叠加使本考点成为考频最高的转让类题目。

---

## 核心知识结构

### 1. 两型分水岭——原债务人"退没退"

| 类型 | 法条 | 原债务人 | 生效要件 | 为什么 |
|---|---|---|---|---|
| **免责的债务承担**（债务转移）| §551 | **退出** | 须债权人**同意** | 换债务人=换偿付能力，对债主有风险 |
| **并存的债务承担**（债务加入）| §552 | **不退**，连带 | **通知**即生效 | 多人担责=对债主有利，无需同意 |

**与相邻制度的边界**（见 [[第三人介入债务的四种结构-对比]]）：

| 制度 | 法条 | 债务人是否变 | 触发事件 |
|---|---|---|---|
| 免责债务承担 | §551 | 换人 | 债权人同意 |
| 并存债务承担 | §552 | 加人（连带） | 通知到达 |
| 第三人代为清偿 | §523/§524 | **不变** | 第三人替还 |
| 保证 | §681 | 原债务人+保证人 | 从属+补充 |

### 2. 生效要件——两个"沉默"方向相反（最高频陷阱）

- **§551Ⅱ**：债权人被催告后**沉默 = 视为不同意**（债务转移**不成立**）
- **§552**：债权人收到加入通知后**未明确拒绝 = 可主张连带**（债务加入**成立**）

同样是"未答复"，一个砸、一个成——命题人反复在此设套。

### 3. 担保连锁——§391（物保）vs §697（人保）

**触发条件**：债务**转移**（免责承担）且担保人**未经书面同意**。

| 条款 | 担保类型 | 免责范围 | 有无但书 |
|---|---|---|---|
| **§391** | 物保（第三人抵押/质押）| 转移的"相应"部分 | **无"另有约定除外"**但书 |
| **§697Ⅰ** | 人保（保证）| 转移的"相应"部分 | **有**"债权人和保证人另有约定的除外" |
| **§697Ⅱ** | 人保（保证）| — | 债务**加入**不触发，保证责任**不受影响** |

> 计算口诀：**保住没转走的，免掉转走的**（500 万转走 200 → 担保人保 **300** 不是 200）。

### 4. 新债务人的权利义务（§553 / §554）

| 条款 | 内容 | 记忆 |
|---|---|---|
| §553 前段 | 可主张原债务人对债权人的**抗辩** | 抗辩随债走 |
| §553 后段 | 但**不得**以原债务人对债权人的债权主张**抵销** | 抵销权不过户 |
| §554 | 与主债务相关的**从债务**由新债务人承担 | 利息/违约金随走 |

### 5. 债务加入人追偿权（通则解释§51 · "9 大创新"）

- 有约定 → 按约定追偿
- 无约定 → 依**不当得利**法理，在**已履行范围内**向债务人请求
- 例外：加入人**明知/应知**加入会损害债务人利益的除外
- 法理依据：类推 §519 连带债务内部追偿

## 命题趋势分析

**1. 债务加入 > 债务转移**
债务加入是《民法典》新设制度，通则解释"9 大创新"提升了命题权重，近年出题密度明显高于债务转移。

**2. 担保连锁是"加分题"**
§391（物保）和§697（人保）联动考，会算"转走多少、保多少"就能拿满分。典型：`C2-单选-31` 考 1500 万（须同时完成 §575 免除 + §697 脱责两步运算）。

**3. "无效"是最大干扰词**
未同意/未通知的效果是"对债权人/债务人不生效/不对抗"，不是"无效"；内部约定仍有约束力。这是历年最常考的混淆点。

**4. §524 代为清偿是连环题的最后一步**
债权转让+债务转移+代为清偿三合一（`C1-单选-59`）是必出题型：第三方接了债、真正债务人却让原债务人先垫钱 → 垫钱人法定取得求偿权。

**5. 物保§391 无但书 vs 人保§697 有但书**
这个差异是进阶考点，多选题常考。物保担保人不论与债权人有无约定，均可脱责（但书无效）；人保有但书，书面约定继续担保的有效。

## 知识脉络（债的转让体系定位）

```
合同编·债的转让（第一章 合同通则 §545-§556）
│
├─ 债权转让（§545-§550）─ 债权人出手，通知债务人即对债务人生效
│   ├─ §546 通知 = 对抗要件（不是生效要件）
│   ├─ §547 从权利随附（抵押权随主债权，无需另行登记）
│   ├─ §548 抗辩继受
│   └─ §549 抵销权（同合同债权 or 先于/同时到期）
│
├─ 债务承担（§551-§554）─ 债务人换/加人
│   ├─ §551 免责承担（须债权人同意；沉默=不同意）
│   ├─ §552 并存承担/加入（通知即生效；有限额）
│   ├─ §553 抗辩承继 + 不得抵销
│   ├─ §554 从债务随转移
│   └─ 担保连锁：§391（物保）§697（人保）
│
├─ 合同概括承受（§555 实体规则 / §556 适用指引）
│
└─ 关联制度
    ├─ §524 第三人代为清偿（不变更债务人，第三人替还后法定求偿）
    ├─ §519 连带债务内部追偿（类推适用于债务加入人追偿权）
    └─ 担保制度解释§36 性质不明推定为保证
```

## 尚待关注的考点

- **债务加入人追偿的"明知损害"边界**（通则解释§51 例外情形，可能出主观题）
- **物保§391 无但书 vs 合同概括承受中担保的处理**（二者在担保脱责路径上有微妙差异）
- **§551 催告期限**："合理期限内"认定，主观题可能结合具体情事考查
- **债务加入 vs 保证意思不明**：增信函/差额补足协议性质认定（担保解释§36 推定保证）
