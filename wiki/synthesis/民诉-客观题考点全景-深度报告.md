## 板块A · 总论

### 第1章 导论、基本原则与基本制度

| # | 考点名称 | 考点描述 |
|---|---------|---------|
| 1-1 | 民事诉讼的主管范围 | 法院受理民事案件的边界：与仲裁、劳动仲裁前置、行政争议、内部纠纷（村民自治等）的划界；常以"该纠纷法院是否受理"设问 |
| 1-2 | 诉的要素与种类 | 当事人、诉讼标的、诉的理由三要素；确认之诉/给付之诉/形成之诉的辨析（离婚=形成、确认合同无效=确认、还款=给付） |
| 1-3 | 诉的合并、变更与追加 | 诉的客观合并/主观合并；增加、变更诉讼请求的时点限制 |
| 1-4 | 一事不再理与诉讼系属 | 重复起诉的三同判断（当事人、诉讼标的、诉讼请求相同或后诉否定前诉裁判结果）；与既判力的关系 |
| 1-5 | 辩论原则与处分原则 | 我国"非约束性辩论"的特色；处分权受国家干预的边界（撤诉须准许、调解自愿）；常考两原则的具体制度体现 |
| 1-6 | 诚实信用原则 | 禁反言、虚假诉讼规制、滥用诉权制裁的原则依据 |
| 1-7 | 检察监督原则与支持起诉 | 检察监督贯穿审判+执行；支持起诉的主体与形式 |
| 1-8 | 同等原则与对等原则 | 涉外诉讼中外国人诉讼权利的同等保障与对等限制 |
| 1-9 | 合议制度与独任制 | 合议庭组成规则；2021 修法后独任制扩张：普通程序独任审理的适用与排除、二审独任制的条件——程序细节高频陷阱区 |
| 1-10 | 回避制度 | 适用对象（含书记员、鉴定人等）、法定事由、申请与决定主体（院长/审判委员会分工）、复议一次、回避期间的工作是否停止 |
| 1-11 | 公开审判制度 | 依法不公开（国家秘密、个人隐私）与依申请不公开（离婚、商业秘密）的二分；宣判一律公开 |
| 1-12 | 两审终审及其例外 | 一审终审情形全清单：小额诉讼、特别程序、督促、公示催告、确认调解协议、（最高法一审）——丢一个就丢分 |

### 第2章 主管与管辖

| # | 考点名称 | 考点描述 |
|---|---------|---------|
| 2-1 | 级别管辖 | 中院管辖的一审案件（重大涉外、本辖区重大影响、最高法确定的类型）；专门法院（知产、海事、金融、互联网法院）管辖要点 |
| 2-2 | 一般地域管辖 | 原告就被告及"被告就原告"的例外（下落不明、被监禁、非军人对军人等）；住所地与经常居住地规则 |
| 2-3 | 特殊地域管辖 | 合同（履行地认定规则：争议标的为给付货币/交付不动产/其他）、侵权（行为地+结果地）、信息网络侵权、保险、票据、运输、交通事故等类型化规则——民诉客观题第一命题密集区 |
| 2-4 | 专属管辖 | 不动产纠纷、港口作业、继承遗产三类；不动产"纠纷"范围（政策性房屋买卖等扩张情形） |
| 2-5 | 协议管辖 | 书面要件、可选法院范围与"实际联系"、不得违反级别/专属管辖；格式条款中管辖协议的效力 |
| 2-6 | 共同管辖、选择管辖与移送管辖 | 两地以上有管辖权时先立案优先；移送管辖的条件与"受移送法院不得再自行移送" |

## 板块C · 审判程序

### 第6章 第一审普通程序

| # | 考点名称 | 考点描述 |
|---|---------|---------|
| 6-1 | 起诉条件与立案登记 | 民诉法第 122 条四要件（适格原告、明确被告、具体诉请与事实理由、属于法院主管+受诉法院管辖）；立案登记制下"七日内立案或裁定不予受理" |
| 6-2 | 不予受理的类型化情形 | 依法应仲裁/行政处理、判决不准离婚或调解和好后六个月内无新情况新理由再起诉、判决维持收养关系的同类限制等清单 |
| 6-3 | 不予受理·驳回起诉·驳回诉讼请求三分 | 前两者=程序性裁定（可上诉），后者=实体判决；发生阶段与救济途径对比——经典送命题 |
| 6-4 | 审理前准备 | 送达起诉状副本与答辩（答辩期十五日、不答辩不影响审理）、举证通知、庭前会议与争点整理、告知合议庭组成人员 |
| 6-5 | 反诉 | 构成要件（同一诉讼程序、牵连性、受诉法院有管辖权且不违反专属管辖）、提出时间（法庭辩论终结前）与处理 |
| 6-6 | 撤诉 | 申请撤诉的准许限制（有违法行为需依法处理的不准撤）、按撤诉处理的情形（原告无正当理由拒不到庭、未经许可中途退庭）、撤诉后再起诉规则（准予撤诉后可再诉；离婚案的六个月限制） |
| 6-7 | 缺席判决 | 被告经传票传唤无正当理由拒不到庭/中途退庭可缺席判决；原告缺席按撤诉处理的对照；必须到庭被告的拘传衔接 |
| 6-8 | 延期审理、诉讼中止与终结 | 三者事由清单辨析（延期=可开庭但当次不能进行；中止=程序暂停待事由消除；终结=不再审理的死亡等情形）——选项混搭高发 |
| 6-9 | 开庭审理流程 | 法庭调查（陈述→举证质证）→法庭辩论（顺序）→最后意见→评议宣判；审限（普通六个月）与延长批准 |
| 6-10 | 判决·裁定·决定三分法（民诉版） | 裁定解决程序问题（可上诉三裁定：不予受理、管辖权异议、驳回起诉）、决定解决回避/强制措施等（不可上诉、部分可复议）；口头裁定/判决的生效 |
| 6-11 | 简易程序 | 基层法院及派出法庭适用；事实清楚权利义务明确争议不大；双方合意适用的空间；简转普（不得普转简）；审限三个月；简易程序的简化点（起诉答辩传唤的简化） |
| 6-12 | 小额诉讼程序 | 2021 修法后标的额标准（上年度就业人员年平均工资 50% 以下必须适用；50%-2 倍可合意适用）；**一审终审**；不得适用的案件类型清单；程序转换与救济（可申请再审？——按现行规定整理，下轮核条文） |
| 6-13 | 普通程序独任制 | 2021 新增：基层法院普通程序可独任审理的条件与排除情形（涉国家利益社会公共利益等不得独任） |

### 第7章 法院调解与裁判

| 9-7 | 案外人救济三条道路的衔接 | **案外人申请再审 vs 第三人撤销之诉 vs 执行异议之诉**的适用场景与择一关系（执行中→执行异议前置；非执行场景→第三人撤销之诉；两者不得并用）——民诉最高阶综合陷阱区，结合 11-11 |

|---|---------|---------|
| 11-1 | 执行依据与执行管辖 | 可执行的法律文书类型（生效判决裁定调解书、支付令、仲裁裁决、公证债权文书等）；第一审法院或同级被执行财产所在地法院管辖 |
| 11-2 | 申请执行期间 | 二年，适用诉讼时效中止中断的规定；起算点（履行期届满日等） |
| 11-3 | 执行开始 | 申请执行与移送执行（具有给付赡养费等内容的和刑附民等的移送）；执行通知与立即强制措施 |
| 11-4 | 执行措施体系 | 查询冻结划拨、扣留提取收入、查封扣押拍卖变卖、交付、迁出房屋退出土地、代履行、迟延履行利息/金；保留生活必需品的限度 |
| 11-5 | 财产报告与信用惩戒 | 被执行人报告财产义务；限制消费、失信名单、限制出境 |
| 11-6 | 执行和解 | 和解协议中止执行；不履行和解协议的双轨救济（申请恢复执行原生效文书 **或** 就履行和解协议起诉）；受欺诈胁迫达成和解的恢复执行 |
| 11-7 | 执行担保 | 向法院提供担保+申请人同意→暂缓执行；期满不履行执行担保财产 |
| 11-8 | 执行承担（变更追加被执行人） | 公民死亡以遗产清偿、法人终止由权利义务承受人履行等典型情形 |
| 11-9 | 参与分配 | 被执行人为公民/其他组织、财产不足清偿全部债务时的申请与顺位；与破产的界分 |
| 11-10 | 执行行为异议（异议→复议） | 当事人、利害关系人对**执行行为**违法的异议（民诉法第 232 条）；十五日内审查裁定；不服向上一级法院申请复议——与案外人异议的二元结构对照 |
| 11-11 | 案外人异议与执行异议之诉 🆕 | 案外人对**执行标的**主张实体权利的异议（第 234 条）→裁定→不服的分流（与原裁判有关→申请再审；无关→**执行异议之诉**）；🆕《执行异议之诉解释》（法释〔2025〕10号，2025-07-24 施行，23 条）细化起诉受理、审理规则与可排除执行的权利类型——机构提示"未入大纲仍可考"，待核 |
| 11-12 | 执行中止、终结与终本 | 中止/终结事由清单；终结本次执行程序的条件与恢复 |
| 11-13 | 执行回转 | 执行完毕后据以执行的文书被撤销的返还与强制回转 |
| 11-14 | 执行检察监督 | 检察院对民事执行活动的法律监督（原则层面+检察建议实践） |

### 第12章 涉外民事诉讼程序（2023 修正消化期）

| # | 考点名称 | 考点描述 |
|---|---------|---------|
| 12-1 | 涉外程序总则 | 涉外案件识别；同等对等原则；司法豁免；使用中国通用语言文字；委托律师代理诉讼**须委托中国律师** |
| 12-2 | 涉外管辖（2023 大修核心） | "适当联系"兜底管辖、涉外协议管辖**不再要求实际联系**、应诉管辖、专属管辖扩张（在华设立的法人组织设立解散清算及知产有效性等类型）——2023 修法后连续处于命题窗口 |
| 12-3 | 平行诉讼与不方便法院 | 相同纠纷境内外法院均受理的处理、先受理规则与例外、不方便法院原则的成文化要件 |
| 12-4 | 涉外送达与期间 | 送达途径扩张清单（对代表机构送达无需授权、电子送达、约定方式等）；涉外公告送达及答辩期上诉期的特殊规定（较境内延长）——具体天数下轮核条文 |
| 12-5 | 域外调查取证 | 条约途径、外交途径及 2023 新增的替代途径（当事人所在国法律不禁止时的即时通讯取证等） |
| 12-6 | 外国判决的承认与执行 | 申请或请求途径；审查标准（互惠、公共秩序保留）；不予承认与执行的事由清单（无管辖权、未获正当传唤、欺诈取得等） |
| 12-7 | 涉外仲裁衔接 | 涉外仲裁协议效力审查、或裁或审在涉外场景的适用；外国仲裁裁决的承认与执行（纽约公约路径） |

### 第13章 仲裁制度（🆕 新《仲裁法》2026-03-01 施行——2026 头号新增模块）

| # | 考点名称 | 考点描述 |
|---|---------|---------|
| 13-1 | 仲裁的基本原则与体制 | 自愿仲裁、或裁或审、一裁终局、独立仲裁不受行政干预；仲裁与诉讼的制度对比 |
| 13-2 | 可仲裁性（仲裁范围） | 平等主体的合同与其他财产权益纠纷可仲裁；**不能仲裁**：婚姻收养监护扶养继承纠纷、依法应由行政机关处理的行政争议；劳动争议与农业承包合同仲裁另行规定 |
| 13-3 | 仲裁协议的有效要件 | 请求仲裁的意思表示+仲裁事项+选定的仲裁委员会；书面形式的宽泛认定；无效情形（超范围、无/限制行为能力人订立、胁迫）与约定不明的补救 |
| 13-4 | 仲裁协议效力的独立性与异议 | 合同无效/不成立不影响仲裁条款效力；对效力有异议的裁决主体（仲裁机构或法院）与**首次开庭前**的时限；一方向法院起诉另一方未在首次开庭前提出异议的视为放弃（应诉管辖式规则） |
| 13-5 | 仲裁协议效力扩张 | 合并分立、继承、债权债务转让情形下仲裁协议对承继方的效力（按新法及司法解释整理） |
| 13-6 | 仲裁程序基本流程 | 申请与受理、仲裁庭组成（三人/独任、选定与指定）、回避、开庭与**不公开**原则、和解调解与裁决（调解书与裁决书同等效力）、多数裁决与首席裁决规则 |
| 13-7 | 🆕 网络仲裁（在线仲裁） | 新法明确仲裁活动可通过信息网络在线进行（当事人明确不同意的除外），在线与线下同等效力——新增法条，客观题程序细节陷阱预期区 |
| 13-8 | 🆕 仲裁地制度 | 新法增设仲裁地作为裁决籍属与司法管辖连接点；当事人可约定仲裁地、无约定时的确定规则——全新制度，必学 |
| 13-9 | 🆕 特定涉外纠纷"专设仲裁庭" | 特定涉外纠纷当事人可在仲裁机构之外选择符合条件的人员组成仲裁庭（临时仲裁的有限引入）——新法最大亮点之一 |
| 13-10 | 🆕 涉外仲裁制度完善 | 涉外仲裁案件范围拓宽、支持境外仲裁机构在自贸试验区/海南自贸港设立业务机构、对外交流合作条款 |
| 13-11 | 撤销仲裁裁决 | 撤销事由清单（无仲裁协议、超裁、程序违法、伪造证据、隐瞒证据、贪污受贿枉法裁决等——按新法条文整理新旧差异）、申请期限、管辖法院（中院）、通知重新仲裁 |
| 13-12 | 不予执行仲裁裁决 | 不予执行的事由与审查；**撤销与不予执行的关系**（择一、驳回撤销申请后能否再以同一理由不予执行）——传统高频＋新法条文号全面更新 ⚠️ |
| 13-13 | 仲裁中的保全与司法支持 | 仲裁前/仲裁中财产保全、证据保全移交法院的程序；法院对仲裁的支持与监督分工——新法强化"支持仲裁"导向 |
| 13-14 | 仲裁司法审查案件 | 确认仲裁协议效力案件的管辖；仲裁司法审查的程序框架 |
