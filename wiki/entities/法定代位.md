# 法定代位（清偿代位）

> 对清偿有**合法利益**的第三人（保证人 / 物上担保人 / 后顺位担保权人 / 连带债务人等）替债务人还了债 → **依法律规定**取代债权人的位置，取得债权人对债务人的债权**及其担保等从权利**，无需另签转让。又称"**清偿代位**"。

## 法条范围

- **[[民法典]]§524**（第三人代为履行）：债务人不履行，第三人**对履行该债务有合法利益**的，可向债权人代为履行；债权人接受后，**其对债务人的债权转让给第三人**（除当事人另有约定外）——这是**法定移转**。
- **§700**（保证人代位）：保证人承担保证责任后，在承担范围内向债务人追偿，**享有债权人对债务人的权利**，但**不得损害债权人的利益**（学理称"**法定代位权**"）。
- **§547**（从权利随主债权移转）：取得债权 → **连同担保物权、利息等从权利一并取得**（专属于债权人自身的除外）。
- 属 [[债的法定移转]] 的一种（与意定的 [[债权转让]] 相对）。
- 🔎 §524 / §700 / §547 原文 2026-06-13 联网核实（[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/)）。

## 是什么 / 易混

### 一句话
替别人还了债、且自己**有合法利益**的人，法律自动让他"**接班债权人**"——原来的债权连同担保一起归他，再去找债务人要。

### ★ 追偿权 vs 法定代位权（同时产生，择优行使）

| 维度 | 追偿权（§700 前段） | 法定代位权（§700 后段 / §524） |
|---|---|---|
| 性质 | 清偿人对债务人的**新债权**（基于内部关系：委托 / 无因管理） | **继受**债权人原来的那个债权 |
| 有无担保加持 | **无担保的普通债权** | **连同原债权的担保 / 顺位 / 利息一并取得**（§547） |
| 实际价值 | 债务人没钱就落空 | 继承担保 / 优先顺位 → 受偿更有保障 |

> 所以代位权常比单纯追偿"值钱"——它把债权人的**担保和顺位**也接了过来。两者并存，清偿人哪个有利用哪个。

### ★ 法定代位 ≠ 意定债权转让
- **法定代位**：法律一规定就移转，**不需通知债务人、不需债权人另签协议**。
- 意定 [[债权转让]]（§545/§546）：靠合意，**须通知债务人**才对其生效。

### ★ 两个"代位"别混（高频）
- **法定代位（清偿代位 §524/§700）**：债权**真的过户**给清偿人。
- **[[代位权]]（债权人代位权 §535）**：**保全**制度，债权人**代债务人**去向次债务人要钱，债权**不移转**。
- 详见 [[债的法定移转]]「两个'代位'别混」。

### 谁能法定代位（"合法利益"的典型）
保证人（§700）、提供抵押 / 质押的**物上担保人**、**后顺位担保权人**、连带债务人 / 连带责任人等——共同点：**不把前面的债清掉，自己的权益就保不住**。纯属"路人"无利害关系地替还，不当然取得法定代位（可能只是赠与 / 不当得利问题）。

## 🚗 实际案例

**案例一（§524 · 后顺位抵押权人代位——最能看出"继承顺位"）**
- 甲的房值 100 万，房上两个抵押：**乙第一顺位**（担保甲欠乙 60 万）、**丙第二顺位**（担保甲欠丙 50 万）。甲两边都还不上。
- 丙怕乙先拍房、自己排在后面拿不到钱（**这就是丙的"合法利益"**）→ 丙替甲把**乙的 60 万还了**。
- 依 §524：丙**取得乙对甲的 60 万债权 + 乙的第一顺位抵押权** → 丙从"第二顺位"**坐上第一顺位**，受偿有了保障。这就是法定代位"**继承担保顺位**"的威力。

**案例二（§700 · 保证人代位）**
- 甲向乙借 100 万、约定利息，丙作保证。甲不还，丙代乙清偿了本息。
- 丙拿到**两条腿**：① **追偿权**——向甲追自己垫的钱；② **法定代位**——继受乙对甲的原债权，**连同原债权的从权利（约定利息、若有担保则担保权）一并取得**（§547）。
- 若这笔债**原本附有担保**，丙代位后即可就该担保**优先受偿**，远胜"空手追偿"。
- ⚠️ 限制（§700）：丙**只是部分**清偿、乙还有余额没拿到时，丙代位取得的权利**不得损害乙**——乙对未受偿部分**优先**于丙。

## 怎么考 / 坑在哪

1. **追偿权 ≠ 代位权**：两者**并存**、择优行使；代位的好处是**继承担保 / 顺位 / 利息**（§547）。
2. **法定移转不需通知 / 同意**：区别于意定 [[债权转让]]（须通知债务人）。
3. **别和债权人代位权（§535）混**：那是保全、债权**不移转**；法定代位是债权**真过户**。
4. **"不得损害债权人利益"（§700）**：债权人未全部受偿前，代位人不得与其争位，**债权人优先**。
5. **"合法利益"是门槛（§524）**：无利害关系地替还不当然取得法定代位。

## 🎯 一句话记忆

> **"替'有利害'的债还了钱，法律让你接班债权人——债权带着担保一起归你（§524/§700 + §547）。**
> **追偿权是新债权（光杆），代位权是老债权（带担保），择优用。**
> **法定代位＝债权真过户（≠ §535 债权人代位权那种'只代行、不过户'）。"**
