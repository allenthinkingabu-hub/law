# 抵押权

> [[担保]]物权之一（[[物权编]] 第四分编）。**为担保债务履行，债务人或第三人不转移财产占有，将财产抵押给债权人**；债务人到期不还，债权人可就该财产变卖**优先受偿**（§394）。**核心特征＝不转移占有**——抵押物仍留在抵押人手里正常使用。顺位/实现等做题步骤见 📐 [[民法-物权-担保物权模型]]，本页是**概念·法条**层。

## 法条范围

- **定义**：[[物权编]] **§394**（不转移占有 + 优先受偿）
- **设立 / 公示**：**§402** 不动产抵押**登记生效** · **§403** 动产抵押**合同生效设立、登记对抗**（未登记不得对抗善意第三人）· §404 不得对抗正常经营买受人
- **担保范围**：§389（主债权 + 利息 + 违约金 + 赔偿金 + 实现费用）；§387 反担保；§393 消灭事由
- **禁止流押**：**§401**（约定到期归债权人无效 → 只能就抵押财产**优先受偿**，须清算）
- **抵押财产转让**：**§406**（可自由转让，抵押权追及效力不受影响，仅须**及时通知**非"经同意"）
- **顺位 / 竞存**：§414（多个抵押按登记先后）· §415（抵押与质权按公示时间先后）· **§416** 价金超级优先权
- **特殊抵押**：§420-424 最高额抵押 · §396 动产浮动抵押 · §388 让与担保（非典型）
- **善意取得**：**§311Ⅲ**（其他物权参照适用 → 可善意取得抵押权）→ [[善意取得]]

## 是什么 / 核心特征

| 项 | 内容 |
|---|---|
| **核心特征** | **不转移占有**——抵押物留在抵押人处正常使用，不交付给债权人 |
| **适用对象** | **不动产（房屋、土地）+ 动产（车辆、设备）都可以** |
| **公示方式** | **不动产抵押＝登记生效**（§402）；**动产抵押＝合同生效设立、登记对抗**（§403）|
| **性质** | 意定担保物权（依抵押合同设立）|

> **通俗例子**：你拿房子向银行贷款，房子你继续住，只去不动产登记中心办抵押登记，银行就取得了房屋抵押权。

### 抵押 / 质押 / 留置 三分（高频区分）

| 维度 | **抵押权** §394 | [[质权]]（动产）§425 | 留置权 §447 |
|---|---|---|---|
| **占有** | **不转移** | **转移**给债权人 | 已（合法）占有债务人动产 |
| **客体** | 不动产 + 动产 | 动产 + 权利（**不含不动产**）| 动产 |
| **设立/公示** | 不动产登记生效§402 / 动产登记对抗§403 | 动产交付设立§429 | 法定，无须登记 |
| **产生** | 意定（约定）| 意定（约定）| **法定** |

## 善意取得抵押权（§311Ⅲ 客体扩张）

§311 第 3 款"善意取得其他物权参照适用前两款"——把善意取得从**所有权**扩张到抵押权、质权等其他物权（**客体扩张**）。

> **例**：甲把车借给乙，乙谎称车是自己的，向不知情的丙借钱并配合丙办了**车辆抵押登记**。丙信赖登记公示、属善意，依法**善意取得该车抵押权**；乙到期不还，丙有权拍卖车辆优先受偿。

真题：[[物权编-多选-04]]（善意取得抵押权）。

## 区分原则：没登记 vs 登记（"两个世界"→ [[区分原则]] §215）

不动产抵押**必须登记才设立抵押权**（§402）；但"没登记"≠"合同无效"——**抵押合同（债权）与抵押权（物权）是两个世界**：

| | 没办抵押登记 | 办了抵押登记 |
|---|---|---|
| **抵押权（物权）** | ❌ 未设立，债权人对该房**无物权** | ✅ 取得抵押权 |
| **抵押合同（债权）** | ✅ **仍有效**（§215 区分原则）| ✅ 有效 |
| **抵押人偷偷卖房过户** | 债权人**不能追及**该房，只能告抵押人**违约赔偿**（拿其他财产还）| **追及效力**：房过户给谁都能申请拍卖该房抵债 |

> **故事**：老王用房给老张作抵押、签了《抵押合同》但**一直没办登记**，又偷偷把房过户给小李。老张**不能拍卖小李的房**（无物权），但合同有效 → 可告老王**违约赔偿**（拿老王其他财产/存款还）。若当初办了登记，老张就有抵押权，能**追着房子**拍卖（**追及效力**），过户给谁都不影响。

真题：[[物权编-多选-20]]（2015-3-53 · 登记部门原因未登记 → D"占有房本取得抵押权"**错**（§402）；A"乙违约"**对**（§215 合同仍有效））。

## 与 [[所有权]] 的关系：主物权 vs 从（限制）物权

**抵押权是"限制物权"——趴在所有权身上的"包袱"，不是与所有权"非此即彼、互相抵消"。** 先定位它在物权体系里的位置：

```
物权
├── 所有权（对自己的物：占有·使用·收益·处分）
├── 用益物权（用别人的物：土地承包经营权 / 居住权 / 地役权）→ [[用益物权]]
└── 担保物权（为债权兜底）
     ├── 抵押权（不转移占有）👈 本页
     ├── 质权（转移占有）→ [[质权]]
     └── 留置权（法定）
```

三层交互（以"房子按揭"为例）：

1. **并存**：同一物上，所有权与抵押权**同时存在**。你是房主（所有权·可住可租），银行有抵押权（不能住、只兜底）。
2. **追及（§406）**：房卖了，抵押权**不消失、跟着房子走**。老王把带抵押的房过户给小李 → 小李拿到的是**"背着银行抵押包袱"的所有权**；到期老王不还，银行可拍卖**小李名下**这套房（详见上文"怎么考"§406 + [[区分原则]]）。
3. **涤除（买受人自救）**：小李可**代老王清偿**贷款 → 主债消灭、抵押权随之消灭（担保物权**从属性** §393）→ 得到"干净的所有权"，再向老王**追偿**垫款。详见 📐 [[民法-物权-抵押财产转让与租赁冲突模型]] 第四步 + [[物权编-多选-20]] C 项（丙代偿后可向甲追偿）。

> **冲突时谁优先？** 一旦要拍卖抵押物，**抵押权（限制物权）优先**，所有权人须**配合拍卖**——这就是"从包袱"反压"主人"的那一刻。

## 怎么考 / 坑在哪

1. **不转移占有**——与 [[质权]]"必须转移占有"是最核心的对立辨析点。
2. **登记生效 vs 登记对抗**——不动产抵押§402 登记**生效**（不登记不设立）；动产抵押§403 登记**对抗**（不登记仍有效、只是不得对抗善意第三人）。体现 [[区分原则]]，高频。
3. **流押禁止 §401**——约定"到期归债权人所有"无效，只能就财产**优先受偿**（须清算），不能直接取得所有权。
4. **抵押财产转让 §406 新规**——抵押期间可**自由转让**，抵押权**追及**到受让人，转让人仅须"及时通知"（非旧法"经同意"）。★★★★★ 头号新规。
5. **顺位看公示** §414/§415——多抵押按登记先后；抵押与质权按公示时间先后（不是"抵押一律优先"）。详见 📐 模型。
