# 违约与侵权竞合

> 同一行为构成**违约 + 侵权** → 受损方**择一**主张（§186）+ 2021 突破
>
> 📐 **答题模型** → [[民法-合同-责任竞合模型]]（竞合识别 → 二选一选择决策树 → 精神损害边界 → 多层侵权拆解）

## 法条范围

[[合同编]] §186；[[人格权编]] §996

## 是什么 / 易混

### 本质：一个行为踩两条线，却只能挑一条告（为什么）

> **一句话**：同一个行为**既违约、又侵权**——两个请求权同时长出来；但法律只让受害方**挑一个告**（§186）。

- **为什么会"竞合"**：违约救的是"合同答应你的没做到"，侵权救的是"你的人身 / 财产被我弄坏了"。同一件事可能**同时踩中这两条线**（修车修出人命、保管把纪念物弄毁）。
- **为什么只能"二选一"**：若两个都告都赔，违约方**双重买单**显失公平、受害方拿**双份赔偿**又构成**不当得利**——故基于公平原则，两请求权**相互排斥、不能并存**，选定一个、另一个即消灭。
- **挑哪个有讲究**：告违约 vs 告侵权，**举证、赔偿范围、能否要精神损害**都不同（见下方对比表）——挑错会少拿钱，这正是考点。
- **§996 的小突破**：本来"告违约要不到精神损害赔偿"；2021 起，违约若**伤了人格权 + 造成严重精神损害**，**告违约也能附带要精神损害赔偿**。

### §186 竞合规则
**§186**：因当事人**一方**的违约行为，**损害对方人身权益、财产权益**的——受损害方有权**选择**请求其承担**违约责任 / 侵权责任**。

→ 二选一，不能同时主张。

### §996 2021 突破：违约也可主精神损害
**§996**：因当事人一方的违约行为，损害对方**人格权**并造成**严重精神损害**——受损方**选择请求其承担违约责任**的，**不影响**受损方请求**精神损害赔偿**。

→ 即：**违约之诉 + 精神损害赔偿可同时主张**（旧法不允许，2021 突破）。

### 典型应用场景

| 案例         | 性质                            |
| ---------- | ----------------------------- |
| 婚礼录像带保管被烧毁 | 保管合同违约 + 侵犯人格利益 → 择一 + 可主精神损害 |
| 婚纱照丢失      | 同上                            |
| 父母骨灰盒被损    | 同上                            |

### 违约 vs 侵权对比

| 维度 | 违约 | 侵权 |
|---|---|---|
| 前提 | **存在合同关系** | 不要求合同 |
| 责任主体 | **合同当事人** | 侵权人 |
| 归责原则 | 严格责任为原则 | 过错责任为原则 |
| 损害范围 | **可预见性**限制（§584）| 全部损失 |
| 精神损害 | **§996 突破**后可主张（仅人格利益） | §1183 |

## 🚗 老王小李故事 · 一件事踩两条线，只能挑一个告

### 故事一（§186 二选一）· 小李把车修出了祸

> 老王把车送到小李的修理厂修刹车。小李偷工减料、刹车没修好就交了车。老王开上路，**刹车失灵撞了**——人受伤住院、车也撞报废。
>
> 小李这**一个行为**踩了两条线：
> - **违约**：修理合同里答应"修好刹车"，没做到（§577）。
> - **侵权**：把老王的人身、财产弄伤弄坏了（§1165）。
>
> 老王能两个都告、拿两份赔偿吗？——**不能！§186 只能挑一个**：
> - 告**违约**：不用证明小李有过错（违约近乎严格责任），但赔偿受**可预见性**限制（§584），传统上**要不到精神损害**。
> - 告**侵权**：能要**精神损害赔偿**（§1183）、赔全部损失，但要**证明小李有过错**。
> - 挑一个赢了拿到钱，另一个就**消灭**；万一挑的那个被驳回、又没过时效，还能**改告另一个**。
>
> 一句话：**一件事踩两条线，老王只能挑一条告，挑哪条赔得不一样——别挑错。**

### 故事二（§996 2021 突破）· 婚车毁了老王的婚礼

> 老王结婚，租了小李的**婚车**（婚庆服务合同），约定吉时接新娘。结果小李的车**半路抛锚、司机迟到两小时**，整场仪式全毁，老王和新娘当众难堪、精神受到**严重打击**。
>
> 老王告小李**违约**（婚车服务没履行好）。按老规矩，"告违约就别想要精神损害赔偿"。但 **§996（2021 新规）**给了突破：小李的违约**伤了老王的人格权 + 造成严重精神损害**，老王**告违约的同时，照样能请求精神损害赔偿**——不必为精神损害另走一遍侵权之诉。
>
> 一句话：**婚车、婚纱照、骨灰盒、婚礼录像这类"砸了就伤心"的违约——告违约也能附带要精神损害赔偿（§996）。**

## 怎么考 / 坑在哪

### 三大陷阱

1. **§996 突破**（C1-多选-17）：违约**可**请求精神损害——2021 新规
2. **二选一、相互排斥**：选定一种并**获实现**→另一种消灭；但若一种**未获实现**（被驳回 / 对方无力赔）且另一种**未过诉讼时效**→仍可**改主张**另一种（"选定即锁死"是常见误记）
3. **保管人 / 承揽人** 等专业服务**对人格利益负责**：合同 + 侵权双重保护
