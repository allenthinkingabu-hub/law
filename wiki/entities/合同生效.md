# 合同生效

> §502；法律评价（合意有无约束力）；与 [[合同成立]] 是两个判断。

## 简介

合同生效是对已 [[合同成立]] 之合同的**法律评价** —— 这份合意有没有**法律约束力**。

## 关键信息

- **法条**：[[民法典]] §502（成立即生效）· §158（附条件）
- **判断性质**：法律评价
- **前提**：[[合同成立]]

## 详细内容

### 一般规则

§502：依法 [[合同成立]] 后，**即生效**。

### 例外（成立但未生效）

| 例外 | 法条 | 说明 |
|---|---|---|
| **附生效条件** | §158 | 等条件成就时生效 |
| **附生效期限** | §158 | 等期限到来时生效 |
| **需经批准** | — | 等批准后生效；未批准则未生效 |

### 报批义务条款的独立效力

> 即使主合同因未批准而未生效，**报批义务条款独立有效**。

### 🚫 易混：登记 / 交付 / 公证 ≠ 合同生效

这是法考**最高频陷阱区**——见 [[合同通则-多选-15]] A 项。

| 易混项       | 真实效果                 | 是否影响合同效力？            |
| --------- | -------------------- | -------------------- |
| **不动产登记** | **物权变动**（§209 所有权移转） | ❌ 不影响（[[区分原则]] §215） |
| **动产交付**  | **物权变动**（§224 所有权移转） | ❌ 不影响                |
| **公证**    | 证明合同真实性              | ❌ 不影响                |
| **网签备案**  | 行政管理 / 防一房二卖         | ❌ 不影响                |

→ **§215 [[区分原则]]**："未办理物权登记的，**不影响合同效力**"
→ 见 [[不动产登记]] 实体页"老王小李买房 4 场景"

### 客观题关键词触发

- 合同附了"……时生效"的条件 → 已成立、未生效

### 主观题流程

主观大案例第一步固定为：

1. 先答 [[合同成立]]（承诺生效没？）
2. 再答合同生效（有无附条件、需批准？）

两个问题**分开答**。

## 🚗 老王小李故事（成立 ≠ 生效，一个故事跑通）

> 老王把车 / 房卖给小李。"两人谈拢" = 合同**成立**；"法律认不认账" = 合同**生效**。一般同时发生，但有三种情形让生效推迟，还有一个"看着没生效、其实早生效"的大坑：
>
> - **场景 A · 默认：成立即生效（§502）**。老王短信"12 万卖你"，小李回"成交"。短信到达那一刻，合同**既成立也生效**，老王得交车、小李得付钱——没附任何条件，握手即生效。
> - **场景 B · 附生效条件：成立但未生效（§158）**。小李说"等我下月发了年终奖再付钱过户"。合同当天就**成立**，却**没生效**，得等"年终奖到账"这个条件成就才生效。真题"喜鹊案"[[合同通则-单选-30]] 同理：乙"明早 7 点屋顶来喜鹊就买"——合同成立、附生效条件；乙反悔想赶走喜鹊**恶意阻止条件成就**，被 §159 拟制为"条件已成就"，合同照样生效。
> - **场景 C · 需经批准：批了才生效（§502 II）**。若这笔买卖依法需审批，批准前合同**未生效**；但合同里的**报批义务条款、争议解决条款独立有效**——老王敢拖着不报批，小李就能直接告他违约。
> - **🏠 大坑 · 没过户 ≠ 没生效（§215 [[区分原则]]）**。老王卖房给小李，合同签了但还没去房管局过户。老王想赖"没过户合同不算数"——**没用**！合同签字时就生效了（§502）；没过户只是**房子产权**还没过去（物权变动 §209），**碰不到合同效力**。小李照样能告老王"继续履行、协助过户"。这正是 [[合同通则-多选-15]] A 项的陷阱："未登记 → 合同未生效"是**错的**。
>
> 一句话理清：**谈成是"成立"，算数才"生效"；一般握手即生效，附条件 / 附期限 / 需批准才推迟；登记 / 交付 / 公证动的是物权，碰不到合同效力。**

## 真题示例

- [[合同通则-多选-15]] 房屋买卖**未过户** = 合同**有效**（登记影响物权变动、不影响合同效力；§215 [[区分原则]]）→ "未登记 → 未生效"错
- [[合同通则-单选-30]] 喜鹊**附生效条件**房屋买卖：合同已成立、未生效；恶意阻止条件成就 → §159 拟制成就（答 D）
- [[合同通则-单选-42]] 教育培训"保证达线否则退费"：违背规律但**有效**——四级效力区分（有效 / 无效 / 可撤销 / 效力待定），详见 [[合同效力分级]]（答 D）
