# 混合担保

> 同一笔债上**"物的担保"（抵押/质押/留置）与"人的担保"（保证）并存**时，债权人怎么实现、谁向谁追偿的规则 —— §392 + §700 + 担保制度解释§13。

## 法条范围

- **核心**：[[民法典]] **§392**（人保 + 物保并存时担保权的实现规则 + 第三人担保人对债务人追偿）
- **追偿 / 代位**：§700（担保人担责后向债务人追偿 + 法定代位）
- **第三人担保人之间**：[担保制度解释](https://ghzyj.gz.gov.cn/sjb/zw/zcfg/content/post_9466449.html) **§13**（原则不得相互追偿 + 3 例外）

> 🔎 **§392 已联网核实（2026-06-13，[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478410.shtml)）**："……没有约定或者约定不明确，**债务人自己提供物的担保的，债权人应当先就该物的担保实现债权**；**第三人提供物的担保的，债权人可以就物的担保实现债权，也可以请求保证人承担保证责任**。提供担保的第三人承担担保责任后，有权向债务人追偿。"

## 是什么 / 易混

### 定义

**混合担保** = 同一债权上**物保 + 人保（保证）同时存在**。债务人到期不还时，要回答三个问题：①债权人**先动谁**（实现顺序）②没拿到钱的担保人**向谁追偿** ③第三人担保人**之间**能不能互相追。

### ① 实现顺序（§392）——关键看物保是"谁"提供的

| 情形                       | 债权人怎么实现                        | 为什么                                      |
| ------------------------ | ------------------------------ | ---------------------------------------- |
| 有**约定**                  | **按约定**                        | 意思自治优先                                   |
| 无约定 · **债务人自己的物保** vs 保证 | **必须先**实现债务人自己的物保，不足才找保证人      | 债务人自己的财产是**第一还款来源**；否则保证人先赔、再回头追债务人，徒增环节 |
| 无约定 · **第三人的物保** vs 保证   | **可择一**：拍第三人的物 / 找保证人，**不分先后** | 物上保证人与保证人**都是"替债务人扛"的第三人，地位平等**          |

> 一句话：**债务人自己的物，强制先动；第三人的物 vs 保证人，债权人随便挑。**

### ② 谁向谁追偿（§700）

任何担保人（保证人 / 第三人物上保证人）替债务人清偿后，**都有权向债务人追偿**，并**法定代位**债权人对债务人的权利（含原担保）。

### ③ 第三人担保人"之间"——原则互不追偿（担保解释§13）

承担了担保责任的第三人担保人，**原则上不得请求其他第三人担保人分担**；**仅 3 种例外**可按份分担：① 约定**相互追偿及份额** ② 约定**连带共同担保** ③ 在**同一份合同书**上签字盖章。

## 怎么考 / 坑在哪

### 三大陷阱

1. **不分"谁的物保"一律先物后人** —— 错！只有**债务人自己**的物保才强制先实现；**第三人**的物保与保证**平等、可择一**（§392）。
2. **第三人担保人之间可按比例互相追偿** —— 错！**原则互不追偿**（解释§13），除 3 例外；但**都能向债务人追偿**（§700）。
3. **把"实现顺序"和"追偿"混为一谈** —— 实现顺序解决"债权人先找谁"；追偿解决"担保人垫钱后找谁要回"，两个层面。

## 🚗 老王小李故事（乙借给甲 100 万，到期甲不还）

> 同一笔 100 万的债，既有物保又有保证人丙。

- **场景①（债务人自己的物保）**：甲拿**自己的房**抵押 + 丙作保证 → 乙**必须先拍甲的房**受偿，不足部分才找丙（§392 强制先序）。
- **场景②（第三人的物保）**：换成**丁（第三人）**拿房抵押 + 丙作保证 → 乙**可择一**：拍丁的房、或直接找丙，**随便选、不分先后**（丁、丙地位平等）。
- **追偿**：丙或丁谁垫了钱，都能找**债务人甲**追偿（§700）；但丙、丁**之间**原则**互不追偿**（解释§13，除非约定/连带共同担保/同一合同书签字）。
