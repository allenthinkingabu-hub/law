# 合同可撤销

> [[合同效力分级]] 之 ③ —— **撤销前有效，撤销后追溯无效**

## 法条范围

[[总则编]] §147-§152、§157

## 是什么 / 易混

### 核心特征
- **撤销前合同有效**（受撤销权约束的有效状态）
- **撤销权人** = **受损方**（不是任何人都可撤销）
- **除斥期间内**撤销，否则失权
- 撤销后**自始无效**（追溯效力）

### 5 大可撤销情形

| # | 情形 | 法条 | 除斥期间起算 |
|---|---|---|---|
| ① | **重大误解** | §147 | **90 日**——知道 / 应知 |
| ② | **欺诈**（一方欺诈）| §148 | **1 年**——知道 / 应知 |
| ③ | **第三人欺诈**（对方知道 / 应知 → 受损方可撤）| §149 | 1 年 |
| ④ | **胁迫** | §150 | **1 年**——胁迫**终止之日**起 |
| ⑤ | **显失公平**（一方乘人之危 / 利用对方处于危困 / 缺乏判断能力等） | §151 | 1 年 |

### 除斥期间（§152）
| 情形 | 期间 |
|---|---|
| 一般情形 | **1 年**——自知道 / 应知之日 |
| **重大误解** | **90 日** |
| **胁迫** | 1 年——自胁迫**终止之日** |
| **最长保护期** | **自合同成立 5 年**（兜底） |

### 撤销权消灭事由
- ① 期限届满未行使
- ② 撤销权人**知道事由后**以**明示 / 行为**表示**放弃**
- ③ 撤销权人**5 年最长保护期**届满

## 怎么考 / 坑在哪

### 五大陷阱

1. **重大误解 90 日 ≠ 1 年**：重大误解是**最短**除斥期间
2. **胁迫起算特殊**：从**胁迫终止**算，不是从知道
3. **第三人欺诈**：仅当**对方知道 / 应当知道**时才可撤销（§149）
4. **撤销 ≠ 解除**：撤销追溯无效；解除一般不溯及既往
5. **可撤销 vs 无效**：可撤销**先生效**，撤销后才无效

## 怎么答

主观题分析框架：
1. **识别**：是哪种可撤销情形？
2. **撤销权人**：受损方是谁？
3. **除斥期间**：90 日 / 1 年 / 5 年兜底？是否在期内？
4. **行使方式**：起诉 / 仲裁主张
5. **撤销后**：§157 返还 + 过错赔偿
