# 合同相对性

> [[合同编]] §465 — 合同**原则上只约束签字双方**,是区分 **[[债]](相对权)vs 物权(对世权)** 的关键

## 法条范围

[[合同编]] §465 主条 + §535 / §538 / §523 / §725 等法定例外

## 是什么 / 易混

### 定义

**§465**:依法成立的合同,**仅对当事人**具有法律约束力,**但是法律另有规定的除外**。

→ 一句话:**合同是"俩人之间的事",外人不沾**。

### 为什么有相对性?

```
       [[债]] (相对权)              物权 (绝对权)
            │                          │
            ▼                          ▼
  ┌─────────────────┐        ┌─────────────────┐
  │ 只约束特定人     │        │ 对全世界主张     │
  │ (合同的当事人)   │        │ (谁占我的房就告) │
  └─────────────────┘        └─────────────────┘
            │                          │
            ▼                          ▼
        合同相对性                  物权对世性
       (§465 法源)
```

→ **合同相对性 = "债权是相对权"的具体表达**

### 三层含义

| 层 | 内容 |
|---|---|
| **主体相对性** | 只能向**合同对方**主张权利 |
| **内容相对性** | 只能按**约定内容**主张,不能扩大 |
| **责任相对性** | 违约责任只能由**违约方**承担 |

### 🚪 法定例外(必背 4 大类)

| # | 例外 | 法条 | 说明 |
|---|---|---|---|
| ① | **[[代位权]]** | §535-§537 | 债权人代位行使**债务人的**到期债权(及于第三人) |
| ② | **[[撤销权]]** | §538-§542 | 债权人撤销**债务人的**损害行为(及于第三人) |
| ③ | **买卖不破租赁** | §725 | 房屋买卖**不影响**承租人对**新房主**的租赁关系 |
| ④ | **[[第三人代为履行]]** | §523-§524 | 涉他合同 |

→ **法定例外都是法条明文规定**,不能类推。

## 🚗 老王小李"隔壁老张"故事

### 场景设定

> 老王和小李签了二手车买卖合同:**12 万**。
> 隔壁的**老张**:
> - 早就想买这台车
> - 还提前跟老王说过"以后想买"
> - 比小李出价高 15 万

### 法律分析(按合同相对性)

#### Q1:老张能不能主张"我也想买",强迫老王卖给他?

→ ❌ **不能**。合同是老王小李之间的事,**外人不沾**。

#### Q2:老张能不能告小李"你抢了我想买的车"?

→ ❌ **不能**。小李对老张**没有任何合同义务**。

#### Q3:老张能不能告老王"违反预约"?

→ 看情况:如果老张老王之间**有预约合同** → 老王违反**预约**(这是老张-老王之间的事,不是老张主张老王小李的买卖合同)

### 法定例外的 4 个场景

#### 场景 1:[[代位权]](§535)

> 老王欠小李 12 万到期不还。
> 但**老张欠老王 15 万**,老王不去要。

→ 小李可以**代位**老王起诉老张,让老张直接还给小李!
→ ⚠️ 突破相对性:**小李主张了对老张的请求权**(虽然债是老王老张之间的)

#### 场景 2:[[撤销权]](§538)

> 老王欠小李 12 万,老王把自己的房子**贱卖给老张** 5 万(远低于市价)。

→ 小李可以**撤销**老王和老张之间的房屋买卖合同!
→ ⚠️ 突破相对性:小李撤销了**老王老张之间**的合同

#### 场景 3:买卖不破租赁(§725)

> 老王把房子租给小李 3 年,签了合同。第二年老王把房子卖给老张。

→ **小李对老张**仍然享有租赁权!不必搬走,租金照交(交给老张)。
→ ⚠️ 突破相对性:原本只有老王和小李之间的租赁,现在**新房主老张**也被约束

#### 场景 4:[[第三人代为履行]](§523)

> 老王和小李约定 → **由老张代老王交货**。

→ 如果老张没交,**老王要担违约责任**(不是老张担)
→ 反过来如果合同规定**让小李向老张交付** → 老王违约时**老张可主张违约责任**

## 怎么考 / 坑在哪

### 三大陷阱

1. **以为"知道合同就能主张"** ← 错,第三人哪怕全程旁观、知情、签字见证都不能基于该合同主张权利
2. **代位权 / 撤销权也是相对性的体现** ← ❌ 错,恰恰是相对性的**法定例外**
3. **遗忘买卖不破租赁** ← 经典考点,承租人对新房主仍享租赁权

### 📐 答题口诀

```
合同 → 只约束签字双方(§465 原则)
↓
第三人主张?→ 看是否有 4 大法定例外
  ├─ 代位权(§535)
  ├─ 撤销权(§538)
  ├─ 买卖不破租赁(§725)
  └─ 第三人代为履行(§523)
没有例外 → 第三人不能主张
```
