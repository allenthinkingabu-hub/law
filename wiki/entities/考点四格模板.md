# 考点四格模板

> 处理**每一个**法考考点的固定结构：是什么/易混 → 怎么考、坑 → 客观答 → 主观答。

## 简介

考点四格模板是 [[2026-06-05-考点精解-要约与承诺]] 中示范的一套**可复用方法论**。任何考点（合同效力、代位权、撤销权、共有……）都可以套这四格来吃透。

## 关键信息

- **类型**：方法论 / 备考模板
- **应用领域**：[[法考]] 所有部门法（尤其是 [[民法]]、[[刑法]]、[[商法]]）
- **核心价值**：把"理解一个考点"标准化为四个动作

## 详细内容

### 四格结构

#### 第 1 格：是什么 / 易混

- 先**立定义**，再**钉死边界**
- 客观题陷阱几乎全在**边界**上
- 列出**易混对照**（按高频陷阱分组）

#### 第 2 格：怎么考、坑在哪

- **命题角度**：客观题 / 主观题分别怎么考
- **高频坑位**：列出命题人最爱设的具体陷阱

#### 第 3 格：客观怎么答

- **固定流程**（如"四步流程"）
- **关键词触发表**：把"判断"变成"反射"

#### 第 4 格：主观怎么答

- **答题结构**：[[结论先行答题法]]
- **填空模板**：可直接套用
- **采分点意识**：阅卷按点给分

### 用法

源素材明确：

> 下一个考点（如**合同效力、保全中的代位权 / 撤销权**）照着这四格填，吃透速度会越来越快。

> 四格结构就是你处理**每一个考点**的固定模板。

### 与 [[结论先行答题法]] 的关系

- 第 4 格的具体落地 = [[结论先行答题法]]
- 四格模板覆盖整个"理解 + 答题"全过程
- 结论先行只覆盖**主观答**这一格的输出阶段

### 与 [[考点四格模板]] 自身的元应用

四格本身已经"被四格化"了：

- 第 1 格 = 是什么 → 即本页"详细内容"
- 第 2 格 = 怎么用 → "用法"小节
- 第 3 + 4 格 = 输出，留给后续 ingest 中的每个考点
