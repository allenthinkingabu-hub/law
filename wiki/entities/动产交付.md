# 动产交付

> 动产物权变动**靠交付**（不动产靠登记 §209）。交付分**现实交付**（真给）+ **三种观念交付**（简易 / 指示 / 占有改定）——**看物在谁手里**定方式、**各自时点**定归属。做题步骤见 📐 [[民法-物权-动产交付模型]]；本页是**概念 + 例子**层。

## 法条范围

[[物权编]] §224（现实交付·一般规则）+ §226 简易交付 + §227 指示交付 + §228 占有改定 + §225 特殊动产（交付生效·登记对抗）· 2026-06-15 两路 gov.cn 逐字核实

## 四方式 + 一例（看"物在谁手里"）

> 角色：**老王**＝出让人 / 卖方｜**小李**＝受让人 / 买方｜**老张**＝第三人

| 方式 | 物在谁手 | 🚗 例子 | 所有权转移时点 | 善意取得 |
|---|---|---|---|---|
| **现实交付 §224** | 实际递到受让人手（默认）| 老王把自行车连钥匙**直接交给**小李 | 交付时 | ✅ |
| **简易交付 §226** | **受让人已先占有** | 小李先**租**老王的车在骑，到期买下 → **不用再交一次** | **买卖合同生效时** | ✅ |
| **指示交付 §227** | **第三人占有** | 车正**借给老张**用，老王把"向老张要车的**返还请求权**"**让与**小李 | 让与协议生效时 | ✅ |
| **占有改定 §228** | **出让人继续占有** | 老王把车卖小李，约定"**车我再用一个月**"→ 车没动 | **约定生效时**（非交回时）| ❌（无现实占有）|
| 特殊动产 §225 | 船 / 航空器 / 机动车 | 老王把**汽车**交付小李即取得所有权，没过户也归小李 | 交付时（登记仅对抗）| ✅（交付即可）|

> 🔑 **指示 vs 占有改定**：物在**第三人**手＝指示交付；物在**出让人自己**手＝占有改定。
> 🔑 **善意取得"简可指可占不可"**：占有改定下受让人没取得现实占有 → **不适用善意取得**（通说），详见 [[善意取得]] 第五步·闸②。

## 怎么考 / 坑在哪

1. **占有改定≠"交回时"才转移**：约定生效就转移（§228）；常设"一个月后才取得"的陷阱。
2. **简易交付不用再交一次**：东西已在受让人手，合同生效即变动（§226）。
3. **特殊动产交付即生效**："没过户＝没所有权"是错的（§225 登记仅**对抗**、非生效）。
4. **占有改定不适用善意取得**（缺公示·通说）；简易 / 指示 / 现实都可以。
5. **多重买卖"交付为王"**：特殊动产先受领交付者优先于仅登记者（买卖合同解释 §7(四)）。

## 特殊动产 §225 的两面：交付为王，登记对抗会"咬人"

特殊动产（船 / 航空器 / 机动车）**交付生效、登记对抗**——同一把"对抗"刀，正反两面：

- **① 交付为王（赢的一面）**：一物二卖，先**受领交付**者取得所有权，胜过仅办**过户登记**者（买卖合同解释 §7(四)）→ [[物权编-单选-39]]。
- **② 登记对抗"咬人"（输的一面）**：你交付拿到车却**没过户**，登记簿仍写原主名；原主拿它向**善意第三人**（如善意银行）设**抵押登记**——你**未登记的所有权不得对抗善意第三人**（§225），只能被抵押权"咬伤"、替原主背债（亦可由 [[善意取得]] §311Ⅲ 解释：善意人取得 [[抵押权]]）。

> **结论**：特殊动产"光拿货（交付）不安全"，受让后要**尽快过户登记**，才挡得住善意第三人。
