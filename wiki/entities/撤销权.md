# 撤销权

> 债权人**撤销债务人**的**减损财产 / 危害债权**行为 — [[合同总则]] **保全**之二

## 法条范围

[[合同编]] §538-§542

## 是什么 / 易混

### 定义
**§538 + §539**：债务人实施下列**危害债权人债权**的行为 → 债权人可请求**撤销**：
1. **放弃**其债权 / 放弃债权担保 / **恶意延长**到期债权履行期 → 影响债权人债权实现
2. 以**明显不合理低价转让**财产 / 明显不合理**高价受让**他人财产 / 为他人债务提供担保 → 影响债权人债权实现 + **相对人知道或者应当知道**

### 两类撤销情形对比

| 类型 | §538（无偿 / 恶意延期）| §539（不合理价格 / 担保）|
|---|---|---|
| 行为 | 放弃债权 / 担保 / 恶意延期 | 不合理低价转让 / 高价受让 / 提供担保 |
| **相对人主观** | **不需要**审查相对人是否知情 | **必须** "**知道或应当知道**" |

→ 总结口诀："**无偿不问知情**，**有偿必问知情**"

> **"明显不合理"标尺（通则解释）**：成交价**低于市场价 70%** 一般认定为"明显不合理的低价"，**高于 130%** 认定为"明显不合理的高价"。故 §539 有偿撤销须**双要件**：① 价格明显不合理（破七成线）+ ② 相对人知道或应当知道（恶意），**缺一不可**（见 [[合同通则-单选-20]]：B 八折=80% 不算"明显低价"、C 六折=60% 算但受让人善意，均不可撤）。

### 行使方式（§539）
- 请求**人民法院**撤销（必须诉讼）
- 撤销以**债权人的债权**为限

### 除斥期间（§541）
| 期间 | 起算 | 性质 |
|---|---|---|
| **1 年** | 知道 / 应知**撤销原因**之日 | **除斥期间** |
| **5 年**（兜底） | **债务人行为发生**之日 | 最长保护期 |

### 撤销后的效果（§542）
- 债务人行为**自始无效**
- 财产返还
- 相对人 / 受益人**返还所得**
- 撤销费用由**债务人**承担

## 怎么考 / 坑在哪

### 五大陷阱

1. **身份行为不可撤销**（C1-单选-19）：放弃继承 / 离婚共有财产分割等**身份行为**不在撤销范围
2. **无偿 vs 有偿**：无偿不问知情；有偿必须证明相对人知情
3. **必须诉讼**：不能自行通知
4. **撤销范围**以债权为限：不是撤销整个交易
5. **1 年 + 5 年双期间**：1 年是除斥，5 年是最长保护

## 怎么答

主观题分析框架：
1. **行为性质**：无偿 / 有偿？是否身份行为？
2. **构成**：是否危害债权 / 相对人知情（有偿时）？
3. **行使**：诉讼请求 + 在期内
4. **撤销范围**：以债权为限
5. **效果**：返还财产 + 受益人担责
