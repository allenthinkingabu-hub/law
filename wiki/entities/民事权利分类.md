# 民事权利分类

> **一句话**：民事权利最高分为人身权和财产权两大类（平级），财产权下分物权和债权（平级），两者效力不同但层级相等——法考最常混淆的"层级高低 vs 效力强弱"之分界线。

## 民法完整权利层级树（三层完整架构）

```
第一层（最高）：民事权利
    ├─ 人身权（和身体绑定·不能买卖）
    │   ├─ 人格权：生命权、健康权、肖像权、名誉权、隐私权
    │   └─ 身份权：配偶权、亲权（父母子女）、监护权
    │
    └─ 财产权（能换钱·流转性·你问的重点）
        ├─ 物权（支配权·管物·对世效）
        │   ├─ 所有权
        │   ├─ 用益物权：居住权、土地承包经营权、建设用地使用权
        │   └─ 担保物权：抵押权、质权、留置权
        │
        ├─ 债权（请求权·管人·相对效）
        │   ├─ 合同之债
        │   ├─ 侵权之债
        │   ├─ 无因管理之债
        │   └─ 不当得利之债
        │
        └─ 其他财产权（客观题偶涉）
            ├─ 知识产权：著作权、专利权、商标权
            ├─ 股权（公司法）
            └─ 继承权（继承编）
```

## 第一层：民事权利的两大分支（平级关系）

### A. 人身权（第一分支）

**定义**：与人的身份、人格密切相关，不能转让、不能继承的权利。

**分为两类**：

| 权利类型 | 具体权利 | 特征 | 法律保护 |
|---|---|---|---|
| **人格权** | 生命权、健康权、肖像权、名誉权、隐私权、个人信息保护权 | 天然拥有，不因行为能力而改变 | §1021-§1039（人格权独立编） |
| **身份权** | 配偶权、亲权（父母权）、监护权、收养权、继承权位阶 | 因特定身份而获得，随身份变动而变动 | §26-§67（婚姻家庭编）|

### B. 财产权（第二分支）

**定义**：具有经济价值、能以金钱衡量、可转让流通的权利。

**分为两类（重点）**：

| 权利类型 | 性质 | 权能 | 效力范围 | 时效 |
|---|---|---|---|---|
| **物权** | 支配权 | 占有、使用、收益、处分 | **对世效**（对全世界人有效） | 原则无时效（§196 特例） |
| **债权** | 请求权 | 请求特定人为特定行为 | **相对效**（仅对相对人有效） | 原则 3 年时效（§188） |

## 第二层：财产权的两大子类（核心区分）

### 物权 vs 债权：五维对比表

| 对比维度 | 物权 | 债权 |
|---|---|---|
| **权利性质** | **支配权**（直接控制物品） | **请求权**（向特定人请求）|
| **客体** | 物（必须是有体物或无体物） | 特定人的行为 |
| **对象** | 对全世界人有效（对世权） | 仅对债务人有效（相对权）|
| **权能范围** | 占有、使用、收益、处分（§222） | 请求债务人履行义务 |
| **能否对抗第三人** | ✅ **可以** — 第三人侵害物权需赔偿 | ❌ **不可以** — 债权人无权强制第三人履行 |
| **典型例子** | 房子（所有权）、车子、抵押权 | 借条（债权）、买卖合同债权、工资债权 |
| **诉讼时效** | 原则**无时效**（不动产/已登记无时效；未登记动产 3 年） | **统一 3 年时效**（§188）|

### 核心秒杀口诀

**"物权对世·债权相对；物权支配·债权请求。"**

物权人可以直接控制物品，任何人侵害都要赔；债权人只能向债务人要求，第三人侵害债权人无法直接追责（只能走侵权赔偿另找人）。

## 第三层：物权、债权各自的细分

### 物权的三类

#### 1. 所有权（最高的物权）

**定义**：对物的最完整的支配权，包括占有、使用、收益、处分全部权能。

**特点**：
- 最高性：被其他物权（用益、担保）所限制时仍为最高
- 绝对性：对全世界人都有效
- 独占性：一物一般归一人
- 永久性：原则不受时效限制

#### 2. 用益物权（他人土地上的使用权）

| 权利类型 | 权利人 | 权利内容 | 例子 |
|---|---|---|---|
| **建设用地使用权** | 非国家 | 70 年内在国有土地上建设 | 商品房、厂房 |
| **土地承包经营权** | 农民 | 30 年内种地 | 农地承包 |
| **居住权** | 配偶或赡养人 | 终身居住（不能转让继承）| 离婚后继续住房 |

**共同特点**：都是他人土地上的使用权，不涉及所有权转移。

#### 3. 担保物权（抵押权、质权、留置权）

**定义**：为了保证债务履行，在债务人或第三人的财产上设立的物权。

| 权利类型 | 设立方式 | 担保物范围 | 特点 |
|---|---|---|---|
| **抵押权** | **登记生效**（不转移占有） | 不动产、动产都可 | 权利人不管理，债务人继续用 |
| **质权** | **交付生效**（转移占有）| 动产/权利 | 权利人保管，债务人交出 |
| **留置权** | **法定**（因保管而当然产生）| 动产 | 修理厂扣车、律师扣合同 |

**共同特点**：都是从权（以主债权存在为前提），债务清偿后自动消灭。

### 债权的四大来源

| 债权来源 | 定义 | 典型例子 |
|---|---|---|
| **合同之债** | 当事人约定产生 | 买卖合同、借款合同、租赁合同 |
| **侵权之债** | 因侵害他人权益产生 | 撞车赔偿、损坏货物赔偿、名誉侵害赔偿 |
| **无因管理之债** | 为他人管理事务而产生 | 朋友出国，你帮他还房贷，他要还你钱 |
| **不当得利之债** | 获得不该有的利益而产生 | 误付的钱款、超付的费用 |

## 法考秒杀区分：层级高低 vs 效力强弱

### ⚠️ 最容易混淆的考点

**错误理解**：物权比债权"更高级"（层级高 = 优先性强）

**正确理解**：
- **层级关系**：物权和债权都是财产权的子类，**在财产权内部平级**
- **效力关系**：物权效力强（对世权）≠ 物权层级高
- **两者是维度不同的概念**，不能比较谁"高级"

### 打破混淆的 3 个例子

**例 1：房子所有权 + 房贷债权**
```
你买房子，签了 30 年房贷。
- 房子所有权（物权）：你拥有
- 银行债权（债权）：银行对你的请求权
结论：两个权利都是你的，物权和债权平级。
```

**例 2：物权优先效力的体现**
```
你的房子被银行抵押（物权担保）。
第三人来买房，银行可以直接对他说：
"这房子有我的抵押权，你买不了。"
这就是物权的"对世效力"强。

反观债权：
邻居欠你 10 万块钱，第三人可以无视：
"这是你俩的事，我不关我事。"
这就是债权的"相对效力"弱。
```

**例 3：清偿顺序中的效力体现（不是层级）**
```
债务人破产，财产不够分：

清偿顺序：
1. 有担保物权的债权（抵押权的债）
2. 法定优先债权（职工工资）
3. 普通债权（民间借贷）

这里物权债权优先赔付，是因为**物权效力强**，
不是因为物权"层级高"。
两者平级，但物权说话更有力。
```

## 记忆口诀

**民事权最高分两类，人身财产平级坐；  
财产之下物债现，支配请求各司职。  
物权对世强，债权相对弱；  
层级都平等，效力有差别。  
第三人敢侵权，物权人可反击；  
第三人视若无，债权人难追及。**

---

**最后提醒**：
- **层级**：民事权利 → 人身权/财产权 → 物权/债权 → 具体权利（三层递进）
- **平级关系**：人身权与财产权平级；物权与债权在财产权内部平级
- **效力≠层级**：物权对世、债权相对，是效力强弱差别，不是层级高低
- **法考秒杀**：看到"效力"、"优先"、"对第三人"就想物权；看到"仅相对"、"相对人"就想债权
