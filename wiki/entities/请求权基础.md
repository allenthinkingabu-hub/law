# 请求权基础

> 贯穿 [[法考主观题]] 民法大案例的统一分析框架。

## 简介

请求权基础是处理民法主观题的核心思维方法：**谁能向谁、依据哪个请求权、主张什么**。

## 关键信息

- **类型**：方法论 / 思维框架
- **应用领域**：[[法考主观题]] 民法案例分析
- **重要性**：贯穿性，非具体考点

## 详细内容

### 核心问题

> 民法主观题本质是"**谁能向谁、依据哪个请求权、主张什么**"。

### 四大请求权基础

| 类型 | 所在编 |
|---|---|
| **合同**请求权 | [[合同编]] |
| **物权**请求权 | [[物权编]] |
| **侵权**请求权 | [[侵权责任编]] |
| **不当得利**请求权 | [[合同编]] · 准合同 |

### 🔥 物权请求权 vs 债权请求权（高频对比）

这是 [[合同通则-多选-15]] B 项陷阱的考查核心——**买方未取得物权时不能行使物权请求权**。

| 维度 | 物权请求权 | 债权请求权（合同请求权）|
|---|---|---|
| **法条** | §235-§238（返还 / 排除 / 恢复 / 确认）| §509 / §577 等 |
| **权利性质** | **绝对权**——对世权 | **相对权**——仅对相对人 |
| **前提** | **已取得物权**（已公示 / 登记 / 交付）| **合同有效**即可 |
| **效力对象** | 任何第三人 | 仅合同相对人 |
| **典型情形** | 我房子被占 → 返还原物 | 卖方违约 → 继续履行 / 赔偿 |
| **房屋买卖未登记**| ❌ 不能用（买方没物权）| ✅ 可用（合同有效）|

### 区分原则在请求权选择中的应用

涉及物权变动的合同纠纷，按 [[区分原则]] 双轨判断：

```
Step 1：合同是否有效（§215）→ 决定能否用债权请求权
Step 2：物权是否已变动（§209/§224）→ 决定能否用物权请求权
Step 3：选择请求权基础
  ├─ 物权已变动 + 合同有效 → 双轨可选
  ├─ 物权未变动 + 合同有效 → 仅债权请求权（典型："未登记房屋买卖"）
  └─ 物权已变动 + 合同无效 → 仅物权请求权 + 不当得利
```

→ 详见 [[不动产登记]]、[[区分原则]]、[[合同通则-多选-15]]

### 学习提示

源素材明确指出：

> 搭骨架时不必展开，但要知道这几大请求权基础是后面做主观案例的统一分析框架。

即：本阶段（目录级骨架）**不展开**，但**必须知道**这是后续做题的统一分析框架。

### 与 [[结论先行答题法]] 的关系

请求权基础与 [[结论先行答题法]] 是**同一答题流水线**上的两个环节：

| 阶段 | 工具 | 输出 |
|---|---|---|
| 找法条（找大前提） | 请求权基础（问：谁能向谁、依据哪个请求权） | 锁定具体法条（如 §472 / §483） |
| 展开论证 | [[结论先行答题法]]（结论 → 法条 → 涵摄） | 答题主体 |

### 合同请求权的成立前提

合同请求权能否主张，**前提是合同已成立**：

- [[合同成立]]（§483）→ 合同请求权有讨论基础
- 若 [[合同成立]] 但 [[合同生效]] 未发生（附条件/未批准）→ 合同请求权暂未生效

详见 [[合同订立流程]]。
