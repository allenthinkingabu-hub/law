# 民事责任

> 民法中最核心的法律责任类型。因违反民事义务（合同义务或法定义务）所产生的法律后果。

## 定义

民事责任是指民事主体因违反民事义务而应承担的法律后果，主要是赔偿他人因此所受的损失，旨在维护私权。

## 民事责任的三大分类

<!-- confidence: EXTRACTED -->
民事责任分为三类，按责任产生的原因不同而区分：

### 1. 违约责任（§534-620）

| 维度 | 内容 |
|------|------|
| **产生原因** | 违反合同约定的义务 |
| **行为类型** | 预期违约、实际违约（履行不能/拒绝/迟延/不完全）|
| **归责规则** | 原则上无过错责任；特定情形（保管/委托）过错责任 |
| **承担方式** | 继续履行、补救措施、赔偿损失、违约金、定金 |
| **免责事由** | 不可抗力；有效免责条款 |
| **考试分值** | ★★★★★ 高频 |

### 2. 侵权责任（§1165-1256）

| 维度 | 内容 |
|------|------|
| **产生原因** | 侵害他人权益（人身权/财产权/人格权等）|
| **行为类型** | 单独侵权、共同侵权、共同危险、分别侵权 |
| **归责规则** | 过错责任、无过错责任（高度危险/产品等）、公平补偿 |
| **承担方式** | 停止侵害、返还财产、赔偿损失、赔礼道歉、消除影响 |
| **免责/减责** | 受害人故意/重大过失、不可抗力、第三人原因 |
| **考试分值** | ★★★★★ 高频 |

### 3. 缔约过失责任（§500-501）

| 维度 | 内容 |
|------|------|
| **产生原因** | 合同磋商阶段违背诚信原则 |
| **行为类型** | 恶意磋商、隐瞒重要事实、泄露商业秘密、其他违背诚信 |
| **归责规则** | 过错责任（必须有过错才担责）|
| **承担方式** | **仅赔偿信赖利益损失**（不含违约金、继续履行）|
| **免责事由** | 无统一法定免责；一般仅无过错可免责 |
| **考试分值** | ★★★ 中频 |

## 统一的下钻维度

<!-- confidence: EXTRACTED -->
三类民事责任虽然类型不同，但采用**统一的下钻维度**系统分析：

**四步走答题法**：

```
① 行为类型 ——— 这是不是该责任的行为？
      ↓
② 归责规则 ——— 过错责任还是无过错责任？
      ↓
③ 承担方式 ——— 怎么赔、赔多少？
      ↓
④ 免责/减责事由 ——— 能不能不赔或少赔？
```

## 核心特点

1. **多元化承担方式**：不仅仅是赔钱，还包括继续履行、停止侵害等
2. **归责规则复杂化**：从原则的过错责任到现代的无过错责任并存
3. **免责/减责条件化**：法定的免责或减责情形而非绝对责任
4. **可并存性**：同一行为可能同时产生多类民事责任

## 与其他责任类型的关系

| 对比维度 | 民事责任 | 行政责任 | 刑事责任 |
|---------|---------|---------|---------|
| 保护对象 | 私权/民事权益 | 公益/行政秩序 | 社会秩序 |
| 承担方式 | 赔偿、排除等 | 罚款、吊销等 | 监禁、罚金 |
| 时效性 | 3年(原则)、20年(长期) | 通常无时效 | 有追诉期限 |
| 并存性 | ✅ 可并存 | ✅ 可并存 | ⚠️ 原则排他 |
