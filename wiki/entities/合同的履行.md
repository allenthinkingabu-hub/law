# 合同的履行

> 把答应的事**按约定做到位** — [[合同总则]] **三·履行**板块总纲（全面履行 + 三大抗辩权 + 情势变更 + 涉他合同 + 约定不明填补）

## 法条范围

[[合同编]] §509-§533（全面履行 §509 · 约定不明填补 §510/§511 · 涉他合同 §522-§524 · 三大抗辩权 §525-§528 · 提前/部分履行 §530/§531 · 情势变更 §533）

## 是什么 / 易混

履行 = **"把答应的事按约定做全、做好"**。两层意思：① **全面履行**（按约定做到位 + 附随义务）；② 出状况时的**三件武器**——抗辩权（可拒绝/中止）、情势变更（可请求变更/解除）、涉他合同（第三人介入的几种结构）。

### 全面履行 + 附随义务（§509）
- 当事人应按约定**全面履行**自己的义务（标的、数量、质量、地点、时间都要到位）。
- 并遵循**诚信原则**，根据合同性质/目的/交易习惯履行**通知、协助、保密**等**附随义务**。

### 约定不明的填补（§510 → §511）
约定不明时的**两级兜底**：先 **§510**（补充协议 → 不成按合同有关条款/交易习惯）；仍不能确定 → **§511 法定填补**：

| 维度 | §511 法定填补 |
|---|---|
| 质量 | 按强制性国家标准 / 行业标准 / 通常或符合目的的标准 |
| **价款** | 按**订立时履行地市价**；依法应执行政府定价的从其规定 |
| **地点** | 给付货币→**接受货币一方**所在地；交付不动产→不动产所在地；其他→**履行义务一方**所在地（详见 [[履行地点]]）|
| **期限** | 可**随时**履行 / 随时请求，但须给对方**必要准备时间** |
| 方式 | 按有利于实现合同目的的方式 |
| 费用 | 由**履行义务一方**负担 |

### 五组高频易混（重头：三大抗辩权）

| # | 对比 | 分水岭 | 法条 |
|---|---|---|---|
| 1 | [[同时履行抗辩权]] vs [[先履行抗辩权]] | 双方债务**有无先后**：无→同时；有→先履行 | §525 / §526 |
| 2 | [[先履行抗辩权]] vs [[不安抗辩权]] | **谁喊**：后履行方**拒绝**=先履行抗辩；先履行方**喊停**=不安抗辩（方向相反）| §526 / §527 |
| 3 | [[情势变更]] vs 商业风险 | 能否**预见**：可预见的正常涨跌=商业风险（自己扛）；无法预见+明显不公=情势变更 | §533 |
| 4 | [[向第三人履行]]·第三人不能告 vs 能告 | 第三人有无**直接请求权**：一般只能债权人告；真正利他合同第三人可自己告 | §522① / §522② |
| 5 | 由第三人履行 vs [[第三人代为履行]]（代为清偿）| **约定**让人做（出事债务人担责）vs **有合法利益者主动**替还（清偿后债权转移）| §523 / §524 |

## 怎么考 / 坑在哪

### 高频坑位
1. **三大抗辩权用错**：没顺序→同时；有顺序、后履行方拒绝→先履行；先履行方因对方要垮喊停→不安。
2. **不安抗辩"没确切证据就中止"** → 自己反而违约。
3. **把正常涨跌当情势变更** → 那是商业风险；情势变更要"无法预见 + 明显不公平"。
4. **情势变更自己直接解除** → 不行，**必先重新协商**，不成再请法院/仲裁变更或解除。
5. **以为向第三人履行时第三人都能告** → 只有真正利他合同（有直接请求权）的第三人能告。
6. **§523 由第三人履行 与 §524 代为清偿搞混**：前者约定、责任在债务人；后者主动、清偿后债权转移。
7. **约定不明的货币给付地点搞反** → 在**收钱方**（接受货币一方）所在地，不是付钱方。
8. **提前 / 部分履行**：债权人**原则上可拒绝**（不损害其利益的除外）；增加的费用由债务人负担（§530/§531）。

## 怎么答

履行类题目分析四维（概念框架）：
1. **抗辩权三连判**：双方债务有无先后？无→同时；有→"该先的没做好"（后履行方→先履行）还是"先履行方有确切证据怕对方垮"（→不安）。
2. **看变化性质**：可预见/正常波动→商业风险（照常履行）；无法预见+明显不公→情势变更（先协商→请法院/仲裁变更或解除）。
3. **理第三人结构**：向第三人履行（看有无直接请求权）/ 由第三人履行（责任在债务人）/ 第三人代为清偿（合法利益+主动，清偿后债权转移）。
4. **约定不明走填补**：§510 补充协议 → §511 法定填补。

## 🚗 老王小李故事（一个故事讲到底）

> **履行**说白了就是"把答应的事按约定做到位"——老王该交的货按时按质交，小李该付的钱如数付。一旦冒出"谁先谁后、对方靠不靠谱、中途情况大变、能不能让别人来做"，就有一串规则和"拒绝/中止"的武器：
>
> - **谁先谁后（抗辩权）**：约定"一手交钱一手交货"（没说谁先）→ 老王在小李付钱前可拒交、小李在老王交货前可拒付（**同时履行抗辩** §525）。若约定"老王先发货、小李收货 7 天后付款"（有先后），老王没发货就来要钱 → 小李（后履行方）可拒付（**先履行抗辩** §526）。
> - **对方要垮（不安抗辩）**：老王该先发货，但发货前拿到**确切证据**——小李经营严重恶化/转移财产逃债 → 老王（先履行方）可先**中止**发货、要求小李提供担保；小李合理期限内不恢复也不担保，老王可**解除**（§527/§528）。
> - **情况剧变（情势变更）**：钢价正常涨 20% → 商业风险，老王照常供；若基础条件**无法预见**地剧变、继续履行**明显不公平** → 老王先与小李**重新协商**，谈不拢再请法院/仲裁**变更或解除**（§533）。
> - **让别人来做（涉他合同）**：约定货送给丙——一般丙不能自己告，货没送好老王对小李担责（§522①）；若约定/法律给了丙**直接请求权**，丙可自己告老王（§522② 真正利他，详见 [[向第三人履行]]）。约定"由丙来交货"，丙没交好仍找老王（**由第三人履行** §523）；丙是担保人**主动**替老王还钱，还完后小李对老王的债权**转给丙**（**代为清偿** §524，详见 [[第三人代为履行]]）。
