# 代位权

> 债权人**代债务人**向**第三人**主张权利 — [[合同总则]] **保全**之一

## 法条范围

[[合同编]] §535-§537；[[合同编通则司法解释]]（代位权诉讼细则 · 重要扩展）
（⚠️ **§540 是「撤销权」的范围 / 必要费用条款，不属代位权**，已从本页删除）

## 是什么 / 易混

### 定义
**§535**：因债务人**怠于行使**其**对相对人的债权 / 与债权有关的从权利**，影响债权人到期债权实现的——债权人可**以自己名义**代位向相对人请求履行。

### 四大构成要件
1. **债务人**对第三人有**到期债权**
2. 债务人**怠于行使**（不行使 / 不按时行使）
3. **影响**债权人**到期债权**实现
4. **不属专属于债务人自身**的债权

### 不可代位的专属债权（§535 II + 司法解释）

| # | 类型 |
|---|---|
| ① | **身份关系**（赡养 / 抚养 / 扶养 / 继承）|
| ② | **人身损害赔偿** |
| ③ | **劳动报酬 / 退休金 / 抚恤金 / 安置费 / 人寿保险** |
| ④ | 其他**生存 / 人格性**密切相关债权 |

→ 注意：**人身权产生的钱（已到期）可代位**（如肖像许可费已届期）。

### 受偿规则（2021 新规突破）
**合同编通则司法解释**：代位权成立后，**相对人直接向代位债权人履行** → 代位债权人**优先受偿**（告别"入库规则"）。

→ 即：丙欠乙 10 万，甲（乙债权人）代位起诉丙 → **丙直接还甲 5 万**（甲的债权额），**剩余 5 万还乙**。

### 抗辩规则（§535 + [[合同编通则司法解释]]，**非 §540**）

代位权诉讼中，相对人（次债务人）的抗辩三类，**均可**向债权人主张：

| 抗辩来源 | 能否主张 |
|---|---|
| ① 相对人**对债务人**的抗辩（已清偿 / 抵销 / 时效 / 同时履行）| ✅ 可 |
| ② 质疑**代位权成立要件**——"债权人对债务人的债权"不成立 / 未到期 / 已过时效（即"债务人对债权人的抗辩"在**债权瑕疵**意义上）| ✅ 可（动摇代位权根基）|
| ✘ 替债务人**行使其积极权利 / 形成权**（替债务人去抵销、解除合同等）| ❌ 不可（属"权利行使"，非"抗辩"）|

> ⚠️ **订正**：旧表"债务人对债权人的抗辩 ❌ 不可"过于绝对——与官方真题 [[合同通则-多选-28]]（2012-3-59，A 判**对**）冲突。准确口径：**债权瑕疵 / 代位要件层面可主张；仅不得替债务人行使其积极权利**。

### 范围 + 必要费用（**§535 III**）
代位行使范围**以债权人的到期债权为限**（取小）；**必要费用由债务人承担**。
> ⚠️ 别混：**§536** 是"债权未到期的代位保存"；**§540** 是**撤销权**的范围 / 费用——都不是这里。

## 怎么考 / 坑在哪

### 四大陷阱

1. **专属债权排除**：身份 / 人身 / 劳动报酬等不可代位
2. **"已到期的"人身权产生的钱**：可代位（如肖像许可费已届期）
3. **优先受偿**（2021 新规）：直接归代位债权人，告别"入库"
4. **次债务人三类抗辩均可主张**（对债务人的 + 质疑债权瑕疵 / 代位要件 + 针对代位成立）；**仅不得替债务人行使其积极权利**（[[合同通则-多选-28]] 官方 ABC）

## 怎么答

主观题分析框架：
1. **构成**：4 要件是否齐备？
2. **是否专属**：是否在排除清单内？
3. **受偿**：相对人直接还代位债权人 + 优先受偿
4. **抗辩**：相对人可主张 ① 对债务人的抗辩 + ② 质疑代位权要件（债权瑕疵）；不得替债务人行使其积极权利
5. **必要费用**：债务人承担
