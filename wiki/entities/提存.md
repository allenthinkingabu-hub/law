# 提存

> [[合同权利义务终止]] 之一 — **债务人将标的物交付提存机关**→ 债务消灭

## 法条范围

[[合同编]] §570-§574

## 是什么 / 易混

### 本质：债务人的"自我解放"按钮（为什么债就没了）

> **一句话**：债务人**想还、却因债权人的原因还不掉**（对方拒收 / 失踪 / 不知道还给谁）——法律给债务人一个出口：把钱 / 物交给**官方的提存机关（公证处）**，**视为已经履行**，债当场消灭，剩下的由债权人自己去领。

- **它解决什么问题**：不让债务人被"不配合的债权人"**一直拴住**——否则债务人想清偿却清偿不了，还可能背上"逾期 / 违约"黑锅、继续付利息。
- **为什么"交了就算还清"**：**§571**——"提存成立的，**视为债务人在其提存范围内已经交付标的物**"。交给公证处那一刻，债务人在法律上**等于已经履行**，债权债务终止（§557(三)）。
- **触发的都是"债权人那边出问题"**（§570）：拒收 / 失踪 / 死了没确定继承人——**不是债务人图省事**就能随便提存。
- **提存到哪**：**公证处**（提存机关），不是自己存个银行账户——必须交给**中立的官方机构**才成立。

### 适用情形（§570）
债权人有下列情形之一 + 难以履行的：
1. **无正当理由拒绝**受领
2. **下落不明**
3. **死亡未确定继承人 / 遗产管理人**，或**丧失民事行为能力未确定监护人**
4. 法律规定的其他情形
> （标的物**不适于提存**或**提存费用过高**的，可依法**拍卖 / 变卖**，提存所得价款——§570 II）

### 提存四规则

| 维度 | 规则 | 法条 |
|---|---|---|
| **风险负担** | 自提存时**风险由债权人**承担 | §573 |
| **孳息** | **归债权人** | §573 |
| **费用** | **债权人**承担 | §573 |
| **领取期** | **5 年内**不领取 → 归**国家**所有 | §574 |

### 提存的性质
- **代物清偿** 性质（事实层面债务消灭）
- 提存物**所有权移转**给债权人 / 提存机关代为保管

## 🚗 老王小李故事 · 老王拒收逼违约，小李提存自救

> 老王把车卖给小李，约定 5/1 小李付**尾款 10 万**、老王交车。临近付款，**车市大涨**，老王后悔想毁约高价另卖——于是**故意拒收**小李的钱、玩失踪，盘算拖到"小李逾期未付"，再反过来告小李**违约**、解除合同。
>
> 小李怎么破？→ 5/1 把 **10 万提存到公证处**：
> - **提存成立那一刻**，小李的付款义务**视为已经履行**（§571）→ 老王再也说不出小李"违约"，债务终止。
> - **风险 + 孳息**从此归老王（§573）——钱在公证处跟小李再无关系。
> - 老王自己去公证处领钱；**领取费用还得老王出**（§573）；**5 年不领，扣费后归国家**（§574）。
> - 反向保护：若**小李也欠老王**一笔到期债没还，老王来领提存款时，公证处可应小李要求**先拒绝交付**，直到老王把欠小李的结清 / 提供担保（§574）。
>
> 一句话：**提存 = 债务人的"自救按钮"——你不收，我交给国家机构，债就清了，烂摊子归你。**

## 怎么考 / 坑在哪

### 四大陷阱

1. **风险移转**（C1-单选-24）：自提存日 → 风险归**债权人**
2. **5 年归国家**（C1-多选-12 D）：不是归债务人，是**归国家**
3. **费用归债权人**：不是债务人
4. **必须有法定情形**才能提存
