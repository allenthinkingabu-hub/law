# 提存

> [[合同权利义务终止]] 之一 — **债务人将标的物交付提存机关**→ 债务消灭

## 法条范围

[[合同编]] §570-§574

## 是什么 / 易混

### 适用情形（§570）
债权人有下列情形之一 + 难以履行的：
1. **无正当理由拒绝**受领
2. **下落不明**
3. **死亡未确定继承人** / 终止未确定权利义务承受人
4. 法律规定的其他情形

### 提存四规则

| 维度 | 规则 | 法条 |
|---|---|---|
| **风险负担** | 自提存时**风险由债权人**承担 | §573 |
| **孳息** | **归债权人** | §573 |
| **费用** | **债权人**承担 | §572 |
| **领取期** | **5 年内**不领取 → 归**国家**所有 | §574 |

### 提存的性质
- **代物清偿** 性质（事实层面债务消灭）
- 提存物**所有权移转**给债权人 / 提存机关代为保管

## 怎么考 / 坑在哪

### 四大陷阱

1. **风险移转**（C1-单选-24）：自提存日 → 风险归**债权人**
2. **5 年归国家**（C1-多选-12 D）：不是归债务人，是**归国家**
3. **费用归债权人**：不是债务人
4. **必须有法定情形**才能提存

## 真题示例

- [[合同通则-单选-24]] 提存风险负担（答 B · 债权人承担）
- [[合同通则-多选-12]] 提存全套规则（答 AC · D"归甲所有"错应为归国家）
