# 自然债务

> **半个债** — 有债的**实体**,但无**国家强制力保护**的债 — 介于"真债"和"不是债"之间

## 法条范围

[[民法典]] §192(主要)+ §1161(继承超额)+ 学理

## 是什么 / 易混

### 定义

**自然债务**:**有债的实体,但无国家强制力保护**的债。

→ 一句话:**实体在,胜诉权没了**

### 自然债务的"中间形态"

> 自然债务**介于"真正的债"和"不是债"(情谊行为)之间**——这是它的本质。

| 维度 | **真正的债** | **自然债务** | **不是债**(情谊) |
|---|---|---|---|
| 实体请求权 | ✅ 有 | ✅ **有** | ❌ 无 |
| 胜诉权 | ✅ 有 | ❌ **消灭** | ❌ 无 |
| 强制执行 | ✅ 可 | ❌ **不可** | ❌ 不可 |
| 自愿清偿 | ✅ 有效 | ✅ **有效** | ⚠️ 可能是不当得利 |
| 保持受领 | ✅ 可 | ✅ **可** | ❌ 不可 |
| **是不是债?** | **是** | **是**(特殊形态)| **不是** |

→ **自然债务 = 半个债** = "实体在,程序保障没了"

### 🔬 为什么自然债务"仍是债" — 请求权能未完全消失

很多人误以为"时效届满 → 没有请求权能 → 不是债"——这是**80% 对 + 20% 不精确**。

实际上**请求权能有两层**:

```
请求权能
   ├─ ① 实体请求权(要求债务人履行的权利)  ✅ 仍存(债的灵魂还在)
   └─ ② 胜诉权 / 诉权(国家强制力实现请求)   ❌ 消灭(程序保障没了)
```

→ 这就是为什么"自然债务 = **半个债**"——**实体请求权能未消失**,所以**仍是债**!

#### 三个证据证明实体请求权仍在

| 证据            | 说明                                           |
| ------------- | -------------------------------------------- |
| ① **小李仍可起诉**  | 法院不主动审查时效(§193),义务人不抗辩 → 小李照样胜诉              |
| ② **小李仍可催款**  | 书面催款 / 上门要求 / 电话催款 — "请求"行为本身依然合法            |
| ③ **自愿履行可保留** | §192 II 倒装:小李保留 → 反向证明对这笔款**有权利依据** = 实体请求权在 |

#### ⚠️ 与 [[合同通则-单选-03]] 关键易混

- **Q03 说**"请求权能欠缺 → 不再是债权"——指的是**实体请求权能彻底消失**(情谊行为)
- **自然债务**只是"**胜诉权消灭** + 实体请求权能仍存"
- 所以自然债务**仍是债**,只是特殊形态(半个债)

→ Q03 和多选-01 不矛盾!**两种不同程度**的"请求权能缺失"
→ 详见 [[诉讼时效]] 实体页"🔬 请求权能的二层结构"段。

### 🔥 4 大典型情形

| # | 类型 | 法条 | 特点 |
|---|---|---|---|
| ① | **时效届满后债务**(最主要)| §192 | 胜诉权消灭,实体仍存 → [[诉讼时效]] |
| ② | **赌博 / 不法债务** | 学理 | 违公序良俗,法律不予强制保护 |
| ③ | **道德义务**(婚约赠与 / 慈善承诺)| 学理 | 法律未将其纳入正式债的范畴 |
| ④ | **继承超额清偿** | §1161 | 继承人**自愿超额清偿**有效,但不得请求 |

### 5 大效果

| 效果 | 内容 | 法条 |
|---|---|---|
| ① **可受领且保留** | 自愿履行 → 债权人**保留**(不是不当得利)| §192 II |
| ② **可转让 / 抛弃** | 处分权能保留 | 学理 |
| ③ **不能主动抵销** | §568 要求主动方债权有**强制力**(自然债务无)| §568 |
| ④ **不能强制执行** | 胜诉权没了,法院判败诉(义务人抗辩时)| §193 |
| ⑤ **可"复活"** | 义务人重新承诺 → 时效重新计算 3 年 | §192 II |

## 🚗 老王小李 4 种自然债务故事

### 故事 ①:时效届满债务(最常见)

> 老王 2023 借小李 12 万,约定 2023/12/31 还。小李一直没起诉。
> 2026/12/31 时效届满。
> 2027/3 老王自愿还了 5 万。

→ 小李**不必返还** ✅(§192 II)
→ 这就是 [[合同通则-多选-01]] 的核心场景

### 故事 ②:赌博债务(不法)

> 老王和小李玩"赌大小",老王输了 5 万,写借条承认。
> 后来老王反悔不还。

→ 小李起诉 → 法院**不予支持**(违公序良俗 / §153)
→ 但如果老王**自愿**还了,不能要回(自然债务)
→ 注意:赌博本身是违法,所以**借条无效**;法律不强制履行但不否认自愿履行

### 故事 ③:道德义务(婚约 / 慈善承诺)

> 老王和小李订婚,老王承诺"结婚时送你一辆车"。
> 后来分手,小李起诉要求老王履行承诺。

→ 法院**不支持**(婚约赠与是道德义务,不是法律义务)
→ 如果老王**已经送了车**,事后反悔索回 → 不支持(自然债务的受领权)

### 故事 ④:继承超额清偿(§1161)

> 老王去世,遗产 50 万,生前债务 80 万。
> 小李(继承人)继承遗产 50 万 + **自愿还了** 30 万超额部分。

→ 小李超额清偿的 30 万 → **不能向其他债权人要回**(§1161)
→ 但**未自愿清偿**前,小李对超额部分**无法定义务**

## 怎么考 / 坑在哪

### 三大陷阱

1. **以为自然债务"不是债"** ❌ —— 是债,只是特殊形态
2. **以为自愿履行可索回** ❌ —— 自然债务有受领权,不构成不当得利
3. **以为自然债务可强制执行** ❌ —— 没胜诉权,法院不会支持(义务人抗辩时)

### 答题口诀(自然债务判定)

```
Step 1:判断有无"债的实体"
  有 + 法律不强制保护 → 自然债务(进入 step 2)
  没有 → 情谊 / 道德 / 反射利益
  
Step 2:识别 4 类典型情形
  ① 时效届满后债务  → 最常见
  ② 赌博 / 不法债务
  ③ 道德义务承诺
  ④ 继承超额清偿
  
Step 3:5 大效果速查
  - 可受领 + 保留(不是不当得利)
  - 可转让 / 抛弃
  - 不能主动抵销
  - 不能强制执行
  - 可重新激活(时效情形)
```
