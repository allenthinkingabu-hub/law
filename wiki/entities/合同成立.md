# 合同成立

> [[承诺]] 生效时合同成立；§483；事实判断（有没有合意）。

## 简介

合同成立是 [[合同订立]] 的终点。本质是**事实判断** —— 当事人之间**有没有合意**。与 [[合同生效]] 是两回事。

## 关键信息

- **法条**：[[民法典]] §483（承诺生效＝合同成立）
- **判断性质**：事实判断
- **后续问题**：是否同步 [[合同生效]]？

## 详细内容

### 一般规则

§483：[[承诺]] 生效时合同成立。

### 特殊形式的成立时点

| 形式             | 成立时点                      | 法条   |
| -------------- | ------------------------- | ---- |
| 一般合同           | 承诺生效时                     | §483 |
| 合同书            | "签名、盖章或者按指印"**任一即可**      | §490 |
| 一方已履行主要义务、对方接受 | 履行时                       | §490 |
| [[电子合同]]       | **提交订单成功时**（不是付款时；另有约定除外） | §491 |

### 与 [[合同生效]] 的区分

| 维度   | 合同成立    | [[合同生效]]                             |
| ---- | ------- | ------------------------------------ |
| 判断   | 事实判断    | 法律评价                                 |
| 问题   | 有没有合意？  | 合意有无约束力？                             |
| 一般情形 | 承诺生效时成立 | 依法成立**即生效**（§502）                    |
| 例外   | —       | **附生效条件/期限**（§158）、**需经批准** → 成立但未生效 |

> 报批义务条款**独立有效**（即使主合同未生效）。

## 🪤 经典陷阱区

### 陷阱 1：把"成立"等于"生效"

> 90% 的初学者错误。

| 维度 | 合同成立 | [[合同生效]] |
|---|---|---|
| 性质 | **事实判断**（有没有合意）| **法律评价**（合意有约束力）|
| 法条 | §483 | §502 / §158 |
| 默认 | 承诺生效时 | 成立即生效 |
| 例外 | — | **附条件 / 期限 / 需批准** → 成立但未生效 |

→ 老王小李"**子场景 4B**"就是典型反例：合同 9/12 成立，但要等到 12 月小李发年终奖**附生效条件**才生效（详见下方"老王小李买车"故事第四幕）。

→ 另一个典型反例：[[合同通则-多选-15]] 房屋买卖**未登记** = 合同**有效**（登记影响**物权变动**，不影响合同的成立 / 生效）

### 陷阱 2：合同书 = 必须签字 + 盖章

> 旧法 vs 新法的重要变化。

**§490 新规则**：**签名 / 盖章 / 按指印 — 任一即可**！

→ 老王小李即使只盖了一个章（没签字、没按指印）也成立 ✅
→ 旧法要"签字 + 盖章"的认知**已过时**

### 陷阱 3：电子合同 = 付款时成立

> 双 11 抢购的典型误区。

**§491**：[[电子合同]] **提交订单成功时**成立——**不是付款时**！

→ 你点了"提交订单"那一刻 → 合同已成立 → 如果商家拒发货 = **违约**（不是"还没合同关系"）
→ 详见 [[电子合同]] · [[合同通则-单选-10]] 真题（双 11 抢冰箱）

### 陷阱 4：合同未成立 ≠ 无责任

> 主观题大案例第二步的反向陷阱。

合同**未成立**时，仍可能产生 [[缔约过失责任]]（§500）——
- 假借订立合同，恶意磋商
- 故意隐瞒重要事实 / 提供虚假情况
- 其他违背诚信原则的行为

→ 例：老王明知车主已被法院查封仍与小李谈，谈崩了 → 合同未成立 → 但小李信赖支出的差旅 / 检测费 → 老王赔（[[合同通则-单选-11]] · [[合同通则-单选-12]]）

## 🌳 4 个概念的完整关系全景

[[合同订立]] / [[要约]] / [[承诺]] / [[合同成立]] / [[合同生效]] 是**包含 + 阶段**关系，不是并列：

```
                     [[合同订立]]
        ═══════════════════════════════════
        (合同总则第一节 · §472-§502 整段)
        
   ┌─────────────┬─────────────┬─────────────┐
   │             │             │             │
[[要约]]      [[承诺]]    [[合同成立]]  [[合同生效]]
 §472         §479         §483          §502
   │             │             │             │
 第 1 步        第 2 步       第 3 步       第 4 步
 发出意思     同意意思      合意达成       法律承认
 (单方)       (单方)       (双方有合意)   (合意有约束力)
   │             │             │             │
   ▼             ▼             ▼             ▼
"我卖你 12 万"  "好我买"     合同成立！    成立 ≠ 生效
                            (事实判断)    (法律评价)
```

### 三个层级对照表

| 层级 | 概念 | 性质 | 范围 |
|---|---|---|---|
| **顶层** | [[合同订立]] | **流程名 / 节名** | 包含 4 个阶段（整段 §472-§502）|
| **第 1 阶段** | [[要约]] | 单方意思表示 | 卖方发出"我卖" |
| **第 2 阶段** | [[承诺]] | 单方意思表示 | 买方说"我买" |
| **第 3 阶段** | **[[合同成立]]**（本页）| **事实状态** | 双方有合意了（§483 承诺生效时）|
| **第 4 阶段** | [[合同生效]] | **法律评价** | 合意有约束力（§502 默认成立即生效）|

### 关键 3 句话理清楚

1. **[[合同订立]] 是"整段流程"的名字** — 包含要约 + 承诺 + 合同成立 + 合同生效
2. **[[要约]] + [[承诺]] 是"两个动作"** — 一发一收，构成合意
3. **[[合同成立]] = 承诺生效那一刻** — 是个**节点**，不是动作

→ "订立"是**线段**，"成立"是**线段上的某个点**。

## 举例 · 老王小李买车（合同成立全流程版）

> 把 4 个阶段在一个故事里都跑一遍，**§472 → §502 一气呵成**。

### 第一幕：发要约（§472 要约阶段）

> **9 月 10 日**，老王发短信给小李："小李，我那台 2020 凯美瑞，14 万公里，**卖你 12 万**，**9 月 20 日前答复**。"

法律评价：
- ✅ 内容具体确定（车 + 价 + 期限）
- ✅ 表明承诺即受约束
- → 构成 **§472 [[要约]]**
- → 短信到达小李 → **要约生效**（§474 到达主义）

**此时**：
- 合同**成立**？❌ 没有（小李还没同意）
- 合同**生效**？❌ 没有（连成立都没）

### 第二幕：作出承诺（§479 承诺阶段）

> **9 月 12 日**，小李回短信："**好，老王，就 12 万，我买！**"

法律评价：
- ✅ 对要约表示**同意**（§479 [[承诺]] 定义）
- ✅ 内容与要约一致（无 [[实质性变更]]，§488）
- → 这是 **§479 [[承诺]]**
- → 小李的短信**还没到老王手机** = 承诺**尚未生效**

**此时**：
- 合同**成立**？❌ 还没（承诺还没到达）
- 合同**生效**？❌ 没有

### 第三幕：承诺到达 = 合同成立（§483 + §484）✨ 关键时点

> **9 月 12 日 14:30**，老王手机"叮"一声，收到小李的承诺短信。

法律效果：
- 承诺**到达老王** → 承诺**生效**（§484 到达主义）
- **§483："承诺生效时合同成立"**
- → **合同于 9 月 12 日 14:30 成立！** ✅

**此时**：
- 合同**成立**？✅ **成立了**！
- 合同**生效**？⏳ 看下一幕——是否有阻碍生效的因素

### 第四幕：成立后的"生效"判断（§502）

#### 子场景 4A：默认 → 成立即生效

> 老王小李的买卖**没有附条件 / 期限**，**不需要批准**。

→ **§502 默认规则**：合同**依法成立即生效**
→ **9/12 14:30 既是成立时点，也是生效时点**
→ 老王必须交车，小李必须付 12 万

#### 子场景 4B：附生效条件 → 成立但未生效（§158）

> 小李说："**等我下个月发了年终奖，再付钱过户**。"  
> 老王同意：合同附条件——**小李发年终奖**时生效。

→ 合同 9/12 **成立**了（有合意）
→ 但**未生效**（生效条件未成就）
→ 等 12 月小李发年终奖 → 条件成就 → 合同**才生效**

→ 这就是经典的 **"成立 ≠ 生效"**！

#### 子场景 4C：报批合同（涉外特殊情形）

> 假设这是涉外车辆买卖，需要海关备案。

→ 合同 9/12 **成立**
→ 但**未生效**（批准前）
→ 一旦获批 → 生效
→ **但是**：合同里的**报批义务条款 + 仲裁条款**——**独立有效**（§502 II）
→ 即：老王如果拒不报批 → 小李可以**起诉违约**

### 故事时间轴汇总

```
9/10           9/12 中午       9/12 14:30       后续
要约发出  →    承诺发出    →   承诺到达      →   生效判断
(§472)       (§479)          = 合同成立        (§502)
                              (§483)
              [要约阶段]      [承诺阶段]       [生效阶段]
                              ✨ 关键时点 ✨
```

### 4 种特殊成立时点的"故事变体"

| 子情形      | 老王小李怎么演            | 成立时点                  | 法条   |
| -------- | ------------------ | --------------------- | ---- |
| 一般合同     | 上述短信往返             | 承诺到达老王时（9/12 14:30）   | §483 |
| 合同书      | 老王小李签纸质买卖合同        | 任一方**签名 / 盖章 / 按指印**时 | §490 |
| 已履行 + 接受 | 老王没等承诺就把车开过去，小李笑纳  | **老王交车那一刻**           | §490 |
| 电子合同     | 小李在二手车 APP 上"立即下单" | **APP 显示"下单成功"那一刻**   | §491 |

## 🔍 §490 II 深度解析："已履行 + 接受" 的特殊成立规则

> "4 种特殊成立时点"中**最容易考、最容易理解错**的一种——**没签字也能成立合同**！

### 法条原文

> **§490 II**："当事人**未采用书面形式**但是**一方已经履行主要义务**，**对方接受**时，该合同成立。"

→ 一句话：**没签字、没合同书、没盖章——但一方"已经做了"、另一方"收了"——合同也算成立。**

### "已履行"是什么意思？

"履行" = **实际做合同约定的事**。"**主要**义务" = 合同**最核心**的那件事，不是边角。

| 合同类型 | "主要义务"是什么 |
|---|---|
| 买卖合同 | **交付标的物**（卖方）/ **支付价款**（买方）|
| 租赁合同 | **交付租赁物**（出租人）/ **支付租金**（承租人）|
| 装修合同 | **完成装修施工**（装修方）|
| 加工承揽 | **交付加工成果**（承揽方）|

→ 法律**不要求"全部履行"**，**主要部分做了**就够。

### 3 个要件（缺一不可）

```
① 未采用书面形式（口头 / 事实行为）
② 一方"已经"履行"主要"义务（已经做了 + 主要的事）
③ 对方"接受"（明示 / 默示——比如不反对、继续配合）
```

→ 3 要件齐全 → 合同成立 → 即使没签字、没合同书、没盖章。

### 🚗 老王小李"口头买车 + 当场交车"故事

> **9/10** 老王和小李在车友群语音聊：
> 老王："**我那辆 2020 凯美瑞卖你 12 万**？"
> 小李："**行啊**！"
> （双方**只是口头约定**，没签任何书面合同 / 转账凭证 / 收据）
>
> **9/11** 第二天，老王**把车开到小李小区门口**，交了钥匙、行驶证。
> 小李**收下车 + 当场开车去兜了一圈**，没有提任何异议。

| 要件 | 本案情形 | 满足？|
|---|---|---|
| ① 未采用书面形式 | 口头约定，没签字 | ✅ |
| ② 一方已经履行主要义务 | 老王**已交车 + 钥匙 + 行驶证**（卖方主要义务）| ✅ |
| ③ 对方接受 | 小李**收车 + 开车上路** = 接受 | ✅ |

→ **合同成立！**
→ **成立时点 = 9/11 老王交车那一刻**（§490 II）
→ 小李**必须付 12 万**——即使没书面合同也跑不掉
→ 如果小李事后说"我没签合同所以不算"——**没用**，§490 II 已经认定合同成立

### 🚫 3 个反向场景（不适用 §490 II）

#### 反例 1：只履行了"次要"部分

> 老王把车开过去时**只给了车，没给行驶证 / 登记证**（无法过户）。

→ 老王履行的**不是主要义务**（车 + 过户文件才是完整的卖方主要义务）
→ §490 II 不适用 → 合同**未成立**

#### 反例 2：对方"不接受"

> 老王把车开过去，小李说：**"我反悔了，不要了，你开走！"**

→ 对方**明示拒绝接受**
→ §490 II 不适用 → 合同**未成立**

#### 反例 3：双方约定了"必须签合同书"

> 老王、小李口头说："**这次我们要正式签合同书，今天先谈，明天来签**"。
> 但老王**今天**就把车开过去了，小李也收了。

→ 一旦双方**约定采用合同书形式**（§490 I 启动）→ **必须签字 / 盖章 / 按指印**
→ **§490 II 不能替代 §490 I 的签字要求**
→ ⚠️ 这正是 [[合同通则-单选-12]] 的核心陷阱

### 📚 §490 I vs §490 II 互斥关系

| 项 | 内容 | 适用情形 |
|---|---|---|
| **§490 I** | 采用**合同书**形式 → 自双方**签名 / 盖章 / 按指印**任一时成立 | **双方约定要书面** |
| **§490 II** | **未采用书面形式**但**一方已履行主要义务 + 对方接受** → **履行时**成立 | **没约定书面，事实合同** |

→ §490 I 和 §490 II **互斥**：要么是**书面合同（要签字）**、要么是**事实合同（看履行）**
→ 不能"我们说好要签合同，但我先履行了"——这种情形按 §490 I 处理，没签字就没成立

### 立法目的

- **保护交易安全**：防止"我没签字所以不算"的事后耍赖
- **尊重事实合意**：双方"做了 + 收了" = 有合意 + 有履行事实 → 不必拘泥于形式

## 🎯 一句话记忆

> **"要约 + 承诺"是两个动作；**  
> **"合同成立"是承诺生效那一刻；**  
> **"成立 ≠ 生效，生效要再看 §502"**
