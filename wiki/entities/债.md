# 债

> [[民法典]] 中**债**是核心概念 — 特定人之间的请求权关系

## 法条范围

[[总则编]] §118；[[合同编]] §463 / §468 等

## 是什么 / 易混

### 大白话定义

> "**债**"听着玄，其实就是 **"谁该给谁点什么"**——欠钱、欠货、欠个赔偿，都是债。

### 定义（法条版）
**§118**：**债权**是因合同、侵权行为、无因管理、不当得利以及法律的其他规定，权利人**请求**特定的义务人为或者**不为一定行为**的权利。

### 债的 4 大要素

| 要素 | 内容 |
|---|---|
| **主体** | 债权人 + 债务人（特定）|
| **客体** | 给付（行为 / 不行为）|
| **内容** | 债权 + 债务（权利义务）|
| **发生原因** | 合同 / 侵权 / 无因管理 / 不当得利等 |

### 与物权的区分

| 维度 | **债权** | **物权** |
|---|---|---|
| 性质 | **相对权**（仅对特定人）| **绝对权**（对世） |
| 客体 | 特定人的行为 | 特定的物 |
| 权能 | 请求 / 受领 / 保全 / 处分 | 占有 / 使用 / 收益 / 处分 |
| 排他性 | **非排他**（同一标的物可有多债）| **排他**（一物一权） |
| 公示 | 不需要公示 | 需公示（登记 / 占有）|

## 怎么考 / 坑在哪

### 三大陷阱

1. **相对性**：债只能对特定人主张，不能对世
2. **非排他**：同一标的可以多债并存
3. **任意性**：债权人可放弃 / 转让 / 行使，自由度高

## 🔑 民法典没有"债编"——合同编通则兼任

> 这是理解整个债法体系的**总开关**。

[[民法典]] 七编里**没有专门的"债法总则"那一编**：

```
民法典七编：
  总则 → 物权 → 合同 → 人格权 → 婚姻家庭 → 继承 → 侵权责任
       ❌ 没有"债编"
```

→ 债的**共通规则**（履行、保全、转让、消灭）**全部塞进了 [[合同编]] 通则**
→ **§468 接口条款**：非合同之债（侵权 / 无因管理 / 不当得利）的共通问题 → **参照合同编通则**（性质排斥的除外）

→ 详见 [[合同编适用范围]]

## 🚗 老王小李"4 种债"故事

> 老王和小李之间能生出**债**的方式有好几种，一个故事四个版本：

| 类型 | 故事 | 法条 |
|---|---|---|
| **合同之债** | 老王卖车给小李，小李欠车款 | [[合同编]] §463 起 |
| **侵权之债** | 老王骑车撞坏小李的车 → 老王欠赔偿 | [[侵权责任编]] §1165 起 |
| **无因管理之债** | 小李出差，老王没义务却帮他喂猫 + 垫猫粮钱 | §979 起 |
| **不当得利之债** | 小李转账手滑多转老王 1000 → 老王欠这 1000 | §985 起 |

→ 说好的 = **合同之债**；没说好、因别的事冒出来的（撞了 / 帮了 / 多拿了）= **非合同之债**

→ 详见 [[债的发生原因]]
