# 抗辩

> 请求权的**防守总纲** —— 面对"你要给我 X"，债务人说**"没欠 / 还过了 / 还没到期 / 过期了不给"**。是 [[请求权基础]] 的另一面。

## 法条范围

散见全编：**§525-§528**（三大履行抗辩权）· **§192-§193**（诉讼时效抗辩 + 职权禁用）· **§548**（抗辩继受）· **§549**（对比：抵销）· **§687**（先诉抗辩权）；学理总结（德国法 **Einwendung / Einrede** 二分）。

## 是什么 / 易混

### 核心：抗辩 = 请求权的"反作用力"

> 债权人行使**请求权**（"你要给我 X"）→ 债务人用**抗辩**回击（否认它 / 消灭它 / 拒绝它）。一正一反，是民法"攻防"的两面。

### ★ 第一刀：抗辩（广义）vs 抗辩权（狭义）——**法院要不要主动管？**

这是最关键的一刀，直接决定打官司会不会"白白败诉"：

|     | **抗辩**（广义 · Einwendung） | **抗辩权**（狭义 · Einrede）        |
| --- | ----------------------- | ---------------------------- |
| 干什么 | **否认**请求权（根本没生 / 已消灭）   | **不否认**请求权，只是**拒绝履行**        |
| 典型  | 合同无效、已清偿、已解除            | 诉讼时效、同时履行、不安、先诉              |
| 法院  | **可依职权审查**（当事人不提也能认）    | **不得主动适用**，**必须当事人主张**（§193） |
| 本质  | 一项**事实 / 事由**           | 一种**权利**（抗辩权）                |

→ **后果（§193 职权禁用规则）**：债权过了时效，债务人**不主动喊**"过时效了"，法院**不会**主动帮他驳回——照样判他还钱。但合同无效，法院**可主动**认定。**广义抗辩，法官替你看着；抗辩权，你不喊没人管。**

### 第二刀：广义抗辩内部——请求权是"没生"还是"死了"

| 类型 | 主张 | 典型 |
|---|---|---|
| **权利未发生抗辩**（权利障碍抗辩） | 请求权**根本没产生** | 合同无效 / 不成立 / 被撤销；欠缺生效要件 |
| **权利消灭抗辩** | 请求权曾有、**已归于消灭** | 已清偿 / 已抵销 / 已提存 / 已免除 / 合同已解除 |

### 第三刀：抗辩权内部——**永久挡** vs **暂时挡**

| 类型 | 效力 | 典型 |
|---|---|---|
| **永久性抗辩权**（永久抗辩） | **永久**排除请求权 | **诉讼时效**届满抗辩（§192）|
| **延期性抗辩权**（一时 / 延缓抗辩） | **暂时**阻止，条件成就即不能再挡 | 三大履行抗辩权（§525-§528）、[[先诉抗辩权]]（§687）|

### 抗辩的体系树（一张图记住）

```
            请求权（攻：你要给我 X）
                 │ 被
                 ▼
              抗辩（守）
        ┌────────┴─────────┐
   广义抗辩                抗辩权
（否认债·法院依职权）   （认债但拒履行·须当事人主张 §193）
     │                        │
  ┌──┴───┐              ┌──────┴──────┐
权利未发生  权利消灭     永久性          延期性
(合同无效) (已清偿/解除) (诉讼时效)  (同时/先履行/不安/先诉)
```

### ★ 抗辩 ≠ 抵销 ≠ 反诉（易混边界）

| | 干什么 | 性质 |
|---|---|---|
| **抗辩** | 纯防守，让对方请求**落空 / 打折**，不产生独立请求 | 防御 |
| **[[抵销]]**（§549） | 拿**自己对对方的债权**去冲抵，转守为攻一部分 | **形成权**（非单纯抗辩）|
| **反诉** | 另起一个独立的诉 | 独立之诉 |

→ 正因抵销是形成权、不是普通抗辩，[[债权转让]] 才把 **§548（抗辩继受）**与 **§549（抵销）分开**规定——抵销还要满足"同种类 + 先于 / 同时到期"条件。

## 怎么考 / 坑在哪

### 三大坑

1. **抗辩 vs 抗辩权混为一谈**：考"法院能否主动适用"——诉讼时效 / 同时履行（**抗辩权**）**必须当事人主张**（§193）；合同无效 / 已清偿（**广义抗辩**）法院**可依职权**认定。
2. **时效抗辩"永久"且"不喊就输"**：诉讼时效抗辩是**永久性抗辩权**，但受 §193 职权禁用约束——债务人不主张，法院装看不见（**缺席 = 放弃**；法官至多作**消极释明**）。
3. **§548 抗辩"全继受"**：债权转让后，债务人对让与人的**一切抗辩（广义 + 抗辩权）**都能向受让人主张——这正是 [[合同通则-多选-11]] 四个选项**全选 ABCD** 的原因（见下）。

### ★ §548 抗辩继受：四类抗辩的"全家福"（[[合同通则-多选-11]] 锚点）

[[合同通则-多选-11]] 的 ABCD 恰好**各踩一类抗辩**——背抗辩体系，用这道题当锚最省力：

| 选项           | 抗辩类型        | 归到哪一类              |
| ------------ | ----------- | ------------------ |
| **A** 合同无效   | **权利未发生抗辩** | 广义抗辩（权利障碍）         |
| **B** 履行期未届至 | **延期性抗辩**   | 抗辩权（一时 · 期限利益）     |
| **C** 已过诉讼时效 | **永久性抗辩权**  | 抗辩权（永久 · §192）     |
| **D** 合同已消灭  | **权利消灭抗辩**  | 广义抗辩（清偿 / 解除 / 抵销） |
|              |             |                    |

→ §548 让债务人把这"**四类全家福**"统统端给受让人 → 全选。受让人接的是"**二手带病**"债权。

### ★ 抗辩继受的应用：债之移转后，债务人的抗辩怎么走（三场景对照）

上面"四类全家福"答的是**继受什么**；这张表答——同一套抗辩，在**债之移转的三种形态**里各自**被加强还是削弱**。一条主线：**移转不改变债的内容，受让人 / 新债务人接的是"带病债权 / 带病债务"；但保理对债务人抗辩另设两道特别限制。**

| 移转形态                            | 债务人能打的抗辩牌                                                   | 法条             | 特别加 / 减                                                                        |
| ------------------------------- | ----------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------ |
| **① 债权转让**（债务人 → 受让人）           | §548 四类抗辩**全继受** + §549 **抵销**                              | §548 / §549    | 基准线：受让人接"**二手带病**"债权，债不因转让"满血复活"                                               |
| **② 保理**（债务人 → 保理人）             | 原则**同①**（§769 准用债权转让：通知§546 / 抗辩§548 / 抵销§549 / 从权利§547 全借） | §769→§548/§549 | **被砍两刀**：§763 砍掉"账款虚构不存在"对**善意**保理人的抗辩（明知除外）；§765 冻结"通知后无正当理由改 / 解基础合同"对保理人的效力 |
| **③ 债务承担·免责**（移转侧 · 新债务人 → 债权人） | §553 新债务人**可承继**原债务人的**抗辩**                                 | §553           | **砍掉抵销**：原债务人对债权人的**抵销权**，新债务人**不得**主张（抵销是形成权、属原债务人处分范围）                       |

- **共同法理**：债之**主体**变了，债之**内容 / 瑕疵**不变——"带病移转"，移转本身不给债"消毒""复活"。
- **关键差异（抵销跟人走）**：转让侧（①②）债务人**继受抗辩 + 可抵销**（§549，抵销权主体＝债务人本人、没变）；承担侧（③）新债务人**只继受抗辩、不得抵销**（§553，原债务人已退出、其抵销权不可代为处分）。
- 🎯 **一句话**：**债权转让＝全继受+可抵销；保理＝同上但 §763/§765 砍两刀；债务承担＝继受抗辩但 §553 不得抵销。移转不消毒，抵销跟人走。**

## 🚗 老王小李故事（一辆车，讲完四类抗辩）

> 老王（债权人）赊卖车给小李（债务人），回头找小李要车款。小李手里能打的"防守牌"，正好凑齐抗辩的**四大类**——一辆车把"抗辩"一次看懂：

- **① 权利未发生抗辩（广义 · 合同无效）**：小李说"咱这买卖合同**根本无效**（车是禁止流通物）——债**压根没成立**，我不欠你"。→ 否认请求权**存在**。法院**可主动**认定无效。
- **② 权利消灭抗辩（广义 · 已清偿）**：小李说"这钱我**早还清了**"（或已解除 / 已抵销）——债**曾经有、现在没了**。→ 否认请求权**仍存**。
- **③ 延期性抗辩权（一时 · 期限未到）**：小李说"咱说好**3 个月后**付，**还没到日子**呢"。→ 不否认欠钱，只是**暂时**不给；到期这张牌自动失效。
- **④ 永久性抗辩权（永久 · 时效已过）**：这笔款**拖过了 3 年时效**，小李说"**过时效了，我有权永远不还**"。→ 不否认欠过钱，但**永久**拒付。⚠️ 关键：小李**必须自己喊**这句（§193，法院不主动帮他）；忘了喊，照样判他还。

> **一句话串起来**：①"没欠" ②"还过了" ③"还没到期" ④"过期了不还"——前两张（①②）是**广义抗辩**（否认债、法院依职权管），后两张（③④）是**抗辩权**（认债但拒付、必须自己主张）。
>
> 而这四张牌，小李原来能对**老王**打，债权转让后对受让人**老张照样打**（§548）——这就是 [[合同通则-多选-11]] 全选 ABCD 的底层逻辑。

## 🎯 一句话记忆

> **"抗辩 = 请求权的防守：广义抗辩**否认债**（没生 / 已灭，法院依职权）；抗辩权**认债但拒履行**（永久 = 时效 / 一时 = 同时·先履行·不安·先诉，**须当事人主张** §193）。"**
> **"时效抗辩**不喊就输**；§548 让一切抗辩**随债权过户**。"**
> **"债之移转三形态抗辩各有命运：债权转让全继受+可抵销、保理同上但 §763/§765 砍两刀、债务承担继受抗辩但 §553 不得抵销——移转不消毒，抵销跟人走。"**
