# 债权转让

> 债权人将**债权**转让给**受让人** — [[合同总则]] **转让**之核心

## 法条范围

[[合同编]] §545-§550

## 是什么 / 易混

### 定义
**§545**：债权人可以将债权的**全部或者部分转让**给第三人——除非**性质 / 当事人约定 / 法律规定**不得转让。

### 三类不得转让债权（§545）

| 类型          | 典型                      |
| ----------- | ----------------------- |
| **性质上不得转让** | 人身损害赔偿 / 扶养费 / 赡养费 等专属性 |
| **约定不得转让**  | 但**不得对抗善意第三人**（金钱债权除外）  |
| **法定不得转让**  | 法律明确规定                  |

### 转让的对外效果（两个层面别混）

| 层面 | 时点 | 效果 |
|---|---|---|
| **让与人 ↔ 受让人** | **让与协议生效时** | 债权（及从权利）**移转**，受让人**取得债权** |
| **对债务人（通知前）** | — | 转让**对债务人不发生效力**（债务人向让与人清偿仍有效）§546 |
| **对债务人（通知后）** | **通知到达** | 对债务人生效，债务人应向**受让人**履行 |

> ⚠️ "受让人**取得债权**" = **让与协议生效时**（非通知日）；通知（§546）只解决"**对债务人的效力**"。两者别混（见 [[合同通则-单选-21]]）。

### 抗辩继受（§548）
**§548**：债务人对**让与人的抗辩** → 可以向**受让人**主张。

→ 一切**通知到达前**已经产生 / 可能产生的抗辩都能用（四项恰好覆盖 [[抗辩]] 的四大类型）：
- 合同无效（**权利未发生抗辩**）
- 履行期未届至（**延期性抗辩权**）
- **时效已过（诉讼时效抗辩 · 永久性抗辩权）**
- 合同已消灭（**权利消灭抗辩**）

> **"抗辩继受"含义**：受让人**接手的是"带原有瑕疵"的债权**——债权转让**不会**让债"满血复活"。债务人原本能对让与人举的抗辩盾，转让后**照样能对受让人举**。
> - **"受让人接（继受）时效抗辩"**（见 [[合同通则-多选-10]] B / [[合同通则-多选-11]]）：过诉讼时效的债权**仍可转让**（自然债务、仍是财产），但受让人买到的是"**债务人一主张时效（§192：时效届满有权拒绝履行）就能赖掉**"的债——能否实现取决于债务人是否举时效盾。即"**转让 ≠ 让债权重获胜诉权**"。
> - ⚠️ nuance：个别裁判认为**善意**受让人（受让时确不知已过时效）可不受时效抗辩对抗；但**默认按 §548——抗辩随债权走**，债务人可对受让人主张时效抗辩。

### 抵销权（§549，两情形）
债务人对让与人的债权，可向**受让人**主张抵销——二选一：
- **§549①**（不同合同之债）：**接到通知时**债务人已对让与人享有债权，且该债权**先于 / 同时**于转让债权到期。
- **§549②**（同一合同之债）：债务人的债权与转让的债权**基于同一合同产生**——**不受债务人债权发生时间限制**（即便通知后才发生 / 到期，亦可抵）。

→ 典型（[[合同通则-单选-55]]）：买方因标的瑕疵对卖方的赔偿债权，与被转让的货款债权同出一份买卖合同 → 走 §549②，**纵使损害发生在通知之后**仍可对受让人抵销。底层仍需是有效抵销（§568：两笔同种类、主动债权到期）。

### 从权利的随附（§547）
**§547 I**：债权人转让债权 → **从权利**（如**抵押权 / 保证 / 利息**）随同转让。但**专属于让与人自身**的除外。
**§547 II**：受让人取得从权利**不因该从权利未办理转移登记手续或者未转移占有而受到影响**（§209 登记生效主义的**法定例外**）。

→ 典型应用：转让债权时，**主债权的抵押权**随债权**自动移转、无须另行登记**（[[合同通则-单选-21]]：抵押权与债权**同于让与生效日**取得，登记仅补公示）。

### 增加的履行费用（§550）
**§550**：因债权转让**增加的履行费用**，由**让与人**负担。

→ 法理：公平 + 诚信——**债务人不应因他人（债权人）的转让行为而使自己地位削弱 / 成本增加**。
→ 典型：**部分 / 分割转让**致债务人要分头向多个受让人履行、跑腿转账成本上升 → 多出的费用由**让与人**掏（[[合同通则-多选-32]]：10 万拆 10 份分别转让，增费由让与人李某承担，D 对）。§545 官方释义把"部分转让增加债务人负担"直接列为 §550 典型场景。

## 怎么考 / 坑在哪

### 五大陷阱

1. **赌债不可转让**：违法之债本身不受保护
2. **时效届满债权可转让**：自然债务可转，受让人继受时效抗辩
3. **专属性人身权不可转**：人身损害赔偿不可
4. **约定不可转让 ≠ 对所有人无效**：不得对抗善意第三人
5. **抵押权随主债权**：无需另行登记（C1-单选-21）

## 怎么答

主观题分析框架：
1. **可否转让**：是否属 3 类不得转让？
2. **通知**：是否到达债务人？
3. **抗辩继受**：债务人可援引哪些抗辩？
4. **抵销**：债务人是否可主张抵销？
5. **从权利**：抵押 / 保证是否随之转移？
