# 债权转让

> 债权人将**债权**转让给**受让人** — [[合同总则]] **转让**之核心

## 法条范围

[[合同编]] §545-§550

## 是什么 / 易混

### 定义
**§545**：债权人可以将债权的**全部或者部分转让**给第三人——除非**性质 / 当事人约定 / 法律规定**不得转让。

### 三类不得转让债权（§545）

| 类型 | 典型 |
|---|---|
| **性质上不得转让** | 人身损害赔偿 / 扶养费 / 赡养费 等专属性 |
| **约定不得转让** | 但**不得对抗善意第三人**（金钱债权除外）|
| **法定不得转让** | 法律明确规定 |

### 转让的对外效果

| 阶段 | 规则 |
|---|---|
| **通知到达债务人**之前 | 对债务人**不发生效力** | §546 |
| **通知到达后** | 受让人取得债权 + 债务人应向受让人履行 |

### 抗辩继受（§548）
**§548**：债务人对**让与人的抗辩** → 可以向**受让人**主张。

→ 一切**通知到达前**已经产生 / 可能产生的抗辩都能用：
- 合同无效
- 履行期未届至
- 时效已过
- 合同已消灭

### 抵销权（§549）
**§549**：债务人在转让通知到达时对让与人享有到期债权 + 与被转让债权**同种类 / 先于到期** → 可向**受让人**主张抵销。

### 从权利的随附（§547）
**§547**：债权人转让债权 → **从权利**（如**抵押权 / 保证 / 利息**）随同转让。但**专属于让与人自身**的除外。

→ 典型应用：转让债权时，**主债权的抵押权**自动随之转移（C1-单选-21）。

## 怎么考 / 坑在哪

### 五大陷阱

1. **赌债不可转让**：违法之债本身不受保护
2. **时效届满债权可转让**：自然债务可转，受让人继受时效抗辩
3. **专属性人身权不可转**：人身损害赔偿不可
4. **约定不可转让 ≠ 对所有人无效**：不得对抗善意第三人
5. **抵押权随主债权**：无需另行登记（C1-单选-21）

## 怎么答

主观题分析框架：
1. **可否转让**：是否属 3 类不得转让？
2. **通知**：是否到达债务人？
3. **抗辩继受**：债务人可援引哪些抗辩？
4. **抵销**：债务人是否可主张抵销？
5. **从权利**：抵押 / 保证是否随之转移？
