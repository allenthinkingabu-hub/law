# 民法典

> 《中华人民共和国民法典》七编体例，2021 年施行，结构稳定。

## 简介

民法典是 [[民法]] 学科的核心法律本体，2021 年正式施行，采用**七编体例**结构。2026 年法考中民法典本体稳定，活跃的是**配套司法解释**。

## 关键信息

- **正式名称**：《中华人民共和国民法典》
- **施行**：2021 年
- **结构**：七编
- **法考归属**：[[民法]]（Tier 1 核心基础）
- **2026 状态**：本体稳定 · 变化极小

## 详细内容

### 七编结构

| 编号 | 编名 | 主题 |
|---|---|---|
| 01 | [[总则编]] | 全编地基 · 主体 / 法律行为 / 代理 / 时效 |
| 02 | [[物权编]] | 静态归属 + 担保物权 |
| 03 | [[合同编]] | 债法核心 · 全编分值之最 |
| 04 | [[人格权编]] | 民法典首创独立编 |
| 05 | [[婚姻家庭编]] | 结婚 / 夫妻关系 / 离婚 / 收养 |
| 06 | [[继承编]] | 法定 / 遗嘱 / 遗产处理 |
| 07 | [[侵权责任编]] | 债法另一支柱 |

### 学习顺序（与编号顺序不同）

**总则 → 物权 → 合同（含担保合并）→ 侵权 → 婚姻家庭 → 继承 → 人格权**
