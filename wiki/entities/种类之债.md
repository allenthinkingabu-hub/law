# 种类之债

> **"一类东西里随便给"** — 标的以**种类 / 品质 / 数量**指明,种类内**任意**符合规格的物都能履行(钱 / 大米 / 矿泉水 / 股票)

## 法条范围

[[合同编]] §595 起(买卖合同 · 默认种类物规则)+ 学理 + 货币之债特别规则

## 是什么 / 易混

### 核心定义(超简单版)

> **种类之债** = 标的只指明 "**种类、品质、数量**",**没有指定具体哪一个**——种类内**任何符合规格**的物都能用来履行。

**关键词对比**:
- "**给我一个 XX**" → 种类之债
- "**给我那个 XX**" → 特定物之债

### 🔑 一个简单测试

> 问自己:"**卖家能不能给我另一个类似的?**"

```
能 ──→ 种类之债(类内任意可替代)
       例:大米 / 矿泉水 / 钱 / iPhone 15

不能 ─→ 简单之债 / 选择之债
       例:那辆京 A12345 / 别墅 / 初版鲁迅
```

## 🛒 4 大生活形象例子

### 🍚 例子 ①:在淘宝买大米

> 你下单:"**100 公斤 五常稻花香大米 2024 新米 一等品**"

- 标的 = "符合品质的 100 公斤大米"
- 卖家仓库里有 **1000 公斤** → **给你哪 100 公斤都行**!
- 大米都长一样 → 无意义指定"那 100 公斤"

→ ✅ **种类之债**(最经典案例)

### 💧 例子 ②:便利店买矿泉水

> "老板,给我**一瓶农夫山泉 550ml**"

- 标的 = "1 瓶农夫山泉 550ml"
- 冰柜里**有 50 瓶**,老板**随手拿一瓶**给你
- 你不会说"我要冰柜里第 17 瓶哦"——根本无意义

→ ✅ **种类之债**(最常见的生活场景)

### 💰 例子 ③:银行取款 1 万

> "我取 1 万元"

- 标的 = "1 万元人民币"
- 柜员给你 10 张 1000 / 20 张 500 / 100 张 100 都行——只要凑够 1 万
- 钱是**最最典型的种类物**(钞票之间完全可替代)

→ ✅ **种类之债**(货币之债 = 特殊的种类之债)

### 📱 例子 ④:买手机

> "我要 **iPhone 15 Pro 黑色 256GB 1 台**"

- 标的 = "1 台 iPhone 15 Pro 黑色 256GB"
- 工业品 → 流水线生产 → 同型号完全互换
- 哪一台都行

→ ✅ **种类之债**(工业品同型号)

## 🆚 对照:什么**不是**种类之债?

### 对照 ① 那辆京 A12345 凯美瑞 → 简单之债(特定物之债)

> 二手车市场:"我要那辆 **京 A12345** 的 2018 凯美瑞"

- 那辆车**独一无二**(车架号 / 里程 / 颜色磨损都不同)
- 卖家**不能**给你"另一辆 2018 凯美瑞"代替
- → ❌ **不是种类之债** → **简单之债**

### 对照 ② Q04 "别墅或汽车" → 选择之债

> Q04:"送你**一套别墅或一辆汽车**"

- 别墅和车**完全不是同类**!
- 每个都是**特定物**,在两个特定物之间选
- → ❌ **不是种类之债** → **[[选择之债]]**

⚠️ Q04 的 A 选项陷阱就在这——别墅和汽车不是种类内的同类物!

### 对照 ③ 1985 年初版鲁迅全集 → 简单之债

> "我要那本 1985 年初版鲁迅全集 第 7 卷"

- 这本书独一无二(古董价值)
- 不能用其他书替代
- → ❌ **不是种类之债** → **简单之债**

## 🔥 为什么"种类 vs 特定"区分这么重要? — 风险负担

### 法律谚语 ⚖️

> **"种类物不灭失" (Genus non perit)**
> ——意思:种类物在世界上总能找到,所以卖家不能用"标的灭失"作为免责理由!

### 🏠 仓库着火场景对比

#### 情景 A:你买了"**那辆京 A12345**"(特定物)

> 9/1 签合同,约 9/10 交付。9/5 那辆车在仓库**被雷击毁**。

→ 那辆车**灭失了** → 卖家**免责**(履行不能)
→ 你也不用付钱 → 合同消灭

#### 情景 B:你买了"**100 公斤五常大米**"(种类物)

> 9/1 签合同,约 9/10 交付。9/5 仓库着火,**200 公斤大米烧没了**。

法律分析:
- 仓库里**还有 300 公斤**符合规格的大米 → 卖家**必须履行**!
- 即使全部 500 公斤都烧光 → 卖家仍要**重新采购**履行!
- **种类物不灭失!**(市场上还有符合规格的大米)

→ 这就是**"种类之债"和"特定物之债"最根本的差异**!

## ⚡ 关键概念:"特定化"

种类之债的标的可以**转化为**特定物之债——通过"**特定化**"。

> **特定化** = 在种类物中**挑出具体的物**指定为履行标的(打标签 / 装袋 / 分离仓储)

### 🚗 老王小李"卖大米"完整故事

> 9/1 小李订老王 **100 公斤五常稻花香大米 2024 新米**,9/10 交付。
> 老王仓库有 500 公斤符合规格的大米。

```
9/1 合同   9/5 烧 200    9/8 特定化   9/9 雷击毁    9/10 交付
   │         │            │            │            │
   ▼         ▼            ▼            ▼            ▼
种类之债  仍可履行     特定物之债   老王免责     风险完全
         (剩 300)    (那 100 公斤)            转移小李
```

### 特定化前后的法律效果

| 时点 | 状态 | 谁担风险? |
|---|---|---|
| **9/1 - 9/8**(特定化前)| 种类之债 | **老王**(种类物不灭失) |
| **9/8**(特定化)| 转为特定物之债 | 风险即将转移 |
| **9/8 - 9/10**(特定化后,未交付)| 特定物之债 | **看交付情况** |
| **9/10**(交付后)| 已交付 | **小李**(§604) |

### 特定化的 3 种方式

| 方式 | 说明 | 例子 |
|---|---|---|
| **分离 / 装袋** | 把货物从大堆中分出来 | 老王挑出 100 公斤装麻袋,标注"小李的"|
| **运输标识** | 装上物流,贴客户标 | 京东仓配货,贴运单 |
| **当事人合意** | 双方明示某批就是合同的标的 | "您看那一垛就是您的" |

→ 法律目的:**明确风险归属,避免争议**

## 货币之债 — 最特殊的种类之债

> 钱是**永不灭失的种类物**(印钞机能印,银行能调度)

特殊规则:
1. **永不履行不能** — 借钱永远要还(没钱可执行其他财产)
2. **金钱抵销无障碍** — 同种货币随时抵销
3. **风险特殊** — 钱在路上丢了仍要补给

→ "**欠钱必还**" 的法律根源 · 详见独立实体页 **[[金钱之债]]**（4 大特异功能 + 金钱/非金钱对照 + §579 vs §580）

## 📋 三种典型债的完整对照

| 维度 | **简单之债** | **种类之债** | **[[选择之债]]** |
|---|---|---|---|
| **标的数量** | 1 个 | "1 类"内任意 1 个 | 几个特定物中选 1 |
| **例子** | 京 A12345 那辆车 | 100 公斤五常大米 | 那套别墅 或 那辆车 |
| **是否可替代** | ❌ 不可替代 | ✅ 类内任意可替代 | ❌ 不可替代(但有选项) |
| **卖家给法** | 必须给指定那个 | 类内随便给一个 | 必须从选项里给一个 |
| **风险负担** | 灭失即履行不能 | **种类物不灭失** | §517 三情形 |
| **法条** | 默认 | §595 起 | §515-§517 |

## 怎么考 / 坑在哪

### 五大陷阱

1. **种类物不灭失陷阱**:仓库烧了卖家**不能免责** — 必须重新采购
2. **特定化时点**:决定风险归属(高频考点)
3. **货币之债 = 种类之债**:钱永不履行不能
4. **种类 vs 选择**:同种类内任取 vs 多特定物择一
5. **种类 vs 简单**:类内可替代 vs 指定那一个

### 📐 答题口诀

```
看到"标的"判断:
  1 个特定物("那个 XX") → 简单之债
  1 类无差别物("符合规格的 XX") → 种类之债 ⭐
  几个特定物中选 1("这个 OR 那个") → 选择之债

关键测试:"卖家能不能给类似的另一个?"
  能 → 种类
  不能 → 特定 / 选择
  
风险问题:
  - 特定物灭失 → 卖家可能免责
  - 种类物灭失 → 卖家不能免责(必须重新采购!)
  - 特定化后 → 转为特定物规则
```

## 🎯 一句话记忆

> **"种类之债 = 一类东西里随便给(大米 / 矿泉水 / 钱)"**
> **"特定之债 = 必须给那个(京 A12345 / 这套别墅)"**
> **"种类物不灭失 → 仓库烧了卖家也得重新采购"**
> **"特定化是关键时点 → 决定风险归属"**
