# 保证合同

> **2021 民法典关键新规**：未约定 = **一般保证**（旧法是连带保证）；**横跨 [[合同编]] + [[担保]]**

## 法条范围

[[民法典]] §681-§702（22 条）+ [[担保]] 制度司法解释

## 是什么 / 易混

### 定义
**§681**：保证人和债权人约定，债务人**不履行**到期债务时，保证人**承担保证责任**的合同。

### 一般保证 vs 连带责任保证（核心区分）

| 维度 | 一般保证 | 连带责任保证 |
|---|---|---|
| 默认 | **2021 新规：未约定 = 一般保证**（§686）| 仅约定时 |
| **[[先诉抗辩权]]** | ✅ 享有（§687）| ❌ 不享有 |
| 债权人主张顺序 | 必须先对债务人执行 | 可直接找保证人 |

### 保证期间 vs 保证债务诉讼时效

| 项 | 保证期间（§692） | 保证债务诉讼时效（§694） |
|---|---|---|
| 性质 | **除斥期间**（不中止 / 不中断 / 不延长）| 普通诉讼时效 |
| 未约定 | 主债履行期满起 **6 个月** | — |
| 约定不明（含"本息还清为止"） | 主债履行期满起 **6 个月**（解释§32；旧法 2 年已废止） | — |
| 一般保证起算 | — | **先诉抗辩权消灭之日**（担保解释§28：对债务人财产强制执行的终本裁定送达债权人之日；旧"裁决生效之日"已废止） |
| 连带保证起算 | — | 债权人**请求保证人**之日 |

### 保证人资格（§683 + 担保解释§11）
**§683 明文禁两类**（有主体资格、政策禁止）：
- **机关法人**（除经国务院批准为转贷外）
- **以公益为目的的非营利法人 / 非法人组织**（公办学校 / 医院等）

**另需区分（非 §683）**：
- **内设机构 / 职能部门**（如"董事长办公室"）：**无独立民事主体资格** → 不能作保证人（主体不适格）
- **分支机构**：对外担保需经**公司决议**（担保解释§11）；旧担保法§10"经法人书面授权即可"已被取代
- **自然人**：有行为能力即可，负债累累不影响资格

## 怎么考 / 坑在哪

### 五大陷阱

1. **2021 新规推定**：未约定 = **一般保证**（旧法相反，常考反差）
2. **先诉抗辩权丧失 4 情形**（§687 II）：失踪 + 无财产 / 受理破产 / 财产不足证明 / **书面**放弃
3. **保证期间不中止中断**（§692 III）
4. **保证人资格**：负债累累自然人**可**作，机关 / 公益 / 内设机构**不可**
5. **保证范围**：未约定 = 包括主债 + 利息 + 违约金 + 实现债权费用（§691）

## 怎么答

主观题分析框架：
1. **定性**：一般保证 or 连带责任保证？（看约定 → 默认一般）
2. **保证期间**起止？是否在期间内主张？
3. **诉讼时效**起算？是否在时效内？
4. **资格审查**：保证人是否适格？
5. **追偿权**：保证人代偿后向债务人追偿（§700）
