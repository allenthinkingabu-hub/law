# 要约邀请

> 希望他人向自己发 [[要约]] 的意思表示；§473。


## 一句话做题判断

看发出内容的一方，有没有把 “最终决定权” 交出去：

- 还留着 “我说了才算” 的空间 → 要约邀请
- 对方只要同意就直接成交，自己没得改 → 要约（承诺即受约束）

### 《商品房买卖合同解释》明确规定：

商品房的销售广告和宣传资料，**对房屋及配套设施的说明、允诺具体确定，且对合同订立、房屋价格有重大影响的**，视为要约。哪怕没写进正式合同，也属于合同内容，开发商没做到就要承担违约责任。

典型如 “承诺配建公立小学、绿化率 35%、赠送入户花园” 等具体明确的允诺，都符合 “承诺即受约束” 的标准。

### 招招债价广


## 简介

要约邀请是 [[要约]] 的"前置"表示 —— 邀请别人来发要约。区分 [[要约]] 与要约邀请是客观题第一坑。

## 关键信息

- **法条**：[[民法典]] §473
- **所属**：[[合同编]] 合同总则 [[合同订立]]
- **本质**：不是 [[要约]]，不能直接经[[承诺]]而成立合同

## 详细内容

### 法定要约邀请（5 类）

1. **招标公告**
2. **招股说明书**
3. **债券募集办法**
4. **寄送的价目表**
5. **（一般）商业广告**

### 与 [[要约]] 的区分（核心判断）

判断标准：**是否同时满足 [[要约]] 两要件**（内容具体确定 + 承诺即受约束）

| 维度 | [[要约]] | 要约邀请 |
|---|---|---|
| 两要件 | 满足 | 不满足 |
| 经承诺的效力 | 直接成立合同 | 不直接成立合同 |
| 法定例子 | — | 招标公告、招股说明书、债券募集办法、价目表、（一般）商业广告 |

### 高频陷阱

1. **商业广告**内容符合要约条件的 → 构成 [[要约]]
2. **商品房销售广告**中**具体确定**的说明、允诺 → 可视为 [[要约]]（司法解释）

## 举例 · 小李逛街的故事

> 用一个生活化场景**对照 4 类情形**，建立"什么能直接说我买了"的直觉。

### 故事开场

小李周末出门逛街，手里有 1000 块，看到 4 个东西，**每一个他都想直接说"我买了"**——但只有一个**能直接成立合同**。

### 场景 A：商铺告示"低价出售，价格面议"

> 路过一家商铺，门上写：**"低价出售，价格面议"**

小李能说"我接受"吗？❌

- "低价"是多少？"面议"还要再谈
- → **要件 ① 失败：价格不具体确定**
- → 这是 **要约邀请**（邀请你来谈，谈成了才有要约）

### 场景 B：收到价目表

> 商店给小李寄了一份**价目表**：A 商品 100 元 / B 商品 200 元...

能直接说"我买"成立合同吗？❌

- 价目表是 **§473 法定 5 类要约邀请之一**
- → 直接被法律定性为 **要约邀请**
- → 小李下单 = 要约；商店确认 = 承诺

### 场景 C：路边招标公告

> 看到丙公司贴出 **"建办公大楼招标公告"**

能直接投标说"我接受工程"吗？❌

- 招标公告是 **§473 法定 5 类要约邀请之一**
- → 是邀请你**投标**（投标 = 要约）
- → 招标人**择优定标** = 承诺

### 场景 D：超市标价陈列商品 ✅

> 走进超市，看到货架上的**农夫山泉** + 旁边写**2 元 / 瓶**

能说"我买了"直接成立合同吗？✅

- 商品（标的）+ 标价（价款）+ 陈列售卖（数量 = 顾客拿几个买几个）
- → **三要素齐全** = **§472 两要件**满足
- → 这是 **[[要约]]**
- → 小李拿到柜台 / 扫码支付 = 承诺 = 合同成立

### 三要素与两要件的关系

```
§472 要约的【两要件】 = 法律层面的总规则
   ├─ 要件 ①：内容具体确定
   │     └─ 在"超市标价"场景下 → 拆成【三要素】
   │           ├─ 商品（标的物）
   │           ├─ 标价（价款）
   │           └─ 陈列售卖（数量 = 顾客拿）
   │
   └─ 要件 ②：表明经承诺即受约束
         └─ 在"超市标价"场景下 → 暗含"售完为止"
```

→ "三要素"不是新的法律标准，是"要件 ① 内容具体确定"在超市场景下的实操化拆解。

## §473 法定 5 类要约邀请（必背口诀：招招债价广）

| # | 类型 | 口诀字 | 典型 |
|---|---|---|---|
| ① | **招标公告** | **招** | 政府工程招标、企业采购招标 |
| ② | **招股说明书** | **招**（招股）| IPO 招股书 |
| ③ | **债券募集办法** | **债** | 国债 / 公司债募集 |
| ④ | **寄送的价目表** | **价** | 商家寄给客户的报价单 |
| ⑤ | **一般商业广告** | **广** | 电视广告、报纸广告 |

→ **口诀：招招债价广**（前两个都是"招"，要分开记招标 vs 招股）

### ⚠️ 反陷阱（要约邀请 → 升级为要约）

| 反例          | 升级条件                                    |
| ----------- | --------------------------------------- |
| **商业广告**    | 内容**具体确定** + 表明承诺即受约束 → 构成要约            |
| **商品房销售广告** | 对房屋及相关设施作出**具体确定**的说明 / 允诺 → 视为要约（司法解释） |
| **悬赏广告**    | 主流通说：要约（寻回失物 + 给付报酬，内容确定）               |
