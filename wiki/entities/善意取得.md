# 善意取得

> 无权处分时，**善意**买受人付**合理价格**且完成**登记 / 交付**，**直接取得所有权**——原所有权人只能向无权处分人**请求损害赔偿**。是"所有权人有权追回"的**例外**。

## 法条范围

[[物权编]] §311（及《物权编司法解释（一）》§14-19 善意判断）

## 是什么 / 易混

### §311 原文（三款）
- **Ⅰ 三要件（须"同时"具备，缺一不可）**：无处分权人转让不动产 / 动产，**所有权人有权追回**；除法律另有规定外，符合下列情形的，受让人取得所有权——
  1. 受让人**受让时是善意**（不知道且无重大过失）；
  2. **以合理的价格转让**；
  3. 应登记的**已登记**、不需登记的**已交付**。
- **Ⅱ**：受让人善意取得后，原所有权人**有权向无处分权人请求损害赔偿**。
- **Ⅲ**：善意取得**其他物权（如质权、抵押权）参照适用**。

### 关键特征
| 项 | 内容 |
|---|---|
| **逻辑起点** | **所有权人有权追回**（原则）；善意取得是**例外**，三要件齐备才阻断追回 |
| **善意判断** | 受让时**不知道且无重大过失**；**真实权利人负举证**（《物权编解释一》§14-19）|
| **非善意典型** | 明知是他人之物、**关联关系**（如交易双方同一控制人）、价格畸低 |
| **与合同效力分层** | §311 解决**物权变动**层；无权处分的**债权合同**有效靠 [[合同编]] **§597**（两层并行）|

### 与无权处分的关系
善意取得是**无权处分**情形下**买受人取得所有权**的关键路径之一（另两条：处分人事后取得处分权 / 权利人追认补正处分权 + §209/§224 物权变动规则）。**§597 管合同有效、§311 管物权归属**，分层并行（详见答题模型）。

## 怎么考 / 坑在哪

1. **三要件须同时**：缺善意 / 缺合理价格 / 未交付登记，任一不满足即不能善意取得。
2. **善意取得是例外不是常态**：默认所有权人可追回，别一见无权处分就套善意取得。
3. **非善意陷阱**：关联关系、明知、价格畸低 → 不构成善意。
4. **§311Ⅲ 其他物权**：质权 / 抵押权也可善意取得（如承租人擅自质押他人物，受让人善意可善意取得质权）。
