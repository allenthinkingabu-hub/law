# 善意取得

> 无权处分时，**善意**受让人付**合理价格**且完成**登记 / 交付**，**直接（原始）取得所有权**——原所有权人丧失物权，只能向无权处分人**请求损害赔偿 / 不当得利**。是"所有权人有权追回"的**重大例外**。做题步骤（四要件→三道闸→失权救济）见 📐 [[民法-物权-善意取得模型]]；本页是**学理·法条**的概念层。

## 法条范围

- **核心**：[[物权编]] **§311**（善意取得三款）
- **系统配套**：《物权编司法解释（一）》法释〔2020〕24 号 **§14-20**（善意取得 7 条，全文 21 条 · 2026-06-15 最高法 court.gov.cn 全文核实）
- **附随效果**：**§313**（善意取得后动产上原有权利消灭·涤除）
- **例外**：**§312**（遗失物追回 + 2 年回赎）、**§319**（埋藏物/隐藏物/漂流物参照）→ 详见 [[遗失物]]
- **跨编并行**：[[合同编]] **§597**（无权处分债权合同有效）→ 详见 [[无权处分]]；失权救济 §985（详见 [[不当得利]]）

## 是什么 / 易混

### §311 原文（三款）
- **Ⅰ 三要件（须"同时"具备，缺一不可）**：无处分权人转让不动产 / 动产，**所有权人有权追回**；除法律另有规定外，符合下列情形的，受让人取得所有权——
  1. 受让人**受让时是善意**（不知道且无重大过失）；
  2. **以合理的价格转让**；
  3. 应登记的**已登记**、不需登记的**已交付**。
- **Ⅱ**：受让人善意取得后，原所有权人**有权向无处分权人请求损害赔偿**。
- **Ⅲ**：善意取得**其他物权（如质权、抵押权）参照适用**。

> "三要件 vs 四要件"只是数法不同：把"无权处分"当**前提**则三要件（§311Ⅰ列的三项），当**要件**则四要件。同一回事。

### 《物权编解释一》§14-20 逐条（已联网核实·7 条系统配套）
| 条 | 规制 | 要点 |
|---|---|---|
| **§14** | 善意定义 + 举证 | 受让时不知道转让人无处分权**且无重大过失**＝善意；**真实权利人负举证**证明非善意 |
| **§15** | 不动产非善意 5 情形 | 有效异议登记 / 预告登记期内未经同意 / 登记簿已记载查封等限制 / 知道登记簿权利主体错误 / 知道他人已享有该物权；"应当知道"＝重大过失 |
| **§16** | 动产重大过失 | 交易的**对象、场所、时机**等不符合交易习惯＝重大过失 |
| **§17** | 善意时点 = 完成时点 | "受让时"指**完成不动产登记 / 动产交付之时**；简易交付 §226 以行为生效时、指示交付 §227 以返还请求权协议生效时为交付之时（**独缺占有改定 §228** → 占有改定不适用善意取得的间接依据）|
| **§18** | 合理价格 | 按标的性质 / 数量 / 付款方式，参考交易地市场价 + 交易习惯综合认定 |
| **§19** | 特殊动产 | 船舶 / 航空器 / 机动车**交付**即满足善意取得（对应 §225，登记仅对抗）|
| **§20** | 不适用 | 转让合同被认定**无效 / 被撤销**的，主张善意取得**不予支持** |

### 法律效果（三连）
1. **受让人原始取得**：取得所有权**不带原瑕疵**——标的物上原有的抵押权 / 质权等**原有权利消灭**（**§313**，善意受让人受让时知道或应知该权利的除外）。
2. **原主丧失物权 → 只能追钱**：原所有权人**不能向善意受让人追物**；只能向**无权处分人**主张——看损失→**损害赔偿 §311Ⅱ**，看获利→**不当得利 §985**。
3. **客体扩张 §311Ⅲ**：抵押权、质权等**其他物权参照适用** → 可善意取得担保物权。

### 三大不适用 / 例外
| 例外 | 依据 | 后果 |
|---|---|---|
| 合同**无效 / 被撤销** | 解释一 §20 | 无有效交易基础 → 不适用（与 [[区分原则]] 呼应）|
| **占有改定** | 通说（解释一 §17 独缺其时点）| 受让人未取得现实占有 → 不满足"交付"（详见 [[民法-物权-动产交付模型]]）|
| **遗失物 / 赃物 / 埋藏物** | §312 / §319 | 非即时取得；原主 **2 年内可向受让人回赎** or 向无权处分人索赔（详见 [[遗失物]]）|

### 关键特征
| 项 | 内容 |
|---|---|
| **逻辑起点** | **所有权人有权追回**（原则）；善意取得是**例外**，要件齐备才阻断追回 |
| **善意判断** | 受让时**不知道且无重大过失**；**真实权利人负举证**（解释一 §14）|
| **非善意典型** | 明知是他人之物、**关联关系**（交易双方同一控制人）、价格畸低、登记簿有异议/预告/查封 |
| **与合同效力分层** | §311 解决**物权变动**层；无权处分的**债权合同**有效靠 [[合同编]] **§597**（两层并行）|

### 与无权处分的关系
善意取得是 [[无权处分]] 情形下**买受人取得所有权**的三条路径之一（另两条：处分人**事后取得处分权** / 权利人**追认**补正处分权）。**§597 管合同有效、§311 管物权归属**，分层并行。

## 怎么考 / 坑在哪

1. **要件须同时**：缺善意 / 缺合理价格 / 未交付登记，任一不满足即不能善意取得。
2. **善意取得是例外不是常态**：默认所有权人可追回，别一见无权处分就套善意取得。
3. **非善意陷阱**：关联关系、明知、价格畸低、异议/预告登记 → 不构成善意。
4. **§311Ⅲ 其他物权**：[[质权]] / [[抵押权]]也可善意取得（承租人擅自质押他人物，受让人善意可善意取得质权）。
5. **遗失物 / 占有改定 / 合同无效**三大不适用，是命题人最爱（详见上表 + 📐 模型陷阱）。
