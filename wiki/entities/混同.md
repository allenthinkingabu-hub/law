# 混同

> [[合同权利义务终止]] 之一 — **债权债务同归于一人**→ 终止

## 法条范围

[[合同编]] §576

## 是什么 / 易混

### 本质：债主和欠债的成了同一人——"自己欠自己"没意义（为什么）

> **一句话**：当**债权和债务落到同一个人头上**，就成了"自己欠自己钱"——毫无意义，于是债**当然消灭**（§576），不需要任何人作意思表示。

- **怎么会"合二为一"**：继承（欠债人继承了债主）、公司合并（A 把债主 B 合并了）、债权转让给债务人本人等。
- **例外**：若这笔债上还**牵着第三人**（如有保证人 / 抵押人，债一消他们的关系就乱套）→ 损害第三人利益的**不混同消灭**（§576 但书）。

### 定义
**§576**：债权债务**同归一人**的，债权债务终止——但是损害**第三人利益**的除外。

### 典型情形

| 情形       | 例子                                      |
| -------- | --------------------------------------- |
| **继承**导致 | 子女继承父母对子女的债权                            |
| **婚姻**导致 | **夫妻共同财产**——丈夫对妻子的债权变为共同财产（C1-单选-26 婚姻） |
| **公司合并** | 一公司合并另一公司，互为债权债务的关系                     |

### 婚姻导致混同的细节
**夫妻共同财产制**下：
- 婚前一方对另一方的债权 → 婚后共有 → **混同**
- 婚后**夫妻共同债权** = 共同财产

### 例外：损害第三人利益
若混同**损害第三人利益**（如**保证人 / 抵押人**仍有追偿权）→ **不发生混同**。

## 🚗 老王小李故事 · 小李把老王公司收购了，债"合二为一"

> 小李欠老王（其实是老王的公司）**10 万车款**。后来小李**把老王的公司整个收购**了——现在"收钱的那个公司"成了小李自己的。
>
> - "**债主**"和"**欠债人**"成了**同一个人** → 自己欠自己、没意义 → 债**当然消灭**（§576），不用谁去主张。
> - 其他常见触发：老王**去世、小李是唯一继承人**（小李继承了"老王对小李的债权"）；或夫妻共同财产下一方对另一方的债变共有（[[合同通则-单选-26]]）。
> - ⚠️ **例外**：若这 10 万债**有保证人老赵担保**，债一混同消灭、对老赵的追偿关系就乱了——**损害第三人（老赵）利益的，不混同消灭**（§576 但书）。
>
> 一句话：**混同 = 债主和欠债的撞成一个人——自己不用还自己，债自动清零（除非牵连第三人）。**

## 怎么考 / 坑在哪

### 三大陷阱

1. **婚姻引起混同**（C1-单选-26）：夫妻共有的核心后果
2. **不损害第三人**：保证人 / 抵押人地位的保护
3. **混同发生 = 当然消灭**：不需要意思表示

## 真题示例

- [[合同通则-单选-26]] 婚姻 → 混同（答 A）
