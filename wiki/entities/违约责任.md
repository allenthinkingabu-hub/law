## 法条范围

[[合同编]] §577-§594

## 是什么 / 易混

### §577 基础规则
**§577**：当事人**一方不履行**合同义务 / 履行不符合约定 → 应当承担**继续履行 / 采取补救措施 / 赔偿损失**等违约责任。

### 归责原则
- **严格责任**为原则（无过错即可担责）
- **过错责任**为例外（赠与合同 / 无偿保管 / 无偿委托等）

### 4 种违约形式（§577、§578）

| 形式 | 内容 |
|---|---|
| ① **拒绝履行**（明示）| 当事人明确表示不履行 |
| ② **预期违约**（§578）| 履行期前**明示**或**默示**表示不履行主要债务 |
| ③ **迟延履行** | 超过约定时间履行 |
| ④ **不完全履行** | 履行存在质量 / 数量瑕疵 |

### 5 种责任承担方式

| 方式 | 法条 | 适用 |
|---|---|---|
| ① **继续履行** | §580 | 金钱债务始终可继续履行；非金钱债务受 §580 限制 |
| ② **采取补救措施** | §582 | 修理 / 重做 / 减价 等 |
| ③ **赔偿损失** | §584 | 损害赔偿，§584 可预见性规则 |
| ④ **违约金** | §585 | 约定 + 调整规则 |
| ⑤ **定金** | §586-§588 | 罚则 + 与违约金选择 |

### §580 继续履行的限制（非金钱债务）
有下列情形 → **不予支持**继续履行：
1. **法律上 / 事实上**不能履行
2. **不适于强制履行 / 履行费用过高**
3. 债权人在**合理期限内**未请求履行

### §584 可预见性规则
**违约损失赔偿**不得超过违约方**订立合同时预见到 / 应当预见到**的因违约可能造成的损失。

### §585 违约金调整
- **过低** → 受损方可请求**增加**至实际损失
- **过分高于损失** → 违约方可请求**适当减少**（一般限 130%）

## 怎么考 / 坑在哪

### 五大陷阱

1. **金钱债务必继续履行**：§580 仅限非金钱
2. **继续履行 + 赔偿损失可并存**（§581）
3. **预期违约**：履行期**前**就可主张违约责任
4. **违约金可调**：双向调整规则
5. **违约 + 侵权竞合**：§186 + §996 突破
