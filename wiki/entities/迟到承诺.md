# 迟到承诺

> [[承诺]] 迟到分两类，结果**完全相反**：§486 = 新要约；§487 = 原则有效。

## 简介

迟到承诺是 [[合同订立]] 中的高频陷阱。同样是"承诺晚了"，由于**晚的原因**不同，法律效果完全不同。

## 关键信息

- **法条**：[[民法典]] §486 + §487
- **核心判断**：晚是**谁的责任**

## 详细内容

### 两类对比

| 维度   | §486                    | §487                        |
| ---- | ----------------------- | --------------------------- |
| 情形   | 发出**就晚** / 通常**不能及时到达** | 发出**及时**、通常**能到达**，但因其他原因迟到 |
| 归责   | 怪受要约人                   | 怪传递过程                       |
| 默认效力 | **新要约**（不构成承诺）          | **原则有效**（构成承诺）              |
| 翻转条件 | 要约人**及时通知该承诺有效**，才有效    | 要约人**及时通知不接受**，才失效          |
|      |                         |                             |

### 口诀

> **怪受要约人 → 新要约；怪传递 → 有效**

### 客观题关键词触发

- 发得**及时**、通常能到，因**邮路延误**迟到 → §487 原则有效
- 发得**就晚** / 通常到不了 → §486 新要约

### 客观题陷阱

不分 §486 / §487，一律按"新要约"或一律按"有效"。
