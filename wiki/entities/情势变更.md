# 情势变更

> 合同**基础条件**发生**重大变化** + 继续履行**显失公平** → 可请求**变更 / 解除**

## 法条范围

[[合同编]] §533

## 是什么 / 易混

### 定义
**§533**：合同成立后，**合同的基础条件**发生了**当事人在订立合同时无法预见的、不属于商业风险的重大变化**，**继续履行**合同对一方**明显不公平** → 受不利影响的当事人可与对方**重新协商**；在合理期限内协商不成，可**请求人民法院 / 仲裁机构**变更或解除合同。

### 五大构成要件
1. **基础条件**重大变化
2. **订立时无法预见**
3. **不属于商业风险**
4. **不可归责**于双方
5. 继续履行对一方**明显不公平**

### 行使程序
1. **第一步**：受不利方与对方**重新协商**
2. **第二步**：协商不成 → **诉讼 / 仲裁**请求变更 / 解除
3. 法院 / 仲裁应**审慎适用**

### 情势变更 vs 不可抗力

| 维度 | 情势变更 | **不可抗力**（§180 / §590）|
|---|---|---|
| 程度 | 继续履行**显失公平** | 履行**不能**（绝对障碍）|
| 救济 | 变更 / 解除 | 部分 / 全部**免责** |
| 程序 | 必须经协商→诉讼 | 自动免责（但需通知）|
| 性质 | 法院 / 仲裁裁量 | 法定免责 |

### ⭐ 民法典 §533 两大变化（高频考点）
1. **不再排除不可抗力**：旧法（合同法解释二）要求情势变更须"**非不可抗力**造成"；民法典 §533 **删掉了这一限定** → 不可抗力导致基础条件剧变、继续履行**显失公平**的，**也可能构成情势变更**。二者**可能竞合**：履行**不能** → 走不可抗力（免责 / 解除）；履行**仍可能但显失公平** → 走情势变更（变更 / 解除）。（[[合同通则-单选-49]] 地震 → 情势变更正是此理）
2. **新增"重新协商"前置**：旧法可直接请求法院变更 / 解除；民法典**必须先与对方重新协商**，合理期限内协商不成，才可请求法院 / 仲裁变更或解除。

## 怎么考 / 坑在哪

### 三大陷阱

1. **不是商业风险**：市场波动 / 价格涨跌一般属商业风险**不适用**
2. **必须先协商**：直接起诉变更 / 解除会被驳回
3. **法院谨慎**：实务中适用率低，门槛高

### 2026 重点关注
- [[合同编通则司法解释]] **§32 已细化**情势变更的认定（基础条件 / 无法预见 / 非商业风险 / 显失公平）与重新协商程序 —— 2024-2026 ★★★★★ 必考。

## 🚗 老王小李故事

> 老王跟小李签了份**长期供货合同**。签完之后突发**地震**，原料和运费蹭蹭涨，老王再按老价供货要亏惨。老王找小李商量改价，小李不松口。这算啥？——**情势变更**：合同签完后冒出谁也没料到的大变故（不是普通市场波动 / 商业风险），继续履行对老王**明显不公**。老王得**先找小李重新协商**，谈不拢再请法院 / 仲裁**变更或解除**。
>
> 易混别踩：① 不是"**显失公平**"（那是**签的时候**就坑人，本题是签**完之后**变天）；② 也别说"**不可抗力可撤销**"——地震是不可抗力，但其后果是**免责 / 解除**、不是"撤销"，且这里履行没到"不能"、只是**显失公平**，正好落进情势变更。

## 真题示例

- [[合同通则-单选-49]] 地震致成本暴涨、协商被拒 → 情势变更**可变更**（答 D）
- [[合同通则-多选-26]] 突发禁渔致无法按期交付 → 情势变更**全要件**（多选）
- → 与 [[合同效力分级]]"可撤销 5 情形"（重大误解 / 显失公平 / 欺诈 / 胁迫 / 第三人欺诈）严格区分：情势变更是**成立后**巨变、走**变更 / 解除**，不是撤销。
