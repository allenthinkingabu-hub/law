# 合同权利义务终止

> [[合同总则]] **终止**块**统称** — 涵盖 **6 大**终止情形（§557 五种 + 解除）

## 法条范围

[[合同编]] §557、§566-§576

## 是什么 / 易混

### 定义
**§557**：有下列情形之一的，**债权债务终止**：
1. **债务已经履行**
2. **债务相互抵销**
3. **债务人依法将标的物提存**
4. **债权人免除债务**
5. **债权债务同归于一人**（混同）
6. **法律规定 / 当事人约定**终止的其他情形

### 6 大终止情形

| 情形           | 法条        | wiki 页        |
| ------------ | --------- | ------------- |
| ① **履行**（清偿） | §557 I 1  | [[合同生效]] 履行完成 |
| ② **抵销**     | §568-§569 | [[抵销]]        |
| ③ **提存**     | §570-§574 | [[提存]]        |
| ④ **免除**     | §575      | [[免除]]        |
| ⑤ **混同**     | §576      | [[混同]]        |
| ⑥ **解除**     | §562-§565 | [[解除]]        |

### 终止 vs 解除（重要区分）

| 维度 | 终止（广义）| 解除（狭义）|
|---|---|---|
| 范围 | 包括解除在内的所有结束情形 | 仅为终止情形之一 |
| 撤销是否在内 | ❌ **撤销不是终止**（合同从未生效）| — |
| 法条 | §557 | §562-§565 |

→ **C1-单选-22 经典考点**：撤销**不属于**合同终止（因为撤销 = 自始无效）。

## 🚗 老王小李故事 · 一笔车款的六种"消失"（§557 六情形）

> 老王把车卖给小李，小李欠老王 **10 万车款**。这笔"10 万的债"能怎么**合法消失（终止）**？正好六种——一个故事记全 §557：

| #   | 情形                | 老王小李版                                             | 生活版                           |
| --- | ----------------- | ------------------------------------------------- | ----------------------------- |
| ①   | **履行**（清偿）        | 小李把 10 万**付清**、老王交车 → 圆满结束                        | 你还清房贷最后一期 → 借款合同终止            |
| ②   | **抵销**（§568）      | 老王此前也欠小李 8 万，两笔到期**对冲** → 小李只补 2 万                | 公司欠你工资、你借了公司钱，发薪时**对扣**       |
| ③   | **提存**（§570）      | 小李要付钱，老王**失踪 / 拒收** → 小李把 10 万**存到公证处**，债即消（视为已还） | 房东失联拒收房租想制造"欠租"→ 租客**提存**房租自保 |
| ④   | **免除**（§575）      | 老王大手一挥"不要了，送你"→ 单方放弃，债消                           | 亲戚借你钱，过年说"不用还了"               |
| ⑤   | **混同**（§576）      | 小李把老王的公司**收购**了（或继承老王）→ 收钱的和还钱的成**同一人** → 自己不用还自己 | 你欠房东租金，后来把房子**买下来**了          |
| ⑥   | **解除**（§562-§565） | 车还没交，老王**违约**交不出 → 小李**解除**合同、要回已付款               | 婚庆公司临时跑路 → 你解约退定金             |

**口诀**：**履、抵、提、免、混、解** ——"还了 / 对冲了 / 存走了 / 不要了 / 合一了 / 喊停了"。

**按"谁让债消失"分三组**（理解用）：
- **目的达到** → ① 履行、③ 提存（债权人利益实现 / 视为实现）
- **当事人意思** → ④ 免除（债主单方）、② 抵销（一方通知）、⑥ 协议解除（双方）
- **法律事实** → ⑤ 混同、⑥ 法定解除（§563）

**三个细节别漏**：
- **提存后风险转移**：标的物毁损灭失风险、孳息归**债权人**（§573）——存了就跟债务人无关了。
- **混同有例外**：债权上有**质押给第三人**等情形，损害第三人利益的**不混同消灭**（§576 但书）。
- **解除 ≠ 前五个**：①~⑤是债"自然了结"；**解除**常伴**违约 / 情势变化**，且非继续性合同（买卖）解除有**溯及力**（恢复原状），继续性合同（租赁）解除一般只向将来。

> ⚠️ 这六种都是**有效合同**的"善终"；**撤销 / 无效 / 不成立**是"自始没有效"，**不在** §557 之列（见 [[合同通则-单选-22]]）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **撤销 ≠ 终止**：撤销是合同**自始无效**，不是合同终止
2. **解除 ⊂ 终止**：解除是终止情形之一
3. **附属条款**：合同终止后**结算 / 清理条款 + 仲裁条款**仍有效
