# 租赁合同

> **3 大陷阱**：转租 / 买卖不破租赁 / 优先购买权。

## 法条范围

[[民法典]] §703-§734（32 条）

## 是什么 / 易混

### 定义
**§703**：出租人将**租赁物交付**承租人使用、收益，承租人**支付租金**的合同。

### 关键特征
| 特征 | 内容 |
|---|---|
| 转移**使用权**（区别于买卖的所有权） | |
| **诺成 / 有偿 / 双务** | |
| 期限 **6 个月以上须书面** | §707 |
| 未书面 → **视为不定期租赁** | §707 |
| 期限上限 **20 年** | §705 |

### 三大特色规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **擅自转租** | 未经同意转租 → 出租人**可解除** + 承租人对次承租人损害**仍负责** | §716 |
| **买卖不破租赁** | 租赁物所有权变动**不影响**租赁 | §725 |
| **优先购买权** | 出租人卖租赁物 → 承租人**同等条件 + 15 日内**优先 | §726 |

## 怎么考 / 坑在哪

### 五大陷阱

1. **长期口头租赁 = 不定期租赁**（§707）
2. **合同相对性**：擅自转租后，出租人对次承租人**无合同请求权**（不能要求次承租人付租金，可要求腾退）
3. **买卖不破租赁**条件：租赁合同**先于**所有权变动**已生效**
4. **优先购买权丧失**：未通知 / 通知后 15 日内未表示
5. **押金 vs 定金**：押金是**租赁担保**，与定金性质不同

## 怎么答

主观题分析框架：
1. **形式**：是否 6 个月以上 + 是否书面 → 定期 / 不定期？
2. **转租**：是否经同意？未同意 → 出租人解除权 + 次承租人责任
3. **物权变动**：买卖不破租赁是否适用？
4. **优先购买权**：是否同等条件 + 是否在期内？
5. **租金 + 解除**：违约责任分析
