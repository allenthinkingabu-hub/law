# 实质性变更

> [[承诺]] 对 [[要约]] 内容作出实质性变更 → 视为**新要约**；§488。

## 简介

[[承诺]] 改了 [[要约]] 的内容时，是构成新要约还是依旧是承诺，取决于变更是否"实质性"。

## 关键信息

- **法条**：[[民法典]] §488（实质性变更）· §489（非实质性变更）
- **效力**：实质性变更 → 新要约；非实质性变更 → 承诺有效，内容**以承诺为准**

## 详细内容

### 实质性变更的 7 项法定标准

源素材明确列出 7 项：

1. **标的**
2. **数量**
3. **质量**
4. **价款 / 报酬**
5. **履行期限 / 地点 / 方式**
6. **违约责任**
7. **争议解决方法**

### 实质性 vs 非实质性

| 类型 | 法条 | 结果 |
|---|---|---|
| 实质性变更 | §488 | **视为新要约**，原要约失效；对方需就新要约重新承诺 |
| 非实质性变更 | §489 | **承诺有效**，合同内容**以承诺为准**（除非要约人及时反对或要约禁止任何变更） |

### 客观题陷阱

- 把**非实质性变更**误判为新要约（其实承诺有效）
- 关键词触发：擅自改了**价款 / 数量 / 履行方式** → 实质性变更 → 新要约
