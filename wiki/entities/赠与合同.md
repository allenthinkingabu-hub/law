# 赠与合同

> **单务无偿合同的代表**：撤销权是核心陷阱。

## 法条范围

[[民法典]] §657-§666（10 条）

## 是什么 / 易混

### 定义
**§657**：赠与人将自己的**财产无偿给予**受赠人，受赠人**表示接受**的合同。

### 关键特征
| 特征 | 内容 |
|---|---|
| 合同性质 | **诺成 / 无偿 / 单务** |
| **必双方意思一致** | 受赠人需**接受**——拒绝则赠与不成立 |
| **任意撤销权** | 转移财产权**前**，赠与人可撤销（例外：公益 / 道德义务 / 经公证） |
| **法定撤销权** | 受赠人侵害 / 不扶养 / 不履行义务 → 可撤销 |

### 撤销权全表
| 类型 | 适用条件 | 撤销权人 | 除斥期间 |
|---|---|---|---|
| **任意撤销**（§658） | 转移财产权前 + 非公益 / 道德 / 公证 | 赠与人 | 转移前 |
| **法定撤销**（§663） | 侵害 / 不扶养 / 不履行义务 | 赠与人本人 | 知道 / 应知 起 **1 年** |
| **特殊撤销**（§664） | 受赠人致赠与人**死亡 / 丧失民事行为能力** | 赠与人**继承人 / 代理人** | 知道 / 应知 起 **6 个月** |

## 怎么考 / 坑在哪

### 三大陷阱

1. **任意撤销的例外**：公益 / 道德义务 / 经公证 **不得撤销**
2. **法定撤销 1 年 vs 6 个月**：本人 1 年，继承人 6 个月
3. **拒绝赠与**导致赠与**不成立**（C2-单选-06）—— 受赠人说"将来奉还" = 拒绝接受赠与

## 怎么答

主观题分析框架：
1. 是否成立赠与（受赠人接受）？
2. 财产权是否已移转？
3. 撤销权类型 + 期限 + 撤销权人？
4. 撤销后返还规则（§665）
