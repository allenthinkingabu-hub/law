# 请求权竞合

> **同一事实生出多个请求权**——目的重叠、只能择一 = **竞合**；目的不同、可以并用 = **聚合**。本页是"竞合"的上位枢纽（仿 [[抗辩]]）：定义 + 竞合 vs 聚合一图 + 三类导航；**完整解题套路在** 📐 [[民法-合同-请求权竞合模型]]。

## 一、是什么（四标准）

请求权竞合 = 一个事实同时满足多套法条、生出多个请求权，且这些权利**目的重叠、不能并得**：
1. **单一事实**：只发生一个行为 / 一件事；
2. **多重法律依据**：同一事实满足 ≥2 套构成要件 → ≥2 个请求权；
3. **给付目的相同**：都指向同一给付（同一笔赔偿 / 同一个原物）；
4. **禁止双重获利**：一个实现，其余消灭——**只能拿一份**。

## 二、竞合 vs 聚合 · 一图断（高频识别坑）

| | **竞合** | **聚合** |
|---|---|---|
| 给付目的 | **相同** | **不同** |
| 能否兼得 | ❌ **择一**、其余消灭 | ✅ **可同时主张** |
| 典型例 | 买到次品：**违约 / 侵权二选一**索赔 | 砸坏电脑：**返还原物 + 赔维修费**一起要 |

> 一句话：**目的同 → 竞合（择一）；目的不同 → 聚合（并用）。** 砸电脑能"既要回电脑、又要维修费"，因为两个诉求目的不同 → 是聚合、不是竞合。

## 三、三类典型竞合 · 导航

| 类型 | 法条 | 性质 | 细则模型 |
|---|---|---|---|
| ❶ **违约 + 侵权竞合** | §186 | **真竞合·择一** | 📐 [[民法-合同-责任竞合模型]] |
| ❷ **物权返还 vs 占有返还** | §235 vs §462 | **真竞合·择一**（同为拿回一物；占有返还 §462Ⅱ 1 年除斥，过期可转物权返还）| 📐 [[占有返还-vs-物权返还]] · [[民法-物权-物权请求权模型]] |
| ❸ **担保物权竞存** | §414/§415/§416/§456 | ⚠️ **广义·按顺位受偿（非择一）** | 📐 [[民法-物权-担保物权竞存清偿顺序模型]] |

> ⚠️ ❸ 担保物权"**竞存**"是数个担保权**并存、按法定顺位先后受偿**（留置＞登记抵押＞质押…），**不是"二选一、其余消灭"**——属广义归类，规则走顺位清偿，别套竞合的"择一/禁止双重获利"。
