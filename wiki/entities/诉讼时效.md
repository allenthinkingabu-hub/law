# 诉讼时效

> [[民法典]] §188-§199 — 权利人**3 年内不行使请求权**,届满后**胜诉权消灭**(实体债权仍存)的制度

## 法条范围

[[总则编]] §188 / §189 / §190 / §192 / §193 / §194 / §195 / §196 / §199

## 是什么 / 易混

### 定义

**诉讼时效**:权利人在**法定期间**内**不行使请求权**,期间届满后,**胜诉权消灭**(但**实体权利仍存**)的制度。

→ 一句话:**时效届满 = 胜诉权死了,债权本身还活着**

### ⭐ 核心命题:消灭"胜诉权"≠ 消灭"债权"

| 维度 | 时效届满前 | 时效届满后 |
|---|---|---|
| 起诉 | ✅ 可起诉 + 必胜 | ✅ 可起诉 + 可能败诉(义务人抗辩时) |
| **胜诉权** | ✅ 有 | ❌ **消灭** |
| 实体请求权 | ✅ 有 | ✅ **保留** |
| 受领权 | ✅ 有 | ✅ **保留** → 自愿履行有效 |
| 保全权 | ✅ 有 | ✅ **保留** |
| 处分权 | ✅ 有 | ✅ **保留** |

→ 时效届满后的债权 = **[[自然债务]]**

### 🔬 请求权能的二层结构(高频细分 · 易混重点)

很多人误以为"时效届满 → 没有请求权能"——这是**80% 对 + 20% 不精确**!

请求权能在法律上其实有**两层**:

```
请求权能
   │
   ├─ ① 实体请求权(要求债务人履行的权利)  → 仍然存在 ✅
   │
   └─ ② 胜诉权 / 诉权(国家强制力实现请求)   → 消灭了 ❌
```

→ **时效届满消灭的只是"胜诉权",不是"整个请求权能"!**

#### 三个证据证明"实体请求权"还在

| 证据 | 说明 |
|---|---|
| ① **小李仍可起诉** | 法院不主动审查时效(§193),义务人不抗辩 → 小李照样赢 → 起诉资格 = 实体请求权的体现 |
| ② **小李仍可催款** | 书面催款 / 上门要求 / 电话催款都是"请求"的体现 |
| ③ **自愿履行可保留** | §192 II 自愿履行不构成 [[不当得利]] — 反向证明小李对这笔款**有权利依据**(=实体请求权在)|

#### ⚠️ Q03 vs 多选-01 关键易混

| 真题 | 假设 | 请求权能状态 | 是债吗? |
|---|---|---|---|
| [[合同通则-单选-03]] | "请求权能**彻底**欠缺" | ① 实体 + ② 胜诉权 **全没** | ❌ **不是债**(情谊行为)|
| [[合同通则-多选-01]] | "时效届满" | ① 实体**还在** + ② 胜诉权**消灭** | ✅ **仍是债**([[自然债务]]) |

→ **两题不矛盾!**它们描述的是**两种不同程度**的"请求权能缺失":
- Q03 的"欠缺" = **彻底消失**(实体 + 胜诉权全没)→ 不是债
- 多选-01 的"届满" = **半死半活**(实体在 + 胜诉权没)→ 仍是债

#### 精准表述对照

| ❌ 不精准说法 | ✅ 精准说法 |
|---|---|
| "时效届满 → 没有请求权能" | "时效届满 → **胜诉权消灭**,但**实体请求权仍存**" |
| "请求权能完全消灭" | "请求权能的**程序保障部分**死了,**实体权利部分**还活着" |
| "4 权能里 1 死 3 活" | "4 权能里 1 个**半死半活** + 3 个完全保留" |

→ 这是法考核心考点,Q03 + 多选-01 必考的"陷阱区"。

### 时效期间

| 类型 | 期间 | 法条 |
|---|---|---|
| **普通诉讼时效** | **3 年** | §188 I |
| **最长保护期** | 自权利受到损害**20 年**(不可中止 / 中断,只可延长)| §188 II |
| **特殊时效** | 商品质量(国际货物买卖等)| 特别法规定 |
| **不适用时效**| 物权请求权 / 抚养费 / 存款本息等 | §196 |

> ⚠️ **§196 物权请求权区分对待**（高频陷阱，详见 [[物权的保护]]）：停止侵害 / 排除妨碍 / 消除危险**一律不适用**时效；返还原物**仅"不动产 + 已登记动产"不适用**，**未登记动产返还仍受 3 年时效**；§238 损害赔偿是债权请求权，**适用** 3 年时效。

### 起算规则

| 情形 | 起算时点 | 法条 |
|---|---|---|
| 一般 | **知道或应当知道**权利受损 + 义务人之日 | §188 |
| 分期履行 | **最后一期**届满之日 | §189 |
| 无 / 限制行为能力人 | **法定代理人确定**之日 | §190 |
| 未成年人遭性侵 | **18 岁**之日 | §191 |

### 🆚 中止 vs 中断 vs 延长(高频考点)

| 项 | **中止**(§194)| **中断**(§195)| **延长**(§188 II) |
|---|---|---|---|
| **触发** | 时效届满**前 6 个月内**有障碍 | ①请求 / ②同意履行 / ③起诉 / ④仲裁等 | 20 年最长保护期内特殊情形 |
| **效果** | **暂停** → 障碍消除后**继续 6 个月** | **重新计算 3 年** | 法院延长 |
| **作用方** | 客观障碍 | 主观行为 | 法院 |
| **比喻** | **按暂停键** | **按重置键** | **按延长键** |

### 时效届满后的"恢复"路径

- 义务人**重新承诺**履行(§192 II)→ **时效重新起算 3 年**(等同于中断)
- 义务人**自愿履行** → 不得请求返还(**不构成 [[不当得利]]**)→ 保持 [[自然债务]] 状态

### 🚨 重要规则:法院不主动审查时效(§193)

> 人民法院**不得主动**适用诉讼时效的规定。

→ 义务人**主动抗辩**才有效
→ 不抗辩 = 视为**放弃时效利益** = 法院仍判履行!

## 🚗 老王小李故事(时效届满 4 阶段剧)

### 剧情设定

> **2023/1/1** 老王借小李 12 万,约定 **2023/12/31** 还。
> 老王到期没还,小李一直没起诉。

### 阶段 ①:2023/12/31 - 2026/12/31(时效内)

- 小李有**完整 4 权能 + 胜诉权**
- 可随时起诉 → 必胜
- 老王可能找各种理由拖延,但**时效在跑**

### 阶段 ②:2026/12/31(时效届满)

- 起算:**2024/1/1**(应当还款次日,知道权利受损)
- 时效期间:3 年
- 届满:**2026/12/31** ← 时效死线
- **胜诉权消灭** → 实体债权仍存(进入 [[自然债务]] 状态)

### 阶段 ③:2027/2 小李起诉

```
情形 a:老王不抗辩(忘记 / 不懂法)
        ↓
法院**不主动**审查时效(§193)
        ↓
法院判老王败诉 ✅(小李胜诉)

情形 b:老王抗辩"已过时效"
        ↓
法院支持抗辩
        ↓
判小李败诉 ❌(但债权实体上仍存)
```

### 阶段 ④:2027/3 老王自愿还了 5 万

- 小李**不必返还**!(**§192 II 倒装情形**)
- **不构成 [[不当得利]]**(保持受领权能仍在)

### 阶段 ⑤:2027/4 老王写借条"我承认还欠 7 万,3 个月内还清"

- 这是**重新承诺**(§192 II)
- → **时效重新计算 3 年**(重新起诉权恢复)
- 新时效:2027/4 - 2030/4

### 阶段 ⑥:中止情景对比

> 假设 **2026/7** - **2026/12** 期间小李去南极考察(不可抗力)→ 触发**中止**!
> - 时效在 2026/12/31 暂停
> - 2027/1 小李回来 → 障碍消除
> - **继续 6 个月** → 2027/7 才真正届满

### 阶段 ⑦:中断情景对比

> 假设 **2025/6** 小李给老王发了催款函(**请求**)→ 触发**中断**!
> - 时效**重置** → 新的 3 年从 2025/6 起算
> - 新届满日 = 2028/6

## 怎么考 / 坑在哪

### 五大陷阱

1. **以为时效届满 = 债权消灭** ❌ —— 只是胜诉权消灭,实体债权仍存
2. **法院主动审查时效** ❌ —— **§193** 法院不得主动适用
3. **混淆中止 / 中断** ❌ —— 中止 = 暂停 / 中断 = 重置
4. **以为自愿履行可索回** ❌ —— §192 II 倒装,不构成不当得利
5. **支配权能 vs 请求权能混淆** ❌ —— 债权无支配权(物权专属)

### 答题口诀

```
看到"已过诉讼时效"
↓
Step 1:消灭胜诉权(程序)
Step 2:实体债权仍存(自然债务)
Step 3:4 权能命运
  ① 请求权能(胜诉权) → 消灭
  ② 受领权能 → 保留(自愿履行有效)
  ③ 保全权能 → 保留
  ④ 处分权能 → 保留
Step 4:特殊陷阱
  - 法院不主动审查(§193)
  - 重新承诺 → 时效重新计算 3 年
  - 自愿履行 → 不得索回
```
