# 债的法定移转

> 债权债务**主体变更**，不靠当事人签协议，而是**法律"自己搬家"** —— 与**意定移转**（[[债权转让]] / [[债务承担]]）相对。

## 法条范围

散见各编：**《保险法》§60**（保险代位）· **§67**（法人合并 / 分立）· **继承编 §1122 / §1161**（继承）· **§725**（买卖不破租赁）· **§524 / §700**（第三人 / 保证人清偿后的法定代位）；学理"**意定 vs 法定**"二分。

## 是什么 / 易混

### 核心：债的移转 = 意定 vs 法定 两条路

债的"主体"换人（债权人或债务人变了），有两种发生方式：

| | **意定移转** | **法定移转** |
|---|---|---|
| 怎么发生 | 当事人**合意**（签协议） | **法律直接规定**，无需专门合意 |
| 典型 | [[债权转让]]（§545 · 通知）、[[债务承担]]（§551 · 债权人同意） | 保险代位、合并分立、继承、买卖不破租赁 |
| 要不要通知 / 同意 | **转债权要通知、转债务要同意** | **不需要**——法律一规定就移转 |

### ★ 法定移转四大典型（本题 [[合同通则-多选-35]] = ABCD）

| 情形 | 法源 | 谁移给谁 |
|---|---|---|
| **① 保险代位求偿** | **《保险法》§60** | 保险人赔付后，被保险人对**第三人**的赔偿请求权 → **保险人** |
| **② 法人合并 / 分立** | **§67** | 原债权债务 → 合并后 / 分立后法人（**分立 = 连带**）|
| **③ 继承** | **继承编 §1122 / §1161** | 被继承人的债权债务 → 继承人（债务**以遗产为限**）|
| **④ 买卖不破租赁** | **§725** | 出租人（原所有人）的**租赁合同地位** → 买受人（新所有人）|

> **D 的法理 = 法定概括转移说**（通说）：租赁物所有权一变动，原出租人的权利义务**概括移转**给买受人，买受人继受成为"**新出租人**"（§725）。别因为"它在讲租赁"就以为不是债的移转。
> **为什么要这条（立法目的）**：**保护承租人**——居住 / 经营是刚需，承租人多属经济弱者；若"卖了就能赶人"，租客永无安稳。于是法律把**租赁权"物权化"**——本来租赁权只是债权（只能对原房东主张），法律特别赋予它**对抗新买主**的效力。**适用前提**：承租人**已占有**租赁物（占有 = 公示）、且**先租后卖**（租赁先于所有权变动生效）。

### ★ 头号大坑：保险代位求偿（§60 · 移转）≠ 债权人代位权（§535 · 保全）

两个都叫"代位"，但**完全不同**——这是本题 A 项最易混处：

| | **保险代位求偿**（本题 A） | **[[代位权]]**（债权人代位权）|
|---|---|---|
| 法源 | **《保险法》§60** | **§535** |
| 性质 | **债的法定移转**（债权真的过户给保险人）| **保全**制度（代债务人行权，债权**不移转**）|
| 谁取得 | 保险人**取得**被保险人的索赔权 | 债权人**没取得**债务人的债权，只是**代为行使** |

→ "保险代位"是债权**真的搬家**；"债权人代位权"债权**没搬**，只是替债务人去要钱。

### 其他法定移转（扩展）

- **第三人代为清偿的法定代位（§524）**：有**利害关系**的第三人清偿后，债权人的债权**法定移转**给该第三人（见 [[第三人代为履行]]）。
- **保证人清偿后的代位（§700）**：保证人担责后，在追偿范围内享有债权人对债务人的权利。

## 怎么考 / 坑在哪

- **判断标准**：主体变更是"**法律直接规定**"还是"**当事人约定**"？前者法定、后者意定。
- **头号坑——两个"代位"**：保险代位（§60，**移转**）vs 债权人代位权（§535，**保全·不移转**）。
- **买卖不破租赁是法定移转**（法定概括转移说），别排除（D 对）。
- **合并分立连带**：分立后的法人对原债务**连带**（§67）。
- 对照**意定移转**：[[债权转让]]（通知）、[[债务承担]]（同意）——靠当事人约定，不是法定。

## 🚗 老王小李故事（一辆车，四种"法律自己搬家"）

> 还是老王和小李买卖车辆那点事，看"债"怎么**不签协议就自己换了主人**：
>
> - **① 保险代位（保险法 §60）**：小李的车被第三人撞了，保险公司**先赔**小李修车钱 → 保险公司**自动**接过"小李找肇事者索赔"的那项权利，回头去找肇事者。债权**搬到**保险公司了。
> - **② 合并分立（§67）**：老王的修理厂（欠着小李一笔货款）和别家**合并**成新公司 → 这笔欠小李的债**自动**归新公司，不用小李点头。
> - **③ 继承（继承编）**：老王不幸去世，还欠小李 5 万车款 → 老王的儿子在**继承遗产范围内自动**接着还（超过遗产的部分不强求）。
> - **④ 买卖不破租赁（§725）**：老王有套**出租给小李住**的房子，住到一半老王把房子**卖给**老张 → 小李的租约**自动**对新房东老张继续有效，**能安稳住到租期满**、老张不能赶人；老张**自动**变成"新房东"收租。（**车位 / 商铺同理**——只要"先租后卖"。）
>
> 四样全是"**法律搬的家**"——和"债权转让要**通知**小李、债务承担要**经同意**"那种**当事人自己搬**的，截然不同。

## 🎯 一句话记忆

> **"债的移转两条路：意定（转债权通知 / 转债务同意）vs 法定（法律直接搬）。"**
> **"法定四典型：保（险代位 §60）、并（合并分立 §67）、继（承）、租（买卖不破租赁 §725）。"**
> **"两个'代位'别混：保险代位 = 移转（§60），债权人代位权 = 保全（§535）。"**
