# 履行地点

> 没约定时的**法定推定**地点 — 按**给付内容**确定

## 法条范围

[[合同编]] §510、§511

## 是什么 / 易混

### 适用顺序
1. **约定**优先
2. 没约定 / 不明 → **协议补充**
3. 不能达成 → **§510**：按合同**有关条款 + 交易习惯**
4. 仍不能确定 → **§511**：**法定推定**

### §511 法定推定（按给付类型）

| 给付类型 | 履行地点 |
|---|---|
| **给付货币** | **接受货币一方**所在地（债权人所在地）|
| **交付不动产** | **不动产所在地** |
| **其他标的物** | **履行义务一方**所在地（债务人所在地）|

### 特殊合同的履行地点

| 合同 | 履行地点 | 法条 |
|---|---|---|
| **[[供用电合同]]** | **供电设施产权分界处** | §651 |
| **运输合同** | 起运地 / 目的地 | 各章 |
| **承揽** | 承揽人加工地 / 交付地 | 一般 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **货币 vs 不动产 vs 其他物**：3 种规则不同
2. **承揽物 / 加工物**：通说承揽人交付地，但严格按 §511 应是债务人所在地（C1-单选-15 争议）
3. **供电合同 = 产权分界处**（§651 特别规定）
