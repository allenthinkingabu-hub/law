# 流押与流质

> 禁止直接归属所有权，强制转化为清算型担保优先受偿的法定规则。

## 法条范围

[[民法典]] **§401**（流押条款）、**§428**（流质条款）+ 关联 **§215**（区分原则）、**§410**（抵押权实现方式）。

---

## 是什么 / 核心概念

### 1. 定义
**流押与流质**是指债权人在**债务履行期限届满前（期前）**，与担保人约定当主债务人不履行到期债务时，担保物（抵押物/质物）的**所有权直接归债权人所有**：
*   在抵押中称为**流押条款**（§401）。
*   在质押中称为**流质条款**（§428）。

### 2. 立法演变与效力“软化”对照

| 维度         | 旧《物权法》规定                  | 新《民法典》规定（§401/§428）                       |
| ---------- | ------------------------- | ----------------------------------------- |
| **立法用语**   | 约定不还所有权归债权人所有的，该条款**无效**。 | 约定不还所有权归债权人所有的，**只能依法就该财产优先受偿**。          |
| **物权变动**   | **不发生**所有权转移的效力（无效）。      | **不发生**所有权转移的效力（不直接过户）。                   |
| **清算义务**   | 模糊，容易引发关于“担保合同是否整体无效”的争议。 | 确认该条款转化为“清算型担保”依据。债权人必须清算并履行“**多退少补**”义务。 |
| **担保合同效力** | 条款无效，但抵押/质押关系有效。          | 条款（所有权直接变动部分）不生效，**担保合同整体及优先受偿权有效**。      |

---

## 强制清算义务与规则（多退少补）

根据《民法典》关于优先受偿的法理，债权人在债务到期未受清偿时，**必须**通过折价、拍卖、变卖等清算程序实现债权：

```
                              债务到期未获清偿
                                     │
                                     ▼
                              对担保物进行清算
                      (折价折算、公开拍卖、依法变卖)
                                     │
                   ┌─────────────────┴─────────────────┐
                   ▼                                   ▼
        【超额：担保物估值 > 债权本息】     【缺额：担保物估值 < 债权本息】
                   │                                   │
                   ▼                                   ▼
           【多退】: 超出部分                  【少补】: 不足部分
         **必须返还**给担保人                **有权继续**向债务人追偿
```

## 🚗 老王小李的故事

> 小李向老王借款10万元。小李为了拿借款，以自有的机器设备（评估价15万元）向老王提供抵押（已办登记），并在合同里写明：“如果小李到期不能还钱，该机器设备的所有权直接归老王所有。”

下面几种情况，双方的权利如何？

| 事实情况                                          | 法律判定与效果                   | 依据与法理                                                     |
| --------------------------------------------- | ------------------------- | --------------------------------------------------------- |
| 借款期满，小李无力还款。老王直接将设备搬走据为己有，拒绝给小李算账。            | 老王的行为**违法**。              | 流押约定不发生所有权转移的效力（§401）。老王必须清算设备价值，多退少补，不能直接吞并设备所有权。        |
| 小李主张，因为合同约定了流押条款违反了《民法典》，所以整个抵押合同无效，抵押权注销。    | 小李的主张**不成立**。             | 区分原则下，流押条款不生效不影响抵押合同整体效力，老王的**抵押权依然有效**（见 [[物权编-多选-15]]）。 |
| 老王把设备拍卖得了15万。扣除10万债务本息。老王把剩下的5万元自己留着。         | 老王**构成不当得利**，必须将5万元退还给小李。 | 清算实行“多退”，超出债务本息的担保财产变现价值必须**返还给担保人**。                     |
| 设备拍卖只得了8万。老王将8万扣除，并起诉要求小李继续偿还剩下的2万元。          | 法院**支持老王**的诉求。            | 清算实行“少补”，不足部分债权人有权继续向主债务人追偿。                              |
| 借款期满小李没钱还。当天双方签订《折价协议》，小李同意设备作价10万抵债，设备过户给老王。 | 协议**合法有效**。               | 债务到期后（期后）双方协议折价抵债是合法的抵押权实现方式（§410），不属于期前流押。               |
