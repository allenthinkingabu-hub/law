# 委托合同

> **双向任意解除权 + 有偿 / 无偿的注意义务区分**

## 法条范围

[[民法典]] §919-§936（18 条）

## 是什么 / 易混

### 定义
**§919**：委托人和受托人约定，由**受托人处理委托人事务**的合同。

### 关键特征
| 特征          | 内容                                        | 法条   |
| ----------- | ----------------------------------------- | ---- |
| 性质          | **诺成 / 不要式 / 可有偿可无偿**                     |      |
| **双向任意解除权** | 委托人 / 受托人**均可随时解除**                       | §933 |
| 解除后赔偿       | 有偿赔**直接损失 + 可得利益**；无偿赔**直接损失**            | §933 |
| 受托人注意义务     | 有偿 = **谨慎勤勉**（一般过失即担责）；无偿 = **故意 / 重大过失** | §929 |

### 与近似合同的区分
| 维度 | [[委托合同]] | [[行纪合同]] | [[中介合同]] |
|---|---|---|---|
| 行为 | 处理事务（广义） | 以自己名义**买卖** | 报告订约机会 / 媒介 |
| 是否成约方 | 否（代理人）| **是** | 否 |
| 报酬 | 可有可无 | 必有偿 | 必有偿 |

## 怎么考 / 坑在哪

### 四大陷阱

1. **任意解除权贯穿全程**（§933）—— 即使一审败诉、即使二审已开庭，仍可解除
2. **有偿委托一般过失即担责**（§929）—— 律师 / 中介这类专业有偿委托
3. **解除 ≠ 违约**：任意解除权是法定权利，**不构成违约**
4. **转委托**：原则**经同意**才可；紧急情况例外（§923）

## 怎么答

主观题分析框架：
1. **定性**：是否委托合同？有偿 / 无偿？
2. **解除权**：行使者 / 时点 / 赔偿范围
3. **注意义务**：根据有偿 / 无偿确定过失程度
4. **代理权范围**：是否超越授权 / 转委托？
5. **费用 + 报酬**
