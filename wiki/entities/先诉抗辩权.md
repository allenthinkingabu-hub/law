# 先诉抗辩权

> 又称**检索抗辩权** — **一般保证人**专属：债权人没先"收拾"债务人之前，保证人可拒绝担责（§687）

## 法条范围

[[民法典]] §687（一般保证 + 先诉抗辩权）· 对比 §688（连带责任保证无此权）

## 是什么 / 易混

### 定义
**§687**：**一般保证**的保证人，在主合同纠纷**未经审判或者仲裁**，并就**债务人财产依法强制执行仍不能履行**债务前，**有权拒绝**向债权人承担保证责任。
- 通俗：债权人得**先告债务人、先执行债务人的财产**；确实榨不出来，才能回头找保证人。"先诉 / 检索"即此意，又叫**顺序利益**。

### 只有"一般保证"才有（vs 连带保证）
| | 一般保证 | 连带责任保证 |
|---|---|---|
| 先诉抗辩权 | ✅ 享有（§687）| ❌ 不享有（§688）|
| 债权人能否直接找保证人 | **不能**，须先诉 / 先执行债务人 | **能**，债务人一违约即可直接找 |
| 2021 默认 | **未约定 = 一般保证**（§686，旧法相反）| 仅明确约定时 |

### ★ 与"三大履行抗辩权"的根本区别（[[合同通则-单选-16]] 的考点）
| | 先诉抗辩权（§687）| 三大履行抗辩权（§525-§528）|
|---|---|---|
| 所在关系 | **保证**（债权人—债务人—保证人 · 三方担保）| **双务合同**（两方互负对待给付）|
| 谁享有 | **一般保证人** | 合同一方当事人 |
| 内容 | "你**先去收拾债务人**，再来找我"（顺序 / 检索利益）| "你**没履行**，我就拒绝 / 中止我这边"|

- 所以 [[合同通则-单选-16]] 里"先诉抗辩权"是**干扰项**——那题是双务买卖里的 [[不安抗辩权]]，与保证无关。

### 先诉抗辩权"丧失"的 4 情形（§687 II）
出现以下任一，保证人**不能**再拿先诉抗辩权挡，债权人可直接找保证人：
1. 债务人**下落不明**，且**无财产**可供执行；
2. 法院已**受理债务人破产**案件；
3. 债权人有**证据证明**债务人财产**不足**清偿全部债务 / 丧失履行能力；
4. 保证人**书面**放弃该权利。

## 怎么考 / 坑在哪

### 三大陷阱
1. **张冠李戴**：把"先诉抗辩权"安到双务合同履行里（如 [[合同通则-单选-16]] 的 A 项）——它只属于**保证**，不是履行抗辩权。
2. **连带保证没有先诉抗辩权**：连带保证人不能说"先去告债务人"，债权人可直接找他（§688）。
3. **4 丧失情形**：尤其"债务人下落不明 + 无财产""**书面**放弃"——一旦命中，先诉抗辩权失效（[[典型合同-多选-08]]：口头放弃 / 移居国外但有房，均**未**丧失）。

## 怎么答

判断先诉抗辩权三步（概念框架）：
1. **是不是保证关系**？不是 → 根本谈不上先诉抗辩权（可能是履行抗辩权，见 [[合同通则-单选-16]]）。
2. **一般保证还是连带保证**？连带 → 无先诉抗辩权（§688）；一般 → 原则上有（§687）。
3. **有没有 4 种丧失情形**？命中任一 → 先诉抗辩权失效，债权人可直接找保证人。

## 🚗 老王小李故事（买卖车辆 + 保证人老赵）

> 老王把车卖给小李，小李一时付不全、欠着**尾款**。邻居老赵给小李这笔尾款做了**保证**，当初**没写**是哪种保证 → 按 2021 新规默认是**一般保证**（§686）。
>
> 尾款到期，小李没付。老王直接找老赵："你是保证人，你替小李还！"老赵把**先诉抗辩权**一亮（§687）："**别急着找我！你得先去法院告小李、把小李的财产强制执行一遍；确实执行不出来，再来找我。**"——这就是"先诉 / 检索"：债权人得先拿债务人"过一遍筛子"。
>
> **换个版本**：若当初白纸黑字约定老赵是**连带责任保证**，那他就**没有**先诉抗辩权——小李一违约，老王可**直接**找老赵要钱（§688）。
>
> **老赵这张牌也会失效（§687 II 四情形）**：① 小李跑路了又没财产可执行；② 法院已受理小李破产；③ 老王有证据证明小李财产根本不够还；④ 老赵当初**书面**放弃过。任一出现，老王就能直接找老赵。
