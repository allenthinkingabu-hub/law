# 缔约过失责任

> 合同**未成立 / 无效 / 被撤销**时的**诚信损害赔偿** — 以**信赖利益**为限

## 法条范围

[[合同编]] §500、§501

## 是什么 / 易混

### 定义
**§500**：当事人在**订立合同过程**中有下列情形之一，造成对方损失的，**应当承担赔偿责任**：
1. **假借**订立合同，恶意进行**磋商**
2. 故意**隐瞒**与订立合同有关的重要事实 / 提供**虚假情况**
3. 有其他**违背诚信原则**的行为

### 关键特征
| 项 | 内容 |
|---|---|
| **责任性质** | 法定责任（不是违约 / 侵权）|
| **保护利益** | **信赖利益**（不是履行利益）|
| **构成时点** | 缔约过程中 → 合同**成立**前 |
| **诚信原则** | §7 + §500 的具象化 |

### 信赖利益的赔偿范围
- **缔约费用**：差旅 / 调查 / 咨询费等
- **机会损失**：因信赖该合同放弃其他机会
- **不超过履行利益**：缔约过失赔偿**不能高于**合同成立时的可得利益

### 缔约过失 vs 违约责任

| 维度 | 缔约过失 | 违约责任 |
|---|---|---|
| 合同状态 | **未成立 / 无效 / 被撤销** | **已成立 + 已生效** |
| 保护利益 | **信赖利益** | **履行利益 / 可得利益** |
| 法条 | §500 | §577 |

### §501 商业秘密保护
**§501**：当事人在订立合同过程中知悉的**商业秘密**或者**应保密的信息** → 不得泄露或不正当使用，否则承担赔偿责任（无论合同是否成立）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **合同未成立也有责任**（§500）—— 不是只有合同成立后才有责任
2. **诚信原则**是基础
3. **信赖利益 vs 履行利益**：不可索要"如果合同成立 + 履行可得的利益"

## 怎么答

主观题分析框架：
1. **合同状态**：未成立 / 无效 / 被撤销？
2. **缔约过失情形**：是 §500 哪一项？
3. **损失类型**：信赖利益（费用 + 机会）
4. **赔偿上限**：不超过履行利益
5. **商业秘密**：§501 单独保护
