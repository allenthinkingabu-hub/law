# 缔约过失责任

> 合同**未成立 / 无效 / 被撤销**时的**诚信损害赔偿** — 以**信赖利益**为限

## 法条范围

[[合同编]] §500、§501

## 是什么 / 易混

### 定义
**§500**：当事人在**订立合同过程**中有下列情形之一，造成对方损失的，**应当承担赔偿责任**：
1. **假借**订立合同，恶意进行**磋商**
2. 故意**隐瞒**与订立合同有关的重要事实 / 提供**虚假情况**
3. 有其他**违背诚信原则**的行为

### 关键特征
| 项 | 内容 |
|---|---|
| **责任性质** | 法定责任（不是违约 / 侵权）|
| **保护利益** | **信赖利益**（不是履行利益）|
| **构成时点** | 缔约过程中 → 合同**成立**前 |
| **诚信原则** | §7 + §500 的具象化 |

### 信赖利益的赔偿范围
- **缔约费用**：差旅 / 调查 / 咨询费等
- **机会损失**：因信赖该合同放弃其他机会
- **不超过履行利益**：缔约过失赔偿**不能高于**合同成立时的可得利益

### 三种责任体系大对比 🔥（主观题必考体系）

| 维度       | **缔约过失**           | [[违约责任]]          | **侵权责任**       |
| -------- | ------------------ | ----------------- | -------------- |
| **法条**   | §500               | §577              | §1165          |
| **合同状态** | **未成立 / 无效 / 被撤销** | **已成立 + 已生效**     | **不要求合同**      |
| **保护利益** | **信赖利益**           | **履行利益 / 可得利益**   | 全部损失（含人身 / 财产） |
| **归责原则** | 过错责任               | **严格责任**（默认）      | 过错责任（默认）       |
| **典型情形** | 恶意磋商 / 隐瞒事实        | 不履行 / 迟延履行 / 瑕疵履行 | 侵犯人身 / 财产权益    |

→ 主观题分析合同争议时，**按合同状态依次排查**三种责任。

### 5 大典型情形清单（§500 + 扩展）

| # | 情形 | 法条 | 关键词 |
|---|---|---|---|
| ① | **恶意磋商**（假借订立，无诚意）| §500 第 1 项 | "假借 + 恶意" |
| ② | **故意隐瞒重要事实 / 提供虚假情况** | §500 第 2 项 | "隐瞒 + 虚假" |
| ③ | **其他违背诚信原则** | §500 第 3 项 | 兜底条款 |
| ④ | **泄露 / 不正当使用商业秘密** | §501 | 即使合同未成立也担责 |
| ⑤ | **合同无效 / 被撤销后过错方的赔偿** | §157 | 按过错分摊损失 |

### §501 商业秘密保护
**§501**：当事人在订立合同过程中知悉的**商业秘密**或者**应保密的信息** → 不得泄露或不正当使用，否则承担赔偿责任（**无论合同是否成立**）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **合同未成立也有责任**（§500）—— 不是只有合同成立后才有责任
2. **诚信原则**是基础
3. **信赖利益 vs 履行利益**：不可索要"如果合同成立 + 履行可得的利益"

## 举例 · 老王小李买车（缔约过失版）

> 4 场景对照 §500 + §501 + §157 的核心情形，让"缔约过失"从抽象法条落地为生活直觉。

### 场景 1：恶意磋商（§500 第 1 项）

> 老王其实**根本不想卖车**，只是想**借小李抬价**，套出市价后转手卖给别人。  
> 老王约小李 **9/15 跨城来看车 + 签合同**。9/15 当天老王临时找理由拒签，9/16 把车 13 万卖给丙。

法律分析：
- 老王主观上**假借磋商**——根本无成约意图
- 合同**未成立**（没签字 / 没合意）
- 但小李：差旅费 800 + 检测费 500 + 误工损失 300 = **1600 元信赖利益损失**
- → 老王构成 **§500 第 1 项缔约过失** → 赔 1600

### 场景 2：故意隐瞒重要事实（§500 第 2 项）

> 老王**明知车已被法院查封**（不能过户），仍跟小李谈判。  
> 9/12 签了合同，9/15 小李付了 12 万。9/20 小李发现无法过户。

法律分析：
- 老王**故意隐瞒重要事实**（车的法律状态）
- 合同**虽已成立**但因标的不能过户而无法履行——可能**被撤销**或归于无效
- 小李损失：检测费 + 差旅费 + **12 万的资金占用利息**
- → 老王构成 **§500 第 2 项缔约过失**
- → 若合同被撤销 → §157 返还 12 万 + 赔信赖利益

### 场景 3：违反保密义务（§501）

> 小李在磋商过程中告诉老王：**"我下个月跳槽到 X 公司当总监，需要这辆商务车撑场面"**。  
> 谈崩了。老王把这事告诉了小李现在的老板，导致小李被开除。

法律分析：
- 老王**违反保密义务**（§501）
- **即使合同没成立**也担责（§501 关键点）
- 小李损失：失业造成的工资损失（机会损失）
- → 老王构成 **§501 缔约过失类责任**

### 场景 4：合同被撤销后的责任（§157 + §500）

> 老王**故意虚报里程数**（实际 30 万公里说成 14 万）。小李 12 万买下。  
> 后来小李发现 → 起诉**撤销合同**（§148 欺诈可撤销）。

法律分析：
- 合同**被撤销** = 自始无效（§157）
- §157：双方**返还财产** + **过错方赔损失**
- 老王是过错方 → 触发 **§500 缔约过失**
- 老王赔小李：检测费 / 差旅费 / 资金占用利息（**信赖利益**）

→ 答题口诀（4 步判定 + 信赖利益清单 + 套用表）见 [[合同通则-单选-12]] 题目页。
