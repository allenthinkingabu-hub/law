# 承揽合同

> **定作人任意解除权**是 [[合同编]] 中**最自由**的解除权之一。

## 法条范围

[[民法典]] §770-§787（18 条）

## 是什么 / 易混

### 定义
**§770**：承揽人**按照定作人要求完成工作**，**交付工作成果**，定作人**支付报酬**的合同。

### 关键特征（条号已联网核实 2026-06-14 · 3 源）
| 特征 | 内容 | 法条 |
|---|---|---|
| 合同核心 | **完成工作 + 交付成果**（买卖卖现成物，承揽按要求现制造）；含加工/定作/修理/复制/测试/检验 | §770 |
| **定作人任意解除权** | 承揽人**完成工作前**可**随时解除** + 赔偿损失（赔偿**不是**解除的前提，先解后赔）| §787 |
| 承揽人**自己完成主要工作** | 主要工作交第三人仍须对成果负责；**未经定作人同意，定作人可解除** | §772 |
| 辅助工作可交第三人 | 但仍对成果向定作人负责 | §773 |
| 承揽人通知义务 | 定作人提供**材料**不符 → 及时通知（§775）；**图纸/技术要求**不合理 → 及时通知（§776）| §775 / §776 |
| 定作人协助义务 | 不协助致工作不能完成 → 催告 + 顺延 → 逾期承揽人可解除 | §778 |
| 质量不符救济 | 定作人可**合理选择**：修理 / 重作 / 减少报酬 / 赔偿损失 | §781 |
| 报酬支付时间 | 约定不明 → 交付工作成果时支付（部分交付相应支付，援引 §510）| §782 |
| 承揽人**留置权 / 拒绝交付** | 定作人不付报酬/材料费 → 对成果留置 或 拒绝交付（另有约定除外）| §783 |
| 承揽人保管义务 | 妥善保管定作人材料 + 工作成果，保管不善毁损灭失 → 赔偿 | §784 |
| **共同承揽连带责任** | 共同承揽人对定作人**连带责任**（另有约定除外）| §786 |

### 与近似合同的区分（高频 · [[典型合同-单选-28]]）
- vs [[建设工程合同]]：建设工程是承揽的**特殊类型**（标的 = **不动产建设** §788）；承揽标的 = **动产 / 工作成果**（设备再大也是承揽）。**§808：建设工程章没规定的准用承揽**。📐 定性见 [[民法-合同-建设工程模型]] 第一步。
- vs [[买卖合同]]：承揽**按要求现制造（定作）**；买卖**交付现成物**。
- vs [[委托合同]]：承揽**重成果**（交付成果才算履行）；委托**重事务**（尽勤勉义务即可，不担保结果）。
- vs [[技术开发合同]]：技术开发**侧重研发新技术**；承揽**侧重按既有技术完成物 / 工**。
- **形式**：承揽是 **[[要式合同|非要式]]**（法律不强制书面）；建设工程则**要式**（§789 须书面）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **任意解除权 ≠ 违约**：定作人解除合同**不是违约**——只需赔偿**实际损失**，**不付全额报酬**、**不付违约金**
2. **承揽人不停手就要担责**：定作人已要求停止 → 承揽人继续做 → 多耗费损失**自负**
3. **报酬按已完成部分**：解除后**按比例**付报酬，不退已支出的必要费用

## 怎么答

主观题分析框架：
1. **定性**：是否承揽合同？
2. **任意解除权**：定作人是否行使？时点？
3. **承揽人责任**：是否擅自更换 / 转包？
4. **赔偿**：定作人解除 → 赔偿承揽人**实际损失**；承揽人违约 → 一般违约责任
