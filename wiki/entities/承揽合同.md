# 承揽合同

> **定作人任意解除权**是 [[合同编]] 中**最自由**的解除权之一。

## 法条范围

[[民法典]] §770-§787（18 条）

## 是什么 / 易混

### 定义
**§770**：承揽人**按照定作人要求完成工作**，**交付工作成果**，定作人**支付报酬**的合同。

### 关键特征
| 特征 | 内容 | 法条 |
|---|---|---|
| 合同核心 | **完成工作 + 交付成果**（与买卖区别：买卖卖现成物，承揽现制造）| §770 |
| **定作人任意解除权** | 在承揽人**完成工作前**可**随时解除** + 赔偿损失 | §787 |
| 承揽人不得擅自更换主要内容 | | §776 |
| 承揽人有**留置权** | 定作人不付报酬 → 留置 | §783 |

### 与近似合同的区分
- vs [[委托合同]]：承揽**重成果**，委托**重事务**
- vs [[建设工程合同]]：建设工程是大型承揽（建房 / 修桥），特殊章节
- vs [[技术开发合同]]：技术开发**侧重技术**，承揽**侧重物 / 工**

## 怎么考 / 坑在哪

### 三大陷阱

1. **任意解除权 ≠ 违约**：定作人解除合同**不是违约**——只需赔偿**实际损失**，**不付全额报酬**、**不付违约金**
2. **承揽人不停手就要担责**：定作人已要求停止 → 承揽人继续做 → 多耗费损失**自负**
3. **报酬按已完成部分**：解除后**按比例**付报酬，不退已支出的必要费用

## 怎么答

主观题分析框架：
1. **定性**：是否承揽合同？
2. **任意解除权**：定作人是否行使？时点？
3. **承揽人责任**：是否擅自更换 / 转包？
4. **赔偿**：定作人解除 → 赔偿承揽人**实际损失**；承揽人违约 → 一般违约责任
