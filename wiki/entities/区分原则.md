# 区分原则

> 民法核心原则：**债权效力（合同）** 与 **物权变动（所有权移转）** **严格分离** — §215 法源

## 法条范围

- **核心法源**：[[民法典]] **§215**（物权编）
- **关联**：§502（合同编 · 成立即生效）· §209 / §214 / §224 / §225（物权编 · 公示原则）

## 是什么 / 易混

### 核心定义

**§215**：当事人之间订立有关物权变动的**合同**，除法律另有规定或者合同另有约定外，**自合同成立时生效**；**未办理物权登记的，不影响合同效力**。

→ 一句话：**合同效力归合同效力，物权变动归物权变动，两件事不串台**。

### 双轨判断图

```
                ┌──────────────────────────┐
                │   涉及物权变动的合同      │
                │ (房屋买卖 / 抵押 / 转股) │
                └──────────────────────────┘
                          │
              ┌───────────┴───────────┐
              ▼                        ▼
    ┌──────────────────┐    ┌──────────────────┐
    │   债权轨道        │    │   物权轨道        │
    │   (合同效力)      │    │   (所有权 / 物权) │
    ├──────────────────┤    ├──────────────────┤
    │ 法条：§502 / §215│    │ 法条：§209/§214/§224│
    │ 生效：**合意即生效**│    │ 变动：**公示时变动** │
    │ 不动产：合意即效 │    │ 不动产：登记时变动 │
    │ 动产：合意即效   │    │ 动产：交付时变动   │
    └──────────────────┘    └──────────────────┘
        (相对权)                (绝对权)
```

### 5 大典型应用场景

| 场景 | 合同效力 | 物权变动 |
|---|---|---|
| **不动产买卖** | 合意即生效（§215）| **登记**时变动（§209/§214）|
| **一般动产买卖** | 合意即生效 | **交付**时变动（§224）|
| **特殊动产**（船舶/飞行器/机动车）| 合意即生效 | 交付时变动（§225 登记对抗主义）|
| **抵押权设立** | 合同合意生效（§400）| 不动产**登记**生效；动产**合意**生效（§403 登记对抗主义）|
| **股权转让** | 合意生效 | **股东名册变更**生效 |

→ 5 个场景，**全都**遵循"**合同先有效 → 物权后变动**"的双轨结构。

### 立法目的

| 目的 | 说明 |
|---|---|
| **保护交易安全** | 防止卖方用"未办登记 / 未交付"作为耍赖借口 |
| **督促履行** | 合同有效 → 卖方**必须协助**履行公示手续，否则违约 |
| **明确救济路径** | 拒不协助登记 / 交付 = 违约 → 可起诉强制履行 + 赔偿 |
| **区分债权和物权** | 债权 = 相对权（仅约束相对人）；物权 = 绝对权（对抗第三人）|

## 答题口诀 · 区分原则三步走

```
Step 1：定合同效力（§502 / §215）
  合意 + 合法 + 具体 → 合同生效 ✅
  ⚠️ 登记 / 交付 与否 → "不影响合同效力"（§215）

Step 2：定物权变动（§209 / §224 / §225）
  不动产 → 登记时变动
  一般动产 → 交付时变动
  特殊动产 → 交付时变动 + 登记对抗

Step 3：定请求权基础
  合同请求权（债权）→ 任何时候都能用（只要合同有效）
  物权请求权 → 仅在物权已变动后能用
```

## 举例 · 老王小李 4 种交易（区分原则全场景）

> 老王是卖方，小李是买方，**4 种不同标的物**对比 §215 区分原则。

### 场景 1：卖凯美瑞（一般动产）

> 9/1 双方说好"12 万卖凯美瑞"
> 9/3 老王交车

- 合同生效时点：**9/1 合意时**
- 物权变动时点：**9/3 交车时**（§224）

### 场景 2：卖房子（不动产）

> 9/1 双方签合同 120 万卖房
> 9/20 办完过户登记

- 合同生效时点：**9/1 签合同时**
- 物权变动时点：**9/20 登记时**（§209）
- ⚠️ 9/1 - 9/20 之间，合同**有效**但小李**没物权**

### 场景 3：卖游艇（特殊动产）

> 9/1 签合同 30 万卖游艇
> 9/5 交付游艇 + 钥匙
> 9/10 办海事局登记

- 合同生效时点：**9/1 合意时**
- 物权变动时点：**9/5 交付时**（§225）
- 登记效果：**登记对抗主义**——9/10 登记后**可对抗第三人**，9/5 至 9/10 已变动但**不对抗善意第三人**

### 场景 4：卖公司股权

> 9/1 签转让协议
> 9/15 变更股东名册

- 合同生效时点：**9/1 协议生效时**
- 物权变动时点：**9/15 股东名册变更时**

### 四场景一表对比

| 场景 | 合同 | 物权 | 标的 |
|---|---|---|---|
| 1️⃣ 凯美瑞 | 9/1 | 9/3 交车 | 动产 |
| 2️⃣ 房子 | 9/1 | 9/20 登记 | 不动产 |
| 3️⃣ 游艇 | 9/1 | 9/5 交付 + 9/10 登记对抗 | 特殊动产 |
| 4️⃣ 股权 | 9/1 | 9/15 股东名册 | 权利 |

→ **共同点**：合同**先**生效，物权**后**变动；中间窗口期内，买方只有**债权请求权**。

## 怎么考 / 坑在哪

### 三大经典陷阱

1. **"未登记 → 合同未生效"** ← 50% 考生选错（[[合同通则-多选-15]] A 项）
2. **"未交付 → 买卖合同无效"** ← 错，交付影响物权移转，**不影响合同效力**
3. **"合同有效 → 买方就有物权"** ← 错，买方需要等**公示完成**才有物权

### 一句话记忆

> **"债权归债权，物权归物权——两条独立轨道"**
> **"合同自合意时生效，物权自公示时变动"**
> **"凡见'未登记 → 合同未生效'——错！"**
