# 所有权

> [[物权编]] 第二分编（**§240–322**）的**章中枢**。所有权＝**最完整的物权**，四项权能齐全：**占有 · 使用 · 收益 · 处分**（§240）——所有权人对自己的物，享有全面支配权。本页是整章的**导航 + 高频考点速记**；单一制度的做题步骤见对应 📐 答题模型，深挖见子页。内容消化自已联网核实的 [[物权编考点-深度报告]]「二、所有权」，**未引入未核实的新法条**。

## 各章要点 & 高频陷阱

### 一、一般规定（§240-245）
- **四权能** §240：占有 · 使用 · 收益 · 处分（**处分**是核心权能，用益物权恰恰**没有**处分权能——辨析点）。
- **征收 vs 征用**：征收（§243）＝**所有权转移** + 补偿；征用（§245）＝**临时使用**，用后**返还** + 补偿损失。征收个人住宅须**保障居住条件**。基础概念题为主。

### 二、国家 / 集体 / 私人所有权 + 孳息（§246-270 · §321）
- 三类所有权主体，多为概念性基础考点。
- **孳息归属 §321**（小高频选择点）：**天然孳息**——既有所有权人又有用益物权人时，**用益物权人优先**（承包人采摘的果实归承包人）；**法定孳息**（租金、利息）——**约定优先**，无约定按交易习惯。

### 三、业主的建筑物区分所有权（§271-287）★★★★
- **表决规则 §278（最爱设陷阱）**：三层门槛——① 先须**专有面积 2/3 且人数 2/3** 业主**参与**表决；② 筹集维修资金 / 改建重建 / 改变共有部分用途经营，须**参与表决面积 3/4 且人数 3/4** 同意（"双过半 → 四分之三"）；③ 其他事项过半。**易错：分母是"已参会业主"，不是全体业主。**
- **专有 / 共有 / 车位车库**（§271-282 + 法释〔2020〕17 号）：§276 车位车库**首先满足业主需要**；占用业主共有道路、场地的车位**归业主共有**（不能约定排除）；共有部分经营收益扣除合理成本后**归业主共有**（解释 §14）。

### 四、相邻关系（§288-296）★★★
- 以**容忍义务**为核心。相邻关系是所有权的**法定限制 / 扩张**：**不需登记、无偿**。
- **★ 对比地役权**（跨用益物权板块合考）：相邻关系＝**法定 · 无偿 · 不登记**；地役权＝**约定 · 可有偿 · 登记对抗**。
- 通风、采光、日照：须**违反国家工程建设标准**才构成侵害。

### 五、共有（§297-310）★★★★
- **按份共有人优先购买权 §305-306**（+ 解释一 §9-13）：同等条件下优先购买；**行使期间**——约定优先；通知未定或短于 15 日的为 **15 日**；未通知则自知道/应知起 **6 个月**，最长自转移登记/交付起 **1 年**。与公司法股东优先购买权对比。
- **共有物处分与重大修缮 §301**：处分 / 重大修缮 / 变更性质用途——**按份共有＝份额 2/3 多数决**，**共同共有＝全体一致**（另有约定除外）；一般管理不需该比例。常与无权处分 + 善意取得合考。
- **共有物分割 §303-307**：按份共有人可**随时请求分割**；共同共有人须**共有基础丧失或有重大理由**（离婚、合伙解散）才可分割；§307——分割后原共有人对共有期间债务**连带责任**。

### 六、所有权取得的特别规定（§311-322）★★★★★
- **善意取得 §311**（+ 解释一 §14-20）——**物权编绝对头号高频**。三要件＝无处分权人处分 + 受让人善意且合理价格 + 完成登记/交付。四大不适用：①**占有改定**不构成"交付"；②**合同无效/被撤销**（§20）；③**遗失物/赃物/埋藏物**；④特殊动产 §19 交付即满足（登记仅对抗）。完整做题步骤见 📐 [[民法-物权-善意取得模型]]，概念层见 [[善意取得]]。
- **遗失物 §312-314**：原则**不适用**善意取得；权利人 **2 年内**可向受让人请求返还；从拍卖/经营者处购得须**有偿回赎**（先付费后追偿）；盗赃物准用。详见 [[遗失物]]。
- **添附 §322**（民法典新增制度，新增即受关注）：加工 / 附合 / 混合取得物权——归属顺序 **约定 > 法律规定 > "物尽其用 + 保护无过错方"**；取得方造成他方损失应赔偿/补偿（与不当得利、债法合考）。详见 [[添附]]。

## 怎么考 / 坑在哪（全章 Top 陷阱）

1. **善意取得四大不适用**（§311 簇）——占有改定 / 合同无效撤销 / 遗失物赃物 / 特殊动产交付即可，命题人最爱（详见 📐 [[民法-物权-善意取得模型]]）。
2. **业主表决 §278 的分母**——是"参与表决"的业主，**不是全体业主**；"双过半 → 四分之三"两档别记反。
3. **相邻关系 ↔ 地役权**——法定/无偿/不登记 ↔ 约定/可有偿/登记对抗，对比命题高频。
4. **共有处分的多数决** §301——**按份 2/3、共同全体一致**；按份"随时分割"vs 共同"须重大理由"。
5. **孳息归属 §321**——天然孳息用益物权人优先于所有权人；法定孳息约定优先。
6. **用益物权无处分权能**——所有权四权能齐全，用益物权只有占有·使用·收益（§323 辨析点）。
