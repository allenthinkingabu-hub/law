# 中介合同

> **报告订约机会 / 媒介订约** — 原"居间合同"，2021 改名

## 法条范围

[[民法典]] §961-§966（6 条）

## 是什么 / 易混

### 定义
**§961**：中介人**向委托人报告订约机会**或**提供订约媒介服务**，委托人**支付报酬**的合同。

### 五大核心规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **促成才付酬** | 中介人**促成合同成立** → 委托人付酬 | §963 |
| **未促成 + 必要费用** | 未促成 → **不付报酬**，但可请求必要费用 | §964 |
| **媒介双方报酬均分** | 双方都委托 → 报酬由合同当事人**平均**负担 | §963 |
| **跳单条款有效** | 委托人擅自跳过中介与他人订约 → 仍付报酬 | §965 |
| **隐瞒重要事实** | 中介人**故意隐瞒 / 虚假** → **不付酬 + 赔偿** | §962 |

### 三类合同对比（委托 / 行纪 / 中介）
| 维度 | [[委托合同]] | [[行纪合同]] | **[[中介合同]]** |
|---|---|---|---|
| 行为 | 处理事务 | 以自己名义买卖 | **报告 / 媒介**（仅牵线）|
| 是否合同方 | 否（代理）| 是 | **否**（仅牵线）|

## 怎么考 / 坑在哪

### 三大陷阱

1. **未促成无报酬**：中介只在**促成**时有报酬权（§963）
2. **双方都委托 → 报酬平均**：实务中房屋中介常考——卖方 + 买方都委托同一中介
3. **跳单条款**：很多人误以为不能约定，实际**有效**（§965）

## 怎么答

主观题分析框架：
1. **定性**：是否仅提供"报告 / 媒介"？
2. **是否促成**？促成 → 付酬；未促成 → 仅必要费用
3. **报酬负担**：单方委托 → 委托方付；双方委托 → 均分
4. **跳单**：是否构成 + 报酬如何
5. **故意隐瞒 / 虚假**：不付酬 + 赔偿
