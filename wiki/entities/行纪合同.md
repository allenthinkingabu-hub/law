# 行纪合同

> **以行纪人自己名义**为他人买卖 — 与 [[委托合同]] / [[中介合同]] 三足鼎立

## 法条范围

[[民法典]] §951-§960（10 条）

## 是什么 / 易混

### 定义
**§951**：行纪人**以自己名义**为委托人**从事贸易活动**，委托人**支付报酬**的合同。

### 四大核心规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **以自己名义** | 行纪人是合同**当事人**（非代理人）| §951 |
| **费用自负** | 行纪人处理委托事务支出的费用**自负**（除非约定）| §952 |
| **高 / 低价处理** | 高于约定价卖 / 低于约定价买 → **利益归委托人** | §955 |
| **直接享有权利义务** | 行纪人与第三人订约 → 行纪人**直接**受权利义务 | §958 |

### 三类合同对比（委托 / 行纪 / 中介）
| 维度 | [[委托合同]] | **[[行纪合同]]** | [[中介合同]] |
|---|---|---|---|
| 行为 | 处理事务 | 以**自己名义**买卖 | 报告 / 媒介 |
| 是否合同方 | 否 | **是** | 否 |
| 报酬 | 可有可无 | **必有偿** | **必有偿** |

## 怎么考 / 坑在哪

### 三大陷阱

1. **以自己名义** vs **以委托人名义**：行纪人是**自己**作为合同方（C2-单选-14 / 15）
2. **高于约定价利益归委托人**（§955）—— 不是平均分
3. **直接受权利义务**：行纪人与第三人订约 → 第三人**找行纪人**，不找委托人

## 怎么答

主观题分析框架：
1. **定性**：以谁的名义？（行纪人自己 = 行纪）
2. **费用 / 报酬**：按约定 / 法定
3. **高 / 低价处理**：差价归委托人
4. **与第三人关系**：行纪人直接担责
5. **委托人介入**：是否符合法定情形
