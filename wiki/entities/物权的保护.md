# 物权的保护

> [[民法典]] 物权编 第一分编·通则·**第三章（§233-§239）**。核心是"**物权妨害双救济**"——**物权请求权**（恢复圆满状态，面向将来）＋**侵权损害赔偿请求权**（填补已发生损失，面向过去），依 **§239** 可单独适用、也可**合并适用**。

## 法条范围

[[民法典]] **§233-§239**（物权的保护）+ 关联 **§196**（诉讼时效不适用情形，见 [[诉讼时效]]）、**§1165**（侵权过错责任）。

> 🔎 **已联网核实（2026-06-14）**：§233-§239 经最高法 court.gov.cn + 政府门户三路逐字核对，§196 经最高检 + 国家法律法规数据库核对，全 CONFIRMED。

## 是什么 / 易混

### 一、双救济：两条性质不同的轨道（核心命门）

| 维度 | ① **物权请求权**（物上请求权） | ② **侵权损害赔偿请求权** |
|---|---|---|
| 法条 | 返还原物 **§235** · 排除妨害/消除危险 **§236** | **§238**（引致）→ 侵权编 **§1165** |
| 功能 | 恢复物权**圆满状态**（面向将来·预防＋回复） | **填补已发生损失**（面向过去） |
| **过错** | **不要**（有无权占有/妨害状态即可） | **要**（一般过错责任 §1165） |
| 需否证明损害 | **不需要** | **需要**（有损害才赔） |
| **诉讼时效** | 原则**不适用**（§196）＊ | **适用 3 年**（§188） |
| 性质 | 物权效力的体现（绝对权请求权） | 债权请求权（侵权之债） |

> ＊**头号陷阱**：返还原物的时效豁免**只限**"不动产物权 + 已**登记**动产物权"（§196②）；**未登记动产**的返还原物请求权**仍受 3 年时效**约束（§196 反对解释）。而**排除妨害 / 消除危险 / 停止侵害**——一律不适用时效，不分动产不动产、不分是否登记（§196①）。

### 二、五大保护方法地图（§234-§238）+ 谁才是"真·物权请求权"

| 法条 | 保护方法 | 性质 |
|---|---|---|
| §234 | **确认**物权（归属 / 内容争议） | 确认之诉（≠给付，一般不适用时效） |
| **§235** | **返还**原物（无权占有） | ✅ 真·物权请求权 |
| **§236** | **排除妨害 / 消除危险**（妨害或"**可能妨害**"） | ✅ 真·物权请求权 |
| §237 | **修理 / 重作 / 更换 / 恢复原状**（毁损） | ⚠️ 性质有争议（见"坑在哪"） |
| §238 | **损害赔偿** + 承担其他民事责任 | 债权请求权（侵权） |

→ 真正的"**物权请求权（三兄弟）**"＝**返还原物 §235 + 排除妨害 §236 + 消除危险 §236**；§238 损害赔偿是债权请求权。

### 三、双救济并用的依据 = §239（不是 §238）

- **§238** 是损害赔偿请求权**本身**的依据（两个"依法"＝引致到侵权责任编，非独立请求权基础）。
- **§239** 才是"可单独 / 可**合并**适用"的依据 → **双救济并用**的法源。
- **通说层次**：**物权请求权优先、损害赔偿补充**——能靠返还 / 排除完全救济且未造成损害的，不动损害赔偿；已造成损害的，§239 把两者**合并适用**。
- 🚗 **例子**：邻居在你院里**堆杂物**砸坏花坛 → **同时**主张 **排除妨害**（搬走，§236 物权请求权）**＋ 损害赔偿**（赔花坛，§238 侵权），二者并行不悖（§239）。

## 怎么考 / 坑在哪

1. **时效一刀切** —— "物权请求权一律不适用时效"是**错**的；**未登记动产返还**仍受 3 年时效（§196 反对解释）。
2. **过错互换** —— "主张返还 / 排除妨害需对方有过错"或"损害赔偿无须过错"——**全错**；物权请求权不问过错，§238 损害赔偿要过错。
3. **§237 性质（进阶）** —— §237 特意加"**依法**"二字，**法考 / 教培主流**当**引致性规范 → 债权请求权 → 需过错、适用 3 年时效**；命题人爱设"恢复原状=物权请求权、不适用时效"的错误项。
   - 🔎 **诚实标注争议**：学理上王利明等主张恢复原状是"独立物权请求权"（不以过错为要件），**但同一学者也承认它适用 3 年时效**——故无论哪说，"§237 不适用时效"都是错的；法考按"债权请求权倾向 + 适用时效"作答更稳。
4. **确权 vs 返还** —— §234 确认物权是**确认之诉**（解决"归谁所有"，一般不适用时效）；§235 返还是**给付之诉**（解决"该不该还"）。别混。
5. **§233 当请求权** —— §233 只是纠纷解决"**途径**"（和解 / 调解 / 仲裁 / 诉讼），**不是**一种保护方法 / 请求权。
6. **消除危险要件** —— 针对"可能妨害 / 有被妨害之虞"，**无须实际损害已发生**；"已造成损害才能主张消除危险"——错。

## 怎么答

客观题判断四步：
1. **是不是真物权请求权**？（返还 §235 / 排除妨害·消除危险 §236＝是；确认 §234、修理恢复 §237、损害赔偿 §238＝否）
2. **要不要过错**？物权请求权不要；损害赔偿（§238/§1165）要。
3. **适不适用时效**？排除妨害 / 消除危险一律不适用；返还原物**仅不动产 + 已登记动产**不适用、**未登记动产适用** 3 年；损害赔偿适用 3 年。
4. **能不能并用**？同一妨害可"物权请求权 + 损害赔偿"**合并适用**（§239）。

## 真题示例

- [[物权编-多选-01]]（2013-3-55 · 答 **ABC**）：装修扰邻——排除妨害可向**所有权人（叶某）+ 直接侵权人（沈某）双向**主张（A、B 对）；排除妨害**不适用诉讼时效**（C 对，§196①）；仅"经常失眠"不满足 §1183**严重精神损害** → 精神损害赔偿不选（D 错）。
- [[物权编-多选-02]]（2010-3-54 · 答 **AC**）：足球落井——球仍属小贝，小贝享**返还原物物权请求权 §235**（A 对）；老马对球无物权、不能主张物权请求权（B 错）；摔碎花瓶 → 老马有**侵权损害赔偿债权请求权 §1165**（C 对）；因拾得而占有与花瓶赔偿债权**非同一法律关系** → **不能留置 §448**（D 错）。体现"**物权请求权与债权请求权可并存**"。

## 📐 口诀

> **物权挨了妨害，两条路一起走（§239 合并适用）：**
> **一条"物权请求权三兄弟"——返还原物、排除妨害、消除危险（§235/§236），不问过错、不证损害、原则不罹时效；**
> **一条"损害赔偿"——§238 引致侵权，要过错、要损害、三年时效躲不掉。**
> **五大方法"确·返·排（消）·修·赔"；§233 只是路、§234 是确权，别当请求权填。**
> **时效记死：不动产＋登记动产返还不受时效拦，未登记动产返还三年要算；恢复原状（§237）依法引致、照样三年。**
