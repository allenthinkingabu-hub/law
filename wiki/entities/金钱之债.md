# 金钱之债

> **"欠钱"** — 以支付一定数额金钱为标的的债。**最特殊的 [[种类之债]]**：钱是终极种类物，永不"履行不能"，故**欠钱必还、天灾不免**。

## 法条范围

[[合同编]] §514（以法定货币履行）+ **§579（金钱债务继续履行 · 无例外）** vs **§580（非金钱债务继续履行 · 三例外）** + §568-§569（抵销）+ §590（不可抗力）+ 学理

> ⚠️ 本页由 [[种类之债]]、[[债的分类]] 及真题 [[C1-单选-75 · 不可抗力不免金钱债务]] 结晶而成，补足"金钱之债"长期无独立实体页的结构空白。

## 是什么 / 易混

### 核心定义（超简单版）

> **金钱之债（= 货币之债 / 金钱债务）= 以"支付一笔钱"为内容的债。** 说白了就是"**欠钱**"——债务人该给债权人付一个**数额**。

关键：金钱之债**只认"数额"，不认"具体哪几张钞票"**。

### 身份：最特殊、最极端的「种类之债」

钱是世界上**可替代性最强**的东西——任何一张百元钞和另一张百元钞完全等价。所以金钱之债是 [[种类之债]] 的"终极版"：

| 你欠的东西 | 是不是"那一个特定的"？ | 类型 |
|---|---|---|
| 那辆京 A12345 二手车 | 是，独一无二 | 特定物之债（简单之债） |
| 100 公斤五常大米 | 不是，哪 100 公斤都行 | 种类之债 |
| **1 万元** | **不是，给你哪 10 张 1000 的都一样** | **金钱之债（终极种类物）** |

> 去银行取 1 万，柜员给 10 张 1000 还是 100 张 100 你都无所谓——你要的是**那个数额**，不是**那几张特定的钞票**。

### 按"标的性质"二分：金钱之债 vs 非金钱之债

债按标的性质分两大类——这是**最顶层的分类**：

```
                    债（按标的"性质"）
                          │
          ┌───────────────┴───────────────┐
          ▼                                ▼
      金钱之债                          非金钱之债
   （标的 = 钱）                    （标的 ≠ 钱：物 / 劳务 / 工作成果 / 不作为）
          │                                │
   永不履行不能                     可能履行不能 → 不可抗力可能免责
   继续履行无例外(§579)            继续履行有 3 例外(§580)
```

- **金钱之债** = 标的是钱（还款、付价款、付租金、付报酬、付利息、赔钱）
- **非金钱之债** = 标的**不是钱**的一切债：
  - 给付**特定物**（交那辆车、那套房）
  - 给付**种类物**（交 100 吨大米）
  - 提供**劳务**（家教、演出、看病、运输）
  - 完成**工作成果**（装修、盖房、写程序）
  - **不作为**（竞业禁止——约定不开同类店）

## 💰 金钱之债的 4 个"特异功能"（考点所在）

### ① 永远不会"履行不能"（最重要 · 90% 考点在这）

普通的债可能因"东西没了"而**履行不能**——你买的那辆特定二手车被雷劈了，卖家真的没法交，债消灭。**但金钱之债永远不会。** 钱是"终极种类物"：印钞机能印、银行能调度、没现金还能执行你的房车工资。法律上认为"**钱永远给得出**"。

> ⚠️ 铁律：**"没钱还" ≠ "履行不能"**
> "我现在拿不出钱"只是**暂时没有偿还能力**——这是**执行层面**的问题（法院可查封拍卖你别的财产），**不消灭这笔债**。

**老王小李例子**：小李借老王 10 万买货车，货车被泥石流埋了。
→ 车没了，但**这 10 万的债一分不少，照还**。（车的灭失是车的事，跟欠的钱无关）

### ② 不可抗力一般免不了金钱之债（[[C1-单选-75 · 不可抗力不免金钱债务]] 的命门）

不可抗力（§590）免的是"**因天灾干不成的活**"（不能履行的给付义务）。但金钱之债**根本不存在"不能履行"**，所以——

> **天灾免得了"交货 / 交房 / 演出"，免不了"欠的钱"。**

**老王小李例子（即该真题原型）**：张某贷款 80 万买房，房子被洪水冲毁。
→ 房子（抵押物）没了 ≠ 借款合同没了。还钱的债**不因房子被冲毁而消灭**。
**实务印证**：上海高院涉疫问答——信用卡、房贷、融资租赁等"**以金钱给付为内容的合同**"，**一般不能以疫情属不可抗力为由减免还款责任**。

### ③ 抵销无障碍（钱和钱随时对冲）

同种货币的金钱之债可随时**[[抵销]]**（§568 法定抵销）。

**老王小李例子**：老王欠小李 5 万，小李恰好也欠老王 3 万。
→ 不用各还各的，直接对冲：**老王只需再给小李 2 万**就两清。（换成"我欠你一头牛、你欠我一袋米"就没这么简单）

### ④ 风险特殊：钱在路上丢了仍要补

普通买卖里货交出去风险就转移了；但金钱之债里，**钱没真正到债权人手里，债就没还清**。

**老王小李例子**：小李网银转账还款，转错账户 / 中途故障没到账。
→ 对老王来说**小李还没还钱**，债还在，小李**还得再付一次**（错转的钱另案追回）。

## 🆚 金钱之债 vs 非金钱之债 · 完整对照（高频考点）

| 维度 | **金钱之债** | **非金钱之债** |
|---|---|---|
| **标的** | 钱（数额） | 物 / 劳务 / 工作成果 / 不作为 |
| **会不会履行不能** | ❌ **永不**履行不能 | ✅ **可能**（标的灭失 / 无法完成） |
| **不可抗力能否免责** | ❌ 一般**不免**（钱总给得出） | ✅ **可能免**（§590，按影响部分/全部） |
| **继续履行（强制实际履行）** | 必须履行，**无例外**（§579） | 原则可请求，**但有 3 例外**（§580） |
| **§580 三例外** | — | ①法律上/事实上不能履行 ②标的不适于强制履行或费用过高 ③债权人合理期限内未请求 |
| **典型法条** | §514 / §579 / §568 | §580 |
| **典型真题** | [[C1-单选-75 · 不可抗力不免金钱债务]] | [[合同通则-多选-14]]（继续履行不予支持的情形） |

> 🔑 **§579 vs §580 是这组对照的灵魂**：
> **§579（金钱债务）**——欠钱就得还，**没有任何例外**，法院判了直接强制执行。
> **§580（非金钱债务）**——原则上能请求对方"接着干"，但碰上"干不了 / 不值得强制 / 你太晚才要"三种情形之一，就**不能强制实际履行**，只能转为赔钱。
> 一句话：**钱永远"还得了"，所以法律对金钱之债最不留情。**

## 怎么考 / 坑在哪

### 五大陷阱

1. **"没钱还 = 债消灭"** —— 错！无偿还能力是**执行**问题，债**不消灭**（金钱之债无履行不能）。
2. **"天灾 / 不可抗力一来，什么债都免"** —— 错！免的是"干不成的活"，**金钱之债免不了**（[[C1-单选-75 · 不可抗力不免金钱债务]]）。
3. **"抵押物 / 标的物没了，欠的钱也没了"** —— 错！担保物灭失只影响担保（§390 物上代位），**主债权独立存续**。
4. **"§580 三例外也能套到欠钱上"** —— 错！三例外**只管非金钱之债**；欠钱走 §579，**无例外**（[[合同通则-多选-14]]）。
5. **"金钱债权约定不得转让就真不能转"** —— 错！金钱之债流通性强，约定"不得转让"**不能对抗善意第三人**，债权仍可转（[[合同通则-单选-55]]）。

### 📐 答题口诀

```
一看标的是不是钱：
  是钱 → 金钱之债 → 永不履行不能、天灾不免、§579 无例外
  不是钱 → 非金钱之债 → 可能履行不能、不可抗力可能免、§580 三例外

"没钱还"只是执行问题，不消灭债！
"抵押物没了"只动担保，不动主债权！
```

## 🎯 一句话记忆

> **"金钱之债 = 欠钱 = 最特殊的种类物之债。"**
> **"钱永远给得出 → 欠钱必还、天灾不免、没钱也只是改执行别的财产，债不消灭。"**
> **"§579 欠钱无例外，§580 非金钱才有三例外。"**

这正是法考铁律 **"金钱债务不发生履行不能"** 的全部来历。
