# 债的分类

> [[债]] 的**多维度分类体系** — 按标的(数量 / 性质)+ 按主体(人数 / 关系)+ 按效力(附条件 / 期限)

## 法条范围

[[合同编]] §515-§517(选择之债)+ §517-§520(连带之债)+ §158(附条件)+ 学理

## 是什么 / 易混

### 🌳 完整分类树

```
                              [[债]]
                                │
        ┌───────────────────────┼───────────────────────┐
        ▼                                                ▼
    按"标的"分类                                  按"主体"分类
        │                                                │

   ▼    ▼    ▼                                  ▼               ▼
简单之债 选择之债 种类之债                      单一之债      多数人之债
  1 个   多择 1   种类内                        一对一               │
                                                            ┌──────┴──────┐
                                                            ▼              ▼
                                                        按份之债       连带之债
                                                        各负份额       任一全责
```

→ 还有第三维度:**按效力** — 附条件之债 / 附期限之债 / 一般之债

### 🔑 5 种典型债的核心特征

| 类型       | 维度  | 核心特征            | 法条        |
| -------- | --- | --------------- | --------- |
| **简单之债** | 按标的 | 标的**单一**确定      | 默认        |
| **选择之债** | 按标的 | 多个特定标的,**择一履行** | §515-§517 |
| **种类之债** | 按标的 | **同种类**物,内任取    | 学理 + §595 |
| **按份之债** | 按主体 | 多人**各负各份额**     | §517      |
| **连带之债** | 按主体 | 多人,**任一负全部**    | §518-§521 |

### ⚠️ 维度陷阱(高频考点)

Q04 的经典陷阱:**4 个选项故意分别来自不同维度!**

```
A 种类之债 → 按"标的种类"
B 选择之债 → 按"标的数量" ⭐ Q04
C 连带之债 → 按"主体关系"  ← 维度陷阱!
D 简单之债 → 按"标的数量"
```

→ 不识别维度差异 = 容易翻车

## 🚗 5 种债 · 老王小李故事全集

### 故事 ①:简单之债(默认 / 最常见)

> 老王借小李 **12 万**。

法律分析:
- 标的:**12 万人民币**(单一确定)
- → **简单之债**(没有任何特殊规则,适用一般给付规则)

### 故事 ②:选择之债(Q04 类型)

> 老王对小李说:"**考上研究生**,我送你**一套别墅或一辆汽车**!"小李同意。一年后小李考上了。

法律分析:
- 标的:**别墅** OR **汽车**(两个**特定物**,择一履行)
- → **选择之债**(§515-§517)
- 此时**选择权默认归老王**(债务人)
- 详见 [[选择之债]]

### 故事 ③:种类之债(易混 A)

> 老王卖给小李 "**100 吨优质东北大米**"。

法律分析:
- 标的:**符合品质的 100 吨大米**(同种类内**任意可替代**)
- → **种类之债**
- 任何 100 吨符合规格的大米都能履行
- **关键测试**:"卖家能不能给我类似的另一份?" → 能 → 种类之债

⚠️ **选择之债 vs 种类之债 关键区分**:
- **选择之债** = 几个**特定物**之间选(别墅 / 汽车)
- **种类之债** = 一类东西里**任取**(任何符合规格的大米)

⚠️ **特殊规则**:
- "**种类物不灭失**" — 仓库烧了卖家**不能免责**,必须重新采购!
- **特定化**是种类之债转特定物之债的关键时点(决定风险归属)
- 货币之债 = 最特殊的种类之债(钱永不履行不能)

→ 详见 [[种类之债]] 实体页 4 大形象例子(大米 / 矿泉水 / 钱 / 手机)+ 老王小李大米故事

### 故事 ④:连带之债(易混 C · 主体维度!)

> 老王和老张合伙开店,**共同**借小李 12 万。

法律分析:
- 这是**主体**形态(两个债务人),**不是标的形态**!
- 小李可向**老王 或 老张任一**主张**全额 12 万**
- → **连带之债**(§518)
- 老王代还后,可向老张追偿其份额

⚠️ **C 选项陷阱**(Q04):
- 题干甲、乙各 1 人 → **主体单一** → 不可能是连带之债
- 不要被"或"字误导以为是连带

### 故事 ⑤:按份之债(连带的对照)

> 老王和老张借小李 12 万,**约定老王还 8 万、老张还 4 万**。

法律分析:
- 各负各的份额(8 万 + 4 万)
- → **按份之债**(非连带)
- 老张破产 → 小李不能向老王追讨老张那 4 万

### 故事 ⑥(附加):附生效条件之债(Q04 还藏着这个!)

> "**如果你两年内考上研究生**,我愿赠..."

法律分析:
- 这是 **§158 附生效条件的合同**
- 合同**已成立**,但**未生效**(条件未成就)
- 条件成就(考上) → **合同才生效** → 进入选择之债阶段
- 详见 [[合同未生效]]

## 怎么考 / 坑在哪

### 五大陷阱

1. **维度混淆**:选项故意混维度(Q04 ABCD)→ 看维度
2. **选择 vs 种类**:特定物 vs 同种类内任取
3. **连带 vs 按份**:任一全责 vs 各负各份
4. **连带 vs 选择 vs 种类**:连带是**主体**形态,其他是**标的**形态
5. **附条件赠与**:成立 ≠ 生效(§158 + §157)

### 📐 答题口诀:债的分类三步走

```
Step 1:看标的(数量 / 性质)
  - 1 个 → 简单之债
  - 多个特定物择 1 → 选择之债 ⭐
  - 同种类内任取 → 种类之债

Step 2:看主体(人数 / 关系)
  - 一对一 → 单一之债
  - 多对一/一对多 + 各负各份 → 按份之债
  - 多对一/一对多 + 任一全责 → 连带之债

Step 3:看条件(成立 vs 生效)
  - 附生效条件 → §158(条件成就才生效)
  - 附解除条件 → 条件成就时消灭
```

## 🎯 一句话记忆

> **"按标的分:1 个简单 / 多择 1 选择 / 同种类种类"**
> **"按主体分:一对一单一 / 多人按份 / 多人连带"**
> **"4 选项故意混维度,先识别维度再判断!"**
