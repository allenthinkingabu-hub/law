# 建设工程合同

> [[承揽合同]] 的**特殊类型**：大型工程 + **要式 + 招投标 + 工程款优先受偿权**

## 法条范围

[[民法典]] §788-§808（21 条）+ 建设工程司法解释

## 是什么 / 易混

### 定义
**§788**：承包人**进行工程建设**，发包人**支付价款**的合同。包括**勘察 / 设计 / 施工**三类合同。

### 关键特征
| 特征 | 内容 | 法条 |
|---|---|---|
| **要式** | 应当采用**书面**形式 | §789 |
| **招投标** | 大型工程需依法招投标 | §789 |
| **质量保修** | 工程在合理使用寿命内**保修**| §801 |
| **工程款优先受偿权** | 承包人对工程**折价 / 拍卖款**有**优先受偿**权（>普通债权，<已登记抵押权）| §807 |

### 三类合同
| 类型 | 内容 |
|---|---|
| **勘察合同** | 地质 / 水文勘察 |
| **设计合同** | 工程设计 |
| **施工合同** | 实际施工 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **是要式合同**（C2-单选-10）—— 非要式问题中排除建设工程
2. **工程款优先受偿权**：优于普通债权，**等于**已登记抵押权（具体顺位看司法解释）
3. **实际施工人**：违法转包 / 分包时，实际施工人对发包人在欠付工程款范围内**有权主张**

## 怎么答

主观题分析框架：
1. **定性**：是哪类工程合同？
2. **形式**：是否书面？是否依法招投标？
3. **质量**：是否合格？保修期内？
4. **欠款**：行使工程款优先受偿权
5. **实际施工人**：是否有特殊请求权
