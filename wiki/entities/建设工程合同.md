# 建设工程合同

> [[承揽合同]] 的**特殊类型**：大型工程 + **要式 + 招投标 + 工程款优先受偿权**

## 法条范围

[[民法典]] §788-§808（21 条）+ 建设工程司法解释

## 是什么 / 易混

### 定义
**§788**：承包人**进行工程建设**，发包人**支付价款**的合同。包括**勘察 / 设计 / 施工**三类合同。

### 关键特征
| 特征 | 内容 | 法条 |
|---|---|---|
| **[[要式合同|要式]]** | 应当采用**书面**形式 | §789 |
| **招投标** | 大型工程需依法招投标 | §789 |
| **质量保修** | 工程在合理使用寿命内**保修**| §801 |
| **[[工程款优先受偿权]]** | 承包人对工程**折价 / 拍卖款**有**优先受偿**权（**优于抵押权** > 普通债权；但劣后于居住+全款的商品房消费者）| §807 / 建工解释一 §36 |

### 三类合同
| 类型 | 内容 |
|---|---|
| **勘察合同** | 地质 / 水文勘察 |
| **设计合同** | 工程设计 |
| **施工合同** | 实际施工 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **是要式合同**（C2-单选-10）—— 非要式问题中排除建设工程
2. **工程款优先受偿权**：**优于**已登记抵押权（建工解释一 §36，哪怕抵押先登记）；但**劣后于**居住 + 全款的商品房消费者（法释〔2023〕1 号 §2「超级优先权」）。范围仅工程价款本身、不含利息违约金（§40）；期限"应当给付价款之日起合理期限最长 18 个月"（§41，**非"竣工 6 个月"旧法**）
3. **实际施工人**：违法转包 / 分包时，实际施工人对发包人在欠付工程款范围内**有权主张**（建工解释一 §43，法院**应当**追加转包/分包人为**第三人**）；但实际施工人**不享有**工程款优先受偿权（主体限直接承包人 §35）

## 怎么答

主观题分析框架：
1. **定性**：是哪类工程合同？
2. **形式**：是否书面？是否依法招投标？
3. **质量**：是否合格？保修期内？
4. **欠款**：行使工程款优先受偿权
5. **实际施工人**：是否有特殊请求权
