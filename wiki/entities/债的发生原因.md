# 债的发生原因

> **4 大类**：合同 / 侵权 / 无因管理 / 不当得利

## 法条范围

[[总则编]] §118；[[合同编]] §463、§979、§985；[[侵权责任编]] §1165

## 是什么 / 易混

### 4 大发生原因

| 原因       | 性质                | 章节                | 法条      |
| -------- | ----------------- | ----------------- | ------- |
| **合同**   | **法律行为**（合意）      | [[合同编]] 总则 + 典型合同 | §463 起  |
| **侵权**   | **事实行为**（违法行为）    | [[侵权责任编]]         | §1165 起 |
| **无因管理** | **事实行为**（合法管事）    | [[合同编]] 准合同       | §979 起  |
| **不当得利** | **事件 / 事实**（法律拟制） | [[合同编]] 准合同       | §985 起  |

### 行为 vs 事件分类

| 分类 | 包含 |
|---|---|
| **行为**（人的意志）| 合同（法律行为）、侵权 / 无因管理（事实行为）|
| **事件**（不依意志）| 不当得利、自然事实（出生 / 死亡）等 |

→ **不当得利属"事件 / 法律规定的事件"**——这是 C3-单选-01 的考点。

### 与 [[请求权基础]] 的关系
4 大请求权基础对应 4 大债的发生原因：
1. **合同请求权** ← 合同
2. **物权请求权 / 侵权请求权** ← 侵权
3. **不当得利返还请求权** ← 不当得利
4. **无因管理偿还请求权** ← 无因管理

## 怎么考 / 坑在哪

### 三大陷阱

1. **不当得利是"事件"**：源头虽有人为，但债的发生是**法律拟制**
2. **侵权 + 不当得利可竞合**：受损方可择一
3. **4 大请求权基础**对应 4 类原因
