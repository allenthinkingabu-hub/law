# 继续履行

> [[违约责任]] 承担方式之一 — **金钱债务必履行；非金钱债务有 §580 限制**

## 法条范围

[[合同编]] §579、§580、§581

## 是什么 / 易混

### 两大规则

#### §579 金钱债务
**§579**：当事人一方**未支付价款 / 报酬 / 租金 / 利息**等金钱债务 → 对方可请求其**继续履行**。

→ **金钱债务必履行**：无 §580 限制空间。

#### §580 非金钱债务
**§580**：当事人**一方不履行非金钱债务 / 履行不符合约定**，对方可请求履行——**但有下列情形除外**：
1. **法律上 / 事实上**不能履行
2. **不适于强制履行 / 履行费用过高**
3. 债权人在**合理期限内**未请求履行

### §581 责任竞合
**§581**：当事人**不履行非金钱债务**或履行**不符合约定** + **不能履行 / 履行费用过高**——对方**可请求承担违约责任**（如赔偿损失 / 违约金）。

→ 即使不能继续履行，仍可要求**其他违约责任**。

## 怎么考 / 坑在哪

### 三大陷阱

1. **A 经典陷阱**：以为"非金钱债务"本身就是不予支持的理由——错。§580 仅在**有除外情形**时才不予支持
2. **D 经典陷阱**：以为"已付违约金 / 损失赔偿"就代替继续履行——错。**可并存**
3. **金钱债务无 §580 限制**：必须继续履行

### 主观题分析
1. 是金钱债务 → 必继续履行（§579）
2. 是非金钱债务 → 是否构成 §580 三种例外？
3. 即使继续履行不能，仍可主张其他责任（§581）
