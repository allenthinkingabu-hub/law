# 法考主观题

> [[国家统一法律职业资格考试]] 第二阶段；满分 180 / 合格 108。

## 简介

法考主观题是 [[国家统一法律职业资格考试]] 的第二阶段，须先通过 [[法考客观题]] 才能参加。

## 关键信息

- **满分**：180
- **合格线**：108
- **形式**：案例分析 + 论述
- **考查范围**：7 个科目

## 详细内容

### 考查 7 科

| 科目 | 主观题形式 |
|---|---|
| 法治理论（含 [[习近平法治思想]] + [[法理学]]） | 论述题 |
| [[刑法]] | 案例分析 |
| [[民法]] | 案例分析 |
| [[刑事诉讼法]] | 案例分析 |
| [[民事诉讼法]] | 案例分析 |
| [[商法]] | 案例分析 |
| [[行政法与行政诉讼法]] | 案例分析 |

### 备考要点

- [[民法]] 是大案例核心来源；分析框架用 [[请求权基础]]（合同 / 物权 / 侵权 / 不当得利）
- [[刑法]] 必考
- [[习近平法治思想]] 论述题必考、权重高
- [[法理学]] 与习近平法治思想常合考
