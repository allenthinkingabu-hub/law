# 扭送

> [[刑事拘留]] 前站的**公民权利行为** — "**扭住 + 立即送交**，是'送'不是'拘'"（刑诉法 §84）

## 法条范围

《刑事诉讼法》**§84**（2018 现行法）

> 🔎 **法条已核实（2026-07-02，随母模型一并核对）**：对下列人员，**任何公民**都可以**立即扭送**公安机关、人民检察院或者人民法院处理——
> ① 正在实行犯罪或者在犯罪后即时被发觉的（**现行犯**）；
> ② 通缉在案的；
> ③ 越狱逃跑的；
> ④ 正在被追捕的。

## 是什么 / 翻成人话

**扭送＝普通老百姓把符合法定四种情形的人，当场"扭住 + 立即送交"公检法处理。**

三个关键点，做题时对号：

| 要点 | 说明 |
|---|---|
| **谁能扭** | **任何公民**都可以（不限于警察）——是法律给公民的**权利**，不是义务 |
| **能扭谁**（四种人） | ①**现行犯**（正在实行 / 犯罪后即时被发觉）；②**通缉**在案；③**越狱**逃跑；④正在**被追捕** |
| **扭了干嘛** | **立即送交**公检法——重点在"送"，不在"关"；到案后是否拘留由**公安另行依法决定** |

**一句话本质**：扭送是"**送**"不是"**拘**"；它不是强制措施（强制措施是国家机关的权力），是公民的**权利行为**。

## 怎么考 / 坑在哪

### 三大辨析

| 对比项      | 扭送（§84）                | 刑事拘留（§82）          | 非法拘禁          |
| -------- | ---------------------- | ------------------ | ------------- |
| **主体**   | 任何公民                   | 公安（检自侦特例检察院）       | 任何人（无权限）      |
| **性质**   | 公民权利行为                 | 刑事强制措施             | 犯罪行为          |
| **对象**   | 现行 / 通缉 / 越狱 / 被追捕 四种人 | 现行犯 / 重大嫌疑分子 + 七情形 | ——            |
| **核心动作** | 扭住后**立即送交**            | 依法**羁押**           | 非法**关押、限制自由** |

### 做题眼

1. **"扭住送派出所"≠ 非法拘禁**：符合四情形、且**立即送交**的，是合法扭送。
2. **扭送不占拘留时限**：扭送、路上押送、到案等待处置的时间**不计入拘留期限**；拘留时限自**公安决定并执行拘留时**起算。
3. **抓错对象 / 关着不送 → 掉进非法拘禁**：只是"怀疑上周可能是他偷的"（非现行犯），或扭住后**私自关押**逼债，均不受扭送保护。

## 数字案例

- **成立扭送 ✅**：张三在超市行窃被顾客李四当场撞见（**现行犯**），李四扭住张三押送至派出所交给民警 → 合法扭送，李四不构成非法拘禁；此后公安**另行决定**是否刑事拘留，拘留时限自公安决定执行时起算。
- **不成立 ❌**：李四抓住张三后不送派出所，反把张三**关在自家地下室三天**逼其还钱 → 无"立即送交"，构成**非法拘禁**。

## 非法拘禁（扭送越界的反面）

> 扭送是"送"，非法拘禁是"关不放"——**同一个动作（扭住、控制人身），差别只在"有没有立即送交＋对象对不对"**。这是命题人给扭送埋的头号反向坑。深挖归 [[刑法-分论-人身自由犯罪模型]]（§238），此处只做界限与高频坑。

### 是什么（刑法 §238）

**非法拘禁罪＝非法拘禁他人，或以其他方法非法剥夺他人人身自由。**

> ⚠️ **诚实标注（MEDIUM）**：§238 条文表述凭记忆概括，量刑档位以正式文本为准——一般处 3 年以下；**致人重伤** 3–10 年、**致人死亡** 10 年以上；**使用暴力**致人伤残、死亡的，转化按**故意伤害罪 / 故意杀人罪**定罪；国家机关工作人员利用职权犯本罪**从重**。

### 扭送 vs 合法拘留 vs 非法拘禁（三方界限）

| 对比项 | 扭送（§84 刑诉法） | 刑事拘留（§82 刑诉法） | **非法拘禁（§238 刑法）** |
|---|---|---|---|
| **谁在关** | 任何公民 | 公安（检自侦特例检察院） | **任何人，无合法权限** |
| **性质** | 公民权利行为 | 刑事强制措施 | **犯罪** |
| **对象** | 现行/通缉/越狱/被追捕 | 现行犯/重大嫌疑分子＋七情形 | **任何被非法剥夺自由的人** |
| **核心动作** | 扭住后**立即送交** | 依法**羁押** | **非法关押、持续剥夺自由** |
| **越界即坠入** | 不送交/抓错对象 → 非法拘禁 | 超期、私设关押点 → 非法拘禁 | —— |

### 高频坑（做题眼）

1. **索债型也算**：即使是**合法债务**（甚至赌债、超额高利贷等有争议债务），私自扣押、关押债务人逼债的，**按非法拘禁罪论**（§238 第三款），**不是绑架罪**——区分核心：目的是索取**与被扣人相关的债务** vs 勒索**第三人**财物。
2. **转化犯要看"暴力"独立性**：拘禁过程中**另行使用暴力**致人伤残、死亡的，**转化**为故意伤害/杀人；若仅是拘禁行为本身（如捆绑不当）致死，属**结果加重**，仍定非法拘禁（致人死亡档），不转化。
3. **扭送反向坑**：合法扭送的前提是"符合四情形 ＋ 立即送交"；**抓错对象**（非现行犯，只是"怀疑"）或**关着不送**（私自关押逼债/私了），一律掉进非法拘禁。
4. **国家机关工作人员从重**：如警察、狱警利用职权非法关人，仍是非法拘禁罪，只是**从重**（超期羁押等还可能牵连滥用职权等罪）。

## 一句话闭环记忆

> **「一眼判：扭送是'送'不是'拘'——现行/通缉/越狱/被追捕四种人，当场扭住立即送交公检法；关着不送、抓错对象，就掉进非法拘禁。」**
