# 试用买卖

> [[买卖合同]] 的**特殊形式**：买受人**先试**后决定是否购买。

## 法条范围

[[民法典]] §637-§640（共 4 条）

> ⚠️ 旧版曾误记"§638-§641"——**§641 是所有权保留**，不属试用买卖；已统一更正为 §637-§640。

## 是什么 / 易混

### 定义
**§637**：当事人**约定**买受人在**试用期间**内**可以购买**标的物的买卖。

### 三大特殊规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **试用期约定** | 由当事人约定 → 没约定 → §510 → 仍不能确定 → **出卖人**确定 | §637 |
| **期满 / 行为推定** | 期满**未表示**是否购买 → **视为购买**；期内**付款 / 出卖 / 出租 / 设担保** → 视为同意购买 | §638 |
| **使用费** | 没约定 / 约定不明 → 出卖人**无权请求**（不付） | §639 |
| **试用期风险** | 试用期间标的物毁损灭失**风险由出卖人**承担 | §640 |

### 与近似合同的区分
- vs [[买卖合同]]：试用买卖**未生效买卖**——附"是否购买"的条件
- 试用 vs **保管**：试用是**买受人占有 + 可用**；保管不可用

## 怎么考 / 坑在哪

### 三大陷阱

1. **使用费**：§639——没约定 / 约定不明则出卖人**无权请求**（不付）
2. **试用期 vs 检验期**：试用期决定"**买不买**"；检验期决定"**已买的合不合格**"
3. **风险归属**：试用期间不属买受人，毁损灭失风险仍在**出卖人**

### 怎么考

- 试用期未约定如何确定？→ 出卖人确定（§637）
- 期满未表示如何处理？→ 视为购买（§638）
- 试用期内毁损？→ 出卖人承担（§640）

## 怎么答

主观题分析框架：
1. 是否构成试用买卖？（看是否约定试用期）
2. 试用期如何确定？
3. 期满是否构成购买？
4. 期间内毁损谁担？
