# 无因管理

> [[准合同]] 之一 — **三要件 + 必要费用偿还 + 损失补偿**

## 法条范围

[[合同编]] §979-§984

## 是什么 / 易混

### 定义
**§979**：**没有法定的或者约定的义务**，为**避免他人利益受损**而**管理他人事务**的人，可以**请求受益人偿还**因管理事务**支出的必要费用**；管理人因管理事务**受到损失**的，可请求受益人**给予适当补偿**。

### 三要件

| 要件 | 内容 | 排除情形 |
|---|---|---|
| ① **管理他人事务** | 必须**他人**事务 | 自己的事务不构成 |
| ② **没有法定 / 约定义务** | 无义务而管理 | 监护人对被监护人 = 有义务 |
| ③ **为他人利益的意思** | 主观为他人 + **客观利他** | 纯为自己利益 ≠ 无因管理 |

### 关键陷阱：初衷有自利 ≠ 否定无因管理
即使**初衷有为自己利益**，但**同时**也为他人利益，**仍可**构成（C3-单选-02 / 03 经典案例）：
- 邻居为防自家受损 + 顺便加固对方房屋 = **仍属无因管理**
- 法律不要求"纯洁的利他动机"

### 排除情形
- 管理**违法 / 违背公德**事务 ≠ 无因管理（不属法律保护的他人事务）
- 替他人尽**道德 / 宗教义务**（如代还愿）≠ 无因管理
- 主动**代朋友处理**朋友的社交事务 ≠ 法律意义上的无因管理

### 法律效果

| 效果 | 内容 | 法条 |
|---|---|---|
| **必要费用偿还**请求权 | 受益人偿还**必要费用 + 利息** | §979 |
| **管理引起损失补偿** | 受益人**在受益限度内**补偿 | §979 |
| 管理事务**不当的责任** | 管理人**故意 / 重大过失** → 担责 | §982 |
| **紧急情况免责** | 紧急救助 + 一般过失 → 不担责 | §984 |
| **通知受益人** | 管理人应**及时通知** | §983 |

### 无因管理 vs 不当得利

| 维度 | 无因管理 | [[不当得利]] |
|---|---|---|
| 关键词 | **"帮了"**（有为他人意思）| **"多拿了"**（无合法根据）|
| 性质 | 事实行为（管理）| 事件 |
| 主观 | **为他人利益** | 不要求 |
| 效果 | 偿还费用 + 补偿损失 | 返还利益 |

→ 这是 4 大债因里**最容易混**的两个，故事区分见下。

### 🚗 老王小李"喂猫"故事

> **小李出差一周**，他家的猫没人喂。老王（邻居）发现后：
> - **没有任何法定 / 约定义务**（老王不是猫的监护人、也没说好替小李照顾）
> - 自己掏钱**买猫粮 300 元**
> - 帮小李**喂猫一周** + 清理猫砂
> - 主观上：为小李利益（小李回来一定会感激）

法律分析：
- ✅ 管理**他人**事务（猫是小李的）
- ✅ **无法定 / 约定义务**（老王没有任何义务）
- ✅ **为他人利益**的意思（为小李而非为自己）
- → 构成 **§979 无因管理**！

法律效果：
- 老王（管理人）→ 可请求小李（受益人）偿还 **300 元 + 必要利息**（§979）
- 如果老王因喂猫摔伤 → 可请求小李**适当补偿**（§979 II）

### 🚫 反向场景对比

| 场景 | 是否构成无因管理？| 为什么 |
|---|---|---|
| **老王帮小李喂猫** | ✅ 构成 | 无义务 + 为他人 + 他人事务 |
| 老王是小李的监护人，喂猫 | ❌ 不构成 | **有法定义务** |
| 老王帮小李喂猫，**目的是讨好小李借钱** | ⚠️ 仍可能构成 | 自利不否定，只要也为他人 |
| 老王把**自家的猫**当成小李的喂了 | ❌ 不构成 | **不是他人事务** |
| 老王帮小李去赌博垫钱 | ❌ 不构成 | **违法违背公德** |

## 怎么考 / 坑在哪

### 四大陷阱

1. **初衷有自利仍构成**：C3-单选-02 D / 单选-03 C 反复考
2. **违法违公德 ≠ 无因管理**：法律不保护的事务排除
3. **结果不影响成立**：管理结果失败仍可构成（C3-单选-03 B 错）
4. **专属性 / 宗教 / 道德事务**排除

## 真题示例

- [[准合同-单选-02]] 无因管理构成（答 D）
- [[准合同-单选-03]] 自利不否定 + 不以结果论（答 C）
