# 合同效力分级

> [[合同总则]] 第 2 块的**主轴**：合同**已成立**后的法律评价 — **4 级评价**。**主观题第二步固定问题**。

## 法条范围

- [[总则编]] §143、§144、§145、§146、§147、§148、§150、§151、§153、§154、§157、§158、§171
- [[合同编]] §502、§503
- 司法解释（[[合同编通则司法解释]]）

## 是什么 / 易混

### 4 级效力区分

| 级别 | 法律状态 | 典型情形 | 处理 |
|---|---|---|---|
| **① 有效** | 合同**有法律约束力** | 满足 §143 三要件 | 双方依约履行 |
| **② [[合同无效]]** | **绝对**无效，自始 / 当然 / 确定 | §144 / §146 / §153 / §154 等 | **任何人**可主张；时效届满**仍可**主张；返还财产 + 赔偿 |
| **③ [[合同可撤销]]** | **可撤销** = 可有效 + 可无效 | §147（重大误解）/ §148（欺诈）/ §149（第三人欺诈）/ §150（胁迫）/ §151（显失公平）· 📐 [[民法-合同-合同可撤销模型]] | 限**受损方**撤销；除斥期间内撤销；撤销后追溯无效 |
| **④ [[合同效力待定]]** | 效力尚未确定 | §145（限制行为能力人）/ §171（无权代理）/ §503（无权代理之追认）| 权利人**追认**则有效；不追认或拒绝则无效 |

### 还有"未生效"——独立于以上 4 级

| 状态 | 含义 | 典型 |
|---|---|---|
| **⑤ [[合同未生效]]** | 合同**已成立**但**尚未生效**（受**法定 / 约定条件 / 期限**所阻）| 附生效条件 §158 / **附期限 §160**（§159 不正当阻止条件成就视为已成就）/ 报批合同 §502 II（报批义务条款独立有效）|

→ 注意："**未生效**"≠"**无效**"——未生效合同**有效但未到时间** / **缺批准**；无效合同**自始无效**。

### 有效 3 要件（§143）

合同**有效**必须**同时**满足：
1. 行为人具**相应民事行为能力**
2. 意思表示**真实**
3. **不违反法律 / 行政法规强制性规定，不违背公序良俗**

## 怎么考 / 坑在哪

### 五大陷阱

1. **效力 vs 成立**：成立看**合意**，效力看**法律评价**。本题"合同未成立 ≠ 无效"——是两个不同阶段
2. **未生效 ≠ 无效**（详见 [[合同未生效]]）
3. **无效**：合同**绝对**无效——任何人 / 任何时间可主张
4. **可撤销**：仅**受损方**可撤销 + **1 年除斥期间**（重大误解 90 天）
5. **效力待定**：需**追认**才生效——追认前**对方有撤销权**（§145、§171）

### 主观题三步答题

1. **第一步**（成立）：合同是否**成立**？（§472 + §483）
2. **第二步**（效力）：合同是**有效 / 无效 / 可撤销 / 效力待定 / 未生效**？
3. **第三步**（履行 / 救济）：合同效力下的后果

## 怎么答

主观题分析框架：
1. 排查**有效 3 要件**（§143）是否满足
2. 若任一不满足 → 进入 4 级分析
3. **不**满足要件 1（行为能力）：
   - 无民事行为能力人 → §144 **无效**
   - 限制行为能力人 → §145 **效力待定**
4. **不**满足要件 2（真实意思）：
   - 虚假表示 → §146 **无效**
   - 重大误解 / 欺诈 / 胁迫 / 显失公平 → §147-§151 **可撤销**
5. **不**满足要件 3（不违法 / 不违公序良俗）：
   - 违反强制性规定 → §153 **无效**
   - 违背公序良俗 → §153 II **无效**
   - 恶意串通损害他人利益 → §154 **无效**
6. **特殊**：无权代理 → 效力待定（§171）；报批合同 → 未生效（§502 II）；⚠️ **无权处分 → 合同有效**（§597，**非**效力待定 / 未生效，待定的只是物权变动），见 [[民法-合同-无权处分模型]]
