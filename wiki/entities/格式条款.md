# 格式条款

> 提供方为**重复使用**预先拟定的条款 — 法律对其**严格规制**

## 法条范围

[[合同编]] §496-§498

## 是什么 / 易混

### 定义
**§496 I**：**当事人为了重复使用**而**预先拟定**，并在**订立合同时未与对方协商**的条款。

### 三大规制规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **提示 + 说明义务** | 提供方应当采取**合理方式**提示对方注意**与对方重大利害关系的条款**，**对方要求** → 说明 | §496 II |
| **未履行 → 条款不成为合同内容** | 未尽提示 / 说明义务 → 对方可**主张该条款不成为合同内容** | §496 II |
| **格式条款无效**情形 | 法定 6 类无效格式条款 | §497 |

### §497 无效格式条款（6 类）
1. **§144 / §146 / §153 / §154 / §155** 等无效情形
2. 提供方**不合理地免除 / 减轻其责任**
3. 提供方**加重对方责任**
4. 提供方**限制对方主要权利**
5. **排除对方主要权利**
6. 提供方**排除诉权 / 仲裁权**

### 格式条款的解释规则（§498）
- **不利于提供方**的解释（消费者倾斜保护）
- **格式条款 vs 非格式条款**：以**非格式条款**为准

## 怎么考 / 坑在哪

### 三大陷阱

1. **未提示的免责条款** → 不成为合同内容（C1-单选-13）
2. **不利解释**：争议时**不利**提供方
3. **格式条款无效 ≠ 整个合同无效**：仅该条款无效
