# 格式条款

> 提供方为**重复使用**预先拟定的条款 — 法律对其**严格规制**

## 法条范围

[[合同编]] §496-§498

## 是什么 / 易混

### 定义
**§496 I**：**当事人为了重复使用**而**预先拟定**，并在**订立合同时未与对方协商**的条款。

### 三大规制规则

| 规则                  | 内容                                                  | 法条      |
| ------------------- | --------------------------------------------------- | ------- |
| **提示 + 说明义务**       | 提供方应当采取**合理方式**提示对方注意**与对方重大利害关系的条款**，**对方要求** → 说明 | §496 II |
| **未履行 → 条款不成为合同内容** | 未尽提示 / 说明义务 → 对方可**主张该条款不成为合同内容**                   | §496 II |
| **格式条款无效**情形        | 法定 6 类无效格式条款                                        | §497    |

### §497 无效格式条款（6 类）
1. **§144 / §146 / §153 / §154 / §155** 等无效情形
2. 提供方**不合理地免除 / 减轻其责任**
3. 提供方**加重对方责任**
4. 提供方**限制对方主要权利**
5. **排除对方主要权利**
6. 提供方**排除诉权 / 仲裁权**

### 🔪 §506 免责条款无效（与格式条款的关系）

**免责条款**（预先免除 / 限制一方未来责任）与**格式条款**是**交叉关系** —— 一个条款可能同时是两者，也可能只是其一：

| 条款类型 | 例子 | 谁来管 |
|---|---|---|
| **格式 ＋ 免责** | [[合同通则-单选-28]] 共享单车"概不负责" | §497 **和** §506 |
| 格式 · 非免责 | 限制对方主要权利的格式条款 | §497 |
| **非格式 · 免责** | [[合同通则-单选-29]] 招工逐条谈"概不负责" | **§506**（§497 管不着）|

**§506 免责条款绝对无效**（不论是否格式条款）：
1. 免除造成对方**人身损害**的（Q28 / Q29）
2. 因**故意或重大过失**造成对方**财产损失**的

**§497 vs §506 分工**：

| | §497 | §506 |
|---|---|---|
| 管谁 | 仅**格式条款** | **所有免责条款**（格式 / 非格式）|
| 砍什么 | 不合理免己责 / 加重对方 / 限权利 | 人身损害 / 故意重大过失致财产损失 |

→ **凡"免人身损害责任"，无论是不是格式条款，一律无效（§506）** —— 比 §497 更硬的底线。

### 格式条款的解释规则（§498）
- **不利于提供方**的解释（消费者倾斜保护）
- **格式条款 vs 非格式条款**：以**非格式条款**为准

### 🚗 老王小李"未提示交付条款"故事

> 乙公司提前给所有客户定制了一套标准条款。和老王（甲）签货物买卖时，乙**对其中"货物交付"的条款只字未提**。签完老王才发现这条对自己很不利。

老王能怎么办？—— **主张这条"不成为合同内容"**（§496 II）：
- 这是格式条款（乙预先拟定、未协商）；
- "交付条款"与老王**有重大利害关系**，乙**必须提示**却没提示；
- 后果 = 这条**没进合同**（不成为内容），不是"无效" —— 老王当它不存在即可。

→ 注意：**"未提示 → 不成为内容" ≠ "无效"**（详见下方"两道关"）。

### 🔑 格式条款"两道关 + 三种命运"（核心框架）

格式条款要"算数"，得**连过两关**；任一关失败，命运不同：

```
         格式条款（§496 预先拟定、未与对方协商）
                      │
   ┌─ 第一关：订入了吗？（§496 II 提示 + 说明义务）─┐
   │   与对方有重大利害的条款（免责 / 限责 / 风险）必须【合理提示】
   ▼ 未提示 / 未说明                        ▼ 提示到位
 ❌ 不成为合同内容                          进入第二关
   〔命运① · Q13〕                             │
                     ┌─ 第二关：内容有效吗？（§497 / §506）─┐
                     ▼ 违法                          ▼ 合法
               ❌ 无效                            ✅ 有效适用
             〔命运② · Q28 / Q18 / Q29〕          〔命运③〕
```

- **命运①「不成为内容」**：栽在**第一关**（程序：没提示）→ 条款没进合同（§496 II）
- **命运②「无效」**：过了第一关、栽在**第二关**（内容违法：免己责 / 加重对方 / 限制权利 / 免人身损害）→ §497、§506
- **命运③「有效」**：两关都过 → 正常适用

> 🎯 **一句话**：**没提示 = 没进门（不成为内容）；进了门但违法 = 无效。两个层次别混！**

### 📋 4 道真题在框架上的定位

| 真题 | 第一关 · 订入 | 第二关 · 有效 | 命运 | 答案 |
|---|---|---|---|---|
| [[合同通则-单选-13]] | ❌ 未提示交付条款 | — | **不成为内容** | D |
| [[合同通则-单选-28]] | ✅ 加粗提示 | ❌ 免人身伤害（§506）| **无效** | A |
| [[合同通则-多选-18]] | ✅ 醒目张贴 | ❌ 限制赔偿（§497）| **无效** | AC |
| [[合同通则-单选-29]] | （个别协商免责）| ❌ 人身损害免责（§506）| **无效** | D |

→ Q13 考**第一关**，Q28 / Q18 / Q29 考**第二关** —— 合起来是格式条款的完整考查网。

## 怎么考 / 坑在哪

### 三大陷阱

1. **未提示的免责条款** → 不成为合同内容（C1-单选-13）
2. **不利解释**：争议时**不利**提供方
3. **格式条款无效 ≠ 整个合同无效**：仅该条款无效

## 真题示例

- [[合同通则-单选-13]] **第一关 · 提示义务**（未提示 → 不成为合同内容）→ D
- [[合同通则-单选-28]] **第二关 · 内容**（共享单车"概不负责"，加粗订入仍因免人身伤害**无效**）→ A
- [[合同通则-多选-18]] **第二关 · 内容**（存包须知"赔 5-10 元"，醒目订入但限制赔偿**无效**）→ AC
- [[合同通则-单选-29]] **免责条款**（招工免重伤死亡责任，§506 人身损害免责无效）→ D
- [[合同通则-单选-31]] **反向对照**："假一罚十"经营者自我加责 → 有效（不属无效格式条款）→ D
