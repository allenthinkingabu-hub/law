# 解除

> [[合同权利义务终止]] 之一 — **约定解除 vs 法定解除 + 通知主义**

## 法条范围

[[合同编]] §562-§566

## 是什么 / 易混

### 两大类型

| 类型 | 触发 | 法条 |
|---|---|---|
| **约定解除** | 当事人**约定**解除条件成就 / **协议解除** | §562 |
| **法定解除** | 法定 5 情形之一 | §563 |

### §563 法定解除 5 情形（核心）

| # | 情形 | 关键词 |
|---|---|---|
| ① | **不可抗力**致**不能实现合同目的** | 不可抗力 |
| ② | **预期违约**（明确表示 / 行为表明不履行）| §578 预期违约 |
| ③ | **迟延履行主要债务**经**催告**后合理期限内**仍未履行** | 催告 + 合理期限 |
| ④ | **迟延 / 其他违约行为**致**合同目的不能实现** | **根本违约** |
| ⑤ | 法律规定的其他情形 | 兜底 |

### 解除程序（§565 通知主义）
**§565**：解除合同**通知到达对方时**解除——**不需要诉讼**。
- 通知 → 到达对方时即解除
- 对方有**异议权** → 可起诉**确认解除效力**
- 当事人**直接起诉解除** → 起诉状副本**到达**对方时解除

### 解除后的效果（§566）
- **尚未履行**的，**终止**履行
- **已经履行**的，根据情况 + 合同性质 → **请求恢复原状 / 采取补救 / 赔偿损失**
- **合同因违约解除** → 解除权人可请求违约方承担违约责任（除当事人另有约定）
- **结算 / 清理条款 + 解决争议方法**条款**独立有效**

## 怎么考 / 坑在哪

### 五大陷阱

1. **通知主义**（C1-多选-16）：解除**不必诉讼**——通知到达即解除
2. **异议权 + 确认之诉**：相对方有 §565 III 异议权
3. **解除 ≠ 撤销**：解除一般不溯及既往；撤销追溯无效
4. **解除 + 违约责任并存**（§566）：解除后仍可索赔
5. **承租人未按约定使用**（C1-多选-13 D）：可解除但需"催告 + 致目的不能实现"

## 怎么答

主观题分析框架：
1. **类型**：约定 / 法定？
2. **法定情形**：§563 五项之哪一项？
3. **通知方式**：通知到达 / 起诉
4. **异议**：相对方是否提异议？
5. **效果**：终止履行 + 恢复原状 / 赔偿
