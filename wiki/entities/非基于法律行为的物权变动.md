# 非基于法律行为的物权变动

> [[物权编]] 物权变动的**例外轨道**（§229-232）：继承 / 法律文书 / 征收 / 事实行为 → **不以登记、交付为生效要件**，法律事实一成就，物权**直接变动**。与"基于法律行为"的公示生效（§209 登记 / §224 交付）相对。
> 📐 **答题模型** → [[民法-物权-非基于法律行为变动模型]]（定轨 → B 轨直接生效 → §232 处分关 → 回 A 轨）。

## 法条范围

[[民法典]] **§229-§232**（物权编第二章第三节"其他规定"）+ 关联 §209 / §215 / §224（基于法律行为的公示生效，[[区分原则]]）+ 物权编解释一 §7（§229 法律文书范围）。

## 是什么 / 易混

### 两条轨道对照

| 维度 | 基于法律行为（A 轨） | **非基于法律行为（B 轨）** |
|---|---|---|
| 典型原因 | 买卖 / 赠与 / 设抵押等**合同** | **继承 / 判决·征收 / 合法建造**等 |
| 生效要件 | 不动产**登记**（§209）、动产**交付**（§224） | **法律事实成就即变动**，不用登记/交付 |
| 登记的作用 | **取得要件**（不登记不变动） | **宣示 / 对抗 / 处分前提**（§232），非取得要件 |
| 统辖原则 | [[区分原则]] §215（合同效力≠物权变动） | 直接依 §229-232 |

### 四个法源（B 轨四源）

| 法条 | 情形 | 变动时点 |
|---|---|---|
| **§229** | 法院/仲裁**法律文书**、政府**征收决定** | 自文书 / 决定**生效时** |
| **§230** | 因**继承**取得物权 | 自**继承开始时**（被继承人死亡） |
| **§231** | 合法**建造、拆除房屋**等**事实行为** | 自**事实行为成就时** |
| **§232** | **处分**本节取得的不动产物权 | **未经登记，不发生物权效力**（处分前置登记） |

### §229 "法律文书"的范围（解释一 §7 · 高频）

仅限**形成性（改变原物权关系）文书**：
- 分割共有不动产 / 动产的**判决书、裁决书、调解书**；
- 执行程序中的**拍卖成交裁定书、以物抵债裁定书**。

→ **"命令某人去办过户登记"的给付判决不算**——物权仍需实际登记才变动。

## 怎么考 / 坑在哪

1. **继承"未过户 = 没所有权"** ❌ —— §230 死亡瞬间即取得。
2. **给付判决"去登记"当成 §229 形成文书** ❌ —— 只有形成判决直接变动（解释一 §7）。
3. **B 轨取得后直接转卖第三人就转移** ❌ —— §232 处分前须先登记到自己名下。
4. **不动产约定"交付即转移"有效** ❌ —— §209 登记生效是强制规则，不能约定排除。
5. **继承人未登记 → 无物权请求权 / 受时效** ❌ —— 是真权利人，不动产返还原物不受时效（§196⑵）。

## 真题示例

- [[物权编-单选-04]] 散伙协议+判决+继承+公证——四轨道辨析（答 C · §215+§229+§230+§209）
