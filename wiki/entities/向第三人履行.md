# 向第三人履行

> [[合同总则]] **涉他合同**之一 — 债务人**向第三人**履行（§522），分"假利他"与"真正利他"两种

## 法条范围

[[合同编]] §522（向第三人履行 / 真正利他合同）

## 是什么 / 易混

约定债务人**向第三人**（合同外的丙）履行。关键看**第三人有没有"自己告债务人"的直接请求权**，分两型：

| 型 | 法条 | 第三人能否直接请求 | 出事谁能告 |
|---|---|---|---|
| **假利他**（经由指令给付）| §522① | **不能** | 货没送好 → **债权人**告债务人，债务人对**债权人**担违约 |
| **真正利他合同** | §522② | **能**（法律/约定授予 + 第三人未及时拒绝）| 第三人可**直接**请求债务人担违约 |

### §522① 一般情形（第三人不能告）
- 当事人约定债务人向第三人履行，债务人未向第三人履行 / 不符约定 → **债务人向债权人承担违约责任**。
- 第三人只是"受领人"，**不取得独立请求权**。

### §522② 真正利他合同（第三人能告）
- 法律规定或当事人约定**第三人可直接请求**债务人履行，第三人未在合理期限内明确拒绝 → 债务人未履行 / 不符约定，**第三人**可请求其承担违约责任。
- 债务人对债权人的**抗辩**，可向第三人主张。

### 与"涉他合同"另两型的边界
- 本条是第三人**受领**给付（利益指向第三人）。
- 区别于 [[第三人代为履行]]：§523 是第三人**做出**给付（履行人换成第三人，责任仍在债务人）；§524 是有合法利益的第三人**主动代偿**（清偿后债权法定转移给他）。

## 怎么考 / 坑在哪

1. **核心坑**：以为向第三人履行时第三人**都能**告债务人——错。只有**真正利他合同**（§522②，有直接请求权）的第三人能自己告；一般情形（§522①）只能**债权人**告。
2. **"真正"的识别**：题干出现"法律规定 / 合同约定第三人**可直接请求**履行" + 第三人**未拒绝** → 真正利他。
3. **别与 §523 由第三人履行混**：那是第三人**来做**给付，不是第三人**来收**给付。

## 🚗 老王小李故事

> 老王（债务人）和小李（债权人）约定：货送给丙。
>
> - **一般情形（§522①，丙不能告）**：货没送好 → 老王对**小李**担违约，**丙不能**自己告老王。丙只是个"代收点"。
> - **真正利他（§522②，丙能告）**：若合同 / 法律明确"**丙可直接请求**老王交付"、丙也没及时拒绝 → 货没送好，**丙可以直接**告老王担违约。
>
> **🏠 经典例（[[合同通则-单选-46]]）**：老王和王婶离婚，协议写明"房子过户给 20 岁儿子小石头，**且小石头有权直接请求老王过户**"。这最后半句把小石头从"旁观者"变成能**亲自上门讨债**的人 → **真正利他合同**，小石头可直接请求过户（§522②，答 C）。少了"可直接请求"这半句，他就只是受益的旁观者、不能自己告。**离婚协议给子女财产 + 明确可直接请求**，是真正利他合同的最常考场景。
