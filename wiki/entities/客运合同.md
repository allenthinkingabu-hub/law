# 客运合同

> [[运输合同]] 子类：**承运人对旅客严格责任 + 三大免责事由**

## 法条范围

[[民法典]] §809-§842（运输合同章）；客运合同：§814-§824

## 是什么 / 易混

### 定义
**§814**：承运人**将旅客**从起运地点**运输至约定地点**，旅客**支付票款**的合同。

### 四大核心规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **无票 / 越站 / 失效票** | 应当补票，不补 → **可拒运** | §815 |
| **旅客伤亡严格责任** | 承运人**应担责** | §823 |
| **三大免责事由** | 自身健康 / 旅客故意 / 重大过失 | §823 但书 |
| **免票 / 优惠 / 经许可** | 适用**同等责任**（不因免票免责）| §824 |
| **行李毁损** | 承运人**有过错**才担责 | §822 |

### 严格责任 vs 过错责任
| 损害类型 | 归责原则 |
|---|---|
| **旅客伤亡** | **严格责任**（无过错也担责）+ 法定免责事由 |
| **随身物品**毁损 | **过错责任**（承运人有过错才担）|
| **托运行李**毁损 | 严格责任（货物运输规则）|

## 怎么考 / 坑在哪

### 四大陷阱

1. **免票同等责任**（§824）—— 不要以为免票就免责
2. **自身健康免责**（§823 但书）—— 突发心脏病 / 自杀 = 免责
3. **第三人侵害 ≠ 承运人免责**——例如制止扒窃被刺伤，承运人有保障安全义务，**仍担责**（可向第三人追偿）
4. **随身物品 vs 托运行李**：随身要承运人过错，托运是严格责任

## 怎么答

主观题分析框架：
1. **定性**：是否客运合同？
2. **伤亡 vs 行李**：分清损害类型
3. **免责事由**：是否构成自身健康 / 故意 / 重大过失？
4. **免票 / 优惠**：不影响责任
5. **赔偿范围**：依实际损失 + 可预见性
