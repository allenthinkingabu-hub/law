# 要式合同 vs 非要式合同（合同形式分类）

> **一句话区分**：看**法律（行政法规）或当事人是否要求采用特定形式（多为书面）**作为合同的**成立 / 生效要件**——要求 = **要式**（必书面）；不要求、形式自由 = **非要式**。
> 🔎 **法条已联网核实（2026-06-14，2 路独立源：最高检 spp.gov.cn 民法典全文 + 政府门户/律所交叉，全 CONFIRMED·HIGH）**。
> ⚠️ **本页两大订正（民法典 vs 旧法）**：① **定金合同已不是要式合同**（§586 删除了《担保法》§90 的"书面"要求，现仅为**实践合同**）；② **物业服务合同是要式**（§938 末句，**不是 §937**）。

## 一、核心区分标准

- **要式合同**：法律 / 行政法规规定，或当事人约定，**必须采用特定形式**（绝大多数是**书面**）才能成立或生效。
  - **法定要式**（法律明定，如建设工程§789）vs **约定要式**（当事人自己约定必须书面）。
  - 形式可能是**成立要件**（不书面 → 不成立，多数如此），也可能是**生效要件**（如抵押"登记"是 [[物权变动]] 生效要件）——需逐个判断。
- **非要式合同（形式自由）**：法律不要求特定形式，口头 / 书面 / 行为均可成立。**这是民法典的"原则 / 默认"**（[[合同形式自由]]，§469 可书面、口头或其他形式）。

## 三、非要式合同（形式自由 · 默认）

普通 [[买卖合同]] · [[委托合同]] · [[行纪合同]]（§951 全章无"书面"二字）· [[中介合同]] · [[承揽合同]] · [[赠与合同]] · **自然人之间借款**（§668 除外）· [[保管合同]] · 借用合同 …… 均**不要求特定形式**。

> 🎯 **真题套路**（[[典型合同-单选-10]]）：四个选项里挑"非要式"——融资租赁(§736)/建设工程(§789)/技术开发(§851)都是**要式**，只有**行纪合同非要式**。

## 四、三大易混点（法考最爱考）

### 易混 1：要式 ≠ 实践（要物）合同 —— 两个不同维度

| 维度 | 要式 / 非要式 | 诺成 / 实践（要物） |
|---|---|---|
| **区分什么** | **形式要件**（要不要书面等特定形式） | **成立要件**（合意够不够，还是要+交付） |
| **要式典型** | 建设工程§789 · 融资租赁§736 · 技术§851/§863 · 抵押§400 · 质押§427 | —— |
| **实践典型** | —— | **自然人间借款 §679**（提供借款时成立）· **保管 §890**（交付保管物成立）· **定金 §586**（交付定金成立）· 借用 |
| **关系** | **两维度独立、互不蕴含**（一个合同可分别判断它"要不要书面"和"合意够不够"） | 同左 |

> 💡 **诺成 vs 实践的衍生考点**：诺成是**原则**、实践是**例外**（须法律明文，不能类推）；实践合同"交付前"违反磋商义务 → **缔约过失责任**（[[民法-合同-缔约过失责任模型]]），不是违约责任。

### 易混 2：⚠️ 定金合同 —— 民法典已删"书面"要求（vs 担保法）

- **旧《担保法》§90**：定金合同**既要式（书面）又要物（交付成立）**——经典"双重叠加"。
- **现行民法典 §586**：**只保留"自实际交付定金时成立"（实践合同），删除了"书面"要求** → 定金合同**不再是法定要式合同**。
- 🪤 **考点**：题目若说"民法典规定定金应当以书面形式约定"→ **错误**（那是已废止的担保法规则）。这是"民法典 vs 担保法"高频变化点。详见 [[民法-合同-定金模型]]。

### 易混 3：书面 ≠ 一定无效；推荐书面 ≠ 强制书面

- "应当采用书面形式"才是**强制要式**；条文若是"可以""一般包括……条款"则**非强制**（如行纪、中介）。
- 未采用法定要式，后果**不是"一律无效"**——见下。

## 五、未采用法定要式形式的后果（关键：不是一律无效）

1. **一般规则**：法定要式而未采用 → 原则上合同**不成立**（而非"无效"；前提是该形式属成立要件）。
2. **补正例外（§490 第二款·"履行治愈"）**：法律 / 约定应书面，当事人**未书面，但一方已履行主要义务、对方接受** → 合同**成立**。
3. **租赁特别规则（§707）**：≥6 个月未书面 → **先允许确定租赁期限；只有"无法确定期限"才视为不定期租赁**（双方可随时解除 + 合理期限前通知）——**既非无效、也非不成立**。

> 📐 一句话：**要式没满足，先想"不成立"，再想两条出路——§490Ⅱ 履行治愈（已履行+接受=成立）、§707 租赁特规（无法定期→不定期）。**

## 六、怎么答（客观题三步）

1. **判类型**：题目合同是不是上表"必书面"清单里的？（建设工程/融资租赁/技术/担保/金融借款/租赁≥6月/物业）→ 是则要式。
2. **辨维度**：题目问的是"形式"（要式）还是"成立"（实践）？别把"自然人借款实践合同"答成"要式"。
3. **看后果**：未书面 ≠ 无效 → 优先"不成立"，再查 §490Ⅱ 补正 / §707 租赁特规。
