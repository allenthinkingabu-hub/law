# 物权取得（原始取得 vs 继受取得）

> 物权怎么"得到"的，分两大类：**继受取得**＝从前手手里**接过来**（依前手既有权利，如买卖/继承）；**原始取得**＝**法律直接赋予**、不依前手（如善意取得/先占/添附）。区别的实益：**前手无权时能不能取得**、**取得的物干不干净**。是理解 [[善意取得]] 为什么是"例外"的地基。

## 法条范围

散见 [[物权编]]：原始取得（善意取得 §311 / 添附 §322 / 孳息 §321 / 遗失物招领满一年归国家 §318）；继受取得（基于法律行为变动 §209/§224 + 非基于法律行为的继承 §230）

## 是什么 / 易混

### 二分总览
| 维度 | 继受取得（传来取得）| 原始取得 |
|---|---|---|
| **权利来源** | 从**前手既有权利**移转 / 派生而来 | **法律直接规定**，不依赖前手 |
| **典型** | 买卖、赠与、互易、**继承 / 受遗赠**；在他人物上设抵押权 / 地役权（创设继受）| **善意取得**、先占（无主动产）、**添附 §322**、生产、取得时效、孳息 §321、征收、没收、遗失物招领满期 §318 |
| **"前手有多少给多少"** | **受限**（nemo dat：无人能转让超过自己所有的权利）| **不受限**，可突破前手 |
| **原有负担（抵押 / 质权）** | **一并继受**（带瑕疵过来）| **消灭**（干净取得，如善意取得 §313 涤除）|

### 两种继受取得
- **移转继受**：整个权利从前手移转——买卖、赠与、继承。
- **创设继受**：在前手所有权上**派生**出限制物权——抵押权、地役权、质权（前手仍保有所有权）。

### 为什么对 [[善意取得]] 重要
- **有权处分** → 买受人**继受取得**（前手有权、正常给得出）→ 普通物权变动，**不进善意取得**的讨论。
- **无权处分** → 前手无权，按继受逻辑**给不出**所有权 → 买受人本拿不到 → **善意取得（原始取得）**例外登场，绕过"前手无权"直接赋权。
- 善意取得是**原始取得** → 取得**干净**所有权、原负担消灭（§313 涤除）；这正是它区别于普通继受买卖之处。

## 怎么考 / 坑在哪

1. **归类题**：善意取得、先占、添附、取得时效、孳息 = **原始取得**；买卖、赠与、继承 = **继受取得**。
2. **原始取得"洗白"负担**：善意取得后原抵押权 / 质权消灭（§313，善意受让人受让时知道的除外）；继受取得则带着负担过来。
3. **继承是继受取得**（移转继受），但属**非基于法律行为**变动（§230，死亡时直接取得、不待登记）→ 见 [[非基于法律行为的物权变动]]。
4. **nemo dat 原则**：继受取得"前手无权则不能取得"，[[善意取得]] 是这条的**法定例外**。
