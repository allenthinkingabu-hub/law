# 物业服务合同

> 2021 民法典**新增独立章节** — 业主大会任意解除 + 不得停水电催费

## 法条范围

[[民法典]] §937-§950（14 条）

## 是什么 / 易混

### 定义
**§937**：物业服务人在物业服务区域内，为业主提供**维修 / 养护 / 环境卫生 / 秩序管理**等服务的合同。

### 四大核心规则

| 规则 | 内容 | 法条 |
|---|---|---|
| **公开承诺为合同组成** | 物业公开作出的**有利于业主的**服务承诺 → 视为合同组成（⚠️物业**单方制定的服务细则**不当然入约） | **§938②** |
| **业主大会任意解除** | 业主**依法共同决定**解聘 → 提前 **60 日**通知 → 可解除 | §946 |
| **禁止停水电** | 物业**不得以停水 / 电 / 气 / 热**等方式催费 | **§944③** |
| **业主未住不能拒交** | 未实际居住 / 未接受服务**不得**作为拒交理由 | **§944①** |

## 怎么考 / 坑在哪

### 四大陷阱

1. **公开承诺有约束力**（**§938②**）—— 实务中物业**有利于业主的**宣传承诺 = 合同内容（单方细则不当然入约）
2. **任意解除权 60 日通知**—— 不需违约理由（与一般委托类似）
3. **停水电违法**：2021 明令禁止，物业只能起诉催费
4. **业主未住仍要交**：物业服务的对价是**公共服务**，与个人是否实际享用无关

## 怎么答

主观题分析框架：
1. **公开承诺是否构成合同内容**？
2. **解除是否合法**？业主大会决议 + 60 日通知
3. **物业催费方式**：诉讼 / 仲裁，**不得停水电**
4. **业主是否可拒交**：仅在物业违约时
