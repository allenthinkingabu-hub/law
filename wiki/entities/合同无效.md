# 合同无效

> [[合同效力分级]] 之 ② —— **绝对无效 + 自始无效 + 当然无效 + 确定无效**

## 法条范围

[[总则编]] §144（无民事行为能力人）/ §146（虚假表示）/ §153（违法 / 违公序良俗）/ §154（恶意串通）/ §157（返还）

## 是什么 / 易混

### 核心特征
"**4 个无**"：
- **自始**无效（合同自订立时即无效）
- **绝对**无效（任何人可主张）
- **当然**无效（法律直接评价，不需法院 / 仲裁宣告）
- **确定**无效（不会变成有效）

### 5 大无效情形

| # | 情形 | 法条 |
|---|---|---|
| ① | **无民事行为能力人**实施 | §144 |
| ② | **虚假表示**（通谋虚伪表示） | §146 I |
| ③ | 违反**法律 / 行政法规强制性规定** | §153 I |
| ④ | 违背**公序良俗** | §153 II |
| ⑤ | **恶意串通**损害他人合法权益 | §154 |

### §153 强制性规定：违法 ≠ 当然无效（§153 I 但书 + 通则解释§16）
**传统二分（结论方向仍可用）**：

| 类型 | 效力 |
|---|---|
| **效力性**强制性规定 | 合同**无效** |
| **管理性**强制性规定 | 合同**有效**（仅行政违法）|

> ⚠️ **2023 更新（[[合同编通则司法解释]]§16）**：已**不再机械套用"效力性/管理性"二分**作判准，改为**综合考量**——①规范目的能否经**行政/刑事责任**实现 ②违反行为对**公序良俗**的实际影响 ③认定无效是否**显失公平** ④规范针对**订立**还是**履行**（针对履行的多不致无效）。核心结论不变：**违法 ≠ 当然无效**。完整解题套路 → [[民法-合同-合同无效模型]] 第二步。

### 无效后果（§157）
- **返还财产**：相互返还（不能返还 → 折价补偿）
- **过错方赔偿**：依过错承担损失赔偿
- **报批义务条款独立有效**：合同无效不影响报批义务

## 怎么考 / 坑在哪

### 三大陷阱

1. **效力性 vs 管理性**：违法 ≠ 当然无效；要看是哪类
2. **虚假表示**（§146）：双方都知是假 → 表面合同无效；**隐藏的真实合同** → 按真实意思评价
3. **无效 vs 可撤销**：
   - **无效**：自始、绝对、任何人可主张
   - **可撤销**：仅受损方 + 除斥期内 → 撤销前**有效**

## 怎么答

主观题分析框架：
1. **识别情形**：是 5 大情形之一吗？
2. **§153 强制性规定**：效力性 / 管理性？
3. **返还财产**：§157 双方返还 + 折价
4. **过错责任**：依过错分摊损失
5. **特殊条款**：报批义务 / 仲裁条款独立有效

## 🚗 老王小李故事（打一开始就废）

> 老王和小李的几桩"自始就没用"的买卖：
> - 老王把**走私的枪**卖给小李 → **违反效力性强制规定 / 违背公序良俗**（§153）→ **无效**。
> - 老王和小李**串通签个假买卖**、做高金额去骗银行贷款 → **恶意串通损害第三人**（§154）+ **通谋虚伪表示**（§146）→ **无效**（藏在背后的真实意思另按真实合同评价）。
> - 老王 3 岁的娃把家里平板"卖"给邻居 → **无民事行为能力人**所为（§144）→ **无效**。
>
> 无效的脾气是"**4 个无**"：自始、当然、绝对、确定——**不用谁去告、谁都能主张、隔多久都能说**；钱货按 §157 各退各的，有过错的还要赔。
> ⚠️ 但别一看"违法"就喊无效：若违反的只是**管理性强制规定**（如无证 / 超范围经营），合同**仍有效**，只担行政责任——这就是"强制性规定柔性化"。
