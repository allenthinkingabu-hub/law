# 质权

> [[担保]]物权之一（[[物权编]] 第四分编）。**为担保债务履行，债务人或第三人将其动产（或权利）出质给债权人占有**；债务人到期不还，债权人可就质押财产变卖**优先受偿**（动产质权 §425）。**核心特征＝必须转移占有**——质押物必须交到债权人手里实际控制。做题步骤见 📐 [[民法-物权-担保物权模型]]，本页是**概念·法条**层。

## 法条范围

- **定义（动产质权）**：[[物权编]] **§425**（转移占有 + 优先受偿）
- **设立 / 公示**：**§429** 动产质权**自出质人交付质押财产时设立**（交付生效，区别于动产抵押的"登记对抗"）
- **禁止流质**：**§428**（约定到期归债权人无效 → 只能就质押财产**优先受偿**，须清算）
- **孳息 / 转质**：§430 质权人可收取孳息 · §434 转质及赔偿责任
- **权利质权**：**§440** 可出质权利列举（汇票/债券/存单、基金份额/股权、知识产权财产权、**应收账款**等）· **§445** 应收账款质权**自办理出质登记时设立** · §443 股权出质登记设立
- **顺位 / 竞存**：§415（抵押与质权按公示时间先后）
- **善意取得**：**§311Ⅲ**（其他物权参照适用 → 可善意取得质权）→ [[善意取得]]

## 是什么 / 核心特征

| 项 | 内容 |
|---|---|
| **核心特征** | **必须转移占有**——质押物交到债权人手里实际控制 |
| **适用对象** | **动产（手机、手表、货物）+ 财产权利（股权、票据、应收账款）**；**不动产不能质押** |
| **公示方式** | 动产质权＝**交付时设立**（§429）；权利质权依权利种类（凭证交付 / 登记，应收账款§445 登记设立）|
| **性质** | 意定担保物权（依质押合同 + 交付/登记设立）|

> **通俗例子**：你拿手表向朋友借钱，**必须把手表交给朋友保管**，朋友才取得质权；不交付就不设立。

### 抵押 / 质押 / 留置 三分（高频区分）

| 维度 | [[抵押权]] §394 | **质权**（动产）§425 | 留置权 §447 |
|---|---|---|---|
| **占有** | 不转移 | **转移**给债权人 | 已（合法）占有债务人动产 |
| **客体** | 不动产 + 动产 | 动产 + 权利（**不含不动产**）| 动产 |
| **设立/公示** | 不动产登记生效§402 / 动产登记对抗§403 | **动产交付设立§429** | 法定，无须登记 |
| **产生** | 意定（约定）| 意定（约定）| **法定** |

## 善意取得质权（§311Ⅲ 客体扩张）

§311 第 3 款"善意取得其他物权参照适用前两款"——把善意取得从**所有权**扩张到质权、抵押权等其他物权（**客体扩张**）。质权善意取得依赖**占有外观**的公示。

> **例**：甲把相机借给乙，乙谎称相机是自己的，向不知情的丙借钱并把相机**交付给丙做质押**。丙信赖占有外观、属善意，依法**善意取得该相机质权**；乙到期不还，丙有权拍卖相机优先受偿。

## 怎么考 / 坑在哪

1. **必须转移占有**——与 [[抵押权]]"不转移占有"是最核心的对立辨析点；不交付＝质权不设立（§429）。
2. **不动产不能质押**——质权客体只能是动产或权利；房屋、土地只能抵押不能质押。
3. **交付生效 vs 登记对抗**——动产**质权**交付设立（§429）；动产**抵押**登记对抗（§403）。同一动产，公示方法不同，是高频区分点。
4. **应收账款质权登记设立 §445**——不是"交付凭证/签合同"就设立，须办理**出质登记**（陷阱）。
5. **流质禁止 §428**——约定"到期归债权人所有"无效，只能就财产**优先受偿**（须清算）。
6. **债权出质，次债务人抗辩** ——可向质权人主张对原债权人的抗辩（准用 §548），详见 📐 模型。
