# 融资租赁合同

> **三方关系**是本质特征 — 出租人 / 承租人 / 出卖人

## 法条范围

[[民法典]] §735-§760（26 条）

## 是什么 / 易混

### 定义
**§735**：出租人**根据承租人选择**的出卖人 + 标的物，**向出卖人购买**租赁物，并**租赁**给承租人使用 + 承租人付租金。

### 三方关系图
```
       买卖合同 (§735)
出租人 ─────────────→ 出卖人（供应商）
   │                  │
   │ 租赁合同         │ §750 承租人
   │                  │ 直接索赔权
   ↓                  ↓
承租人 ←──────────────
```

### 四大核心规则
| 规则 | 内容 | 法条 |
|---|---|---|
| **形式** | **应当采用书面** | §736 II |
| **质量瑕疵直索** | 承租人**直接向出卖人索赔** | §750 |
| **出租人免责** | 出租人**不对**标的物质量瑕疵担责（除非承租人依赖其技能 / 干预）| §744 |
| **租金不受瑕疵影响** | 承租人**仍应付租**（一般情形下）| §745 |
| **期满归属** | 当事人**约定**——没约定推定**归出租人** | §759 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **直接索赔权**（§750）—— 突破合同相对性的特殊规则
2. **期满所有权归出租人**（默认）—— 不要误以为"分期付款 = 期满归承租人"
3. **出租人不担质量责任**—— 即使设备坏了，租金仍要付

## 怎么答

主观题分析框架：
1. **三方关系**：识别出租人 / 承租人 / 出卖人
2. **质量问题**：承租人能否直接索赔出卖人？（§750 可）
3. **租金**：是否可拒付？（一般不可）
4. **期满归属**：看合同约定
