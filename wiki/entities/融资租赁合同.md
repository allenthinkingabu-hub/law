# 融资租赁合同

> **三方关系**是本质特征 — 出租人 / 承租人 / 出卖人

## 法条范围

[[民法典]] §735-§760（26 条）

## 是什么 / 易混

### 定义
**§735**：出租人**根据承租人选择**的出卖人 + 标的物，**向出卖人购买**租赁物，并**租赁**给承租人使用 + 承租人付租金。

### 两种交易模式：直租 / 售后回租
融资租赁按交易结构分两种，**售后回租是其法定的一种模式，不是另立一种合同**：

| 模式 | 结构 | 出卖人是谁 | 实质 |
|---|---|---|---|
| **直租**（直接租赁） | 出租人**向第三方**买承租人选定的物 → 租给承租人 | 第三方 | 典型**三方** |
| **售后回租**（回租） | 承租人把**自有物卖给出租人**，再**租回来用** | **承租人本人** | 三方塌缩为**两方**，纯**融资**（盘活设备换现金、不丧失使用） |

> 📌 **售后回租受法律明文认可**：最高法《融资租赁合同司法解释》**第 2 条**——"承租人将其自有物出卖给出租人，再通过融资租赁合同将租赁物从出租人处租回的，人民法院**不应仅以承租人和出卖人系同一人为由认定不构成融资租赁**法律关系。" 故售后回租仍适用本章 §735 以下规则。库内 [[典型合同-单选-29]] 即售后回租情节。

### ⚠️ 易混：融资租赁 ≠ 租赁合同的"子类"
**融资租赁合同与租赁合同是两个平行、独立的典型合同，不是父子关系**：
- [[租赁合同]] = 合同编**第十四章**（§703-§734）；融资租赁合同 = **第十五章**（§735-§760）——并列单列，各成一章。
- 名字都带"租赁"只是**用词重叠**。本质区别：普通租赁出租人**本来就有物**、纯让渡使用；融资租赁出租人**专门为你去买**、租金是**买价 + 利息**的分期回收（融资＋融物合一）。
- 故本页把 [[租赁合同]] 列在"**横向**（兄弟）"而非"上层（父类）"——别答成"融资租赁是租赁的一种"。

### 三方关系图（直租形态）

### 核心规则速查（条号已联网核准 2026-06）
| 规则 | 内容 | 法条 |
|---|---|---|
| **形式** | 应当采用**书面**形式 | §736 Ⅱ |
| **质量瑕疵直索** | （可约定）承租人**直接向出卖人索赔**，出租人协助 | **§741** |
| **租金照付 + 出租人原则不担质量责任** | 承租人索赔**不影响支付租金**；但承租人**依赖出租人技能**选物 / 出租人**干预选择** → 可请求**减免相应租金** | **§742** |
| **所有权登记对抗** | 出租人对租赁物的所有权，**未经登记不得对抗善意第三人** | **§745** |
| **承租人保管 / 维修** | 承租人应**妥善保管、使用**租赁物，并履行占有期间**维修义务** | **§750** |
| **期满归属** | 可**约定**；约定不明且依 §510 仍不能确定 → **归出租人**（§757）；约定仅付**象征性价款** → **归承租人**（§759） | §757 / §759 |

> ⚠️ **条号纠错（2026-06-12 联网核准，旧版三处有误）**：直接索赔权是 **§741**（非 §750）；"租金照付 + 技能依赖例外减租"是 **§742**（非 §744/§745）；**§745** 实为"所有权登记对抗善意第三人"、**§750** 实为"承租人保管 / 维修义务"；期满"约定不明 → 归出租人"是 **§757**（§759 是"象征性价款 → 归承租人"）。

### 🏠 实际案例（CT 机直租，一看就懂三方关系）

> **甲医院**想引进一台进口 CT 机（约 500 万元），但一次性掏不出这笔钱，也不想走银行抵押贷款。于是走融资租赁：
>
> 1. **承租人自己选货**：甲医院**自行看中**了 **乙医疗器械公司**（出卖人）的某型号 CT 机——买哪台、向谁买，是**甲医院定的**，不是租赁公司定的。
> 2. **出租人出钱买物**：甲医院找到 **丙融资租赁公司**（出租人）。由**丙公司出钱向乙公司买下**这台 CT 机（§735：出租人按承租人的选择购买租赁物），CT 机**所有权先归丙公司**。
> 3. **出租人把物租给承租人**：丙公司把 CT 机**交甲医院使用**，甲医院**按月付租金**（如每月 10 万、共 5 年）。合同**须书面**（§736Ⅱ）。
> 4. **期满**：合同约定甲医院再付 **1 元象征性价款**即可**取得 CT 机所有权**（§759 象征性价款 → 归承租人）；若**没约定、依 §510 仍定不了** → 归出租人丙（§757）。

> **本质一句话**：丙公司表面"出租设备"，实质是**替甲医院垫钱买设备、再用租金分期收回本息**——**"融资"(出钱) ＋ "融物"(给物) 合一**。这正是它与**普通租赁**的根本分野：普通租赁里出租人**本来就有那东西**才出租；融资租赁里出租人是**专门为了租给你才去买**的，**买什么、向谁买由承租人(你)挑**。

> **三方各管各的（考点所在）**：
> - CT 机**有质量毛病** → 甲医院（经约定）**直接找乙公司(出卖人)索赔**（**§741**，突破合同相对性），而且**索赔不影响向丙公司付租金**（**§742**）。
> - 丙公司**原则上不对质量瑕疵负责**——除非甲医院当初**依赖丙的技能**选机器、或丙**干预了选择**，这时甲才可请求**减免租金**（§742 但书）。
> - 丙公司想让这台 CT 机的**所有权对抗外人**（如甲擅自把机器转卖、甲的债权人来查封）→ 须办**登记**，否则**不得对抗善意第三人**（**§745**）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **直接索赔权**（**§741**，非 §750）—— 突破合同相对性的特殊规则
2. **期满所有权归出租人**（约定不明时的默认，**§757**）—— 不要误以为"分期付款 = 期满归承租人"；只有约定**象征性价款**才归承租人（§759）
3. **出租人不担质量责任**（**§742**）—— 即使设备坏了租金仍要付；除非承租人依赖出租人技能 / 出租人干预选择，才可请求减免租金

## 怎么答

主观题分析框架：
1. **三方关系**：识别出租人 / 承租人 / 出卖人
2. **质量问题**：承租人能否直接索赔出卖人？（**§741** 可，经约定）
3. **租金**：是否可拒付？（一般不可）
4. **期满归属**：看合同约定
