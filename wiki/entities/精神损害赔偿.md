# 精神损害赔偿

> 2021 民法典**双轨突破**：侵权 §1183 + **违约 §996（新增）**

## 法条范围

[[侵权责任编]] §1183；[[人格权编]] §996

## 是什么 / 易混

### 两条路径

| 路径 | 法条 | 适用 |
|---|---|---|
| **侵权之诉**（传统） | §1183 | 侵犯**人身权益**致**严重**精神损害 |
| **违约之诉**（2021 新增）| §996 | 违约**损害人格权**致**严重**精神损害 |

### §1183 侵权精神损害
**§1183**：
- 侵害**自然人**人身权益致**严重精神损害** → 受害人可请求精神损害赔偿
- 因故意 / 重大过失侵害**自然人具有人身意义的特定物**致**严重精神损害** → 可请求精神损害赔偿

→ 注意"**具有人身意义的特定物**"——如骨灰盒 / 婚礼录像 / 婚戒等。

### §996 违约精神损害（2021 突破）
**§996**：违约行为**损害对方人格权**并**致严重精神损害** → 即使选择违约之诉，仍**可请求**精神损害赔偿。

→ 突破"传统违约不主张精神损害"的原则。

### 适用条件
| 条件 | 内容 |
|---|---|
| **严重精神损害** | 一般精神不适不够，需达"严重"程度（两条路径**共同门槛**）|
| **侵权·一般** | 侵害**人身权益**致严重精神损害（§1183 ①）|
| **侵权·特定物** | **故意 / 重大过失**侵"具人身意义的特定物"致严重精神损害（§1183 ②）；**一般过失不行** |
| **违约** | 违约**损害人格权**致严重精神损害（§996）；**与"特定物"无关** |

### ⚠️ 违约 vs 侵权：精神损害的边界（90% 栽在这）

> **一句话**：违约之诉精神损害**只认"损害人格权"**；"具人身意义的特定物"是**侵权之诉**的专属理由，**不能**搬进违约之诉。

| 受损法益 | 违约之诉（§996）| 侵权之诉（§1183）|
|---|---|---|
| **人格权**（肖像 / 名誉 / 人格尊严…）| ✅ 可 | ✅ 可 |
| **具人身意义的特定物**（录像带 / 骨灰 / 旧照片）| ❌ **不可**（只损财产权）| ✅ 可（须**故意 / 重大过失**）|
| 一般财产 | ❌ | ❌ |

- **婚纱照底片丢失** → 损**肖像 / 人格利益** → 违约之诉**也能**主精神损害（§996）。
- **录像带 / 旧照片烧毁** → 只损**财产权** → 违约之诉**不能**，只能走侵权之诉（特定物 + 故意/重大过失）。

## 怎么考 / 坑在哪

### 五大陷阱

1. **§996 突破**：违约**可以**主张精神损害（2021 大新规）——但**仅限损害人格权**
2. **违约 ≠ 特定物**：违约之诉精神损害**只看人格权**；"特定物"是**侵权**的理由，别搬进违约之诉
3. **特定物需故意 / 重大过失**：**一般过失**侵害具人身意义的特定物 → **不能**主张（新增考点）
4. **严重**精神损害：门槛较高，一般不适不够
5. **多层侵权**：第三人介入时先拆"直接侵权 / 不作为侵权"，别把数人侵权混为一谈 → [[违约与侵权竞合]]

## 真题示例

- [[合同通则-多选-17]] 婚礼录像带烧毁（乙保管、丙失火）→ **答 B**：违约之诉**不能**主精神损害（仅财产权），侵权之诉**可以**（特定物 + 乙重大过失）
- **对照例**（照相馆翻拍母亲遗照、员工**一般过失**打扫时损毁）→ **答 D**：违约之诉不能（财产权）；侵权之诉也不能（**一般过失**，非故意/重大过失）→ 两条路都要不到
