# 精神损害赔偿

> 2021 民法典**双轨突破**：侵权 §1183 + **违约 §996（新增）**

## 法条范围

[[侵权责任编]] §1183；[[人格权编]] §996

## 是什么 / 易混

### 两条路径

| 路径 | 法条 | 适用 |
|---|---|---|
| **侵权之诉**（传统） | §1183 | 侵犯**人身权益**致**严重**精神损害 |
| **违约之诉**（2021 新增）| §996 | 违约**损害人格权**致**严重**精神损害 |

### §1183 侵权精神损害
**§1183**：
- 侵害**自然人**人身权益致**严重精神损害** → 受害人可请求精神损害赔偿
- 因故意 / 重大过失侵害**自然人具有人身意义的特定物**致**严重精神损害** → 可请求精神损害赔偿

→ 注意"**具有人身意义的特定物**"——如骨灰盒 / 婚礼录像 / 婚戒等。

### §996 违约精神损害（2021 突破）
**§996**：违约行为**损害对方人格权**并**致严重精神损害** → 即使选择违约之诉，仍**可请求**精神损害赔偿。

→ 突破"传统违约不主张精神损害"的原则。

### 适用条件
| 条件 | 内容 |
|---|---|
| **严重精神损害** | 一般精神不适不够，需达"严重"程度 |
| **人格权 / 人身意义的特定物** | 财产损失一般不主张 |
| **故意 / 重大过失**（特定物时）| 限制范围 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **§996 突破**：违约**可以**主张精神损害（这是 2021 大新规）
2. **特定物**严格限制：要求"具有**人身意义**"+ 故意 / 重大过失
3. **严重**精神损害：门槛较高
