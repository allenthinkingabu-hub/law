# 除斥期间

> [[民法典]] §199 — 法律为**形成权**设定的法定权利保质期，**不变期间，不中止、不中断**，期满**权利本身直接消灭**

## 法条范围

[[总则编]] §199（通用规则）· §152（合同撤销权，最典型适用）· §564（合同解除权）

## 是什么 / 易混

### 定义

**除斥期间**：法律为**形成权**（仅凭权利人一方意思即可直接变动法律关系的权利）设定的法定存续期间，期间届满，**权利本身直接、彻底消灭**。

→ 一句话：**期满 = 权利死了，不是对方获得挡箭牌**

### 适用对象：只管形成权

形成权举例：合同撤销权（§152）、合同解除权（§564）、继承 [[追认]]/拒绝追认权、抵销权等——只要是"一方一声令下就能变动法律关系"的权利，都配除斥期间，不配诉讼时效。

### ⭐ 核心命题：除斥期间消灭"权利本身"，诉讼时效只消灭"胜诉权"

| 维度 | 诉讼时效 | 除斥期间 |
|---|---|---|
| **适用权利** | 债权请求权（要钱/要赔偿/要求履行） | 形成权（撤销权/解除权/追认权） |
| **过期后果** | 义务人获得**抗辩权**，实体债权仍存（[[自然债务]]） | **权利本身直接消灭** |
| **期间性质** | 可变期间，可中止/中断/延长 | **不变期间**，绝对不中止/不中断/不延长 |
| **法院审查** | 不得主动适用，须义务人**主动抗辩** | 法院**依职权主动审查**，双方不提也直接驳回 |
| **典型法条** | §188（3年普通诉讼时效） | §152（撤销权）·§564（解除权） |

→ 这是法考最核心的一组对比，详见 [[诉讼时效]] 的另一半视角。

### 三大特性拆解

1. **不变期间**：时长法定死值（90日/1年/5年），无弹性，法院不能酌情延长。
2. **不中止**：无论遇到任何客观障碍（不可抗力、权利人昏迷无法行为），期间照常计算、一天不暂停，不存在"补时间"。
   - 对比诉讼时效**中止**（§194）：最后6个月内遇障碍暂停计算，障碍消除后再补足6个月。
3. **不中断**：协商、催告、发函、反复主张权利，都不会让期间重新起算。
   - 对比诉讼时效**中断**（§195）：催告/起诉/义务人同意履行 → 已过时效全部清零，重新计算3年。

### §152 撤销权的三档除斥期间（最典型例子）

| 期限 | 起算方式 | 适用情形 |
|---|---|---|
| **90 日** | 主观起算（知道/应知撤销事由之日） | 重大误解 |
| **1 年** | 主观起算（知道/应知撤销事由之日） | 欺诈、显失公平、胁迫（胁迫从胁迫行为终止之日起算） |
| **5 年** | **客观起算**（民事法律行为发生之日起） | 兜底最长期限，无论知不知道撤销事由，5年一到直接消灭 |

## 怎么考 / 坑在哪

### 三大陷阱

1. **误以为除斥期间届满 = 对方获得抗辩权** ❌ —— 是权利本身彻底消灭，法院可依职权主动驳回，不需要对方抗辩
2. **误以为客观障碍（昏迷、天灾）能让期间中止暂停** ❌ —— 除斥期间不中止，一天不停
3. **误以为反复协商、发函能重启计时** ❌ —— 除斥期间不中断，协商行为不影响期间计算

### 答题口诀

```
形成权配除斥期，过期权利直接熄；
固定时长不拐弯，不停不重算，法院主动查。
```

看到"撤销权/解除权 + 期限"关键词：
1. 先判断是不是形成权 → 是 → 走除斥期间，不走诉讼时效
2. 期间性质：不变、不中止、不中断
3. 过期后果：权利本身消灭，法院可主动审查驳回
4. §152 具体数值：90日（重大误解）/ 1年（欺诈显失公平胁迫）/ 5年（客观兜底）
