# 合同未生效

> [[合同效力分级]] 之 ⑤ —— **合同已成立但效力被悬置（条件 / 期限 / 批准）**

## 法条范围

[[总则编]] §158（附条件 / 期限）；[[合同编]] §502（需批准的合同）+ [[合同编通则司法解释]]

## 是什么 / 易混

### 核心特征
- 合同**已成立**（合意 + 形式）
- **暂时不生效**（受条件 / 期限 / 批准的阻碍）
- 一旦**条件成就 / 期限届至 / 获得批准** → 自动生效
- 与**无效** 严格区分：未生效**有效力基础**，无效则**根本不发生效力**

### 3 大未生效情形

| # | 情形 | 法条 |
|---|---|---|
| ① | **附生效条件**（条件成就时生效）| §158 |
| ② | **附生效期限**（期限届至时生效）| §160 |
| ③ | **需经批准 / 登记**（如外商投资、矿权转让等）| §502 / 行政法规 |

### 附条件合同的特殊规则（§159）
**§159**：附条件的合同，**当事人为自己利益不正当地阻止条件成就的，视为条件已成就**；**不正当地促成条件成就的，视为条件不成就**。

### 报批合同的"独立有效"规则（§502 II + 司法解释）

```
报批合同未获批准
  ↓
合同**未生效**
  ↓
但**报批义务条款 / 仲裁条款 / 争议解决条款**——**独立有效**
  ↓
违反报批义务 → 缔约过失 / 违约责任
```

→ 即：报批合同未获批准，**仅主合同**未生效；**附属义务条款仍有效**。

### 未生效 vs 无效 vs 效力待定

| 维度 | **未生效** | 无效 | 效力待定 |
|---|---|---|---|
| 合同**成立**？ | ✅ | ✅ | ✅ |
| 当前是否有效？ | ❌（暂时）| ❌（确定）| ❌（暂时）|
| 何时有效 | 条件成就 / 期限届至 / 获批 | **永远无效** | 追认 |
| 内部条款效力 | 报批 / 仲裁等条款**独立有效** | 一般全部无效 | 看追认 |

## 怎么考 / 坑在哪

### 四大陷阱

1. **未生效 ≠ 无效**：典型反差——批准缺失合同**未生效**，不是**无效**
2. **报批义务独立**：违反报批义务可主张违约责任
3. **不正当阻止 / 促成条件**：拟制条件成就 / 不成就（§159）
4. **未登记 ≠ 合同未生效**（重要！）：
   - 不动产**登记**是**物权变动**的生效要件
   - 不是合同生效要件
   - 房屋买卖合同**未登记仍生效**（C1-多选-15）

## 怎么答

主观题分析框架：
1. 合同是否**已成立**？
2. 是否附**条件 / 期限**？
3. 是否需**批准**？是否已获批？
4. 是否构成"**不正当**阻止 / 促成条件"（§159）？
5. **报批义务**：未获批的合同 + 报批义务条款仍有效

## 真题示例

- [[合同通则-单选-12]] 缔约过失 vs 合同成立（与未生效相关）
- [[合同通则-多选-15]] 房屋未登记 → **合同有效**（答 ABD 错误，A "未登记 = 未生效"是经典陷阱）
