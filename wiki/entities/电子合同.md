# 电子合同

> 网络商品/服务信息符合 [[要约]] 条件 → 对方**提交订单成功时** [[合同成立]]；§491。

## 简介

电子合同是 [[合同订立]] 的特殊形式。成立时点与一般合同不同，是客观题陷阱密集区。

## 关键信息

- **法条**：[[民法典]] §491
- **核心规则**：网络发布商品/服务信息符合要约条件的，对方**提交订单成功时**合同成立
- **另有约定**：除外

## 详细内容

### 成立时点

| 节点 | 是否合同成立 |
|---|---|
| 商家在网上展示商品 / 服务 | 若符合 [[要约]] 条件，构成要约 |
| 消费者**提交订单成功** | **合同成立** ✓ |
| 消费者付款 | 不是合同成立时点 ✗ |
| 商家发货 | 不是合同成立时点 ✗ |

### 客观题陷阱

误以为是**付款时**或**发货时**才成立。

> 实际是**提交订单成功时**成立（除非另有约定）。
