# 遗失物

> **非基于权利人意思而脱离占有的动产**（丢失的物）。两大考点：① **善意取得受限**——不同于普通动产即时善意取得，遗失物原主**2 年内可向受让人回赎**（§312）；② **拾得人规则**——返还/通知/保管/报酬，拾得人**不能取得所有权**（§314-318）。赃物准用、埋藏物参照（§319）。

## 是什么 / 易混

### 一、遗失物的善意取得排除（§312）—— 与 [[善意取得]] 的核心区别
> **普通动产**：善意 + 合理价格 + 交付 → **即时**善意取得（§311）。
> **遗失物**：即便受让人善意，原主仍**有权追回**——
- 原主可**二选一**：向**无处分权人请求损害赔偿**，**或自知道 / 应知受让人之日起 2 年内向受让人请求返还原物**；
- **有偿回赎例外**：受让人通过**拍卖**或**向有经营资格的经营者**购得的，原主请求返还须**先支付受让人所付费用**，再向无处分权人追偿（先付费、后追偿）。

| 对比 | 普通动产 | 遗失物 / 赃物 / 埋藏物 |
|---|---|---|
| 善意取得 | 即时取得（§311）| 受限（§312 / §319）|
| 原主追回 | 不可（已失权）| **2 年内**可向受让人回赎 |
| 拍卖 / 经营者购得 | — | 须**有偿**回赎（先付费后追偿）|

### 二、拾得人规则（§314-318）—— 拾得人不能取得所有权
| 条 | 规则 |
|---|---|
| **§314** | 拾得遗失物应**返还**权利人，及时**通知**领取或**送交**公安等有关部门 |
| **§315** | 有关部门收到后，知道权利人的通知领取，不知道的**发布招领公告** |
| **§316** | 送交 / 领取前应**妥善保管**；因**故意或重大过失**致毁损灭失 → 承担赔偿责任 |
| **§317** | 权利人领取付**必要费用**；有悬赏的按承诺给**报酬**；拾得人**侵占（拒不返还）→ 丧失**费用与报酬请求权 |
| **§318** | 招领公告满**一年**无人认领 → 归**国家**所有 |

### 三、埋藏物 / 隐藏物 / 漂流物（§319）
**参照适用**拾得遗失物的规定（§314-318）。所有人明确的仍归原主；所有人不明的招领满一年归国家。**盗赃物**通说亦准用遗失物规则（善意取得受限）。

## 怎么考 / 坑在哪

1. **遗失物 ≠ 普通动产**：善意受让人**不能即时善意取得**，原主 2 年回赎（§312）——头号坑（[[物权编-单选-08]] 埋藏物经 §319→§312，受让人不确定取得）。
2. **§316 vs §317 别标反**：§316 = 妥善保管 + 毁损赔偿；§317 = 报酬 + 侵占丧失（[[物权编-单选-09]]）。
3. **拒不返还（侵占）→ 丧失报酬**：拾得人主张报酬 / 费用的前提是依法返还。
4. **埋藏物条号是 §319**（参照遗失物），不是 §316。
5. **回赎 vs 损害赔偿二选一**：§312 给原主选择权，向受让人回赎（2 年）**或**向无权处分人索赔。
