# 合同编适用范围

> [[合同编]] 通则一般规定(§463-§468)— 整个**债法的"地图"**:合同编通则**兼任**债法总则

## 法条范围

[[合同编]] §463 / §464 / §465 / §466 / §467 / §468

## 是什么 / 易混

### 🔑 核心命题:民法典没有独立"债编 / 债法总则"

[[民法典]] 七编里**没有专门的"债法总则"那一编**:

```
民法典七编:
  总则 → 物权 → 合同 → 人格权 → 婚姻家庭 → 继承 → 侵权责任
       ❌ 没有"债编"
```

→ 债的**共通规则**(履行、保全、转让、消灭)**全部塞进了合同编通则**
→ [[合同编]] 通则**兼任**了整个债法的"总开关 / 地图说明"
→ 法源在 **§468** 接口条款

### 6 大法条速览

| 法条 | 解决问题 |
|---|---|
| **§463** | 合同编**调整范围**:财产性合同 |
| **§464** | 合同定义 + **身份关系协议参照** |
| **§465** | 依法成立受保护 + **[[合同相对性]]** |
| **§466** | 合同条款解释 |
| **§467** | **[[无名合同]]** 适用通则 + 参照最相类似 |
| **§468** ⭐ | **非合同之债参照通则**(接口条款) |

### 5 大易混对照

#### ① 合同之债 vs 非合同之债

| 类型        | 内容                       |
| --------- | ------------------------ |
| **合同之债**  | 双方说好的([[合同编]])           |
| **非合同之债** | 不是约定来的(侵权 / 无因管理 / 不当得利) |

→ 详见 [[债的发生原因]]

#### ② 有专门规定 vs 没专门规定(§468 接口条款)

```
非合同之债
  ↓
① 先找它自己的专门规定(侵权编 / 准合同两章)
  ↓ 找不到且性质不冲突
② 参照合同编通则(§468)
```

→ **口诀:特别规定优先,通则兜底(性质排斥的除外)**

#### ③ 有名合同 vs 无名合同(§467)

| 类型             | 内容                    |
| -------------- | --------------------- |
| **有名合同**(典型合同) | 法典点过名、有专章(如 [[买卖合同]]) |
| **无名合同**       | 法律没专门规定的新型合同          |

→ **无名合同适用通则 + 参照最相类似的典型合同**
→ 详见 [[无名合同]]

#### ④ 合同相对性 vs 法定例外(§465)

| 原则 | 例外 |
|---|---|
| **只约束签字双方**([[合同相对性]]) | **[[代位权]] / [[撤销权]] 及于第三人**、买卖不破租赁等 |

→ 详见 [[合同相对性]]

#### ⑤ 财产性合同 vs 身份关系协议(§464 II)

| 类型 | 适用 |
|---|---|
| **财产性合同**(买卖 / 租赁) | 合同编**直接管** |
| **身份关系协议**(结婚 / 收养 / 监护) | **身份法优先**,合同编只**根据性质参照** |

## 🚗 老王小李"4 种债 + 5 大子规则"完整故事

### 4 种债的发生原因

> 老王和小李之间能生出**债**的方式有好几种:

| 类型 | 故事 | 法条 |
|---|---|---|
| **合同之债** | 老王卖车给小李,小李欠车款 | [[合同编]] §463 起 |
| **侵权之债** | 老王骑车撞坏小李的车 → 老王欠赔偿 | [[侵权责任编]] §1165 起 |
| **无因管理之债** | 小李出差,老王没义务却帮他喂猫 + 垫猫粮钱 | §979 起 |
| **不当得利之债** | 小李转账手滑多转老王 1000 → 老王欠这 1000 | §985 起 |

→ 4 种都是**[[债]]**,规则上**先找自己的章节,再回合同编通则借用 §468**。

### 5 大子规则详解

#### 子规则 1:§468 接口条款 — 撞车赔偿怎么履行?

> 老王骑车撞坏小李的车 → 欠赔偿(侵权之债)
> 这笔"赔偿之债"怎么履行?能不能抵销小李欠老王的别的钱?

→ **侵权责任编**没细说"履行 / 抵销" → **§468 参照合同编通则**!
→ 通则里的 [[抵销]](§568)、[[同时履行抗辩权]](§525) 等都能用上。

#### 子规则 2:§467 无名合同 — "房屋换教学"是什么合同?

> 老王给小李"用一年房子",小李给老王"教钢琴一年"。
> 民法典里没"房屋互换教学合同"这种典型 → **无名合同**!

→ 适用 [[合同编]] 通则 + 参照**最相类似**的典型合同:
   - 房屋使用 → 参照 [[租赁合同]]
   - 教学服务 → 参照 [[委托合同]]
→ 详见 [[合同通则-多选-02]] 真题

#### 子规则 3:§465 合同相对性 — 隔壁老张能不能告?

> 老王和小李的买卖合同 → **只约束**老王和小李。
> 隔壁**老张**对车有兴趣 → 不能基于这个合同主张任何权利!

→ 合同是**俩人之间的事**,原则上**外人不沾**
→ **法定例外**:[[代位权]](§535)/ [[撤销权]](§538) 及于第三人、买卖不破租赁(§725)
→ 详见 [[合同相对性]]

#### 子规则 4:§464 II 身份协议 — 老王小李婚前财产协议怎么管?

> 老王和小李谈恋爱,准备结婚 → 写了"婚前财产协议"。
> 此时还涉及到**结婚意愿**本身。

→ **婚姻家庭编优先**(身份法)
→ 合同编**只能根据性质参照**(如争议解决、生效要件)
→ 不能直接套买卖合同那套规则

#### 子规则 5:§464 §466 — 合同条款怎么解释?

> 老王小李合同写"按市价交付" → 什么叫"市价"?
> → §466 合同解释规则启动 → 参考 [[合同解释]]

## 怎么考 / 坑在哪

### 命题定位:框架性 + 低频

- **客观题**:偶尔点状出现"产生的是哪种债"、"非合同之债能否参照通则"等
- **主观题**:几乎不单独成题,但它是案例的**前置定性**入口

### 六大陷阱

1. **以为民法典有独立"债法总则"**——没有,合同编通则兼任
2. **把非合同之债一律套合同编通则**——要先找它自己的规定,§468 只是兜底
3. **把无名合同当"无法可依"**——适用通则 + 参照最相类似
4. **忽视合同相对性的法定例外**([[代位权]] / [[撤销权]] / 买卖不破租赁)
5. **身份协议直接套合同编**——应身份法优先,合同编只"参照"
6. **混淆债的发生原因**,尤其 [[无因管理]] vs [[不当得利]]

### 📐 客观题答题四步走

```
第 1 步:认债从哪来(合同 / 侵权 / 无因 / 不当)
第 2 步:找它自己的规则(合同编 / 侵权编 / 准合同章)
第 3 步:没专门规则 → 参照合同编通则(§468)
第 4 步:特殊判断(无名合同 / 身份协议 / 合同相对性)
```

### 关键词触发表

| 触发词 | → 适用 |
|---|---|
| "双方约定 / 签了协议" | → 合同之债 |
| "造成损害" | → 侵权之债 |
| "没义务、为他人管理事务" | → 无因管理 |
| "没有合法根据获得利益" | → 不当得利 |
| "法律没专门规定的新型合同" | → 无名合同(§467) |
| "非合同之债 + 履行 / 抵销 / 转让没规定" | → 参照合同编通则(§468) |
| "结婚 / 收养 / 监护协议" | → 身份法优先 |
| "合同管不管第三人" | → 原则相对性(§465) |
