# 债务承担

> 债务人把**债务**转给第三人 / 让第三人加入 — [[合同总则]] **转让**之另一半（与 [[债权转让]] 对称）

## 法条范围

[[合同编]] §551-§554（债务转移）+ §391/§697（担保人书面同意免责）+ [[合同编通则司法解释]]§51（债务加入人追偿 · "9 大创新"之一）

## 是什么 / 易混

债务承担 = **债务主体的变动**。分两型，分水岭是**原债务人退没退**：

| 类型                | 法条   | 原债务人             | 生效要件         | 为什么                 |
| ----------------- | ---- | ---------------- | ------------ | ------------------- |
| **免责的债务承担**（债务转移） | §551 | **退出**（全部）/ 部分卸下 | 须债权人**同意**   | 换人可能让债主收不回钱，须债主点头   |
| **并存的债务承担**（债务加入） | §552 | **不退**，与新人**连带** | **通知**债权人即生效 | 多个责任人**对债主有利**，无需同意 |

### 免责的债务承担（§551）
- **§551①**：债务人将债务的全部或部分转移给第三人的，应当经**债权人同意**。
- **§551②**：债务人或第三人可催告债权人在合理期限内同意，债权人**未作表示 = 视为不同意**。
- 效果：原债务人（就转移部分）**脱离**债务关系，新债务人取代。

### 并存的债务承担 / 债务加入（§552）
- 第三人与债务人约定加入债务并**通知**债权人，或第三人**直接向债权人**表示愿意加入、债权人未在合理期限内**明确拒绝** → 债权人可请求第三人在其**愿意承担的范围内**与债务人承担**连带债务**。
- 三特征：① **加入**而非取代（原债务人仍在）；② **通知即生效**（不需同意，因对债主有利）；③ **有限额**（只在承诺范围内负责，C1-多选-34：承诺 100 万就 100 万）。

### 抗辩与抵销（§553）／从债务（§554）
- **§553**：新债务人可主张原债务人对债权人的**抗辩**；但原债务人对债权人享有债权的，新债务人**不得**主张抵销。
- **§554**：新债务人应承担与主债务有关的**从债务**，专属于原债务人自身的除外。（条号：抗辩/抵销＝§553，从债务＝§554）

### 债务加入人的追偿权（通则解释 · "9 大创新"之一）
- 旧法时代学理有争议：债务加入人替还后能否向原债务人追偿？
- **通则解释明确**：并存的债务承担人（债务加入人）清偿后，**有权在其承担的范围内向原债务人追偿**（当事人另有约定的除外）—— 参照 §519 连带债务内部分担法理。
- → C1-单选-59 中"乙对外清偿后向约定承债人戊求偿"即此理。

### §391 担保人免责（债务转移的连锁反应）
- **§391**：第三人提供担保，**未经其书面同意**，债权人允许债务人转移全部或部分债务的，担保人对**转移的部分**不再承担担保责任。
- 三个要点：① 要件是担保人**书面**同意，口头 / 电话不够；② 免责的只是**转走的那部分**，留下的仍保；③ 债务转移**本身有效、不以担保人同意为前提**，未同意的后果是"**担保人脱责**"，不是"转让须经担保人同意"（C1-多选-33：500 万转走 200 万、仅电话通知钱某 → 钱某只保剩下 300 万）。

## 怎么考 / 坑在哪

### 四大陷阱
1. **债权转让 vs 债务转移的"同意"差异**：[[债权转让]] 只需**通知**（§546）；免责的债务转移须债权人**同意**（§551）。题目常把"债权转让须同意"安到你头上（C1-单选-52 的 A 选项是镜像陷阱）。
2. **并存 vs 免责看"原债务人退没退"**：没退 = 并存（§552 通知即生效）；退了 = 免责（§551 须同意）。把"债务加入须债权人同意"当成对的就中招（C1-多选-34 的 D）。
3. **§391 别选反**：免责的是**转走的部分**，担保人只保**留下的**（C1-多选-33：保 300 不是 200）。
4. **"无效"是常见干扰项**：债务转移未经同意 / 债权转让未通知，多是**对外不生效 / 不对抗**问题，**不是"无效"**；内部约定仍有约束力、可据以求偿（C1-单选-59 的 C 错、D 对）。

### 债务加入 vs 保证（高频易混）
| | 债务加入（并存承担）| [[保证合同]] |
|---|---|---|
| 责任顺位 | 与债务人**同一顺位**、连带 | **补充性**（一般保证有**先诉抗辩权**）|
| 从属性 | **独立**债务（无从属性）| **从属**于主债务 |
| 对第三人 | 责任**重** | 责任**轻** |

- **性质不明时** → **推定为保证**（保证责任较轻、对第三人有利；担保解释§36 第二款"难以确定保证还是债务加入的，认定为保证"）。

> 📐 **完整辨析解题套路** → [[民法-合同-保证与债务加入辨析模型]]（保证 / 债加入 / 安慰函 / 免责承担四选一 + 意思不明推定为保证 §36 + 法代以公司名义加入债务参照公司担保 §12）

## 怎么答

债务承担分析四步（概念框架）：
1. **定型**：原债务人退出了吗？退 = 免责（§551）；没退、一起扛 = 并存 / 债务加入（§552）。
2. **生效**：免责 → 债权人**同意**了吗（未表示 = 不同意）？并存 → **通知**到达 / 债权人未明确拒绝即可。
3. **担保**：有第三人担保吗？债务转移未经担保人**书面**同意 → 担保人对**转移部分**免责（§391）。
4. **追偿**：债务加入人 / 替清偿人对外清偿后，可在承担范围内向原债务人**追偿**。

## 🚗 老王小李故事

> 老王欠债主张三 10 万块。
>
> **场景一（免责承担 §551）**：老王想让小李替他还这 10 万、自己**彻底退出**。这等于"换债务人"——万一小李是穷光蛋，张三就收不回钱了，所以**必须张三点头同意**才算数；张三被催告后还**装聋不表态，就视为不同意**（§551②）。
>
> **场景二（并存承担 / 债务加入 §552）**：小李不忍心，说"老王这债我**也一起扛**，但我只认 8 万"，并**通知**了张三。这回老王**没退**，等于多了个还钱的人，对张三是**好事**——所以**通知一到就生效，不用张三同意**；小李也只在自己认的 **8 万**范围内与老王**连带**负责（§552 有限额）。
>
> **场景三（担保人免责 §391）**：当初赵六拿房子替老王这笔债作了抵押担保。如今老王把其中 4 万的债搬给了小李，只给赵六**打了个电话**（没让赵六**书面**签字同意）。赵六还保多少？——只保**没搬走的 6 万**；搬走的 4 万没经他书面点头，他**不保了**。
>
> **场景四（加入人追偿）**：小李作为债务加入人真替老王还了钱，回头能**找老王把这部分要回来**（追偿）——这是通则解释"9 大创新"敲定的规则。

## 辨析对照表 · 第三人介入债务的四张面孔

| 制度 | 法条 | 债务人是谁 | 关键特征 |
|---|---|---|---|
| **免责的债务承担** | §551 | 新债务人（原退出）| 换人 · 须债权人**同意** |
| **并存的债务承担**（债务加入）| §552 | 原 + 新**连带** | 加人 · **通知**即生效 · 有限额 |
| [[第三人代为履行]]（代为清偿）| §523/§524 | **原债务人不变** | 只是履行人换成第三人；§524 代偿后法定取得债权 |
| [[保证合同]]（保证）| §681 | 原债务人 + 保证人 | **从属** + 补充（一般保证有先诉抗辩权）|
| [[无因管理]] | §979 | —（本无债务关系）| **无义务**为他人管理、可主张必要费用 |
