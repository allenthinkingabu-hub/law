# 无名合同

> 民法典**未明文规定**的合同 — 适用通则 + 参照最相类似的典型合同

## 法条范围

[[合同编]] §467

## 是什么 / 易混

### 定义
**§467**：本法或者其他法律没有明文规定的合同，**适用本编通则的规定**，并可以**参照适用本编或者其他法律最相类似合同的规定**。

→ 又叫"**非典型合同**"。

### 与 [[典型合同]] 对比

| 维度 | 典型合同 | **无名合同** |
|---|---|---|
| 法律规定 | 民法典**专章规定** | **未规定** |
| 适用规则 | 该类合同特别规定 + 通则 | **通则** + 参照最相类似典型 |
| 案例 | 买卖 / 租赁 / 保证等 19 类 | 房屋互换教学服务 / 装修分期等 |

### 适用规则的双重路径

```
无名合同
   ↓
①  适用 [[合同编]] **通则**（订立 / 效力 / 履行 / 违约责任 等）
   ↓
②  **参照适用最相类似**的典型合同章节
```

### 典型案例（C1-多选-02）
**甲乙互换**：甲提供房屋无偿使用 + 乙免费教钢琴
- **无名合同**（民法典未单独规定）
- **有偿合同**（双向给付：房屋使用 ↔ 钢琴课）
- 适用**通则**（合同效力 / 履行 / 违约）
- 参照**租赁合同**（房屋使用方面）+ **委托合同**（提供教学服务方面）

## 怎么考 / 坑在哪

### 三大陷阱

1. **互换型合同 = 有偿**：双向给付 = 有偿，不要看"无偿提供"字面
2. **可同时参照多个典型合同**：本题既参照租赁又参照委托
3. **通则始终适用**：基础规则不变
