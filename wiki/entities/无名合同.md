# 无名合同

> 民法典**未明文规定**的合同 — 适用通则 + 参照最相类似的典型合同

## 法条范围

[[合同编]] §467

## 是什么 / 易混

### 定义
**§467**：本法或者其他法律没有明文规定的合同，**适用本编通则的规定**，并可以**参照适用本编或者其他法律最相类似合同的规定**。

→ 又叫"**非典型合同**"。

### 与 [[典型合同]] 对比

| 维度 | 典型合同 | **无名合同** |
|---|---|---|
| 法律规定 | 民法典**专章规定** | **未规定** |
| 适用规则 | 该类合同特别规定 + 通则 | **通则** + 参照最相类似典型 |
| 案例 | 买卖 / 租赁 / 保证等 19 类 | 房屋互换教学服务 / 装修分期等 |

### 适用规则的双重路径

```
无名合同
   ↓
①  适用 [[合同编]] **通则**（订立 / 效力 / 履行 / 违约责任 等）
   ↓
②  **参照适用最相类似**的典型合同章节
```

### 典型案例（C1-多选-02）
**甲乙互换**：甲提供房屋无偿使用 + 乙免费教钢琴
- **无名合同**（民法典未单独规定）
- **有偿合同**（双向给付：房屋使用 ↔ 钢琴课）
- 适用**通则**（合同效力 / 履行 / 违约）
- 参照**租赁合同**（房屋使用方面）+ **委托合同**（提供教学服务方面）

### ⚠️ "对价陷阱" — 字面"免费"≠ 实质无偿

[[合同通则-多选-02]] 题干故意写"**无偿提供 + 免费教学**" → 测试你是否真懂"**有偿**"的定义!

**"有偿"≠ 用钱付** — 只要双方都付出**有价值的对价**就是有偿!

| 形式 | 看着像 | 实质 |
|---|---|---|
| 一方给钱（买卖）| 有偿 | ✅ 有偿 |
| 物换物（互易）| 有偿 | ✅ 有偿 |
| **物换服务**（房屋换教学）| "免费" | ✅ **有偿!** |
| 服务换服务 | "互相帮忙" | ✅ 有偿 |
| 物换"看广告" | "免费" | ✅ 有偿（注意力对价）|
| 单方给苹果不要回报 | 赠与 | ❌ 无偿 |

→ Q02 B 选项的核心陷阱!

### 现实生活中的无名合同（扩展）

| 例子 | 最相类似的典型合同 |
|---|---|
| 健身房 + 私教合同 | 服务合同（委托?承揽?）|
| 婚介服务 | 委托 + [[中介合同]] |
| 学校 + 学生教育协议 | 服务合同 |
| 美容护肤服务 | 服务 + [[承揽合同]] |
| 物业管家全套服务 | 委托 + [[物业服务合同]] |
| 早教 / 培训机构 | 服务 + 教育合同 |
| 共享办公 | [[租赁合同]] + 服务 |

→ 现实生活有**大量**无名合同 — 别以为典型合同就够用!

## 怎么考 / 坑在哪

### 三大陷阱

1. **互换型合同 = 有偿**：双向给付 = 有偿，不要看"无偿提供"字面
2. **可同时参照多个典型合同**：本题既参照租赁又参照委托
3. **通则始终适用**：基础规则不变

## 真题示例

- [[合同通则-多选-02]] **互换型无名合同**（答 ABCD）— §467 知识链完整考查:识别 + 有偿陷阱 + 双层适用规则
  - A 无名合同识别 ✅
  - B 有偿合同（"免费"字面陷阱）✅
  - C §467 第一层 适用通则 ✅
  - D §467 第二层 参照租赁 + 委托（可多个）✅
