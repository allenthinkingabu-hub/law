# 供用电合同

> **公益性 + 强制缔约**的公共事业合同代表（含供水 / 气 / 热力 4 兄弟）

## 法条范围

[[民法典]] §648-§656 + 参照供用水 / 气 / 热力（§656）

## 是什么 / 易混

### 定义
**§648**：供电人向用电人**供电**，用电人**支付电费**的合同。

### 关键特征
| 特征 | 内容 |
|---|---|
| **公益性** | 公共事业 → **强制缔约**（供方不得拒绝合理用户）|
| **履行地点** | 没约定 → **供电设施产权分界处** |
| **通知义务** | 计划检修 / 临时检修 / 限电 / 违法用电 → **应当事先通知** |

### 四兄弟（一起记）
- 供用**电** §648-§655
- 供用**水**、供用**气**、供用**热力** § 656（参照供电规则）

## 欠费的法律后果：只能"中止"，不能"解除"（核心考点）

**§654**：用户**逾期不付费** → 供应方经**催告**、合理期限内仍不付（含违约金）→ 可按国家规定程序**中止供应**；**中止前应当事先通知**用户。**§656**：供水 / 气 / 热**参照**适用。

> 🔑 公用事业合同**强制缔约 + 公益性** → 供应方**没有"解除 / 终止"合同的权利**，对欠费用户只能"**暂停**"（中止）；用户补清欠费 + 违约金后须**立即恢复**供应。

### 中止 ≠ 解除 ≠ 终止（高频偷换陷阱）

| 概念 | 效果 | 合同关系 | 供应方能否对欠费用户用 |
|---|---|---|---|
| **中止** | 暂停供应 | **仍存续** | ✅ 可（须催告 + 事先通知）|
| **解除** | 消灭合同 | 终结 | ❌ 不可 |
| **终止** | 消灭合同 | 终结 | ❌ 不可 |

### 🚗 老王小李故事

- 小李拖欠 3 个月电费 → 供电公司**先催告**给合理期限、仍不交 → **事先通知**后**中止供电**（§654）。小李补清电费 + 违约金 → 供电公司**必须立即恢复**。
- ❌ 供电公司**不能**因欠费就"解除供电合同"一拍两散——强制缔约的公用事业，不是普通买卖。
- ⚠️ 跨界对照：若是**物业**催**物业费**，物业**连"中止"都不行**——**不得停水 / 停电 / 停热 / 停气**，只能**诉讼 / 仲裁**（§944，见 [[物业服务合同]]）。

## 怎么考 / 坑在哪

### 三大陷阱

1. **公益性 ≠ 无偿性**（C2-单选-05）：
   - 无偿是"**不收钱**"，公益是"**服务公共**"
   - **赠与无偿但非公益**；供电是**有偿但公益**

2. **履行地点 = 产权分界处**（§651）：
   - 不是营业地，不是用电人所在地
   - 谁的设施谁负责

3. **中断供电的赔偿**（§654 + §655）：
   - 计划检修 / 临时检修 / 限电 → 未事先通知 → **担责**
   - **用电人违法用电** → 供电人合法中止 → **不担赔偿**

## 怎么答

主观题分析框架：
1. 是否供用电关系？
2. 中断是否经通知？
3. 是否用电人自身违法？
4. 损失如何赔偿？
