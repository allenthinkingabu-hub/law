# 供用电合同

> **公益性 + 强制缔约**的公共事业合同代表（含供水 / 气 / 热力 4 兄弟）

## 法条范围

[[民法典]] §648-§656 + 参照供用水 / 气 / 热力（§656）

## 是什么 / 易混

### 定义
**§648**：供电人向用电人**供电**，用电人**支付电费**的合同。

### 关键特征
| 特征 | 内容 |
|---|---|
| **公益性** | 公共事业 → **强制缔约**（供方不得拒绝合理用户）|
| **履行地点** | 没约定 → **供电设施产权分界处** |
| **通知义务** | 计划检修 / 临时检修 / 限电 / 违法用电 → **应当事先通知** |

### 四兄弟（一起记）
- 供用**电** §648-§655
- 供用**水**、供用**气**、供用**热力** § 656（参照供电规则）

## 怎么考 / 坑在哪

### 三大陷阱

1. **公益性 ≠ 无偿性**（C2-单选-05）：
   - 无偿是"**不收钱**"，公益是"**服务公共**"
   - **赠与无偿但非公益**；供电是**有偿但公益**

2. **履行地点 = 产权分界处**（§651）：
   - 不是营业地，不是用电人所在地
   - 谁的设施谁负责

3. **中断供电的赔偿**（§654 + §655）：
   - 计划检修 / 临时检修 / 限电 → 未事先通知 → **担责**
   - **用电人违法用电** → 供电人合法中止 → **不担赔偿**

## 怎么答

主观题分析框架：
1. 是否供用电关系？
2. 中断是否经通知？
3. 是否用电人自身违法？
4. 损失如何赔偿？
