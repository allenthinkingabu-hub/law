# 间接代理

> [[委托合同]] 项下 — **受托人"以自己名义"为委托人与第三人订约**；两条线 §925（知道→直接归属）/ §926（不知道→披露 + 介入权 / 选择权）

## 法条范围

[[合同编]] §925-§926（委托合同章）

## 是什么 / 易混

### 定义

**间接代理**＝受托人**以自己的名义**、在委托人**授权范围内**、为委托人利益与第三人订立合同。
"间接"对照的是 **直接代理（显名代理）**——后者以委托人名义行事、合同直接约束委托人（§162）。

| 维度 | 直接代理（§162）| **间接代理（§925/§926）** | 行纪（§951）|
|---|---|---|---|
| 以谁名义 | 委托人名义 | **受托人自己名义** | 行纪人自己名义 |
| 合同后果 | 直接约束委托人↔第三人 | **原则约束受托人↔第三人，§925/§926 可打通到委托人** | 行纪人**永远是当事人**，委托人与第三人**无合同** |
| 能否穿透到委托人 | —（本就是委托人）| **能**（§925 知道即直接约束；§926 披露后介入/选择）| **不能** |

> 🔎 **法条已联网核实**：§925/§926 逐字原文随 [[民法-合同-委托行纪中介模型]] 7 路对抗式复核（最高检 spp.gov.cn + 国家法律法规数据库）一并 CONFIRMED。

### 启动三前提
① 受托人**以自己名义** ② 在**委托人授权范围内** ③ 与**第三人**订约。三者齐备才走 §925/§926。

### 总开关：第三人订约时"知不知道"有委托人

```
受托人以自己名义与第三人订约
   ├─ 第三人订约时【知道】有委托人 ──► §925 直接归属
   └─ 第三人订约时【不知道】有委托人 ─► §926 披露线
            ├─ 因【第三人】原因不履行 → 披露第三人 → 委托人【介入权】
            └─ 因【委托人】原因不履行 → 披露委托人 → 第三人【选择权】
```

### 第一条线 · §925 直接归属（第三人"知道"）

> **原文**：受托人以自己的名义，在委托人的授权范围内与第三人订立的合同，第三人在订立合同时**知道**受托人与委托人之间的代理关系的，**该合同直接约束委托人和第三人**；但是，有**确切证据**证明该合同**只约束受托人和第三人**的除外。

- 第三人本就知道真正的相对人是委托人 → 合同直接落在委托人↔第三人之间（受托人退场），效果≈直接代理。
- **但书**：有确切证据证明只约束受托人与第三人的，不归属委托人。

### 第二条线 · §926 披露 +（介入权 / 选择权）（第三人"不知道"）

> ⚠️ **发动闸（铁则）**：§926 的介入权与选择权**都以"受托人不履行义务"为共同前提**——受托人不违约，就不发生披露与穿透。再分"对谁不履行 + 因谁的原因"决定哪条穿透打开。**对照 §925：直接归属"知道就通"、根本不问违约。** 一句话——**§925 知道就通，§926 违约才通。**

> **原文**：受托人以自己的名义与第三人订立合同时，第三人**不知道**受托人与委托人之间的代理关系的——
> **(a)** 受托人因**第三人**的原因对委托人不履行义务，受托人应当**向委托人披露第三人**，委托人因此可以**行使受托人对第三人的权利**（＝**委托人介入权**），但是第三人与受托人订立合同时如果知道该委托人就不会订立合同的除外；
> **(b)** 受托人因**委托人**的原因对第三人不履行义务，受托人应当**向第三人披露委托人**，第三人因此可以**选择**受托人或者委托人作为相对人主张其权利（＝**第三人选择权**），但是第三人**不得变更**选定的相对人。

**记忆钩子**：谁是"违约源头的隔壁那方"，谁就拿到突破相对性的权利——**第三人坑了委托人 → 委托人去追第三人（介入）；委托人坑了第三人 → 第三人挑一个告（选择，选了不能改）。**

### 🚗 老王小李"以自己名义买货"故事
> 小李受老王委托、**以自己名义**向老张买货。

- ① 老张签约时**知道**小李替老王买 → 合同**直接约束老王与老张**（§925）。
- ② 老张**不知**有老王，后老张迟延、小李交不出货 → 小李披露老张，**老王可直接向老张追**（介入权 §926）。
- ③ 老张**不知**有老王，后老王不付款、小李对老张违约 → 小李披露老王，**老张可选择**告小李或老王（选择权 §926，选定不得变更）。

## 怎么考 / 坑在哪

1. **§926"介入权" ≠ §956"介入权"**（同名不同义）：§926＝委托人**介入到受托人与第三人的合同**直接主张；§956＝**行纪人**在商品有市场定价时**自任买受人 / 出卖人**。互换即错。
2. **间接代理 ≠ 行纪**：都"以自己名义"，但行纪人**永远是合同当事人、不可被穿透**（委托人与第三人无合同）；间接代理可经 §925/§926 打通到委托人。
3. **两条线触发条件别错配**：§925 看"**订约时知不知道**"；§926 内部再看"**谁的原因不履行**"。把"第三人原因"配"选择权"、"委托人原因"配"介入权"是经典反向坑。
4. **§925＝直接归属，不是介入权**：§925 的关键词是"第三人**知道**→直接约束"；**介入权和选择权都在 §926**。把介入权挂到 §925 是常见条号错。
