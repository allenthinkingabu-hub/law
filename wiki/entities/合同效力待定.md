# 合同效力待定

> [[合同效力分级]] 之 ④ —— **效力悬置 + 待权利人追认**

## 法条范围

[[总则编]] §145（限制行为能力人）/ §171（无权代理）/ [[合同编]] §503（无权处分）

## 是什么 / 易混

### 核心特征
- 合同**已成立但效力未定**
- 经**有权人追认** → **有效**（追溯到成立时）
- 不追认 / 拒绝 → **无效**
- 第三人**有撤销权 / 催告权**（保护交易安全）

### 3 大效力待定情形

| # | 情形 | 追认人 | 法条 |
|---|---|---|---|
| ① | **限制民事行为能力人**实施超出范围的合同 | 法定代理人 | §145 |
| ② | **无权代理**（无代理权 / 超越代理权 / 代理权终止后）| **被代理人** | §171 |
| ③ | **无权处分** | 权利人 | §503 / 物权编 §311 善意取得 |

### 追认与撤销规则

#### 限制行为能力人合同（§145）
| 情形 | 处理 |
|---|---|
| 纯获利益 / 与年龄智力相适应 | **直接有效** |
| 超出范围 | 效力待定 |
| 法定代理人**追认** | 有效 |
| 拒绝 / 1 个月未表示 | **视为拒绝** = 无效 |
| 善意相对人在追认前 | **可撤销** |

#### 无权代理（§171）
| 情形 | 处理 |
|---|---|
| 被代理人**追认** | 有效 |
| 不追认 | 无效 |
| 相对人**催告**（30 日内追认）| 期间届满未追认 = 视为拒绝 |
| 善意相对人 | 追认前**有撤销权**——以通知方式 |

#### 无权处分（§503）
- 处分人**事后取得**处分权 → 有效
- 权利人**追认** → 有效（按 [[请求权基础]] 框架处理）

### 默示追认
**§140 II**：未明确表示**但行为表明追认** → 视为追认
- 接受履行
- 主动履行
- 主张合同权利

## 怎么考 / 坑在哪

### 四大陷阱

1. **追认 vs 撤销 vs 拒绝**：三种结果
2. **默示追认**（C1-单选-14）：行为表明 = 视为追认
3. **善意相对人撤销权**：在追认前可撤销
4. **效力待定 vs 可撤销**：
   - 待定：**权利人决定** → 追认 / 拒绝
   - 可撤销：**受损方决定** → 撤销 / 不撤销

## 怎么答

主观题分析框架：
1. **识别**：是哪种效力待定？
2. **是否纯获利益 / 适应年龄**（§145 例外）？
3. **追认人**是谁？是否追认（含默示）？
4. **善意相对人**：是否催告？是否撤销？
5. **追认 / 拒绝后**：分别按有效 / 无效处理

## 🚗 老王小李故事（先悬着，等有权人拍板）

> 老王和小李的几桩"效力悬着、等老板追认"的买卖：
> - 老王**15 岁的儿子小小王**背着大人，把家里电脑卖给小李（**限制行为能力人**超范围 §145）→ **效力待定**，等老王（法定代理人）**追认**才有效；老王拒绝 / 装聋满 30 天 → **视为拒绝** = 无效。
> - 老王的**邻居老赵没经授权**，冒充老王代理人把车卖给小李（**无权代理** §171）→ **效力待定**，等老王追认。
>
> 相对人小李的护身符：① **善意**（不知情）时，追认前可**撤回**；② 可**催告**老王 30 日内表态，逾期 = 拒绝。老王要是**开始履行 / 收了钱**，就算**默示追认**（§140 II）= 有效（真题 [[合同通则-单选-14]]）。
> ⚠️ 两个易混：① 老赵若**握有"像有授权"的凭证**（公章 / 残留授权书）→ 构成**表见代理**（§172）→ 合同**直接有效**护着善意的小李，**不是**效力待定；② **无权处分**在民法典下：**负担行为（债权合同）有效**（§597），别再套旧法说"整个合同效力待定"。
