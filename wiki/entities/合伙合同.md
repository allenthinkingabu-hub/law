# 合伙合同

> 两个以上合伙人为了**共同的事业目的**，订立的**共享利益、共担风险**的协议 —— [[合同编]] 第二十七章，**2021 民法典新设典型合同**（把"个人合伙/民事合伙"升为有名合同）。灵魂＝**共担风险**；区别于《合伙企业法》的**商事合伙**（须登记、有普通/有限之分）。

## 是什么 / 易混

### 定义与本质（§967）

**§967**：合伙合同是两个以上合伙人为了共同的事业目的，订立的共享利益、共担风险的协议。

| 要素 | 内容 |
|---|---|
| **共同事业目的** | 为同一事业共同经营 |
| **共享利益** | 按 §972 分配利润 |
| **共担风险** | **核心标志**——没有风险共担≠合伙 |
| **是否登记** | **不以登记为要件**（区别于合伙企业；"未登记"不影响合伙合同成立，但无"用人单位"资格）|

> ⚠️ **真假合伙（第一大考点）**：**固定回报 + 不担风险 + 期满还本 = 名为合伙实为借贷**——合伙外壳无效（§146Ⅰ），隐藏的借款有效（§146Ⅱ，利率仍卡 §680 LPR×4）。见 [[借款合同]]、[[典型合同-多选-41]]。

### 对内：财产 / 执行 / 分配

| 主题 | 条文 | 要点 |
|---|---|---|
| **合伙财产共有** | §969 | 出资+收益+其他财产=合伙财产；**终止前不得请求分割** |
| **出资义务** | §968 | 按约定的方式、数额、缴付期限履行出资 |
| **事务执行** | §970 | 原则**全体共同执行**；可委托一个或数个合伙人；未执行者**有监督权**；分别执行可**提异议→异议后暂停**；事务决定原则**全体一致同意** |
| **执行无报酬** | §971 | **不得因执行合伙事务请求报酬**，约定除外（≠委托 §928 有偿）|
| **损益分配** | §972 | 三级瀑布：**约定→协商→实缴出资比例→平均**（"实缴"非认缴）|

### 对外：连带责任（§973 / §975）

- **§973**：合伙人对**合伙债务**承担**连带责任**；超份额清偿可向其他合伙人**追偿**。
- ⚠️ **连带只认"合伙债务"**——合伙人**个人侵权 / 个人消费 / 超授权行为**不是合伙债务，其他合伙人**不连带**（[[典型合同-多选-42]]）。
- **§975**：合伙人的债权人**不得代位**行使其合伙权利，**但利益分配请求权除外**。

### 变动与终止

| 主题 | 条文 | 要点 |
|---|---|---|
| **份额对外转让** | §974 | 向**合伙人以外的人**转让须**其他合伙人一致同意**（对内转让不限）|
| **不定期合伙** | §976 | 期限不明依§510 仍不能确定=不定期；期满续干无异议→转不定期；**可随时解除，应合理期限前通知** |
| **终止事由** | §977 | 合伙人**死亡/丧失行为能力/终止→合同终止**；**约定或依性质不宜终止除外** |
| **终止清算** | §978 | 付费用+清偿合伙债务后剩余，**依§972分配** |

## 怎么考 / 坑在哪

1. **名为合伙实为借贷**——固定回报+不担风险=借贷，壳无效/核有效（§146/§680）。
2. **连带责任无边界**——只认"合伙债务"，个人侵权自担（§973）。
3. **损益按"认缴"**——错，是**实缴**出资比例（§972）。
4. **份额对外转让"过半数"**——错，**一致同意**（§974）。
5. **终止前分割财产**——错，§969 终止前不得请求分割。
6. **执行事务当然有报酬**——错，§971 原则无报酬。
7. **不定期合伙不能解除**——错，§976 可随时解除（提前合理通知，条号非 §786）。
8. **死亡必散伙**——不一定，§977 有例外。

## 怎么答

按 [[民法-合同-合伙模型]] 四步：①**定性**（真合伙 vs 名为合伙实为借贷，看共担风险）→ ②**对内三件事**（财产共有§969 / 执行§970-971 / 分配§972）→ ③**对外连带**（只认合伙债务§973、债权人代位限制§975）→ ④**变动与终止**（对外转让§974 / 不定期随时解除§976 / 死亡终止§977 / 清算§978）。
