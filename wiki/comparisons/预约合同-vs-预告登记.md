# 预约合同 vs 预告登记

> **一句话区分**：预约合同管"**签不签**正式合同"（债权），预告登记管"**能不能拿到**房子所有权"（物权）——交易的不同阶段。

## 核心对比表

| 维度 | 预约合同 | 预告登记 |
|---|---|---|
| **所属编章** | **合同编**（债权关系） | **物权编**（物权保全） |
| **法条依据** | §495（预约合同条款） | §221（预告登记条款） |
| **法律性质** | 债权合同（约定将来签本约） | 物权保全手段（登记行为） |
| **出现时机** | **签本约之前** | **签本约之后、过户之前** |
| **典型文件** | 认购书、意向书、订购书 | 不动产登记簿上的登记 |
| **主要功能** | 锁定交易机会、防止反悔 | 防止一房二卖、锁死产权 |
| **违反后果** | 违约责任（退定金/赔损失） | 不发生物权效力（产权仍属你） |
| **时效性** | 临时约束力（到期需订立本约） | 临时保护效力（90日，可续期） |
| **能否强制执行** | ❌ 不能强制过户 | ✅ 可直接要求过户 |

## 完整买房流程对照

```
老王看中房子
    ↓
第一步：签预约合同 ← **预约合同在这里**
├─ 行为：与小李签《认购书》
├─ 约定：3个月内签正式合同
└─ 作用：锁定交易、防止卖家反悔
    ↓
第二步：签本约（正式合同）
├─ 双方签《商品房买卖合同》
└─ 老王付定金或首付款
    ↓
第三步：办预告登记 ← **预告登记在这里**
├─ 行为：去不动产登记中心办理
├─ 作用：登记簿上标记"准物权人"
└─ 保障：防止卖家再卖给别人、抵押给银行
    ↓
第四步：交房、办过户
├─ 交房完成
└─ 办理正式过户
    ↓
老王获得完整所有权
（预告登记自动失效）
```

## 高频陷阱 / 法考秒杀判断

### 关键词识别

**选"预约合同"的信号：**
- 出现"认购书"、"订购书"、"订立本约"、"将来合同"
- 问题涉及"签不签合同"、"反悔"、"违约金"
- 时间在"签本约之前"

**选"预告登记"的信号：**
- 出现"登记"、"一房二卖"、"卖给别人"、"保障产权"
- 问题涉及"不发生物权效力"、"物权对抗"、"保护"
- 时间在"签本约之后、过户之前"

### 常见错误

❌ **混淆**：把预约合同当成能锁死产权 → 错，只能锁住签约义务  
❌ **混淆**：把预告登记当成正式产权 → 错，只是临时保全，正式需过户  
❌ **混淆**：预约合同违反可直接要求过户 → 错，只能要求赔损失；预告登记违反才能直接要求过户

## 一句话记忆

**"约为债、登为权；约锁约、登锁权。约违赔、登违转。"**
- 预约合同是**债权约定**，只锁住**双方签约义务**；违反只能要**赔损失**
- 预告登记是**物权保全**，锁住**你的产权权益**；违反可要**直接过户**
