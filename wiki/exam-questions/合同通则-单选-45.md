# C1-单选-45 · 定做玉器送人，履行辅助人碰坏：买方向卖方追违约

## 题干

> 方某为送汤某生日礼物，特向余某定做一件玉器。订货单上，方某指示余某将玉器交给汤某，并将订货情况告知汤某。玉器制好后，余某委托朱某将玉器交给汤某，朱某不慎将玉器碰坏。下列哪一表述是正确的？（2014-3-11）

- A. 汤某有权要求余某承担违约责任
- B. 汤某有权要求朱某承担侵权责任
- C. 方某有权要求朱某承担侵权责任
- D. 方某有权要求余某承担违约责任

## 我的答案

**D**（方某是当事人；朱某是余某的履行辅助人，碰坏 = 余某违约）<!-- confidence: EXTRACTED -->（官方参考答案：D）

## 涉及考点

- 📐 **违约总模型** → [[民法-合同-违约责任模型]]（第三人原因 / 履行辅助人违约 §593）
- [[合同相对性]]
- [[向第三人履行]]（§522① · 涉他合同）
- [[违约责任]]

## 考点精解 · 合同相对性 + 履行辅助人

### 是什么 / 易混

- 合同在**方某（定作人）与余某（承揽人）**之间；约定**向第三人汤某交付**（向第三人履行 §522）。
- **朱某是余某的履行辅助人**：债务人使用的辅助人造成的损害，**视为债务人自己的违约**（§593 因第三人原因违约仍由债务人对相对人负责）。
- 汤某只是收货第三人，非当事人，无合同请求权（A 错）。朱某对汤某不构成独立侵权（玉器此时所有权未及于汤某；朱某是履行辅助人），B 错。方某不能越过合同找朱某侵权（C 错），应找合同相对人余某追违约。

### 怎么考 / 坑在哪

- 履行辅助人（朱某）的过错 = 债务人（余某）的违约，债权人（方某）**向债务人**主张。
- 别被"谁动手碰坏的就找谁"误导——合同纠纷优先走合同相对性。

## 📐 答题口诀 · 履行辅助人闯祸 = 债务人违约；找合同对手算账

> **"我请的人干砸了，算我违约；你（买方）找我（卖方）就对了，别去找我手下那个人。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"债务人委托/雇人去履行，那人弄坏了"          → 履行辅助人过错 = 债务人违约（§593）
"下单的买方 + 找谁"                          → 找合同相对人（卖方）追违约 ★
"收货的第三人要告"                           → 非当事人，无合同请求权
"买方去告卖方的雇员侵权"                      → 撞合同相对性，不选
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A | ❌ | 汤某非当事人，无合同请求权 |
| B | ❌ | 朱某是履行辅助人，对汤某不独立担侵权 |
| C | ❌ | 方某应向合同相对人余某主张，非找朱某 |
| **D** | ✅ | 余某对其履行辅助人朱某之过错负违约责任 |

### 🚗 老王小李故事

> 老王（方某）向师傅小余定做一件玉器，说好送给朋友小汤。小余做好后，雇了小朱去送，小朱手一滑把玉器磕坏了。老王找谁？——找**小余**（自己的合同对手）追违约。小朱是小余请来帮忙的"履行辅助人"，他闯的祸算在小余头上。老王别去找小朱（俩人没合同），小汤也别去找小余（小汤只是收货的，不是签约人）。合同的事，认"签约的两个人"。

### 🎯 一句话记忆

> **"雇来的人弄坏 = 债务人违约；买方找卖方，不找跑腿的，不找收货的。"**

### 填空模板（主观题用）

> 合同在方某与余某之间，约定**【向第三人汤某履行】**。朱某系余某的**【履行辅助人】**，其过错视为**【余某的违约】**（§593）。汤某非当事人**【无合同请求权】**，方某应向合同相对人**【余某】**主张违约。故选 **D**。
