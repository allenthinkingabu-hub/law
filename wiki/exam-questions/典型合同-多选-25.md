# C2-多选-25 · 间接代理：委托人介入权与第三人选择权

## 题干

> 甲委托乙以**乙自己的名义**向丙采购一批货物，丙不知道甲的存在。货物交付后，乙因资金周转困难迟迟未向丙支付货款。下列说法正确的有？

- A. 丙只能向乙追索货款，因甲丙之间无合同关系
- B. 丙知道委托关系后，可直接向甲主张货款，但须以甲对乙尚有未履行的义务为前提
- C. 丙须先向乙穷尽催告，乙拒绝后方可向甲主张
- D. 甲可介入，直接向丙主张因采购产生的权利，但须同时告知丙委托关系的存在

> 🔧 **条号订正（2026-06-15）**：本卡原把"委托人介入权"挂 §925——有误。**介入权与选择权同属 §926**；§925 是"第三人订约时**知道**→合同直接约束委托人与第三人"的**另一条线**。已据 [[民法-合同-委托行纪中介模型]]（联网核实 CONFIRMED）订正，答案 BD 不变。

## 考点精解 · §926 间接代理双向穿透

### 是什么 / 易混

**间接代理**：受托人以**自己名义**与第三人订约。两条线看第三人订约时**知不知道**委托人：

**§925（直接归属）**：第三人订约时**知道**委托关系 → 合同**直接约束委托人与第三人**（本题丙**不知**甲，不走此条）。

**§926（披露 + 介入权 / 选择权）**：第三人**不知道**委托关系时——
> - **委托人介入权**：因**第三人**原因致受托人对委托人不履行 → 受托人向委托人**披露第三人** → 委托人可行使受托人对第三人的权利；
> - **第三人选择权**：因**委托人**原因致受托人对第三人不履行 → 受托人向第三人**披露委托人** → 第三人可**选择**受托人或委托人主张、且**不得变更**。

| 方向           | 法条       | 触发                          | 规则             |
| ------------ | -------- | --------------------------- | -------------- |
| 甲 → 丙（委托人介入） | **§926** | 因**第三人**原因致受托人对委托人不履行、披露第三人 | 甲可行使乙对丙的权利     |
| 丙 → 甲（第三人选择） | **§926** | 因**委托人**原因致受托人对第三人不履行、披露委托人 | 丙可选择告乙或甲（不得变更） |

**本题分析**（丙不知甲、乙未付款）：
- A：披露后丙可**选择**向甲主张（§926），"只能向乙"错误 → A **错**
- B：丙向甲主张＝§926 第三人选择权 → B **正确**
- C：§926 给丙的是**选择权**，不是代位权（无先诉顺位要求，丙直接选择）→ C **错**
- D：甲可介入直接向丙主张（§926 委托人介入权）→ D **正确**

### 怎么考 / 坑在哪

- **A 大坑**："无合同关系 = 不能直接主张"——§926 突破合同相对性，允许双向穿透
- **C 混淆**：把 §926 的选择权误认为代位权（代位权才有先诉顺位要求）
- **§925 vs §926 别记反**（本卡原误把介入权挂 §925，已订正）：
  - **§925** = 第三人订约时**知道** → **直接归属**（合同直接约束委托人与第三人）
  - **§926** = 第三人**不知道** → 披露后，**委托人介入权**（第三人原因不履行 → 找第三人）/ **第三人选择权**（委托人原因不履行 → 挑相对人）

### 怎么答

BD。§926 给丙**选择权**（披露甲后择一主张、不得变更）、给甲**介入权**（披露丙后直接主张）；§925 是"第三人知道→直接归属"的另一条线，本题丙不知甲、不适用。

## 📐 答题口诀

> **间接代理两条线**：第三人**知道**＝§925 直接归属；第三人**不知**＝§926 披露后双向穿透（介入权找第三人 / 选择权挑相对人）。
