# 物权-单选-32 · A公司汽车送修——B公司可对全部车辆留置

## 题干

> A公司长期委托B公司进行汽车维护。A公司一次送来15辆总价值50万元的汽车，并支付了2万元维护费，B公司收费并进行了维护。但拒绝归还维护好的车辆，主张A公司之前欠其20万元维护费未还。下列说法正确的是？(2025金题-2-1-14, 单)

- A. B公司可以进行留置
- B. B公司不可以进行留置
- C. B公司可以全部留置
- D. B公司仅可以对一辆汽车进行留置

## 答案

**A**（企业间留置§448：不需要同一法律关系；A/B两企业之间→B公司可就当前占有的15辆车留置）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2025金题 2-1-14
- 素材：[[2026-06-15-物权编客观真题]]

## 涉及考点

- §448 **企业间留置例外**：企业之间留置，**不需要**债权与留置财产属同一法律关系（商事留置）
- §447 民事留置须同一法律关系（个人主体）；企业间不要求
- A公司欠20万维护费（独立债务）+ B公司占有15辆车（本次维护）→企业间→可留置
- 📐 **完整答题模型** → [[民法-物权-留置权模型]]

## 考点精解

| 选项      | 分析                                                                                                                                                                                                                                   | 结论                      |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------- |
| A（可留置）  | 企业间例外，不需同一法律关系，可以留置                                                                                                                                                                                                                  | **正确** ✓                |
| B（不可）   | 错误，§448 企业间例外明文                                                                                                                                                                                                                      | **错**                   |
| C（全部留置） | A是说B可以留置，   > 💡 **“可分财产限额留，不可分物才全部”**<br><br>- **可分财产限额留**：如果留置的财产是“可分物”（比如 15 辆汽车、100 箱红酒、50 吨煤炭），留置财产的价值**应当相当于债务的金额**，欠多少钱，只能扣等值的物，不能超额扣留。<br>- **不可分物才全部**：只有在留置物是“不可分物”（比如一辆价值 100 万的完整跑车，你没法把车锯开）时，即使债权只有 10 万，你也可以“全部留置”整辆车。 | 错（与A冲突，且B支付了2万本次费，仍有欠款） |
| D（一辆）   | 无法律依据限定                                                                                                                                                                                                                              | **错**                   |
|         |                                                                                                                                                                                                                                      |                         |

注：A（可以进行留置）是正确描述，C（可以全部留置）在逻辑上也不完全排除，但A是更直接的正确选项。
