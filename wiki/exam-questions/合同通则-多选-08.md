# C1-多选-08 · 代位权的专属性排除

## 题干

> 甲对乙有 10 万元到期债权。对乙怠于行使的下列权利，甲**无权代位行使**的是？

- A. 乙对其子丙享有的赡养费请求权
- B. 乙所在单位欠付 7 个月工资 6 万元
- C. 丙赔偿乙人身损害 10 万元
- D. 乙许可丙公司使用其肖像作广告，许可费 10 万元已经届期

## 我的答案

**ABC**（A/B/C 专属不可代位；D 肖像许可费"已届期"→ 已财产化，可代位）<!-- confidence: INFERRED -->

## 涉及考点

- [[代位权]]（§535-§537 · [[合同总则考点-深度报告]] 保全板块 #1 · ★★★★★）
- 📐 **答题模型** → [[民法-合同-代位权模型]]（第一步·专属排除清单与已届期肖像许可费）
- [[代位权]] 排除范围：专属于债务人自身的债权**不得代位**（§535 但书 + 通则解释）
- **边界点**：人格权"商业化"产生、**已到期的财产收益**（肖像 / 姓名许可费、稿酬）已"财产化"→ **可代位**
- ⚠️ 问法陷阱：本题问"**无权**代位"（= 选专属的 ABC），与 [[合同通则-单选-17]]"**有权**代位"正反相对

## 考点精解 · 代位权的"专属性"排除（含已财产化的边界）

### 是什么 / 易混

**§535 但书 + 合同编通则司法解释**：下列**专属于债务人自身**的债权**不得代位**——

| # | 专属类型（不可代位）| 本题对应 |
|---|---|---|
| ① | **身份关系**（赡养 / 抚养 / 扶养 / 继承）| **A** 赡养费 |
| ② | **人身损害赔偿** | **C** 人身损害 10 万 |
| ③ | **劳动报酬 / 退休金 / 抚恤金 / 安置费 / 人寿保险** | **B** 7 个月工资 |
| ④ | 其他**生存 / 人格性**密切相关债权 | — |

**D 的边界（核心）**：肖像权**本身**专属（人格权），但**许可他人商业使用产生的"许可费"**是财产收益；题干强调"**已经届期**"→ 已变成**确定的到期金钱债权** → **可代位**。

→ 问"**无权**代位"，选**专属**的 **A / B / C**；D 已财产化、可代位（不选）。

### 怎么考 / 坑在哪

- **D 经典陷阱**：人格权产生的"**钱**"（已到期）≠ 人格权本身——肖像许可费 / 稿酬 / 演出报酬一旦到期，**可代位**。
- **问法陷阱**：本题问"**无权**代位"（选专属 ABC）；[[合同通则-单选-17]] 问"**有权**代位"（选财产性的合伙分红 C）。看清"有权 / 无权"再下手。
- **判断诀窍**：看这笔钱现在**是不是"纯财产 / 已到期的钱"**——是 → 可代位；跟人身 / 活命 / 身份绑着没变现 → 专属不可代位。

### 怎么答

ABC。A 赡养费（身份）、B 工资（劳动报酬）、C 人身损害赔偿均专属不可代位；D 肖像许可费已届期、已转为金钱债权可代位。故"无权代位"选 **ABC**。

## 📐 答题口诀 · 专属排除"看清有权/无权 + 钱到期就能代位"

> **专属（不可代位）= 身份 / 人身赔偿 / 劳动报酬安置费等"保命钱"；可代位 = 纯财产债权 + 人格权"已到期的许可费 / 稿酬"。** 先看题干问"有权"还是"无权"，再对号入座。

### 关键词触发表

```
看到题干"债务人怠于行使的这笔权利……"             → 能不能代位
"赡养费 / 抚养费 / 扶养费 / 继承"                → 身份性，专属，不可代位 ✗
"工资 / 退休金 / 抚恤金 / 安置费 / 人寿保险"       → 生存保障，专属，不可代位 ✗
"人身损害赔偿"                                 → 专属，不可代位 ✗
"肖像 / 姓名许可费 / 稿酬 / 演出报酬'已届期'"       → 人格权'已财产化'，可代位 ✓ ★
"合伙分红 / 货款 / 租金 / 普通借款"              → 纯财产，可代位 ✓
"题干问'无权代位'"                             → 选专属的；问'有权代位' → 选财产性的 ★
```

### 📋 4 选项陷阱解析（题干问"无权代位"）

| 选项 | 可否代位 | 本题（问"无权"）| 性质 |
|---|---|---|---|
| **A 赡养费** | ❌ 不可代位 | ✅ 选 | 身份关系（专属）|
| **B 7 个月工资 6 万** | ❌ 不可代位 | ✅ 选 | 劳动报酬（专属）|
| **C 人身损害赔偿 10 万** | ❌ 不可代位 | ✅ 选 | 人身损害（专属）|
| D 肖像许可费 10 万**已届期** | ✅ **可代位** | ❌ 不选 | 人格权**已财产化**的到期金钱债权 |

→ 无权代位的是 **ABC** ✅

### 🚗 老王小李故事

> 老王卖车给小李，小李欠老王 **10 万**车款（老王 = 债权人，小李 = 债务人）。小李怠于行使几笔权利，老王想代位——哪些**伸不进手**（无权代位）？
>
> - 小李有权找儿子要的**赡养费** → "养老的家务事"，身份性，专属，老王**不能**代位（A✗，选）。
> - 小李单位欠他的 **7 个月工资 6 万** → 活命口粮，专属，老王**不能**代位（B✗，选）。
> - 有人打伤小李、赔他的 **10 万人身损害赔偿** → 补身体的苦，专属，老王**不能**代位（C✗，选）。
> - 小李把**自己的脸授权给广告公司**，那 **10 万许可费已经到期** → 这是小李"**靠脸赚的钱**"、已变成一笔到期的钱，纯财产，老王**能**代位（D✓，不选）。
>
> 诀窍：靠"身份 / 活命 / 身体"的钱小李留着保命，老王伸不进手；靠"脸 / 名 / 作品"赚的、**已经到期**的钱，老王才能代位去要。

### 🎯 一句话记忆

> **"靠'身份 / 活命 / 身体'的钱（赡养费 / 工资 / 人身赔偿）不能代位；靠'脸 / 名 / 作品'赚的、已到期的钱（肖像许可费 / 稿酬）能代位——人格权产生的'钱'≠人格权本身。"**

### 填空模板（主观题用）

> 甲对乙有 10 万到期债权 + 乙怠于行使 → 甲可代位，但**【专属于债务人自身】**的债权除外（§535 但书）。A 赡养费（身份）、B 工资（劳动报酬）、C 人身损害赔偿均属**【专属，不可代位】**（故"无权代位"选 ABC）；D 肖像许可费**【已届期 → 已转为财产性金钱债权】**（可代位，不选）。故选 **ABC**。

### 横向真题对照

- 本题（多选-08）= 专属**边界**："人格权产生的**已到期财产收益**（肖像许可费）可代位" → ABC（无权代位）
- [[合同通则-单选-17]] = 专属**排除**（人身赔偿 / 工资 / 安置费不可代位，**合伙分红可代位**）→ C（有权代位）
- [[合同通则-单选-18]] = 代位对象含**从权利（抵押权）** → B
- [[合同通则-多选-09]] = 代位权诉讼**抗辩 + 受偿** → ABCD
- [[合同通则-单选-51]] = 代位"以债权人债权为限"取小 → C
- → 多选-08 与 单选-17 是"专属 vs 财产"边界的**正反两面**：17 给的"可代位"是合伙分红（纯财产），08 给的"可代位"是肖像许可费（人格权商业化的到期收益）；两题合起来把边界考全。代位权 ★★★★★ 必考（通则解释§36），与 [[撤销权]] 并称"保全双子星"。
