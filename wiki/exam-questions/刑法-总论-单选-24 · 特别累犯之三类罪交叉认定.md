# 刑法-总论-单选-24 · 特别累犯之三类罪交叉认定

## 题干

> 来源：依据《刑法》第66条命制的**仿真题**（题干为本库命制，非历年真题；§66"恐怖活动犯罪"系2015年《刑法修正案（九）》并入，已联网核验）。

乙2008年因组织、领导黑社会性质组织罪被判处有期徒刑8年，2016年刑满释放。2024年（出狱已满7年），乙又实施恐怖活动犯罪。关于乙的累犯认定，正确的是？

- A. 不构成累犯，因间隔已超过5年
- B. 不构成累犯，因前后罪不是同一类犯罪
- C. 构成特别累犯，因前后罪均属§66列举的三类犯罪，任何时候再犯均构成
- D. 构成一般累犯，应自刑满释放之日起算5年

## 我的答案

**C**<!-- confidence: EXTRACTED -->

C：根据《刑法》第66条，危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织犯罪这三类犯罪，前罪与后罪只要都属于这三类之中（**允许交叉**，如前罪是黑社会性质组织犯罪、后罪是恐怖活动犯罪），在**任何时候**再犯都以累犯论处，不受5年期限的限制，也不受"有期徒刑以上"刑度的限制。乙前罪为黑社会性质组织犯罪、后罪为恐怖活动犯罪，均在三类之列，构成特别累犯 ✓

A："间隔超过5年"是一般累犯（§65）的否定理由。特别累犯不受5年期限限制，无论间隔多久（本题7年）都成立，故该理由错误 ✗

B：§66只要求前后罪都落入三类范围之内，并**不要求前后罪为同一罪名或同一类**，黑社会与恐怖活动可以交叉认定。以"不是同一类"否定累犯属误读 ✗

D：本题应优先适用特别累犯（§66），而非一般累犯（§65）。特别累犯不存在"自刑满释放之日起算5年"的期限问题，该选项定性错误 ✗

## 考点精解 · 一般累犯 vs 特别累犯对照

特别累犯是针对三类严重犯罪的从严特例，与一般累犯在多个要件上不同：

| 比较项 | 一般累犯（§65） | 特别累犯（§66） |
| --- | --- | --- |
| 罪名范围 | 任何故意犯罪 | 仅限三类：危害国安/恐怖活动/黑社会性质组织 |
| 前后罪关系 | 均须故意 | 均须落入三类（**可交叉**，不要求同一罪名） |
| 时间限制 | 执行完毕后5年内 | **任何时候**，无5年限制 |
| 刑度限制 | 前后罪均应判有期徒刑以上 | **无**刑度限制 |
| 未成年/过失排除 | 适用（前罪未成年或过失则排除） | 通说同样排除未成年与过失 |

```
  前罪：黑社会性质组织罪(2008)  ──── 出狱7年(无关期限) ────  后罪：恐怖活动罪(2024)
        └────────────── 两端均属三类罪，交叉也算 ──────────────┘
                            ➜ 任何时候再犯 = 特别累犯
```

要点：特别累犯"任何时候+无刑度限制+可交叉"，是比一般累犯更严的从重事由。
