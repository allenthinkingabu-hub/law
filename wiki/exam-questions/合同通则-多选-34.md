# C1-多选-34 · 债务加入"通知即对债权人生效"；只承诺100万就还100万

## 题干

> 甲公司欠乙公司200万元货款，甲公司与丙公司约定丙公司加入甲公司对乙公司的债务，但只承诺还100万元，并及时将情况通知了乙公司，乙公司表示同意，后丙公司偿还了50万元。根据《民法典》，下列哪些选项是正确的？（2020金题-2-1-23）

- A. 该债务承担协议自通知乙公司时对乙公司有效
- B. 乙公司有权请求丙公司再支付50万元
- C. 乙公司有权请求丙公司支付150万元
- D. 该债务承担协议自乙公司同意时对乙公司有效

## 我的答案

**AB**<!-- confidence: EXTRACTED -->（官方参考答案：AB）

> 🔎 **2026-06-09 联网核实（AB 确认无误，与官方参考答案一致）**：本题系 2020 金题-2-1-23。经《民法典》**§552** 原文（法信 / 知乎法律专栏 / 德恒·海华永泰律所 / 汉斯学术一致）——"第三人与债务人约定加入债务并**通知债权人**……债权人可以请求第三人在其**愿意承担的债务范围内**和债务人承担**连带债务**"：① **A 对**——债务加入（并存承担）**对债权人有利**（多个责任人），故**通知到达债权人即生效**、**不以债权人同意为要件**；题干"乙表示同意"是**干扰项**，生效时点仍是**通知**日 → ② **D 错**（"自乙同意时才有效"把 §552 错套成 §551 **免责承担**"须债权人同意"的规则）。③ **B 对 / C 错**——丙只在**承诺的 100 万**内与甲**连带**，已还 50，乙可请求丙**再付 50 万**（100−50），**不是 150 万**。④ 对照 **§551 免责的债务承担**（债务人**退出**、对债权人不利）→ **须债权人同意**（未表示 = 不同意）。故 **AB**。

## 考点精解 · 并存的债务承担（债务加入，§552）

### 是什么 / 易混

- **债务加入（并存的债务承担）**：第三人丙**加入**债务、与原债务人甲**共同**对债权人乙负责。
- **与免责债务承担的关键差异**：债务加入**对债权人有利**（多个责任人），故**通知债权人即生效**，**无需**债权人同意（§552）。

| 选项                | 判断  | 理由                                           |
| ----------------- | --- | -------------------------------------------- |
| **A 自通知乙时对乙有效**   | ✅   | 债务加入通知到达债权人即生效（§552），不以债权人同意为生效要件            |
| **B 可请求丙再付 50 万** | ✅   | 丙承诺加入 100 万、已还 50 万，乙可请求丙**再付 50 万**（100−50） |
| C 可请求丙付 150 万     | ❌   | 丙只在**承诺的 100 万**范围内加入，已还 50，余 50，不是 150      |
| D 自乙同意时才有效        | ❌   | 债务加入**通知即生效**，不需债权人同意（这是免责承担的规则，别混）          |

### 怎么考 / 坑在哪

- **A vs D**：债务加入（对债权人有利）→ **通知生效**（A 对）；免责的债务承担（债务人换人，可能不利）→ **须债权人同意**（D 把它套错了）。
- 债务加入**有限额**：丙只在其**承诺的范围（100 万）**内负责，已还 50 则余 50（B 对，C 错）。

## 📐 答题口诀 · 债务加入：通知即生效（不需同意）；只在承诺额内负责

> **"加入债务对债主有利 → 打个招呼（通知）就生效；丙只认自己承诺的 100 万，还了 50 就剩 50。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"第三人'加入'债务（并存承担）+ 通知债权人"     → 通知即对债权人生效（§552，A）★
"债务加入需债权人同意才生效"                  → 错（那是免责承担 §551，D 混了）
"加入人承诺还 100 万，已还 50"                → 还能请求 50（B），不是 150（C）
"原债务人是否退出"                            → 没退（并存），与债务加入人共同负责
```

### 🚗 老王小李故事

> 老王把一批车卖给小李，小李欠老王 **200 万**车款，一时周转不开。小李的朋友**老张**主动对老王说："这笔车款我**加入**进来一起还，不过我只认 **100 万**"，并把这事**通知**了老王，老王也乐意。后来老张先还了 **50 万**。几个判断：
>
> - **① 通知就生效，不用等"同意"（A 对，D 错）**：老张加入还债，对债主老王是**好事**（凭空多个人替小李还钱）→ **通知一到老王就生效**，并不需要老王点头"同意"。题干里老王虽也"表示同意"，但那只是顺水人情——**生效靠"通知"，不靠"同意"**。D 把它当成"小李退出、老张顶上"那种**换债务人**（§551 免责承担，才需债权人同意）的规则，套错了。
> - **② 只在承诺额内负责（B 对，C 错）**：老张只认 **100 万**、已还 50 → 老王还能找老张**再要 50 万**（100−50，B），可不能狮子大开口要 **150 万**（C）。
> - 注意：小李**没退出**，仍和老张一起欠老王，两人在 **100 万** 内**连带**（老王这 100 万找谁要都行）；剩下 100 万只能找小李。

### 🎯 一句话记忆

> **"债务加入：通知即生效（不需同意）；只在承诺额内（100−50=50）负责。"**
