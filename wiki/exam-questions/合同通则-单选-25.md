# C1-单选-25 · 免除的法律性质

## 题干

> 下列关于免除的说法，**错误**的是：

- A. 免除是非要式民事法律行为
- B. 免除是无偿民事法律行为
- C. 免除需取得债务人的明确同意
- D. 免除是双方民事法律行为

## 我的答案

**D**（错误：免除是单方法律行为）<!-- confidence: INFERRED -->

## 涉及考点

- [[免除]]（§575）
- 单方法律行为 vs 双方法律行为

## 考点精解 · 免除的性质

### 是什么 / 易混

**§575 免除**：债权人**免除债务人**全部或部分债务的，债权债务部分或者全部终止。

**关键性质**：
- **单方民事法律行为** —— 只需债权人的意思表示，**不需要**债务人同意
- **非要式** —— 无特定形式要求
- **无偿** —— 债权人单方让渡债权
- **诺成** —— 自表示到达债务人时生效

⚠️ 题中 C 选项"需取得债务人的明确同意"也是有争议的：
- 主流通说：免除**不需要债务人同意**（单方行为）
- 但如果债务人**不愿被免**（如出于荣誉），可能拒绝——民法学界对此有讨论

→ 主流答案选 **D**（明显错误，免除非双方）。但 C 也常被列为错误（"明确同意"过强）。

**注意：本题答案可能是 C 或 D，需对照教材**

### 怎么考 / 坑在哪

- D 是基础性错误：免除单方
- C 是细节争议：免除一般不需同意，但某些版本认为需

### 怎么答

主流通说：免除是**单方**法律行为 → D"双方" 错误。故选 **D**。

> ⚠️ 若教材标 C，依据是"免除不需任何同意"——C 与 D 互为陷阱，请用户复核。
