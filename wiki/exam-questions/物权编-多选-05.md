# 物权-多选-05 · 假结婚证出卖共有房——肖某多项请求权综合

## 题干

> 陈某与肖某系夫妻。婚后二人共同购买了一套房屋，登记在陈某名下。2019年2月3日，陈某找来老相好蔡某，以夫妻名义做了一张假结婚证和蔡某一起将房屋过户给不知情的秦某。妻子肖某发现后，要求撤销合同。关于本案，下列说法正确的有？(2019年金题2-9)

- A. 虽然房屋登记在陈某名下，但依然系陈某和肖某共同共有
- B. 肖某有权请求撤销房屋买卖合同
- C. 秦某有权主张善意取得房屋所有权
- D. 肖某有权请求蔡某赔偿损失

## 答案

**ACD**（登记≠独自所有；秦某善意取得；肖某无撤销权但可向蔡某索赔）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2019年金题 2-9
- 素材：[[2026-06-15-物权编客观真题]]

## 涉及考点

- §308 共同共有：夫妻共同财产属**共同共有**，不因登记在一方名下而改变
- [[善意取得]] §311：秦某不知情+正常价格+登记过户 → 善意取得
- 撤销权主体：§148 欺诈撤销权归**受欺诈方**（被欺诈方是秦某，肖某不是合同当事人）
- §1165 侵权赔偿：蔡某协助欺诈，共同侵权

## 考点精解

| 选项 | 分析 | 结论 |
|---|---|---|
| A（共同共有）| §308：婚后共同购买 = 夫妻共同共有（登记在陈某名下不改变共有性质）| **正确** ✓ |
| B（肖某撤销合同）| 撤销权由**受欺诈的合同当事人**主张（§148）；肖某不是买卖合同一方 → 肖某**无撤销权** | **错** |
| C（秦某善意取得）| 秦某不知情+登记名义符合+已完成过户登记 → §311善意取得 | **正确** ✓ |
| D（肖某→蔡某赔偿）| 蔡某协助陈某用假证欺骗秦某出售共有房，侵害肖某共有权 → **共同侵权** → 肖某可向蔡某索赔 | **正确** ✓ |

**B 高频坑**：只有合同当事人（受欺诈方=秦某）才有撤销权，但秦某不需要撤销（因为善意取得对自己有利）；肖某虽受损但不是合同当事人，无撤销权。

## 📐 口诀

> **夫妻共有≠登记人独有；善意取得对抗所有人（含共有人）；受欺诈方=合同当事人才有撤销权。**
