# C3-单选-02 · 无因管理的构成

## 题干

> 管理下列事务的，**可以构成无因管理之债**的是？

- A. 违法或者违背社会公德的行为
- B. 主动代朋友招待远道而来的客人
- C. 替考上北大研究生的好友去五台山还愿
- D. 为防止自家房屋受影响而帮助外出打工的邻居修缮房屋

## 我的答案

**D**<!-- confidence: INFERRED -->

## 涉及考点

- [[无因管理]] **三要件**（§979）
- 初衷有自利但**客观利他**仍可构成

## 考点精解 · 无因管理三要件

### 是什么 / 易混

**§979**（无因管理）：
- ① **管理他人事务**
- ② **没有法定 / 约定义务**（无义务）
- ③ **为他人利益**的意思（即使**兼有自利**亦可）

→ **管理违法 / 违公德事务 ≠ 无因管理**——因为不属"法律保护的他人事务"。

本题对照：
- A 违法 / 违公德 → **不属法律保护事务** → 不构成（×）
- B 朋友的客人 → 这是朋友的**社交事务**，但严格说也是"他人事务"——但**主动代招待**更像是**赠与 / 礼让**，无管理之意
  - 通行答案：B 不属典型无因管理（朋友的客人由朋友自处理，主动接管像介入朋友自主决定的事务）
- C 替别人还愿 → 是别人**自己的道德 / 宗教**事务——不属法律保护事务，且"还愿"不构成法律意义的管理
- D 防自家受影响 + 帮邻居修房屋 → 初衷有**自利**但**客观利他** → **构成无因管理**（学界 + §979 共识）

### 怎么考 / 坑在哪

- **D 经典陷阱**：以为"初衷为自己 ≠ 无因管理" → 错。**主观为他人意思 + 客观利他**即可构成，**自利不否定**
- A/C "违法违公德 / 迷信"事务不属无因管理

### 怎么答

D。初衷有自利 + 客观为他人利益 → 构成无因管理。
