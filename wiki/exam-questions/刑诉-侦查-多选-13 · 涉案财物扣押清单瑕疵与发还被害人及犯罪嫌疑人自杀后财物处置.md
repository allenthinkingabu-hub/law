# 刑诉-侦查-多选-13 · 涉案财物扣押清单瑕疵与发还被害人及犯罪嫌疑人自杀后财物处置

## 题干

> 来源：金题（Note 1 Q19）

涉案财物查封扣押冻结处理正确的是？

- A. 盗窃电视机及时发还被害人李四
- B. 毒品随案移送当庭出示
- C. 受贿金条依判决上缴国库
- D. 嫌疑人自杀冻结存款直接上缴

## 我的答案

**AC**<!-- confidence: EXTRACTED -->

- **A项正确**：根据《刑事诉讼法》和《高法解释》规定，对被害人的合法财产，权属明确的，**应当依法及时发还**，无需等到案件判决后再处理（只要不影响诉讼进行即可留存照片、清单备查）。
- **B项错误**：毒品属于国家管制的违禁品，依法应当收缴、封存并妥善保管。根据规定，对于毒品等违禁品，**一般不随案移送**（即不随案移送到检察院和法院），而应当移送扣押清单、照片及检验鉴定报告。法庭审判时也无需当庭出示毒品实物，以防发生流失或安全隐患。
- **C项正确**：受贿所得的金条属于违法赃物，在案件审理终结、法院判决生效后，应当依法予以没收，并**上缴国库**。
- **D项错误**：犯罪嫌疑人、被告人死亡的（如嫌疑人自杀），刑事诉讼终止。但对于其冻结的涉案赃款（存款），侦查机关**不得直接划拨上缴**，必须走法定的**犯罪嫌疑人、被告人逃匿、死亡案件违法所得没收程序**，由人民检察院向人民法院提出没收违法所得的申请，由人民法院依法作出裁定后，才能予以没收上缴。

## 涉及考点

- [[合法财产及时发还规则]] — 被害人合法财产的先行发还
- [[违禁品不随案移送规则]] — 毒品、易燃易爆等特殊物品的保管与实物排除
- [[赃款赃物没收上缴国库]] — 判决生效后的最终处分
- [[逃匿死亡案件违法所得没收程序]] — 嫌疑人死亡时涉案财物的司法控制

## 考点精解 · 涉案财物处置的法定程序

### 是什么 / 易混

| 财物类型 | 处置方式 | 易错混淆 / 陷阱 |
| :--- | :--- | :--- |
| **被害人合法财物** | 权属明确的，**及时发还** | 设坑为“必须作为物证扣留，等到判决后发还” |
| **违禁品（毒品等）** | 扣押、封存、检验，**实物不随案移送** | 误判为“毒品是关键物证，必须当庭出示” |
| **普通赃物（金条等）** | 法院判决生效后上缴国库 | 混淆侦查机关与审判机关的最终处分权 |
| **嫌疑人死后财物** | **检察院申请 $\rightarrow$ 法院裁定没收** | **高频陷阱**：“嫌疑人已死，公安/检察院直接划拨上缴” |

### 怎么考 / 坑在哪

- **被害人财产“及时发还”陷阱**：考官喜欢以“为了法庭出示的需要，电视机必须一直扣押到判决生效才能还给李四”来设置障碍。其实，只要拍照、登记、鉴定后，电视机就应该“及时发还”。
- **违禁品不随案移送**：对于毒品、枪支弹药、易燃易爆品等，由于安全隐患极大，法律规定**不能随案移送实物**，更不能在法庭上“当庭出示”毒品粉末或枪支，当庭出示的是照片、鉴定报告等。
- **嫌疑人死后的财物处理（特别程序）**：这是刑诉特别程序的核心考点。人死债不烂，赃款要收回，但必须尊重司法权。公安/检察机关绝对没有权力“直接划拨上缴”，必须由**法院出具裁定没收**。

### 怎么答

- 看到“被害人的合法财产” $\rightarrow$ 选择**及时发还**。
- 看到“毒品随案移送、当庭出示” $\rightarrow$ **排除**。
- 看到“嫌疑人自杀/死亡，冻结存款直接划拨上缴” $\rightarrow$ **判定为错**，必须走“法院裁定没收程序”。

## 选项分析表

| 选项 | 选项具体表述 | 判断 | 核心依据 |
| :---: | :--- | :---: | :--- |
| **A** | 盗窃电视机及时发还被害人李四 | **✅** | 权属明确的被害人财产应当及时发还，不影响诉讼的可用照片留存。 |
| **B** | 毒品随案移送当庭出示 | **❌** | 毒品等违禁品不随案移送实物，亦不能当庭出示毒品本体。 |
| **C** | 受贿金条依判决上缴国库 | **✅** | 贪污受贿赃款赃物在法院判决生效后，依法收缴国库。 |
| **D** | 嫌疑人自杀冻结存款直接上缴 | **❌** | 嫌疑人自杀死亡后，必须通过法院的“违法所得没收程序”裁定后方可上缴。 |

## 故事记忆 · 老王与小李

小李办理了一起贪污涉毒的复杂案子，嫌疑人跳楼自杀。
小李整理好卷宗说：“师父，你看我这处置对不对：第一，被盗的电视机咱们一直扣押着，准备下个月开庭当庭出示，然后再还给被害人。第二，查获的5公斤冰毒我已经装箱了，准备明天连同卷宗一起抱到法院随案移送。第三，嫌疑人贪污的赃款被我们冻结在银行，既然嫌疑人都死了，我今天下午就直接划拨上缴国库。”
老王听完直叹气，指着他说：“你这是程序法盲！第一，被害人的电视机只要拍照留档，现在就应该及时还给人家，压在咱们所里干嘛？第二，5公斤冰毒是违禁品，你抱着去法院，半路丢了或者出事你担得起吗？这东西不随案移送，当庭只出示照片和检验报告！第三，嫌疑人自杀了，这贪污的赃款绝不能由我们直接划拨，必须走‘死亡案件违法所得没收特别程序’，让法院裁定没收后才能动！”
小李吓出一身冷汗，赶忙把箱子里的毒品又锁回了毒品库。
