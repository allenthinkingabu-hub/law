# 侵权-单选-19 · 医疗损害-患方承担举证责任

## 题干

> 来源：2016-3-23（司考真题，单）

田某突发重病神志不清，田父将其送至医院，医院使用进口医疗器械实施手术，手术失败，田某死亡。田父认为医院在诊疗过程中存在一系列违规操作，应对田某的死亡承担赔偿责任。关于本案，下列哪一选项是正确的？

- A. 医疗损害适用过错责任原则，由患方承担举证责任
- B. 医院实施该手术，无法取得田某的同意，可自主决定
- C. 如因医疗器械缺陷致损，患方只能向生产者主张赔偿
- D. 医院有权拒绝提供相关病历，且不会因此承担不利后果

## 我的答案

**A**<!-- confidence: EXTRACTED -->

A：§1218 医疗损害责任适用**过错责任原则**，由患方（原告）对医疗机构的过错承担举证责任 ✓

B：田某神志不清无法同意，但应取得**家属（田父）同意**（§1219 告知义务；神志不清时由家属或关系人代为同意）。医院不得"自主决定"，无法取得任何人同意时才可自主决定（紧急情形），本案有田父在场 ✗

C：因医疗器械缺陷致损，患方既可向**医疗机构**主张（§1223），也可向器械**生产者**或**销售者**主张；非"只能向生产者" ✗

D：医疗机构有义务为患者提供病历复制件（§1225）；拒绝提供或伪造病历，法律规定推定医疗机构有过错（过错推定）→ 会承担不利后果 ✗

## 涉及考点

- [[侵权责任编]] §1218 医疗损害过错责任原则
- §1219 知情同意权（家属代为同意）
- §1223 医疗器械缺陷→可向医院或生产者主张
- §1225 病历提供义务

## 考点精解 · 医疗损害责任四条核心

| 法条    | 内容              | 本题选项        |
| ----- | --------------- | ----------- |
| §1218 | 过错责任原则，患方举证     | A ✓         |
| §1219 | 告知同意，无行为能力时家属代为 | B ✗（应家属同意）  |
| §1223 | 器械缺陷可向医院或生产者主张  | C ✗（不是"只能"） |
| §1225 | 提供病历义务，拒绝→推定过错  | D ✗（有不利后果）  |
