# C1-多选-12 · 提存的全套规则

## 题干

> 甲乙签订销售空调 100 台的合同，乙拒绝受领，请求甲返还货款。下列正确的是？（2003-3 真题原型）

- A. 甲可以向有关部门提存这批空调
- B. 提存后火灾烧毁 5 台 → 损失应由甲承担
- C. 提存费用应由乙支付
- D. 自提存之日起 5 年内乙不领取 → 归甲所有

## 我的答案

**AC**（A §570① 拒绝受领可提存 ✅ / B 风险已移转给乙、"由甲承担"错 ❌ / C §573 费用归债权人乙 ✅ / D §574 归**国家**所有、"归甲"错 ❌）<!-- confidence: EXTRACTED -->

| ③ | [厚德汇法网 · §573 释义](http://www.ahdhf.com/law/msf/8582.html) + [§574 释义](http://www.ahdhf.com/law/msf/8583.html) | 风险/孳息/费用三归债权人 + 领取权 5 年消灭归国家的释义解读 |

**法条逐项验证**（最高检官网原文）：

| 选项 | 对应法条原文 | 验证 |
|---|---|---|
| A | §570①："债权人**无正当理由拒绝受领**……债务人可以将标的物提存" | ✅ 一字对应 |
| B | §573："标的物提存后，毁损、灭失的风险**由债权人承担**" | ❌ 题说"由甲（债务人）承担"——与法条**相反** |
| C | §573："**提存费用由债权人负担**" | ✅ 一字对应 |
| D | §574："自提存之日起**五年**内不行使而消灭，提存物扣除提存费用后**归国家所有**" | ❌ 题说"归甲所有"——与法条**相反** |

→ **AC 确凿，无任何争议空间**。命题手法 = 把 §573/§574 的明文规定**反着说**（B/D 项）。

> 📌 **历史沿革**：2003 年考时依据《合同法》§101-§104，民法典 §570-§574 完全延续该规则——老真题至今有效。

## 考点精解 · 提存四规则（一题考全）

### 法条四件套（修正版条文归属）

| 维度 | 规则 | 法条 | 对应选项 |
|---|---|---|---|
| ① 何时可提存 | 债权人**无正当理由拒绝受领** / 下落不明 / 死亡未定继承人 / 其他法定情形 | **§570** | A ✅ |
| ② 风险负担 | 自提存日起**风险移转给债权人** | **§573** | B 的反面 |
| ③ 费用负担 | **债权人**承担（公证费 / 保管费 / 公告费等）| **§573** ⚠️（不是 §572，§572 是**通知义务**）| C ✅ |
| ④ 5 年归属 | 5 年内不领取 → 领取权消灭 → 扣除费用后**归国家所有** | **§574** | D 的反面 |

### 4 选项陷阱深度解析

| 选项 | 判断 | 详细法理分析 |
|---|---|---|
| **A · 甲可以提存这批空调** | ✅ | **§570① 明文**：债权人（买方乙）**无正当理由拒绝受领** → 债务人（卖方甲）"难以履行债务" → 可将标的物提存。乙不仅拒收还反要退款，正是典型的"无正当理由拒绝受领"。甲提存后债务消灭（§571 视为交付 + §557(三)），从"交不出货"的困境中合法解套。 |
| B · 火灾烧毁 5 台 → 损失由甲承担 | ❌ | **反向陷阱**：§573 明文"标的物提存后，毁损、灭失的风险**由债权人承担**"。火灾（不可归责事由）烧毁 5 台 → 损失归**乙**。逻辑链：§571 提存成立 = **视为已交付** → 按 §604 交付主义，风险随交付移转 → 乙承担。甲早在提存完成时就合法"下车"了。 |
| **C · 提存费用由乙支付** | ✅ | **§573 明文**："提存费用由债权人负担。"法理：提存因**乙拒绝受领**而起——乙不找事，甲正常交货就没这笔开销（公证费 / 仓储保管费 / 公告通知费等）。谁惹的事谁买单。 |
| D · 5 年不领归甲所有 | ❌ | **反向陷阱**：§574 明文——领取权 5 年不行使而消灭，提存物扣除提存费用后**归国家所有**，不是回到债务人甲手里。法理：提存视为交付，甲交出那一刻已完成履行，标的物在法律逻辑上已"离开"甲；乙又不要 → 物权悬空 → 收归国家。⚠️ 例外（本题无此事实）：乙对甲负有**到期债务未履行**，或乙**书面放弃**领取 → 甲负担提存费用后**有权取回**（§574 后段）。 |

→ 正确答案 = **AC** ✅

## 🔑 核心概念深度讲解 1 · 本题 = §570-§574 的"全覆盖扫描题"

本题一道题把提存制度的**四个考查维度**全部扫了一遍——这是"制度全套规则"型多选的典型命题法：

```
§570 能不能提存？   → A 项考（拒绝受领 ✅）
§571 提存的效果？   → 隐含前提（视为交付 → B 项风险移转的逻辑起点）
§573 风险/费用归谁？ → B 项考（风险反着说）+ C 项考（费用正着说）
§574 不领怎么办？   → D 项考（归属反着说）
```

**命题手法识别**：B 和 D 都是把法条明文**反着说**——"由债权人承担"改成"由甲（债务人）承担"、"归国家"改成"归甲"。对付这类题：**法条原文记准方向，反着说的全杀**。

## 🔑 核心概念深度讲解 2 · "拒绝受领"的受领迟延本质（A 项法理）

乙的行为拆解：
1. **拒绝受领** 100 台空调 = **受领迟延**（债权人迟延）
2. **反请求返还货款** = 试图毁约退出

对甲（守约债务人）的出路：
| 路径 | 依据 | 效果 |
|---|---|---|
| **提存**（本题）| §570① | 视为交付 → 债务消灭 → 风险/费用甩给乙 |
| 请求乙受领 + 赔偿保管费 | §589 | 债权人受领迟延 → 债务人可请求赔偿增加的费用 |
| 若乙构成根本违约 → 解除 + 索赔 | §563 I ④ | 终止合同另算账 |

→ 提存是其中**最干脆**的方案：不用打官司、不用等乙回心转意，交给提存部门即完成履行。

## 🔑 核心概念深度讲解 3 · D 项"归国家"的物权逻辑 + 双重例外

**为什么不归债务人甲？**
- §571 提存成立 = 视为交付 → 甲的履行**已完成**，标的物法律上已"交出"
- 甲若能随时拿回 → "提存消灭债务"的制度根基就塌了（债务消灭了东西还能收回 = 白嫖履行效果）

**为什么归国家？**
- 乙 5 年不领 → 领取权消灭 → 标的物**物权悬空**（甲已交出、乙不要）
- 无主化处理 → 扣除提存费用后收归国家

**双重例外**（§574 后段 · 甲可取回）：
1. 乙对甲**负有到期债务未履行**（也未提供担保）
2. 乙向提存部门**书面表示放弃**领取

→ 甲负担提存费用后**有权取回**。本题题干无此事实 → D 仍错。

### 🚗 老王小李买车故事（车载空调供货版 · 四选项全覆盖）

- **小李**（4S 店 = 买方 = **受领债权人**）
- **公证处**（提存部门 = 保管人）

```

        （老王 3/5 提存完成时就已合法"下车"）

  4/15  公证处寄来账单：公证费 + 仓储保管费 + 公告费
        ★ C 项判断：这笔提存费用谁出？
```

### 💡 关键洞察 1：B/D 是"法条反着说"的镜像双陷阱

本题最毒的设计：B 和 D 把 §573/§574 的归属方向**整个调转**——
- B："风险由债权人承担" → 改说"由甲（债务人）承担"
- D："归国家所有" → 改说"归甲（债务人）所有"

两个陷阱共享同一个错误直觉：「**东西物理上还没到乙手里，所以还跟甲有关系**」。破解钥匙 = §571 **视为交付**：提存完成那一刻，法律上等于交付完成，甲与标的物的一切关联（风险 / 收益 / 归属期待）全部切断。

### 💡 关键洞察 2：与 Q24 的姊妹关系

- [[合同通则-单选-24]]（单选）= **单点深钻** §573 风险移转
- 本题（多选-12）= **全套扫描** §570 + §573 + §574
- 两题共用同一条逻辑链：**§604 交付主义 → §571 视为交付 → §573 风险移转**
- 学习顺序建议：先 Q24 吃透"视为交付"枢纽，再用 Q12 全面检验

### 填空模板（主观题用）

> 乙**【无正当理由拒绝受领】**，甲依 **§570①** 可将标的物**【提存】**（A 对）。依 §571，提存成立**【视为甲已交付标的物】**，债务**【消灭】**。
>
> 提存后火灾烧毁 5 台，依 **§573**，毁损灭失的风险**【由债权人乙承担】**——"由甲承担"错（B 错）；提存费用依 §573 **【由债权人乙负担】**（C 对）。
>
> 乙自提存之日起 **【5 年】**内不行使领取权而消灭，提存物扣除提存费用后**【归国家所有】**——"归甲所有"错（D 错；除非乙未履行到期债务或书面放弃领取，甲才可取回）。
>
> 故选 **AC**。
