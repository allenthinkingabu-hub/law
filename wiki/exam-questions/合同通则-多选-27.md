# C1-多选-27 · 商品房包销期内自卖 + 调控致丙失资格：违约 + 解除

## 题干

> 甲公司与乙公司签订商品房包销合同，约定甲公司将其开发的10套房屋交由乙公司包销。甲公司将其中1套房屋卖给丙，丙向甲公司支付了首付款20万元。后因国家出台房地产调控政策，丙不具备购房资格，甲公司与丙之间的房屋买卖合同不能继续履行。下列哪些表述是正确的？（2012-3-60）

- A. 甲公司将房屋出卖给丙的行为属于无权处分
- B. 乙公司有权请求甲公司承担违约责任
- C. 丙有权请求解除合同
- D. 甲公司只需将20万元本金返还给丙

## 我的答案

**BC**（甲有权处分自己开发的房屋但对包销人违约；丙因限购失资格可请求解除；返还不限于本金）<!-- confidence: EXTRACTED -->（官方参考答案：BC）

## 考点精解 · 包销关系 + 政策致履行不能

### 先弄懂：什么是"商品房包销"？

**包销** = 开发商（甲）把一批房屋交给包销人（乙）**独家销售**，约定包销基价；包销期内卖出的差价归乙赚，**包销期满卖不掉的由乙按约定承购**。

**关键法律定性**：
| 维度 | 结论 |
|---|---|
| 房屋所有权 | **仍归开发商甲**（包销不转移所有权）|
| 乙的地位 | 独家销售代理 + 期满承购义务人（混合无名合同）|
| 甲能否自卖 | **有权利（所有权人）**，但**违反包销合同义务** → 构成违约 |

→ 这个"**物权层面有权 vs 合同层面违约**"的双层结构，就是本题 A/B 两项的命题轴心。

### 4 选项陷阱深度解析

| 选项                      | 判断  | 详细法理分析                                                                                                                                                                                                          |
| ----------------------- | --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A · 甲卖房给丙属于无权处分         | ❌   | **核心陷阱**：无权处分（§597）= 处分**他人**财产或无处分权。房屋是**甲自己开发的、所有权归甲**——包销合同只是给乙**债权性的独家销售权**，**不剥夺、不转移**甲的所有权和处分权。甲卖自己的房 = **有权处分**，甲丙买卖合同**有效**。命题人故意把"违反包销约定"包装成"无权处分"，混淆**合同义务违反**与**处分权欠缺**。                             |
| **B · 乙有权请求甲承担违约责任**    | ✅   | 甲在包销期内**自行出售包销范围内的房屋**，违反包销合同的**独家销售条款**（不作为义务）→ 对乙构成**违约**（§577）。注意：违约的是**甲乙之间的包销合同**，与甲丙买卖合同的效力**互不影响**（合同相对性）。                                                                                               |
| **C · 丙有权请求解除合同**       | ✅   | **法理基础 = 最高法《全国民事审判工作会议纪要》（法办〔2011〕442号）**："房屋买卖合同签订后，由于住房限购政策的实施，当事人无法办理房屋所有权变更登记，买受人请求解除合同，并要求出卖人返还所收受的购房款或定金的——**可予支持**。"丙因调控政策**丧失购房资格** → 合同**客观不能继续履行**（不可归责于双方）→ 合同目的不能实现 → 丙可请求解除（今 §563 I ①/④ + 纪要精神）。 |
| D · 甲只需将 20 万**本金**返还给丙 | ❌   | **"只需…本金"过于绝对**：解除后恢复原状（§566），甲应返还首付款 **20 万 + 资金占用期间的利息**。最高法纪要同时明确：因宏观调控解除的，损失处理区分基本住房/改善住房/投资住房公平处理——但**无论哪种，返还本金 + 利息是底线**，"只还本金"直接错。                                                                       |

→ 正确答案 = **BC** ✅

## 🔑 核心概念深度讲解 1 · "无权处分"的精确边界（A 项专项）

**§597 无权处分** = 出卖人**未取得处分权**致使标的物所有权不能转移 → 买受人可解除合同并请求违约责任。

| 情形 | 是否无权处分 |
|---|---|
| 卖**别人**的房（未获授权）| ✅ 是 |
| 卖**自己**的房，但违反与第三人的包销/独家代理约定 | ❌ **不是**（有权处分 + 对第三人违约）|
| 卖**自己**的房，但已被法院查封 | ✅ 是（处分权受限）|
| 共有人**擅自**卖共有房（未经其他共有人同意）| ✅ 是（部分无权）|

**判断公式**：
> **看"卖的是谁的东西 + 有没有处分权"，不看"有没有违反对别人的合同承诺"。**
> 违反合同承诺 → 违约问题（债权层面）；处分权欠缺 → 无权处分（物权层面）。两个层面**严格分开**。

→ 本题甲卖**自己开发的房** → 有权处分 → A 错。但违反对乙的包销承诺 → 违约 → B 对。**一个行为，两层评价**。

## 🔑 核心概念深度讲解 2 · 限购政策致合同不能履行（C 项专项 · 最高法纪要）

### 法理依据原文

> **最高法《全国民事审判工作会议纪要》（法办〔2011〕442号）**：
> "房屋买卖合同签订后，由于相应住房限购政策的实施，当事人无法办理房屋所有权变更登记，买受人请求解除合同，并要求出卖人返还所收受的购房款或定金的，如果经审查，当事人的确因住房限购政策的实施而不能办理房屋所有权变更登记，对其请求**可予支持**。"

### 三个层次理解

1. **政策属于"不可归责于双方的客观情况"**——丙签约时有资格，政策出台后失资格，双方都没过错
2. **合同目的不能实现**——房子过不了户，"买房"目的落空 → 解除权成立（今 §563 I ① 类推/④ + 纪要）
3. **解除后互不担责 + 返还**——出卖人返还购房款/定金（+ 利息）；纪要还规定：购买**基本/改善住房**的，卖方反请求买方赔损失**原则上不支持**；**投资性住房**以定金数额为限

### 限购 vs 情势变更 vs 不可抗力（易混三角）

| 维度   | 限购失资格（本题）        | [[情势变更]] §533                 | 不可抗力 §563 I ①     |
| ---- | ---------------- | ----------------------------- | ----------------- |
| 触发   | 政策使买方**失去履约资格**  | 基础条件重大变化，继续履行**显失公平**         | 客观情况致**不能履行**     |
| 后果   | 客观履行不能 → **可解除** | 先**重新协商** → 协商不成请求法院**变更或解除** | 致目的不能实现 → **可解除** |
| 程序   | 通知解除（按纪要可直接支持）   | **必须经法院/仲裁**（形成诉权）            | 通知解除              |
| 本题适配 | ✅ C 项            | 不是本题路径                        | 学理近似（政策类推）        |

→ 法考小心：限购政策案型，主流按"**目的不能实现 + 纪要**"处理为解除，**不强制走情势变更的法院变更程序**。

## 🔑 核心概念深度讲解 3 · 解除后的返还范围（D 项专项）

**§566 解除后果**：尚未履行的终止履行；已履行的，根据履行情况和合同性质，可请求**恢复原状**或采取其他补救措施，并有权请求**赔偿损失**。

**返还首付款的完整账单**：
```
甲应返还丙：
  ① 首付款本金 20 万          ← 恢复原状（底线）
  ② + 资金占用利息            ← 20 万在甲手里趴了几个月，利息跟着退
  ③ ± 损失分担               ← 按 2011 纪要：双方无过错（政策原因）→ 互不赔偿
                                （基本/改善住房：卖方索赔不支持；投资房：以定金为限）
```

→ D 项"**只需**返还 20 万**本金**"砍掉了利息 → 过于绝对 → 错。

## 📐 答题口诀 · 包销不夺处分权；政策失资格可解除

> **"自己的房自己有权卖（不是无权处分）；包销期内偷偷卖 = 对包销方违约；买家因政策没资格 = 可解除；解除退钱本金 + 利息，不止本金。"**

### 关键词触发表

```
看到题干关键词                                  → 判断
"包销/独家代销 + 开发商（所有权人）自己卖"        → 有权处分（A 类陷阱 ✗）+ 对包销人违约（B ✓）
"调控政策/限购 + 买家丧失购房资格 + 不能履行"     → 买家可请求解除（C ✓ · 2011 纪要）
"解除后只返还本金"                               → 错，本金 + 利息（D 类陷阱 ✗）
"卖别人的房 / 卖查封房 / 共有人擅卖"             → 才是真·无权处分（§597）
"政策致显失公平（还能履行但亏大了）"             → 走情势变更 §533（法院变更/解除）
```

### 💡 关键洞察 1：A 项是"无权处分"的经典反向陷阱

命题人赌你看到"包销期内卖了不该卖的房"就条件反射选"无权处分"。破解钥匙一句话：

> **无权处分看"东西是不是你的、处分权在不在你手里"，不看"你有没有对别人承诺过不卖"。**

承诺不卖却卖了 = **违约**（债权层面）；东西不是你的却卖了 = **无权处分**（物权层面）。本题房是甲自己的 → 有权处分 → A 错、B 对。

### 💡 关键洞察 2：C 项是 2011 限购纪要的"时事题"

本题 2012 年出题，恰逢 2010-2011 全国限购潮 + 最高法 2011 杭州民事审判会议纪要出台——**司法考试爱考"新规 + 时事"**。今天换成民法典语言：政策致履行不能 → 目的不能实现 → §563 解除 + §566 返还。2026 法考同理：盯住 [[合同编通则司法解释]] 2023 新规的"时事题"。

### 💡 关键洞察 3：D 项的"绝对化措辞"信号

"**只需**返还本金"——多选题里看到"只需 / 仅 / 一律 / 必须"这类**绝对化措辞**，先打问号。解除后的返还 = 恢复原状的完整账：**本金 + 利息**（± 损失分担）。砍掉利息 → 错。

### 🆚 一个行为两层评价 — A vs B 对照速记

| 评价层面 | 问题 | 本题答案 | 选项 |
|---|---|---|---|
| **物权层面** | 甲有没有**处分权**？ | 有（自己开发的房）→ 有权处分，甲丙合同有效 | A ❌ |
| **合同层面** | 甲有没有**违反对乙的承诺**？ | 有（包销期内自卖）→ 对乙违约 | B ✅ |

### 🆚 真·无权处分 vs 假·无权处分 — 一表速记

| 情形 | 定性 |
|---|---|
| 卖**自己的**房，违反包销/独家代理约定（本题）| 有权处分 + **违约** |
| 卖**他人的**房（无授权）| **无权处分** §597 |
| 卖**查封**的房 | **无权处分**（处分权受限）|
| 共有人**擅自**卖整套共有房 | **无权处分**（超出份额部分）|
| 一房二卖（都是自己的房）| 两份合同**都有效**，先过户者得房，另一买家索赔违约 |

### 🎯 一句话记忆

> **"自己的房 = 有权处分；包销期偷卖 = 对包销方违约；买家政策失资格 = 可解除；退钱 = 本金 + 利息，不止本金。"**

> **"无权处分看'东西是谁的'，违约看'承诺给谁了'——一个行为，两层评价，互不打架。"**

### 填空模板（主观题用）

> 房屋系甲公司**【自己开发、享有所有权】**，其出卖给丙为**【有权处分】**，甲丙买卖合同**【有效】**（A 错）。
>
> 但甲在包销期内自行出售包销范围内房屋，**【违反包销合同的独家销售义务】**，乙公司有权请求甲公司**【承担违约责任】**（§577 · B 对）；依合同相对性，乙**【不得对抗丙】**。
>
> 因国家调控政策丙**【丧失购房资格，合同客观不能继续履行，且不可归责于双方】**，依最高法 2011 民事审判会议纪要（今 §563 + §566 精神），丙有权**【请求解除合同】**（C 对），甲应返还首付款**【20 万本金及利息】**——"只需返还本金"过于绝对（D 错）。
>
> 故选 **BC**。
