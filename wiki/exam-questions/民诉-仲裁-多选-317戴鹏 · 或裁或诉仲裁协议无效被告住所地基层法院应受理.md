# 民诉-仲裁-多选-317戴鹏 · 或裁或诉仲裁协议无效被告住所地基层法院应受理

## 题干

> 【出处】2026戴鹏民诉311-324题独立文档第 317 题（题库自带标注"2020 金题-2-4-28"，该年份编号未经独立核验；与另一民诉库"管辖章"第317题系不同题库、不同题目）

C 市 J 区甲公司和 C 市 K 区乙公司签订服务合同，约定因为履行合同发生纠纷由 C 市仲裁委仲裁或者由被告住所地法院管辖。后来因为合同履行发生纠纷，甲公司向 C 市仲裁委申请仲裁，乙公司向 J 区法院起诉，并申请确认仲裁协议无效。关于本案，下列哪些选项是正确的？

- A. J 区法院应当裁定仲裁协议无效
- B. 乙公司可以向 C 市 K 区法院申请确认仲裁协议无效
- C. J 区法院应当受理本案
- D. 本案仲裁协议无效

## 我的答案

**CD**

## 解析

### 本题考什么

本题考查 **"或裁或诉"条款（由C市仲裁委仲裁或由被告住所地法院管辖）中仲裁协议无效＋乙向被告（甲，C市J区）住所地法院起诉，J区法院应受理＋确认仲裁协议效力由中级法院管辖（非基层）**：
- 约定"由C市仲裁委仲裁或由被告住所地法院管辖"属**或裁或诉条款**，其中的**仲裁协议无效**（D对）；
- 乙公司向被告（甲公司，C市J区）住所地的**J区法院起诉**——J区是被告住所地、有管辖权，J区法院**应受理本案**（C对）；
- 确认仲裁协议效力的案件由**中级人民法院**管辖，J区法院（基层）无权裁定确认仲裁协议无效（A错）；乙也不能向K区法院（基层）申请确认无效（B错，应向中院申请）。

📍 对应深度报告考点：[[民诉-客观题考点全景-深度报告]] › 板块D · 仲裁司法审查（或裁或诉/确认效力管辖）

### 逐项解析

**D —— ✅ 正确（应选）**

- 判断理由：约定"由C市仲裁委仲裁**或者**由被告住所地法院管辖"属或裁或诉条款，其中的**仲裁协议无效**（当事人可选择诉讼，仲裁排他性丧失）。
- 法律依据：《仲裁法》（2025修订，现行有效）；或裁或诉条款下仲裁协议原则无效。
- 官方链接：[仲裁法（npc.gov.cn）](http://www.npc.gov.cn/npc/c2/c30834/202509/t20250912_446000.html)
- 对应深度报告考点：或裁或诉→仲裁协议无效

**C —— ✅ 正确（应选）**

- 判断理由：仲裁协议无效、约定的"被告住所地法院管辖"有效。乙向被告甲公司住所地（C市J区）的J区法院起诉，J区法院有管辖权，**应受理本案**。
- 法律依据：《民事诉讼法》（2023修正，现行有效）第二十四条（合同纠纷由被告住所地/合同履行地管辖）；管辖协议约定被告住所地有效。
- 官方链接：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)
- 对应深度报告考点：被告住所地法院受理

**A —— ❌ 错误（不选）**

- 判断理由：确认仲裁协议效力的案件由**中级人民法院**管辖，J区法院（基层）无权"裁定确认仲裁协议无效"。J区法院受理的是本案实体诉讼；确认仲裁协议效力须由中院处理。
- 法律依据：确认仲裁协议效力由中级人民法院管辖（仲裁法司法解释）。
- 官方链接：[仲裁法（npc.gov.cn）](http://www.npc.gov.cn/npc/c2/c30834/202509/t20250912_446000.html)
- 对应深度报告考点：确认效力归中院

**B —— ❌ 错误（不选）**

- 判断理由：确认仲裁协议效力由**中级人民法院**管辖，乙不能向K区法院（基层）申请确认仲裁协议无效。
- 法律依据：确认仲裁协议效力由中级人民法院管辖。
- 官方链接：[仲裁法（npc.gov.cn）](http://www.npc.gov.cn/npc/c2/c30834/202509/t20250912_446000.html)
- 对应深度报告考点：非基层法院

### 结论

综上，或裁或诉中仲裁协议无效（D）、乙向被告住所地J区法院起诉J区法院应受理（C）；确认仲裁协议效力归中院，J区/K区基层法院无权确认无效（A、B错）。本题答案为 **CD**。

### ⚡ 做题眼

> **"或裁或诉：仲裁协议无效；告到被告住所地基层法院受理；但'确认仲裁协议效力'归中院"（一眼判）**：
> "C市仲裁委仲裁**或**被告住所地法院管辖"＝或裁或诉 → **仲裁协议无效**（D）。乙向被告甲的J区（被告住所地）起诉 → **J区法院受理**（C）。
> 但"**确认仲裁协议效力**"是**中院**的事，J区/K区基层法院都无权确认无效（A、B 错）。
> 一句话："**又裁又诉仲裁作废、告到被告地基层法院；但确认仲裁协议效力得找中院。**"
