# C2-多选-41 · 名为合伙实为借贷：合伙无效，借款有效（§967/§146 II）

## 题干（金题来源：2020金题-2-1-28）

> 肖某经营的餐厅因扩大经营需要资金，戴某愿意向其提供借款100万元，但要求与肖某签订一份合伙协议，约定合伙期限为3年，戴某不承担任何经营风险，仅每年固定获取收益10万元，第三年年底获得本息合计130万元。肖某遂与之签订了该合伙协议，并取得100万元资金用于餐厅经营。关于该合伙协议的性质和效力，下列选项正确的是？

- A. 合伙合同无效
- B. 性质为合伙合同
- C. 借款合同有效
- D. 性质为借款合同

## 我的答案

**ACD**<!-- confidence: INFERRED -->

戴某不分担任何经营风险、仅取固定回报，实质是借款关系，名为合伙实为借贷（§146 II）；合伙的标签无效（A），真实性质是借款（D），借款安排本身有效（C）。

## 涉及考点

- 📐 **答题模型** → [[民法-合同-合伙模型]]（第一步·定性：共担风险是合伙灵魂；固定回报+不担风险+期满还本=名为合伙实为借贷，壳无效§146Ⅰ/核有效§146Ⅱ）
- [[合伙合同]] 定义要素：共同出资 + 共担风险 + 共享收益（§967）
- [[借款合同]] 名实不符：以虚假合同隐藏真实借款（§146 II）
- "固定回报不分担风险" = 本质特征之借款

## 考点精解 · 名为合伙实为借贷认定三步法

### 是什么 / 易混

**§967 合伙合同定义**：
> 合伙合同是两个以上合伙人为了共同的事业目的，订立的**共同出资、共同经营、共享收益、共担风险**的合同。

**"共担风险"是合伙的核心标志**。没有风险共担 = 不是真正的合伙。

**§146 II 名实不符原则**（以虚假意思表示隐藏真实行为）：
- 虚伪表示（合伙协议外壳）→ 无效（A正确：合伙合同无效）
- 隐藏的真实行为（借款）→ 依照有关法律规定处理

本题隐藏的真实关系是**借款合同**（戴某出资100万，肖某固定还款）→ 借款合同本身无违法理由 → **有效**（C正确）

### 识别"名为合伙实为借贷"的三特征

| 特征 | 合伙 | 名为合伙实为借贷 |
|---|---|---|
| 风险承担 | 共同承担经营风险 | **一方不承担任何风险** |
| 收益方式 | 按约定比例分享利润 | **固定金额/固定比率** |
| 本金归还 | 无本金返还约定 | **期满返还本金** |

本题：戴某"不承担任何经营风险"+ "固定获取收益10万元/年"+ "第三年年底获得130万（本息合计）" → **三大特征全中** → 名为合伙实为借贷

### 逐项解析

**A（合伙合同无效）→ 正确**
合伙协议的外壳是虚假意思表示（§146 I），双方真实意图是借款关系，"合伙协议"的性质定性不成立 → 作为合伙合同无效。

**B（性质为合伙合同）→ 错误**
名实不符，真实性质是借款，不是合伙（D正确→B错误，两者互斥）。

**C（借款合同有效）→ 正确**
隐藏的真实借款行为，依借款合同规则处理（§146 II）。月利率不超过LPR×4，无违法目的 → 借款合同有效。

**D（性质为借款合同）→ 正确**
不分担风险、固定回报、期满还本 → 本质是借款而非合伙，应认定为借款合同。

### 怎么考 / 坑在哪

1. **BD 互为干扰**：B说合伙，D说借款，二者必有一错一对→选D排B。
2. **A/C 的关系**：合伙合同定性无效（A），但借款合同有效（C）——不是说"合同整体无效"，而是"剥去合伙外壳后，内核借款合同有效"。
3. **利率要另行验证**：固定年化收益 = 10万/100万 = 10%，在LPR×4（约16%）以内，无高利贷问题。

## 📐 答题口诀 · [[合伙合同]] 真假合伙辨别

**关键词触发**：签了"合伙协议" / 一方固定回报 / 不承担风险

**🎯 一句话记忆**：
> 合伙必担风险；固定回报不担险 = 借款，合伙壳无效，借款核有效。

**识别三连问**：
```
① 有没有固定回报（不管经营好坏）？→ 有 → 非合伙特征
② 有没有"不承担任何风险"的约定？→ 有 → 非合伙特征
③ 期满是否还本？→ 是 → 借款特征

三个"是" → 名为合伙实为借贷 →
  · 合伙合同无效（§146 I/§967）
  · 借款合同有效（§146 II）
  · 利率仍须 ≤ LPR×4（§680）
```
