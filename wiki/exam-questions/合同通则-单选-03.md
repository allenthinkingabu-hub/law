# C1-单选-03 · 债权的核心权能

## 题干

> 下列债权的权能中，若哪一项欠缺后**即不再是债权**？

- A. 请求权能
- B. 保持受领权能
- C. 保全权能
- D. 处分权能

## 我的答案

**A**（请求权能）<!-- confidence: INFERRED -->

## 涉及考点

- [[债的特征]] · 请求权能

## 考点精解 · 债权四权能

### 是什么 / 易混

- **请求权能**：请求债务人为或不为一定行为——债权的**本质特征**
- **保持受领权能**：受领并保有给付（决定有无不当得利）
- **保全权能**：[[代位权]] / [[撤销权]] 等保全制度
- **处分权能**：转让、抛弃、设定担保等

注：请求权能是债权之"魂"——欠缺即不再是债权（变成"自然债"等其他）；其他权能可有可无。

### 怎么考 / 坑在哪

- **干扰项分析**：
  - 保持受领权能欠缺 → 仍是债权，只是受领后须返还
  - 保全权能欠缺 → 仍是债权，只是受保护程度低
  - 处分权能欠缺 → 仍是债权，只是不能转让等

### 怎么答

债权的核心是"请求债务人给付"。请求权能消失即丧失债的本质属性。故选 **A**。


### Step 2:4 权能层级速记

```
请求权能（核心 / 灵魂 / 本质）   ← 欠缺 → 不是债权
   ▼
保持受领权能（重要但可缺）       ← 欠缺 → 形成不当得利之债（仍是债）
   ▼
保全权能（衍生）                 ← 欠缺 → 保护力降低（仍是债）
   ▼
处分权能（衍生）                 ← 欠缺 → 不能转让（仍是债）
```

### Step 3:4 权能"欠缺测试"——还是债权吗?

| 选项           | 欠缺情景          | 还是债权?    | 错因 / 对因            |
| ------------ | ------------- | -------- | ------------------ |
| **A 请求权能**   | "下周一一起爬山"情谊行为 | ❌ **不是** | ✅ **正解 — 债权的灵魂**   |
| **B 保持受领权能** | 小李错转老王 1000 元 | ✅ 是      | ❌ 错 — 形成**不当得利之债** |
| **C 保全权能**   | 专属性债权排除代位权    | ✅ 是      | ❌ 错 — 12 万债权**还在** |
| **D 处分权能**   | 约定"不得转让"      | ✅ 是      | ❌ 错 — 仍可请求还款       |

→ 选 **A 请求权能** ✅

### 🚗 故事化记忆 · "请求权能 = 灵魂" 3 种关系对比

| 关系                   | 请求权能（实体） | 胜诉权  | 是债权?        |
| -------------------- | -------- | ---- | ----------- |
| **A 情谊行为**（"下次请你吃饭"） | ❌ 无      | ❌ 无  | **不是**      |
| **B 正常债权**（写了借条）     | ✅ 有      | ✅ 有  | **是**       |
| **C 自然债务**（时效届满）     | ✅ 实体有    | ❌ 消灭 | **是**（特殊形态） |

→ **请求权能 vs 胜诉权细分**:
- **实体请求权能**（要求债务人给付的权利）= 债的**灵魂**
- **胜诉权 / 诉权**（国家强制力实现请求）= 债的**保障**
- 时效届满 = **胜诉权**消灭 ≠ **请求权能**消灭 → 自然债务仍是债

### 🎯 一句话记忆

> **"4 权能不平等:请求权能是核心,其他 3 是属性"**  
> **"请求权能 = 债权的'灵魂',欠缺即不再是债权"**  
> **"时效届满消灭的是'胜诉权',不是'请求权能本身'——所以自然债务仍是债"**
