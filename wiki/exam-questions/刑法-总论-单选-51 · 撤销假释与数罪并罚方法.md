# 刑法-总论-单选-51 · 撤销假释与数罪并罚方法

## 题干

> 来源：依据《刑法》第85、86条命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

丁被判处有期徒刑15年，执行8年后假释，假释考验期为剩余的7年。下列关于撤销假释的说法，正确的是？

- A. 丁在考验期内又犯抢劫新罪，应撤销假释，将前罪未执行的7年与新罪所判刑罚依第70条"先并后减"
- B. 丁在考验期内被发现假释前还有漏罪未判，应撤销假释，依第71条"先减后并"
- C. 丁在考验期内严重违反监管规定但尚未构成新罪，应撤销假释，收监执行未执行完毕的刑罚（即剩余7年）
- D. 丁在考验期满后才被发现假释前有漏罪，仍应撤销假释，数罪并罚

## 我的答案

**C**<!-- confidence: EXTRACTED -->

正解为 C。§86 规定撤销假释的三种情形及处理：①考验期内**犯新罪** → 撤销，依 **§71"先减后并"**；②发现**漏罪** → 撤销，依 **§70"先并后减"**；③**违反监管规定**情节严重尚未构成新罪 → 撤销，**收监执行未执行完毕的刑罚**。

- A 错：新罪应依 §71**先减后并**，A 写成 §70"先并后减"，方法错位。
- B 错：漏罪应依 §70**先并后减**，B 写成 §71"先减后并"，方法错位。
- C 对：违规情节严重，撤销假释，收监执行剩余 7 年，不再数罪并罚（无新罪/漏罪）。
- D 错：**考验期满后**才发现漏罪的，依 §85 原判刑罚已**视为执行完毕**，不撤销假释，对漏罪单独处理即可。

## 考点精解 · 撤销假释三情形对照表

| 情形 | 是否撤销 | 处理方法 | 依据 |
|------|:---:|------|:---:|
| 考验期内**犯新罪** | 撤销 | **先减后并**（先减已执行，再并新旧两罪） | §71 |
| 发现假释前**漏罪** | 撤销 | **先并后减**（先并两罪，再减已执行） | §70 |
| **违反监管规定**情节严重（无新罪） | 撤销 | 收监执行**未执行完毕的刑罚** | §86③ |
| **考验期满后**才发现漏罪 | **不撤销** | 原判视为执行完毕，漏罪单独处理 | §85 |

"先减后并 / 先并后减"记忆法：
```
新罪 → 罪在假释"之后"发生 → 已执行的应"先减"掉 → 先减后并（§71）
漏罪 → 罪在假释"之前"已有 → 数罪应"先并"算总 → 先并后减（§70）
```
口诀：**新后漏前**——新罪发生在后所以先减，漏罪本就在前所以先并。
