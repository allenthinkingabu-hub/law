# 刑法-总论-犯罪论-单选-07 · 因果关系不等于刑事责任与意外事件

## 题干

> 来源：依据"因果关系≠刑事责任"及《刑法》第16条意外事件学理通说命制的**仿真题**（题干为本库命制，非历年真题；§16已联网核验 CONFIRMED）。

甲正常驾驶通过路口（已尽合理注意），乙突然从绿化带蹿出横穿马路，甲刹车不及将乙撞死，事后查明甲无任何交通违章、亦无从预见。下列正确的是？

- A. 甲的驾驶行为与乙的死亡有因果关系，故应负交通肇事罪的责任
- B. 甲的行为与乙的死亡有因果关系，但甲既无故意也无过失，属意外事件，不负刑事责任
- C. 甲的行为与乙的死亡没有因果关系
- D. 只要造成死亡结果，甲就应负刑事责任

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正解为 B。条件意义上，甲的车辆碰撞是乙死亡的原因，**因果关系成立**。但据《刑法》第16条，甲已尽合理注意义务、对乙突然蹿出的结果**不能预见**，既无故意也无过失，属**意外事件**，不负刑事责任。核心命题：**因果关系 ≠ 刑事责任**——有因果关系还须具备 §14 的故意或过失，缺主观要件即不担责。

- A 错：有因果关系不等于要负责；甲无过失，不构成交通肇事罪。
- B 对：因果关系成立，但无故意无过失、属意外事件，不负刑事责任。
- C 错：条件意义上碰撞确实导致死亡，因果关系存在，不能否认。
- D 错：纯结果归责（"造成死亡就担责"）违背责任主义，无主观罪过即不担责。

陷阱：把"有因果关系"直接等同于"要负责"，**忽略主观要件与 §16 意外事件**。

## 考点精解 · 因果之后必查主观，方知担责与否

因果关系只解决"客观上谁的行为导致了结果"，不解决"该不该让他负责"。负责还需 §14 主观罪过。本题正是"有因果但无罪过"的标准意外事件：尽到注意、不能预见 → §16 出罪。

```
        责任成立两步走
┌────────────────────────────────┐
│ 第一步：因果关系（客观）         │
│  甲驾车碰撞 → 乙死亡             │
│  条件意义上成立 ✔               │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ 第二步：主观罪过（§14）         │
│  有故意？ —— 无                  │
│  有过失？ —— 已尽注意、不能预见  │
│           → 无过失              │
└──────────────┬─────────────────┘
               ▼
        无故意 + 无过失
        ⇒ §16 意外事件
        ⇒ 不负刑事责任

  口径：因果关系 ≠ 刑事责任
  （有因果 → 还须查主观，缺罪过即出罪）
```

对比记忆：若甲超速/闯红灯（有过失）→ 因果＋过失成立 → 交通肇事罪；本题甲无违章、不能预见 → 因果成立但无过失 → §16 意外，出罪。
