# 刑法-总论-单选-23 · 累犯之假释考验期内犯新罪

## 题干

> 来源：依据《刑法》第65条、第86条命制的**仿真题**（题干为本库命制，非历年真题逐字摘录；法条已联网核验 CONFIRMED）。

甲于2015年因故意伤害罪被判处有期徒刑5年，2018年获假释，假释考验期为2年。在假释考验期内（2019年），甲又故意实施抢劫犯罪，应判处有期徒刑10年。关于甲是否构成累犯，下列说法正确的是？

- A. 构成累犯，因前后两罪均为故意犯罪且应判有期徒刑以上
- B. 不构成累犯，因后罪发生在假释考验期内，前罪刑罚尚未执行完毕
- C. 构成累犯，自假释之日起计算5年
- D. 不构成累犯，因抢劫与故意伤害不属同类犯罪

## 我的答案

**B**<!-- confidence: EXTRACTED -->

B：根据《刑法》第65条，一般累犯要求后罪发生在前罪"刑罚执行完毕或者赦免以后"。假释只是附条件地提前释放，考验期内原判刑罚仍处于"执行中"的状态（附条件、尚未执行完毕），并不满足"执行完毕"要件。考验期内再犯新罪，应当撤销假释、对新旧两罪数罪并罚（§86），而非以累犯论处。故甲不构成累犯 ✓

A：A选项表面看前后均为故意犯罪、均应判有期徒刑以上，似乎符合累犯条件，但其错误在于把"假释考验期内"当成了"刑罚执行完毕"，前罪刑罚此时尚未执行完毕，要件不成立 ✗

C：§65第二款"假释的犯人，从假释期满之日起计算"五年期限，前提是假释考验期已经平安届满、原判刑罚视为执行完毕。本题尚在考验期内（2019年仍属考验期），五年期限根本无从起算 ✗

D：一般累犯并不要求前后罪为同类犯罪，"同类"是特别累犯（§66）的认定思路。故"不属同类"不能成为否定累犯的理由，该选项理由错误 ✗

## 考点精解 · "执行完毕"与"考验期内"的分水岭

一般累犯的时间要件是"前罪刑罚执行完毕或者赦免以后5年内"。假释考验期的法律性质决定了它**不等于**执行完毕：

```
         判刑5年         获假释          考验期2年              考验期满
 [服刑]──────────➔[假释]──────────[考验期内]──────────➔[期满=视为执行完毕]
                    │                  │                       │
            原判刑罚"执行中"     仍属执行中(未完毕)        从此日起算累犯5年
                    │                  │
              此时再犯 ──➔ 撤销假释·数罪并罚(§86)，不构成累犯
                                       期满后5年内再犯 ──➔ 才可能构成累犯
```

核心区分：
1. **考验期内再犯**：原判刑罚未执行完毕 ➜ 撤销假释、数罪并罚，**不是累犯**。
2. **考验期满后再犯**：原判刑罚视为执行完毕（§83）➜ 自期满之日起5年内再犯故意罪，**才可能构成累犯**。
