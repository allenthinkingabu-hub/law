# C2-单选-06 · 第三人代偿后的赠与

## 题干

> 甲欠丙 800 元无力偿还，乙替甲还款并对甲说："这 800 就算给你了。" 甲称将来一定奉还。后甲还了乙 500 元。乙再要 300，甲反要回 500。哪一说法正确？

- A. 甲应再还 300 元
- B. 乙应退回 500 元
- C. 乙不必退 500，甲也不必再还 300
- D. 乙应退还 500 + 银行利息

## 我的答案

**A**<!-- confidence: INFERRED -->

## 涉及考点

- [[赠与合同]] 须双方意思表示一致（§657）
- [[第三人代为履行]]（§524）
- [[不当得利]] 的边界
- 📐 **答题模型** → [[民法-合同-赠与合同撤销与抗辩模型]]

## 考点精解 · "赠与"被拒后的代偿关系

### 是什么 / 易混

**赠与合同**（§657）：赠与是**双方法律行为**——赠与人**单方表示**送，受赠人需**接受**。

| 阶段               | 法律分析                     |
| ---------------- | ------------------------ |
| ① 乙替甲偿丙 800      | 第三人代为履行（§524）→ 乙对甲取得追偿权  |
| ② 乙说"就算给你了"      | 单方表示赠与，要约                |
| ③ 甲说"将来奉还"       | **拒绝赠与**（受赠人拒绝接受）→ 赠与不成立 |
| ④ 乙仍对甲有 800 元追偿权 | 第三人代为履行后的回填关系            |
| ⑤ 甲还 500 元       | 部分清偿，剩余 300              |

→ 赠与**因甲拒绝而不成立**——乙仍是债权人，甲应还 800，已还 500，剩 300。

### 怎么考 / 坑在哪

- **C 易错**：以为"双方都不动" = 公平。其实赠与未成立 → 必须按代偿关系处理
- **B/D 错**：500 元是正当清偿，乙不必返还
- **重点**：赠与必须**受赠人接受**——拒绝则不成立

### 怎么答

A。甲拒绝赠与 → 800 元代偿债务仍存 → 再付 300。
