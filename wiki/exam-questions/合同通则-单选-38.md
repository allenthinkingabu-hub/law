# C1-单选-38 · 恶意磋商 + 泄露商业秘密 = 缔约过失（德凯案）

## 题干

> 德凯公司拟为新三板上市造势，在无真实交易意图的情况下，短期内以业务合作为由邀请多家公司来其主要办公地点洽谈。其中，真诚公司安排授权代表往返十余次，每次都准备了详尽可操作的合作方案，德凯公司佯装感兴趣并屡次表达将签署合同的意愿，但均在最后一刻推脱拒签。期间，德凯公司还将知悉的真诚公司的部分商业秘密不当泄露。对此，下列哪一说法是正确的？（2017-3-12）

- A. 未缔结合同，则德凯公司就磋商事宜无需承担责任
- B. 虽未缔结合同，但德凯公司构成恶意磋商，应赔偿损失
- C. 未缔结合同，则商业秘密属于真诚公司自愿披露，不应禁止外泄
- D. 德凯公司也付出了大量的工作成本，如被对方主张赔偿，则据此可主张抵销

## 我的答案

**B**（恶意磋商 = 缔约过失，赔偿信赖利益损失）<!-- confidence: EXTRACTED -->（官方参考答案：B）

## 考点精解 · [[缔约过失责任]]（§500 / §501）

### 是什么 / 易混

- **恶意磋商**：假借订立合同、无真实交易意图地磋商（§500 ①）。德凯"无真实交易意图""佯装感兴趣""最后一刻拒签"完美命中。
- **保密义务**：磋商中知悉的商业秘密，无论合同是否成立都**不得泄露/不正当使用**（§501）。
- 责任性质 = **缔约过失**，赔偿**信赖利益**损失（往返差旅、方案制作等真诚公司的实际投入）。

### 怎么考 / 坑在哪

- **A"无需担责"错**：缔约过失的精髓正是"**合同没成立也要赔**"。
- **C"自愿披露可外泄"错**：磋商中知悉≠自愿公开，§501 保密义务**独立于合同成立**。
- **D"工作成本可抵销"错**：恶意磋商的**过错方**自己的成本是自担风险，无权拿来抵销，更不能向受害方主张。

### 怎么答

合同未成立但德凯恶意磋商 + 泄密 → 缔约过失，赔真诚公司损失 → 选 **B**。

## 📐 答题口诀 · 缔约过失：没签约也得赔，过错方别想抵销

> **"假意谈判晃点人 = 恶意磋商；磋商知密负保密；没成合同照样赔；过错方成本，自己咽。"**

### 关键词触发表

```
看到题干关键词                          → 指向
"无真实交易意图 / 假借磋商 / 屡次拒签"   → 恶意磋商 §500①（缔约过失）
"磋商中知悉商业秘密 + 泄露"             → 违反保密义务 §501（合同未成立也担责）
"合同没成立 = 不担责"                   → 错（缔约过失就是没成立也赔）
过错方"我也花了成本，可抵销"            → 错（过错方无权抵销）
```

### 逐项选项分析

| A 无需担责 | ❌ | 缔约过失=合同未成立也担责 |
| **B 恶意磋商赔偿** | ✅ | §500① + §501 |
| C 可外泄 | ❌ | §501 保密义务独立于合同成立 |
| D 抵销 | ❌ | 过错方自己的成本不能抵销 |

### 🚗 老王小李故事

> 老王压根不想跟小李做生意，只是想借"谈合作"给自己撑场面、套小李的方案。小李傻乎乎跑了十几趟、做了一堆详细方案，老王每次都说"快签啦"，临门一脚就溜，还把小李的商业机密抖了出去。合同一份没签——老王能甩锅"没签约不关我事"吗？不能。这叫**恶意磋商**（缔约过失），小李白跑白做的钱老王得赔；机密更不能泄（不管签没签）。老王还想拿"我也累着了"抵账？没门，他是过错方。

### 🎯 一句话记忆

> **"假谈判、真晃点 = 缔约过失；没成合同照赔信赖利益；过错方成本不能抵。"**

### 填空模板（主观题用）

> 德凯公司**【无真实交易意图、假借磋商屡次拒签】**，构成 §500① **【恶意磋商】**；磋商中知悉并泄露商业秘密，违反 §501 **【保密义务】**（合同是否成立**均**担责）。虽未缔约，仍应赔偿真诚公司**【信赖利益损失】**（往返、方案成本）；过错方德凯无权以自身成本主张抵销。故选 **B**。
