# 刑法-总论-单选-46 · 减刑的限度限制

## 题干

> 来源：依据《刑法》第78条第2款命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

下列关于减刑后实际执行刑期下限的表述，正确的是？

- A. 张某被判处有期徒刑12年，多次减刑后实际执行刑期不能少于6年
- B. 李某被判处无期徒刑，多次减刑后实际执行刑期不能少于10年
- C. 王某被判死缓并由法院依法决定限制减刑，缓期执行期满后减为无期徒刑的，实际执行不能少于25年（含死缓考验的2年）
- D. 减刑以后实际执行的刑期可以低于原判刑期的三分之一

## 我的答案

**A**<!-- confidence: EXTRACTED -->

依《刑法》第78条第2款，减刑后实际执行刑期不能低于法定下限。(一)判处管制、拘役、有期徒刑的，减刑后实际执行的刑期**不能少于原判刑期的二分之一**。A项有期徒刑12年×1/2＝6年，正确。

逐项解析：
- B项：§78第2款(二)，判处**无期徒刑**的，减刑后实际执行的刑期**不能少于13年**（《刑法修正案（八）》已将原"10年"改为"13年"）。"不能少于10年"是修八前的旧标准，错。
- C项：§78第2款(三)，对死缓限制减刑的，缓期执行期满依法减为无期徒刑的，不能少于**25年**；减为25年有期徒刑的，不能少于**20年**。但该25年/20年是**从死刑缓期执行期满之日起**计算的，**不包含**死缓2年考验期。C项"含死缓考验的2年"错误。错。
- D项：(一)管制、拘役、有期徒刑减刑后不能少于原判刑期的二分之一，远高于"三分之一"。"可以低于三分之一"错。

## 考点精解 · 减刑下限"一表清"

§78第2款的三档下限是必背数字，命题人专挖"无期=10年"和"死缓含不含2年"两个坑：

| 原判刑罚                 | 减刑后实际执行**下限**         | 起算点                 |
| -------------------- | --------------------- | ------------------- |
| 管制 / 拘役 / 有期徒刑       | **不少于原判刑期的 1/2**      | 判决执行之日              |
| 无期徒刑                 | **不少于 13 年** ⚠️（非10年） | 判决执行之日              |
| 死缓→（限制减刑）减为**无期**    | **不少于 25 年**          | **死缓考验期满之日**起算，不含2年 |
| 死缓→（限制减刑）减为**25年有期** | **不少于 20 年**          | **死缓考验期满之日**起算，不含2年 |


两个高频陷阱：
```
坑1：无期徒刑减刑下限 = 13年（修八后），不是10年
坑2：死缓限制减刑的25/20年，从"缓期执行期满之日"起算
     → 不包含死缓2年考验期（命题人爱加"含2年"诱你选错）
```
