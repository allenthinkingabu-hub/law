# C2-单选-41 · 多主体借款合同：贷款人未签字 + 保证责任成立（§679/§681）

## 题干（2015-3-13）

> 方某、李某、刘某和张某签订借款合同，约定："方某向李某借款100万元，刘某提供房屋抵押，张某提供保证。"除李某外其他人都签了字。刘某先把房本交给了李某，承诺过几天再作抵押登记。李某交付100万元后，方某到期未还款。下列哪一选项是正确的？

- A. 借款合同不成立
- B. 方某应返还不当得利
- C. 张某应承担保证责任
- D. 刘某无义务办理房屋抵押登记

## 我的答案

**C**<!-- confidence: EXTRACTED -->

自然人借款=实践合同，李某交付100万元后合同成立（A错）；合同成立非不当得利（B错）；张某保证有效，应承担保证责任（C正确）；刘某承诺抵押登记有义务履行（D错）。

## 涉及考点

- [[借款合同]] 自然人间借款 = 实践合同（§679）：以贷款人提供借款时成立
- [[保证合同]] 保证合同效力认定：保证人签字有效（§681/§686）
- 抵押合同义务：承诺办理抵押登记须履行（§403）

## 考点精解 · 多主体借款合同的成立与担保效力

### 是什么 / 易混

本题涉及一份"大合同"，同时包含：
- **主债**：方某（借款人）← 向 → 李某（贷款人）借款100万
- **担保一**：刘某 提供房屋抵押
- **担保二**：张某 提供保证

签字情况：**李某未签字**，方某、刘某、张某签了字。李某提供了100万元借款。

**§679 自然人间借款=实践合同**：
> 自然人之间的借款合同，**自贷款人提供借款时成立**。

→ 李某（贷款人）未签字，但以实际交付行为（提供100万元）表明其接受，借款合同**成立**（通过行为表示同意）。A错。

**保证合同的成立（§681 + §686）**：
张某签字提供保证 → 保证合同成立有效。即使主合同（借款）中债权人（李某）未签字，张某单方签字提供保证 + 李某以提供借款的行为表示接受 → 保证合同生效 → 张某有保证义务（C正确）。

### 四个选项分析

**A（借款合同不成立）→ 错误**
理由：李某虽未在书面合同上签字，但其实际交付100万元 = **以行为表示同意**（§140 II）。自然人借款实践合同 = 自交付时成立，李某交付后合同成立。

**B（方某应返还不当得利）→ 错误**
理由：借款合同已成立，方某收到100万有合同依据 → 有合法原因，非不当得利（§985）。方某应依约还款，但不是返还不当得利。

**C（张某应承担保证责任）→ 正确**
理由：张某签字保证，保证合同成立有效。债务到期未还 → 张某须依保证合同承担保证责任。
（注：§686 Ⅰ 未约定保证方式 → 推定为**一般保证**，张某享有先诉抗辩权；但最终仍须承担保证责任。）

**D（刘某无义务办理抵押登记）→ 错误**
理由：刘某已签合同并承诺"过几天再作抵押登记"。该承诺具有合同约束力 → 刘某**有义务**按约履行抵押登记。
（注：未办登记 → 抵押权未设立，李某对刘某房屋无优先受偿权；但刘某因违约承诺不办理登记，需承担违约责任/赔偿。）

### 实践合同 vs 诺成合同对比

| 类型 | 成立时间 | 代表 |
|---|---|---|
| **实践合同** | 交付标的物/借款时 | 自然人间借款（§679）|
| **诺成合同** | 要约+承诺时 | 金融机构借款（§667）、赠与合同（§657）|

本题：自然人 vs 自然人 → 实践合同 → 交付100万时成立

### 怎么考 / 坑在哪

1. **A 陷阱**：看到"李某未签字"就以为合同不成立。关键：实践合同成立于交付，不在于签字；且李某实际交付100万 = 用行为表示了同意。
2. **D 陷阱**：以为"抵押未登记则无效→刘某无义务"。区分：抵押权设立（需登记，§403）vs 抵押登记义务（来自合同承诺）。刘某有登记义务但未履行 → 需赔偿李某损失，而非"无义务"。
3. **C 的保证方式**：§686 未约定保证方式 = 推定一般保证（2021年民法典新规：从原来的连带推定 → 一般保证）。本题考的是"张某有无保证责任"，答案是有（C正确），至于是一般还是连带，本题未考察。

## 📐 答题口诀 · 多主体借款四选项破解

**关键词触发**：多方签借款合同 / 贷款人未签字 / 已交付 / 保证人签了字

**🎯 一句话记忆**：
> 自然人借款，交付即成立，签没签字看行为；保证人签了字，保证责任就来了。

**四步验证**：
```
① 借款合同成立了吗？
   → 自然人借款 = 实践合同 → 看有没有提供借款 → 有 → 成立（A错）

② 收款有合法依据吗？
   → 合同成立 → 有依据 → 非不当得利（B错）

③ 保证合同有效吗？
   → 张某签字 → 李某以行为接受 → 保证成立 → 张某担责（C正确）

④ 抵押登记有义务吗？
   → 合同约定 + 刘某承诺 → 有义务（D错）
```
