# C2-多选-14 · 物业服务合同的关键规则

## 题干

> 关于业主与物业服务公司的权利义务，下列哪些选项**错误**？

- A. 物业公开作出的有利于业主的承诺 / 细则**不是**合同组成部分
- B. 即使物业无违约 → 业主大会仍可解除物业服务合同
- C. 业主拖欠物业费 → 物业可**停水电气热**催缴
- D. 业主出国进修 → 可**以未接受服务**为由**拒交**物业管理费

## 我的答案

**ACD**<!-- confidence: INFERRED -->

## 考点精解 · 物业服务合同 4 大金句

### 是什么 / 易混

**§938②**（公开承诺为合同组成部分）：物业服务人**公开作出的有利于业主的服务承诺** → **属于物业服务合同的组成部分**（⚠️物业**单方制定的服务细则**不当然入约；§939 另指"前期 / 选聘合同对业主有约束力"，别记串）。

**§944**（物业费交纳）：
- 业主**不能以未接受 / 无需接受**物业服务为由**拒付**物业费
- 物业**不得以停止供电、供水、供热、供燃气**等方式**催交**

**§946**（业主大会任意解除）：业主依法**共同决定**解聘物业 → 提前 **60 日**书面通知物业人 → **可解除**（不需要违约理由）

本题对照（问"错误"）：
- A "公开承诺不是合同组成部分" → **错**（§938② 明确：有利于业主的公开承诺是组成部分）→ 入
- B "无违约也可解除" → 对（§946 任意解除权）→ 正确
- C "停水电气热催缴" → **错**（§944 禁止）→ 入
- D "未实际居住可拒交" → **错**（§944 拒绝以此抗辩）→ 入

### 怎么考 / 坑在哪

- **D 经典陷阱**：以为"没住 = 没受益 = 不付费"——错。**物业服务的对价是公共服务**，是否实际居住不影响
- 本题问"错误"，故选 ACD

### 怎么答

ACD（"错误"项）。
