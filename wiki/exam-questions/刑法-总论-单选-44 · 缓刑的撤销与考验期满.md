# 刑法-总论-单选-44 · 缓刑的撤销与考验期满

## 题干

> 来源：依据《刑法》第73、76、77条命制的**仿真题**（题干为本库命制，非历年真题；本题型为缓刑撤销经典考法，法条已联网核验 CONFIRMED）。

关于缓刑的撤销与考验期，下列哪一选项是正确的？

- A. 缓刑考验期满，只要没有再犯新罪，原判刑罚就不再执行
- B. 被宣告缓刑者在考验期内又犯新罪的，应当撤销缓刑，把前罪与后罪所判处的刑罚依"先减后并"决定执行
- C. 缓刑考验期限，从判决确定之日起计算
- D. 被宣告缓刑者在考验期内违反监管规定，无论情节是否严重，一律撤销缓刑

## 我的答案

**C**<!-- confidence: EXTRACTED -->

依《刑法》第73条第3款，缓刑考验期限"从判决确定之日起计算"。C项表述准确，当选。

逐项解析：
- A项：依§76、§77，缓刑考验期满、原判刑罚"不再执行"的前提是**没有§77规定的三种情形**——①考验期内又犯新罪（含发现漏罪）、②发现判决宣告前还有漏罪未判、③违反法律行政法规或缓刑监督管理规定且情节严重。仅排除"再犯新罪"一种，表述不周延，遗漏"漏罪""违规情节严重"两种撤销事由。错。
- B项：缓刑撤销时，原判刑罚**尚未实际执行**。考验期内又犯新罪的，撤销缓刑后，应将**前罪原判的全部刑罚**与新罪所判刑罚，依§69的限制加重原则数罪并罚——不存在"减去已执行刑期"的问题，因此**不是"先减后并"**。"先减后并"是§71针对原刑罚**已部分实际执行**（如假释、刑罚执行期间又犯新罪）的算法，不能误套到缓刑。错。
- D项：§77第2款规定，考验期内违反法律、行政法规或缓刑监管规定，须达到"**情节严重**"才撤销缓刑。情节轻微的不撤销。"无论情节是否严重一律撤销"错误。错。

## 考点精解 · 撤销缓刑走§69、不是"先减后并"

缓刑与假释的撤销并罚算法不同，是命题人最爱挖的坑：

| 项目 | 缓刑撤销（§77→§69） | 假释撤销（§86→§71） |
|---|---|---|
| 原判刑罚是否实际执行 | **未执行**（缓刑只是暂缓） | **已执行一部分** |
| 有无"已执行刑期"可减 | 无 | 有 |
| 并罚算法 | 直接§69限制加重（**先并不减**） | §71"**先减后并**" |

**§77缓刑撤销三情形**（满足其一即撤销）：
```
①考验期内又犯新罪 / 发现漏罪（无论情节，必撤）
②判决宣告前的漏罪在考验期内被发现（必撤）
③违反法律·行政法规·监管规定，且【情节严重】（情节轻微不撤）
```

考验期满、且无上述三情形 → 原判刑罚**不再执行**（§76），并公开予以宣告。

## 📐 答题口诀 · 缓刑撤销先并不减

**关键词触发**：先减后并 / 考验期满不再执行 / 违规情节严重 / 撤销缓刑

**🎯 一句话记忆**：
> 缓刑没实际执行，撤销后直接§69"先并不减"（"先减后并"是假释/§71的活）；违规须"情节严重"才撤，考验期满无三情形原判不再执行。（详见 📐 [[刑法-总论-刑罚执行与消灭模型]]）
