# 刑法-总论-单选-28 · 减轻与从轻的临界判断

## 题干

> 来源：依据《刑法》第63条第1款命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

某罪法定刑为"三年以上十年以下有期徒刑"。被告人戊具有一个法定减轻处罚情节。下列量刑符合减轻处罚规则的是？

- A. 判处有期徒刑3年
- B. 判处有期徒刑2年
- C. 判处有期徒刑8年
- D. 判处有期徒刑10年

## 我的答案

**B**<!-- confidence: EXTRACTED -->

B：根据《刑法》第63条第一款，减轻处罚必须在法定**最低刑（本题为3年）以下**判处。2年低于法定最低刑3年，落入"下一个量刑幅度"，正是减轻处罚的应有之义，符合规则 ✓

A：判处有期徒刑3年恰好等于法定最低刑。"等于最低刑"仍在法定刑幅度**之内**（贴着下限），属于"从轻处罚"，而不是"在法定刑以下"的减轻处罚 ✗

C：判处8年在"3年以上10年以下"幅度之内，属于正常量刑（偏中上），既非从轻也非减轻 ✗

D：判处10年是法定最高刑，仍在原法定刑幅度内，属正常量刑甚至偏从重，与减轻处罚相反 ✗

## 考点精解 · "踩线"与"破线"的临界刻度

以本题"3年以上10年以下"为标尺，把四个选项放到数轴上，分界线一目了然：

```
   减轻处罚区          │  ← 法定最低刑3年(分水岭)            法定最高刑10年 →
 ───────────●─────────│────●──────────────────●──────────────●───────
            B:2年      │   A:3年              C:8年          D:10年
        (破线=减轻 ✓)  │  (踩线=从轻 ✗)    (档内正常 ✗)   (档内/从重 ✗)
                       │←──────────  法定刑幅度之内(3~10年)  ──────────→│
```

核心刻度：
1. **分界线是法定最低刑（3年）**。判到**等于**最低刑（3年）只是"从轻"；必须**突破**最低刑往下（如2年）才叫"减轻"。
2. A的迷惑性最强：3年看似"最低"，但"等于最低"仍在档内，是从轻不是减轻。
3. C、D都在3~10年幅度内，连从轻都谈不上，更非减轻。
