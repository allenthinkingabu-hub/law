# 刑法-分论-财产犯罪-单选-13 · 盗拟制之盗接通信线路与非牟利使用界分案 V2

## 题干

> **信息来源**：依据《中华人民共和国刑法》第265条关于“以牟利为目的”盗接他人通信线路拟制为盗窃罪的规定，以及最高人民法院《关于审理扰乱电信市场管理秩序案件具体应用法律若干问题的解释》（法释〔2000〕12号）相关条款命制（已联网核验 CONFIRMED，来源：SPC court.gov.cn/chinacourt.org 刑事审判参考案例及最高人民法院公报案例）。

关于盗接他人通信线路或复制他人电信码号的行为定性，下列哪一选项是正确的？

- A. 甲为了给家里省钱，私自盗接了邻居乙家的固定电话线路，并用该线路给远在国外的亲戚拨打长途电话，产生电话费共计 3500 元。由于甲并非以转卖话费变现为目的，甲的行为不构成盗窃罪
- B. 丙为了获取非法利益，私自盗接了某电信公司的光纤宽带线路，并利用该线路在自己租赁的房屋内开设“黑网吧”，供他人付费上网，获取上网费 5000 元。丙的行为不构成盗窃罪，应定性为非法经营罪
- C. 丁以营利为目的，非法复制了他人的移动电话SIM卡码号（电信码号），并以低于市场价的价格向社会出租、出售该复制卡，供他人拨打电话使用，共计造成他人电信资费损失 8000 元。丁的行为构成盗窃罪
- D. 戊为了好玩，利用技术手段侵入某公司的内部程控交换机，盗接了通信线路。戊用该线路拨打免费客服热线和娱乐电话，未产生任何实际扣费，但导致该公司内部通信瘫痪半天。戊的行为构成盗窃罪

## 我的答案

**C**<!-- confidence: EXTRACTED -->

本题选正确项，正确答案为C。

- **A项错误**：虽然甲盗接邻居电话线是为了“自用省钱”，不属于《刑法》第265条规定的“以牟利为目的”盗接通信线路的法律拟制情形。但是，甲使用该线路打长途电话，产生了 3500 元的电话资费损失。根据最高法《关于审理扰乱电信市场管理秩序案件具体应用法律若干问题的解释》及刑法学理通说，**盗接他人通信线路“自用”且造成他人资费损失数额较大（达1000–3000元起）的，依然依照《刑法》第264条的普通盗窃罪定罪处罚**（盗窃的对象是无形的电信资费/财产利益）。因此甲的行为构成盗窃罪，A项说不构成是错误的。
- **B项错误**：丙以获取非法利益（营利）为目的，盗接光纤宽带线开设黑网吧。这完全符合《刑法》第265条的拟制规定：**以牟利为目的，盗接他人通信线路的，依照本法第264条（盗窃罪）的规定定罪处罚**。丙的行为直接构成**盗窃罪**（数额按其造成的资费损失或其获取的上网费计算），而非非法经营罪。
- **C项正确**：丁以营利为目的，非法复制他人电信码号并出售、出租给他人使用，造成资费损失 8000 元。这属于《刑法》第265条规定的“以牟利为目的……复制他人电信码号……而使用”的情形。丁作为复制并销售卡的人，与使用者构成盗窃罪的共同犯罪，依法应当按照**盗窃罪（§264）**定罪处罚。
- **D项错误**：戊虽然盗接了线路，但其既非以“牟利为目的”，且拨打的是免费热线，未产生任何财产性资费损失。因此，戊的行为不构成盗窃罪。但戊的行为导致该公司内部通信瘫痪半天，造成了严重的生产经营混乱，戊应当构成**破坏生产经营罪（§275）**。

**陷阱**：本题考查《刑法》第265条“盗接通信线路”的法理结构与“自用”的定性关系：
1.  **以牟利（营利）为目的盗接**（如开设公共公用电话、出租出售复制卡） ➜ 直接触发 §265 特别拟制 ➜ 依照 **盗窃罪** 处罚；
2.  **不以牟利为目的（自用省钱）盗接** ➜ 不触发特别拟制，但如果打掉的资费达到“数额较大” ➜ 依然依照普通 **盗窃罪** 处罚；
3.  **未产生资费损失仅破坏通信** ➜ 不构成盗窃 ➜ 视后果按 **破坏生产经营罪** 处罚。

## 考点精解 · 核心要点对照表

| 盗接行为主观目的        | 是否产生资费损失与数额       | 刑法定性与结论                      |
| --------------- | ----------------- | ---------------------------- |
| **以牟利为目的**      | 产生资费损失或获取上网费等。    | 依 §265 特别拟制定为**盗窃罪**。        |
| **非以牟利为目的（自用）** | 产生资费损失达到**数额较大**。 | 依 §264 普通盗窃定为**盗窃罪**（偷电信资费）。 |
| **非以牟利为目的（自用）** | 未产生资费损失（打免费电话）。   | 不构成盗窃罪（无财产损失）。               |
| **故意破坏线路/通信**   | 造成通信线路瘫痪或损失。      | 定**破坏生产经营罪**或**故意毁坏财物罪**。    |
