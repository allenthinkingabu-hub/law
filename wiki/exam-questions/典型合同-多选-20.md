# C2-多选-20 · 货已收风险移转：缺单证只是违约

## 题干

> 甲乙约定卖方甲负责将所卖货物运送至买方乙指定的仓库。甲如约交货，乙验收收货，但甲未将产品合格证和原产地证明文件交给乙。乙已经支付80%的货款。交货当晚，因山洪暴发，乙仓库内的货物全部毁损。下列哪些表述是正确的？

- A. 乙应当支付剩余20%的货款
- B. 甲未交付产品合格证与原产地证明，构成违约，但货物损失由乙承担
- C. 乙有权要求解除合同，并要求甲返还已支付的80%货款
- D. 甲有权要求乙支付剩余的20%货款，但应补交已经毁损的货物

## 答案

**AB**<!-- confidence: EXTRACTED -->

> 出处性质：**官方历年真题**（2013 年卷三第 61 题）。

## 出处与来源

- 出处：2013 年司法考试卷三第 61 题（官方答案 **AB**）
- 素材：[[2026-06-10-典型合同买卖合同真题]]（含参考答案）
- 法条依据：《民法典》§604（风险自交付时移转买受人）· **§599**（产品合格证/原产地证明等"提取单证以外的单证和资料"= 从给付义务）· **§611**（风险移转不影响追究出卖人违约责任）· §563（根本违约才可解除）
- 验真（2026-06-11）：题干与官方答案 AB 经[司法部官网 · 2013 年卷三原卷](https://www.moj.gov.cn/pub/sfbgw/jgsz/jgszzsdw/zsdwgjsfkszx/gjsfkskskt/202102/t20210203_172338.html)复核；§598 主给付（仓单/提单等"提取标的物的单证"）vs **§599 从给付**（产品合格证、原产地证明书等）之分经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对——**原 §598 引用更正为 §599**

## 涉及考点

- **风险负担交付主义** §604：货物已交付乙并验收 → 风险移转乙，山洪损失乙担
- 交付产品合格证/原产地证明是 **§599 从给付义务**，缺失构成违约但**非根本违约**（不影响 §604 风险移转、§611 仍可追责）
- 📐 **答题模型** → [[民法-合同-风险负担模型]]（交付主义→4 特殊场景→瑕疵阻断→风险≠违约责任·含 §598/§599 给付层次）
- 📐 **三者关系枢纽** → [[民法-合同-所有权交付风险三角关系模型]]（交付定风险：缺从给付单证(§599)不阻断风险移转(§609)，"缺单证=没交付=风险没转"是伪因果）

## 考点精解

- **A 对**：货物已交付且乙验收受领 → 自交付起风险移转乙（§604）；货被山洪毁损的风险由乙承担，乙仍应支付剩余 20% 全款。
- **B 对**：甲未交产品合格证/原产地证明，违反 **§599 从给付义务**构成违约；但依 **§611**，风险移转**不影响**乙另行追究甲的违约责任，**货物损失仍由乙承担**——两笔账并存。
- **C 错**：缺交单证是**从给付义务的瑕疵履行**、非根本违约（§563），乙**无权解除**、更不能要回 80%。
- **D 错**：货物已毁损、风险在乙，且交付后标的物已**特定化**，甲**无需补交**货物，乙仍应付清。

## 🎯 答题思路 ·"已收货 + 有瑕疵"四步定性模型（风险 × 给付义务 × 解除权）

> 凡"一方**已交货**、但履行有点**瑕疵**（缺单证 / 小毛病 / 少配件），问风险、能否解除、谁赔"的题，按这四步走。**本页真题即标准范例（答案 AB）。** 纯风险移转细则见 [[典型合同-单选-03]]，本模型聚焦其上叠加的"给付义务层次 + 解除权"。

### 一、核心考情

- **考查频率**：买卖合同高频多选点（[[典型合同考点-深度报告]]），最爱把"风险负担 + 从给付义务 + 根本违约 / 解除权"三件事**叠在一道题**里考你拆不拆得开。
- **命题核心**：制造"**已经收货却出了岔子**"的局面——用"缺单证 / 货毁了"诱你得出"没完成交付 / 能解约退款 / 不用付钱"的错误连锁。
- **三大必考点**：①交付了风险就移转（§604）②瑕疵分主给付 / 从给付（§598 / §599）③只有**根本违约**才能解除（§563），风险与违约责任**并行**（§611）。

### 二、万能四步模型

#### 第一步：先定"风险移转了没有"（§604 交付主义）

**法考铁则**：标的物已**交付并受领** → 风险移转买受人，之后的意外毁损由买受人担（§604；路货 / 托运 / 自提等细则套 [[典型合同-单选-03]] 风险四步模型）。
> ⚠️ 关键：风险是否移转，看**标的物本身**交付没有——**不因"缺几张单证"而停摆**。

**老王小李例子**（一条挖掘机故事贯穿四步）
- 老王把二手挖掘机开到小李工地、小李清点验收签字 → 当晚泥石流冲走挖掘机 → **风险已随交付转给小李**，小李照付款。
- 对照：若挖掘机还停在老王院里没交，就被泥石流冲走 → 风险**还在老王**。

- **本题**：甲送货至乙指定仓库、乙验收收货 → 标的物已交付 → 风险移转乙 → 山洪损失乙担、乙付全款（**A 对**）。

#### 第二步：给"瑕疵 / 违约"分层 —— 主给付义务 vs 从给付义务（§598 / §599）

**法考铁则**：
- **主给付义务**（§598）：合同的**核心**——交标的物本身、转移所有权、交"**提取标的物的单证**"（仓单 / 提单，凭它就能提货）。
- **从给付义务**（§599）：**辅助性**的——"提取单证**以外**的单证和资料"：产品合格证、质量保证书、原产地证明、发票、使用说明书、保险单等。
- **判断口诀**：缺了它，合同目的还能不能实现？**能 → 从给付；不能 → 主给付**。

**老王小李例子**（接挖掘机故事）
- **主给付**：交挖掘机本身 + 转移所有权（过户）—— 没这个，小李买挖掘机的目的直接落空。
- **从给付**：附带的**操作说明书、保养记录、发票** —— 缺了，挖掘机照样能开能用。
- 一测便知：少给说明书 = **从给付**瑕疵；挖掘机本身没交 = **主给付**不履行。

- **本题**：产品合格证 / 原产地证明 = §599 **从给付义务**，缺了不影响货物本身使用 → 从给付瑕疵。

#### 第三步：是不是"根本违约"—— 决定能不能解除（§563）

**法考铁则**：只有**致使不能实现合同目的**的根本违约，守约方才有法定解除权（§563①(四)）。**一般瑕疵履行 / 违反从给付义务 = 非根本违约 → 不能解除**，只能请求补正 + 赔偿。

**老王小李例子**（接挖掘机故事）
- 老王少给一本说明书（从给付瑕疵、挖掘机能用）→ 小李**只能要求补给 + 赔偿**，**不能退机解约**。
- 但若老王交来的挖掘机**发动机报废、根本开不动**（合同目的落空 = 根本违约）→ 小李**可解除退货**。

- **本题**：缺两张证书 ≠ 货物不能用 ≠ 合同目的落空 → **非根本违约** → 乙**无权解除**、更不能要回 80%（**C 错**）。

#### 第四步：风险 × 违约责任 —— 两笔账并行不悖（§611）

**法考铁则**：风险移转给买受人，**不影响**买受人就出卖人的违约（含从给付义务违反）**另行追责**（§611）。即：**货物损失（风险）归买受人 + 违约赔偿 / 补正（责任）追出卖人**，两条线同时成立。

**老王小李例子**（接挖掘机故事·收尾）
- 挖掘机已交付小李、当晚被泥石流冲走 → **风险在小李**（损失自担、货款照付）；
- **同时**，老王迟迟不补开发票 / 合格证 → 小李**仍可单独告老王违约**，要求补开或赔偿。
- 两笔账互不相妨：**冲走的损失算小李的，缺的单证算老王的。**

- **本题**：乙担货物损失风险、付清货款（A）**＋** 乙仍可要甲补交合格证 / 原产地证明或赔偿（B）→ **B 对**；货已毁、风险在乙、标的物已特定化 → 甲**无需补交**货物（**D 错**）。

### 三、命题人最爱的 5 个陷阱

1. **"收了货还能拿'缺单证'当理由解除合同退款"** —— 错！从给付义务瑕疵非根本违约，不能解除（**C 陷阱**）。
2. **"货毁了，所以买受人不用付钱"** —— 错！风险已随交付移转，钱照付（**A**）。
3. **"缺单证 = 没完成交付 = 风险没移转"** —— 错！标的物本身已交付即移转风险，单证是另一条线。
4. **"风险移转了，出卖人就不用补单证 / 不担违约责任"** —— 错！§611 两笔账分开，违约责任照追（**B**）。
5. **"货已毁，出卖人得补交货物"** —— 错！风险在买受人、交付后已特定化，无需补交（**D 陷阱**）。

### 四、真题演练（套用四步模型 → 本题 AB）

1. **第一步**：甲送货至乙指定仓库、乙验收收货 → 标的物已交付 → 风险移转乙 → 山洪损失乙担、付清 20%（**A 对**）。
2. **第二步**：产品合格证 / 原产地证明 = §599 从给付义务（缺了货仍能用）。
3. **第三步**：从给付瑕疵 ≠ 根本违约 → 乙无法定解除权 → **C 错**。
4. **第四步**：§611 风险与违约并行 → 乙付款 ＋ 可追甲补证 / 赔偿（**B 对**）；货毁风险在乙、已特定化 → 甲不补交（**D 错**）。
→ **答案：AB** ✅

## 📐 口诀

> **风险归买家 ≠ 卖家免责，缺证照追（§611）；山洪冲了货，钱照样付清。"**
