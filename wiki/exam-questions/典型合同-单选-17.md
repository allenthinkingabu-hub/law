# C2-单选-17 · 委托开发的成果权属

## 题干

> 甲研究所委托刘某开发软件，未约定技术成果归属。下列哪项**不正确**？

- A. 申请专利的权利属于刘某，但刘某无权获得报酬
- B. 申请专利的权利属于刘某，且刘某有权获得约定的报酬
- C. 若刘某转让专利申请权 → 甲享有同等条件优先受让权
- D. 若刘某取得专利权 → 甲可依法实施该专利

## 我的答案

**A**<!-- confidence: INFERRED -->

## 涉及考点

- [[技术开发合同]] 委托开发成果权属（§859）
- 报酬独立于成果权属

## 考点精解 · 委托开发成果权属三规则

### 是什么 / 易混

**§859**（委托开发的成果权属）：
1. **没约定 / 约定不明** → 申请专利权利属于**研究开发人**（受托人）
2. 研究开发人转让专利申请权 → 委托人**优先以同等条件受让**
3. 研究开发人获得专利权 → 委托人**免费实施**该专利

→ **报酬归属与成果权属是两条独立线**：
- 成果归刘某 ✓
- 但合同约定的**报酬**仍应由甲付（违约 / 已完成工作必付）

本题对照：
- A "属刘某 + 无权报酬" → **错**（报酬独立于权属）
- B "属刘某 + 有权报酬" → 对
- C 转让 → 优先受让权 → 对（§859）
- D 委托人免费实施权 → 对（§859）

### 怎么考 / 坑在哪

- **A 经典陷阱**：以为"既然成果归刘某，刘某就不能要报酬"——**报酬 ≠ 成果权属**
- 报酬是劳务对价，成果权属是知识产权归属——**两条线**

### 怎么答

A（"不正确"项）。成果归研究开发人不影响报酬请求权。
