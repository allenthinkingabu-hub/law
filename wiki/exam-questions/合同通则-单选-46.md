# C1-单选-46 · 离婚协议给儿子过户：真正利他合同，第三人可直接请求

## 题干

> 甲乙系夫妻，离婚协议约定，甲净身出户，登记在甲名下的房屋过户给20岁的儿子丙，并且丙有权直接请求甲过户。后夫妻双方离婚，丙请求甲过户房屋。关于本案，下列说法正确的是？（2025金题-2-1-15）

- A. 即使乙同意，甲亦不得撤销协议
- B. 甲在过户登记前可以单方撤销协议
- C. 丙可以直接请求甲过户
- D. 丙不可以直接请求甲过户

## 我的答案

**C**（明确约定丙可直接请求 = 真正利他合同）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 涉及考点

- [[合同相对性]]
- [[向第三人履行]]（§522② · 真正利他合同 · 本题考点）

## 考点精解 · 真正利他合同（向第三人履行 + 第三人直接请求权）

### 是什么 / 易混

- 离婚协议（甲乙之间）约定"房屋过户给儿子丙"+**"丙有权直接请求甲过户"** → 这是**真正利他合同**（利益第三人条款，§522 II）：第三人丙**取得对债务人甲的直接请求权**（C 对，D 错）。
- **A"即使乙同意也不得撤销"错**：协议是甲乙合意，**经双方（甲乙）协商一致仍可变更**；说"即使乙同意甲也不得撤销"否定了双方合意变更的可能，过于绝对。
- **B"甲可单方撤销"错**：离婚协议生效后，甲**不得单方撤销**（非任意撤销的赠与，且已赋予第三人请求权）。

### 怎么考 / 坑在哪

- 题眼是"**丙有权直接请求**"——这句话直接把它定性为真正利他合同，第三人有直接请求权。
- 区分：没有这句"可直接请求"的，第三人就只是收货人（无独立请求权，参见 [[合同通则-单选-45]]）。

---

## 📐 答题口诀 · 看见"第三人可直接请求" = 真正利他合同

> **"约定里写明'他能自己来要' = 第三人有直接请求权（真正利他）；没写这句 = 只能收货不能告。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"约定向第三人给付 + 第三人有权直接请求"       → 真正利他合同，第三人可直接请求（§522 II）★
"仅约定向第三人交付（没说可请求）"           → 第三人只收货、无请求权
"离婚协议给子女财产 + 可直接请求"            → 第三人（子女）可直接请求
"一方单方撤销 / 即使对方同意也不得撤销"       → 多为干扰（合意可变更，单方不可撤）
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A | ❌ | 甲乙合意仍可变更，"即使乙同意也不得撤"过绝对 |
| B | ❌ | 甲不得单方撤销已生效协议 |
| **C** | ✅ | 明确约定丙可直接请求 = 真正利他合同 |
| D | ❌ | 与 C 相反 |

### 🚗 老王小李故事

> 老王和王婶离婚，协议白纸黑字写："房子过户给 20 岁的儿子小石头，**小石头可以自己直接找老王要过户**。"这最后一句是关键——它把小石头从"旁观者"变成了能**亲自上门讨债**的人（真正利他合同）。所以小石头有权直接请求老王过户。老王想自己反悔单方撕协议？不行；说"哪怕王婶同意也铁板钉钉不能改"？也太绝对——夫妻俩要是再商量一致，还是能改的。

### 🎯 一句话记忆

> **"'第三人可直接请求'这句话 = 真正利他合同 = 他能自己来要。"**

### 填空模板（主观题用）

> 离婚协议约定房屋过户给丙并明确**【丙有权直接请求甲过户】**，构成**【真正利他合同（利益第三人条款）】**，丙取得**【对甲的直接请求权】**（§522 II）。甲不得**【单方撤销】**，但甲乙合意仍可变更。故选 **C**。
