# 物权-多选-01 · 购房人装修侵害邻居——物权保护请求权综合

## 题干

> 叶某将自有房屋卖给沈某，在交房和过户之前，沈某擅自撬门装修，施工导致邻居赵某经常失眠。下列哪些表述是正确的？(2013年卷三第55题)

- A. 赵某有权要求叶某排除妨碍
- B. 赵某有权要求沈某排除妨碍
- C. 赵某请求排除妨碍不受诉讼时效的限制
- D. 赵某可主张精神损害赔偿

## 答案

**ABC**（叶某是所有权人有义务排除妨碍；沈某是直接侵害人；排除妨碍请求权不适用诉讼时效；精神损害赔偿另需满足条件）<!-- confidence: EXTRACTED -->

- 来源：2013年司法考试卷三第55题

## 涉及考点

- 📐 **答题模型** → [[民法-物权-物权请求权模型]] 第三步（认主体·排除妨害可向所有权人+直接侵权人双向）+ 第四步（过时效）+ 第五步（精神损害 §1183 边界）
- [[物权的保护]] §233-238：排除妨碍请求权
- 物权请求权 vs 诉讼时效：§196 排除妨碍请求权**不适用诉讼时效**
- 叶某（所有权人）vs 沈某（侵权行为人）均可被要求排除妨碍

## 考点精解

| 选项           | 分析                                              | 对错       |
| ------------ | ----------------------------------------------- | -------- |
| A（赵某→叶某排除妨碍） | 叶某是所有权人，应控制对房屋的使用，有义务排除妨碍                       | **正确** ✓ |
| B（赵某→沈某排除妨碍） | 沈某是直接实施妨碍行为者，当然可要求其排除                           | **正确** ✓ |
| C（不受时效限制）    | §196/一般原则：排除妨碍请求权属物权请求权，不适用诉讼时效                 | **正确** ✓ |
| D（精神损害赔偿）    | 精神损害赔偿须满足"严重后果"等特定条件，仅"经常失眠"是否满足存疑；且本题无侵犯人格权等情形 | **不选**   |

## 📐 口诀

> **物权请求权：可向所有权人+直接侵权人双向主张；不受诉讼时效；精神赔偿须有严重后果。**
