# C2-多选-39 · 公益捐赠：不得任意撤销 + 情势变更可免履行（§658/§533）

## 题干（金题来源：2022金题-2-1-20）

> 2016年6月6日，汪某与志华中学签订赠与合同，约定汪某每年向志华中学捐赠10万元用于资助贫困学生，直至所有贫困学生毕业。2020年5月，汪某罹患重病，无法工作，为治病花光了所有积蓄，家庭生活陷入了困难，遂向志华中学表示无法继续捐赠。据此，下列选项正确的是？

- A. 汪某有权撤销赠与
- B. 汪某与志华中学之间的赠与合同于2016年6月6日成立
- C. 志华中学可以免除汪某捐赠义务
- D. 汪某可以不再履行捐赠义务

## 我的答案

**BCD**<!-- confidence: INFERRED -->

公益性质赠与不得任意撤销（§658 II）；合同于签订时成立（诺成合同）；债权人可免除债务（§557 II）；情势变更可主张不再履行（§533）。

## 涉及考点

- [[赠与合同]] 任意撤销权的**例外**：公益 / 道德义务 / 公证不得撤销（§658 II）
- 赠与合同成立时间（诺成合同 vs 实践合同）
- 情势变更原则（§533）在赠与合同中的适用
- 债权放弃 / 债务免除（§557 II）

## 考点精解 · [[赠与合同]] 公益捐赠规则

### 是什么 / 易混

**§658 任意撤销权及例外**：

| 类型 | 赠与人能否任意撤销（转移前）| 法条 |
|---|---|---|
| 一般赠与 | **可以**（转移前任意撤销）| §658 I |
| 公益性质赠与（救灾/扶贫/助残等）| **不得**撤销 | §658 II |
| 道德义务性质赠与 | **不得**撤销 | §658 II |
| 经公证的赠与 | **不得**撤销 | §658 II |

本题：资助贫困学生 = **公益性质** → 汪某**不得**任意撤销（A 错误）

**§533 情势变更**：

合同成立后，合同基础条件发生了**当事人在订立合同时无法预见的、不属于商业风险的重大变化** → 当事人可以请求对方变更或解除合同。

汪某罹患重病 + 花光积蓄 = 无法预见的重大情势变更 → D（汪某可不再履行）**正确**

### 逐项解析

**A（汪某有权撤销赠与）→ 错误**
公益性质赠与合同，赠与人不得行使任意撤销权（§658 II）。汪某以"资助贫困学生"为目的的捐赠合同属于公益赠与，哪怕尚未履行，也不得撤销。

**B（赠与合同于2016年6月6日成立）→ 正确**
赠与合同属于**诺成合同**（一方赠与、另一方接受即成立，区别于借款合同的实践合同）。签订合同当日（要约+承诺）即成立，无需交付。

**C（志华中学可以免除汪某捐赠义务）→ 正确**
§557 II：债权可以因债权人免除债务而消灭。志华中学（债权人）主动免除汪某的捐赠义务，合同消灭，属于债权人对权利的处分，合法有效。

**D（汪某可以不再履行捐赠义务）→ 正确**
§533 情势变更：汪某罹患重病、丧失收入来源，属合同成立时无法预见的重大变化（非正常商业风险），汪某有权主张变更或解除赠与合同，从而可以不再履行捐赠义务。

### 怎么考 / 坑在哪

1. **A 是经典陷阱**：看到"病重无钱"就以为赠与人可以"任意撤销"——忘记了§658 II 公益赠与例外！一旦确认公益属性，**任意撤销权出局**，只能走情势变更或要求债权人免除。

2. **B 容易漏选**：赠与合同是诺成合同（§657），签订即成立，不需要等到交付。合同成立 ≠ 转移所有权。

3. **D 的法律依据**：是情势变更（§533）而非撤销权。"不再履行"→ 实质是通过情势变更主张解除合同，区别于"撤销"（§658/§663 特别条款）。

## 📐 答题口诀 · [[赠与合同]] 公益捐赠三步法

**关键词触发**：公益捐赠 / 助贫 / 救灾 / 任意撤销 / 赠与人病重

**🎯 一句话记忆**：
> 公益捐赠不撤销（§658 II），病重可走情势变（§533），学校主动免则消（§557 II）。

**三步判断口诀**：
```
① 问"能不能任意撤销？"
   → 看赠与性质：公益/道德义务/已公证 → 不得撤销
   → 一般赠与 → 可以撤销（转移前）

② 问"能不能不履行？"
   → 检查情势变更要件（§533）：
     a. 合同基础条件发生重大变化
     b. 订立时无法预见
     c. 不是商业风险
     d. → 可请求变更/解除

③ 问"能不能免除义务？"
   → 债权人主动免除（§557 II）→ 可以
   → 合同消灭 → 义务消失
```
