# C2-单选-25 · 转委托规则

## 题干

> 甲委托乙处理一批货物的销售事宜，双方未约定可以转委托。乙在非紧急情况下，未经甲同意擅自将委托事务转委托给丙处理，丙因过失给甲造成损失 3 万元。下列说法正确的是？

- A. 乙与丙之间的转委托合同无效，损失由丙自行承担
- B. 转委托合同有效，乙须对丙的行为向甲承担赔偿责任
- C. 转委托合同有效，甲可直接向丙主张赔偿，乙免除责任
- D. 乙已尽到选任与指示义务，可以减轻或免除赔偿责任

## 我的答案

**B**<!-- confidence: INFERRED -->

## 涉及考点

- [[委托合同]] 受托人亲自处理义务 + 转委托规则（§923）
- 📐 **三段论**：经同意 / 未经同意 / 紧急情况 三种转委托的责任差异

## 考点精解 · 转委托三种情形

### 是什么 / 易混

**§923**（转委托规则）：

| 场景                         | 转委托合同效力 | 受托人乙的责任                 |
| -------------------------- | ------- | ----------------------- |
| 经委托人**同意**后转委托             | 有效      | 仅对**选任与指示**承担责任         |
| **未经同意**擅自转委托（非紧急）         | 有效      | 对第三人丙的**一切行为**向甲**全担责** |
| **紧急情况**自行转委托，且**及时通知**委托人 | 有效      | **不承担**责任               |

> §923 只调整责任范围，**不让转委托合同无效**。

**本题分析**：
- 未约定可转委托 + 未经甲同意 + 非紧急 → 落入第二种情形
- A：转委托合同仍有效，§923 未规定合同无效 → A **错**
- B：乙须对丙的一切行为向甲担责 → B **正确**
- C：甲须向乙主张（乙为主责方），无法跳过乙直接找丙 → C **错**
- D：选任义务减责规则只在"经同意"转委托（§923 第1款）才适用 → D **错**

### 怎么考 / 坑在哪

- **A 大坑**："未经授权 → 合同无效"——§923 管的是责任归属，不是合同效力
- **D 陷阱**：选任义务减责规则仅限**经同意**场景，在未经同意时不存在

### 怎么答

B。未经同意擅自转委托（非紧急）= 转委托合同有效 + 受托人对第三人一切行为全担责（§923）。

## 📐 答题口诀

> **转委托三结局**：经同意→选任指示担；未经同意→全担；紧急及时通知→免担
