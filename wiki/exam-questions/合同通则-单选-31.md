# C1-单选-31 · "假一罚十"的性质与效力

## 题干

> 甲手机专卖店门口立有一块木板，上书"假一罚十"四个醒目大字。乙从该店购买手机，后经鉴定该手机系假冒产品，乙遂要求甲履行"假一罚十"承诺。关于本案，下列哪一选项是正确的？

- A. "假一罚十"过分加重了甲的负担，属于无效的格式条款
- B. "假一罚十"没有被订入到合同之中，故对甲没有约束力
- C. "假一罚十"显失公平，甲有权请求法院予以变更或者撤销
- D. "假一罚十"是甲自愿作出的真实意思表示，应当认定为有效

## 我的答案

**D**（甲自愿作出的真实意思表示，有效）<!-- confidence: INFERRED -->

## 涉及考点

- [[要约]]（向不特定人的要约 / 单方允诺）
- "假一罚十" = 经营者**自我加重责任**的承诺，效力辨析

## 考点精解 · "假一罚十"的定性

### 是什么 / 易混

- "假一罚十"是甲**主动、自愿**向不特定顾客作出的承诺（要约 / 单方允诺性质），乙购买即**接受**，成为合同内容。
- **方向是"自我加重"**，不是"免己责 / 加重对方" —— 所以**不落入** §497 格式条款无效情形。
- **显失公平**针对"一方被趁危 / 缺判断力致失衡"；甲自愿加责，不存在甲被显失公平。

### 怎么考 / 坑在哪

- **A 陷阱**：把它当"无效格式条款" —— 方向反了，格式条款规制**免己责**，这里是**自我加责**。
- **B 陷阱**：醒目立牌 = 向顾客的要约，乙购买即订入合同。
- **C 陷阱**：甲**自愿**加责，无"显失公平"，甲不能撤销自己的承诺。
- → D 有效。

### 怎么答

"假一罚十"是甲自愿向不特定公众作出、自我加重责任的真实意思表示，乙购买即纳入合同；既非"免己责 / 加重对方"的无效格式条款，也不存在甲被"显失公平"，应认定**有效**，甲须履行。故选 **D**。

## 📐 答题口诀 · "假一罚十"：自我加责 = 有效（别套格式条款无效）

> 关键一句话：**格式条款无效规制的是"免自己、坑对方"；"假一罚十"是"加自己"，方向正好相反 → 有效。**

### 🚗 "假一罚十" 故事

> 甲手机店门口立块大牌子：**"假一罚十"**。这是甲**自己**向所有进店顾客拍的胸脯（像**悬赏**：你买到假的，我赔十倍）。
> 乙买了手机，一鉴定 —— 假货！乙拿牌子说事："赔十倍！"
> 甲想反悔："这条款无效 / 显失公平！" —— **不行**，**你自己立的牌子，自愿加重自己责任，赖不掉**。

### 🔑 "方向"决定效力

```
格式条款无效（§497）规制的方向：
    提供方【免除自己责任】/【加重对方】/【限制对方主要权利】 → 无效

"假一罚十"的方向：
    经营者【加重自己责任】、给消费者【更多保障】 → 有效 ✅

→ 方向相反！不能套"格式条款无效"否定它
```

### 📋 4 选项解析

| 选项 | 判断 | 错在哪 |
|---|---|---|
| A 无效格式条款 | ❌ | 方向反了：自我加责 ≠ 免己责 / 加重对方 |
| B 未订入 | ❌ | 醒目立牌 = 要约，乙购买即订入 |
| C 显失公平可撤销 | ❌ | 甲自愿加责，无"被显失公平"，不能撤销自己承诺 |
| **D 真实意思有效** | ✅ | 自愿真实意思 ＋ 不违法 → 有效 |

→ 选 **D** ✅

### ⚠️ 核心陷阱：A 选项"无效格式条款"

格式条款无效（§497）是**保护弱势相对人**、限制提供方"免己责 / 坑对方"。
"假一罚十"恰恰是经营者**给消费者更多保护**、**加重自己** —— 用无效规则去打它，**方向完全搞反**。

### 🎯 一句话记忆

> **"假一罚十 = 经营者自我加责的真实意思 → 有效（像惩罚性承诺 / 悬赏）"**
> **"格式条款无效打的是'免己责'，自我加责打不着 → A 陷阱"**

### 填空模板（主观题用）

> "假一罚十"系甲**自愿**向不特定顾客作出、**自我加重责任**的真实意思表示，乙购买即接受并订入合同。其方向为加重提供方责任，不属 §497 格式条款无效情形；甲自愿加责亦无"显失公平"可言。该承诺合法有效，甲应"假一罚十"（D）。
