# 刑法-总论-犯罪论-单选-16 · 紧急避险与正当防卫的区分及职务限制

## 题干

> 来源：依据《刑法》第20条、第21条（含第21条第3款职务限制）命制的**仿真题**（题干为本库命制，非历年真题；§20/§21已联网核验 CONFIRMED，spp.gov.cn）。

关于正当防卫与紧急避险，下列说法**错误**的是？

- A. 正当防卫针对不法侵害人本人，紧急避险针对无辜第三人的法益
- B. 紧急避险要求"不得已"（补充性），正当防卫不要求"不得已"，可主动反击
- C. 消防员在火场为避免自己被烧伤，破门躲入他人房屋，可主张紧急避险免责
- D. 甲被疯狗追咬，情急下推倒路人乙、夺乙自行车逃离致乙受伤，甲的行为可能成立紧急避险

## 我的答案

**C**<!-- confidence: EXTRACTED -->

本题选"错误"项，正确答案为 **C**。

《刑法》第21条第3款：第1款关于**避免本人危险**的规定，**不适用于职务上、业务上负有特定责任的人**。即消防员、警察、船长等负有特定职责者，**不得为避免本人危险**而紧急避险（但为他人/公共利益避险不受此限）。

- **A 正确**：危险来源与损害对象的核心区别——防卫打侵害人本人，避险损害无辜第三人。
- **B 正确**：避险以"不得已"为要件，防卫不要求"不得已"。
- **C 错误**（应选）：消防员属"**职务上负有特定责任的人**"，为避免**本人**被烧伤而避险，依**§21Ⅲ不得主张紧急避险免责**——其职责本就要求其承受相应职业风险。
- **D 正确**：疯狗追咬是"危险"（非人的不法侵害），甲损害无辜第三人乙的法益、情急不得已逃生——符合紧急避险的危险来源与对象特征，可能成立紧急避险（再审查不得已与限度）。

**陷阱**：用"消防员也是人、也怕烧伤"诱导适用紧急避险——§21Ⅲ 明确**职务上负特定责任的人不得为避免本人危险避险**。

## 考点精解 · 防卫 vs 避险 + 职务限制

| 维度 | 正当防卫§20 | 紧急避险§21 |
|---|---|---|
| 危险来源 | 人的不法侵害 | 自然/动物/他人无辜法益等危险 |
| 损害对象 | 不法侵害人本人 | 无辜第三人 |
| 是否"不得已" | 不要求 | 要求（补充性）|
| 限度 | 未明显超限+重大损害 | 所保护≥所损害 |
| 特殊限制 | 无 | **职务/业务负特定责任者不得避己险§21Ⅲ**|

```
危险来自"人的不法侵害"？
  ├─ 是 ─► 打侵害人本人 → 正当防卫
  └─ 否（自然/动物/第三人法益）─► 不得已损害第三人 → 紧急避险
                                       │
                              避免"本人"危险 + 职务上负特定责任？
                                       └─ 是 → §21Ⅲ 不得避险免责（本题C消防员）
```

> 注意：动物侵袭一般属"危险"走避险；但若他人**故意驱使**动物侵害，则属"不法侵害"，可对驱使人正当防卫。
