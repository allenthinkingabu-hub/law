# C1-单选-35 · 招标投标：中标通知到达即合同成立，拒签是违约

## 题干

> 甲公司拟为其员工宿舍楼聘请物业服务机构，通过某招标公司公开发出投标邀请。2024年7月5日，乙物业公司向招标公司发出《投标文件》，7月15日，招标公司向乙公司发出中标通知书，并于3日后到达。后甲公司决定自行管理该宿舍楼，遂于7月22日通知乙公司不与其签订合同。对此，下列说法正确的是？（2024金题-2-1-10）

- A. 甲公司与乙公司之间成立预约合同
- B. 乙公司可请求甲公司承担违约损害赔偿责任
- C. 乙公司可请求甲公司承担缔约过失责任
- D. 甲公司与乙公司之间的合同未成立

## 我的答案

**B**（合同已成立，甲拒签 = 违约损害赔偿）<!-- confidence: EXTRACTED -->（官方参考答案：B）

## 考点精解 · 招投标三段式

### 是什么 / 易混

招投标对应要约/承诺三段：

| 招投标动作 | 合同法定性 | 法条 |
|---|---|---|
| 发出投标邀请（招标公告）| **要约邀请** | §473 |
| 投标人提交《投标文件》| **要约** | §472 |
| 发出**中标通知书** | **承诺** | §479 |

- 中标通知书**到达**投标人 → **承诺生效 → 合同成立**（§484、通则解释§4）。
- 本案 7/18 中标通知到达，合同**已成立**；甲 7/22 拒签 = **不履行已成立合同的义务 = 违约**。

### 怎么考 / 坑在哪

- **A 预约**错：招投标中标通知到达即成立**本约**，不是"将来再订合同"的预约。
- **C 缔约过失**错：缔约过失只在合同**未成立/无效/被撤销**时适用；本案合同已成立，只能走**违约**。这是缔约过失 vs 违约的经典分水岭。
- **D 未成立**错：承诺已到达。

### 怎么答

中标通知书到达 = 承诺生效 = 合同成立 → 甲拒签是违约 → 选 **B**。

## 📐 答题口诀 · 缔约过失 vs 违约：以"合同是否成立"切线

> **"合同成立前耍赖 = 缔约过失；成立后耍赖 = 违约。中标通知一到达，门槛已过，只能算违约。"**

### 关键词触发表

```
看到题干关键词                           → 定性
"招标公告 / 投标邀请"                     → 要约邀请
"投标文件 / 报价单"                       → 要约
"中标通知书到达 / 承诺到达"               → 合同成立（本约）★
合同成立后拒不签约 / 不履行                → 违约（不是缔约过失）
合同未成立就耍赖                          → 缔约过失
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 预约 | ❌ | 中标通知到达成立的是**本约**，非预约 |
| **B 违约赔偿** | ✅ | 合同已成立，拒签 = 违约 |
| C 缔约过失 | ❌ | 缔约过失仅限合同**未成立/无效/撤销**，本案已成立 |
| D 未成立 | ❌ | 承诺（中标通知）已到达 |

### 🚗 老王小李故事

> 老王挂出"招物业"的牌子（要约邀请），小李递了份报价（要约），老王回了张"就你了"的中标通知书并送到小李手上（承诺到达，合同成立！）。这时候老王突然说"我不签了"——晚啦，门已经关上，合同早成立了，老王这叫**违约**，得赔小李的损失，而不是轻飘飘的"缔约过失"。

### 🎯 一句话记忆

> **"中标通知到 = 合同成；成立后反悔 = 违约，不是缔约过失。"**

### 填空模板（主观题用）

> 招标公告为**【要约邀请】**，投标文件为**【要约】**，中标通知书为**【承诺】**，其**【到达乙公司】**时合同**【成立并生效】**。甲公司事后拒签，系不履行已成立合同义务，构成**【违约】**，应承担违约损害赔偿（§577）。故选 **B**。
