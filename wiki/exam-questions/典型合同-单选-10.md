# C2-单选-10 · 非要式合同识别

## 题干

> 下列合同中，属于**非要式合同**的是？

- A. 融资租赁合同
- B. 建设工程合同
- C. 行纪合同
- D. 技术开发合同

## 我的答案

**C**<!-- confidence: INFERRED -->

## 考点精解 · 民法典中要式合同清单

### 是什么 / 易混

**要式合同**：法律要求必须用**特定形式**（多数为书面）才能成立 / 生效。

> ⚠️ **2026-06-14 联网核实订正**：技术开发 §849/§853 → **§851**；技术转让/许可 §852 → **§863**；融资租赁 §736 II → **§736**。完整清单 + 易混见 [[要式合同]]。

| 合同                       | 是否要式     | 法条                    |
| ------------------------ | -------- | --------------------- |
| [[融资租赁合同]]               | ✅ 书面     | §736                  |
| [[建设工程合同]]               | ✅ 书面     | §789                  |
| [[技术开发合同]]               | ✅ 书面     | §851                  |
| [[技术转让合同]] / [[技术许可合同]]  | ✅ 书面     | §863                  |
| [[保证合同]]                 | ✅ 书面     | §685（条文"可以是书面"，按要式记）  |
| [[租赁合同]]（≥6 个月）          | ✅ 书面     | §707（否则视为不定期租赁）       |
| [[抵押合同]] / [[质押合同]]      | ✅ 书面     | §400 / §427（物权编）      |
| [[物业服务合同]]               | ✅ 书面     | §938（**非 §937**）      |
| [[借款合同]]（金融机构）           | ✅ 书面     | §668（自然人间约定可除外）       |
| [[行纪合同]]                 | ❌ 非要式    | §951（全章无书面）           |
| 普通买卖 / 委托 / 中介 / 承揽 / 保管 | ❌ 非要式    | 形式自由                  |
| 定金合同 → [[民法-合同-定金模型]]    | ❌（民法典已改） | §586 仅实践合同；《担保法》时代才要式 |

### 怎么考 / 坑在哪

- **要式四大金刚**：建设工程 / 融资租赁 / 技术 / 保证 → 必书面
- **租赁 > 6 个月**也须书面 → 未书面 = 不定期租赁（§707）
- **行纪 / 委托 / 中介**都是**非要式**

### 怎么答

C。行纪合同是**非要式**合同。
