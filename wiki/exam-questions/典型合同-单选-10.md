# C2-单选-10 · 非要式合同识别

## 题干

> 下列合同中，属于**非要式合同**的是？

- A. 融资租赁合同
- B. 建设工程合同
- C. 行纪合同
- D. 技术开发合同

## 我的答案

**C**<!-- confidence: INFERRED -->

## 涉及考点

- 要式合同 vs **非要式**合同
- 各典型合同的形式要求

## 考点精解 · 民法典中要式合同清单

### 是什么 / 易混

**要式合同**：法律要求必须用**特定形式**（多数为书面）才能成立 / 生效。

| 合同 | 是否要式 | 法条 |
|---|---|---|
| [[融资租赁合同]] | ✅ 书面 | §736 II |
| [[建设工程合同]] | ✅ 书面 | §789 |
| [[行纪合同]] | ❌ 不要求 | §951（无要式条款） |
| [[技术开发合同]] | ✅ 书面 | §849、§853 |
| [[技术转让合同]] / [[技术许可合同]] | ✅ 书面 | §852 |
| [[保证合同]] | ✅ 书面 | §685 |
| [[租赁合同]]（>6 个月） | ✅ 书面 | §707 |
| [[借款合同]]（自然人间） | ❌ | 形式自由 |
| 普通买卖 / 委托 / 保管 | ❌ | 形式自由 |

### 怎么考 / 坑在哪

- **要式四大金刚**：建设工程 / 融资租赁 / 技术 / 保证 → 必书面
- **租赁 > 6 个月**也须书面 → 未书面 = 不定期租赁（§707）
- **行纪 / 委托 / 中介**都是**非要式**

### 怎么答

C。行纪合同是**非要式**合同。
