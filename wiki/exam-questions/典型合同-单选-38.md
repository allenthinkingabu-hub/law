# C2-单选-38 · 保理合同性质与当事人：仅债权人与保理人两方

## 题干

> 来源：233 网校 2022 年法考卷二模拟题

关于保理合同法律关系的说法，不正确的是：

- A. 保理合同法律关系的本质是债权让与法律关系
- B. 应收账款债务人接到应收账款转让通知后，应收账款债权人和债务人无正当理由协商变更或者终止基础交易合同，对保理人产生不利影响的，对保理人不发生效力
- C. 保理合同应当采用书面形式
- D. 保理法律关系有三方主体

## 我的答案

**D**<!-- confidence: EXTRACTED -->

D 错误：保理**合同**当事人只有**两方**——应收账款债权人和保理人（§761）。债务人不是保理合同的当事人，只是保理业务结构中的第三方义务人。

- 📐 **答题模型** → [[民法-合同-保理模型]] 第一步（定性：两方 / 债权让与 / 书面提倡性）
- [[保理合同]] 定义与当事人：应收账款债权人 + 保理人（§761）
- [[保理合同]] 书面形式：提倡性规定（§762 第2款）

## 考点精解 · 保理合同基本框架

### 是什么 / 易混

**§761 定义**：保理合同是应收账款**债权人**（下称债权人）将现有的或者将有的应收账款转让给**保理人**，保理人提供资金融通、应收账款管理或者催收、应收账款债务人付款担保等服务的合同。

| 核心规则 | 内容 | 法条 |
|---|---|---|
| **当事人** | 两方：债权人（应收账款出让人） + 保理人（银行/金融机构） | §761 |
| **债务人地位** | 不是保理合同当事人，是基础交易合同相对方 | §761 反面解释 |
| **合同形式** | 应当书面形式（提倡性，非效力强制性规定） | §762II |
| **准用规则** | 本章未规定的准用债权转让（第六章）| §769 |
| **法律本质** | 应收账款转让 = 债权让与；具有担保和融资双重功能 | §769 + §761 |

### 三方结构 vs 两方合同（考试陷阱核心）

保理业务在商业结构上涉及三方：

```
债权人（供应商）←→ 债务人（采购商）【基础交易合同（买卖/服务）】
        ↓ 应收账款转让
  债权人 ←→ 保理人【保理合同（两方）】
              ↓ 收款通知
        保理人 → 债务人【转让通知（单方行为）】
```

**关键区分**：
- **保理合同** = 两方（债权人+保理人）
- **保理业务结构** = 三方（债权人+债务人+保理人）
- 债务人对保理合同的效力有影响（§763/§765），但**不是当事人**

### 选项逐析

**A（本质是债权让与）** → **正确**
§769 规定，保理章无规定的适用债权转让规定（第六章），保理合同的核心是应收账款的转让，法律本质即债权让与。

**B（基础合同变更不利保理人→对保理人不发生效力）** → **正确**
§765：债务人收到转让通知后，债权人与债务人**无正当理由**协商变更或终止基础交易合同，对保理人产生不利影响的，对保理人**不发生效力**。这保护了保理人对已转让应收账款的权益。

**C（应当采用书面形式）** → **正确**
§762 第2款：保理合同应当采用书面形式。注意：这是**提倡性规定**（"应当"≠效力强制），不符合书面形式不必然导致合同无效——这是另一个常见陷阱（见单选-39外延说明）。

**D（三方主体）** → **错误（本题答案）**
保理**合同**当事人是债权人和保理人**两方**，§761 原文清晰界定，无"三方主体"之说。

### 怎么考 / 坑在哪

- **三方结构幻觉**：商业现实确实有三方，但保理**合同**只有两方——债务人只是收到通知后负有付款义务，不是合同当事人
- **书面形式陷阱**：§762 的书面形式是提倡性规定，≠ 违反则无效（区别于§788 建设工程合同必须书面）
- **债务人的抗辩权限**：债务人虽非当事人，但有权提出基础交易抗辩（§763、§765 例外除外）
