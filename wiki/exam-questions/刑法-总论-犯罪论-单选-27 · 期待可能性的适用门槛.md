# 刑法-总论-犯罪论-单选-27 · 期待可能性的适用门槛

## 题干

> 来源：依据期待可能性学理通说（责任阻却事由，我国刑法无独立专条）命制的**仿真题**（题干为本库命制，非历年真题；教义学通说·张明楷/柏浪涛口径）。

关于期待可能性，下列哪一选项是正确的？

- A. 行为人只要主观上不愿犯罪，即欠缺期待可能性，可阻却责任
- B. 甲为牟取暴利长期走私，辩称"不走私就赚不到钱、养不起家"，欠缺期待可能性
- C. 海难中乙抢夺仅能承载一人的浮木独自求生、致争夺者溺亡，在当时别无生路的极端情境下，可考虑因欠缺期待可能性而阻却或减轻责任
- D. 期待可能性是我国刑法分则明文规定的独立出罪事由

## 我的答案

**C**<!-- confidence: EXTRACTED -->

正解为 C。期待可能性是**责任阻却事由**：判断标准是行为当时**客观情境**下行为人有无实施合法行为的选择余地，而非其主观意愿；门槛极高，须达到"客观上别无合法选择"的极端程度才可能阻却或减轻责任。

逐项：

- A 错：期待可能性看的是**当时客观情境**有无实施合法行为的余地，而非"主观上不愿犯罪"。若只要主观不愿就免责，人人皆可借口脱罪。
- B 错："不走私就赚不到钱、养不起家"远未达到"别无选择"的程度。正常牟利型犯罪存在充分的合法替代选择（合法经营、另谋生计），不欠缺期待可能性。
- C 对：海难中独木仅能承载一人、**客观上确无其他合法求生途径**的生死攸关极端情境，才可能因欠缺期待可能性而阻却或减轻责任，正体现该制度门槛极高、仅适用于极端例外。
- D 错：期待可能性是**学理上的责任阻却事由**，我国刑法并无独立专条明文规定，并非分则明文的出罪事由。

故选 C。

## 考点精解 · 期待可能性的高门槛

期待可能性，指在行为当时的具体情境下，**能够期待行为人作出合法行为的可能性**。无此可能性（"实在做不到守法"）才阻却或减轻责任。考试中它**绝大多数是干扰项**，因为门槛极高。

| 主张 | 是否欠缺期待可能性 | 评析 |
|---|---|---|
| "我主观上不愿犯罪" | ❌ 否 | 看客观情境，不看主观意愿 |
| "为赚钱养家而走私/盗窃" | ❌ 否 | 有合法替代选择，未达别无选择 |
| 生死攸关、客观上别无合法生路 | ✅ 可考虑 | 极端例外（如海难独木求生） |
| "刑法明文规定的出罪事由" | —— | 错：我国无独立专条，属学理事由 |

```
判断期待可能性 → 看「行为当时的客观情境」
        │
        ▼
 客观上还有没有实施合法行为的余地？
 ┌──────────────┬───────────────┐
 有（绝大多数）     完全没有（极端例外）
 → 仍有期待可能性   → 欠缺期待可能性
   不免责           可阻却/减轻责任
```

记忆要点：①标准是**客观选择余地**，不是主观不愿；②**经济压力、为家庭、不犯罪赚不到钱**一律不构成欠缺；③须达到"**客观上别无合法选择**"的极端程度（生死攸关）；④我国刑法**无独立专条**，是学理责任阻却事由。
