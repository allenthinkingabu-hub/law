# C1-单选-49 · 地震致成本暴涨、协商被拒：情势变更可变更

## 题干

> 甲公司和乙公司签订了一份长期的供货合同。后因地震，原材料成本和运输费用均上涨，若继续履行合同甲公司将遭受重大损失，甲公司与乙公司协商变更合同被拒。关于本案，下列选项正确的是？（2022金题-2-1-16）

- A. 合同因重大误解可撤销
- B. 合同因不可抗力可撤销
- C. 合同因显失公平可撤销
- D. 合同因情势变更可变更

## 我的答案

**D**（客观情况重大变化、继续履行显失公平 = 情势变更）<!-- confidence: EXTRACTED -->（官方参考答案：D）

## 考点精解 · [[情势变更]]（§533 + 通则解释§32）

### 是什么 / 易混

- **情势变更（§533）**：合同成立后，**基础条件发生当事人订立时无法预见的、不属于商业风险的重大变化**，继续履行对一方明显不公平 → 可请求**重新协商**；协商不成可请求法院/仲裁**变更或解除**。
- 本案地震致成本/运费暴涨、继续履行甲重大损失、协商被拒 → 完美命中情势变更，可请求**变更**（D 对）。

### 怎么考 / 坑在哪

辨析四个"可撤销/变更"事由：

| 选项         | 错在哪                                                      |
| ---------- | -------------------------------------------------------- |
| A 重大误解     | 是订立时对合同性质/标的的**认识错误**，本题无误解                              |
| B 不可抗力     | 地震虽是不可抗力，但其法律后果是**免责/解除**，"因不可抗力**可撤销**"表述错误（不可抗力不是撤销事由） |
| C 显失公平     | 是**订立时**就因乘人之危/缺乏判断致失衡；本题失衡是**成立后**情况变化造成                |
| **D 情势变更** | ✅ 成立后客观巨变 + 非商业风险 + 继续履行显失公平                             |

### 怎么答

"合同成立后、客观情况重大变化、继续履行不公平" = 情势变更 → 选 **D**。

---

## 📐 答题口诀 · 情势变更 vs 显失公平 vs 不可抗力：看"何时失衡 + 什么后果"

> **"订立时就坑你 = 显失公平（撤销）；成立后天变了 = 情势变更（变更/解除）；天灾免责或解除 = 不可抗力（不是撤销）。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"合同成立后 + 地震/疫情/政策/价格暴涨"        → 情势变更（§533）★
"订立时一方乘人之危/缺判断致显失衡"           → 显失公平（可撤销）
"地震/台风致不能履行 → 免责/解除"             → 不可抗力（非撤销事由）
"协商不成，请求法院变更或解除"               → 情势变更的程序特征
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 重大误解 | ❌ | 无认识错误 |
| B 不可抗力可撤销 | ❌ | 不可抗力后果是免责/解除，非撤销 |
| C 显失公平 | ❌ | 失衡发生在成立后，非订立时 |
| **D 情势变更** | ✅ | 成立后客观巨变 + 继续履行显失公平 |

### 🚗 老王小李故事

> 老王跟小李签了长期供货合同。签完之后突发地震，原料和运费蹭蹭涨，老王再按老价供货要亏惨。老王找小李商量改价，小李不松口。这属于啥？——**情势变更**：合同签完后冒出来谁也没料到的大变故（不是普通的市场波动/商业风险），继续履行对老王明显不公。老王可以请法院**变更或解除**。注意别选"显失公平"（那是签的时候就坑人），也别说"不可抗力可撤销"（不可抗力是免责/解除，不是撤销）。

### 🎯 一句话记忆

> **"成立后天塌了、继续履行太亏 = 情势变更 → 协商不成请法院变更/解除。"**
