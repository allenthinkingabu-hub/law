# C2-单选-09 · 擅自转租的法律关系

## 题干

> 甲将房屋租给乙，乙擅自转租给丙。丙练飞镖损坏墙面。下列**不正确**的是？

- A. 甲有权要求解除与乙的租赁合同
- B. 甲有权要求乙赔偿墙面损坏造成的损失
- C. 甲有权要求丙搬出房屋
- D. 甲有权要求丙支付租金

## 我的答案

**D**<!-- confidence: INFERRED -->

## 涉及考点

- [[租赁合同]] 擅自转租（§716）
- 合同相对性与次承租人责任
- 📐 **答题模型** → [[民法-合同-转租模型]]（转租三方相对性 · 万能四步；本题 D 即"向次承租人要租金"的相对性命门）

## 考点精解 · 擅自转租的"两条不动"

### 是什么 / 易混

**§716**（擅自转租）：承租人**未经出租人同意**转租 → 出租人**可解除合同**。承租人对**次承租人造成的损害**对出租人**仍负责任**。

| 法律关系 | 是否存在 |
|---|---|
| 出租人甲 ↔ 承租人乙 | ✅ 原租赁合同（可解除） |
| 出租人甲 ↔ 次承租人丙 | ❌ **无合同关系**（合同相对性） |
| 承租人乙 ↔ 次承租人丙 | ✅ 次租赁合同 |

→ 甲对丙**无合同请求权**（包括租金），但解除合同后丙占有失去基础 → 甲可基于**所有权**要求腾退。

本题对照：
- A 解除甲乙合同 → §716 → 对
- B 乙对丙的损害对甲负责 → §716 → 对
- C 解除后丙占有无据 → 物上请求权要腾退 → 对
- D 甲要丙支付租金 → **错**（甲与丙无合同关系，租金应是乙向丙收）

### 怎么考 / 坑在哪

- **D 经典陷阱**：以为"反正都在用房 → 谁住谁付租"——错，**合同相对性**严格
- 注意"租金请求权"和"占用费请求权"的区别：占用费基于所有权可向丙主张

### 怎么答

D（"不正确"项）。合同相对性 → 甲无权要丙付**租金**。
