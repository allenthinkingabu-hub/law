# C1-多选-07 · 选择之债的选择权

## 题干

> 甲对乙说：考上公务员就赠送一套住房或一辆宝马。乙考取后下列哪些选项正确？

- A. 该债属于选择之债
- B. 当事人未约定的，甲享有选择权
- C. 甲经催告不行使选择权 → 乙享有选择权
- D. 甲的轿车意外灭失 → 甲只能赠与住房

## 我的答案

**ABCD**<!-- confidence: INFERRED -->

## 涉及考点

- [[选择之债]] 三规则（§515-§517）
- 选择权归属 + 转移 + 标的物毁损减为单纯之债

## 考点精解 · 选择之债 3 规则

### 是什么 / 易混

**[[选择之债]]**（§515-§517）：标的有数项，履行时仅交付其一即清偿。

| 规则 | 法条 | 内容 |
|---|---|---|
| ① 选择权归属 | §515 | 未约定 → **债务人**享有 |
| ② 选择权转移 | §515 II | 经催告仍不行使 → 转移给对方 |
| ③ 减为单纯之债 | §517 | 标的物之一**不可归责**毁损 → 选择权指向其余 |

本题对照：
- A 选择之债（住房 / 宝马二选一）→ 对
- B 甲（赠与人 = 债务人）享有选择权 → 对（§515）
- C 甲经催告不选 → 乙享有 → 对（§515 II）
- D 宝马**意外**灭失（不可归责）→ 选择权指向住房 → 对（§517）

### 怎么考 / 坑在哪

- **D 易错**：很多人以为债务人随意，但 §517 限定了"**不可归责**"才减为单纯之债
- 如果是债务人故意 / 过失毁损宝马 → 选择权仍可指向宝马（赔损害）

### 怎么答

ABCD。选择之债 3 大规则全部命中。

> 这一题是 **Q04 + Q07 配对题的第二题**:
> - Q04 (单选) 考 "**识别**" — 这是不是选择之债?
> - **Q07 (多选) 考 "3 规则全部命中"** — 选择权 / 转移 / 毁损

### 4 选项 vs §515-§517 对应表

| 选项 | 对应规则 | 法条 |
|---|---|---|
| **A** 选择之债 | **识别**(同 Q04)| §515 |
| **B** 甲享有选择权 | 规则 ① **选择权归属** | §515 I |
| **C** 催告不行使 → 转移 | 规则 ② **选择权转移** | §515 II |
| **D** 宝马意外灭失 → 只赠住房 | 规则 ③ **减为单纯之债** | §517 |

→ 4 个选项 = §515-§517 的**完整规则覆盖** → 选 **ABCD** ✅

### 🚗 老王送侄子 4 阶段剧

> 老王对侄子小李说:"**考上公务员**,我送你**一套住房(500 万) 或 一辆宝马(80 万)**!"
> 一年后小李考上 → 条件成就(§158)→ 进入选择之债阶段。

#### 阶段 ① · 选项 A:识别为选择之债

测试:
- 住房 vs 宝马 → **完全不同类**(不是种类之债)
- 都是**特定物**(不是种类之债)
- 几个**特定物**中选 1 → **选择之债**(§515)
- 主体一对一(不是连带之债)

→ **A 对** ✅

#### 阶段 ② · 选项 B:选择权默认归债务人

法律规定 §515 I:
- 没约定 → **债务人**(老王)选

**为什么默认归债务人?**
- 老王是履行方(送东西)
- 让他选 → 可以挑相对便宜的(宝马 80 万 vs 住房 500 万)
- 避免债权人"挑肥拣瘦"

→ **B 对** ✅
→ 老王第一反应:"我选宝马,便宜!"

#### 阶段 ③ · 选项 C:选择权转移 — 经催告

故事推进:
- 老王迟迟不选(犹豫 / 拖延 / 想等房价跌)
- 小李 6/1 书面催告:"30 天内必须选!"
- 7/2 老王仍未选

法律规定 §515 II:
- 享有方**怠于行使**
- 对方**催告** + 合理期限不行使
- → **转移给对方**

→ **C 对** ✅
→ 小李毫不犹豫选**住房**(500 万)→ 老王傻眼!

⚠️ **关键**:不是自动转移,必须**催告**!

#### 阶段 ④ · 选项 D:减为单纯之债 — "意外"灭失

> 选择前(假设老王还在犹豫),**宝马被雷击烧毁**。

题干关键词:**"意外灭失"** = **不可归责**

法律规定 §517 a:
- 不可归责毁损 → 选择权**指向其余**(住房)
- → **自动减为单纯之债**(必须送住房)

→ **D 对** ✅

### ⚠️ 选项 D 的深陷阱:§517 三种情形

D 选项写的是 **"意外灭失"** ——这是"**不可归责**"。如果题目改成其他情形,答案完全不同!

| 情形 | 关键词 | 选择权命运 | 实际效果 |
|---|---|---|---|
| **a 不可归责**(本题 D)| **"意外" / "雷击" / "不可抗力"** | 指向剩余物 | **减为单纯之债** ⭐ |
| **b 归责于债务人** | **"老王故意 / 过失烧"** | 仍可指向毁损物 | **转损害赔偿**(80 万)|
| **c 归责于债权人** | **"小李不小心烧"** | 未失,可选剩余物 | 老王选住房继续 |

→ **出题人常常故意改"意外"为"故意 / 过失"** 来测试你是否真懂 §517!

### 🪤 隐藏考点:附生效条件赠与(同 Q04)

注意题干:"**考上公务员就**赠送..."

→ 这是 **§158 附生效条件的赠与合同**!

```
9/1 双方约定 → 赠与合同**成立**(§483)
        ↓
        (条件未成就)
        ↓
    合同已成立但**未生效** ❌
        ↓
1 年后小李考上 → 条件**成就**(§158)
        ↓
    合同**生效** ✅ → 进入选择之债阶段
```

→ Q07 完整考点 = **赠与合同 + 附生效条件 + 选择之债 3 规则**(四合一!)

### 📐 答题口诀 4 步走

```
Step 1 (识别):
  几个特定物中选 1 → 选择之债(§515)

Step 2 (选择权归属):
  没约定 → 默认债务人选(§515 I)

Step 3 (转移):
  经催告 + 合理期限不选 → 转移给对方(§515 II)

Step 4 (毁损):
  - 不可归责("意外") → 减为单纯之债(§517 a)
  - 归责债务人 → 仍可选 + 损害赔偿(§517 b)
  - 归责债权人 → 选择权未失,可选剩余(§517 c)
```

> **"选择之债 3 规则:默认债务人选 / 催告不选转债权人 / 不可归责减单纯"**
> **"§517 关键看'谁的错':雷击减单纯 / 自毁转赔偿 / 对方毁不影响"**
> **"D 选项'意外'= 不可归责 → 减为单纯之债 → 必须送剩余物"**

### 填空模板(主观题用)

> 本案中老王、小李之间的赠与合同附**【生效条件】**(§158),小李考上公务员后条件成就,合同生效。
>
> 赠与标的为"**【住房或宝马】**"——两个特定标的物择一履行,构成 **[[选择之债]]**(§515)。
>
> ① 选择权默认归**【债务人老王】**(§515 I);
> ② 若老王怠于行使,经小李**【催告】+合理期限不行使**,选择权**转移给小李**(§515 II);
> ③ 宝马**【意外/不可归责】**灭失 → 选择权**指向住房** → **减为单纯之债**(§517)。
>
> 故 ABCD 均对。
