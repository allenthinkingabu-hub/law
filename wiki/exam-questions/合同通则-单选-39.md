# C1-单选-39 · 谁向谁要约？"再考虑一下"不是承诺

## 题干

> 李某想将自己的汽油车更换为新能源车辆，欲以8万元的价格出售其汽油车，邻座的张某听见后，表示愿意购买此车。但李某与张某向来不睦，便对张某说次日再考虑一下。第二日，张某又来问李某是否愿意出售车辆，李某拒绝。关于本案，下列选项正确的是？（2023金题-2-1-10）

- A. 李某应当承担缔约过失责任
- B. 李某对张某构成承诺
- C. 张某对李某构成要约
- D. 李某对张某构成要约

## 我的答案

**C**（张某"愿意购买"=向李某发出要约）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 考点精解 · 要约/邀请/承诺的角色定位

### 是什么 / 易混

还原对话角色：

| 主体行为 | 定性 | 理由 |
|---|---|---|
| 李某"欲以 8 万出售"被邻座听见 | **要约邀请**（或意思表露）| 李某随后说"再考虑"，表明**不愿受拘束** |
| 张某"表示愿意购买此车" | **要约**（C 对）| 内容具体、有受约束意图，向特定人李某发出 |
| 李某"次日再考虑一下" | **未承诺** | 没有同意，只是搁置 |
| 次日李某"拒绝" | 拒绝要约 | 合同不成立 |

### 怎么考 / 坑在哪

- 判断"谁的话是要约"，关键看**说话人是否愿意一经对方同意即受拘束**。李某说"再考虑"=不愿受拘束 → 他的话只是**要约邀请**（D 错）。
- **B"李某构成承诺"错**：李某根本没同意。
- **A"缔约过失"错**：李某有缔约自由，正当拒绝磋商不构成缔约过失（无恶意、无诚信违背）。

### 怎么答

张某的"愿意购买"是要约，李某未承诺并最终拒绝，合同不成立 → 选 **C**。

## 📐 答题口诀 · 要约 vs 邀请：看"愿不愿一拍即合就受拘束"

> **"我说'考虑考虑' = 不想被绑 = 要约邀请；你说'我要买' = 想被绑 = 要约。"**

### 关键词触发表

```
看到题干关键词                          → 定性
"我再考虑 / 容我想想 / 看情况"           → 不愿受拘束 → 要约邀请
"我愿意买 / 我要了 / 就这个价我买"        → 愿受拘束、内容确定 → 要约
对方说"愿意"后我方"再想想"               → 我方未承诺
正当拒绝磋商（无恶意）                    → 不构成缔约过失
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 缔约过失 | ❌ | 正当行使缔约自由，无恶意 |
| B 李某承诺 | ❌ | 李某"再考虑"非同意 |
| **C 张某要约** | ✅ | "愿意购买"内容确定 + 受拘束意图 |
| D 李某要约 | ❌ | 李某"再考虑"=要约邀请，不愿受拘束 |

### 🚗 老王小李故事

> 老王在车里嘟囔"这破车 8 万卖了算了"，邻座小李一听"我买！"。老王跟小李素来不对付，慢悠悠来一句"我再想想吧"。第二天小李又来问，老王说"不卖"。谁向谁发的要约？是**小李**——他那句"我买"内容明确、铁了心要买（要约）。老王那句"卖了算了"+"再想想"，根本不想被绑住，只是**要约邀请**。老王没承诺、最后拒绝，合同没成；老王正当拒绝也不算缔约过失。

### 🎯 一句话记忆

> **"愿受拘束才是要约；'再考虑'是邀请；没同意 = 没承诺；正当拒绝无过失。"**

### 填空模板（主观题用）

> 李某"欲以 8 万出售"并称"再考虑"，**【不愿受一经同意即受拘束】**，为**【要约邀请】**；张某"愿意购买"内容确定且有受约束意图，构成**【要约】**（向李某）。李某未表示同意，**【不构成承诺】**，次日拒绝致合同不成立；其正当拒绝磋商**【不构成缔约过失】**。故选 **C**。
