# C3-单选-03 · 无因管理 + 自家受损补偿

## 题干

> 张某外出台风将至。邻居李某担心张某房子被刮倒祸及自家，雇人用木料支撑张某房屋。房屋仍倒塌，压死李某养的鸡。下列哪一说法正确？

- A. 李某初衷为自己利益 → 不构成无因管理
- B. 房屋最终倒塌未达管理效果 → 无因管理不成立
- C. 李某的行为构成无因管理
- D. 张某不需支付李某固房的费用，但应补偿房屋倒塌给李某造成的损失

## 我的答案

**C**<!-- confidence: INFERRED -->

## 涉及考点

- [[无因管理]] **不以结果论**成立
- 初衷有自利 ≠ 否定无因管理
- 无因管理偿还请求权（§979）

## 考点精解 · 无因管理成立 vs 损失补偿

### 是什么 / 易混

**§979**（无因管理）：管理人**为避免他人利益受损**而管理事务的——
- 受益人**应当偿还**管理人**因此支出的必要费用**
- 管理人因管理事务**受到损失**的，可请求受益人**给予适当补偿**

→ **核心理念**：
- 无因管理**不以结果**论成立（即使没救成功也成立）
- 初衷有自利**不否定**为他人利益的意思
- 偿还费用 vs 补偿损失是**两条不同请求权**

本题对照：
- A "初衷自己利益 → 不构成" → 错（初衷有自利不否定）
- B "未达效果 → 不成立" → 错（结果不是构成要件）
- **C 李某行为构成无因管理 → 对**（§979）
- D "不付固房费 + 应补偿倒塌损失" → 错（固房费应付；倒塌压死鸡的损失基于 §1252 物件致损，不是无因管理补偿）

### 怎么考 / 坑在哪

- **D 复合陷阱**：固房费是**必要费用** = 张某应付（§979）
- 倒塌压鸡 = §1252 建筑物倒塌致损责任，与无因管理补偿不同路径

### 怎么答

C。李某构成无因管理，张某应付固房费用。
