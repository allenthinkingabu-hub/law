# C2-多选-06 · 自然人借款无息无期

## 题干

> 马某向好朋友车某书面借款 50 万元，**未约定利息**，未约定还款期限。下列说法哪些正确？

- A. 借款合同自车某向马某提供借款时成立
- B. 车某有权随时要求马某返还借款
- C. 车某可以要求马某按银行同期同类贷款利率支付利息
- D. 经车某催告 + 马某仍不还款 → 车某有权主张逾期利息

## 我的答案

**ABD**<!-- confidence: INFERRED -->

## 涉及考点

- [[借款合同]] 自然人借款的实践性（§679）
- 利息约定不明视为无息（§680 II）
- 没约定期限的返还规则（§675）+ 逾期利息

## 考点精解 · 自然人借款 4 规则

### 是什么 / 易混

**§679 + §680 II + §675**：

| 规则 | 内容 |
|---|---|
| 实践合同 | 自然人借款**自提供时成立**（§679） |
| 无利息约定 = 无息 | §680 II → 不按市场利率推定 |
| 无期限 | 借款人**可随时返还**；贷款人**可催告**借款人**合理期限**内返还（§675） |
| 逾期利息 | 借款人未按约定 / 催告期返还 → 出借人可主张逾期利息（§676 + 司法解释） |

本题对照：
- A 实践合同成立 → 对（§679）
- B 车某"随时要求返还" → 对（§675 出借人可催告，要求"合理期限"返还——表述上"有权随时要求"成立，但实际操作要给合理期限）
- C 按银行同期 → **错**（§680 II 视为无息）
- D 经催告仍不还 → 逾期利息 → 对（§676 + 司法解释）

### 怎么考 / 坑在哪

- **C 高频陷阱**：很多人误认"借款没说利息就按市场利率"——错，**视为无息**
- **B 边缘**：严格说"随时主张"≠"随时立刻还"，但**可随时催告**——通行答案为对

### 怎么答

ABD。
