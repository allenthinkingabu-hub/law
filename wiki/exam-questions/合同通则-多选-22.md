# C1-多选-22 · 自动贩卖机：设置 = 要约，投币 = 承诺；多吐的硬币要还

## 题干

> 甲在某大学摆设饮料自动贩卖机，乙投入两枚硬币购买了一罐咖啡，咖啡出来后，两枚硬币因机器故障跳出。乙见四处无人，乃取两枚硬币放入口袋。这一场景恰好被甲的职员丙发现，遂产生纠纷。关于本案，下列哪些说法是正确的？（2018金题-2-1-10）

- A. 甲摆设自动贩卖机的行为属于要约
- B. 乙投币购买咖啡的行为属于承诺
- C. 乙将两枚硬币放入口袋的行为构成不当得利
- D. 甲有权请求乙给付两枚硬币

## 我的答案

## 考点精解 · 自动售货机的要约承诺 + 找零错误

### 是什么 / 易混

- **A 设置贩卖机 = 要约**：摆出可即时交易的机器，向不特定人发出**内容确定、一经投币即受拘束**的要约（与"橱窗标价 = 要约邀请"不同，自动售货机是**要约**）。
- **B 投币 = 承诺**：乙投币的行为是以行为作出的承诺，合同成立、咖啡交付。
- **C 取回硬币 = 不当得利**：咖啡已出，两枚硬币是机器故障多吐出的（本应留作货款）。乙取走 = **无合法依据获得利益**（白喝了咖啡又拿回钱）→ 不当得利。
- **D 甲请求给付硬币**：基于买卖价款/不当得利返还，甲有权请求乙交付那两枚硬币（货款）。

### 怎么考 / 坑在哪

- 易错点：把自动售货机当"要约邀请"。**自动售货机 = 要约**（确定 + 受拘束）。
- 硬币跳出≠免单：咖啡已交付，乙未付对价，取走硬币是不当得利，须返还。

## 📐 答题口诀 · 自动售货机 = 要约（不是邀请）；白拿找零 = 不当得利

> **"机器摆出来 = 要约；投币 = 承诺；咖啡到手又把钱揣走 = 不当得利，得吐出来。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"自动售货机/贩卖机/自助机 设置"              → 要约（不是要约邀请）★
"投币 / 扫码支付 取货"                        → 以行为承诺，合同成立
"机器故障多吐钱/找零 被取走"                  → 无合法依据得利 → 不当得利
"商家请求返还多吐的钱"                        → 有权（货款/不当得利返还）
```

### 🚗 老王小李故事

> 老王在学校摆了台自动贩卖机（这一摆就是**要约**，谁投币谁就能买）。小李投两枚硬币买了罐咖啡（**承诺**，合同成立），咖啡掉出来了，可那两枚硬币又因故障"哐当"吐了回来。小李瞅瞅没人，把硬币塞兜里——咖啡白喝了、钱还揣走了，这两枚硬币就是**不当得利**，老王有权让小李吐出来。

### 🎯 一句话记忆

> **"贩卖机 = 要约、投币 = 承诺；故障吐的钱白拿 = 不当得利，要还。"**
