# C1-多选-17 · 违约 / 侵权竞合 + 精神损害赔偿

## 题干

> 甲将仅有的婚礼录像带交乙制作 VCD，乙店铺因丙抽烟失火烧毁录像带。下列正确的是？

- A. 甲可对乙提起违约之诉，并请求精神损害赔偿
- B. 甲可对乙提起侵权之诉，并请求精神损害赔偿
- C. 甲只能对丙提起侵权之诉，并请求精神损害赔偿
- D. 甲可对乙提起违约之诉或侵权之诉，不能请求精神损害赔偿

## 我的答案

**AB**<!-- confidence: INFERRED -->

## 涉及考点

- [[违约与侵权竞合]]（§186）
- [[精神损害赔偿]] 在**违约之诉**中的可主张性（§996 + 通则解释）

## 考点精解 · 2021 突破：违约也可主精神损害

### 是什么 / 易混

**§186**（竞合规则）：违约 + 侵权同时构成 → 受损方**择一**主张。

**§996**（重大突破）：**违反合同**侵害对方**人格权益**造成**严重精神损害**——
- 受损方**选择请求违约责任**的，**不影响**其请求**精神损害赔偿**

→ 即：**违约之诉 + 精神损害赔偿** **可同时主张**（2021 新规）。

**婚礼录像带**：是寄托人格利益的特殊物（具人身专属性纪念意义）→ 损害构成精神损害。

本题对照：
- A 违约之诉 + 精神损害 → 对（§996 突破）
- B 侵权之诉 + 精神损害 → 对（§1183）
- C "只能对丙" → 错（保管人乙亦有违约 / 侵权责任，与丙的侵权可并存——甲可择乙）
- D "不能请求精神" → 错（§996 已允许）

### 怎么考 / 坑在哪

- **2021 大新规**：旧法下违约**不能**主张精神损害，新法（§996）**允许**
- 婚礼录像带 / 骨灰盒 / 结婚纪念品等"具人格意义的特殊物" → 损坏可构成**严重精神损害**

### 怎么答

AB。
