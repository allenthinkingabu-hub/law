# C1-多选-17 · 违约 / 侵权竞合 + 精神损害赔偿

> ⚠️ **勘误（2026-06-10）**：答案由 ~~AB~~ 更正为 **B**。
> 旧分析误把"婚礼录像带是具人身意义的特定物"当作**违约之诉**可主精神损害的理由（选 A）。
> 实则 §996 违约精神损害**只看"损害人格权"**；录像带毁损只损**财产权**，"特定物"是
> **§1183 侵权之诉**的理由，**不能**搬进违约之诉。故 A 错、B 对。概念详见 [[精神损害赔偿]]。

## 题干

> 甲将仅有的婚礼录像带交乙制作 VCD，乙店铺因丙抽烟失火烧毁录像带。下列正确的是？

- A. 甲可对乙提起违约之诉，并请求精神损害赔偿
- B. 甲可对乙提起侵权之诉，并请求精神损害赔偿
- C. 甲只能对丙提起侵权之诉，并请求精神损害赔偿
- D. 甲可对乙提起违约之诉或侵权之诉，不能请求精神损害赔偿

## 我的答案

**B**<!-- confidence: INFERRED -->

# 一、答题思路 · 万能三步模型（多层侵权 · 最终版）

> 凡"竞合 + 精神损害 + 第三人"题，按这三步走，一步不跳。

## 第一步：先拆清所有法律关系（先在草稿画"关系图"）

列出全部主体（受害人 / 违约方 / 直接侵权人 / 间接侵权人），逐一判断：

- 谁与谁有**合同**？谁违反了合同义务？
- 谁实施了**侵权**？侵害了谁的**什么法益**？
- 侵权是**作为还是不作为**？是**直接还是间接**侵权？

## 第二步：分别判断各请求权"能否主张精神损害赔偿"（核心 · 边界在这）

> **一句话**：违约之诉精神损害**只认"损害人格权"**；"具人身意义的特定物"是**侵权之诉**的专属理由，**不能**搬进违约之诉。

| 受损法益                          | 违约之诉（§996）      | 侵权之诉（§1183）         |
| ----------------------------- | --------------- | ------------------- |
| **人格权**（肖像 / 名誉 / 人格尊严…）      | ✅ 可             | ✅ 可                 |
| **具人身意义的特定物**（录像带 / 骨灰 / 旧照片） | ❌ **不可**（只损财产权） | ✅ 可（须**故意 / 重大过失**） |
| 一般财产                          | ❌               | ❌                   |

- **违约（§996）**：仅当违约**损害人格权 + 造成严重精神损害**才可主张；**单纯财产损害（哪怕是特定物）不行**。
- **侵权（§1183）**：① 侵**人身权益**致严重精神损害 → 可；② **故意 / 重大过失**侵**特定物**致严重精神损害 → 可；③ **一般过失**侵特定物 → **不可**（新增考点）。
- 两条路径共同门槛：都须达到**"严重"**精神损害。
- 对照判别例：**婚纱照底片丢失**损的是**肖像 / 人格利益** → 违约之诉**也能**主张（§996）；**录像带 / 旧照片**烧毁损的是**财产权** → 违约之诉**不能**，只能走侵权。

## 第三步：判断受害人的选择权与责任承担

- **一个加害人（责任竞合）**：违约、侵权**择一主张**，不能同时（§186）。选定一种并**获实现**→另一种消灭；若被驳回 / 对方无力赔且另一种**未过时效**→可**改主张**另一种。
- **两个以上加害人（第三人侵权）**：受害人可①只告违约方、②只告某一侵权人、③同告数侵权人（按份 / 连带）；但**不得就同一损害双重获赔**。

# 二、本题精解

## 三层法律关系（别把乙、丙的侵权混为一谈）

| 主体    | 行为                 | 侵害法益     | 责任性质                        |
| ----- | ------------------ | -------- | --------------------------- |
| **丙** | 在乙店内抽烟失火           | 甲的录像带所有权 | 对甲：**直接侵权（作为）**             |
| **乙** | 未尽承揽合同的妥善保管 / 防火义务 | 甲的录像带所有权 | 对甲：**违约** + **不作为侵权**（二者竞合） |
| 甲     | 交付录像带制作 VCD        | ——       | 受害人                         |

→ 乙、丙**无意思联络**、**分别**侵害甲的同一录像带 → **分别侵权、按份责任**（§1172：能定责任大小各自承担，难定则平均）。

## 逐项分析

- **A 错**：乙违约只损害甲的**财产权**（录像带所有权），未损人格权；§996 违约精神损害**仅限人格权损害**，"特定物"不是违约之诉的理由 → 违约之诉**不能**主张精神损害。
- **B 对**：乙作为保管人负防火 / 保管的注意义务，未尽义务存**重大过失**；婚礼录像带是 §1183 ② "具人身意义的特定物" → **侵权之诉可主张**精神损害。
- **C 错**：错在"**只能**"。甲有三条请求权——对乙违约、对乙侵权、对丙侵权，可任选其一，并非只能告丙。
- **D 错**：错在"**不能请求精神损害**"。侵权之诉（B）可以。

## 对照例 · 一般过失 → 两条路都要不到（2023 真题改编）

> 甲将母亲生前唯一照片交乙照相馆翻拍，员工丙打扫卫生时**一般过失**将照片掉入水中损毁。下列正确的是？（同样四个选项）

- 违约之诉：只损**财产权** → **不能**主精神损害。
- 侵权之诉：丙是**一般过失**（非故意 / 重大过失）→ 特定物路径也**不能**主张。
- → **答 D**（甲可提违约或侵权之诉，但都要不到精神损害）。

**两题对比**：本题乙系**重大过失** → 侵权之诉可主张（B）；对照例丙系**一般过失** → 不能（D）。**过失程度是分水岭。**

# 三、五大陷阱（命题人最爱）

1. **§996 突破有边界**：违约**可**主精神损害（2021 大新规），但**仅限损害人格权**——别以为"告违约一律要不到"，也别以为"特定物违约也能要"。
2. **违约 ≠ 特定物**：违约之诉精神损害**只看人格权**；"具人身意义的特定物"是**侵权**的理由，搬进违约之诉就错。
3. **特定物需故意 / 重大过失**：**一般过失**侵害特定物 → **不能**主张（对照例 D 的考点）。
4. **二选一、相互排斥**：竞合时违约、侵权**择一**；"选定即永久锁死"是常见误记（被驳回且未过时效仍可改主张）。
5. **第三人介入别混淆**：第三人（丙）与违约方（乙）**分别侵权、按份责任**（§1172）；因第三人原因致违约，**违约方仍先担违约责任**（合同相对性，§593）、赔后向第三人追偿，受害人**不能**直接向第三人主张**违约**，但可主张**侵权**。

**B**。（更正前为 AB —— 见顶部勘误）
