# 民诉-小额诉讼-多选-183 · 小额诉讼管辖异议裁定与再审救济

## 题干

> 【出处】民事诉讼法真题（175-195题）第 183 题（题库自带标注"2021 金题-2-4-21"，该年份编号未经独立核验）

A 区张某和 B 区甲公司在 C 区签订租赁合同，约定将甲公司在 D 区的一套公寓租赁给张某，同时约定因为履行本合同产生纠纷应当由合同签订地 C 区法院管辖。后来张某拒不支付租金，甲公司向 C 区法院起诉张某，C 区法院受理案件后依法适用小额诉讼的程序审理。张某认为本案应当由 D 区法院专属管辖，故向 C 区法院提出管辖权异议。C 区法院认为管辖权异议不成立，裁定驳回其异议。后 C 区法院经过审理后判决张某支付租金。张某认为该判决在认定事实和适用法律方面存在错误。关于本案表述正确的是？

- A. 张某对法院驳回其管辖权异议的裁定可以提起上诉
- B. 张某对法院驳回其管辖权异议的裁定不能上诉
- C. 张某对本案生效判决可以向 C 区法院申请再审
- D. 张某对本案生效判决可以向中院申请再审

## 我的答案

**BC**

## 解析

### 本题考什么

本题考查 **小额诉讼中管辖异议裁定一经作出即生效（不能上诉）+ 小额诉讼一审终审，不服生效判决向原审法院申请再审**：
- 小额诉讼案件的管辖权异议裁定**一经作出即生效**，张某**不能对其上诉**（B对、A错）；
- 小额诉讼**实行一审终审**，张某不服生效判决不能上诉，只能**向原审 C 区法院申请再审**（C对）；
- 再审申请向原审 C 区法院提出，而非"向中院申请再审"（D错）。

📍 对应深度报告考点：[[民诉-客观题考点全景-深度报告]] › 板块C · 审判程序 › 第6章 › 小额诉讼（管辖异议、一审终审、再审）

### 逐项解析

**B —— ✅ 正确（应选）**

- 判断理由：当事人对小额诉讼案件提出管辖异议的，人民法院应当作出裁定，**裁定一经作出即生效**。故张某对驳回管辖异议的裁定**不能上诉**。
- 法律依据：《民诉法解释》（法释〔2022〕11号修正，现行有效）第二百七十六条："当事人对小额诉讼案件提出管辖异议的，人民法院应当作出裁定。裁定一经作出即生效。"
- 官方链接：[民诉解释全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：小额诉讼

**C —— ✅ 正确（应选）**

- 判断理由：小额诉讼实行一审终审，当事人不服生效判决不能上诉，但可以**以民事诉讼法规定的再审事由向原审人民法院申请再审**。张某认为判决认定事实、适用法律有错误，可向原审 C 区法院申请再审。
- 法律依据：《民诉法解释》第四百二十四条第一款（当事人以再审事由向**原审人民法院**申请再审的，法院应当受理，事由成立的裁定再审、组成合议庭审理，作出的再审判决**当事人不得上诉**）；《民事诉讼法》第二百一十一条（再审事由）。
- 官方链接：[民诉解释全文PDF（已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：小额诉讼再审

**A —— ❌ 错误（不选）**

- 判断理由：小额诉讼案件的管辖异议裁定**一经作出即生效**，不存在上诉问题。张某不能对驳回管辖异议的裁定提起上诉。
- 法律依据：《民诉法解释》第二百七十六条（裁定一经作出即生效）。
- 官方链接：[民诉解释全文PDF（已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：小额诉讼

**D —— ❌ 错误（不选）**

- 判断理由：小额诉讼案件不服生效判决申请再审，向**原审人民法院（C 区法院）**申请，而非"向中院申请再审"。
- 法律依据：《民诉法解释》第四百二十四条（向原审人民法院申请再审）。
- 官方链接：[民诉解释全文PDF（已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：小额诉讼再审

### 结论

综上，小额诉讼管辖异议裁定一经作出即生效、不能上诉（B对、A错）；小额诉讼一审终审，不服生效判决向原审 C 区法院申请再审（C对、D"向中院"错）。本题答案为 **BC**。

### ⚡ 做题眼

> **小额诉讼两个"即时/终局"（一眼判）**：
> **管辖异议裁定 → 一经作出即生效，不能上诉**（B 对，民诉解释276条）；
> **判决 → 一审终审，不能上诉**，不服只能**向原审法院申请再审**（C 对，向原审 C 区，不是中院——D 的坑）。
> 一句话："**小额诉讼里，管辖异议裁定当场生效、判决一审终审——都不能上诉，不服就回原法院申请再审。**"
