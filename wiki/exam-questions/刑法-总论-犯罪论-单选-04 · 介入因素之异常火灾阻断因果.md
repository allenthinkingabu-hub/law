# 刑法-总论-犯罪论-单选-04 · 介入因素之异常火灾阻断因果

## 题干

> 来源：依据因果关系介入因素学理通说（关联《刑法》§14、§16）命制的**仿真题**（题干为本库命制，非历年真题；三步判定法参见最高检《三方面判断介入因素是否中断因果关系》 https://www.spp.gov.cn/spp/llyj/201812/t20181210_402045.shtml ）。

甲故意将乙打成重伤，乙被送医院抢救，生命体征已平稳。当晚医院电路故障突发火灾，乙逃生不及被烧死。关于甲的刑事责任，下列正确的是？

- A. 甲的伤害行为与乙的死亡有因果关系，构成故意伤害致死
- B. 火灾系极度异常、独立的介入因素，阻断因果关系，甲对死亡不负责，仅成立故意伤害（致人重伤）
- C. 甲成立故意伤害罪（未遂）
- D. 火灾介入不影响归责，甲仍须对乙的死亡负责

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正解为 B。介入因素三步判定：①前行为（伤害）虽是条件，但乙生命体征已平稳，原因力趋于稳定；②火灾极度异常、不可预见，且独立于伤害行为而发生；③火灾对死亡起决定性作用——三步指向"异常独立介入＋作用力压倒性"，阻断伤害行为与死亡之间的因果关系。故甲对已实现的重伤结果负责（故意伤害致人重伤，**既遂**），但不对死亡负责。

- A 错：火灾阻断因果，死亡不能归责于甲，不成立"故意伤害致死"。
- B 对：异常独立介入阻断对死亡的归责，重伤结果已实现，定故意伤害（致人重伤）。
- C 错：重伤结果已实际发生，伤害已**既遂**，不存在未遂问题。
- D 错：极度异常的独立介入阻断归责，不能让甲对死亡负责。

陷阱：阻断的只是"死亡"的归责，**伤害本身已既遂**，不要误判为未遂。

## 考点精解 · 异常独立介入阻断"加重结果"

火灾是"极度异常＋独立发生＋作用力压倒"的三重叠加，是介入因素阻断因果的典型样态。关键不是"有没有因果"一刀切，而是分层判断：对**已实现的重伤**仍有因果（既遂），对**死亡**因异常介入而被阻断。

```
        介入因素三步判定法
┌────────────────────────────────┐
│ ① 前行为原因力                 │
│   伤害 → 乙重伤、但已平稳        │
│   原因力趋稳，未直接导向死亡     │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ ② 介入异常度 / 关联度           │
│   火灾：极度异常、不可预见        │
│   且独立发生（非伤害诱发）        │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ ③ 介入对结果的作用力            │
│   火灾对"死亡"起决定作用         │
└──────────────┬─────────────────┘
               ▼
        异常 + 独立 + 作用力压倒
        ⇒ 阻断"死亡"的因果归责
        ⇒ 重伤已既遂，对死亡不负责
        ⇒ 定故意伤害（致人重伤）
```

记忆要点：异常独立介入只切断"加重结果（死亡）"的归责，已发生的基础结果（重伤）照旧既遂。
