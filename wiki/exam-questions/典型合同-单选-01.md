# C2-单选-01 · 买卖合同检验期与保质期

## 题干

> 甲公司购买生产设备未约定检验期间。设备运到后立即检验未发现重大问题。第三年发现核心部件严重质量问题。使用说明书规定保质期 5 年。下列说法正确的是？

- A. 合理期限内未通知 → 视为合格
- B. 收到之日起 2 年内未通知 → 视为合格
- C. 没约定 → 共同承担
- D. 说明书规定保质期 → 应由乙公司承担责任

## 答案

**D**（**质量保证期优先于 2 年一般上限**）<!-- confidence: EXTRACTED -->

> 答案为依 §621 验证的正确法律结论。⚠️ 本题系**考点重构练习题**（来源 [[2026-06-06-合同章真题库]]），未检索到可溯源的逐字历年真题，故以法条原文验真为准。题中"乙公司"为出卖人（甲向乙购买）。

## 出处与来源

- 性质：买卖合同"检验期间 / 质量异议期"**考点重构题**（非逐字历年真题）
- 验真（2026-06-10）：§620-§623 经[最高检官网民法典全文](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)核对；核心但书 **§621②"对标的物有质量保证期的，适用质量保证期，不适用该二年的规定"** 逐字确认（[法治日报"书·法" · 陈合仁释义民法典第621条](http://www.legaldaily.com.cn/zt/content/2021-02/23/content_8437906.htm) 复核）

## 涉及考点

- [[买卖合同]] 标的物**检验期间**的三层规则（§620-§623）
- **保质期 vs 2 年极限**：保质期优先（§621 Ⅱ 但书）

## 考点精解 · 买卖合同检验期三层链

### 是什么 / 易混

**§621 + §622 + §623**（标的物检验期三层规则）：

| 层 | 适用条件 | 结果 |
|---|---|---|
| ① 约定检验期 | 当事人有约定 | 按约定期内通知 |
| ② 合理期间 | 无约定 | 合理期间内通知（最长 2 年） |
| ③ **保质期** | 有保质期约定 / 法规规定 | **保质期优先**于 2 年极限 |

→ **保质期是 2 年规则的"例外"**：保质期 5 年 → 在 5 年内发现质量问题 → 出卖人仍担责。

### 怎么考 / 坑在哪

- **B 经典陷阱**：很多考生只记得"2 年极限规则" → 选 B
- **关键**：本题第 3 年发现问题，**5 年保质期**仍在期内 → 突破 2 年限制
- **D 表述精准**：保质期约定 = 当事人对质量保证期的特别约定

### 怎么答

D。保质期 5 年 → 第 3 年发现核心部件问题仍在保护期内 → 出卖人乙公司应担责。

## 🎯 答题思路 · 买卖合同"检验期间 / 质量异议"万能四步模型

> 凡"买受人发现质量 / 数量问题、还能不能找出卖人担责"题，按这四步走，一步不跳。**本页真题即此模型的标准范例（答案 D）。**

### 一、核心考情

- **考查频率**：典型合同（买卖）高频考点（[[典型合同考点-深度报告]]），客观题常考，主观题买卖纠纷案例几乎必涉；常与**诉讼时效**、**违约救济**（§582）串考。
- **命题核心**：永远围绕"**异议期限到底多长**"——把"约定检验期 / 合理期限 / 2 年硬上限 / 质量保证期 / 出卖人恶意"五个时间规则故意混在一起，看你会不会按优先级拆解。不考定义背诵，全考期限适用。
- **四大必考点**：①有没有约定检验期 ②无约定时的"合理期限 + 2 年" ③**质保期突破 2 年**（本题）④出卖人恶意 + 外观 / 隐蔽瑕疵打断一般规则。

### 二、万能四步模型

#### 第一步：先看"有没有约定检验期间"（决定走哪条轨道）

**法考铁则**：
- **有约定检验期** → 买受人须在**约定期内**通知瑕疵；怠于通知 → **视为数量 / 质量符合约定**（§621 Ⅰ），出卖人免责。
- **无约定检验期** → 转入第二步"合理期限 + 2 年 / 质保期"轨道（§621 Ⅱ）。
- （§620：收到时有约定按约定期检验，无约定应"**及时检验**"。）

**老王小李例子**
- 合同写"到货 7 日内验收，逾期视为合格" → 小李第 10 天才提质量问题 → 晚了，视为合格。
- 合同没写检验期 → 走第二步。

#### 第二步：无约定时，定"异议期限的天花板"（2 年 vs 质保期 —— 本题核心）

**法考铁则**（§621 Ⅱ）：
- 原则：在**发现或应当发现**瑕疵的**合理期限内**通知；
- 外层硬上限：**自收到标的物起 2 年**内未通知 → 视为符合约定；
- ⭐ **例外（高频）：有质量保证期的，适用质量保证期，不适用该 2 年规定**。
  - 质保期 5 年 > 2 年 → 天花板抬到 5 年；质保期内发现并及时通知 → 出卖人担责。
  - ⚠️ "合理期限内通知"的要求**仍在**；质保期替换掉的只是"2 年"这个**外层硬上限**。

**老王小李例子**
- 小李买的设备没约定检验期、说明书写保质期 5 年 → 第 3 年发现核心部件缺陷 → **不受 2 年限制**，仍可追责（= 本题）。
- 若说明书**没写**保质期 → 2 年就是死线，第 3 年才提 → 视为合格，要不到了。

#### 第三步：识破"打断一般规则"的两张特殊牌

**法考铁则**：
1. **出卖人恶意**（§621 Ⅲ）：出卖人**知道或应当知道**标的物不符合约定的，买受人**不受**前两款通知期限的限制——卖家明知有问题，时间限制全部失效。
2. **约定检验期过短**（§622）：约定期过短、买受人难以完成全面检验的，该短期**仅视为"外观瑕疵"的异议期**；**隐蔽瑕疵**不受此短期限制。
   - 外观瑕疵 = 一看 / 一验就能发现（缺件、表面破损）；隐蔽瑕疵 = 内部、需使用才暴露（核心部件内在缺陷）。

**老王小李例子**
- 老王**明知**发动机翻新（恶意）却当新机卖 → 小李哪怕过了 2 年也能追责（§621 Ⅲ）。
- 约定"到货当天验完否则视为合格"——这种短到离谱的期限只管"外观"（少零件当天该发现），内部缺陷另算（§622）。

#### 第四步：定法律后果（谁担责 + 救济方式）

**法考铁则**：
- 在**有效异议期内**通知 → 出卖人承担**质量瑕疵违约责任**：修理、更换、重作、退货、减价、赔偿损失（§582 + §617）。
- 超期未通知 → **视为符合约定**，买受人**丧失质量异议权**，出卖人免责。
- ⚠️ 与**诉讼时效**分开：异议期是"**通知期**"（不发 = 视为合格，实体权没了）；诉讼时效是 3 年**起诉期**（§188）。两者独立各算——过了异议期即便没过时效也白搭；没过异议期也仍要在时效内起诉。

**老王小李例子**
- 小李在 5 年保质期内及时通知 → 可要求老王修理 / 更换 / 退货 / 赔偿。
- 即便在异议期内，也得在知道权利受损起 3 年内起诉，别拖过时效。

### 三、命题人最爱的 5 个陷阱

1. **只记"2 年上限"，忘了"有质保期适用质保期"** —— 错！质保期突破 2 年（本题 **B 陷阱**）。
2. **把"约定检验期过短"当成一切瑕疵的死线** —— 错！过短期**只管外观瑕疵**，隐蔽瑕疵不受限（§622）。
3. **把"检验期 / 异议期"等同"诉讼时效"** —— 错！异议期过 = 视为质量合格（实体权灭）；时效过 = 丧失胜诉权。两者独立、各算各的。
4. **忽略出卖人恶意例外** —— 错！卖家明知有瑕疵，买受人**不受任何通知期限制**（§621 Ⅲ）。
5. **"没约定检验期就双方共担 / 按公平分"** —— 错！没约定走"合理期限 + 2 年 / 质保期"，有明确规则，不是和稀泥共担（本题 **C 陷阱**）。

### 四、真题演练（套用四步模型 → 本题 D）

1. **第一步**：甲乙**未约定检验期间** → 走 §621 Ⅱ 轨道。
2. **第二步**：本应"合理期限 + 2 年"，但说明书规定**保质期 5 年** → **适用质保期、不适用 2 年**；第 3 年发现仍在 5 年内 → 异议有效。
3. **第三步**：核心部件严重质量问题属**隐蔽瑕疵**（立即检验未发现），第 3 年暴露合乎常理；无需动用恶意 / 外观规则即可定案。
4. **第四步**：异议有效 → **出卖人乙公司承担质量瑕疵责任** → **D 对**。
   - **A 错**：只套"合理期限"一般规则得出"视为合格"，无视质保期 → 结论反了。
   - **B 错**：套"2 年"死线，正是 §621 Ⅱ 但书**排除**的情形（经典陷阱）。
   - **C 错**：没有"共同承担"这一说，无约定有明确规则。
→ **答案：D** ✅
