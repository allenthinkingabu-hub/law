# 侵权-单选-12 · 自甘风险-骑马爱好者受惊马损失自担

## 题干

> 来源：2019 金题 2-1-21（众合）

甲、乙、丙、丁均为资深骑马爱好者，相约去草原骑马。甲提供四匹马，骑行过程中，乙的马被突然出现的野兔惊吓，造成乙受伤。请问：该责任如何承担？

- A. 甲承担全部责任
- B. 四人平均分担
- C. 乙自行承担
- D. 甲承担补充责任

## 我的答案

**C**<!-- confidence: EXTRACTED -->

C：乙作为资深骑马爱好者，明知骑马存在马匹受惊等风险，仍自愿参与——属于§1176 自甘冒险，乙应自行承担损失 ✓

A：甲提供马匹，但无故意或重大过失（§1176 但书：故意或重大过失除外）。野兔突然出现属不可预见，甲无过错，无需全责 ✗

B：无任何法律依据要求其他参与者平均分担 ✗

D：补充责任适用于安保义务人（第三人侵权场景），此处无安保义务主体，甲不是经营者 ✗

## 涉及考点

- [[侵权责任编]] §1176 自甘冒险（文体活动）
- §1176 但书：故意或重大过失除外
- 饲养动物责任与自甘风险竞合

## 考点精解 · §1176 自甘风险适用要件

### 四要件

1. **主动参与**：受害人自愿参与活动（非被强迫）
2. **认知风险**：受害人事先知道或应当知道该活动存在风险
3. **文体活动**：§1176 明确限于"具有一定风险的文体活动"
4. **无故意/重大过失**：加害方无故意或重大过失

**本题**：乙是资深骑马爱好者（认知风险）+ 自愿相约（主动参与）+ 骑马是文体活动 + 甲提供马匹无过失（野兔突然出现不可预见）→ 全部四要件满足 → **自甘风险，乙自担**。

### 对比：哪些是文体活动？

| 活动 | 是否适用§1176 |
|---|---|
| 骑马（自愿，资深） | ✓ 自甘风险 |
| 掰手腕（自愿同意）| ✓ 自甘风险（[[侵权-单选-05]]） |
| 非参与者横穿球场 | ✗ 不适用（[[侵权-单选-06]]） |
| 日常散步被绊倒 | ✗ 不是文体活动 |
