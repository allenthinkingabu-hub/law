# C2-多选-15 · 合作开发 + 一方放弃专利

## 题干

> 甲乙丙合作开发技术，未约定权属。完成后甲丙想申请专利，乙主张商业秘密保护。下列哪些选项**错误**？

- A. 甲、丙不得申请专利
- B. 甲、丙可申请专利，专利权归甲、乙、丙**共有**
- C. 甲、丙可申请专利，专利权归甲、丙所有，**乙有免费实施权**
- D. 甲、丙不得申请专利，但乙应向甲、丙支付补偿费

## 我的答案

**ABD**<!-- confidence: INFERRED -->

## 涉及考点

- [[技术合同]] 合作开发成果权属（§860）
- 商业秘密 vs 专利保护（§862）

## 考点精解 · §860 一方放弃后的处理

### 是什么 / 易混

**§860**（合作开发的成果权属）：
> 合作开发完成的发明创造，除当事人另有约定外，申请专利的权利**属于合作开发的当事人共有**。当事人一方**转让其共有**的专利申请权 → 其他各方享有**优先受让**的权利。
>
> 合作开发的当事人一方**声明放弃其共有**的专利申请权 → 除当事人另有约定外，可以由**另一方单独申请 / 其余当事人共同申请**；申请人取得专利权 → **放弃方**可以**免费实施**该专利。

**§862**（一方主张商业秘密保护）：合作开发的当事人**一方不同意申请专利**的 → 另一方或者其他各方**不得**申请专利。

→ 但这里乙是"**主张商业秘密**"——这相当于乙**放弃**专利申请权 + 自己用秘密保护。乙未明确"反对"甲丙申请。
→ 实务中：乙放弃 = 甲丙可申请 + 乙享免费实施权

本题对照（问"错误"）：
- A "甲丙不得申请" → **错**（乙放弃 → 甲丙可申请）→ 入
- B "三方共有" → **错**（乙已放弃，不享共有）→ 入
- C "甲丙共有 + 乙免费实施" → **对**（§860 放弃后规则）
- D "甲丙不得申请，乙应付补偿" → **错**（甲丙可申请，无补偿义务）→ 入

### 怎么考 / 坑在哪

- 注意 §862（一方反对则不得申请）vs §860（一方放弃则可申请）的区别
- **乙"主张商业秘密"** = 自我保护方式选择，不是反对 → 视为放弃专利申请权

### 怎么答

ABD（"错误"项）。
