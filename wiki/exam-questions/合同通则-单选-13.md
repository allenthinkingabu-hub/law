# C1-单选-13 · 格式条款的提示与说明义务

## 题干

> 甲与乙公司签订一份货物买卖合同，乙公司提前为与其日后进行业务往来的各方定制了一套标准化的条款。在签订合同的过程中，乙公司未通过任何方式对条款中有关货物交付的相关内容进行提示。合同签订后，甲在合同的条款中发现该条款对自己十分不利。对此，下面哪个选项是正确的？

- A. 因乙公司未进行提示，该条款应当认定为无效
- B. 甲可以要求修改合同中的该条款
- C. 甲应当承担不注意条款内容造成的后果
- D. 甲可以主张该条款不成为合同的内容

## 我的答案

**D**（该条款不成为合同的内容）<!-- confidence: INFERRED -->

## 涉及考点

- [[格式条款]] · 提示与说明义务（§496-§497）

## 考点精解 · 格式条款

### 是什么 / 易混

- **[[格式条款]]**（§496）：当事人为了重复使用而**预先拟定**、订立合同时**未与对方协商**的条款
- **提示与说明义务**（§496）：提供格式条款的一方应当**合理提示**对方注意与对方有重大利害关系的条款（如**免责 / 限责 / 风险负担**等），并按对方要求**说明**
- **违反后果**（§496 II）：对方可以主张**该条款不成为合同的内容**（非无效，而是不进入合同）

**§497** 格式条款**无效**情形：违反 §144、§146、§153 等一般无效；或者不合理免责 / 加重对方责任 / 限制主要权利

### 怎么考 / 坑在哪

- 错选 A "认定为无效"：违反提示义务的法律效果不是**无效**，而是该条款**不成为合同的内容**
- 错选 B "可以要求修改"：法律不赋予单方修改权
- 错选 C "应当承担后果"：错误地否认提供方的提示义务

### 怎么答

依 §496 II，提供格式条款一方违反提示义务，对方可主张该条款不成为合同的内容。故选 **D**。

## 📐 答题口诀 · [[格式条款]]：未提示 →"不成为内容"（≠ 无效）

> 这一题考**第一关 · 订入**：提供方**没提示**重大利害条款 → 该条款**不成为合同内容**（§496 II）。
> 最大陷阱：把"不成为内容"错当成"无效"（A）。

### 🚗 "未提示交付条款" 故事（题干场景化）

> 乙公司给所有客户备了一套**标准条款**。和老王（甲）签货物买卖时，乙**对"货物交付"那条只字未提**。
> 签完老王才发现：这条对自己**很不利**。

老王的正确武器 = **"这条不成为合同内容"**（D）：

| 要素 | 本题 |
|---|---|
| 是格式条款吗 | ✅ 乙预先拟定、未协商 |
| 是重大利害条款吗 | ✅ "交付"直接关系老王利益 |
| 乙提示了吗 | ❌ 只字未提 |
| 后果（§496 II）| **该条款不成为合同内容** → 老王当它不存在 |

→ 选 **D** ✅

### ⚠️ 核心区分："不成为内容" vs "无效"

| | 不成为合同内容（D）| 无效（A 陷阱）|
|---|---|---|
| 栽在哪 | **第一关 · 订入**（没提示）| **第二关 · 内容**（违法）|
| 法条 | §496 II | §497 / §506 |
| 含义 | 条款**没进合同**、自始不在 | 条款进了合同、但内容被否定 |
| 本题 | ✅ 乙未提示交付条款 | ❌ 本题只是"对甲不利"，未必违法 |

> 📌 **"对我不利" ≠ "无效"**：不利条款若内容合法，只要提示到位照样有效；本题的问题是**没提示**，所以走"不成为内容"，不是"无效"。

### 📋 4 选项解析

| 选项            | 判断  | 理由                     |
| ------------- | --- | ---------------------- |
| A 认定无效        | ❌   | 未提示的后果是"不成为内容"，不是无效    |
| B 可要求修改       | ❌   | 法律不赋予单方修改权             |
| C 甲承担不注意后果    | ❌   | 提示义务在**提供方**乙，不是甲的注意义务 |
| **D 不成为合同内容** | ✅   | §496 II 违反提示义务的法定后果    |

→ 选 **D** ✅

### 🎯 一句话记忆

> **"格式条款没提示 → 该条款『不成为合同内容』（§496 II），不是无效！"**
> **"不利 ≠ 无效；没提示 = 没进门，违法 = 进门也作废"**

### 填空模板（主观题用）

> 乙公司的标准条款系 **[[格式条款]]**（预先拟定、未协商）。"货物交付"条款与甲**有重大利害关系**，乙负有**合理提示义务**（§496 II）却未提示，致甲未注意。依 §496 II，甲可主张**该条款不成为合同的内容**。注意：此为**订入层面**的后果，与 §497 的**条款无效**不同。故选 D。
