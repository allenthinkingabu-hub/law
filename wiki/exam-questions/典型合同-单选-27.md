# C2-单选-27 · 转委托 + 行纪：委托人行使受托人对第三人的权利

## 题干（2011-3-4）

> 甲委托乙销售一批首饰并交付，乙经甲同意转委托给丙。丙以其名义与丁签订买卖合同，约定将这批首饰以高于市场价 10% 的价格卖给丁，并赠其一批箱包。丙因此与戊签订箱包买卖合同。丙依约向丁交付首饰，但因不能向戊交付箱包，导致丙无法向丁交付箱包。丁拒绝向丙支付首饰款。下列哪一表述是正确的？

- A. 乙的转委托行为无效
- B. 丙与丁签订的买卖合同直接约束甲和丁
- C. 丙应向甲披露丁，甲可以行使丙对丁的权利
- D. 丙应向丁披露戊，丁可以行使丙对戊的权利

## 我的答案

**C**<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **答题模型** → [[民法-合同-委托行纪中介模型]] 范例⑥ / B.[[间接代理]]（§925 知道→直接归属 / §926 不知→披露+介入/选择）
- [[委托合同]] 经同意转委托（§923 第1款）
- [[行纪合同]] / [[间接代理]]：受托人以自己名义对外、委托人披露后行使其对第三人的权利（§925/§926）
- 📐 **对照** → [[典型合同-单选-25]]（转委托责任归属三情形）· [[典型合同-多选-25]]（间接代理双向穿透）

## 考点精解 · 转委托 + 行纪间接代理综合题

### 关系梳理

```
甲（委托人）→ 委托乙销售首饰
乙 →[经甲同意转委托]→ 丙（受转委托）
丙 →[以丙自己名义，行纪方式]→ 与丁签买卖合同（卖首饰）
丙 →[额外承诺赠箱包]→ 与戊签买卖合同（买箱包）
结果：戊未能给丙箱包 → 丙无法赠丁 → 丁拒付首饰款
```

### 选项逐析

**A：乙转委托无效** → **错**
§923 第1款：经委托人甲**同意**，转委托有效。

**B：丙丁合同直接约束甲丁** → **错**
丙以**自己名义**（行纪方式）与丁订约，丁订约时不知甲存在。
§925：第三人在订立时**知道委托关系**，合同才直接约束委托人。本题丁不知甲，故不约束甲。

**C：丙向甲披露丁，甲可行使丙对丁的权利** → **正确**
间接代理中，受托人（丙）以自己名义对第三人（丁）享有收款权。当丁拒付，丙须向甲**披露丁的身份**，甲得以**代位行使**丙对丁的收款权（§926 精神）。

**D：丙向丁披露戊，丁可行使丙对戊的权利** → **错**
丁是买首饰的**买方**，不是委托丙买箱包的委托人。§926 适用于同一委托链上的当事人——丁不是"委托丙买箱包"的委托人，故丁无权代位丙向戊主张权利。

### 怎么考 / 坑在哪

- **B 大坑**："行纪人以自己名义订约" → 不直接约束委托人（须丁知晓委托关系才能直接约束）
- **D 混淆**：套用§926 但搞错了当事人关系——丁在"丙-戊"合同中既不是委托人也不是受托人，无法穿透主张
- **此题考点综合性强**：§923 转委托（A陷阱）+ §925 直接约束前提（B陷阱）+ §926 委托人代位权（C正确）+ 间接代理穿透边界（D陷阱）

### 怎么答

C。经甲同意转委托有效（A错）；丙行纪以自己名义，丁不知甲，不直接约束甲（B错）；甲可代位行使丙对丁权利，但须丙先向甲披露丁（C对）；丁不是委托丙买箱包的人，无法穿透（D错）。

## 📐 答题口诀

> **行纪不透明，委托人借力须"披露"**：受托人须向委托人披露第三人身份，委托人方可代位行使权利（§926精神）
