# C1-多选-04 · 合同成立的最低限度

## 题干

> 当事人对合同是否成立存在争议，人民法院能够确定下列哪些因素的，一般应当**认定合同成立**？

- A. 当事人姓名或者名称
- B. 标的
- C. 数量
- D. 价款

## 我的答案

**ABC**<!-- confidence: INFERRED -->

## 涉及考点

- [[合同成立]] 的最低必要条件
- [[合同编通则司法解释]] 第 3 条

## 考点精解 · 合同成立"三要素"

### 是什么 / 易混

[[合同编通则司法解释]] 第 3 条（实质同 §470 但放宽认定）：
> 当事人**姓名 / 名称、标的、数量**确定的，人民法院**一般应当认定合同成立**。

**三要素**：
1. **谁**（当事人姓名 / 名称）
2. **什么**（标的）
3. **多少**（数量）

→ 这是合同**成立**的最低限度。

**价款 / 报酬 / 履行期限 / 地点 / 方式**等其他条款，**没约定可推定**（§510 + §511）→ 不是成立必要条件。

### 怎么考 / 坑在哪

- **超高频陷阱**：D 价款。考生想当然认为"买卖合同没价钱怎么算"
- 实际上：价款没约定 → §511 可按市价确定 → **不影响合同成立**

### 怎么答

ABC。

合同成立看"三要素"（人 / 标的 / 数量），其余条款可推定补正。
