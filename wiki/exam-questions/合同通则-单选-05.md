# C1-单选-05 · 合同编的适用范围

## 题干

> 下列民事法律关系的调整，**可以适用**民法典合同编规定的是（ ）。

- A. 甲与乙签订的收养协议
- B. 甲与乙离婚时签订的子女抚养协议
- C. 甲行政机关与公务员签订的廉政协议
- D. 甲为了方便出行，出钱修缮邻居乙家被台风刮倒的院墙

## 我的答案

**D**（无因管理 / 适用合同编关于无因管理的规定）<!-- confidence: INFERRED -->

## 涉及考点

- [[合同编]] 的适用范围
- [[准合同]]（无因管理）

## 考点精解 · 合同编适用范围

### 是什么 / 易混

- **合同编不适用**：婚姻、收养、监护等**身份关系协议**（§464 II）；**行政协议**也独立适用行政法
- **合同编适用**：财产关系协议 + **无因管理 / 不当得利**（合同编"准合同"分编）
- 易混：身份关系协议**优先**适用婚姻家庭编、收养相关规定；性质不抵触时**可参照适用**合同编

### 怎么考 / 坑在哪

- 选项 A 收养、B 抚养 → **身份关系**，优先婚姻家庭编 / 收养规定
- 选项 C 公务员廉政协议 → **行政协议**，不是民事合同
- 选项 D 修缮邻居被毁院墙 → **无因管理**，正好是合同编"准合同"分编范围

### 怎么答

D 选项是典型的无因管理（为他人管理事务，无法定 / 约定义务）。合同编"准合同"分编涵盖无因管理和不当得利。其他三项要么是身份关系（A/B），要么是行政关系（C），均不适用合同编。故选 **D**。
