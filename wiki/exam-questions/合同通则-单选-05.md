# C1-单选-05 · 合同编的适用范围

## 题干

> 下列民事法律关系的调整，**可以适用**民法典合同编规定的是（ ）。

- A. 甲与乙签订的收养协议
- B. 甲与乙离婚时签订的子女抚养协议
- C. 甲行政机关与公务员签订的廉政协议
- D. 甲为了方便出行，出钱修缮邻居乙家被台风刮倒的院墙

## 我的答案

**D**（无因管理 / 适用合同编关于无因管理的规定）<!-- confidence: INFERRED -->

## 涉及考点

- [[合同编]] 的适用范围
- [[准合同]]（无因管理）

## 考点精解 · 合同编适用范围

### 是什么 / 易混

- **合同编不适用**：婚姻、收养、监护等**身份关系协议**（§464 II）；**行政协议**也独立适用行政法
- **合同编适用**：财产关系协议 + **无因管理 / 不当得利**（合同编"准合同"分编）
- 易混：身份关系协议**优先**适用婚姻家庭编、收养相关规定；性质不抵触时**可参照适用**合同编

### 怎么考 / 坑在哪

- 选项 A 收养、B 抚养 → **身份关系**，优先婚姻家庭编 / 收养规定
- 选项 C 公务员廉政协议 → **行政协议**，不是民事合同
- 选项 D 修缮邻居被毁院墙 → **无因管理**，正好是合同编"准合同"分编范围

### 怎么答

D 选项是典型的无因管理（为他人管理事务，无法定 / 约定义务）。合同编"准合同"分编涵盖无因管理和不当得利。其他三项要么是身份关系（A/B），要么是行政关系（C），均不适用合同编。故选 **D**。

## 📐 答题口诀 · [[合同编适用范围]] 范围识别三步走

> 这一题考查的是合同编**到底管什么 / 不管什么**(管辖边界)。

### 三步走结构

```
看到"是否适用合同编":

Step 1: 是不是民事关系?
  - 行政关系(政府 vs 公务员)→ ❌ 不适用(C 排除)
  - 民事关系(平等主体)→ 继续

Step 2: 是不是身份关系?
  - 婚姻 / 收养 / 监护 / 抚养 → ❌ 身份法优先(A, B 排除)
  - 财产关系 → 继续

Step 3: 是不是合同 / 准合同?
  - 合同 / 无因管理 / 不当得利 → ✅ 适用合同编(D 命中)
  - 侵权 / 物权变动 → 各自编 + §468 参照
```

### 🔑 合同编"管辖边界"全景图

```
                      民事关系
                          │
        ┌─────────────────┼─────────────────┐
        ▼                                    ▼
    财产关系                              身份关系
        │                                    │
   ┌────┼────┐                       ┌──────┼──────┐
   ▼    ▼    ▼                       ▼      ▼      ▼
合同 / 无因管理 / 不当得利           婚姻   收养   监护
  ✅ 合同编管(本题 D)                ❌ 合同编不管(本题 A, B)
                                       (§464 II 身份法优先,可参照)

另外:行政关系(本题 C)→ ❌ 行政法适用
```

### 🚗 老王老李 4 场景剧(对应 4 选项)

#### 场景 A · 收养协议 ❌

> 老王要收养孤儿小李,签了**收养协议**。

→ 收养建立**亲属身份关系** → 适用收养法 / 婚姻家庭编
→ 不适用合同编(§464 II)

#### 场景 B · 子女抚养协议 ❌

> 老王和老李离婚,签了"小明跟妈妈,老王每月付 5000 抚养费"。

→ 子女抚养 = 身份关系 → 婚姻家庭编
→ ⚠️ 离婚**财产分割**部分可参照合同编,但**子女抚养**不参照

#### 场景 C · 公务员廉政协议 ❌

> 政府让公务员老王签廉政承诺书:"严守纪律,不收红包"。

→ 行政机关 vs 公务员 = **不平等主体** → 行政法
→ 不是民事关系,不适用合同编

#### 场景 D · 修缮邻居院墙 ✅

> 台风把老李家院墙刮倒,**挡了老王进出**。老李不在家。
> 老王**自掏腰包修好了院墙**。

→ 无义务 + 为他人(也为自己)+ 他人事务 → 构成 **§979 无因管理**
→ 老王可请求老李偿还必要费用
→ ✅ **合同编"准合同"分编直接适用**

⚠️ **关键点**:"**为了方便出行**" = 也为自己利益 → **不影响**无因管理成立!法律不要求"纯粹利他动机"

### 📋 4 选项陷阱完整解析

| 选项 | 关系类型 | 适用什么 | 排除原因 |
|---|---|---|---|
| **A 收养协议** | **身份关系** | 收养法 / 婚姻家庭编 | §464 II 身份法优先 |
| **B 子女抚养协议** | **身份关系** | 婚姻家庭编 | §464 II 身份法优先 |
| **C 公务员廉政协议** | **行政关系** | 行政法 / 公务员法 | 主体不平等,不是民事 |
| **D 修缮邻居院墙** | **准合同(无因管理)** | **合同编 §979** | ✅ **正解** |

→ 选 **D** ✅

### ⚠️ §464 II 的"参照"≠ "适用"(深入辨析)

**§464 II 原文**:身份关系协议**适用**有关该身份关系的法律规定;**没有规定的,可以根据其性质参照适用本编规定**。

→ 两层结构:
- **第一层**:身份法**优先适用**(婚姻家庭编 / 收养法)
- **第二层**:身份法没规定时 → 根据**性质参照**合同编

实例对比:
- 收养撤销纠纷 → 收养法**有**规定 → 直接适用收养法
- 收养中财产返还细节 → 收养法**没说** → **参照**合同编
- 离婚财产分割违约责任 → 婚姻法不细说 → **参照**合同编违约责任

→ "**参照**"是**有条件的辅助性适用**,不是"完全适用"!

### 🎯 一句话记忆

> **"合同编管财产 + 准合同,不管身份和行政"**
> **"§464 II:身份协议先用身份法,性质允许可参照合同编"**
> **"§979 无因管理是合同编'准合同'分编 — Q05 的 D 直接适用"**
> **"为他人 + 自己利益 ≠ 否定无因管理"**

### 填空模板(主观题用)

> 本案中**【某行为】**是否适用合同编,需按 **§463 / §464**(合同编调整范围)判断:
>
> ① 关系性质:**【民事 / 行政】**关系;
> ② 是否身份关系:**【是 → 适用身份法 / 否】**;
> ③ 是否合同 / 准合同:**【是 → 适用合同编 / 否】**。
>
> 本案 D 选项属**【无因管理】**(§979),由合同编**准合同**分编直接调整 → 适用合同编。
