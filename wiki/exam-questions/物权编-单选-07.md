# 物权-单选-07 · 失踪宣告财产代管人卖房——丙知情故不能善意取得

## 题干

> 甲被法院宣告失踪，其妻乙被指定为甲的财产代管人。3个月后，乙将登记在自己名下的夫妻共有房屋出售给丙，交付并办理了过户登记。在此过程中，乙向丙出示了甲被宣告失踪的判决书，并将房屋属于夫妻二人共有的事实告知丙。1年后，甲重新出现，并经法院撤销了失踪宣告。现甲要求丙返还房屋。对此，下列哪一说法是正确的？(2016年卷三第6题)

- A. 丙善意取得房屋所有权，甲无权请求返还
- B. 丙不能善意取得房屋所有权，甲有权请求返还
- C. 乙出售夫妻共有房屋构成家事代理，丙继受取得房屋所有权
- D. 乙出售夫妻共有房屋属于有权处分，丙继受取得房屋所有权

## 答案

**B**（丙已知情，不满足善意取得"善意"要件）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2016年司法考试卷三第6题

## 涉及考点

- [[善意取得]] §311：受让人须在**取得时不知道且不应知道**出让人无权处分
- 共有房屋处分：需全体共有人同意，乙单独处分甲乙共有房屋属**无权处分**
- **善意要件被打破**：乙明确告知丙"房屋属夫妻共有"→丙知情→丙非善意

## 考点精解

**善意取得四要件**（§311）：

| 要件 | 本案 | 是否满足 |
|---|---|---|
| ① 出让人无权处分 | 乙单独卖共有房 | ✓ |
| ② 受让人善意（不知/不应知） | 乙**主动告知**丙是共有房 | **✗ 丙知情** |
| ③ 合理价格 | 未提及异常 | ✓ |
| ④ 法定公示（不动产须登记） | 办理了过户登记 | ✓ |

善意要件缺失 → 丙**不能**善意取得 → 甲有权请求丙返还房屋 → **B** ✓

**C、D错**：乙是财产代管人，代管人有权管理财产，但代管范围有限；出售共有房超出代管权，且不构成家事代理（金额远超一般家事）。

## 📐 口诀

> **知情者无善意——乙明说共有，丙知则非善意，善意取得失败。**
