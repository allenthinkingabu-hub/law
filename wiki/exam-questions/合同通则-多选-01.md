# C1-多选-01 · 已过诉讼时效债权的权能

## 题干

> 已过诉讼时效的债权，具有哪些权能？（ ）

- A. 支配权能
- B. 保持受领权能
- C. 保全权能
- D. 处分权能

## 我的答案

**BCD**（已过时效 = **胜诉权**消灭，实体权利仍存）<!-- confidence: INFERRED -->

## 涉及考点

- [[债的特征]]（非排他、相对性）
- 诉讼时效届满 → 自然债务
- 债权 4 大权能：请求 / 受领 / 保全 / 处分

## 考点精解 · 自然债务的权能

### 是什么 / 易混

**诉讼时效届满**：胜诉权（强制履行请求权）消灭，债权**实体不消灭** → 变"自然债务"。

| 权能 | 时效届满后 | 说明 |
|---|---|---|
| 请求权能（胜诉权） | ❌ 消灭 | 法院不再强制保护 |
| **受领权能** | ✅ 保留 | 债务人自愿履行→不得请求返还 |
| **保全权能** | ✅ 保留 | 仍可代位 / 撤销 |
| **处分权能** | ✅ 保留 | 可放弃 / 转让 |
| 支配权能 | ❌ 无 | 债权本就无支配（物权才有） |

→ A 错（支配是物权权能，债权根本无）；B/C/D 对。

### 怎么考 / 坑在哪

- A 支配权能：**债权无支配权**（陷阱常见）
- D 处分权能：很多考生忘了——时效届满**仍可转让 / 抛弃**

### 怎么答

BCD。诉讼时效仅吃掉"胜诉权"，受领 / 保全 / 处分都还在。

## 📐 答题口诀 · [[诉讼时效]] 届满 + [[自然债务]] 双视角

> 这一题是**三连考的终章**:Q01 特征 → Q03 权能 → 本题**时效届满后权能命运**

### Step 1:识别核心命题"时效届满 ≠ 债消失"

```
看到"已过诉讼时效"
       ↓
消灭"胜诉权"(程序保障) ❌
       ↓
实体债权仍存 → [[自然债务]] ✅
```

### Step 2:4 权能命运速查

| 权能 | 时效届满后 | 原因 |
|---|---|---|
| ① **请求权能**(胜诉权)| ❌ **消灭** | 程序保障没了 |
| ② **保持受领权能** | ✅ **保留** | §192 II:自愿履行不得索回 |
| ③ **保全权能** | ✅ **保留** | 仍可代位 / 撤销 |
| ④ **处分权能** | ✅ **保留** | 可转让 / 抛弃 |

→ 选 ②③④ = **BCD** ✅

### 🪤 Step 3:破解 A "支配权能"陷阱(高频)

⚠️ A 错的不是"时效届满后没有",而是 **"债权本就没有"**!

```
支配权 ─→ 物权的核心权能(占有 / 使用 / 收益 / 处分)
              ↑
              这是物权的!债权根本无支配权!
              
请求权 ─→ 债权的核心权能(请求债务人为或不为)
```

### 5 个权能视角对比(陷阱根源)

| 权能 | **债权**有? | **物权**有? | 备注 |
|---|---|---|---|
| **支配权能** | ❌ **无** | ✅ **核心** | ⚠️ A 陷阱根源 |
| **请求权能** | ✅ 核心 | ⚠️ 有限(物权请求权) | 时效届满消胜诉权 |
| **保持受领权能** | ✅ | — | 与物权无关 |
| **保全权能** | ✅ | — | 代位 / 撤销 |
| **处分权能** | ✅ | ✅ | 都可处分 |

→ **支配权 = 物权专属** → A 永远错(不论时效)

### 📋 4 选项陷阱解析

| 选项 | 内容 | 对错 | 错因 / 对因 |
|---|---|---|---|
| **A** | 支配权能 | ❌ 错 | **支配权是物权专属** — 债权本就无此权能,与时效无关 |
| **B** | 保持受领权能 | ✅ 对 | §192 II 自愿履行不得索回 → 不构成 [[不当得利]] |
| **C** | 保全权能 | ✅ 对 | 仍可行使 [[代位权]] / [[撤销权]] |
| **D** | 处分权能 | ✅ 对 | 可转让 / 抛弃 / 设定担保 |

→ 选 **BCD** ✅

### 🎯 一句话记忆

> **"时效届满消灭'胜诉权',不消灭'债权'本身"**
> **"4 权能里 1 死 3 活:请求(胜诉)死 / 受领 + 保全 + 处分活"**
> **"A 支配权能是物权专属,**永远**不是债权的权能(与时效无关)"**
> **"自愿履行不得索回 → 不是不当得利"**

### 填空模板(主观题用)

> 本案中**【某债权】**已过诉讼时效,根据 **§192**:① **胜诉权消灭**(义务人抗辩时法院判驳回);② 但**实体债权仍存**,形成 [[自然债务]];③ 债权人**仍享有**:保持受领 / 保全 / 处分 3 权能;④ 义务人**自愿履行**的,**不得**请求返还(**不构成 [[不当得利]]**)。

### Q01 单选 vs Q03 单选 vs 本题(多选-01)的关键差异

| 题 | 假设 | 问 | 答案视角 |
|---|---|---|---|
| Q01 单选 | "正常债权" | 4 特征哪个? | 任意性 |
| Q03 单选 | "欠缺即不再是债" | 灵魂权能? | 请求权能 |
| **多选-01** | "时效届满后" | 还保留哪些权能? | BCD(3 个保留) |

→ **Q03 vs 本题对比**:
- Q03 说"请求权能欠缺 → 不再是债"——指**实体请求权能**完全消失
- 本题"时效届满"——只消灭**胜诉权**(请求权能的程序保障部分),**实体请求权能**仍在
- 所以 [[自然债务]] 仍是债!
