# C1-多选-01 · 已过诉讼时效债权的权能

## 题干

> 已过诉讼时效的债权，具有哪些权能？（ ）

- A. 支配权能
- B. 保持受领权能
- C. 保全权能
- D. 处分权能

## 我的答案

**BCD**（已过时效 = **胜诉权**消灭，实体权利仍存）<!-- confidence: INFERRED -->

## 涉及考点

- [[债的特征]]（非排他、相对性）
- 诉讼时效届满 → 自然债务
- 债权 4 大权能：请求 / 受领 / 保全 / 处分

## 考点精解 · 自然债务的权能

### 是什么 / 易混

**诉讼时效届满**：胜诉权（强制履行请求权）消灭，债权**实体不消灭** → 变"自然债务"。

| 权能 | 时效届满后 | 说明 |
|---|---|---|
| 请求权能（胜诉权） | ❌ 消灭 | 法院不再强制保护 |
| **受领权能** | ✅ 保留 | 债务人自愿履行→不得请求返还 |
| **保全权能** | ✅ 保留 | 仍可代位 / 撤销 |
| **处分权能** | ✅ 保留 | 可放弃 / 转让 |
| 支配权能 | ❌ 无 | 债权本就无支配（物权才有） |

→ A 错（支配是物权权能，债权根本无）；B/C/D 对。

### 怎么考 / 坑在哪

- A 支配权能：**债权无支配权**（陷阱常见）
- D 处分权能：很多考生忘了——时效届满**仍可转让 / 抛弃**

### 怎么答

BCD。诉讼时效仅吃掉"胜诉权"，受领 / 保全 / 处分都还在。
