# C1-多选-15 · 房屋买卖未过户

## 题干

> 乙买甲房屋已付 1/3，约定余款过户后付清。甲反悔要解除，乙起诉请求继续履行。下列哪些**错误**？

- A. 因双方未办理登记，故房屋买卖合同未生效
- B. 乙有权向法院起诉主张物权确认请求权
- C. 合同有效，甲应继续履行合同
- D. 合同有效，法院应当判决解除合同、甲赔偿乙的损失

## 我的答案

**ABD**<!-- confidence: INFERRED -->

## 涉及考点

- [[合同成立]] vs [[合同生效]] vs **物权变动**
- [[请求权基础]]：物权请求权 vs 债权请求权
- 法定解除事由 vs 法院主动判决解除

## 考点精解 · "未登记不生效"是经典错觉

### 是什么 / 易混

**核心规则**：
- 房屋买卖**合同**自合意时即**生效**（§502）—— 不动产**登记 ≠ 合同生效**
- **登记**是**物权变动**的生效要件（§209、§214）—— 影响**所有权移转**，不影响**合同效力**
- → "未登记不影响合同效力，影响所有权"

本题对照（问"错误"项）：
- A "未登记 → 合同未生效" → **错**（混淆物权变动与合同生效）
- B 乙是买方未取得所有权 → **无物权** → 不能行使**物权确认请求权** → **错**
  - 乙的请求权基础是**合同请求权**（要求过户履行），不是物权
- C 合同有效 + 甲应继续履行 → **对**（正常救济）
- D 法院"应当判决解除合同" → **错**
  - 法院不能主动解除，必须当事人主张
  - 本题甲请求解除，但缺乏 §563 法定事由（乙未违约）→ 不应支持
  - 乙请求继续履行，应予支持

### 怎么考 / 坑在哪

- **A 王牌陷阱**：50% 考生选 "未登记合同未生效"
- **B 易错点**：买方**未取得所有权前**只有合同请求权，**没有**物权请求权
- **D 易错点**：法院**不主动解除**合同，要看当事人请求 + §563 事由

### 怎么答

ABD（错误项）；C 是唯一正确的——合同有效，甲应继续履行。

## 📐 答题口诀 · §215 区分原则三步走

> 涉及**物权变动的合同纠纷**（房屋买卖 / 抵押 / 股权转让等）的**通用万能模板**。

### 三步走结构

```
Step 1：定合同效力（§502 / §215）
  合意 + 合法 + 具体 → 合同生效 ✅
  ⚠️ 登记 / 交付 / 公证 / 备案 与否 → "不影响合同效力"（§215）

Step 2：定物权变动（§209 / §214 / §224 / §225）
  不动产 → 登记时变动
  一般动产 → 交付时变动
  特殊动产 → 交付时变动 + 登记对抗

Step 3：定请求权基础（"用哪条枪？"）
  合同请求权（债权）→ 任何时候都能用（只要合同有效）
  物权请求权 → 仅在物权已变动后能用
```

### "未登记"两条独立轨道

```
                ┌──────────────────────────┐
                │   涉及物权变动的合同      │
                └──────────────────────────┘
                          │
              ┌───────────┴───────────┐
              ▼                        ▼
    ┌──────────────────┐    ┌──────────────────┐
    │   债权轨道        │    │   物权轨道        │
    │   (合同效力)      │    │   (所有权)        │
    ├──────────────────┤    ├──────────────────┤
    │ 法条：§502/§215  │    │ 法条：§209/§214  │
    │ 生效：合意即生效 │    │ 变动：登记时变动 │
    │ **未登记 → 有效**│    │ **未登记 → 未动**│
    └──────────────────┘    └──────────────────┘
        ✅ 乙可主张合同请求权     ❌ 乙无物权 → 无物权请求权
```

### 📋 Q15 四选项错因逐一分析

| 选项    | 内容             | 对错  | 错在哪 / 对在哪                    |
| ----- | -------------- | --- | ---------------------------- |
| **A** | 未登记 → 合同未生效    | ❌ 错 | **混淆物权变动 vs 合同效力** — 违反 §215 |
| **B** | 乙主张**物权确认请求权** | ❌ 错 | 乙未取得所有权 → **没物权** → 仅能用合同请求权 |
| **C** | 合同有效 + 甲应继续履行  | ✅ 对 | 合同有效 + 没违约事由 → 应履行           |
| **D** | 法院**应当判决解除合同** | ❌ 错 | 法院**不主动解除** + 缺 §563 法定事由    |

→ 选 **ABD**（错误项）

### 三大经典陷阱

1. **"未登记 → 合同未生效"** ← 50% 考生选错（A 项）
2. **"买方就有物权"** ← 错，买方需公示完成才有物权（B 项）
3. **"法院主动解除"** ← 错，法院不主动解除（D 项）

### 🎯 一句话记忆

> **"未登记，房没过户；但合同 100% 有效"**
> **"§215 [[区分原则]]：债权归债权，物权归物权"**
> **"凡见'未登记 → 合同未生效'——错！"**

### 填空模板（主观题用）

> 甲乙之间的**【房屋买卖】合同**自合意时生效（**§502 + §215**）。**未办理过户登记**——根据 **§215 [[区分原则]]**，**不影响合同效力**，仅影响**物权移转**。
>
> 因此：① 合同**有效**，甲负有协助办理过户登记的合同义务；② 房屋所有权**仍归甲**（§209 未登记，未变动）；③ 乙的请求权基础是**合同请求权**（要求甲继续履行 / 赔偿），**不是**物权请求权（乙未取得所有权）。

### 📚 §215 立法目的速记

- **保护交易安全**：防止"我没登记所以合同无效"的耍赖
- **督促履行**：合同有效 → 卖方必须协助办登记
- **明确责任**：拒不协助登记 = **违约**（§577）

### 横向真题对照

- 本题（Q15）= **不动产** "未登记"陷阱（§215 + §209）
- 类比 → **动产** "未交付" 同理（§215 + §224）：买卖合同有效，但物权未变动
- 类比 → **抵押权设立**（§400 / §403）：合同合意生效，抵押权登记 / 合意时设立
