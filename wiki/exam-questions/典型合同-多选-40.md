# C2-多选-40 · 违法目的借款全部无效 + 担保随之无效（§153/§388/§679）

## 题干（金题来源：2022金题-2-1-21）

> 4月20日，贺某因购买制造假酒设备和原料向宫某借款50万元，期限一年，月息2%，并告知了借款用途，宫某当即表示同意，并于次日向贺某交付现金20万元，4月22日向贺某银行卡实时转账30万元。应宫某要求，董某以自己所持某有限责任公司的股权为该笔借款提供担保，并办理了质押登记。对此，下列说法正确的是？

- A. 借款合同无效
- B. 董某应承担担保责任
- C. 借款合同于4月20日成立
- D. 借款合同部分无效

## 我的答案

**A**<!-- confidence: INFERRED -->

贷款人知晓违法目的仍放贷，合同整体违反公序良俗无效（§153）；主债无效则担保从债亦无效（§388）；自然人借款为实践合同（§679），成立于首次交付日（4月21日），非签约日（C错）。

## 涉及考点

- [[借款合同]] 贷款方知悉违法目的时合同效力（§153 公序良俗）
- 担保合同从属性（§388 II）：主合同无效→担保合同无效
- 自然人间借款 = 实践合同（§679）：合同成立于"贷款人提供借款时"

## 考点精解 · 违法目的借款效力三层分析

### 是什么 / 易混

**§153 违反公序良俗**（合同无效）：
- 违反法律/行政法规强制性规定 → 无效
- 违背公序良俗 → 无效
- **知情放贷**：贷款人知悉借款用于违法目的（如制造假酒）仍提供借款 → 合同整体无效（双方均有过错）

**§388 II 担保合同从属性**：
> 主债权债务合同无效的，担保合同无效，但法律另有规定的除外。

主合同（借款合同）无效 → 从合同（担保合同）无效 → 董某无须承担担保责任

**§679 自然人间借款=实践合同**：
> 自然人之间的借款合同，自贷款人提供借款时成立。

本题：4月20日仅签订合同（诺成），4月21日首次交付20万 → 借款合同于**4月21日**成立（C错：C说4月20日成立）

### 逐项解析

**A（借款合同无效）→ 正确**
宫某知道贺某借款用于制造假酒（违法），仍然出借 → 违背公序良俗（§153）→ **整体无效**（非部分无效，D错）

**B（董某应承担担保责任）→ 错误**
担保合同（股权质押）是主合同（借款合同）的从合同（§388）。主合同无效 → 担保合同随之无效 → 董某无须承担质押担保责任。
（注：董某若有过错，可能承担相应赔偿责任，但不是基于担保合同的担保责任）

**C（借款合同于4月20日成立）→ 错误**
自然人间借款 = 实践合同（§679），以贷款人提供借款为成立要件，不是签订书面合同时。4月20日只是签约；4月21日交付20万元 → 就20万元部分成立；但整体合同仍无效。

**D（借款合同部分无效）→ 错误**
违法目的是整体性的（为制造假酒），不能切割认定部分有效。§153 导致整体无效，不适用部分无效规则（区别于"可分性"：本题违法目的贯穿全部借款，不可分）。

### 怎么考 / 坑在哪

1. **C 经典陷阱**：只记"自然人借款=实践合同"，但忘了本题已经告知"4月20日签约、4月21日付款"→ 正确成立时间是4月21日。
2. **B 经典陷阱**：以为"担保已办登记就一定有效"——忘记担保从属性，主合同无效则从合同无效。
3. **D 区分**：部分无效 vs 整体无效：违法目的附着于全部借款 → 整体无效。

## 📐 答题口诀 · 违法目的借款无效链

**关键词触发**：知悉违法用途 / 制造假冒伪劣 / 仍然出借

**🎯 一句话记忆**：
> 知违法而借→全无效（§153），从担随主灭（§388），成立看付款日（§679）。

**四步解题模板**：
```
① 贷款人知悉违法目的？→ 是 → §153 合同无效（整体）
② 主合同无效 → 担保合同无效（§388 II）
③ 自然人借款成立时间 = 首次提供借款时（§679）
④ 能否部分有效？→ 违法目的贯穿全部 → 不能分割 → 整体无效
```
