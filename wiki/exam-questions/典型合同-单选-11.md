# C2-单选-11 · 无偿保管 + 不可抗力

## 题干

> 贾某把古书交朋友王某无偿代为保管。楼上水管冻裂 → 水流损毁古书。下列哪项正确？

- A. 王某有过失 → 全部赔偿
- B. 王某有过失 → 适当赔偿
- C. 此事对王某属不可抗力 → 不应赔偿
- D. 王某无偿保管且无重大过失 → 不应赔偿

## 我的答案

**D**<!-- confidence: INFERRED -->

## 涉及考点

- [[保管合同]] 注意义务的区分（§897）
- 有偿 / 无偿保管的不同归责标准
- 📐 **答题模型** → [[民法-合同-委托行纪中介模型]]（第二步 A · 本题作"§929 有偿/无偿归责"的**无偿侧真实锚点**；§897 保管与 §929 委托归责同构）
- 🔗 横切概念 → [[有偿与无偿合同]]（"有偿责任重、无偿责任轻"主线）

## 考点精解 · 无偿保管 = 故意 / 重大过失才担责

### 是什么 / 易混

**§897**（保管人责任）：
> 保管期间，因保管人保管不善造成保管物毁损、灭失的，保管人应当承担赔偿责任，但是**无偿保管人**证明自己**没有故意或者重大过失**的，**不承担赔偿责任**。

→ **有偿保管** = 一般过失即担责（**严格 + 谨慎勤勉**注意义务）
→ **无偿保管** = **仅故意 / 重大过失**担责（轻过失免责）

本题：
- **王某是无偿**保管（朋友间代管）
- 把古书放床下 = 正常保管方式（无重大过失）
- 水管冻裂是**意外** + 非王某控制
- → 无重大过失 → 不担责

### 怎么考 / 坑在哪

- **C 错点**：水管冻裂**不是不可抗力**（属意外事件）——不可抗力要求"不能预见、避免、克服"
  - 但即使不是不可抗力，王某也因无重大过失而免责
- **A/B 错**：未区分有偿 / 无偿——无偿保管对一般过失豁免

### 怎么答

D。无偿保管 + 无重大过失 → 免责。
