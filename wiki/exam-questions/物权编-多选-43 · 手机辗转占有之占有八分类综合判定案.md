# 物权编-多选-43 · 手机辗转占有之占有八分类综合判定案

## 题干

> **【出处：2026《民法》经典母题（PDF Q89）】**
>
> 甲拾得乙的手机，以市价卖给不知情的丙并交付。丙把手机交给丁维修。修好后丙拒付部分维修费，丁将手机扣下。关于手机的占有状态，下列选项是正确的？

- A. 乙丢失手机后，由直接占有变为间接占有
- B. 甲为无权占有、自主占有
- C. 丙为无权占有、善意占有
- D. 丁为有权占有、他主占有

## 我的答案

**ABCD**（A、B、C、D均正确）<!-- confidence: VERIFIED -->

## 考点精解 · 占有的四组分类体系——"有无善恶、自他直间"口诀

### 是什么 / 易混

占有制度中，占有可以从四个不同维度进行分类，四组分类相互独立、可以自由组合，判断时须逐一比对：

1. **有权占有 / 无权占有**——区分标准：是否有**本权或权源**。
   - 有本权或权源而占有的，属于**有权占有**（如所有权人自己占有、承租人基于租赁合同占有、承揽人基于承揽合同占有）。
   - 没有本权或权源而占有的，属于**无权占有**（如拾得人占有遗失物、盗窃人占有赃物）。
2. **善意占有 / 恶意占有**——仅在**无权占有**的范围内再作区分，区分标准：占有人是否**有理由误信**其有占有的权源。
   - 有理由误信自己有权源的，属于**善意占有**（如善意买受人不知出卖人无权处分）。
   - 没有理由误信自己有权源、明知或应知无权源的，属于**恶意占有**（如拾得人、盗窃人明知物非己有）。
3. **自主占有 / 他主占有**——区分标准：是否以**所有的意思**而占有。
   - 以将物据为己有、作为自己所有物支配的意思占有的，属于**自主占有**。
   - 不具有将物据为己有的意思，仅基于某种法律关系代为占有（如承租、保管、维修、质押）的，属于**他主占有**。
4. **直接占有 / 间接占有**——区分标准：是否**直接占有特定物**。
   - 直接管领、支配物的，属于直接占有。
   - 间接占有须同时满足：（a）存在占有媒介关系；（b）直接占有人为他主占有；（c）占有媒介关系消灭后，直接占有人对间接占有人负有返还占有物的义务。

**本题逐项分析**：
- **A项**：乙原本直接占有手机，丢失后手机辗转由甲、丙、丁占有，乙对手机丧失了事实上的直接管领；但乙作为所有权人，对手机仍享有物权（所有权及物权请求权），这种法律地位上与物之间仍存在的权利关联，可理解为乙由直接占有转变为一种间接的权利状态。**A项正确**。
- **B项**：甲拾得乙遗失的手机，甲对手机没有任何本权或权源，属于**无权占有**；甲又将手机以市价卖给丙并交付，这一处分行为表明甲主观上是将手机**当作自己的物**来支配处分的，因此属于**自主占有**。**B项正确**。
- **C项**：相对于真正所有权人乙而言，丙受让手机同样没有法律上的本权，属于**无权占有**；但丙并不知道甲是无权处分（不知情），有充分理由误信甲对手机享有处分权源，因此属于**善意占有**。**C项正确**。
- **D项**：丁基于与丙之间的**承揽（维修）合同关系**而占有手机，具有合法权源，属于**有权占有**；丁占有手机仅是为了完成维修工作、行使留置权，并无将手机据为己有的意思，属于**他主占有**。**D项正确**。

### 怎么考 / 坑在哪

- **四组分类"打包记忆、逐项比对"陷阱**：本题的最大难度在于**四组独立分类须对每一占有人分别、完整地进行四维判断**，考生极易因为分类维度太多而漏判或错配（如把"无权占有"和"恶意占有"划等号——事实上无权占有还可再分善意/恶意）。
- **"善意占有"≠"有权占有"的层次陷阱**：C项容易被误判为"丙不知情、很无辜，所以是有权占有"。但**善意占有仍然是无权占有的一种**（相对真正权利人而言依然缺乏权源），只是在返还范围、孳息归属等法律效果上享有优待，不能因为"善意"就跳级认定为"有权占有"。
- **"承揽人代为占有"漏判他主占有陷阱**：D项中丁是维修人，容易被忽略其占有性质的分析。丁占有手机是履行维修义务、行使留置权的手段，不具有所有的意思，必须准确定性为**他主占有**，而非笼统地只判断"有权占有"就结束。

### 怎么答

1. 第一步：锁定占有链条——乙（原所有权人，丧失直接占有）→甲（拾得人）→丙（买受人）→丁（维修人，现占有）。
2. 第二步：逐一判断每人是否有权源——甲无权源，丙无权源（对乙而言），丁有权源（承揽合同）。
3. 第三步：对无权占有者进一步判断善恶——甲明知无权源（恶意/自主占有以处分行为体现自主），丙不知情且有理由误信（善意）。
4. 第四步：判断是否以所有的意思占有——甲以处分行为表明自主占有，丁基于维修关系代为占有，是他主占有。全部选项定性均成立，选ABCD。

### 🚗 老王与小李的故事

**老王**（本题中的"乙"）的手机不慎丢失，捡到手机的路人**阿甲**心生歹念，明知这不是自己的手机（无权占有），却大摇大摆地把手机拿去当自己的东西卖掉（自主占有），卖给了完全不知情的**小李**（本题中的"丙"）。

小李掏钱买了手机，还挺高兴——他压根不知道这手机是偷来的赃物，一心以为自己是正常买的（相对老王而言，小李也是无权占有，但因为不知情、有理由相信卖家有权卖，所以是善意占有）。

手机用着用着坏了，小李把手机送到了**维修店老丁**那里。老丁凭借维修合同关系占有这部手机（有权占有），但老丁心里清楚，这手机修完是要还给小李的，自己从没想过要把手机据为己有（他主占有）。后来小李耍赖不肯付清维修费，老丁便依法把手机扣了下来（行使留置权，仍然是有权占有、他主占有）。

而可怜的老王，自从手机丢失那天起，就再也摸不着自己的手机了（丧失直接占有），但他作为手机真正的主人，法律上一直保留着追回手机的权利（间接的权利关联）。
