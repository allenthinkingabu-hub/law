# 刑法-总论-单选-38 · 数罪并罚之漏罪先并后减

## 题干

> 来源：法考真题改编 / 瑞达·厚大·众合高频题（已联网核验法条）

甲因盗窃罪被法院判处有期徒刑5年，判决宣告后甲被送监执行。在执行了2年时，司法机关发现甲在该盗窃判决宣告之前还实施过一起抢劫罪（未被判决），遂对抢劫罪判处有期徒刑8年。关于甲应当执行的刑罚，下列说法正确的是？

- A. 应先将盗窃罪余刑3年与抢劫罪8年并罚，在8年至11年间决定执行
- B. 应在盗窃5年与抢劫8年并罚（8年至13年）后决定一个总刑期，再减去已执行的2年
- C. 应直接执行抢劫罪8年，盗窃罪5年被吸收
- D. 应将盗窃5年与抢劫8年相加执行13年，再减去2年

## 我的答案

**B**<!-- confidence: EXTRACTED -->

抢劫罪实施于盗窃罪**判决宣告之前**，属于"判决宣告以前还有其他罪没有判决"的**漏罪**，适用《刑法》§70「先并后减」。

- **第一步 并**：将前罪**全部原判刑**5年与漏罪8年，按§69限制加重并罚——在总和刑期13年以下、数刑中最高刑8年以上，即 **8～13年** 区间酌情决定（总和13年<35年，不触20年顶格限制），假设法院决定 11 年。
- **第二步 减**：从决定的总刑期11年中减去**已经执行的2年**，甲实际还需执行 **9年**。

**A 错**：「盗窃余刑3年 + 抢劫8年」是「先减后并」即§71新罪的方法，混淆了漏罪与新罪——漏罪并罚对象是前罪**全部原判刑**（5年），不是余刑。

**C 错**：吸收原则只适用于死刑、无期徒刑（§69）。本题三罪均为有期徒刑，应适用限制加重，不能直接执行8年吸收盗窃。

**D 错**：13年是把两刑**单纯相加**的总和刑期。§69是「限制加重」——在最高刑以上、总和刑以下**酌定**一个刑期，并非把刑期相加执行。

## 考点精解 · 漏罪「先并后减」的两步计算

漏罪的识别关键：后被发现的罪行**实施于前罪判决宣告之前**——它本应在一审时一并审判，因漏判而后补，故并罚对象是前罪的**全部原判刑**。

```
【§70 漏罪 · 先并后减】
前罪盗窃 5年 ──┐
               ├─ 第①步【并】§69限制加重
漏罪抢劫 8年 ──┘   区间：最高刑8年 ≤ X ≤ 总和13年
                   决定总刑期 = 11年（示例）
                          │
                          ▼
                   第②步【减】减去已执行
                   11年 − 已执行2年 = 实际还需执行 9年
```

口诀映射：**先并**（并前罪全刑）→ **后减**（减已执行）。已执行的2年不会"白蹲"，它被计入最终决定的刑期内。
