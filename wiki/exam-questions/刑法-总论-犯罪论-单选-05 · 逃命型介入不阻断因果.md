# 刑法-总论-犯罪论-单选-05 · 逃命型介入不阻断因果

## 题干

> 来源：依据因果关系介入因素学理通说（关联《刑法》§14）命制的**仿真题**（题干为本库命制，非历年真题；最高检"可预见即附随、不中断"口径参见 https://www.spp.gov.cn/spp/llyj/201812/t20181210_402045.shtml ）。

甲持刀追杀乙，乙仓皇逃命、慌不择路冲上车流密集的快速路，被正常行驶的丙车撞死。关于甲的责任，下列正确的是？

- A. 丙车碰撞是独立介入因素，阻断因果关系，甲仅成立故意杀人未遂
- B. 乙横穿马路系甲追杀强行诱发，介入因素不异常、可预见，不阻断因果关系，甲对死亡负责（故意杀人既遂）
- C. 乙系自己冲上马路，属被害人自我答责，甲不负责
- D. 甲仅成立过失致人死亡罪

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正解为 B。乙横穿快速路是被甲持刀追杀"强行诱发"的逃命行为：①前行为（追杀）原因力强、直接制造致命险境；②介入（横穿马路、被撞）对追杀有高度附随性、属可预见范围，不异常；③故介入不中断因果关系。甲对致死有故意（持刀追杀），成立**故意杀人既遂**。

- A 错：介入（丙车碰撞）是被前行为追杀所诱发的附随结果，不具独立性、不异常，不阻断因果。
- B 对：逃命型介入可预见、不中断，甲对死亡负责，故意杀人既遂。
- C 错："被害人自我答责"要求被害人**自愿、自由**地决定承受风险；乙是被追杀被迫逃命，并非自愿冒险，不成立自我答责。
- D 错：甲持刀追杀有杀人故意，非过失，不能定过失致人死亡罪。

陷阱：①逃命型介入（被前行为诱发）不阻断；②"被害人自我答责"是高级干扰项——**逃命是被迫的，不是自愿自由的风险决定**。

## 考点精解 · 前行为"强行诱发"的介入不中断

判断逃命型介入，核心看介入是否被前行为"逼出来"：被追杀者横穿马路、跳楼、跳河，都是前行为强行诱发的可预见反应，不具异常性，因此不阻断因果。难点在于区分"被害人自我答责"——它要求被害人在自由意志下自主选择风险，而逃命是被迫的，不满足。

```
        逃命型介入三步判定
┌────────────────────────────────┐
│ ① 前行为原因力                 │
│   持刀追杀 → 制造致命险境        │
│   原因力强，直接逼出逃命         │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ ② 介入异常度 / 关联度           │
│   横穿快速路被撞 = 逃命的        │
│   附随后果，可预见、不异常        │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ ③ 介入对结果的作用力            │
│   丙车碰撞虽近因，但被追杀诱发   │
│   不能独立切断追杀的因果         │
└──────────────┬─────────────────┘
               ▼
        可预见 + 被诱发 ⇒ 不中断
        ⇒ 甲对死亡负责（故意杀人既遂）

   ┌─ 排除项：被害人自我答责 ─┐
   │ 须"自愿+自由"决定风险      │
   │ 逃命=被迫 → 不成立自我答责 │
   └────────────────────────┘
```
