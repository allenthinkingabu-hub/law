# 侵权-单选-08 · 用工责任-拳击馆免责协议因重大过失无效

## 题干

> 来源：2025 金题 2-1-29（众合）

甲报名参加拳击馆培训，拳击馆和甲签订了一份免责协议，除非拳击馆有故意或重大过失，否则不承担任何责任。拳击馆给甲分配了赵教练，赵教练安排甲和学员乙训练，没有做相应的安全措施，也没有铺防滑垫，甲滑倒摔伤。关于本案，下列说法正确的是？

- A. 拳击馆和乙承担连带责任
- B. 甲可以向乙主张承担赔偿责任
- C. 甲可以向拳击馆主张承担赔偿责任
- D. 甲可以主张拳击馆和赵教练承担赔偿责任

## 我的答案

**C**<!-- confidence: EXTRACTED -->

赵教练"未做安全措施、未铺防滑垫"属于**重大过失**，触发免责协议中的例外条款（"除非故意或重大过失"），故免责协议无效，拳击馆须承担责任（§1191 用人单位责任 + §506 免责条款无效规则）。赵教练是拳击馆员工，执行职务致损由拳击馆（用人单位）对外承担，不是甲直接向赵教练主张。

## 涉及考点

- **答题模型**：📐 [[民法-侵权-用工劳务与承揽人侵权模型]]
- [[侵权责任编]] §1191 用人单位责任
- 格式免责条款有效性：§506 造成人身损害的免责条款无效；本题是双方协商条款，但约定"故意/重大过失除外"，该例外保留了必要救济

## 考点精解 · 用工责任与免责协议

### 用工责任 §1191

| 主体            | 责任       | 说明                     |
| ------------- | -------- | ---------------------- |
| **用人单位**（拳击馆） | 对外承担替代责任 | 工作人员执行工作任务致损，由单位赔偿     |
| 工作人员（赵教练）     | 内部追偿     | 拳击馆赔偿后可向有故意/重大过失的赵教练追偿 |
| 乙（学员）         | 不承担      | 乙与甲同为学员，不是用工关系，乙无过错    |

### 免责协议分析

免责协议内容："除非故意或重大过失，否则不承担任何责任"。本案：赵教练未铺防滑垫 = **重大过失**（专业人员对基本安全措施的严重疏忽），触发例外，免责条款对该次事故无效 → 拳击馆须担责。

### 选项逐析

**A** 拳击馆和乙连带：错误。乙是同期学员，无过错，不参与连带责任。

**B** 甲向乙主张：错误。乙无过错，无责任。

**C** 甲向拳击馆主张：**正确**。§1191 用工责任 + 重大过失触发例外，拳击馆担责。

**D** 拳击馆和赵教练一起担：错误。§1191 规定用人单位对外承担，劳动者个人不对受害第三人直接负责（内部追偿除外）。
