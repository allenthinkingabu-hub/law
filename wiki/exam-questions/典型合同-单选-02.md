# C2-单选-02 · 试用买卖的使用费

## 题干

> 商场告示"家电试用 20 天，满意付款"。王某试用期满退回，商场要求付使用费 100 元。哪一种说法正确？

- A. 王某不应支付使用费，因为双方没有约定
- B. 没约定试用期 → 由买受人确定
- C. 王某应支付按平均寿命折算的使用费
- D. 试用期间未对质量异议 → 应购买

## 我的答案

**A**<!-- confidence: INFERRED -->

## 涉及考点

- [[试用买卖]]（§638-§641）
- 试用期间的费用约定规则

## 考点精解 · 试用买卖三规则

### 是什么 / 易混

**§638-§641**（试用买卖）：

| 规则 | 内容 | 法条 |
|---|---|---|
| 试用期 | **当事人约定** → 没约定 → **出卖人**确定 | §640 |
| 标的物风险 | 试用期间标的物**风险由出卖人**负担 | §640 |
| 期满未表示 | **视为购买**（默示购买） | §641 |
| 使用费 | 法律**未规定**——无约定则不付 | 学理 |

本题：
- A "没约定→不付使用费" → 对（**民法基本规则**：约定有偿才有偿）
- B "买受人确定试用期" → 错（应当由**出卖人**确定）
- C "按平均寿命折算" → 错（无法律依据）
- D "未对质量异议视为购买" → 错（题目王某**已退回** = 明确表示拒绝购买，§641 II 不适用）

### 怎么考 / 坑在哪

- **D 经典陷阱**：把"未对质量异议"和"未表示购买"混淆——本题王某**退回行为**已构成"拒绝购买"
- **A 是默认规则**：私法**无约定 = 自由 = 不付**

### 怎么答

A。无约定 + 王某明确退回 → 不付使用费。
