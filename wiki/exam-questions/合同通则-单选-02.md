# C1-单选-02 · 第三人代为履行的违约责任

## 题干

> 甲、乙双方约定，由丙每月代乙向甲偿还债务 500 元，期限 2 年。丙履行 5 个月后，以自己并不对甲负有债务为由拒绝继续履行。甲遂向法院起诉，请求乙、丙承担违约责任。下列哪一说法是正确的？

- A. 法院应判决乙承担违约责任
- B. 法院应判决丙承担违约责任
- C. 法院应判决乙、丙连带承担违约责任
- D. 法院应判决乙、丙分担违约责任

## 我的答案

**A**（乙承担违约责任）<!-- confidence: INFERRED -->

## 考点精解 · 第三人代为履行

### 是什么 / 易混

- **第三人代为履行**（§523）：当事人约定第三人**向债权人**履行债务，第三人**不履行**或**履行不符合约定**的，**债务人**应当向债权人承担违约责任
- 关键：第三人**不是合同当事人**，不构成合同相对性的例外
- 易混：与"第三人加入债务"、"债务承担"区分——后两者第三人才成为当事人

### 怎么考 / 坑在哪

- **常见错选 B**：以为"谁不履行谁担责"，但合同相对性下第三人非当事人，不直接对债权人担责
- **常见错选 C/D**：连带 / 分担需法律明文，本场景没有

### 怎么答

合同当事人是甲、乙，丙只是约定的代为履行第三人。丙拒履时，依 §523 由**债务人乙**承担违约责任。故选 **A**。

---

## 📐 答题口诀 · 第三人代为履行"谁担责"

> 凡是"约定第三人来履行 + 第三人不干"——**先问谁是合同当事人，违约责任就落在债务人头上**。

```
看到题干关键词                                  → 判断
"约定由第三人向债权人履行 / 代为偿还"            → 第三人代为履行（§523）
"第三人拒绝 / 不履行 / 履行不符合约定"           → 由【债务人】担违约责任 ★
"第三人不是合同当事人"                          → 不直接对债权人担责（合同相对性）
"判第三人 / 连带 / 分担担责"                     → 干扰项（无法律明文，不成立）
```

### 📋 4 选项陷阱解析

| 选项         | 判断  | 理由                               |
| ---------- | --- | -------------------------------- |
| **A 判乙担责** | ✅   | 乙是债务人，丙拒履 → §523 由乙对甲担违约         |
| B 判丙担责     | ❌   | 丙非合同当事人，不直接对债权人甲担责（最大陷阱"谁不干谁担责"） |
| C 乙丙连带     | ❌   | 连带须法律明文 / 当事人约定，本案没有             |
| D 乙丙分担     | ❌   | 同上，无分担依据                         |

### 🚗 老王小李故事

> 老王（债主）借钱给小李（债务人），俩人约定"**由小李的朋友老张每月替小李还 500 给老王**，还 2 年"。老张还了 5 个月突然不干了："我又不欠老王的，凭啥替小李还！"老王把老张和小李一起告了，要他俩担违约责任。
>
> 法院判谁？——**只判小李（债务人）**！老张压根不是老王、小李这份借款合同的当事人，他只是"被叫来还钱的手"（§523 由第三人履行）。老张撂挑子，违约责任落在**债务人小李**头上，不是老张（排除 B），更没有连带 / 分担那一说（排除 C、D）。
>
> 一句话：**"叫来帮忙还钱的人甩手不干，债务人自己顶。"**

### 🎯 一句话记忆

> **"第三人代为履行（§523）：第三人不是当事人；他不干，债务人担违约。判第三人 / 连带 / 分担都是坑。"**

### 填空模板（主观题用）

> 甲乙约定由丙**【代为向甲履行】**，丙**【非合同当事人】**；丙拒绝继续履行的，依《民法典》**【§523】**，由**【债务人乙】**向甲承担违约责任（A）；丙不直接担责（B 错），亦无**【连带 / 分担】**依据（C、D 错）。故选 **A**。
