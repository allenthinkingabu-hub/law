# 刑法-总论-单选-26 · 酌定减轻处罚的核准主体

## 题干

> 来源：法考真题改编 / 瑞达·厚大·众合高频题（已联网核验法条）

被告人丁犯非法经营罪，不具有任何法定减轻处罚情节，但案件有特殊情况，法院拟在法定刑以下判处刑罚。关于该减轻处罚的核准程序，正确的是？

- A. 由作出判决的中级人民法院自行决定即可
- B. 报请高级人民法院核准
- C. 报请最高人民法院核准
- D. 报请最高人民检察院核准

## 我的答案

**C**<!-- confidence: EXTRACTED -->

C：根据《刑法》第63条第二款，犯罪分子虽然不具有本法规定的减轻处罚情节，但根据案件的特殊情况，经**最高人民法院核准**，也可以在法定刑以下判处刑罚。可见，"酌定减轻处罚"的核准权专属于最高人民法院，本题应报请最高人民法院核准 ✓

A：酌定减轻属于突破法定刑的例外，作出判决的中级人民法院无权自行决定，必须层报至最高人民法院核准 ✗

B：高级人民法院同样无权核准酌定减轻处罚，§63第二款明确将核准权赋予最高人民法院，高级法院只是逐级上报的中间环节而非核准主体 ✗

D：核准主体是审判机关——最高人民法院，而非检察机关。最高人民检察院无核准酌定减轻处罚的职权，该选项主体错误 ✗

## 考点精解 · 法定减轻 vs 酌定减轻的核准差异

减轻处罚分两类，关键差别在于"有无法定减轻情节"以及"是否需要最高法核准"：

| 比较项 | 法定减轻（§63①） | 酌定减轻（§63②） |
| --- | --- | --- |
| 前提 | 具有法定减轻处罚情节 | **不具有**任何法定减轻情节 |
| 依据 | 法律规定的减轻情节 | 案件的特殊情况 |
| 核准程序 | 无须特别核准，法院依法判处 | **必须报请最高人民法院核准** |
| 核准主体 | —— | **最高人民法院**（专属） |

```
  无法定减轻情节 + 案件特殊情况  ──逐级上报──➔  最高人民法院核准  ──➔  方可在法定刑以下判处
              （中级/高级法院都无权自决，检察院也无核准权）
```

记忆锚点：**酌定减轻，唯最高法**——这是核准主体类考点的高频陷阱（常被错设为高级法院或检察院）。
