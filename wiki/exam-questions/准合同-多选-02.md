# C3-多选-02 · 餐馆上错菜的不当得利

## 题干

> 朱某在餐馆吃饭，服务员误将李某点的"佛跳墙"上给他，朱某**明知**仍吃完，导致李某因未及时上菜被餐馆免单。下列正确的是？

- A. 朱某的行为构成不当得利
- B. 餐馆有权请求朱某支付佛跳墙的价款
- C. 餐馆有权请求朱某支付免单而遭受的损失
- D. 餐馆有权请求朱某返还佛跳墙的价款，但不能请求朱某赔偿免单损失

## 我的答案

**ABC**<!-- confidence: INFERRED -->

## 涉及考点

- [[不当得利]] 构成（§985）
- **恶意得利人** 的赔偿责任（§987）
- §985 但书"**明知无义务而给付**"针对**给付者**，不针对受领者

## 考点精解 · 恶意得利人的全责返还

### 是什么 / 易混

**§985**（不当得利构成）：朱某明知是误上的菜仍吃完 → 获得佛跳墙利益 + 餐馆受损 + 无法律根据 → 构成不当得利

**§985 但书**只针对**给付方**（给付方明知无义务还给）——**餐馆**是给付方（误送），餐馆**不明知**，但书不适用。
**朱某是受领方** → 不能援引但书。

**§987**（恶意得利人责任）：
> 得利人**知道 / 应当知道**取得的利益**没有法律根据**的——受损失的人可以请求得利人**返还其取得的利益**并依法**赔偿损失**。

→ 朱某**明知** = 恶意得利人 → 返还佛跳墙价款 + **赔偿**餐馆免单损失。

本题对照：
- A 构成不当得利 → 对（§985）
- B 请求支付佛跳墙价款 → 对（返还得利）
- C 请求赔偿免单损失 → 对（§987 恶意得利人额外赔偿）
- D 不能赔偿免单损失 → 错（恶意得利人需赔偿）

### 怎么考 / 坑在哪

- **D 经典陷阱**：把不当得利限定为"仅返还得利"——错。**恶意得利人 §987 须额外赔偿**
- **善意 vs 恶意** 得利人区分：
  - 善意（§986）：返还**现存利益**
  - 恶意（§987）：返还**全部利益** + 赔偿损失

### 怎么答

ABC。朱某明知 = 恶意得利人 → 返还 + 赔偿。
