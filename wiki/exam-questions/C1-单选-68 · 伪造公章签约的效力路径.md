# C1-单选-68 · 伪造公章签约的效力路径

## 题干

> 甲用伪造的乙公司公章，以乙公司名义与不知情的丙公司签订食用油买卖合同，以次充好，将劣质食用油卖给丙公司。合同没有约定仲裁条款。关于该合同，下列哪一表述是正确的？

- A. 如乙公司追认，则丙公司有权通知乙公司撤销
- B. 如乙公司追认，则丙公司有权请求法院撤销
- C. 无论乙公司是否追认，丙公司均有权通知乙公司撤销
- D. 无论乙公司是否追认，丙公司均有权要求乙公司履行

## 答案

**B**（233 答案页下划线标注，来源：中国普法网）<!-- confidence: EXTRACTED -->

## 新法核对（2026 视角）

**答案不变（B）**。民法典 §171（无权代理追认）+ §148（欺诈撤销）同构。**新规衔接**：伪造印章签约按无权代理处理、本人不当然担责——与 2023 通则解释 §22 的"印章与合同效力分离"（看有无代表/代理权，不只看章）一脉相承。

## 涉及考点

- 📐 **答题模型** → [[民法-合同-效力待定模型]]（无权代理待定 + 可撤销叠加·状态视角）
- [[合同效力待定]] · 无权代理（§171）
- 印章与合同效力分离（通则解释 §22 思路的旧题源头）
- 效力待定与可撤销的**叠加**
- 📐 **答题模型** → [[民法-合同-追认模型]]（第五步"先追认定效力 → 再撤销方式：须诉讼 / 仲裁"演练题）

## 考点精解

- 第一层：伪造公章冒名签约 = **无权代理** → 合同对乙效力待定；乙追认 → 合同有效。
- 第二层：合同有效后，"以次充好"构成**欺诈** → 受欺诈方丙可撤销。
- **撤销方式**：撤销权须以**诉讼/仲裁**方式行使（无仲裁条款 → 法院），**不能"通知撤销"** → A、C 错，B 对。
- **D 错**：乙不追认则合同对乙不发生效力，谈不上要求履行。

## 📐 口诀

> **"假章 = 效力待定打底；追认后骗局现形 = 还能撤；但撤销要上法院，发函没用。"**
