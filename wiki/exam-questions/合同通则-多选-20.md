# C1-多选-20 · 银行保险柜协议：兼具租赁 + 保管的非典型合同

## 题干

> 甲与银行签订了一份保险柜使用协议，协议约定甲可以使用保险柜30年。其中，锁具及物品存取事宜由甲自行安排。3年后，甲死亡，甲的继承人请求银行返还物品。关于本案，下列说法正确的是？（2023金题-2-1-9）

- A. 该协议兼有租赁合同与保管合同的性质
- B. 银行可以拒绝返还
- C. 甲的继承人的请求应得到支持
- D. 该协议为仓储合同

## 我的答案

**AC**<!-- confidence: EXTRACTED -->（官方参考答案：AC）

- [[无名合同]]

## 考点精解 · 混合合同识别 + 继承

### 是什么 / 易混

- 保险柜使用协议：银行**出租柜位空间**（租赁特征）+ 为客户**保管财物安全**（保管特征），且锁具/存取由客户自行掌控 → **兼具租赁与保管性质的非典型（混合）合同**（A 对）。
- **D 仓储合同错**：仓储是保管人验收、登记、签发仓单的专业储存（§904），与"客户自管钥匙、自行存取"的保险柜不同。
- 甲死亡，合同权利由**继承人概括承受**，继承人有权请求返还柜内物品（C 对）；银行无正当理由不得拒绝（B 错）。

### 怎么考 / 坑在哪

- 把保险柜当成单纯"租赁"或单纯"保管"都不全面——它是**混合**。
- 误选 D 仓储：仓储有"仓单、专业验收"等硬指标，保险柜不具备。
- 继承人承受合同地位，请求返还应支持。

## 📐 答题口诀 · 保险柜 = 租赁 + 保管的混合体；继承人接棒

> **"租柜位 + 保安全 = 兼具两性；不是仓储；人没了，继承人接着要。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"保险柜/保管箱 + 自管钥匙自存取"             → 租赁+保管的混合（非典型）合同
"仓单 / 专业验收登记"                        → 才是仓储合同（本题没有）
"当事人死亡 + 继承人请求返还"                → 继承人概括承受，请求应支持
"银行可拒绝返还"                             → 无正当理由不可拒
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| **A** | ✅ | 出租柜位（租赁）+ 保管安全（保管）兼具 |
| B | ❌ | 银行无正当理由不得拒绝返还 |
| **C** | ✅ | 继承人概括承受，请求应支持 |
| D | ❌ | 无仓单/专业验收，非仓储合同 |

### 🚗 老王小李故事

> 老王在银行租了个保险柜用 30 年，钥匙自己管、东西自己存取。这柜子合同算啥？——一半是"**租**"（柜位空间），一半是"**保管**"（银行保安全），是个**混合**的非典型合同。它可不是"仓储"（仓储得有仓单、专业验收那一套）。老王 3 年后去世，儿子来要柜里的东西，银行能赖着不给吗？不能——儿子作为继承人接了老王的合同位子，要东西天经地义。
