# C1-多选-29 · 资不抵债把全部财产抵给一个债权人：无效/撤销 + 所有权未转移

## 题干

> 甲公司欠乙公司和丙公司的债务均无法全部偿还。甲公司名下还剩下一辆汽车和一套房屋，乙公司带着礼物去找甲公司说你干脆把房屋和汽车都抵押给我正好还我的债，不然也是被丙公司拿去了，甲公司想了想后同意签了抵押合同。甲公司到期后无法偿还，乙公司申请实现抵押权。关于本案，下列说法正确的有？（2019金题-2-1-12）

- A. 丙公司可以主张甲、乙公司之间的抵押合同因未登记而不发生效力
- B. 丙公司可以主张甲、乙公司之间的抵押合同无效
- C. 丙公司可以主张撤销甲、乙公司之间的行为
- D. 汽车和房屋的所有权依然归甲公司所有

## 我的答案

## 考点精解 · 偏颇担保的两条否定路径 + 抵押不转移所有权

### 是什么 / 易混

甲在**资不抵债**时，受乙游说（"别被丙拿去"）把**全部剩余财产**抵押给乙一个债权人，损害丙：

| 选项 | 判断 | 理由 |
|---|---|---|
| A 未登记不发生效力 | ❌ | **混淆合同效力与物权变动**：抵押合同**成立即生效**；未登记影响的是抵押权（物权）能否设立/对抗，不是合同效力 |
| **B 合同无效** | ✅ | 甲乙明知损害丙、**恶意串通损害第三人**（§154）→ 抵押合同无效 |
| **C 可撤销** | ✅ | 甲资不抵债时无偿/不当为既存债务提供担保、损害债权人丙 → **债权人撤销权**（§538/539）|
| **D 所有权仍归甲** | ✅ | **抵押不转移所有权**（抵押人保留所有权，仅设负担）|

> B 与 C 是两条**可选择**的否定路径（恶意串通无效 / 诈害债权撤销），本题认为均"有法律依据"。

### 怎么考 / 坑在哪

- **A 经典陷阱**：合同效力 ≠ 物权变动。抵押合同未登记仍**有效**，只是抵押权未设立（不动产）/不得对抗（动产）。
- 抵押**不转移所有权**（D 对）——别和"以物抵债/让与担保"混。

## 📐 答题口诀 · 抵押合同"未登记照样有效"；偏颇担保可无效/可撤销；抵押不夺所有权

> **"未登记 = 物权没设/不对抗，可合同有效（A 错）；坑别的债主 = 恶意串通无效 or 诈害债权撤销（B、C）；抵押只设负担、不转所有权（D）。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"抵押合同未登记 → 不发生效力"                 → 错（合同有效，物权未设）★
"资不抵债 + 受游说把全部财产抵给一个债主"      → 恶意串通无效（§154，B）/ 诈害债权撤销（§538，C）
"抵押后所有权归谁"                            → 仍归抵押人（不转移，D）
"恶意串通损害第三人"                          → 无效；"无偿/低价损害债权"→ 撤销
```

> 甲公司同时欠老乙、老丙的钱，都还不上，名下只剩一车一房。老乙拎着礼物上门："你把车和房都抵押给我，正好还我的，不然也便宜了老丙！"甲想了想签了。老丙能怎么反击？① 别拿"没登记所以合同无效"说事——抵押**合同照样有效**，没登记只是抵押权没设上（A 错）；② 甲乙明摆着合伙坑老丙，可主张**恶意串通无效**（B）；③ 也可走**债权人撤销权**撤掉（C）；④ 而且抵押**不转移所有权**，车和房还是甲的（D）。
