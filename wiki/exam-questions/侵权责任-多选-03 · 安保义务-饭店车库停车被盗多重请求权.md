# 侵权-多选-03 · 安保义务-饭店车库停车被盗多重请求权

## 题干

> 来源：2023 金题 2-1-29（众合）

谷某驾车到某饭店就餐，将车停放在该饭店专用的地下车库后取得停车票据一张，上面印有当日日期并载明：在本饭店消费达300元以上的，当日停车免费；未达到300元的，按每小时10元收取停车费。当日20时，谷某的车辆被常某盗走后转卖。对此，谷某有权作出下列哪些请求？

- A. 请求常某返还转卖所得
- B. 请求饭店承担侵权责任
- C. 请求饭店承担违约责任
- D. 请求饭店承担补充赔偿责任

## 我的答案

**ABCD**<!-- confidence: EXTRACTED -->

A（常某不当得利/侵权）：常某盗车后转卖，侵犯谷某所有权，盗窃行为同时构成侵权，谷某可请求返还转卖所得（不当得利§985 或侵权§1165）✓
B（饭店侵权责任）：饭店地下车库对停车客户负安保义务（§1198），违反安保义务的，承担侵权责任 ✓
C（饭店违约责任）：停车票据构成停车保管合同，车被盗属未能保管好，饭店违约 ✓
D（饭店补充赔偿责任）：具体侵权人是常某，饭店作为安保义务人，在常某财产不足赔偿时承担补充赔偿责任（§1198Ⅱ）✓

- **答题模型**：📐 [[民法-侵权-安全保障与教育机构第三人侵权模型]]
- [[侵权责任编]] §1198 安全保障义务与补充赔偿责任
- 停车合同保管义务（违约）

## 考点精解 · 安保义务三重请求权

### 为何 ABCD 都对

| 选项 | 对象 | 请求权基础 | 说明 |
|---|---|---|---|
| A | 常某 | 不当得利§985 / 侵权§1165 | 盗车转卖 → 返还所得 |
| B | 饭店 | 侵权§1198 | 安保义务违反 → 侵权赔偿 |
| C | 饭店 | 违约（停车保管合同） | 车未保管好 → 违约赔偿 |
| D | 饭店 | §1198Ⅱ 补充赔偿 | 第三人（常某）为主责，饭店安保义务人补充 |

### 重要区分：B（侵权）vs D（补充赔偿）

- **B 侵权责任**：直接依侵权路径主张，饭店独立承担
- **D 补充赔偿责任**：饭店是"第三人侵权+安保义务人未尽职"时的**第二顺位责任**（先追常某，不足时再追饭店）
- 本题 B/D 均成立，两种请求权可并存；实际执行中 D 更明确顺位

### 饭店能否用"车主承担风险"免责？

停车票据没有明确排除保管责任，"免费停车"条件不影响保管义务。饭店无法仅凭停车票据格式条款免除人身或财产损害赔偿责任（格式条款免责限制§497）。

## 📐 答题口诀 · 停车场车被盗的请求权

**关键词触发**：停车场 / 车被盗 / 第三人盗车转卖 / 安保义务

**🎯 一句话记忆**：
> 车库停车被盗：直接盗者（常某）→ 侵权/不当得利；车库（饭店）→ 违约 + 侵权 + 补充赔偿，三重请求权可并存。

**请求权全图**：
```
常某（盗车人）← 谷某 → 饭店（车库）
  ↑侵权/不当得利      ↑违约（B保管合同）
                      ↑侵权（C §1198）
                      ↑补充赔偿（D §1198Ⅱ，常某不足付时）
```
