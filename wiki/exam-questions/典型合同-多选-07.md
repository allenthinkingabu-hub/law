# C2-多选-07 · 不可作为保证人

## 题干

> 下列各种情形中，**不可以作为保证人**的是哪几项？

- A. 甲公司的董事长办公室
- B. 中国人民大学
- C. 北京市公安局
- D. 负债累累的张某

## 我的答案

**ABC**<!-- confidence: INFERRED -->

## 涉及考点

- [[保证合同]] 保证人资格（§683）

## 考点精解 · §683 不能作保证人的清单

### 是什么 / 易混

**§683**（保证人资格限制）：
- **机关法人不得**为保证人（**除非**国务院批准为使用外国政府或国际经济组织贷款进行转贷的）
- **以公益为目的**的非营利法人、非法人组织**不得**为保证人
- **营利法人的分支机构**：经法人**书面授权**可保证；**内设机构**不得为保证人

本题对照：
- A 董事长办公室 = **内设机构** → 不得为保证人 → 对
- B 中国人民大学 = **公益性事业单位**（教育）→ 不得 → 对
- C 北京市公安局 = **机关法人** → 不得 → 对
- D 负债累累的张某 = **自然人**，法律**未禁止** → 仍可作保证人（虽然清偿能力差但**法律不禁**）→ D 不入

### 怎么考 / 坑在哪

- **D 陷阱**：以为"负债累累 = 不可作保证人"——错。**清偿能力差 ≠ 没资格**
- 自然人资格只要有民事行为能力即可
