# 刑法-总论-犯罪论-单选-08 · 实行行为性与预备行为的界分

## 题干

> 来源：依据《刑法》第13条及实行行为学理通说命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

关于实行行为与危害结果，下列说法正确的是？

- A. 甲为杀乙而购买毒药、踩点摸清乙的作息——此时已具备侵害法益的紧迫危险，属实行行为
- B. 实行行为的本质是具有侵害法益的紧迫（现实）危险，以此区别于仅为犯罪制造条件的预备行为
- C. 只要发生危害结果，无论行为本身是否具有法益侵害危险，都成立既遂
- D. 危害结果不属于客观（违法）构成要件要素

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正确答案为 **B**。

- **B 正确**：实行行为的本质是具有**侵害法益的紧迫（现实）危险**的行为。正是这一"紧迫现实危险"标准，将实行行为（着手）与仅"为犯罪制造条件"的预备行为区分开来。
- **A 错误**：购买毒药、踩点摸清作息只是**为犯罪制造条件**，危险尚停留在抽象、遥远的程度，**未达紧迫现实**，属预备行为，尚未着手实行，不是实行行为。
- **C 错误**：结果归责须由**具有法益侵害危险的实行行为引起**并具有因果关系，才能将结果归于行为人；若行为本身无法益侵害危险，则结果不能归责，不能一概成立既遂。
- **D 错误**：危害结果是客观（违法）构成要件的"落点"，属于**客观/违法构成要件要素**。

**陷阱**：把预备行为的"抽象、遥远危险"误当作实行行为的"紧迫、现实危险"，从而把"踩点买药"错认作着手。

## 考点精解 · 预备行为 vs 实行行为对照表

| | 预备行为 | 实行行为 |
|---|---|---|
| 危险程度 | 抽象、遥远的危险 | 紧迫、现实的危险 |
| 功能 | 为犯罪制造条件 | 直接指向法益侵害（着手） |
| 典型例 | 买毒药、踩点、准备工具、守候 | 把毒药递到被害人嘴边、举刀砍向被害人 |
| 停止形态 | 既遂前可成立犯罪预备 | 着手后可成立未遂/既遂 |

```
危害行为
  ├─ 仅制造条件、危险抽象遥远 ──► 预备行为（买药/踩点：本题A）
  └─ 危险紧迫现实、直接侵害法益 ─► 实行行为=着手（本题B的标准）
                                      │
                          引起结果 + 因果关系 → 既遂（否则结果不归责，否定本题C）
```

> 危害结果定位：属客观（违法）构成要件要素（否定本题D）；结果出现不等于既遂，须由有危险的实行行为引起。
