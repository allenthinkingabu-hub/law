# C2-单选-12 · 客运合同的责任与免责

## 题干

> 关于客运合同，下列有关说法正确的是？

- A. 用过期学生证乘坐大巴拒补 → 承运人可拒载
- B. 免票小华被乘客撞伤 → 承运人**不**赔
- C. 火车上因自身健康原因受伤 → 承运人应赔
- D. 火车上隔壁乘客把热水浇笔记本电脑 → 承运人应赔

## 我的答案

**A**<!-- confidence: INFERRED -->

## 涉及考点

- [[客运合同]] 承运人责任范围（§815、§823、§824）
- 旅客自身原因 / 故意 / 重大过失的免责
- 📐 **答题模型** → [[民法-合同-运输合同模型]]

## 考点精解 · 客运合同 4 条核心规则

### 是什么 / 易混

| 规则                 | 法条   | 内容                                |
| ------------------ | ---- | --------------------------------- |
| ① 无票 / 越站 / 持失效票   | §815 | 应当补票，**不补 → 可拒运**                 |
| ② 旅客伤亡             | §823 | 承运人**严格责任**，例外：自身健康 / 旅客故意 / 重大过失 |
| ③ 免票 / 优惠票 / 经许可搭乘 | §824 | **同等责任**（与有票相同）                   |
| ④ 行李毁损             | §822 | 承运人**有过错**才担责                     |

本题对照：
- A 持过期学生证 = 持失效票 → 应补，不补可拒载 → 对（§815）
- B 免票小华被撞伤 → §824 同等责任（不因免票免责）→ 承运人**应担责** → 表述"不应承担"**错**
- C 自身健康 → §823 **免责** → 表述"应承担"**错**
- D 隔壁乘客倒水到电脑 → 承运人**无过错**→ §822 不担责 → 表述"应承担"**错**

### 怎么考 / 坑在哪

- **B 经典陷阱**：以为"免票就不担责"——错。**免票同等责任**
- **C 经典陷阱**：自身健康是**免责**事由——临场会反向理解
- **D 易错**：旅客随身物品毁损是**过错责任**，不是严格责任

### 怎么答

A。持失效票 → 补票，不补可拒载。
