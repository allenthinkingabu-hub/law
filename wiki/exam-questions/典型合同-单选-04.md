# C2-单选-04 · 供用电合同的履行地点

## 题干

> 供用电合同的履行地点，按当事人约定；没有约定或约定不明确的，履行地点为？

- A. 供电人营业地
- B. 用电人所在地
- C. 供需双方的中间地
- D. 供电设施的产权分界处

## 我的答案

**D**<!-- confidence: EXTRACTED -->

## 涉及考点

- [[供用电合同]] 的法定履行地点（§651）

## 考点精解 · 供用电履行地点

### 是什么 / 易混

**§651**（供用电合同履行地点的法定推定）：
> 供电人和用电人对供电设施的产权分界处不明确的，按供电设施的产权分界处确定。供电、用电的双方当事人没有约定履行地点的，**履行地点为供电设施的产权分界处**。

→ 产权分界处 = **谁的设施谁负责**的分界，是供电技术与法律责任的**关键节点**。

**类比**：供用水 / 供用气 / 供用热力 履行地点也均默认产权分界处。

### 怎么考 / 坑在哪

- **A 易错**："营业地"是借款 / 保管的默认地，不是供用电
- 记住"**产权分界处**"——供电四兄弟（电 / 水 / 气 / 热）通用

### 怎么答

D。法定默认 = 产权分界处。
