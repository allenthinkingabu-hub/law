# C1-单选-17 · 代位权可行使的对象（专属债权排除）

## 题干

> 甲对乙享有 10 万元借款债权已到期。乙怠于行使的下列权利中，甲**有权代位行使**的是（ ）。

- A. 乙因医疗事故受到伤害对医院享有的 50 万元损害赔偿请求权
- B. 乙所在单位欠付的基本工资 8 万元
- C. 乙基于与他人的合伙合同享有的 5 万元利益分配请求权
- D. 乙因房屋被征收拆迁获得的 10 万元安置费

## 我的答案

**C**（合伙利益分配 = 纯财产性债权，可代位；A/B/D 均专属不可代位）<!-- confidence: INFERRED -->

## 涉及考点

- [[代位权]] 的**消极限制**：专属于债务人自身的债权**不可代位**（§535 但书）
- 专属清单（人身 / 生存 / 身份性）vs 纯财产性债权
- 进阶：人格权**已到期的财产收益**（肖像许可费）已"财产化"→ 可代位（见 [[合同通则-多选-08]]）

## 考点精解 · 代位权的对象限制（专属排除）

### 是什么 / 易混

**§535**：债权人可代位行使债务人对相对人的债权 / 与债权有关的从权利——**但专属于债务人自身的除外**。

**不可代位的专属债权（"保命钱"四类）**：

| #   | 类型                                      | 本题对应                      |
| --- | --------------------------------------- | ------------------------- |
| ①   | **身份关系**（赡养 / 抚养 / 扶养 / 继承请求权）          | —                         |
| ②   | **人身损害赔偿**请求权                           | **A**（医疗事故 50 万）          |
| ③   | **劳动报酬 / 退休金 / 养老金 / 抚恤金 / 安置费 / 人寿保险** | **B**（基本工资）· **D**（拆迁安置费） |
| ④   | 其他**生存 / 人格性**密切相关债权                    | —                         |

→ **A 人身损害、B 基本工资、D 安置费 = 专属（保人身 / 活命 / 住房）→ 不可代位**
→ **C 合伙利益分配 = 纯财产性债权 → 可代位** ✓

### 怎么考 / 坑在哪

- **错选 B**：以为"工资也是债权就能代位"——错，**基本工资**是生存保障，专属。
- **错选 D**：以为"安置费是普通钱"——错，是**居住保障**，专属。
- **判断诀窍**：看这笔钱现在**是不是"纯财产"**——跟人身 / 活命 / 住房 / 身份绑的 = 专属；纯赚来的（合伙分红 / 货款 / 租金）= 可代位。
- **进阶（多选-08）**：人格权"商业化"产生、**已到期的财产收益**（肖像许可费）已变成"赚到的钱"→ **可代位**。

### 怎么答

只有 C 是纯财产债权、不属专属。故选 **C**。

## 📐 答题口诀 · 代位权专属排除"保命钱不可代位"

> **跟"人身 / 活命 / 住房 / 身份"绑的钱（人身赔偿、工资、退休金、抚恤金、安置费、赡养费）= 债务人的保命钱，专属不可代位；纯赚钱的财产债权（合伙分红、货款、租金、普通借款）才能代位。**

### 关键词触发表

```
看到题干"债务人怠于行使的这笔钱是……"           → 能不能代位
"人身损害 / 医疗事故 / 人身伤害赔偿"            → 专属，不可代位 ✗
"基本工资 / 退休金 / 养老金 / 抚恤金 / 安置费"    → 生存保障，专属，不可代位 ✗
"赡养费 / 抚养费 / 扶养费 / 继承"              → 身份性，专属，不可代位 ✗
"合伙分红 / 货款 / 租金 / 利益分配 / 普通借款"    → 纯财产债权，可代位 ✓
"已到期的肖像 / 姓名许可费"                    → 已财产化，可代位 ✓（见多选-08）
```

### 📋 4 选项陷阱解析

| 选项               | 判断        | 性质                  |
| ---------------- | --------- | ------------------- |
| A 医疗事故 50 万损害赔偿  | ❌ 不可代位    | **人身损害赔偿**（专属）      |
| B 基本工资 8 万       | ❌ 不可代位    | **劳动报酬 / 生存保障**（专属） |
| **C 合伙利益分配 5 万** | ✅ **可代位** | **纯财产性债权**          |
| D 拆迁安置费 10 万     | ❌ 不可代位    | **居住 / 生存保障**（专属）   |

→ 选 **C** ✅

### 🚗 老王小李故事

> 老王卖车给小李，小李欠老王 **10 万**车款（老王 = 债权人，小李 = 债务人）。小李自己手里有好几笔别人欠他的钱，可他**怠于去要**。老王想替小李把这些钱要回来抵债——哪些能要？
>
> - 小李出车祸，肇事方赔他 **50 万人身损害赔偿** → 补小李**身体受的苦**，专属小李，老王**不能**代位（A✗）。
> - 小李单位欠他 **8 万基本工资** → 小李的**活命口粮**，生存保障，老王**不能**代位（B✗）。
> - 小李合伙开店该分他 **5 万利润** → **纯赚钱的财产收益**，跟人身无关，老王**能**代位（C✓）。
> - 小李家拆迁给他 **10 万安置费** → 保障小李**有地方住**，专属，老王**不能**代位（D✗）。
>
> 诀窍：跟"人身 / 活命 / 住房"绑的钱是小李的**保命钱**，老王的手伸不进去；只有小李**纯赚来的钱**老王才能代位去要。

### 🎯 一句话记忆

> **"保命钱（人身赔偿 / 工资 / 退休金 / 抚恤金 / 安置费 / 赡养费）专属不可代位；赚钱债（合伙分红 / 货款 / 租金）才能代位。"**

### 填空模板（主观题用）

> 甲对乙有 10 万到期债权 + 乙怠于行使 → 甲可代位，但**【专属于债务人自身】**的债权除外（§535 但书）。A 人身损害赔偿、B 基本工资、D 安置费均属**【人身 / 生存保障性债权】**（专属，不可代位）；唯 C 合伙利益分配是**【纯财产性债权】**（可代位）。故选 **C**。

### 横向真题对照

- 本题（单选-17）= 专属债权**排除**（人身赔偿 / 工资 / 安置费不可代位，合伙分红可代位）→ C
- [[合同通则-多选-08]] = 代位权专属排除（**已到期肖像费"已财产化"可代位**）→ ABC
- [[合同通则-单选-18]] = 代位对象含**从权利（抵押权）** → B
- [[合同通则-多选-09]] = 代位权诉讼**抗辩 + 受偿** → ABCD
- [[合同通则-单选-51]] = 代位"以债权人债权为限"取小 → C
- → 本题考"对象的**消极限制（专属排除）**"，与 单选-18"对象的**积极扩展（从权利）**"正好一体两面；代位权 ★★★★★ 必考（通则解释§36），与 [[撤销权]] 并称"保全双子星"。
