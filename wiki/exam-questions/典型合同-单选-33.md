# C2-单选-33 · 混合担保：先就债务人自己的物保

## 题干

> 甲公司与乙公司经常有业务往来，甲公司虚构与乙公司的应收账款，质押给丙公司融资并办理了质押登记手续。同时，丁公司提供保证。经查，丙公司曾向乙公司发函确认该笔应收账款，乙公司认可其真实性。现甲公司到期无法偿还丙公司的债务。关于担保的实现，下列说法正确的是？

- A. 丙公司只能请求丁公司承担保证责任
- B. 应收账款质押权未设立
- C. 丙公司应当先就应收账款实现担保
- D. 丙公司可以同时实现债权质押权和保证

## 答案

**C**（法考通说 / 命题意图）<!-- confidence: 法理多源核验·机构金题无官方key·B承载真实学理争议 -->

## 出处与来源

- 出处：2023金题-2-1-20（机构模拟金题）
- 素材：[[2026-06-10-典型合同保证合同真题]]
- 法条依据：《民法典》§392（混合担保：债务人自己提供物保的，债权人应先就该物保受偿）· §440(六)/§445（应收账款属可出质权利·质押**登记设立**）· **担保制度解释§61**（①次债务人向质权人**确认真实性后**，不得再以"应收账款不存在/已消灭"抗辩＝**禁止反言**；②未确认时质权人须**举证登记时真实存在**，仅凭登记不够；③次债务人已向原债权人履行的，质权人不得再请求其履行）

## 涉及考点

- [[保证合同]] 与 [[物权编]] 担保物权的**混合担保实现顺序** §392
- 出质的应收账款是**债务人甲自己**对乙的债权 → **债务人自身物保优先**
- 虚构应收账款经债务人乙**发函确认** → 质权**设立**（善意保理/质押人受保护）

> 📐 **解题套路** → [[民法-合同-保证模型]] 第五步（混合担保：**债务人自己物保先实现** §392）；应收账款质押（§445 登记设立）细节 → [[民法-物权-担保物权模型]] 第四步

## 考点精解

- **C 对**：应收账款（甲对乙的债权）是**债务人甲自己提供的物保** → §392 债权人丙应**先就该物保**受偿。
- **B 错（应试口径·但为最强干扰项）**：虽系虚构，但乙已向丙**确认真实性** → 依担保解释§61① **禁止反言**，乙不得再以"不存在"对抗丙 → 对善意的丙质权**可主张、可实现**（已办登记§445）。⚠️ **此项承载真实学理争议**，见下方 ⚖️。
- **A 错**：丙不是"只能找保证人丁"——还有债务人自己的物保，且§392 下应**先就之**实现，A 把路径写死且方向反了。
- **D 错**：债务人自身物保**强制先序**（§392），不能"同时"任意实现、绕开顺序（"择一/并行"只适用第三人物保）。

## ⚖️ 争议与新旧法（C 是通说，但 B 不是全无道理）

> **争点**：甲**虚构**的应收账款，经乙确认后，质权到底**设立 / 可实现没有**？这决定选 B 还是 C。

| 学说 | 主张 | 依据 | 评价 |
|---|---|---|---|
| **通说 / 命题意图（→ C）** | 乙确认真实性 → **禁止反言**，对善意丙质权可实现；叠加 §392 债务人自己物保先实现 | 担保解释§61① + §445 + §392 | **法考采此**——§61① 本就是**专为打击"虚构应收账款"而设** |
| **否定说（→ B）** | 应收账款虚构 = 质物自始不存在，"皮之不存毛将焉附"，**质权自始未设立**，不适用善意取得 | 天同律所《虚假应收账款质押探析》 | 该文**成于担保解释§61 出台前**，未纳入"确认禁反言"，现行法下不采 |
| **限缩说（C 打折扣）** | §61① 只排除"**真实性**"的事实抗辩，**非票据式无因性**；乙仍可主张付款条件未成就 / 抵销等**权利抗辩**，"确认 ≠ 必然担责" | 全国律协 / 知乎《§61 适用范围》 | C 的"先就应收账款实现"以实际能受偿为前提，**严格学理上有保留** |

- 🕰️ **新旧法**：本题"虚构 + 确认"情节是**专为考担保解释§61（2021 新规）而设**。旧法（无 §61）下倾向 **B**（虚构→质权未成立）；现行法下因乙确认 → **C**。**务必用现行法作答 = C。**

## 🎯 针对演练（吃透"先判设立、再排顺序"两层）

> **解题两步框架**：
> **第一步 · 质权设立 / 可实现吗？**（§445 登记 + 担保解释§61：①次债务人**确认**→禁反言、可对抗；②**未确认**→质权人须举证登记时真实存在，仅凭登记不够；③次债务人**已向原债权人履行**→质权落空）
> **第二步 · 设立了，按谁的物保排顺序？**（§392：**债务人自己**物保→**强制先物后人**；**第三人**物保 vs 保证→**择一**，不分先后）

**变式①（顺序维度·换成第三人物保）**：甲向丙借款，**丁以丁自己对乙的真实应收账款**出质（已登记、乙确认），另有戊提供保证，甲到期不还。丙怎么实现？
→ **可择一**：就丁的应收账款质权 / 或请求戊担保，**不分先后**（丁是**第三人**物保，与保证地位平等，§392）。⚠️ 与本题（甲自己出质 → 强制先物保）正相反。

**变式②（设立维度·乙未确认且确系虚构）**：甲虚构对乙的应收账款出质给丙、办了登记，但**乙从未确认**真实性，事后查明登记时该账款**根本不存在**。丙主张就应收账款优先受偿？
→ **不支持**：§61② 未确认时，质权人须**举证登记时应收账款真实存在**，仅凭"已登记"不够 → 这块物保落空，丙只能转向保证人丁。

**变式③（设立维度·账款真实，剔除虚构干扰）**：应收账款**真实存在**、已登记，甲（债务人）自己出质 + 丁保证。
→ 质权正常设立（§445）；债务人自己物保 → **§392 先就应收账款、不足再找丁**（＝本题 C 的"纯净版"，说明 C 的内核是 §392，"虚构 / 确认"只是设立层的干扰）。

**变式④（§61③ · 次债务人已履行）**：甲以对乙的应收账款出质给丙并登记，但在丙**通知乙向丙履行之前**，乙已向**甲**（原债权人）清偿完毕。丙再请求乙向自己履行？
→ **不支持**：§61③ 次债务人接到质权人要求向其履行的通知**前**已向原债权人履行的，丙不能再请求乙履行 → 质权落空（除非乙**接到通知后仍**向甲履行）。

> 📌 **一句话**：本题是"**两层叠加**"——先用 §445 / §61 判**质权能不能实现**，再用 §392 判**先物保还是先保证**；命题人用"虚构 + 乙确认"专测 §61①，用"债务人自己出质"专测 §392 先物后人。

## 📐 口诀

> **"债务人自己押的物，债主先吃这块（§392）；虚构应收账款但对方确认了 → 质权照设；保证人垫底。"**
