# C1-单选-56 · 面包券（不记名不挂失）：无记名债权凭证，善意持券人可兑付

## 题干

> 甲、乙两公司签订协议，约定甲公司向乙公司采购面包券。双方交割完毕，面包券上载明"不记名、不挂失，凭券提货"。甲公司将面包券转让给张某，后张某因未付款等原因被判处合同诈骗罪。面包券全部流入市场。关于协议和面包券的法律性质，下列哪一表述是正确的？（2015-3-12）

- A. 面包券是一种物权凭证
- B. 甲公司有权解除与乙公司的协议
- C. 如甲公司通知乙公司停止兑付面包券，乙公司应停止兑付
- D. 如某顾客以合理价格从张某处受让面包券，该顾客有权请求乙公司兑付

## 我的答案

**D**（无记名有价证券，善意有偿持券人有权凭券兑付）<!-- confidence: EXTRACTED -->（官方参考答案：D）

## 涉及考点

- [[债]]
- [[买卖合同]]

## 考点精解 · 无记名有价证券的性质与流通

### 是什么 / 易混

- 面包券"**不记名、不挂失、凭券提货**" = **无记名（不要式）债权凭证 / 有价证券**：它代表的是**请求乙公司交付面包的债权**，**不是物权凭证**（A 错——物权凭证如提单、仓单代表对特定物的支配；面包券只是请求提货的债权）。
- 无记名证券**随交付而流通**：善意、有偿受让的持券人取得证券权利 → 顾客可请求乙兑付（D 对）。

### 怎么考 / 坑在哪

- **C 错**：正因"**不记名、不挂失**"，乙公司**不能**因甲的通知就停止兑付——谁持券谁有权，挂失止付与其性质矛盾。
- **B 错**：甲乙间采购协议已"交割完毕"，甲无法定/约定解除事由，无权解除。
- 张某虽因诈骗被判刑（刑事），但**不影响善意第三人凭无记名证券取得的兑付权利**（民刑分离 + 证券流通保护）。

### 怎么答

面包券是无记名债权凭证，善意持券人可兑付 → 选 **D**。

> **"凭券提货、不记名不挂失 = 认券不认人；谁善意拿着谁能兑，卖券人想'止付'？没门。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"不记名、不挂失、凭券提货/兑付"               → 无记名债权凭证（有价证券），认券不认人 ★
"面包券/提货券是物权凭证"                     → 错（是债权凭证，非提单/仓单类物权凭证）

"善意有偿受让持券人请求兑付"                   → 有权（证券流通保护）
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 物权凭证 | ❌ | 是债权凭证（请求提货），非物权凭证 |
| B 甲可解除 | ❌ | 已交割完毕，无解除事由 |
| C 通知停付 | ❌ | 不记名不挂失，不能止付 |
| **D 顾客可兑付** | ✅ | 善意有偿持券人取得证券权利 |
