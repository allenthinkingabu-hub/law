# 刑法-总论-犯罪论-单选-03 · 先前行为与真正不真正不作为犯

## 题干

> 来源：依据《刑法》第13条、第261条及不作为犯学理通说命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

关于不作为犯，下列哪一选项是正确的？

- A. 甲正当防卫将持刀抢劫的乙打成重伤倒地，甲径自离去致乙失血死亡——甲必然成立不作为的故意杀人罪
- B. 母亲甲对出生婴儿乙拒不哺乳、意图使其饿死，乙死亡——甲成立不真正（不纯正）不作为犯（不作为的故意杀人）
- C. 遗弃罪是不真正（不纯正）不作为犯的典型
- D. 先前行为必须具有违法性，合法行为一律不能成为作为义务来源

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正确答案为 **B**。

- **B 正确**：母亲对新生婴儿负**法定抚养义务**，本应以作为（哺乳）方式履行。其以**不作为**（拒不哺乳）方式实现了通常由作为构成的故意杀人罪，属于**不真正（不纯正）不作为犯**——即用不作为去实现一个分则未限定行为方式的犯罪。
- **A 错误**：正当防卫能否成为先前行为有争议，通说倾向认为防卫人对不法侵害人**一般不负**救助义务（被害人自陷风险）。即便有争议，"**必然**成立"的绝对化表述也是错误的。
- **C 错误**：遗弃罪（§261）是刑法**分则明文规定、只能由不作为构成**的犯罪，属于**真正（纯正）不作为犯**的典型，而非不真正不作为犯。
- **D 错误**：通说**不以**先前行为具有违法性/过错为前提，**合法行为亦可**成为作为义务来源（参见 [[刑法-总论-犯罪论-单选-01 · 不作为犯的作为义务来源辨析]] 的 A 项）。

**陷阱**：①真正/不真正不作为犯张冠李戴——遗弃罪是"真正"，不是"不真正"；②"先前行为须违法"是错误命题。

## 考点精解 · 真正 vs 不真正不作为犯对照表

| | 真正（纯正）不作为犯 | 不真正（不纯正）不作为犯 |
|---|---|---|
| 含义 | 刑法分则**只能**由不作为构成的犯罪 | 用**不作为**去实现通常由作为构成的犯罪 |
| 罪名是否限定行为方式 | 是（法条本身要求不作为） | 否（罪名不限方式，作为/不作为皆可） |
| 典型例 | 遗弃罪、拒不支付劳动报酬罪、不解救被拐卖妇女儿童罪 | 母亲不哺乳致婴儿死亡（不作为故意杀人）、不作为放火 |
| 本题对应 | C 项（遗弃罪）→ 误标为"不真正"故错 | B 项（母亲不哺乳）→ 正确 |

```
犯罪能否只由不作为构成？
  ├─ 只能不作为（法条限定）────► 真正不作为犯（遗弃罪）
  └─ 作为/不作为皆可（如杀人）─► 以不作为实现 → 不真正不作为犯（母亲不哺乳）
```

> 先前行为补充规则：①不以违法/过错为必要（合法行为亦可）；②对正当防卫造成的不法侵害人，防卫人通说一般不负救助义务。
