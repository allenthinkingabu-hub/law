# 刑法-总论-单选-43 · 缓刑考验期的计算与起算

## 题干

> 来源：依据《刑法》第73条命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

甲犯罪被判处拘役4个月并宣告缓刑；乙犯罪被判处有期徒刑10个月并宣告缓刑。关于二人缓刑考验期，下列哪一选项正确？

- A. 甲的考验期可以是3个月
- B. 甲的考验期可以是1年2个月
- C. 乙的考验期可以是1年
- D. 乙的考验期可以是6年

## 我的答案

**C**<!-- confidence: EXTRACTED -->

依《刑法》第73条：拘役的缓刑考验期为**原判刑期以上1年以下，但不能少于2个月**；有期徒刑的缓刑考验期为**原判刑期以上5年以下，但不能少于1年**；缓刑考验期限，从判决确定之日起计算。

C项乙判有期徒刑10个月，考验期1年：≥原判10个月、≤上限5年、≥下限1年，三重条件全部满足，正确。

逐项解析：
- A项：甲判拘役4个月，考验期须"原判刑期以上"，即≥4个月。3个月＜4个月，违反"原判刑期以上"，错。
- B项：拘役考验期上限为1年。1年2个月＞1年，超出上限，错。
- D项：有期徒刑考验期上限为5年。6年＞5年，超出上限，错。

## 考点精解 · 考验期"三重夹逼"

缓刑考验期的合法区间，要同时满足三个约束，少一个都不合法：

| 原判刑种 | 下限（不少于） | 区间 | 上限 |
|---|---|---|---|
| 拘役 | 2个月 | **原判刑期 ≤ 考验期 ≤ 1年** | 1年 |
| 有期徒刑 | 1年 | **原判刑期 ≤ 考验期 ≤ 5年** | 5年 |

三重夹逼公式：`max(原判刑期, 法定下限) ≤ 考验期 ≤ 法定上限`

本题验证：
```
甲 拘役4个月：合法区间 = max(4个月,2个月)=4个月 ～ 1年
   A 3个月 ✗（<4个月）   B 1年2个月 ✗（>1年）
乙 有期10个月：合法区间 = max(10个月,1年)=1年 ～ 5年
   C 1年 ✓               D 6年 ✗（>5年）
```

**起算点**：从**判决确定之日**起计算（不是宣判之日、不是交付执行之日）。
