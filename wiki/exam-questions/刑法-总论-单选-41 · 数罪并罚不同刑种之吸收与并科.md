# 刑法-总论-单选-41 · 数罪并罚不同刑种之吸收与并科

## 题干

> 来源：依据《刑法》第69条第3款命制的**仿真题**（题干为本库命制，非历年真题；徒刑吸收拘役、管制刑后并科规则已联网核验）。

丁在判决宣告以前犯有三罪：A罪判处有期徒刑3年，B罪判处拘役5个月，C罪判处管制2年。关于对丁的数罪并罚，下列说法正确的是？

- A. 三刑相加，执行有期徒刑3年+拘役5个月+管制2年
- B. 拘役、管制均被有期徒刑吸收，只执行有期徒刑3年
- C. 有期徒刑与拘役择一重执行有期徒刑3年；有期徒刑执行完毕后，管制2年仍须执行
- D. 先执行拘役5个月，再执行有期徒刑3年，最后执行管制2年

## 我的答案

**C**<!-- confidence: EXTRACTED -->

三罪均在判决宣告以前，适用《刑法》§69第二款关于**不同刑种**并罚的规则。关键是同样面对"有期徒刑 + X"，拘役与管制待遇不同：

- **有期徒刑 + 拘役**：§69明定"数罪中有判处有期徒刑和拘役的，**执行有期徒刑**"——拘役被有期徒刑**吸收**，B罪拘役5个月不再单独执行，只执行有期徒刑3年。
- **有期徒刑 + 管制**：§69明定"有判处有期徒刑和管制、或拘役和管制的，**有期徒刑、拘役执行完毕后，管制仍须执行**"——管制无法在监内执行，采**并科**，先把有期徒刑3年执行完毕、刑满后再执行管制2年。

**A 错**：拘役被有期徒刑吸收，不能相加；三刑相加本身也违反§69的并罚规则。

**B 错**：管制并非被吸收——它须在有期徒刑执行完毕后**单独续行**，不是不执行。

**D 错**：拘役应被吸收（不执行），D却把拘役单独执行了；且把管制放进监内同段执行，顺序也错。

## 考点精解 · 「徒刑吸收拘役，管制后续执行」

§69对**主刑刑种不同**时的并罚，不是限制加重，而是按刑种轻重定吸收或并科。核心区别：**拘役**与有期徒刑同属剥夺自由的监禁刑，可被吸收；**管制**是限制自由的非监禁刑，性质不同无法同时执行，只能刑后续行（并科）。

```
【§69第二款 · 不同刑种并罚】
A 有期徒刑 3年 ┐
              ├─ 徒刑 vs 拘役 → 吸收：拘役被吃掉，不执行
B 拘役 5个月  ┘
                       │ 执行有期徒刑3年
                       ▼ （3年监内服刑期间，拘役5月不另算）
                  徒刑执行完毕
                       │
                       ▼
C 管制 2年 ──── 并科：刑满出狱后，再执行管制2年
                       
执行链：有期徒刑3年 ─▶（刑满）─▶ 管制2年；拘役5月被吸收
```

记忆抓手：**拘役被吸收（不执行）、管制要并科（刑后续执行）**——同样的"有期徒刑+"，结局相反。
