# 刑法-总论-单选-52 · 追诉时效之法定最高刑与时效中断

## 题干

> 来源：**真实真题** · 2016年国家司法考试卷二第10题（多源交叉核验：华律网 https://m.66law.cn/laws/363354.aspx 、新浪教育 http://edu.sina.com.cn/zgks/2016-09-27/doc-ifxwevmf2346414.shtml 、司法部参考答案）。

关于追诉时效，下列哪一选项是正确的？

- A. 《刑法》规定，法定最高刑为不满5年有期徒刑的，经过5年不再追诉。危险驾驶罪的法定刑为拘役，不能适用该规定计算危险驾驶罪的追诉时效
- B. 在共同犯罪中，对主犯与从犯适用不同的法定刑时，应分别计算各自的追诉时效，不得按照主犯适用的法定刑计算从犯的追诉期限
- C. 追诉时效实际上属于刑事诉讼的内容，刑事诉讼采取从新原则，故对刑法所规定的追诉时效，不适用从旧兼从轻原则
- D. 刘某故意杀人后逃往国外18年，在国外因伪造私人印章（在我国不构成犯罪）被通缉时潜回国内。4年后，其杀人案件被公安机关发现。因追诉时效中断，应追诉刘某故意杀人的罪行

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正解为 B。追诉时效**个别计算**：共同犯罪中各共犯按**各自实际适用的法定刑**分别计算追诉期限，不能一律按主犯的法定刑去算从犯。

- A 错：§87 第①项"法定最高刑为**不满 5 年有期徒刑**"在解释上**涵盖法定最高刑为拘役、管制**的情形。危险驾驶罪法定刑为拘役，正属此档，追诉期为 5 年，并非"不能适用"。
- B 对：追诉时效个别计算，共犯分别按各自法定刑档计算。
- C 错：《关于〈中华人民共和国刑法〉施行后追诉时效适用问题的解释》明确追诉时效适用"**从旧兼从轻**"原则，并非从新。
- D 错：§89 时效中断要求"又犯罪"的是**触犯中国刑法之罪**；伪造私人印章在我国不构成犯罪，不引起中断。（本案故意杀人本可走 §88"逃避侦查/不受期限限制"路径，但 D 的错误在于"**中断**"这一错误归因。）

## 考点精解 · 四个高频陷阱

| 选项  | 命题人挖的坑      | 正解法理                             |
| --- | ----------- | -------------------------------- |
| A   | 拘役/管制"没有时效" | "不满5年有期徒刑"**含**拘役、管制，按 **5 年**追诉 |
| B   | 共犯一律按主犯算    | 时效**个别计算**，各按**各自法定刑**分别算 ✅      |
| C   | 时效是程序法、从新   | 解释定为**从旧兼从轻**                    |
| D   | 国外又犯=中断     | 中断须"**又犯中国刑法之罪**"，伪造私人印章在我国非罪    |

时效中断（§89 第2款）成立要件：
```
前罪追诉期内 ──→ 又犯罪（须触犯中国刑法）──→ 前罪追诉期"从后罪之日起重新计算"
                       ↑
              国外不构成中国之罪的行为，不触发中断
```
