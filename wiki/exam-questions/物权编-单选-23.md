# 物权-单选-23 · 在先抵押后出租商铺——拍卖后丁可请腾退，丙向甲追偿

## 题干

> 甲以某商铺作抵押向乙银行借款，抵押权已登记，借款到期后甲未偿还。甲提前得知乙银行将起诉自己，在乙银行起诉前将该商铺出租给不知情的丙，预收了1年租金。半年后经法院委托拍卖，由丁竞买取得。下列哪一选项是正确的？(2017-3-8, 单)

- A. 甲与丙之间的租赁合同无效
- B. 丁有权请求丙腾退商铺，丙有权要求丁退还剩余租金
- C. 丁有权请求丙腾退商铺，丙无权要求丁退还剩余租金
- D. 丙有权要求丁继续履行租赁合同

## 答案

**C**（先抵押后租赁→租赁不对抗抵押权实现；丁可请腾退；剩余租金应向甲追索非丁）<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **答题模型** → [[民法-物权-抵押财产转让与租赁冲突模型]]（第三步“先押后租租赁不对抗”）
- **先抵押后租赁不对抗**：抵押权登记在先，后设租赁→租赁合同有效但不得对抗抵押权实现（拍卖时可请腾退）
- §725"买卖不破租赁"反面：该规则只适用于租赁在先于其他权利设立的情形
- 剩余租金向谁追索：丙已向甲预付租金，甲收了但未履行全部义务→丙应向甲追索违约损失，与丁无关

## 考点精解

| 选项               | 分析                     | 结论       |
| ---------------- | ---------------------- | -------- |
| A（租赁无效）          | 甲有权出租，租赁合同本身有效（仅对抗力受限） | **错**    |
| B（丁请腾退+退租金）      | 丁可请腾退正确；但剩余租金应向甲追索，不是丁 | **错**    |
| C（丁请腾退，丙无权要丁退租金） | 两项均正确                  | **正确** ✓ |
| D（丙可要求丁继续履行）     | 先抵押后租赁→无"买卖不破租赁"保护     | **错**    |

## 📐 口诀

> **先抵押后租赁：抵押权实现时腾退，租赁不对抗；买卖不破租赁只保护在先租赁。**
