# 刑法-总论-单选-31 · 亲友规劝陪同投案的自首认定

## 题干

> 来源：法考真题改编 / 瑞达·厚大·众合高频题（已联网核验法条与司法解释）

丙抢劫后逃跑，公安机关已发现犯罪事实但未确定犯罪嫌疑人。数日后，丙的父亲规劝丙，并陪同丙到公安机关，丙到案后如实供述了全部抢劫事实。关于丙，下列哪一选项正确？

- A. 因犯罪事实已被发觉，不成立自动投案，不构成自首
- B. 亲友陪同投案不属于本人投案，不构成自首
- C. 成立一般自首
- D. 仅构成坦白

## 我的答案

**C**<!-- confidence: EXTRACTED -->

依法释〔1998〕8号第1条，犯罪事实虽被发觉，但犯罪嫌疑人尚未被讯问、未被采取强制措施时投案的，应认定为自动投案；经亲友规劝、陪同投案的，视为自动投案。丙在尚未被讯问、未被采取强制措施时，经父亲规劝、陪同到案，并如实供述了主要犯罪事实，符合《刑法》§67Ⅰ"自动投案+如实供述"的要件，成立一般自首。

- A 错："犯罪事实已被发觉"并不等于丧失自首资格，关键看嫌疑人是否已被讯问或采取强制措施；丙投案时二者均未发生，仍属自动投案。
- B 错：经亲友规劝、陪同投案的，司法解释明文规定视为自动投案，并不因有亲友陪同而否定本人投案。
- D 错：丙具备自动投案要件，应认定为自首，而非仅坦白。

## 考点精解 · "被发觉"不等于丧失自首资格

考生易把"犯罪事实已被公安发现"直接等同于"不能自首"，这是命题人最爱挖的坑。自动投案的时间节点不是看案件有没有被发觉，而是看**嫌疑人本人是否已被讯问或采取强制措施**：

| 投案时点 | 是否自动投案 |
| --- | --- |
| 犯罪事实未被发觉前投案 | 是 |
| 事实被发觉、但本人未被讯问/未被强制措施时投案 | 是 ✅（本题） |
| 已被讯问或已被采取强制措施后"交代" | 否（看是否准自首/坦白） |

亲友介入的方式也要区分：

| 亲友方式 | 定性 |
| --- | --- |
| 规劝、陪同投案 | 视为自动投案（本题，成立自首） |
| 捆绑/强行送去（"大义灭亲"扭送） | 不认定自动投案，但可参照自首从轻处罚 |

丙是"父亲规劝并陪同"，落在第一栏，成立一般自首。
