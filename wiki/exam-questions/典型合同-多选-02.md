# C2-多选-02 · 试用买卖的期限处理

## 题干

> 甲乙签订试用买卖合同，未约定试用期。期满双方对是否购买没达成协议。下列哪些正确？

- A. 没约定试用期 → 应适用 6 个月
- B. 没约定试用期 → 若不能按民法典确定 → 由**出卖人**确定
- C. 试用期间届满，买受人未表示 → 视为**购买**
- D. 试用期间未对质量提异议 → 应当购买

## 我的答案

**BC**<!-- confidence: INFERRED -->

## 涉及考点

- [[试用买卖]] 试用期确定 + 期满推定（§640、§641）

## 考点精解 · 试用买卖两条核心规则

### 是什么 / 易混

**§640**（试用期）：
> 试用买卖的试用期间由**当事人约定**；没有约定 / 约定不明 / §510 不能确定 → **由出卖人确定**。

**§641**（期满推定）：
> 试用期间届满，**买受人**对是否购买标的物**未作表示**的，视为**购买**。

本题对照：
- A "6 个月" → **无法定值**，错
- B 出卖人确定 → 对（§640）
- C 期满未表示 → 视为购买 → 对（§641）
- D "未对质量异议 → 应购买" → 错
  - "未表示是否购买" ≠ "未对质量异议"
  - 试用买卖的关键是"是否决定购买"，与质量异议是两个层面

### 怎么考 / 坑在哪

- **A 高频陷阱**：6 个月是某些其他合同的法定值（如保证期间），不是试用买卖
- **D 易混**：试用买卖**期满未表示 = 购买**，不是"未质疑 = 购买"
