# C2-单选-29 · 挂靠施工：无资质施工队的权利与合同效力

## 题干

> 甲公司与没有建筑施工资质的某施工队签订合作施工协议，由甲公司投标乙公司的办公楼建筑工程，施工队承建并向甲公司交纳管理费。中标后，甲公司与乙公司签订建筑施工合同。工程由施工队负责施工。办公楼竣工验收合格交付给乙公司。乙公司尚有部分剩余工程款未支付。下列哪一选项是正确的？

- A. 合作施工协议有效
- B. 建筑施工合同属于效力待定
- C. 施工队有权向甲公司主张参照合同关于工程价款的约定折价补偿
- D. 甲公司有权拒绝支付剩余折价补偿款

## 我的答案

**C**<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **答题模型** → [[民法-合同-建设工程模型]]（第二+三+五步：挂靠协议无效→对外合同看名义方资质→验收合格折价补偿）
- [[建设工程合同]] 挂靠施工：无资质实际施工人借用资质 → 合同无效（建工解释一 §1（二））
- [[建设工程合同]] 实际施工人验收合格→参照合同折价补偿（建工解释一 §2）

## 考点精解 · 挂靠施工的三层法律关系

### 关系梳理

```
施工队（无资质）← 挂靠协议 → 甲公司（有资质）
                                    ↓ 建筑施工合同
                              乙公司（发包人）
施工队（实际施工人）→ 实际完成工程 → 竣工验收合格
```

### 是什么 / 易混

**挂靠施工**：无资质施工队借用有资质公司名义（交管理费），本质是**资质挂靠**，属于违法行为。

| 法律关系          | 性质                          | 依据          |
| ------------- | --------------------------- | ----------- |
| 合作施工协议（甲-施工队） | **无效**（资质挂靠协议违法）            | 建工解释一 §1（二） |
| 建筑施工合同（甲-乙）   | **有效**（甲有资质，与乙合同有效；乙不知内部安排） | §788 / 建工解释 |
| 施工队对甲的折价补偿请求权 | **成立**（工程完工验收合格，实际施工人可主张）   | 建工解释一 §2    |

### 选项逐析

**A（合作施工协议有效）** → **错**
合作施工协议本质是资质挂靠协议——无资质施工队以甲公司名义承揽工程，属于违法行为，协议无效（建工解释一 §1（二）："借用资质"协议无效）。

**B（建筑施工合同效力待定）** → **错**
建筑施工合同是**甲公司**与乙公司签订的，甲公司具有合法建筑施工资质，该合同合法有效，不属于效力待定。内部挂靠安排不影响对外合同的效力。

**C（施工队有权向甲主张折价补偿）** → **正确**
施工队是**实际施工人**：虽然合作协议无效，但工程已实际完工且竣工验收合格。建工解释一 §2 规定：实际施工人可以**参照合同约定**向转包人/违法分包人主张折价补偿。施工队可参照甲乙合同中的工程价款约定，向甲公司主张折价补偿。

**D（甲有权拒绝支付）** → **错**
甲不能拒绝支付。C 中已说明施工队有权主张，甲必须在合同约定范围内支付折价补偿款，拒绝支付无法律依据。

### 怎么考 / 坑在哪

- **A 陷阱**：工程已完工 → 以为协议"有效"或"补正" → 错！完工不影响合同效力，挂靠协议自始无效
- **B 陷阱**：以为"内部有无资质施工队"会影响对外合同效力 → 错！对外合同（甲-乙）由甲公司名义缔结，甲有资质，合同有效
- **D 陷阱**：以为无效协议→甲可拒付 → 错！无效合同不妨碍实际施工人主张不当得利式的折价补偿

### 怎么答

C。合作协议（挂靠）无效（A错）；甲有资质，建筑施工合同有效非效力待定（B错）；施工队作为实际施工人，工程验收合格，有权参照合同约定向甲主张折价补偿（C对）；甲不得拒绝支付（D错）。

## 📐 答题口诀

> **挂靠施工三件事**：
> 1. 挂靠协议**无效**（资质借用违法）
> 2. 对外合同看**名义方**资质（甲有资质→合同有效）
> 3. 实际施工人工程验收合格 → 有权**参照合同**向名义承包人主张**折价补偿**
