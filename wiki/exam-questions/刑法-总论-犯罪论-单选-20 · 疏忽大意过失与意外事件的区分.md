# 刑法-总论-犯罪论-单选-20 · 疏忽大意过失与意外事件的区分

## 题干

> 来源：依据《刑法》第15条、第16条命制的**仿真题**（题干为本库命制，非历年真题；§15/§16 已联网核验于最高检 https://www.spp.gov.cn/spp/fl/201802/t20180206_364975.shtml CONFIRMED）。

关于过失与意外事件，下列哪一选项是正确的？

- A. 甲护士按常规剂量为患者注射青霉素，事前皮试正常，因该患者罕见特异体质（医学上无从预见）当场过敏死亡——甲构成医疗事故罪
- B. 乙倒车时未察看后方，将蹲在车后玩耍的儿童碾死——乙不可能预见，属意外事件
- C. 丙打猎时将草丛中的同伴误看成野猪开枪打死，经查当时光线、距离条件下一般猎人均应辨明是人——丙成立过失致人死亡罪
- D. 丁过失损坏他人价值十万元的名画，因法律未将过失毁坏财物规定为犯罪而不负刑责——该结论错误

## 我的答案

**C**<!-- confidence: EXTRACTED -->

正解为 C。疏忽大意的过失与意外事件**唯一的分界**是"有无预见可能性"：依《刑法》第15条，应当预见而疏忽大意没有预见的是过失；依《刑法》第16条，行为人对结果**不能预见**（也无故意过失）的，是意外事件，不是犯罪。

逐项：

- A 错：皮试正常、患者系罕见特异体质且**医学上无从预见**，甲对死亡结果无预见可能性，属第16条意外事件，**不构成犯罪**，更非医疗事故罪。
- B 错：乙倒车时**应当预见**车后可能有人、负有查看后方的义务，因疏忽大意没有预见而碾死儿童，属**疏忽大意的过失**（有预见可能性），并非意外事件。
- C 对：当时光线、距离条件下**一般猎人均应辨明是人**，说明丙应当且能够预见是人，因疏忽大意没有预见而开枪打死——疏忽大意的过失，成立过失致人死亡罪（§233）。
- D 错：错在末句"该结论错误"。我国刑法确实未将过失毁坏财物规定为犯罪，依第15条第2款"过失犯罪，法律有规定的才负刑事责任"，丁确实不负刑责，故丁不负刑责的**原结论是正确的**，本项判断错误。

故选 C。

## 考点精解 · 疏忽大意的过失 vs 意外事件

二者都是"行为人没有预见到结果"，区别只在一点——**当时有没有预见的可能性**：

| 维度 | 疏忽大意的过失（§15） | 意外事件（§16） |
|---|---|---|
| 是否预见 | 没有预见 | 没有预见 |
| **预见可能性** | **有**（应当且能够预见） | **无**（不能预见） |
| 评价 | 违反注意义务，有过错 | 无过错，不能抗拒或不能预见 |
| 法律后果 | 过失犯罪（法有规定才罚） | **不是犯罪** |
| 例 | 倒车不看后方碾人、误人为兽开枪 | 特异体质过敏死、不可预见的天灾 |

```
没有预见结果
     │
     ▼  当时"应当且能够预见"吗？
 ┌───────────────┬───────────────┐
 能预见而没预见     根本不能预见
 → 疏忽大意过失     → 意外事件
   （有过错·可罚）   （无过错·不是犯罪）
```

另一铁律——**§15Ⅱ 过失法定**：过失犯罪只有刑法分则明文规定的才负刑责（如过失致人死亡、过失致人重伤、失火等）；像"过失毁坏财物"刑法无规定，即便造成十万元损失也不构成犯罪。命题人常用"过失毁坏财物""过失伤害他人未达重伤"等设陷。
