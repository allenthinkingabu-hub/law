# 刑法-总论-单选-33 · 坦白避免特别严重后果可减轻

## 题干

> 来源：依据《刑法》第67条第3款后段命制的**仿真题**（题干为本库命制，非历年真题；同理真实判决可参河北魏县法院李某甲绑架案；法条已联网核验）。

戊绑架人质后被抓获，归案时人质下落不明、生命垂危。戊如实供述罪行并准确说出人质藏匿地点，公安机关据此及时解救人质，避免了人质死亡。关于对戊的处罚，下列哪一选项正确？

- A. 成立坦白，可以从轻处罚，但不得减轻
- B. 成立坦白，因如实供述避免特别严重后果发生，可以减轻处罚
- C. 成立一般自首，应当减轻处罚
- D. 成立立功，可以减轻或免除处罚

## 我的答案

**B**<!-- confidence: EXTRACTED -->

戊系被抓获、被动归案，构成坦白；其如实供述并据此解救人质，避免了人质死亡这一**特别严重后果**，符合《刑法》§67Ⅲ后段："因其如实供述自己罪行，避免特别严重后果发生的，可以减轻处罚。"故对戊可以减轻处罚。

- A 错：一般坦白固然只能"可以从轻"，但本题因如实供述避免了特别严重后果，触发§67Ⅲ后段的"升级条款"，可以减轻，并非"不得减轻"。
- C 错：戊系被抓获归案，并非自动投案，不成立一般自首。
- D 错：戊供述自己罪行、解救的是本案被害人，属如实供述自己罪行的应有之义，并非揭发他人犯罪或协助侦破他案，不成立立功。

- 《刑法》§68（立功）：揭发他人犯罪行为查证属实，或提供重要线索得以侦破其他案件等，构成立功。

## 考点精解 · §67Ⅲ的"升级条款"与坦白/立功之辨

**坦白本身的两档效果**——§67Ⅲ内部就有梯度：

| 坦白类型 | 法律效果 |
| --- | --- |
| 一般坦白（如实供述自己罪行） | 可以从轻处罚 |
| 升级坦白（因如实供述避免特别严重后果发生） | 可以减轻处罚 |

本题戊的供述直接避免了人质死亡，正是"避免特别严重后果"的典型，可以减轻。

**为何不是立功？** 立功的核心是"超出本人罪责、帮助国家追诉他人或侦破他案"。戊只是供述自己绑架罪行、指出自己藏匿的本案被害人位置，这是其如实供述义务的延伸，未涉及揭发他人或侦破他案，故不成立立功。

```
救"本案被害人" → 属如实供述义务 → 坦白（可能升级减轻）
揭发"他人犯罪"/破"他案" → 立功
```
