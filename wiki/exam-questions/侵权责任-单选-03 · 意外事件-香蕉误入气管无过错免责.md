# 侵权-单选-03 · 意外事件-香蕉误入气管无过错免责

## 题干

> 来源：2017-3-23（众合）

刘婆婆回家途中，看见邻居肖婆婆带着外孙小勇和另一家邻居的孩子小囡（均为4岁多）在小区花园中玩耍，便上前拿出几根香蕉递给小勇，随后离去。小勇接过香蕉后，递给小囡一根，小囡吞食时误入气管导致休克，经抢救无效死亡。对此，下列哪一选项是正确的？

- A. 刘婆婆应对小囡的死亡承担民事责任
- B. 肖婆婆应对小囡的死亡承担民事责任
- C. 小勇的父母应对小囡的死亡承担民事责任
- D. 属意外事件，不产生相关人员的过错责任

## 我的答案

**D**<!-- confidence: EXTRACTED -->

意外事件（§180）：各方均无过失——刘婆婆给香蕉是善意行为，无预见可能；肖婆婆在场是日常监护，香蕉噎喉属意外；小勇分香蕉是4岁小孩正常分享行为，无过错。结论：任何人均无过失，属不可预见的意外事件，不产生过错责任。

## 涉及考点

- [[侵权责任编]] §180 不可抗力免责 / 意外事件免责
- 对比：意外事件（行为人主观无过失）vs 不可抗力（客观外力无法克服）

## 考点精解 · 意外事件免责

### 是什么 / 易混

| 概念 | 含义 | 免责效果 |
|---|---|---|
| **意外事件** | 行为人对损害后果的发生无法预见（非故意/过失） | 阻却过错，不承担过错责任 |
| **不可抗力** | 客观上不能预见/避免/克服的外力（洪水/地震） | 免责（§180） |
| **区分** | 意外事件侧重"行为人主观不可预见"；不可抗力侧重"客观力量不可抗" | 均可免责 |

### 逐人分析

**刘婆婆**：给香蕉是善意行为，对4岁孩子吞食香蕉会误入气管无合理预见可能 → 无过失 ✗

**肖婆婆**：监护的是小勇（外孙），对邻居孩子小囡是否有监护义务？小囡父母委托谁监护未说明，即使在场，小孩吞香蕉噎喉属突发意外，无预见可能 → 无过失 ✗

**小勇父母**：小勇分香蕉是4岁儿童正常分享行为，无过失 ✗

→ **D 正确**：属意外事件，不产生相关人员过错责任。

### 怎么考 / 坑

- **陷阱**：看到死亡就想找责任人 → 过错责任以"有过错"为前提，无过错即无责任；
- **陷阱**：认为肖婆婆在场就负监护责任 → 监护责任须基于法定/约定监护关系，临时在场不等于成为监护人。

## 📐 答题口诀 · 意外事件判断

**关键词触发**：死亡 / 意外 / 任何人都无过错？

**🎯 一句话记忆**：
> 意外事件：发生了损害但所有人都无法预见 → 过错责任归零，不赔！

**过错判断三步**：
1. 行为人有无法律义务？（无义务 → 无过失可言）
2. 有义务的人，能否预见损害？（不能预见 → 意外，无过错）
3. 能预见但未采取措施 → 有过失 → 承担责任

**填空模板**：
刘婆婆给香蕉（无\_\_预见可能\_\_）+ 小勇分香蕉（\_\_正常儿童行为\_\_）+ 肖婆婆在场（非\_\_法定监护人\_\_）→ 均无过错 → 意外事件 → 无\_\_过错责任\_\_。
