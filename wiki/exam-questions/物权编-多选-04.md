# 物权-多选-04 · 公司车登记在白某名下，转让后再抵押——洪某取得所有权，黄某取得抵押权

## 题干

> 白某将登记在自己名下的某公司汽车一辆以市价转让给不知情的洪某，并完成交付，后白某又将汽车抵押给不知情的黄某，并办理抵押权登记。现黄某债权已到期，白某非法集资被判入狱，并没收全部财产。下列说法正确的有？(2020年金题2-1-10)

- A. 白某因被没收财产不再承担还款义务
- B. 洪某已取得汽车所有权
- C. 黄某有对汽车的优先受偿权
- D. 该汽车不能没收

## 答案

**BCD**（洪某善意取得；黄某因登记取得抵押权；没收不能及于他人合法财产）<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **答题模型** → [[民法-物权-善意取得模型]] 第六步·客体扩张（§311Ⅲ 黄某善意取得**抵押权**）+ 特殊动产§225登记对抗
- [[善意取得]] §311：洪某以市价从登记名义人取得，完成交付 → **善意取得所有权**
- 特殊动产§225：黄某善意取得**抵押权**（白某登记在册 → 黄某信赖登记办理抵押权登记）
- 刑事没收：只没收**犯罪人自有财产**，不能没收他人已取得所有权的财产
- 债务不因没收消灭：民事债务独立于刑事惩罚

## 考点精解

| 选项          | 分析                                                                 | 结论       |
| ----------- | ------------------------------------------------------------------ | -------- |
| A（没收→不承担债务） | 刑事没收≠免除民事债务，黄某债权仍存在                                                | **错**    |
| B（洪某善意取得）   | 白某是登记名义人+不知情+市价+已交付 → §311善意取得                                     | **正确** ✓ |
| C（黄某有优先受偿权） | 白某登记为名义所有人 → 黄某信赖登记取得并**登记抵押权** → 善意取得抵押权；洪某未登记所有权不能对抗已登记的黄某（§225） | **正确** ✓ |
| D（汽车不能没收）   | 洪某是所有权人（善意取得）；黄某有抵押权。均不是白某财产，不可没收                                  | **正确** ✓ |

**C的关键**：§225 未登记的所有权（洪某）不得对抗善意第三人（黄某，已登记抵押权）。

## 📐 口诀

> **刑事没收≠民事债务消灭；善意+登记名义人=善意取得；未登记所有权≤已登记抵押权（§225对抗）。**
