# C1-单选-48 · 没给"使用说明书"能拒付房款吗？从给付义务不对价

## 题干

> 甲与乙公司签订的房屋买卖合同约定："乙公司收到首期房款后，向甲交付房屋和房屋使用说明书；收到二期房款后，将房屋过户给甲。"甲交纳首期房款后，乙公司交付房屋但未立即交付房屋使用说明书。甲以此为由行使先履行抗辩权而拒不支付二期房款。下列哪一表述是正确的？（2015-3-10）

- A. 甲的做法正确，因乙公司未完全履行义务
- B. 甲不应行使先履行抗辩权，而应行使不安抗辩权，因乙公司有不能交付房屋使用说明书的可能性
- C. 甲可主张解除合同，因乙公司未履行义务
- D. 甲不能行使先履行抗辩权，因甲的付款义务与乙公司交付房屋使用说明书不形成主给付义务对应关系

## 我的答案

**D**（说明书是从给付义务，与付二期款的主给付义务不对价）<!-- confidence: EXTRACTED -->（官方参考答案：D）

## 涉及考点

- [[先履行抗辩权]]
- [[同时履行抗辩权]]

## 考点精解 · 抗辩权只对"主给付义务对价"成立

### 是什么 / 易混

- **履行抗辩权（同时/先/不安）的成立前提**：对方未履行的是与自己义务**互为对价的主给付义务**。
- 乙未交的"**房屋使用说明书**"是**从给付义务**（辅助实现合同目的），它与甲的"**支付二期房款**"这一**主给付义务不构成对价对应**。
- 故甲**不能**以"没给说明书"为由行使先履行抗辩权拒付二期款（D 对）。

### 怎么考 / 坑在哪

- **A 错**：从给付义务未履行不足以触发抗辩权拒付主给付。
- **B 不安抗辩权错**：不安抗辩权针对"先履行方有证据证明后履行方丧失/可能丧失履行能力"（§527），本题不是履行能力问题。
- **C 解除错**：未交说明书是轻微的从义务瑕疵，未致合同目的不能实现，不构成根本违约，不能解除（可另请求交付/补救）。

### 怎么答

主从给付义务区分：从义务不对价 → 抗辩权不成立 → 选 **D**。

---

## 📐 答题口诀 · 抗辩权只挡"对价的主给付"，挡不住"从给付"

> **"你没干的那件事，得跟我要干的事'对价'，我才能抗辩；你只是没给个说明书（从给付），我不能赖着不付主款。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"对方没履行的是'说明书/发票/附随小义务'"      → 从给付义务，不对价 → 抗辩权不成立 ★
"对方没履行的是'交房/付款'核心义务"           → 主给付义务对价 → 可抗辩
"对方丧失履行能力的可能"                      → 才考虑不安抗辩权 §527
"轻微从义务瑕疵 → 解除"                       → 错（未达根本违约）
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A | ❌ | 从义务未履行不足以拒付主款 |
| B | ❌ | 非履行能力问题，不安抗辩权不适用 |
| C | ❌ | 未达根本违约，不能解除 |
| **D** | ✅ | 说明书=从给付，与二期款主给付不对价 |

### 🚗 老王小李故事

> 小李买老王的房，合同写：付首期 → 老王交房 + 给《房屋使用说明书》；付二期 → 过户。小李付了首期，老王把房交了，就是说明书还没给。小李一拍大腿："你没给说明书，我先履行抗辩，二期款不付了！"——不行。说明书只是个"**从给付**"小义务，跟小李"付二期款"这个**主给付**不是一对一的对价。小李不能拿"少给张说明书"当挡箭牌赖掉一大笔房款，顶多另外催老王把说明书补上。

### 🎯 一句话记忆

> **"抗辩权认'主给付对价'；从给付（说明书）不对价，不能拿来拒付主款。"**

### 填空模板（主观题用）

> 履行抗辩权以**【对方未履行互为对价的主给付义务】**为前提。乙未交的房屋使用说明书系**【从给付义务】**，与甲支付二期款的**【主给付义务不构成对价对应】**，故甲**【不能行使先履行抗辩权】**；亦不符合不安抗辩权要件、未达根本违约不得解除。故选 **D**。
