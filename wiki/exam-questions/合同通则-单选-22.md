# C1-单选-22 · 终止 vs 撤销

## 题干

> 下列情形中，**不属于**合同权利义务终止的是：

- A. 买卖合同被解除
- B. 债务被免除
- C. 赠与合同被撤销
- D. 标的物被提存

## 我的答案

**C**（赠与合同被撤销）<!-- confidence: INFERRED -->

> 🔎 **2026-06-09 联网核实（C 确认无误）**：源题库无官方答案，经《民法典》**§557** + 通说核实，推断 **C 经得起法源检验**。① §557 债权债务终止**六情形**：履行、抵销、提存、免除、混同、+ **合同解除**（§557 II："合同解除的，该合同的权利义务关系终止"）→ 故 **A 解除、B 免除、D 提存均属终止**。② **撤销 ≠ 终止**（权威通说一致）：**终止**＝"仅向将来消灭、**无溯及力**、不产生恢复原状"；**撤销**＝"使合同**自始无效、溯及既往**、恢复原状"。赠与撤销（§658 任意 / §663 法定）属撤销——"撤销通知到达受赠人即**自始无效**、赠与人可请求**返还**"——是**另一条消灭路径**，不属终止。故"不属于终止"的是 **C**。⚠️ 三个"撤销"别混：**可撤销合同**（§147-152 意思表示瑕疵）/ **赠与撤销**（§658/663，本题 C）/ **债权人撤销权**（§538 保全，即 [[撤销权]]）——本题是前两类的"自始无效"效果，与 §538 那个"撤销"无关。

## 涉及考点

- [[合同权利义务终止]]（§557 终止**六情形**）
- **终止 vs 撤销** 的本质区别：**向将来消灭**（终止）vs **自始无效·溯及既往**（撤销）

## 考点精解 · 合同消灭的两条路：终止（向将来）vs 撤销（自始无效）

### 是什么 / 易混

**核心一刀——合同"收场"分两条路，时间方向完全相反**：

| | **终止**（§557）| **撤销**（§147-152 / §658 等）|
|---|---|---|
| 前提 | 合同**有效成立** | 合同**带瑕疵出生**（意思表示瑕疵 / 法定可撤销）|
| 效果方向 | **向将来**消灭（前面都算数）| **自始无效·溯及既往**（当它从没存在过）|
| 要不要恢复原状 | 原则**不**（已履行的有效）| **要**（恢复原状、返还财产）|
| 性质 | 有效合同的**了结** | 对成立瑕疵的**纠正** |

**§557 终止六情形**：① 履行（清偿）② 抵销 ③ 提存 ④ 免除 ⑤ 混同（债债同归一人）⑥ **解除**（§557 II）。

四个选项归位：

| 选项 | 是不是"终止"？ | 依据 |
|---|---|---|
| A 买卖合同被**解除** | ✅ 是终止 | §557 II 解除 → 权利义务终止 |
| B 债务被**免除** | ✅ 是终止 | §557(四) 免除 |
| **C 赠与合同被撤销** | ❌ **不是终止** | 撤销 = **自始无效**，是另一条消灭路径（§658 / §663）|
| D 标的物被**提存** | ✅ 是终止 | §557(三) 提存 |

→ "**不属于**终止"的是 **C**。

### 怎么考 / 坑在哪

- **撤销 = 自始无效，不是终止**：这是题眼。终止是"有效合同往后了结"，撤销是"把合同从根拔掉、当它没成立过"。
- **三个"撤销"别混**（高频混淆）：① **可撤销合同**（§147-152，欺诈 / 胁迫 / 重大误解 / 显失公平）；② **赠与撤销**（§658 任意撤销 + §663 法定撤销）——本题 C；③ **债权人撤销权**（§538 保全制度，即 [[撤销权]]，是"债权人撤销债务人的诈害行为"，跟本题完全两码事）。
- **无效 / 不成立也不是"终止"**：同理，合同被宣告**无效**、**不成立**，都因"自始没有有效过"而不属于 §557 的终止。
- **终止后并非全完**：合同终止后，**结算 / 清理条款 + 争议解决（仲裁）条款**仍然有效（§557 / §567）。

### 怎么答

A 解除、B 免除、D 提存都是 §557 的法定**终止**情形；C 赠与被**撤销**是"自始无效"的另一条路，不属于终止。故选 **C**。

## 📐 答题口诀 · 终止 = 有效合同"善终"（向将来）；撤销 = 带病合同"作废"（自始无效）

> **"终止是合同**活完一辈子、往后了结**（履行 / 解除 / 抵销 / 提存 / 免除 / 混同，前面都算数）；撤销是合同**出生证作废、当它从没存在**（自始无效、溯及既往）。问'不属于终止'，就挑那个'自始无效'的。"**

### 关键词触发表

```
看到题干"下列不属于合同(权利义务)终止的是"        → 找"撤销 / 无效 / 不成立"那个 ★
"履行完毕 / 解除 / 抵销 / 提存 / 免除 / 混同"      → §557 终止 ✓（六情形）
"被撤销 / 可撤销 / 欺诈胁迫 / 重大误解 / 显失公平" → 撤销 = 自始无效 ≠ 终止 ★
"被宣告无效 / 合同不成立"                          → 自始无效 / 自始不存在 ≠ 终止
"赠与被撤销（任意 §658 / 法定 §663）"             → 撤销，不是终止（本题 C）
```

### 📋 4 选项分析

| 选项 | 机制 | 属于终止？ | 法条 |
|---|---|---|---|
| A 买卖合同被解除 | 有效合同因解除而了结 | ✅ 是 | §557 II |
| B 债务被免除 | 债权人放弃债权 | ✅ 是 | §557(四)|
| **C 赠与合同被撤销** | 合同**自始无效**（溯及既往）| ❌ **不是** → **选** | §658 / §663（撤销，非 §557）|
| D 标的物被提存 | 债务人依法提存而消灭债务 | ✅ 是 | §557(三)|

→ 唯一"不属于终止"的是 **C** ✅

### 🚗 老王小李故事（一辆车，终止 vs 撤销一眼分清）

> 围绕老王和小李的一辆车，"合同怎么收场"有两条**截然不同**的路——看哪条是"终止"、哪条是"撤销"：
>
> **第一条路 · 终止（合同本来有效，后来"了结"，只管将来）**——§557：
> - **A 解除**：小李买了老王的车却迟迟不付款（严重违约），老王**解除**买卖合同 → 合同权利义务终止 ✓
> - **B 免除**：老王大手一挥"这车款不要了，算我送你"→ **免除**债务 → 终止 ✓
> - **D 提存**：小李凑齐钱要付，老王却玩失踪 / 拒收，小李把钱**提存**到提存机构 → 债务终止 ✓
> - （还有：双方履行完毕、两人互相欠钱**抵销**、小李把老王的公司收购了债债**混同**——都是终止。）
>
> **第二条路 · 撤销（合同"带病出生"，撤销后当它从没存在过、溯及到最初）**：
> - **C 撤销**：老王本来说好把车**赠**给小李，后来（车还没过户前）老王反悔、**撤销**了赠与（§658 任意撤销）→ 这不是"了结一个有效合同"，而是把合同**从根上拔掉、自始无效**，当这事从没发生 → 是**撤销**，**不属于终止**。
>
> **一句话**：**终止 = "善终"**（活过一辈子、自然或被结束，前面都算数）；**撤销 = "出生证作废"**（从出生那刻起就当没存在过）。题目问"不属于终止"，答案就是那条"自始无效"的路 → **C**。

### 🎯 一句话记忆

> **"终止（§557）= 有效合同往后了结：履 / 解 / 抵 / 提 / 免 / 混（六情形，向将来）；撤销 = 带瑕疵合同自始无效（溯及既往，恢复原状）。"**
> **"问'不属于终止'→ 挑'撤销 / 无效 / 不成立'那个。"**

### 填空模板（主观题用）

> 合同权利义务**【终止】**（§557）指**有效成立**的合同因法定情形（履行 / 解除 / 抵销 / 提存 / 免除 / 混同）而**【向将来消灭】**；而**【撤销】**（§147-152 / §658）使合同**【自始无效、溯及既往】**，产生**【恢复原状 / 返还财产】**的后果，二者性质不同。A 解除、B 免除、D 提存均属**【§557 终止情形】**，C 赠与被撤销属**【撤销（自始无效）】**、不属于终止。故选 **C**。
