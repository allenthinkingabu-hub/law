# C2-多选-24 · 供热拒交费：能中止不能解除

## 题干

> 甲公司与小区业主吴某订立了供热合同。因吴某要出国进修半年，向甲公司申请暂停供热未果，遂拒交上一期供热费。下列哪些表述是正确的？

- A. 甲公司可以直接解除供热合同
- B. 经催告吴某在合理期限内未交费，甲公司可以解除供热合同
- C. 经催告吴某在合理期限内未交费，甲公司可以中止供热
- D. 甲公司可以要求吴某承担违约责任

## 答案

**CD**<!-- confidence: EXTRACTED -->

> 出处性质：**官方历年真题**（2014 年卷三第 60 题）。

## 出处与来源

- 出处：2014 年司法考试卷三第 60 题
- 素材：[[2026-06-10-典型合同买卖合同真题]]（含参考答案）
- 法条依据：《民法典》§654（逾期不交费，催告后合理期限仍不交 → 供电人可**中止**供电、中止前应**事先通知**）· §656（供水 / 气 / 热**参照**供用电）· §577（违约责任）· §944（物业费欠费**不得停水停电**、只能诉讼 / 仲裁——变形题关联）
- 验真（2026-06-11）：§654 / §656 / §944 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对（§944 在物业服务合同章）

## 涉及考点

- 📐 **违约总模型** → [[民法-合同-违约责任模型]]（违约责任 §577；中止供应 ≠ 解除）
- [[供用电合同]] 规则**准用于供热**（§656）：公用事业、**强制缔约**
- 📐 **对照解除门槛** → [[民法-合同-解除模型]]（中止 ≠ 解除）
- 📐 **中止辨析中枢** → [[民法-合同-中止模型]]（公用事业中止 §654 + 中止 vs 终止 vs 解除）
- 供应方对欠费用户只能"**催告 → 中止供应**"，**不能擅自解除**合同
- 用户欠费仍负**违约责任**

## 考点精解

- **C 对**：吴某拒交供热费，甲公司经**催告**、合理期限内仍不交 → 可**中止供热**（§654 准用）。
- **D 对**：吴某欠费违约 → 应承担**违约责任**（§577）。
- **A 错**：供热是强制缔约的公用事业合同，甲公司**不能"直接解除"**（更不能不经催告）。
- **B 错**：即便经催告未交费，供应方的法定手段是"**中止供应**"而非"解除合同"——这是供用电/热合同区别于一般合同的关键。

## 🎯 变形题套路 · 公用事业合同"只能中止不能解除"（重者恒重 · 2026 必考型）

> **同一个核心考点（欠费只能"中止供应"、不能"解除 / 终止"合同），换场景、换干扰项反复考，考点 100% 不变。** 本题（2014-3-60 供热）即其原型。
> ⚠️ 说明：坊间复习资料常把此考点冠以"2024 原题"并改写题干（如"李某拖欠 2023-2024 供热费"），**实为教学改写、非真实历年真题**；可溯源的真实锚点是本页 **2014 年卷三第 60 题**。

### 核心铁则（§654 + §656，已验真）

- **水、电、气、热**四类公用事业合同：用户欠费 → 供应方只能**催告 → 中止供应**，**不能解除 / 终止合同**（§654；§656 准用于水 / 气 / 热）。
- 法定程序**两道关卡**：**①催告**（给合理期限补费 + 违约金）→ 仍不付 → **②中止前应当事先通知**用户（§654 Ⅱ）。**缺任一程序 = 违法中止 = 供应方反担违约责任**。
- 补费后必须**及时恢复**供应（中止 = 暂停，关系存续）。

### 5 种常见变形（换马甲，考点不变）

1. **换公用事业类型**（最常见）：供热 → 供水 / 供电 / 供气，规则完全一样。"供电公司有权**解除**供电合同"→ 错；"按国家规定程序**中止**供电"→ 对。
2. **加程序干扰**（每年必考）：未经催告 / 未事先通知就直接停供 → **供应方违法、担违约责任**（"做法合法"→ 错）。
3. **混淆相近概念**（最高频陷阱）：用"**解除**""**终止**"偷换"**中止**"。"逾期不交费可**终止**供水""有权**解除**合同"→ 错；"可以**中止**供水"→ 对。
4. **与关联考点结合**：物业费场景——**物业服务人不得以停水 / 停电 / 停热 / 停气催交物业费**，只能**催告后诉讼 / 仲裁**（§944）。"物业有权停水停电"→ 错。
5. **加例外情形干扰**：欠费时间再长（"连续 3 年未交"）也只是**中止**不是解除——**强制缔约 + §654 专门规定中止**，不因欠费时长升级出解除权。

### ⚡ 秒杀技巧

> 选项见"**解除合同**""**终止合同**" → **直接排除**；见"**中止**" → 再查"**催告**" + "**事先通知**"两道前置程序齐不齐。
> 物业费变形：见"**停水停电**催费" → 错；正解是"**诉讼 / 仲裁**"（§944）。

## 概念辨析：中止 ≠ 解除 ≠ 终止

- **中止**（本题正解）：**暂时停止**供应，**合同关系仍存续**；用户补交欠费 + 违约金后，供应方须**立即恢复**。
- **解除 / 终止**：**消灭**合同关系——公用事业合同因**强制缔约 + 公益性**，供应方**无此权利**。
- 概念全貌 + 老王小李故事见 [[供用电合同]]；解除门槛对照 [[解除]]（§563 根本违约）· [[民法-合同-解除模型]]。

## 📐 口诀

> **水、电、气、热等公用事业合同，永远只能中止，不能解除**。选项见"解除 / 终止合同"直接排除；见"中止"再查"催告 + 事先通知"两道前置程序。物业费更狠——连停水停电都不行，只能诉讼 / 仲裁（§944）。
