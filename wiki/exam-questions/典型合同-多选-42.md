# C2-多选-42 · 执行合伙事务中个人侵权：不属于合伙债务，连带责任不及（§973）

## 题干（金题来源：2020金题-2-1-31）

> 甲乙丙丁四人签订合伙合同，但未登记为合伙企业。甲乙丙推选丁作为合伙事务的执行人，丁在执行合伙事务的过程中，与戊发生口角，并将戊打伤，现在戊欲追究甲乙丙丁及合伙的责任，根据《民法典》，下列哪些说法是正确的？

- A. 甲乙丙不应与丁承担连带责任
- B. 应由丁自己承担责任
- C. 应由合伙承担用人单位责任
- D. 应由合伙与丁承担连带责任

## 我的答案

**AB**<!-- confidence: INFERRED -->

丁打人是个人侵权行为，不属于"合伙债务"（§973 仅适用于合伙债务）；未登记合伙无用人单位资格（C错）；合伙连带责任限于合伙经营产生的债务（D错）。

## 涉及考点

- [[合伙合同]] 合伙人对外连带责任的**范围**：仅限于合伙债务（§973）
- 执行合伙事务的**行为边界**：个人侵权行为不等于合伙事务
- 未登记合伙的主体资格：不具备合法"用人单位"地位

## 考点精解 · [[合伙合同]] 连带责任边界精解

### 是什么 / 易混

**§973 合伙人对外连带责任**：
> 合伙人对合伙的**债务**承担连带责任。清偿合伙债务超过自己应当承担份额的合伙人，有权向其他合伙人追偿。

**关键词："合伙的债务"**——只有属于"合伙债务"的，其他合伙人才承担连带责任。

**什么是"合伙债务"？**
- 为合伙事业目的产生的债务（如合伙经营所欠的货款、租金）
- 合伙人在执行合伙事务时依法产生的债务

**什么不是"合伙债务"？**
- 合伙人个人侵权行为（本题丁打人）
- 合伙人个人消费债务
- 超越授权范围的个人行为

### 四个选项精析

**A（甲乙丙不应与丁承担连带责任）→ 正确**
理由：丁与戊口角后打人 = **个人侵权行为**，不属于"合伙债务"的范畴。§973 要求连带责任的前提是"合伙的债务"，打人侵权不是合伙为业务目的产生的债务 → 甲乙丙不连带。

**B（应由丁自己承担责任）→ 正确**
理由：丁实施人身侵权（故意伤害），依侵权责任章，由行为人丁自己承担赔偿责任（§1165 过错责任一般条款）。个人侵权行为后果由个人承担。

**C（应由合伙承担用人单位责任）→ 错误**
理由：
① 本题四人签订合伙合同但未登记为合伙企业 → 未形成法人或非法人组织的用人单位；
② 打人行为超出合伙执行事务的范围，不适用"执行工作任务造成他人损害"规则（§1191）；
③ 口角致伤是丁的个人行为，非用人单位指派事务。

**D（应由合伙与丁承担连带责任）→ 错误**
理由：同A，打人不是"合伙债务"，不适用§973 连带责任规则。合伙无需为丁的个人侵权行为承担连带责任。

### 连带责任范围对比表

| 场景 | 是否"合伙债务" | 其他合伙人连带？|
|---|---|---|
| 合伙经营欠供应商货款 | ✅ 是合伙债务 | ✅ 连带 |
| 执行合伙事务过失损害第三人财产 | ✅ 是合伙债务 | ✅ 连带 |
| 合伙人**个人**打架伤人 | ❌ 个人侵权，非合伙债务 | ❌ 不连带 |
| 合伙人个人向外借款（非合伙用途）| ❌ 个人债务 | ❌ 不连带 |

### 怎么考 / 坑在哪

1. **D 的陷阱**：看到"执行合伙事务过程中"就误以为一切后果都由合伙+丁连带承担——错！关键在于行为本身是否属于"合伙债务"。打人 = 个人侵权，超出合伙事务范围。
2. **C 的陷阱**：未登记合伙不是法人/非法人组织 → 无用人单位资格 → §1191 用人单位责任不适用。
3. **A/B 并列正确**：A说其他合伙人不连带，B说丁自己担责，两句话从不同角度说同一件事，都选。

## 📐 答题口诀 · [[合伙合同]] 连带责任范围

**关键词触发**：合伙事务过程中 / 合伙人做了坏事 / 其他合伙人是否连带

**🎯 一句话记忆**：
> 合伙连带限"合伙债务"；个人侵权超范围，自己扛，其他人不连带。

**两步判断**：
```
① 该行为产生的债务是"合伙的债务"吗？
   · 为合伙业务目的 → 是合伙债务 → §973 连带
   · 个人侵权/个人事务 → 不是合伙债务 → 不连带

② 是否未登记？
   · 未登记为合伙企业 → 无"用人单位"资格 → §1191 不适用
```

**🚗 生活故事**（小李做律师事务所合伙人）：
小李（合伙人）出差途中酒后打架伤人。法院判：其他合伙人不连带（打架不是律所业务）。若是法律意见书出错导致客户损失→ 才是合伙事务债务 → 其他合伙人才连带。
