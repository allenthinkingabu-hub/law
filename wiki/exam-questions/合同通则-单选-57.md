# C1-单选-57 · 以"欠款人"身份在欠条签名 = 并存的债务承担（债务加入）

## 题干

> 甲经乙公司股东丙介绍购买乙公司矿粉，甲依约预付了100万元货款，乙公司仅交付部分矿粉，经结算欠甲50万元货款。乙公司与丙商议，由乙公司和丙以欠款人的身份向甲出具欠条。其后，乙公司未按期支付。关于丙在欠条上签名的行为，下列哪一选项是正确的？（2017-3-9）

- A. 构成第三人代为清偿
- B. 构成免责的债务承担
- C. 构成并存的债务承担
- D. 构成无因管理

## 我的答案

**C**（丙以"欠款人"身份与乙共同出具欠条，乙仍负债 = 债务加入）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 考点精解 · 四个"第三人介入债务"的辨析

### 是什么 / 易混

丙以"**欠款人**"身份、与乙**共同**向甲出具欠条，且**乙仍是债务人** → **并存的债务承担（债务加入）**：丙加入债务，与乙**共同**对甲负责（§552）。

四概念一次辨清：

| 概念 | 特征 | 本题为何不是 |
|---|---|---|
| A 第三人代为清偿 | 第三人**直接替债务人还钱**（履行行为）| 丙是"签字担债"不是"现在就还钱" |
| B 免责的债务承担 | 原债务人**退出**，新人**取代** | 乙**没退出**，仍是欠款人 |
| **C 并存的债务承担** | 新人**加入**，与原债务人**共同**负责 | ✅ 丙以欠款人身份加入，乙仍在 |
| D 无因管理 | **无义务**而为他人管理事务 | 丙是经介绍的交易关联人、主动担债，非管理他人事务 |

### 怎么考 / 坑在哪

- **并存 vs 免责**的分水岭：**原债务人是否退出**。乙仍是欠款人 → 并存（C），不是免责（B）。
- **债务加入 vs 保证**：丙以"欠款人"（而非"保证人")身份签名 → 倾向债务加入（与债务人**同一顺位**共同负责），而非补充性的保证。

### 怎么答

丙加入、乙不退 = 并存的债务承担 → 选 **C**。

---

## 📐 答题口诀 · 原债务人退没退？退=免责，不退=并存

> **"新人来扛债：老的走了 = 免责承担；老的还在、一起扛 = 并存（债务加入）。以'欠款人'落款 = 加入，不是保证、不是代偿。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"第三人以'欠款人'身份 + 原债务人仍在"         → 并存的债务承担（债务加入 §552）★
"原债务人退出、由新人取代"                    → 免责的债务承担（§551，需债权人同意）
"第三人当场把钱替还了"                        → 第三人代为清偿
"以'保证人'身份签 + 补充性"                   → 保证（补充责任，先诉抗辩）
"无义务而管他人事"                           → 无因管理
```

### 🚗 老王小李故事

> 甲预付了 100 万买乙公司的矿粉，乙只发了一部分，结算还欠甲 50 万。介绍人丙（乙公司股东）和乙一商量，俩人**一起以"欠款人"的名义**给甲打了张欠条。丙这一签，算什么？——**债务加入（并存承担）**：丙跳进来和乙**一块儿**欠甲这 50 万，乙可没溜（不是免责承担），丙也不是当场掏钱（不是代为清偿），更不是学雷锋管闲事（不是无因管理）。一句话：老的没走、新的进来一起扛 = 并存。

### 🎯 一句话记忆

> **"老债务人没退、新人以'欠款人'加入一起扛 = 并存的债务承担（债务加入）。"**
