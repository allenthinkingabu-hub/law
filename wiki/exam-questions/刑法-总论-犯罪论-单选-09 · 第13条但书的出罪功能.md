# 刑法-总论-犯罪论-单选-09 · 第13条但书的出罪功能

## 题干

> 来源：依据《刑法》第13条但书命制的**仿真题**（题干为本库命制，非历年真题；§13但书"情节显著轻微危害不大的，不认为是犯罪"已联网核验 CONFIRMED）。

甲在超市顺手拿走价值2元的一支笔被当场发现。关于本案，下列说法正确的是？

- A. 甲的行为侵犯财产法益，无论数额一律以盗窃罪论处
- B. 依《刑法》第13条但书，甲的行为"情节显著轻微危害不大"，不认为是犯罪，但可予以治安管理处罚
- C. 但书只是宣示性规定，没有出罪功能
- D. 适用但书意味着甲的行为毫无违法性，不可作任何处理

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正确答案为 **B**。

《刑法》第13条但书规定："但是情节显著轻微危害不大的，不认为是犯罪。"该但书具有**实质的出罪功能**，是定量出罪的法律依据。

- **B 正确**：甲顺手拿走价值2元之物，"情节显著轻微危害不大"，依但书**不认为是犯罪**；但"不构成犯罪"≠"完全合法"，仍可依《治安管理处罚法》予以治安管理处罚。
- **A 错误**：盗窃罪一般要求"数额较大"或多次盗窃、入户盗窃等情形，2元属情节显著轻微危害不大，不能一律以盗窃罪论处。
- **C 错误**：通说与司法实践均承认但书的**出罪功能**，并非单纯宣示。
- **D 错误**："不认为是犯罪"不等于"毫无违法性、不可作任何处理"，仍可作行政（治安）处罚等非刑事处理。

**陷阱**：①否认但书的出罪功能；②把"不构成犯罪"误读为"完全合法、不受任何处理"。

## 考点精解 · 但书出罪的三层含义

```
危害行为
  │
情节显著轻微 + 危害不大？
  ├─ 是 ──► §13但书：不认为是犯罪（出罪）
  │           │
  │       但仍可：治安管理处罚 / 民事赔偿等非刑事处理  ← 非"完全合法"
  └─ 否 ──► 进入构成要件等正常入罪审查
```

| 误区命题 | 正解 |
|----------|------|
| "无论数额一律定盗窃罪"（A） | 错：盗窃罪须数额较大等，定量限制 |
| "但书无出罪功能、仅宣示"（C） | 错：通说与实践承认实质出罪功能 |
| "适用但书＝毫无违法性、不作处理"（D） | 错：不构成犯罪≠合法，可治安处罚 |
| "情节显著轻微危害不大→不认为是犯罪，可治安处罚"（B） | 对 |

> 要害：但书是"出罪闸门"，把"轻微违法"挡在犯罪门外，但门外仍有行政处罚的空间。
