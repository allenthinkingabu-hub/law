# C2-多选-22 · 所有权保留：取回权·加速到期·善意取得

## 题干

> 周某以6000元的价格向吴某出售一台电脑，双方约定五个月内付清货款，每月支付1200元，在全部价款付清前电脑所有权不转移。合同生效后，周某将电脑交给吴某使用。期间，电脑出现故障，吴某将电脑交周某修理，但周某修好后以6200元的价格将该电脑出售并交付给不知情的王某。对此，下列哪些说法是正确的？

- A. 王某可以取得该电脑所有权
- B. 在吴某无力支付最后一个月的价款时，周某可行使取回权
- C. 如吴某未支付到期货款达1800元，且经催告后在合理期限内仍未支付，周某可要求其一次性支付剩余货款
- D. 如吴某未支付到期货款达1800元，且经催告后在合理期限内仍未支付，周某可要求解除合同，并要求吴某支付一定的电脑使用费

## 答案

**ACD**<!-- confidence: EXTRACTED -->

## 出处与来源

- 出处：2016 年司法考试卷三第 61 题（改编）
- 素材：[[2026-06-10-典型合同买卖合同真题]]（含参考答案）
- 法条依据：《民法典》§311（善意取得）· §642（取回权：催告未付 / 不当处分）+《买卖合同司法解释》§26（取回两上限：已付 75% / 被善意取得）· §634（分期付款 **1/5 + 催告** → 加速到期 / 解除 + 使用费）
- 验真（2026-06-11）：§311 / §634 / §641-§643 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对；取回权"已付 75% 不得取回"见买卖合同司法解释（法释〔2020〕17号修正）§26。**原"取回权需欠款 1/5"系将 §634 门槛误植到 §642，已更正**

## 涉及考点

- **善意取得** §311：周某（占有外观）将电脑卖给不知情、合理价款、已交付的王某 → 王某善意取得
- **所有权保留取回权** §642：条件 = 催告未付 / 未完成特定条件 / 不当处分；**两上限**（司法解释§26）= 已付 75% 或被善意取得则**取不回**
- 分期付款的**加速到期 / 解除 + 使用费**（§634，1/5 门槛 · 所有权保留参照）
- 📐 **完整答题模型** → [[民法-合同-所有权保留模型]]

## 考点精解

- **A 对**：周某虽非真正所有权人（保留在自己名下、实际已交吴某），但其将电脑出售给**不知情**的王某、价格合理（6200）且**已交付** → 王某**善意取得**所有权（§311）。
- **C 对**：吴某欠款达 1800 元（占总价 6000 的 30%，超 1/5），经催告合理期限仍不付 → 周某可主张**一次性支付剩余货款**（加速到期，§634）。
- **D 对**：同样条件下，周某也可选择**解除**合同并请求支付**电脑使用费**（§634）。
- **B 错**（两个独立理由）：① 吴某欠"最后一个月"时**已付 4800 = 80% > 75%** → 撞《买卖合同司法解释》§26 取回上限，出卖人**不得取回**；② 电脑已被王某**善意取得** → 取回**对抗不能**。（取回权门槛是"催告未付 / 不当处分"§642；**"1/5"是 §634 加速到期 / 解除的门槛、与取回权无关**——干扰项正利用这点。）

## 📐 四步速查（完整版 → [[民法-合同-所有权保留模型]]）

| 步                         | 一句话                                 | 本题套用                              |
| ------------------------- | ----------------------------------- | --------------------------------- |
| ① **认定 / 形式**（§641）       | 不要式 + 未登记不对抗善意第三人                   | 保留所有权未登记 → 顶不住善意王某                |
| ② **所有权 ≠ 风险**（§604）      | 风险随交付走                              | 本题不涉风险                            |
| ③ **取回权**（§642 + 司法解释§26） | 催告未付 / 不当处分；**已付 75% 或被善意取得 → 取不回** | 吴某已付 80%>75% + 电脑被善意取得 → **B 错**  |
| ④ **加速 / 解除**（§634）       | 欠 **1/5** + 催告 → 加速到期 / 解除 + 使用费    | 欠 1800=30%>1/5、催告未付 → **C 对、D 对** |
|                           |                                     |                                   |

→ 王某**善意取得**电脑所有权（§311）→ **A 对**；综上 **答案：ACD**

## 📐 口诀

> **"卖给不知情的善意得（§311）；欠款过两成又催了，能加速、能解约要使用费；东西被善意取走了，取回权就落空。"**
