# C1-多选-31 · 卖房未过户能否撤销/取得？（⚠️问"错误的"）

## 题干

> ⚠️ **本题问"哪些表述是错误的"——选错误项！**
>
> 杜某拖欠谢某100万元。谢某请求杜某以登记在其名下的房屋抵债时，杜某称其已把房屋作价90万元卖给赖某，房屋钥匙已交，但产权尚未过户。该房屋市值为120万元。关于谢某权利的保护，下列哪些表述是错误的？（2014-3-54）

- A. 谢某可请求法院撤销杜某、赖某的买卖合同
- B. 因房屋尚未过户，杜某、赖某买卖合同无效
- C. 如谢某能举证杜某、赖某构成恶意串通，则杜某、赖某买卖合同无效
- D. 因房屋尚未过户，房屋仍属杜某所有，谢某有权直接取得房屋的所有权以实现其债权

## 我的答案

**ABD**（三项均为**错误**表述）<!-- confidence: EXTRACTED -->（官方参考答案：ABD）

## 考点精解 · 90万/120万未达"明显不合理低价"+ 区分原则 + 债权不能直接变物权

### 是什么 / 易混

逐项判断（**问错误的**）：

| 选项                      | 对/错     | 理由                                                                         |
| ----------------------- | ------- | -------------------------------------------------------------------------- |
| **A 可撤销买卖合同**           | ❌**错误** | 90 万 ÷ 120 万市值 = **75%**，**未低于 70% 红线**，不构成"明显不合理低价"→ 不满足债权人撤销权要件，**不能撤销** |
| **B 未过户 → 合同无效**        | ❌**错误** | **区分原则**：买卖合同成立即生效，**未过户只是物权未变动**，不影响合同效力                                  |
| C 恶意串通则无效               | ✅ 正确    | 若谢某能证明杜赖**恶意串通损害债权**，则买卖合同**无效**（§154）——表述正确，故**不选**                       |
| **D 未过户 → 谢某直接取得房屋所有权** | ❌**错误** | 谢某只是**金钱债权人**，**不能直接取得房屋所有权**；债权不能自动变物权，须经执行程序就房屋变价受偿                      |

### 怎么考 / 坑在哪

- **70% 价格红线**：90/120=75% > 70%，**不算明显不合理低价**，撤销权不成立（A 错）。这是 §539 + 通则解释的量化红线。
- **区分原则**：未过户 ≠ 合同无效（B 错）。
- **债权 ≠ 物权**：债权人不能"直接拿房抵债"，须走执行（D 错）。
- 只有 C（恶意串通才无效）是正确表述，因此**错误项 = ABD**。

## 📐 答题口诀 · "错误的"题型 + 70%红线 + 区分原则 + 债权不直接变物权

> **"75% 没破 70% 红线 → 撤不了（A 错）；没过户≠合同无效（B 错）；债权人不能直接把房收走（D 错）；只有'恶意串通才无效'是对的（C 不选）。"**


### 🚗 老王小李故事

> 老杜欠老谢 100 万。老谢想让老杜拿名下房子抵债，老杜说"我已经 90 万把房卖给老赖了，钥匙都给了，就是还没过户"。房子市值 120 万。问哪些说法**错**？① "老谢能撤销这买卖"——90 万是市价的 75%，**没跌破 70% 红线**，不算贱卖，撤不了（A 错）；② "没过户所以合同无效"——没过户只是房没过去，合同照样有效（B 错）；③ "没过户房还是老杜的，老谢能直接把房收了抵债"——老谢只是个**要钱的债主**，不能直接把房变成自己的，得走执行（D 错）；④ 只有"能证明俩人恶意串通才无效"是对的（C，不选）。

### 🎯 一句话记忆

> **"问'错误的'先标√✗；75%>70%撤不了；未过户≠无效；债权人不能直接拿房。"**

### 填空模板（主观题用）

> 成交价 90 万为市值**【75%，未低于 70% 红线】**，不构成明显不合理低价，**【不能撤销】**（A 错）；**【区分原则】**下未过户不影响买卖合同效力（B 错）；谢某为金钱债权人**【不能直接取得房屋所有权，须经执行受偿】**（D 错）；仅"恶意串通才无效"正确（C）。故错误项为 **ABD**。
