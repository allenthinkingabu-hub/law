# 刑法-总论-犯罪论-单选-06 · 被害人特殊体质不属于介入因素

## 题干

> 来源：依据最高检"被害人特殊体质不属于因果关系介入因素"官方口径（关联《刑法》§14、§16）命制的**仿真题**（题干为本库命制，非历年真题；参见最高检 https://www.spp.gov.cn/ztk/dfld/2017dfld/dfld98_5139/ywtt/201709/t20170912_200209.shtml ）。

甲、乙发生口角，甲一拳将瘦小的乙打成轻伤，乙因自身患有血友病（甲完全不知情）抢救无效死亡。关于甲的行为与乙死亡的因果关系，下列正确的是？

- A. 血友病是介入因素，因其异常而阻断因果关系，甲的行为与乙死亡无因果关系
- B. 被害人特殊体质不属于因果关系的介入因素，甲的行为与乙的死亡存在因果关系；甲是否对死亡负责另看主观（有无故意/过失）
- C. 只要有因果关系，甲就构成故意伤害（致人死亡）
- D. 甲构成故意杀人罪

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正解为 B。最高检明确：特殊体质（血友病、心脏病、"蛋壳脑袋"）在先行行为发生**前已存在**，是被害人自身固有状况，**不是偶然介入的外部原因**，因此**不属于介入因素**——不能套用介入因素三步法去判"异常阻断"。依"蛋壳脑袋"原则，因果关系一律肯定。但**因果关系≠刑事责任**：甲对血友病不知情、对死亡无故意亦无过失（死亡超出其预见可能），通常仅对轻伤负责，死亡部分可能属意外事件（§16）。

- A 错：特殊体质不是介入因素，谈不上"因异常而阻断"；因果关系成立。
- B 对：特殊体质非介入因素，因果关系肯定；担责与否转入主观判断。
- C 错：有因果关系 ≠ 当然承担致死责任，还须具备对死亡的故意或过失。
- D 错：甲只是斗殴一拳、对死亡无故意，没有杀人故意，不构成故意杀人罪。

陷阱：把特殊体质当"介入因素"去做三步判断是**方向性错误**——特殊体质不是介入因素，因果关系直接肯定，争点应转移到**主观**（有无故意/过失、是否意外）。

## 考点精解 · 特殊体质不进三步法，争点转主观

特殊体质（血友病、心脏病、脾肿大、蛋壳脑袋）是被害人**先在的固有状况**，不是"行为之后偶然插入的外部因素"，所以根本不进介入因素三步法。正确路径是：先一律肯定因果，再独立判断主观。

```
   遇到"特殊体质"先分流（关键！）
┌────────────────────────────────┐
│  问：体质是"先在固有" 还是      │
│      "行为后偶然外部介入"？      │
└──────────────┬─────────────────┘
        先在固有 │
               ▼
┌────────────────────────────────┐
│ 不属于介入因素 → 不进三步法      │
│ 蛋壳脑袋原则：因果关系一律肯定   │
└──────────────┬─────────────────┘
               ▼
┌────────────────────────────────┐
│ 因果关系 ≠ 刑事责任             │
│ 再查主观（§14）：               │
│  · 对死亡有故意/过失？ → 担责    │
│  · 不知情、不能预见 → §16 意外  │
│    甲仅对轻伤负责                │
└────────────────────────────────┘

  （对照：真正的"介入因素"才走
   异常度→关联度/原因力→是否阻断 三步）
```
