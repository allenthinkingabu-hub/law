# 刑法-总论-单选-54 · 追诉时效起算与立案后逃避

## 题干

> 来源：依据《刑法》第88、89条命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

甲于2010年1月将被害人非法拘禁，持续关押至2013年1月才释放（非法拘禁罪法定最高刑为3年有期徒刑）。2013年6月公安机关立案侦查，甲随即潜逃。2025年甲被抓获。下列哪一选项是正确的？

- A. 非法拘禁的追诉期从2010年1月（着手之日）起算，5年至2015年期满，已过时效
- B. 该罪为继续犯，追诉期从2013年1月行为终了之日起算，5年至2018年期满，已过时效
- C. 公安机关2013年6月立案后甲潜逃，依§88第1项不受追诉期限的限制，2025年仍可追诉
- D. 因已过追诉期，须报最高人民检察院核准才能追诉

## 我的答案

**C**<!-- confidence: EXTRACTED -->

正解为 C。非法拘禁是**继续犯**，依 §89"犯罪行为有连续或继续状态的，从犯罪行为**终了之日**起计算"，起算点为 2013 年 1 月释放之日（故 A 起算点错；B 起算点正确）。但**决定性事实**是：2013 年 6 月公安已**立案侦查**、甲**随即潜逃（逃避侦查）**，依 **§88 第1项**"立案侦查后逃避侦查的，**不受追诉期限的限制**"——无论 5 年期是否届满，2025 年都可追诉。

- A 错：继续犯起算点是"行为终了之日"（2013.1），非"着手之日"（2010.1）。
- B 错：起算点正确，但结论被 §88 推翻——已立案后逃避，不受期限限制。
- C 对：立案后逃避，进入 §88 不受期限限制，2025 年仍可追诉。
- D 错：§88 不受期限限制时**无需** §87 末句"满 20 年报最高检核准"程序；该程序针对**死刑/无期罪**满 20 年仍欲追诉的情形，与本案最高刑 3 年无关。

## 考点精解 · 起算点与"不受期限限制"两层分析

**第一层 起算点（§89）**：

| 犯罪形态 | 起算点 |
|------|------|
| 一般犯罪 | 犯罪**之日** |
| 连续犯 / **继续犯** | 犯罪行为**终了之日** |

非法拘禁是典型继续犯，2010.1 着手、2013.1 释放终了 → 起算 = **2013.1**。

**第二层 不受期限限制（§88）**——一旦成立，时效档次是否届满**已不重要**：
```
§88 第1项：人民法院/检察院/公安机关立案侦查或受理案件后，
           行为人逃避侦查或审判的 → 不受追诉期限限制
§88 第2项：被害人在追诉期内提出控告，应立案而不予立案的 → 不受限制
```

本题逻辑链：
```
2013.6 公安立案 ──→ 甲随即潜逃（逃避侦查）──→ 命中§88①
                                              ↓
                            不受5年期限限制 → 2025年仍可追诉（C对）
```
⚠️ 区分两个"20年"：§88 是"不受期限限制"（直接可追）；§87 末句的"满 20 年报最高检核准"只针对**死刑/无期档**，本案最高刑 3 年，根本用不到（D 错）。
