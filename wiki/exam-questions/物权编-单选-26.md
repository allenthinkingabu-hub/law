# 物权-单选-26 · 共有货车担保+侵权——甲承担全部后可按份向乙追偿

## 题干

> 甲、乙二人按照3:7的份额共有一辆货车，为担保丙的债务，甲、乙将货车抵押给债权人丁，但未办理抵押登记。后该货车在运输过程中将戊撞伤。对此，下列哪一选项是正确的？(2016-3-8, 单)

- A. 如戊免除了甲的损害赔偿责任，则应由乙承担损害赔偿责任
- B. 因抵押权未登记，戊应优先于丁受偿
- C. 如丁对丙的债权超过诉讼时效，仍可在2年内要求甲、乙承担担保责任
- D. 如甲对丁承担了全部担保责任，则有权向乙追偿

## 答案

**D**（甲乙共同担保人，甲承担全部后可向乙内部追偿；按份3:7）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2016-3-8
- 素材：[[2026-06-15-物权编客观真题]]

## 涉及考点

- **按份共有人的内部追偿（民法典§307）**：甲、乙是货车的按份共有人（3:7），将共有货车抵押给丁。甲承担了全部担保责任（使得共有货车免受执行/消灭抵押权），该债务属于“因共有的动产产生的债权债务”。对外甲乙承担连带债务，对内则按份额比例分担。因此，甲有权**直接**向乙追偿其应承担的70%份额（受偿金额）。此处的追偿基于共有关系，无需以“向主债务人丙追偿不能”为前提。
  *注：若仅从共同担保（担保解释§13）来看，甲、乙在同一份合同签字满足“有分担合意”（第二步），但需要满足“向债务人丙追偿不能”之前置程序（第一步）。本题是2016年旧真题，在《民法典》时代，最合理的解释是通过第307条“共有人内部追偿权”直接解题。*
- 侵权连带责任：A错，共同侵权人之间承担连带责任，免除甲不影响乙继续对戊负责（§1168）
- **未登记动产抵押的效力**：合同生效但不得对抗第三人；戊是侵权受害人（普通债权），不能"优先于"担保物权
- C错：担保期间=主债权时效届满后6个月，非"2年"

## 考点精解

| 选项         | 分析                                          | 结论       |
| ---------- | ------------------------------------------- | -------- |
| A（免除甲→乙承担） | **连带债务人之一被免除，其他债务人自动扣减其内部份额，绝不为被免除人的份额买单。** | **错**    |
| B（戊优先于丁）   | 戊无担保物权，不能优先于丁（抵押权人）受偿 -> **物权秒杀债权，普通不能对抗**  | **错**    |
| C（债权时效后2年） | 担保期间≠"2年"，且与主债权时效联动                         | **错**    |
| D（甲追偿乙）    | 共同担保内部按份额（3:7）追偿                            | **正确** ✓ |
|            |                                             |          |
