# 物权-单选-28 · 最高额抵押——债权可转让但抵押权不随之转让（§421）

## 题干

> 甲在2013年11月将自己对乙已取得的债权全部转让给丁。下列说法正确的是？(2016-3-90, 任)

- A. 甲的行为将导致其最高额抵押权消灭
- B. 甲将上述债权转让给丁后，丁取得最高额抵押权
- C. 甲将上述债权转让给丁后，最高额抵押权不随之转让
- D. 2014年5月5日前，甲对乙的任何债权均不得转让

## 答案

**C**（§421：最高额抵押所担保债权在确定期届至前转让，最高额抵押权不随之转让）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2016-3-90（2016年真题第90题）
- 素材：[[2026-06-15-物权编客观真题]]

## 涉及考点

- §421 **最高额抵押与债权转让分离**：确定期前，债权可以转让，但最高额抵押权不随之转让（除非另有约定）
- A错：债权转让不导致最高额抵押权消灭，抵押权仍归甲
- D错：§421并未禁止确定期前的债权转让（转让只是不带走抵押权）

## 考点精解

| 选项        | 分析                 | 结论       |
| --------- | ------------------ | -------- |
| A（抵押权消灭）  | 转让债权只是债权离开，抵押权留在甲处 | **错**    |
| B（丁取得抵押权） | §421：抵押权不随债权转让     | **错**    |
| C（抵押权不随转） | §421核心规则           | **正确** ✓ |
| D（不得转让）   | §421允许转让，只是抵押权不随行  | **错**    |
