# C1-单选-14 · 无权代理的默示追认

## 题干

> 甲未经许可以乙公司的名义和丙公司订立合同。下列情形中，**可以视为对合同的追认**的是（ ）。

- A. 乙公司主动开始履行合同义务
- B. 乙公司未向甲表示拒绝履行该合同
- C. 乙公司知道甲的行为后未作否认表示
- D. 丙公司向乙公司核时时，乙公司合理期限内未回复

## 我的答案

**A**（主动开始履行）<!-- confidence: INFERRED -->

## 涉及考点

- [[追认]] · 无权代理（§171）
- 默示追认 vs 沉默不表态

## 考点精解 · 追认（明示 / 默示 / 沉默）

### 是什么 / 易混

- **无权代理**（§171）：被代理人**追认**之后对被代理人发生效力
- **追认**可以是：
  - **明示**：明确表示承认
  - **默示（积极行为推定）**：以**实施履行行为**等积极行为表明承认
- **沉默**原则上**不构成追认**——除法律或交易习惯规定
- **§171 IV**：相对人**催告**被代理人在 30 日内追认，被代理人**未作表示**的，视为**拒绝**追认（不是追认！）

### 怎么考 / 坑在哪

- 关键陷阱：**沉默 ≠ 追认**
- B、C 都是被代理人**消极不表态** → 不构成追认
- D 是相对人核时（催告），未回复 → 视为**拒绝**追认（§171 IV），不是追认
- A 是**积极履行行为** → 默示追认 ✓

### 怎么答

只有 A 是积极行为足以推定承认。其他三项均为沉默或不作为，不构成追认。故选 **A**。

---

## 📐 答题口诀 · [[追认]]：追认靠"动作"，沉默不算数

> "哪个算追认"题 —— 一把尺子量到底：**只有积极作为算追认；任何沉默 / 不作为都不算，催告后沉默还直接算拒绝。**

### 🚗 "老王冒名签约" 故事（题干场景化）

> 老王（无权代理人）没经过授权，冒用 **乙公司（老李的公司）** 的名义，和 **丙公司** 签了供货合同。
> 这份合同此刻**效力待定** —— 要老李（被代理人）**追认**了才对乙公司生效。

老李怎么做才算"追认"？四种反应对号入座：

| 选项 | 老李的反应 | 性质 | 算追认吗 |
|---|---|---|---|
| **A** | **主动开始备货发货**（履行）| 积极作为 | ✅ **默示追认** |
| B | 没跟老王说"我不干"（不拒绝）| 消极沉默 | ❌ |
| C | 知道了但闷不吭声（知情不否认）| 消极沉默 | ❌ |
| D | 丙催"30 天内表态"，老李装死不回 | 催告后沉默 | ❌ **视为拒绝**（§171 IV）|

→ 只有 **A 动起来了** → 选 **A** ✅

### 🔑 §171 无权代理"四款全景"

```
§171 无权代理（甲冒名签约 → 效力待定）
  Ⅰ 没追认 → 对被代理人不生效
  Ⅱ 相对人【催告】被代理人 30 日内追认；
      被代理人【未作表示】→ 视为【拒绝】追认   ← D 选项
  Ⅲ 善意相对人 追认前有【撤销权】
  Ⅳ 拒绝 / 未追认 → 行为人（甲）对相对人担责
```

### ⚠️ 核心陷阱：沉默 ≠ 追认（B / C / D 全灭）

**追认是"意思表示"，原则上要"说出来 / 做出来"**：
- **明示**：明确说"我认这单"
- **默示**：用**积极行为**表明（履行 / 接受履行 / 主张权利 / 领取标的 / 收款）

而 **沉默原则上不是意思表示**（§140 II，仅"法律规定 / 当事人约定 / 交易习惯"三种例外才算）：
- B 不拒绝 = 沉默 ❌
- C 知情不否认 = 沉默 ❌
- D 催告后不回复 = 沉默，且 §171 IV **明文"视为拒绝"** ❌（不是追认！）

> 📌 **D 是最毒陷阱**：很多人以为"催告了还不回复，就默认同意了吧" —— **恰恰相反**，法律为保护相对人，把"催告后沉默"直接定为**拒绝**。

### 📋 4 选项逐项

| 选项 | 判断 | 一句话 |
|---|---|---|
| **A 主动履行** | ✅ | 积极行为 → 默示追认 |
| B 未表示拒绝 | ❌ | 单纯不拒绝 = 沉默 |
| C 知道不否认 | ❌ | 知情沉默 ≠ 追认 |
| D 催告未回复 | ❌ | §171 IV 视为**拒绝** |

→ 选 **A** ✅

### 📐 答题口诀

```
"哪个算追认"题：
  Step 1: 锁定积极作为（履行 / 收款 / 领货 / 主张权利）→ 这个就是追认
  Step 2: 其余"不拒绝 / 不否认 / 不回复"全是沉默 → 不追认
  Step 3: 见"催告后未表示" → §171 IV 视为【拒绝】（反向陷阱）
```

### 🎯 一句话记忆

> **"追认靠动作（履行 / 收款 / 领货），沉默一律不算数"**
> **"催告后再沉默 → 直接视为拒绝（§171 IV），不是同意！"**

### 填空模板（主观题用）

> 甲无权代理以乙名义与丙订约，合同**效力待定**，须乙**追认**方对乙生效（§171 I）。
> 乙**主动履行**合同义务，系以积极行为作出**默示追认**，合同自始有效。
> 其余"未拒绝 / 知情不否认 / 经催告未回复"均属**沉默**，依 §140 II 不构成追认；其中经丙**催告**后未表示的，依 **§171 IV 视为拒绝追认**。故选 A。
