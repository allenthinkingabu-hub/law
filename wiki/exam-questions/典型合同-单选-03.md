# C2-单选-03 · 买受人违约时的风险负担

## 题干

> 甲向乙买水泥，约定当晚提货。甲未按时提货，当晚暴雨，乙抢救水泥但仍部分被水淋毁。损失风险由谁承担？

- A. 甲
- B. 乙
- C. 双方均摊
- D. 双方均不承担

## 答案

**A**（买受人迟延受领违约 → 风险自违约时移转给甲）<!-- confidence: EXTRACTED -->

> 答案为依 §605 / §608 验证的正确法律结论。⚠️ 本题系**考点重构练习题**（来源 [[2026-06-06-合同章真题库]]，"水泥 / 暴雨 / 迟延提货"为经典教学例），未检索到可溯源的逐字历年真题，故以法条原文验真为准。题中甲 = 买受人、乙 = 出卖人。

## 出处与来源

- 性质：买卖合同"风险负担 / 买受人违约移转"**考点重构题**（非逐字历年真题）
- 验真（2026-06-10）：§603-§611 经[最高检官网民法典全文](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对；核心 **§605"因买受人的原因致使标的物未按照约定的期限交付的，买受人应当自违反约定时起承担标的物毁损、灭失的风险"**、**§608**（出卖人将标的物置于交付地点、买受人违约没有收取，风险自违约时起由买受人承担）确认

## 涉及考点

- [[买卖合同]] [[风险负担]]（§604 + §605）
- 买受人**违反约定**导致风险移转
- 📐 **答题模型** → [[民法-合同-风险负担模型]]（交付主义→4 特殊场景→瑕疵阻断→风险≠违约责任）
- 📐 **三者关系枢纽** → [[民法-合同-所有权交付风险三角关系模型]]（风险线奠基题：风险随交付/占有，不随所有权——货还在卖方仓库，买受人违约即担风险）

## 考点精解 · 风险移转 2 条核心规则

### 是什么 / 易混

**§604**（基础规则）：标的物毁损灭失的**风险**——
- **交付前**由**出卖人**承担
- **交付后**由**买受人**承担

**§605**（买受人违约时的例外）：因**买受人原因**致**未按约定时间交付**——风险**自违约时**起由**买受人承担**。

本题：
- 约定提货时间 = 当晚，甲**自提**
- 甲（买受人）未按时提货 → **迟延受领**（应受领而未受领），属 §605 / §608 的买受人违约
- 风险**自约定提货时（违约时）**转移给甲
- 即使水泥**还在乙手上未交付**，风险已转

### 怎么考 / 坑在哪

- **B 经典陷阱**：以为"东西还在乙手上 → 乙担风险"，忽略 §605 / §608 违约移转
- **C 错点**：双方"均摊"不是法律规则——风险负担是**全有或全无**

### 怎么答

A。甲违约未按时提货（迟延受领）→ §605 / §608 风险已自违约时转移给甲。

## 🎯 答题思路 · 买卖合同"风险负担"万能四步模型

> 凡"标的物意外毁损灭失、价金风险归谁"题，按这四步走，一步不跳。**本页真题即此模型的标准范例（答案 A）。**

### 一、核心考情

- **考查频率**：典型合同（买卖）高频考点（[[典型合同考点-深度报告]]），客观题常考，主观题买卖纠纷案例几乎必涉；常与违约责任、不可抗力、所有权保留串考。
- **命题核心**：永远围绕"**风险移转的时点**"——把"交付主义 / 路货 / 代办托运 / 买受人不收取 / 质量瑕疵阻断"几条规则混在一起，再用"东西还在谁手上""所有权归谁"误导你。不考定义，全考时点。
- **三大必考点**：①交付主义（风险随交付、不随所有权）②买受人违约 / 迟延受领提前移转（本题）③风险负担 ≠ 违约责任（§611）。

### 二、万能四步模型

#### 第一步：定基准线 —— "交付了没有"（§604 交付主义）

**法考铁则**：**标的物毁损灭失的风险，交付前由出卖人承担，交付后由买受人承担**（§604）。
> ⚠️ 铁律：风险随"**交付（占有移转）**"走，**不随所有权**走——哪怕出卖人保留所有权 / 不动产未过户，只要交付了，风险就归买受人。

**老王小李例子**
- 老王把车交付给小李（钥匙行驶证都给了），约定下月付清才过户。车次日被冰雹砸坏 → **风险已随交付转给小李**（虽未过户），小李照付车款。

#### 第二步：套"特殊场景"修正风险移转时点（4 张牌）

**法考铁则**：
- **路货买卖**（在途标的物）→ 风险自**合同成立时**起由买受人承担（§606）
- **代办托运 / 送货**→ 自交付**第一承运人** / 运至指定地点交付承运人后移转（§607）
- **买受人自提却不来收取** → 自**违约没有收取**时起移转（§608）
- **因买受人原因未按约定期限交付** → 自**违约时**起移转（§605）

**老王小李例子（= 本题情形）**
- 约定当晚自提，小李（买受人）不来取、当晚暴雨淋毁货 → §608 / §605：风险**自当晚违约时**已转给小李，即便货还在老王仓库。
- 对照：路货买卖中老王把在途的一船煤卖给小李 → 风险自**合同成立时**即归小李（§606），船在海上沉了也由小李担。


## 生活例子

你在家具店订一张餐桌，约定**周五送货**。到了周五，**店家自己人手不够、排不出车**，说"下周三再送"。结果**周日店里失火**，你那张餐桌烧没了。

→ 本该周五就交出去的货，是**店家自己的原因**拖着没送（货一直在店里、未交付）→ 周日的火灾损失**店家自担**，得重新做一张给你，**不能要你付钱买这张烧焦的**。

#### 第三步：检查"阻断 / 反推"规则（谁有错，风险天平偏谁）

**法考铁则**：
1. **质量瑕疵致合同目的不达**（§610）→ 买受人可拒收 / 解除，风险**仍由出卖人**承担——瑕疵给付**阻断**风险移转。
2. **因出卖人原因未按期交付** → 风险**不转移**，继续由出卖人承担。

**老王小李例子**
- 老王交的水泥是受潮废品（根本质量瑕疵、不能用）→ 小李有权拒收，风险**不转**、仍归老王，哪怕已"交付"。
- 对照本题：乙的水泥**无瑕疵**、乙还**抢救**了货（无违约无过错）→ 不阻断，风险照转给甲。
- **一句话：该交没交是卖家的错 → 这期间货出意外，卖家自己扛。** 
	你在家具店订一张餐桌，约定**周五送货**。到了周五，**店家自己人手不够、排不出车**，说"下周三再送"。结果**周日店里失火**，你那张餐桌烧没了。
	本该周五就交出去的货，是**店家自己的原因**拖着没送（货一直在店里、未交付）→ 周日的火灾损失**店家自担**，得重新做一张给你，**不能要你付钱买这张烧焦的**。

#### 第四步：风险负担 vs 违约责任 —— 两笔账分开算（§611）

**法考铁则**：
- **风险负担**：解决**意外**（无人过错的天灾意外）造成毁损灭失时，**价金风险**归谁。
- 风险移转给买受人，**不影响**买受人就出卖人的瑕疵 / 违约**另行主张违约责任**（§611）。
- 迟延受领期间，出卖人仍负**妥善保管**义务；**保管不善**致损的，另担赔偿责任（与风险负担两码事）。

**老王小李例子**
- 暴雨毁货 = 意外，乙已抢救、无过错 → 纯**风险**问题 → 甲承担（付价款 / 自担损失）。
- 但若乙明明能轻松遮盖却**故意不管**任其淋毁（保管不善）→ 风险虽在甲，乙仍要为**保管过错**部分担赔偿。


### 三、命题人最爱的 5 个陷阱

1. **"东西还在出卖人手上 → 出卖人担风险"** —— 错！买受人违约 / 不收取，风险已**提前**移转（§605 / §608）（本题 **B 陷阱**）。
2. **"风险随所有权走"** —— 错！风险随**交付**，与所有权脱钩；保留所有权 / 未过户也照转。
3. **"损失双方均摊 / 按公平分担"** —— 错！风险负担是**全有或全无**，没有"均摊"（本题 **C 陷阱**）。
4. **"质量瑕疵也归买受人担风险"** —— 错！瑕疵致目的不达，风险**仍由出卖人**担（§610 阻断）。
5. **"风险一转移，出卖人就全免责"** —— 错！§611 买受人仍可追违约责任；迟延受领期间出卖人仍有妥善保管义务。

### 四、真题演练（套用四步模型 → 本题 A）

1. **第一步**：约定当晚自提，**尚未交付** → 基准线本在出卖人乙。
2. **第二步**：甲（买受人）未按时提货 = **迟延受领 / 买受人违约** → §605（买受人原因致未按期交付）+ §608（自提不收取）→ 风险**自当晚违约时**移转给甲。
3. **第三步**：乙的水泥无质量瑕疵、乙还抢救（无违约无过错）→ 不阻断移转。
4. **第四步**：暴雨=意外、乙无保管过错 → 纯风险问题 → **甲承担** → **A 对**。
   - **B 错**：货虽在乙手，但买受人违约已使风险提前移转（§605 / §608）。
   - **C 错**：风险全有或全无，无"均摊"。
   - **D 错**：风险必有归属，不存在"双方均不承担"。
→ **答案：A** ✅

## 🛒 四大生活场景实例 · 风险移转规则的"生活原型"

> 下面 4 组都是**生活中真实会遇到、法考也直接照搬原型**的场景，每个都标「**谁担损失**」+「**核心判断点**」。一一对应 🎯 模型**第二步的 4 张牌**，看完不再搞混。

### 场景 1 · 路货买卖（货先在路上，后签合同）→ §606

**常见**：批发商在途转卖、跨境电商中途改单、生鲜整车转售

> 山东果农老王把一车刚摘的樱桃交冷链物流、发往上海。货车开到江苏境内，杭州水果连锁店老板小李电话加价 20% 买走整车，双方当场微信签合同。当晚货车在浙江高速追尾，整车樱桃报废。

- **谁担损失**：**小李（买受人）全担**，仍向老王付全额货款。
- **核心判断**：合同成立时货还在路上 → 风险**自合同成立时立刻移转**（§606）；哪怕货车次日才到杭州，只要签约后出事，全是买家的。
- **唯一例外**：老王**明知**货车已追尾还隐瞒、骗小李签约 → 损失归老王（诚信 / 欺诈例外，学理采 CISG 第 68 条规则）。

### 场景 2 · 代办托运 vs 送货上门（90% 考生分不清）

#### （2a）代办托运（卖家只帮你找物流，不负责送到家）→ §607

**常见**：1688 批发、工业零件采购、大件建材"运费到付"

> 你在 1688 买 10 箱瓷砖，卖家说"我帮你联系专线物流，运费 300 元你直接付给司机"。卖家把瓷砖搬上物流货车、司机签了收货单。物流车半路翻车，瓷砖全碎。

- **谁担损失**：**你（买受人）全担**，仍付瓷砖钱，只能自己找物流公司索赔。
- **核心判断**：卖家完成"**交付第一承运人**"动作，风险即移转（§607）；物流谁找的不重要，运输环节风险归买家。

#### （2b）送货上门（卖家负责送到你指定地点）→ §604（风险**不**转的反例）

**常见**：京东自营、天猫包邮、外卖、同城配送

> 你在京东自营买一台笔记本，约定明天送到你家。京东快递员在你家**楼下**停车时，电动车被偷，电脑也没了。

- **谁担损失**：**京东（出卖人）全担**，重发一台或全额退款。
- **核心判断**：必须运到**约定交付地点（你家）并交到你手上**风险才转（§604）；京东物流是出卖人的履行辅助人、不是你雇的承运人 → 没送到手 = 没交付，出事全是卖家的。

### 场景 3 · 买受人自提却不来收取 → §608

**常见**：订蛋糕、门店自提、取快递

> 你周三在蛋糕店订生日蛋糕，约定**周六 15:00 自己到店取**、付了全款。周六临时加班忘了，周日上午才想起来去取。店家说：周六晚上店里冰箱坏了、所有蛋糕都变质扔了，你的也没了。

- **谁担损失**：**你（买受人）全担**，店家不退钱、不重做。
- **核心判断**：货已备好、置于约定地点、只等你取；从**约定提货时间到期那一刻**起风险移转给你（§608）。
- ⚖️ **精确**：受领迟延后，出卖人对标的物的**注意义务降低、原则上仅就故意 / 重大过失负责**——冰箱意外故障属一般意外，损失仍归买家；**除非**店家**故意 / 重大过失**致蛋糕毁损，那部分才回到店家。⚠️ 此规则系**学理通说（参照德国法）**，《民法典》**无直接明文**：§589 字面只规定"债权人无正当理由拒收 → 债务人可请求赔偿**增加费用** + 受领迟延期间**无须支付利息**"，并未写"注意义务降低"；答题援用须标"通说 / 学理"，勿挂某条号。

### 场景 4 · 因买受人原因未按约定期限交付 → §605

**常见**：改家具送货时间、延迟收房、卖家送货买家不在家

> 你在宜家买一套沙发，约定**周五 14:00 送货上门**。周四晚你临时要出差，打电话让宜家"下周一再送"。周日宜家仓库火灾，你那套沙发烧毁。

- **谁担损失**：**你（买受人）全担**，仍向宜家付沙发钱。
- **核心判断**：本来周五就能按时交付，**因你的原因**导致推迟 → 风险**自原定交付时间（周五 14:00）**起移转给你（§605）。
- **易错点**：若是宜家自己的车坏了导致周五没送成（**出卖人原因**）→ 周日火灾损失归宜家。

| 场景 | 法条 | 风险移转时点 | 谁担损失 | 一句话抓手 |
|---|---|---|---|---|
| 路货买卖 | §606 | **合同成立时** | 买受人 | 货在路上才签约，签完出事买家担 |
| 代办托运 | §607 | 交付**第一承运人**时 | 买受人 | 货一上物流车，风险就走 |

| 自提不取 | §608 | **约定提货时间到期**时 | 买受人 | 备好货你不来，过点你担 |
| 买受人致迟延 | §605 | **原定交付时间**时 | 买受人 | 你的原因推迟，按原定时点你担 |
