# C1-多选-11 · 债权转让后债务人对受让人的抗辩

## 题干

> 乙公司将对甲公司的购销债权转让给丙公司，丙公司请求甲履行。甲有权提出下列哪些抗辩？

- A. 甲乙之间合同无效的抗辩
- B. 合同履行期尚未届至的抗辩
- C. 被让与债权已经过诉讼时效的抗辩
- D. 合同已经消灭的抗辩

## 我的答案

**ABCD**<!-- confidence: INFERRED -->

> 🔎 **2026-06-09 联网核实（ABCD 确认无误，无需订正）**：依《民法典》**§548** 原文——"债务人接到债权转让通知后，债务人**对让与人的抗辩，可以向受让人主张**"（多家法律释义平台逐字一致，承袭原《合同法》§82）。法理基础是**债权同一性**：受让人的地位**由原债权人处承继**，"享有的权利不应优于让与人的权利"，债权连同其**瑕疵 / 负担**一并移转。通说与释义明确：债务人可主张的抗辩**不以抗辩权为限**，涵盖"阻止或排斥债权**成立、存续、行使**的一切**实体抗辩 + 程序抗辩"，且 §548 **不限制抗辩产生的时点**。逐项验证：① 合同无效＝债权自始**不发生**（A✓）；② 履行期未到＝**期限抗辩**（B✓）；③ 已过诉讼时效＝**时效抗辩**随债权移转——转让协议签订时债权**已过**时效的，通知**不产生时效中断**、债权不会"起死回生"，债务人仍可主张（C✓）；④ 合同已消灭（已清偿 / 已抵销 / 已解除）＝**排斥债权存续**（D✓）。四项均为债务人本可对让与人主张的真实抗辩 → 全部继受 → **ABCD**。

## 考点精解 · 债务人对受让人的抗辩范围（§548 抗辩继受）

### 是什么 / 易混

**§548（抗辩继受规则）**：债务人对**让与人**的**抗辩**，可以向**受让人**主张。

> **一句话内核**：受让人取得的是**"原汁原味、二手带病"**的债权——债权连同其上的所有**瑕疵 / 抗辩**一起过户。债务人原来能对让与人说的"不"，对受让人**照样能说**；受让人**不会**因为"接手"就得到一个比让与人**更干净、更强**的债权。

→ 凡是债务人**本可对让与人主张**的抗辩，都能继受（§548 **不限制抗辩产生时点**，通知到达前已产生 / 可能产生的都算）：

| 选项           | 抗辩类型        | 法理                          | 判断  |
| ------------ | ----------- | --------------------------- | --- |
| **A** 合同无效   | 债权**自始不发生** | 标的债权本就不存在，无可履行              | ✓   |
| **B** 履行期未届至 | **期限**抗辩    | 期限利益属债务人，未到期可拒绝履行           | ✓   |
| **C** 已过诉讼时效 | **时效**抗辩    | 时效抗辩随债权移转；已过的债权不因转让"复活"     | ✓   |
| **D** 合同已消灭  | 排斥债权**存续**  | 已清偿 / 已抵销 / 已解除 → 债权已灭，无可履行 | ✓   |

→ 四项**全部**是债务人本可对让与人主张的真实抗辩 → **全部继受 → ABCD**。

### 怎么考 / 坑在哪

- **核心理念**：受让人取得"原汁原味"的债权，**能用的抗辩 = 能继受**。本题四项都是"真抗辩"，所以**全选**。
- **§548 抗辩 ≠ §549 抵销（头号易混）**：
  - **§548** = 债务人**对让与人的抗辩**（合同无效 / 期限 / 时效 / 已消灭…）→ 直接继受、无附加条件。
  - **§549** = 债务人对让与人另享**到期债权**、且与被转让债权"**同种类**"或"**先于 / 同时到期**"→ 可向受让人主张**抵销**（有条件）。
  - 若某选项写"债务人**以其对让与人的到期债权抵销**"——那是 §549 抵销，**不是**普通 §548 抗辩，套错条文会判错。
- **C 的时效陷阱（"已过" vs "进行中"）**：本题 C 写"**已经过**诉讼时效"——转让时**已过期** → 通知**不产生中断**、债权不会复活 → 时效抗辩随债权移转，债务人可主张（✓）。反向陷阱：若债权**尚在时效期内**，债权转让**通知到达之日**起诉讼时效**中断**（重新计算）——此时谈"时效已过"就不成立。**"已过"才有时效抗辩，"进行中"则因通知而中断**。
- **"我没收到转让通知"不是本类抗辩（§546，别混）**：未收到通知时，转让**对债务人不发生效力**，债务人**向让与人清偿仍有效**（§546）——这是"**向谁清偿**"的保护，不是对债权本身的"成立 / 存续 / 行使"抗辩。考点归 §546，**别塞进 §548 的抗辩继受里**。
- **从权利随附（§547）顺带记**：债权转让时，**抵押权 / 保证 / 利息**等从权利随同移转，且**不因未办转移登记或未转移占有而受影响**（§547 II，§209 登记生效主义的法定例外）——见 [[合同通则-单选-21]]。

### 怎么答

ABCD。债权转让"**抗辩随债权一起跑**"——A 合同无效（债权不存在）、B 履行期未到（期限抗辩）、C 时效已过（时效抗辩随移转、已过不复活）、D 合同已消灭（已清偿 / 抵销 / 解除），四项都是债务人本可对让与人主张的真实抗辩，依 §548 全部可向受让人主张。故选 **ABCD**。

## 📐 答题口诀 · 抗辩随债权跑（原来能对让与人说的"不"，对受让人照样说）

> **"债权转让 = 二手过户，带病移交。债务人对**让与人**能提的抗辩——合同无效、期限未到、时效已过、合同已灭——对**受让人**照样能提（§548）。受让人**不会**比让与人拿到更干净的债权。"**

### 🚗 老王小李故事

> 老王把车**赊卖**给小李，小李欠老王一笔**购车款**（这就是"乙公司对甲公司的购销债权"——老王＝让与人乙、小李＝债务人甲）。后来老王把"向小李要这笔钱"的债权**转让给老张**（受让人丙）。现在老张拿着债权找小李：还钱！小李能拿哪些理由（抗辩）**对抗老张**？
>
> 关键：老张接手的是一张**"二手、带原来所有毛病"**的债权——小李原来能对老王说的"不"，对老张**照样说**。
>
> - **A 合同无效**：老王卖小李的那辆车，买卖合同其实**无效**（比如标的违法）→ 这笔债权**根本没成立** → 小李本就不欠老王 → 对老张也能说"合同无效，我不付"（A✓）。
> - **B 履行期未到**：老王和小李约好"**提车 3 个月后**付款"，现在才过 1 个月 → 小李对老张说"**还没到约定的付款日**，凭啥现在要？"（B✓）。
> - **C 时效已过**：这笔车款小李**拖了好几年、已过 3 年诉讼时效** → 小李取得**时效抗辩**；老张接手的是一张**"已经过期"**的债权（转让**不会**让过期债权起死回生）→ 小李对老张主张"**过了时效，我有权不还**"（C✓）。
> - **D 合同已消灭**：其实小李**早把车款付清了**（或双方已解除 / 已抵销）→ 债权**早就消灭** → 老张手里是张"**空债权**" → 小李对老张说"这债**早没了**"（D✓）。
>
> 诀窍：受让人 ≠ 升级版债权人。债权**原汁原味过户、抗辩跟着债权跑** → 四个"不"小李对老张全能说 → **ABCD**。
>
> ⚠️ **对照反例**（不属本题抗辩）：① 若小李说"我**没收到**转让通知"——那是 §546 的"向谁清偿"问题，不是对债权本身的抗辩；② 若小李说"**老王还欠我**一笔到期货款，拿来抵"——那是 §549 的**抵销权**（要"同种类 + 先于/同时到期"），走另一条规则。

### 🎯 一句话记忆

> **"债权转让 = 二手带病过户：债务人对让与人的抗辩（无效 / 期限未到 / 时效已过 / 已消灭）全部随债权移交受让人（§548）。"**
> **"受让人不会拿到更干净的债权——原来能说的'不'，照样说。"**
> **"抗辩（§548）≠ 抵销（§549，有条件）≠ 没收到通知（§546，向谁清偿）。"**

### 填空模板（主观题用）

> 依《民法典》**§548**，债务人对**【让与人】**的抗辩，可以向**【受让人】**主张（**抗辩继受**，法理为**债权同一性**——受让人承继让与人地位、债权连同瑕疵一并移转）。本题中甲对乙享有的抗辩——**【A 合同无效（债权自始不发生）/ B 履行期未届至（期限抗辩）/ C 已过诉讼时效（时效抗辩随债权移转，已过不复活）/ D 合同已消灭（已清偿、抵销、解除）】**——均为债务人本可对让与人主张的真实抗辩，故甲**均可**向受让人丙主张。故选 **ABCD**。
