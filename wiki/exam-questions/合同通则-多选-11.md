# C1-多选-11 · 债权转让后债务人对受让人的抗辩

## 题干

> 乙公司将对甲公司的购销债权转让给丙公司，丙公司请求甲履行。甲有权提出下列哪些抗辩？

- A. 甲乙之间合同无效的抗辩
- B. 合同履行期尚未届至的抗辩
- C. 被让与债权已经过诉讼时效的抗辩
- D. 合同已经消灭的抗辩

## 我的答案

**ABCD**<!-- confidence: INFERRED -->

## 涉及考点

- [[债权转让]] 抗辩继受（§548）

## 考点精解 · 债务人对受让人的抗辩范围

### 是什么 / 易混

**§548**（抗辩继受规则）：债务人对**让与人**的**抗辩**，可以向**受让人**主张。

→ 一切**债权转让通知到达前**已经产生 / 可能产生的抗辩，都能用：
- A 合同无效 → 标的债权本就不存在 → 对
- B 履行期未届至 → 期限抗辩 → 对
- C 时效已过 → 时效抗辩 → 对
- D 合同已消灭（如已清偿 / 已抵销 / 已解除）→ 对

### 怎么考 / 坑在哪

- **核心理念**：受让人取得"原汁原味"的债权，能用的抗辩 = 能继受
- **抵销特别规则**（§549）：债务人在转让通知到达时**对让与人享有**到期债权 + 与被转让债权"同种"或"先于到期" → 可向受让人主张抵销

### 怎么答

ABCD。债权转让"抗辩随债权一起跑"。
