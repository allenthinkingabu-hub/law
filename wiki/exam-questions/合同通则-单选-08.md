# C1-单选-08 · 数据电文形式要约的生效规则

## 题干

> 关于采用数据电文形式的要约的生效规则，下列说法**错误**的是：

- A. 要约人与受要约人对生效时间有约定的，按照其约定
- B. 受要约人指定特定系统接收数据电文的，要约自该数据电文进入该特定系统时生效
- C. 未指定特定系统的，要约自受要约人知道或者应当知道该数据电文进入其系统时生效
- D. 采用数据电文形式的要约自进入受要约人的任一系统时生效

## 我的答案

**D**（错误说法）<!-- confidence: INFERRED -->

## 涉及考点

- [[要约]] · 数据电文的到达规则（§137 + §474）

## 考点精解 · 数据电文到达规则

### 是什么 / 易混

**§137 数据电文到达规则**（适用于要约 / 承诺 / 一般意思表示）：

| 情形              | 生效时点                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| 当事人**有约定**      | 按约定                                                                                        |
| 受要约人**指定特定系统**  | 数据电文**进入该特定系统**时                                                                           |
| 受要约人**未指定特定系统** | 数据电文**进入其任一系统的首次时间** 或 受要约人**知道/应当知道**该电文已进入其系统时（看具体规则版本，民法典通常以"进入任一系统的首时间"或"知道/应当知道"为生效点） |

**关键陷阱**：D "进入任一系统" 漏掉了"指定特定系统"和"知道 / 应当知道"两种情形，过于绝对。

### 怎么考 / 坑在哪

- A、B、C 都精准对应法条层级——有约定 → 按约定；指定系统 → 进入指定系统；未指定 → 进入或知道
- D "任一系统" 不正确，因为如果受要约人指定了系统，进入"其他系统"不算到达

### 怎么答

D 表述与 §137 + §474 规则不符，属于错误说法。故选 **D**。

### 🔥 关键背景 · 旧法 → 新法的演变

D 选项的"任一系统"是**旧法（合同法 §16 II）话术**——民法典 §137 已废止此规则：

| 法律 | 未指定系统时规则 | 哲学 |
|---|---|---|
| **旧法**：合同法 §16 II（2021 前） | "进入**任一系统**的首次时间" | 客观主义 |
| **新法**：民法典 §137（2021 起） | "**知道 / 应当知道**" | 主客观结合（保护收件人）|

→ 见到 "**任一系统**" = 旧法陷阱 = 错；见到 "**知道 / 应当知道**" = 新法 = 对。

### 📐 答题口诀 · §137 三步走

> 碰到"数据电文何时到达 / 生效"题，**三步走**：

#### Step 1：先看有没有约定
```
有约定 → 按约定（§137 第 3 句）
无约定 → Step 2
```

#### Step 2：看收件人有没有指定特定系统
```
指定了 → 进入该特定系统之时生效
        ├─ 发到指定系统：进入时生效
        └─ 发到非指定系统：不生效（哪怕看到了）
未指定 → Step 3
```

#### Step 3：未指定 → 套"知道 / 应当知道"
```
进入收件人的系统 + 【知道】       → 生效（如电话告知）
进入收件人的系统 + 【应当知道】   → 生效（如常用工作邮箱）
进入收件人的系统 + 【不应当知道】 → 不生效（如废弃 5 年的邮箱）
```

### 📋 Q08 套用结果

| 选项 | 内容 | §137 对应层 | 判定 |
|---|---|---|---|
| A 有约定按约定 | 第 3 句"另有约定" | 层 ① | ✅ 对 |
| B 指定特定系统 → 进入该系统时 | 第 1 句 | 层 ② | ✅ 对 |
| C 未指定 → 知道 / 应当知道时 | 第 2 句 | 层 ③ | ✅ 对 |
| **D 进入任一系统时** | **旧法话术** | 不在新法中 | ❌ **错** |

→ 题目问"**错误**" → **答 D**

### 🎯 一句话记忆

> **"3 层规则：约定 → 指定系统 → 知道/应当知道"**  
> **"见'任一系统' = 旧法陷阱 = 错"**

### ⚠️ 易混区分：§137 vs §491

| 维度 | **§137** 数据电文到达 | **§491** 电子合同成立 |
|---|---|---|
| 适用对象 | **意思表示通用**（要约/承诺/通知）| 电子合同特殊（淘宝/拼多多）|
| 解决问题 | **何时生效**（一方意思表示）| **合同何时成立**（双方合意）|
| 关键时点 | 知道 / 应当知道 | **提交订单成功时** |

→ Q08 考 §137；[[合同通则-单选-10]] 考 §491——不要搞混。
