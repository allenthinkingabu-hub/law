# 刑法-总论-犯罪论-单选-17 · 正当防卫之不法侵害正在进行（真题·2007卷二2）

## 题干

> 来源：**真实真题** · 2007 年国家司法考试卷二第 2 题（已联网核验：司法部官网收录该年卷二真题 https://www.moj.gov.cn/jgsz/jgszzsdw/zsdwgjsfkszx/gjsfkskskt/202102/t20210203_172290.html ；中国教育在线 sifa.eol.cn 题干+答案 C https://sifa.eol.cn/sifaquanjiexi/juaner/xingfa/201203/t20120329_759806.shtml ）。

陈某抢劫出租车司机甲，用匕首刺甲一刀，强行抢走财物后下车逃跑。甲发动汽车追赶，在陈某往前跑了 40 米处将其撞成重伤并夺回财物。关于甲的行为性质，下列哪一选项是正确的？

- A. 法令行为
- B. 紧急避险
- C. 正当防卫
- D. 自救行为

## 我的答案

**C**<!-- confidence: EXTRACTED -->

本题考"不法侵害是否正在进行"的时间条件。抢劫犯逃离现场不远、赃物尚可当场挽回的，依教义学（及后来法发〔2020〕31 号时间条件精神）认定不法侵害尚未结束，甲撞击夺回财物属正当防卫，**C 对**。

- **A 错**：法令行为指法律法规明文授权的行为（如依法逮捕、依法执行死刑），本题甲的行为与法令授权无关。
- **B 错**：紧急避险是损害无辜第三人合法权益以保全更大法益；本题甲损害的是侵害人陈某本人，而非无辜第三人，方向与避险不符。
- **C 对**：财产犯罪中行为人虽已离开现场，但当场来得及挽回损失的，视为不法侵害尚未结束，针对侵害人本人的反击成立正当防卫。
- **D 错**：自救行为针对的是**已经结束**的不法侵害的事后救济（如发现小偷次日上门追赃），本题侵害尚未结束，不属自救。

**陷阱**：财产犯罪"正在进行"的特例——行为人已离开现场但当场来得及挽回损失的，视为侵害尚未结束；命题人用"下车逃跑＋跑了 40 米"制造"已结束"假象。

## 考点精解 · 正当防卫五要件与"正在进行"的财产犯罪特例

正当防卫的成立须同时满足五个要件，任缺其一即不成立：

| 要件 | 含义 | 本题对应 |
| --- | --- | --- |
| 起因条件 | 存在现实的不法侵害 | 陈某抢劫，✓ |
| 时间条件 | 不法侵害正在进行 | 赃物当场可挽回，未结束 ✓ |
| 主观条件 | 具有防卫认识与意志 | 甲为夺回财物而追 ✓ |
| 对象条件 | 针对侵害人本人 | 撞的是陈某本人 ✓ |
| 限度条件 | 未明显超过必要限度 | 抢劫属暴力犯罪，重伤未明显过当 ✓ |

**"正在进行"的财产犯罪特例（金钥匙）**：

```
普通规则：侵害结束 → 不得防卫（事后防卫）
财产犯罪特例：
  行为人已离开现场，但"当场"来得及挽回损失
      ↓
  视为不法侵害"尚未结束"→ 仍可防卫
判断核心：能否当场、立即挽回 ≠ 是否离开了现场
```

本题"跑了 40 米""刚下车"正是"当场可挽回"的典型场景，故侵害未结束。
