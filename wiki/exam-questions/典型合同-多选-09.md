# C2-多选-09 · 保证期间 vs 保证债务诉讼时效

## 题干

> 下列关于**保证期间**和**保证债务诉讼时效**的表述，哪些是正确的？

- A. 保证期间可以适用诉讼时效中止中断的规定
- B. 保证债务的诉讼时效起算后 → 不必再计算保证期间
- C. 一般保证的诉讼时效从债权人对债务人提起诉讼或仲裁时起算
- D. 连带责任保证债务的诉讼时效从债权人请求保证人履行债务时起算

## 涉及考点

- [[保证合同]] 期间 / 时效 区分（§692、§694）

## 考点精解 · 保证期间 vs 诉讼时效

### 是什么 / 易混

**§692**（保证期间）：
> 保证期间是确定保证人**承担保证责任的期间**，**不发生中止、中断、延长**。

**§694**（保证债务诉讼时效起算）：
- **一般保证**：从**对债务人的判决 / 仲裁裁决生效之日**起算
- **连带责任保证**：从**债权人请求保证人**承担保证责任之日起算

本题对照：
- A 保证期间适用中止中断延长 → 错（§692 III 明确不适用）
- B 进入诉讼时效后不再计算保证期间 → 对（**期间是承担入口，时效是程序终点**——已转入时效阶段则期间使命完成）
- C 一般保证时效从"对债务人起诉时" → 错（应从**裁决生效**起算）
- D 连带保证时效从请求保证人时起算 → 对

### 怎么考 / 坑在哪

- **C 经典陷阱**：把"债权人对债务人起诉时" vs "裁决生效时"搞混
- **核心区别**：保证期间是"是否担责"的关口；诉讼时效是"还能否起诉"的程序时限
