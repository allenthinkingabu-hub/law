# C2-多选-09 · 保证期间 vs 保证债务诉讼时效

## 题干

> 下列关于**保证期间**和**保证债务诉讼时效**的表述，哪些是正确的？

- A. 保证期间可以适用诉讼时效中止中断的规定
- B. 保证债务的诉讼时效起算后 → 不必再计算保证期间
- C. 一般保证的诉讼时效从债权人对债务人提起诉讼或仲裁时起算
- D. 连带责任保证债务的诉讼时效从债权人请求保证人履行债务时起算

## 考点精解 · 保证期间 vs 诉讼时效

### 是什么 / 易混

**§692**（保证期间）：
> 保证期间是确定保证人**承担保证责任的期间**，**不发生中止、中断、延长**。

**§694**（保证债务诉讼时效起算）：
- **一般保证**：从**"保证人拒绝承担保证责任的权利（先诉抗辩权 §687）消灭之日"**起算——具体即**担保制度解释§28**：债权人对债务人财产强制执行、法院作出**终结本次执行程序裁定送达债权人之日**起算。
  - ⚠️ **旧担保法解释§34"判决 / 仲裁裁决生效之日"已于 2021 废止**，别再用；现行是"先诉抗辩权消灭之日（终本裁定送达日）"。
- **连带责任保证**：从**债权人请求保证人**承担保证责任之日起算（§694②）

本题对照：
- A 保证期间适用诉讼时效中止 / 中断 → **错**：保证期间是**除斥期间**性质，[[民法典]]§692 明文"**不发生中止、中断和延长**"（详见下方🚗例子）
- B 进入诉讼时效后不再计算保证期间 → 对（**期间是承担入口，时效是程序终点**——已转入时效阶段则期间使命完成）
- C 一般保证时效从"对债务人起诉 / 仲裁时" → **错**：现行 §694 应从**"先诉抗辩权消灭之日"**起算（担保解释§28：终本裁定送达债权人之日）；C 把它提前到"起诉时"是错的。（注：旧法"裁决生效之日"也已废止，别拿旧标准当对错依据）
- D 连带保证时效从请求保证人时起算 → 对

### 🚗 例子说明 A（为什么保证期间不中止、不中断）

> 乙借给甲 100 万，丙作**连带责任保证**，**没约定保证期间** → 保证期间 **6 个月**（§692）；主债 **2024/1/1 到期** → 保证期间窗口 **2024/1/1 ~ 7/1**。

- **① 不"中断"**：乙在 3 月、5 月两次催债务人甲。**若保证期间像诉讼时效那样中断**，每催一次就重新起算 6 个月、窗口被无限拉长；**但 §692 说不中断** → 丙的窗口仍在 **7/1 准时关上**。且连带保证须在窗口内**请求保证人丙**才算主张，乙只催了甲、7/1 前没请求丙 → **7/1 一到，丙彻底免责**。
- **② 不"中止"**：假设 6/20（临界点）发生不可抗力，乙没来得及请求丙。**诉讼时效遇障碍会中止**（暂停顺延）；**但保证期间不中止** → 仍在 **7/1 准时届满**，乙错过 → **丙免责**。
- **✅ 对比（什么才中止中断）**：乙若在 7/1 前就**请求了丙**（正确主张），保证期间**使命完成**，接着才开始算"**保证债务诉讼时效**"（3 年）——**这个诉讼时效才可以中止 / 中断**（§694 衔接）。

> 一句话：**保证期间 = 固定关门时间，不重置不暂停（§692）；只有它届满前主张后接力的"保证债务诉讼时效"才中止中断。A 把两者搞反了。**

> ⚠️ **别把"接力"误当成"保证期间中断"**："中断"是法律专用词＝**同一个时钟清零重数**，只有诉讼时效有。债权人在期间内主张后，保证期间**不是重新计时，而是任务完成、就此退场、永远消失**；随后**另起一个全新时钟**——保证债务诉讼时效（3 年）。能中止 / 中断的是**这个新时钟**，不是已退场的保证期间。
> 🏃 **接力赛比喻**：保证期间 = **第一棒**（固定 6 个月，喊加油不重跑＝不中断、累了不能停＝不中止；跑到交接区就**交棒下场**）；保证债务诉讼时效 = **第二棒**（接棒后跑 3 年，**这一棒才能暂停 / 重跑**）。"接力"是**换人**，不是第一棒自己重来。
> 📅 **数字版**（连带保证，窗口 1/1~7/1）：乙 5/1 请求丙（窗口内主张）→ 保证期间**到此退场**（不是从 5/1 重算 6 个月！），从 5/1 起算**保证债务诉讼时效 3 年**（至 2027/5/1）；这 3 年里催丙 / 起诉丙才会让**这 3 年**中断重算、遇障碍才中止——都与已下场的保证期间无关。

> ❓ **保证期间到底"什么时候没"的？看有没有人接力**：
> - **有人主张（接力）** → 保证期间在**主张那一刻**就功成身退，**不用等到到期日**。证据：连带保证 §694 规定诉讼时效从"**请求日（5/1）**"起算、**不是**从到期日（7/1）起算 → 反推 5/1 当场就交棒了。
> - **没人主张（没接力）** → 保证期间才会**空跑到到期日（7/1）届满**，随后**保证人免责**。
> - （一般保证小细节：5/1 起诉债务人 → 保证期间 5/1 退场，但诉讼时效要等"先诉抗辩权消灭"＝裁决生效+执行不能才起算，中间是过渡期；保证期间仍在 5/1 就退场，不走到 7/1。）

### 怎么考 / 坑在哪

- **C 经典陷阱**：一般保证时效起算**不是**"对债务人起诉时"，而是**"先诉抗辩权消灭之日"**（§694 ／担保解释§28 终本裁定送达债权人之日）；⚠️"裁决生效之日"是**已废止**的旧担保法解释§34 表述，别再用
- **核心区别**：保证期间是"是否担责"的关口；诉讼时效是"还能否起诉"的程序时限
