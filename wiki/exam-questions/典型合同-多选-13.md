# C2-多选-13 · 律师事务所的随时解除权

## 题干

> 律师事务所代理某案件一、二审，一审开庭后建议不再代理，事务所坚持，结果一审败诉。下列哪些表述正确？

- A. 律师事务所有权单方解除委托合同，但须承担赔偿责任
- B. 律师事务所在委托人一审败诉后不能单方解除合同
- C. 即使一审胜诉，委托人也可解除委托合同，但须承担赔偿责任
- D. 只有故意或重大过失时，律师事务所才对败诉承担赔偿责任

## 我的答案

**AC**<!-- confidence: INFERRED -->

## 涉及考点

- [[委托合同]] 双向任意解除权（§933）
- 📐 **对照法定解除** → [[民法-合同-解除模型]]（任意解除 vs §563 法定解除）
- **有偿委托**的注意义务 = 谨慎勤勉（§929）

## 考点精解 · 律师代理的委托合同性质

### 是什么 / 易混

**§933**（双向任意解除权）：
> **委托人 / 受托人**可以**随时解除**委托合同——造成对方损失的，**有偿合同**赔**直接损失 + 可得利益损失**；**无偿合同**赔**直接损失**。

**§929**（受托人注意义务）：
- **有偿委托** → **谨慎勤勉**义务，**一般过失**即担责
- **无偿委托** → **故意 / 重大过失**才担责

本题分析：
- 律师代理 = **有偿**委托合同
- 受托人（事务所）有权随时解除 + 担赔偿 → A 对
- 委托人（败诉的客户）也有权随时解除 → 即使胜诉也可（C 对）
- B "败诉后不能解除" → **错**（§933 始终可解除）
- D "只故意 / 重大过失才担责" → **错**（有偿委托一般过失即担责）

### 怎么考 / 坑在哪

- **B 经典陷阱**：以为"已经败诉了不能再退出" → 错，任意解除权**贯穿始终**
- **D 易错**：把有偿 / 无偿委托的归责标准弄反

### 怎么答

AC。
