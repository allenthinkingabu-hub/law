# C1-多选-43 · 一房二卖与违约金酌减

## 题干

> 甲与乙签订房屋买卖合同，将一幢房屋卖与乙。双方同时约定，一方违约应支付购房款35％的违约金。但在交房前甲又与丙签订合同，将该房卖与丙，并与丙办理了过户登记手续。下列说法中哪些是正确的？

- A. 乙可以自己与甲签订的合同在先，主张甲与丙签订的合同无效
- B. 乙有权要求甲收回房屋，实际履行合同
- C. 乙不能要求甲实际交付该房屋，但可要求甲承担违约责任
- D. 若乙要求甲支付约定的违约金，甲可以请求法院或仲裁机构予以适当减少

## 答案

**CD**（233 分类真题解析页 + 2002 年官方参考答案页一致）<!-- confidence: EXTRACTED -->

- 出处：2002 年司法考试卷三第 59 题

## 新法核对（2026 视角）

**答案不变（CD）**。民法典下各依据：两份买卖合同均为债权合同、效力无先后（§215 区分原则）；过户登记生所有权变动（§209）→ 房归丙，乙不能要求实际履行（事实不能）；甲担违约责任（§577）；35% 违约金过分高于损失可请求酌减（§585 II + 通则解释 §65 的 30% 参考线）。

## 涉及考点

- 📐 **违约总模型** → [[民法-合同-违约责任模型]]（违约金④号出口酌减 + 履行不能转赔偿 §584）
- 📐 **违约金模型** → [[民法-合同-违约金模型]]（30% 酌减红线 + 恶意违约排除酌减 解释§65）
- 违约金 §585 酌减规则（[[合同总则考点-深度报告]] 违约板块 #4 · ★★★★★）
- 一房二卖：负担行为 vs 处分行为（区分原则）

## 考点精解

- **A 错**：卖两次签两份合同都有效——"一物二卖、合同均有效"是区分原则的招牌结论。
- **B 错**：房已过户给丙，丙取得所有权；乙的履行请求陷于**事实不能**。
- **C 对**：要不到房，但违约责任跑不掉。
- **D 对**：35% 的违约金可请求**适当减少**——酌减只能"请求法院或仲裁机构"，不能自行少付。

## 🎯 答题思路 → 统一模型

> 本题是"一物数卖"考点的**不动产 + 违约金酌减**范例。完整四步模型（普通动产 / 特殊动产 / 不动产三类履行顺序 + 区分原则 + 履行不能 + 违约金衔接）已统一至 → 📐 **[[民法-合同-一物多卖模型]]**。

**套用四步 → 本题 CD**：
1. **合同效力**：甲卖乙、甲卖丙两份合同**都有效**（债权平等，区分原则）→ 乙不能以"在先"主张甲丙合同无效 → **A 错**。
2. **物权归属**：房已**过户登记给丙**（§209）→ **丙得所有权**（不动产看登记）。
3. **救济**：甲对乙**履行不能**（§580）→ 乙**不能**要求实际交付，但**可**要求甲担违约责任 → **B 错、C 对**。
4. **违约金**：35% > 30% 参考线、过分高于损失 → 违约方甲**可请求**法院 / 仲裁适当减少（§585 Ⅱ）→ **D 对**（完整调整规则 → [[民法-合同-违约金模型]]）。
→ **答案：CD** ✅
