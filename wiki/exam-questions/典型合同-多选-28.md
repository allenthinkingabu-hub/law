# C2-多选-28 · 无资质建设工程施工合同：效力认定与工程价款处理

## 题干

> 甲房地产开发公司开发一个较大的花园公寓项目，作为发包人，甲公司将该项目的主体工程发包给了乙企业，签署了建设工程施工合同。乙企业一直未取得建筑施工企业资质。现该项目主体工程已封顶完工。就相关合同效力及工程价款，下列哪些说法是正确的？

- A. 该建设工程施工合同无效
- B. 因该项目主体工程已封顶完工，故该建设工程施工合同不应认定为无效
- C. 该项目主体工程经竣工验收合格，则乙企业可以参照合同约定请求甲公司折价补偿
- D. 该项目主体工程经竣工验收不合格，甲公司可以请求乙企业赔偿损失

## 我的答案

**ACD**<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **答题模型** → [[民法-合同-建设工程模型]]（第二+三步：无资质无效 → 合格折价补偿/不合格赔偿）
- [[建设工程合同]] 无资质施工：合同无效（建工解释一 §1（一））
- [[建设工程合同]] 竣工验收合格→折价补偿（建工解释一 §2）；不合格→修复费/赔偿损失（建工解释一 §3）

## 考点精解 · 无资质施工合同的"效力 + 救济"双轨规则

### 核心法条：建工解释一 §1 + §2 + §3

**§1（合同无效情形）**：承包人未取得建筑业企业资质签订的建设工程施工合同，应认定无效（属 §1（一））。

**§2（验收合格→折价补偿）**：建设工程施工合同无效，但建设工程**经竣工验收合格** → 承包人请求按照合同关于工程价款的约定**折价补偿**的，应予支持。

**§3（验收不合格→修复/赔偿）**：建设工程施工合同无效，建设工程**经竣工验收不合格** → 修复后验收合格→发包人可请求承包人承担修复费用；修复后仍不合格→承包人**无权**请求工程价款。

### 选项逐析

**A（合同无效）** → **正确**
乙企业**从未取得**建筑施工企业资质，直接触发建工解释一 §1 的无效事由，施工合同无效。

**B（封顶完工→不认定无效）** → **错**
**工程完工 ≠ 合同有效**。建工解释对"无资质"的处理是无效（§1），工程是否完工不影响效力认定。完工（甚至竣工验收合格）只影响**救济方式**（折价补偿 vs 赔偿），不影响**合同效力**本身。

**C（验收合格→折价补偿）** → **正确**
建工解释一 §2：合同无效 + 竣工验收合格 → 承包人（乙）可参照合同约定主张**折价补偿**。乙虽无资质，但工程质量合格，应当获得相应对价。

**D（验收不合格→赔偿损失）** → **正确**
建工解释一 §3：合同无效 + 竣工验收不合格 → 甲公司可要求乙企业赔偿损失（修复费用或无法修复时的赔偿）。

### 无资质合同效力与救济全景图

| 情形 | 合同效力 | 救济方式 |
|---|---|---|
| 乙无资质 | **无效** | — |
| 无效 + 验收**合格** | 无效 | 乙→甲：参照合同价**折价补偿** |
| 无效 + 验收**不合格** + 可修复 | 无效 | 甲→乙：支付**修复费用** |
| 无效 + 验收**不合格** + 不可修复 | 无效 | 甲→乙：**赔偿损失** |

### 怎么考 / 坑在哪

- **B 经典陷阱**：工程封顶/完工 → 直觉认为合同"有效"或"不再无效" → 错！效力由**资质**决定，不因完工而治愈
- **折价补偿 vs 赔偿损失** 的分水岭：**验收合格**是关键——合格才能折价补偿，不合格只能赔损失
- 本题 ACD 都正确：A（定性无效）+ C（合格→补偿）+ D（不合格→赔偿）构成完整规则

### 怎么答

ACD。乙无资质，合同无效（A对）；完工不影响效力认定，B说法错误（B错）；验收合格→折价补偿（C对）；验收不合格→赔偿损失（D对）。
