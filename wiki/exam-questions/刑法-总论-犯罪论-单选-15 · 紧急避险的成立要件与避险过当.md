# 刑法-总论-犯罪论-单选-15 · 紧急避险的成立要件与避险过当

## 题干

> 来源：依据《刑法》第21条（紧急避险）命制的**仿真题**（题干为本库命制，非历年真题；§21已联网核验 CONFIRMED，spp.gov.cn）。

关于紧急避险，下列说法**正确**的是？

- A. 只要面临危险，行为人即可损害他人法益避险，无需"不得已"
- B. 为保全自己价值1万元的财物，可以损害他人价值5万元的财物
- C. 紧急避险须现实危险正在发生、不得已、针对第三人无辜法益，且所保护法益不小于所损害法益；超过必要限度造成不应有损害的，成立避险过当，应当减轻或免除处罚
- D. 为保全自己的生命，可以牺牲另一无辜者的生命进行避险

## 我的答案

**C**<!-- confidence: EXTRACTED -->

正确答案为 **C**。

《刑法》第21条：①为使法益免受**正在发生的危险**，②**不得已**采取的紧急避险，③造成损害不负刑责；④**超过必要限度造成不应有损害的**（避险过当），应当负刑责，**但应当减轻或免除处罚**。成立要件：现实危险 + 正在发生 + **不得已（补充性）** + 针对**第三人无辜法益** + 限度（**所保护≥所损害**）+ 避险意图。

- **A 错误**：紧急避险以**"不得已"（补充性）**为要件——只有别无其他合理避险方法时才可损害第三人法益。
- **B 错误**：限度要求**所保护法益不小于所损害法益**；为保 1 万损 5 万，是"以大保小"，超过必要限度，成立**避险过当**。
- **C 正确**：完整列举了五要件 + 避险过当的后果（§21Ⅱ应减轻或免除）。
- **D 错误**：**不允许牺牲他人生命保全自己生命**（生命不能比较、不能成为避险手段牺牲品），此种"避险"不成立、应负刑责。

**陷阱**：①漏"不得已"要件；②误判限度（以大保小、牺牲生命保生命）；③把避险过当后果记错（应"减轻或免除"）。

## 考点精解 · 紧急避险五要件 + 限度

```
①现实危险（自然/动物/他人无辜法益等）
②正在发生
③不得已（补充性）──── 别无他法才可避险（区别于正当防卫）
④针对第三人无辜法益
⑤限度：所保护法益 ≥ 所损害法益
       （不得以大保小；不得牺牲他人生命保自己生命）
   超过必要限度造成不应有损害 → 避险过当§21Ⅱ（应减轻/免除）
```

| 命题陷阱 | 正解 |
|---|---|
| "面临危险即可避险，无需不得已"（A）| 错：须"不得已"补充性 |
| "为保1万损5万"（B）| 错：以大保小→避险过当 |
| "牺牲他人生命保自己生命"（D）| 错：不允许，应负刑责 |

> 要害：避险比防卫多两道关——**"不得已"** 和 **"所保护≥所损害"**。
