# 侵权-多选-07 · 肖像权名誉权精神损害-艺术照纠纷

## 题干

> 来源：2011-3-66（司考真题，多）

甲女委托乙公司为其拍摄一套艺术照。不久，甲女发现丙网站有其多张半裸照片，受到众人嘲讽和指责。经查，乙公司未经甲女同意将其照片上传到公司网站做宣传，丁男下载后将甲女头部移植至他人半裸照片，上传到丙网站。下列哪些说法是正确的？

- A. 乙公司侵犯了甲女的肖像权
- B. 丁男侵犯了乙公司的著作权
- C. 丁男侵犯了甲女的名誉权
- D. 甲女有权主张精神损害赔偿

## 我的答案

**ABCD**<!-- confidence: EXTRACTED -->

A：乙公司未经甲女同意将其照片上传网站——**未经同意使用他人肖像**，侵犯甲女**肖像权**（§1019-§1020）✓

B：乙公司对甲女艺术照享有著作权（摄影作品）。丁男下载后改造使用，未经乙公司许可，侵犯**乙公司著作权** ✓

C：丁男将甲女头部移植至半裸照片上传，使公众对甲女产生错误认知并嘲讽指责——**损害甲女名誉**，侵犯**名誉权** ✓

D：甲女的肖像权和名誉权均遭侵害，可请求**精神损害赔偿**（§1183Ⅰ：人身权利遭受侵害，可请求精神损害赔偿）✓

## 涉及考点

- [[侵权责任编]] §1019 肖像权侵害
- §1024 名誉权侵害
- §1183Ⅰ 人格权被侵害可主张精神损害赔偿
- 著作权侵权（拍摄者著作权）

## 考点精解 · 多重权利侵害

### 侵权关系梳理

```
甲女（被摄者）                乙公司（摄影者）
    ↑肖像权                      ↑著作权
    |                              |
乙公司未经同意上传              丁男下载改造
→ 侵犯甲女肖像权(A)           → 侵犯乙公司著作权(B)
                                    ↓
                              丁男头像移植上传半裸照
                              → 侵犯甲女名誉权(C)
                                    ↓
                              甲女可主张精神损害赔偿(D)
```

### §1183Ⅰ 精神损害赔偿触发条件

**人格权**（生命权、健康权、姓名权、名誉权、荣誉权、肖像权、隐私权等）遭受侵害 → 可主张精神损害赔偿。本题肖像权+名誉权均被侵害，D正确。
