# C1-单选-06 · 要约 vs 要约邀请的辨认

## 题干

> 下列情形中，哪一项**属于要约**？

- A. 甲在自己的一间商铺门上张贴告示：低价出售，价格面议
- B. 乙将自己商店出售商品的价目表寄送给客户
- C. 丙公司要建设办公大楼，在官方网站发布了招标公告
- D. 丁超市的商品实物标价陈列出售

## 我的答案

**D**（超市标价陈列）<!-- confidence: EXTRACTED -->

## 涉及考点

- [[要约]]（§472 两要件）
- [[要约邀请]]（§473 法定 5 类）
- 📐 **答题模型** → [[民法-合同-要约与承诺模型]]（第一关：定性）

## 考点精解 · 要约 vs 要约邀请

### 是什么 / 易混

- **[[要约]]**（§472）：① 内容**具体确定** + ② 表明经承诺即受约束
- **[[要约邀请]]**（§473）：希望他人向自己**发要约**；法定 5 类：招标公告 / 招股说明书 / 债券募集 / 寄送的价目表 / 一般商业广告
- 反例（要约邀请变要约）：广告或价目表内容**具体确定**到可构成要约要件时——构成要约

### 怎么考 / 坑在哪

- A "价格面议" → 价格不确定，不满足"具体确定"要件 → 要约邀请
- B "寄送价目表" → 法定要约邀请
- C "招标公告" → 法定要约邀请
- D "实物标价陈列" → 标的、价款、数量都明确，超市表达了"经承诺即出售"的意思 → 构成要约

### 怎么答

抓"两要件"：超市商品 + 标价 + 陈列售卖，三要素齐全且面向不特定顾客有约束意，属于**要约**。其他三项均缺其一。故选 **D**。

### 🔍 两要件 vs 三要素 的关系

> 很多人误以为是并列概念，其实是**父子关系**：

```
§472 要约的【两要件】 = 法律层面的总规则
   ├─ 要件 ①：内容具体确定
   │     └─ 在"超市标价"场景下 → 拆成【三要素】
   │           ├─ 商品（标的物）
   │           ├─ 标价（价款）
   │           └─ 陈列售卖（数量 = 顾客拿几个买几个）
   │
   └─ 要件 ②：表明经承诺即受约束
         └─ 在"超市标价"场景下 → 暗含"售完为止"
```

→ **三要素** = "要件 ① 内容具体确定"在超市场景下的实操化拆解，不是新的法律标准。

### 📐 答题口诀 · 三步走

> 碰到"是要约 / 要约邀请"题，**三步走**：

#### Step 1：先筛 §473 法定 5 类（口诀：**招招债价广**）

| 看到关键词 | 直接定性 |
|---|---|
| **招**标 / **招**股 / **债**券募集 / **价**目表 / 商业**广**告 | → [[要约邀请]]（除非命中反陷阱）|

#### Step 2：不命中 5 类 → 套 §472 两要件

```
要件 ① 内容具体确定？
  ├─ 标的：明确否？（商品 / 服务）
  ├─ 价款：明确否？（具体数 vs "面议" vs "起步价"）
  └─ 数量：明确否？（数量 / 频次 / 范围）
  → 任一不明确 → [[要约邀请]] / 不构成要约

要件 ② 表明经承诺即受约束？
  ├─ "售完为止"、"过期作废"、"先到先得"  → ✅ 有约束意
  ├─ "敬请咨询"、"价格面议"、"详情来电"   → ❌ 无约束意
  → 缺约束意 → [[要约邀请]]
```

#### Step 3：检查反陷阱

```
是商业广告 / 商品房广告？
  └─ 内容是否"具体确定"到足以让对方承诺即成立合同？
        ├─ 是 → 升级为 [[要约]]
        └─ 否 → 保持 [[要约邀请]]
```

### 📋 Q06 套用结果

| 选项 | Step 1 命中？ | Step 2 两要件 | Step 3 反陷阱 | 结论 |
|---|---|---|---|---|
| A 价格面议 | ❌ | 要件 ① 失败（价格不定）| — | 要约邀请 |
| B 寄送价目表 | ✅ 第 4 类"**价**" | — | 无 | 要约邀请 |
| C 招标公告 | ✅ 第 1 类"**招**" | — | 无 | 要约邀请 |
| **D 超市标价陈列** | ❌ | ✅ 两要件齐全（三要素）| — | **要约** ✅ |

→ **答 D**

### 🎯 一句话记忆

> **"5 类法定（招招债价广）+ 两要件（具体确定 + 承诺即受约束）+ 反陷阱（广告内容到位升级要约）"**
