# C1-多选-33 · 债务转移未经担保人书面同意：担保人对转移部分免责

## 题干

> 青山公司与绿水公司签署一份采购协议，由青山公司以500万元价格向绿水公司购买一批棉纺制品，货到后3个月付款。同时，自然人钱某提供了一套商品房为青山公司的付款义务作担保，并且完成了抵押登记。后经两家公司协商，其中200万元的付款义务转由虹达公司承担。就此，青山公司总经理电话通知了钱某。关于钱某的担保责任，根据《民法典》规定，下列选项正确的是？（2020金题-2-1-22）

- A. 钱某仅就300万元承担担保责任
- B. 钱某仅就200万元承担担保责任
- C. 债务转让协议应取得钱某的书面同意
- D. 钱某的担保责任因债务转移而发生变化

## 我的答案

**AD**（200 万转走未经书面同意 → 钱某对其免责 + 仅就剩 300 万担保 + 担保责任范围发生变化）<!-- confidence: EXTRACTED -->（官方参考答案：AD）

## 考点精解 · §391 担保人免责的连锁反应

### 是什么 / §391 法条原文

> **[[民法典]]§391**：第三人提供担保，**未经其书面同意**，债权人允许债务人转移全部或者部分债务的，担保人**不再承担相应的担保责任**。

> **[[民法典]]§697**：债权人未经保证人**书面同意**，允许债务人转移全部或者部分债务的，保证人对未经其同意转移的债务不再承担保证责任。**但是，债权人和保证人另有约定的除外**。

### §391（物保）vs §697（人保）核心差异

| 维度 | §391 物保（抵押 / 质押 / 留置） | §697 人保（保证）|
|---|---|---|
| **规则核心** | 未经书面同意 → 担保人对转移部分免责 | 未经书面同意 → 保证人对转移部分免责 |
| **是否允许约定例外** | ❌ **强制性规定**（无另有约定条款）| ✅ "**债权人和保证人另有约定除外**" |
| **担保物权解释 §39** | 物保领域**无约定例外** | 不适用 |
| **本题适用** | ✅（钱某用**商品房**抵押 = 物保）| 不适用（钱某不是保证人）|

→ 本题钱某用商品房抵押（物保）+ 完成抵押登记 → 适用 **§391**。

### 三大要点（§391 适用关键）

1. **必须是"书面"同意**：
   - 口头同意 ❌
   - 电话通知 ❌（本题正是此陷阱）
   - 短信通知 ❌
   - 微信 / 电邮（争议较大，最高法倾向需要明确意思表示）
   - **正式书面同意 / 签字** ✅

2. **免责范围 = 转走的部分**（不是留下的）：
   - 转走 200 万 → 担保人对 **200 万免责**
   - 留下 300 万 → 担保人**仍担保 300 万**
   - 易选反陷阱：B 选项"仅就 200 万担保"是反向陷阱 ❌

3. **债务转移本身有效 → 不以担保人同意为前提**：
   - 债务转移有效要件 = 债权人同意（§551）+ 通知担保人（不需同意）
   - 担保人未书面同意的法律后果 = **担保人对转移部分脱责**
   - **不是**"债务转移因担保人未同意而无效"
   - C 选项"债务转让应取得钱某书面同意"是**误把'免责前提'当成'转让生效前提'**的陷阱 ❌

### 4 选项陷阱深度解析

| 选项 | 判断 | 详细法理分析 |
|---|---|---|
| **A · 钱某仅就 300 万承担担保责任** | ✅ | **核心考点**：500 万原债务中 200 万转给虹达，**仅电话通知**钱某（非书面同意），依 §391，钱某对**转移的 200 万免责**，仅就剩余 **300 万** 继续承担担保责任。 |
| B · 钱某仅就 200 万承担担保责任 | ❌ | **反向陷阱**：把"免责范围"和"担保范围"搞反。免责的是**转走的部分**（200 万），担保人仍保**留下的部分**（300 万）。命题人最常用的"AB 反选"陷阱。 |
| C · 债务转让协议应取得钱某书面同意 | ❌ | **概念错位陷阱**：债务转让协议**有效**与否，只看**债权人**是否同意（§551），**不需要担保人同意**。担保人书面同意只是**担保人是否继续担保**的判断标准——未同意只是**担保人脱责**，不是"转让无效"或"转让须经其同意"。这是典型的"把免责前提误当生效前提"陷阱。 |
| **D · 钱某的担保责任因债务转移而发生变化** | ✅ | **担保范围由 500 万缩减为 300 万** = 范围**变化**了。担保责任的"质"和"量"都因债务转移而变化（钱某只对剩余 300 万继续担保 + 抵押物责任范围相应调整）。 |

→ 正确答案 = **AD** ✅

## 🔑 核心概念深度讲解 1 · "电话通知" ≠ "书面同意" 的法理基础

**§391 / §697 为什么强制要求"书面"？**

| 要点 | 法理理由 |
|---|---|
| **证据固定** | 担保人的同意是重大法律行为，影响其责任范围；书面形式锁定证据，避免事后口供争议 |
| **意思明确** | 书面要求担保人**审慎考虑**——电话中担保人可能没意识到法律后果就口头答应 |
| **强化保护** | 担保人提供财产担保是基于对**原债务人**的信任，换债务人（部分换）→ 风险变化 → 必须以书面方式明确表态 |
| **司法识别** | 法院审理时直接看"有无书面同意" → 简化判断，提高效率 |

**本题"电话通知"为什么不够？**
- ① 不是"同意"，仅是"通知"（性质完全不同）
- ② 不是"书面"，仅是"电话"（形式完全不同）
- → **双重不达标**：性质 + 形式都不符合 §391 要求

→ 这是命题人**最爱埋的陷阱**：用"通知"代替"同意"，用"电话"代替"书面"，迷惑考生。

## 🔑 核心概念深度讲解 2 · §391 vs §697 的"另有约定"例外（命题热点）

| 场景 | §391 物保（本题钱某适用）| §697 人保（保证）|
|---|---|---|
| 标准规则 | 未书面同意 → 担保人对转移部分免责 | 同左 |
| **能否事先约定免责？** | ❌ **不能**（强制性规定）| ✅ **可以**（"另有约定除外"）|
| 典型约定示例 | 不适用 | "保证人在 100 万范围内对未来债务转移仍承担保证责任" |
| 立法理由 | 物保涉及登记 / 实物，更需稳定 | 人保灵活性更高 |

→ Q33 钱某是**物保（房产抵押）**，即使青山公司与钱某事先约定"债务转移仍担保"，按 §391 + 担保制度司法解释 §39，该约定**也无效**！这是物保 vs 人保的关键差异。

## 🔑 核心概念深度讲解 3 · "免责部分" vs "未免责部分" 的精确计算

**Q33 数学模型**：

```
原债务：500 万元
                                       钱某担保范围（500 万）
                                              ↓
                ┌──────────────────────────────────────────────┐
                │ 青山公司原欠绿水 500 万                      │
                └──────────────────────────────────────────────┘

  转移后：       转移 200 万 给虹达       原债务人留 300 万
                ┌──────────────────┐    ┌──────────────────────┐
                │ 200 万（钱某免责）│    │ 300 万（钱某仍担保）  │
                └──────────────────┘    └──────────────────────┘
                       ↑                        ↑
                未经书面同意                 钱某继续担保
                  → 免责                       → A 答案
```

**钱某的最终担保责任**：
- 担保数额：500 万 → **300 万**（缩减 200 万）
- 担保物：商品房（不变）
- 担保形式：抵押（不变）
- 实际效果：抵押物执行时，最多就 **300 万**优先受偿

**如果债务全部转移（500 万都给虹达）**：
- 钱某全部免责（500 万都免）
- 抵押物可申请涂销登记（不再担保）

> **"债务搬走一部分，没让担保人书面点头 → 搬走的那块他不保了，只保留下的。500 转 200，担保保 300 不保 200。"**

### 关键词触发表

```
看到题干关键词                                    → 判断
"债务转移 + 电话通知/口头通知/未书面同意担保人"     → §391 担保人对转移部分免责 ★
"500 万转走 200 万，担保人保多少"                  → 保留下的 300 万（A），不是 200 万（B 反）

"事先约定即使转移仍担保"                           → 物保（§391）无效；人保（§697）有效
```

## 🆚 §551 债权人同意 vs §391 担保人书面同意 — 一表速记

| 维度 | §551 债务转移 → 债权人同意 | §391 担保人书面同意 |
|---|---|---|
| **谁的同意** | **债权人**（如本题绿水）| **担保人**（如本题钱某）|
| **作用** | 债务转移的**生效要件** | **担保人是否继续担保**的判断标准 |
| **未取得后果** | 转移**对债权人完全无效** | 转移**有效** + 担保人**对转移部分免责** |
| **形式要求** | 一般同意即可（明示或默示）| **必须书面同意** ★ |
| **本题适用** | 青山 + 绿水协商 → 取得绿水同意 ✅ | 仅电话通知钱某 → 未取得钱某书面同意 ❌ |

→ **两个"同意"作用完全不同，命题人最爱混淆**。

## 🆚 §391 物保 vs §697 人保 — 一表速记

| 维度 | §391（物保 · 本题适用） | §697（人保 · 保证）|
|---|---|---|
| **担保类型** | 抵押 / 质押 / 留置 / 定金 | 保证（一般 / 连带）|
| **规则核心** | 未书面同意 → 担保人对转移部分免责 | 同左 |
| **"另有约定"例外** | ❌ **无**（强制性规定）| ✅ **有**（"债权人和保证人另有约定除外"）|
| **担保制度司法解释 §39** | 物保领域无约定例外 | 不适用 |
| **典型案例** | Q33 钱某商品房抵押（物保）| 假设钱某是保证人（人保）|

## 🎯 一句话记忆

> **"债务搬家，担保人没书面点头 → 搬走的那块他不保，只保留下的（500→300）。电话通知不算书面同意。"**

> **"物保（§391）一刀切：电话通知 = 免责，约定无效；人保（§697）可约定：'转移仍保'有效。"**

> **"债权人同意 = 转移生效；担保人书面同意 = 担保继续。两个'同意'，作用完全不同。"**

## 填空模板（主观题用）

> 本题中，青山公司将 200 万付款义务转给虹达公司**【已经债权人绿水公司同意 → §551 转移有效】**。
>
> 关于担保人钱某：钱某提供**【商品房抵押 + 完成抵押登记】**，属于**【物保】**（适用 §391）。青山公司**【仅以电话通知】**钱某债务转移情况，**【非书面同意】**——
>
> 依 **[[民法典]]§391**："第三人提供担保，未经其书面同意，债权人允许债务人转移全部或者部分债务的，担保人**【对转移的部分不再承担担保责任】**。"
>
> 故钱某对**【转走的 200 万免责】**，**【仅就剩余 300 万】**承担担保责任（A），担保范围**【从 500 万缩减为 300 万】**——担保责任**【发生变化】**（D）。
>
> 排除分析：
> - B 错（**【免责的是转走的 200 万，不是留下的；选项把范围搞反】**）
> - C 错（**【债务转让协议有效不以担保人同意为前提，§551 只需债权人同意；担保人未书面同意的后果是免责，不是"转让无效"或"须经其同意"】**）
>
> 故选 **AD**。

## 横向真题对照

- 本题（多选-33）= 债务转移未经担保人书面同意 → 担保人对转移部分免责 → **AD**（2020 金题）
- [[合同通则-单选-52]] = 债务转移须**债权人**同意（§551）+ 代位权诉讼次债务人抗辩 → B（2011-3-12）
- [[合同通则-单选-57]] = 以"欠款人"身份共同签欠条 → 并存的债务承担 §552 → C（2017-3-9）
- [[合同通则-单选-59]] = 债权连环转让 + 债务转移求偿（§524 第三人代为清偿）→ D（2012-3-13）
- [[合同通则-多选-32]] = 部分债权转让 + 通知不得擅撤 → CD
- [[合同通则-多选-34]] = 债务加入（并存承担）系列
- → "**债务转移涉及的三类同意**"对照：
  - **债权人同意（§551）** → 转移生效要件
  - **担保人书面同意（§391/§697）** → 担保人是否免责
  - 与 §552 债务加入对照：加入仅需通知，无须担保人同意（独立加入，不影响原担保）
