# C1-多选-33 · 债务转移未经担保人书面同意：担保人对转移部分免责

## 题干

> 青山公司与绿水公司签署一份采购协议，由青山公司以500万元价格向绿水公司购买一批棉纺制品，货到后3个月付款。同时，自然人钱某提供了一套商品房为青山公司的付款义务作担保，并且完成了抵押登记。后经两家公司协商，其中200万元的付款义务转由虹达公司承担。就此，青山公司总经理电话通知了钱某。关于钱某的担保责任，根据《民法典》规定，下列选项正确的是？（2020金题-2-1-22）

- A. 钱某仅就300万元承担担保责任
- B. 钱某仅就200万元承担担保责任
- C. 债务转让协议应取得钱某的书面同意
- D. 钱某的担保责任因债务转移而发生变化

## 我的答案

**AD**<!-- confidence: EXTRACTED -->（官方参考答案：AD）

## 涉及考点

- [[债务承担]]（债务转移 · §551 · 触发 §391）
- [[担保]]（§391 担保人书面同意 · 转移部分免责）

## 考点精解 · 债务转移 + 担保人免责（§391）

### 是什么 / 易混

- **§391 铁律**：第三人提供担保，**未经其书面同意**，债权人允许债务人转移**全部或部分债务**的，担保人对**转移的部分**不再承担担保责任。
- 本案：500 万付款义务中 **200 万转给虹达**，仅"**电话通知**"钱某（**未取得钱某书面同意**）→ 钱某对转移的 200 万**免责**，**仅就剩余 300 万**继续担保。

| 选项 | 判断 | 理由 |
|---|---|---|
| **A 仅就 300 万担保** | ✅ | 200 万转移未经书面同意 → 钱某对其免责，剩 300 万 |
| B 仅就 200 万 | ❌ | 正好反了——免责的是转移走的 200 万 |
| C 债务转让应取得钱某书面同意 | ❌ | 债务转移**有效不以担保人同意为前提**；未经同意的法律后果是**担保人免责**，而非"转让须经担保人同意" |
| **D 担保责任因债务转移而变化** | ✅ | 担保范围由 500 万缩减为 300 万 = 发生变化 |

### 怎么考 / 坑在哪

- **A vs B**：免责的是"**转走的那部分（200 万）**"，担保人只对"**留下的（300 万）**"负责。别选反。
- **C 陷阱**：债务转移本身**不需要担保人同意**就有效；担保人未书面同意只是**自己脱责**，不是"转让无效/须经其同意"。

## 📐 答题口诀 · 债务转移没经担保人书面同意 → 转走的部分担保人免责

> **"债务搬走一部分，没让担保人书面点头 → 搬走的那块他不保了，只保留下的。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"债务转移 + 仅电话通知/未书面同意担保人"       → 担保人对转移部分免责（§391）★
"500 万转走 200 万，担保人保多少"             → 保剩下的 300 万（A），不是 200 万（B 反）
"债务转让应经担保人书面同意"                  → 错（转让有效，未同意=担保人免责，非须同意）
"担保责任是否变化"                            → 变化（范围缩减）
```

### 🚗 老王小李故事

> 青山公司欠绿水公司 500 万货款，钱某拿一套房子（已抵押登记）替青山的付款义务作担保。后来青山把其中 **200 万**的付款义务甩给了虹达公司，只**打了个电话**通知钱某（没让钱某**书面签字同意**）。钱某还保多少？——只保**剩下的 300 万**（A）！那转走的 200 万，没经钱某书面点头，钱某**不保了**（§391）。注意别选反成"只保 200 万"（B）。债务搬家本身有效、不用担保人同意（C 错），只是没同意的后果是担保人对那块脱责（D：责任变了）。

### 🎯 一句话记忆

> **"债务转走没经担保人书面同意 → 转走部分免责，只保留下的（500→300）。"**

### 填空模板（主观题用）

> 200 万付款义务转移仅**【电话通知、未经钱某书面同意】**，依 §391，钱某对**【转移的 200 万免责】**，**【仅就剩余 300 万】**承担担保责任（A），担保责任**【发生变化（缩减）】**（D）；债务转移**【有效不以担保人同意为前提】**（C 错）。故选 **AD**。
