# C1-单选-42 · 教育培训"保证达线否则退费"：违背规律但有效

## 题干

> 甲与乙教育培训机构就课外辅导达成协议，约定甲交费5万元，乙保证甲在接受乙的辅导后，高考分数能达到二本线。若未达到该目标，全额退费。结果甲高考成绩仅达去年二本线，与今年高考二本线尚差20分。关于乙的承诺，下列哪一表述是正确的？（2012-3-11）

- A. 属于无效格式条款
- B. 因显失公平而可撤销
- C. 因情势变更而可变更
- D. 虽违背教育规律但属有效

## 我的答案

**D**（双方真实约定，违背教育规律但有效，未达线应退费）<!-- confidence: EXTRACTED -->（官方参考答案：D）

## 考点精解 · 有效 vs 无效/可撤销 的排除法

### 是什么 / 易混

"保证达二本线、否则全额退费" = 双方**真实意思**达成的**对赌式服务条款**：

- **不违反法律/行政法规强制性规定**、不违背公序良俗 → **有效**（§143、§153）。
- 虽然"保证提分"违背教育规律（教学效果本难承诺），但**法律不因'违背行业规律'而否定其效力**——它只是个有风险的承诺，乙愿赌服输。

### 怎么考 / 坑在哪

- **A"无效格式条款"错**：这是双方协商的核心交易条款，非"不合理免责"的格式条款；且它**加重的是乙自己**的责任（保证 + 退费），对甲有利，不可能因 §497 无效。
- **B"显失公平可撤销"错**：显失公平要求一方利用对方危困/缺乏判断**致双方利益严重失衡**；本条款是乙自我加重义务，无失衡。
- **C"情势变更"错**：差 20 分是履行结果未达标，非"客观情况重大变化致显失公平"，不属情势变更。

### 怎么答

排除 A/B/C，落在"有效" → 乙未达标应全额退费 → 选 **D**。

## 📐 答题口诀 · 效力四级排除法：先问"违不违强制/公序良俗"

> **"自我加责的承诺最'有效'；违背行业规律 ≠ 法律无效。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"保证达标 / 否则退费"（自我加重义务）        → 有效（对相对人有利）
"违背教育规律 / 行业惯例"                    → 不影响合同效力（只是商业风险）
"无效格式条款"（但条款加重己方）             → 错（§497 针对免己责，不针对加己责）
"显失公平 / 情势变更"                        → 需"利益严重失衡 / 客观巨变"，本题没有
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 无效格式条款 | ❌ | 加重乙己方义务，非不合理免责 |
| B 显失公平 | ❌ | 乙自我加责，无利益失衡 |
| C 情势变更 | ❌ | 未达标是履行结果，非客观巨变 |
| **D 有效** | ✅ | 真实意思 + 不违强制规定 |

### 🚗 老王小李故事

> 小李交 5 万给老王的培训班，老王拍胸脯："保证你娃考上二本，考不上全退！"结果差 20 分。老王这承诺有效吗？——**有效**。这是老王自愿给自己上的"军令状"（自我加重义务），法律最乐见这种对相对人有利的承诺。"保证提分违背教育规律"只是说明老王这买卖有风险，可不让合同无效；也谈不上坑小李（显失公平）或天降变故（情势变更）。考不上，老王老老实实退钱。

### 🎯 一句话记忆

> **"自我加责的承诺 = 有效；'违背规律'不等于'法律无效'；没达标，照退费。"**

### 填空模板（主观题用）

> 乙"保证达线、否则退费"系双方**【真实意思表示】**，不违反**【法律行政法规强制性规定及公序良俗】**，故**【有效】**（§143）。其"违背教育规律"仅属**【商业风险】**，不影响效力；既非不合理免责的格式条款，亦无**【显失公平 / 情势变更】**情形。未达线，乙应**【全额退费】**。故选 **D**。
