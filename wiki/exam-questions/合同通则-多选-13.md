# C1-多选-13 · 法定解除合同的情形

## 题干

> 下列情形中，**甲方可以解除合同**的是？

- A. 场地租赁合同 + 突发大风雨毁场地 → 无法举办婚礼
- B. 买卖合同 + 乙明确表示不履行
- C. 建设工程合同 + 乙迟延 + 催告后仍不履行
- D. 商铺租赁合同 + 乙未按约定经营 → 长期闲置

## 我的答案

**ABC**（A 不可抗力致目的不能实现 + B 预期违约 + C 催告无果迟延 = 三项标准 §563 情形；D 不构成 §711 "致使租赁物受损失"，通说不解除）<!-- confidence: EXTRACTED -->

> 注：D 项存在轻度学理争议（若证明"长期闲置导致商铺贬值"则也可能解除），保守取 **ABC**。

## 考点精解 · §563 五大法定解除情形

### §563 法条原文（最高检官网原文）

> **[[民法典]]§563 第一款**：有下列情形之一的，当事人可以解除合同：
> （一）因不可抗力**致使不能实现合同目的**；
> （二）在履行期限届满前，当事人一方明确表示或者以自己的行为表明不履行主要债务；
> （三）当事人一方迟延履行主要债务，经催告后在合理期限内仍未履行；
> （四）当事人一方迟延履行债务或者有其他违约行为致使**不能实现合同目的**；
> （五）法律规定的其他情形。

### 五大情形核心要件速读

| #   | 情形                       | 关键要件                        | 易混点                               |
| --- | ------------------------ | --------------------------- | --------------------------------- |
| ①   | **不可抗力**                 | 不可抗力 + **致目的不能实现**          | 仅有不可抗力但目的仍可实现 → 不能解除（如延期 1 天即可恢复） |
| ②   | **预期违约**（§563 II + §578） | 履行期前 + 明示 / 行为表明不履行**主要**债务 | 表示不履行"次要义务"不算                     |
| ③   | **迟延履行 + 催告无果**          | 迟延 + 催告 + 合理期限内仍未履行         | **必须催告**！直接解除无效                   |
| ④   | **根本违约**                 | 迟延 / 其他违约 + 致**目的不能实现**     | 不必催告，但门槛高（根本违约）                   |
| ⑤   | 法律规定其他情形                 | 特别法规定                       | 如 §711 / §610 / §730 等            |

### 4 选项陷阱深度解析

| 选项                               | 判断       | 详细法理分析                                                                                                                                                                                                            |
| -------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A · 场地租赁 + 突发大风雨毁场地 → 无法举办婚礼** | ✅        | **§563 I ① 不可抗力**：突发大风雨 = 不可预见 + 不可避免 + 不可克服 → 不可抗力；场地被毁 → "举办婚礼"这一**合同目的不能实现** → 双要件齐全 → 甲方可解除。⚠️ 注意：仅有不可抗力**不必然**解除，必须"**致目的不能实现**"才行。                                                                          |
| **B · 买卖合同 + 乙明确表示不履行**          | ✅        | **§563 I ② + §578 预期违约**：乙在履行期届满前**明确表示**不履行 → **明示预期违约**。甲方既可立即解除合同（§563 II），也可在履行期届满前请求承担违约责任（§578）。两条赛道任选一。                                                                                                    |
| **C · 建设工程合同 + 乙迟延 + 催告后仍不履行**   | ✅        | **§563 I ③ 催告无果迟延**：① 迟延履行 ② 经催告 ③ 合理期限内仍未履行——三要件齐全。"建设工程合同"对工期敏感，履行迟延 + 催告后仍不动工 → 甲方法定解除权成立。                                                                                                                     |
| D · 商铺租赁 + 乙未按约定经营 → 长期闲置        | ❌（通说不解除） | **§711 严格要件分析**：§711 = "承租人未按约定方法 / 性质使用 + **致使租赁物受到损失** → 出租人可解除"。"**长期闲置**"通常**不构成**"致使租赁物受到损失"——只要按时付租金，闲置≠物理损害租赁物。除非证明闲置**严重导致商铺贬值**或**周边连锁退租**等损害事实（少数学者意见），通说不构成根本违约（§563 I ④），故甲方**不能**直接据 §711 / §563 解除。 |

→ 正确答案 = **ABC** ✅

## 🔑 核心概念深度讲解 1 · §563 五大情形的判断标准

### 情形 ①：不可抗力（A 项基础）

**完整要件**（§180 + §563 I ①）：
1. **不可抗力**：不能预见 + 不能避免 + 不能克服的客观情况（自然灾害 / 战争 / 法律变更等）
2. **致使** = 因果关系（不可抗力是合同目的不能实现的原因）
3. **不能实现合同目的** = 关键门槛 ★

**A 项验证**：
- 突发大风雨 ✅ 不可抗力（不可预见 / 避免 / 克服）
- 场地毁 → 婚礼无法举办 ✅ 致使合同目的不能实现
- → 双要件齐全 → 解除权成立

**陷阱提醒**：若题干说"大风雨延误 1 天即可恢复，婚礼可改日举办" → 合同目的仍可实现 → **不能解除**（仅可中止履行或主张减损）。

### 情形 ②：预期违约（B 项基础 · §563 + §578）

**两种类型**：
| 类型 | 触发 | 法条 | 救济 |
|---|---|---|---|
| **明示预期违约** | 履行期前**明确表示**不履行主要债务 | §563 I ② + §578 | 立即解除 / 请求违约责任 |
| **默示预期违约** | 履行期前**以自己的行为表明**不履行主要债务 | §563 I ② + §578 | 同左 |

**B 项验证**：
- 乙**明确表示**不履行 = 明示预期违约 ✅
- 甲方权利：① 立即解除（§563）+ ② 请求违约责任（§578）→ 两条赛道任选

**经典案例**：
- 卖方在交货前明确说"我不卖了"
- 卖方把货已卖给他人（行为表明不履行）
- 卖方解雇所有员工无法生产（默示预期违约）

### 情形 ③：催告无果迟延（C 项基础）

**三要件齐全**：
1. **迟延履行**：超过约定期限
2. **催告**：明确要求履行的意思表示（书面 / 口头均可）
3. **合理期限内仍未履行**：催告后给的"宽限期"过了还没动

**"合理期限"判断**：
- 看合同性质和履行难度
- 一般 7-30 天（参考最高法司法实践）
- 紧急合同（如鲜活物 / 婚礼场地）可缩短

**C 项验证**：
- 建设工程合同对工期敏感 ✅
- 乙迟延 + 催告 + 合理期限内仍不动工 → 三要件齐全 ✅
- 注意区分 §563 I ③ 与 ④：催告无果不需"目的不能实现"门槛（只要"主要债务"迟延即可）

### 情形 ④：根本违约（兜底条款）

**触发要件**：
- 迟延履行**或**其他违约行为
- 致使**合同目的不能实现**

**与 §563 I ③ 的关系**：
| 维度 | ③ 催告无果迟延 | ④ 根本违约 |
|---|---|---|
| 是否需催告 | ✅ 必须催告 | ❌ 无需催告 |
| 门槛 | 迟延履行**主要债务** | 致**目的不能实现** |
| 关系 | 程序条款 | 实体条款 |

### 情形 ⑤：法律规定的其他情形

| 法条 | 情形 |
|---|---|
| §610 | 标的物不符合质量要求 + 致目的不能实现 |
| §711 | 承租人未按约方法使用 + **致租赁物受损失** |
| §730 | 不定期租赁，任一方随时解除 |
| §786 | 合伙合同任一合伙人退伙 |
| 等 | 各典型合同章特别解除条款 |

→ D 项试图触发 §711，但要件不齐（无"致租赁物受损失"）。

## 🔑 核心概念深度讲解 2 · §711 租赁合同特殊解除权（D 项专项分析）

### §711 法条原文（最高检官网）

> **[[民法典]]§711**：承租人未按照约定的方法或者未根据租赁物的性质使用租赁物，**致使租赁物受到损失**的，出租人可以解除合同并请求赔偿损失。

### §711 适用要件

1. **承租人未按约定方法使用** **或** **未按租赁物性质使用**
2. **致使租赁物受到损失** ★（核心要件）

### "长期闲置"是否符合 §711？

| 情形 | 是否构成"致租赁物受损失" | 是否可据 §711 解除 |
|---|---|---|
| 商铺**长期闲置**（按时付租金）| ❌ 通常不构成 | ❌ 不能解除（本题 D）|
| 住宅擅自**改建结构** | ✅ 物理损害 | ✅ 可解除 |
| 商铺擅自**改变用途**（合法变违法） | ✅ 涉及合规风险 | ✅ 可解除 |
| 仓库存放**易燃物**致风险 | ✅ 安全风险即损失 | ✅ 可解除 |
| 商铺闲置 + 证明**导致严重贬值** | 学界少数意见可能支持 | ⚠️ 争议 |

→ **D 项**：题干仅说"长期闲置"，未说明致租赁物受损失 → 通说**不能解除**。

### §711 vs §722（迟延付租金）

| 法条       | 触发                 | 解除条件            |
| -------- | ------------------ | --------------- |
| **§711** | 未按约方法使用            | **致租赁物受损失**     |
| **§722** | 承租人无正当理由未支付或迟延支付租金 | 经催告 + 合理期限内仍不支付 |

→ 出租人解除租赁合同的两个常见路径，注意区分。

## 🔑 核心概念深度讲解 3 · [[合同编通则司法解释]] §53 新规（2023.12.5 施行）

### 法条原文

> **[[合同编通则司法解释]]§53**：当事人一方以通知方式解除合同，并以对方未在约定的异议期限或者其他合理期限内提出异议为由主张合同已经解除的，人民法院应当对其**是否享有法律规定或者合同约定的解除权进行审查**。
> 经审查，**享有解除权的** → 合同自通知到达对方时解除；
> **不享有解除权的** → 不发生合同解除的效力。

### 核心要点

**重大变化**：旧法（[[合同法]] §96）允许"对方未在异议期内异议 → 解除生效"，新司法解释要求**法院主动审查解除权基础**。

**Q13 适用情境**：
- 即使甲方按 §563 发了解除通知 + 乙方未异议
- 法院仍要**审查**甲方是否真的有 §563 五大情形之一
- 若不构成 §563 情形（如 D 项假设甲方据"长期闲置"解除）→ 解除**不生效**
- 这是 2024-2026 法考"主观题第二步必考"的命题热点

### 时间脉络

```
2021.1.1 → 民法典 §563 施行（5 情形）
2023.12.5 → 合同编通则司法解释 §53 施行（解除通知审查规则）
                                      ↓
2024 起 → 法考命题增量点（"通知解除是否生效"成为高频考点）
```

## 📐 答题口诀 · §563 五情形 + 一锤定音法则

> **"不可抗力毁目的 / 履行前明确不干 / 催告无果迟迟拖 / 根本违约目的死 / 法律另有规定"——五情形齐全才可解。"长期闲置"不算损害租赁物（§711）。"**

### 关键词触发表

```
看到题干关键词                                          → 判断
"不可抗力 / 突发自然灾害 + 目的不能实现"                 → §563 I ① ★
"履行期前 + 明确表示 / 行为表明不履行主要债务"           → §563 I ② + §578 预期违约 ★
"迟延 + 催告 + 合理期限内仍未履行"                       → §563 I ③ 催告无果 ★
"迟延 / 其他违约 + 致目的不能实现"                       → §563 I ④ 根本违约
"法律规定其他情形"                                       → §563 I ⑤（兜底）

具体陷阱：
"未按约定使用租赁物 + 长期闲置（无具体损害）"           → §711 不满足 → 不能解除
"未按约定使用租赁物 + 改建/损害"                        → §711 满足 → 可解除
"承租人未付租金 + 催告无果"                              → §722 → 可解除
"对方未在异议期内异议"                                   → 仍要审查解除权（§53 解释）
"不可抗力但目的仍可实现"                                 → 不能解除（仅可中止或减损）
```

### 🚗 老王小李买车故事（4 角色版 · 一情境一场景）

> **场景背景**：豪车定制圈的四个真实剧情，对照 §563 五大情形

```
====================== 场景 A · 不可抗力 ======================
老王（场地老板）与小李签合同：8/8 下午在老王酒店草坪场地办婚礼
合同款 20 万

8/7 突降百年一遇的大暴雨 + 龙卷风 → 草坪场地完全被毁
8/8 草坪根本不能用，婚礼现场拍不到 / 站不住

  老王对小李：「太抱歉了，场地用不了，咱解约吧。」
  小李：「行，钱退给我，按 §563 I ① 不可抗力解除」 ✅
  分析：① 不可抗力 ✅（百年一遇大暴雨）② 致目的不能实现 ✅（婚礼办不了）
  → 双要件齐全 → A 答案成立

====================== 场景 B · 预期违约 ======================
老王（卖家）与小李签合同：9/1 交付一辆特斯拉
9/1 当天交车，付清尾款

8/15 老王发了个朋友圈：「老子不卖了！这车价涨了，宁可赔违约金」
小李一看：明示预期违约！

  小李：「老王你既然明确表示不履行，我现在就解除合同 + 找你赔违约金」
  老王：「履行期还没到啊！」
  小李：「§563 I ② + §578：履行期届满前你明确表示不履行 →
        我可以立即解除 / 也可以等履行期到了再找你赔，任选！」 ✅
  → B 答案成立

====================== 场景 C · 催告无果迟延 ======================
老王（建设工程承包方）与小李签合同：3 个月内建好定制车库（精装修）
约定 9/1 交付

9/1 到了 → 老王还没动工！

  小李：「老王，你迟延履行了，请于 9/15 前开工，否则我解除合同」（催告）
  9/15 → 老王还是没动工
  小李：「§563 I ③：迟延 + 催告 + 合理期限内仍未履行 → 我现在解除」 ✅
  → C 答案成立
  ⚠️ 关键：必须先催告，直接解除无效！

====================== 场景 D · 商铺闲置 ======================
小李（出租人）把商铺租给老李（承租人）：约定经营特色咖啡店
租金按月正常支付

老李一直按时付租金，但商铺一直闲置 → 没装修 / 没经营，看起来跟没租一样

  小李：「老李你不经营 + 长期闲置，我要解除合同！」
  老李：「我按时付租金啊，你解除什么？」
  
  分析：
  - §711 要件：未按约方法使用 + **致租赁物受损失** ★
  - 老李的情形：未按约方法使用 ✅（合同约定经营特色咖啡店）
  - 但 "**致租赁物受损失**" ❌（闲置≠物理损害，按时付租金）
  - § 563 I ④ 根本违约："长期闲置"通说不构成根本违约（出租人收租金的目的并未受影响）
  
  → 法院判：小李**不能**直接据 §711 / §563 解除 → D 项**不成立** ❌
  → 答案 ABC ✅
```

### 💡 关键洞察 1：A 项是命题人最喜欢埋的"不可抗力陷阱"

不可抗力**自身**不等于解除权——必须 **+ 致目的不能实现**：

| 题干表述 | 是否能解除 |
|---|---|
| "突发地震 + 工厂倒塌 + 半年内无法恢复生产" | ✅ 可解除（目的不能实现）|
| "突发地震 + 工厂受损 + 1 周内可恢复" | ❌ 不能解除（仅延期，目的可实现）|
| "突发疫情 + 旅游团延期 3 个月" | ❌ 通常不能解除（仅延期）|
| "突发疫情 + 婚礼无法举办（婚期已定，过了就过了）" | ✅ 可解除 |

→ **核心标准**：合同目的的"时效性"。婚礼有强时效性，工厂生产可延期。

### 💡 关键洞察 2：B 项预期违约的两条赛道

明示预期违约 → 守约方可选：
1. **§563 立即解除合同**（断臂止损）
2. **§578 请求承担违约责任**（等履行期到了再算账）

两者**不冲突**，可任选其一或先 1 后 2（先解除再追究剩余损失）。

### 💡 关键洞察 3：C 项催告是"必经程序"

§563 I ③ 必须满足**三要件**：
- ① 迟延履行
- ② **催告** ★（这是关键，跳过则解除无效）
- ③ 合理期限内仍未履行

**直接解除无催告 = 解除通知无效**（即使对方未异议，按 §53 解释，法院仍审查催告程序）。

### 💡 关键洞察 4：D 项是 §711 严格要件陷阱

§711 ≠ 只要承租人"未按约使用"就能解除：
- 必须 **+ 致租赁物受损失** ★
- "长期闲置"通说不构成"损失"（只要按时付租金）
- 命题人故意省略"致损失"细节，引诱考生误选

→ **学习要点**：法考考租赁合同解除时，必看是否触发 **§711 / §722 / §730** 等特别条款的**完整要件**。

## 🆚 §562 协议解除 vs §563 法定解除 — 一表速记

| 维度 | §562 协议解除 | §563 法定解除 |
|---|---|---|
| **依据** | 当事人**约定 / 协议** | **法律规定**的 5 种情形 |
| **类型** | ① 约定解除条件成就 ② 双方协议解除 | 法律列举的 5 情形 |
| **触发要件** | 约定条件成就 / 双方合意 | 不可抗力 / 预期违约 / 催告无果 / 根本违约 / 其他 |
| **是否需通知** | 协议解除自合意时；约定解除条件成就时单方通知 | 单方通知（[[合同编通则司法解释]]§53 审查解除权）|
| **典型适用** | 合同有约定 / 双方友好协商 | 一方根本违约 / 不可抗力等 |

## 🆚 §711 vs §722 — 出租人解除的两条路径

| 维度 | §711（使用不当）| §722（拖欠租金）|
|---|---|---|
| **触发** | 承租人未按约方法 / 性质使用 | 承租人无正当理由未付 / 迟延付租金 |
| **核心要件** | **致租赁物受损失** ★ | **催告 + 合理期限内仍未支付** |
| **是否需催告** | 一般无需（损失既成）| **必须**催告 |
| **本题适用** | D 项试图触发但要件不齐 ❌ | 不适用（按时付租金）|

> **"§563 五情形：不可抗力毁目的 / 履行前明示不干 / 催告无果拖 / 根本违约目的死 / 法律规定其他。"**

> **"租赁特别解除：§711 必须'**致损失**'（D 项闲置不算）/ §722 拖租金必须**催告**。"**

> **"不可抗力**仅是触发**，'**致目的不能实现**'**才是关键**——不可抗力不必然解除。"**

> **"明示预期违约两条赛道：§563 立即解除 / §578 等到期算账，任选其一。"**

## 填空模板（主观题用）

> 本题考查 [[民法典]]§563 法定解除合同的五大情形：
