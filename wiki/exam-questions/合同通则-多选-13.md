# C1-多选-13 · 法定解除合同的情形

## 题干

> 下列情形中，**甲方可以解除合同**的是？

- A. 场地租赁合同 + 突发大风雨毁场地 → 无法举办婚礼
- B. 买卖合同 + 乙明确表示不履行
- C. 建设工程合同 + 乙迟延 + 催告后仍不履行
- D. 商铺租赁合同 + 乙未按约定经营 → 长期闲置

## 我的答案

**ABC**<!-- confidence: INFERRED -->

> 注：D 也有版本认为可解除（§711 出租人解除权），保守取 ABC。

## 涉及考点

- 法定解除（§563）的 5 种情形
- 预期违约（§578）

## 考点精解 · §563 五大法定解除情形

### 是什么 / 易混

**§563 I**（法定解除事由）：
- ① **不可抗力**致**不能实现合同目的**
- ② **预期违约**（明确表示 / 行为表明不履行主要债务）
- ③ **迟延履行主要债务**经**催告**后合理期限内仍未履行
- ④ **迟延履行 / 其他违约**致**合同目的不能实现**（根本违约）
- ⑤ 法律规定的其他情形

本题对照：
- A 大风雨 → §563 I 1 不可抗力致目的不能实现 → 对
- B 乙明确表示不履行 → §563 I 2 / §578 预期违约 → 对
- C 迟延 + 催告无果 → §563 I 3 → 对
- D 商铺未按约经营 → 出租人能否解除？
  - 若构成根本违约（"长期闲置"），可解除（§711 + §563）
  - 通说不构成根本违约，保守选 **ABC**
  - 实战中如题目说"严重影响"则也对，本题用"长期闲置"中性偏轻

### 怎么考 / 坑在哪

- **D 边缘**：未按约用途使用 → §711 要求承租人在催告后"未按约方法或目的使用且未补正" → 才能解除
- 主流答案 **ABC**

### 怎么答

ABC。A 不可抗力 + B 预期违约 + C 催告无果迟延，三项标准 §563 情形。
