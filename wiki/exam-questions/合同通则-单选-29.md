# C1-单选-29 · 人身损害免责条款 + 受害人承诺

## 题干

> 王大卫在玩具厂打工前签了招工协议，招工人员特意指着一条说："这一条说了，工作中发生任何意外，包括重伤、死亡，工厂概不负责。"王大卫说："那是当然，都是自己的命。"后王工作时被切割机切断手指，请求工厂支付医疗费。下列说法正确的是（ ）。

- A. 招工协议属于格式条款，工厂已尽提示注意义务，应当有效
- B. 王大卫已签免责条款，工厂不用支付费用
- C. 王大卫同意条款且口头认可，属受害人承诺，工厂不用支付医疗费
- D. 以上说法均不对，工厂需要支付医疗费

## 我的答案

**D**（人身损害免责条款无效，工厂需支付）<!-- confidence: INFERRED -->

## 涉及考点

- [[格式条款]]（免责条款 §506）
- 人身损害免责无效（§506(1)）+ 受害人承诺辨析

## 考点精解 · 免责条款无效（§506）

### 是什么 / 易混

- **§506(1)**：合同中**免除造成对方人身损害**责任的条款**无效**。
- 该规则**不限于格式条款** —— 即使是双方协商的个别条款，免除人身损害责任也无效。
- **受害人承诺（自甘风险）**：可对**财产**风险有限适用，但**不能预先概括放弃生命健康保护**；生命健康权不得预先抛弃。

### 怎么考 / 坑在哪

- **A 陷阱**：尽了提示义务 → 只解决"订入"，不解决"有效"。免人身损害责任**当然无效**。
- **B 陷阱**：签了 / 同意了 → 无效条款不因当事人同意而有效。
- **C 陷阱**："受害人承诺"**不适用**于对人身权的预先免责。
- → 工厂必须赔。

### 怎么答

"重伤、死亡概不负责"系免除工厂对劳动者**人身损害**责任的条款，依 **§506(1) 无效**；工厂虽特意提示、王亦口头认可，均不能使该无效条款生效，"自己的命"式的口头承诺亦不构成对生命健康的有效预先放弃。故选 **D**，工厂需支付医疗费。

## 📐 答题口诀 · 免责条款：人身损害免责"一律无效"

> 见到"免除人身伤害 / 重伤 / 死亡责任"的条款 —— **不用纠结是不是格式、提没提示、同没同意，直接无效**。

### 🚗 "工厂概不负责" 故事

> 王大卫进玩具厂，招工的**特意指着**一条念："工作出任何意外，重伤、死亡，工厂概不负责。"
> 王大卫拍胸脯："那当然，都是自己的命！"
> 结果切割机切断他的手指，他找工厂要医疗费。

工厂的三道挡箭牌，全被打掉：

| 挡箭牌 | 选项 | 为什么挡不住 |
|---|---|---|
| "这是格式条款，我提示了" | A | 提示只解决**订入**，免人身损害责任仍**无效**（§506(1)）|
| "你签字了" | B | **无效条款**不因签字而有效 |
| "你口头答应了（受害人承诺）" | C | 生命健康**不得预先概括放弃**，受害人承诺不适用人身权 |

→ 三道挡箭牌全废 → 工厂照赔 → **D**

### 🔑 §506 免责条款"绝对无效"两情形

```
合同免责条款，这两种一律无效（§506）：
  (1) 免除造成对方【人身损害】的            ← 本题
  (2) 因【故意或重大过失】造成对方【财产损失】的

特点：不管是不是格式条款、提没提示、同没同意 —— 都无效
```

### 📋 4 选项解析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 提示 → 有效 | ❌ | 提示解决订入，不解决效力；人身损害免责无效 |
| B 签了 → 免责 | ❌ | 无效条款不因同意而有效 |
| C 受害人承诺 | ❌ | 生命健康不得预先抛弃，承诺不适用人身权 |
| **D 工厂需付** | ✅ | §506(1) 无效 → 工厂担责 |

→ 选 **D** ✅

### 填空模板（主观题用）

> 招工协议中"重伤、死亡概不负责"系**免除用人方人身损害责任**的条款，依 **§506 第（一）项**当然**无效**。工厂虽尽提示义务、王某亦口头认可，但**无效条款不因提示或同意而生效**，且对**生命健康权**的预先概括放弃不构成有效的受害人承诺。故工厂应支付医疗费（D）。
