# 民诉-保全-多选-125 · 诉前保全的担保、保全方法与手续移送

## 题干

> 【出处】民事诉讼法真题（117-144题）第 125 题（题库自带标注"2019 金题-2-4-9"，该年份编号未经独立核验）

位于 A 省 B 县的甲公司和 A 省 C 县的乙公司订立水果买卖合同，甲公司付款后，乙公司迟迟不发货，甲公司担心乙公司的发货能力，于是向水果仓库所在地 D 县法院申请保全，法院采取相应保全措施后，甲公司向 C 县法院提起诉讼，下列选项正确的是？

- A. 甲公司应当提供担保
- B. D 县法院应当冻结这批水果
- C. C 县法院受理案件后，D 县法院应当将保全手续一并移送 C 县法院
- D. C 县法院受理案件后应当将案件移送 D 县法院

## 我的答案

**AC**

## 解析

### 本题考什么

本题考查 **诉前保全的三个要点：必须提供担保 + 保全方法（货物用查封/扣押而非冻结）+ 起诉后保全手续移送受理法院**：
- 诉前保全，申请人**必须提供担保**，不提供的裁定驳回申请（A对）；
- 保全"这批水果"（货物）应采取**查封、扣押**，"冻结"针对存款等资金，故"冻结水果"错（B错）；
- 甲向 C 县法院起诉后，采取诉前保全的 D 县法院应将**保全手续移送**受理案件的 C 县法院（C对）；
- 管辖不因保全改变，C 县受理后不移送案件给 D 县（D错）。

📍 对应深度报告考点：[[民诉-客观题考点全景-深度报告]] › 板块B · 证据·证明与程序保障 › 第5章 期间、送达、保全与强制措施 › 5-3 财产保全

### 逐项解析

**A —— ✅ 正确（应选）**

- 判断理由：甲公司在**起诉前**向财产所在地 D 县法院申请保全，属诉前保全。诉前保全**申请人必须提供担保**，不提供担保的，法院裁定驳回申请。
- 法律依据：《中华人民共和国民事诉讼法》（2023年修正，现行有效）第一百零四条第一款："利害关系人……可以在提起诉讼或者申请仲裁前向被保全财产所在地、被申请人住所地或者对案件有管辖权的人民法院申请采取保全措施。**申请人应当提供担保，不提供担保的，裁定驳回申请。**"
- 官方链接：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)
- 对应深度报告考点：5-3 诉前保全

**C —— ✅ 正确（应选）**

- 判断理由：甲公司向**采取诉前保全措施以外**的其他有管辖权的 C 县法院起诉，采取诉前保全的 D 县法院应当将**保全手续移送**受理案件的 C 县法院，诉前保全裁定视为受移送法院（C 县）作出的裁定。
- 法律依据：《民诉法解释》（法释〔2022〕11号修正，现行有效）第一百六十条："当事人向采取诉前保全措施以外的其他有管辖权的人民法院起诉的，采取诉前保全措施的人民法院应当将保全手续移送受理案件的人民法院。诉前保全的裁定视为受移送人民法院作出的裁定。"
- 官方链接：[民诉解释全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：5-3

**B —— ❌ 错误（不选）**

- 判断理由：财产保全的方法是**查封、扣押、冻结**或法律规定的其他方法。"冻结"适用于存款、资金、股权等；对"这批水果"（有体货物）应采取**查封或扣押**，而非"冻结"。故"D 县法院应当冻结这批水果"用词错误。
- 法律依据：《民事诉讼法》第一百零六条第一款（"财产保全采取查封、扣押、冻结或者法律规定的其他方法"——货物对应查封扣押）。
- 官方链接：[民诉法2023全文PDF（已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)
- 对应深度报告考点：5-3 保全方法

**D —— ❌ 错误（不选）**

- 判断理由：C 县法院是甲公司选择起诉的有管辖权法院，案件由 C 县审理；管辖**不因保全在 D 县而改变**。C 县受理后只需接收 D 县移送的保全手续（见C），不存在"把案件移送 D 县"的问题。
- 法律依据：《民诉法解释》第一百六十条（移送的是保全手续，不是案件管辖）。
- 官方链接：[民诉解释全文PDF（已核验）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)
- 对应深度报告考点：5-3

### 结论

综上，诉前保全须提供担保（A）、起诉后 D 县保全手续移送 C 县（C）；货物应查封扣押而非"冻结"（B错）、管辖不移送给 D 县（D错）。本题答案为 **AC**。

### ⚡ 做题眼

> **诉前保全一眼判**：
> **担保**——诉前保全**必须提供担保**，不提供就驳回（A，民诉法104条）；
> **方法**——货物用**查封/扣押**，存款资金才用**冻结**（B把水果说成"冻结"就错）；
> **手续移送**——起诉后，做诉前保全的法院把**保全手续**移送受理案件的法院（C，民诉解释160条）；移的是**手续不是案件**（D错）。
> 一句话："**诉前保全＝先交担保、货物查扣、起诉后手续跟着案子走。**"
