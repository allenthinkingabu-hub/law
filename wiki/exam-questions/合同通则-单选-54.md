# C1-单选-54 · 资不抵债后捐赠：债权人可撤销；公益捐赠赠与人不得任意撤销

## 题干

> 甲公司在2011年6月1日欠乙公司货款500万元，届期无力清偿。2010年12月1日，甲公司向丙公司赠送一套价值50万元的机器设备。2011年3月1日，甲公司向丁基金会捐赠50万元现金。2011年12月1日，甲公司向戊希望学校捐赠价值100万元的电脑。甲公司的3项赠与行为均尚未履行。下列哪一选项是正确的？（2012-3-15）

- A. 乙公司有权撤销甲公司对丙公司的赠与
- B. 乙公司有权撤销甲公司对丁基金会的捐赠
- C. 乙公司有权撤销甲公司对戊学校的捐赠
- D. 甲公司有权撤销对戊学校的捐赠

## 我的答案

**C**（戊捐赠发生在甲资不抵债后、损害债权 → 债权人乙可撤销；公益捐赠赠与人甲不得任意撤销）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 涉及考点

- [[撤销权]]（债权人撤销权 §538：债务人**无偿处分**财产、**损害债权**，债权人可撤）
- [[赠与合同]]（赠与人任意撤销权 §658：赠与财产**权利转移前**可撤；**但公益 / 道德义务赠与 + 经公证赠与除外**）
- **同一"撤销"二字，两套规则、两个主体、结论相反**：C 是债权人乙撤（成立）、D 是赠与人甲撤（不成立）

## 考点精解 · 两种撤销权别混（债权人撤销 vs 赠与人任意撤销）

### 是什么 / 易混

本题把**两种"撤销权"**摆在一起考——主体不同、条件不同：

| 撤销权                | 谁来撤      | 条件                                                         | 本题       |
| ------------------ | -------- | ---------------------------------------------------------- | -------- |
| **债权人撤销权**（§538）   | 债权人**乙** | 债务人**无偿处分**财产、**损害债权**（债务人已 / 将无力清偿）                       | A/B/C 考它 |
| **赠与人任意撤销权**（§658） | 赠与人**甲** | 赠与财产**权利转移前**可任意撤；**但救灾 / 扶贫 / 助残等公益、道德义务赠与 + 经公证赠与不得任意撤** | D 考它     |

**三笔赠与的分水岭 = 甲"是否已无力清偿"（2011/6/1 届期无力清偿）**：

- **C 对**：对戊学校的捐赠在 **2011/12/1（甲已届期无力清偿之后）**——甲此时已**资不抵债**仍无偿往外送，**明显损害**乙的债权 → 乙可依 §538 撤销。
- **A、B 错**：对丙（2010/12/1）、对丁（2011/3/1）都在债务届期（6/1）**之前**——那时甲尚未显出无力清偿，难以认定这两笔赠与"损害债权"，乙撤销权不成立。
- **D 错**：对戊的是**公益捐赠**（希望学校），依 §658 II，赠与人甲**不享有任意撤销权**，不能自己反悔。

### 怎么考 / 坑在哪

- **最大的坑：C 与 D 方向相反**——同样针对"对戊学校的捐赠"，债权人乙**能撤**（C 对，保全债权），赠与人甲自己**不能撤**（D 错，公益捐赠锁死任意撤销权）。两条线**互不矛盾**。
- **时间线是 A/B/C 的分水岭**：债权人撤销针对的是**让债务人陷入 / 加重无力清偿**的无偿处分——资不抵债**之后**的处分才明显损害债权（C），之前的（A/B）难认定。
- 别一看"赠与 / 捐赠"就以为都能撤——要先分清**谁在撤**。

### 怎么答

对戊的捐赠发生在甲资不抵债后、损害债权 → 债权人乙可撤（§538，C 对）；该捐赠系公益捐赠，赠与人甲不得任意撤销（§658 II，D 错）；对丙、丁的赠与在债务届期前、未损害债权（A、B 错）。故选 **C**。

## 📐 答题口诀 · 债权人撤销看"欠债后往外送"；赠与人撤销看"是不是公益"

> **"债务人欠债（资不抵债）后又无偿往外送 = 债权人能撤（C）；公益捐款一旦答应，赠与人自己反悔不了（D 错）。"** 同一笔捐赠，债权人撤 ✓、赠与人撤 ✗，两条线不打架。

### 关键词触发表

```
看到题干"债务人无偿赠与 / 捐赠，谁能撤"           → 先分"债权人撤"还是"赠与人撤"
"资不抵债 / 届期无力清偿之后 + 无偿赠与"          → 损害债权 → 债权人可撤 §538 ✓ ★
"赠与在债务届期前 / 债务人当时有清偿力"           → 未损害债权 → 债权人撤不成立 ✗
"救灾 / 扶贫 / 助残 / 公益 / 学校捐赠 + 赠与人想反悔" → 不得任意撤销 §658 II（D 类陷阱）✗ ★
"债权人撤公益捐赠"                              → 仍可（保全债权，与 §658 不冲突）✓
"经过公证的赠与 + 赠与人想撤"                    → 也不得任意撤销 §658 II
```

### 📋 4 选项陷阱解析

| 选项 | 谁撤 | 判断 | 理由 |
|---|---|---|---|
| A 撤对丙赠与 | 债权人乙 | ❌ | 2010/12 在债务届期前，甲未显无力清偿，未损害债权 |
| B 撤对丁捐赠 | 债权人乙 | ❌ | 2011/3 同在届期前，同上 |
| **C 撤对戊捐赠** | 债权人乙 | ✅ | 2011/12 甲资不抵债后，无偿处分损害债权（§538）|
| D 甲撤对戊 | 赠与人甲 | ❌ | 公益捐赠，赠与人不得任意撤销（§658 II）|

→ 选 **C** ✅

### 🚗 老王小李故事

> 老王把车卖给小李，小李欠老王 **500 万**车款，**6 月 1 日到期却还不上**（老王 = 债权人，小李 = 债务人）。可小李偏偏到处"做好事"白送东西：
>
> - **去年 12 月**，送给老张一台 **50 万**的设备；
> - **今年 3 月**，给某基金会捐了 **50 万**现金；
> - **今年 12 月**（已经还不起老王的钱**之后**），又给**希望小学**捐了 **100 万**电脑。
>
> 老王急着讨那 500 万，能撤掉小李哪一笔白送？
>
> - **只能撤最后那笔——对希望小学的**（C✓）！因为它发生在小李**已经资不抵债之后**，明摆着把家当往外撒、坑债主老王，§538 债权人撤销权正好打它。
> - 前两笔（送老张、捐基金会）发生在**还没到期、小李那会儿还撑得住**的时候，难说"损害了老王的债权"，老王撤不了（A、B✗）。
> - 那小李自己呢？捐给希望小学后又**反悔想要回**那 100 万电脑？——**不行**（D✗）！公益捐赠一旦答应，**赠与人自己撤不了**（§658 II）。
>
> 诀窍：**债权人老王撤的是"小李欠债后往外送"（看时间 + 损害）；赠与人小李自己想撤，得看"是不是公益"（公益锁死）。** 同一笔对希望小学的捐赠，老王能撤（保债权）、小李撤不了（公益）——两条线不打架。

### 🎯 一句话记忆

> **"债权人撤销看'欠债（资不抵债）后有没有往外送'（C 对）；公益捐赠赠与人自己撤不了（D 错）；同一笔捐赠，债权人能撤、赠与人不能，两条线不矛盾。"**

### 填空模板（主观题用）

> 对戊学校的捐赠发生于甲**【届期无力清偿（资不抵债）之后】**，无偿处分**【损害乙的债权】**，债权人乙可依 §538 **【撤销】**（C 对）；对丙、丁的赠与在债务届期**【之前】**，甲当时未显无力清偿、未损害债权，乙撤销权**【不成立】**（A、B 错）；对戊系**【公益（助学）捐赠】**，赠与人甲依 §658 II **【不得任意撤销】**（D 错）。故选 **C**。
