# C1-单选-36 · 合作意向书 = 预约合同，拒订本约担违约责任

## 题干

> 某日，甲公司与乙公司订立《合作意向书》，约定待甲公司取得某地建设用地使用权后双方订立《合作开发合同》，并初步约定了出资比例、收益分享等事宜，当日乙公司依《合作意向书》向甲公司支付了100万元预付款。甲公司取得建设用地使用权后，因决定与其他公司合作而拒绝与之签订《合作开发合同》。以下说法正确的是？（2020金题-2-1-17）

- A. 乙公司有权请求甲公司承担违约责任
- B. 《合作意向书》不具有法律约束力
- C. 乙公司有权请求甲公司支付《合作开发合同》项下的违约金
- D. 甲公司应向乙公司双倍返还预付款

## 我的答案

**A**（意向书=预约，拒订本约→违约责任）<!-- confidence: EXTRACTED -->（官方参考答案：A）

## 考点精解 · 预约合同（§495 / 通则解释§6）

### 是什么 / 易混

- **预约合同**：约定将来订立合同的合同（§495）。本案《合作意向书》"约定待取得用地后订立《合作开发合同》"+初步约定出资收益+已付 100 万预付款 → **构成预约合同，具有法律约束力**。
- 违反预约（拒订本约）→ 承担**预约的违约责任**（§495 II），不是本约的违约。

### 怎么考 / 坑在哪

- **B"无约束力"错**：意向书具备预约特征（明确将来缔约 + 主要内容初步约定），有约束力。
- **C"本约违约金"错**：本约（《合作开发合同》）尚未订立，无本约违约金可言；只能追究**预约**违约责任。
- **D"双倍返还"错**：双倍返还是**定金罚则**（§587），但 100 万是"**预付款**"不是定金，无定金性质则不双倍返还。

### 怎么答

意向书=预约（有约束力），甲拒订本约违反预约 → 乙可请求承担**违约责任** → 选 **A**。

## 📐 答题口诀 · 预约三关：约束力？本约还是预约？定金还是预付款？

> **"意向书别小看：约定将来缔约 = 预约，有约束力；违反预约担违约，但只赔预约的、不是本约的。"**

### 关键词触发表

```
看到题干关键词                              → 定性
"意向书/认购书/订购书 + 约定将来订正式合同"  → 预约合同（有约束力）§495
违反预约（拒订本约）                          → 预约违约责任
"本约违约金"（本约还没订）                     → 干扰项，排除
"预付款"（非定金）                            → 不适用双倍返还
"定金"明确标注                                → 才有定金罚则 §587
```

### 🚗 老王小李故事

> 老王和小李签了张《合作意向书》：等老王拿到地，俩人就签正式开发合同，还把出资、分成都先聊定了，小李先掏了 100 万。结果老王拿到地，转头跟别人合作了。小李能告吗？能——这意向书已经是个**预约**（有约束力的"约定将来签约"），老王毁约要担**违约责任**。但小李不能按"正式合同的违约金"要钱（正式合同压根没签），那 100 万也只是预付款、不是定金，退一份就行不用退两份。

### 🎯 一句话记忆

> **"意向书是预约、有约束力；毁约担违约；预付款非定金、不双倍。"**

### 填空模板（主观题用）

> 《合作意向书》约定**【将来订立本约 + 初步约定主要内容】**，构成 **【预约合同】**（§495），具有法律约束力。甲拒订本约违反预约义务，乙有权请求其承担**【（预约的）违约责任】**。100 万系**【预付款而非定金】**，不适用双倍返还。故选 **A**。
