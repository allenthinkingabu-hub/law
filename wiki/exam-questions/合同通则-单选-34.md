# C1-单选-34 · 以劳务抵租金的混合合同 + 替代成本赔偿

## 题干

> 甲和某音乐学院研究生乙约定，乙租甲房屋，期限1年，但乙可以通过每晚为甲的女儿辅导钢琴1小时，代替房屋租金的支付。双方依约行事。3个月后寒假开始，乙房屋上锁不知所终，甲无奈聘请某音乐学院本科生为女儿辅导1个月，每晚1小时，共支付2000元。后乙返回，告知甲其随导师去国外巡演1个月，甲提出乙应当支付1个月的房屋租金。正确的是？（2020金题-2-116）

- A. 乙应当按照甲的房屋在当地的平均租金4000元向甲支付
- B. 甲无权请求乙支付租金
- C. 乙应当向甲支付2000元
- D. 乙应当按照当地音乐学院研究生授课的平均报酬向甲支付3000元

## 我的答案

**C**（乙应向甲支付 2000 元）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 考点精解 · [[无名合同]] + 替代成本

### 是什么 / 易混

- 双方约定"**以钢琴辅导劳务抵租金**"——租赁 + 劳务的**非典型合同**，且约定了**代物清偿式**的给付方式（不付钱，提供等值劳务）。
- 乙寒假擅自离开 1 个月未辅导 = **违约**（不履行约定的对待给付）。
- 甲的损失 = **替代履行的实际支出**：花 2000 元请人补 1 个月辅导。依 §577、§584，违约赔偿 = 填补守约方实际损失（此处即替代成本 2000 元）。

### 怎么考 / 坑在哪

- A 4000 平均租金、D 3000 研究生报酬都是**诱导你去"市场价"**——但本案约定的对价是"辅导劳务"，乙违约后甲的实际损失是**他真金白银付出的 2000 元替代费**，不是抽象市场价。
- B"甲无权请求"错：乙违约，甲当然有权请求赔偿。

### 怎么答

锁定"甲实际花了多少补窟窿"=2000 元，即为乙应赔金额。故选 **C**。

---

## 📐 答题口诀 · 替代成本赔偿：赔"我实际花的"，不赔"市场价"

> **"以劳务抵债、劳务断供 = 违约；赔的是替代实付，不是平均价。"**

### 关键词触发表

```
看到题干关键词                       → 答这个数
"我花了 ×× 元请人补上"               → 替代实际支出（守约方真实损失）★
"当地平均租金 / 平均报酬"            → 干扰项（抽象市场价，不选）
"无权请求"                           → 直接排除（违约必有赔偿）
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 4000 | ❌ | 平均租金是干扰，不是甲的实际损失 |
| B 无权 | ❌ | 乙擅自离开 = 违约，甲有权请求 |
| **C 2000** | ✅ | 甲**实际支付**的替代辅导费 = 真实损失 |
| D 3000 | ❌ | "研究生平均报酬"仍是抽象市价干扰 |

### 🚗 老王小李故事

> 小李租老王的房，说好"我不付租金，每晚给你闺女弹一小时钢琴"。结果寒假小李锁门跑了去巡演，老王只好花 2000 元另请人补课。小李回来，老王要他赔——赔多少？不是按市场租金 4000，也不是按研究生课时费 3000，而是**老王实打实掏的 2000 元**。违约赔偿 = 填平守约方真实损失，多一分少一分都不对。

> **"违约赔偿填实损：我花多少，你赔多少 —— 别被'平均价'带跑。"**
