# 物权-多选-06 · 按份共有装修——75%多数决有效，张某可转让份额或请求分割

## 题干

> 刘某、关某、张某按照3:3:2的比例，共同出资80万元购买了一套房屋，按照按份共有进行了登记。为大幅提高租金收益，刘某和关某倾向于对该房重新装修，预计需再投入8万元装修资金，张某反对。关于刘某、关某二人的主张，下列说法正确的有？(2020年金题2-1-12)

- A. 张某就此可转让份额
- B. 张某就此可主张分割共有物
- C. 张某就此可主张刘某、关某侵权
- D. 刘某、关某有权主张重新装修

## 答案

**ABD**（张某可转让份额或请求分割；75%>2/3多数决有权推进装修）<!-- confidence: EXTRACTED -->

## 出处与来源

- 来源：2020年金题 2-1-12
- 素材：[[2026-06-15-物权编客观真题]]

## 涉及考点

- §301 按份共有**重大事项多数决**：须占份额**2/3以上**的共有人同意
- 刘某（3/8）+关某（3/8）= 6/8 = **75% > 2/3** → 可决定重大修缮
- §303 共有物分割：共有人协议无法达成时，可请求分割
- §305 份额转让：按份共有人可自由转让自己份额（向外部人须通知其他共有人）

## 考点精解

**共有份额比例**：刘某3/8 + 关某3/8 = 6/8 = 75%；张某2/8 = 25%

| 选项 | 分析 | 结论 |
|---|---|---|
| A（张某转让份额）| 按份共有人有权自由转让自己份额（§305） | **正确** ✓ |
| B（张某请求分割）| 共有人无法就共有物管理达成一致，可请求分割（§303条理） | **正确** ✓ |
| C（张某主张侵权）| 刘关二人75%多数决有权决定装修，合法行使权利，非侵权 | **错** |
| D（刘关有权装修）| 75%>2/3阈值，满足§301多数决 → **有权推进** | **正确** ✓ |

## 📐 口诀

> **按份共有重大事项：2/3以上份额同意（§301）；75%>2/3 → 有权；少数人可转让份额或请求分割，但不能主张侵权。**
