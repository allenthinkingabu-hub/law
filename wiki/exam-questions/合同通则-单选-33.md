# C1-单选-33 · 非典型合同识别（退休返聘"销售责任书"）

## 题干

> 龙某原为某实业公司的销售人员，退休后与该实业公司签订了《销售人员责任认定书》，约定了全年销售任务，年底货款100%两清，提成20%。请问：龙某和某实业公司签订的《销售人员责任认定书》性质属于？（2024金题-2-19）

- A. 非典型合同
- B. 行纪合同
- C. 买卖合同
- D. 劳动合同

## 我的答案

**A**（非典型合同 / 无名合同）<!-- confidence: EXTRACTED -->（官方参考答案：A）

## 涉及考点

- [[无名合同]]

## 考点精解 · [[无名合同]]

### 是什么 / 易混

- **识别合同性质，看权利义务实质，不看名称**（[[合同解释]] §15 名实不符）。
- **退休返聘 ≠ 劳动关系**：龙某已退休（依法享受养老保险待遇），与公司之间不再是劳动法上的"劳动者—用人单位"，而是平等主体的民事/劳务合作 → 排除**劳动合同**（D）。
- 约定"销售任务 + 货款两清 + 提成20%"混合了委托、承揽、买卖的多重特征，**法律未单独命名** → 属 [[无名合同]]（非典型合同），适用 §467（参照最相类似典型合同 + 总则通则）。

### 怎么考 / 坑在哪

- **最大陷阱：望名生义选 D 劳动合同**——"销售人员"三字诱导。退休后无劳动关系是题眼。
- B 行纪：行纪人以**自己名义**为委托人买卖并收报酬，本题龙某非以自己名义独立交易 → 排除。
- C 买卖：转移标的物所有权换价金，本题核心是"完成销售任务拿提成"的持续性合作 → 排除。

### 怎么答

题干给的全是**实质权利义务**（任务/结算/提成），且主体一方已退休无劳动关系。逐一排除典型合同后，落点在"法律没有对应名称"的**非典型合同**。故选 **A**。

## 📐 答题口诀 · [[无名合同]]：先排典型，再落非典型

> **"识别合同看实质、不看名；典型排完剩无名。"**

### 关键词触发表

```
看到题干关键词                          → 指向
"退休 / 返聘 / 已领养老金"               → 排除劳动合同（无劳动关系）
"以自己名义为他人买卖 + 报酬"            → 行纪
"转移所有权 + 价金"                      → 买卖
混合多种特征 / 法律无对应名称            → 非典型（无名）合同 §467
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| **A** | ✅ | 权利义务混合、法律未命名 → 非典型合同 |
| B | ❌ | 非"以自己名义为他人买卖收佣" |
| C | ❌ | 核心非"转移所有权换价金" |
| D | ❌ | **退休后无劳动关系**，非劳动合同 |
