# C1-单选-58 · 第三人代为履行：债务人不知情，履行照样有效

## 题干

> 甲公司对乙公司负有交付葡萄酒的合同义务。丙公司和乙公司约定，由丙公司代甲公司履行，甲公司对此全不知情。下列哪一表述是正确的？（2012-3-12）

- A. 虽然甲公司不知情，丙公司的履行仍然有法律效力
- B. 因甲公司不知情，故丙公司代为履行后对甲公司不得追偿代为履行的必要费用
- C. 虽然甲公司不知情，但如丙公司履行有瑕疵的，甲公司需就此对乙公司承担违约责任
- D. 虽然甲公司不知情，但如丙公司履行有瑕疵从而承担违约责任的，丙公司可就该违约赔偿金向甲公司追偿

## 我的答案

**A**（第三人代为清偿，债权人受领即生清偿效力，不以债务人知情为要件）<!-- confidence: EXTRACTED -->（官方参考答案：A）

## 涉及考点

- [[第三人代为履行]]

## 考点精解 · 第三人代为履行（清偿）的效力

### 是什么 / 易混

- 丙与乙约定由丙代甲履行交葡萄酒：只要**债权人乙受领**、且债务非专属性、不违反约定，**第三人的履行即产生清偿效力**——**不以债务人甲知情/同意为前提**（A 对）。
- 这是债之"清偿"可由第三人完成的体现（§523 / §524 精神）。
- **"代为履行"vs"代为清偿"别绕晕——同一件事的两面**：**代为履行**=偏重**行为**（谁来做）；**代为清偿**=偏重**效果**（债是否因此**消灭**）。本题问的是"丙的履行**有没有效力**"（即债有没有被清偿），所以**精确叫法是"第三人代为清偿"**；标题与 [[第三人代为履行]] 实体页用的"代为履行"是涵盖 §523 由第三人履行 + §524 代为清偿的**统称**，二者不矛盾。
- **顺带辨型**：本题是 **丙与债权人乙约定 + 债务人甲不知情** → 属**第三人代为清偿**（自愿替还），**不是 §523**（§523 须债务人与债权人约定由第三人履行）。

### 怎么考 / 坑在哪

- **B 错**：丙代为清偿后，在清偿范围内**对甲享有追偿权**（甲因此免除对乙的债务，受有利益）；"不得追偿"错。
- **C / D 错**：这两项把"瑕疵履行的违约责任 + 追偿"绕复杂了。题干单选定 **A**——核心结论是"代为履行有效"。C、D 关于瑕疵责任分配的表述不成立（债务人是否知情不改变代为履行的有效性；瑕疵责任与追偿另有规则，但本题答案锁定 A）。

### 怎么答

第三人代为履行有效，不看债务人是否知情 → 选 **A**。

## 📐 答题口诀 · 还债不挑人：第三人替还，债权人收了就算数

> **"别人替你还债，你知不知道都行——债主收了就清偿有效；替还的人事后还能找你追偿。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"第三人代为履行 + 债务人不知情"               → 履行仍有效（不以债务人知情为要件）★
"代为清偿后不得向债务人追偿"                  → 错（清偿范围内可追偿）
"专属债务（人身性）由第三人履行"              → 才可能无效（本题交葡萄酒非专属）
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| **A** | ✅ | 债权人受领，代为履行有效，不以债务人知情为要件 |
| B | ❌ | 代为清偿后在清偿范围内可向甲追偿 |
| C | ❌ | 瑕疵责任表述不成立，债务人知情与否不改变代为履行效力 |
| D | ❌ | 追偿规则表述不成立 |

### 🚗 老王小李故事

> 老王欠老乙一批葡萄酒。第三方老丙跟老乙说"这批酒我替老王送"，老王自己压根不知道。老丙送了、老乙收了——这履行有效吗？**有效**（A）。还债这事不挑人，只要债主乐意收、债又不是非老王亲自干不可（不是专属债务），第三人替还就算数，不用问债务人知不知道。而且老丙替还之后，还能回头找老王把这笔钱要回来（追偿），可不是"白替"。

### 🎯 一句话记忆

> **"第三人替还、债主收下 = 清偿有效（不问债务人知不知道）；替还者可追偿。"**

### 填空模板（主观题用）

> 丙代甲向乙履行交付葡萄酒，债非专属、债权人乙受领，**【代为履行产生清偿效力】**，不以债务人甲**【知情/同意】**为要件（A）；丙在清偿范围内**【对甲享有追偿权】**（B 错）。故选 **A**。
