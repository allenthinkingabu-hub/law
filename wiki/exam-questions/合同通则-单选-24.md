# C1-单选-24 · 提存的风险移转

## 题干

> 债务人将标的物提存后，标的物毁损、灭失的风险由谁承担（ ）。

- A. 债务人
- B. 债权人
- C. 提存部门
- D. 债务人和债权人共同承担

## 我的答案

**B**（债权人 · §573 法条明文："标的物提存后，毁损、灭失的风险由债权人承担"）<!-- confidence: EXTRACTED -->

## 考点精解 · 提存五条全景（§570-§574）

### 法条地图（最高检官网原文）

| 条文 | 内容 | 一句话 |
|---|---|---|
| **§570** | 提存情形：① 债权人**无正当理由拒绝受领** ② **下落不明** ③ **死亡未确定继承人**/丧失行为能力未确定监护人 ④ 法律规定其他情形；不适于提存的可**拍卖变卖提存价款** | 什么时候能提存 |
| **§571** | 标的物（或变卖价款）交付提存部门时**提存成立**；提存成立 = **视为债务人已交付标的物** ★ | 提存 = 视为交付 |
| **§572** | 提存后债务人应**及时通知**债权人或其继承人、监护人、财产代管人 | 提存要通知 |
| **§573** | 提存后**毁损灭失风险由债权人承担**；提存期间**孳息归债权人**；**提存费用由债权人负担** ★ | 三个"债权人" |
| **§574** | 债权人可随时领取；**5 年**不行使领取权 → 消灭，提存物扣除费用后**归国家**；例外：债权人对债务人负有到期债务未履行 / 书面放弃领取 → 债务人可**取回** | 5 年不领归国家 |

### 4 选项陷阱解析

| 选项 | 判断 | 详细法理分析 |
|---|---|---|
| A · 债务人 | ❌ | **直觉陷阱**：东西还没真正到债权人手里，直觉上似乎债务人还得管。错——**§571 提存成立 = 视为已交付**，债务人在提存范围内**已经履行完毕**（债务消灭 §557(三)），风险随"交付"移转。债务人已经合法"下车"。 |
| **B · 债权人** | ✅ | **§573 法条明文**："标的物提存后，毁损、灭失的风险**由债权人承担**。"法理：① 提存的发生**可归责于债权人**（拒绝受领 / 下落不明）② 提存视为交付（§571）→ 按交付主义（§604）风险随交付移转 ③ 债务人已尽其责，不能让守约方继续背风险。 |
| C · 提存部门 | ❌ | **角色混淆陷阱**：提存部门（公证处等）只是**保管人**，不是风险承担者。台风地震把提存物毁了（不可归责事由）→ 债权人自担。⚠️ 区分：若提存部门**保管不善**有过错致损 → 那是**赔偿责任**（过错责任），不是"风险负担"——风险特指**不可归责于任何人**的意外毁损灭失。 |
| D · 共同承担 | ❌ | 无任何法条依据——风险负担是"非此即彼"的分配规则，§573 明确分配给债权人**一方**。 |

→ 正确答案 = **B** ✅

## 🔑 核心概念深度讲解 1 · "提存视为交付" → 风险移转的逻辑链（§571 → §604 → §573）

```
为什么提存后风险归债权人？三步逻辑链：

第 1 步  §604 交付主义（风险负担总规则）
        "标的物毁损、灭失的风险，交付之前由出卖人承担，
         交付之后由买受人承担"
        → 中国法风险负担跟着【交付】走（不跟所有权走）

第 2 步  §571 提存的"视为交付"拟制
        "提存成立的，视为债务人在其提存范围内已经交付标的物"
        → 交给提存部门那一刻 = 法律上等于交给了债权人

第 3 步  §573 风险移转结论
        视为交付 → 风险随"交付"移转 → 债权人承担 ✅
```

**一句话**：提存是把"交付"这个动作**拟制完成**——交付完成，风险就过去了。

## 🔑 核心概念深度讲解 2 · §573 三个"债权人"一揽子规则

> **§573 原文**：标的物提存后，毁损、灭失的**风险由债权人承担**。提存期间，标的物的**孳息归债权人**所有。**提存费用由债权人负担**。

| 项目 | 归属 | 法理理由 |
|---|---|---|
| **风险**（毁损灭失）| 债权人 | 视为交付 + 提存可归责于债权人 |
| **孳息**（天然孳息：母牛生小牛；法定孳息：价款利息）| 债权人 | **利益与风险一致原则**——风险你担、好处也归你 |
| **提存费用**（公证费 / 保管费 / 鉴定费 / 拍卖费等）| 债权人 | 提存因债权人原因发生（拒领 / 失踪）——你不找事就没这笔开销 |

**法理核心**：提存的发生**可归责于债权人**（§570 四种情形全是债权人侧的原因）——债务人是"想履行而履行不了"的守约方，所以三项后果全部一揽子归债权人。

**对照记忆**：风险 / 孳息 / 费用——**"祸福开销全归债主"**。

## 🔑 核心概念深度讲解 3 · §574 领取权 5 年消灭 + 双重例外

> **§574**：债权人可以**随时领取**提存物。但债权人对债务人**负有到期债务**的，在债权人未履行债务或者提供担保之前，提存部门根据债务人的要求**应当拒绝其领取**。
> 债权人领取提存物的权利，**自提存之日起 5 年内**不行使而消灭，提存物**扣除提存费用后归国家所有**。但债权人未履行到期债务，或者债权人向提存部门**书面表示放弃**领取的，债务人负担提存费用后**有权取回**提存物。

**三个层次**：
1. **原则**：债权人随时可领
2. **对抗**：债权人欠债务人到期债 → 债务人可要求提存部门**拒绝其领取**（类似同时履行抗辩的延伸）
3. **消灭**：5 年不领 → 归国家（扣除费用）；但若债权人欠债未履行 / 书面放弃 → **债务人可取回**

⚠️ **条文归属易错点**："5 年归国家"在 **§574**，不在 §573——§573 只管风险/孳息/费用三件事。

        → 提存期间这 80 万生的利息（法定孳息）→ 归小李（§573）

### 💡 关键洞察 1：提存是债务人的"合法下车键"

§570 四种提存情形（拒领 / 失踪 / 死亡无继承人 / 其他）**全是债权人侧的原因**——债务人明明想履行却交不出去。提存制度就是给守约债务人一个**单方解套出口**：交给提存部门 = 履行完毕，从此风险、孳息、费用全部翻篇给债权人。

### 💡 关键洞察 2：风险负担 ≠ 保管责任（C 项陷阱的本质）

| 概念 | 含义 | 承担者 |
|---|---|---|
| **风险负担** | **不可归责于任何人**的意外毁损灭失（台风 / 地震）谁吃亏 | 债权人（§573）|
| **保管责任** | 提存部门**保管不善**（有过错）致损的赔偿 | 提存部门（过错责任）|

→ 题干问"毁损、灭失的**风险**" = 问前者 → B。若题干改问"提存部门未尽保管义务致车被盗" → 提存部门赔偿。**看清问的是"风险"还是"过错责任"**。

### 💡 关键洞察 3：条文归属精确记忆（防"张冠李戴"陷阱）

```
§570 → 什么时候【能】提存（四情形 + 变卖提存价款）
§571 → 提存何时【成立】+ 视为交付 ★
§572 → 提存后要【通知】
§573 → 风险 / 孳息 / 费用 三个"债权人" ★（本题）
§574 → 领取权 + 5 年归国家 + 债务人取回
```

→ 易错："5 年归国家"常被误记进 §573——它在 **§574**。

### 🆚 提存前 vs 提存后 — 法律状态一表对照

| 维度 | 提存前 | 提存后 |
|---|---|---|
| 债务状态 | 存续（债务人负交付义务）| **消灭**（§557(三) + §571 视为交付）|
| 毁损灭失风险 | 债务人（交付前 · §604）| **债权人**（§573）★ |
| 孳息 | 债务人（所有权人收益）| **债权人**（§573）|
| 保管费用 | 债务人自理 | **债权人**负担（§573）|
| 债权人迟延受领的违约风险 | 债务人可主张受领迟延 | 已解套，无需再主张 |

### 🎯 一句话记忆

### 填空模板（主观题用）

> 债务人因债权人**【无正当理由拒绝受领 / 下落不明】**等原因难以履行债务，依 §570 将标的物提存。依 **§571**，标的物交付提存部门时提存成立，**【视为债务人已交付标的物】**，债务**【消灭】**（§557(三)）。
>
> 依 **§573**，标的物提存后，毁损、灭失的风险**【由债权人承担】**；提存期间孳息**【归债权人】**；提存费用**【由债权人负担】**。
>
> 提存部门仅为**【保管人】**，对不可归责事由造成的毁损**【不承担风险】**（仅保管过错时负赔偿责任）。故选 **B**。
