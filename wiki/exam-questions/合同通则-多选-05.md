# C1-多选-05 · 质量约定不明的补充

## 题干

> 甲公司向乙公司订购货物，双方对质量未作明确约定，也未达成补充协议，应当按照哪些标准确定？

- A. 合同的有关条款
- B. 该行业领域双方均知道的通常做法
- C. 甲乙公司往常交易的习惯做法
- D. 甲公司支付的价款高低

## 我的答案

**ABC**<!-- confidence: INFERRED -->

## 涉及考点

- §510（约定不明的补充）
- §511（合同条款的补救规则）
- [[交易习惯]]

## 考点精解 · 约定不明的补充顺序

### 是什么 / 易混

**§510 → §511 二级补充链**：
1. **第一档**：补充协议（达不成→进下一档）
2. **第二档**：合同的**有关条款 + 交易习惯**
3. **第三档**：法律规定（§511 详细规则，如质量按国标 / 行业标 / 通常标准）

**交易习惯**包括：
- 行业内**普遍做法**（B）
- 双方**之前的交易做法**（C）

→ 价款（D）**不是质量判断的标准** — 价款高低不能反推质量。

### 怎么考 / 坑在哪

- **陷阱 D**："高价 = 高质" 是市场逻辑而非法律标准
- §510 / §511 是**通用补充规则**——其他条款约定不明（价款 / 期限 / 地点）同样适用

### 怎么答

ABC。

质量补充顺序：合同条款 → 交易习惯（行业 + 双方往来）→ 法定标准。价款高低无关。
