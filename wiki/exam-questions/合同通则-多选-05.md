# C1-多选-05 · 质量约定不明的补充

## 题干

> 甲公司向乙公司订购货物，双方对质量未作明确约定，也未达成补充协议，应当按照哪些标准确定？

- A. 合同的有关条款
- B. 该行业领域双方均知道的通常做法
- C. 甲乙公司往常交易的习惯做法
- D. 甲公司支付的价款高低

## 我的答案

**ABC**<!-- confidence: INFERRED -->

## 考点精解 · 约定不明的补充顺序

### 是什么 / 易混

**§510 → §511 二级补充链**：
1. **第一档**：补充协议（达不成→进下一档）
2. **第二档**：合同的**有关条款 + 交易习惯**
3. **第三档**：法律规定（§511 详细规则，如质量按国标 / 行业标 / 通常标准）

**交易习惯**包括：
- 行业内**普遍做法**（B）
- 双方**之前的交易做法**（C）

→ 价款（D）**不是质量判断的标准** — 价款高低不能反推质量。

### 怎么考 / 坑在哪

- **陷阱 D**："高价 = 高质" 是市场逻辑而非法律标准
- §510 / §511 是**通用补充规则**——其他条款约定不明（价款 / 期限 / 地点）同样适用

### 怎么答

ABC。

质量补充顺序：合同条款 → 交易习惯（行业 + 双方往来）→ 法定标准。价款高低无关。

## 📐 答题口诀 · 约定不明填补"先商量 → 再惯例 → 后法定"

> 凡是"约定不明 / 没说清"——**先协议补 → 再按合同条款 / 交易习惯 → 最后才上法定标准**；价款高低不是质量标准。

```
看到题干关键词                                  → 判断
"质量 / 价款 / 地点 约定不明 + 没补充协议"        → 按合同有关条款 + 交易习惯（§510）★
"行业通常做法 / 双方以前的交易惯例"              → 都属"交易习惯"
"前面都定不了"                                  → 上 §511 法定标准（质量：强制国标→推荐国标→行业标→通常 / 符合目的标准）
"价款高 = 质量好"                               → 错（市场逻辑，非法律标准）
```

### 📋 4 选项陷阱解析

| 选项           | 判断  | 理由                          |
| ------------ | --- | --------------------------- |
| **A 合同有关条款** | ✅   | §510 第二档第一项                 |
| **B 行业通常做法** | ✅   | 属"交易习惯"（行业普遍做法）             |
| **C 双方往来习惯** | ✅   | 属"交易习惯"（当事人之间惯例）            |
| D 价款高低       | ❌   | "高价 = 高质"是市场逻辑，**不是**质量判断标准 |

### 🚗 老王小李故事

> 老王向小李订一批货，**质量没写清**、事后也**没补签协议**。这货按啥质量交？——**先看合同里其他条款 + 交易习惯**：行业里通常怎么干（B）、老王小李以前打交道的老规矩（C），加上合同别处的相关条款（A），这三样都算数（§510）。要是这么着还定不下来，才轮到**法定标准**（§511：先强制国标 → 再推荐国标 → 再行业标 → 最后通常 / 符合目的的标准）。至于"老王给的钱多就该给好货"（D）？——那是做买卖的心理，**法律不认**：价高 ≠ 质优。

### 🎯 一句话记忆

> **"约定不明：先协议补 → 再条款 / 交易习惯 → 后法定标准；价款高低 ≠ 质量标准。"**

### 填空模板（主观题用）

> 甲乙对质量约定不明、又未达成**【补充协议】**，依《民法典》**【§510】**，按**【合同有关条款 + 交易习惯（行业通常做法 + 双方往来惯例）】**确定（A、B、C）；价款高低**【不是质量判断标准】**（D 错）；仍不能确定的，再依**【§511 法定标准：强制国标→推荐国标→行业标→通常标准】**。故选 **ABC**。
