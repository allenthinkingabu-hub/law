# C1-单选-43 · 二手平台砍价拉扯：以实际履行确认 1000 元合意

## 题干

> 甲在校内的二手平台上发布了信息出售自己的自行车，价款1000元，附上了发票照片和自行车照片，并附言"诚信出售，先到先得"。乙看到消息后，通过微信联系甲，出价900元。甲不同意。之后二者又来回拉扯了几次。几天后，乙给甲发微信"就按你说的价来，1100元"。后二人线下见面，乙转账1000元给甲，甲主张还差100元并出示了微信聊天记录。乙表示是自己打错了。关于本案，下列哪一说法是正确的？（2023金题-2-1-11）

- A. 两人间成立了1100元的合同
- B. 甲在二手平台上发布的信息属于要约邀请
- C. 两人未达成合意
- D. 两人间成立了1000元的合同

## 我的答案

**D**（线下乙转 1000、甲受领 = 以行为达成 1000 元合意）<!-- confidence: EXTRACTED -->（官方参考答案：D）

- [[要约]]

## 考点精解 · 要约/反要约/以行为承诺

### 是什么 / 易混

- 甲发布"自行车 1000 元 + 发票照 + 先到先得" = **要约**（内容具体确定 + 受拘束意图，B 错把它当要约邀请）。
- 乙"出价 900" = 对价款的**实质性变更** → **反要约**（§488），原要约消灭。
- 来回拉扯几次后乙发"1100 元"（打错）= 乙的新要约，但**甲从未发出过 1100 的要约**，"就按你说的价"指向的真实价是 1000。
- 线下乙**实际转账 1000**、甲**受领** → 双方以**行为**就 **1000 元**达成合意（§483 合同成立 / 以行为作出承诺）。乙"打错的 1100"是其内部错误的意思表示，未被甲接受为价款。

### 怎么考 / 坑在哪

- **A 1100 错**：甲根本没主张过 1100，1100 是乙单方笔误，未形成合意。
- **B 要约邀请错**：附具体价款 + 实物/发票 + "先到先得"，已具备要约的确定性与受拘束性。
- **C 未达成合意错**：双方已通过转账 1000 / 受领的行为达成一致。

### 怎么答

实际成交以"转 1000、收 1000"的行为确定 → 1000 元合同成立 → 选 **D**。

## 📐 答题口诀 · 砍价拉扯：还价 = 反要约；最后看"实际怎么付怎么收"

> **"挂价带照'先到先得' = 要约；你还价 = 反要约；笔误的数字不算数，实际转多少 = 成交多少。"**

### 关键词触发表

```
看到题干关键词                              → 定性
"发布价款 + 实物照/发票 + 先到先得"          → 要约（不是要约邀请）
对方"出价 ××"低于/不同于原价                 → 实质性变更 → 反要约 §488
"打错了 / 笔误"的数字                         → 非真实意思，不构成该价合意
最终"实际转账 + 受领"                         → 以行为达成该数额的合意 ★
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 1100 | ❌ | 甲从未要约 1100，乙笔误未成合意 |
| B 要约邀请 | ❌ | 有价款+发票+先到先得 = 要约 |
| C 未达成合意 | ❌ | 转 1000/收 1000 的行为已达成 |
| **D 1000** | ✅ | 实际履行确认 1000 元合意 |

### 🚗 老王小李故事

> 老王在二手群发"自行车 1000，发票实物照都有，先到先得"（这就是**要约**，不是随便问问）。小李微信砍到 900（**反要约**，把老王的原价顶回去了）。俩人来回磨了几轮，小李手一抖发了句"就按你说的，1100"（其实是打错）。线下见面，小李**实际转了 1000**，老王收下，又回头说"还差 100"。差不差？不差——成交价以"**实际转 1000、收 1000**"的行为为准，1100 是小李自己手滑，不算数。1000 元合同，成立。

### 🎯 一句话记忆

> **"挂价带照=要约；还价=反要约；笔误不算数；实际付收定成交。"**

### 填空模板（主观题用）

> 甲发布信息含**【具体价款+实物发票+先到先得】**，为**【要约】**；乙出价 900 系**【实质性变更→反要约】**。乙"1100"为**【笔误，非真实意思】**，未与甲形成该价合意；二人线下**【实际转账 1000 并受领】**，以行为就 1000 元**【达成合意、合同成立】**。故选 **D**。
