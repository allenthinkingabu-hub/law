# C2-多选-44 · 借款人擅改用途：贷款人三项权利 + 抵押未登记无优先受偿权（§676/§403）

## 题干（2017-3-90）

> 甲服装公司与乙银行订立合同，约定甲公司向乙银行借款300万元，用于购买进口面料。同时，双方订立抵押合同，约定甲公司以其现有的以及将有的生产设备、原材料、产品为前述借款设立抵押。借款合同和抵押合同订立后，乙银行向甲公司发放了贷款，但未办理抵押登记。之后，根据乙银行要求，丙为此项贷款提供连带责任保证，丁以一台大型挖掘机作质押并交付。如甲公司违反合同约定将借款用于购买办公用房，则乙银行享有的权利有？

- A. 提前收回借款
- B. 解除借款合同
- C. 请求甲公司按合同约定支付违约金
- D. 对甲公司所购办公用房享有优先受偿权

## 我的答案

**ABC**<!-- confidence: EXTRACTED -->

§676 明确规定借款人擅改用途时贷款人可提前收回/解除合同（A/B）；约定违约金可主张（C）；但D错：抵押合同约定的是"生产设备/原材料/产品"而非办公用房，且动产浮动抵押未登记不得对抗善意第三人（§403）。

## 涉及考点

- [[借款合同]] 借款用途违约：贷款人三项权利（§676）
- 动产抵押权设立与登记效力（§403）
- 约定违约金可并用（§585）
- 抵押物范围：约定外不适用

## 考点精解 · §676 借款用途违约救济体系

### 是什么 / 易混

**§676 借款人未按约定用途使用借款的，贷款人可以**：
1. **停止发放**借款
2. **提前收回**借款
3. **解除**合同

本题：甲公司擅改用途（进口面料→办公用房）→ 乙银行同时享有上述三项权利（题目只列了"提前收回"和"解除"，再加上合同约定的违约金）。

### 为什么 D 错

**D说"对所购办公用房享有优先受偿权"**——错！原因双重：

**原因一：抵押物范围不含办公用房**
抵押合同约定的是"现有的以及将有的**生产设备、原材料、产品**"。
办公用房不是生产设备/原料/产品 → 不在抵押范围内 → 无优先受偿权基础。

**原因二：动产浮动抵押未登记 = 不对抗善意第三人**
§403（动产抵押权生效）：
> 以动产抵押的，抵押权**自抵押合同生效时设立**；未经登记，**不得对抗善意第三人**。

乙银行未办理抵押登记 → 抵押权设立（在当事人之间有效），但**不得对抗善意第三人**（无登记优先权）。
即：乙银行对生产设备等有未登记抵押，可以追及；但对办公用房（不在抵押范围内），无任何优先权。

### 为什么 ABC 正确

| 权利 | 法律依据 | 说明 |
|---|---|---|
| A. 提前收回借款 | §676 | 用途违约→贷款人可提前收回 |
| B. 解除借款合同 | §676 + §563（根本违约） | 擅改用途 = 根本违约，可解除 |
| C. 主张违约金 | §585 | 合同约定违约金条款有效，可主张 |

注意：A/B/C 可以并用（主张违约金 + 提前收回，或解除合同 + 赔偿损失），但解除后就不再有"提前收回"，而是"返还借款"。

### 担保体系全景（本题复杂情形）

| 担保类型 | 生效情况 | 有效性 |
|---|---|---|
| 抵押（生产设备等）| 未办登记 | 设立有效，但不对抗善意第三人 |
| 丙连带责任保证 | 已成立（书面） | 有效 |
| 丁质押（挖掘机）| 已交付 | **动产质押自交付时设立**（§428）→ 有效，可优先受偿 |

乙银行对丁质押的挖掘机有**有效的质押权**（已交付），可就挖掘机优先受偿（但本题D问的是办公用房，不是挖掘机）。

### 怎么考 / 坑在哪

1. **D 双重排除**：①不在抵押范围 ②即便是抵押物也未登记。两层叠加→明确无优先受偿权。
2. **A+B可并用**：提前收回 ≠ 解除，两者都是§676 的选项；违约金可与赔偿损失并用（§585）。
3. **区分动产抵押 vs 质押**：
   - 动产抵押（浮动抵押）：合同生效设立，登记才能对抗第三人（§403）
   - 动产质押：**交付设立**（§428），无需登记

## 📐 答题口诀 · §676 借款用途违约三板斧

**关键词触发**：擅改借款用途 / 私自挪用借款 / 贷款人发现用途违约

**🎯 一句话记忆**：
> 擅改用途 → §676 三板斧：停发 / 提前收 / 解除；未登记抵押 → 不能对抗善意第三人。

**§676 三板斧**：
```
借款人擅改用途 →
  ① 停止发放借款（尚未发完的部分）
  ② 提前收回借款（已发放的部分）
  ③ 解除合同（彻底终止关系）
  + ④ 约定违约金 → 可并用
```

**抵押 vs 质押生效对比口诀**：
```
动产抵押：合同生效即设立，登记才对抗第三人（§403）
动产质押：交付即设立，无需登记（§428）
```
