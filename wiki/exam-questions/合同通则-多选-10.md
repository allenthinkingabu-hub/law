# C1-多选-10 · 不得转让的债权（§545 三类 + 自然债务可转）

## 题干

> 下列哪些债权**不得转让**？

- A. 甲对乙享有的赌债
- B. 甲对乙已经过诉讼时效的 5 万元债权
- C. 甲因人身遭受伤害对乙的赔偿请求权
- D. 当事人约定不得转让的债权

## 我的答案

**ACD**（A 赌债非法不受保护、C 人身损害赔偿性质专属、D 约定禁止；B 过时效债权属自然债务**可转**，不选）<!-- confidence: INFERRED -->

> 🔎 **2026-06-09 联网核实（ACD 确认无误，无需订正）**：经民法典 §545 + 最高检 / 澎湃新闻 / 律所通说一致——① **赌债**系非法之债、不受法律保护（"赌债不是债"）→ 不得转让（A）；② **过诉讼时效的债权**仍是财产权（自然债务）、**可以转让**（受让人继受时效抗辩）→ 不属"不得转让"（B 不选）；③ **人身伤害赔偿请求权**明列 §545(1) 专属清单 → 性质不得转让（C）；④ **约定不得转让**= §545(1)(二)（D）。与 [[合同通则-单选-21]] 不同，本题推断答案经得起法源检验。

## 涉及考点

- [[债权转让]] 禁止情形（**§545 三类**：性质专属 / 当事人约定 / 法律规定）
- **自然债务可转让**：过诉讼时效的债权仍为财产权，可转（受让人继受时效抗辩）
- **专属清单**（人身损害赔偿 / 工资 / 抚恤金 / 扶养费…）——同时管 [[债权转让]] 禁止（§545 性质）与 [[代位权]] 排除（§535 但书）

## 考点精解 · §545 三类不得转让 + 一个"可转"陷阱

### 是什么 / 易混

**§545（不得转让的债权 = 三类）**：

| #   | 类型                   | 典型                                               | 本题               |
| --- | -------------------- | ------------------------------------------------ | ---------------- |
| ①   | **根据债权性质**（专属于债权人自身） | 人身损害赔偿 / 扶养费 / 赡养费 / 工资 / 退休金 / 抚恤金 / 安置费 / 人寿保险 | **C**            |
| ②   | **按照当事人约定**          | 合同约定"不得转让"（但 §545 II：不得对抗（善意）第三人）                | **D**            |
| ③   | **依照法律规定**           | 法律明文禁止                                           | —（A 赌债近此：非法不受保护） |

四项对照：

- **A 赌债** → **非法之债，自始不受法律保护**（"赌债不是债"），连合法债权都不是，更不能作为合法债权转让 → **不得转让** ✓
- **B 已过诉讼时效的 5 万** → 时效届满只丧失**胜诉权**，债权作为**财产权仍存在**（自然债务）→ **可以转让**（受让人继受时效抗辩）→ **不属"不得转让"** ✗
- **C 人身损害赔偿请求权** → §545(1) **性质专属**（明列专属清单）→ **不得转让** ✓
- **D 约定不得转让** → §545(1)(二) → **不得转让** ✓

→ 不得转让的是 **A、C、D**。

### 怎么考 / 坑在哪

- **B 是头号陷阱**：「过了诉讼时效 → 就不能转让」是**错的**！债权仍是财产、**可转**，只是受让人接手那个"时效抗辩"的包袱（债务人仍可主张时效抗辩）。
- **C 的进阶 nuance**：人身损害赔偿请求权**未确定数额时**专属、不得转让；一旦经**协议 / 判决确定为具体金额**，转为普通金钱债权 → **可转**。本题是一般"赔偿请求权"（未确定）→ 专属不得转让。
- **D 的进阶 nuance**：约定不得转让，§545 II——**金钱债权**约定不得转让"**不得对抗第三人**"、**非金钱债权**"不得对抗**善意**第三人"。即"约定禁止"对外效力受限，但作为"不得转让"类别本身，D 入选。
- **专属清单是通用考点**：人身损害赔偿 / 工资 / 抚恤金等，既是 §545 债权转让的"性质专属"，也是 §535 代位权的"专属排除"——一张清单，两处通吃（见 [[合同通则-单选-17]] / [[合同通则-多选-08]]）。

### 怎么答

A 赌债（非法不受保护）、C 人身损害赔偿（性质专属）、D 约定不得转让（§545），均不得转让；B 过时效债权属自然债务、可转（不选）。故选 **ACD**。

## 📐 答题口诀 · 不得转让三类（性质/约定/法定）；过时效的债照样能转

> **"不得转让三类——**性质专属**（人身损害赔偿、工资、抚恤金…）、**约定禁止**、**法定/非法不保护**（赌债）；唯独**过了诉讼时效的债**还是财产、**照样能转**（受让人接时效抗辩的包袱）。"**

### 📋 4 选项陷阱解析

| 选项 | 能否转让 | 不得转让？ | 依据 |
|---|---|---|---|
| **A 赌债** | ❌ 不能 | ✅ 选 | 非法之债、不受法律保护（"赌债不是债"）|
| B 已过诉讼时效的 5 万 | ✅ **能转** | ❌ 不选 | 自然债务，债权仍为财产权；受让人继受时效抗辩 |
| **C 人身损害赔偿请求权** | ❌ 不能 | ✅ 选 | §545(1) 性质专属（专属清单）|
| **D 约定不得转让** | ❌ 不能 | ✅ 选 | §545(1)(二) 约定（§545 II 不得对抗（善意）第三人）|

→ 不得转让 = **ACD** ✅

### 🚗 老王小李故事

> 老王是个债主。他**卖车给小李、小李欠的那笔车款**，是普通金钱债权，想转让给**老张**完全没问题（这是**参照系**——普通债权随便转）。可老王手里还攥着几笔"特殊的债"，也想打包卖给老张——哪些**转不了**？
>
> - **A 赌债**：老王赌赢小李的钱 → **赌债压根不是合法的债、不受保护**，老王自己都讨不回，更别提转让给老张 → **转不了**（A✓）。
> - **B 过了诉讼时效的 5 万**：小李欠老王的这 5 万**过了时效** → 债**还在**（只丧了胜诉权，叫"自然债务"），是财产，老王**可以转**给老张（老张接手时也接下"时效抗辩"这包袱）→ **转得了**（B✗，不选）。
> - **C 人身损害赔偿**：小李把老王**打伤**、该赔老王的钱 → 这是"赔老王身体的苦"的**专属**请求权，跟人身绑死 → **转不了**（C✓）。
> - **D 约定不得转让**：老王和小李**白纸黑字约好**"这笔债不许转" → 约定禁止（§545）→ **转不了**（D✓）。
>
> 诀窍：转不了的就三类——**身体/身份/活命的钱（专属，C）、白纸黑字说不许转的（约定，D）、违法不受保护的（赌债，A）**；**唯独"过了时效的债"（B）还是块财产、照样能卖**。

### 🎯 一句话记忆

> **"不得转让三类：性质专属（人身损害赔偿）/ 约定禁止 / 非法不保护（赌债）；过了诉讼时效的债不是'不得转'——它是自然债务、照样能转，受让人接时效抗辩。"**

### 填空模板（主观题用）

> 债权转让的禁止情形（§545）有三类：**【根据债权性质（专属）/ 当事人约定 / 依照法律规定】**。A 赌债系**【非法之债、不受法律保护】**（不得转让）；C 人身损害赔偿请求权属**【性质专属】**（§545(1)，不得转让）；D 约定不得转让属**【§545(1)(二)】**（不得转让，但 §545 II 不得对抗（善意）第三人）。B 已过诉讼时效的债权属**【自然债务、债权仍为财产权、可以转让】**（受让人继受时效抗辩，不选）。故选 **ACD**。

### 横向真题对照

- 本题（多选-10）= **不得转让**三类（性质 / 约定 / 法定）+ 自然债务可转 → ACD

- [[合同通则-多选-11]] = 债务人对受让人的**抗辩继受**（§548）→ ABCD
- [[合同通则-单选-17]] = 代位权**专属排除**（人身赔偿 / 工资 / 安置费不可代位，合伙分红可代位）→ C
- [[合同通则-多选-08]] = 代位权专属排除（已到期肖像费可代位）→ ABC
- → **同一张"专属清单"**（人身损害赔偿 / 工资 / 抚恤金…）：在 [[债权转让]] 里是"**性质不得转让**"（§545），在 [[代位权]] 里是"**专属不得代位**"（§535 但书）——一处掌握、两处通吃。
