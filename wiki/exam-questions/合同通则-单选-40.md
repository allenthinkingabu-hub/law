# C1-单选-40 · 美容"余款不退"格式条款无效

## 题干

> 甲与乙公司订立美容服务协议，约定服务期为半年，服务费预收后逐次计扣，乙公司提供的协议格式条款中载明"如甲单方放弃服务，余款不退"（并注明该条款不得更改）。协议订立后，甲依约支付5万元服务费。在接受服务1个月并发生费用8000元后，甲感觉美容效果不明显，单方放弃服务并要求退款，乙公司不同意。甲起诉乙公司要求返还余款。下列哪一选项是正确的？（2017-3-11）

- A. 美容服务协议无效
- B. "如甲单方放弃服务，余款不退"的条款无效
- C. 甲单方放弃服务无须承担违约责任
- D. 甲单方放弃服务应承担继续履行的违约责任

## 我的答案

**B**（"余款不退"格式条款无效）<!-- confidence: EXTRACTED -->（官方参考答案：B）

## 涉及考点

- [[格式条款]]

## 考点精解 · [[格式条款]] 内容控制（§497）

### 是什么 / 易混

- "余款不退 + 不得更改" = 乙公司预先拟定、不容协商的**格式条款**。
- 它**不合理地免除乙方退款责任、加重甲方负担、排除甲方主要权利**（任意解除后的退款权）→ 依 §497 **该条款无效**。
- **无效的只是"该条款"，不是整个协议**——协议其他部分仍有效（[[合同无效]]的"部分无效不影响其余"§156）。

### 怎么考 / 坑在哪

- **A"协议无效"错**：只是个别格式条款无效，协议本身有效。
- **C"无须违约责任"错**：服务合同中甲方有任意解除权（委托类），但**已发生的费用 8000 元应承担**；说"无须任何责任"过于绝对。
- **D"继续履行"错**：美容服务具人身属性，不能强制继续履行（§580 不适于强制履行）。
- 结论落在"**那一条**无效" → B。

### 怎么答

锁定格式条款"余款不退"违反 §497 → 单条无效，协议仍有效 → 选 **B**。

## 📐 答题口诀 · 格式条款：免己责/加重对方/排除主要权利 = 无效（单条）

> **"霸王条款只敲掉那一条，合同照样有效。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"格式条款 + 余款不退/不退费/概不负责"        → §497 不合理免责 → 该条款无效
"注明不得更改 / 一律 / 概不"                 → 格式条款霸王味，重点审查
"整个协议无效"                              → 多半错（部分无效 §156）
"继续履行"服务类人身性合同                   → 不能强制（§580）
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 协议无效 | ❌ | 仅个别条款无效，协议有效 |
| **B 该条款无效** | ✅ | §497 不合理免除己方退款责任 |
| C 无须责任 | ❌ | 已发生费用 8000 元应担 |
| D 继续履行 | ❌ | 美容人身性，不能强制继续履行 |

### 🚗 老王小李故事

> 小李在老王的美容店办了张半年卡，预交 5 万。合同里老王早印好一行小字："中途不做了，余款一律不退，此条不得改。"小李做了一个月（花了 8000）觉得没效果，要退余款，老王搬出那行字。法院怎么判？那行"余款不退、不得更改"是老王单方拟的**霸王格式条款**，不合理地把退款责任全免了——**这一条无效**，余款（5 万 − 8000）该退。但注意：无效的只是这一条，整张美容合同还有效，已花的 8000 也算数。

### 🎯 一句话记忆

> **"余款不退是霸王 → 单条无效；合同还活着，已花的钱照扣。"**

### 填空模板（主观题用）

> "余款不退、不得更改"系乙方预拟的**【格式条款】**，不合理免除其退款责任、排除甲方**【任意解除后取回余款】**的主要权利，依 §497 **【该条款无效】**；但属**【部分无效】**，不影响协议其余效力（§156）。甲应承担已发生的**【8000 元费用】**，余款应退。故选 **B**。
