# C2-多选-12 · 承运人不担责的情形

## 题干

> 根据《民法典》，承运人对运输过程中下列哪些旅客伤亡事件**不承担赔偿责任**？

- A. 一旅客因制止扒窃行为被歹徒刺伤
- B. 一旅客在客车正常行驶过程中突发心脏病身亡
- C. 一失恋旅客行车途中吞服安眠药过量致死
- D. 一**免票乘车**婴儿在行车途中因急刹车受伤

## 我的答案

**BC**<!-- confidence: INFERRED -->

## 涉及考点

- [[客运合同]] 承运人**严格责任 + 法定例外**（§823、§824）
- 📐 **答题模型** → [[民法-合同-运输合同模型]]

## 考点精解 · §823 三大免责事由

### 是什么 / 易混

**§823**（承运人责任）：
> 承运人应当对运输过程中**旅客的伤亡**承担赔偿责任，但是伤亡是**旅客自身健康原因**造成的，或者承运人证明伤亡是旅客**故意 / 重大过失**造成的，**不承担赔偿责任**。

**§824**（免票同等）：旅客持失效客票乘坐、**免票**或者经承运人许可搭乘的，**适用**前条规定。

| 情形 | 是否担责 |
|---|---|
| **自身健康**原因（突发疾病 / 心脏病） | **不担责**（§823 II） |
| **旅客故意**（自杀 / 故意服药）| **不担责**（§823 II） |
| **旅客重大过失** | **不担责**（§823 II） |
| **免票 / 优惠 / 经许可** | **同样担责** |
| **第三人侵害**（如扒窃案）| **担责**（运输中保障安全义务 + 可向第三人追偿）|
| **承运人原因**（急刹车）| **担责** |

本题对照：
- A 制止扒窃被刺伤 → 第三人侵害，承运人**仍担责** → 不入"不担责"
- B 突发心脏病 → 自身健康 → **不担责** → 入
- C 故意服药致死 → 旅客**故意** → **不担责** → 入
- D 免票婴儿急刹车受伤 → **同等担责**（§824）→ 不入

### 怎么考 / 坑在哪

- **D 经典陷阱**：以为"免票 = 不担责" → 错，**同等责任**
- **A 易错**：以为"第三人造成 = 承运人不担责" → 错，承运人有**保障安全义务**

### 怎么答

BC。
