# C1-单选-12 · 缔约过失 vs 合同成立

## 题干

> 甲公司于 6 月 5 日以传真方式向乙公司求购一台机床，要求"立即回复"。乙公司当日回复"收到传真"。6 月 10 日，甲公司电话催问，乙公司表示同意按甲公司报价出售，要其于 6 月 15 日来人签订合同书。6 月 15 日，甲公司前往签约，乙公司坐地起价要求加价，未获同意，乙公司遂拒绝签约。对此，下列哪一种说法是正确的？

- A. 买卖合同于 6 月 5 日成立
- B. 买卖合同于 6 月 10 日成立
- C. 买卖合同于 6 月 15 日成立
- D. 甲公司有权要求乙公司承担缔约过失责任

## 我的答案

**D**（缔约过失责任）<!-- confidence: INFERRED -->

## 涉及考点

- [[缔约过失责任]]（§500）
- [[合同成立]]（§483、§490 合同书的特别成立规则）

## 考点精解 · 合同书形式下的成立与缔约过失

### 是什么 / 易混

- 甲乙约定"6/15 来人签订合同书"——属约定**采用合同书形式订立合同**（§490）
- §490：当事人采用合同书形式订立合同的，自双方**签名 / 盖章 / 按指印**任一即成立
- 6/5 乙仅回复"收到传真"——非承诺
- 6/10 乙口头同意 + 要求 6/15 签约——口头同意属意向，但因双方约定签订合同书，**未签订之前合同未成立**
- 6/15 乙拒签——合同**未成立**
- 但乙的行为属于"假借订立合同恶意磋商"或"违反诚信原则" → 构成 [[缔约过失责任]]

### 怎么考 / 坑在哪

- 错选 B：误以为 6/10 口头同意 = 承诺 = 合同成立
- 实际：双方约定合同书形式 → 须按 §490 签字盖章 → 6/15 前合同未成立

### 怎么答 

合同未成立 → 排除 A、B、C。乙坐地起价 + 拒签 → 违反诚信 → 甲可主张 [[缔约过失责任]]。故选 **D**。

### 📐 答题口诀 · 合同成立 + 生效 三步骤万能模板

> 主观题大案例**第一步固定问题**：合同**成立没有 + 何时成立 + 是否生效**。本题是这个口诀的"反面应用"——合同**未成立**仍有责任。

#### Step 1：定要约 / 承诺
```
甲的行为是 [[要约]] / [[要约邀请]]？(§472 / §473 + 两要件)
乙的回复是 [[承诺]] / 反要约？(§479 / §488 实质性变更)
```

#### Step 2：判合同成立（4 种成立时点）
```
一般合同   → §483 承诺生效时（看承诺何时到达要约人）
合同书     → §490 签名 / 盖章 / 按指印任一时
已履行 + 接受 → §490 履行时    ← ⚠️ "没签字也能成立"的特殊规则
电子合同   → §491 提交订单成功时
```

> 🔍 **"已履行 + 接受" 3 要件速查**（§490 II）：
> ① 未采用书面形式 + ② 一方已履行**主要**义务 + ③ 对方**接受** → **缺一不可**
>
> 其中"已履行" = **实际做了合同最核心的那件事**（卖方交货 / 买方付款 / 装修方开工 等），不要求全部完成，"主要部分"做了就够。
>
> **本题为何 §490 II 不命中？**（3 要件 0/3 满足）
>
> | 要件 | Q12 情形 | 满足？|
> |---|---|---|
> | ① 未采用书面形式 | 双方**约定采用合同书形式** → 进入 §490 I 模式 | ❌ |
> | ② 一方已履行主要义务 | 6/15 前**双方都没交货 / 付款** | ❌ |
> | ③ 对方接受 | 乙拒签 = 没"接受"任何履行 | ❌ |
>
> → §490 II 不适用 → 合同**未成立** → 走 [[缔约过失责任]]
>
> 💡 详细解析（3 要件 + 老王小李口头买车故事 + 3 个反向场景）见 [[合同成立]] 实体页 "🔍 §490 II 深度解析" 段。

#### Step 3：判合同生效
```
§502 默认 → 成立即生效
§158 附生效条件 → 条件成就时生效
附生效期限 → 期限届至时生效
需批准    → 获批时生效（**报批义务条款独立有效**）
```

#### Step 4（反向陷阱 · 本题考点）：合同未成立 ≠ 无责任
```
合同未成立 / 无效 / 被撤销 → 仍可能产生 [[缔约过失责任]]（§500）
触发情形：
  ├─ 假借订立合同，恶意磋商  ← 本题乙坐地起价 + 拒签
  ├─ 故意隐瞒重要事实 / 提供虚假情况
  └─ 其他违背诚信原则的行为
赔偿范围：**信赖利益**（差旅 / 检测 / 机会损失），不超过履行利益
```

### 📋 Q12 套用结果

| 时点   | 事件                 | §490 合同书成立要件                      | 合同成立？       |
| ---- | ------------------ | --------------------------------- | ----------- |
| 6/5  | 乙回"收到传真"           | ❌ 非承诺                             | ❌ 否         |
| 6/10 | 乙口头同意 + 约定 6/15 签约 | ❌ 双方已约定**合同书形式** → 须签字 / 盖章 / 按指印 | ❌ 否         |
| 6/15 | 乙坐地起价 + **拒签**     | ❌ 没人签字                            | ❌ **始终未成立** |

→ 合同**未成立** → 排除 A / B / C
→ 乙违反诚信 → 触发 **缔约过失责任**（Step 4）→ 选 **D**

### 🎯 一句话记忆

> **"约定合同书形式 → 没签字盖章就没成立"**  
> **"未成立 ≠ 无责任 → 看 §500 缔约过失"**

### 填空模板（主观题用）

> 甲发出的**【行为】**构成**【要约 / 要约邀请】**（§472 / §473）。乙的回复构成**【承诺 / 新要约】**（§479 / §488）。**因双方约定采用合同书形式**，依 **§490**，合同自双方**签名 / 盖章 / 按指印**任一时成立。
>
> 本案中乙至 6/15 仍未签字 → 合同**未成立**。但乙坐地起价、拒签 → 违反诚信原则 → 甲可依 **§500** 请求 [[缔约过失责任]]，赔偿范围以**信赖利益**为限。

## 📐 缔约过失专属答题口诀

> **本题 D 的核心**：合同未成立 / 无效 / 被撤销时，如何判定 [[缔约过失责任]]？**4 步判定 + 信赖利益清单**。

### Step 1：先排查合同状态（缔约过失适用前提）
```
合同状态？
  ├─ 已成立 + 已生效 → 走 [[违约责任]]（§577）✗ 不适用缔约过失
  ├─ 未成立 → 缔约过失可能适用 ✓
  ├─ 已成立但无效（§144/§146/§153/§154）→ 缔约过失 + §157 返还 ✓
  ├─ 已成立但被撤销（§147-§151）→ 缔约过失 + §157 返还 ✓
  └─ 已成立未生效（§158 / 报批）→ 一般不适用缔约过失（按生效规则处理）
```

### Step 2：匹配 §500 五大情形之一
```
是否构成下列情形之一？
  ① 假借订立合同，恶意磋商                  ← 本题乙坐地起价拒签
  ② 故意隐瞒重要事实 / 提供虚假情况          ← 隐瞒车被查封
  ③ 其他违背诚信原则的行为                  ← 兜底
  ④ 泄露 / 不正当使用商业秘密（§501）        ← 即使合同未成立也担责
  ⑤ 合同无效 / 被撤销后过错方的赔偿（§157）   ← 撤销后处理
```

### Step 3：核算"信赖利益"赔偿范围
```
可赔（信赖利益）:
  ✅ 缔约费用：差旅 / 调查 / 检测 / 咨询费
  ✅ 机会损失：因信赖该合同放弃的其他交易机会
  ✅ 已支出的准备履行费用：原料 / 定金等
  ✅ 资金占用利息（已付款被冻结）

不可赔（履行利益）:
  ❌ "如果合同成立 + 履行可得的利润"
  ❌ 上限：信赖利益不能高于履行利益（防止反向获利）
```

### Step 4：三种责任互斥排查
```
按合同状态依次走：
  合同未成立  → 缔约过失（§500）
  合同已生效  → 违约责任（§577）
  无合同关系  → 侵权责任（§1165）
→ 三者不能并存（不会同时主张违约 + 缔约过失）
```

### 📋 Q12 缔约过失判定套用结果

| 维度 | 本题情形 | 评价 |
|---|---|---|
| **Step 1 合同状态** | 6/15 乙拒签 → **合同未成立** | ✅ 缔约过失适用 |
| **Step 2 §500 情形** | 乙先口头同意→后坐地起价→拒签 | ✅ 第 1 项"恶意磋商" + 第 3 项"违背诚信" |
| **Step 3 信赖利益** | 甲来回差旅费 + 信赖磋商支出 | ✅ 可赔 |
| **Step 4 责任类型** | 无合同 → 排除违约 | ✅ 选缔约过失 |

→ 选 **D** ✅
