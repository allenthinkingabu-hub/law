# 合同-单选-78 · 认购书另签合同约款——事实履行主要义务且接受的直接转化为本约合同

## 题干

> 甲房地产开发公司开发了一处高档写字楼，乙公司欲购买其中一层。双方签订了一份《写字楼认购书》，详细约定了房屋的单元号、面积、单价、付款方式，并约定“本认购书签订后30日内，双方应当另行签署正式的《商品房买卖合同》”。《认购书》签订后第2天，乙公司按照约定向甲公司支付了全部购房款的30%作为首付款，甲公司出具了收据并予以接受。30日届满前，该区域房价大涨，甲公司拒绝与乙公司签署正式买卖合同，并声称该《认购书》仅为预约合同，双方尚未签署正式合同，故甲公司有权退还首付款并拒绝交付房屋。关于本案合同的性质与效力，下列哪一选项是正确的？
>
> - A. 该《认购书》仅为预约合同，本约买卖合同尚未成立，甲公司有权退款并拒绝交付房屋
> - B. 虽然约定了另签合同，但《认购书》已具备本约主要条款，且乙公司已支付首付款、甲公司予以接受，该《认购书》已转化为本约合同成立
> - C. 乙公司虽已履行主要义务，但因未签署正式《商品房买卖合同》，合同属于效力待定状态
> - D. 甲公司虽然违约，但乙公司仅有权要求甲公司双倍返还定金，无权要求甲公司继续交付房屋

## 答案

**B**（当事人虽然约定将来另行订立合同，但一方已经实施了履行本约主要义务的行为且对方接受的，人民法院应当直接认定本约合同成立。）<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **预约合同模型** → [[民法-合同-预约合同模型]]
- **预约向本约的转化规则（《通则解释》第6条第3款）**：认购书、订购书等已就标的、数量、价款等主要内容达成合意，且符合合同成立要件：
  1. 若未明确约定将来另行订立合同，直接认定为本约。
  2. **事实履行转化**：虽然明确约定了将来另签合同，但“当事人一方已实施履行行为且对方接受的”，应认定为本约成立。乙公司支付30%首付款（本约主要义务），甲公司接受，符合事实履行转化，原《认购书》在法律性质上已变成本约合同，甲公司必须按买卖合同交付房屋。

## 考点精解

| 选项  | 分析                                              | 结论       |
| --- | ----------------------------------------------- | -------- |
| A   | 忽略了事实履行行为的转化效果。甲公司接受了首付款后，合同性质已转化为本约，无权任意退款解约。  | **错**    |
| B   | 完全符合《通则解释》第6条第三款。买卖合同主要条款具备且首付款已付并接受，合同已是本约合同。  | **正确** ✓ |
| C   | 事实履行使合同直接生效，并非效力待定。                             | **错**    |
| D   | 既然合同已是本约合同，乙公司有权要求甲公司继续履行（交付房屋），而不仅限于定金罚则或损害赔偿。 | **错**    |
