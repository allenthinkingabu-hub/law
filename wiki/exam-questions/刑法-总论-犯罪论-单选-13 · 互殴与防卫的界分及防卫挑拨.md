# 刑法-总论-犯罪论-单选-13 · 互殴与防卫的界分及防卫挑拨

## 题干

> 来源：依据《刑法》第20条第1款及《关于依法适用正当防卫制度的指导意见》（法发〔2020〕31号）"互殴与防卫界分、防卫挑拨"口径命制的**仿真题**（题干为本库命制，非历年真题；指导意见已联网核验，court.gov.cn / spp.gov.cn）。

下列哪一情形，行为人**成立正当防卫**？

- A. 甲、乙因纠纷相约到空地"单挑"，各持木棍互相殴打，甲将乙打成轻伤
- B. 丙为教训仇人丁，故意辱骂激怒丁，待丁挥拳打来时早有准备将丁打成重伤
- C. 戊预备好水果刀，主动找庚挑衅，趁庚动手时持刀将庚捅伤
- D. 辛在公交车上劝阻一名持刀抢劫的歹徒，被歹徒反扑，辛夺刀将歹徒手臂划伤

## 我的答案

**D**<!-- confidence: EXTRACTED -->

正确答案为 **D**。

正当防卫的"**意图（防卫认识）**"要件要求行为人主观上是**为制止不法侵害**。据《法发〔2020〕31号》，**互殴**（双方均有侵害故意）与**防卫挑拨**（故意挑动对方侵害再借机加害）因缺乏防卫意图，**不成立正当防卫**；判断须坚持**主客观相统一**（综合起因、是否升级过错、是否准备凶器）。

- **A 错误**：相约"单挑"互殴，双方均有侵害故意，**无防卫意图**——互殴，不成立正当防卫。
- **B 错误**：丙故意辱骂激怒、早有准备，本意借机伤丁——**防卫挑拨**，不成立正当防卫。
- **C 错误**：戊预备凶器、主动挑衅，是典型**防卫挑拨**（携带凶器更印证侵害故意），不成立防卫。
- **D 正确**：辛对正在进行的持刀抢劫予以制止，主观为防卫、客观针对侵害人本人，五要件齐备，**成立正当防卫**。

**陷阱**：用"对方先动手/我也挨打了"制造"我是防卫"的假象——**约架互殴、挑拨他人先动手，都缺防卫意图，不是正当防卫**。

## 考点精解 · 缺"防卫意图"的两类情形

| 情形 | 主观 | 是否防卫 |
|---|---|---|
| 互殴（约架、斗殴）| 双方均有侵害故意 | ✘ 不成立 |
| 防卫挑拨（挑动对方先动手再反击）| 本意借机加害 | ✘ 不成立 |
| 真正防卫（制止正在进行的侵害）| 为制止不法侵害 | ✅ 成立 |

```
主客观相统一判断（法发2020·31号）：
  看起因 + 是否对冲突升级有过错 + 是否准备/使用凶器
        │
   有侵害故意/借机加害 → 互殴·挑拨 → 不成立防卫
   纯为制止不法侵害     → 正当防卫(本题D)
```

> 总精神：法不能向不法让步——但前提是你**真的在"防卫"**，不是借"防卫"之名行加害之实。

**关键词触发**：约架单挑 / 挑衅激怒 / 预备凶器 / 防卫意图

**🎯 一句话记忆**：
> 一眼判：约好了打架是互殴、故意惹对方先动手是挑拨——**心里没有"防卫"只有"加害"，就不是正当防卫**；真去制止正在进行的不法侵害才算。（详见 📐 [[刑法-总论-违法阻却事由模型]]）
