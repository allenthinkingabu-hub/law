# 物权-多选-24 · 乙破产宣告——最高额债权确定+甲可先请求丙保证

## 题干

> 乙于2014年1月被法院宣告破产，下列说法正确的是？(2016-3-91, 任)

（本题接续第89题背景：甲乙水泥供应最高额抵押合同，丙为最高额保证人，债权确定日2014年5月5日）

- A. 甲的债权确定期届至
- B. 甲应先就抵押物优先受偿，不足部分再要求丙承担保证责任
- C. 甲可先要求丙承担保证责任
- D. 如甲未申报债权，丙可参加破产财产分配，预先行使追偿权

## 答案

**ABD**<!-- confidence: EXTRACTED -->

## 涉及考点

- 📐 **物保人保实现顺序模型** → [[民法-物权-物保人保并存实现顺序模型]]
- [[混合担保]]（概念实体页）
- §421 **破产宣告=债权确定**：乙被宣告破产→最高额抵押债权确定（**A正确**）
- §392 **保证与抵押并存时优先顺序**：债权人（甲）既有抵押又有保证→**A正确**（甲应先就抵押物优先受偿）；**B正确**（甲不能先请求保证人，因有物的担保）→C错（顺序规则：物的担保先→B正确，C错，详见 📐 [[民法-物权-物保人保并存实现顺序模型]]）
- **D正确**：§703 保证人预先行使追偿权：主债务人破产时，保证人可向破产财产申报债权（预先追偿），即使尚未履行保证责任

## 考点精解

| 选项        | 分析                       | 结论       |
| --------- | ------------------------ | -------- |
| A（破产=确定）  | §421破产宣告→最高额确定           | **正确** ✓ |
| B（先抵押后保证） | §392：有物担保先就抵押物受偿         | **正确** ✓ |
| C（先要求丙）   | §392规定有物的担保须先行使，不能先要求保证人 | **错**    |
| D（丙预先申报）  | §703：主债务人破产，保证人可预先行使追偿权  | **正确** ✓ |
