# C2-多选-03 · 供用电合同的中断责任

## 题干

> 甲公司未接到通知突被断电，损失重大。哪些情形下供电公司**应承担赔偿责任**？

- A. 因供电设施计划检修中断供电
- B. 为保证居民生活用电而拉闸限电
- C. 因甲公司违法用电而中断供电
- D. 因供电设施临时检修中断供电

## 我的答案

**ABD**<!-- confidence: INFERRED -->

## 涉及考点

- [[供用电合同]] 中断的事先通知义务（§654、§655）

## 考点精解 · 中断供电三规则

### 是什么 / 易混

**§654**（中断供电的事先通知）：供电人**因供电设施计划检修、临时检修、依法限电、用电人违法用电**需要中断供电 → 应当**事先通知**用电人。
- 未事先通知 → **担责**

**§655**（用电人违法用电）：用电人**违反约定 / 国家规定**使用电 → 供电人可催告**整改**或**中止**供电。

本题对照：
- A 计划检修未通知 → 担责 → 对
- B 拉闸限电未通知 → 担责 → 对
- C 用电人违法用电 → §655 供电人**可中止**且**不担赔偿责任**（用电人本身违法）→ 错
- D 临时检修未通知 → 担责 → 对

### 怎么考 / 坑在哪

- **C 易错**："违法用电"是用电人**自身原因**——供电人合法中止，不担责
- A/B/D 都是供电人主动行为 + **未通知**→ 担责

### 怎么答

ABD。
