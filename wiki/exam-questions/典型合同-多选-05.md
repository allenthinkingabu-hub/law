# C2-多选-05 · 口头长期租赁 + 同意转租

## 题干

> 冯某口头将门面租给张某 2 年 / 月 1000。1 年后张某经冯同意转租给翁某 1 年 / 月 1200。翁某拆隔墙，冯欲收回。下列哪些**不正确**？

- A. 冯张之间的租赁合同为不定期租赁
- B. 张转租后，冯有权按 1200/月向张收租
- C. 冯有权要求张赔偿损失
- D. 冯有权要求翁承担违约责任

## 涉及考点

- [[租赁合同]] 形式要求（§707）
- 经同意转租的法律关系（§716）
- 合同相对性

## 考点精解 · 长期口头租赁 + 经同意转租

### 是什么 / 易混

**§707**（书面形式）：租赁期限**6 个月以上**的，应当采用**书面形式**。
- 未采用书面 → **视为不定期租赁**

**§716 II**（经同意转租）：经出租人**同意**转租 → 转租合同**有效**——但承租人对**次承租人造成的损害**仍对出租人**负责**。

本题对照：
- A 口头 2 年 → 视为不定期 → 对（§707）
- B 冯按 1200 收张租金 → **错**（冯张之间仍按 1000，转租是张和翁的关系，差价归张）
- C 冯要求张赔偿（翁拆墙）→ 对（§716 II 承租人对次承租人损害仍对出租人负责）
- D 冯要求翁担违约责任 → **错**（冯翁**无合同关系**，违约请求权无依据；可基于侵权要求翁担责）

### 怎么考 / 坑在哪

- **B 经典陷阱**：以为"原承租人转得高价 → 出租人可分一杯羹"——错。**冯张关系不变**
- **D 易错**：冯对翁不能"违约"，但可"侵权"或基于物权请求

### 怎么答

BD（"不正确"项）。
