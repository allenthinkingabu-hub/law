# 侵权-多选-02 · 精神损害赔偿-具有人身意义特定物照片被烧

## 题干

> 来源：2020 金题 2-1-43（众合）

赵某在唐山大地震中成了孤儿，将仅有的一张和父母的合照视为珍宝，为更好保存照片，赵某将照片送到照相馆翻拍。几日后，照相馆雇员乱丢烟头引起火灾，照片被烧毁，赵某为此十分愤恨和痛苦。根据《民法典》，下列哪些选项是正确的？

- A. 赵某可以要求照相馆承担违约责任
- B. 照相馆侵犯了赵某的健康权
- C. 照相馆侵犯了赵某的肖像权
- D. 赵某有权请求照相馆赔偿精神损失

## 我的答案

**AD**<!-- confidence: EXTRACTED -->

A：照相馆与赵某有翻拍合同（保管+加工），照片被烧属未尽保管义务，构成违约 → 违约责任 ✓
D：§1183Ⅱ 故意或**重大过失**（乱丢烟头）侵害具有**人身意义的特定物**（唯一与父母的合照，对孤儿具有不可替代的人身意义），造成严重精神损害 → 有权请求精神损害赔偿 ✓
B：损坏的是照片（财物），非侵害健康权 ✗
C：照片的"肖像"用途≠侵犯肖像权，肖像权侵权须"未经授权使用/公开"，本题是损毁，非使用 ✗

## 考点精解 · §1183Ⅱ 特定物精神损害赔偿

### 什么是"具有人身意义的特定物"

§1183Ⅱ：因**故意或重大过失**侵害自然人**具有人身意义的特定物**（即对该人具有独特情感价值、无法替代的物品），造成**严重精神损害**的，被侵权人有权请求精神损害赔偿。

| 要件 | 本题 | 分析 |
|---|---|---|
| 故意或重大过失 | 雇员乱丢烟头引火灾 | 重大过失 ✓ |
| 具有人身意义的特定物 | 唯一一张与已故父母合照 | 孤儿的不可替代纪念物 ✓ |
| 严重精神损害 | 赵某十分愤恨痛苦 | ✓ |

→ **D 正确**：可请求精神损害赔偿。

### 肖像权辨析（C 错的原因）

| 行为类型 | 是否侵犯肖像权 |
|---|---|
| 未经授权**使用**他人肖像（商业用途、公开展示） | ✓ 侵犯肖像权 |
| **损毁/烧毁**他人照片 | ✗ 不是侵犯肖像权（是物权损害 or 精神损害路径） |

→ **C 错误**。

### 违约与侵权竞合（A + D 并存）

- A（违约责任）：照相馆保管照片属合同义务，烧毁属违约
- D（侵权精神损害）：依侵权路径可主张精神损害赔偿
- 违约责任通常**不支持精神损害赔偿**（§996 例外：合同同时侵害人格权益时可），故 D 成立须走侵权路径
- 两种请求权可同时提出，但不能重复获赔
