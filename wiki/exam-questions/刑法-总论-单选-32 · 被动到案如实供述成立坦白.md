# 刑法-总论-单选-32 · 被动到案如实供述成立坦白

## 题干

> 来源：依据《刑法》第67条第3款命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

丁因涉嫌诈骗被传唤到案，到案后如实供述了办案机关已掌握的全部诈骗事实。关于丁，下列哪一选项正确？

- A. 成立一般自首
- B. 成立准自首
- C. 成立坦白，可以从轻处罚
- D. 不具有任何法定从宽情节

## 我的答案

**C**<!-- confidence: EXTRACTED -->

丁系被传唤、被动到案，缺乏"自动投案"的主动性，不成立一般自首；其供述的是办案机关已掌握的罪行，亦不符合准自首"供述未掌握的异种罪行"之要件。丁如实供述自己罪行，依《刑法》§67Ⅲ成立坦白，可以从轻处罚。

- A 错：被传唤到案属被动归案，不具"自动投案"的主动性，不成立一般自首。
- B 错：准自首须供述司法机关尚未掌握的异种罪行，丁供述的是已掌握罪行，不符合要件。
- D 错：坦白是法定从宽情节，丁如实供述自己罪行即可从轻，并非"无任何从宽情节"。

## 考点精解 · 自首 vs 坦白的分水岭——投案是否主动

自首与坦白都要求"如实供述自己罪行"，二者唯一的分水岭在于**到案是否出于主动**：

| 情形 | 到案方式 | 如实供述 | 定性 |
| --- | --- | --- | --- |
| 自己跑去投案 | 主动 | 是 | 一般自首 |
| 被传唤/被抓获/被扭送后交代 | 被动 | 是 | 坦白 |
| 被羁押后供述未掌握的异种罪行 | （已羁押） | 是 | 准自首 |

丁被"传唤"到案，是典型的被动归案；且供述内容是已掌握的诈骗事实，既排除一般自首（非主动投案），也排除准自首（非未掌握的异种罪行），最终落在坦白。

```
被动到案 + 如实供述 = 坦白
自动投案 + 如实供述 = 自首
```
