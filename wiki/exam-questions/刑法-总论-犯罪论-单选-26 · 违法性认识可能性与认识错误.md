# 刑法-总论-犯罪论-单选-26 · 违法性认识可能性与认识错误

## 题干

> 来源：依据违法性认识可能性学理通说（责任阶层，无独立专条）命制的**仿真题**（题干为本库命制，非历年真题；通说参见知乎专题《违法性认识可能性的理解与适用》 https://zhuanlan.zhihu.com/p/594469746 ）。

关于违法性认识，下列哪一选项是正确的？

- A. 甲外贸商拟出口某化工原料，专门书面咨询主管部门，获该部门正式书面答复"该原料不属管制物项、可自由出口"，甲据此出口，后经查该答复错误、该原料系管制物项——甲缺乏违法性认识可能性，阻却责任
- B. 乙明知贩毒违法，但误以为本省量刑较轻，遂在本省贩毒——乙的认识错误阻却责任
- C. 丙是文盲，称"不知道盗窃是犯罪"——故不构成盗窃罪
- D. 违法性认识可能性属于构成要件要素，欠缺即不符合构成要件

## 我的答案

**A**<!-- confidence: EXTRACTED -->

正解为 A。违法性认识可能性是**责任阶层**的要素：原则上"不知法不免责"，只有当行为人**完全没有认识违法性的可能性**时（典型即信赖有权机关的正式书面答复），才欠缺违法性认识可能性、阻却责任。

逐项：

- A 对：甲已尽审查义务，专门书面咨询并**信赖有权主管机关的正式书面答复**行事，是"完全无法认识其行为违法"的典型情形，欠缺违法性认识可能性，阻却（罪责）责任。这几乎是通说唯一公认的免责范例。
- B 错：乙**明知贩毒违法**，只是对量刑轻重产生误解。对法定刑高低的误解不影响"知道行为违法"，不阻却责任。
- C 错：盗窃违法属于社会一般常识，文盲同样具有违法性认识的**可能性**，"不知法不免责"，丙仍构成盗窃罪。
- D 错：违法性认识可能性是**责任阶层**要素，不是构成要件要素；欠缺它阻却的是责任（罪责），而非构成要件该当性。

故选 A。

## 考点精解 · 违法性认识可能性的免责边界

违法性认识可能性解决的是"行为人能不能意识到自己行为违法"。通说采**原则不免责、例外极窄**的立场：

| 情形 | 是否阻却责任 | 理由 |
|---|---|---|
| 信赖**有权机关**正式（书面）错误答复 | ✅ 阻却 | 已尽审查义务，完全无认识可能性 |
| 误以为量刑较轻 / 误解法定刑 | ❌ 不阻却 | 已知违法，仅误解后果 |
| 文盲/外地人"不知是犯罪"（常识性违法） | ❌ 不阻却 | 一般人有认识可能性，不知法不免责 |
| 信赖无权机关、私人律师或道听途说 | ❌ 不阻却 | 未尽审查义务，仍有认识可能性 |

```
是否"完全没有认识违法性的可能性"？
        │
   ┌────┴─────┐
   是          否
   │           │
信赖有权机关     不知法 / 误解量刑
正式错误答复     / 信赖无权来源
   │           │
阻却责任        不阻却（不知法不免责）
```

阶层定位：违法性认识可能性属**责任（有责性）阶层**，与构成要件该当性、违法性相区分。命题人常将它错置为"构成要件要素"设陷（本题 D）。免责需达到"完全无认识可能性"，门槛极高，**信赖有权机关公开错误答复几乎是唯一被认可的范例**。
