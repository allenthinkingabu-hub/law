# 刑法-总论-单选-29 · 准自首之供述未掌握的异种罪行

## 题干

> 来源：法考真题改编 / 瑞达·厚大·众合高频题（已联网核验法条与司法解释）

甲因涉嫌盗窃被刑事拘留，羁押期间，办案人员尚未掌握甲曾实施过一起抢劫。审讯中甲主动交代了该起抢劫事实。关于甲对抢劫罪的认定，下列哪一选项正确？

- A. 成立一般自首
- B. 成立准自首（以自首论）
- C. 仅成立坦白
- D. 不成立任何从宽情节

## 我的答案

**B**<!-- confidence: EXTRACTED -->

甲已因盗窃被刑事拘留，属于"被采取强制措施的犯罪嫌疑人"。其所供述的抢劫，是司法机关尚未掌握、且与已掌握的盗窃属**不同种罪行**，依《刑法》§67Ⅱ及《最高人民法院关于处理自首和立功具体应用法律若干问题的解释》（法释〔1998〕8号）第2条，以自首论，即成立准自首。

- A 错：甲已被刑事拘留，处于羁押状态，不可能"自动投案"，故不符合一般自首"自动投案+如实供述"的要件。
- C 错：甲供述的是司法机关未掌握的**异种罪行**，符合准自首的两项硬条件，应认定为准自首而非仅坦白。
- D 错：甲至少成立准自首，是法定从宽情节，并非"不成立任何从宽情节"。

## 考点精解 · 准自首的两道硬门槛

准自首（"以自首论"）针对的是已被采取强制措施或正在服刑之人，他们已无"自动投案"的可能，故立法另设一条从宽通道。但门槛有二，缺一不可：

| 条件 | 含义 | 本题判断 |
| --- | --- | --- |
| 主体特殊 | 被采取强制措施的嫌疑人/被告人，或正在服刑的罪犯 | 甲被刑事拘留 ✅ |
| 司法机关尚未掌握 | 该罪行办案机关此前不知情 | 抢劫未被掌握 ✅ |
| 与已掌握罪行**不同种** | 法释〔1998〕8号第2条限定 | 盗窃 vs 抢劫，异种 ✅ |

三项全部满足，故成立准自首。

```
已被强制措施 → 排除"自动投案" → 不可能一般自首
            ↓
  供述未掌握 + 异种罪行 → 准自首（以自首论）
  供述未掌握 + 同种罪行 → 坦白
```
