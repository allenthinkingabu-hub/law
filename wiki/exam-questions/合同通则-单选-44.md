# C1-单选-44 · 鸽子飞了归谁：交付未完成，所有权未变动

## 题干

> 古某携幼子古晓（5周岁）出游，古晓对农户张某的鸽子甚是喜爱。为取悦儿子，古某向张某选购一只，张某微信收款后将把鸽子交给古某时，古某示意其直接把鸽子交给古晓。不料古晓害怕，接鸽子时手一缩，鸽子飞了。关于鸽子权属，下列哪一说法是正确的？（2020金题-2-1-18）

- A. 古晓
- B. 古某
- C. 张某
- D. 鸽子的所有权不适用物权变动规则

## 我的答案

**C**（动产交付未完成，所有权仍属张某）<!-- confidence: EXTRACTED -->（官方参考答案：C）

## 涉及考点

- [[物权编]]
- [[区分原则]]

## 考点精解 · 动产物权变动 = 交付（§224）

### 是什么 / 易混

- **债权行为 ≠ 物权变动**（[[区分原则]]）：古某向张某买鸽，买卖合同有效成立、付了款，但这只产生**债权效果**；鸽子**所有权转移**还得看**交付**（§224 动产物权设立和转让，自交付时发生效力）。
- 张某要把鸽子交古某时，古某指示"直接交给古晓"——属向第三人（古晓）现实交付。但古晓**接鸽时手一缩、鸽子飞了**，鸽子**从未被任何买方有效占有** → **交付未完成**。
- 交付未完成 → 所有权**未发生转移** → 鸽子（飞走前/被视为）仍属**出卖人张某**（C 对）。同理，**标的物毁损灭失风险**在交付前由出卖人承担（§604）。

### 怎么考 / 坑在哪

- **A 古晓 / B 古某 错**：买方一侧从未完成占有取得，所有权未转移。
- **D"不适用物权变动规则"错**：鸽子是**动产**，完全适用 §224 交付规则。
- 付款 ≠ 取得所有权——这是区分原则的经典陷阱。

### 怎么答

钱付了但鸽子没接住（交付未完成）→ 所有权未转移 → 仍属张某 → 选 **C**。

## 📐 答题口诀 · 动产看交付：钱货两清才转移，没接住 = 没过户

> **"付款只生债权；动产所有权 = 交付那一刻。鸽子没握住 = 交付没完成 = 还是卖家的。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"已付款 / 微信收款" 但 "没拿到货"            → 仅债权效果，所有权未转移（区分原则）
"动产 + 交付时...手一缩/没接住/灭失"          → 交付未完成 → 所有权未变动 ★
"所有权归买方"（钱付了但没交付）              → 错
"不适用物权变动规则"                          → 错（动产适用 §224 交付）
```

### 逐项选项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| A 古晓 | ❌ | 古晓未有效占有（手一缩鸽飞）|
| B 古某 | ❌ | 古某也未取得占有 |
| **C 张某** | ✅ | 交付未完成，所有权未转移，仍属出卖人 |
| D 不适用 | ❌ | 动产适用 §224 交付规则 |

### 🚗 老王小李故事

> 老王带 5 岁娃逛农庄，看上小李的一只鸽子。老王微信把钱付了（**债权了结**），小李正要把鸽子递给老王，老王说"直接给我娃"。娃一害怕，手一缩，鸽子扑棱飞了。这鸽子算谁的？——还是**小李的**。钱付了只是把买卖的"账"结清（债权），鸽子的"户"（所有权）得**交到手**才过（动产 §224 交付）。娃没接住 = 没交付完成 = 没过户，飞走前所有权仍在卖家小李，灭失风险也在交付前由小李扛。

### 🎯 一句话记忆

> **"付款生债权、交付转所有权；动产没接住 = 没过户 = 还是卖家的。"**

### 填空模板（主观题用）

> 古某付款仅生**【债权效果】**（区分原则）；鸽子为**【动产】**，所有权自**【交付】**时转移（§224）。张某向古晓交付时古晓未握住、鸽子飞走，**【交付未完成、占有未转移】**，所有权**【未发生变动】**，仍属**【张某】**。故选 **C**。
