# C1-多选-25 · 母公司替还欠薪 = 无因管理；司机开走车 ≠ 自助行为

## 题干

> 甲公司因经营不善歇业，欠专职司机潘某工资3万元，潘某多次催要未给，一气之下把公司一辆面包车开走。甲公司的母公司乙公司知道此事主动偿还潘某2万元。关于本案，下列说法正确的是？（2023金题-2-1-13）

- A. 甲公司尚欠潘某1万元
- B. 乙公司的行为属于无因管理
- C. 甲公司尚欠潘某3万元
- D. 潘某开走面包车属于自助行为

## 我的答案

**AB**<!-- confidence: EXTRACTED -->（官方参考答案：AB）

## 涉及考点

- 📐 **答题模型** → [[民法-合同-无因管理模型]]（独立法人无义务替还＝无因管理；定性命门：无义务 + 为他人）
- [[无因管理]]

## 考点精解 · 无因管理 + 自助行为的边界

### 是什么 / 易混

| 选项 | 判断 | 理由 |
|---|---|---|
| **A 尚欠 1 万** | ✅ | 乙代偿 2 万产生清偿效力，甲对潘某债务减为 1 万 |
| **B 乙构成无因管理** | ✅ | 乙公司**无法定/约定义务**（母子公司各为独立法人），主动替甲清偿 = 为他人管理事务（§979）|
| C 尚欠 3 万 | ❌ | 已被乙代偿 2 万 |
| D 自助行为 | ❌ | 不符合自助行为要件（见下）|

- **D 为什么不是自助行为**：自助行为（§1177）要求"**情况紧迫、来不及请求国家机关保护、不立即采取措施将受难以弥补的损害**"。潘某讨薪**完全可以走劳动仲裁/诉讼**，不具紧迫性；私自开走公司车辆属**私力扣押、超出必要限度**，不构成自助行为。

### 怎么考 / 坑在哪

- 母子公司**各自独立法人**，乙替甲还债无义务 → 无因管理（而非"应当代偿"）。
- 自助行为是**极窄的例外**：必须紧迫 + 无法及时公力救济 + 限度内。讨薪不满足。

## 📐 答题口诀 · 无义务而帮还 = 无因管理；讨薪扣车 ≠ 自助行为

> **"独立法人替你还债 = 无因管理；要账能走法律的，私自扣车 = 不是自助行为。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"无义务的人主动替他人还债/处理事务"           → 无因管理（§979）★
"母子公司/关联公司替还"                       → 各独立法人，无义务 → 无因管理
"私自扣押/开走对方财物讨债"                    → 一般不构成自助行为（缺紧迫性/超限度）
"情况紧迫 + 来不及报警 + 限度内"              → 才是自助行为（§1177）
```

### 🚗 老王小李故事

> 甲公司倒闭，欠司机潘师傅 3 万工资。潘师傅要不到钱，一气之下把公司一辆面包车开走了。甲公司的"母亲"乙公司看不下去，主动替甲还了潘师傅 2 万。两个判断：① 乙公司和甲公司是**两家独立公司**，乙没义务替还，这一还就是**无因管理**（B），还完甲还欠潘师傅 1 万（A）。② 潘师傅开走车算"自助行为"吗？**不算**——讨薪可以去劳动仲裁、去法院，没到"火烧眉毛、来不及报警"的份上，私自扣车超了限度。
