# 刑诉-审判-单选-67 · 法庭审理活动先后顺序排列

## 题干

> 【出处】2008年卷二第38题

按照我国《刑事诉讼法》的规定，关于法庭审理活动先后顺序的排列，下列哪一选项的组合是正确的？①宣读勘验笔录；②公诉人发表公诉词；③讯问被告人；④询问证人、鉴定人；⑤出示物证；⑥被告人最后陈述。

- A. 235416
- B. 345126
- C. 245163
- D. 341526

## 我的答案

**B**<!-- confidence: VERIFIED -->

### 解析

正确顺序为 ③④⑤①②⑥，即 **345126**，对应B选项。

按庭审进程，可分为三大板块，各要素归位如下：

第一板块——**法庭调查**（把事实、证据摆清楚），其内部顺序大致为：讯问被告人 → 询问证人、鉴定人 → 出示物证、宣读书证与勘验笔录等。对应本题：
- ③讯问被告人（法庭调查开始，先问被告人）
- ④询问证人、鉴定人（再问证人、鉴定人）
- ⑤出示物证（出示实物证据）
- ①宣读勘验笔录（宣读勘验、检查等笔录类证据）

第二板块——**法庭辩论**：
- ②公诉人发表公诉词（公诉词是公诉人在法庭辩论阶段发表的意见，位于法庭调查全部结束之后）

第三板块——**最后陈述**：
- ⑥被告人最后陈述（法庭辩论结束后，审判长宣布辩论终结，由被告人作最后陈述，位于整个庭审之末）

将三大板块串起来即 ③→④→⑤→①→②→⑥ = 345126。

逐项排除：
- A（235416）：把②公诉词放到最前，公诉词属辩论环节不可能在法庭调查之前，错误。
- C（245163）：以②公诉词开头，且顺序混乱，错误。
- D（341526）：③④之后接①宣读勘验笔录、再⑤出示物证——物证与勘验笔录同属法庭调查中的证据出示，本题标准排序为先出示物证⑤后宣读勘验笔录①，且D整体不符合"调查在前、辩论居中、最后陈述在末"的框架，错误。

故本题答案为B。

## 涉及考点

- 庭审三大板块顺序：法庭调查 → 法庭辩论 → 被告人最后陈述
- 法庭调查内部顺序：讯问被告人 → 询问证人鉴定人 → 出示物证 → 宣读书证/勘验笔录等
- 公诉词属法庭辩论环节，位于法庭调查之后（区分公诉词与起诉书宣读）
- 被告人最后陈述固定位于整个庭审的最后

## 考点精解

**是什么 / 易混**：庭审顺序题的骨架就三步——先"查"（法庭调查，摆事实讲证据）、再"辩"（法庭辩论，控辩交锋，公诉词在这里发表）、最后"让被告人说最后一句话"（最后陈述）。最容易被绕的是"公诉词"的位置：很多考生把公诉词和开庭时宣读的起诉书混为一谈，误以为公诉词在最前面。要区分——**宣读起诉书**在法庭调查一开始，而**发表公诉词**是法庭辩论阶段公诉人的辩论意见，靠后。本题②是"公诉词"，所以它必须排在法庭调查全部结束之后。

**怎么考 / 坑在哪**：
1. **"公诉词"陷阱是本题设计核心**：A、C两个错误项都拿②公诉词打头，正是利用"公诉词/起诉书"的混淆。记牢公诉词＝辩论意见，绝不可能在讯问被告人、举证质证之前出现。凡见"公诉词/辩论意见"排在庭审很靠前位置的组合，直接排除。
2. **最后陈述⑥必在末位**：这是最稳的锚点。任何把⑥排在非末尾的组合都错。用⑥定位尾巴，能快速砍掉一批干扰项。
3. **法庭调查内部的证据出示次序**：讯问被告人③ → 询问证人鉴定人④ → 出示物证⑤ → 宣读勘验笔录①。先"问人"（被告人、证人鉴定人），再"示物/读笔录"。本题标准答案把出示物证⑤排在宣读勘验笔录①之前，D项恰好把①⑤颠倒且整体错乱，据此排除D。
4. **三板块框架优先，细节次之**：做题先用"调查→辩论→最后陈述"大框架卡位，能定②靠后、⑥最末，A、C立即出局；再在B、D之间比证据出示细节即可。

**怎么答**：庭审顺序题三步走——① 先锁尾巴：被告人最后陈述⑥永远在最后；② 再拎辩论：公诉词/辩论意见②必在法庭调查之后（别和起诉书混）；③ 最后排调查内部：讯问被告人→询问证人鉴定人→出示物证→宣读书证勘验笔录。套进去即得345126。

### 故事化记忆

法庭开审，法官老李像主持一台三幕剧。第一幕"查案子"：先问站在被告席上的老王（③讯问被告人），再叫证人、鉴定人上来问话（④询问证人鉴定人），然后把作案的刀、赃物摆上台（⑤出示物证），再念一念现场勘验的笔录（①宣读勘验笔录）。第二幕"打嘴仗"：公诉人这才起身发表公诉词，慷慨陈词（②——注意，是"公诉词"不是开场念的起诉书，所以它在这么靠后的地方）。第三幕"临别赠言"：所有辩论都结束了，老李把最后的话筒递给老王，让他做最后陈述（⑥）。三幕演完，顺序就是 345126。

### 一句话记忆
