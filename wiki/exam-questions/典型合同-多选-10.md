# C2-多选-10 · 融资租赁三方关系

## 题干

> 甲根据乙选择向丙买大型设备，出租给乙使用。设备安装后不能运行。下列哪些判断正确？

## 考点精解 · 融资租赁四规则

### 是什么 / 易混

**融资租赁合同**（三方关系）：
- **甲（出租人）** ↔ **丙（出卖人）**：买卖合同
- **甲（出租人）** ↔ **乙（承租人）**：租赁合同
- **乙（承租人）** → 丙：基于法律规定的**直接索赔权**

**核心规则**：

| 项 | 规则 | 法条 |
|---|---|---|
| 标的物**质量瑕疵** | 承租人**直接**向出卖人索赔 | §741 |
| 出租人责任 | **不**对标的物质量瑕疵担责（除承租人依赖出租人技能 / 出租人干预外） | §747 |
| 租金 | 即使有瑕疵，承租人**仍应付租**（除承租人依赖出租人技能/干预例外减租） | §742 |
| 期满**所有权归属** | 当事人**约定**——没约定且依§510仍定不了则**归出租人** | §757 |

本题对照：
- A 直接向丙索赔 → 对（§741）
- B 甲不担质量责任 → 对（§747）
- C 仍应付租 → 对（§742，存在抗辩限制）
- D 期满**乙取得所有权** → 错（无约定且依§510仍定不了则**归出租人甲**，§757）

### 怎么考 / 坑在哪

- **D 经典陷阱**：以为"融资租赁 = 分期付款买卖" → 错，期满归属看**约定**
- A 的"直接索赔权"是融资租赁的**特征性规则**——突破合同相对性
