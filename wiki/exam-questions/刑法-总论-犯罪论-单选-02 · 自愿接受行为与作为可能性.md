# 刑法-总论-犯罪论-单选-02 · 自愿接受行为与作为可能性

## 题干

> 来源：依据《刑法》第13条及不作为犯学理通说命制的**仿真题**（题干为本库命制，非历年真题；法条已联网核验 CONFIRMED）。

甲见邻居3岁幼童乙独自在小区池塘边玩耍，遂主动对其母说"我帮你看着孩子，你去买菜"，其母离开。甲看护期间只顾玩手机，乙跌入池塘。甲不会游泳，池塘水深3米、四周无救生设备、呼救亦无人应答。甲眼睁睁看乙溺亡。关于甲的责任，下列正确的是？

- A. 甲自愿接受看护产生作为义务，且不履行致死，成立不作为的故意杀人罪
- B. 甲虽因自愿接受行为产生作为义务，但因不会游泳、无救生设备、现场无人，欠缺作为可能性，不成立不作为犯
- C. 甲与乙无任何关系，纯属道德范畴，不负刑责
- D. 甲成立遗弃罪

## 我的答案

**B**<!-- confidence: EXTRACTED -->

正确答案为 **B**。

不作为犯的成立须**同时**具备三要件：①作为义务（保证人地位）；②作为可能性（物理上与法律上的现实救助可能）；③不履行义务并造成危害结果。三者缺一不可。

- 甲因"自愿接受行为"（主动承诺看护幼童）已取得**保证人地位**，确有作为义务。
- 但本案救助在**物理上不可能**：甲不会游泳、水深3米、四周无救生设备、呼救无人应答——客观上没有任何现实的救助手段。这属于**欠缺作为可能性**。
- 依"法律不强人所难"原则，无作为可能性即不成立不作为犯，故甲不构成不作为的故意杀人罪。**B 正确**。

- **A 错误**：只看到"有义务"就定罪，忽略了独立要件"作为可能性"。
- **C 错误**：甲已因自愿接受行为取得保证人地位，并非纯道德义务，前提判断错误。
- **D 错误**：遗弃罪要求行为人对被害人负**扶养义务**而拒绝扶养，本情形是临时看护且无作为可能性，不符合遗弃罪构成。

**陷阱**：有作为义务 ≠ 必然成立不作为犯。必须独立审查"作为可能性"，物理上不能救助则出罪。

## 考点精解 · 不作为犯三要件递进审查

```
①作为义务（保证人地位）── 自愿接受看护 → 有 ✔
        │
②作为可能性（物理+法律现实可能）── 不会游泳/3米深水/无设备/无人 → 无 ✘  ← 本题在此出罪
        │
③不履行 + 造成结果 ── （已不必审查）
        │
      成立不作为犯
```

| 要件 | 本题判断 | 结论 |
|------|----------|------|
| 作为义务 | 自愿接受看护 → 取得保证人地位 | 有 |
| 作为可能性 | 不会游泳·深水·无设备·呼救无人 | 无 → 出罪 |
| 不履行致果 | 不再审查 | — |

> 要害：作为可能性是与作为义务**并列**的独立要件，"想救也救不了"时不成立不作为犯。
