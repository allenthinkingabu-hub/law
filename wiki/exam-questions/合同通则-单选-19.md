# C1-单选-19 · 撤销权对象（财产 vs 身份行为）

## 题干

> 乙向甲借款 20 万元，借款到期后，乙的下列哪种行为导致无力偿还甲的借款时，甲**可申请法院予以撤销**？

- A. 乙收养残障儿童丙
- B. 乙残废后拒绝接受亲友捐赠的 15 万元
- C. 乙在离婚协议中放弃对家庭共有财产的权利
- D. 乙父去世，乙放弃对父亲遗产的继承权

## 我的答案

**C**（离婚协议放弃**已有的**共有财产份额 = 处分既有财产的财产行为）<!-- confidence: INFERRED -->

## 涉及考点

- [[撤销权]]（§538-§542 · [[合同总则考点-深度报告]] 保全板块 #2 · ★★★★★）
- 📐 **答题模型** → [[民法-合同-撤销权模型]]（第一步·定性关：对象排除两道滤网）
- 排除：① **身份行为**（收养 / 放弃继承）② **放弃"将得利益"**（拒绝受赠 / 放弃继承——财产未到手）

## 考点精解 · 撤销权的对象（两道滤网）

### 是什么 / 易混

债权人撤销权（§538-§539）只打**债务人积极减少"既有责任财产"的财产行为**。一个行为能不能撤，过**两道滤网**：

| 滤网              | 问什么         | 过不了的（不可撤销）             |
| --------------- | ----------- | ---------------------- |
| ① 是不是**财产行为**   | 还是身份行为？     | 收养 / 结婚 / 放弃继承的**身份性** |
| ② 动的是不是**既有财产** | 还是放弃"将得利益"？ | 拒绝受赠 / 放弃继承（财产**没到手**） |

→ **两关都过**才可撤：处分**已有财产**的财产行为（无偿送 / 贱卖 / 放弃已有份额 / 放弃债权担保）。

### 怎么考 / 坑在哪

- **A 收养** → 纯**身份行为** → 不可撤销（债权人不能干涉人身选择）。
- **B 拒绝受赠** → 放弃的是"白得的机会"，**没动既有财产** → 不可撤销。
- **C 离婚放弃共有财产** → 放弃的是**已经是自己的**共有份额（财产行为 + 无偿处分既有财产）→ **可撤销** ✓。
- **D 放弃继承** → **身份性** + 遗产**未到手** → 不可撤销（通说）。

### 怎么答

只有 C 是对**已有共同财产**的无偿处分（财产行为），损害债权人。故选 **C**。

## 📐 答题口诀 · 撤销权对象"两道滤网"

> 债权人撤销权只打**债务人减损"既有责任财产"的财产行为**——**两道滤网**：① **身份行为**（收养 / 结婚 / 放弃继承的身份性）排除；② **放弃"将得利益"**（拒绝受赠 / 放弃继承，财产没到手）排除。两关都过才可撤。

### 关键词触发表

```
看到题干"债务人做了……，债权人能否撤销"          → 判断
"收养 / 结婚 / 离婚的纯身份部分"                 → 身份行为，不可撤销 ✗
"拒绝接受赠与 / 放弃继承"                        → 放弃"将得利益"（财产没到手），不可撤销 ✗
"离婚放弃'已有的'共有财产份额"                   → 处分既有财产，可撤销 ✓
"无偿转让 / 放弃债权 / 放弃担保 / 明显低价贱卖"   → 处分既有财产，可撤销 ✓
```

### 📋 4 选项陷阱解析

| 选项 | 判断 | 性质 |
|---|---|---|
| A 收养残障儿童 | ❌ 不可撤销 | **身份行为** |
| B 拒绝受赠 15 万 | ❌ 不可撤销 | 放弃"将得利益"（**非既有财产**）|
| **C 离婚放弃共有财产** | ✅ **可撤销** | **财产行为 · 无偿处分既有财产** |
| D 放弃继承权 | ❌ 不可撤销 | **身份性** + 遗产未到手 |

→ 选 **C** ✅

### 🚗 老王小李故事

> 老王卖车给小李，小李欠老王 **20 万**车款、到期还不上（老王 = 债权人，小李 = 债务人）。小李做了几件事，哪件老王能请法院撤销？
>
> - 小李**收养**了个残障孩子 → **身份行为**，老王管不着（A✗）。
> - 亲友要**捐 15 万**给小李，小李**拒绝**了 → 放弃的是"白得的机会"，钱没进口袋、没动现有财产，老王管不着（B✗）。
> - 小李离婚，把本该分自己的**共有财产份额全放弃** → 把"**已经是自己的钱**"白送出去、害老王讨不回债，老王**能撤销**（C✓）。
> - 小李他爸去世，小李**放弃继承** → 身份性 + 遗产还没到手，老王管不着（D✗）。
>
> 诀窍：撤销权只打"**动既有财产的财产行为**"——身份的事（收养 / 放弃继承）、白来没拿的钱（拒绝受赠），老王都伸不进手。

### 🎯 一句话记忆

> **"撤销权只打'动既有财产的财产行为'；身份行为（收养 / 放弃继承）、放弃'将得利益'（拒绝受赠）都打不着。"**

### 填空模板（主观题用）

> 债权人撤销权的对象限于债务人**【积极处分既有责任财产的财产行为】**。A 收养、D 放弃继承属**【身份行为 / 身份性选择】**（不可撤销）；B 拒绝受赠属放弃**【将得利益、非既有财产】**（不可撤销）；唯 C 离婚放弃**【已有的共有财产份额】**= 财产行为 + 无偿处分既有财产（可撤销）。故选 **C**。
