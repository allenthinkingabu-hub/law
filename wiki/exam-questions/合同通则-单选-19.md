# C1-单选-19 · 撤销权对象（财产 vs 身份行为）

## 题干

> 乙向甲借款 20 万元，借款到期后，乙的下列哪种行为导致无力偿还甲的借款时，甲**可申请法院予以撤销**？

- A. 乙收养残障儿童丙
- B. 乙残废后拒绝接受亲友捐赠的 15 万元
- C. 乙在离婚协议中放弃对家庭共有财产的权利
- D. 乙父去世，乙放弃对父亲遗产的继承权

## 我的答案

**C**（离婚协议中放弃共有财产）<!-- confidence: INFERRED -->

## 涉及考点

- [[撤销权]]（§538-§542）
- 身份行为 vs 财产行为的区分

## 考点精解 · 撤销权的对象

### 是什么 / 易混

**[[撤销权]]**（§538-§539）：债务人**无偿处分财产权益** / **不合理低价转让** / **放弃债权** / **放弃担保** 等损害债权人利益的行为，债权人可申请撤销。

**对象限制**：仅限**财产行为**，不及于**身份行为**：
- **可撤销**：无偿转让 / 放弃债权 / 不合理低价交易 / 在离婚协议中放弃**家庭共有财产**等
- **不可撤销**：
  - 收养（**身份行为**）
  - 拒绝**接受**他人**赠与**（拒绝的是机会而非已有财产）
  - 放弃**继承**（继承的接受 / 放弃是身份性 + 选择权）

### 怎么考 / 坑在哪

- A 收养 → 身份行为 → 不可撤销
- B 拒绝受赠 → 没有"已有财产"被处分 → 不可撤销
- C 离婚协议放弃**已有的家庭共有财产** → **已有财产被无偿处分** → 可撤销 ✓
- D 放弃继承 → 通说是**身份性**选择，不可撤销（继承财产**未到手**）

### 怎么答

只有 C 是对**已有的共同财产**作无偿处分，损害债权人利益且性质上属财产行为。故选 **C**。
