# C1-多选-19 · 假借合作的恶意磋商

## 题干

> 甲乙公司属竞争关系。乙为干扰甲与某客户洽谈，联系丙公司，由丙在**无真实交易意图**下向甲发合作邀请书，以重要业务合作为由邀甲到其办公地洽谈。甲安排授权代表往返十余次、每次备详尽方案，丙佯装感兴趣并屡次表达签约意愿，但均在最后一刻推脱拒签。下列选项中**错误**的是（ ）。

- A. 丙公司发出邀请书的行为在性质上属于要约
- B. 甲公司与丙公司虽未缔结合同，但丙公司构成恶意磋商，甲公司可就遭受的损失要求丙公司赔偿
- C. 丙公司需就磋商事宜向甲公司承担违约责任
- D. 丙公司也付出了工作成本，如被甲方主张赔偿，则据此可主张抵销

## 我的答案

**ACD**（本题问"错误的"）<!-- confidence: INFERRED -->

## 涉及考点

- [[缔约过失责任]]（恶意磋商 §500(1)）
- [[要约]] vs [[要约邀请]]；缔约过失 ≠ 违约；过错方无权抵销

## 考点精解 · 恶意磋商（§500(1)）

### 是什么 / 易混

- 丙发"合作邀请书" = **邀请洽谈** = **要约邀请**，非要约；且丙**无真实交易意图**。→ A **错误**。
- 丙"**假借订立合同、恶意磋商**"，造成甲损失 → §500(1) **缔约过失**，甲可索赔。→ B **正确**。
- 甲丙间**无合同成立** → 缔约过失责任，**非违约责任**。→ C **错误**。
- 丙是恶意磋商**过错方**，对甲**无合法赔偿请求权**，不能主张**抵销**。→ D **错误**。

### 怎么考 / 坑在哪

- 题目问"**错误的**" —— 选 **A、C、D**。
- 恶意磋商三特征：① 假借订立合同（无真实意图）② 反复磋商拖延 ③ 致对方损失。
- 抵销需**双方互负到期债权**；过错方无对待请求权，不能抵销。

### 怎么答

A 错（邀请洽谈是要约邀请非要约）；C 错（无合同 → 缔约过失非违约）；D 错（过错方无请求权不能抵销）；B 对（§500(1) 恶意磋商可索赔）。问"错误的"，故选 **ACD**。

## 📐 答题口诀 · 恶意磋商：假借订立 = 缔约过失（§500(1)）

> 这题是"缔约过失"里最坏的一种 —— **根本没想签，纯粹来耗你**。问"错误的"，逐项打叉。

### 🚗 "演戏拖垮对手" 故事

> 乙想搞垮竞争对手甲，找来丙公司**演戏**：丙给甲发"合作邀请书"，装得诚意满满，把甲请去谈。甲信了，**派代表往返十几次**、每次准备详细方案。丙**屡次说"马上签"**，可一到关键时刻就**推脱拒签** —— 丙**压根没打算签**，就是来**耗甲、拖住甲**别去谈真客户。

逐项打叉（问"错误的"）：

| 选项             | 对 / 错  | 理由                        |
| -------------- | ------ | ------------------------- |
| A 邀请书 = **要约** | ❌**错** | 邀请洽谈 = **要约邀请**，且无真实交易意图  |
| B 恶意磋商，甲可索赔    | ✅对     | §500(1) 假借订立合同恶意磋商 → 缔约过失 |
| C 丙担**违约**责任   | ❌**错** | 没合同 → 是**缔约过失**，不是违约      |
| D 丙可主张**抵销**   | ❌**错** | 过错方无对待请求权，不能抵销            |

→ 错误的 = **ACD** ✅

### 🔑 恶意磋商 三特征（§500(1)）

```
① 假借订立合同（根本无真实交易意图）  ← 丙
② 恶意进行磋商（反复拖延、佯装诚意）  ← 屡次说签又拒
③ 造成对方损失（白投入成本）          ← 甲往返十余次

后果：缔约过失责任，赔信赖利益损失
```

### ⚠️ 三个陷阱点

1. **A 要约 vs 要约邀请**：合作邀请、招商邀请 = **要约邀请**（希望对方发要约）。
2. **C 缔约过失 ≠ 违约**：没合同成立，谈不上违约责任。
3. **D 过错方不能抵销**：抵销要双方互负到期债权；丙作为坏人对甲无赔偿请求权，拿"自己成本"抵销 = **没门**。

### 📋 选项正误总表

| 选项 | 正误 | 选不选（问"错误"）|
|---|---|---|
| A 要约 | 错 | ✅ 选 |
| B 恶意磋商可索赔 | 对 | ❌ 不选 |
| C 违约责任 | 错 | ✅ 选 |
| D 可抵销 | 错 | ✅ 选 |

→ **ACD**

### 🎯 一句话记忆

> **"假借订立合同、来回耗你 = 恶意磋商（§500(1)）缔约过失"**
> **"没合同 → 非违约（C 错）；邀请洽谈 → 要约邀请（A 错）；过错方不能抵销（D 错）"**

### 填空模板（主观题用）

> 丙公司**无真实交易意图**，假借合作"恶意磋商"，致甲往返备案产生损失，构成 **§500 第（一）项缔约过失责任**，甲可请求赔偿信赖利益（B 对）。丙发"合作邀请书"系**要约邀请**而非要约（A 错）；甲丙间未成立合同，丙承担**缔约过失**而非违约责任（C 错）；丙为过错方，对甲无对待请求权，不得主张抵销（D 错）。问"错误的"，答 **ACD**。
