# C1-多选-16 · 根本违约的解除程序

## 题干

> 热电厂从煤矿购煤，约定 9/30 交货 + 10/31 付款。9 月底煤矿交付的煤含硫量远超约定，按政府规定不能燃烧。下列正确的是？

- A. 因煤矿根本违约，热电厂有权解除合同
- B. 若热电厂解除，须通过诉讼方式主张
- C. 热电厂解除后，煤矿有权诉讼请求确认解除效力
- D. 热电厂解除后，有权请求煤矿赔偿损失

## 我的答案

**ACD**<!-- confidence: INFERRED -->

## 涉及考点

- 根本违约（§563）
- 解除权行使方式（§565）：**通知到达即生效**，不需诉讼
- 异议权（§565 III）
- 解除与赔偿损失并存（§566）

## 考点精解 · 解除通知主义 vs 诉讼解除

### 是什么 / 易混

**§565**（解除程序）：
- **解除通知到达对方时**合同解除——**不需要**诉讼或仲裁
- 对方异议 → 可起诉**确认解除效力**（§565 III）
- 当事人**直接起诉解除** → 起诉状副本到达对方时解除（§565 II）

→ 解除采**通知主义**，诉讼**不是必经程序**。

本题对照：
- A 根本违约（含硫严重超标→合同目的不能实现） → 可解除（§563 I 4） → 对
- B 必须诉讼 → **错**（§565 通知即可）
- C 煤矿可起诉**确认解除效力**（异议权） → 对（§565 III）
- D 解除 + 赔偿损失 → 并存（§566） → 对

### 怎么考 / 坑在哪

- **B 高频陷阱**：误以为"解除合同要打官司"
- **C 易漏**：相对方有**异议权**——既可请求**确认解除有效**，也可请求**确认解除无效**

### 怎么答

ACD。B 通知主义错。
