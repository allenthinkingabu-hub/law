# C1-多选-16 · 根本违约的解除程序（通知主义 + 异议权 + 解除赔偿并存）

## 题干

> 热电厂从煤矿购煤，约定 9/30 交货 + 10/31 付款。9 月底煤矿交付的煤含硫量远超约定，按政府规定不能燃烧。下列正确的是？

- A. 因煤矿根本违约，热电厂有权解除合同
- B. 若热电厂解除，须通过诉讼方式主张
- C. 热电厂解除后，煤矿有权诉讼请求确认解除效力
- D. 热电厂解除后，有权请求煤矿赔偿损失

## 我的答案

**ACD**（A 根本违约→法定解除权；B 错·解除采通知主义不必诉讼；C 异议权·任何一方可诉请确认；D 解除+赔偿并存）<!-- confidence: INFERRED -->

> 🔎 **2026-06-09 联网核实（ACD 确认无误，无需订正）**：经《民法典》§563 + §565 + §566 + 厚德 / 德恒 / 君悦律所释义一致——① §563④：违约致**合同目的不能实现**=根本违约→法定解除权（A）；② §565：解除权人"**可不经诉讼、直接发解除通知，通知到达即解除**"（B 错）；③ §565：对方有异议，**任何一方**可请求法院/仲裁确认解除效力（民法典把主体由"被通知方"扩大到任何一方，C）；④ §566：合同解除**不影响请求赔偿损失**、解除与损害赔偿**可并存**（D）。

## 涉及考点

- 📐 **违约总模型** → [[民法-合同-违约责任模型]]（根本违约 → 解除＋赔偿并存 §566）
- [[解除]]：§563 法定解除（根本违约）· §565 **通知主义 + 异议权** · §566 解除后果
- 📐 **答题模型** → [[民法-合同-解除模型]]（能不能解→除斥期间→通知主义→解除后果）
- [[违约责任]]：解除**不排斥**违约损害赔偿（§566，二者并存）
- **一条线**：能不能解除（§563）→ 怎么解除（§565 通知）→ 对方不服（§565 异议确认）→ 解除后能否索赔（§566）

## 考点精解 · 解除的"前因—程序—后果"一条线

### 是什么 / 易混

本题把**解除**的"前因 / 程序 / 后果"全考了：

**① 能不能解除？——根本违约 → 法定解除权（§563）**
§563 I 列 5 种法定解除情形，本题是第 ④ 种：**一方违约致合同目的不能实现**（= 根本违约）。煤含硫超标、按政府规定**不能燃烧**——热电厂买煤就为了烧煤发电，煤不能烧 = **合同目的彻底落空** → 热电厂享法定解除权（**A 对**）。

**② 怎么解除？——通知主义，诉讼非必经（§565）**
§565：解除权人**通知**对方，合同**自通知到达对方时解除**——**不需要**诉讼 / 仲裁（**B 错**，头号陷阱）。
- ⚠️ 前提：通知人**确实享有解除权**（符合 §563）；无解除权者发通知、对方不异议也不解除。本题热电厂有解除权 → 通知有效。
- 诉讼只是"另一条路"：未通知而**直接起诉**解除的，自**起诉状副本送达**对方时解除（§565 II）——但不是"必须"。

**③ 对方不服？——异议权 + 确认之诉（§565）**
对方对解除有异议的，**任何一方**当事人可请求法院 / 仲裁**确认解除行为的效力**（**C 对**）。
- 民法典亮点：提确认之诉的主体由原《合同法》的"被通知方"**扩大到任何一方**。

**④ 解除后还能索赔？——解除 + 赔偿损失并存（§566）**
合同解除**不影响**请求赔偿损失（§566）；因违约解除的，解除权人可请求违约方**承担违约责任**（**D 对**）。赔偿根据是"违约"这一事实，相对独立于合同本身。

### 怎么考 / 坑在哪

- **B 是头号陷阱**："解除合同要打官司"**错**！解除采**通知主义**，通知到达即解除（§565），诉讼**非必经程序**。
- **C 易漏**：相对方不只是"被动挨解除"——有**异议权**，可主动起诉**确认解除（有/无）效**；且民法典把提诉主体扩大到**任何一方**。
- **解除 ≠ 撤销**：解除朝向**未来**（一般不溯及既往，§566 视情况恢复原状）；撤销**自始无效**（溯及既往）。别混。
- **解除不排斥索赔**（D，§566）：别以为"解除了就两清"——守约方仍可索赔履行利益损失。

### 怎么答

根本违约致合同目的不能实现 → 热电厂有法定解除权（A）；解除采通知主义、不必诉讼（B 错）；对方有异议权可诉请确认解除效力（C）；解除与赔偿损失并存（D）。故选 **ACD**。

## 📐 答题口诀 · 根本违约能解除；解除靠通知（到达即生效）；对方可诉请确认；解除＋索赔两不误

> **"根本违约（目的落空）能解除；解除**发通知就生效**（不必打官司）；对方不服可去法院**确认解除有没有效**；解除了**照样能索赔**。"**

### 关键词触发表

```
看到"标的物根本不能用 / 致合同目的不能实现"        → 根本违约、法定解除权（§563④）✓
"解除合同必须 / 只能通过诉讼"                     → 错！通知到达即解除（§565 通知主义）★
"解除通知到达对方"                               → 合同当场解除（不需对方同意、不需诉讼）
"对方对解除有异议"                               → 任何一方可诉请"确认解除效力"（§565）★
"解除后还能不能要赔偿"                           → 能！解除 + 赔偿损失并存（§566）★
"无解除权的人发了解除通知"                        → 不解除（通知主义以"有解除权"为前提）
```

### 📋 4 选项陷阱解析

| 选项 | 判断 | 依据 |
|---|---|---|
| **A 根本违约 → 可解除** | ✅ | 煤不能燃烧 = 合同目的不能实现 = 根本违约（§563④）|
| B 须诉讼解除 | ❌ | 通知到达即解除，诉讼非必经（§565 通知主义）|
| **C 对方可诉请确认解除效力** | ✅ | 异议权，**任何一方**可诉请确认（§565）|
| **D 解除 + 赔偿损失** | ✅ | 解除不影响索赔、可并存（§566）|

→ 选 **ACD** ✅

### 🚗 老王小李故事

> 老王卖给小李一辆车（约定先交车、后付款）。结果老王交的车有**根本性毛病**——发动机报废、按规定根本**不能上路**。小李买车就是为了开，现在这车**压根没法用**，买车的目的彻底落空——这就是**根本违约**。
>
> - **A 能解除吗？——能** ✓。车不能用 = **合同目的不能实现** = 根本违约（§563④）→ 小李享**法定解除权**。
> - **B 解除必须打官司吗？——不用** ✗（头号陷阱）。小李**发个解除通知**给老王，**通知一到，合同当场解除**（§565 通知主义），诉讼**不是必经程序**。〔⚠️前提：你得**真有解除权**；没解除权的人乱发通知、对方不吭声也不解除。本题小李有解除权，通知有效。〕
> - **C 老王不服能咋办？——去法院请求"确认解除到底有没有效"** ✓。老王觉得"车没那么糟、不该解除"，可行使**异议权**起诉；民法典亮点：**任何一方**都能提这个确认之诉。
> - **D 解除了还能要赔偿吗？——能** ✓。合同解除**不影响**索赔——小李另外高价买车的差价、误工损失，照样能让老王赔（§566，**解除 + 赔偿并存**）。
>
> 诀窍：**根本违约能解除；解除发通知就生效（不必打官司）；对方不服可去法院确认解除有没有效；解除了照样能索赔。**

### 🎯 一句话记忆

### 填空模板（主观题用）

> 煤含硫超标不能燃烧致**【合同目的不能实现】**= 根本违约，热电厂享**【法定解除权】**（§563，A 对）；解除采**【通知主义：通知到达对方时解除，不必诉讼】**（§565，B 错）；对方有异议的，**【任何一方可请求法院 / 仲裁确认解除效力】**（C 对）；解除**【不影响请求赔偿损失，二者并存】**（§566，D 对）。故选 **ACD**。
