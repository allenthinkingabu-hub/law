# C2-多选-11 · 定作人任意解除权

## 题干

> 何女士提供 3 块木料给家具厂订制衣柜，开工不久要求停止。家具厂继续用 2 块做完衣柜。下列哪些正确？

- A. 家具厂应赔偿因此给何女士造成的损失
- B. 何女士应支付全部约定报酬
- C. 何女士应支付部分报酬
- D. 何女士应支付全部约定报酬和违约金

## 我的答案

**AC**<!-- confidence: INFERRED -->

## 涉及考点

- [[承揽合同]] **定作人任意解除权**（§787）
- 📐 **对照法定解除** → [[民法-合同-解除模型]]（任意解除 vs §563 法定解除）
- 📐 **任意解除全家族** → [[民法-合同-委托行纪中介模型]]（§787 承揽定作人 vs §933 委托双向，横向对照）

## 考点精解 · 定作人随时解除权

### 是什么 / 易混

**§787**（定作人任意解除权）：
> 定作人在承揽人**完成工作前**可以**随时解除**承揽合同，造成承揽人损失的，应当**赔偿损失**。

→ **定作人单方任意解除权**是承揽合同的特色——理由不限。

**解除后处理**：
- 承揽人**已完成部分**：定作人**按比例**支付报酬
- 定作人**多支出**的损失：由**承揽人**承担（如本题家具厂继续违法做完，损失自负）

本题分析：
- 何女士要求停止 → 行使任意解除权
- 家具厂**违反**该解除 → 继续做完，木料损失自负
- A 家具厂应赔何损失（已耗费的木料 / 工时 / 折损）→ 对
- B 全部报酬 → **错**（仅按已完成部分付）
- C 部分报酬（停工前已完成的部分）→ 对
- D 全部报酬 + 违约金 → **错**（解除非违约 + 无违约金约定）

### 怎么考 / 坑在哪

- **B/D 陷阱**：以为"定作人解除 = 违约 = 全付 + 违约金"——错，是**任意解除权**
- 任意解除权 → 不构成违约，仅需赔偿**实际损失**

### 怎么答

AC。
