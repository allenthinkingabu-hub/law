# 刑法-总论-单选-39 · 数罪并罚之新罪先减后并

## 题干

> 来源：法考真题改编 / 瑞达·厚大·众合高频题（已联网核验法条）

乙因故意伤害罪被判处有期徒刑10年，在执行了4年后，乙在监狱内又故意伤害他人，构成新的故意伤害罪，被判处有期徒刑6年。对乙应如何决定执行的刑罚？

- A. 在10年至16年间决定执行刑期，再减去已执行的4年
- B. 先减去已执行的4年得余刑6年，再将余刑6年与新罪6年并罚，在6年至12年间决定执行
- C. 直接将新罪6年与原判10年相加执行16年
- D. 余刑6年与新罪6年相加，执行12年，不得低于12年

## 我的答案

**B**<!-- confidence: EXTRACTED -->

乙在前罪**判决宣告以后、刑罚执行完毕以前**又犯新罪，属于**新罪**，适用《刑法》§71「先减后并」。

- **第一步 减**：前罪原判10年 − 已执行4年 = **余刑6年**。
- **第二步 并**：按§69限制加重，将**余刑6年**与新罪6年并罚——在总和12年以下、数刑中最高刑6年以上，即 **6～12年** 区间酌情决定。

**A 错**：「先并后减、用前罪全部10年并罚」是§70漏罪的方法，混淆新罪与漏罪——新罪的并罚对象是前罪**余刑**，不是原判全刑。

**C 错**：16年是把原判全额单纯相加，既未先减已执行的4年，又把限制加重错写成相加。

**D 错**：12年只是本案总和刑期上限。§69要求在最高刑6年以上、总和12年以下**酌情决定**，并非必须执行满12年。

> 补充：监狱内又犯罪通常还构成**累犯**（§65）应从重处罚，但本题只问并罚方法，不影响"先减后并"的判断。

## 考点精解 · 新罪「先减后并」的两步计算

新罪的识别关键：又犯的罪行**实施于前罪判决宣告之后**——前罪的判决已既定，已经执行的部分不能重算，故只能拿**剩下没执行的余刑**去与新罪并罚。

```
【§71 新罪 · 先减后并】
前罪故伤 10年
   │ 第①步【减】减去已执行
   ▼
余刑 = 10年 − 已执行4年 = 6年 ──┐
                                 ├─ 第②步【并】§69限制加重
新罪故伤 6年 ────────────────────┘   区间：最高刑6年 ≤ X ≤ 总和12年
                                     决定执行 6～12年
```

口诀映射：**先减**（减已执行得余刑）→ **后并**（并余刑与新罪）。与漏罪正好相反，新罪并的是"余刑"而非"全刑"，且不存在事后再减一道。

## 📐 答题口诀 · 新罪先减后并

**关键词触发**：判决宣告**之后**又犯罪 / 服刑期间又犯 / 监狱内又犯 / 执行X年后

**🎯 一句话记忆**：
> 判决后的罪是新罪，先减已执行得余刑、后并新罪——「先减后并并余刑」（详见 📐 [[刑法-总论-刑罚裁量模型]]）
