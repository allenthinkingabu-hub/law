# C1-多选-21 · 深夜霸占车位被拖走：侵权 + 不当得利（非缔约过失）

## 题干

> 某日深夜，乙擅自将自己的轿车停放在甲停车位上。甲深夜回来时，无法联系上乙，也无其他车位供停车，遂致电拖车公司将乙的轿车拖走，并支付了拖车费300元。对此，下列说法正确的是？（2020金题-2-1-20）

- A. 甲有权请求乙赔偿因支付拖车费造成的损失
- B. 甲有权请求乙承担缔约过失责任
- C. 乙侵害了甲对停车位享有的物权
- D. 乙构成不当得利

## 我的答案

**ACD**<!-- confidence: EXTRACTED -->（官方参考答案：ACD）

## 涉及考点

- [[不当得利]]
- [[无因管理]]
- [[侵权责任编]]

## 考点精解 · 一个霸占行为引发的多重责任

### 是什么 / 易混

| 选项 | 定性 | 法理 |
|---|---|---|
| A 赔拖车费 300 | ✅ | 乙无权占用致甲实际损失，甲有权请求赔偿（侵权/排除妨害费用）|
| **B 缔约过失** | ❌ | 甲乙**之间根本没有磋商/缔约**，缔约过失无从谈起 |
| C 侵害物权 | ✅ | 乙擅自占用甲车位 = 侵害甲对车位的**用益/占有权能**（物权）|
| D 不当得利 | ✅ | 乙无合法依据占用车位**获得停车利益** → 不当得利 |

- B 是最大干扰：把"乙害甲"误套成缔约过失。**缔约过失必须发生在磋商缔约语境**，本题毫无缔约关系。

### 怎么考 / 坑在哪

- 同一霸占行为可同时触发**侵权（C）+ 不当得利（D）+ 损害赔偿（A）**，但**绝不是缔约过失（B）**。
- 甘的拖车自助行为合法，拖车费可向侵权人乙主张。

---

## 📐 答题口诀 · "没磋商就别提缔约过失"；霸占可同时侵权 + 不当得利

> **"占我车位 = 侵物权 + 占便宜（不当得利）+ 赔我拖车钱；唯独不是缔约过失（俩人没谈过）。"**

### 关键词触发表

```
看到题干关键词                              → 判断
"擅自占用 / 无权使用他人之物"                → 侵害物权（C）+ 不当得利（D）
"我为此实际花了钱（拖车费）"                  → 有权请求赔偿损失（A）
"双方无任何磋商/谈判"                        → 排除缔约过失（B）★
"自助拖车 / 自力排除妨害"                     → 合法，费用可向侵权人追偿
```

### 逐项分析

| 选项 | 判断 | 理由 |
|---|---|---|
| **A** | ✅ | 乙侵权致甲损失，赔拖车费 300 |
| B | ❌ | 无缔约关系，谈不上缔约过失 |
| **C** | ✅ | 擅占车位侵害甲物权 |
| **D** | ✅ | 无合法依据占用获益 = 不当得利 |

### 🚗 老王小李故事

> 大半夜小李把车往老王的车位一甩就走人，电话还打不通。老王没地方停，只好叫拖车把小李的车拖走，自掏 300 块拖车费。小李惹了几摊事？——**侵了老王车位的物权（C）**、**白占车位是不当得利（D）**、**还得赔老王那 300 拖车费（A）**。唯一沾不上的是"缔约过失"——老王和小李压根没坐下来谈过生意，哪来的缔约？B 是纯干扰。

### 🎯 一句话记忆

> **"霸占 = 侵权 + 不当得利 + 赔损失；没谈过 = 没有缔约过失。"**

### 填空模板（主观题用）

> 乙擅自占用甲车位，**【侵害甲对车位的物权】**（C），且**【无合法依据获得停车利益构成不当得利】**（D）；甲为排除妨害支付拖车费 300 元，有权**【请求乙赔偿该损失】**（A）。双方**【无磋商缔约关系】**，不构成缔约过失（B）。故选 **ACD**。
