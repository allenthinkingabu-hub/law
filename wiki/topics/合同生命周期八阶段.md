# 合同生命周期八阶段

> 效力评价之后分化为"履约周期"与"清算收尾"两条终局路径，全流程共 8 个阶段——这是审合同题时的第一道推导清单，而不是新知识点。

## 核心观点

第三阶段「四级效力评价」完成后，合同分化为两条终局路径：
- **确定有效** → 进入履行-变动-终止的完整履约周期
- **确定无效 / 被撤销 / 确定不生效** → 直接进入清算收尾

结合《民法典》合同编通则法定体系，全流程共 8 个阶段：

| 阶段 | 阶段名称 | 核心性质 | 核心任务 |
|---|---|---|---|
| 1 | 合同订立 | 动态磋商 | 要约-承诺往来，达成合意 |
| 2 | 合同成立 | 事实判断 | 确认合同在事实上"诞生" |
| 3 | 效力评价（四级分析） | 价值判断 | 评定为有效/无效/可撤销/效力待定 |
| 4 | 效力定型 | 过渡衔接 | 中间状态落地，终局确定有效或无效 |
| 5 | 履行与保全 | 核心履约 | 实现合同目的，保障债权实现 |
| 6 | 变更与转让 | 内容/主体变动 | 不改变合同同一性的合法调整 |
| 7 | 权利义务终止 | 关系消灭 | 正常履约终结或提前终止 |
| 8 | 清算救济与收尾 | 善后追责 | 违约赔偿/财产返还 + 后合同义务 |

**做题速记逻辑**：遇到任何合同题，永远按「订立→成立→效力→定型→履行→终止→清算」的顺序推导，避免"没判断效力就直接算违约""合同无效还主张履行利益"这类底层逻辑错误。

### 第四阶段：效力定型（枢纽环节）

把「可撤销、效力待定、成立未生效」三类中间状态收敛为终局结果：
- **效力待定合同**：有权人追认 → 自始有效；拒绝追认/相对人行使撤销权 → 自始无效
- **可撤销合同**：除斥期间内行使撤销权 → 自始无效；除斥期间届满未行使 → 确定完全有效
- **成立但未生效**：生效条件成就/期限届至/完成审批 → 正式生效；条件不成就/未获批准 → 确定不生效，按无效清算
- **无效合同**：直接跳过履行环节，进入清算

法考考点：追认的生效时间、撤销权的除斥期间、报批义务条款的独立生效规则。

### 第六阶段：变更与转让（不改变合同同一性）

- 合同变更：协商一致修改内容
- 债权转让：**通知债务人即生效**，无需债务人同意
- 债务承担：**须经债权人同意**才生效
- 概括转移：需对方同意

### 第八阶段：清算——两条独立规则路径（最易混淆）

| | 有效合同终止后 | 无效/被撤销/不生效 |
|---|---|---|
| 依据 | 解除清算 + 违约责任 | 《民法典》第157条财产清算 |
| 责任性质 | 违约责任（继续履行/赔偿损失/违约金/定金罚则） | 缔约过失责任（按过错程度） |
| 赔偿范围 | **履行利益** | **信赖利益** |
| 附加义务 | 后合同义务（通知、协助、保密、旧物回收） | — |
