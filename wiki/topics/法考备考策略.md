# 法考备考策略

> 基于 [[法考科目分层]] 的复习次序与时间分配。

## 核心观点

不要平均用力。按"先核心 + 关键 → 中段理论法 → 考前小法 → 始终盯新法"的四阶段次序投入。

## 四阶段次序

### First — 先啃核心 + 关键

[[民法]]、[[刑法]]、[[刑事诉讼法]]、[[民事诉讼法]]、[[行政法与行政诉讼法]]、[[商法]] 六科：

- 是主观题**全部来源**
- 约占客观题 **2/3**
- 须用整个备考期**反复理解、做题**

### Then — 中段吃透理论法

- 分值近 50 而难度低，是拉分性价比之王
- [[宪法]]、[[法理学]] 为重
- [[习近平法治思想]] 主观必背
- [[司法制度和法律职业道德]] 务必拿满

### Finally — 考前突击小法

- [[经济法]] + [[知识产权法]] + 三国法（[[国际私法]] / [[国际经济法]] / [[国际公法]]）+ [[环境资源法]] + [[劳动与社会保障法]]
- 靠**短期记忆**
- 置于考前 **2–3 个月**集中速记
- 不宜过早投入

### Always — 盯紧新法

- [[仲裁法]] 为 2026 头号新增
- [[公司法]] 持续重点
- 新法条＝高命中考点，**第一时间**纳入
