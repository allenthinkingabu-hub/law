# 合同订立流程

> [[要约]] → [[承诺]] → [[合同成立]] → [[合同生效]]；[[合同编]] 合同总则的核心流程。

## 核心观点

合同订立流程是 [[民法]] [[合同编]] 中所有动态规则的起点。它是 [[法考主观题]] 民法大案例的**入口判断**：先认定合同**是否成立**、**何时成立**，才能往下谈效力、履行、违约。

## 主干流程

```
要约生效  ─→  承诺生效（= 合同成立）  ─→  合同生效
   ↑                ↑                       ↑
 §472/§474       §483/§484                §502
```

详细节点：

1. **发出 [[要约]]**（§472）— 须满足两要件
   - 区分 [[要约邀请]]（§473）
   - 可能 [[要约的撤回]]（§475）/ [[要约的撤销]]（§476）

2. **作出 [[承诺]]**（§479）— 到达主义（§484）
   - 承诺可 [[要约的撤回|撤回]]（§485），**不可撤销**
   - [[迟到承诺]]（§486 / §487）
   - 变更内容：[[实质性变更]] → 新要约（§488）；非实质性 → 承诺有效（§489）

3. **[[合同成立]]**（§483）— 事实判断（有合意）
   - 一般合同：承诺生效时
   - 合同书：签名/盖章/按指印**任一**（§490）
   - [[电子合同]]：提交订单成功时（§491）

4. **[[合同生效]]**（§502）— 法律评价（合意有约束力）
   - 默认：成立即生效
   - 例外：附条件/期限（§158）、需经批准 → 成立但未生效
   - 报批义务条款**独立有效**

## 客观题答题四步法

| Step | 动作 | 关键 |
|---|---|---|
| 1 | **定性** | 要约 / 要约邀请？抓两要件 + 法定要约邀请 + 广告例外 |
| 2 | **画时间轴** | 撤回 / 撤销 / 迟到的"到达"先后，默认到达主义 |
| 3 | **判变更** | 承诺改了内容？实质性 → 新要约；非实质性 → 承诺有效 |
| 4 | **成立 / 生效两步走** | 先问成立，再问生效，两个问题分开答 |

### 填空模板

> 甲发出的__行为__构成 __要约/要约邀请__，因为 __满足/不满足要约两要件__（§472/§473）。乙的回复构成 __承诺/新要约__，理由是 __一致/作出实质性变更__（§479/§488）。依 §483，承诺生效时合同成立，故合同于 __某时点__ 成立。
>
> 〔如需区分生效〕合同虽已成立，但因 __附生效条件/未经批准__，依 §502/§158，**尚未生效**。
