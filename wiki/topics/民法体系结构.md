# 民法体系结构

> [[民法典]] 七编的内部结构、依赖关系、学习顺序与三梯队分类。

## 核心观点

[[民法]] 学科以 [[民法典]] 为基础，按"重要程度 × 频率 × 主客 × 难度 × 依赖"将七编分为三梯队，学习时**不按编号顺序**而是按**依赖顺序**展开。

## 三梯队分层

### 第一梯队（分值最大、最高频、主观核心、优先吃透）

按学习顺序排：

1. **[[总则编]]**（编 01）— 全编地基，最先学
2. **[[物权编]]**（编 02）— 静态归属 + [[担保]]物权
3. **[[合同编]]**（编 03）— 债法核心，全编分值之最
4. **[[侵权责任编]]**（编 07）— 债法另一支柱

### 第二梯队（中频，客观为主，偶进主观）

- **[[婚姻家庭编]]**（编 05）
- **[[继承编]]**（编 06）— 易拿分，性价比最高

### 第三梯队（低频/特色，客观为主，记忆为主）

- **[[人格权编]]**（编 04）— 民法典首创独立编，易拿分

## 学习顺序（最优依赖路径）

```
总则 → 物权 → 合同（含担保合并） → 侵权 → 婚姻家庭 → 继承 → 人格权
```

注意：**与编号顺序不同**。编 04 [[人格权编]] 移到最后，编 03 [[合同编]] 与编 02 [[物权编]] 的[[担保]]合并学。

### 关键依赖

| 编 | 依赖 |
|---|---|
| [[总则编]] | 无（最先学） |
| [[物权编]] | [[总则编]] |
| [[合同编]] | [[总则编]]（法律行为/效力）+ 债法总则思维 |
| [[侵权责任编]] | [[总则编]]（民事责任） |
| [[婚姻家庭编]] | 相对独立 |
| [[继承编]] | 相对独立 |
| [[人格权编]] | 相对独立 |

## 两条贯穿全编的提示

### ① 担保是横跨编的

- [[担保]] 物权（抵押 / 质押 / 留置）在 [[物权编]]
- 保证在 [[合同编]]
- 命题常合并考 → **建议合并成一个"担保"专题**

### ② 请求权基础思维贯穿主观大案例

- [[请求权基础]] = 谁能向谁、依据哪个请求权、主张什么
- 四大基础：合同 / 物权 / 侵权 / 不当得利
- 是 [[法考主观题]] 民法案例的统一分析框架

## 2026 复习重心

- 民法典本体**稳定**，机构对 2026 民法大纲解读为**变化极小**
- 复习重心：[[担保]] + [[合同编]]
