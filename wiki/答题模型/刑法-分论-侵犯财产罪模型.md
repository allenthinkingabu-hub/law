# 📐 侵犯财产罪 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑法法考教练。侵犯财产罪是分论分值最高的板块，也是命题人挖坑最密的地方。绝大多数同学的惯性是"**见暴力就抢劫、见拿走就盗窃、见交钱就诈骗**"——凭一个动作直觉贴标签，结果在抢劫与敲诈、盗窃与诈骗、盗窃与侵占之间反复横跳。但命题人挖的坑，全埋在四个字眼上：
> 
> **占有**（这东西取财前到底归谁攥着）、
> **处分**（被害人是自愿交的还是被人拿走的）、
> **职务便利**（靠的是职务权限还是仅仅工作机会）、
> **拟制**（明明长得不像抢劫/盗窃，法律却硬把它当抢劫/盗窃定）。
> 
> 今天用**一张总决策树＋一张黑话对号入座表**把这一章一次理清：**先问占有转移没（取得型 vs 毁弃/背信）→ 取得型四刀切 7 罪 → 背信型四把刀切清侵占/职务侵占/挪用 → 毁弃拒付三罪收尾**。看到题干，30 秒切对罪名。

## 适用场景与解决问题

本模型覆盖侵犯财产罪全章三大罪群（对应 [[刑法分论-人身与财产犯罪考点-深度报告]] 第二板块）：

- **取得型 7 罪**：抢劫§263（含转化抢劫§269、携带凶器抢夺拟制§267②）、盗窃§264（含四类新型、§196③信用卡拟制、§265/§210①拟制、虚拟财产）、诈骗§266（含三角诈骗、诉讼诈骗）、抢夺§267①、聚众哄抢§268、敲诈勒索§274。
- **背信型 4 罪**：侵占§270、职务侵占§271、挪用资金§272、挪用特定款物§273。
- **毁弃/拒付 3 罪**：故意毁坏财物§275、破坏生产经营§276、拒不支付劳动报酬§276之一。

要破解的核心问题：①占有归谁判（取得型 vs 毁弃/背信、盗窃 vs 侵占/职务侵占）；②取得型 7 罪如何用"暴力/自取/公秘/心理"四刀分开；③法律拟制条款（§196③、§267②、§269、§265、§210①）的适用与对照；④2026 顶级增量（职务侵占/挪用资金并轨参照贪污/挪用公款罪）。

> **核心一句**：财产罪先问**占有有没有从被害人转移到行为人手里**——转移了进**取得型**（抢偷骗夺敲哄，四刀细分）、原地砸烧扔是**毁弃**（故意毁坏财物§275）、本在自己手里/职务权限吞掉是**背信**（侵占§270·职务侵占§271·挪用§272）。

> 🔎 **法条已联网核实（2026-06-28）**：抢劫§263（基本刑3年以上10年以下·八种加重情节10年以上、无期或死刑）、盗窃§264三档（较大**1千–3千**、巨大**3万–10万**、特别巨大**30万–50万**·法释〔2013〕8号第1条·四类新型见第3条）、诈骗§266三档（较大**3000**、巨大**3万**、特别巨大**50万**·法释〔2011〕7号第1条·共11条）、敲诈勒索§274三档（较大**2000–5000**·法释〔2013〕10号第1条·共9条）、抢夺§267①（"数额较大或者多次抢夺"入罪）、聚众哄抢§268（只罚首要分子和积极参加的）、侵占§270（绝对亲告罪·最高5年）、职务侵占§271（刑修十一三档·最高无期）、挪用资金§272（三种用途门槛互不相同）。**2026 顶级增量**：法释〔2026〕6号第八条令职务侵占、挪用资金定罪量刑标准**分别参照贪污罪、挪用公款罪执行**（2026-04-10发布·**2026-05-01施行**），职务侵占参照贪污罪＝**数额较大3万、巨大20万、特别巨大300万**（援引法释〔2016〕9号）。两份抢劫规则为**法发**字号（法发〔2005〕8号"两抢意见"·法发〔2016〕2号"抢劫指导意见"），**非"法释"**，勿与海事诉讼"法释〔2016〕2号"混淆。
> ⚠️ **诚实标注（账本中标 MEDIUM/待核验项）**：①"持枪抢劫"中"枪支"适用《枪支管理法》——**枪支界定主要见于规则汇编，未在法发〔2016〕2号正文逐字坐实，标 MEDIUM**；②"机器不能被骗""处分意识""三角诈骗处分权限""占有判定（封缄物/遗忘物/死者占有）"均系**刑法理论通说与判例规则**，非司法解释逐字明文（法释〔2013〕8号仅规范数额与四类新型，未规定占有归属）；③虚拟财产"想象竞合、择一重"为**学理与个案判决通行立场**，两高未用此确切措辞，标 MEDIUM；④"拾得他人信用卡在ATM等机器上使用"定性（信用卡诈骗 vs 盗窃）**学理与实务存在对立**，标 MEDIUM（详见盗窃模块第三步）；⑤法释〔2026〕6号是否含**明文废止**旧"6万/100万""2倍/5倍折算"条款未逐字坐实，本模型按"实质取代/后法优于前法"表述，不作绝对化断言。

> ⚠️ **易记错点（命题人最爱反向设陷）**：①**占有第一刀切错全盘皆输**——没转移占有的别往抢劫/盗窃套；②**真军警**亮真实身份抢劫≠"冒充军警"加重（按基本犯从重）；③**14-16周岁**盗窃/诈骗/抢夺后施暴**不转化抢劫**（只就重伤死亡单独定故意伤害/杀人）；④**机器不能被骗**——骗ATM/自助机定盗窃不定诈骗；⑤**携带凶器抢夺**拟制抢劫（§267②）、**携带凶器盗窃**只是新型盗窃（绝不拟制）；⑥三档数额起点各不同——**盗窃1000、敲诈2000、诈骗3000**，别张冠李戴。

> **姊妹模型**：[[刑法-总论-罪数形态模型]]（竞合并罚·盗窃信用卡拟制·携带凶器抢夺拟制接口）、[[刑法-总论-危害行为与因果关系模型]]（毁坏与盗后毁弃分阶段定性）、[[刑法-分论-侵犯人身权利犯罪模型]]（绑架vs抢劫接口）、[[物权的保护]]（占有的民刑投射）。

## 一、 侵犯财产罪总决策树

> 拿到一道财产罪题，别急着在抢偷骗里乱猜，按这棵树从上往下砍。

```
                          一笔财产案，到底定哪个罪？
                                    │
   ▼ 第一步 · 总闸门：被害人对财物的"占有"有没有转移到行为人手里？
   │   （占有=对财物的实际控制支配；先问"东西离没离开他的控制圈"）
 ┌──┴───────────────────────────────────────────────┐
 ▼ 没转移占有                                          ▼ 转移了占有 → 取得型（进第二步）
 ├─ 只毁损价值/效用、不据为己有                          │
 │    → 毁弃型：故意毁坏财物罪 §275                      │
 │      （破坏生产经营§276 · 拒不支付劳动报酬§276之一）   │
 └─ 行为人"本来就合法占有/有职务权限"再吞掉               │
      → 背信型：侵占§270 · 职务侵占§271 · 挪用资金§272    │
                                                       │
   ▼ 第二步 · 取得型怎么分（四刀定位 7 罪）
   │
   ├─【第一刀·真正的分水岭】有没有"完全压制人身反抗（不能·不敢·不知反抗）、
   │     被害人毫无意志选择余地"，当场逼对方就范并当场取财？
   │     ★ 关键：开关是"是否压垮反抗·有无选择余地"，不是"当场/将来"！
   │       当场胁迫≠必然抢劫——当场拦人扬言"现在不给就天天堵你"、
   │       被害人仍可拒绝/报警/讨价的，是敲诈不是抢劫。
   │     完全压制、被害人无选择、当场取财 → 抢劫罪 §263 ★
   │       （事后施暴走§269转化 · 携凶抢夺走§267②拟制）
   │     未完全压制、被害人仍有选择余地 ↓
   │
   ├─【第二刀】东西是行为人"自己夺/拿"走的，还是被害人"自己交"出来的？
   │     ┌── 行为人自己取（被害人没交）──┐    ┌── 被害人自己交（有瑕疵的交付）──┐
   │     ▼                            ▼    ▼                              ▼
   │  【第三刀】公开还是秘密？           │  【第四刀】交付时被害人什么心理？
   │   ├─ 当面公然夺取（乘人不备）        │   ├─ 基于"错误认识"（看走眼、信了假话）
   │   │    → 抢夺罪 §267①             │   │    → 诈骗罪 §266
   │   │   （聚众趁乱公然哄抢 → 哄抢§268）│   └─ 基于"恐惧"（被吓住、怕吃亏，但仍有选择余地）
   │   └─ 暗中秘密窃取（自以为不被发觉）   │        → 敲诈勒索罪 §274（当场胁迫也可能是敲诈）
   │        → 盗窃罪 §264               │
   │       （对机器/ATM下手取财 → 仍是盗窃，机器不能被骗）
   │
   覆盖取得型 7 罪：抢劫§263 · 盗窃§264 · 抢夺§267① · 聚众哄抢§268 · 诈骗§266 · 敲诈勒索§274
```

> ⚠️ **第一刀最易错处（命题人最爱的对撞点）**：分水岭是"**是否达到完全压制反抗、被害人有无意志选择余地**"，**不是"当场还是将来"**。敲诈勒索完全可以**当场实施、当场交付**（如当场拦住人扬言"现在不给 200 就天天来堵你"，被害人当场掏钱）——只要被害人尚有拒绝/报警/讨价的选择余地，就是敲诈不是抢劫。把"当场"当唯一开关，会把大量"当场胁迫型敲诈"误判成抢劫。

## 二、 黑话→人话 对号入座表

> 财产罪的"黑话"集中扎堆，先把它们一次性翻成大白话、对上号，后面读模型不卡壳。

| 黑话术语 | 翻成人话 | 对号入座（一句话定位） |
|---|---|---|
| **占有** | 法律上"谁实际攥着、对财物说了算、能支配它"（≠民法所有权） | 停在你家楼下的车，你在屋里睡觉也算你占着 |
| **打破他人占有** | 违背别人意志，把别人正控制的东西弄到自己手里 | 盗窃/抢劫/抢夺的灵魂动作 |
| **处分意识** | 被害人"心里清楚自己正把这东西交出去、并且愿意交" | 有＝诈骗；没有（不知交的是啥）＝盗窃 |
| **处分行为** | 被害人基于处分意识把占有实际转移（交付、签字放行、转账） | 诈骗必备一环 |
| **完全压制反抗** | 被害人被逼到"不能·不敢·不知"反抗、毫无意志选择余地 | 有＝抢劫；仅被吓住但还能选择＝敲诈 |
| **转化犯（事后抢劫）** | 先犯了较轻的罪（盗诈夺），因后续暴力整体升格成抢劫 | §269转化抢劫 |
| **法律拟制** | 本不符合该罪，法律硬把它"当作"该罪定（改变定性） | 盗窃信用卡并使用§196③＝盗窃；携凶抢夺§267②＝抢劫 |
| **结果加重犯** | 基本犯造成法定更重结果，不并罚、直接升量刑档 | 抢劫致人重伤死亡§263第5项 |
| **间接正犯** | 把"不知情/无责任能力的人"当工具来犯罪，幕后操纵者才是正犯 | 骗无处分权的路人帮搬车＝盗窃间接正犯 |
| **背信** | 你信得过我才把东西交给我/让我管，我却辜负信任据为己有 | 侵占§270·职务侵占§271·挪用§272 |
| **绝对亲告罪** | 不告不理、纯自诉，被害人不告，检察院、法院都不能动 | 侵占罪§270第3款（无转公诉口子） |
| **利用职务上的便利** | 凭"主管/管理/经手"本单位财物的**权限**（≠只是熟悉环境的工作机会） | 靠权吞＝职务侵占；靠机会拿＝盗窃 |

## 三、 取得型财产罪总界分 · 第一步＋第二步骨架

> 这一节是整张财产罪决策树的**总主干**——把"取得型 7 罪"用四刀一层层切开。

### 第一步：占有有没有转移（取得型 vs 毁弃/背信的总闸门）

> 拿到一道财产罪题，绝大多数同学第一反应就是"偷？抢？骗？"——直接奔取得型去了。这恰恰是命题人最爱的入口陷阱：他先给你一个"东西没了/受损了"的结果，引你往盗窃、抢劫上套，其实东西**根本没从被害人手里转移到行为人手里**（被砸了、被烧了），或者**本来就在行为人合法手里**（保管的、有职务权限的）。做财产罪题，必须先拉这道总闸门：占有转移了没有。

#### 1. 核心逻辑（极简字诀）

> **「东西离手是取得，原地报废是毁弃，本在手里吞是背信」**

- **「东西离手是取得」**（取得型）：**占有**（人话＝"谁实际攥着、对财物说了算、能支配它"，不等于谁是物主）从被害人那边**转移**到了行为人或第三人手里——行为人想把财物**据为己有**。只有这一摊，才往下分抢劫、盗窃、抢夺、诈骗、敲诈、哄抢 7 个罪。

- **「原地报废是毁弃」**（毁弃型·故意毁坏财物罪§275）：行为人**没把东西占为己有**，只是把财物**原地砸了、烧了、扔了、放跑了**，让它失去价值或效用。占有**没有转移给行为人**（行为人手里什么也没多出来），所以不是取得型。"毁坏"既包括物理上砸烂，也包括**效用性毁损**（把戒指扔进大海、放飞他人笼中的鸟）。

- **「本在手里吞是背信」**（背信型·侵占§270／职务侵占§271／挪用资金§272）：财物**本来就合法在行为人手里**（替别人保管的、捡到的遗忘物、或基于职务权限经手的本单位财物），行为人把"**合法持有变成非法占有**"——他**没有打破别人的占有**（东西本就在他控制下），这跟取得型"打破他人占有、把东西抢/偷/骗过来"根本两码事。

#### 2. 大白话讲解（完整数字案例）

用老王（行为人）、小李（被害人）、老张（老板）演四个对照案例，专门盯住"占有到底转移没转移"：

* **【案例一：老王偷走小李的电瓶车 —— 占有转移了，取得型】**
  小李把价值 4000 元的电瓶车停在楼下，老王趁四下无人撬锁骑走变卖。
  * **判定**：电瓶车原本在小李的实际控制圈里（停在自家楼下、仍属小李占有），老王把它**骑走据为己有**——占有从小李转移到老王手里了。**这是取得型**，进第二步细分（最后定盗窃罪§264）。

* **【案例二：老王把小李的手机扔进河里 —— 占有没转移，毁弃型】**
  老王和小李吵架，气头上抢过小李价值 6000 元的手机，当着小李的面狠狠摔在地上踩烂，又一脚踢进河里。老王自己**一分钱没拿、什么也没占**。
  * **判定**：手机虽然"没了"，但老王**没有把它据为己有**，占有没有转移到老王手里，他只是把财物**原地报废**。定**故意毁坏财物罪§275**（损失 6000 元，已过 5000 元立案线·依《立案追诉标准（一）》第33条）。命题人最爱用"老王把东西弄没了"误导你选盗窃——记住：**没据为己有就不是取得型**。

* **【案例三：老王私吞替小李保管的 3 万元 —— 东西本在手里，背信型】**
  小李出国前把 3 万元现金交给好友老王代为保管。半年后小李回国索要，老王谎称"钱被偷了"拒不归还。
  * **判定**：这 3 万元从一开始就是小李**自愿合法地交到老王手里保管**的——东西**本来就在老王合法占有之下**，老王没有"打破谁的占有去抢去偷"，他只是把"替你保管"变成"占为己有、拒不退还"。这是**侵占罪§270**（背信型），不是盗窃。一句话区分：**盗窃是把别人攥着的东西弄到自己手里，侵占是自己手里的东西不还了。**

* **【案例四：仓库保管员老王监守自盗 5 万元货 —— 利用职务权限，背信型】**
  老王是某公司仓库保管员，手里有库房钥匙和出入库登记权限。他利用这一**职务便利**，把本单位价值 5 万元的货物私运出库变卖。

  * **判定**：货物本就由老王基于**职务权限**经手控制，他是把"代单位管"变成"占为己有"。这是**职务侵占罪§271**（5 万元已达"数额较大"3 万元起·依法释〔2026〕6号第八条参照贪污罪标准），不是盗窃。对照：若是清洁工趁打扫顺手拿走同事的电脑（对该电脑**毫无职务支配权限**），那就**回到取得型定盗窃罪**。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「先问占有走没走：走了进取得（抢偷骗夺敲），原地砸烧扔是毁弃，本在手里不还是背信。」**

> 🎯 **做题眼**：
> 1. 拿到任何财产罪题，**第一刀永远先问"占有有没有从被害人转移到行为人手里"**，再谈罪名；
> 2. 题干出现"砸烂/烧毁/扔掉/放跑、行为人自己分文未取"的，**直接排除取得型，往故意毁坏财物罪§275 上靠**；
> 3. 题干出现"**代为保管/捡到的遗忘物/利用职务权限经手**"再吞掉的，**直接排除盗窃**，往侵占§270 / 职务侵占§271 / 挪用资金§272 上靠。

### 第二步：取得型怎么分（四刀定位 7 罪）

> 确定占有转移、进了"取得型"后，绝大多数同学又开始凭感觉在抢劫、盗窃、诈骗里乱猜。其实取得型 7 个罪是被**四刀**整整齐齐切开的。

#### 1. 核心逻辑（极简字诀）

> **「一刀压反抗定抢劫，二刀看谁动的手，三刀公夺秘窃分，四刀骗怕定诈敲」**

- **「一刀压反抗定抢劫」**（§263）：第一刀的真正开关是"**有没有完全压制人身反抗、被害人有无意志选择余地**"——当场使用暴力/胁迫**把被害人逼到不能·不敢·不知反抗、毫无选择余地**，当场取财，才是**抢劫罪§263**。**注意：开关不是"当场还是将来"**——当场胁迫但没把反抗压垮、被害人还能拒绝/报警/讨价的，是敲诈不是抢劫。没把反抗完全压制的，往下走。

- **「二刀看谁动的手」**：第一刀过了，就分两条道——东西是**行为人自己夺/拿走的**（被害人压根没"交"），还是**被害人自己（带瑕疵地）交出来的**。这一刀把 7 罪劈成"自取型"（抢夺、哄抢、盗窃）和"交付型"（诈骗、敲诈）两半。

- **「三刀公夺秘窃分」**（自取型内部）：**当面乘人不备公然夺取**＝**抢夺罪§267①**（"数额较大或者多次抢夺"即入罪）；聚众趁乱公然哄抢＝**聚众哄抢罪§268**（只罚首要分子和积极参加的）；**暗中秘密窃取、自以为不会被发觉**＝**盗窃罪§264**。补一刀：对着 **ATM／自助机器**下手取财，因为"**机器不能被骗**"，通说定**盗窃**而非诈骗。

- **「四刀骗怕定诈敲」**（交付型内部）：基于"**错误认识**"（看走眼、信了假话，自愿处分）＝**诈骗罪§266**（较大3000元起）；基于"**恐惧**"（被吓住、怕吃亏，被迫交付，但**仍有意志选择余地**）＝**敲诈勒索罪§274**（较大2000–5000元起）。

#### 2. 大白话讲解（完整数字案例）

继续用老王（行为人）、小李（被害人）——每个案例只差一个关键动作，罪名就变了：

* **【案例一：老王持刀逼小李交出 5000 元 —— 第一刀·抢劫】**
  老王在小巷里掏出匕首抵住小李，喝令"把钱掏出来，不然捅死你"，小李吓得不敢动，乖乖交出 5000 元。
  * **判定**：老王**当场用暴力（持刀威胁）把小李反抗完全压制住、当场取财**，小李毫无选择余地——**抢劫罪§263**。小李虽是"自己掏的钱"，但被**压制到不敢不能反抗**才交的，不算"有选择余地的交付"，走抢劫而非敲诈。

* **【案例二：老王骑车飞抢小李的手机 —— 第一刀过、二刀自取、三刀公夺·抢夺】**
  老王骑电动车经过，趁小李低头看价值 8000 元的手机时，一把夺过加速逃走，全程只对"物"用力、没对小李人身施加压制性暴力。
  * **判定**：第一刀没有压制人身反抗的暴力，不是抢劫；第二刀是老王自己夺走的，走自取型；第三刀当面公然夺取。落到**抢夺罪§267①**（8000 元已达"数额较大"；§267① 还有"或者多次抢夺"这条独立入罪门）。

* **【案例三：老王趁小李熟睡摸走 4000 元 —— 二刀自取、三刀秘窃·盗窃】**
  深夜小李在网吧熟睡，老王悄悄把小李口袋里 4000 元现金摸走，全程自以为神不知鬼不觉。
  * **判定**：没把反抗压制（一刀过）→ 老王自己拿的（二刀自取）→ 暗中秘密窃取（三刀秘窃）。落到**盗窃罪§264**（4000 元已过"数额较大"1000–3000 元起点）。**延伸**：若老王撬 ATM、或用他人卡在 ATM 取款，因"机器不能被骗"照样定**盗窃**。

* **【案例四：老王骗小李"代缴话费"，小李自己转 3000 元 —— 二刀交付、四刀错误认识·诈骗】**
  老王假冒营业厅工作人员，谎称"你话费欠 3000 元要停机，先转给我代缴"，小李信以为真，**自己主动**把 3000 元转给老王。
  * **判定**：没把反抗压制（一刀过）→ 钱是小李自己交出来的（二刀交付型）→ 交时小李心里是"看错了、信了假话"即**错误认识**（四刀）。落到**诈骗罪§266**（3000 元正好踩"数额较大"起点）。

* **【案例五：老王当场拦住小李扬言"现在不给 3000 就天天来堵你"，小李怕了当场掏钱 —— 二刀交付、四刀恐惧·敲诈（当场胁迫也是敲诈）】**
  老王在小李店门口当面拦住小李，扬言"今天现在不给我 3000 元，我就天天带人来堵你的门、让你做不成生意"，小李害怕长期被纠缠，**当场**掏了 3000 元。
  * **判定**：虽是**当场胁迫、当场交付**，但老王**没把小李反抗完全压垮**——小李此刻仍有拒绝、报警、讨价的选择余地，他是**基于恐惧、为息事宁人而交钱**（四刀恐惧）。落到**敲诈勒索罪§274**（3000 元已过"数额较大"2000–5000 元起点）。**与案例一抢劫的唯一分水岭**：不是"当场还是将来"，而是"**反抗有没有被完全压垮、被害人还有没有选择余地**"——压垮了、没得选＝抢劫；没压垮、还能选＝敲诈。**与案例四诈骗的分水岭**：同样自己交钱，心里是"看走眼（错误认识）"＝诈骗，还是"我怕（恐惧）"＝敲诈。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「取得型，四刀切：完全压垮反抗·没得选＝抢劫；没压垮再看谁动手——自己夺(公)＝抢夺、自己偷(秘)＝盗窃；被害人自己交，看心理——看走眼＝诈骗、怕吃亏(还能选)＝敲诈。」**

> 🎯 **做题眼**：
> 1. **第一刀认准"完全压制反抗·有无选择余地"**：把人逼到不能·不敢·不知反抗、当场夺财、毫无选择＝抢劫§263；**当场胁迫但没把反抗压垮、被害人还能拒绝/报警/讨价的，是敲诈§274——别看到"当场"就判抢劫**；
> 2. **抢夺 vs 盗窃只看"公开还是秘密"**：当面乘人不备夺走＝抢夺§267①，暗中自以为不被发觉＝盗窃§264；看到"对 ATM／自助机器下手取财"的，**直接定盗窃**，排除诈骗；
> 3. **诈骗 vs 敲诈死盯被害人交付时的心理**：基于错误认识自愿处分＝诈骗§266，基于恐惧被迫交付（仍有选择余地）＝敲诈§274——只问他掏钱那一刻心里是'信'还是'怕'。

#### 🗺️ 取得型财产罪总界分 · 两步全景速览

| 步 | 干什么 | 🎯 一眼判 |
|---|---|---|
| **一 占有转移否** | 取得型 vs 毁弃/背信 | **东西离手据为己有＝取得型；原地砸烧扔＝故意毁坏财物§275；本在手里/职务权限吞掉＝侵占§270·职务侵占§271·挪用资金§272** |
| **二·一刀 压反抗** | 抢劫 or 其余 | **完全压制反抗·被害人无选择·当场取财＝抢劫§263**；当场胁迫但未压垮、仍能选择 → 不是抢劫，往下走（多半是敲诈） |
| **二·二/三刀 自取** | 公夺 vs 秘窃 | **当面公然夺取＝抢夺§267①（聚众趁乱＝哄抢§268）；暗中秘密窃取＝盗窃§264；对机器下手取财＝盗窃** |
| **二·四刀 交付** | 诈骗 vs 敲诈 | **基于"错误认识"自愿交＝诈骗§266；基于"恐惧"被迫交（仍有选择余地）＝敲诈§274（当场胁迫也可能是敲诈）** |

## 四、 抢劫罪深度模块（§263 八大加重 / §269 转化 / §267② 携带凶器拟制）

> **教练开场白**
> 抢劫罪是财产罪"三巨头"里分值最稳、坑也最密的一个。绝大多数同学一看到"打人＋拿钱"就往抢劫上扣，又把八大加重情节当顺口溜背、考场上张冠李戴。命题人最爱挖的三个坑：① **真军警**亮明身份抢劫，到底算不算"冒充军警抢劫"那一档加重？（答案：**反而不算**，按基本犯从重）；② 小偷被抓现行、**当场**动手打人——这是"转化抢劫"还是单纯故意伤害？年龄够不够？③ 揣着一把管制刀去**抢夺**，法律凭什么直接拟制成抢劫罪、却不要求你掏刀子？今天用**先认基本犯（两个"当场"+完全压制反抗）→ 再核八大加重 → 再判转化抢劫§269 → 最后辨携带凶器抢夺拟制§267②**讲透。

> 🔎 **法条已联网核实**：§263 八种加重情节、§267② 携带凶器抢夺拟制、§269 转化抢劫三要件均经最高检一手源逐字 CONFIRMED；细则依 **法发〔2005〕8号"两抢意见"**、**法发〔2016〕2号"抢劫指导意见"**（二者均为"**法发**"指导意见、不是"法释"司法解释）；"为劫财杀人 vs 为灭口杀人"是否并罚依 **法释〔2001〕16号**；14-16周岁不转化依 **法释〔2006〕1号第十条**。"持枪/枪支定义"账本标 MEDIUM（待核验）。

### 抢劫罪·四步判定流程（决策树）

```
                 这是不是抢劫罪？定哪一档？要不要并罚？
                                  │
   ▼ 第一步 · 基本犯：两个"当场"+完全压制反抗
   │   当场以暴力/胁迫/其他方法【完全压制反抗·使被害人无选择余地】 + 当场取财
   ├─ 仅当场胁迫但未压垮反抗·被害人仍能选择 → 不是抢劫（多半敲诈，看第六节）
   ├─ 缺"当场取财" → 不是抢劫（看敲诈/抢夺/盗窃）
   └─ 两个"当场"齐+反抗被完全压制 → 抢劫基本犯（3年以上10年以下）→ 进第二步
                                  │
   ▼ 第二步 · 八大加重（§263）：升到10年以上/无期/死刑？
   │   入户 / 公共交通工具上 / 抢银行金融机构 / 多次或数额巨大 /
   │   致人重伤死亡 / 冒充军警 / 持枪 / 抢军用·抢险救灾救济物资
   └─ 三大反向陷阱：真军警≠冒充、入户盗窃转化≠"入户抢劫"、为灭口杀人→并罚
                                  │
   ▼ 第三步 · 不是典型抢劫？看 §269 转化抢劫（事后抢劫）
   │   ①前提罪只限 盗窃/诈骗/抢夺 ②当场使用暴力或以暴力相威胁
   │   ③目的＝窝藏赃物/抗拒抓捕/毁灭罪证
   └─ 14-16周岁不转化（只就重伤/死亡单独定故意伤害/杀人）
                                  │
   ▼ 第四步 · 携带凶器"抢夺"→ §267② 直接拟制抢劫
       前提：抢夺行为本身已成立（达数额较大或多次抢夺）；
       无须当场使用凶器（区别于§269）；
       强对照：携带凶器"盗窃"只是§264新型盗窃、不拟制抢劫
```

### 第一步：抢劫罪基本犯——盯死两个"当场"+完全压制反抗

> 拿到"打人＋拿钱"的题，绝大多数同学直接写抢劫。但命题人会在"暴力够不够压制反抗""取财是不是当场""当场胁迫到底是抢劫还是敲诈"上做手脚。

#### 1. 核心逻辑（极简字诀）

> **「当场施暴压垮反抗，当场取财才算抢；将来加害是敲诈，当场胁迫但未压垮、仍可选择的也是敲诈；乘隙夺走是抢夺」**

- **「当场施暴压垮反抗」**：手段必须是**当场**对人实施暴力、胁迫或其他方法（如灌醉、麻醉），且程度足以**完全压制反抗**（不能、不敢、不知反抗，被害人**毫无意志选择余地**）。这才是抢劫的命门——**不是"当场"本身，而是"反抗被压垮、没得选"**。

- **「当场取财才算抢」**：压制反抗与取得财物在时空上**紧密衔接、当场完成**。
- **「将来加害是敲诈」+「当场胁迫但未压垮也是敲诈」**：威胁的是**将来**才兑现的恶害、被害人尚有选择余地、基于**恐惧**交钱→**敲诈勒索罪§274**；**即便是当场胁迫、当场交付**，只要**没把反抗完全压垮、被害人还能拒绝/报警/讨价**，仍是**敲诈**，不是抢劫。

- **「乘隙夺走是抢夺」**：没对人身使用足以压制反抗的暴力、只是**乘人不备公然夺取**（飞车夺包）→**抢夺罪§267①**，暴力只作用于"物"。

- 法定刑：抢劫基本犯处 **3年以上10年以下**有期徒刑，并处罚金（§263）。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王持刀逼小李交手机 —— 标准抢劫】**
  老王深夜在巷子里掏刀抵住小李脖子喝令"把手机交出来"，小李吓得不敢动，当场把价值 6000 元的手机递给老王，老王拿了就走。
  * **判定**：老王**当场**用刀**把小李反抗完全压制（不敢动、无选择余地）**，又**当场**取得手机——成立**抢劫罪基本犯**（3年以上10年以下）。

* **【案例二：老王威胁"一周内不打 5 万就放你裸照" —— 敲诈勒索，不是抢劫】**
  老王手里有小李的隐私照片，发微信说"一周之内往这个账户打 5 万元，否则发到你公司群"。小李害怕，三天后转了 5 万元。
  * **判定**：恶害指向**将来**、小李交钱前**仍有选择余地**、基于**恐惧**交付——**敲诈勒索罪§274**，没有"完全压制反抗＋当场取财"。

* **【案例三：老王当场拦住小李扬言"现在不给 2 万就天天来店里闹"，小李当场转账 —— 当场胁迫，仍是敲诈】**
  老王在小李饭店里当面拦住小李："今天不给我 2 万，我就天天带人来你店里大闹、砸场子，看你还怎么开。"小李怕生意做不下去，**当场**用手机转了 2 万元。
  * **判定**：虽是**当场胁迫、当场交付**，但老王**没把小李反抗完全压垮**——小李仍可拒绝、报警、讨价，他是**基于恐惧息事宁人**而交钱。**敲诈勒索罪§274**，不是抢劫。**核心：第一刀的开关是"反抗被压垮没、有没有选择余地"，不是"当场还是将来"。**

* **【案例四：老王骑摩托飞车抢走小赵挎包 —— 抢夺，不是抢劫】**
  老王骑摩托从背后拽走小赵肩上价值 8000 元的挎包，小赵踉跄一下没摔倒，老王加速逃离。
  * **判定**：力量作用于"物"，未对小赵人身实施足以压制反抗的暴力，是乘人不备公然夺取——成立**抢夺罪§267①**。（若拽拖中致小赵倒地重伤，可能升格按抢劫评价。）

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「两个当场+压垮反抗才是抢劫：当场制服到没得选＋当场拿；威胁将来、当场胁迫但没压垮·还能选，都归敲诈；乘隙夺物归抢夺。」**

> 🎯做题眼：
> 1. 选项定抢劫，先在题干里圈出"**反抗有没有被完全压垮、被害人有没有选择余地**"——只圈到"当场"两个字、却没压垮反抗的，**别急着判抢劫**；
> 2. 看到"几天内/否则将来如何"指向未来的威胁，**或者当场胁迫但被害人仍可拒绝/报警/讨价**的，优先定敲诈勒索§274；
> 3. 看到"乘人不备、公然夺取、夺了就跑"、暴力只作用于物的，优先定抢夺§267①。

### 第二步：八大加重情节（§263）——升到 10 年以上/无期/死刑

> 确认是抢劫基本犯后，命题人专挑三处反向设陷：真军警抢劫反而不算"冒充军警"加重、入户盗窃被发现后转化原则上不算"入户抢劫"、为灭口而杀人要另定故意杀人罪并罚。

#### 1. 核心逻辑（极简字诀）

> **「入户公交抢银行，多次巨额最常考；致死升档不并罚，冒充军警假才算；持枪抢军救灾物，真警灭口要拐弯」**

八种加重情节（命中即处 **10年以上有期徒刑、无期徒刑或者死刑**，并处罚金或没收财产）——按 §263 法定顺序：

1. **入户抢劫**——"户"＝供他人**家庭生活**（功能特征）＋**与外界相对隔离**（场所特征）的住所；集体宿舍、旅店宾馆、临时工棚一般**不算**"户"（个案具备两特征的除外）。还须：**入户目的具有非法性**＋**暴力发生在户内**。

2. **在公共交通工具上抢劫**——指**正在运营中**的公共汽车、大中型出租车、火车、地铁、轻轨、轮船、飞机等。**不含小型出租车**；不含在**未运营**的交通工具上针对司售/乘务人员抢劫。

3. **抢劫银行或者其他金融机构**——抢的是金融机构的经营资金、有价证券、客户资金等。

4. **多次抢劫或者抢劫数额巨大**——"多次"＝三次以上。

5. **抢劫致人重伤、死亡**——**结果加重犯**：直接升档，**不另定故意伤害/故意杀人罪并罚**（**抢劫罪是财产罪里唯一有结果加重犯的罪**）。

6. **冒充军警人员抢劫**——只有**假冒**（穿军警制服、持枪、出示军警证件，足以使人误以为是军警）才算；**真军警利用真实身份抢劫的，不算这一档加重**，而是按抢劫**基本犯从重处罚**。

7. **持枪抢劫**——使用或向被害人显示持有/佩带的枪支；"枪支"范围适用《枪支管理法》。**【MEDIUM·待核验】此项"枪支"界定主要见于规则汇编，未在法发〔2016〕2号正文逐字坐实，与已坐实条文区别对待，勿混为一谈。**

8. **抢劫军用物资或者抢险、救灾、救济物资**。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王踹门入室抢劫小李家 —— 入户抢劫（第1项）】**
  老王以抢劫为目的，深夜踹开小李家门，持棍逼小李交出 2 万元现金及金饰。
  * **判定**：小李家是"户"，老王**入户目的就是抢劫**、暴力发生在**户内**——成立**入户抢劫**，处 10 年以上。

* **【案例二：老王翻窗入室盗窃被发现、当场打人逃跑 —— 转化抢劫且应当认定为"入户抢劫"】**
  老王翻窗进小李家**盗窃**，正翻出 5000 元时被回家的小李撞见，老王为抗拒抓捕当场在客厅打了小李一拳逃走。
  * **判定**：老王**入户时具有盗窃的非法目的**，且转化抢劫的暴力行为发生在**户内**，根据司法解释，应当认定为**"入户抢劫"加重处罚情节**。

* **【案例三：老王在运营公交上抢劫 vs 在小型出租车上抢劫 —— 一个加重一个不加重】**
  情形A：老王在正在载客行驶的公交车上持刀抢劫乘客 3000 元——成立**"在公共交通工具上抢劫"**（第2项加重）。
  情形B：老王在一辆**小型出租车**上持刀抢劫司机 3000 元——小型出租车**不属于**本项"公共交通工具"，**不适用该加重**，按抢劫基本犯处理。

* **【案例四：真军警 vs 假军警抢劫 —— 法律效果相反（第6项）】**
  情形A：老王是普通混混，**穿仿制警服、亮出假警官证**拦下小赵搜身劫走 1 万元——成立**"冒充军警人员抢劫"**（第6项加重，10年以上）。
  情形B：老张是**真警察**，下班后**亮明真实警察身份**拦车劫走司机 1 万元——**不算"冒充军警抢劫"**，按抢劫**基本犯从重**处罚。

* **【案例五：为劫财杀人 vs 抢完为灭口杀人 —— 一个不并罚一个并罚】**
  情形A：老王为劫取小李 5 万元，**预谋先杀后取**，或在劫财过程中为制服小李反抗将其打死——以**抢劫罪一罪**论（§263第5项"致人死亡"加重档，**不并罚**）。
  情形B：老王抢完小李 5 万元后，**为了灭口**怕小李报警，又把小李掐死——抢劫已既遂、事后另起杀人故意，**抢劫罪与故意杀人罪数罪并罚**（法释〔2001〕16号）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「八项加重背顺序，三坑记牢不踩雷：真警不算冒充、户内盗窃转化也算入户抢、灭口杀人要并罚。」**

> 🎯做题眼：
> 1. "真军警亮真实身份抢劫"的，选项凡写"冒充军警/适用第六项加重"的**一律排除**——正确是抢劫基本犯**从重**；
> 2. "入户盗窃被发现后当场施暴"的，定**转化抢劫**，若暴力发生在**户内**，**应当认定为"入户抢劫"加重**（发生在户外则不构成入户抢劫）；
> 3. "抢劫致人死亡"分两步：为劫财/制服反抗而杀＝抢劫一罪不并罚；抢完为灭口而杀＝抢劫罪＋故意杀人罪**并罚**；
> 4. "公共交通工具"看到**小型出租车**、**未运营**车辆的，**排除**该项加重。

### 第三步：转化抢劫（§269 事后抢劫）——三要件＋年龄红线

> 这一步专治"小偷被抓现行、当场动手"的题。§269 有铁打的三要件，更隐蔽的坑是年龄。

#### 1. 核心逻辑（极简字诀）

> **「盗诈夺当场施暴，护赃拒捕毁罪证，三者齐全转抢劫；十四十六不转化，只就重伤死亡单独算」**

- **「盗诈夺」（前提罪三限定）**：前提行为**只能是盗窃、诈骗、抢夺**三种罪。犯**侵占、职务侵占、敲诈勒索**等罪后即使为拒捕施暴，**也不转化**。

- **「当场施暴」**：必须**当场**使用暴力或以暴力相威胁。"当场"＝作案现场，**也包括**逃离现场后被追捕围堵时使用暴力。

- **「护赃拒捕毁罪证」（主观目的三选一）**：使用暴力的目的必须是**窝藏赃物、抗拒抓捕、或者毁灭罪证**。

- **「十四十六不转化」（主体年龄红线）**：已满 14 不满 16 周岁的人，对盗窃/诈骗/抢夺**本不负刑责**，事后施暴**不成立转化抢劫§269**；只就其暴力造成的**重伤、死亡**结果单独定故意伤害罪或故意杀人罪。满 16 周岁才能转化。

- 前提行为原则上还须达到或接近"**数额较大**"（数额明显偏低又无特定加重情节的，不构成转化抢劫）。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王（20岁）入室盗窃被发现、当场打人逃跑 —— 标准转化抢劫】**
  老王（20 岁）翻进小李家偷了 4000 元正要走，被小李撞见，老王为**抗拒抓捕**当场用拳头把小李打成轻伤后逃走。
  * **判定**：前提罪是盗窃（达数额较大）、**当场**施暴、目的是**抗拒抓捕**——三要件齐备，成立**转化抢劫§269（依§263定罪处罚）**。

* **【案例二：老王敲诈勒索后为拒捕打人 —— 不转化】**
  老王敲诈了小李 5000 元，离开时被巡逻保安拦下，老王挥拳打伤保安逃跑。
  * **判定**：前提罪是**敲诈勒索§274**，**不在**盗窃/诈骗/抢夺三种之列——**不成立转化抢劫**。打伤保安另按故意伤害罪等处理。

* **【案例三：小赵（15岁）盗窃后施暴致人重伤 —— 不转化，只定故意伤害】**
  小赵（15 周岁）入户盗窃 3000 元被户主发现，为逃跑当场用棍子把户主打成**重伤**。
  * **判定**：小赵未满 16 周岁，对盗窃不负刑责，**不适用§269转化抢劫**；但故意伤害致人重伤是 14-16 周岁应负刑责的范围，故**只就重伤结果单独定故意伤害罪**（法释〔2006〕1号第十条）。若打成轻伤则连故意伤害罪也不构成。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「转化抢劫三件套：盗诈夺、当场暴、护赃拒捕毁罪证；满十六才转化，少一件就出局。」**

> 🎯做题眼：
> 1. 看到"先犯罪后当场打人"，先核**前提罪**——前提是**侵占/职务侵占/敲诈勒索**等的，转化抢劫**一律排除**；
> 2. 行为人是**14-16 周岁**、盗窃/诈骗/抢夺后施暴的，定转化抢劫的选项**一律排除**——正确是只就**重伤/死亡**单独定故意伤害/故意杀人罪；
> 3. 暴力目的不是"护赃/拒捕/毁证"（如纯属事后报复泄愤）的，不转化。

### 第四步：携带凶器抢夺拟制抢劫（§267②）——与"携带凶器盗窃"强对照

> 这是抢劫模块最精巧的一处法律拟制。命题人爱用两组对照挖坑：一是"携凶抢夺 vs 携凶盗窃"，二是"抢夺基础行为成不成立"。

#### 1. 核心逻辑（极简字诀）

> **「先得有抢夺，携凶才拟制；掏不掏都算，盗窃不升格」**

- **【适用前提：抢夺行为本身先成立】**：§267② 拟制抢劫的**大前提**是"**抢夺**"这一基础行为本身已经成立——即须达到"**数额较大**"或"**多次抢夺**"。
	- **单纯携带凶器、却没实施抢夺（或抢夺未着手、数额未达且非多次）的，不拟制为抢劫。**

- **「携凶才拟制」**：§267 第2款"携带凶器抢夺的，依照本法第263条的规定定罪处罚"。这是**法律拟制**：本来抢夺没对人身用暴力，但**因携带凶器升高了人身危险性**，法律硬把它**当作抢劫罪**定。

- **「掏不掏都算」（"携带"的主观限定）**：
	- 携带**国家禁止个人携带的器械**（枪支、爆炸物、管制刀具等）抢夺的，**无须显示、无须使用、也无须额外证明携带目的**即拟制为抢劫（与§269转化抢劫"必须当场施暴"的关键区别）；
	- 携带**其他器械**（如普通水果刀、棍棒）抢夺的，须有证据证明系**为实施犯罪而有意携带**才认定。（若有意**显示**凶器、被害人察觉的，则直接成立**普通抢劫**。）

- **「盗窃不升格」（立法逻辑对照）**：携带凶器去**盗窃**的，只是§264"携带凶器盗窃"这一**新型盗窃**情节（不要求数额较大即入罪），**绝不拟制为抢劫罪**。**立法逻辑差异**：携凶抢夺因"凶器＋公开夺取"显著升高了对人身的现实危险，才被拟制升格为抢劫；携凶盗窃只是把"带凶器"作为新型盗窃的**入罪门槛**（解决偷得少也要管的问题），并未升高到抢劫那种人身危险，所以不升格。**记结论更要懂这层差异，否则遇到变式题（携凶抢夺但未着手/未达数额）会翻车。**

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王揣管制刀抢夺挎包、全程没掏刀 —— 拟制抢劫】**
  老王把一把管制刀揣在外套里，骑车冲上去夺走小赵价值 7000 元的挎包（已达数额较大），全程**没掏刀、没亮刀**，小赵都不知道他带着刀。
  * **判定**：抢夺基础行为已成立（7000 元达数额较大）＋管制刀属"国家禁止个人携带的器械"＋老王**携带凶器抢夺**，依§267②**直接拟制为抢劫罪**——哪怕全程没使用、没显示、也无须证明携带目的（处3年以上）。

* **【案例二：老王只揣管制刀闲逛、压根没动手抢夺 —— 不拟制抢劫】**
  老王把管制刀揣在身上在街上闲逛，被巡警查获，但他**当时并未实施任何抢夺行为**。
  * **判定**：§267② 的大前提是"**抢夺行为本身已成立**"，老王**根本没抢夺**——不拟制为抢劫（可能涉非法携带管制器具的治安/其他评价，但不是抢劫罪）。**对照案例一可见：携凶＋实施了达标抢夺才拟制，光携凶不抢夺不拟制。**

* **【案例三：老王亮出匕首抢夺、被害人看见了 —— 普通抢劫】**
  老王夺包时**故意把匕首亮给小赵看**、晃了两下，小赵吓得松手，老王夺走价值 7000 元挎包。
  * **判定**：老王**有意显示凶器、被害人察觉**，这已是当场以凶器相威胁压制反抗——直接成立**普通抢劫§263**。

* **【案例四：老王揣管制刀去入室盗窃 —— 只是携带凶器盗窃，不拟制抢劫】**
  老王把管制刀揣在身上，翻窗进小李家**盗窃**，偷了 800 元就走，全程未被发现、未对任何人施暴。
  * **判定**：老王是**携带凶器盗窃**，属§264"新型盗窃"（哪怕只偷 800 元、未达数额较大也入罪），但**绝不拟制为抢劫罪**——与"携带凶器抢夺"拟制抢劫形成强对照（立法逻辑：携凶抢夺升高人身危险才升格，携凶盗窃只是入罪门槛）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「先成立抢夺，携凶才拟制抢劫（掏不掏都算）；携凶盗窃只是入罪门槛、绝不升格；一字之差，定罪两重天。」**

> 🎯做题眼：
> 1. 看到"携带凶器**抢夺**"，先确认**抢夺本身成不成立（达数额较大或多次）**——成立才定抢劫罪§267②，且不纠结"有没有当场使用凶器"；**光携凶却没实施达标抢夺的，不拟制**；
> 2. "国家禁止个人携带的器械"（枪/爆炸物/管制刀具）抢夺，**无须证明携带目的**即拟制；"其他器械"须证明**为犯罪而携带**；
> 3. 看到"携带凶器**盗窃**"，定**盗窃罪§264新型盗窃**，选项凡把它拟制成抢劫的**一律排除**；记住立法逻辑差异（携凶抢夺升高人身危险→升格；携凶盗窃只是门槛）；
> 4. 区分"§267②拟制抢劫"（不要求当场施暴）与"§269转化抢劫"（必须当场施暴），别混。

## 五、 盗窃罪深度模块（§264 占有判定 / 四类新型 / §196③ 信用卡拟制 / 虚拟财产）

> **教练开场白**
> 盗窃罪是财产罪里出题量最大的一个。绝大多数同学一看到"偷偷拿走别人东西"就条件反射定盗窃，可坑全埋在两件事上：**第一，这东西"原来归谁占着"？**——拿错了就成了侵占（亲告罪、不告不理）；**第二，"偷"和"骗"、"偷"和"侵占"、"偷"和"职务侵占"到底哪一条线**——同样是"把卡刷了"，偷来的卡刷＝盗窃罪，捡来的卡刷＝信用卡诈骗罪，差一个字判得天差地别。今天用**占有归谁判 → 四类新型不看数额也入罪 → 信用卡/通信线路/发票的法律拟制 → 虚拟财产怎么定**打透。

> **核心一句**：盗窃＝**违背被害人意志、打破他人对财物的占有、建立自己（或第三人）的新占有**（秘密性已弱化、公开盗窃也算）。判罪先问"**这东西原来归谁占着**"——还在被害人/管理人手里＝盗窃，已在自己手里＝侵占/职务侵占，被害人自己交出来＝诈骗。

> 🔎 **法条已联网核实**：§264 三档（法释〔2013〕8号第1条）：数额较大 **1千–3千**起、巨大 **3万–10万**起、特别巨大 **30万–50万**起。四类新型（法释〔2013〕8号第3条）：①多次盗窃＝**2年内盗窃3次以上**；②入户盗窃；③携带凶器盗窃；④扒窃＝公共场所或公共交通工具上窃取他人**随身携带**的财物。§196第3款（盗窃信用卡并使用→依§264·法律拟制）、§265（牟利盗接通信线路/复制电信码号→依§264）、§210第1款（盗窃增值税专用发票等→依§264）。虚拟财产：§264与§285数据罪**想象竞合、择一重**（学理与判例通行立场，非两高司法解释明文，标 MEDIUM）。
> ⚠️ **诚实标注**：占有判定（封缄物/遗忘物/死者占有）系**刑法理论通说与判例规则**，非法释〔2013〕8号明文（该解释只规定数额、四类新型、累计、既遂，未规定占有归属）。"拾得他人信用卡在 ATM 等机器使用"定性存在学理与实务对立（标 MEDIUM，详见第三步）。

### 第一步：占有归谁判（盗窃 vs 侵占 vs 职务侵占）

> 这是盗窃罪的头号命门。绝大多数同学看到"东西被拿走了"就直奔盗窃，跳过了最该问的一刀："行为前这东西归谁占着？"

#### 1. 核心逻辑（极简字诀）

> **「占有在他打破即盗，占有在我据为侵占，职权管着私吞职侵」**

- **占有判定的几个高频场景（理论通说/判例规则，非法释〔2013〕8号明文）**：

  - **封缄物**（上锁的箱子、封口的包裹）：整体交付保管时，**整体由保管人占有，但里面的内容物仍由委托人占有**。→ 偷偷**抽取内容物**＝打破委托人占有＝**盗窃**；**连箱带物整个吞掉**＝合法占有的整体变非法据有＝**侵占**。

  - **遗忘物**（落在出租车/宾馆房间里）：东西一旦遗忘在他人管理的特定空间，**占有转移给司机/宾馆管理者**。→ 第三人进去拿走＝打破司机/管理者占有＝**盗窃**；若是**司机/清洁工本人**因职务便利发现并据为己有、拒不交出＝**侵占**。

  - **死者占有**（两种相反分支，必须切全）：
    - **杀人者当场或紧接着取财**＝死者**生前占有的延续**，通说定**盗窃**（杀人行为另定故意杀人罪，与盗窃数罪并罚）。

    - **行为人杀人后离开、事后另起意返回取财（隔时较久、占有已脱离）**，或**无关第三人事后路过取走尸体上的财物**＝财物已成**脱离占有物**，无"占有可打破"，按**脱离占有物处理、定侵占罪§270**（侵占遗忘物/脱离物的延伸），不再是盗窃。**分水岭：取财与杀人是否紧接、占有是否仍在延续。**

#### 2. 大白话讲解（完整数字案例）

* **【案例一：小李把名牌手表落在出租车上，老张（乘客）顺走 —— 盗窃罪】**
  小李把价值 2 万元的手表落在出租车后座。下一位乘客老张上车后发现手表，悄悄塞进口袋下车。
  * **判定**：东西一落在出租车这个**司机管理的封闭空间**里，占有就已**转移给司机**。老张把司机占有下的手表拿走，正是**打破他人（司机）占有、建立自己占有**，成立**盗窃罪**（2 万元，达数额较大），不是侵占罪。
  * **对照**：若是**出租车司机自己**收车时发现这块表、揣兜里拒不交出——手表此时已在司机合法保管之下，定**侵占罪**（亲告罪）。

* **【案例二：老王受托保管一个上锁的密码箱，撬锁取走里面 5 万元现金 —— 盗窃罪】**
  小李把上锁的密码箱（封缄物）交老王保管，箱里有 5 万元现金。老王起贪念，撬开锁取走 5 万元，箱子原样还回。
  * **判定**：封缄物规则——**箱子整体由保管人老王占有，但箱内现金仍由委托人小李占有**。老王撬锁抽取内容物，是**打破小李对箱内现金的占有**，成立**盗窃罪**（5 万元，数额巨大）。
  * **对照**：若老王把**整个密码箱（连箱带钱）一起卷走变卖**——整个箱子本就在老王合法保管之下，定**侵占罪**。抽内容＝盗窃，吞整体＝侵占。

* **【案例三：老王杀人后当场取财 vs 杀人离开后第三人取财 —— 死者占有的两种分支】**
  情形A：老王为劫财把小李打死，**当场**从尸体上搜走 5 万元现金离开。
  情形B：老王因仇杀小李后逃离现场，**两小时后无关路人老张**经过，见尸体身上有钱包，顺手取走里面 5 万元。
  * **判定**：情形A——取财与杀人**紧接、当场**，按"**死者生前占有的延续**"定**盗窃罪**（与故意杀人罪数罪并罚）；情形B——小李已死、老王早已离开，钱包成了**脱离占有物**，无关第三人老张取走它**没有打破谁的占有**，定**侵占罪§270**（侵占脱离物），不是盗窃。**一刀切：取财紧接杀人、占有仍延续＝盗窃；隔时较久、占有已脱离＝脱离占有物按侵占处理。**

* **【案例四：仓库保管员老王私运货物 vs 清洁工老张顺走同事电脑 —— 职务侵占 vs 盗窃】**
  仓库保管员老王，利用保管钥匙、负责出入库登记的**职务权限**，把本单位价值 8 万元的货物私运变卖；同公司清洁工老张趁打扫之机，顺手拿走同事桌上价值 6000 元的笔记本电脑。
  * **判定**：老王对单位货物有"主管、管理、经手"的**职务权限**，定**职务侵占罪§271**（2026-05-01后定罪量刑标准**参照贪污罪**：数额较大 3 万、巨大 20 万、特别巨大 300 万；8 万元达数额较大）。老张对那台电脑**没有任何职务上的支配权限**，只是"趁工作之便"打破同事对电脑的占有，定**盗窃罪§264**（6000 元，达数额较大）。
  * **一刀切**：分水岭只有一个——取财时利用的是**"职务权限"**还是仅仅**"工作机会/熟悉环境的劳务便利"**。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「先问占有在谁手：在他打破是盗窃，在我赖着是侵占，靠职权吞是职侵；封缄抽内容＝盗、吞整体＝侵，遗忘落在管理空间＝盗；死者占有——紧接杀人取财＝盗，隔时脱离＝侵。」**

> 🎯 **做题眼**：
> 1. "拿走他人财物"的题，**第一步永远先问"行为前这东西归谁占着"**——东西还在被害人/司机/宾馆/单位的控制范围里，选项凡定"侵占罪"的一律警惕、优先盗窃；
> 
> 2. 看到**"代为保管/受托保管/捡到遗忘物·埋藏物/拒不退还·拒不交出"**字眼，往**侵占罪§270 亲告罪**上靠；看到**"利用职务上的便利/主管·管理·经手本单位财物"**，往**职务侵占罪§271**上靠；
> 
> 3. **封缄物**题：抽取内容物＝盗窃、连整体吞掉＝侵占——固定考点，记死；
> 
> 4. **死者占有**题：杀人者当场/紧接取财＝盗窃（与故意杀人并罚）；行为人事后另起意返回取财、或无关第三人事后取走＝脱离占有物，按侵占处理——别把所有"从尸体上拿钱"都判盗窃。

### 第二步：四类新型盗窃（不要求"数额较大"即入罪）

> 命题人在这里挖坑：法释〔2013〕8号规定的四种情形——多次、入户、携带凶器、扒窃，只要符合其一，哪怕没偷到钱、没达"数额较大"，照样成立盗窃罪。

#### 1. 核心逻辑（极简字诀）

> **「多次入户带凶扒，不看数额也入罪；扒窃只算贴身物，落在座上不算扒」**

- **多次盗窃**＝**2 年内盗窃 3 次以上**（次数本身入罪）。
- **入户盗窃**＝**非法进入**供他人家庭生活、与外界相对隔离的**住所**盗窃（"户"同入户抢劫；学生宿舍房间、旅客租用期的宾馆房间等，只要符合生活居住与相对隔离特征，**均应认定为“户”**）。

- **携带凶器盗窃**＝携带枪支、爆炸物、管制刀具等**国家禁止个人携带的器械**盗窃，**或**为实施违法犯罪而携带其他足以危害人身安全的器械盗窃。

- **扒窃**＝在**公共场所或公共交通工具上**，窃取他人**随身携带（贴身、近身控制）**的财物。**落在座位上、放身旁桌上、脚边购物车里人没贴身控制的，不算"随身携带"，不构成"扒窃"**（仍可能是普通盗窃，看数额）。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王半年内连偷 3 家，每次都不到 1000 元 —— 多次盗窃，照样构罪】**
  老王 8 个月内先后撬了 3 家便利店收银台，分别偷得 600 元、800 元、700 元，单次都没到当地"数额较大"（1000 元起）门槛。
  * **判定**：虽然单次都没够、累计才 2100 元，但老王**2 年内盗窃达 3 次**，符合"多次盗窃"，**直接成立盗窃罪**。（详见：[[刑法-分论-财产犯罪-单选-07 · 盗窃罪之多次盗窃与二年折算界分案 V2]]）

* **【案例二：老张翻墙进小李家行窃，还没拿到钱就被抓 —— 入户盗窃，未遂仍构罪】**
  老张趁小李一家外出，翻墙进入小李**自住的独栋住宅**翻找财物，被回家的小李抓住，**分文未得**。
  * **判定**：小李家是"户"，老张非法入户行窃，符合"入户盗窃"，**不要求达数额即已着手盗窃罪**（本案因未取得财物属盗窃未遂，但罪名成立）。（详见：[[刑法-分论-财产犯罪-单选-08 · 盗窃罪之入户盗窃与相对封闭空间认定案 V2]]）

* **【案例三：老王在地铁里偷乘客挎包 vs 偷座位上没人看的手机 —— 扒窃 vs 普通盗窃】**
  老王在运营中的地铁上，趁拥挤把手伸进小李**挎在肩上的背包**拿走 500 元现金；同一趟车又把小赵**放在空座位上、人却站在两米外刷手机**的另一部手机（价值 3000 元）顺走。
  * **判定**：拿小李挎包里的钱＝窃取**随身携带**的财物，成立**扒窃**，500 元虽不达数额也构成盗窃罪；拿小赵放在座位上、本人没贴身控制的手机，**不属"随身携带"，不算扒窃**——但手机 3000 元已达数额较大，仍构成**普通盗窃罪**。（其携带凶器盗窃与扒窃随身性界分详见：[[刑法-分论-财产犯罪-单选-09 · 盗窃罪之携带凶器盗窃与扒窃随身性界分案 V2]]）

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「多次（2 年 3 次）、入户（宿舍/住宅）、带凶器、扒窃（贴身物）——四类盗窃不看钱数；座位上没贴身的不是扒窃，回去看数额；携带凶器盗窃绝不拟制抢劫。」**

> 🎯 **做题眼**：
> 1. "偷的钱很少/没偷到钱"却问构不构罪时，**先扫有没有"2 年内 3 次以上""进了人家家里（含学生宿舍）""带着管制刀具/凶器""在地铁公交商场偷贴身物"**——命中任一，"因未达数额不构成犯罪"的选项**一律排除**；
> 
> 2. "**扒窃**"专盯**"随身携带"**：落在座位上、桌上、脚边没人看的，改判普通盗窃看数额；
> 
> 3. "入户盗窃"的"户"＝住宅/供人生活的封闭场所，**学生宿舍、正在租用的宾馆房间属于户**。携带凶器盗窃仍是盗窃罪，**不拟制为抢劫罪**（携带凶器抢夺才拟制抢劫）。

### 第三步：信用卡 / 通信线路 / 发票的法律拟制（§196③、§265、§210①）

> 几个本不该叫盗窃的行为，被刑法**法律拟制**成盗窃罪；信用卡那一组又跟"信用卡诈骗罪"贴身对撞——尤其"拾得卡到 ATM 用"是超高频争议点。

#### 1. 核心逻辑（极简字诀）

> **「偷卡又刷算盗窃，拾骗刷卡是诈骗，光偷信息网上用还是诈骗；盗接线路偷发票，一律拟制成盗窃」**

- **信用卡三连对照**：
  - **盗窃信用卡并使用（§196③拟制盗窃罪）**：须**实物卡被盗 + 使用**两条件都满足（排除了权利人对卡片实物的占有）。

  - **拾得他人信用卡并使用 / 骗取他人信用卡并使用**＝属"**冒用他人信用卡**"＝**信用卡诈骗罪**（§196①第3项，法释〔2009〕19号第五条·经法释〔2018〕19号修改）。

  - **只窃取卡信息资料 + 通过互联网/通讯终端使用**（没拿到实物卡）＝也属"冒用"＝**信用卡诈骗罪**（因没排除对卡片实物的占有）。

- **⚠️【MEDIUM·超高频争议点】拾得他人信用卡后"对人用"还是"对机器用"，定性可能不同**：
	  - **对自然人柜员/特约商户营业员使用**（有人当面审核）＝典型"**冒用**"＝**信用卡诈骗罪**（无争议）。
	  - **对 ATM 等机器使用**：存在尖锐对立——一种观点认为"**机器不能被骗**"、拾得卡到 ATM 取款应回归**盗窃罪**（与本章"机器不能被骗→盗窃"主线一致）；另一种观点（及多数司法实践、依§196 与法释〔2009〕19号精神）仍认定为"**冒用→信用卡诈骗罪**"。**法考遇到此变量务必看清题干"对人用还是对机器用"，并意识到对机器用存在争议。**]

- **另外两个拟制**：**§265**（以**牟利为目的**盗接他人通信线路、复制他人电信码号，或明知是盗接/复制的电信设备而使用）→依§264以盗窃罪论；**§210第1款**（盗窃增值税专用发票、或可用于骗取出口退税/抵扣税款的其他发票）→依§264以盗窃罪论（区别于§210第2款"诈骗发票"依§266诈骗罪）。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王偷了小李的信用卡又去 POS 机刷 3 万元 —— 拟制盗窃罪】**
  老王扒走小李钱包，里面有一张信用卡，老王持卡到商场 POS 机刷消费 3 万元。
  * **判定**：实物卡被盗 + 使用，依 **§196 第 3 款法律拟制，定盗窃罪**（不是信用卡诈骗罪）。命题人会用"刷卡＝冒用＝诈骗"诱你错选信用卡诈骗罪。注意：根据全国人大常委会立法解释，刑法上的“信用卡”包含借记卡（储蓄卡），故偷借记卡并使用的，同样适用此拟制，定盗窃罪；而拾得他人借记卡并使用的，构成信用卡诈骗罪。（具体详见增补考题：[[刑法-分论-财产犯罪-单选-51 · 盗窃信用卡并使用之“借记卡与储蓄卡”立法拟制案 V2]]）

* **【案例二：老张捡到小李掉的信用卡去 ATM 取款 vs 拿到柜台/商户刷 —— 注意"对机器还是对人"的争议变量】**
  情形①：老张在地上**捡到**小李的信用卡，拿去 **ATM 机**取了 2 万元。
  情形②：老张拿这张捡来的卡，**到银行柜台让柜员办理转账、或在商场让营业员刷卡**消费 2 万元。
  * **判定**：情形②是"对自然人（柜员/营业员）使用"＝典型**冒用＝信用卡诈骗罪**（无争议）；情形①"**对 ATM 机器使用**"是**MEDIUM 级争议点**——"机器不能被骗"一派倾向盗窃罪，但§196 与法释〔2009〕19号精神及多数司法实践倾向认定为**信用卡诈骗罪**。**做题眼：先看清"对人还是对机器"；对机器用的，意识到它与'机器不能被骗→盗窃'主线存在张力，按题干给定立场或选"信用卡诈骗（实务通行）/标注争议"作答。**

* **【案例三：只偷拍卡号在网上买东西 —— 信用卡诈骗罪】**
  老张没拿到实物卡，只**偷拍了小李的卡号、有效期、验证码**，在网购平台下单买了 2 万元商品。
  * **判定**："**窃取卡信息 + 网络使用**"（没拿到实物卡）＝冒用＝**信用卡诈骗罪**（没排除对卡片实物的占有，不适用§196③盗窃拟制）。
  * **⚠️强对照：盗刷他人手机绑定支付**：如果行为人**盗窃他人手机并利用手机微信、支付宝绑定的快捷支付转账或刷码消费**，因手机非信用卡，微信/支付宝非信用卡，机器亦不能被骗，此种利用手机作为密钥划扣资金的行为直接定**普通盗窃罪（§264）**，不适用§196③拟制，亦不构成信用卡诈骗罪（详见增补考题：[[刑法-分论-财产犯罪-单选-52 · 盗窃并使用他人手机微信或支付宝资金定性案 V2]]）。

* **【案例四：老王为牟利盗接邻居电话线打长途 / 偷一沓增值税专用发票 —— 拟制盗窃罪】**
  老王为省话费并转卖，**盗接**邻居的通信线路、复制其电信码号牟利；另一案中老王潜入财务室**偷走一批增值税专用发票**。
  * **判定**：前者依 **§265**、后者依 **§210 第1款**，**均拟制为盗窃罪**（依§264 定罪量刑）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「偷实物卡去刷＝盗窃（§196③）；捡的、骗的、只偷信息网上用＝信用卡诈骗；'拾得卡对机器用'有争议(MEDIUM)；盗接线路、偷增值税发票＝拟制盗窃（§265/§210①）。」**

> 🎯 **做题眼**：
> 1. 信用卡题先抓**"卡怎么来的"**：盗窃/窃取（实物卡）+使用→盗窃罪；出现**"拾得""骗取""窃取卡信息+网络/电话使用"**任一→偏向信用卡诈骗罪；
> 2. **"拾得卡"再追问"对人用还是对机器用"**：对柜员/营业员用＝信用卡诈骗（无争议）；对 ATM 等机器用＝MEDIUM 争议（"机器不能被骗"倾向盗窃 vs 实务倾向信用卡诈骗），按题干立场作答、心里有这根弦；
> 3. "盗接通信线路、复制电信码号（牟利）""盗窃增值税专用发票"→**盗窃罪（拟制）**；但"诈骗/虚开发票"是诈骗罪（§210②），别混。

### 第四步：虚拟财产 / 虚拟货币被盗（§264 与 §285 想象竞合择一重）

> 游戏装备、比特币/USDT 被盗，定盗窃罪还是计算机犯罪学界有争论。考试要点是记住**通行处理：盗窃罪（§264）与非法获取计算机信息系统数据罪（§285第2款）想象竞合、择一重处断**；但要先看"取得方式"是否真的触犯了 §285。

#### 1. 核心逻辑（极简字诀）

> **「侵入系统窃数据才竞合，登录转移仅盗窃；竞合择一重不并罚，能变现金额大倾向盗窃」**

- **想象竞合**＝**一个行为**同时触犯两个罪名，**只能挑最重的一个定罪、不并罚**（参见 [[刑法-总论-罪数形态模型]]）。

- **§285第2款（非法获取计算机信息系统数据罪）**：违反国家规定，**侵入计算机信息系统或用其他技术手段**，获取系统中存储/处理/传输的数据，情节严重处3年以下；情节特别严重处3–7年。

- **⚠️ 竞合的前提是"取得方式"**：
	- 只有"侵入/非法控制计算机信息系统"获取数据**（如盗号木马、技术手段侵入后台窃取）的行为，才**同时该当 §285②**，与盗窃罪产生**想象竞合、择一重**。

	  - 若行为人**仅凭已知的账号密码正常登录、把虚拟财产转移走**（没有"侵入/非法控制系统"这一动作），一般**径直评价为盗窃罪**，**不必然产生 §285 竞合**。**别把所有盗虚拟财产都套"想象竞合"。**
- 虚拟财产具有**财产属性、可变现流通**的才能评价为"财物"定盗窃；实务中**涉案金额巨大、财产属性明显时倾向定盗窃罪**。（这是**学理与个案判决的通行立场，非两高司法解释明文表述**，标 MEDIUM。）

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王用木马盗号侵入系统转走小李 5 万元游戏装备并变现 —— 想象竞合择一重（倾向盗窃罪）】**
  老王用木马**侵入**小李的游戏账号系统，把账号里价值 5 万元的稀有装备转到自己号上，挂到交易平台卖了 5 万元。
  * **判定**：老王"**侵入系统**窃取虚拟财产"**一个行为**，既该当**盗窃罪**（虚拟装备有财产属性、可变现、5万元数额巨大），又该当**非法获取计算机信息系统数据罪§285②**。二者**想象竞合，择一重处断**；本案金额大、财产属性明显，**实务倾向定盗窃罪**。

* **【案例二：老王凭偷看到的账号密码正常登录、转走 5 万元装备 —— 一般径直定盗窃罪，不必然竞合】**
  老王偷看到小李的账号密码，用这组密码**正常登录**游戏（未侵入/破坏系统），把价值 5 万元装备转到自己号上变现。
  * **判定**：老王没有"侵入/非法控制计算机信息系统"的动作，只是**用已知密码登录转移**——一般**径直评价为盗窃罪§264**，**不必然产生 §285 竞合**。**对照案例一可见：竞合前提是"侵入系统"，单纯登录转移不当然竞合。**

* **【案例三：老王侵入系统窃取一批不可变现、无财产价值的纯数据 —— 定计算机数据罪】**
  老王侵入某公司系统，拷走一批**不能变现、不具备财产价值**的内部数据。
  * **判定**：这批数据没有财产属性、无法评价为"财物"，不该当盗窃罪，按**非法获取计算机信息系统数据罪§285②**论处。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「侵入系统窃虚拟财产＝盗窃与§285竞合、择一重（不并罚）；仅凭密码登录转移＝径直盗窃；能变现、金额大倾向盗窃，纯无价值数据＝§285。」**

> 🎯 **做题眼**：
> 1. "盗窃游戏装备/游戏币/比特币/USDT"，选项里出现"盗窃罪与§285数据罪**数罪并罚**"的**一律排除**（竞合是择一重）；
> 2. **先看取得方式**：题干强调"**侵入/控制系统、木马、技术手段**"的→可能 §285 竞合、择一重；题干是"**用已知账号密码正常登录转移**"的→一般径直定盗窃罪，别硬套竞合；
> 3. 判能否定盗窃，再问"虚拟物有没有财产价值、能不能变现"——能变现且金额大→倾向盗窃罪；纯数据无财产价值→§285数据罪。此为 MEDIUM 级争议点。

## 六、 诈骗·敲诈·抢夺·聚众哄抢模块（§266 / §274 / §267① / §268）

> **教练开场白**
> 讲完抢劫、盗窃，今天收尾"取得型"的另一半——诈骗、敲诈勒索、抢夺、聚众哄抢。这一块是"陷阱密集区"：绝大多数同学的惯性是"被害人把钱交出来了就是诈骗、用了暴力就是抢劫、人多就是聚众哄抢"，凭一个动作贴标签。但命题人挖的坑全在**"被害人为什么把钱交出来"**这条心理线上——是**自愿处分**、还是**基于恐惧被迫交付（但仍有选择余地）**、还是**根本没交是被夺走**？今天用**诈骗五环 → 三角诈骗/机器不能被骗 → 敲诈三界限 → 抢夺与哄抢的"公然"**一次拆穿。

> 🔎 **法条已联网核实**：诈骗罪数额（法释〔2011〕7号第一条）：较大**3000**（3000至1万）、巨大**3万**（3万至10万）、特别巨大**50万**（仅设单一下限，无上限幅度）；该解释共**11条**、2011-04-08施行。敲诈勒索数额（法释〔2013〕10号第一条）：较大**2000**（2000至5000）、巨大**3万**、特别巨大**30万**；为"法释"司法解释、共**9条**、2013-04-27施行。抢夺§267第1款（含"或者多次抢夺"独立入罪）、第2款"携带凶器抢夺依§263定罪处罚"；聚众哄抢§268"数额较大或者有其他严重情节"入罪、**只罚首要分子和积极参加的**。虚假诉讼罪§307之一（"以捏造的事实提起民事诉讼"入罪，第三款"又构成其他犯罪的，依照处罚较重的规定定罪从重处罚"）。
> ⚠️ **诚实标注**："处分意识""三角诈骗处分权限""机器不能被骗"均系刑法学理通说，非司法解释逐字条文，但属法考铁律；诉讼诈骗中"无中生有才构成虚假诉讼罪、部分篡改不构成"系**学理通说/倾向**，非铁律，存争议（详见第二步案例四）。

### 第一步：诈骗罪（§266）——"五环链条"缺一环就不是诈骗

> 命题人专门在中间环节抽掉一环：被害人**没陷入错误**（早识破了只是可怜你给钱）、**没有处分意识**（递东西时根本不知道里面有什么）、**被骗的是机器**——只要缺一环，就不是诈骗，往往掉进盗窃。

#### 1. 核心逻辑（极简字诀）

> **「骗术五连环，缺环非诈骗：诓人入错觉，自愿掏腰包；机器不上当，硬拿算偷盗」**

- **处分意识**＝被害人"心里清楚自己正在把这个财物交出去、并且愿意交"（诈骗与盗窃的分水岭：诈骗是被害人"自己心甘情愿递出来"，盗窃是行为人"自己伸手拿走/夺走"）。

- **诈骗五环（缺一环不成立诈骗）**：

	- ①行为人**虚构事实/隐瞒真相**→
	- ②被害人因此**陷入或维持错误认识**→
	- ③被害人**基于错误认识、带着处分意识作出处分行为**（自愿交付）
	- →④行为人或第三人**取得财产**→
	- ⑤被害人**遭受财产损失**。

- **断环=出局**：

	- 被害人没被骗（识破出于同情给钱）→不构成；

	- 没有处分意识（不知交出去的是啥）→**盗窃罪**；

	- 骗的是机器→**盗窃罪**。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王编假项目，小李自愿打款 8 万 —— 标准诈骗（五环齐全）】**
  老王虚构"内部认购原始股、稳赚不赔"的项目（①欺骗），小李信以为真（②错误认识），主动往老王账户转了 8 万元认购款（③带处分意识自愿处分），老王取得（④），小李血本无归（⑤）。
  * **判定**：五环完整闭合，老王构成**诈骗罪**，8 万元超"数额巨大"起点（3 万元），按数额巨大档处理。**做题眼**：被害人"主动转账/亲手交付"是诈骗的强标志。

* **【案例二：老王调包，小李帮忙看包却被抽走 2 万现金 —— 缺"处分意识"，定盗窃】**
  老王在火车站谎称"帮我看下行李箱"，把自己的空箱托给小李，趁小李低头看手机，老王顺手拎走了小李脚边装着 2 万元现金的背包。
  * **判定**：小李虽"被骗"，但他**对自己那 2 万元背包从没有过"我把它交给老王"的处分意识**——背包被拎走是老王"自己伸手拿"的。**缺了"处分意识"这一环**，老王构成**盗窃罪**（2 万元）。

* **【案例三：小李早识破，出于可怜给了老王 500 元 —— 缺"因果"，诈骗未遂】**
  老王假装重病乞讨，小李一眼看穿是装的（没陷入错误认识），但觉得可怜还是给了 500 元。
  * **判定**：被害人**没有基于错误认识处分**——给钱是出于同情而非上当，因果链断了。老王成立**诈骗未遂**（且 500 元未达数额较大，通常不以犯罪论）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「诈骗是被害人'自己掏'，盗窃是行为人'自己拿'；五环缺处分意识就掉盗窃，骗了机器也掉盗窃。」**

> 🎯做题眼：
>
> 1. 先问"钱是被害人主动交的，还是行为人自己拿/夺的"——主动交且自愿＝诈骗方向；自己拿/夺＝盗窃/抢夺/抢劫方向；
> 
> 2. 被害人"递东西时不知道里面是什么/不知道自己在交付"（看包被调包、刷卡被多刷），凡定"诈骗罪"的，**优先考虑盗窃罪**；
> 
> 3. 看到"骗 ATM / 自动售货机 / 网络后台机器"取财，往**盗窃罪**上想，选"诈骗罪"的先排除。

### 第二步：三角诈骗 vs 盗窃间接正犯 + 机器不能被骗

> 命题人把"受骗的人"和"受损的人"拆成两个人（三角结构），再问：这个"中间被骗的人"到底是有权处分财产的"管家"，还是只是被当枪使的"工具人"？

#### 1. 核心逻辑（极简字诀）

> **「受骗受损非一人，看他有没有处分权+是否基于认识错误：管家受骗仍是骗，工具被使是偷盗；机器铁石不上当，骗机取财算偷盗」**

- **三角诈骗**＝"被骗的人"和"财产受损的人"不是同一个人。判断公式：受骗人 ≠ 受损人时，**要同时满足两层**——

  - **第一层·处分权限/地位**：
	  - 那个"被骗的中间人"必须**有处分权限/地位**（保管员、收银员、占有辅助人、法官），他的"自愿交付"才能等于财产主人的处分 → 成立**诈骗罪（三角诈骗）**；

	  - 若**无处分权限·只是被当工具**（骗路人帮你搬"你的"车、骗不懂事的小孩）→ 行为人成立**盗窃罪（间接正犯）**。

  - **第二层·基于认识错误**：受骗的中间人还须**基于"认识错误"而处分**。**若中间人明知真相（明知无权/明知是骗局）仍配合行为人交付，则不属三角诈骗，按共同犯罪（共犯）处理。**

- **机器不能被骗**：诈骗罪要求"被骗者是有意识的自然人"，机器、ATM、自助设备、电脑后台不会产生"错误认识"。骗机器、利用机器漏洞取财 → 往**盗窃罪**上定。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王伪造提货单骗仓库保管员，拉走老板 50 台电脑（值 25 万）—— 三角诈骗，定诈骗罪】**
  老王伪造一张"总经理授权提货"的单据，交给仓库保管员小李，小李核对单据后（**基于"这是真授权"的认识错误**）帮老王把 50 台电脑（价值 25 万元）装车放行。
  * **判定**：受骗的是保管员小李，受损的是公司，三角结构。小李是公司**受雇看管货物、有权按单放货的人，具有处分地位**，且**基于认识错误**放货——两层都满足。老王成立**诈骗罪（三角诈骗）**，25 万元属"数额巨大"。**对照：若小李明知是假单据、为收老王好处故意放货，则小李与老王构成共同犯罪，而非三角诈骗。**

* **【案例二：老王骗路人小赵"那辆电动车是我的、钥匙丢了"，让小赵帮抬走（车值 4000 元）—— 工具人，定盗窃间接正犯】**
  老王指着停在路边的、其实是别人的电动车（价值 4000 元），骗路过的小赵"这是我的车，帮我抬到三轮车上"，小赵信以为真帮忙抬走。
  * **判定**：小赵确实"被骗"，但他**对这辆车没有任何处分权限/地位，只是被当成搬车的"工具"**。真正车主从头到尾没有"自愿处分"。老王成立**盗窃罪（间接正犯）**，4000 元已达盗窃"数额较大"。

* **【案例三：老王捡到小李银行卡，猜中密码到 ATM 取走 1 万元 —— 骗机器，定盗窃罪】**
  老王捡到小李的银行卡，试出密码，到 ATM 取走 1 万元现金。
  * **判定**：ATM 是机器，**机器不会"陷入错误认识"**，不存在"被骗自愿付款"。在"纯机器取款"法理上倾向定**盗窃罪**（1 万元，达数额较大）。（注：拾得卡到 ATM 用属盗窃模块第三步标注的 MEDIUM 争议点，实务亦有按信用卡诈骗处理者，遇到看题干立场。）

* **【案例四·补充对照：诉讼诈骗——老王伪造借条起诉小李，骗法院判小李还款 30 万 —— 诈骗 + 虚假诉讼罪竞合，依§307之一第三款从一重】**

  老王凭空伪造小李欠他 30 万元的借条，向法院提起民事诉讼，法官被假证据蒙蔽，判小李败诉、强制执行了 30 万。
  * **判定**：被骗的是**法院（法官）**、受损的是小李——法院对当事人财产有依判决处分的权力地位，是典型的**三角诈骗，定诈骗罪§266**。同时，老王"以捏造的事实提起民事诉讼"还构成**虚假诉讼罪§307之一**。

  * **两步走（别一刀切）**：

	  * ①先判是否"**以捏造的事实提起民事诉讼**"——是，构成**虚假诉讼罪§307之一**；

	  * ②再判是否同时**骗取了财产**——是，构成**诈骗罪**；

	  * ③二者竞合时，依**§307之一第三款"依照处罚较重的规定定罪从重处罚"从一重处罚**。**⚠️ 通说/倾向（非铁律·有争议）**：一般认为"无中生有型"（凭空捏造）更典型地构成虚假诉讼罪；"仅部分篡改已有真实债权"是否构成虚假诉讼罪学理上仍有争议，不宜写成无条件结论。**关键以"是否捏造事实提起民事诉讼"为准，而非简单按"无中生有 vs 部分篡改"贴标签。**

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「受骗受损分两人，看中间人有没有处分权+是否基于认识错误——有权且被骗还是骗，无权当工具翻成偷，明知配合是共犯；机器铁石不上当，骗机取财一律偷。」**

> 🎯做题眼：
> 1. "行为人骗 A、让 A 把 B 的东西交出来"的三角结构，分两层问：①A 有没有权处分 B 的财物（保管员/收银员/法官＝有权→诈骗；路人/小孩/精神病人/不知情快递员＝无权当工具→盗窃间接正犯）；②A 是不是**基于认识错误**配合（A 明知真相仍配合＝共犯，不是三角诈骗）；
> 2. ATM / 自助设备 / 机器漏洞取财，选"诈骗罪"的**一律先排除**（倾向盗窃）；
> 3. "伪造证据起诉、骗法院判决取财"：先定虚假诉讼罪§307之一（以捏造事实提起民事诉讼）＋诈骗罪（三角），竞合依**§307之一第三款从一重**，选"数罪并罚"的排除；别把"无中生有才构成虚假诉讼"当无条件铁律。

### 第三步：敲诈勒索罪（§274）——夹在抢劫与诈骗中间的"恐惧交付"

> 命题人卡两条线：往上和**抢劫**比（反抗有没有被完全压垮、有无选择余地），往下和**诈骗**比（交钱是因为"害怕"还是"上当"）。再叠近年大热点：维权高额索赔到底算不算敲诈。

#### 1. 核心逻辑（极简字诀）

> **「敲诈靠'吓'，恐惧才交钱；威胁可待来日、当场胁迫也行，关键被害人尚能选；当场压垮反抗·没得选当场夺，那才是抢劫不是敲」**

- **vs 抢劫（§263）**：抢劫＝**完全压制被害人反抗（被害人没有选择余地）**＋**当场取财**。敲诈＝**未达完全压制反抗、被害人尚有意志选择空间**；威胁**可指向将来、也可当场实施**（"现在不给就天天来堵你"），但只要被害人还能拒绝/报警/讨价，就是敲诈。**分水岭是"反抗压垮没、有无选择余地"，不是"当场还是将来"。**

- **vs 诈骗（§266）**：基于"**错误认识**自愿处分"＝诈骗；基于"**恐惧**被迫交付"＝敲诈。**恐吓+虚假事实并存时，以"恐惧"为主→敲诈**。

- **入罪门槛**：§274 数额较大**2000 元**起，或"多次敲诈勒索"（法释〔2013〕10号：二年内三次以上）独立入罪。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王掌握小李婚外情照片，扬言"不给 5 万就发给你老婆"—— 标准敲诈】**
  老王偷拍到已婚的小李与他人约会的照片，发信息"一周内转我 5 万元，否则把照片发给你老婆和单位领导"。小李害怕家庭破裂，转了 5 万。

  * **判定**：老王用"曝光隐私"恶害相威胁，小李**基于恐惧、为消灾交钱**，威胁指向将来、小李还能选择报警——**敲诈勒索罪**。5 万元超"数额巨大"起点（3 万元）。

* **【案例二：老王半夜持刀顶住小李脖子，当场逼其交出 3000 元 —— 这是抢劫不是敲诈】**
  老王深夜用匕首顶住小李脖子"现在、立刻把身上的钱掏出来，不然捅死你"，小李吓得当场交出 3000 元。
  * **判定**：老王**当场用暴力相威胁、当场取财、小李反抗已被完全压制、毫无选择余地**——这是**抢劫罪§263**。**核心对照：完全压垮反抗+没得选+当场夺＝抢劫；尚能选择（哪怕当场胁迫）＝敲诈。**

* **【案例三：小李喝到一只苍蝇，以"曝光上网"相威胁向饭店索赔 8 万 —— 维权 or 敲诈?（热点）】**

  小李在饭店汤里喝出一只苍蝇（事实存在轻微问题），以"不赔 8 万就把视频发全网、举报到市场监管局让你倒闭"相威胁，索要明显超出实际损失的 8 万。
  * **判定**：
	  * ①若小李**确有受损、在合理维权范围内主张赔偿**（哪怕略高），属民事维权，不构成敲诈；
	* 
	  * ②若小李**以损害事实为筹码、用"曝光/举报"相要挟，索取明显超出合理限度的巨额赔偿、具有非法占有目的**，可能成立**敲诈勒索罪**。法考命题倾向："以维权为名、索赔金额明显畸高、且以恶害相要挟"的，倾向认定敲诈。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「'恐惧'交钱是敲诈，'上当'交钱是诈骗，'反抗被压垮·没得选'交钱是抢劫；敲诈起点 2000、威胁可待来日也可当场、关键被害人还能选。」**

> 🎯做题眼：
> 1. 区分**抢劫 vs 敲诈**："完全压垮反抗+被害人无选择+当场取财"齐全→抢劫；**没压垮反抗、被害人仍能拒绝/报警/讨价（哪怕是当场胁迫）→敲诈**——别看到"当场"就判抢劫；
> 
> 2. 区分**敲诈 vs 诈骗**：只问被害人交钱时心里是"怕"还是"信"：怕→敲诈，信→诈骗；
> 
> 3. "喝出异物/买到假货后，以曝光、举报相要挟索要明显畸高赔偿"，往**敲诈勒索罪**上想；记住敲诈数额较大起点是 **2000 元**（不是诈骗的 3000、不是盗窃的 1000）。

### 第四步：抢夺罪（§267①）与聚众哄抢罪（§268）——"公然夺取"的两种形态

> 抢夺常和"抢劫/盗窃"三角混淆（关键看反抗有没有被压垮），聚众哄抢常考"谁要负刑责"。

#### 1. 核心逻辑（极简字诀）

> **「抢夺乘空夺其物，力施于物不及人；一旦暴力压垮反抗，立马升格变抢劫。聚众哄抢趁乱抢，只罚头目与积极」**

- **抢夺**＝**乘人不备、公然夺取财物**，**暴力只作用于"物"、不直接作用于"人身压制反抗"**（骑车飞抢手机、夺过项链就跑）。

- **聚众哄抢**＝**纠集多人、一拥而上、趁乱公然把财物抢走、瓜分**，不以对特定被害人施加暴力胁迫压制反抗为手段。

- **抢夺 → 抢劫的升格线**：抢夺一旦**把暴力作用于人身、用以压制反抗**（为夺包把人拽倒拖行致伤），就**升级为抢劫罪§263**。（**携带凶器抢夺**依§267第2款**直接拟制为抢劫罪**。）**§267① 除"数额较大"外，还含"或者多次抢夺"独立入罪。**

- **聚众哄抢的主体限定线**：§268 只处罚"**首要分子和积极参加的**"，**一般参加者（凑热闹、被裹挟的）不构成本罪**。入罪门槛为"数额较大或者有其他严重情节"。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王骑摩托飞车夺走小李挂在肩上的包（内有 6000 元）—— 抢夺罪】**
  老王骑摩托，**趁小李不备**一把扯走她肩上的挎包（内有 6000 元）加速逃离，小李被带得趔趄一下但未摔倒受伤。
  * **判定**：老王是乘人不备、公然夺取，力主要作用于"包"、没有为压制小李人身反抗而施暴。构成**抢夺罪§267①**，6000 元已达抢夺"数额较大"。

* **【案例二：老王为夺包将小李拽倒在地拖行致其骨折 —— 升格为抢劫罪】**
  同样夺包，但小李死死攥住包带不放，老王为把包抢到手，**把小李拽倒在地、拖行数米**致手臂骨折，得手逃离。
  * **判定**：老王的暴力**已作用于小李人身、用以压制反抗**（拽倒拖行致骨折）。**抢夺升格为抢劫罪§263**，且致人重伤属抢劫加重情节。**核心对照：力作用于物＝抢夺；力作用于人身、压制反抗＝抢劫。**

* **【案例三：货车侧翻散落苹果，老王带头吆喝、众人哄抢 —— 聚众哄抢罪（只罚头目和积极者）】**
  货车侧翻苹果散落一地。老王第一个吆喝"快来捡啊不要钱"，纠集围观村民一拥而上哄抢，老王本人抢走价值 5000 元苹果，村民小赵积极参与抢了一大袋（价值 2000 元），路过的小钱顺手捡了两个苹果（价值 5 元）。
  * **判定**：
	  * ①老王是**纠集众人的"首要分子"**、小赵是**"积极参加者"**，二人构成**聚众哄抢罪§268**；
	  * ②小钱只是顺手拿两个的**一般参加者，不构成聚众哄抢罪**（顶多治安处罚/退赔）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「抢夺力在物、抢劫力压垮人，一拽倒升格；聚众哄抢趁乱抢，只揪头目和积极，凑热闹的不入罪。」**

> 🎯做题眼：
> 1. **抢夺 vs 抢劫一刀切**：看暴力是否作用于人身以压制反抗——只对物＝抢夺；为压垮反抗对人身施暴＝抢劫。看到"携带凶器抢夺"，直接定**抢劫**（§267②拟制）；
> 2. **聚众哄抢看主体**：凡是"一般参加者/凑热闹者也构成聚众哄抢罪"的，**一律直接排除**；
> 3. 记牢**抢夺 §267① 含"或者多次抢夺"独立入罪**，别只盯"数额较大"。

### 收尾彩蛋：五罪对号入座总表

| 罪名 | 财物怎么转移（核心动作） | 被害人交付的心理 / 是否交付 | 暴力打在哪 / 威胁性质 | 入罪数额起点 | 一眼判 |
|---|---|---|---|---|---|
| **诈骗罪 §266** | 被害人**自愿交付**（有处分意识） | 基于"**错误认识**"自愿处分 | 无暴力，靠"骗" | **3000 元**（巨大3万·特别巨大50万） | 被害人"自己掏"、且是"上当" |
| **敲诈勒索罪 §274** | 被害人**被迫交付** | 基于"**恐惧**"交付、**尚有选择余地** | 恶害相威胁，**可指向将来/也可当场**，未完全压制反抗 | **2000 元**（巨大3万·特别巨大30万） | 被害人"被吓得交"、还能选 |
| **抢劫罪 §263** | 行为人**当场夺取** | 被害人**无选择**、被完全压制 | **当场暴力压垮人身反抗**+当场取财+被害人无选择 | 无数额门槛 | "完全压垮反抗+没得选+当场夺" |
| **抢夺罪 §267①** | 行为人**公然夺取** | 被害人来不及反应、未交付 | 暴力**只作用于"物"**、不压制人身 | **1000 元**，或**多次抢夺** | 力在物、乘人不备夺了就跑 |
| **盗窃罪 §264** | 行为人**平和/秘密转移占有** | 被害人不知情、未交付 | 无暴力（对人无强制） | **1000 元**（含多次/入户/携凶器/扒窃不要求数额） | 行为人"自己拿"、不惊动人 |
| **聚众哄抢罪 §268** | 多人**趁乱公然抢、瓜分** | 被害人难以阻止、未交付 | 趁乱公然夺，不以暴力压制特定人 | **数额较大或严重情节**（只罚首要+积极） | 一拥而上抢、只揪头目和积极者 |

> 🎯 **一眼判总诀**：**"自愿交+上当=诈骗；被迫交+恐惧+还能选=敲诈（当场胁迫也算）；反抗被压垮+没得选+当场夺=抢劫；力在物乘空夺=抢夺；平和秘密自己拿=盗窃；趁乱多人抢=聚众哄抢（只罚头目和积极者）。"**

## 七、 背信型财产罪模块（§270 侵占 / §271 职务侵占 / §272·§273 挪用）

> **教练开场白**
> 前面"取得型"那一组有个共同动作——**打破他人占有、建立自己占有**（东西本来在你那边，我想办法弄到我这边）。可这一组完全反过来：**东西本来就合法在我手上**（我替你保管、我是公司管钱的、我手里就攥着单位的资金），我只是**赖着不还、悄悄据为己有或挪去花**——这叫"**背信**"（你信得过我才把东西交给我，我却辜负了这份信任）。绝大多数同学一看到"占为己有"就条件反射写盗窃，命题人的坑全在这儿：**取财时这东西到底是不是已经合法在你手里了？****2026 顶级增量**——法释〔2026〕6号（2026-05-01 施行）把职务侵占、挪用资金的数额标准**并轨参照贪污罪/挪用公款罪**，旧的"6万/100万""2倍/5倍折算"已经作古，今年必考。这一节用**一条主线＋一张对号入座表**把"侵占／职务侵占／盗窃／贪污"四罪一次切清。

> 🔎 **法条已联网核实**：§270 三款（代管物"拒不退还"／遗忘物·埋藏物"拒不交出"／**绝对亲告罪**，最高刑仅 5 年）、§271 三档法定刑（刑修十一改为 3 档、最高升至无期；第 2 款国有单位人员/委派人员→定贪污罪）、§272 三种用途门槛与三档法定刑——均经多源逐字 CONFIRMED。**2026 增量**：法释〔2026〕6号第八条"职务侵占罪、挪用资金罪定罪量刑标准分别**参照**贪污罪、挪用公款罪定罪量刑标准执行"，2026-04-10发布、**2026-05-01施行**；职务侵占参照贪污罪＝**数额较大3万、巨大20万、特别巨大300万**（援引法释〔2016〕9号）；挪用资金参照**挪用公款罪§384**＝数额较大约**3万**、**特别巨大约200万**（援引挪用公款罪标准·中间档"巨大"具体数账本把握不足，标 **MEDIUM·待核验**，不臆造确数）。
> ⚠️ **诚实标注**：①法释〔2026〕6号是否含**明文废止**旧"6万/100万""2倍/5倍折算"条款未逐字坐实，本模型按"实质取代/后法优于前法"表述（对"实质已废"的置信度为 MEDIUM）；②挪用资金参照挪用公款罪的"巨大"中间档具体数字账本把握不足，标 MEDIUM，按现有诚实风格留待核验，不写死。

### 1. 核心逻辑（极简字诀）

> **「合法到手再翻脸，是侵占；管钱靠权吞了它，是职务；只挪不吞图周转，是挪用——四罪先问东西到底在不在我手里」**

- **「合法到手再翻脸，是侵占」**（§270 侵占罪）：
	- "**变合法持有为非法占有**"（东西本来就**正大光明在我手上**——你托我保管的、你落在我这儿的、我挖出来的埋藏物），我后来起贪心**赖着不还/不交**。
	- 与盗窃的根本区别——盗窃要"**打破他人占有**"，侵占则是"**我先已合法占有**"。
	- 
	- 对象只限三种：**代为保管的他人财物 / 他人的遗忘物 / 埋藏物**；入罪硬要件是"**拒不退还**"（代管物）或"**拒不交出**"（遗忘物·埋藏物）；§270 第 3 款规定它是**绝对亲告罪**。法定最高刑只有 5 年，无第三档。

- **「管钱靠权吞了它，是职务」**
	- （§271 职务侵占罪）：核心分水岭是"**利用职务上的便利**"（我**主管、管理、经手**本单位财物的**权限**）。
	- 跟盗窃的分界是"**靠权还是靠机会**"——靠"主管/管理/经手"的**职务权限**侵吞＝职务侵占；只是"熟悉环境、有进出机会"的**劳务/工作便利**顺手拿走＝盗窃。
	- 再往上跟**贪污罪**分界看**主体**：国家工作人员（或国有单位委派人员）利用职务便利侵吞＝**贪污罪**（§271第2款明文移送§382/§383）；普通公司企业职员＝**职务侵占罪**。**【2026 并轨】**数额标准参照贪污罪：数额较大 **3 万**、巨大 **20 万**、特别巨大 **300 万**。

- **「只挪不吞图周转，是挪用」**
	- **（§272 挪用资金罪）：与侵占类罪的区别在**主观目的**——侵占/职务侵占是"**永久占为己有、不打算还**"，挪用是"**暂时挪去用一下、心里还想着还**"。三种用途门槛**互不相同**：
		- ①挪去**归个人使用/借给他人**，"超 3 个月未还"（数额较大）；
		- ②挪去搞**营利活动**（数额较大、**不受 3 个月限制**）；
		- ③挪去搞**非法活动**（**不受时间限制**、门槛更低）。
		- 三档法定刑：数额较大→3 年以下；数额巨大→3-7 年；数额特别巨大→7 年以上。**【2026 并轨新规】**标准**参照挪用公款罪§384**执行：
		  - **数额较大起点**：进行非法活动为 **3 万元**，进行营利活动或超 3 个月未还为 **5 万元**；
		  - **数额巨大起点**：进行非法活动为 **300 万元**，进行营利活动或超 3 个月未还为 **200 万元**。
		- **穿透认定规则（解释第九条）**：虚构付款事由、应收账款不入账等逃避单位监管的方式将本单位资金供其他单位使用的，认定为“以个人名义将单位资金供其他单位使用”（属于“归个人使用”）。
		- **混合主体共犯规则**：国家工作人员与非国家工作人员共同挪用本单位资金，利用了国家工作人员 the 职务便利定挪用公款罪共犯；利用了非国家工作人员 the 职务便利定挪用资金罪共犯。

- **「四罪先问东西到底在不在我手里」**：总开关——东西取财时已**合法在我手里**才进背信组（侵占/职务侵占/挪用）；东西还在**别人控制下、我去拿的**，回取得型那一组（盗窃）。

### 2. 大白话讲解（完整数字案例）

用老王（行为人）、小李（被害人）、老张（第三人）演五个对照案例：

* **【案例一：老王替小李保管 8 万元名表，到期赖着不还 —— 侵占罪 §270 第 1 款】**
  小李出国前把价值 8 万元的名表交给老王代为保管，说好半年后取。半年后小李回国索要，老王谎称"早丢了"，**死活不还**，自己偷偷戴上了。
  * **判定**：这块表**从一开始就是小李亲手、合法交到老王手上的**——老王是"**合法持有**"。老王起贪心、**拒不退还**，构成**侵占罪§270 第 1 款**，数额 8 万属"数额较大"以上。①这**不是盗窃**——表早就在老王手里，没有任何"打破"动作；②**绝对亲告罪**——只有小李自己去法院**自诉**才处理。
  > 🔧 对比："拒不退还"是**代管物**用语；若换成老王在出租车上**捡到**小李遗忘的这块表（遗忘物）后据为己有，则适用 §270 第 2 款、要件改成"**拒不交出**"。

* **【案例二：老王是仓库保管员凭钥匙私运货物变卖 15 万 vs 清洁工小李顺手牵羊一台 1 万的电脑 —— 职务侵占 §271 vs 盗窃 §264】**
  老王是某民营公司**仓库保管员**，手握库房钥匙、负责出入库登记。他利用这个**职务权限**，私自把本单位 15 万元的货物运出变卖；同公司**清洁工小李**趁打扫之机顺手把同事桌上一台 1 万元的笔记本电脑揣走。
  * **判定**：老王对货物有"**主管/管理/经手**"的职务权限，**靠权**吞掉单位财物——构成**职务侵占罪§271**（15 万元属"**数额较大**"——参照贪污罪标准，数额较大为 **3 万元以上不满 20 万元**，处 **3 年以下**有期徒刑或拘役）。小李对那台电脑**没有任何职务上的支配权限**，只是"趁工作机会"——**靠机会、不靠权**，构成**盗窃罪§264**。**一句话切**：库管私吞＝职务侵占；清洁工顺手牵羊＝盗窃。
  > 🔧 档位演示：若老王私运的货物价值 **25 万元**，则 25 万∈[20 万, 300 万)＝"**数额巨大**"——参照贪污罪，数额巨大为 **20 万元以上不满 300 万元**，处 **3 年以上 10 年以下**有期徒刑。15 万（较大）与 25 万（巨大）一线之隔，别把"较大"的区间安到"巨大"头上。

* **【案例三：同样侵吞 15 万单位款，老王是国企财务科长 vs 私企会计 —— 贪污罪 §382 vs 职务侵占罪 §271】**
  老王利用经手单位资金的职务便利，侵吞本单位 15 万元。
  * **判定**：如果老王是**国有公司的财务科长**（国家工作人员）——定**贪污罪**（§271第2款明文依§382/§383处理）；如果老王只是**民营私企的会计**——定**职务侵占罪§271第1款**。**同样的动作、同样的金额，仅因主体身份不同而罪名不同。**并轨之后两罪的"数额较大/巨大/特别巨大"门槛现在是**一样的数字**了——但**罪名、移送条文仍按主体身份分开**。

* **【案例四：村主任老王占 30 万征地补偿款 vs 占 30 万村集体鱼塘承包款 —— 贪污罪 vs 职务侵占罪】**
  村委会主任老王利用职务便利，占有了 30 万元。
  * **判定**：
	  * ①这 30 万是**国家拨下来的征地补偿款**（老王在此是"**协助人民政府从事行政管理**"——土地征用补偿费用管理属全国人大常委会解释列明的**七项**之一），他**以国家工作人员论**，定**贪污罪**；
	
	  * ②这 30 万是**村集体自己鱼塘的承包款**（管的是村集体**日常自治事务**），定**职务侵占罪**。**一刀切**：占的是"协助政府的那七项款物（救灾/抢险/防汛/优抚/扶贫/移民/救济款物、社会捐助款物、国有土地经营管理、征地补偿费、代征代缴税款、计生户籍征兵、其他协助政府行政管理）"＝贪污；占的是"村集体日常事务的钱"＝职务侵占。（具体关于村委会人员侵吞财产之身份与业务性质界分，详见增补考题：[[刑法-分论-财产犯罪-单选-60 · 职务侵占罪与贪污罪界分之“村委会成员双重身份与业务性质”案 V2]]）

* **【案例五：老王把单位 10 万挪去炒股 vs 挪去赌博 —— 挪用资金罪 §272 的"营利 vs 非法"门槛】**
  私企出纳老王利用职务便利，挪用本单位 10 万元。
  * **判定**：
	  * ①挪去**炒股（营利活动）**——成立**挪用资金罪**，数额达 5 万即构罪（**不受 3 个月限制**）；
	  * ②如果只是挪去**借给朋友周转、没拿去营利也没干违法事**——则要"**超过 3 个月未还**"且达 5 万才入罪；
	  * ③如果挪去**赌博（非法活动）**——数额达 3 万即可成立（**不受时间限制**，门槛最低）。
	  * **关键**：挪用资金的本质是"**只挪不吞、还想还**"——如果老王从一开始就打定主意**永远不还、做平账吞掉**，那就不是挪用，而是**职务侵占**。

  > 🔧 主体/对象再分一刀：国家工作人员挪公款＝**挪用公款罪§384**；普通职员挪本单位资金＝**挪用资金罪§272**；挪救灾抢险等**特定款物**且**归公家单位用**（不是归个人）＝**挪用特定款物罪§273**。（具体关于村委会人员/私营组织人员挪用身份界定与归公用、归私用区别，详见增补考题：[[刑法-分论-财产犯罪-单选-55 · 挪用资金罪与挪用公款、挪用特定款物罪界分案 V2]] 与 [[刑法-分论-财产犯罪-单选-58 · 挪用资金罪与挪用公款、挪用特定款物罪之私营公益组织款项挪用界分案 V2]]）

### 3. 一句话闭环记忆 + 🎯做题眼

> **「东西先在我手里，赖着不还是侵占（亲告·5年封顶）；靠职务权限吞单位，普通职员职务侵占、国家工作人员贪污（2026 同为 3万/20万/300万）；只挪不吞图周转是挪用，营利非法各有门槛——四罪先问占有，再问靠权、再问身份、最后问吞还是挪。」**

> 🎯 **做题眼**：
> 1. **先问"取财时东西在不在行为人手里"**：凡出现"代为保管/受托保管/捡到（遗忘物）/挖到（埋藏物）/已经合法持有"再据为己有的，**一律先往侵占/职务侵占/挪用这一组定，排除盗窃**；
> 
> 2. "侵占罪"题，凡选项写"公诉机关/检察院可主动追诉""被害人撤诉后法院仍应判决"的，**一律直接排除**——§270 是**绝对亲告罪**；
> 
> 3. 职务侵占/挪用资金的数额一律用 2026 新账本：职务侵占参照贪污罪＝**3万/20万/300万**；挪用资金参照挪用公款罪＝较大**3万（非法）/5万（营利/超3月）**，巨大**200万（营利/超3月）/300万（非法）**。凡出现旧口径"6万/100万"或"按贪污罪 2倍/5倍折算"的，**一律直接排除**；
> 
> 4. **"靠权 vs 靠机会"一眼判**：有"主管/管理/经手"权限的（库管、会计、出纳）凭权侵吞＝职务侵占；只有"工作机会、熟悉环境"而无财物处分权的（清洁工顺手牵羊）＝盗窃；
> 
> 5. **"吞 vs 挪"一眼判**：打算永久占有、做平账不还＝侵占/职务侵占；只是临时挪用、主观上还想还＝挪用资金§272。

## 八、 毁弃·拒付模块（§275 故意毁坏财物 / §276 破坏生产经营 / §276之一 拒不支付劳动报酬）

> **教练开场白**
> 侵犯财产罪学到收尾这三个罪，命题人换了个角度挖坑——这三个罪的行为人**根本不想把东西据为己有**：故意毁坏财物是"我得不到、也让你用不了"；破坏生产经营是"我看你不顺眼，砸你机器、害你赔本"；拒不支付劳动报酬是"我有钱就是不给农民工发工资"。大多数同学最容易栽的三个坑是：
> 
> ①把"毁坏"当成必须砸烂——其实把戒指扔进大海、放飞笼中的鸟，**东西完好无损也算"毁坏"**；
> ②看到老板赖账逃跑就直接定拒不支付劳动报酬罪——其实**没经过政府部门责令支付这一关，逃了也不构罪**；
> ③把任何破坏生意的行为都往破坏生产经营罪上套——其实主观上必须是"泄私愤"。今天用**"毁不占·泄私愤·先责令"**这条线一次理清。

> 🔎 **法条已联网核实**：§275 故意毁坏财物（数额较大/有其他严重情节→3年以下；数额巨大/有其他特别严重情节→3年以上7年以下）；立案门槛**5000元**出自《立案追诉标准（**一**）》（公通字〔2008〕36号）**第33条**——注意是"规定（**一**）"不是"规定（二）"。§276 破坏生产经营（"泄愤报复或者其他个人目的"毁坏机器设备、残害耕畜或以其他方法破坏生产经营，3年以下；情节严重3年以上7年以下）；最高检官网刊文明确"反向刷单、恶意好评"可解释为本罪"其他方法"。§276之一 拒不支付劳动报酬（刑修八新增），司法解释为**法释〔2013〕3号**（标题"**审理**"非"办理"，2013-01-23施行，共9条）。
> ⚠️ **诚实标注**：①"5万元数额巨大"多为**各省高院/检的本地区执行标准（地区裁量）**，全国性立案标准只硬性规定 5000 元入罪门槛，讲义若把"5万元数额巨大"说成全国统一硬数额并不准确；②法释〔2013〕3号第6条三阶从宽逐字、破坏生产经营罪与§286竞合规则缺一手规范文件，正文按"通说/最高检刊文/倾向认定"措辞处理，未拔高为硬性法条结论。

### 第一步：故意毁坏财物罪 vs 盗窃罪——"是否建立新的占有"

> 命题人故意设计"东西没了但行为人一分钱没得到""东西完好无损但被害人再也用不了"这类反直觉情形，专坑只会按"东西在不在"判断的考生。

#### 1. 核心逻辑（极简字诀）

> **「占为己有是盗窃，毁不占有是毁坏；砸不砸烂都不论，丧失效用即'毁坏'」**

- 两罪分水岭只有一条——行为人有没有**建立对财物的新占有（即"非法占有目的"）**。盗窃就是要这个；故意毁坏财物罪**恰恰相反，行为人不要这东西，只想让被害人也得不到/用不成**。

- 法律上的"**毁坏**"有两种——**物理毁损**（砸碎、烧毁、摔坏）与**价值/效用毁损**（东西本身完好无损但对被害人已经没用了：把钻戒扔进大海、把鸟笼里的鸟放飞、把鱼塘的鱼放跑）。**不要求东西"碎掉"**。

- "**先毁后窃""盗后毁弃"**：一个案子里既有毁坏又有占有的，按**行为人最终对财物建立没建立占有**分段判断。
- **达 5000 元立案线**  ，单独不构成故意毁坏财物罪，作为盗窃的情节评价。若被砸财物达 5000 元以上，则盗窃罪与故意毁坏财物罪分别成立、数罪并罚。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王把小李的手机扔进河里 —— 故意毁坏财物罪】**
  老王和小李吵架，一气之下抢过小李价值 6000 元的手机扔进河里，手机沉底找不回来。老王自己一分钱、一样东西都没拿到。
  * **判定**：老王**没有建立对手机的新占有**，只是让小李丧失了手机——典型的故意毁坏财物。损失 6000 元已超 5000 元立案线，成立**故意毁坏财物罪§275**，不是盗窃罪。

* **【案例二：老王半夜把小李鱼塘的鱼全放跑 —— 价值/效用毁损也算"毁坏"】**
  老王嫉妒邻居小李养鱼挣钱，半夜偷偷打开小李鱼塘的闸门，把价值 8 万元的成鱼全部放进大河，鱼游走无法收回。老王没捞走一条鱼。
  * **判定**：鱼一条没"碎"，但对小李而言**效用彻底丧失**——这就是"价值/效用毁损"，通说成立故意毁坏财物罪。老王没把鱼据为己有（不是偷鱼卖钱），所以**不是盗窃罪**。

* **【案例三：老王先撬保险柜偷走 5 万，再泄愤砸烂柜子 —— "盗后毁弃"分阶段定性】**
  老王撬开小李办公室保险柜拿走里面 5 万元现金（已据为己有），临走又把价值 4000 元的保险柜砸烂泄愤。
  * **判定**：拿走 5 万元现金＝**建立了新占有**，定**盗窃罪**；砸保险柜＝毁坏，但保险柜价值 4000 元**未达 5000 元立案线**，单独不构成故意毁坏财物罪，作为盗窃的情节评价。若被砸财物达 5000 元以上，则盗窃罪与故意毁坏财物罪分别成立、数罪并罚。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「想要它＝盗窃（占为己有），不想要它只想毁了它＝故意毁坏财物；砸烂是毁坏，扔海、放鸟、放鱼让东西没用了，照样是毁坏。」**

> 🎯做题眼：
> 1. 行为人**把财物据为己有/拿去卖钱**的，定盗窃；行为人**没拿走、东西被弄坏/弄丢/放跑、自己一分没得**的，往**故意毁坏财物罪§275**上靠；
> 2. 凡说"把戒指扔海/放飞笼中鸟/放跑鱼塘鱼**因为东西没损坏所以不构成故意毁坏财物罪**"的选项，**一律直接排除**；
> 3. 立案/数额纠纷题：看到"全国统一规定故意毁坏财物数额巨大为5万元"的表述要警惕——全国硬标准只有 **5000 元入罪门槛（《立案追诉标准（一）》第33条）**，5万元多是地区标准。

### 第二步：破坏生产经营罪——"泄私愤"＋"其他方法"的口袋边界

> 命题人挖两个坑：一是主观上必须是"泄愤报复或其他个人目的"，纯为赚钱的非法竞争不算；二是"其他方法"虽已扩张到网络（反向刷单等），但同时干扰计算机系统时会与§286竞合，要"择一重"。

#### 1. 核心逻辑（极简字诀）

> **「泄私愤、害生意，机器耕畜其他法；网络刷单也能算，撞上§286择一重」**

- **主观必须出于"泄愤报复或者其他个人目的"**（私人恩怨、报复、嫉妒）。**反向排除**：纯粹为了赚钱/抢市场的非法经营、不正当竞争，不构成本罪。

- 行为方式＝**毁坏机器设备、残害耕畜、或者以其他方法**破坏生产经营。

- **"其他方法"网络化扩张**：最高检官网刊文认定，店铺的**销量、信誉**是网络空间里的生产经营资料，"**反向刷单、恶意好评**"造成经营损失的，可解释为本罪"其他方法"——与"残害耕畜、毁坏机器设备"具有同质性。但要防止"其他方法"被无限扩大成口袋罪。

- **撞上§286择一重**：上述网络手段如果**同时侵入、干扰了计算机信息系统功能**，就既该当破坏生产经营罪（§276）又该当**破坏计算机信息系统罪（§286）**，二者**想象竞合、择一重处断**。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王报复前东家，半夜砸毁车间机器 —— 典型破坏生产经营罪】**
  老王被工厂开除，怀恨在心，深夜潜回车间用大锤砸毁 3 台数控机床（价值 15 万元），导致工厂停产 7 天。
  * **判定**：主观是"**泄愤报复**"，客观毁坏机器设备破坏生产经营——成立**破坏生产经营罪§276**（情节严重，3年以上7年以下档）。

* **【案例二：老王给竞争对手刷 2000 单虚假订单致其被平台降权 —— "其他方法"的网络扩张】**
  老王开网店，嫉妒同行小李销量比自己高，雇人给小李店铺恶意下单 2000 笔再集中退款（反向刷单），触发平台风控，小李店铺被降权、销量暴跌，3 个月损失 12 万元。

  * **判定**：老王主观是"**泄愤＋报复性打击同行**"的个人目的，客观用"反向刷单"这一"**其他方法**"破坏小李的网络生产经营，倾向认定**破坏生产经营罪**。若刷单手段**同时侵入/干扰平台计算机系统功能**，则与破坏计算机信息系统罪§286想象竞合，**择一重处断**。

* **【案例三：老王为自己多卖货低价倾销挤垮对手 —— 不构成本罪】**
  老王为抢占市场份额，把自己的产品长期亏本低价销售，导致同行小李经营困难。
  * **判定**：老王主观是"**为自己营利、抢市场**"，**不是泄愤报复或其他个人目的**——属市场竞争（可能涉不正当竞争的行政/民事问题），**不构成破坏生产经营罪**。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「破坏生产经营先看心里——是'泄私愤报复'才入罪，是'纯赚钱抢市场'就出罪；砸机器、害耕畜、网络反向刷单都算'其他方法'，撞上破坏计算机系统罪就择一重。」**

> 🎯做题眼：
> 1. "破坏他人生意"的题，**先抓主观**：强调"报复、泄愤、嫉妒、私人恩怨"的→破坏生产经营罪；强调"为自己牟利、抢占市场、不正当竞争"的→**直接排除本罪**；
> 
> 2. 网络手段（反向刷单/删改数据/DDoS）破坏生意的，倾向定破坏生产经营罪；题干点明"侵入/破坏了计算机信息系统功能"的，选"与§286想象竞合择一重"；
> 
> 3. 别把破坏生产经营罪和故意毁坏财物罪记混：针对"生产经营"且出于"泄私愤"→§276；单纯毁损财物、不针对生产经营→§275。

### 第三步：拒不支付劳动报酬罪——"经政府责令仍不支付"是入罪命门

> 命题人最大的陷阱：本罪有一道**法定前置程序**——必须先经过政府有关部门责令支付、行为人仍不支付，才构罪。没有这道关，逃得再彻底也不构成本罪。

#### 1. 核心逻辑（极简字诀）

> **「逃薪不是马上判，先经政府'责令'关；有钱不给或逃匿，公诉前付可减免」**

- **法定入罪前置程序**：罪状明确要求"**经政府有关部门责令支付仍不支付**"。即欠薪逃跑本身还**不够**定罪，必须**人社部门或政府其他部门先依法下了"限期整改指令书/行政处理决定书"等文书责令付钱、在指定期限内仍不付**（法释〔2013〕3号第4条），刑事这条线才算接上。**未经责令，即使逃匿欠薪，也不构成本罪**。

- **行为方式限定**：①"以转移财产、逃匿等方法逃避支付"；或②"有能力支付而不支付"。**反向排除**：**单纯没钱付（确实无力支付）的，不入罪**。

- **从宽阶梯**：尚未造成严重后果，在**提起公诉前**支付报酬并依法承担相应赔偿责任的，**可以减轻或者免除处罚**（法释〔2013〕3号第6条还有"立案前付清→可不追究、一审宣判前付→可从轻"的三阶递减从宽）。

- **数额较大两档**（法释〔2013〕3号第3条）：①拒付**1名**劳动者**3个月以上**报酬且数额在**5000元至2万元以上**；②拒付**10名以上**劳动者报酬且累计在**3万元至10万元以上**。

#### 2. 大白话讲解（完整数字案例）

* **【案例一：老王转移财产玩失踪，但人社部门还没责令 —— 暂不构成本罪】**
  包工头老王拖欠 15 名农民工工资共 8 万元，把账户上的钱转给亲戚后关机失踪。农民工刚去人社局投诉，人社局**尚未下达任何责令支付的文书**。
  * **判定**：老王虽有"转移财产、逃匿"的行为、欠薪数额也达标，但**法定前置程序"经政府有关部门责令支付仍不支付"还没走完**——此刻**尚不构成拒不支付劳动报酬罪**。

* **【案例二：老王经人社局责令后仍不付，被查时已逃避 —— 成立本罪】**
  接上例，人社局向老王送达《限期整改指令书》责令其 7 日内支付，老王在指定期限内仍拒不支付、继续躲藏。15 名农民工、8 万元，已达"10名以上、累计3万至10万元以上"标准。
  * **判定**：欠薪数额达标＋以逃匿方法逃避支付＋**经政府责令仍不支付**——三要件齐全，成立**拒不支付劳动报酬罪**（3年以下，并处或单处罚金）。

* **【案例三：老王在检察院起诉前付清了 8 万元工资 —— 可减轻或免除处罚】**
  接上例，案件移送审查起诉后、检察院**提起公诉之前**，老王筹钱付清了全部 8 万元工资并依法承担相应赔偿责任，尚未造成严重后果。
  * **判定**：符合法释〔2013〕3号第6条"**提起公诉前支付且依法担责→可以减轻或者免除处罚**"的从宽情形（付得越早从宽越多：立案前付→可不追究；公诉前付→可减免；一审宣判前付→可从轻）。

#### 3. 一句话闭环记忆 + 🎯做题眼

> **「欠薪逃跑还不够，政府'责令'是命门——经责令仍不付才入罪；有钱赖账/转移逃匿才罚，真没钱不罚；公诉前付清可减免。」**

> 🎯做题眼：
> 1. 欠薪题**第一刀先找"政府有关部门责令支付"这道程序**：题干**没出现人社/政府部门责令**的，说"已构成拒不支付劳动报酬罪"的选项**一律直接排除**；
> 
> 2. 区分"有能力不付"和"无力支付"：强调"转移财产、有钱躲账、逃匿"→构罪；强调"经营亏损确实拿不出钱"→不构罪；
> 
> 3. 司法解释文号别记错：是**法释〔2013〕3号**，标题"**审理**"（不是"办理"）。

## 命题人最爱的陷阱合集

> 把跨模块的高频坑汇总成清单，考前扫一遍。每条都标"正解"。

1. **遗忘在出租车/宾馆的财物 → 司机/管理者占有 → 第三人拿走定盗窃（不是侵占）**；但司机/清洁工本人据为己有、拒不交出才定侵占。
2. **封缄物：抽取内容物＝盗窃，连箱带物整体吞掉＝侵占。**
3. **死者占有两分支**：杀人者当场/紧接取财＝死者占有延续定盗窃（与故意杀人并罚）；行为人事后另起意返回取财、或无关第三人事后取走＝脱离占有物按侵占处理。
4. **携带凶器抢夺拟制抢劫§267② 的前提是"抢夺本身已成立（达数额较大或多次）"**；光携凶不抢夺、或抢夺未达数额且非多次的，不拟制。**携带凶器盗窃 ≠ 拟制抢劫**——只是§264新型盗窃入罪门槛（立法逻辑：携凶抢夺升高人身危险才升格，携凶盗窃只是门槛）。
5. **14-16 周岁盗窃/诈骗/抢夺后施暴不转化抢劫**——只就重伤/死亡单独定故意伤害/故意杀人罪（轻伤不构罪）。满 16 才转化。
6. **机器不能被骗 → 骗 ATM/自助机/利用机器漏洞取财定盗窃，不定诈骗**；但"**拾得他人信用卡到 ATM 等机器使用**"存在 MEDIUM 争议（"机器不能被骗"倾向盗窃 vs 实务倾向信用卡诈骗），对柜员/营业员用则无争议定信用卡诈骗。
7. **真军警利用真实身份抢劫 ≠ "冒充军警人员抢劫"加重**——按抢劫基本犯从重。
8. **入户盗窃被发现后转化抢劫 ≠ "入户抢劫"加重**——入户时目的非抢劫。
9. **为劫财/制服反抗而杀人＝抢劫一罪不并罚；抢完为灭口而杀人＝抢劫罪与故意杀人罪数罪并罚。**
10. **抢劫 vs 敲诈的分水岭是"反抗有没有被完全压垮、被害人有无选择余地"，不是"当场还是将来"**——当场胁迫但被害人仍可拒绝/报警/讨价的，是敲诈不是抢劫。
11. **维权高额索赔**：实际受损、合理范围、正常协商＝民事维权；以损害为筹码、用曝光/举报相要挟、索赔明显畸高＋非法占有目的＝敲诈勒索。
12. **诈骗 vs 敲诈**：交钱那一刻被害人心里是"看走眼（错误认识）"＝诈骗，还是"我怕（恐惧）"＝敲诈——不数题干里有几句吓唬话。
13. **三角诈骗 vs 盗窃间接正犯**：被骗的中间人有处分权（保管员/法官）+基于认识错误＝诈骗；无处分权只被当工具（路人/小孩）＝盗窃间接正犯；中间人明知真相仍配合＝共犯。
14. **盗窃信用卡并使用＝盗窃罪（§196③）；拾得/骗取信用卡使用、只偷卡信息网上用＝信用卡诈骗罪（拾得卡对 ATM 机器用＝MEDIUM 争议）。**
15. **盗虚拟财产**：侵入/控制系统窃取才与§285想象竞合、择一重（不并罚）；仅凭已知密码登录转移一般径直定盗窃，不必然竞合。
16. **职务侵占 vs 盗窃**：靠"主管/管理/经手"职务权限吞＝职务侵占；只靠工作机会/熟悉环境顺手拿＝盗窃。
17. **职务侵占/挪用资金数额（2026新规）**：职务侵占参照贪污罪＝3万/20万/300万（15万＝较大、25万＝巨大，别错位）；挪用资金参照挪用公款罪＝较大约3万、特别巨大约200万（中间"巨大"档 MEDIUM）；凡"6万/100万""2倍/5倍折算"旧口径一律排除。
18. **侵占罪是绝对亲告罪**：不告不理、纯自诉，无转公诉口子。
19. **抢夺§267①、敲诈§274 都含"多次"独立入罪**（多次抢夺；二年内三次以上敲诈），别只盯数额较大。
20. **故意毁坏财物立案 5000 元出自《立案追诉标准（一）》第33条**，不是"规定（二）"；"5万元数额巨大"是地区标准，非全国硬数额。
21. **拒不支付劳动报酬罪未经"政府责令支付"不构罪**；司法解释是法释〔2013〕3号、标题"审理"。
22. **数额起点别串台**：盗窃较大1000、敲诈较大2000、诈骗较大3000；诈骗特别巨大只设单一下限50万（无上限幅度）。
23. **抢劫两份规则是"法发"指导意见**（法发〔2005〕8号/法发〔2016〕2号），不是"法释"；勿与海事"法释〔2016〕2号"、贪污旧解释"法释〔2016〕9号"混。

## 案例演练

> 7 个综合案例，每个标"例/仿真题"+ governing 法条 + 模型分析（走第几步）。出处均为自拟教学案例，未编造任何"某年司考/法考真题"。

### 例 1（仿真题）：老王持刀逼小李交手机
- **案情**：老王深夜持刀抵住小李脖子，喝令交出价值 6000 元手机，小李吓得当场交出。
- **governing 法条**：§263。
- **模型分析**：总决策树第一步占有转移（取得型）→ 第二步第一刀"完全压制反抗·当场取财·被害人无选择" → **抢劫罪基本犯§263**（3年以上10年以下）。

### 例 2（仿真题）：老王翻窗入室盗窃被发现、当场打小李逃跑
- **案情**：老王（20岁）翻窗进小李家偷 5000 元，被回家的小李撞见，为抗拒抓捕当场打小李一拳逃走。
- **governing 法条**：§269（依§263定罪）。
- **模型分析**：抢劫模块第三步——前提罪盗窃（达数额较大）＋当场施暴＋抗拒抓捕目的，三要件齐 → **转化抢劫§269**；但入户时目的是盗窃，**不评价为"入户抢劫"加重**（陷阱合集第8条）。若行为人是15岁，则不转化，只就暴力的重伤/死亡结果单独定罪。

### 例 3（仿真题）：老王在出租车上顺走前一位乘客遗忘的手表
- **案情**：小李把价值 2 万元手表落在出租车后座，下一位乘客老张发现后悄悄塞进口袋下车。
- **governing 法条**：§264。
- **模型分析**：盗窃模块第一步占有归谁判——手表遗忘在出租车这一司机管理空间，**占有已转移给司机**，老张打破司机占有 → **盗窃罪§264**（不是侵占罪，陷阱合集第1条）。

### 例 4（仿真题）：老王伪造提货单骗保管员放走 50 台电脑
- **案情**：老王伪造"总经理授权提货"单据交仓库保管员小李，小李核对后帮老王装车放行价值 25 万元的 50 台电脑。
- **governing 法条**：§266。
- **模型分析**：诈骗模块第二步——三角结构，受骗人小李是有处分地位的保管员、且基于认识错误放货，其"自愿放货"等于公司处分 → **诈骗罪（三角诈骗）§266**，25 万属数额巨大。若小李明知是假单据仍配合＝共犯；若骗的是无处分权的路人帮搬车，则为盗窃间接正犯。

### 例 5（仿真题）：老王凭空伪造借条起诉小李、骗法院判还款 30 万
- **案情**：老王凭空伪造小李欠他 30 万的借条提起民事诉讼，法官被假证据蒙蔽判小李败诉、执行 30 万。
- **governing 法条**：§266 + §307之一第三款。
- **模型分析**：诉讼诈骗两步走——①"以捏造的事实提起民事诉讼"构成**虚假诉讼罪§307之一**；②同时骗法院判决取财、被骗的是有处分地位的法院，构成**诈骗罪§266（三角诈骗）**；③二者竞合依§307之一第三款**从一重处罚**（不是数罪并罚、也不是一律按诈骗）。

### 例 6（仿真题）：仓库保管员老王私运货物 vs 清洁工老张顺走电脑
- **案情**：民企仓库保管员老王利用钥匙、出入库登记权限私运本单位 15 万元货物变卖；清洁工老张趁打扫顺走同事桌上 1 万元电脑。
- **governing 法条**：老王§271（参照贪污罪标准·法释〔2026〕6号）；老张§264。
- **模型分析**：背信型模块——老王"靠职务权限"吞单位财物 → **职务侵占罪§271**（15 万属"**数额较大**"——参照贪污罪标准 3 万以上不满 20 万，处 3 年以下；25 万才到"数额巨大"档）；老张"靠工作机会、无财物处分权" → **盗窃罪§264**。若老王是国企财务人员，则升为贪污罪§382。

### 例 7（仿真题）：老王把鱼塘鱼全放跑 vs 偷鱼卖钱
- **案情**：情形A：老王嫉妒小李养鱼，半夜放跑其鱼塘价值 8 万元成鱼、自己一条没捞。情形B：老王半夜捞走小李鱼塘价值 8 万元成鱼卖掉。
- **governing 法条**：A 定§275；B 定§264。
- **模型分析**：毁弃模块第一步——A 老王**没建立新占有**（鱼游走、自己分文未得），是"价值/效用毁损" → **故意毁坏财物罪§275**（8 万元，已过 5000 元立案线）；B 老王**据为己有变现**（建立新占有） → **盗窃罪§264**（8 万元，数额巨大）。同一鱼塘，"放跑"还是"捞走卖钱"决定毁坏还是盗窃。
