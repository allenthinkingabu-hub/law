# 📐 非法证据排除程序流转 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。上一节讲了"什么该排"（实体标准），这一节讲"**怎么排、走什么程序排**"。绝大多数同学有两个惯性：一是以为"排非只能上了法庭才提"；二是以为"被告人得自己证明遭了刑讯"。命题人正是拿这两个惯性挖坑——**排非贯穿侦查、审查起诉、审判三个阶段，侦查阶段就能申请**；而且**证明取证合法的责任在控方（检察院），不是让辩方去证明被刑讯**，辩方只要提供"线索或材料"就能启动。
> 破解就三句话：**「三阶段都能排、发现即排（§56③）」、「申请只要给线索或材料，合法性由控方证（§58/§59）」、「重大案件终结前先核查、开庭前应开庭前会议、庭审当庭决定不质证（规程§4/§28、庭前会议规程§2②）」**。
> 今天用**一张"侦查→起诉→审判"三阶段排非流程轴＋一张黑话对号入座表＋三大程序关卡**把这块程序考点走通。

## 适用场景与解决问题

本模型覆盖 [[刑诉-刑事证据制度-深度报告]] 第二板块的**程序类考点（考点4侦查终结前核查、考点5申请线索材料、考点6庭前会议、考点7庭审调查质证、考点8三阶段贯穿）**。凡题干出现"何时能申请排非""申请要提供什么""谁来证明取证合法""侦查终结前核查""应否召开庭前会议""庭审如何调查、被排证据能否质证""排除后能否作起诉依据"等，立即调用本模型。

- **三阶段贯穿（§56③）**：排非**不是审判阶段专属**——**侦查、审查起诉、审判**各阶段发现有应当排除的证据的，都应依法排除；排除后**不得作为起诉意见、起诉决定和判决的依据**。
- **申请与线索材料（规程§8＋2017排非规定）**：**侦查阶段即可申请**排非；申请须提供**线索**（涉嫌非法取证的人员、时间、地点、方式等）**或材料**（伤情照片、体检记录、讯问录音录像、同监人证言等）；**空泛指控、无线索材料**的不予启动。
- **证明责任在控方（§59）**：启动后，证据收集**合法性由公诉人证明**——**不是**让辩方证明"被刑讯"；控方证不到确实充分即排（衔接§60）。
- **侦查终结前核查（规程§4）**：可能判处**无期徒刑、死刑**等重大案件，侦查机关在**侦查终结前**应**书面通知**驻看守所检察人员开展**讯问合法性核查**。
- **庭前会议（庭前会议规程§2②）**：开庭前当事人及辩护人**申请排非并提供线索材料**的，**应当召开庭前会议**了解情况、听取意见；但**排非的最终决定权在庭审**。
- **庭审调查与质证（规程§28）**：法庭对合法性调查后**当庭作出是否排除的决定**；**被排除的证据不得出示、宣读、质证、作为定案根据**；合法性调查期间**不停止对其他事实的审理**。

> **核心一句**：**「排非三阶段通用、发现即排；辩方给线索/材料就能启动，合法性控方证；重大案终结前核查、开庭前应开庭前会议、庭审当庭定、被排证据不质证」**。

> 🔎 **法条已联网核实（2026-07-05 · 最高法公报／中国政府网）**：刑诉法§56第三款（三阶段贯穿）、§58（当事人申请与法庭调查）、§59（公诉人证明合法性）系现行法；**《办理刑事案件排除非法证据规程》法发〔2024〕12号**§4（重大案件侦查终结前讯问合法性核查）、§8（申请排非的线索或材料）、§28（庭审调查后当庭决定、被排证据不得质证）逐条核实无误；**《办理刑事案件庭前会议规程》§2**（申请排非有线索材料的应当召开庭前会议）核实无误。

> ⚠️ **易记错点（勿望文生义）**：①**排非不是审判专属**，侦查、审查起诉阶段发现即排（§56③）；②**侦查阶段就能申请**排非，不必等到庭审；③**合法性证明责任在控方**（§59），辩方只需提供线索或材料，不承担"证明被刑讯"的责任；④**庭前会议只是"了解情况、听取意见"**，排非**最终决定在庭审**（庭前会议达不成一致的留庭审解决）；⑤**被排除的证据不得出示、质证**，但合法性调查期间**不停止**对其他证据的审理。

> **适用真题**：[[刑诉-证据-多选-18 · 非法排除程序启动的线索与材料要件辨析|多选-18]]（线索材料要件）、[[刑诉-证据-多选-48 · 侦查阶段排非申请与线索释明要件及举证责任倒置|多选-48]]（侦查阶段申请＋控方举证）、[[刑诉-证据-多选-55 · 李某案辩护律师侦查阶段申请排除非法证据的正确路径辨析|多选-55]]（侦查阶段申请路径＋申诉救济）（全部 11 道见文末对照表）。
>
> **姊妹模型**：📐 [[刑诉-证据-非法证据排除实体标准]]（什么该排/什么可补的实体标准）· [[刑诉-证据-重复性供述排除模型]]（重复供述连带排除与例外）——本模型只管"**怎么申请、走什么程序排**"。

## 一、 "侦查 → 审查起诉 → 审判"三阶段排非流程轴

```
 ┌─────────────侦查阶段─────────────┬────审查起诉阶段────┬──────────审判阶段──────────┐
 │ · 嫌疑人/辩护律师可申请排非(侦查即可)│ · 检察院审查·可排除  │ · 开庭前：申请排非+线索材料      │
 │ · 须提供线索或材料(非空泛指控)      │ · 发现即排(§56③)    │   → 应当召开庭前会议(了解/听取意见)│
 │ · 重大案(无期/死刑)侦查终结前：     │ · 撤回非法证据       │ · 庭审：法庭调查合法性           │
 │   书面通知驻所检察核查讯问合法性(§4)│                     │   → 当庭作出是否排除决定(§28)     │
 │                                    │                     │   · 被排证据不得出示/宣读/质证/定案│
 │                                    │                     │   · 调查期间不停止审理           │
 └────────────────────────────────────┴─────────────────────┴────────────────────────────┘
        ★贯穿三阶段(§56③)：任何阶段发现应排除的证据→依法排除；
          排除后不得作为"起诉意见、起诉决定、判决"的依据
        ★证明责任(§59)：取证合法性由控方(公诉人)证明；辩方只需提供线索或材料
```

> **一句话总诀**：**「三阶段都能排、发现即排；辩方给线索/材料启动、合法性控方证；重大案终结前核查、开庭前开庭前会议、庭审当庭定不质证」**。

## 二、 黑话 → 人话 对号入座表

| 黑话术语 | 翻成人话 | 对号入座（一句话定位） |
| :--- | :--- | :--- |
| **三阶段贯穿** | 排非不是只有法庭能干，**侦查、起诉、审判都能排** | 侦查/审查起诉发现刑讯证据也要排 |
| **线索或材料** | 申请排非得给点**由头**——说清谁、何时、何地、怎么非法取证，或拿出伤情照片/体检/录像 | 空喊"我被刑讯了"不给线索→不启动 |
| **证明责任在控方** | 是不是合法取证，**由检察院来证明**，不是让被告人证明挨了打 | 控方证不清白→排除 |
| **侦查终结前核查** | 重大案子（可能判无期死刑）**在结案前**，先请驻所检察官查一遍讯问合不合法 | 侦查机关书面通知驻所检察 |
| **应当召开庭前会议** | 开庭前提了排非又给了线索材料的，**法官必须先开个庭前会议** | 了解情况、听取意见（不是最终裁决） |
| **当庭作出决定** | 庭审查完合法性，**当场拍板**排不排 | 排除的证据不许再出示质证 |
| **不停止审理** | 查这份证据合法性时，**别的证据照常审**，不停摆 | 合法性调查与其他审理并行 |

## 三、 三大程序关卡（每关：字诀 + 先懂几个词 + 数字案例 + 🎯做题眼）

> 拿到一道排非程序题，别凭"感觉哪个阶段该干啥"，按下面三关走：先定"谁在哪个阶段、怎么启动、谁举证"，再看"侦查终结前核查＋三阶段贯穿"，最后看"庭前会议与庭审调查"。

### 第一关：申请、线索材料与证明责任 —— 盯死"侦查即可申请""控方举证"

> **教练提示**：一看到"排非"，绝大多数同学下意识觉得"那得上法庭才提""被告人得自己拿出被刑讯的证据"。命题人专卡两个点：**侦查阶段就能申请**（不必等庭审）；**证明取证合法的责任在控方**，辩方只需给"线索或材料"就能启动——但**空泛指控不行**，得说清人、时、地、方式或拿出伤情/录像等材料。

> # 侦查阶段即可申请；给线索或材料就启动（非空泛指控）；合法性控方证

- **先懂几个词**：
	- **申请主体与阶段**＝犯罪嫌疑人、被告人及其**辩护律师**，**侦查阶段就可以**申请排除非法证据，不必等到审判；
	- **线索**＝指向非法取证的**具体由头**——涉嫌非法取证的**人员、时间、地点、方式**等（"某月某日在某看守所被某人殴打"）；
	- **材料**＝能初步印证的**客观东西**——伤情照片、体检记录、讯问录音录像、同监室人员证言等；
	- **空泛指控**＝只喊"我被刑讯了"却**说不清人、时、地、方式，也拿不出材料**——**不予启动**；
	- **证明责任（§59）**＝启动后，证据收集**合法性由公诉人（控方）证明**，**不是**让辩方去证明"确实被刑讯"；控方证不到确实充分→排（§60）。

- **判"能不能申请、何时申请"**：侦查阶段即可；主体含嫌疑人/被告人及辩护律师。
- **判"启动够不够格"**：有**线索或材料**（说清人时地方式/拿出伤情录像）→启动；**空泛指控**→不启动。
- **判"谁举证"**：合法性由**控方**证明；辩方不承担"证明被刑讯"的责任。

#### 大白话讲解

##### 🔍 对号入座表：排非申请，启动 vs 驳回

| 情形 | 是否合格 | 结论 |
| --- | --- | --- |
| 提供伤情照片、体检记录、血衣 | 有材料 | **启动** |
| 说清"某日某地某人以某方式刑讯" | 有线索 | **启动** |
| 只说"我被刑讯了"，无人时地方式、无材料 | 空泛指控 | **不启动** |
| 侦查阶段律师提出排非申请 | 侦查即可申请 | **可以提** |
| 要求被告人自证遭刑讯 | 举证责任错置 | **错**（合法性控方证） |

##### 💰 完整数字案例：侦查阶段申请排非的正确路径（[[刑诉-证据-多选-55 · 李某案辩护律师侦查阶段申请排除非法证据的正确路径辨析|多选-55]]／[[刑诉-证据-多选-48 · 侦查阶段排非申请与线索释明要件及举证责任倒置|多选-48]]）

> **案情**：李某涉嫌犯罪，其辩护律师认为侦查机关存在刑讯。律师**在侦查阶段**即向办案机关**提出排除非法证据的申请**，并提供了李某的**伤情照片与体检记录**（线索材料）；办案机关未答复的，律师可依法**向上一级或同级检察机关申诉/控告**（救济）。进入审查起诉后，律师可**查阅讯问录音录像**。
>
> - 排非**侦查阶段即可申请**（不必等庭审）；
> - 提供**伤情照片、体检记录**＝合格的线索材料，足以启动；
> - 合法性由**控方证明**，控方证不清→排；
> - 不予答复的，有**申诉/控告**救济渠道。
>
> 👉 记住三点：侦查能申请、给材料就启动、合法性控方证。**答案 ABD。**

#### 一句话闭环记忆

> 🎯 **一眼判**：排非**侦查阶段就能申请**；辩方给**线索或材料**（人时地方式/伤情录像）即启动，**空泛指控不启动**；合法性**证明责任在控方**。把"排非只能庭审提""被告人须自证被刑讯""空喊被刑讯即启动"的——**排除**。

### 第二关：侦查终结前核查 + 三阶段贯穿 —— 盯死"发现即排、排后不作三层级依据"

> **教练提示**：一看到"排非"，很多同学以为是审判阶段的专利。命题人专卡这条——**排非贯穿侦查、审查起诉、审判**，任何阶段发现应排除的证据都要排，而且排除后连"起诉意见书、起诉决定、判决"都不能拿它当依据；重大案子还要在**侦查终结前**先做一道讯问合法性核查。

> # 排非贯穿三阶段·发现即排；排后不作起诉意见/起诉决定/判决依据；重大案终结前核查

- **先懂几个词**：
	- **三阶段贯穿（§56③）**＝**侦查、审查起诉、审判**任一阶段发现有应当排除的证据的，都应**依法排除**——排非不是审判专属；
	- **排除后不作三层级依据**＝被排除的证据**不得作为起诉意见（侦查机关）、起诉决定（检察院）、判决（法院）的依据**；
	- **侦查终结前核查（规程§4）**＝**可能判处无期徒刑、死刑**等重大案件，侦查机关在**侦查终结前**，应**书面通知**驻看守所检察人员，开展**讯问合法性核查**；
	- **审查起诉阶段的排除**＝检察院审查中发现非法证据可**排除、撤回**（如 [[刑诉-证据-多选-32 · 顾某诈骗案中重复性供述法庭排除与阶段转化规则|多选-32]] 中检察机关撤回非法证据）。

- **判"哪个阶段能排"**：侦查/审查起诉/审判**都能**，发现即排。
- **判"排除的效果"**：不得作为**起诉意见、起诉决定、判决**依据（三层级）。
- **判"重大案件"**：可能判无期/死刑的，**侦查终结前**书面通知驻所检察核查讯问合法性。

#### 大白话讲解

##### 💰 完整数字案例：批捕/侦查阶段就该排（[[刑诉-证据-多选-47 · 审查逮捕中非法证据核查与纠正及重复供述排除|多选-47]]）

> **案情**：某案在**审查逮捕**环节，检察机关发现侦查取证存在刑讯，遂进行**核查并提出纠正意见**；对刑讯所得供述及其未阻断的重复供述予以排除。
>
> - 排非**不必等到审判**——审查逮捕/审查起诉阶段发现即可核查、纠正、排除（§56③）；
> - 检察机关有**监督纠正**职责，不能推给法庭；
> - 若属可能判无期/死刑的重大案件，侦查终结前还应有**讯问合法性核查**（规程§4）。
>
> 👉 排非是"全程在线"的，任何阶段发现都要处理，排除后连起诉意见、起诉决定、判决都不能用它。

#### 一句话闭环记忆

> 🎯 **一眼判**：排非**贯穿侦查/审查起诉/审判**、发现即排，排除后**不作起诉意见/起诉决定/判决依据**；重大案（无期/死刑）**侦查终结前**书面通知驻所检察核查。把"排非只能审判阶段"的——**排除**。

### 第三关：庭前会议与庭审调查 —— 盯死"应当召开""当庭决定""被排不质证"

> **教练提示**：一看到"庭前会议能不能把非法证据直接排掉"，很多同学以为庭前会议就能拍板。命题人专卡这里——**庭前会议只是"了解情况、听取意见"，排非的最终决定权在庭审**；而庭审查完合法性要**当庭作决定**，被排除的证据**不得再出示质证**，但合法性调查期间**不停止**对其他证据的审理。

> # 有线索材料应开庭前会议（了解听取，非终局）；庭审当庭定、被排不质证、不停审

- **先懂几个词**：
	- **应当召开庭前会议（庭前会议规程§2②）**＝开庭前，当事人及辩护人**申请排非并提供了线索或材料**的，法庭**应当召开庭前会议**，就排非等问题**了解情况、听取意见**；
	- **庭前会议的效力**＝是**准备/沟通**程序——对能达成一致的可确认，**达不成一致的留待庭审解决**，排非的**最终决定权在庭审**；
	- **当庭作出决定（规程§28）**＝法庭对证据收集合法性**调查后当庭**作出是否排除的决定；
	- **被排证据不得质证**＝被决定排除的证据，**不得出示、宣读、质证，不得作为定案根据**；
	- **不停止审理**＝证据合法性**调查期间**，对案件其他事实与证据的**审理不停止**。

- **判"要不要开庭前会议"**：开庭前申请排非**且**有线索材料→**应当召开**。
- **判"庭前会议能否终局排除"**：不能——**了解、听取意见**为主，最终排非**在庭审**决定。
- **判"庭审如何处理"**：调查后**当庭决定**；被排证据**不得出示质证**；调查期间**不停止审理**。

#### 大白话讲解

##### 🔍 对号入座表：排非各环节的"权限边界"

| 环节 | 能干什么 | 不能干什么 |
| --- | --- | --- |
| **庭前会议** | 了解情况、听取意见、组织展示线索材料 | **不能终局裁决排除**（留庭审） |
| **庭审调查** | 对合法性调查、**当庭决定**是否排除 | —— |
| **被排除证据** | —— | 不得出示、宣读、**质证**、作定案根据 |
| **合法性调查期间** | 其他证据事实**继续审理** | 不因调查而**停止审理** |

##### 💰 完整数字案例：庭前会议 + 庭审的分工（[[刑诉-证据-多选-32 · 顾某诈骗案中重复性供述法庭排除与阶段转化规则|多选-32]]）

> **案情**：顾某案开庭前，辩护人申请排非并提供了线索材料，法庭**召开了庭前会议**了解情况、听取控辩意见；庭前会议未能就排非达成一致，遂**留待庭审**，法庭调查合法性后**当庭作出排除决定**，被排除的供述**不再出示质证**，判决对排非作出说理。
>
> - 有申请＋线索材料→**应当召开庭前会议**（了解、听取意见）；
> - 庭前会议**不终局裁决**，排非最终由**庭审当庭决定**；
> - 被排证据**不得质证**、不作定案根据；判决须**说理**。
>
> 👉 庭前会议是"热身沟通"，庭审才"拍板"，被排的证据从此退出法庭。

#### 一句话闭环记忆

> 🎯 **一眼判**：开庭前申请排非**有线索材料**→**应当召开庭前会议**（了解/听取意见、非终局）；庭审调查后**当庭决定**，被排证据**不得出示质证**，调查期间**不停止审理**。把"庭前会议直接排除定案""被排证据仍可质证"的——**排除**。

| 关 | 干什么 | 🎯 一眼判 |

| **一 申请与举证** | 谁、何时、怎么启动、谁证明 | **侦查即可申请**；给**线索或材料**启动（非空泛指控）；合法性**控方证** |

## 五、 主观题万能说理模板

### 模板一：三阶段与证明责任
> "依刑诉法§56第三款，非法证据排除**贯穿侦查、审查起诉、审判**全过程，任一阶段发现应当排除的证据均应依法排除，且排除后不得作为起诉意见、起诉决定和判决的依据。依§58、§59，当事人及其辩护人**在侦查阶段即可申请**排除非法证据，只需提供涉嫌非法取证的线索（人员、时间、地点、方式）或材料（伤情、体检、录音录像等）；证据收集**合法性的证明责任在于公诉人**，控方不能证明至确实、充分的，应予排除。"

### 模板二：庭前会议与庭审调查
> "依《庭前会议规程》§2及《办理刑事案件排除非法证据规程》（法发〔2024〕12号）§28，开庭前当事人及辩护人申请排非并提供线索材料的，**应当召开庭前会议**了解情况、听取意见，但排非的最终决定权在庭审；法庭对证据收集合法性调查后**应当当庭作出是否排除的决定**，被排除的证据**不得出示、宣读、质证，不得作为定案根据**，且合法性调查期间**不停止**对其他事实的审理。此外，可能判处无期徒刑、死刑等重大案件，侦查机关应在侦查终结前书面通知驻看守所检察人员开展讯问合法性核查（规程§4）。"

## 六、 典型考题演练

### 1. 线索材料要件（[[刑诉-证据-多选-18 · 非法排除程序启动的线索与材料要件辨析|多选-18]]／[[刑诉-证据-多选-42 · 申请非法证据排除程序启动线索与材料要件|多选-42]]）

- **模型应用**：第二关。批捕/侦查阶段发现即核查、纠正、排除，检察监督不推脱。
