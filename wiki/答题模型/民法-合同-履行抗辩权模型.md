# 📐 履行抗辩权（§525-528）+ 易混抗辩权辨析 · 答题模型

> 凡"互负债务、一方先不给 / 怕对方给不了，能不能拒绝 / 中止履行"题，按这三步走。
> **⚠️ 范围提示**：本模型主讲**双务合同三大履行抗辩权**（§525-528）；并附带辨清两个最爱被混进来的"邻居"——**先诉抗辩权（§687·保证）**与**时效抗辩（§192）**，三者**不是一家**（见下「易混辨析」）。完整抗辩体系树 → [[抗辩]]。
> **适用真题**：[[典型合同-多选-18|多选18·先付款方行不安抗辩]] · [[典型合同-多选-19|多选19·撤销后双向返还同时履行]] · [[合同通则-单选-16|单选16·先诉作干扰→不安]] · [[典型合同-多选-08|多选08·先诉抗辩权丧失]]
> 🔎 **法条核实（2026-06-11，3 路联网 + 对抗复核）**：§525–§528、**§687（先诉抗辩权 + 4 丧失情形）** 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对全部 CONFIRMED；双向返还同时履行另引[最高法《合同编通则解释》法释〔2023〕13号 §25](https://www.court.gov.cn/fabu/xiangqing/419382.html)。
> ⚠️ **考频说明**：司法部自 2018 年起**不公布真题及频次**，星级为**机构 / 学理研判**。

## 一、核心考情

- **考频**：★★★★（机构研判）。三大抗辩权是合同履行核心高频；《合同编通则解释》（2023）新增"双向返还同时履行"等规则后热度叠加。
- **命题核心**：把三种抗辩权**适用前提**（有无先后顺序、谁是权利人）混在一起，再用"对方好像要赖账"诱你滥用不安抗辩。**辨析三权 + 不安抗辩的'确切证据'红线**是命门。
- **三大必考点**：①同时履行 §525（无先后）②先履行 / 后履行 §526（有先后，后履行方拒绝）③不安抗辩 §527-528（先履行方自保）。

## 二、万能三步模型

### 第一步：先问"有没有先后履行顺序"

**铁则**：
- **没有先后顺序、应同时履行** → **同时履行抗辩权（§525）**：一方在对方履行之前 / 对方履行不符约定时，**有权拒绝**其（相应）履行请求。
- **有先后顺序** → 进第二、三步（区分你是"后履行方"还是"先履行方"）。

**老王小李例子**
- 同时履行 §525：一手交钱一手交货、没说谁先 → 小李不给钱，老王**有权先不交货**（你不掏钱我不发货）。

### 第二步：有先后顺序——你是"后履行方"→ 后履行抗辩权（§526）

**铁则**：有先后顺序，**应先履行的一方未履行 / 履行不符约定**的，**后履行一方有权拒绝**其（相应）履行请求（§526）。
> 📌 **正名**：§526 学理正称"**后履行抗辩权**"（权利人是后履行方）；"先履行抗辩权"是俗称，法考两名称均认。

**老王小李例子**
- 后履行抗辩 §526：约定老王先发货、小李收货后付款。老王没发货 → 小李**有权拒绝付款**（你没先发，我不先付）。

### 第三步：有先后顺序——你是"先履行方"遇险 → 不安抗辩权（§527-528）

**铁则**：
- **§527 中止条件**：应先履行的一方，有**确切证据**证明对方有四情形之一 → 可**中止履行**：①经营状况严重恶化；②转移财产、抽逃资金以逃避债务；③丧失商业信誉；④**丧失或者可能丧失**履行债务能力的其他情形。
  - ⚠️ **红线**：**没有确切证据**就中止履行的，**自己反而构成违约**（§527 末句）——最高频陷阱。
- **§528 中止之后**：应**及时通知**对方；对方**提供适当担保**的 → **恢复履行**；中止后对方在**合理期限内既未恢复履行能力、又未提供适当担保**的 → **视为以自己的行为表明不履行主要债务**，中止方**可以解除合同并可以请求**对方承担违约责任。
  - 🔗 **衔接**：此处"解除"本质是**默示预期违约**（落 [[民法-合同-解除模型|§563②]]），其解除程序（§565 通知）/ 后果（§566 返还赔偿）由 [[民法-合同-解除模型]] 接力；"中止"的横向辨析（vs 终止 / 解除）+ 另一种"公用事业欠费中止"（§654）→ [[民法-合同-中止模型]]。

**老王小李例子**
- 不安抗辩 §527：小李先付款、老王后交货。付款前小李拿到**确切证据**——老王把厂房机器都偷偷转移了（②抽逃逃债）→ 小李**可中止付款**。
- §528 后续：小李中止后**通知**老王；老王**拿出担保**（如找人保证）→ 小李**得恢复付款**；老王在合理期限内**既不恢复也不担保** → 小李**可解除合同 + 可请求违约责任**。
- ⚠️ 红线：小李只是"听说老王最近手头紧"（无确切证据）就停付 → **小李自己违约**。

### ➕ 拓展：合同无效 / 撤销后的"双向返还"也能主张同时履行

**铁则**：合同**不成立 / 无效 / 被撤销 / 确定不发生效力**后，**双方互负返还义务**的，一方主张**同时履行**的，**人民法院应予支持**——依[最高法《合同编通则解释》§25]，这是**司法解释明文 + 裁判规则**（不再是单纯"学理类推"），主观题可直接援引。

**老王小李例子**
- 买卖被撤销 → 老王退钱、小李退货，两个返还义务**对等无先后** → 任一方都可说"**你不还我也先不还**"（同时履行）。

## ⚖️ 易混辨析：先诉抗辩权 & 时效抗辩（别和履行抗辩权混）

> 学生最爱把这三个"抗辩权"混成一锅。**一句话分清**：履行抗辩权是"**双务合同两方**"的事；先诉抗辩权是"**保证三方**"的事；时效抗辩是"**时间到了**"的事。完整体系树见 [[抗辩]]。

### A. 先诉抗辩权（§687）——属"保证"，**不是**履行抗辩权

**保证只有两种方式（§686），区别就在"先诉抗辩权"：**

| 维度               | 一般保证                                            | 连带责任保证             |
| ---------------- | ----------------------------------------------- | ------------------ |
| **先诉抗辩权**        | **有**（§687）——须先告 / 先执行债务人，不足才找保证人               | **无**（§688）        |
| 能否**直接**找保证人     | **不能**（先收拾债务人）                                  | **能**（债务人一违约即可直接找） |
| 责任性质             | **补充**责任                                        | **连带**责任           |
| 保证债务诉讼时效起算（§694） | **先诉抗辩权消灭之日**（担保解释§28：终本裁定送达债权人之日；旧"裁决生效之日"已废止） | **请求保证人**之日        |
| 2021 默认推定（§686）  | 没约定 / 约定不明 → **一般保证**                           | 仅**明确约定**才是        |

> 一句话：**一般保证＝"先收拾债务人，不行再找我"；连带保证＝"债务人和我随便找"。**

**铁则**：**一般保证**的保证人，在主合同纠纷**未经审判 / 仲裁**、且就**债务人财产强制执行仍不能履行**前，**有权拒绝**向债权人担责（又称检索抗辩权 / 顺序利益）。
- **4 种丧失情形（§687 Ⅱ）**，命中任一即不能再挡、债权人可直接找保证人：① 债务人**下落不明且无财产**可供执行；② 法院已**受理债务人破产**；③ 债权人**有证据证明**债务人财产**不足清偿 / 丧失履行能力**；④ 保证人**书面**放弃。

**🚗 实际案例（债权人老王 — 债务人小李 — 保证人老赵）**
- 老王借给小李 10 万，老赵作保证但**没写**哪种 → 默认**一般保证**（§686）。到期小李不还，老王直接找老赵 → 老赵亮出**先诉抗辩权**："你**先去告小李、强制执行小李的财产**；确实执行不出来，再回头找我"（§687）。这就是"先诉 / 检索"——债权人得先拿债务人"过一遍筛子"。
- 🆚 若白纸黑字写的是**连带责任保证** → 老赵**没有**先诉抗辩权，小李一违约，老王可**直接**找老赵要钱（§688）。
- 老赵这张牌**何时失效**（§687 Ⅱ 四情形）：①小李跑路又无财产可执行 ②法院已**受理小李破产** ③老王有**证据**证明小李财产不够还 ④老赵当初**书面**放弃——任一出现，老王即可直接找老赵。

> 📌 **考题参照** → [[典型合同-多选-08|C2-多选-08]]（一般保证人先诉抗辩权**丧失的 4 情形**，答 **AC**）：A 债务人失踪 + 无财产 → 丧失 ✅；C 已受理破产 → 丧失 ✅；**B** 移居国外但**国内有房**（仍有可执行财产）→ **未**丧失 ❌；**D** **口头**放弃（非书面）→ **未**丧失 ❌。完整保证规则 → [[民法-合同-保证模型]]。

### B. 时效抗辩（§192）——永久性抗辩权，且"不喊就输"
- 诉讼时效届满 → 债务人取得**永久**拒绝履行的抗辩权（§192）；但**必须当事人主张**，法院**不得依职权**适用（§193）——忘了喊，照判还钱。

### C. 三者一表辨清

| 维度 | 履行抗辩权（§525-528） | 先诉抗辩权（§687） | 时效抗辩（§192） |
|---|---|---|---|
| 所在关系 | **双务合同**（两方对待给付） | **保证**（债权人—债务人—保证人 三方） | 任何债 |
| 谁享有 | 合同一方当事人 | **一般保证人** | 债务人 |
| 内容 | "你没履行→我拒绝 / 中止我这边" | "你**先去收拾债务人**，再来找我" | "**过时效了**，我永久不还" |
| 效力 | 延期性（条件成就即不能再挡） | 延期性（4 情形之一即丧失） | **永久性**，但须主张（§193） |

> 🚩 命题套路：双务买卖题里塞一个"**先诉抗辩权**"当**干扰项**（如[[合同通则-单选-16|单选-16]] 的 A）——只要不是保证关系，先诉抗辩权一律排除。

## 三、命题人最爱的 6 个陷阱
1. **无确切证据就中止履行** —— 错！§527 末句：**自己构成违约**。
2. **不安抗辩 = 直接解除** —— 错！先**中止 + 通知**；要等"合理期限内未恢复且未担保"**才能解除**（§528）。
3. **把同时履行 / 后履行 / 不安抗辩混用** —— 看**有无先后顺序 + 你是先还是后履行方**对号入座。
4. **§528 写成"解除合同并请求违约责任"** —— 原文是"**可以**解除合同**并可以**请求"（任择主张），主观题须照搬。
5. **以为双向返还不能主张同时履行** —— 错！《合同编通则解释》§25：法院**应予支持**。
6. **把"先诉抗辩权"当履行抗辩权** —— 错！先诉抗辩权（§687）只属**一般保证人**（保证三方关系），双务合同题里出现它必是**干扰项**（[[合同通则-单选-16|单选-16]] 的 A）。
