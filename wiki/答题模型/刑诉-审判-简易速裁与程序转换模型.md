# 📐 简易程序·速裁程序·程序转换 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。简易、速裁是一审的"快车道"，命题人最爱在这里挖**"适用条件、绝对排除、审限、独任"四组数字**的坑——尤其把简易和速裁的门槛混着考。破解的窍门是**"两快车道并排对比"**：
> - **简易**：任何刑期都能走（但超3年要合议），要求"被告人认罪、对适用没异议"；
> - **速裁**：只走"**可能判3年以下**"的小案，要求"**认罪认罚**"，而且**不开法庭调查辩论、一律独任**；
> - **绝对排除**：速裁比简易**多两条**（未成年人、辩护人作无罪辩护）；
> - **审限**：简易20日、速裁10日；走不下去就**转换**（速裁→简易/普通、简易→普通），转换后**审限重算**。
> 今天用**一张"能不能上快车道"决策流＋一张简易/速裁对比大表**把这块高频数字题一次锁死。

## 适用场景与解决问题

本模型覆盖 [[刑诉-审判程序-深度报告]] 第一板块**简易速裁类考点（考点2简易适用与期限、3简易绝对排除、4速裁适用与期限、5速裁绝对排除、6速裁简化审理、7程序转换）**。凡题干出现"能否适用简易/速裁""哪些情形绝对不能适用""审限多少天""要不要开庭调查辩论""独任还是合议""转普通程序审限怎么算"等，立即调用本模型。

- **简易程序适用（§214）**：**基层法院**管辖 + 案件**事实清楚、证据充分** + 被告人**承认所犯罪行、对指控事实无异议** + 被告人**对适用简易程序无异议**。**无刑期上限**（但可能判超3年的须组成合议庭；3年以下可独任可合议）；**公诉人应当出庭（§216）**。
- **简易绝对排除（§215）四类**：①盲、聋、哑人，或尚未完全丧失辨认/控制能力的精神病人；②有**重大社会影响**的；③**共犯中部分被告人不认罪或对适用简易有异议**的；④其他不宜适用的。
- **速裁程序适用（§222）**：**基层法院**管辖 + **可能判处3年以下**有期徒刑 + 事实清楚证据充分 + 被告人**认罪认罚、同意适用速裁**。**一律独任**审判。
- **速裁绝对排除（§223）**：在简易四类基础上**多两条**——**未成年人**（一般排除）、**辩护人作无罪辩护**的；另含重大社会影响、共犯有异议、未达成和解调解协议等。
- **速裁简化审理（§224）**：**不受送达期限限制**；**一般不进行法庭调查、法庭辩论**；但判决宣告前**应听取辩护人意见和被告人最后陈述**；**当庭宣判**。
- **审限**：简易**§220=20日**（可能判超3年的延至**1个半月**）；速裁**§225=10日**（可能判超1年的延至**15日**）。
- **程序转换（解释§368/§375/§376）**：速裁可转**简易或普通**，简易可转**普通**；转换后**审判期限重新起算**。

> **核心一句**：**「简易＝认罪无异议、任何刑期（超3年合议）、公诉人出庭、20日；速裁＝认罪认罚、3年以下、一律独任、不开调查辩论、10日；速裁排除比简易多'未成年+无罪辩护'；走不了就转、审限重算。」**

> 🔎 **法条口径**：刑诉法§214（简易适用）、§215（简易排除）、§216（简易公诉人出庭）、§217（简化审理）、§220（简易审限）、§222（速裁适用）、§223（速裁排除）、§224（速裁简化）、§225（速裁审限）+ 最高法解释§368/§375/§376（程序转换·上位报告🆕2026-07-06联网订正）。

> ⚠️ **易记错点（数字/条件必背）**：①**简易无刑期上限**（超3年须合议，别误以为"简易只能判3年以下"）——那是速裁；②**速裁一律独任、不开法庭调查辩论**，简易仍有（简化的）调查辩论、可独任可合议；③**速裁绝对排除比简易多"未成年人"和"辩护人作无罪辩护"**；④**简易程序公诉人应当出庭（§216）**，别误为"简易不出庭"；⑤审限：**简易20日/超3年1.5月、速裁10日/超1年15日**；⑥**转换后审限重新起算**，不接续计算。

## 一、 "能不能上快车道"决策流

```
                 【一审案件，能走简易/速裁的快车道吗？】
                                 │
        基层法院管辖？事实清楚证据充分？──否──► 普通程序
                                 │是
        被告人认罪 + 对适用无异议？──否──► 普通程序
                                 │是
   ┌─────────────────────────────┴─────────────────────────────┐
   可能判处3年以下 + 认罪认罚 + 同意速裁？              仅"认罪、无异议"（刑期不限）
   （速裁通道）                                       （简易通道）
        │                                                 │
   过§223绝对排除关？                              过§215绝对排除关？
   （比简易多：未成年人、辩护人无罪辩护）              ①盲聋哑/未完全丧失辨控精神病人
        │否→速裁：一律独任·不开法庭调查辩论            ②重大社会影响 ③共犯有异议 ④其他不宜
        │    ·10日(超1年→15日)·当庭宣判                    │否→简易：可独任(≤3年)/合议(>3年)
        │沾→排除，走简易或普通                             │    ·公诉人应出庭·20日(>3年→1.5月)
        └──────────────────────────┬──────────────────────────┘
                          审理中发现不宜/被告人反悔不认罪
                                    │
                   转换(解释§368/375/376)：速裁→简易/普通、简易→普通
                                    │
                          ★转换后审判期限【重新起算】
```

> **一句话总诀**：**「速裁＝3年以下＋认罪认罚＋独任＋不开调查辩论＋10日；简易＝认罪无异议＋刑期不限(超3年合议)＋公诉人出庭＋20日；排除关速裁多两条；转了就审限重算。」**

## 二、 简易 vs 速裁 · 核心对比大表（背这一张就够）

| 维度 | **简易程序**（§214-221） | **速裁程序**（§222-226） |
| :--- | :--- | :--- |
| **管辖法院** | 基层法院 | 基层法院 |
| **刑期条件** | **无上限**（超3年须合议） | **可能判处3年以下**有期徒刑 |
| **认罪要求** | 承认罪行、对指控事实无异议、同意简易 | **认罪认罚**、同意速裁 |
| **审判组织** | 3年以下可**独任**、超3年**必合议** | **一律独任** |
| **公诉人** | **应当出庭**（§216） | 出庭（认罪认罚见证具结） |
| **庭审** | **可简化**讯问/举证质证等（仍有简化的调查辩论） | **不进行法庭调查、法庭辩论**（§224） |
| **最后陈述** | 保留 | **保留**（宣判前听取辩护人意见+被告人最后陈述） |
| **宣判** | — | **当庭宣判** |
| **审限** | **20日**；可能判超3年→延至**1个半月**（§220） | **10日**；可能判超1年→延至**15日**（§225） |
| **绝对排除** | 盲聋哑/未完全丧失辨控精神病人·重大社会影响·共犯有异议·其他不宜（§215） | **简易四类 + 未成年人 + 辩护人作无罪辩护**（§223） |

> 🎯 **对比记忆口诀**：**「速裁更快更严——3年以下、一律独任、不开调查辩论、10日；排除多两条（未成年、无罪辩护）。简易更宽——刑期不限、可独任可合议、公诉人出庭、20日。」**

## 三、 三大判定关卡（每关：字诀 + 先懂几个词 + 数字案例 + 🎯做题眼）

### 第一关：简易程序（适用·排除·审理·审限）—— 盯死"认罪无异议＋刑期不限但超3年合议"

> **教练提示**：一看到简易，同学最容易误记"简易只能判3年以下"（那是速裁）、"简易不用公诉人出庭"。命题人专卡这两处——**简易无刑期上限**（超3年只是要合议），且**公诉人应当出庭**。

> # 简易＝基层+认罪无异议+同意；刑期不限(超3年合议)；公诉人出庭；20日(超3年1.5月)

- **先懂几个词**：
	- **适用要件（§214）**
		- 基层管辖 + 事实清楚证据充分 + 被告人**承认所犯罪行、对指控事实无异议** + **同意适用简易**；
			- 案件只能由**基层人民法院**一审审理。
				- 中院、高院、最高法一审案件，一律不能用简易；
				- 二审、再审、死刑复核程序，永远不存在简易；
				- 简易是简化流程，只适用于普通轻微一审案件，重罪、重大案件归中院及以上，程序必须完整普通审理。

	- **无刑期上限**
		- 简易不限刑期，但**可能判超3年**的须**组成合议庭**（3年以下可独任可合议）；

	- **绝对排除（§215）**

		- ①盲聋哑/未完全丧失辨认控制能力精神病人；
		- ②有重大社会影响；
		- ③共犯部分人不认罪或有异议；
		- ④其他不宜；

	- **公诉人应当出庭（§216）**
		- 简易程序**公诉人应当出庭**（破"简易不出庭"惯性）；

	- **审限（§220）**＝20日审结；可能判**超3年**的延至**1个半月**。

- **判"能否简易"**：基层+认罪无异议+同意+不沾§215四类→可简易。

- **判"独任还是合议"**：3年以下可独任；**超3年必合议**。

#### 大白话讲解

##### 💰 完整数字案例：聋哑人能否简易（[[刑诉-审判-单选-22 · 王某聋哑人盗窃案简易程序法律援助规则|单选-22]]）

> **案情**：聋哑人王某盗窃案，事实清楚、王某认罪，法院拟用简易程序。
>
> - 王某是**聋哑人**，落入§215①**绝对排除**——**不得适用简易程序**；
> - 且聋哑人属**应当通知法律援助**的情形（强制辩护）。
>
> 👉 盲聋哑/精神病是简易速裁**共同**的绝对排除硬伤，认罪也不能走快车道。

#### 一句话闭环记忆

> 🎯 **一眼判**：简易＝**认罪无异议+同意、刑期不限(超3年合议)、公诉人出庭、20日**；盲聋哑/精神病/重大影响/共犯异议**绝对排除**。把"简易只能判3年以下""简易公诉人不出庭"的——**排除**。

### 第二关：速裁程序（适用·排除·简化·审限）—— 盯死"3年以下＋认罪认罚＋一律独任＋不开调查辩论"

> **教练提示**：速裁是"快中之快"。命题人专卡它比简易**更严的门槛**（3年以下、认罪认罚、排除多两条）和**更简的审理**（一律独任、不开法庭调查辩论、当庭宣判）。

> # 速裁＝基层+3年以下+认罪认罚+同意；一律独任；不开法庭调查辩论；10日(超1年15日)；排除多"未成年+无罪辩护"

- **先懂几个词**：
	- **适用要件（§222）**＝基层管辖 + **可能判处3年以下**有期徒刑 + 事实清楚证据充分 + **认罪认罚、同意速裁**；
	- **一律独任**＝速裁**一律独任审判**（不合议）；
	- **绝对排除（§223）**＝简易四类**再加**：**未成年人**、**辩护人作无罪辩护**、未达成和解/调解协议等；
	- **简化审理（§224）**
		- 不受送达期限限制、一般不进行法庭调查和法庭辩论，但宣判前听取辩护人意见和被告人最后陈述、当庭宣判；
	- **审限（§225）**＝10日审结；可能判**超1年**的延至**15日**。

- **判"能否速裁"**：基层+3年以下+认罪认罚+同意+不沾§223（含未成年/无罪辩护）→可速裁。
- **判"怎么审"**：一律独任；不开法庭调查辩论；当庭宣判。

#### 大白话讲解

##### 💰 完整数字案例：速裁审限与值班律师（[[刑诉-审判-单选-26 · 李某危险驾驶案速裁审限与值班律师规则|单选-26]]）

> **案情**：李某危险驾驶案（可能判拘役，3年以下），认罪认罚，适用速裁。
>
> - 速裁**10日**审结（本案不会超1年，不涉及延至15日）；
> - **一律独任**；不进行法庭调查、法庭辩论，当庭宣判；
> - 认罪认罚需**值班律师**在场见证具结（保障权利）。
>
> 👉 速裁的"快"体现在独任+不开调查辩论+10日+当庭宣判。

#### 一句话闭环记忆

> 🎯 **一眼判**：速裁＝**3年以下+认罪认罚+同意、一律独任、不开法庭调查辩论、10日(超1年15日)、当庭宣判**；排除比简易多**未成年人+辩护人无罪辩护**。把"速裁要合议""速裁开法庭调查辩论""未成年人可速裁"的——**排除**。

### 第三关：程序转换 —— 盯死"转得了但审限重算"

> **教练提示**：一看到"审理中被告人反悔不认罪/发现不宜"，同学容易纠结能不能转、审限怎么算。命题人专卡这条——**速裁可转简易或普通、简易可转普通**，且**转换后审判期限重新起算**（不接续）。

> # 速裁→简易/普通、简易→普通；转换后审限重新起算

- **先懂几个词**：
	- **转换方向（解释§368/§375/§376）**＝**速裁**发现不宜的可转**简易或普通**；**简易**发现不宜的转**普通**（快车道只能往"更慢"的方向转）；
	- **转换触发**＝被告人**不认罪/反悔**、案情复杂、发现§215/§223排除情形等；
	- **审限重新起算**＝转为新程序后，**审判期限从转换之日重新计算**，不与原程序接续。

- **判"能否转、往哪转"**：速裁→简易/普通；简易→普通（不能反向"升格"为快车道）。
- **判"审限"**：转换后**重新起算**。

#### 一句话闭环记忆

> 🎯 **一眼判**：**速裁→简易/普通、简易→普通；转换后审限重新起算**。把"简易可转速裁""转换后审限接着算"的——**排除**。

## 五、 主观题万能说理模板

> "简易程序依刑诉法§214，须基层法院管辖、事实清楚证据充分、被告人承认所犯罪行且对指控事实与适用简易均无异议，**不受刑期限制**（可能判处超三年有期徒刑的应组成合议庭，三年以下可独任），**公诉人应当出庭**（§216），审限20日、可能判超三年的延至一个半月（§220）；具有§215情形（盲聋哑/未完全丧失辨控精神病人、重大社会影响、共犯有异议等）的绝对不适用。速裁程序依§222，限**可能判处三年以下**、被告人**认罪认罚**并同意，**一律独任**审判，**不进行法庭调查、法庭辩论**但应听取辩护人意见及被告人最后陈述、当庭宣判（§224），审限10日、可能判超一年的延至15日（§225）；§223在简易排除基础上**另排除未成年人及辩护人作无罪辩护**的情形。审理中发现不宜或被告人反悔的，速裁可转为简易或普通、简易可转为普通程序，**转换后审判期限重新起算**（解释§368/§375/§376）。"
