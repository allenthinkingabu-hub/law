# 📐 附带民事诉讼（含附带民事公益诉讼）· 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。附带民事诉讼这一块，命题人最爱的套路是**给你一个"看起来该赔"的案情，然后从五六个不同的角度同时挖坑**——手机被抢又被卖了，被害人能不能直接管被告人要钱？出庭作证的交通费能不能补？被告人的狐朋狗友要替他赔钱，法院能不能拦着？交警执法把人撞伤了，能不能告交警队？案发时同伙跑了，能不能把他也列成被告？这些问题看着都不难，但命题人专挑"感觉上该赔、法律上不让赔"或者反过来"感觉上不该管、法律上必须受理"的场景来出题。
> 破解的钥匙是把附带民事诉讼拆成**六道闸门**依次过：**受理范围闸门**（这笔损失能不能通过附带民事要）→ **国家赔偿闸门**（侵权人是不是"公家人"在执行公务）→ **主体资格闸门**（谁能当原告、谁能当被告）→ **程序细节闸门**（保全、公开审理、发问权这些操作性规则）→ **公益诉讼闸门**（检察院提起的特殊情形）→ **二审闸门**（谁上诉、纠正谁那部分）。
> 今天用**一张六闸门决策树＋六大万能解题步骤＋对号入座表＋数字案例**把这块地基打牢。

## 适用场景与解决问题

本模型覆盖 [[刑诉-审判程序-深度报告]] "五、附带民事诉讼（含附带民事公益诉讼）"板块及"附带民事二审"相关考点。凡题干出现"被害人能否提起附带民事诉讼""某某能否成为附带民事诉讼原告人/被告人""财产保全怎么处理""能不能不公开审理""亲友代为赔偿怎么处理""检察院提起的附带民事公益诉讼""附带民事上诉/抗诉二审怎么审"等，立即调用本模型。

- **受理范围三分界**：财物被**非法占有、处置**（抢夺/盗窃/诈骗后变卖占有）→ 走**追缴、责令退赔**，**不得**另提附带民事诉讼；财物被**毁坏**或**人身权利受侵犯**造成物质损失 → **可以**提附带民事诉讼；因人身损害**间接引发**的经济损失（如昏迷无法履行合同）→ **不属于**赔偿范围。
- **国家机关工作人员职务侵权的排除规则**：行使职权侵犯人身/财产权利构成犯罪的，被害人**只能申请国家赔偿**，不得提附带民事诉讼；该规则同时排除"告单位"这条替代路径；且**渎职犯罪不适用刑事和解**。
- **主体资格**：**近亲属**范围是**封闭列举**（夫、妻、父、母、子、女、同胞兄弟姊妹），**不含祖父母**；**共同犯罪同案犯在逃的，不列为**附带民事诉讼共同被告人。
- **程序细节**：**财产保全**可依申请直接裁定查封/扣押/冻结（非必须先担保、无需移送财产所在地法院）；**不公开审理**、**发问权**、**证人出庭补助不适用被害人**、**亲友代为赔偿可作量刑酌定情节**等操作性规则。
- **附带民事公益诉讼**：检察院以"公益诉讼起诉人"身份提起，**管辖跟随刑事案件审理法院**（不因公益性质拔高至中院）；赔偿款判令**向检察院交付**用于修复；检察院对判决**享有上诉权**；可判令**非财产性责任**（如公开赔礼道歉）。
- **附带民事二审**：谁上诉带谁进二审——刑事进二审、附民没上诉却有错→走**审判监督程序**；附民进二审、刑事没上诉却有错→**本二审一并纠正**（镜像相反）；不得加重赔偿只护**被告单独上诉**；抗诉案件**应当开庭**。

> **核心一句**：**「先问损失是不是'能通过附带民事要'（占有处置追缴退赔、毁坏侵犯人身才能诉、间接损失不算）；再问侵权人是不是'公家人执行公务'（是→只能国家赔偿）；再问谁能当原告被告（近亲属封闭列举、同案犯在逃不列被告）；再看程序细节和公益诉讼特殊规则；最后判二审谁上诉带谁进。」**

> 🔎 **法条口径**：核心依据为《刑诉解释》§175-§194 相关条款（受理范围§175/§176或§167、职务侵权排除§177、同案犯在逃不列被告§183、已调解履行不再受理§185、财产保全§189、亲友代赔§180②/§194、赔偿范围§192②）及刑诉法§191②（发问权）、§288（刑事和解适用范围）；附带民事公益诉讼另见检察公益诉讼相关司法解释。**本板块系 2026-07-06/08 首次入库，来源为单一"2026《刑诉法》经典母题"PDF，尚未按报告 5 大权威源标准逐条联网核验，星级为保守估计，非最终定级。**
>
> ⚠️ **易记错点（勿望文生义）**：①**"占有处置"≠"毁坏"**——抢了/偷了/骗了东西**变卖**属占有处置（走追缴退赔），把东西**砸了/烧了**才是毁坏（可诉）；②**间接经济损失不算**——人身受害导致"没法上班/没法履约"造成的损失，不属于"财物被毁坏"型物质损失；③**同一条"占有处置不得另诉"规则，两张真题卡分别引用了 §167 与 §176 两个不同条号**——本模型未联网核验统一，如实并列存证，未擅自取舍；④**祖父母不是近亲属**，不能提附带民事诉讼；⑤**国家机关工作人员职务侵权排除规则，连"告单位"这条路也堵死**，不是换个被告就能绕过去；⑥**财产保全不是"不予受理"也不是"必须先担保"**，法院可以直接依申请裁定；⑦**证人出庭补助≠被害人补助**，被害人不适用该条款；⑧**亲友代为赔偿是"可以准许"，不是"应当准许"**；⑨**"没上诉却有错"该怎么救济，方向会反转**——刑事带进二审时附民有错走审判监督，附民带进二审时刑事有错反而本二审一并纠正，别记反。

## 一、核心考情

> **频次研判**：本板块 2026-07-06/08 首次入库，来源单一"2026《刑诉法》经典母题"PDF，星级为**保守估计**（★★★），非经 5 大权威源交叉核验的最终定级；"附带民事二审"相关题卡另有独立真题来源（吴某任某案、甲绑架撕票案等）。

命题核心集中在六条线：

1. **受理范围三分界**——占有处置（不得诉）vs 毁坏/侵人身（可诉）vs 间接损失（不算）vs 已调解履行（不再受理），命题人最爱用"东西被抢了当然该赔"的直觉设陷阱。
2. **国家赔偿排除**——"公家人"执行公务侵权，附带民事诉讼、告单位、刑事和解三条路一律堵死，只剩国家赔偿一条出口。
3. **主体资格**——近亲属封闭列举（不含祖父母）、同案犯在逃不列共同被告，命题人爱用"都是亲人应该都能告""一起打的应该一起当被告"的想当然来诱导。
4. **程序细节**——财产保全、不公开审理、发问权、证人出庭补助、亲友代赔，命题人爱用"绝对化"错误选项（必须先担保、被害人也能领补助、法院必须准许代赔）来诱导。
5. **附带民事公益诉讼**——管辖不提级、赔偿款不归检察院自留、检察院享有上诉权、可判非财产责任，命题人爱往"级别更高的法院""检察院自己留钱"上引导。
6. **附带民事二审**——谁上诉带谁进二审，"没上诉却有错"的救济方向会因带进二审的是刑事还是附民而反转，是命题人设"镜像坑"的重灾区。

## 二、六闸门决策树

```
              【被害人/近亲属想通过刑事案件顺带把民事赔偿的钱要回来，能不能？】
                                 │
     ▼ 第一闸 · 受理范围 ── 这笔损失是什么性质？
     ├─ 财物被非法占有、处置（抢/偷/骗后变卖）──→ 走追缴、责令退赔，不得另诉
     ├─ 财物被毁坏 / 人身权利受侵犯 ──→ 可以提附带民事诉讼
     ├─ 人身受害间接导致的经济损失（如无法履约） ──→ 不属于赔偿范围
     └─ 侦查/审查起诉阶段已调解并全部履行 ──→ 不予受理（违反自愿合法原则的除外）
              │
     ▼ 第二闸 · 国家赔偿 ── 侵权人是不是"公家人"在执行公务？
     ├─ 是（国家机关工作人员行使职权侵权构成犯罪）──→ 只能申请国家赔偿，不得提附带民事
     │    （告单位也不行；若系渎职犯罪，还额外排除刑事和解）
     └─ 否 ──→ 进入第三闸
              │
     ▼ 第三闸 · 主体资格 ── 谁能当原告？谁能当被告？
     ├─ 原告：近亲属封闭列举＝夫/妻/父/母/子/女/同胞兄弟姊妹（不含祖父母）
     └─ 被告：共同犯罪同案犯在逃的，不列为共同被告人
              │
     ▼ 第四闸 · 程序细节
     ├─ 财产保全：可依申请直接裁定查封/扣押/冻结（不必先担保、无需移送）
     ├─ 不公开审理：涉个人隐私（如性侵案）应不公开审理
     ├─ 发问权：被害人/附带民事原告人经审判长许可可向被告人发问
     ├─ 证人出庭补助：只适用证人，不适用被害人
     └─ 亲友代为赔偿：法院"可以"准许，可作量刑酌定情节
              │
     ▼ 第五闸 · 附带民事公益诉讼（检察院提起）
     ├─ 管辖：跟随刑事案件审理法院（不因公益性质拔高至中院）
     ├─ 赔偿款：判令向检察院（公益诉讼起诉人）交付，用于修复，非检察院自留
     ├─ 上诉权：检察院对附带民事部分判决享有上诉权
     └─ 责任形式：可判令非财产性责任（如公开赔礼道歉）
              │
     ▼ 第六闸 · 附带民事二审 ── 谁上诉、就纠正谁那部分
     ├─ 刑事进二审、附民没上诉却有错 ──→ 走审判监督程序（不在本二审一并判决）
     ├─ 附民进二审、刑事没上诉却有错 ──→ 本二审一并审理纠正（镜像相反）
     ├─ 不得加重赔偿 ──→ 只护被告单独上诉，原告也上诉可增加
     └─ 检察院抗诉的案件 ──→ 应当开庭审理
```

> **一句话总诀**：**「占有处置追退赔、毁坏侵人身才能诉；公家人执法侵权只能国家赔；近亲属不含祖父母、同案犯在逃不列被告；保全不用先担保；公益诉讼钱交检察院；二审谁上诉带谁进，方向会反转」**。

## 三、核心规则拆解

> 六道闸门的底层法理与命题陷阱，做题前先建立整体地图，具体操作细节见"四、万能解题六步"。

1. **占有处置 vs 毁坏的分界线**：非法占有处置（抢/偷/骗后变卖）本质是"物还在，只是易了主"，已有追缴、责令退赔这套更专门的程序解决，附带民事诉讼不重复介入；毁坏是"物已经物理性消灭"，只能靠赔偿解决，这是附带民事诉讼真正管辖的领域。间接经济损失（违约、误工）不是"财物被毁坏"本身的损失，被排除在外。
2. **国家赔偿的排他性**：一旦确认侵权人是"执行公务的公家人"，立法选择让被害人只走**国家赔偿**这一条渠道，既不允许告本人（走附带民事），也不允许换个被告告单位，是一套封闭的排除逻辑；渎职犯罪额外排除刑事和解，因为渎职犯罪不属于刑事和解限定的"民间纠纷引起的轻罪"或"除渎职外的过失犯罪"范围。
3. **主体资格的两条独立规则**：近亲属范围（原告一方）和同案犯到案状态（被告一方）是两条完全独立的判断线，一个看**身份关系**（是否落入封闭列举），一个看**归案状态**（是否在逃），不能混着用同一套逻辑去判断。
4. **程序细节的"绝对化"陷阱**：财产保全、证人补助、亲友代赔这几条规则，命题人偏爱用"必须""应当"这类绝对化措辞来把"可以"性质的裁量规则包装成强制规则，做题时要盯住法条原本的裁量空间。
5. **公益诉讼是特殊的原告地位，不是特殊的管辖或财产归属**：检察院以"公益诉讼起诉人"身份出现，本质上处于原告人地位（因此享有上诉权），但案件本身仍按普通刑事案件的审级管辖走，赔偿款的归属也遵循"取之于公、用之于公"的修复目的，不因诉讼主体是检察院就产生特殊待遇。
6. **二审"谁带谁进"的镜像逻辑**：二审只全面审查被带进来的那部分（刑事或附带民事），未被带进来的部分即使发现有错，原则上也不能在本次二审顺手改判——但这个"不能顺手改"的救济出口，会因为哪一部分是"主动上诉/抗诉带进来的"而不同：刑事部分带进二审时，未上诉的附带民事有错走审判监督；反过来附带民事带进二审时，未上诉/抗诉的刑事部分有错，二审反而应当一并处理。这是全模型唯一的"方向性"规则，也是命题人的最爱陷阱。

## 四、万能解题六步

### 第一步：判受理范围——盯死"这笔损失能不能通过附带民事要"

> **教练提示**：一看到"东西被抢了/偷了"，绝大多数同学下意识觉得"当然能要回钱"，却不知道法律已经给了另一条路——追缴、责令退赔，压根不需要（也不允许）另外打附带民事官司。命题人专卡这条**"占有处置 vs 毁坏"**的分界线，还会加一层更细的"间接损失不算"陷阱。

> 占有处置追退赔不诉；毁坏侵人身才能诉；间接损失不算；已调解履行不再诉


> 刑事部分管定罪判刑，附带民事只管物质损失赔偿，二者程序独立。

> @! 刑事只管定罪量刑；被害人财产 / 人身损失分四条救济路径，互不通用、边界严格区分：**附带民事诉讼、追缴 / 责令退赔、国家赔偿、单独民事诉讼**，附民只是其中一种渠道，并非唯一。
> 	- 单独提起普通民事诉讼（兜底补充）两类适用：
> 		- 附民二审新增赔偿请求、调解不成，告知另行民事起诉；
> 		- 追缴退赔后仍有无法弥补的间接损失，可单独民事立案。

#### 🗣️ 口诀怎么拆

| 字诀分句      | 对应规则                                  |
| --------- | ------------------------------------- |
| 占有处置追退赔不诉 | 财物被抢/偷/骗后变卖 → 走追缴、责令退赔，不得另提附带民事       |
| 毁坏侵人身才能诉  | 财物被打砸烧毁 / 人身权利受侵犯造成物质损失 → 可以提附带民事诉讼   |
| 间接损失不算    | 人身受害间接导致的经济损失（违约、误工）→ 不属于赔偿范围         |
| 已调解履行不再诉  | 侦查/审查起诉阶段已调解并全部履行 → 不予受理（违反自愿合法原则的除外） |


四句话对应四种损失、四种命运——先看物还在不在（占有处置 vs 毁坏），再看损失是不是财物本身的（直接 vs 间接），最后看纠纷是不是已经解决过（是否已调解履行）。

**先懂几个词**：
- **非法占有、处置**
	- 把被害人的财物**抢走、偷走、骗走**，还**据为己有或卖掉**——这类损失通过**追缴（把原物找回来）或责令退赔（追不回就折价赔）**就能解决，法律不允许被害人再另外打一场附带民事官司要求"赔偿"（会造成双重救济）；

- **财物被毁坏**
	- 东西被犯罪行为**打砸、烧毁**等方式**物理性破坏**，已经没法"追缴"回原物了，只能通过**赔偿**解决——这才是附带民事诉讼真正管的事；

- **间接经济损失**
	- 不是财物本身坏了，而是**人身受到伤害后连带耽误了别的事**造成的经济损失（比如昏迷了没法履行合同、没法上班），这类损失**不属于**"财物被毁坏"型的物质损失，**不属于**附带民事诉讼赔偿范围；

	- **犯罪行为直接造成的人身、财物直接损失**（医疗费、护理费、修车费等）,绝对不赔两类:
	  - 精神损失
	  - 间接可得利益 / 连锁违约损失,(殴打→昏迷→无法履约→被客户索赔、违约金、订单利润没了）

- **已调解履行不再受理**
	- 在**侦查、审查起诉阶段**双方已经**调解并全部履行**了民事赔偿，事后又反悔提附带民事诉讼的，法院**不予受理**——除非有证据证明那次调解**违反自愿、合法原则**。
	- 公诉刑事本来不能调；附民赔偿无论是否审前履行，法院审理阶段依然可以调解;

- **人身权利遭受犯罪侵害，由此直接产生的物质损失**，是提起刑事附带民事诉讼的法定范围。
	- 核心两点：
		- 侵害客体：生命、健康、身体、自由、名誉等人身权利（故意伤害、故意杀人、非法拘禁、强奸等）；
		- 损失限定：**实际、必然发生的物质开支**；精神损失不能提附民。

	 可主张项目：医疗费、护理费、误工费、交通费、住院伙食补助、残疾辅助器具费、丧葬费、被扶养人生活费、残疾赔偿金、死亡赔偿金等。

**判"占有处置 vs 毁坏"**：财物**还在、被卖了/被拿走了** → 占有处置，走追缴退赔；财物**已经坏了、烧了、砸了** → 毁坏，可以诉。

**判"直接 vs 间接损失"**：损失是**财物本身**的价值 → 可诉；损失是**因为受伤耽误了别的事**（违约、误工的连带影响）→ 不算。

**判"能否重复起诉"**：侦查/审查起诉阶段**已调解且已履行完毕** → 原则不予受理；能证明调解**不自愿/不合法** → 例外可以再诉。

#### 大白话讲解

##### 🔍 对号入座表：四种损失，四种命运

| 情形                 | 性质            | 能否附带民事诉讼      |
| ------------------ | ------------- | ------------- |
| 抢夺手机后变卖            | 非法占有、处置       | **不能**，走追缴退赔  |
| 寻衅滋事打砸财物、打伤人       | 财物被毁坏/人身受侵犯   | **可以**        |
| 殴打致人昏迷、无法履行合同的违约损失 | 人身损害间接导致的经济损失 | **不能**，不属赔偿范围 |
| 侦查阶段已调解并全部履行，事后又起诉 | 已解决的纠纷重复起诉    | **不能**，法院不予受理 |

##### 💰 完整数字案例：同一批案子，四种损失四种结论

> **案情**：①抢夺案，甲抢走乙的手机并当场卖掉——乙想让法院判甲赔手机钱，法院说"不用另外起诉，我们直接追缴变卖所得或者责令退赔"；②寻衅滋事案，丙打砸了丁的店铺、打伤了丁——丁提附带民事诉讼要求赔物质损失，法院**受理**，因为财物确实是"被毁坏"、人身确实"受侵犯"；③殴打案，戊被打成长期昏迷，因此**没法履行**已签的合同、造成违约损失——这笔损失不属于"财物被毁坏"造成的物质损失，**不属于**赔偿范围；④己在侦查阶段已经和被告人调解并拿到了全部赔偿款，之后又反悔提起附带民事诉讼——法院**不予受理**，因为纠纷已经通过合法调解解决了。

👉 四个案子看着都"有损失"，但只有②能走附带民事诉讼——①有更专门的追缴退赔程序、③损失类型不对、④纠纷已经解决过了。

#### 一句话闭环记忆

> 🎯 **一眼判**：**占有处置（抢/偷/骗后变卖）→追缴退赔不得另诉；毁坏/侵犯人身→可以诉；间接经济损失（违约/误工）→不算；已调解且已履行→不再受理**（除非调解违反自愿合法原则）。⚠️同一条"占有处置不得另诉"规则，两张真题卡引用条号不一致（§167/§176），本模型如实并列、未擅自取舍。

### 第二步：判国家赔偿——盯死"侵权人是不是'公家人'在执行公务"

> **教练提示**：一看到交警、狱警这类"执法人员"把人打伤打死了，绝大多数同学下意识觉得"这不比普通人侵权更该赔吗"，甚至想"告不了本人就告单位"。命题人专卡这条**"职务侵权只能走国家赔偿"**的铁律——不管伤得多重、告本人还是告单位，一律行不通。

> 国家机关工作人员执行公务侵权构成犯罪，只能申请国家赔偿；告单位也不行；渎职不能和解 . 刑事
> 
>  ->@!
> 	刑事责任照常承担，仅不能提附民，赔偿走国家赔偿。 公职履职犯罪照常走完整刑事公诉流程：监委 / 检察院调查侦查→检察院公诉→法院定罪量刑，正常判处刑罚，只是赔偿不能走附民、走国家赔偿。

#### 🗣️ 口诀怎么拆

| 字诀分句                        | 对应规则                           |
| --------------------------- | ------------------------------ |
| 国家机关工作人员执行公务侵权构成犯罪，只能申请国家赔偿 | 触发要件（公家人+行使职权+构成犯罪）→ 唯一出口是国家赔偿 |
| 告单位也不行                      | 排除规则连"换被告告单位"这条替代路径也一并堵死       |
| 渎职不能和解                      | 渎职犯罪被专门排除在刑事和解适用范围之外           |

三句话锁死三条路——告本人不行、告单位不行、和解也不行，被害人唯一的出口只剩国家赔偿。

**先懂几个词**：
- **国家机关工作人员职务侵权排除规则**
	- 国家机关工作人员在**行使职权**（执行公务）时**侵犯他人人身、财产权利并构成犯罪**的，被害人及其法定代理人、近亲属**不得提起附带民事诉讼**，法院**不予受理**，但应当**告知其可以依法申请国家赔偿**；[[200-刑诉-基本原理-职务侵权（职务犯罪）完整考点+案例+管辖规则（2026法考）]]

- **告单位也不行**
	- 这条排除规则**连"换个被告告单位"这条替代路径也一并堵死**——工作人员所在单位（如交通运输管理所）**同样不能**作为附带民事诉讼被告人；

- **渎职犯罪不适用刑事和解**＝刑事和解程序**只适用于**民间纠纷引起的轻罪案件，以及**除渎职犯罪以外**的过失犯罪案件——像滥用职权罪这种**渎职犯罪**，即便双方都愿意和解，也**不能**走刑事和解程序。

	- **公诉无刑事调解、有法定刑事和解；**
	- **渎职罪禁用刑事和解、但照常可以民事赔钱调解。**

**判"是不是职务侵权"**：侵权人是**国家机关工作人员**，且是在**行使职权（执行公务）**时实施的侵权行为，并**构成犯罪** → 触发排除规则，被害人**只能**走国家赔偿。
**判"能不能告单位"**：**不能**，排除规则同时否定"告单位"这条替代救济思路。
**判"渎职犯罪能不能和解"**：**不能**——渎职犯罪被专门排除在刑事和解适用范围之外。

#### 大白话讲解

##### 🔍 对号入座表：交警执法伤人案里的四个"想当然"

| 想法                    | 对不对 | 正解                 |
| --------------------- | --- | ------------------ |
| "受伤的司机可以告交警要赔偿"       | ❌   | 只能申请国家赔偿，不得提附带民事诉讼 |
| "死者家属可以告交警要赔偿"        | ❌   | 同上，法院应裁定不予受理       |
| "告不了交警本人，那告他所在的单位总行吧" | ❌   | 单位也不能作被告           |
| "既然是过失犯罪，那可以和交警和解"    | ❌   | 滥用职权罪是渎职犯罪，不适用刑事和解 |

##### 💰 完整数字案例：一次执法事故，四条路全被堵死

> **案情**：甲是某地交通运输管理所工作人员，在巡查执法时导致一辆出租车发生重大交通事故，司机乙重伤，乘客丙当场死亡。甲以滥用职权罪被公诉。
>
> - 乙想申请成为附带民事诉讼原告人要求赔偿——**不行**，甲是执行公务时侵权构成犯罪，乙只能申请国家赔偿；
> - 丙的妻子想告交通运输管理所（甲所在单位）——**也不行**，单位同样不能作附带民事诉讼被告人；
> - 有人建议乙、丙的近亲属和甲达成刑事和解——**同样不行**，滥用职权罪属渎职犯罪，不适用刑事和解程序。

👉 一旦确认侵权人是"执行公务的公家人"，附带民事诉讼、告单位、和解——三条路同时被堵死，被害人唯一的出口是国家赔偿。

#### 一句话闭环记忆

> 🎯 **一眼判**：国家机关工作人员**行使职权**侵权构成犯罪的，被害人/近亲属**只能申请国家赔偿**，不得提附带民事诉讼——**告单位也不行**；若系**渎职犯罪**，还额外**不适用刑事和解**。看到"交警/狱警/城管等执法人员执行公务时致人伤亡"的题干，直接锁定这条排除规则。

### 第三步：判主体资格——盯死"谁能当原告、谁能当被告"

> **教练提示**：一看到"死者的父母、祖父母都来告"，绝大多数同学觉得"都是亲人，应该都能告"；一看到"同案犯甲被抓、乙在逃"，又觉得"两人一起干的，应该一起当被告"。命题人专卡这两处**主体资格**的边界——近亲属是个**封闭清单**，同案犯**在逃就不列被告**。

> 近亲属封闭列举不含祖父母；同案犯在逃不列为共同被告人

#### 🗣️ 口诀怎么拆

| 字诀分句          | 对应规则                          |
| ------------- | ----------------------------- |
| 近亲属封闭列举不含祖父母  | 原告一方：只认**夫妻父母子女同胞兄弟姊妹**，祖父母不算 |
| 同案犯在逃不列为共同被告人 | 被告一方：已到案的列被告，在逃的不列（不影响将来另行处理） |

两句话管两头——原告一方看**身份关系**是否落入封闭清单，被告一方看**归案状态**是否已到案，互不影响、别混用。

**先懂几个词**：
- **近亲属（封闭列举）**＝法律明确圈定的几类关系——**夫、妻、父、母、子、女、同胞兄弟姊妹**，**仅此几种**，不能类推扩大到祖父母、外祖父母、叔伯姑舅等其他亲属；
- **同案犯在逃不列为共同被告人**
	- 共同犯罪案件中，如果**部分同案犯尚未归案（在逃）**，附带民事诉讼**只能把已到案的被告人列为被告**，在逃的那个人**不列入**本次附带民事诉讼的被告人范围（不影响将来其归案后另行处理）。
	- 

**判"谁是近亲属"**：只认**夫妻、父母子女、同胞兄弟姊妹**这几类，**祖父母、外祖父母不算**近亲属，无权提附带民事诉讼。
**判"同案犯要不要列被告"**：**已到案**的列为被告；**在逃**的**不列**，哪怕案情证明他也参与了犯罪。

#### 大白话讲解

##### 🔍 对号入座表：谁能告、谁能被告

| 人物关系         | 能否提附带民事诉讼 / 能否列为被告        |
| ------------ | ------------------------- |
| 死者的父母        | **能**（近亲属）                |
| 死者的祖父母       | **不能**（不属于法定近亲属范围）        |
| 被害人的妻子、儿子、弟弟 | **都能**（配偶、子女、同胞兄弟姊妹均属近亲属） |
| 已到案的同案犯甲     | **列为被告**                  |
| 案发后在逃的同案犯乙   | **不列**为附带民事诉讼被告人          |

##### 💰 完整数字案例：同一起共同伤害案，谁能告、谁被告

> **案情**：韩某和苏某共同殴打他人，致被害人李某死亡、吴某轻伤。韩某被抓获，苏某在逃。
>
> - **谁能告**：李某的**父母**属于近亲属，有权提附带民事诉讼；李某的**祖父母**不属于近亲属范围，**无权**提起。
> - **谁被告**：本次附带民事诉讼**只能列已到案的韩某**为被告人；**在逃的苏某不列**为共同被告人（不代表苏某将来归案后不用担责，只是本次先不列入）。

👉 同一起案子，"能不能告"看的是原告一方的**身份关系**（近亲属清单），"谁当被告"看的是被告一方的**归案状态**（在逃不列），两条规则各管一边，别混着用。

#### 一句话闭环记忆

> 🎯 **一眼判**：近亲属＝**夫妻父母子女同胞兄弟姊妹**（封闭列举，**不含祖父母**）；共同犯罪中**同案犯在逃的，不列为**附带民事诉讼共同被告人（只告已到案的）。

### 第四步：判程序细节——保全、公开审理、发问权与量刑情节

> **教练提示**：这一关考的都是"操作层面"的细节规则，命题人喜欢用"绝对化"的错误选项来诱导——"必须先交担保才能保全""证人补助被害人也能领""亲友代赔法院必须准许"，这些看似合理的推断，恰恰都不对。

> # 保全不用先担保、无需移送；不公开审理保护隐私；发问权经许可；证人补助不适用被害人；亲友代赔"可以"非"应当"

#### 🗣️ 口诀怎么拆

| 字诀分句          | 对应规则                              |
| ------------- | --------------------------------- |
| 保全不用先担保、无需移送  | 财产保全：法院可依申请直接裁定，不必先担保、不需移送财产所在地法院 |
| 不公开审理保护隐私     | 涉个人隐私（如性侵案）应当不公开审理，无需申请           |
| 发问权经许可        | 被害人/附带民事原告人经审判长许可可向被告人发问          |
| 证人补助不适用被害人    | 出庭补助专属证人身份，被害人不适用                 |
| 亲友代赔"可以"非"应当" | 亲友自愿代为赔偿，法院"可以"准许，可作量刑酌定情节        |

五句话对应五条独立的操作性规则，命题人常把其中的"可以"偷换成"应当"、把"经许可"偷换成"无条件"，逐句核对即可破解。

**先懂几个词**：
- **财产保全**
	- 财产保全，是**刑事审判法院**为防止被告人转移、隐匿、变卖个人财产，导致后续附带民事赔偿判决无法执行，对被告人合法财产采取**查封、扣押、冻结**的强制措施。
	- 担心将来附带民事判决**执行不了**，法院可以依原告人**申请**裁定**查封、扣押或冻结**被告人的财产——法院**可以**要求申请人提供担保，也**可以不要求**，并非"必须先担保"；也**无需移送**财产所在地法院，本院可以**直接裁定**；

- **不公开审理**
	- 涉及**个人隐私**（如性侵类案件）的第一审案件，应当**不公开审理**（区别于商业秘密案件需**当事人申请**才不公开）；

- **发问权**＝被害人、附带民事诉讼原告人及其辩护人/诉讼代理人，**经审判长许可**，可以就案情向被告人**发问**；

- **证人出庭补助**
	- 证人因出庭作证支出的交通、住宿、就餐等费用，法院应当给予补助——这项补助**只适用于证人**，**被害人不适用**（被害人另有自己的诉讼地位，不是"证人"）；

	- 这笔补助**不是当事人、被告人、被害人掏腰包**，属于国家财政支出，由公检法每年预算统一拨付。
		- 谁通知证人作证，就由谁现场发放补助：
			- 侦查阶段作证 → 公安机关出钱发放
			- 审查起诉阶段作证 → 检察院出钱发放
			- 开庭审判出庭作证 → 法院出钱发放

- **亲友代为赔偿**
	- 附带民事诉讼被告人的亲友**自愿代为赔偿**的，法院**可以**准许（不是"应当"必须准许），并可以结合被告人的赔偿情况认定其**悔罪表现**、作为量刑时的**酌定情节**考虑。

**判"保全条件"**：**不是**不予受理，**不是**必须先担保，**不需**移送——法院可直接依申请裁定保全。

**判"要不要公开审理"**：涉个人隐私 → **应当**不公开（无需申请）；涉商业秘密 → 当事人**申请**才可以不公开。

**判"证人补助能不能给被害人"**：**不能**，补助专属于证人身份。

| -------------------- | ----------------------- |
| "财产保全必须先交担保"         | 法院**可以**要求担保，也**可以不要求** |
| "财产保全要移送财产所在地法院办理"   | **无需移送**，本院可直接裁定        |

##### 💰 完整数字案例：财产保全 + 隐私案的发问权

> **案情①**：王某被姜某打伤致残，开庭前向法院申请财产保全。法院**可以**直接裁定查封、扣押或冻结姜某的财产，**不需要**王某先提供担保，也**不需要**移送财产所在地的法院。
>
> **案情②**：甲女遭乙男强行发生性关系后起诉。因涉及个人隐私，本案**应当不公开审理**；甲女作为被害人出庭作证支出的交通住宿费，**不能**要求法院补助（补助只给证人）；但甲女可以就侵害事实要求乙男赔偿医疗费等（属于人身权利受侵犯的赔偿范围）；公诉人讯问乙男后，甲女经**审判长许可**，可以就强奸的犯罪事实向乙男**发问**。

👉 这一关的题目往往一题揉进两三个程序细节，做题时把每个选项拆开单独核对，别被"看起来合理"的绝对化表述带偏。

#### 一句话闭环记忆

> 🎯 **一眼判**：财产保全**不必先担保、无需移送**；涉隐私案件**应当不公开审理**；被害人/原告经许可可**发问**；证人出庭补助**不适用被害人**；亲友代赔法院**"可以"准许**、可作量刑酌定情节。

### 第五步：判附带民事公益诉讼——检察院提起的特殊情形

> 检察院对污染环境、食药安全、侵害英烈名誉等**损害社会公共利益**的犯罪提起刑事公诉时，**一并附带**向同一法院起诉，要求被告人承担修复生态、惩罚性赔偿、公开赔礼道歉等**民事公益责任**；法院对刑事、公益民事两部分一并审理、一并作出判决，即你说的 “判附带民事公益诉讼”。
> 
> 	**食药安全（食品药品安全领域）**：生产、加工、销售、运输、使用食品、药品环节，实施违法行为，侵害**不特定众多消费者**身体健康、生命安全，损害社会公共利益的案件范畴，是检察院可提起**刑事附带民事公益诉讼**三大法定领域之一安庆长安网

> **教练提示**：一看到"公益诉讼"，绝大多数同学下意识往"级别更高的法院"或"检察院自己留钱"上想。命题人专卡这两处——**管辖不因公益性质拔高**，**赔偿款也不是检察院自己的**。

> 管辖跟随刑事审理法院；赔偿款交检察院用于修复；检察院享有上诉权；可判非财产责任


#### 🗣️ 口诀怎么拆

| 字诀分句        | 对应规则                          |
| ----------- | ----------------------------- |
| 管辖跟随刑事审理法院  | 由审理刑事案件的法院一并管辖，不因公益性质提级到中院    |
| 赔偿款交检察院用于修复 | 判令交付检察院，但用于环境治理等公益修复，非检察院自留   |
| 检察院享有上诉权    | 检察院作为"公益诉讼起诉人"相当于原告人地位，可对判决上诉 |
| 可判非财产责任     | 除赔偿损失外，还可判令停止损害、公开赔礼道歉等       |

四句话破掉四个"想当然"——不提级、不自留、能上诉、不止赔钱。

**先懂几个词**：
- **附带民事公益诉讼**
	- 检察院在提起刑事公诉的同时，以**"公益诉讼起诉人"**的身份，就被告人的犯罪行为**同时损害了社会公共利益**（如环境污染）的部分，一并提起的民事公益诉讼；
- **管辖跟随刑事审理法院**
	- 附带民事公益诉讼**由审理该刑事案件的法院管辖**，**不会**因为是"公益诉讼"就要求提级到中级以上人民法院管辖；
- **赔偿款交检察院、用于修复**
	- 法院判决后应判令被告人向**检察院（公益诉讼起诉人）**交付赔偿款，该笔钱**不能由检察院自己占有**，而应用于**环境治理修复**等公益目的；

- **检察院享有上诉权**
	- 检察院作为公益诉讼起诉人，相当于附带民事诉讼中的**原告人地位**，对一审附带民事公益诉讼部分的判决不服，有权**提起上诉**；
- **非财产性责任**
	- 除了赔偿损失，法院还可以判令被告人承担**停止损害、赔礼道歉**（含向社会公众公开赔礼道歉）等**非财产性**责任形式。

**判"管辖法院"**：**跟随刑事案件**审理法院，**不**单独提级。
**判"赔偿款归谁"**：判令交付给**检察院**，用于**修复**，**不是**检察院自己的钱。
**判"检察院能不能上诉"**：**能**，检察院相当于原告人地位。

### 第六步：判附带民事二审——盯死"谁上诉、就纠正谁那部分"

> **教练提示**：这一关是一对"**镜像题**"——刑事上诉/抗诉、附带民事没上诉却有错→附带民事走**审判监督程序**（不在本二审一并判决）；反过来，附带民事上诉、刑事没上诉却有错→**刑事部分反而可以在本二审一并审理纠正**。方向一变，救济通道就变，命题人专卡这个"镜像反转"。

> 谁上诉带谁进二审；没上诉但有错的那部分（刑事错→走监督；附民错→可一并纠正）；不得加重赔偿只护被告单独上诉；抗诉案件必开庭

#### 🗣️ 口诀怎么拆

| 字诀分句           | 对应规则                                  |
| -------------- | ------------------------------------- |
| 谁上诉带谁进二审       | 二审只全面审查因上诉/抗诉被带进来的那部分（刑事或附民）          |
| 刑事错→走监督        | 刑事上诉/抗诉带进二审时，附带民事没上诉却有错，只能走审判监督程序纠正   |
| 附民错→可一并纠正      | 附带民事上诉带进二审时，刑事没上诉却有错，二审应当一并审理纠正（镜像相反） |
| 不得加重赔偿只护被告单独上诉 | 该限制只在被告单独上诉时适用；原告也上诉的，可以增加赔偿          |
| 抗诉案件必开庭        | 检察院抗诉的案件，第二审应当开庭审理，抗诉主体是原公诉同级检察院      |

五句话锁死二审的"谁带谁进+方向会反转"这条最容易被记反的规则——先看谁上诉把案件带进了二审，再看没被带进来的那部分错在哪、该走哪条救济路，最后核对加刑保护范围和是否必须开庭。

**先懂几个词**：
- **谁上诉、谁进二审**
	- 二审只审理"因上诉/抗诉被带进来"的那部分（刑事或附带民事），另一部分若没人上诉，原则上不因这次二审而被直接改判；

	- 未上诉的附带民事部分依法生效;

	- 只上诉附带民事、刑事不上诉、检察院也不抗诉：**刑事上诉期 10 天一满，刑事判决直接生效** 仅附带民事留在二审审理。二审若发现已生效的刑事判决有错，不能直接改刑事，只能另走审判监督程序再审，再审可和附民二审合并处理。

- **附带民事没上诉却有错**（刑事上诉/抗诉带进二审）
	- 二审发现附带民事部分确有错误的，**不能**在本二审程序里顺手一并判决，只能通过**审判监督程序（再审）**纠正；

- **刑事没上诉却有错**（附带民事上诉带进二审）＝这种情形是"镜像"的反面——附带民事把案件带进了二审，此时若发现**刑事部分确有错误**，二审**应当对刑事部分一并审理、依法处理**（不是置之不理，也不是必须另走审判监督）；

- **不得加重赔偿的保护范围**

	- "二审不得加重被告人赔偿数额"这条限制，**只在附带民事被告人一方单独上诉时**适用；若**原告人也上诉**（通常意在增加赔偿），则不受此限，二审可以依法**增加**赔偿数额；

	- 附带民事诉讼的当事人和他们的法定代理人，可以对地方各级人民法院第一审的判决、裁定中的**附带民事诉讼部分**，提出上诉。

- **抗诉必开庭＋新证据要告知**
	- 检察院抗诉的案件，第二审**应当开庭审理**；抗诉主体是**原提起公诉的同级检察院**（非上级院）；
	- 一方提交新证据的，法院应及时**通知对方查阅、摘抄或复制**，保障质证权；

- **暂缓送监执行**
	- 死刑缓期执行等案件因附带民事部分上诉仍处于二审阶段的，二审审结前**可以暂缓**将被告人交付送监执行。
		- 送监执行:  判决生效后，看守所把判处死缓、无期、长期有期徒刑的罪犯移交监狱，正式在监狱服刑，叫送监执行；剩余刑期 3 个月以下留在看守所，不用送监。

**判"哪部分错了该怎么纠正"**：刑事上诉带进二审、**附带民事没上诉却有错**→**审判监督程序**；附带民事上诉带进二审、**刑事没上诉却有错**→**本二审一并审理**。

**判"能不能加赔偿"**：只有**被告单独上诉**才受"不得加重"保护；**原告也上诉**的，可以增加。

**判"要不要开庭"**：检察院**抗诉**的案件，二审**应当开庭**。

| "刑事上诉/抗诉进二审时，发现附带民事有错也能顺手改判" | 附带民事没上诉却有错的，只能走**审判监督程序**纠正，不在本二审一并判决 |

| "不管谁上诉，二审都不能加重赔偿数额"          | 该限制**只护被告单独上诉**；原告也上诉的，可以增加赔偿         |
| "抗诉案件二审可以书面审理"               | 检察院抗诉的案件**应当开庭审理**                    |
| "抗诉可以由上级检察院直接提出"             | 抗诉由**原提起公诉的同级检察院**提出                  |
| "死缓案件附带民事部分一上诉，就必须立即送监执行"    | 二审审结前**可以暂缓**送监执行                     |

##### 💰 完整数字案例：一对镜像案

> **案情一（吴某任某非法拘禁致死案）**：检察院以量刑过轻抗诉并提交新证据，被告人吴某就量刑上诉，任某和附带民事原告人（被害人妻子）均未上诉，二审中发现附带民事判决确有错误。
>
> - 附带民事部分**没人上诉**，只是被二审全面审查"顺带发现"有错——**不能**在本二审一并判决纠正，须走**审判监督程序**；
> - 本次二审真正审理的是**刑事部分**：因检察院**抗诉**，二审**应当开庭审理**；抗诉主体是原公诉的**A区检察院**（同级院）；检察院提交的新证据，法院应**通知对方查阅、摘抄或复制**。
>
> **案情二（甲绑架撕票死缓案，与案情一镜像）**：一审判甲死缓、赔偿附带民事原告人乙35万元，检察院**未抗诉**，甲和乙**均对附带民事判决上诉**（刑事部分无人上诉/抗诉）。
>
> - 附带民事部分**被上诉带进了二审**，此时若发现**刑事部分**确有错误，二审**应当对刑事部分一并审理、依法处理**（与案情一的处理方向正好相反）；
> - 甲被判死缓，案件因附带民事上诉尚在二审，**二审审结前可以暂缓**将甲交付送监执行；
> - 乙在二审期间**增加独立诉讼请求**的，法院**可以调解**处理；
> - 由于**乙（原告）也提起了上诉**，"不得加重赔偿"的保护不适用于本案，二审**可以依法增加**甲的赔偿数额（若只有甲单独上诉，则不能加重）。

→ 对应 [[刑诉-审判-多选-100 · 吴某任某非法拘禁致死案附带民事二审抗诉主体与开庭|多选-100]]、[[刑诉-审判-多选-101 · 甲绑架撕票死缓案附带民事上诉二审一并审理与不得加重赔偿|多选-101]]、[[刑诉-审判-多选-102 · 甲诋毁殴打乙重伤自诉附带民事案公诉转自诉与撤诉终结|多选-102]]、[[刑诉-审判-多选-156 · 赵某伤害李某自诉附民案缺罪证处理二审反诉与附民效力|多选-156]]。

#### 一句话闭环记忆

> 🎯 **一眼判**：**谁上诉、谁进二审**——刑事进二审、附民没上诉却有错→**走审判监督**；附民进二审、刑事没上诉却有错→**本二审一并纠正**（镜像相反）；**不得加重赔偿只护被告单独上诉**，原告也上诉可增加；**抗诉案件必开庭**，抗诉主体是原公诉同级院。


- 按《刑诉解释》407、409 条极简结论：
	- 仅刑事上诉 / 抗诉、附民不上诉：刑走二审；附民期满生效，发现附民有错，**单独走再审纠正，不用一并审理**。
	- 仅附民上诉、刑事不上诉：附民走二审；刑事期满生效，发现刑事有错，**刑事启动再审，附民二审和刑事再审一并审理**。
	- 刑、民都上诉：两部分均未生效，二审可直接一并改判，无需再审。

## 主观题万能说理模板

> "依《刑诉解释》相关规定，被害人因财物被犯罪分子**非法占有、处置**而遭受损失的，应当依法予以**追缴或者责令退赔**，被害人提起附带民事诉讼的，人民法院不予受理；因**人身权利受到犯罪侵犯**或者**财物被毁坏**而遭受物质损失的，被害人有权提起附带民事诉讼，但**因人身损害间接导致**的经济损失不属于赔偿范围。若侵权人系**国家机关工作人员在行使职权时**侵犯他人人身、财产权利构成犯罪的，被害人及其法定代理人、近亲属提起附带民事诉讼的，人民法院不予受理，应当告知其可以依法申请**国家赔偿**（该排除同样及于以单位为被告的诉请）。附带民事诉讼原告人限于**近亲属**（夫、妻、父、母、子、女、同胞兄弟姊妹），被告人范围中**同案犯在逃的不予列入**。本案中[某损失]属于[占有处置/毁坏/间接损失]，故[能否]提起附带民事诉讼；[某人]系/不系近亲属，故[能否]作为原告人；[某人]在逃，故不列为被告人。若案件因附带民事诉讼被告人一方单独上诉进入第二审程序，则二审不得加重其赔偿数额；若原告人一并上诉，则不受此限。"
