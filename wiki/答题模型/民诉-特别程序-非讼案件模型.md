# 📐 特别程序（非讼案件）· 完整答题模型（共性规则 + 六类案件门槛 + 实现担保物权 + 司法确认）

> **核心一句**：特别程序审的不是"你我之间谁对谁错"的**争议**，而是"某个法律状态需要法院**确认一下**"的**非讼事项**。考试主线是**"识别非讼 → 共性规则（一审终审/独任/30日/四不）→ 六类案件各自门槛 → 裁判效力与'新判决取代' → 救济只剩异议"**；最毒的陷阱是**给非讼裁判安上"上诉/再审/复议"的救济**、**把"有争议走诉讼"与"无争议走特别程序"两条轨道搞混**、**司法确认忘了"双方共同+30日"**、**实现担保物权跑去被告住所地法院**。

> 🔎 **《民事诉讼法》（2023修正）第十五章"特别程序"核心条文速查**（条号已逐条在本地官方全文中核验）：
> - **第184条【适用范围】**：选民资格案件、宣告失踪或者宣告死亡案件、**指定遗产管理人案件**（2023新增一节）、认定公民无民事行为能力或者限制民事行为能力案件、认定财产无主案件、确认调解协议案件和实现担保物权案件，适用本章规定。
> - **第185条【一审终审与审理组织】**：实行**一审终审**。**选民资格案件或者重大、疑难的案件，由审判员组成合议庭**审理；其他案件由审判员**一人独任**审理。
> - **第186条【发现争议→终结】**：审理过程中发现本案属于**民事权益争议**的，应当**裁定终结特别程序**，并告知利害关系人**可以另行起诉**。
> - **第187条【审限】**：应当在**立案之日起30日内**或者**公告期满后30日内**审结。有特殊情况需要延长的，由**本院院长**批准。但审理**选民资格的案件除外**。
> - **第188-189条【选民资格】**：选举日的**5日以前**向**选区所在地基层法院**起诉；必须在**选举日前**审结；审理时**起诉人、选举委员会的代表和有关公民必须参加**。
> - **第190-193条【宣告失踪、宣告死亡】**：下落不明满**2年**申请宣告失踪；下落不明满**4年**、或因意外事件下落不明满**2年**、或因意外事件下落不明经有关机关证明不可能生存的，申请宣告死亡；均向**下落不明人住所地基层法院**提出。公告期：失踪**3个月**、死亡**1年**、意外+证明不可能生存**3个月**；期满作出**判决**。重新出现的，经本人或利害关系人申请，法院应当作出**新判决，撤销原判决**。
> - **第198-201条【认定无/限制行为能力】**：由**利害关系人或者有关组织**向**该公民住所地基层法院**提出；必要时**鉴定**；**近亲属为代理人（申请人除外）**，推诿的法院指定；健康许可的还应询问本人意见；原因消除的，经本人、利害关系人或有关组织申请，作出**新判决，撤销原判决**。
> - **第202-204条【认定财产无主】**：由公民、法人或其他组织向**财产所在地基层法院**申请；发出**财产认领公告，满1年**无人认领的，**判决**认定无主、收归国家或集体所有；原财产所有人或继承人出现，在民法典诉讼时效期间内提出请求、审查属实的，作出**新判决，撤销原判决**。
> - **第205-206条【确认调解协议（司法确认）】**：由**双方当事人**自调解协议**生效之日起30日内共同**提出；法院邀请调解组织先行调解的→**作出邀请的法院**；调解组织自行调解的→**当事人住所地、标的物所在地、调解组织所在地基层法院**（应由中院管辖的纠纷→相应中院）。审查符合规定→**裁定调解协议有效**，一方拒不履行的对方可**申请执行**；不符合→裁定驳回，当事人可变更原协议/达成新协议，也可**起诉**。
> - **第207-208条【实现担保物权】**：由**担保物权人以及其他有权请求实现担保物权的人**向**担保财产所在地或者担保物权登记地基层法院**提出。审查符合规定→**裁定拍卖、变卖担保财产**，当事人可据以**申请执行**；不符合→裁定驳回，当事人可以**起诉**。
> - **《民诉法解释》（法释〔2022〕11号修正）"十七、特别程序"部分**（条号已逐条核验）：§341-346（宣告失踪死亡配套：指定审理期间财产管理人与判决时指定财产代管人、**变更代管人双轨**、失踪判决后满4年申请宣告死亡应受理仍须公告、共同申请人、公告内容、撤回申请裁定终结）；§347（诉讼中提出认定当事人行为能力→受诉法院按特别程序立案、**原诉讼中止**）；§348（财产无主公告期间有人请求→**裁定终结特别程序告知另行起诉**）；§351-358（司法确认：本人或符合条件的代理人申请、多调解组织均有管辖权最先立案优先、**书面或口头**均可、材料限期补交、**不予受理五情形**、双方共同到场核实、撤回、**驳回六情形**）；§359-371（实现担保物权：主体扩张至抵押人出质人等、权利质权管辖、专门法院、多个担保物分别申请均受理、**物保+人保违反约定顺序不予受理**、后顺位担保物权人可申请、申请材料、5日送达+被申请人5日内异议、**独任审查（标的额超基层管辖范围→合议庭）**、审查内容、**无争议准许/部分争议部分准许/实质争议驳回**、可保全）；§372（**特别程序纠错=向作出裁判的法院提异议**；对确认调解协议、准许实现担保物权的裁定：当事人**15日**内、利害关系人自知道权益受侵害之日起**6个月**内提出）；配套外围：§143（特别程序**不得调解**）、§295（一）（**第三人撤销之诉不予受理**）、§378（**不得申请再审**）、§412（不予受理**抗诉**）、§460（实现担保物权裁定、确认调解协议裁定由**作出裁定的法院或同级被执行财产所在地法院执行**；认定财产无主判决由作出判决的法院收归国家或集体）、§204（实现担保物权申请费：准许→债务人、担保人负担；驳回→申请人负担；另行起诉的已交申请费可从受理费中扣除）。

> ⚠️ **诚实标注（本地不可核验来源）**：①本模型所有《民事诉讼法》条号均以 2023 修正版官方全文（ssf.gov.cn PDF）逐条 grep 核验、《民诉法解释》条号均以法释〔2022〕11号官方全文逐条核验。②**《民诉法解释》原文内部引用的民诉法条号仍是 2021 旧版号**（如解释§351/§352 引"民事诉讼法第二百零一条"＝今205条司法确认、解释§359 引"第二百零三条"＝今207条实现担保物权，旧号偏移-4）——读原文时勿被旧号带偏，本模型一律换算为 2023 现行条号。③宣告失踪/死亡的**实体要件**在《民法典》总则编（失踪§40-45、死亡§46-53、财产代管人变更§44），本地无民法典全文，条号以官方为准：[国家法律法规数据库 flk.npc.gov.cn](https://flk.npc.gov.cn/)。④**失踪人财产诉讼管辖=总则编解释第15条第2款、担保物权实现案件的"担保物权登记地"细化=民法典担保制度解释第21条**，二者本地均无全文，条号系 MEMORY 已核验锚点，仍以官方为准。⑤《人民调解法》§31-33（调解协议约束力/就协议起诉/司法确认）本地无全文，内容以真题卡322已核验的官方转载文本为据。
>
> ⚠️ **易记错点**：①特别程序的结案文书**判决、裁定都有**——选民资格/宣告失踪死亡/认定行为能力/认定财产无主用**判决**，司法确认/实现担保物权用**裁定**，终结特别程序用**裁定**；②"一审终审"≠"不能纠错"——纠错通道是**向作出裁判的法院提异议**（解释§372），不是上诉/再审/复议；③宣告死亡公告期原则**1年**，但"意外事件+有关机关证明不可能生存"只要**3个月**；④变更财产代管人**双轨**：代管人**自己**申请变更→特别程序，**别人**争着当→告**现任代管人**、普通程序；⑤司法确认必须**双方共同**申请（一方单独申请不受理）且**30日**从"调解协议生效"起算；⑥实现担保物权管辖认**担保财产所在地/登记地**，不认被告住所地，也不看主合同的仲裁条款（抵押合同没约定仲裁就与仲裁无关）；⑦实现担保物权**标的额超过基层法院管辖范围的仍由基层法院管**，只是要组成**合议庭**审查（解释§367）。

## 二、判别模型（识别非讼 → 共性规则 → 分类门槛 → 效力 → 救济）

```
          【某个"法律状态"需要法院确认：失踪？死亡？无行为能力？无主？
            调解协议要执行力？担保物要变现？选民名单有错？】
                              │
   ▼ 第一关：有没有"民事权益争议"？（§186）
   │
   ├─ 无争议（纯状态确认）──→ 特别程序（非讼轨道）
   └─ 审理中发现有争议 ──→ 裁定终结特别程序，告知另行起诉
      （财产无主公告期有人认领＝解释§348；实现担保物权有实质争议＝解释§370(三)）
                              │
   ▼ 第二关：共性规则（§185-187 + 解释四不）
   │
   ├─ 一审终审（判决/裁定作出即生效）
   ├─ 原则独任；选民资格 or 重大疑难 → 合议庭（担保物权标的额超基层管辖也合议，解释§367）
   ├─ 审限：立案之日起30日 或 公告期满后30日；延长→院长批；选民资格除外
   └─ 四不：不得调解 / 不能上诉 / 不得再审 / 不受理三撤与抗诉
                              │
   ▼ 第三关：进哪一节？各自门槛（见第四节横向对照表）
   │
   ├─ 选民资格：选举日5日前 → 选区所在地基层法院（§188）
   ├─ 宣告失踪(满2年)/死亡(满4年或意外满2年) → 下落不明人住所地基层法院（§190-191）
   ├─ 认定无/限制行为能力 → 该公民住所地基层法院（§198）
   ├─ 认定财产无主 → 财产所在地基层法院（§202）
   ├─ 司法确认：双方共同+生效30日内 → 邀请法院/三地基层法院（§205）
   └─ 实现担保物权 → 担保财产所在地或登记地基层法院（§207）
                              │
   ▼ 第四关：裁判效力（§193/201/204/206/208）
   │
   ├─ 四类"判决"案件：情势变化（人回来了/病好了/原主出现）→ 新判决撤销原判决
   └─ 两类"裁定"案件：确认调解协议裁定、准许拍卖变卖裁定 → 可直接申请执行
                              │
   ▼ 第五关：救济出口（不能上诉 ≠ 没有出口）
   │
   ├─ 认为裁判有错 → 向作出该裁判的法院提异议（解释§372；
   │    对司法确认/准许实现担保物权裁定：当事人15日、利害关系人6个月）
   ├─ 被驳回/被终结 → 另行起诉（司法确认被驳回还可变更协议/达成新协议）
   └─ 状态事实变化 → 申请新判决取代原判决（不叫再审！）
```

> **一句话总诀**：**「无争议进特别，有争议裁终结；一审终审独任审、三十日内院长延；选民资格全例外；四判决遇变化新判决取代，两裁定生效力直接执行；不服不许上诉再审，回原法院提异议」**

## 三、高频干扰选项

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据） |
|---|---|---|
| **给非讼裁判装"上诉/再审/复议"** | "对司法确认裁定不服，可向上一级法院上诉/申请再审/申请复议。" | **❌ 全错。**特别程序一审终审（§185）、不得再审（解释§378），也无复议通道；唯一出口是**向作出裁定的法院提异议**（解释§372）。 |
| **两条轨道互串** | "利害关系人争当财产代管人的，向法院申请变更、适用特别程序。" | **❌ 错。**他人争管＝对抗性争议，应以**现任代管人为被告起诉、普通程序**；只有**代管人本人**申请变更才比照特别程序（解释§342）。 |
| **司法确认一方申请** | "一方当事人可持调解协议单独申请司法确认。" | **❌ 错。**须**双方**当事人自协议**生效之日起30日内共同**提出（§205）。 |
| **司法确认包办确权** | "调解协议约定房屋归买方所有，可申请司法确认赋予执行力。" | **❌ 错。**协议内容**涉及物权、知识产权确权**的，不予受理/驳回（解释§355(五)）；身份关系确认解除同样排除（§355(三)）。 |
| **担保物权管辖跟人走** | "实现担保物权应向被申请人（债务人）住所地法院/主合同约定的仲裁委提出。" | **❌ 错。**认**担保财产所在地或担保物权登记地基层法院**（§207）；主合同仲裁条款不当然及于未约定仲裁的抵押合同。 |
| **有异议就全案驳回** | "一名抵押人提出实质争议，法院应驳回全部实现担保物权申请。" | **❌ 错。**部分实质争议的，**无争议部分照样裁定准许**拍卖变卖，有争议部分驳回告知起诉（解释§370(二)）。 |
| **"人回来了"走再审** | "被宣告死亡人重新出现，利害关系人应申请再审撤销原判决。" | **❌ 错。**经本人或利害关系人申请，法院**作出新判决、撤销原判决**（§193）——是"新判决取代"机制，不是再审。 |
| **公告期一刀切** | "宣告失踪和宣告死亡的公告期均为一年。" | **❌ 错。**失踪**3个月**；死亡**1年**；意外事件+有关机关证明不可能生存的死亡公告**3个月**（§192）。 |

## 四、相邻制度对照

### 4.1 特别程序 vs 普通（争讼）程序

| 事项 | 特别程序（非讼） | 普通程序（争讼） |
|---|---|---|
| 解决对象 | 无争议的法律状态确认 | 平等主体间的民事权益**争议** |
| 启动 | 起诉（仅选民资格）/申请 | 起诉 |
| 审级 | **一审终审** | 两审终审 |
| 审理组织 | 原则**独任**；选民资格、重大疑难合议 | 普通程序合议（独任制有法定适用范围） |
| 调解 | **不得调解**（解释§143） | 可以调解 |
| 审限 | 30日（或公告期满后30日），院长批延长；选民资格除外 | 六个月起算的普通审限体系 |
| 救济 | 不能上诉、不得再审、无三撤与抗诉；**向原法院提异议** | 上诉、再审、第三人撤销之诉、抗诉俱全 |
| 发现争议 | **裁定终结**，告知另行起诉（§186） | —— |

### 4.2 六类案件横向对照（一表打尽；含2023新增指定遗产管理人）

| 案件 | 申请人/起诉人 | 管辖法院（均基层） | 审理组织 | 公告期 | 结案文书 | 效力与纠错 |
|---|---|---|---|---|---|---|
| **选民资格**（§188-189） | 不服选举委员会申诉处理决定的公民（选举日**5日前**起诉） | **选区所在地** | **必须合议庭**（§185） | 无；**选举日前**必须审结，不受30日审限 | 判决（选举日前送选举委员会和起诉人，通知有关公民） | 一审终审；起诉人、选举委员会代表和有关公民**必须参加** |
| **宣告失踪/宣告死亡**（§190-193） | 利害关系人（**含债权人**；多人＝共同申请人，解释§344） | **下落不明人住所地** | 独任（重大疑难合议） | 失踪**3个月**；死亡**1年**；意外+证明不可能生存**3个月** | **判决**（宣告或驳回） | 重新出现→经本人/利害关系人申请**新判决撤销原判决**；判决宣告失踪同时依民法典§42指定**财产代管人**（解释§341） |

| **认定财产无主**（§202-204） | 公民、法人或其他组织 | **财产所在地** | 独任（重大疑难合议） | **认领公告满1年** | **判决**认定无主，收归国家或集体 | 公告期有人认领→**裁定终结**告知另诉（解释§348）；原主/继承人在诉讼时效内出现→**新判决撤销原判决** |
| **确认调解协议**（§205-206） | **双方当事人共同**（生效30日内；书面或口头，解释§353） | 邀请先行调解的法院／当事人住所地·标的物所在地·**调解组织所在地**（应归中院的向中院） | 独任 | 无 | **裁定**（确认有效或驳回） | 有效裁定→**可申请执行**；驳回→变更/新协议/起诉；纠错=异议（当事人**15日**/利害关系人**6个月**，解释§372） |
| **实现担保物权**（§207-208） | 担保物权人＋其他有权请求实现的人（**含抵押人、出质人**等，解释§359） | **担保财产所在地或担保物权登记地**（票据等权利凭证→持有人住所地；无凭证权利质权→出质登记地，解释§360） | 独任；**标的额超基层管辖范围→合议庭**（仍在基层，解释§367） | 无（受理后**5日**送达，被申请人**5日**内可提异议，解释§366） | **裁定**（准许拍卖变卖／部分准许／驳回） | 准许裁定→**可申请执行**（解释§460）；实质争议→驳回告知**起诉**；纠错=异议（15日/6个月，解释§372）；申请费：准许→债务人担保人负担，驳回→申请人负担（解释§204） |

## 五、万能五步答题模型

*   🚗 **统一案例（一案贯穿五步）**：老陈借给跑船的赵大海 **50万元**，赵大海还以自己名下一间**位于 C 区的门面房**抵押给老陈并办了登记。2024年3月起赵大海随船出海后**下落不明**；老陈同时还与邻居孙婶因宅基地围墙纠纷经村人民调解委员会达成了一份"孙婶赔老陈 2 万元"的调解协议。围绕"赵大海的债怎么办、调解协议怎么落地"，老陈把特别程序六类案件几乎跑了个遍。

### 第一步：识别非讼——这事有没有"争议对手"？

> **无争进特别，有争裁终结**

#### 概述

特别程序的入场券只有一张：**申请事项不存在民事权益争议**。法院只是给某个法律状态"盖章确认"（人失踪了没有？协议有效没有？担保物能不能拍？），不是在两个吵架的人之间断是非。因此：

- 一开始就有对抗（你要当代管人、我不让）→ 根本进不了特别程序，直接**起诉、普通程序**；
- 进来之后才**发现有争议**（公告期有人认领无主财产、被申请人对担保物权提实质争议）→ **裁定终结特别程序，告知另行起诉**（§186、解释§348、§370(三)）。

#### 大白话讲解

老陈想申请宣告赵大海失踪——赵大海下落不明满2年、没人跳出来说"他没失踪"，这是**纯状态确认**，特别程序收。

对比一幕：宣告失踪后法院指定赵大海的妻子当财产代管人，赵大海的父亲不服，说"儿媳会坑我孙子，我要当代管人"——这就不是"确认状态"了，是**老爷子和儿媳抢代管权**，两人对着干。这种事特别程序不收，老爷子得**以现任代管人（儿媳）为被告去打官司，普通程序**。

再对比一幕：老陈拿抵押登记去申请拍卖赵大海的门面房，如果这时冒出个王某说"这房其实是我的、抵押合同是伪造的"——法院不会在特别程序里查真伪，而是对争议部分**裁定驳回，让你们起诉去**。

| 场景 | 有无争议 | 走哪条轨道 |
|---|---|---|
| 申请宣告下落不明满2年的赵大海失踪 | 无 | 特别程序 |
| 赵父与儿媳争当财产代管人 | 有（对抗性） | 以现任代管人为被告起诉，普通程序 |
| 无主财产公告期内有人跑来认领 | 有（中途冒出） | 裁定终结特别程序，告知另诉 |
| 被申请人对担保物权提实质争议 | 有 | 争议部分裁定驳回，告知起诉 |

#### 一句话闭环记忆

> 🎯 **一眼判**：先问"有没有人跟申请人对着干"——没有→特别程序；一开始就有→直接起诉普通程序；中途冒出来→裁定**终结**特别程序、另行起诉（终结用裁定，不是判决）。

---

### 第二步：套共性规则——一审终审、独任、30日、"四不"

> **一终独任三十日，不调不上不再不抗**

#### 概述

只要进了特别程序，不管哪一类案件，先套四条共性（§185-187 + 解释配套）：

- **一审终审**：判决、裁定一作出即生效，没有二审；
- **审理组织**：原则**独任**；两个例外要**合议庭**——①选民资格案件（法定必须合议），②重大、疑难案件（外加实现担保物权标的额超基层管辖范围的，解释§367）；
- **审限**：立案之日起**30日**内、有公告的**公告期满后30日**内审结；延长报**本院院长**批准；**选民资格案件不受此限**（因为它被"选举日前审结"这个更硬的死线管着）；
- **"四不"**：**不得调解**（解释§143，非讼没有"互谅互让"的对象）、**不能上诉**（一审终审）、**不得申请再审**（解释§378）、**不受理第三人撤销之诉和抗诉**（解释§295(一)、§412）。

#### 大白话讲解

老陈申请宣告赵大海失踪，法院一个审判员**独任**就办了；如果这案子牵扯船公司赔偿等特别复杂的背景，才升级成合议庭。立案后掐表：先登**3个月**寻人公告，公告期满后**30日内**必须出判决；实在办不完，承办人得找**自家院长**签延期，不是找上级法院。

判决一出**立刻生效**——老陈别琢磨"对方会不会上诉"，特别程序里**没有上诉这回事**；也别琢磨"过两年申请再审"，特别程序**不进再审的门**；检察院抗诉、案外人第三人撤销之诉，统统不收。甚至连"调解一下"都不行——跟谁调？对面根本没有对手。

**唯一的口子**留在第五步讲：向**作出裁判的法院提异议**。

#### 一句话闭环记忆

> 🎯 **一眼判**：特别程序＝**一审终审＋原则独任（选民资格/重大疑难/超标的额担保案合议）＋30日或公告期满后30日（院长批延长、选民资格除外）＋不调解不上诉不再审不抗诉**。

---

### 第三步：对号入座——六类案件各自的门槛（谁申请、去哪儿、等多久）

> **五日选民住所失踪，本人住所财产所在，双方三十调解协议，担保财产登记地**

#### 概述

共性套完，看这案子落在哪一节，把"**申请人—管辖—期间**"三件套对准（完整横向表见第四节 4.2，此处给记忆主干）：

1. **选民资格**：选举日**5日前**→**选区所在地**；
2. **宣告失踪/死亡**：利害关系人（含债权人）→**下落不明人住所地**；失踪满**2年**、死亡满**4年**（意外满2年；意外+机关证明不可能生存不受期间限制）；
3. **认定无/限制行为能力**：利害关系人**或有关组织**→**该公民住所地**；
4. **财产无主**：公民/法人/其他组织→**财产所在地**；
5. **司法确认**：**双方共同**、协议生效**30日内**→邀请法院或三地（当事人住所地/标的物所在地/调解组织所在地）基层法院；
6. **实现担保物权**：担保物权人＋抵押人出质人等→**担保财产所在地或登记地**。

#### 大白话讲解

把老陈这一年跑的法院排一排：

- **申请宣告赵大海失踪**：老陈是债权人＝利害关系人，**有资格**申请；去**赵大海住所地**基层法院；赵大海 2024年3月失联，到 2026年3月**满2年**才够门槛。法院登**3个月**寻人公告，期满判决宣告失踪，并同时指定财产代管人（解释§341）。若赵大海是因沉船事故失联且海事部门证明不可能生存，老陈可以直接申请宣告**死亡**，公告只要**3个月**；普通的下落不明要熬满**4年**、公告**1年**。
- **实现担保物权**：门面房在 **C 区**、抵押登记也在 C 区，老陈就去 **C 区基层法院**申请拍卖——不看赵大海（被申请人一方）住所地，主合同里就算写了仲裁条款、抵押合同没写，也拦不住这条路。
- **司法确认**：老陈想让"孙婶赔2万"的调解协议有执行力，必须拉着**孙婶一起**、在协议**生效30日内**，去老陈住所地/孙婶住所地/村调解委所在地任一基层法院申请，**书面口头都行**；孙婶不去，这条路就断了（那就只能拿协议当合同去**起诉孙婶**——注意被告是孙婶，不是调解委员会）。

**记忆锚**：管辖全是**基层法院**打底（司法确认涉中院管辖纠纷、担保物权涉海事等专门法院时例外），方位词各认各的——选民认**选区**、失踪认**人**（住所地）、无主认**物**（财产所在地）、担保认**担保物**（所在地/登记地）、司法确认认**三地任选**。

#### 一句话闭环记忆

> 🎯 **一眼判**：失踪2年死亡4年（意外减半、证明不可能生存不限）、公告3月/1年/3月；司法确认＝**双方＋30日＋三地基层**；担保物权＝**担保财产所在地/登记地基层**——谁申请、去哪儿、等多久，三件套一错全错。

---

### 第四步：看裁判效力——"新判决取代"与"两个能执行的裁定"

> **四判决新判取代，两裁定直接执行**

#### 概述

特别程序的裁判分两队：

- **判决队**（选民资格/宣告失踪死亡/认定行为能力/财产无主）：确认的是**会变化的状态**——人可能回来、病可能痊愈、原主可能现身。状态一变，经申请，法院**作出新判决、撤销原判决**（§193/§201/§204）。这不叫再审、不叫上诉，是特别程序自带的"状态刷新"机制；
- **裁定队**（确认调解协议/准许实现担保物权）：赋予的是**执行力**——一方不履行确认过的调解协议，对方**直接申请执行**（§206）；准许拍卖变卖的裁定，当事人**据以申请执行**（§208），由作出裁定的法院或同级被执行财产所在地法院执行（解释§460）。

#### 大白话讲解

三个"剧情反转"：

- **赵大海回来了**：被宣告失踪（甚至死亡）的赵大海突然自己走下船——不用打再审，赵大海本人或利害关系人向法院申请，法院**作出新判决，撤销原判决**，失踪/死亡状态解除。
- **门面房开拍**：C 区法院审查后，赵大海一方没提实质争议，裁定**准许拍卖**——老陈拿着这张裁定**直接申请强制执行**，不用再打一场诉讼。要是赵大海的另一位共同抵押人提出"我是被骗签的"这种**实质争议**，法院就**只驳回有争议那套房**、无争议部分照样准许（解释§370(二)）——"部分争议部分驳回，无争议部分准许"。
- **孙婶赖账**：调解协议经司法确认后孙婶不给钱，老陈**直接申请执行**；反过来，如果当初法院**驳回**了确认申请（比如协议里写了"围墙那块地归老陈"——涉**物权确权**，解释§355(五)不收），老陈孙婶可以修改协议、另达新协议，或者干脆**起诉**。

#### 一句话闭环记忆

> 🎯 **一眼判**：人回来/病好了/原主出现→**新判决撤销原判决**（不是再审）；司法确认裁定与准许拍卖变卖裁定→**直接申请执行**；司法确认被驳回→改协议/新协议/起诉三选一。

---

### 第五步：找救济出口——不能上诉再审，只剩"异议+另诉+新判决"

> **不服回原院提异议，驳回终结另起诉**

#### 概述

特别程序把上诉、再审、复议、三撤、抗诉的门全焊死了，但留了三个出口：

1. **异议**（解释§372）：当事人、利害关系人认为特别程序的判决、裁定有错误的，**向作出该裁判的法院**提出异议；异议成立→作出**新的判决、裁定**撤销或改变原裁判；不成立→裁定驳回。对**确认调解协议、准许实现担保物权**两种裁定，期限卡死：当事人自收到裁定之日起**15日**、利害关系人自知道或应当知道权益受侵害之日起**6个月**；
2. **另行起诉**：被裁定终结/驳回（有争议）的，走争讼轨道；
3. **新判决取代**：状态变化的，按第四步申请新判决。

#### 大白话讲解

孙婶事后越想越亏："2万赔多了！"她能怎么办？**上诉？没门**（一审终审）。**再审？不收**（解释§378）。**复议？没这通道**。她只剩一条路：在收到裁定 **15日内**，回到**作出确认裁定的那家法院**提**异议**——法院审查，异议成立就出新裁定撤销原裁定，不成立就驳回。要是受损的不是当事人而是案外的利害关系人（比如发现调解协议损害了自己权益的第三人），期限放宽到**知道权益受侵害之日起6个月**。

同样，赵大海对"准许拍卖门面房"的裁定不服，也是 15 日内向 C 区法院提异议，而不是去中院上诉。

**警惕反向陷阱**：命题人最爱把"异议"包装成"向上一级法院申请复议""申请再审"——记住方向词：**向"作出裁判的"法院、提"异议"**，两个词都对才是正确选项。

#### 一句话闭环记忆

> 🎯 **一眼判**：对特别程序裁判不服＝**回原法院提异议**（司法确认/担保物权裁定：当事人15日、利害关系人6个月）；被驳回或终结＝**另行起诉**；状态变了＝**申请新判决**——三个出口以外的救济选项全是坑。

## 六、易混考点辨析

*   **变更财产代管人：特别程序 vs 普通程序**：
    *   *代管人本人*有正当理由申请变更→**比照特别程序**（裁定撤销身份、另行指定）；*其他利害关系人*要求变更→**以原代管人为被告起诉、普通程序**（解释§342）。谁发起、跟谁争，决定走哪条轨道。
*   **"新判决撤销原判决" vs 再审**：
    *   四类判决案件因**状态变化**（人重现/行为能力恢复/原主出现）的刷新机制是**新判决取代**；再审针对**生效裁判确有错误**，且特别程序案件**根本不得再审**。题面写"申请再审撤销宣告死亡判决"必错。
*   **司法确认裁定 vs 法院调解书**：
    *   司法确认对象是**诉讼外调解组织**的协议，双方**共同申请**、以**裁定**确认；法院调解书是**诉讼中**法院主持达成、**签收生效**、本身即有执行力，无需再确认。二者救济也不同（调解书可申请再审主张调解违法/违愿）。
*   **实现担保物权程序 vs 担保物权诉讼**：
    *   非讼程序只处理**无实质争议**的变现请求，快、省（申请费准许时由债务人担保人负担）；一旦有实质争议→驳回后**另行起诉**，已交申请费可从案件受理费中扣除（解释§204）。
*   **宣告失踪 vs 宣告死亡的关系**：
    *   二者**非前置关系**，满足死亡条件可直接申请宣告死亡；但已宣告失踪的，**自失踪之日起满4年**申请宣告死亡的应当受理，失踪判决即失踪证明，**仍须依§192公告**（解释§343）。
*   **人民调解协议未确认 vs 已确认**：
    *   未经司法确认＝有约束力的"合同"，不履行只能**以对方当事人为被告起诉**（人民调解法§32，调解委员会不是被告）；经确认＝**可直接申请执行**（§206）。

## 七、命题陷阱清单

1.  **"对司法确认/准许拍卖裁定不服可以上诉、申请再审或复议"** —— 错！一审终审（§185）＋不得再审（解释§378），只能向**作出裁判的法院提异议**（解释§372，当事人15日/利害关系人6个月）。
2.  **"利害关系人争当财产代管人，向法院申请变更、适用特别程序"** —— 错！他人争管＝对抗性争议，应**以现任代管人为被告起诉、普通程序**；代管人**本人**申请变更才走特别程序（解释§342）。
3.  **"一方当事人可以单独申请司法确认"／"随时都能申请"** —— 错！须**双方共同**、自协议**生效之日起30日内**提出（§205）。
4.  **"调解协议约定房屋所有权归属，可申请司法确认"** —— 错！涉及**物权、知识产权确权**及**身份关系确认解除**的协议不能司法确认（解释§355）。
5.  **"实现担保物权向被申请人住所地法院/按主合同仲裁条款向仲裁委提出"** —— 错！认**担保财产所在地或担保物权登记地基层法院**（§207）；抵押合同未约定仲裁的，主合同仲裁条款管不到。
6.  **"部分抵押人提实质争议，应驳回全部申请"** —— 错！**无争议部分照样裁定准许**拍卖变卖，仅争议部分驳回告知起诉（解释§370(二)）。
7.  **"被宣告死亡人重新出现，应申请再审"** —— 错！经本人或利害关系人申请，**新判决撤销原判决**（§193）。
8.  **"宣告失踪、宣告死亡公告期均为一年"** —— 错！失踪**3个月**、死亡**1年**、意外事件+机关证明不可能生存**3个月**（§192）。
9.  **"特别程序案件可以调解结案"** —— 错！特别程序案件**不得调解**（解释§143）——非讼案件没有可供互谅互让的对方当事人。
10. **"实现担保物权标的额超过基层法院管辖范围的，由中院管辖"** —— 错！仍由**基层法院**管辖，只是应**组成合议庭**审查（解释§367）。
