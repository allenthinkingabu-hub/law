# 📐 保证 vs 债的加入 · 辨析答题模型（先定性，再套责任）

> 第三人对债权人撂一句"这债我管 / 我兜底 / 我跟他一起还"——**这到底是①保证 ②债的加入（并存的债务承担）③免责的债务承担（债务转移）④还是只是安慰函**？定性不同，**责任天差地别**（有没有保证期间、有没有先诉抗辩、原债务人退不退出、谁向谁追偿全不一样）。这是 [[保证合同]] 的"入口考点"——[[民法-合同-保证模型]] 解决"是保证之后怎么办"，**本模型解决"它到底是不是保证"**。
> **姊妹 / 概念** → [[保证合同]] · [[担保]] · [[债务承担]] · [[民法-合同-保证模型]]（认定为保证后走五步）。
> **适用真题**：[[典型合同-多选-32|多选-32·保证意思认定（保证 vs 安慰函）]]。
>
> 🔎 **法条已联网核实（2026-06-13）**：[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/) §681 保证定义 · §551 免责的债务承担 · §552 并存的债务承担（债务加入）· §519 连带债务内部追偿；[担保制度解释全文](https://ghzyj.gz.gov.cn/sjb/zw/zcfg/content/post_9466449.html) **§36 增信文件定性 + 难以确定保证还是债加入→推定为保证** · §12 法代以公司名义加入债务参照公司担保规则。
> ⚠️ **新旧法提示**：旧担保法解释§18"注册资金不实 / 注册资金保证"等规则已于 2021 **废止**；现行一律依 **§36 + §681 判有无"担保意思表示"**。

## 一、核心考情

- **频率**：★★★☆（保证合同的"定性前置题"，常以多选 / 案例形式出现，近年因《民法典》新增 §552 债务加入而升温）。
- **命题核心**：给一段第三人的承诺文字（保函 / 安慰函 / 差额补足函 / "我和他一起还"），让你**定性**，再问**法律后果**（能否主张保证期间、先诉抗辩、原债务人是否脱身、追偿路径）。
- **必抓三点**：①**保证 vs 债加入**（最高频，差在"从属性 + 保证期间 + 先诉抗辩"）②**意思不明 → 推定为保证**（§36，对承诺人更有利）③**安慰函 / 增信文件**有无"担保意思表示"。

## 二、万能三步：先定性 → 再定后果 → 法代特别审查

### 第一步：四选一定性（核心辨析表）

| 维度          | **保证**（§681）                      | **债的加入**（§552，并存的债务承担）                    | **免责的债务承担**（§551，债务转移）  | **安慰函 / 增信文件**（§36）         |
| ----------- | --------------------------------- | ----------------------------------------- | ----------------------- | --------------------------- |
| 性质          | 从债务，有**从属性 + 补充性**                | **独立的连带债务**，无从属性                          | 债务**转移**，原债务人退出         | 看有无"担保意思"：有→按保证；无→可能仅道义、不担责 |
| 谁还在还        | 债务人 + 保证人                         | 债务人 + 加入人**都在**（连带）                       | **只剩**新债务人              | ——                          |
| 怎么成立        | 保证人与债权人**达成保证合意**（签字盖章 / 保函，§685） | 加入人通知债权人 / 向债权人表示愿加入、**债权人未在合理期限内明确拒绝**即可 | **必须经债权人同意**（催告未表示=不同意） | 看文件意思表示                     |
| 保证期间 / 先诉抗辩 | **有**（一般保证有先诉抗辩§687）              | **无**（按连带债务，债权人可直接找加入人）                   | 无                       | 若定性为保证则有                    |
| 追偿          | §700 向**债务人**追偿 + 法定代位            | §519 **连带债务内部份额**追偿                       | ——                      | 若按保证→§700                   |

> 🔑 **一句话**：保证是"**替你扛、你先上**（从属 + 补充）"；债加入是"**这债也算我一份，我跟你平起平坐**（独立连带）"；债务转移是"**这债归我了，你走**"；安慰函是"**得看那张纸到底说没说担保的话**"。

### 第二步：分不清保证还是债加入怎么办？——三个判准 + 兜底推定

**实务三判准**（从强到弱）：
1. **有没有自身利益**：纯为他人作担保、自己无直接利益 → 倾向**保证**；承诺人**自己有直接经济利益**（为关联公司、有对价、本就是利益相关方）→ 倾向**债加入**。
2. **文字表述**：出现"**保证 / 担保 / 保证人 / 连带责任保证**" → 保证；出现"**共同偿还 / 我也还 / 该债务由我承担 / 加入**" → 债加入。
3. **是否表达补充性**："债务人不能清偿时由我……" → 补充性 = 保证味；"我和债务人一起还" → 并列 = 债加入味。

**兜底推定（§36 第二款，必考）**：增信 / 承诺文件**难以确定是保证还是债务加入的，认定为保证**。
> 💡 **为什么往轻里推**：保证人有**保证期间 + 先诉抗辩 + 从属性**等多重保护，比连带债务的"债加入"**责任更轻**；意思不明时推定为保证，对承诺人更有利、符合"有疑义不利于条款拟定方"的精神。**别推成债加入！**

### 第三步：法定代表人以公司名义"加入债务"——按公司担保审查（解释§12）

法代以公司名义加入他人债务的，**认定效力时参照"公司为他人提供担保"的规则**（解释§12）——即需要公司**股东（大）会 / 董事会决议**（民法典§16 / 公司担保规则），无决议且相对人非善意的，对公司**不发生效力**。
> 🪤 **陷阱**：以为"债加入不是担保，不用决议"。错！§12 明确**参照担保规则**，照样要决议。

**老王小李例子（甲欠乙 100 万）**
- 丙对乙说"**甲不还我还**" → **保证**（补充性；丙有保证期间，一般保证还能先诉抗辩）。
- 丙对乙说"**这 100 万算我一份，我跟甲一起还**" → **债的加入**（§552，丙与甲连带，**无**保证期间、**无**先诉抗辩，乙可直接找丙；丙还了按 §519 找甲分担）。
- 丙出具《**差额补足函**》"甲还不够的我补上" → 有担保意思，**按保证处理**（§36）。
- 丙的函**含糊**，看不出是保证还是债加入 → **推定为保证**（§36 第二款），不是债加入。
- 丙是 A 公司法定代表人，**以 A 公司名义**出函加入债务 → 须 A 公司**决议**，否则效力参照公司越权担保（解释§12）。

## 三、命题人最爱的 5 个陷阱

1. **债加入当成保证**，给被告主张保证期间 / 先诉抗辩 —— 错！债加入是**连带债务**，**无**保证期间、**无**先诉抗辩。
2. **安慰函一律不担责** —— 错！若含"**担保意思表示**"（差额补足 / 流动性支持等），**按保证办**（§36 第一款）。
3. **意思不明推定为债加入** —— 错！**推定为保证**（§36 第二款，责任更轻）。
4. **法代以公司名义加入债务无需决议** —— 错！**参照公司担保规则**，要决议（解释§12）。
5. **债加入（并存）= 债务转移（免责）** —— 错！债加入原债务人**不脱身**（§552 连带）；债务转移原债务人**退出**且**须债权人同意**（§551）。

## 📐 口诀

> **"替你扛 + 你先上 = 保证（有期间、有先诉）；算我一份 + 一起还 = 债加入（连带、无期间无先诉）；这债归我你走人 = 债务转移（须债权人同意）。**
> **增信文件有担保的话就按保证；分不清保证还是债加入——往轻里推，认定为保证（§36）。**
> **法代拿公司名义加入债务，照样要决议（解释§12）。"**
