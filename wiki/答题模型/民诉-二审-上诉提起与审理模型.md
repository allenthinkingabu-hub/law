# 📐 二审上诉提起与审理 · 完整答题模型（主体对象期限 + 撤回限制 + 审理范围 + 审理方式）

> **核心一句**：[[民诉-一审-审理进程与裁判形式模型]]解决"一审这场官司怎么走完"，本模型解决"**输了不服怎么翻盘**"，一条主线四站：**谁能上诉告什么（主体＋对象＋期限＋递交路径，§171-174）→ 后悔了能撤吗（撤回上诉的准许与限制，§180＋解释§335）→ 二审看多宽（围绕上诉请求为原则＋全面审查例外，§175＋解释§321）→ 开不开庭（开庭原则＋径行裁判条件，§176＋解释§331）**。最毒陷阱是**把上诉期记成统一起算**（判决书分别送达、各自起算）、**让原审法院自行裁定驳回超期上诉**（原审只管移送，超期与否由二审审查）、**把二审当成全面审查**（围绕上诉请求，例外才全面）、**把诉讼和解协议当执行依据**（撤回上诉后依生效的一审判决执行）。
>
> 🔎 **核心条文速查**：
> - **民诉法§171【上诉期】**：不服地方法院第一审**判决**的，有权在判决书**送达之日起十五日**内向上一级法院上诉；不服第一审**裁定**的，在裁定书**送达之日起十日**内上诉。
> - **民诉法§157 II【可上诉裁定】**：对§157第一款**第一项至第三项**裁定（**不予受理、管辖权异议、驳回起诉**），可以上诉。**§59 II【无独三】**：人民法院**判决承担民事责任的第三人，有当事人的诉讼权利义务**（含上诉权）。
> - **民诉法§172-174【上诉状与移送】**：上诉应当**递交上诉状**（§172）；上诉状应当**通过原审法院提出**并按对方人数提出副本，当事人**直接向二审法院上诉**的，二审法院应当在**五日**内将上诉状**移交原审法院**（§173）；原审法院收到上诉状**五日**内将副本送达对方当事人，对方**十五日**内答辩、不答辩**不影响审理**；原审法院收到上诉状、答辩状，应当在**五日**内**连同全部案卷和证据报送二审法院**（§174）。
> - **解释§318【口头上诉与上诉费】**：宣判或送达时口头表示上诉的，应告知**必须在法定上诉期内递交上诉状**，未递交的**视为未提起上诉**；虽递交上诉状但未在指定期限交纳上诉费的，**按自动撤回上诉处理**。
> - **解释§315-317【二审当事人地位】**：双方当事人和第三人都上诉的**均列上诉人**（§315）；必要共同诉讼人一人或部分人上诉的**三分**（§317）：①仅对与**对方**之间权利义务分担有意见→对方为被上诉人，未上诉的同方依原审地位列明；②仅对**共同诉讼人之间**分担有意见→未上诉的同方为被上诉人，对方依原审地位列明；③对**双方之间及共同诉讼人之间**均有意见→未提起上诉的其他当事人**均为被上诉人**。
> - **民诉法§180【撤回上诉】**：二审法院**判决宣告前**，上诉人申请撤回上诉的，**是否准许，由第二审人民法院裁定**。**解释§335【不准撤回】**：二审中当事人申请撤回上诉，经审查认为**一审判决确有错误**，或者当事人之间**恶意串通损害国家利益、社会公共利益、他人合法权益**的，**不应准许**。**解释§337**：二审中达成和解协议的，法院可根据当事人请求审查并**制作调解书**；因和解申请撤诉、符合撤诉条件的应予准许。**解释§336**：二审中原审原告申请**撤回起诉**，须经其他当事人同意且不损害国家社会公共他人利益，准许的**一并裁定撤销一审裁判**，撤回起诉后**重复起诉的不予受理**。
> - **民诉法§175【审理范围】**：二审法院**应当对上诉请求的有关事实和适用法律进行审查**。**解释§321**：二审应当**围绕当事人的上诉请求**进行审理；当事人没有提出请求的**不予审理**，但一审判决**违反法律禁止性规定**，或者**损害国家利益、社会公共利益、他人合法权益的除外**。
> - **解释§324/§326【遗漏与新增分流】**：对当事人在**一审已经提出**、原审法院**未作审理判决**的诉请，二审可自愿调解，**调解不成发回重审**（§324）；二审中原审原告**增加独立诉请**或原审被告**提出反诉**的，就新请求调解，**调解不成告知另行起诉**，双方同意由二审一并审理的可以一并裁判（§326）。§327：一审判不准离婚、二审认为应当判离的，可与子女抚养、财产一并调解，调解不成**发回重审**。
> - **民诉法§176【审理方式】**：二审法院对上诉案件**应当开庭审理**。经过**阅卷、调查和询问当事人**，对**没有提出新的事实、证据或者理由**，认为不需要开庭的，**可以不开庭审理**。二审可以在本院进行，也可以**到案件发生地或者原审法院所在地**进行。**解释§331【可不开庭四情形】**：①不服不予受理、管辖权异议和驳回起诉裁定的；②上诉请求**明显不能成立**的；③原判认定事实清楚但**适用法律错误**的；④原判**严重违反法定程序需要发回重审**的。
> - **民诉法§41 II【二审独任】**：中级法院对**第一审适用简易程序审结**或者**不服裁定**提起上诉的二审案件，事实清楚、权利义务关系明确的，**经双方当事人同意**，可以由审判员一人独任审理。**§183【二审审限】**：对**判决**的上诉案件二审立案之日起**三个月**内审结（特殊情况**本院院长**批准延长）；对**裁定**的上诉案件**三十日**内作出终审裁定。

> ⚠️ **易记错点**：①**上诉期"各自起算"**——判决书应分别送达各当事人，每个当事人的十五日（裁定十日）从**自己收到之日**起算，一方先收不影响后收方的期间；②**超期上诉原审法院说了不算**——原审法院收到上诉状只管**五日内送达对方＋连同案卷报送二审法院**（§174），是否超期、是否受理由**二审法院**审查，原审法院不能不予接收、更不能自行裁定驳回；③**可上诉裁定只有三种**（不予受理、管辖权异议、驳回起诉，§157 II），准许/不准许撤诉、中止/终结诉讼、保全裁定统统不能上诉；④**被判担责的无独三能上诉**（§59 II），"第三人一律无上诉权"是陷阱；⑤**撤回上诉≠撤回起诉**——撤回上诉（§180）只需二审法院裁定、后果是**一审判决生效**；二审中撤回**起诉**（解释§336）须**其他当事人同意**、一并**撤销一审裁判**，且撤回起诉后**重复起诉不予受理**（与一审撤诉可再诉相反）；⑥**诉讼和解协议无强制执行力**——因和解撤回上诉后对方反悔，依**生效的一审判决**申请执行，不能依和解协议执行/司法确认；⑦**围绕上诉请求≠全面审查**——没上诉的部分原则不审，只有一审判决**违反法律禁止性规定或损害国家/社会公共/他人合法权益**才破例全面审；⑧**开庭是原则、径行是例外**——不开庭前必须先**阅卷、调查、询问当事人**，且限于"无新事实证据理由"（§176）；⑨**二审独任要"双方同意"**（§41 II），一方异议即合议庭——别与一审简易程序的当然独任混淆。

## 二、 判别模型（提起 → 撤回 → 范围 → 方式）

```
        【一审判决/裁定作出并送达（前接：一审审理进程与裁判形式模型）】
                        │
   ▼ 第一站：谁能上诉告什么（§171-174，§157 II，§59 II，解释§315-318）
   │  主体：当事人 + 被判决承担民事责任的无独三（§59 II）
   │  对象：一审判决 + 三种裁定（不予受理/管辖权异议/驳回起诉，§157 II）
   │  期限：判决15日 / 裁定10日，自判决书裁定书送达之日【各自】起算
   │  路径：递交上诉状，通过原审法院提出；径向二审的，二审5日内移交原审
   │     → 原审5日内送副本、对方15日答辩（不答辩不影响审理）
   │     → 原审5日内连同全部案卷证据报送二审（超期与否由二审审查）
   │  隐形出局：口头上诉不递状=视为未上诉；不交上诉费=按自动撤回上诉（解释§318）
   │  二审地位：都上诉均列上诉人；一人上诉三分——只碰对方/只碰队友/两头都碰（解释§317）
                        │
   ▼ 第二站：后悔了能撤吗（§180，解释§335-337）
   │  时间：二审判决宣告前申请 → 是否准许由二审法院【裁定】
   │  两种不准：一审判决确有错误 / 恶意串通损害国家·社会公共·他人合法权益
   │  准许后果：一审判决生效；和解协议无执行力，反悔的依一审判决申请执行
   │  ⚠️ 区分：二审中撤回【起诉】须其他当事人同意，撤销一审裁判，再诉不受理（解释§336）
                        │
   ▼ 第三站：二审看多宽（§175，解释§321、§324、§326-327）
   │  原则：围绕上诉请求审理，没提的不审
   │  例外（全面审查）：一审判决违反法律禁止性规定 /
   │     损害国家利益、社会公共利益、他人合法权益
   │  一审已提出但漏判的诉请 → 调解，不成【发回重审】（解释§324）
   │  二审新增诉请 / 反诉 → 调解，不成【告知另行起诉】（双方同意可一并裁判，解释§326）
   │  一审判不准离婚、二审认为应离 → 一并调解，不成发回重审（解释§327）
                        │
   ▼ 第四站：开不开庭、谁来审、多久审完（§176，§41 II，§183，解释§331）
   │  原则：应当开庭审理（可在本院，也可到案件发生地/原审法院所在地）
   │  径行裁判：经阅卷、调查、询问当事人，无新事实证据理由 → 可不开庭
   │     （解释§331四情形：三裁定上诉 / 上诉请求明显不能成立 /
   │       事实清楚仅法律适用错误 / 严重违反程序需发回）
   │  组织：合议庭为原则；中院对一审简易审结或裁定上诉案，
   │     事实清楚+权利义务明确+【双方同意】→ 可独任（§41 II）
   │  审限：判决上诉3个月（院长批延长）；裁定上诉30日终审（§183）
```

> **一句话总诀**：**「判决十五裁定十、送达之日各自起，状经原审往上送、超期让二审去判，无独三被判担责也能上；宣判前可撤但两种不准（原判有错、恶意串通），撤了一审判决生效、和解反悔依判执行；二审只围着上诉请求转，碰了禁止性规定和三益才全面查，漏判发回、新增另诉；开庭是原则，阅卷调查询问后无新料才径行，独任要双方点头，判决三月裁定三十日」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **上诉期统一起算** | 判决书已由一方签收，全案上诉期自该签收之日起算，另一方未收到不影响。 | **❌ 说法错误！**判决书应**分别送达**各当事人，上诉期自**各自收到判决书之日**起算（§171）。一方先签收只启动他自己的十五日；未收到判决书的当事人经补发收到后，其上诉期从补收之日才起算，仍可上诉。 |
| **原审法院自行处理超期上诉** | 原审法院发现上诉已超上诉期的，应当不予接收上诉材料或裁定驳回上诉。 | **❌ 说法错误！**上诉状通过原审法院提出后，原审法院的法定动作只有"送达副本＋**连同全部案卷和证据报送二审法院**"（§173-174）。是否超期、是否受理由**二审法院**审查，原审法院无权不收、无权自行裁定驳回。 |
| **第三人一律无上诉权** | 无独立请求权第三人不是当事人，对一审判决不得提起上诉。 | **❌ 说法错误！**被人民法院**判决承担民事责任**的无独三，"有当事人的诉讼权利义务"（§59 II），当然包括上诉权。只有未被判担责的无独三才无上诉权。 |
| **撤回上诉一律准许** | 上诉是当事人的处分权，二审宣判前申请撤回上诉的，法院应当准许。 | **❌ 说法错误！**是否准许由二审法院**裁定**（§180）；经审查**一审判决确有错误**、或当事人**恶意串通损害国家/社会公共/他人合法权益**的，**不应准许**（解释§335）。 |
| **和解协议可以强制执行** | 二审中双方和解、上诉人撤回上诉后对方反悔的，可依和解协议申请强制执行或司法确认。 | **❌ 说法错误！**诉讼中自行达成的和解协议**无强制执行力**，也不属可司法确认的调解协议。撤回上诉经准许后**一审判决生效**，反悔的依**生效一审判决**申请执行；想给和解协议执行力，路径是请求法院审查后**制作调解书**（解释§337）。 |
| **二审全面审查** | 第二审人民法院应当对一审判决认定的全部事实和法律适用进行全面审查。 | **❌ 说法错误！**二审**围绕上诉请求**审理，没提出的不审（§175＋解释§321）；只有一审判决**违反法律禁止性规定**或**损害国家利益、社会公共利益、他人合法权益**时才破例全面审查。未上诉部分即使证据不充分，二审也不能主动改判。 |
| **二审一律开庭／想不开就不开** | 二审案件必须开庭审理，不存在不开庭的情形（或：二审法院认为不必要即可径行裁判）。 | **❌ 两头都错！**开庭是**原则**，但经过**阅卷、调查和询问当事人**，对**没有提出新的事实、证据或者理由**、认为不需要开庭的，**可以不开庭**（§176）；径行裁判有法定前置动作和情形限制（解释§331四情形），不是法院任意裁量。 |

## 四、 相邻制度对照表（同场竞技，勿混规则）

**对照一：三个"撤"——一审撤诉 vs 二审撤回上诉 vs 二审撤回起诉**

| 事项 | 一审撤诉（§148＋解释§214） | 二审撤回上诉（§180＋解释§335） | 二审撤回起诉（解释§336） |
|---|---|---|---|
| 撤的对象 | 自己的**起诉** | 自己的**上诉** | 原审原告在二审撤回**起诉**（全案清零） |
| 谁把关 | 一审法院裁定 | 二审法院裁定 | 二审法院准许（**须经其他当事人同意**＋不损三益） |
| 不准的情形 | 有违法行为需处理；辩论终结后被告不同意 | **一审判决确有错误**；**恶意串通损害三益** | 其他当事人不同意即不准 |
| 后果 | 案件了结，一审判决不存在 | **一审判决生效** | **一并裁定撤销一审裁判** |
| 能否再诉 | 同一诉请**可再诉**（离婚案六个月限） | 不涉再诉（判决已生效，只剩执行/再审） | **重复起诉不予受理** |

**对照二：共同诉讼人一人上诉的二审地位三分（解释§317）——单204-208母题群**

| 上诉矛头指向 | 被上诉人 | 依原审地位列明 | 典型真题 |
|---|---|---|---|
| ①仅对**对方当事人**之间权利义务分担有意见 | 对方当事人 | 未上诉的同方当事人 | 单208（丙诉代位权不成立→甲被上诉人） |
| ②仅对**共同诉讼人之间**分担有意见 | 未上诉的**同方**当事人 | 对方当事人 | 单205（被告甲嫌被告丙赔太少→丙被上诉人、原告丁原审列明） |
| ③对**双方之间及共同诉讼人之间**均有意见 | 未提起上诉的**其他当事人均为**被上诉人 | —— | 单204（甲嫌丙丁份额多→丙丁被上诉人、乙原审列明）、单207（报社两头都碰→甲乙丙全列被上诉人） |

> 补充（解释§315）：双方当事人和第三人**都**提起上诉的，**均列为上诉人**（单206：原告章佐＋被告章佑同向上诉→均上诉人，蒋浩被上诉人）；法院可依职权确定二审诉讼地位。

**对照三：一审 vs 二审关键数字与组织**

| 事项 | 一审（普通程序） | 二审 |
|---|---|---|
| 启动期限 | 起诉无期限门槛（时效另论） | 判决**15日**／裁定**10日**（送达之日各自起算） |
| 副本送达/答辩 | 立案5日送副本，15日答辩 | 原审收上诉状5日送副本，15日答辩（不答辩均不影响审理） |
| 审限 | 6个月＋院长批6个月＋报上级批 | 判决上诉**3个月**（院长批延长）；裁定上诉**30日**终审 |
| 审判组织 | 合议庭；基层简易/普通独任（§40） | **合议庭为原则**；中院对一审简易审结或裁定上诉案，事实清楚＋**双方同意**可独任（§41 II） |
| 开庭 | 应当开庭 | 开庭原则＋**径行裁判例外**（§176＋解释§331）；可到案件发生地/原审法院所在地开庭 |
| 裁判效力 | 可上诉（未生效） | **终审**（§182），送达即生效；对裁定上诉的处理**一律用裁定**（§178） |

## 五、 万能四步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序问题分析），按照以下四步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司偿还借款本金**20万元**、利息**2万元**，并请求一般保证人丙公司承担保证责任。某区法院适用简易程序，判决乙公司偿还本金20万元、利息2万元，丙公司承担一般保证责任。判决书**3月10日**送达乙公司，**3月15日**送达甲公司。乙公司认为利息过高，就**2万元利息部分**提起上诉。全案以这条时间线贯穿四步。

### 第一步：提起诀——判决十五裁定十，各自起算经原审

> **谁能告、告什么、几天内、往哪递**

#### 概述

上诉这扇门，进门先答四个小问：

- **谁能上诉（主体）**：一审**当事人**（原告、被告、有独三）；**无独三**原则上无上诉权，但**被人民法院判决承担民事责任**的无独三"有当事人的诉讼权利义务"（§59 II），**可以上诉**；无/限制民事行为能力人的法定代理人可代为上诉（解释§319）。
- **告什么（对象）**：一审**判决**都可上诉；**裁定**只有三种可上诉——**不予受理、管辖权异议、驳回起诉**（§157 II）。
- **几天内（期限）**：判决**十五日**、裁定**十日**，均自判决书/裁定书**送达之日**起算——判决书**分别送达**各当事人，期间**各自起算**。
- **往哪递（路径）**：上诉应当**递交上诉状**（口头表示上诉、未在期内递状的**视为未上诉**；递了状但不交上诉费的**按自动撤回上诉**处理，解释§318）。上诉状**通过原审法院**提出并按对方人数提副本；**直接递到二审法院**也行——二审法院**五日内移交原审法院**（§173）。原审法院收到后：五日送副本→对方十五日答辩（不答辩不影响审理）→**五日内连同全部案卷和证据报送二审法院**（§174）。**超期与否由二审法院审查**，原审法院只管移送。

多人诉讼还要加答一问——**二审谁列什么地位**：都上诉的**均列上诉人**（§315）；一人上诉按矛头三分（§317，见对照二）。

#### 大白话讲解

一审判完，乙公司老板拍桌子："利息判高了，我要上诉！"法务给他捋日子和路径：

**先数日子**：判决书3月10日送到乙公司——乙的十五日从3月10日起算，**3月25日**前必须递交上诉状。注意甲公司是3月15日才收到判决——**甲自己的上诉期到3月30日**才截止。两家各数各的表，谁也不搭谁的车。变个剧情：如果法院把两份判决书都交给甲签收、乙一直没拿到，一个月后法院才给乙补发——乙的十五日**从补收那天才起跑**，乙照样能上诉（单202的考法）。

**再选路径**：法务把上诉状递到**原审区法院**（也可以直接递到中院，中院五日内会转回区法院）。区法院收到后五日内把副本寄给甲公司，甲十五日内答辩（不答辩不碍事），然后区法院把上诉状、答辩状**连同全部案卷证据**打包报送中院。变个剧情：如果区法院一看"哟，3月27日才递的，超期两天"，能不能把材料退回去或自己裁定驳回？**都不能**——超没超期是**中院**的活，区法院只有"往上送"一个动作（单203的考法）。

**再看主体**：变个案型——甲公司对乙公司的代位权诉讼里，债务人丁被列为**无独三**，一审判决丁承担责任。丁能上诉吗？**能**——被判决承担民事责任的无独三有当事人的诉讼权利义务（§59 II）。

**最后排座次**（多人上诉的地位）：本案只有乙公司上诉、矛头指向对方甲公司的利息请求 → 乙＝上诉人，甲＝被上诉人；丙公司没被上诉针对 → **依原审地位列明**。矛头三分口诀详见对照二：**只碰对方→对方被上诉人；只碰队友→队友被上诉人、对方原审列明；两头都碰→没上诉的全是被上诉人**。

| 要素 | 本案对应 | 结论 |
|---|---|---|
| 主体 | 乙公司是一审被告（当事人） | ✅ 有上诉权 |
| 对象 | 一审判决（非裁定） | ✅ 可上诉 |
| 期限 | 3月10日送达＋15日＝3月25日前 | ✅ 期内递状即合法 |
| 路径 | 上诉状经原审区法院提出 | ✅ 区法院五日送副本、报送中院 |

#### 一句话闭环记忆

> 🎯 **一眼判**：上诉主体为一审原告、被告、有独立请求权第三人；无独立请求权第三人原则无上诉权，一审判决判令其承担民事责任的享有上诉权；无、限制民事行为能力人由法定代理人代为上诉。可上诉对象：一审全部判决；裁定仅限不予受理、管辖权异议、驳回起诉三类。上诉期限：判决 15 日、裁定 10 日，自裁判文书送达之日分别独立起算，各方当事人上诉期互不牵连。上诉必须递交上诉状，仅口头上诉未按期提交上诉状视为未上诉，递交上诉状但逾期不交上诉费按自动撤回上诉处理。上诉路径：上诉状原则通过原审法院提交；亦可直接递交二审法院，二审法院 5 日内移交原审法院，材料移交原审后统一走后续流程。原审法院收到上诉状后 5 日内送达上诉状副本给对方当事人；对方当事人收到副本 15 日内可提交答辩状，不答辩不影响审理；对方提交答辩状的，原审法院收到答辩状 5 日内将答辩状副本送达上诉人；原审法院集齐材料后 5 日内将案卷全部报送二审法院；**上诉是否超期由二审法院审查，原审法院无权审查、驳回上诉**。当事人均上诉，全部列为上诉人；必要共同诉讼部分上诉，按上诉矛头划分地位：仅针对对方当事人，对方为被上诉人，其余原审列明；仅针对共同诉讼内部其他当事人，内部未上诉方为被上诉人，对方原审列明；同时针对双方，所有未上诉当事人均列为被上诉人。

### 第二步：撤回诀——宣判前可撤两种不准，撤了判决生效反悔依判执行

> **撤上诉≠撤起诉，和解协议不是执行依据**

#### 概述

上诉人打到一半后悔了，规则三句话：

- **时间与把关**：二审**判决宣告前**申请撤回上诉，**是否准许由二审法院裁定**（§180）——不是"申请即撤"。
- **两种不准**（解释§335）：经审查**一审判决确有错误**的不准撤（不能让错误判决借撤诉生效）；当事人之间**恶意串通损害国家利益、社会公共利益、他人合法权益**的不准撤。
- **后果与和解衔接**：撤回上诉经准许后，**一审判决发生法律效力**。二审中双方达成**和解协议**再撤回上诉的：和解协议本身**没有强制执行力**，对方反悔不履行的，只能依**生效的一审判决**申请强制执行；想让和解内容有执行力，应请求法院审查后**制作调解书**（解释§337，调解书送达后原判视为撤销，§179）。

千万别混进来一个"近亲"：二审中原审原告申请撤回的如果是**起诉**（解释§336），门槛高得多——须**其他当事人同意**＋不损三益，准许的**一并撤销一审裁判**，而且撤回起诉后**重复起诉不予受理**（与一审撤诉"可再诉"正好相反）。

#### 大白话讲解

二审开庭前，甲乙两家坐下来谈拢了：甲公司说"利息2万我不要了"，乙公司说"那我撤回上诉，15日内把20万本金付清"。双方签了**书面和解协议**，乙公司向中院申请撤回上诉，中院审查一审判决没毛病、也无串通损人，**裁定准许**——**一审判决就此生效**。

一个月后，乙公司反悔，一分钱不付。甲公司怎么办？拿着**和解协议**去申请强制执行？**不行**——诉讼里自己签的和解协议就是一纸合同，不是执行依据；申请**司法确认**？也不行——司法确认只伺候调解组织主持达成的调解协议。正确答案：拿**已生效的一审判决**（本金20万＋利息2万都在判项里）去申请强制执行（单220、221的考法）。当初想让"甲放弃利息"这个优惠锁死，正确姿势是请求二审法院把和解协议**做成调解书**——调解书一送达，原判视为撤销，以后就按调解书执行。

**两个变体看"不准撤"**：变体一——二审法官阅卷发现一审把**法定利率上限算错了**、判决确有错误，乙公司却申请撤回上诉（想让错判生效再私下了断）？法院**不应准许**，接着审。变体二——甲乙两家其实是**串通虚假诉讼**、想借生效判决损害乙公司其他债权人，二审识破后乙申请撤回上诉？**不应准许**（解释§335）。

**再区分"撤起诉"**：如果二审中是**甲公司（原审原告）**说"这案子我整个不告了"——那是撤回**起诉**，得问乙公司丙公司**同不同意**，准了还要**把一审判决一并撤销**，而且甲以后**再拿同一诉请起诉法院不收**（解释§336）。撤上诉是"认了一审"，撤起诉是"全案清零且永久出局"，方向完全不同。

#### 一句话闭环记忆

> 🎯 **一眼判**：撤回上诉＝**宣判前申请＋二审裁定把关**，**"原判有错、恶意串通"两种不准**；准了→**一审判决生效**；和解后反悔→**依一审判决执行**（和解协议不能执行、不能司法确认，想要执行力去做**调解书**）；**撤上诉认原判、撤起诉须同意＋撤原判＋再诉不受理**——两个"撤"字方向相反。

### 第三步：范围诀——围着上诉请求转，碰了禁止规定三益才全面查

> **没上诉的不审，漏判发回、新增另诉**

#### 概述

二审的"视野"由**处分原则**划界（§175＋解释§321）：

- **原则**：围绕**当事人的上诉请求**审理——上诉请求的有关事实和适用法律才审；**当事人没有提出请求的，不予审理**。未上诉部分哪怕二审瞄见了瑕疵，也不能伸手改。
- **例外（全面审查）**：一审判决**违反法律禁止性规定**，或者**损害国家利益、社会公共利益、他人合法权益**的——此时不受上诉请求限制。
- **两条分流管"请求对不上"**：
	- **一审已提出但漏判**的诉请（解释§324）：二审可自愿**调解**，调解不成→**发回重审**（一审欠的账让一审补，二审直接判会剥夺一个审级）；
	- **二审才新增**的独立诉请或反诉（解释§326）：就新请求**调解**，调解不成→**告知另行起诉**（一审压根没审过，二审直接审等于一审终审）；双方都同意由二审一并审理的，可以**一并裁判**；
	- 特例：一审判不准离婚、二审认为应当判离的，与子女抚养、财产**一并调解**，调解不成**发回重审**（解释§327）。

#### 大白话讲解

中院拿到甲乙公司的案卷。乙公司只对**2万元利息**上诉——中院的审理范围就是**这2万利息**：本金20万没人上诉，**不审**；保证人丙公司二审开庭时嚷嚷"我不该承担保证责任"，但丙**自己没上诉**——嚷嚷不等于上诉，担保部分**不在审理范围**（单212的考法：只审利息，本金、担保都靠边）。就算二审法官翻卷时发现"一审对丙承担保证责任的证据好像不太充分"，也**不能主动改**——那部分没人上诉（多211的考法）。

**什么时候破例全面查**？变个剧情：中院阅卷发现这笔"借款"其实是**赌债**——一审判决支持赌债违反法律**禁止性规定**——此时不管乙只上诉了利息，中院**全面审查**、连本金一起纠正。再变：一审判决把**案外人丁的房子**误当乙公司财产处理了，损害**他人合法权益**——同样破例全面审。

**两条分流别走反**：
- **剧情A（一审漏判）**：假设甲公司一审除了本息还请求了**违约金1万元**，一审判决只字未判。甲上诉后，二审能不能顺手判violations违约金？**不能直接判**——先调解，调不成就**发回重审**（解释§324）。二审替一审补判，等于这1万块**一审终审**，剥夺了当事人的审级利益（多216的考法：二审主动判一审漏掉的赔礼道歉＝错误做法）。
- **剧情B（二审新增）**：二审中甲公司突然加一条"再赔我仓储费5000元"——一审从没审过这请求，二审**调解，调不成告知另行起诉**（解释§326）；只有**双方都同意**让二审一并处理，才可以一并裁判。

**一句话分流**："**一审欠的账（漏判）→发回让一审补；二审新添的账（新增/反诉）→另案去开户**"——两条出口一个向下、一个向外，命题人最爱互换。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审视野＝**上诉请求那一块**（乙只告利息就只审利息，没上诉的本金、担保一概不碰）；破例全面查只有两把钥匙——**违反法律禁止性规定**、**损害国家/社会公共/他人合法权益**；请求对不上走分流：**漏判的调解不成发回重审（§324），新增的调解不成另行起诉（§326），双方同意才可一并裁判**。

### 第四步：方式诀——开庭是原则，阅卷询问无新料才径行，独任要双方点头

> **先阅卷调查询问，无新事实证据理由，方可不开庭**

#### 概述

最后一问：这案子**怎么个审法**？

- **开庭原则**：二审对上诉案件**应当开庭审理**（§176）。开庭地点灵活：可在**本院**，也可到**案件发生地或原审法院所在地**（巡回/就地开庭）。
- **径行裁判（不开庭）例外**：必须先完成**阅卷、调查和询问当事人**三个前置动作，且当事人**没有提出新的事实、证据或者理由**、法院认为不需要开庭的，才**可以不开庭**。解释§331落地为四情形：①不服**不予受理、管辖权异议、驳回起诉**裁定的上诉；②上诉请求**明显不能成立**；③原判**事实清楚、仅适用法律错误**；④原判**严重违反法定程序需发回重审**。
- **审判组织**：合议庭为原则（成员单数，§41 I）；**例外独任**——中院对**一审简易程序审结**或**不服裁定**上诉的二审案件，**事实清楚、权利义务关系明确**，**经双方当事人同意**，可由审判员一人独任审理（§41 II）。一方异议→不能独任、转合议庭。
- **程序与审限**：二审除本章规定外**适用一审普通程序**（§181）；开庭的可依§136第四项做审理前准备（解释§322）；新证据须组织**质证**。审限：对**判决**上诉三个月（本院院长批准延长）、对**裁定**上诉三十日终审（§183，延长亦由院长批准，解释§339）。二审裁判是**终审**（§182），对裁定上诉的处理**一律用裁定**（§178）。
- **附带**：二审可以**调解**，调解书送达后**原判视为撤销**（§179）。

#### 大白话讲解

中院怎么安排甲乙公司这场二审？

**先看开不开庭**：乙公司上诉状里附了一张一审没交过的**利息结算单**——这是**新证据**，中院**必须开庭**，还要组织双方对这张单子**质证**、可指定举证期限（多210的考法）。开庭地点不一定在中院大楼——为方便当事人，可以**跑到区法院所在地开庭**（巡回审理，同样是多210考点）。变个剧情：如果乙公司上诉状通篇就是把一审辩过的理由复读一遍、没有任何新事实新证据新理由，中院**阅卷、调查、询问双方**之后，认为没必要开庭——**可以径行裁判**；再如上诉的是"驳回起诉"裁定、或原判明显要发回重审——也在解释§331的可不开庭清单里。记牢顺序：**先"阅卷＋调查＋询问"三件套，后"无新料"判断，才能不开庭**——跳过前置动作直接书面审，程序违法。

**再看谁来审**：本案一审是**简易程序**审结的，中院认为事实清楚、权利义务明确，想让赵法官**一人独任**——行不行？要**问甲乙两家**：双方都同意→独任合法（多210）；乙公司当庭异议→**独任泡汤，转合议庭**（单209的考法）。注意这跟一审不一样：一审简易程序独任是**当然配置**，二审独任是**协商解锁**。

**最后掐表**：二审立案之日起，对**判决**的上诉**三个月**内审结（特殊情况**本院院长**批准延长——注意二审延长只需院长批，没有"报上级"这一级）；如果乙公司当初上诉的是个**裁定**（比如驳回起诉），中院**三十日**内必须作出**终审裁定**。审完的判决、裁定都是**终审**文书，送达即生效——想再翻盘，只剩审判监督程序那扇窄门。

#### 一句话闭环记忆

> 🎯 **一眼判**：**开庭是原则**——有新事实/证据/理由必须开（新证据还要质证）；**径行裁判三前置**（阅卷＋调查＋询问）＋**四情形**（三裁定上诉、请求明显不成立、仅法律适用错、严重违程序要发回）；**二审独任＝一审简易/裁定上诉＋事实清楚＋双方同意**，一方摇头就合议庭；审限**"判三月、裁三十"**，延长找**本院院长**；二审是**终审**，可就地开庭、可调解（调解书送达原判即视为撤销）。

## 六、 易混提示

*   **上诉期起算 vs 统一起算**：
    *   判决书**分别送达**各当事人，十五日（裁定十日）**各自起算**；一方补收判决书的，其上诉期从补收之日起算——不存在"全案统一的上诉截止日"。
*   **撤回上诉 vs 撤回起诉（二审中）**：
    *   *撤回上诉*（§180＋解释§335）：二审裁定把关，两种不准，后果是**一审判决生效**；*撤回起诉*（解释§336）：须**其他当事人同意**＋不损三益，**一并撤销一审裁判**，且**重复起诉不予受理**。
*   **围绕上诉请求 vs 全面审查**：
    *   *原则*围绕上诉请求、没提的不审；*例外*仅在一审判决**违反法律禁止性规定**或**损害国家/社会公共/他人合法权益**时全面审查——"可依职权全面审查"是把例外当常态的错误表述。
*   **一审漏判 vs 二审新增（两条分流）**：
    *   *漏判*（一审已提出未判）：调解不成**发回重审**（解释§324）；*新增*（二审才提出的诉请/反诉）：调解不成**告知另行起诉**（解释§326，双方同意可一并裁判）——一个向下发回、一个向外另诉，勿互换。
*   **一审独任 vs 二审独任**：
    *   *一审*简易程序独任是当然配置（§40）；*二审*独任是例外解锁——限中院、限一审简易审结或裁定上诉案、事实清楚，且**必须经双方当事人同意**（§41 II），一方异议即合议庭。
*   **一审审限 vs 二审审限**：
    *   *一审*六个月＋院长批六个月＋**报上级批**（三段）；*二审*判决上诉**三个月**、裁定上诉**三十日**，延长只需**本院院长批**（无"报上级"一级）。

## 七、 命题人最爱的 6 个陷阱

1.  **"判决书已送达一方当事人，全案上诉期自该日起算"** —— 错！判决书分别送达，上诉期自**各自收到之日**起算；未收到的当事人经补发收到后仍可在自己的十五日内上诉（其间判决对他未生效，谈不上再审）。
2.  **"原审法院发现上诉超过上诉期的，应不予接收或裁定驳回上诉"** —— 错！原审法院只负责送达副本并**连同全部案卷证据报送二审法院**（§173-174），是否超期由**二审法院**审查处理。
3.  **"无独立请求权第三人对一审判决不得上诉"** —— 错！**被判决承担民事责任**的无独三有当事人的诉讼权利义务（§59 II），可以上诉；但其在二审提出的**超出本案标的**的请求（如代位权案中债务人索要未被代位的余款）不属二审审理范围，应另案主张。
4.  **"二审宣判前上诉人申请撤回上诉的，法院应当准许"** —— 错！由二审法院**裁定**是否准许；**一审判决确有错误**或当事人**恶意串通损害三益**的不应准许（解释§335）。
5.  **"二审和解后撤回上诉，对方反悔的，可依和解协议申请强制执行/司法确认"** —— 错！诉讼和解协议**无强制执行力**、也不能司法确认；撤回上诉后**一审判决生效**，应依**生效一审判决**申请执行；要执行力须请求法院制作**调解书**（解释§337）。
6.  **"二审应当全面审查一审认定的事实和适用法律／未上诉部分可主动改判／一审漏判的诉请二审可直接判决"** —— 错！二审**围绕上诉请求**审理（§175＋解释§321），全面审查仅限"违反禁止性规定/损害三益"例外；未上诉部分不审不改；一审漏判的诉请调解不成**发回重审**（解释§324），二审直接判决＝超出上诉请求、剥夺审级。

| [[民诉-二审程序-单选-207 · 上诉同时涉及对方与共同被告的二审地位]] | **"既碰对方又碰队友"全列被上诉人。**<br>报社上诉既要改对乙丙的赔偿道歉（对方）、又要甲多担（队友）——未上诉的甲、乙、丙**均为被上诉人**（B对，解释§317(三)）。 | **第一步·二审地位三分（对照二③）** |
| [[民诉-二审程序-单选-208 · 代位权诉讼中第三人上诉超范围的二审地位]] | **无独三上诉权＋超范围请求不入二审。**<br>丙诉"甲对乙债权不成立"直击代位权标的→丙上诉人、甲被上诉人（A对）；第三人乙索要未被代位的5万**超出本案标的**，不属二审审理范围，乙不因此成为上诉人、应另案主张（§175）。 | **第一步·上诉主体 + 第三步·审理范围边界** |
| [[民诉-二审程序-单选-209 · 二审独任制须经双方当事人同意]] | **二审独任须双方同意。**<br>中院对一审简易审结的上诉案可独任，但**须经双方当事人同意**（§41 II）；乙公司当庭异议→**转合议庭**（D对）；二审并非绝对不能独任（A错）、简易程序两审终审可上诉（B错，一审终审的是小额）。 | **第四步·二审独任** |
| [[民诉-二审程序-多选-210 · 二审独任新证据质证与巡回开庭]] | **二审"可以"清单四连对。**<br>经甲乙同意可独任（§41 II）；可为新证据指定15日举证期限；二审新证据（收条）须组织**质证**；可**到原审法院所在地就地开庭**（§176 II），选ABCD。 | **第四步·审理方式（独任＋质证＋巡回）** |

| [[民诉-二审程序-单选-212 · 二审审理范围仅限上诉的利息部分]] | **本模型统一案例的真题原型。**<br>只有乙对利息上诉→二审**仅审利息**（B对，§175）；保证人丙二审喊"不担责"但**没上诉**，担保部分不入审理范围；本金无人上诉不审。 | **第三步·围绕上诉请求（利息案）** |
| [[民诉-二审程序-多选-216 · 二审超出上诉请求判决与漏判诉请的处理]] | **漏判诉请二审不能直接判。**<br>二审只能对上诉请求（赔偿数额）审理判决（A对）；主动判一审漏判的赔礼道歉＝**超出上诉请求，错误**（B对）；正确处理是就漏判部分调解、**调解不成发回重审**（C对，解释§324）；不是全案直接发回（D错）。 | **第三步·漏判分流（解释§324）** |
| [[民诉-二审-单选-346 · 二审审理范围以上诉请求为限]] | **原则与例外的教科书式表述。**<br>二审仅审上诉请求范围（A对，§175＋解释§321）；"依职权全面审查"把例外当常态（B错）；未上诉诉求不能主动改判（C错）；审理范围原则上受上诉请求限制（D错）。 | **第三步·原则＋全面审查例外** |
