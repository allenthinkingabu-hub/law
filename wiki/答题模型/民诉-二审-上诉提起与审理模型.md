# 📐 二审上诉提起与审理 · 完整答题模型（主体对象期限 + 撤回限制 + 审理范围 + 审理方式 + 裁判出口）

> **核心一句**：[[民诉-一审-审理进程与裁判形式模型]]解决"一审这场官司怎么走完"，本模型解决"**输了不服怎么翻盘**"，一条主线六站：**谁能上诉告什么（主体＋对象＋期限＋递交路径，§171-174）→ 后悔了能撤吗（撤回上诉的准许与限制，§180＋解释§335）→ 二审看多宽（围绕上诉请求为原则＋全面审查例外，§175＋解释§321）→ 开不开庭（开庭原则＋径行裁判条件，§176＋解释§331）→ **查出一审有问题走哪个出口**（维持／改判／事实不清可改可发／程序严重违法必须发回，§177＋解释§323、§328-333）→ **改判能改到哪儿**（三个来源＋四条边界：不出上诉请求范围、禁止不利益变更、漏判与新增不能靠改判补、程序违法不得改判）**。最毒陷阱是**把上诉期记成统一起算**（判决书分别送达、各自起算）、**让原审法院自行裁定驳回超期上诉**（原审只管移送，超期与否由二审审查）、**把二审当成全面审查**（围绕上诉请求，例外才全面）、**把诉讼和解协议当执行依据**（撤回上诉后依生效的一审判决执行）、**把"事实不清可改可发"与"程序严重违法必须发回"混为一谈**、**对错误的一审裁定喊"发回重审"**（裁定错了用"指令"，判决错了才发回）。
>
> 🔎 **核心条文速查**：
> - **民诉法§171【上诉期】**：不服地方法院第一审**判决**的，有权在判决书**送达之日起十五日**内向上一级法院上诉；不服第一审**裁定**的，在裁定书**送达之日起十日**内上诉。
> - **民诉法§157 II【可上诉裁定】**：对§157第一款**第一项至第三项**裁定（**不予受理、管辖权异议、驳回起诉**），可以上诉。**§59 II【无独三】**：人民法院**判决承担民事责任的第三人，有当事人的诉讼权利义务**（含上诉权）。
> - **民诉法§172-174【上诉状与移送】**：上诉应当**递交上诉状**（§172）；上诉状应当**通过原审法院提出**并按对方人数提出副本，当事人**直接向二审法院上诉**的，二审法院应当在**五日**内将上诉状**移交原审法院**（§173）；原审法院收到上诉状**五日**内将副本送达对方当事人，对方**十五日**内答辩、不答辩**不影响审理**；原审法院收到上诉状、答辩状，应当在**五日**内**连同全部案卷和证据报送二审法院**（§174）。
> - **解释§318【口头上诉与上诉费】**：宣判或送达时口头表示上诉的，应告知**必须在法定上诉期内递交上诉状**，未递交的**视为未提起上诉**；虽递交上诉状但未在指定期限交纳上诉费的，**按自动撤回上诉处理**。
> - **解释§315-317【二审当事人地位】**：双方当事人和第三人都上诉的**均列上诉人**（§315）；必要共同诉讼人一人或部分人上诉的**三分**（§317）：①仅对与**对方**之间权利义务分担有意见→对方为被上诉人，未上诉的同方依原审地位列明；②仅对**共同诉讼人之间**分担有意见→未上诉的同方为被上诉人，对方依原审地位列明；③对**双方之间及共同诉讼人之间**均有意见→未提起上诉的其他当事人**均为被上诉人**。
> - **民诉法§180【撤回上诉】**：二审法院**判决宣告前**，上诉人申请撤回上诉的，**是否准许，由第二审人民法院裁定**。**解释§335【不准撤回】**：二审中当事人申请撤回上诉，经审查认为**一审判决确有错误**，或者当事人之间**恶意串通损害国家利益、社会公共利益、他人合法权益**的，**不应准许**。**解释§337**：二审中达成和解协议的，法院可根据当事人请求审查并**制作调解书**；因和解申请撤诉、符合撤诉条件的应予准许。**解释§336**：二审中原审原告申请**撤回起诉**，须经其他当事人同意且不损害国家社会公共他人利益，准许的**一并裁定撤销一审裁判**，撤回起诉后**重复起诉的不予受理**。
> - **民诉法§175【审理范围】**：二审法院**应当对上诉请求的有关事实和适用法律进行审查**。**解释§321**：二审应当**围绕当事人的上诉请求**进行审理；当事人没有提出请求的**不予审理**，但一审判决**违反法律禁止性规定**，或者**损害国家利益、社会公共利益、他人合法权益的除外**。
> - **解释§324/§326【遗漏与新增分流】**：对当事人在**一审已经提出**、原审法院**未作审理判决**的诉请，二审可自愿调解，**调解不成发回重审**（§324）；二审中原审原告**增加独立诉请**或原审被告**提出反诉**的，就新请求调解，**调解不成告知另行起诉**，双方同意由二审一并审理的可以一并裁判（§326）。§327：一审判不准离婚、二审认为应当判离的，可与子女抚养、财产一并调解，调解不成**发回重审**。
> - **民诉法§176【审理方式】**：二审法院对上诉案件**应当开庭审理**。经过**阅卷、调查和询问当事人**，对**没有提出新的事实、证据或者理由**，认为不需要开庭的，**可以不开庭审理**。二审可以在本院进行，也可以**到案件发生地或者原审法院所在地**进行。**解释§331【可不开庭四情形】**：①不服不予受理、管辖权异议和驳回起诉裁定的；②上诉请求**明显不能成立**的；③原判认定事实清楚但**适用法律错误**的；④原判**严重违反法定程序需要发回重审**的。
> - **民诉法§177【二审裁判方式·四出口】**：二审对上诉案件，经过审理，按照下列情形，分别处理：（一）原判决、裁定**认定事实清楚，适用法律正确**的，以判决、裁定方式**驳回上诉，维持**原判决、裁定；（二）原判决、裁定**认定事实错误或者适用法律错误**的，以判决、裁定方式依法**改判、撤销或者变更**；（三）原判决**认定基本事实不清**的，**裁定**撤销原判决，**发回**原审人民法院重审，**或者查清事实后改判**；（四）原判决**遗漏当事人或者违法缺席判决等严重违反法定程序**的，**裁定**撤销原判决，**发回**原审人民法院重审。**第二款**：原审人民法院对发回重审的案件作出判决后，当事人提起上诉的，二审人民法院**不得再次发回重审**。**§178**：对不服一审**裁定**的上诉案件的处理，**一律使用裁定**。
> - **解释§323【严重违反法定程序的补充列举】**：下列情形，可以认定为民诉法**§177 I(四)**规定的严重违反法定程序：（一）**审判组织的组成不合法**；（二）**应当回避的审判人员未回避**；（三）**无诉讼行为能力人未经法定代理人代为诉讼**；（四）**违法剥夺当事人辩论权利**。（"遗漏当事人、违法缺席判决"写在§177 I(四)条文本体的例示里，与本条四项是**两份清单**。）
> - **解释§328/§329/§330【三条特殊出口】**：二审认为案件**依法不应由法院受理**的，可由二审**直接裁定撤销原裁判、驳回起诉**（§328）；认为一审受理案件**违反专属管辖**的，**裁定撤销原裁判并移送**有管辖权的法院（§329）；查明一审**不予受理裁定**有错误的，撤销原裁定同时**指令一审立案受理**，查明一审**驳回起诉裁定**有错误的，撤销原裁定同时**指令一审审理**（§330）。
> - **解释§332/§333【维持的弹性与"基本事实"】**：原判认定事实或适用法律**虽有瑕疵、但裁判结果正确**的，二审可在裁判中**纠正瑕疵后依§177 I(一)予以维持**（§332）；§177 I(三)的**基本事实**，指用以确定**当事人主体资格、案件性质、民事权利义务**等对原裁判**结果有实质性影响**的事实（§333）。
> - **发回重审后的一审【解释§251＋§257(二)＋§39 II】**：二审裁定撤销一审判决发回重审的案件，当事人申请**变更、增加诉请或提出反诉**的，依民诉法**§143**处理（§251）；**发回重审的案件不适用简易程序**（§257(二)）；发回重审或按一审程序再审的案件，当事人提出**管辖异议的不予审查**（§39 II）。
> - **民诉法§41 II【二审独任】**：中级法院对**第一审适用简易程序审结**或者**不服裁定**提起上诉的二审案件，事实清楚、权利义务关系明确的，**经双方当事人同意**，可以由审判员一人独任审理。**§183【二审审限】**：对**判决**的上诉案件二审立案之日起**三个月**内审结（特殊情况**本院院长**批准延长）；对**裁定**的上诉案件**三十日**内作出终审裁定。

## 二、 判别模型（提起 → 撤回 → 范围 → 方式 → 裁判出口 → 改判边界）

```
        【一审判决/裁定作出并送达（前接：一审审理进程与裁判形式模型）】
                        │
   ▼ 第一站：谁能上诉告什么（§171-174，§157 II，§59 II，解释§315-318）
   │  主体：当事人 + 被判决承担民事责任的无独三（§59 II）
   │  对象：一审判决 + 三种裁定（不予受理/管辖权异议/驳回起诉，§157 II）
   │  期限：判决15日 / 裁定10日，自判决书裁定书送达之日【各自】起算
   │  路径：递交上诉状，通过原审法院提出；径向二审的，二审5日内移交原审
   │     → 原审5日内送副本、对方15日答辩（不答辩不影响审理）
   │     → 原审5日内连同全部案卷证据报送二审（超期与否由二审审查）
   │  隐形出局：口头上诉不递状=视为未上诉；不交上诉费=按自动撤回上诉（解释§318）
   │  二审地位：都上诉均列上诉人；一人上诉三分——只碰对方/只碰队友/两头都碰（解释§317）
                        │
   ▼ 第二站：后悔了能撤吗（§180，解释§335-337）
   │  时间：二审判决宣告前申请 → 是否准许由二审法院【裁定】
   │  两种不准：一审判决确有错误 / 恶意串通损害国家·社会公共·他人合法权益
   │  准许后果：一审判决生效；和解协议无执行力，反悔的依一审判决申请执行
   │  ⚠️ 区分：二审中撤回【起诉】须其他当事人同意，撤销一审裁判，再诉不受理（解释§336）
                        │
   ▼ 第三站：二审看多宽（§175，解释§321、§324、§326-327）
   │  原则：围绕上诉请求审理，没提的不审
   │  例外（全面审查）：一审判决违反法律禁止性规定 /
   │     损害国家利益、社会公共利益、他人合法权益
   │  一审已提出但漏判的诉请 → 调解，不成【发回重审】（解释§324）
   │  二审新增诉请 / 反诉 → 调解，不成【告知另行起诉】（双方同意可一并裁判，解释§326）
   │  一审判不准离婚、二审认为应离 → 一并调解，不成发回重审（解释§327）
                        │
   ▼ 第四站：开不开庭、谁来审、多久审完（§176，§41 II，§183，解释§331）
   │  原则：应当开庭审理（可在本院，也可到案件发生地/原审法院所在地）
   │  径行裁判：经阅卷、调查、询问当事人，无新事实证据理由 → 可不开庭
   │     （解释§331四情形：三裁定上诉 / 上诉请求明显不能成立 /
   │       事实清楚仅法律适用错误 / 严重违反程序需发回）
   │  组织：合议庭为原则；中院对一审简易审结或裁定上诉案，
   │     事实清楚+权利义务明确+【双方同意】→ 可独任（§41 II）
   │  审限：判决上诉3个月（院长批延长）；裁定上诉30日终审（§183）
                        │
   ▼ 第五站：查出一审有问题，怎么判（§177-178，解释§323、§328-333）
   │  ① 事实清楚+法律正确 → 判决/裁定【驳回上诉，维持原判】（§177 I(一)）
   │     └ 瑕疵但结果正确 → 裁判中【纠正瑕疵后维持】（解释§332）
   │  ② 认定事实错误 或 适用法律错误 → 【依法改判】、撤销或变更（§177 I(二)）
   │     └ 改判能改到哪儿 → 见【第六站】
   │  ③ 原判【基本事实不清】 → 裁定撤销原判 →【发回重审 or 查清后改判】（可改可发）
   │     └ 基本事实＝主体资格/案件性质/权利义务等对结果有实质影响者（解释§333）
   │  ④ 原判【严重违反法定程序】 → 裁定撤销原判 →【必须发回重审】（无改判选项）
   │     └ 条文本体例示：遗漏当事人 / 违法缺席判决
   │     └ 解释§323另四项：审判组织不合法 / 应回避未回避 /
   │        无诉讼行为能力人未经法代 / 违法剥夺辩论权
   │  🚫 发回重审【以一次为限】：重审判决后再上诉，二审不得再发回（§177 II）
   │     └ "只就财产/某一诉请发回"同样属再次发回，禁止
   │  ⚠️ 不走"发回"的三条特殊出口：
   │     · 一审不予受理/驳回起诉【裁定】错 → 撤销＋【指令】受理/审理（解释§330）
   │     · 依法不应由法院受理 → 二审直接裁定撤销原裁判、驳回起诉（解释§328）
   │     · 一审受理违反【专属管辖】 → 裁定撤销原裁判并移送（解释§329）
   │  形式：对裁定的上诉，处理【一律用裁定】（§178）；二审裁判即终审（§182）
   │  发回后的一审：按一审程序重来——可依§143变更/增加诉请、反诉（解释§251）；
   │     【不得适用简易程序】（解释§257(二)）；管辖异议【不予审查】（解释§39 II）
                        │
   ▼ 第六站：决定改判后，能改到哪儿（§177 I(二)(三)＋§177 II，§175＋解释§321）
   │  改判三来源：①事实清楚但认定/适用法律错 →【直接改判】（§177 I(二)）
   │             ②基本事实不清 →【查清事实后改判】（§177 I(三)，与发回二选一）
   │             ③已发回过一次、重审后再上诉 →【只能自判】（§177 II）
   │  ─────────── 四条边界（分值全在这儿）───────────
   │  边界1 只能在【上诉请求范围内】改，未上诉部分不动（§175＋解释§321）
   │        例外：违反法律禁止性规定 / 损害国家·社会公共·他人合法权益
   │  边界2 【禁止不利益变更】：仅一方上诉的，不得改得对该上诉人【更不利】
   │        ⚠️ 民诉法与解释【均无明文】＝处分原则＋§321推出的通说，勿标条号
   │        ⚠️ "上诉不加刑"是【刑诉§237】，不得移用于民诉
   │        ✅ 对方也上诉 → 双方请求区间全入审理范围，限制解除
   │  边界3 不能用改判补审级窟窿：漏判→【发回】（§324）；新增/反诉→【另诉】（§326）
   │  边界4 程序严重违法【不得改判】，只能发回（§177 I(四)＋解释§325）
   │  形式：判决上诉用判决改判；裁定上诉一律用裁定（§178）
   │        ⚠️ 二审调解成立→调解书送达后原判【视为撤销】（§179），此项不叫改判
```

> **一句话总诀**：**「判决十五裁定十、送达之日各自起，状经原审往上送、超期让二审去判，无独三被判担责也能上；宣判前可撤但两种不准（原判有错、恶意串通），撤了一审判决生效、和解反悔依判执行；二审只围着上诉请求转，碰了禁止性规定和三益才全面查，漏判发回、新增另诉；开庭是原则，阅卷调查询问后无新料才径行，独任要双方点头，判决三月裁定三十日；查出毛病四条路——对了维持（瑕疵纠正后仍维持）、错了改判、事实不清可改可发、程序严重违法必须发回，发回只此一次，裁定错了用指令、不该受理直接驳、专属管辖撤了移送；改判只在上诉请求里改、绝不把上诉人改得更糟（对方也上诉才解禁），漏判发回、新增另诉、程序违法不许改」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **上诉期统一起算** | 判决书已由一方签收，全案上诉期自该签收之日起算，另一方未收到不影响。 | **❌ 说法错误！**判决书应**分别送达**各当事人，上诉期自**各自收到判决书之日**起算（§171）。一方先签收只启动他自己的十五日；未收到判决书的当事人经补发收到后，其上诉期从补收之日才起算，仍可上诉。 |
| **原审法院自行处理超期上诉** | 原审法院发现上诉已超上诉期的，应当不予接收上诉材料或裁定驳回上诉。 | **❌ 说法错误！**上诉状通过原审法院提出后，原审法院的法定动作只有"送达副本＋**连同全部案卷和证据报送二审法院**"（§173-174）。是否超期、是否受理由**二审法院**审查，原审法院无权不收、无权自行裁定驳回。 |
| **第三人一律无上诉权** | 无独立请求权第三人不是当事人，对一审判决不得提起上诉。 | **❌ 说法错误！**被人民法院**判决承担民事责任**的无独三，"有当事人的诉讼权利义务"（§59 II），当然包括上诉权。只有未被判担责的无独三才无上诉权。 |
| **撤回上诉一律准许** | 上诉是当事人的处分权，二审宣判前申请撤回上诉的，法院应当准许。 | **❌ 说法错误！**是否准许由二审法院**裁定**（§180）；经审查**一审判决确有错误**、或当事人**恶意串通损害国家/社会公共/他人合法权益**的，**不应准许**（解释§335）。 |
| **和解协议可以强制执行** | 二审中双方和解、上诉人撤回上诉后对方反悔的，可依和解协议申请强制执行或司法确认。 | **❌ 说法错误！**诉讼中自行达成的和解协议**无强制执行力**，也不属可司法确认的调解协议。撤回上诉经准许后**一审判决生效**，反悔的依**生效一审判决**申请执行；想给和解协议执行力，路径是请求法院审查后**制作调解书**（解释§337）。 |
| **二审全面审查** | 第二审人民法院应当对一审判决认定的全部事实和法律适用进行全面审查。 | **❌ 说法错误！**二审**围绕上诉请求**审理，没提出的不审（§175＋解释§321）；只有一审判决**违反法律禁止性规定**或**损害国家利益、社会公共利益、他人合法权益**时才破例全面审查。未上诉部分即使证据不充分，二审也不能主动改判。 |
| **二审一律开庭／想不开就不开** | 二审案件必须开庭审理，不存在不开庭的情形（或：二审法院认为不必要即可径行裁判）。 | **❌ 两头都错！**开庭是**原则**，但经过**阅卷、调查和询问当事人**，对**没有提出新的事实、证据或者理由**、认为不需要开庭的，**可以不开庭**（§176）；径行裁判有法定前置动作和情形限制（解释§331四情形），不是法院任意裁量。 |
| **事实不清"必须发回"** | 原判决认定基本事实不清的，二审应当裁定撤销原判决、发回原审法院重审。 | **❌ 偷换成必须！**§177 I(三)是"发回原审人民法院重审，**或者查清事实后改判**"——**可改可发**，二审有裁量权。只有第（四）项**严重违反法定程序**才是"裁定撤销原判决，**发回**重审"（无改判选项）。 |
| **程序严重违法可以直接改判** | 一审遗漏当事人／违法缺席判决的，二审可以查清后直接改判，以提高效率。 | **❌ 说法错误！**§177 I(四)只有**发回重审**一条出口——遗漏的当事人从未参加过一审，二审直接判等于剥夺其**一个审级**。同理，一审漏判的诉请调解不成也是**发回重审**（解释§324），必要当事人一审未参加同样**调解不成发回**（解释§325）。 |
| **发回重审可以来第二次** | 重审判决后当事人再次上诉，二审认为事实仍不清的，可以再次发回重审（或"就财产部分发回"）。 | **❌ 说法错误！**§177 II明文封死：原审对**发回重审的案件作出判决后**当事人上诉的，二审**不得再次发回重审**——只能查清事实**自行裁判**（离婚等案件可再行调解，§179）。"只就财产部分发回"仍属再次发回，同禁。 |
| **一审裁定错了"发回重审"** | 一审驳回起诉的裁定错误的，二审应当撤销原裁定并发回原审法院重审。 | **❌ 用错动词！**查明**不予受理**裁定有错的→撤销原裁定同时**指令**一审**立案受理**；查明**驳回起诉**裁定有错的→撤销原裁定同时**指令**一审**审理**（解释§330）。**裁定用"指令"，判决才谈"发回"**；且对裁定上诉的处理**一律用裁定**（§178）。 |
| **有瑕疵就得改判／发回** | 原判决在事实认定或法律适用上存在瑕疵的，二审应当改判或发回重审。 | **❌ 说法错误！**原判认定事实或适用法律**虽有瑕疵、但裁判结果正确**的，二审可在判决、裁定中**纠正瑕疵后，依§177 I(一)予以维持**（解释§332）——结果对不对才是分水岭，不是有没有瑕疵。 |
| **改判可以改到上诉人更不利** | 只有被告一方上诉请求少判的，二审经审理认为原判判少了，可以改判增加其给付数额。 | **❌ 说法错误！**二审**围绕上诉请求**审理（§175＋解释§321），改判不得超出上诉人划定的范围；只有一方上诉时，也**不得作出对该上诉人比原判更不利的改判**（**禁止不利益变更**——处分原则下的**通说，民诉法与解释均无明文，勿虚标条号**）。**对方也上诉的**，两造请求区间均入审理范围，不受此限。 |
| **民诉也有"上诉不加刑"** | 《民事诉讼法》规定，二审不得作出对上诉人更不利的判决（"民事上诉不加刑"）。 | **❌ 张冠李戴！**"上诉不加刑"是**刑诉法§237**的明文规则。民诉法全文中"改判"仅见于**§177两处**，"不利益／更不利／不得加重"**一处也无**——民诉的同类效果是从**处分原则＋解释§321**推出的理论表述，答题可用其**结论**，但不能给它安一个民诉法条号。 |
| **改判可以补一审的漏判** | 一审已提出但漏判的诉请，二审查清后可以直接改判一并解决，以免当事人另诉讼累。 | **❌ 说法错误！**一审已提出而未审理判决的诉请→调解，**调解不成发回重审**（解释§324）；二审才新增的诉请/反诉→调解，**调解不成告知另行起诉**（解释§326）。二审直接判＝该部分**一审终审**，剥夺审级利益。 |

## 四、 相邻制度对照表（同场竞技，勿混规则）

**对照一：三个"撤"——一审撤诉 vs 二审撤回上诉 vs 二审撤回起诉**

| 事项 | 一审撤诉（§148＋解释§214） | 二审撤回上诉（§180＋解释§335） | 二审撤回起诉（解释§336） |
|---|---|---|---|
| 撤的对象 | 自己的**起诉** | 自己的**上诉** | 原审原告在二审撤回**起诉**（全案清零） |
| 谁把关 | 一审法院裁定 | 二审法院裁定 | 二审法院准许（**须经其他当事人同意**＋不损三益） |
| 不准的情形 | 有违法行为需处理；辩论终结后被告不同意 | **一审判决确有错误**；**恶意串通损害三益** | 其他当事人不同意即不准 |
| 后果 | 案件了结，一审判决不存在 | **一审判决生效** | **一并裁定撤销一审裁判** |
| 能否再诉 | 同一诉请**可再诉**（离婚案六个月限） | 不涉再诉（判决已生效，只剩执行/再审） | **重复起诉不予受理** |

**对照二：共同诉讼人一人上诉的二审地位三分（解释§317）——单204-208母题群**

| 上诉矛头指向 | 被上诉人 | 依原审地位列明 | 典型真题 |
|---|---|---|---|
| ①仅对**对方当事人**之间权利义务分担有意见 | 对方当事人 | 未上诉的同方当事人 | 单208（丙诉代位权不成立→甲被上诉人） |
| ②仅对**共同诉讼人之间**分担有意见 | 未上诉的**同方**当事人 | 对方当事人 | 单205（被告甲嫌被告丙赔太少→丙被上诉人、原告丁原审列明） |
| ③对**双方之间及共同诉讼人之间**均有意见 | 未提起上诉的**其他当事人均为**被上诉人 | —— | 单204（甲嫌丙丁份额多→丙丁被上诉人、乙原审列明）、单207（报社两头都碰→甲乙丙全列被上诉人） |

> 补充（解释§315）：双方当事人和第三人**都**提起上诉的，**均列为上诉人**（单206：原告章佐＋被告章佑同向上诉→均上诉人，蒋浩被上诉人）；法院可依职权确定二审诉讼地位。

**对照三：一审 vs 二审关键数字与组织**

| 事项 | 一审（普通程序） | 二审 |
|---|---|---|
| 启动期限 | 起诉无期限门槛（时效另论） | 判决**15日**／裁定**10日**（送达之日各自起算） |
| 副本送达/答辩 | 立案5日送副本，15日答辩 | 原审收上诉状5日送副本，15日答辩（不答辩均不影响审理） |
| 审限 | 6个月＋院长批6个月＋报上级批 | 判决上诉**3个月**（院长批延长）；裁定上诉**30日**终审 |
| 审判组织 | 合议庭；基层简易/普通独任（§40） | **合议庭为原则**；中院对一审简易审结或裁定上诉案，事实清楚＋**双方同意**可独任（§41 II） |
| 开庭 | 应当开庭 | 开庭原则＋**径行裁判例外**（§176＋解释§331）；可到案件发生地/原审法院所在地开庭 |
| 裁判效力 | 可上诉（未生效） | **终审**（§182），送达即生效；对裁定上诉的处理**一律用裁定**（§178） |

## 五、 万能六步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序问题分析），按照以下六步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司偿还借款本金**20万元**、利息**2万元**，并请求一般保证人丙公司承担保证责任。某区法院适用简易程序，判决乙公司偿还本金20万元、利息2万元，丙公司承担一般保证责任。判决书**3月10日**送达乙公司，**3月15日**送达甲公司。乙公司认为利息过高，就**2万元利息部分**提起上诉。全案以这条时间线贯穿四步。

### 第一步：提起诀——判决十五裁定十，各自起算经原审

> **谁能告、告什么、几天内、往哪递**

#### 概述

上诉这扇门，进门先答四个小问：

- **谁能上诉（主体）**：一审**当事人**（原告、被告、有独三）；**无独三**原则上无上诉权，但**被人民法院判决承担民事责任**的无独三"有当事人的诉讼权利义务"（§59 II），**可以上诉**；无/限制民事行为能力人的法定代理人可代为上诉（解释§319）。
- **告什么（对象）**：一审**判决**都可上诉；**裁定**只有三种可上诉——**不予受理、管辖权异议、驳回起诉**（§157 II）。
- **几天内（期限）**：判决**十五日**、裁定**十日**，均自判决书/裁定书**送达之日**起算——判决书**分别送达**各当事人，期间**各自起算**。
- **往哪递（路径）**：上诉应当**递交上诉状**（口头表示上诉、未在期内递状的**视为未上诉**；递了状但不交上诉费的**按自动撤回上诉**处理，解释§318）。上诉状**通过原审法院**提出并按对方人数提副本；**直接递到二审法院**也行——二审法院**五日内移交原审法院**（§173）。原审法院收到后：五日送副本→对方十五日答辩（不答辩不影响审理）→**五日内连同全部案卷和证据报送二审法院**（§174）。**超期与否由二审法院审查**，原审法院只管移送。

多人诉讼还要加答一问——**二审谁列什么地位**：都上诉的**均列上诉人**（§315）；一人上诉按矛头三分（§317，见对照二）。

#### 大白话讲解

一审判完，乙公司老板拍桌子："利息判高了，我要上诉！"法务给他捋日子和路径：

**先数日子**：判决书3月10日送到乙公司——乙的十五日从3月10日起算，**3月25日**前必须递交上诉状。注意甲公司是3月15日才收到判决——**甲自己的上诉期到3月30日**才截止。两家各数各的表，谁也不搭谁的车。变个剧情：如果法院把两份判决书都交给甲签收、乙一直没拿到，一个月后法院才给乙补发——乙的十五日**从补收那天才起跑**，乙照样能上诉（单202的考法）。

**再选路径**：法务把上诉状递到**原审区法院**（也可以直接递到中院，中院五日内会转回区法院）。区法院收到后五日内把副本寄给甲公司，甲十五日内答辩（不答辩不碍事），然后区法院把上诉状、答辩状**连同全部案卷证据**打包报送中院。变个剧情：如果区法院一看"哟，3月27日才递的，超期两天"，能不能把材料退回去或自己裁定驳回？**都不能**——超没超期是**中院**的活，区法院只有"往上送"一个动作（单203的考法）。

**再看主体**：变个案型——甲公司对乙公司的代位权诉讼里，债务人丁被列为**无独三**，一审判决丁承担责任。丁能上诉吗？**能**——被判决承担民事责任的无独三有当事人的诉讼权利义务（§59 II）。

**最后排座次**（多人上诉的地位）：本案只有乙公司上诉、矛头指向对方甲公司的利息请求 → 乙＝上诉人，甲＝被上诉人；丙公司没被上诉针对 → **依原审地位列明**。矛头三分口诀详见对照二：**只碰对方→对方被上诉人；只碰队友→队友被上诉人、对方原审列明；两头都碰→没上诉的全是被上诉人**。

| 要素 | 本案对应 | 结论 |
|---|---|---|
| 主体 | 乙公司是一审被告（当事人） | ✅ 有上诉权 |
| 对象 | 一审判决（非裁定） | ✅ 可上诉 |
| 期限 | 3月10日送达＋15日＝3月25日前 | ✅ 期内递状即合法 |
| 路径 | 上诉状经原审区法院提出 | ✅ 区法院五日送副本、报送中院 |

#### 一句话闭环记忆

### 第二步：撤回诀——宣判前可撤两种不准，撤了判决生效反悔依判执行

> **撤上诉≠撤起诉，和解协议不是执行依据**

#### 概述

上诉人打到一半后悔了，规则三句话：

- **时间与把关**：二审**判决宣告前**申请撤回上诉，**是否准许由二审法院裁定**（§180）——不是"申请即撤"。
- **两种不准**（解释§335）：经审查**一审判决确有错误**的不准撤（不能让错误判决借撤诉生效）；当事人之间**恶意串通损害国家利益、社会公共利益、他人合法权益**的不准撤。
- **后果与和解衔接**：撤回上诉经准许后，**一审判决发生法律效力**。二审中双方达成**和解协议**再撤回上诉的：和解协议本身**没有强制执行力**，对方反悔不履行的，只能依**生效的一审判决**申请强制执行；想让和解内容有执行力，应请求法院审查后**制作调解书**（解释§337，调解书送达后原判视为撤销，§179）。

千万别混进来一个"近亲"：二审中原审原告申请撤回的如果是**起诉**（解释§336），门槛高得多——须**其他当事人同意**＋不损三益，准许的**一并撤销一审裁判**，而且撤回起诉后**重复起诉不予受理**（与一审撤诉"可再诉"正好相反）。

#### 大白话讲解

二审开庭前，甲乙两家坐下来谈拢了：甲公司说"利息2万我不要了"，乙公司说"那我撤回上诉，15日内把20万本金付清"。双方签了**书面和解协议**，乙公司向中院申请撤回上诉，中院审查一审判决没毛病、也无串通损人，**裁定准许**——**一审判决就此生效**。

一个月后，乙公司反悔，一分钱不付。甲公司怎么办？拿着**和解协议**去申请强制执行？**不行**——诉讼里自己签的和解协议就是一纸合同，不是执行依据；申请**司法确认**？也不行——司法确认只伺候调解组织主持达成的调解协议。正确答案：拿**已生效的一审判决**（本金20万＋利息2万都在判项里）去申请强制执行（单220、221的考法）。当初想让"甲放弃利息"这个优惠锁死，正确姿势是请求二审法院把和解协议**做成调解书**——调解书一送达，原判视为撤销，以后就按调解书执行。

**两个变体看"不准撤"**：变体一——二审法官阅卷发现一审把**法定利率上限算错了**、判决确有错误，乙公司却申请撤回上诉（想让错判生效再私下了断）？法院**不应准许**，接着审。变体二——甲乙两家其实是**串通虚假诉讼**、想借生效判决损害乙公司其他债权人，二审识破后乙申请撤回上诉？**不应准许**（解释§335）。

**再区分"撤起诉"**：如果二审中是**甲公司（原审原告）**说"这案子我整个不告了"——那是撤回**起诉**，得问乙公司丙公司**同不同意**，准了还要**把一审判决一并撤销**，而且甲以后**再拿同一诉请起诉法院不收**（解释§336）。撤上诉是"认了一审"，撤起诉是"全案清零且永久出局"，方向完全不同。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审撤回上诉规则：上诉人可在二审判决宣告前申请撤回上诉，是否准许由二审法院裁定；两类情形不予准许：一审判决确有错误，当事人恶意串通损害国家利益、社会公共利益、他人合法权益。二审法院裁定准许撤回上诉的，一审判决发生法律效力。二审阶段当事人自行达成和解协议后撤回上诉的，和解协议不具备强制执行力；一方不履行和解协议，另一方只能依据生效一审判决申请强制执行；若想要和解内容具备强制执行力，可申请法院依据和解协议制作调解书，调解书送达后一审判决视为撤销。区分二审撤回上诉与二审中原审原告撤回起诉：撤回上诉仅终结二审程序、一审判决生效；原审原告在二审申请撤回起诉，需要其他当事人同意，且不得损害三类法益，准许撤回起诉应当一并撤销一审裁判，且原审原告撤回起诉后就同一纠纷再次起诉，人民法院不予受理。‘

### 第三步：范围诀——围着上诉请求转，碰了禁止规定三益才全面查

> **没上诉的不审，漏判发回、新增另诉**

#### 概述

二审的"视野"由**处分原则**划界（§175＋解释§321）：

- **原则**：围绕**当事人的上诉请求**审理——上诉请求的有关事实和适用法律才审；**当事人没有提出请求的，不予审理**。未上诉部分哪怕二审瞄见了瑕疵，也不能伸手改。
- **例外（全面审查）**：一审判决**违反法律禁止性规定**，或者**损害国家利益、社会公共利益、他人合法权益**的——此时不受上诉请求限制。
- **两条分流管"请求对不上"**：
	- **一审已提出但漏判**的诉请（解释§324）：二审可自愿**调解**，调解不成→**发回重审**（一审欠的账让一审补，二审直接判会剥夺一个审级）；
	- **二审才新增**的独立诉请或反诉（解释§326）：就新请求**调解**，调解不成→**告知另行起诉**（一审压根没审过，二审直接审等于一审终审）；双方都同意由二审一并审理的，可以**一并裁判**；
	- 特例：一审判不准离婚、二审认为应当判离的，与子女抚养、财产**一并调解**，调解不成**发回重审**（解释§327）。

#### 大白话讲解

中院拿到甲乙公司的案卷。乙公司只对**2万元利息**上诉——中院的审理范围就是**这2万利息**：本金20万没人上诉，**不审**；保证人丙公司二审开庭时嚷嚷"我不该承担保证责任"，但丙**自己没上诉**——嚷嚷不等于上诉，担保部分**不在审理范围**（单212的考法：只审利息，本金、担保都靠边）。就算二审法官翻卷时发现"一审对丙承担保证责任的证据好像不太充分"，也**不能主动改**——那部分没人上诉（多211的考法）。

**什么时候破例全面查**？变个剧情：中院阅卷发现这笔"借款"其实是**赌债**——一审判决支持赌债违反法律**禁止性规定**——此时不管乙只上诉了利息，中院**全面审查**、连本金一起纠正。再变：一审判决把**案外人丁的房子**误当乙公司财产处理了，损害**他人合法权益**——同样破例全面审。

**两条分流别走反**：
- **剧情A（一审漏判）**：假设甲公司一审除了本息还请求了**违约金1万元**，一审判决只字未判。甲上诉后，二审能不能顺手判violations违约金？**不能直接判**——先调解，调不成就**发回重审**（解释§324）。二审替一审补判，等于这1万块**一审终审**，剥夺了当事人的审级利益（多216的考法：二审主动判一审漏掉的赔礼道歉＝错误做法）。
- **剧情B（二审新增）**：二审中甲公司突然加一条"再赔我仓储费5000元"——一审从没审过这请求，二审**调解，调不成告知另行起诉**（解释§326）；只有**双方都同意**让二审一并处理，才可以一并裁判。

**一句话分流**："**一审欠的账（漏判）→发回让一审补；二审新添的账（新增/反诉）→另案去开户**"——两条出口一个向下、一个向外，命题人最爱互换。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审审理范围规则：二审法院原则上围绕当事人上诉请求审理，当事人未提出上诉请求的内容不予审理；例外情形为一审判决违反法律禁止性规定，或者损害国家利益、社会公共利益、他人合法权益，不受上诉请求范围限制。当事人一审已提出但原审漏审漏判的诉讼请求，二审可调解，调解不成应当发回重审；二审中新增加独立诉讼请求、提出反诉的，二审可以调解，调解不成告知当事人另行起诉，双方当事人一致同意二审一并审理的，二审可以一并裁判；一审判决不准离婚，二审认为应当判决离婚的，可与子女抚养、财产分割问题一并调解，调解不成发回重审。

### 第四步：方式诀——开庭是原则，阅卷询问无新料才径行，独任要双方点头

> **先阅卷调查询问，无新事实证据理由，方可不开庭**

#### 概述

最后一问：这案子**怎么个审法**？

- **开庭原则**：二审对上诉案件**应当开庭审理**（§176）。开庭地点灵活：可在**本院**，也可到**案件发生地或原审法院所在地**（巡回/就地开庭）。
- **径行裁判（不开庭）例外**：必须先完成**阅卷、调查和询问当事人**三个前置动作，且当事人**没有提出新的事实、证据或者理由**、法院认为不需要开庭的，才**可以不开庭**。解释§331落地为四情形：①不服**不予受理、管辖权异议、驳回起诉**裁定的上诉；②上诉请求**明显不能成立**；③原判**事实清楚、仅适用法律错误**；④原判**严重违反法定程序需发回重审**。
- **审判组织**：合议庭为原则（成员单数，§41 I）；**例外独任**——中院对**一审简易程序审结**或**不服裁定**上诉的二审案件，**事实清楚、权利义务关系明确**，**经双方当事人同意**，可由审判员一人独任审理（§41 II）。一方异议→不能独任、转合议庭。
- **程序与审限**：二审除本章规定外**适用一审普通程序**（§181）；开庭的可依§136第四项做审理前准备（解释§322）；新证据须组织**质证**。审限：对**判决**上诉三个月（本院院长批准延长）、对**裁定**上诉三十日终审（§183，延长亦由院长批准，解释§339）。二审裁判是**终审**（§182），对裁定上诉的处理**一律用裁定**（§178）。
- **附带**：二审可以**调解**，调解书送达后**原判视为撤销**（§179）。

#### 大白话讲解

中院怎么安排甲乙公司这场二审？

**先看开不开庭**：乙公司上诉状里附了一张一审没交过的**利息结算单**——这是**新证据**，中院**必须开庭**，还要组织双方对这张单子**质证**、可指定举证期限（多210的考法）。开庭地点不一定在中院大楼——为方便当事人，可以**跑到区法院所在地开庭**（巡回审理，同样是多210考点）。变个剧情：如果乙公司上诉状通篇就是把一审辩过的理由复读一遍、没有任何新事实新证据新理由，中院**阅卷、调查、询问双方**之后，认为没必要开庭——**可以径行裁判**；再如上诉的是"驳回起诉"裁定、或原判明显要发回重审——也在解释§331的可不开庭清单里。记牢顺序：**先"阅卷＋调查＋询问"三件套，后"无新料"判断，才能不开庭**——跳过前置动作直接书面审，程序违法。

**再看谁来审**：本案一审是**简易程序**审结的，中院认为事实清楚、权利义务明确，想让赵法官**一人独任**——行不行？要**问甲乙两家**：双方都同意→独任合法（多210）；乙公司当庭异议→**独任泡汤，转合议庭**（单209的考法）。注意这跟一审不一样：一审简易程序独任是**当然配置**，二审独任是**协商解锁**。

**最后掐表**：二审立案之日起，对**判决**的上诉**三个月**内审结（特殊情况**本院院长**批准延长——注意二审延长只需院长批，没有"报上级"这一级）；如果乙公司当初上诉的是个**裁定**（比如驳回起诉），中院**三十日**内必须作出**终审裁定**。审完的判决、裁定都是**终审**文书，送达即生效——想再翻盘，只剩审判监督程序那扇窄门。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审审理方式规则：二审审理上诉案件以开庭审理为原则；开庭地点可在本院，也可在案件发生地或原审法院所在地。不开庭径行裁判须先完成阅卷、调查和询问当事人，当事人未提出新事实、新证据、新理由，法院认为无需开庭才可适用；可不开庭审理包含四类情形：不服不予受理、管辖权异议、驳回起诉裁定提起上诉；上诉请求明显不能成立；原判决事实清楚、仅适用法律错误；原判决严重违反法定程序需要发回重审。二审审判组织以审判员组成合议庭为原则；中级法院审理一审简易程序审结的案件、不服裁定上诉的案件，事实清楚、权利义务关系明确，经双方当事人一致同意，可由审判员一人独任审理，一方当事人提出异议的，应当转为合议庭审理。二审程序除二审专门规定外，适用一审普通程序；审理中出现新证据应当组织质证。审限区分两类：针对判决上诉案件审限三个月，针对裁定上诉案件审限三十日；特殊情况需要延长审限，由本院院长批准。二审裁判属于终审裁判；针对裁定的上诉案件，二审处理结果一律使用裁定。二审程序可以调解，调解书送达后，原审判决视为撤销。 必要共同诉讼人一审未参加，二审调解不成撤销原判发回重审;

- 一个案子打到中院二审，二审作出的判决书、裁定书，**就是最终结果**。 不能再继续往上上诉。不服只能走再审（审判监督程序）。

### 第五步：出口诀——对了维持错了改，事实不清可改可发，程序违法必须发回

> **发回只有一次；裁定错了用"指令"，判决错了才谈"发回"**

#### 概述

前四步解决"怎么上去、审什么、怎么审"，最后一问才是当事人真正关心的：**二审审出一审有问题，到底怎么收场？**民诉法§177把出口锁死为**四条**，多一条少一条都是错项：

| 一审的毛病 | 二审出口 | 裁判形式 | 有无裁量 |
|---|---|---|---|
| ①事实清楚＋法律正确 | **驳回上诉，维持原判** | 判决/裁定 | —— |
| ①之延伸：**有瑕疵但结果正确** | 裁判中**纠正瑕疵后维持**（解释§332） | 判决/裁定 | —— |
| ②认定事实**错误**／适用法律**错误** | **依法改判**、撤销或者变更 | 判决/裁定 | —— |
| ③原判**基本事实不清** | 撤销原判后：**发回重审 or 查清事实后改判** | 裁定（发回） | ✅ **可改可发** |
| ④原判**严重违反法定程序** | 撤销原判，**发回重审** | 裁定 | ❌ **只能发回** |

- **第③项的"基本事实"不是随便什么事实**——指用以确定**当事人主体资格、案件性质、民事权利义务**等对原裁判**结果有实质性影响**的事实（解释§333）。枝节事实不清不构成发回理由。
- **第④项"严重违反法定程序"有两份清单**：条文本体例示**遗漏当事人、违法缺席判决**；解释§323另列四项——**审判组织的组成不合法／应当回避的审判人员未回避／无诉讼行为能力人未经法定代理人代为诉讼／违法剥夺当事人辩论权利**。两份清单不可互相错挂条号。
- **发回重审以一次为限**（§177 II）：原审对发回重审的案件作出判决后，当事人再上诉的，二审**不得再次发回重审**——只能自己查清事实裁判（可再行调解，§179）。
- **三条"不走发回"的特殊出口**：一审**不予受理／驳回起诉裁定**错误的→撤销原裁定同时**指令**一审立案受理／审理（解释§330）；案件**依法不应由法院受理**的→二审**直接裁定撤销原裁判、驳回起诉**（解释§328）；一审受理**违反专属管辖**的→**裁定撤销原裁判并移送**有管辖权的法院（解释§329）。
- **形式与效力**：对**裁定**的上诉，处理**一律用裁定**（§178）；二审判决、裁定即**终审**（§182），不得再上诉，只剩再审。

- 🔀 **②号出口"改判"已单独成步**：改判的三个来源、四条边界（含**禁止不利益变更**这个"无明文的通说"陷阱）见下方**第六步**——本步只负责把四条出口先分清楚。
- **发回之后一审怎么走**：按**一审程序**重新审理——当事人变更、增加诉请或提反诉的依§143处理（解释§251）；**不得适用简易程序**（解释§257(二)）；当事人提**管辖异议不予审查**（解释§39 II）。

#### 大白话讲解

回到甲乙公司那条时间线：乙公司只就**2万元利息**上诉，中院开完庭，接下来就是"判"这一步。**同一份卷宗，五种剧情五种判法**：

**剧情①（一审全对）**：中院算下来利息计得没错、法律引得也对——**判决驳回上诉，维持原判**。变体：一审判决书把利率写成"年化"却按月息算式列了一遍，**表述有瑕疵但金额算对了**——中院不必改判，在判决书里**把瑕疵纠正一下、照样维持**（解释§332）。记住分水岭是**结果对不对**，不是有没有小毛病。

**剧情②（算错了/法条引错了）**：中院查明一审把逾期利率上限适用错了，2万应为1.2万——事实/法律**错误**，中院**直接改判**（§177 I(二)）。这时候没有"发回"的余地：事实是清楚的，只是结论错了，二审自己改就行——**别一见错就喊发回**。（改判**能改到哪儿**、能不能改得更多，是另一套规则，见**第六步**。）

**剧情③（事实糊了）**：中院翻卷发现，这20万到底是**借款还是投资款**都没查清——这直接决定**案件性质和权利义务**，属于**基本事实不清**（解释§333）。中院有**两条路可选**：裁定撤销原判**发回重审**，或者**自己查清后改判**——法条原文就是"发回……**或者**查清事实后改判"。所以选项里出现"基本事实不清的**必须**发回重审"，是把裁量说成义务，**错**。

**剧情④（程序烂了）**：中院发现一审压根**没通知保证人丙公司参加诉讼**就判它担责——**遗漏当事人**，§177 I(四)只有一条出口：**裁定撤销原判、发回重审**，**不能**"二审直接追加丙进来改判"（丙就被吃掉一个审级了，单347的考法）。同理，一审**合议庭里混进了书记员**（审判组织不合法）、**该回避的法官没回避**、**违法剥夺一方辩论权**——都在解释§323的四项里，**一律发回**。

**剧情⑤（发回过一次了）**：一审重审后又判了，乙公司再次上诉，中院还是觉得事实没查透——**能不能再发一次？不能**（§177 II）。只能自己查清直接判；如果是离婚案，还可以**再调解一次**（多219的考法：A"再次发回"错、D"就财产部分发回"也错，因为那还是再次发回）。口诀：**"发回只有一张票，第二次上来自己判。"**

**别走错门的三个变体**：
- 一审裁定**驳回起诉**、中院认为不该驳——不是"发回重审"，而是**撤销原裁定＋指令一审审理**（解释§330）。**裁定用"指令"，判决才"发回"**。
- 中院发现这案子**根本不属于法院主管**（比如属于行政处理事项）——**直接裁定撤销原裁判、驳回起诉**（解释§328），不发回。
- 中院发现一审违反**专属管辖**（不动产纠纷跨区受理）——**裁定撤销原裁判并移送**有管辖权的法院（解释§329），也不发回。

**发回以后一审怎么审**：按一审程序重来一遍，甲公司这时候**可以变更、增加诉请**、乙公司**可以反诉**（依§143处理，解释§251）；但**不能再用简易程序**（解释§257(二)，多177的考法）；乙公司想借机再提**管辖异议**——**不予审查**（解释§39 II）。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审裁判方式四出口（民诉法§177 I）：①原判决、裁定认定事实清楚、适用法律正确的，以判决、裁定驳回上诉、维持原判；原判虽有瑕疵但裁判结果正确的，纠正瑕疵后仍依第一项维持（解释§332）。②原判决、裁定认定事实错误或者适用法律错误的，依法改判、撤销或者变更。③原判决认定基本事实不清的，裁定撤销原判决，发回原审法院重审**或者**查清事实后改判——**可改可发，二审有裁量权**；基本事实指确定当事人主体资格、案件性质、民事权利义务等对裁判结果有实质性影响的事实（解释§333）。④原判决遗漏当事人或者违法缺席判决等严重违反法定程序的，裁定撤销原判决，**必须发回重审**，无改判选项；严重违反法定程序另包括审判组织的组成不合法、应当回避的审判人员未回避、无诉讼行为能力人未经法定代理人代为诉讼、违法剥夺当事人辩论权利四项（解释§323）。**发回重审以一次为限**：原审法院对发回重审的案件作出判决后当事人再上诉的，二审不得再次发回重审，只能查清事实自行裁判，仅就部分事项发回同样禁止, 离婚案二审可再行调解（§177 II）。三条不走发回的出口：一审不予受理裁定错误的撤销原裁定并**指令**立案受理、驳回起诉裁定错误的撤销原裁定并**指令**审理（解释§330）；案件依法不应由法院受理的，二审直接裁定撤销原裁判、驳回起诉（解释§328）；一审受理违反专属管辖的，裁定撤销原裁判并移送有管辖权的法院（解释§329）。对裁定的上诉案件处理一律使用裁定（§178）；二审判决、裁定为终审（§182）。发回重审后按一审程序审理：原告增加诉讼请求，被告提出反诉，第三人提出与本案有关的诉讼请求，可以合并审理，不得适用简易程序（解释§257(二)），当事人提出管辖异议不予审查（解释§39 II）。

> 📎 **本步与姊妹模型的分工**：本步只讲"**查出问题怎么判**"（§177四出口＋发回规则＋三条特殊出口）。二审的**调解**（§179调解书送达后原判视为撤销）、**撤回起诉**（解释§336）、**新增诉请/反诉的另诉分流**（解释§326）、**终审效力与再审衔接**（§182→§211）等收尾制度的完整展开，见 [[民诉-二审-二审裁判与调解模型]]（第8章 8-5~8-7）。

### 第六步：改判诀——只在上诉请求里改，不能把上诉人改得更糟

> **能改判 ≠ 想怎么改就怎么改；改判的分数全在"边界"上**

#### 概述

第五步解决"走哪个出口"，本步只解决一件事：**决定改判之后，能改多少、往哪个方向改。**命题人极少问"能不能改判"，几乎全在考**改判的边界**。

**一、改判有三个来源，别只记住 §177 I(二)：**

| 来源 | 触发情形 | 二审的自由度 |
|---|---|---|
| **§177 I(二) 直接改判** | 事实清楚，只是**认定事实错误**或**适用法律错误** | 应当改判——事实不用再查，二审自己纠 |
| **§177 I(三) 查清事实后改判** | 原判**基本事实不清** | **可改可发**（二选一）——二审可自行开庭调查、组织新证据质证，查清后改判 |
| **§177 II 被迫改判** | 已**发回重审过一次**、重审判决后当事人再上诉 | **只能自行裁判**，不得再发回（离婚等案件可再调解，§179） |

**二、"改判、撤销或者变更"是 §177 I(二) 原文的三个并列动词。** 做题层面的理解性区分（**属理解性 gloss，非法条定义**，仅用于把选项读通）：*改判*＝重新作出实体判项；*撤销*＝把原判决或其中某判项废掉；*变更*＝对原判项作局部调整（数额、履行方式、期限）。共同点是**二审自行终局处理、不退回一审**。

**三、改判的四条边界（本步全部分值所在）：**

1. **只能在上诉请求范围内改**（§175＋解释§321）——未上诉部分不得改判，哪怕二审认为一审判错了、证据不足。破例仅限一审判决**违反法律禁止性规定**或**损害国家利益、社会公共利益、他人合法权益**（此时才全面审、才可动未上诉部分）。
2. **禁止不利益变更**——只有一方上诉时，二审**不得作出对该上诉人比原判更不利的改判**（否则等于因其行使上诉权而惩罚他，也超出了他自己划定的请求范围）。**对方也提起上诉的**，双方请求区间全部进入审理范围，**不受此限**。
   > ⚠️ **诚实标注（本模型最容易被编造条号的一处）**：这条规则在**民诉法与民诉解释中均无明文**。已对2023民诉法、2022民诉解释官方全文逐词检索——"**改判**"在民诉法中**仅出现2次**（都在§177第二、三项），"**不利益／更不利／不得加重**"**零命中**。它是由**处分原则＋解释§321**（围绕上诉请求审理、未提出请求的不予审理）推出的**学理/通说表述**。答题可以用它的**结论**，但**不得虚标民诉法条号**，更不能写成"民诉法规定了上诉不加刑"——**"上诉不加刑"是刑诉法§237的规则**，见 [[刑诉-审判-上诉不加刑模型]]，两者不可混用。
3. **不能用改判去补一审的窟窿**——一审**已提出但漏判**的诉请：调解，**调解不成发回重审**（解释§324）；二审**才新增**的诉请或反诉：调解，**调解不成告知另行起诉**（解释§326，双方同意才可一并裁判）。二审直接判＝该部分**一审终审**，剥夺审级。
4. **程序严重违法不得改判**——§177 I(四) 只有"发回"一条路；一审遗漏必要共同诉讼当事人的，同样是"调解不成**发回**"（解释§325），**不能**"二审直接追加当事人并改判"。

**四、形式配套**：对**判决**的上诉用**判决**改判；对**裁定**的上诉处理**一律使用裁定**（§178）。另有一条**不叫改判但同样消灭原判**的路径：二审调解成立的，**调解书送达后原审判决即视为撤销**（§179）——选项把它说成"二审改判"是偷换。

#### 大白话讲解

还是甲乙那笔账：一审判乙公司还本金**20万**、付利息**2万**，丙公司承担一般保证责任。**只有乙公司上诉，只诉利息，理由是"利息判高了"。**中院决定要动这2万——**能动到哪儿？四个变体一次记牢：**

| 变体 | 中院能不能这么判 | 理由 |
|---|---|---|
| 中院算出利息应为 **1.2万** | ✅ **改判：利息1.2万** | 在乙的上诉请求范围内（乙求少判），方向对上诉人**有利** |
| 中院认为利息应为 **2.5万**（甲没上诉） | ❌ **只能维持2万** | 既**超出上诉请求**（解释§321），又让唯一上诉人**处境更糟**（禁止不利益变更） |
| 甲公司**也上诉**、主张利息应为3万 | ✅ 可改判 **2.5万** | 双方都上诉，2万~3万整个区间都进了审理范围，不利益变更的限制解除 |
| 中院顺手觉得**本金20万**认定有疑 | ❌ **不审不改** | 本金无人上诉；除非查出是**赌债**等违反禁止性规定，才破例全面审 |

**一句话记住方向**：**"乙自己上诉喊少判，中院最多把利息判得更少，绝不会因为他上诉反而判他更多。"** 想让他判更多？**甲必须自己也上诉。**

**再看三个"以为能改判、其实不能"的坑**：
- 甲一审还请求过**违约金1万**、一审判决只字没提——中院能不能顺手在改判时补上？**不能**。这是**漏判**，先调解，调解不成**发回重审**（解释§324，多216的考法）。
- 甲在二审突然加一句"再赔仓储费5000"——**不能改判解决**，调解不成**告知另行起诉**（解释§326）；除非**双方都同意**由二审一并审理。
- 中院发现一审**没通知丙公司**就判它担保——**不能**"把丙追加进来一起改判"，只能**发回**（解释§325＋§177 I(四)，单347的考法）。

**最后别混形式**：乙上诉的是**判决**→中院用**判决**改判；如果乙当初上诉的是"驳回起诉"**裁定**→中院的处理**一律用裁定**（§178），而且这种情形正确动作是**指令一审审理**（解释§330），根本不叫"改判"。还有一种"原判没了但不是改判"的情况：甲乙二审调解成立，**调解书一送达，一审判决就视为撤销**（§179）。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审改判规则：改判有三个来源——①原判决、裁定认定事实错误或者适用法律错误的，依法改判、撤销或者变更（民诉法§177 I(二)）；②原判决认定基本事实不清的，二审可发回重审**或者**查清事实后改判（§177 I(三)，可改可发）；③已发回重审一次、原审重新判决后当事人再上诉的，二审不得再次发回，只能查清事实自行裁判（§177 II）。改判受四条边界限制：第一，改判只能在**上诉请求范围内**进行，当事人没有提出上诉请求的部分不予审理、不得改判，例外为一审判决违反法律禁止性规定或损害国家利益、社会公共利益、他人合法权益（民诉法§175＋解释§321）；第二，**禁止不利益变更**——仅一方当事人上诉的，二审不得作出对该上诉人比原判更为不利的改判，对方当事人也提起上诉的不受此限（**该规则民诉法与民诉解释均无明文，系处分原则与解释§321推导出的通说，引用时不得虚标条号；"上诉不加刑"是刑事诉讼法§237的规则，不得移用于民诉**）；第三，改判不得用于填补审级空缺——一审已提出而漏判的诉讼请求，调解不成应当**发回重审**（解释§324），二审新增的独立诉讼请求或反诉，调解不成应当**告知另行起诉**（解释§326），双方同意由二审一并审理的方可一并裁判；第四，原判决遗漏当事人、违法缺席判决等严重违反法定程序的，只能撤销原判决**发回重审**，不得查清后改判（§177 I(四)＋解释§325）。形式上，对判决的上诉以判决改判，对裁定的上诉处理一律使用裁定（§178）；二审调解成立的，调解书送达后原审判决视为撤销（§179），此项不属改判。



- 原判决认定基本事实不清 
	- **基本事实 = 能直接决定输赢的关键事实（欠钱数额、是否存在合同、侵权责任是否成立等核心事实），不是鸡毛蒜皮的次要细节。
	- ** 原判决认定基本事实不清：一审法院**没有把决定案件结果的关键事实查明白**，证据不足、事实存疑。

## 六、 易混提示

*   **上诉期起算 vs 统一起算**：
    *   判决书**分别送达**各当事人，十五日（裁定十日）**各自起算**；一方补收判决书的，其上诉期从补收之日起算——不存在"全案统一的上诉截止日"。
*   **撤回上诉 vs 撤回起诉（二审中）**：
    *   *撤回上诉*（§180＋解释§335）：二审裁定把关，两种不准，后果是**一审判决生效**；*撤回起诉*（解释§336）：须**其他当事人同意**＋不损三益，**一并撤销一审裁判**，且**重复起诉不予受理**。
*   **围绕上诉请求 vs 全面审查**：
    *   *原则*围绕上诉请求、没提的不审；*例外*仅在一审判决**违反法律禁止性规定**或**损害国家/社会公共/他人合法权益**时全面审查——"可依职权全面审查"是把例外当常态的错误表述。
*   **一审漏判 vs 二审新增（两条分流）**：
    *   *漏判*（一审已提出未判）：调解不成**发回重审**（解释§324）；*新增*（二审才提出的诉请/反诉）：调解不成**告知另行起诉**（解释§326，双方同意可一并裁判）——一个向下发回、一个向外另诉，勿互换。
*   **一审独任 vs 二审独任**：
    *   *一审*简易程序独任是当然配置（§40）；*二审*独任是例外解锁——限中院、限一审简易审结或裁定上诉案、事实清楚，且**必须经双方当事人同意**（§41 II），一方异议即合议庭。
*   **一审审限 vs 二审审限**：
    *   *一审*六个月＋院长批六个月＋**报上级批**（三段）；*二审*判决上诉**三个月**、裁定上诉**三十日**，延长只需**本院院长批**（无"报上级"一级）。
*   **§177(三) vs §177(四)——可改可发 vs 必须发回**：
    *   *(三)基本事实不清*：撤销原判后"发回重审**或者**查清事实后改判"——**二选一**；*(四)严重违反法定程序*（遗漏当事人、违法缺席判决＋解释§323四项）：**只能发回重审**，条文里没有"或者改判"。
*   **发回重审 vs 指令受理/审理 vs 直接驳回起诉 vs 撤销并移送**：
    *   一审**判决**有事实/程序问题→**发回重审**（§177）；一审**不予受理/驳回起诉裁定**错误→撤销原裁定＋**指令**立案受理/审理（解释§330）；案件**不应由法院受理**→二审**直接裁定撤销原裁判、驳回起诉**（解释§328）；一审受理**违反专属管辖**→**裁定撤销原裁判并移送**（解释§329）。**只有第一种叫"发回"**。
*   **瑕疵 vs 错误**：
    *   事实认定或法律适用**有瑕疵但裁判结果正确**→纠正瑕疵后**维持**（解释§332，走§177 I(一)）；认定事实**错误**或适用法律**错误**（结果不对）→**改判**（§177 I(二)）。分水岭是**结果**，不是瑕疵本身。
*   **改判 vs 撤销 vs 变更（§177 I(二)三个并列动词）**：
    *   *改判*＝重新作出实体判项；*撤销*＝废掉原判决或其中某判项；*变更*＝对原判项作局部调整（数额、履行方式、期限）。三者都是**二审自行终局处理、不退回一审**——这是**理解性区分，非法条定义**。
*   **民诉"禁止不利益变更" vs 刑诉"上诉不加刑"**：
    *   *民诉*：仅一方上诉的，二审不得改得对该上诉人更不利——**无明文**，由处分原则＋解释§321推出的**通说**，对方也上诉即解除限制；*刑诉*：**§237明文**的上诉不加刑（被告人一方上诉的不得加重刑罚）。**引用民诉时不得标条号，更不得写成"民诉法规定了上诉不加刑"**（详见 [[刑诉-审判-上诉不加刑模型]]）。
*   **改判 vs 调解书撤销原判**：
    *   *改判*＝二审以判决重新处理实体（§177 I(二)(三)）；*二审调解成立*＝**调解书送达后原审判决视为撤销**（§179）——原判同样消灭，但**不是改判**，选项互换即错。
*   **发回重审"一次为限" vs 再审发回**：
    *   §177 II限的是**二审对同一案件的第二次发回**——重审判决后再上诉，二审只能自判；"只就财产/某一诉请发回"仍算再次发回。（再审程序的发回规则另循审判监督章，勿混。）

## 七、 命题人最爱的 12 个陷阱

1.  **"判决书已送达一方当事人，全案上诉期自该日起算"** —— 错！判决书分别送达，上诉期自**各自收到之日**起算；未收到的当事人经补发收到后仍可在自己的十五日内上诉（其间判决对他未生效，谈不上再审）。
2.  **"原审法院发现上诉超过上诉期的，应不予接收或裁定驳回上诉"** —— 错！原审法院只负责送达副本并**连同全部案卷证据报送二审法院**（§173-174），是否超期由**二审法院**审查处理。
3.  **"无独立请求权第三人对一审判决不得上诉"** —— 错！**被判决承担民事责任**的无独三有当事人的诉讼权利义务（§59 II），可以上诉；但其在二审提出的**超出本案标的**的请求（如代位权案中债务人索要未被代位的余款）不属二审审理范围，应另案主张。
4.  **"二审宣判前上诉人申请撤回上诉的，法院应当准许"** —— 错！由二审法院**裁定**是否准许；**一审判决确有错误**或当事人**恶意串通损害三益**的不应准许（解释§335）。
5.  **"二审和解后撤回上诉，对方反悔的，可依和解协议申请强制执行/司法确认"** —— 错！诉讼和解协议**无强制执行力**、也不能司法确认；撤回上诉后**一审判决生效**，应依**生效一审判决**申请执行；要执行力须请求法院制作**调解书**（解释§337）。
6.  **"二审应当全面审查一审认定的事实和适用法律／未上诉部分可主动改判／一审漏判的诉请二审可直接判决"** —— 错！二审**围绕上诉请求**审理（§175＋解释§321），全面审查仅限"违反禁止性规定/损害三益"例外；未上诉部分不审不改；一审漏判的诉请调解不成**发回重审**（解释§324），二审直接判决＝超出上诉请求、剥夺审级。
7.  **"原判决认定基本事实不清的，二审应当裁定撤销原判决、发回重审"** —— 把裁量说成义务！§177 I(三)是"发回原审人民法院重审，**或者查清事实后改判**"——**可改可发**。反过来，第（四）项**严重违反法定程序**才是**只能发回**（无"或者改判"），选项若给它安排"可以查清后改判"同样错。
8.  **"一审遗漏必要共同诉讼当事人的，二审可直接追加当事人并改判"** —— 错！遗漏当事人属§177 I(四)严重违反法定程序，路径是**自愿调解；调解不成裁定撤销原判、发回重审**（解释§325）——直接追加改判会让被追加人**一审即终审**，剥夺审级（单347）。解释§323另列三种同类程序违法：审判组织不合法、应回避未回避、无诉讼行为能力人未经法代、违法剥夺辩论权。
9.  **"发回重审的案件重审后再上诉，二审仍可发回（或就财产部分发回）"** —— 错！§177 II明文：原审对**发回重审的案件作出判决后**当事人上诉的，二审**不得再次发回重审**，只能查清事实**自行裁判**（离婚等案件可再调解，§179）；"只发回财产部分"仍是再次发回（多219）。
10.  **"仅被告一方上诉请求少判，二审认为原判判少了，可以改判增加其给付数额"** —— 错！改判**不得超出上诉请求范围**（§175＋解释§321），只有一方上诉时也**不得改得对该上诉人更不利**（**禁止不利益变更**）。⚠️ 该规则**民诉法与解释均无明文**（系处分原则＋§321推出的通说），**引用勿标条号**；"上诉不加刑"是**刑诉§237**，不得移用于民诉。**对方也上诉的，限制解除。**
11.  **"一审漏判的诉请／二审新增的诉请，二审可以查清后一并改判解决"** —— 错！**漏判**→调解不成**发回重审**（解释§324）；**新增诉请/反诉**→调解不成**告知另行起诉**（解释§326，双方同意才可一并裁判）。改判**不能用来填补审级**。
12.  **"一审驳回起诉的裁定错误，二审应撤销原裁定并发回重审"** —— 用错动词！**裁定错了用"指令"**：不予受理裁定错→撤销＋**指令立案受理**；驳回起诉裁定错→撤销＋**指令审理**（解释§330）。另两条也不叫发回：不应由法院受理→**直接裁定撤销原裁判、驳回起诉**（解释§328）；违反专属管辖→**裁定撤销原裁判并移送**（解释§329）。
