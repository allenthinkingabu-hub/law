# 📐 民诉·执行总论与措施 · 完整答题模型（执行依据 + 执行管辖 + 申请执行期间 + 执行措施体系 + 财产报告与信用惩戒）

> **核心一句**：强制执行的主线是**「凭什么执行（依据）→ 向哪个法院、多久内申请（管辖§235＋期间§250）→ 怎么启动（申请/移送执行§247）→ 用什么措施（金钱债权查冻划扣提§253-255／交付迁出代履行§260-263）→ 拿什么保障（财产报告§252、信用惩戒§266、迟延履行金§264）」**。最毒的陷阱是**把执行管辖说成"一律一审法院/一律中院"**、**把无给付内容的确认判决/形成判决当成执行依据**、**把"申请执行期间2年"当成不可中止中断的除斥期间（其实与诉讼时效同规则可中止中断）**、**把"加倍支付迟延履行利息"套到非金钱义务上**、**说"查封后被执行人可擅自处置查封物"**。
>
> 🔎 **《民事诉讼法》（2023修正，2024-01-01施行）核心条文速查**（条号已逐条 grep 官方全文核验）：
> - **§235【执行管辖】**：生效民事判决、裁定，及刑事判决、裁定中的财产部分，由**第一审法院或者与第一审法院同级的被执行财产所在地法院**执行；法律规定由法院执行的**其他法律文书**（仲裁裁决、公证债权文书等），由**被执行人住所地或者被执行财产所在地法院**执行。
> - **§237【6个月未执行】**：法院自收到申请执行书超过六个月未执行的，申请执行人可向**上一级法院**申请执行；上级可责令原院限期执行、决定自行执行或指令他院执行。
> - **§245【调解书执行】**：法院制作的调解书的执行，适用本编（执行编）的规定（前提是含给付内容）。
> - **§247【申请执行与移送执行】**：生效判决裁定当事人必须履行，一方拒绝的对方可申请执行，也可由**审判员移送执行员执行**；调解书及其他应由法院执行的文书同。
> - **§250【申请执行期间】**：申请执行的期间为**二年**。申请执行时效的**中止、中断**，适用法律有关**诉讼时效**中止、中断的规定。期间从法律文书规定履行期间最后一日起算；分期履行的从最后一期届满日起算；未规定履行期间的从文书生效之日起算。
> - **§251【执行通知】**：执行员接到申请执行书或移交执行书，应向被执行人发出执行通知，**并可以立即采取强制执行措施**。
> - **§252【财产报告令】**：被执行人应报告当前及收到执行通知之日前一年的财产情况；拒绝报告或虚假报告的，可对被执行人或其法定代理人、有关单位主要负责人/直接责任人**罚款、拘留**。
> - **§253【金钱债权措施·查询扣冻划变】**：法院有权查询存款、债券、股票、基金份额等，并可扣押、冻结、划拨、变价被执行人财产，**不得超出应履行义务的范围**；应作出裁定并发协助执行通知书。
> - **§254【扣留提取收入】**：可扣留、提取被执行人应履行义务部分的收入，但应**保留被执行人及其所扶养家属的生活必需费用**。
> - **§255【查封扣押冻结拍卖变卖】**：可查封、扣押、冻结、拍卖、变卖被执行人应履行义务部分的财产，但应**保留其及所扶养家属的生活必需品**。
> - **§256【查封扣押通知到场】**：查封、扣押时被执行人是公民的应通知本人或成年家属到场，是法人/组织的通知法定代表人或主要负责人到场，**拒不到场不影响执行**。
> - **§257【查封物保管】**：被查封的财产，执行员可指定被执行人负责保管；因其过错造成损失由被执行人承担（保管≠可处分）。
> - **§260-263【交付与行为债权】**：§260交付财物票证；§261强制迁出房屋、退出土地（院长签发公告）；§262财产权证照转移协助；**§263行为债权代履行**（可强制执行或委托他人完成，**费用由被执行人承担**）。
> - **§264【迟延履行责任】**：未按期履行**金钱**给付义务的，**加倍支付迟延履行期间的债务利息**（I款）；未按期履行**其他（非金钱）**义务的，**支付迟延履行金**（II款）。
> - **§266【信用惩戒】**：被执行人不履行义务的，可对其采取或通知有关单位协助采取**限制出境，在征信系统记录、通过媒体公布不履行义务信息**及法律规定的其他措施。
>
> 🔎 **配套司法解释**：《民诉法解释》（法释〔2022〕11号）**§505**（非金钱义务迟延履行金：已造成损失双倍补偿、未造成损失法院酌定）、**§508**（执行价款先清偿优先债权）、**§516**（失信被执行人名单+征信通报）、**§1097**（限制高消费令）；到期债权**代位执行**规则出自《最高人民法院关于人民法院执行工作若干问题的规定（试行）》（法释〔1998〕15号，2020修正）。

> ⚠️ **诚实标注（条号核验说明）**：上列**民诉法§235-§266、§237、§247、§250-§257、§260-§264全部经本次逐条 grep 官方全文（ssf.gov.cn 权威版）核对原文一致**，可信度高。**特别订正**：既往部分资料/讲义把"执行管辖"标为**§231**——经核验实为**§235**（系2021旧版条号，2023现行版偏移+4）；"财产报告令""移送执行""行为债权代履行"曾被标为"多在民诉解释"——经核验均在**民诉法本体**（§252/§247/§263），并非仅见于司法解释。**本地未逐字核验、诚实标注"以官方为准"者**：①到期债权代位执行的具体条号（《执行工作规定》第61-69条依通说，本地无原文，附 [court.gov.cn](https://www.court.gov.cn)）；②查封/冻结的具体期限天数、公证债权文书执行的级别归属（基层法院系实务通行做法，最高法专门规定本轮未程序化核验）。**权威源**：[民诉法2023全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)、[国家法律法规数据库（flk.npc.gov.cn）](https://flk.npc.gov.cn)。

> ⚠️ **易记错点**：①**执行管辖是"二选一"不是"独占"**——法院裁判由"一审法院**或**同级财产所在地法院"，其他文书由"被执行人住所地**或**财产所在地法院"，见"一律一审法院""一律中院"必错；②**执行找一审法院不找二审法院**——二审中院只作终审裁判，执行回到第一审法院；③**申请执行期间2年是"时效"不是"除斥期间"**——可中止、中断，与诉讼时效同规则（§250），过了2年只是丧失申请执行的胜诉权、并非绝对消灭；④**只有"给付内容"的文书才有执行力**——确认之诉、形成之诉的判决自身不含给付命令，不能直接申请执行；⑤**"加倍支付迟延履行利息"专属金钱义务（§264 I），非金钱义务是"迟延履行金"（§264 II）**，二者不可互换；⑥**查封的命门是"限制处分"**——查封后被执行人只能保管（§257）、不得擅自处置，不动产执行必须"先查封后拍卖"；⑦**"生活必需费用"（§254扣留提取收入）与"生活必需品"（§255查封拍卖）是两个不同条文的但书**，别记串；⑧**移送执行仅限特定案件**（赡养费、扶养费、抚养费、劳动报酬等），不是所有案件都能由审判员移送执行。

## 二、 执行五步判别模型（依据 → 管辖·期间 → 启动 → 措施 → 保障惩戒）

```
        【债权人甲持对乙的生效法律文书，欲实现债权】
                        │
   ▼ 第一关：凭什么执行？——执行依据是否有"给付内容"？（§245/§247/§248/§249）
   │
   ├─ 给付判决 / 给付调解书 / 支付令 / 仲裁裁决 / 公证债权文书 ──→ 有给付内容，可执行
   └─ 确认之诉判决（确认合同有效/所有权归属）、形成之诉判决（撤销/解除/离婚）
      ──→ 无给付内容，不能直接申请执行
                        │
   ▼ 第二关：向哪个法院、多久内申请？（管辖§235 + 期间§250 + 6个月救济§237）
   │
   ├─ 管辖两轨（均二选一，非独占）：
   │   ├─ 法院裁判（判决/裁定/刑事财产部分）→ 第一审法院 或 同级财产所在地法院
   │   │   （★执行找一审法院，不找二审法院！）
   │   └─ 其他法律文书（仲裁裁决/公证债权文书）→ 被执行人住所地 或 财产所在地法院
   ├─ 申请执行期间 = 2年，可中止/中断（同诉讼时效§250）；
   │   起算：履行期最后一日 / 分期最后一期届满 / 未定期从生效日
   └─ 法院超6个月未执行 → 申请执行人可向上一级法院申请执行（§237）
                        │
   ▼ 第三关：怎么启动？（申请执行 or 移送执行 §247 + 执行通知 §251）
   │
   ├─ 申请执行：对方拒不履行，由当事人向法院申请（常态）
   ├─ 移送执行：审判员移送执行员（限赡养费/扶养费/抚养费、劳动报酬等特定案件）
   └─ 执行员发出执行通知，并可立即采取强制执行措施（§251）
                        │
   ▼ 第四关：用什么措施？——按债权类型对号入座
   │
   ├─ 金钱债权：
   │   ├─ 查询存款/债券/股票/基金份额 + 扣押冻结划拨变价（§253，不超范围）
   │   ├─ 扣留、提取收入（§254，保留"生活必需费用"）
   │   └─ 查封、扣押、冻结、拍卖、变卖财产（§255，保留"生活必需品"）
   │       └─ 不动产链条：先查封 → 后拍卖变卖（§255、§258）；查封=限制处分（§257）
   ├─ 交付物 / 票证：传唤当面交付或转交、被交付人签收（§260）
   ├─ 迁出房屋 / 退出土地：院长签发公告，逾期由执行员强制执行（§261）
   └─ 行为债权：代履行——强制执行或委托他人完成，费用由被执行人承担（§263）
                        │
   ▼ 第五关：拿什么保障与惩戒？（报告§252 + 迟延责任§264 + 信用惩戒§266）
   │
   ├─ 财产报告令：报告当前+前一年财产，拒报/虚报 → 罚款、拘留（§252）
   ├─ 迟延履行责任：
   │   ├─ 金钱义务未按期 → 加倍支付迟延履行期间债务利息（§264 I）
   │   └─ 非金钱义务未按期 → 支付迟延履行金（§264 II + 民诉解释§505）
   └─ 信用惩戒：限制出境 + 征信记录 + 媒体公布（§266）
      ＋ 限制高消费令（民诉解释§1097）、失信被执行人名单（民诉解释§516）
```

> **一句话总诀**：**「先看依据有没有给付（确认之诉、形成之诉不能执行）；再定管辖两轨（法院裁判找一审法院或财产地、别人的文书找被执行人住所地或财产地，都是二选一）＋期间2年可中止中断；启动分申请/移送＋执行通知后立即可动手；措施对号入座——金钱债权查冻划扣提、交付迁出走§260/261、行为债权代履行费用债务人担；最后靠财产报告令＋迟延履行金（非金钱）/加倍利息（金钱）＋限出境征信失信名单兜底」**

## 三、 高频干扰选项一览

命题人在执行编的绝对化、张冠李戴上挖坑最密集：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **管辖独占化** | 生效判决"一律由一审法院执行"；仲裁裁决"一律由被执行人住所地中院执行"。 | **❌ 均是"二选一"。**法院裁判→一审法院**或**同级财产所在地法院；其他文书→被执行人住所地**或**财产所在地法院（§235）。"一律"漏掉财产所在地/绝对化级别即错。 |
| **执行找二审法院** | 二审维持原判后，向二审中院申请执行。 | **❌ 执行回第一审法院。**二审只作终审裁判，生效判决由第一审法院或同级财产地执行（§235），不归二审中院。 |
| **无给付内容也能执行** | 确认合同有效/确认所有权的判决、离婚判决可直接申请强制执行。 | **❌ 无给付内容不能执行。**确认之诉、形成之诉判决自身不含给付命令；离婚判决中财产分割等给付部分另计（§245执行以给付内容为前提）。 |
| **申请执行期间是除斥期间** | 申请执行期间2年不变期间，不因任何事由中止中断。 | **❌ 是时效，可中止中断。**§250明定"适用诉讼时效中止、中断规定"，性质同诉讼时效。 |
| **加倍利息套非金钱义务** | 拒不迁出房屋，加倍支付以损失为基数的同期银行利息。 | **❌ 加倍利息仅限金钱义务（§264 I）。**非金钱义务是"迟延履行金"（§264 II、民诉解释§505），迁出房屋适用后者。 |
| **查封后可处分** | 查封后被执行人可保管，故可自行处置查封财产。 | **❌ 查封=限制处分。**被执行人只能保管（§257），擅自处分不得对抗执行；不动产须先查封后拍卖。 |
| **唯一住房绝对豁免** | 被执行人唯一住房一律不得执行。 | **❌ 非绝对豁免。**保留的是"生活必需品/必需费用"（§254/§255但书），在保障基本居住前提下符合条件的唯一住房仍可执行。 |

## 四、 相邻制度对照

### 表1：申请执行期间（2年） vs 诉讼时效（3年）

| 事项 | 申请执行期间（§250） | 诉讼时效（民法典§188） |
|---|---|---|
| 期间长度 | **2年** | 一般 **3年** |
| 性质 | 时效期间（可中止、中断） | 时效期间（可中止、中断） |
| 中止/中断 | **适用诉讼时效的中止、中断规定**（§250明文） | 民法典§194-195 |
| 起算点 | 履行期最后一日／分期最后一期届满／未定期从生效日 | 从知道或应当知道权利受损及义务人之日 |
| 适用阶段 | 生效文书作出**后**、进入执行阶段 | 起诉**前**、实体权利保护阶段 |

> ⚠️ 二者都可中止中断，但期间不同（2年 vs 3年）、适用阶段不同（执行阶段 vs 审判前），命题人爱把"申请执行期间"写成"3年"或"不可中断的除斥期间"。

### 表2：申请执行 vs 移送执行（§247）

| 事项 | 申请执行（常态） | 移送执行（例外） |
|---|---|---|
| 启动主体 | 当事人（权利人）向法院申请 | 审判员依职权移送执行员 |
| 适用范围 | 一切生效给付文书 | **限特定案件**：赡养费、扶养费、抚养费、劳动报酬等 |
| 法理 | 处分原则（当事人自主决定是否执行） | 保护弱势/公益，法院主动推进 |

### 表3：各类执行措施横向对号入座（本模型重点）

| 债权/义务类型 | 对应执行措施 | 条文 | 关键限制/要点 |
|---|---|---|---|
| **金钱债权①存款证券** | 查询→扣押、冻结、划拨、变价 | §253 | 不得超出应履行义务范围；须裁定+协助执行通知书 |
| **金钱债权②收入** | 扣留、提取收入 | §254 | 保留被执行人及所扶养家属"生活必需**费用**" |
| **金钱债权③财产变现** | 查封、扣押、冻结、拍卖、变卖 | §255、§258 | 保留"生活必需**品**"；不动产先查封后拍卖；查封=限制处分（§257） |
| **交付特定物/票证** | 传唤当面交付、转交，被交付人签收 | §260 | 有关单位/公民持有的须协助或强制交出 |
| **迁出房屋/退出土地** | 院长签发公告，逾期强制执行 | §261 | 通知被执行人到场，拒不到场不影响执行 |
| **行为债权（可替代行为）** | 代履行：强制执行或委托他人完成 | §263 | **费用由被执行人承担** |
| **迟延履行·金钱义务** | 加倍支付迟延履行期间债务利息 | §264 I | 仅限金钱给付义务 |
| **迟延履行·非金钱义务** | 支付迟延履行金 | §264 II、解释§505 | 已造成损失双倍补偿，未造成损失法院酌定 |
| **不履行的一般惩戒** | 财产报告令；限制出境/征信/媒体公布 | §252、§266 | 拒报虚报→罚款拘留；配套限高（解释§1097）、失信名单（解释§516） |

> ⚠️ **易混条文**：§254但书是"生活必需**费用**"（扣留提取收入场景），§255但书是"生活必需**品**"（查封拍卖场景）；金钱义务迟延是"加倍**利息**"（§264 I），非金钱义务迟延是"迟延履行**金**"（§264 II）——四组词两两成对，别记串。

## 五、 万能五步答题模型

> 🚗 **统一案例**：甲对乙享有一份**100万元借款的生效判决**（某区法院一审、市中院二审维持，履行期为判决送达后10日内）。乙拒不履行。经查，乙名下有：①银行存款30万元；②一辆汽车（乙与其兄共有）；③一套占用甲交付的商铺（判决同时判乙迁出）；④丙欠乙的到期货款40万元。甲拟申请强制执行。全程用这个案例贯穿五步。

### 第一步：判执行依据——这份文书"凭什么"能执行？

> **给付才有执行力，确认形成不能执**

#### 概述

强制执行的前提是有一份**具有给付内容且已生效**的法律文书。可作执行依据的典型是：给付判决/裁定、给付调解书（§245调解书执行适用执行编）、支付令、仲裁裁决（§248）、公证机关赋强的债权文书（§249）。反面则是**确认之诉、形成之诉的判决**——它们只"确认既存法律关系"或"变动法律关系"，本身不含"命令谁给付什么"的内容，无从执行。

#### 大白话讲解

甲手里这份判决写的是"乙向甲偿还100万元、限期迁出商铺"——**白纸黑字有'给谁、给什么、干什么'的给付命令**，这就是标准的执行依据，能直接拿去申请执行。

反过来假设：如果法院判的是"确认甲乙之间的借款合同有效"（确认之诉），或者"撤销甲乙之间的赠与合同"（形成之诉），这两种判决**只是给法律关系'定性/变形'，没说'谁该给谁钱'**，甲拿着它去执行局，执行法官会说"这份判决没有给付内容，执行不了，你要拿钱得另外起诉一个给付之诉"。

| 文书类型 | 能否直接执行 | 理由 |
|---|---|---|
| 给付判决（还钱/交物/迁出） | ✅ 能 | 有给付命令 |
| 给付调解书（§245） | ✅ 能 | 含给付内容，适用执行编 |
| 仲裁裁决（§248）/公证债权文书（§249） | ✅ 能 | 法定其他执行依据 |
| 确认之诉判决（确认合同有效/所有权） | ❌ 不能 | 只确认，不给付 |
| 形成之诉判决（撤销/解除/离婚） | ❌ 不能 | 只变动关系，不给付（分割给付部分另计） |

本案甲的判决含"还100万+迁出"的给付内容，**是合格的执行依据**。

#### 一句话闭环记忆

> 🎯 **一眼判**：执行力认"给付内容"——给付判决/调解书/支付令/仲裁裁决/公证债权文书才能执行；确认之诉、形成之诉的判决自身不给付，执行不了。

---

### 第二步：判管辖与期间——找哪个法院、多久内申请？

> **法院裁判找一审或财产地，二审只管审不管执；两年期间可中止中断**

#### 概述

- **管辖两轨（§235，均为"二选一"）**：
  - 法院自己作出的裁判（判决、裁定、刑事财产部分）→ **第一审法院** 或 **与其同级的被执行财产所在地法院**；
  - 其他法律文书（仲裁裁决、公证债权文书等）→ **被执行人住所地** 或 **被执行财产所在地法院**。
  - ★关键：**执行找第一审法院，不找二审法院**——二审中院只作终审裁判，执行仍回一审法院。
- **申请执行期间（§250）**：2年，**适用诉讼时效的中止、中断规定**（是可中止中断的时效，不是除斥期间）；起算三段——履行期最后一日／分期最后一期届满日／未定履行期从生效日。
- **6个月救济（§237）**：法院收到申请执行书超6个月未执行，申请执行人可向上一级法院申请执行。

#### 大白话讲解

甲的判决是**某区法院一审、市中院二审维持**。甲要申请执行，该找谁？

很多人第一反应"二审是终审，找市中院呗"——**错！执行要回到一审的某区法院**（或与该区法院同级的、乙财产所在地的基层法院）。二审中院只负责"把官司审到终审"，判决生效后的执行是一审法院的活儿（§235）。

再看**期限**：判决送达后10日是履行期，履行期最后一日一过，2年的申请执行期间就开始跑。这2年**跟诉讼时效一样能中止、中断**——比如甲在这2年里向乙催告、或申请过一次执行，时效就中断重新起算。所以别被"过了2年就永远执行不了"的说法唬住，只要中间有中断事由，期间就顺延。

万一甲申请执行后，区法院**拖了6个多月不动手**，甲可以直接**向市中院（上一级）申请执行**，市中院可以责令区法院限期执行、或自己执行、或指令别的法院执行（§237）。

#### 一句话闭环记忆

> 🎯 **一眼判**：法院裁判→一审法院或同级财产地（**执行不找二审中院**）；其他文书→被执行人住所地或财产地，都是二选一；申请执行期间2年、可中止中断（同诉讼时效）；法院超6个月不执行可请上级法院执行。

### 第三步：判执行启动——申请执行还是移送执行？

> **常态靠当事人申请，特定案件审判员移送；执行通知后可立即动手**

#### 概述

执行程序的启动有两条路（§247）：
- **申请执行**（常态）：对方拒不履行，由**当事人**向法院申请强制执行；
- **移送执行**（例外）：由**审判员移送执行员**执行，**仅限**赡养费、扶养费、抚养费、劳动报酬等具有特殊保护必要的案件。

启动后，**执行员发出执行通知，并可以立即采取强制执行措施**（§251）——注意"立即"，不必等执行通知期满才能查冻。

#### 大白话讲解

本案甲乙是普通借款纠纷，乙拒不还钱，**由甲自己去法院申请执行**（申请执行，常态路径）。

那什么时候是"移送执行"？换个场景：如果这是一起**赡养费案件**，判决儿子每月付父亲赡养费，儿子不给——考虑到父亲是弱势、赡养费关乎生存，**审判员可以直接把案子移送给执行员执行**，不必非等老人自己去申请。但移送执行是"特权通道"，只给赡养费、扶养费、抚养费、劳动报酬这类案件，普通商事债务不适用。

甲申请执行后，执行员向乙发出执行通知（"限你X日内还钱"），但**不必干等这个期限**——执行员**当场就可以查询、冻结乙的银行存款**（§251"可以立即采取强制执行措施"），防止乙转移财产。

#### 一句话闭环记忆

> 🎯 **一眼判**：普通案件当事人**申请执行**；赡养费/扶养费/抚养费/劳动报酬等特定案件审判员可**移送执行**；执行通知发出后可**立即**采取强制措施（不必等期满）。

---

### 第四步：判执行措施——对什么财产用什么招？

> **金钱债权查冻划扣提，交付迁出代履行，对号入座别用错**

#### 概述

执行措施按"要实现的债权/义务类型"对号入座：
- **金钱债权**：①查询存款证券基金→扣押冻结划拨变价（§253）；②扣留提取收入（§254，留"生活必需费用"）；③查封扣押冻结拍卖变卖（§255，留"生活必需品"）。核心记忆：**查、冻、划、扣、提**，均不得超出应履行义务范围；**不动产先查封后拍卖**，查封=限制处分（§257），被执行人只能保管不能擅自处置。
- **交付物/票证**：传唤当面交付或转交（§260）。
- **迁出房屋/退出土地**：院长签发公告，逾期强制执行（§261）。
- **行为债权**：**代履行**——法院强制执行或委托他人完成，**费用由被执行人承担**（§263）。

#### 大白话讲解

甲的100万判决要落地，执行员针对乙的不同财产分别出招：

- **乙的30万存款**→ 执行员**查询→冻结→划拨**（§253），直接从乙的账户划30万给甲；
- **乙的汽车（与兄共有）**→ 可以**查封、扣押**这辆共有车（就乙那份份额），但因为**还没析产、乙的具体份额没确定，不能直接把整辆车拍卖**——甲得先提析产诉讼析出乙的份额，再就份额处置（详见第286、287题）；
- **乙占着的商铺（判决判乙迁出）**→ 属**迁出房屋**，院长签发公告责令乙限期迁出，乙逾期就由执行员**强制迁出**（§261）；如果乙拒不迁出，还要**支付迟延履行金**（非金钱义务，§264 II，见第五步与第299题）；
- **丙欠乙的40万到期货款**→ 属**代位执行到期债权**：法院向丙发履行通知，丙不得再向乙清偿；丙15日内一提异议（口头也算）法院即不得对丙强制执行、且不作实质审查；丙不异议又不还才能强制执行丙的财产（第266题）；但若这40万债权已被**生效裁决确定**，丙就不能再喊"太高/管辖不对"实质异议了（第297题）。

**关键提醒（查封=锁死处分权）**：乙名下若有房产被查封，乙**只能作为保管人看着**（§257），**不能偷偷卖掉或抵押**——擅自处分不能对抗执行。而且房产执行必须**先查封、后拍卖**（先§255查封，再§258拍卖），顺序不能颠倒。

#### 一句话闭环记忆

> 🎯 **一眼判**：金钱债权走"查询→扣押冻结划拨变价（§253）／扣留提取收入（§254）／查封拍卖变卖（§255）"，留生活必需费用/必需品；交付走§260、迁出走§261、行为债权代履行费用债务人担（§263）；查封锁死处分权，不动产先查封后拍卖。

### 第五步：判保障与惩戒——怎么逼被执行人履行？

> **财产报告令＋迟延履行金/加倍利息＋限出境征信失信名单**

#### 概述

被执行人"没钱/装没钱/拖着不履行"时，法律给了三道保障与惩戒：
- **财产报告令（§252）**：被执行人须报告当前及收到执行通知前一年的财产情况；拒报、虚报→**罚款、拘留**。
- **迟延履行责任（§264）**：金钱义务未按期→**加倍支付迟延履行期间债务利息**（I款）；非金钱义务未按期→**支付迟延履行金**（II款；民诉解释§505：已造成损失双倍补偿，未造成损失法院酌定）。
- **信用惩戒（§266）**：**限制出境 + 征信系统记录 + 媒体公布**不履行信息；配套还有**限制高消费令**（民诉解释§1097）、**失信被执行人名单**（民诉解释§516）。

#### 大白话讲解

乙一直装穷、拖着不还这100万，法院层层加码：

- **先下财产报告令**：责令乙如实报告"现在有什么财产、收到执行通知前一年有什么财产"。乙要是**拒绝报告或报假账**，法院可以直接**罚款、甚至拘留**乙（§252）——这一招专治"我什么都没有"的耍赖。
- **算迟延履行责任**：这100万是**金钱债务**，乙拖着不还，就要**在原本欠款之外，加倍支付迟延履行期间的债务利息**（§264 I）——欠得越久、罚得越多。而那套**商铺的"迁出"义务是非金钱义务**，乙拖着不搬，则要**支付迟延履行金**（§264 II；如果给甲造成了损失，按损失双倍补偿——见第299题），注意**这里不能套用"加倍利息"，加倍利息是金钱债务专用**。
- **上信用惩戒**：法院可以**限制乙出境**（不让他跑路避债）、把乙的失信信息**记入征信系统、通过媒体公布**（§266）；还能对乙下**限制高消费令**（不许坐飞机高铁一等座、住星级酒店，民诉解释§1097）、把乙**纳入失信被执行人名单**（民诉解释§516）。多管齐下，逼乙履行。

#### 一句话闭环记忆

> 🎯 **一眼判**：财产报告令（§252，拒报虚报→罚款拘留）＋迟延履行责任（金钱义务加倍利息§264 I／非金钱义务迟延履行金§264 II）＋信用惩戒（限出境+征信+媒体公布§266，配套限高§1097、失信名单§516）。

## 六、 易混考点辨析

- **执行管辖 vs 二审法院**：生效判决执行找**第一审法院**或同级财产所在地法院（§235），**不找二审中院**——二审只作终审裁判。（第126题、第220题）
- **给付之诉判决 vs 确认/形成之诉判决**：只有**给付判决**有执行力；确认之诉（确认合同有效/所有权）、形成之诉（撤销/解除/离婚）判决自身不含给付，不能直接执行。（第353题）
- **申请执行期间 vs 诉讼时效**：申请执行期间**2年**（§250）、诉讼时效一般**3年**（民法典§188），**都可中止中断**，但期间与适用阶段不同。
- **加倍利息（§264 I）vs 迟延履行金（§264 II）**：加倍利息专属**金钱**给付义务；迟延履行金对应**非金钱**义务（迁出、交付、行为），二者不可混用。（第299题）
- **生活必需费用（§254）vs 生活必需品（§255）**：前者是"扣留提取收入"时保留的现金费用，后者是"查封拍卖财产"时保留的实物用品——两个不同条文的但书。
- **申请执行 vs 移送执行（§247）**：常态是当事人申请；移送执行仅限赡养费/扶养费/抚养费/劳动报酬等特定案件由审判员移送。
- **查封的保管 vs 处分**：查封后被执行人可**保管**（§257），但**不得擅自处分**——保管≠处分自由。（第355题）
- **代位执行（执行程序）vs 代位权诉讼（实体）**：代位执行是执行中向次债务人发履行通知（次债务人一异议即不得执行、不实质审查，第266题）；代位权诉讼是实体法上以自己名义起诉（详见 [[民法-合同-代位权模型]]）。

## 七、 命题人最爱的 7 个陷阱

1. **"生效判决一律由一审法院执行 / 仲裁裁决一律由被执行人住所地中院执行"** —— 错！均是"二选一"：法院裁判由一审法院**或**同级财产地，其他文书由被执行人住所地**或**财产地（§235）。见"一律"必疑。
2. **"二审维持原判后，向二审中院申请执行"** —— 错！执行回**第一审法院**，二审中院只管终审裁判（§235）。
3. **"确认合同有效的判决、离婚判决可直接申请强制执行"** —— 错！确认之诉、形成之诉判决无给付内容，不能直接执行（§245执行以给付内容为前提）。
4. **"申请执行期间2年是不变的除斥期间，不中止不中断"** —— 错！§250明定"适用诉讼时效中止、中断规定"，是可中止中断的时效。
5. **"拒不迁出房屋，应加倍支付以损失为基数的同期银行利息"** —— 错！加倍利息仅限**金钱义务**（§264 I）；非金钱义务是**迟延履行金**（§264 II、解释§505）。
6. **"查封后被执行人可自行处置查封财产"** —— 错！查封=限制处分，被执行人只能保管（§257），擅自处分不得对抗执行；不动产先查封后拍卖。
7. **"被执行人唯一住房一律不得执行"** —— 错！保留的是"生活必需品/必需费用"（§254/§255但书），非绝对豁免唯一住房，保障基本居住前提下符合条件的仍可执行。
