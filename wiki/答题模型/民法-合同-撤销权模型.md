# 📐 撤销权 · 完整答题模型（入库突破 + 70%低价/130%高价双标准 + 行为类型扩展）

> **核心一句**：债权人撤销权是债权人请求法院**撤销债务人危害债权的行为**的**保全**制度。考试核心在于**"对象限制 → 无偿/有偿二分 → 70%/130%量化红线 → 除斥期间 → 撤销效果"**这条主线；最毒陷阱是**把身份行为/放弃将得利益也当成可撤销对象**、**把"无偿不问知情"套到"有偿"上（或反之）**、**记混70%/130%红线的方向**、**把撤销权和恶意串通无效混为一谈**、**把除斥期间的1年/5年记反**。
>
> 🔎 **《民法典》核心条文速查**：
> - **第538条【无偿处分的撤销】**：债务人以**放弃其债权、放弃债权担保、无偿转让财产**等方式**无偿处分**财产权益，或者**恶意延长**其到期债权的履行期限，**影响债权人的债权实现**的，债权人可以请求法院**撤销**债务人的行为。
> - **第539条【有偿处分的撤销】**：债务人以**明显不合理的低价转让财产**、以**明显不合理的高价受让**他人财产或者**为他人的债务提供担保**，**影响债权人的债权实现**，**债务人的相对人知道或者应当知道**该情形的，债权人可以请求法院撤销债务人的行为。
> - **第540条【必要费用】**：债权人行使撤销权的必要费用应由**债务人负担**。
> - **第541条【除斥期间】**：撤销权自债权人**知道或应当知道**撤销事由之日起**一年**内行使。自债务人的行为**发生之日**起**五年**内没有行使撤销权的，撤销权**消灭**。
> - **第542条【撤销的效果】**：债务人影响债权人的债权实现的行为被撤销的，**自始没有法律约束力**。
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号，2023年12月4日发布、12月5日施行）**：第42条明确**明显不合理低价/高价的量化认定标准（70%/130%）及关联关系例外**；第43条对§539作**目的性扩张**，将**互易财产、以物抵债、出租或承租财产、知识产权许可使用**等行为纳入可撤销范围；第46条创设**撤销权行使后的直接执行路径**（相对人向债务人承担责任+撤销权诉讼可一并审理债权人与债务人间的债权债务关系+法院可对相对人财产强制执行以实现债权人的债权）。

> ⚠️ **诚实标注（条号核验说明）**：本模型对§538-542（民法典本体）、通则解释§42（低价/高价量化标准）、§43（行为类型扩张）、§46（直接执行）均已通过网络信源交叉核实，内容一致、可信度高。§42中"关联关系/亲属关系不受70%/130%比例限制"这一细化规则同样有信源支持，已纳入模型；本库既往关联真题卡尚未有题目实测这一细化点，模型如实标注为"规则本身已核验、真题实测暂缺"。

> ⚠️ **易记错点**：①**身份行为（收养、离婚财产分割、放弃继承）不可撤销**——撤销权对象仅限**财产行为**；②**放弃"将得利益"（如拒绝接受赠与、放弃继承）也不可撤销**——这类利益**尚未成为债务人的既有财产**，撤销权只打"减少既有责任财产"的行为；③**无偿处分（§538）不问相对人是否知情**，哪怕相对人是善意的也可撤销；**有偿处分（§539）必须证明相对人"知道或应当知道"**，缺这一点不能撤销；④**70%/130%不是"70%以下才算低、70%-130%之间都正常、130%以上才算高"这种简单区间理解**，而是**未达70%即明显低价、超过130%即明显高价**，两条线各自独立判断；⑤**撤销权 ≠ 无效**：撤销权（§538/§539，形成权、须债权人在除斥期内诉请）与恶意串通无效（§154，自始当然无效、任何人可主张）是**性质不同、可以并存的两条路径**，命题人常在同一案情下让两个选项分别站这两条路径，不冲突；⑥**撤销权行使范围以债权人的债权为限**，不是撤销全部交易金额；⑦**撤销后债权人不能直接取得标的物的所有权**，只是使该处分行为"自始无效"、恢复债务人的责任财产状态，债权人仍须通过强制执行程序受偿（通则解释§46提供了更便捷的"一并审理+直接执行"路径，但性质仍是**责任财产的恢复**，不是**债权人直接取得物权**）。

## 二、 五步判别模型（对象 → 二分 → 红线 → 期间 → 效果）

```
                【债务人乙实施了某项行为，债权人甲认为该行为危害了自己的到期债权】
                                    │
     ▼ 第一关：是否属于撤销权的对象？
     │
     ├─ 身份行为（收养/离婚财产分割/放弃继承）──→ 不属于，不可撤销
     ├─ 放弃"将得利益"（拒绝接受赠与/放弃继承——财产尚未到手）──→ 不属于，不可撤销
     └─ 处分既有财产的财产行为 ──→ 进入第二关
                                                       │
     ▼ 第二关：是无偿处分还是有偿处分？
     │
     ├─ 无偿处分（§538）：放弃债权/放弃债权担保/无偿转让财产/恶意延长到期债权履行期
     │     → 不问相对人是否知情，只要影响债权人到期债权实现，即可撤销
     └─ 有偿处分（§539）：明显不合理低价转让/明显不合理高价受让/为他人债务提供担保
           → 须"价格明显不合理"+"相对人知道或应当知道"双要件同时满足
                                                       │
     ▼ 第三关：（有偿处分时）价格是否触及量化红线？（通则解释§42）
     │
     ├─ 转让价未达市场交易价70% ──→ 一般认定"明显不合理低价"
     ├─ 受让价高于市场交易价130%（超出30%）──→ 一般认定"明显不合理高价"
     └─ 债务人与相对人存在关联关系/亲属关系等 ──→ 不受70%/130%比例限制
                                                       │
     ▼ 第四关：行为类型是否落入扩张范围？（通则解释§43）
     │
     └─ 不限于"转让财产"，还包括：互易财产、以物抵债、出租或承租财产、知识产权许可使用
        （存在明显不合理价格的，同样可撤销）
                                                       │
     ▼ 第五关：是否在除斥期间内行使？（§541）
     │
     ├─ 自债权人知道/应当知道撤销事由之日起1年内 ──→ 除斥期间
     └─ 自债务人行为发生之日起5年内未行使 ──→ 撤销权消灭（最长保护期）
                                                       │
     ▼ 撤销权成立后如何处理？（§540/§542 + 通则解释§46）
     │
     ├─ 该行为自始没有法律约束力（§542）
     ├─ 必要费用由债务人负担（§540）
     ├─ 撤销范围以债权人的债权为限
     └─ 相对人应向债务人（非直接向撤销权人）承担责任；债权人可请求在撤销权诉讼中
        一并审理其与债务人间的债权债务关系；法院可对相对人财产强制执行以实现债权人的债权
        （通则解释§46，不必等撤销后另诉执行）
```

> **一句话总诀**：**「先过对象关（身份行为、将得利益排除）；再看无偿有偿（无偿不问知情、有偿必问知情）；有偿再卡70%/130%红线（关联关系不受此限）；行为类型不限转让（互易/以物抵债/租赁/知产许可都算）；1年知道起、5年行为起，除斥期间不能中断中止；撤销自始无效、费用债务人担、范围以债权为限、可一并审理直接执行」**

## 三、 两个高频干扰（撤销权 vs 无效 / 撤销 vs 直接取得）

命题人极喜欢在"撤销权和无效能不能并存"以及"撤销后债权人能不能直接拿东西"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **撤销与无效非此即彼** | 债务人资不抵债时把全部财产偏向性抵押给一个债权人，这只能走恶意串通无效，不能同时主张撤销。 | **❌ 说法错误！撤销权（§538/§539）与恶意串通无效（§154）是否定同一行为的两条平行路径，可以并存。**无效是自始当然无效（任何人可主张、不受除斥期间限制）；撤销权是形成权（须债权人在除斥期内诉请）。若既能证明"恶意串通损害第三人"又符合撤销权要件，两条路径**都可以选择主张**。 |
| **撤销后债权人直接取得标的物** | 债务人以明显不合理低价把房屋卖给他人，债权人撤销该买卖合同后，有权直接取得该房屋的所有权抵债。 | **❌ 说法错误！撤销权人不能直接取得标的物所有权。**撤销的效果是使该处分行为**自始无效**、**恢复**债务人的责任财产状态，债权人仍是**普通金钱债权人**，须通过强制执行程序就该财产变价受偿——通则解释§46只是提供了"一并审理+直接执行"的便捷路径，性质上仍是**责任财产的恢复与执行**，不是债权人直接取得物权。 |

## 四、 与代位权的对照（保全双子星，勿混同法条号）

撤销权（§538-542）与代位权（§535-537）同属"保全"制度，命题人常混用条号：

| 事项 | 撤销权 | 代位权 |
|---|---|---|
| 针对的行为 | 债务人**积极处分**财产的行为（作为） | 债务人**怠于行使**权利（不作为） |
| 是否要求债权到期 | 不要求到期 | 原则要求到期（§535），例外见§536代位保存权 |
| 行使方式 | 请求法院**撤销**该行为 | 以**自己名义**代位**行使**权利 |
| 期间限制 | **除斥期间**：1年（知道起）+5年（行为发生起） | 无独立除斥期间，受诉讼时效一般规则约束 |
| 必要费用 | 由**债务人**负担（**§540**） | 由**债务人**负担（**§535 III**） |
| 受偿/救济效果 | 恢复债务人的责任财产（非直接受偿），通则解释§46可一并审理直接执行 | **直接受偿**（§537，相对人直接向代位债权人履行） |

> ⚠️ **易混条号**：撤销权必要费用是**§540**，代位权必要费用是**§535 III**，不可互换；撤销权除斥期间是**§541**，不要与代位权任何条文混同。

## 五、 万能五步答题模型

在法考答题中（无论客观题选项判断，还是主观题第一步定性与第二步效力分析），按照以下五步进行涵摄：

*   🚗 **统一案例**：甲对乙享有100万元到期债权。乙名下一套价值120万元的房屋，以90万元的价格出卖给知情的丙（丙明知乙拖欠甲的债务）。同时，乙还与丁签订了《离婚协议书》，将其婚前另一套住房无偿赠与丁，办理了变更登记。甲得知后诉请撤销乙与丙、乙与丁的两项行为。

### 第一步：判对象——是不是可撤销的财产行为？

> **身份将得皆排除，既有财产才够格**

#### 概述

撤销权只能对付**处分既有财产的财产行为**，两类行为一律排除在撤销权大门之外：

- **身份行为**——收养、离婚协议中的身份/财产分割本身（作为整体的婚姻家庭安排）、放弃继承权；
	- 财产分割看两点：是否公平、是不是债务人自有财产全部白送他人，满足恶意转移就可撤销财产条款。**身部分永远不能撤销；财产部分看性质，分两种情形**

		1. 身份配套分割（不可撤销）
		    
		    正常离婚分割夫妻共同财产，是婚姻身份解除附带的常规财产安排，属于身份绑定行为，债权人无权撤销。
		    
		    例：夫妻婚后一套房，离婚一人一半，正常均分，不是恶意逃债，不可撤。
		    
		2. 恶意无偿处分自有财产（可撤销）
		    
		    债务人把自己婚前个人财产、本该分到的共同财产全部无偿给配偶，自己净身出户，故意掏空还债资产，属于《民法典》538 条可撤销行为。
		    
		    例：男方欠外债，婚前全款房产登记自己名下，离婚直接约定全部归女方，自己一无所有，明显逃债，该财产条款能撤销。

- **放弃将得利益**——拒绝接受赠与、放弃继承——这类"利益"根本**没有成为**债务人的既有财产，谈不上"处分"。

一句话：撤销权保护的是"债务人**已经拥有、正在被搬空**的责任财产"，不是"债务人**本可以多拥有一点、但选择不要**的将来利益"。

#### 大白话讲解

老赵借给老钱100万元，早就到期了。老钱最近手头很紧，老赵越查越发现老钱这段时间干了不少"甩包袱"的事：

- 老钱的**父亲去世**，老钱**放弃了对父亲遗产的继承权**——老赵想："老钱这是把到手的钱往外推，我能不能撤销他这个'放弃继承'？"法院说：**不能**。继承权是老钱**"将得"而非"已得"**的利益，遗产还没实际分到老钱名下，老钱放弃的是"可能到手的钱"，不是"已经在他口袋里的钱"，这不叫"处分既有财产"，撤销权管不着。

- 老钱最近还**收养了一个孩子**——这是**身份行为**，跟财产分配毫无关系，老赵更不能拿这个说事。

- 老钱和妻子离婚，在《离婚协议书》里，老钱把**婚前个人名下的一套住房**无偿给了妻子的娘家侄女小周——这一步，虽然裹着"离婚协议"这层身份行为的外壳，但**处分的是老钱婚前个人所有的既有财产**，本质上是一次不折不扣的**无偿财产处分**，**属于**撤销权可以打击的对象。

同一份《离婚协议书》里，命题人常常把"身份性的财产分割安排"和"打着离婚幌子的无偿处分个人财产"揉在一起，做题时要学会拆解：**分割的是不是夫妻共有财产、体现的是不是身份性质的整体安排**——如果是，往"身份行为"那边靠；**处分的是不是一方的婚前个人财产、明显是"甩锅"性质的无偿赠与**——如果是，就是一次实打实的可撤销财产行为。

#### 一句话闭环记忆

> 🎯 **一眼判**：身份行为（收养、身份性财产安排）、放弃将得利益（拒绝受赠、放弃继承）——两类一律不可撤销；只有**处分既有财产**的财产行为，才进入下一步的无偿/有偿判断。

---

### 第二步：判无偿/有偿——是否需要审查相对人知情？

> **无偿不问知情，有偿必问知情**

#### 概述

撤销权把债务人的处分行为分成两大类，审查力度完全不同：

- **无偿处分（§538）**：放弃债权、放弃债权担保、无偿转让财产、恶意延长到期债权履行期——**根本不问**接手的那个人是好人还是坏人，是不是知情，**只要影响了债权人的到期债权实现**，就可以撤销。
- **有偿处分（§539）**：明显不合理低价转让、明显不合理高价受让、为他人债务提供担保——这一类**必须**同时满足两个条件：①价格**明显不合理**；②相对人**知道或者应当知道**这一情形（也就是相对人"没安好心"、跟债务人"一个鼻孔出气"）。

这个区分背后的道理很朴素：**天上掉馅饼，你不能怪捡馅饼的人**——无偿受益人反正没花一分钱，法律优先保护债权人，不追究受益人是否知情；但**花钱买东西的人**，如果价钱正常、他也不知道卖家在逃债，那是一次正常交易，不能因为卖家后来还不起债，就让买家白白吐出东西来。

#### 大白话讲解

老赵接着查：老钱把婚前住房**无偿**送给了小周（对方明确知情老钱欠着老赵的钱），这属于**§538无偿处分**——法官压根不问小周是不是"善意"、知不知道老钱欠债，**只要这笔赠与影响了老赵100万元债权的实现，直接就可以撤销**，小周即便毫不知情，一样得把房子吐出来（这一点在下一个案例里会看得更清楚）。

再看另一笔：老钱名下市值120万元的一套商铺，以**90万元**的价格卖给了**知道老钱欠债的老孙**。这不是白送的，是**有偿**处分，得走**§539**这一套**双重考验**：

1. **价格够不够"离谱"**？——90万元跟市场价120万元相比，打了多少折？这是下一步（第三步）要精确计算的。
2. **老孙知不知情**？——题干已经交代老孙"知情"，这一条件先记在心里，等第三步价格红线一起判断，两个条件都满足才能撤销，缺一个都不行。

**一张表把"无偿 vs 有偿"焊死**：

| 类型 | 典型行为 | 是否审查相对人知情 | 法条 |
|---|---|---|---|
| 无偿处分 | 放弃债权、放弃债权担保、无偿转让财产、恶意延长履行期 | **不问**（哪怕相对人是善意的，照样可撤销） | §538 |
| 有偿处分 | 明显不合理低价转让、明显不合理高价受让、为他人债务提供担保 | **必问**（须"知道或应当知道"，缺此要件不能撤销） | §539 |

#### 一句话闭环记忆

> 🎯 **一眼判**：**无偿**处分（白送的），**不问**相对人是否知情，只要影响债权实现就能撤；**有偿**处分（花钱买的），必须**同时**满足"价格明显不合理"+"相对人知道或应当知道"两个条件，缺一不可。

---

### 第三步：判价格红线——是否触及70%/130%？（有偿处分时）

> **未达七成低价，超过三成高价，关联交易不受限**

#### 概述

"明显不合理"不是法官凭感觉拍脑袋，通则解释§42给出了**量化红线**：

- 转让价**未达**市场交易价（或指导价）**70%**的，一般认定为"明显不合理低价"；
- 受让价**高于**市场交易价（或指导价）**130%**（也就是超出30%）的，一般认定为"明显不合理高价"；
- **但**——如果债务人和相对人之间存在**关联关系、亲属关系**等特殊情形，**不受**这两条比例的限制，法院可以结合其他证据综合认定（因为亲戚朋友之间打个"友情价"，很可能本身就是在配合逃债，不能用一般市场交易的宽容标准去套）。

这条红线是一条**纯计算题**，法考最爱在这里出"算错一个百分点、答案就反了"的送分兼送坑题。

#### 大白话讲解

老赵拿计算器算了一下：老孙买老钱的商铺，市值120万元，成交价90万元。

**90 ÷ 120 = 75%**

75%比70%这条红线**要高**（75% > 70%），也就是说，这笔交易的成交价**没有跌破**"明显不合理低价"的红线——虽然90万元听起来是"打折卖"，但从量化标准看，它**还没低到"明显不合理"的程度**。

老赵一开始很不服气："我不管，反正老孙知情，这就该撤！"——但法律的逻辑是：**价格要件和知情要件必须同时满足**，老孙"知情"这一条件是满足了，但**价格没有触线**，§539的两个条件只满足了一半，**这笔90万元的商铍买卖，撤不了**。

（旁注：如果老钱和老孙之间是**表兄弟**关系，那就另当别论——存在**关联关系/亲属关系**的，**不受70%这道比例红线的限制**，法官会结合双方关系、交易背景等其他证据综合判断是否"明显不合理"，哪怕账面上是75%这种"看起来不算太离谱"的价格，也可能被认定为暗中利益输送、依然可以撤销。）

**再补一道对照题，加深红线记忆**：如果同样的商铺，老钱只卖了**80万元**（80÷120≈66.7%），跌破70%红线，构成"明显不合理低价"，只要老孙同时"知情"，**这次就能撤销**了。

#### 一句话闭环记忆

> 🎯 **一眼判**：**转让价 < 市场价70%** → 明显低价；**受让价 > 市场价130%** → 明显高价；两条红线各自独立判断，别把"70%-130%之间都算合理"这种区间理解代入——只要没跌破70%这条线，即使打折出售，一般仍不算"明显不合理"；存在**关联关系/亲属关系**的，不受这两条比例限制。

---

### 第四步：判行为类型——是否落入扩张范围？（通则解释§43）

> **转让之外还四类：互易抵债租赁许可**

#### 概述

§539原文只写了"转让财产""受让财产""提供担保"三种行为，但通则解释§43做了**目的性扩张**——只要是"用不合理的价格进行财产性安排、危害了债权人的债权"，不管披着什么样的合同外衣，都可以被撤销权盯上：

- **互易财产**（拿东西换东西，而不是拿钱买）；
- **以物抵债**（用实物抵偿到期债务，实物明显不值那么多钱）；
- **出租或承租财产**（租金明显偏离市场价）；
- **知识产权许可使用**（许可费明显偏离市场价）。

扩张的逻辑很简单：**债务人想"金蝉脱壳"的手段五花八门，法律不能只认"卖房子"这一种套路**。

#### 大白话讲解

假设剧情往下发展：老钱不甘心，又想到了新招——老钱还欠着老孙120万元到期债务，老钱干脆跟老孙签了一份**《以物抵债协议》**，用一辆**市值只有30万元**的货车，去**抵偿全部120万元**的债务。老孙对老钱资不抵债的情况**心知肚明**。

老赵这次要不要慌？**不用**——虽然这次的行为形式不是"转让财产"，而是"**以物抵债**"，但通则解释§43早就把"以物抵债"这类行为**纳入了撤销权的打击范围**。用30万元的货车抵偿120万元的债务，折算下来相当于用**25%**的价格"清偿"了这笔债务，远远低于70%的红线，属于"明显不合理"，只要老孙知情，老赵**照样可以**依§539+§43请求法院撤销这份以物抵债协议。

再举一反三：如果老钱不是"以物抵债"，而是拿自己一台值10万元的设备，去跟别人**互易**一台市价只值2万元的破机器（互易，即"以物易物"，没有金钱对价但同样存在明显不对等）——同样落入扩张范围；如果老钱把自己名下一套商铺，以远低于市场行情的租金**出租**给亲戚——同样可以被审查；如果老钱把自己享有的一项**专利许可使用权**，以明显偏低的许可费授权给别人使用——同样在扩张范围内。

**一张表把扩张的四类行为记牢**：

| 扩张行为类型 | 判断要点 |
|---|---|
| 互易财产 | 以物易物，交换的财产价值明显不对等 |
| 以物抵债 | 用实物抵偿债务，实物价值明显低于债务数额 |
| 出租或承租财产 | 租金明显偏离市场价 |
| 知识产权许可使用 | 许可费明显偏离市场价 |

本案中，老钱把住房无偿赠与小周（第一步、第二步已经解决），老钱把商铺以90万元卖给老孙（第三步已经解决，未破红线不能撤）——本案原始设定中**没有**互易、以物抵债等场景，此步骤在本案不需要额外适用；但只要案情换成"以物抵债"或"互易"，思路完全一样，照样代入"是否明显不合理+相对人是否知情"这套逻辑判断。

#### 一句话闭环记忆

> 🎯 **一眼判**：撤销权对象**不限于"转让财产"**，互易、以物抵债、出租/承租财产、知识产权许可使用，只要价格**明显不合理**，同样可以被撤销——命题人换个"马甲"（协议名称），底层判断逻辑不变。

---

### 第五步：判除斥期间与撤销效果

> **一年起知道，五年起行为，撤销自始无约束**

#### 概述

即使撤销权成立，也不能"想什么时候撤就什么时候撤"——法律给了两道**除斥期间**的"保质期"：

- **1年**：自债权人**知道或应当知道**撤销事由之日起算——这是相对期间，一旦超过，撤销权就没了；
- **5年**：自债务人的行为**发生之日**起算——这是绝对的"兜底大限"，哪怕债权人一直不知道，5年一过，撤销权照样消灭。

撤销权成立后，效果也不是"债权人直接拿走东西"，而是：

- 该行为**自始没有法律约束力**（像从来没发生过一样）；
- 债权人行使撤销权的**必要费用**（律师费等）由**债务人**负担；
- 通则解释§46还给债权人开了一条"快车道"——可以**请求在撤销权诉讼中一并审理**其与债务人之间的债权债务关系，法院还可以直接对相对人持有的相关财产**采取强制执行措施**，不用撤销之后再另外起诉执行一遍。

#### 大白话讲解

**先算期间**：老赵是什么时候"知道"老钱把房子送给小周这件事的？假设老赵是2026年3月发现的，那他必须在**2027年3月之前**把撤销权行使掉（起诉），否则1年的除斥期间一过，这个权利就彻底没了。同时还有一道"总闸"：不管老赵什么时候发现，只要**从老钱把房子过户给小周那天算起满5年**、老赵还没动手，撤销权照样**自动消灭**——这条5年线是给"债权人长期不闻不问"的债务人一个最终的安全边界，不因债权人"一直不知道"而无限期悬空。

> ⚠️ **除斥期间不是诉讼时效**：这1年、5年**不能中断、不能中止**，跟前面代位权模型里"诉讼时效可以中断"完全是两码事，一旦期满，权利直接**消灭**，没有任何补救。

**再看撤销后的效果**：法院最终认定老钱对小周的无偿赠与**可以撤销**（无偿处分，不问小周是否知情，只要影响了老赵的债权实现）。判决生效后：

- 老钱和小周之间那份房屋赠与，**从头到尾**就没有法律效力（自始无约束力），房子重新算回老钱名下的责任财产；
- 老赵为了打这场官司，请律师花的钱，由**老钱（债务人）**承担，不用老赵自己贴钱；
- 老赵还可以**顺带**请求法院在这场撤销权官司里，**一并审理**自己那100万元债权的存在与数额问题，并直接对小周手里（或者已经过户回老钱名下）的这套房产**强制执行**，用来清偿自己的100万元债权——不用先打一场撤销官司，赢了之后再另开一场执行官司，两步并作一步走。

**但要澄清一个常见误解**：老赵能不能"撤销之后直接把房子搬进自己名下住"？**不能**。撤销的效果是把房子**恢复**成老钱的责任财产，老赵仍然只是一个**普通的金钱债权人**，只能通过强制执行程序，把这套房产**变价**（拍卖或变卖）后按自己的债权数额受偿，如果卖了150万元，超出100万元的部分依然要还给老钱，老赵不能"整套房子据为己有"。

回到本案完整结论：乙（老钱）对丁（小周）的无偿赠与**符合§538**，**可以撤销**；乙对丙（老孙）的房屋买卖因**未达70%价格红线**，**不满足§539的价格要件**，**不能**仅凭此撤销。

#### 一句话闭环记忆

> 🎯 **一眼判**：撤销权须在**知道之日起1年内**、且**行为发生之日起5年内**行使，逾期消灭（除斥期间，不能中断中止）；撤销后行为**自始无约束力**，必要费用**债务人**担，可**一并审理+直接执行**，但撤销权人**不能直接取得**标的物所有权，仍须走强制执行变价受偿。

## 六、 易混提示

*   **撤销权 vs 代位权**：
    *   *撤销权*针对债务人**积极处分财产**的行为（作为）；*代位权*针对债务人**消极怠于行使**权利的不作为。二者必要费用条款不同（§540 vs §535 III），除斥期间也只有撤销权独有（§541）。
*   **撤销权 vs 恶意串通无效**：
    *   *撤销权*（§538/§539）是**形成权**，须债权人在**除斥期间**内诉请，效果是**恢复责任财产**；*恶意串通无效*（§154）是**自始当然无效**，任何人均可主张、不受除斥期间限制。二者可以**并存**，不是非此即彼。
*   **诉讼时效 vs 除斥期间**：
    *   撤销权的1年/5年是**除斥期间**，**不能中断、不能中止**，期满权利消灭；诉讼时效（如代位权诉讼引起的时效中断）可以中断、中止、延长。

## 七、 命题人最爱的 5 个陷阱

1.  **"收养、离婚财产分割、放弃继承等身份行为也可以被债权人撤销"** —— 错！撤销权对象仅限**处分既有财产的财产行为**，身份行为、放弃将得利益（如放弃继承）均不属于撤销对象。
2.  **"无偿转让财产也要审查受让人是否知情才能撤销"** —— 错！**无偿处分（§538）不问相对人是否知情**，即便受让人善意，只要影响债权人到期债权实现，照样可以撤销。
3.  **"转让价打八折（80%）也算明显不合理低价"** —— 错！明显不合理低价的量化红线是**未达市场价70%**，80%>70%，不构成明显不合理低价（除非存在关联关系不受比例限制）。
4.  **"债务人资不抵债后把财产恶意抵押给一个债权人，只能主张恶意串通无效，不能主张撤销"** —— 错！**撤销权与恶意串通无效可以并存**，是否定同一行为的两条平行路径。
5.  **"撤销买卖合同后，债权人有权直接取得该标的物的所有权抵债"** —— 错！撤销权人**不能直接取得**标的物所有权，只是恢复债务人的责任财产状态，仍须通过强制执行程序受偿（通则解释§46提供一并审理+直接执行的便捷路径，但性质不变）。

## 八、 真题演练

| 真题卡片 | 涉及考点与解析要领 | 模型定位 |
|---|---|---|
| [[合同通则-单选-19]] | **撤销权对象限制：身份行为与将得利益的双重排除。**<br>乙收养残障儿童（身份行为）、拒绝接受捐赠（放弃将得利益，财产未到手）、放弃继承权（放弃将得利益）均不可撤销，唯乙在离婚协议中放弃对**家庭共有财产**的权利属处分既有财产的行为，**可以撤销**，选C。 | **第一步·对象限制** |
| [[合同通则-单选-20]] | **无偿不问知情 vs 有偿双要件（价格+恶意）。**<br>车某将手表**无偿赠与**不知情的马某（§538，不问知情）**可撤销**（A对）；以8万元（80%，未破70%线）卖给知情马某**不能撤**（B错）；以6万元（60%，破线）卖给**不知情**马某因缺"相对人知情"要件**不能撤**（C错）；抵押给不知情的龚某**不能撤**（D错），选A。 | **第二步·无偿有偿二分 + 第三步·70%红线** |
| [[合同通则-单选-53]] | **以物抵债协议触发撤销权（行为类型扩张的典型场景）+ 与无效/代位权的区分。**（2024金题）<br>甲对丙120万到期债权，以30万货车抵债（30/120=25%，明显低价），丙知情——满足§539，乙有权请求撤销该以物抵债协议（C对）；不是"无效"（D错，撤销≠无效）；不是直接要求丙交付货车（A错）；不是先代位（B错，应先撤销）。 | **第四步·行为类型扩张（以物抵债）+ 撤销与无效/代位权的区分** |
| [[合同通则-单选-54]] | **资不抵债时点是撤销权成立的分水岭+与赠与人任意撤销权（§658）的区分。**（2012-3-15）<br>甲公司对丙、丁的赠与均发生在债务**届期无力清偿之前**，不构成损害债权，不可撤销；对戊学校的捐赠发生在**资不抵债之后**，损害乙公司债权，乙**可以撤销**（C对）；戊学校捐赠属**公益捐赠**，甲公司**无权**依§658任意撤销（D错）。 | **第二步·无偿处分（§538）+ 时点判断** |
| [[合同通则-多选-29]] | **恶意串通无效与撤销权可并存+区分原则+抵押不转移所有权。**（2019金题）<br>甲把全部责任财产偏向性抵押给乙，丙可主张甲乙**恶意串通、抵押合同无效**（§154，B对）；丙也可主张**撤销**该诈害债权的行为（§538/§539，C对）；未登记只影响抵押权（物权）能否设立，**不影响合同效力**（A错）；抵押不转移所有权，房屋汽车所有权仍归甲（D对），选BCD。 | **撤销权与恶意串通无效并存 + 区分原则** |
| [[合同通则-多选-30]] | **必要费用由债务人负担+应追加相对人为被告+行为损害债权的实质要件。**（2017-3-58）<br>甲将婚前房无偿赠与知情的丙（§538），若甲有其他财产足以清偿，**未损害债权**，撤销权不成立、法院应驳回（B对）；乙仅告甲，法院应**追加丙为被告**（C对）；撤销权成立的，甲应承担乙支出的律师代理费等必要费用（D对，§540）；该行为不是"恶意串通无效"而是走撤销权路径（A错），选BCD。 | **第五步·必要费用（§540）+ 撤销权成立要件（损害债权）** |
| [[合同通则-多选-31]] | **70%价格红线的精确计算+撤销后不能直接取得所有权+区分原则。**（2014-3-54，问"错误的"表述）<br>90万卖120万市值房屋，90/120=**75%**，**未破70%线**，不构成明显不合理低价，**不能撤销**（A表述错误）；未过户不影响买卖合同效力（B表述错误，区分原则）；能证明恶意串通则合同**无效**（C表述正确，不选）；谢某**不能**直接取得房屋所有权（D表述错误，只是普通金钱债权人，须走执行程序），选ABD。 | **第三步·70%红线精确计算 + 撤销效果（不能直接取得所有权）** |
