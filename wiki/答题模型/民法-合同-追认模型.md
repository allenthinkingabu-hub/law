# 📐 追认 · 完整答题模型（效力待定的"事后认可"主轴）

> **核心一句**：追认是有权人对**效力待定**行为的**单方事后认可（形成权）**，一经作出即使该行为**自始有效（溯及成立时）**。考试只在三个场景出现——**限制行为能力人（§145）/ 无权代理（§171·§503默示）/〔对照〕无权处分（管物权变动·非合同效力）**；机制永远是**追认 / 拒绝 / 催告30日 / 善意相对人撤销**四件套；最毒陷阱是**把"沉默"当"默示追认"**。
>
> 🔎 **三处核实纠正点（务必内化，勿照抄旧表述）**：
> ① **"自始有效"是通说 / 体系解释结论，非某条逐字明文**。旧《合同法解释二》§11（追认到达即生效、合同自订立时有效）已随《合同法》废止；现行《民法典》无对应逐字条款。正面文本线索仅为 §145 / §171"经追认后有效" + 撤销权指向"被追认前"。表述时标注"通说"，不得伪称"§X 明文规定自始有效"。
> ② **§171 的"催告30日 / 视为拒绝 / 善意相对人撤销"三项同在第二款（§171Ⅱ）**。经核 spp.gov.cn《民法典》原文：§171Ⅰ=未追认不生效；**§171Ⅱ=催告30日 + 未表示视为拒绝追认 + 善意相对人撤销权**；§171Ⅲ=无权代理人对善意相对人的赔偿责任；§171Ⅳ=相对人知道无权代理时按各自过错担责。**凡"催告 / 视为拒绝 / 善意撤销"标 §171Ⅳ 或 §171Ⅲ 的，全部是款号错误，应改为 §171Ⅱ。**（§145Ⅱ 对应限制行为能力人之催告与撤销，标注正确。）
> ③ **无权处分的"追认"不写 §503、不写旧 §51**。§503 是**无权代理**的默示追认；无权处分合同本就有效（§597），权利人追认指向**物权变动 / 处分权补正**，属学理 / 体系解释结论，叠加 §311 善意取得或 §209/§224 物权变动规则。

## 二、追认是什么（形成权 · 事后认可 · 溯及自始有效）

| 维度   | 要点                                                      | 依据 / 提醒                         |
| ---- | ------------------------------------------------------- | ------------------------------- |
| 性质   | **形成权**——权利人单方意思表示即可使效力待定状态确定化，**无需相对人同意**              | 学理通说；适用**到达生效**（§137）           |
| 行使期限 | 形成权适用**除斥 / 失权期间**，**非诉讼时效**；§145Ⅱ / §171Ⅱ 的 30 日即典型除斥期 | 通说                              |
| 相对人  | 追认意思表示**既可向相对人、亦可向行为人（无权代理人）作出**                        | §503 即以"对相对人开始履行 / 受领履行"的事实行为作出 |
| 效果   | 效力待定 → **自始有效**，溯及行为成立时                                 | ⚠️**通说 / 体系解释结论，非逐字明文**（见纠正点①）  |

## 四、机制四要素（追认 / 拒绝 / 催告30日 / 善意相对人撤销）

```
        效力待定（限制行为能力人§145 / 无权代理§171）
                          │
      ┌───────────┬───────┴────────┬──────────────┐
      ▼           ▼                ▼              ▼
  有权人追认    有权人拒绝     相对人催告(30日)   善意相对人撤销
   → 自始有效    → 自始无效    未表示→视为拒绝     → 自始无效
  （通说溯及）  （通说溯及）  （§171Ⅱ / §145Ⅱ） （§171Ⅱ / §145Ⅱ）
```

> ✅ **款号已校正**：§171 的"催告30日、视为拒绝、善意撤销"**三项同在第二款（§171Ⅱ）**；§145 对应"催告与撤销"在 §145Ⅱ。**催告权属任何相对人；撤销权专属善意相对人，且追认后撤销权消灭。**

| 角色        | 权利                          | 依据            |
| --------- | --------------------------- | ------------- |
| 有权人       | **追认**（使有效）/ 拒绝（使无效）        | §145 / §171Ⅰ  |
| 任何相对人     | 追认前可**催告**（30 日，未表示→视为拒绝追认） | §171Ⅱ / §145Ⅱ |
| **善意**相对人 | 追认前**有撤销权**（通知方式），追认后消灭     | §171Ⅱ / §145Ⅱ |

### 🏠 生活实例 · 一个场景跑完四要素（无权代理 §171）

> 老王的表弟**小赵，没经老王同意，擅自以老王的名义**把老王名下一间门面房按市价租给开奶茶店的老陈、签了 3 年租约。小赵**既没有授权书、也没拿老王的房本或任何凭证**，老陈只是听小赵一句"我表哥委托我出租"就签了 —— **无权利外观、纯无权代理 → 合同效力待定**，本人＝老王。

| 要素 | 谁 · 做什么 | 后果 | 依据 |
|---|---|---|---|
| **① 追认** | 老王得知后正好想出租 → **打电话给老陈"这租约我认，按合同来"**（或直接收了第一期租金）| 合同**自始有效**，老王受约束 | §171Ⅰ；收租＝**§503 默示追认**（接受相对人履行）|
| **② 拒绝** | 老王回"我没让小赵租，不认" | 合同对老王**自始不生效**，改由小赵对老陈担责 | §171Ⅰ（行为人担责 §171Ⅲ）|
| **③ 催告 30 日** | 老陈怕装修白投，**书面催老王"30 日内表态认不认"**；老王收到后**不理不睬、满 30 日没回** | **视为拒绝追认**（≠默认同意！）| §171Ⅱ |
| **④ 善意相对人撤销** | 老陈当初**不知道小赵无权（善意）**，后来在隔壁找到更好铺面 → 在老王追认前**书面通知撤销**退出 | 合同**自始无效**，老陈全身而退；**老王一旦先追认，老陈就撤不了** | §171Ⅱ |

> ⚠️ **配套分水岭（高频陷阱）**：若小赵**持老王的房本 ＋ 盖了老王私章的空白委托书**去签，老陈**有理由相信**他有权 → 这就翻成**表见代理（§172）、合同直接有效**，**没有效力待定、没有催告 / 撤销问题**。"**有没有权利外观**"是 §171（效力待定）vs §172（直接有效）的分界。

### 👦 平行实例（限制行为能力 §145，机制完全相同，条号换 §145Ⅱ）

> 15 岁的小明用压岁钱在二手平台 **5000 元买了一台二手电脑**（超出年龄智力 → 效力待定，追认人＝父母）。
> ① 父母确认并付款＝**追认**（有效）；② 父母嫌贵要退＝**拒绝**（无效）；③ 卖家催父母"30 日内表态"、父母不回＝**视为拒绝**（§145Ⅱ）；④ 卖家**当初不知买家是未成年人（善意）**、自己反悔不卖 → 父母追认前可**通知撤销**。

## 五、默示追认 vs 单纯沉默（§140 的红线）

> **§140 原文（spp.gov.cn 核实逐字相符）**：行为人可以**明示或者默示**作出意思表示；**沉默**只有在有**法律规定、当事人约定或者符合当事人之间的交易习惯**时，才可以视为意思表示。

- **明示追认**：明确说"这单我认了"。
- **默示追认**：以**积极行为**表明承认——**接受履行 / 主动履行 / 主张合同权利 / 领取标的物 / 支付价款**（§503 即"已开始履行 / 受领履行=视为追认"）。
- **单纯沉默 ≠ 追认**：不拒绝、知情不否认、催告后不回复，原则上**无表示价值**，不构成追认。

> ⚠️ **概念别混**：**默示**（以积极行为推知，有表示价值）≠ **沉默**（不作为，原则上无表示价值）。§503 的"开始履行→视为追认"本质是**积极行为的默示**，**不是沉默**；而 §145Ⅱ / §171Ⅱ"催告后未表示→视为拒绝追认"针对的才是**真正的沉默**（法律拟制为拒绝）。**两者一句话对置：催告后纯沉默＝拒绝；积极履行＝默示追认。**

**沉默被赋予意义的反例（别和无权代理搞混）**：试用买卖试用期满买受人沉默→视为购买（§638）；租赁期满承租人续用、出租人不反对→不定期租赁（§734Ⅱ）。**但无权代理催告后沉默＝拒绝（§171Ⅱ），方向相反。**

## 六、万能五步模型（每步铁则 + 老王小李例子）

> 🚗 **统一案例**：老王（无权代理人）没授权就**冒用乙公司（老李的）名义**和丙签了供货合同 → 效力待定，等老李追认。

### 第一步：定性——是不是效力待定？落哪个场景？
**铁则**：先问"待定的是合同效力，还是物权变动"。①以**他人名义**无权 = 无权代理（§171，待定的是合同对本人生效）；②**限制行为能力人**超范围 = §145；③以**自己名义**卖他人之物 = 无权处分（§597 合同已有效，不进本模型待定区，只管物权）；④**无行为能力人**=一律无效（§144，不可追认）。
**例子**：老王以**乙公司名义**签 → 无权代理 §171，待定的是"合同对乙是否生效"。

### 第二步：找追认人，判明示 / 默示 / 沉默
**铁则**：追认人＝本人（§171）/ 法定代理人（§145）。明示（说"认了"）✅；默示（积极履行 / 受领 / 收款 / 领货 / 主张权利）✅；单纯沉默 ❌。
**例子**：老李**闷声开始备货发货**＝默示追认✅；老李"没说不干 / 知情不吭声"＝沉默❌。



- **明示** → 是追认 ✅(明确说"我认")
- **默示** → 是追认 ✅(用**积极行为**推定:履行、收款、领货、主张权利)
- **沉默** → **不算追认** ✅——但**别等同于"拒绝/不同意"**。

	关键区别在这:

	- **一般沉默 = 不表态**,合同**仍然效力待定**(悬而未决),既没被认可、也没被否决——它只是"不构成追认",不是主动"拒绝"。
	- **只有"催告后的沉默"才升级成拒绝**:相对人催告,有权人 **30 日**不表示 → 法律**拟制"视为拒绝"**(§171Ⅱ / §145Ⅱ)。这是法律替沉默"定性",不是沉默本身等于拒绝。
	
	一句话:
	
> 	**明示、默示 = 追认;沉默 = 不算追认(中性悬着);沉默 + 被催告满 30 日 = 才视为拒绝。**
	
	所以"沉默就是不追认"对;但"沉默就是不同意(拒绝)"只在**被催告**那一种情形下才成立。

### 第三步：跑机制四要素，处理催告与撤销
**铁则**：相对人催告→本人 30 日内未表示**视为拒绝追认**（§171Ⅱ）；追认前**善意**相对人可**通知撤销**（§171Ⅱ），追认后撤销权消灭。
**例子**：丙催"30 天表态"、老李装死 → **视为拒绝**（§171Ⅱ，**不是同意！**）；丙若善意，追认前可撤销退出。

### 第四步：（叠加瑕疵时）区分追认权与撤销权的归属
**铁则**：效力待定 + 可撤销可并存——本人**既可追认**（§171）**又可因缔约受欺诈 / 胁迫而撤销**（§148/§149）；**追认权与撤销权均归本人，骗子永无撤销权**。
**例子**：见 [[C1-多选-38 · 越权代理加欺诈的追认与撤销|C1-多选-38]]——甲既能追认越权代理的合同（A），又能因受丙欺诈撤销（B），两路都通；骗子丙无撤销权（D 错）。

### 第五步：追认后的后续救济 / 效力路径
**铁则**：**先追认定效力，再谈撤销方式**。追认使合同自始有效后，若有欺诈等可撤销事由，撤销须**以诉讼 / 仲裁方式**行使（无仲裁条款→法院），**不能通知撤销**；本人不追认则合同对本人不生效、谈不上履行。
**例子**：见 [[C1-单选-68 · 伪造公章签约的效力路径|C1-单选-68]]——乙追认则合同有效，受欺诈方丙须诉讼撤销（不能通知撤销）；乙不追认则对乙不生效。

## 七、易混提示

- **表见代理 §172 无需追认（关键分水岭）**：相对人**有理由相信**行为人有代理权 → 代理行为**直接有效**，**不存在效力待定、不需追认、相对人无撤销权、无催告问题**。§172 原文（spp.gov.cn）全文无"追认 / 不发生效力 / 效力待定"字样，与 §171Ⅰ"未经追认不发生效力"鲜明对比。**口诀：表见＝直接有效，狭义无权代理＝效力待定需追认。**
- **无权处分追认管"物权"、不管"合同效力"（§597）**：合同本就有效，追认指向物权变动 / 处分权补正，**不是 §503 / §171，不是旧 §51**。详见 [[民法-合同-无权处分模型]]。
- **债务承担的"同意"≠追认**：免责的债务承担须经债权人**同意**（§551），这是**生效要件**，与效力待定的"追认"分属不同制度；债权人单方催讨≠同意（见 [[合同通则-单选-52|C1-单选-52]]，甄别题）。
- **效力待定家族孪生对照**：§145 / §171·§503 共享"追认"机制，但条号、追认对象各异；无权处分已摘出（合同有效）。

## 八、命题人最爱的 5 个陷阱

1. **"沉默 = 默示追认"** —— 错！默示靠**积极行为**，单纯不拒绝 / 知情不否认都是沉默（§140Ⅱ，仅法定 / 约定 / 交易习惯三例外）。
2. **"催告后不回复 = 默认同意"** —— 恰恰相反！§171Ⅱ / §145Ⅱ **明文"视为拒绝追认"**（最毒反向陷阱，对应 [[合同通则-单选-14|C1-单选-14]] 的 D）。
3. **"表见代理也要被代理人追认"** —— 错！§172 **直接有效**，不需追认、无撤销权。
4. **"无权处分要权利人追认合同才有效"** —— 错！§597 **合同本就有效**，追认管**物权变动**，依据是物权变动规则 + 区分原则，**不是 §503 / 旧 §51**。
5. **追认权 / 撤销权归属错位** —— 叠加瑕疵中，追认权与撤销权**均归本人**，**骗子（实施欺诈的相对人）永无撤销权**。
