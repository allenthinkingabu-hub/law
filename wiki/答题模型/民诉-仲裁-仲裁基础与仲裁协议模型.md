# 📐 仲裁基础与仲裁协议 · 完整答题模型（可仲裁性 + 三要件 + 独立性 + 效力异议 + 效力扩张 · 2026新仲裁法）

> **核心一句**：仲裁是当事人**基于合意**、把**平等主体间的合同/财产权益争议**交给**仲裁机构一裁终局**解决的制度。整章做题就一条主线——**「能不能仲裁（§3可仲裁性）→ 协议有没有效（§27三要件 / §28-29无效与补救）→ 协议独立于主合同（§30）→ 对效力有异议找谁、何时提（§31 仲裁机构或法院、首次开庭前）→ 协议约束谁（效力扩张 / 相对性）」**。最毒陷阱是**把旧仲裁法条号（§16/§18/§20）当成现行号**、**把『约定的区级仲裁委/两个仲裁委/只约定仲裁规则』当成有效**、**把『合同无效→仲裁条款也无效』当成真理**、**把效力异议时点『首次开庭前』记成『开庭时/庭审中』**、**用仲裁协议去约束没签它的连带责任人/派生诉讼被告/代位债权人**。
>
> 🔎 **《仲裁法》（2025-09-12修订，2026-03-01施行）核心条文速查**（条号已逐条 grep 新法全文核到）：
> - **§3【可仲裁性】**：平等主体的自然人、法人、非法人组织之间发生的**合同纠纷和其他财产权益纠纷**，可以仲裁。下列纠纷**不能仲裁**：（一）**婚姻、收养、监护、扶养、继承**纠纷；（二）依法应当由行政机关处理的**行政争议**。
> - **§4【自愿原则】**：选择仲裁应遵循**自愿原则**，达成仲裁协议；**没有仲裁协议，一方申请仲裁的，仲裁机构不予受理**。
> - **§5【或裁或审·仲裁排除诉讼】**：达成仲裁协议、一方向法院起诉的，**法院不予受理**，但**仲裁协议无效或法律另有规定的除外**。
> - **§6【机构由当事人协议选定】**：仲裁机构应当由当事人协议选定；仲裁**不实行级别管辖和地域管辖**。
> - **§10【一裁终局】**：裁决作出后，当事人就同一纠纷再申请仲裁或起诉的，仲裁机构或法院不予受理。
> - **§27【仲裁协议三要件 + 拟制条款】**：仲裁协议应具有：①**请求仲裁的意思表示**；②**仲裁事项**；③**选定的仲裁机构**。（新增）一方主张有仲裁协议、另一方**在首次开庭前不予否认**、经仲裁庭提示并记录的，**视为存在仲裁协议**。
> - **§28【无效三情形】**：①约定事项超出法定仲裁范围；②**无/限制民事行为能力人**订立；③一方**胁迫**订立。
> - **§29【约定不明的补救】**：对**仲裁事项或仲裁机构**没有约定或约定不明确的→可**补充协议**；**达不成补充协议的→仲裁协议无效**。
> - **§30【独立性】**：仲裁协议**独立存在**。合同是否成立及其变更、不生效、终止、被撤销或者无效，**不影响**已达成的仲裁协议的效力。仲裁庭**有权确认合同的效力**。
> - **§31【效力异议】**：对效力有异议→可请求**仲裁机构/仲裁庭作出决定**，也可请求**人民法院作出裁定**；**一方请求机构、另一方请求法院的，由法院裁定**。异议应在**仲裁庭首次开庭前**提出。
> - **§37【起诉未声明有仲裁协议】**：一方起诉未声明有仲裁协议、法院受理后，另一方在**首次开庭前提交仲裁协议**的→法院**驳回起诉**（协议无效除外）；另一方首次开庭前**未提异议**的→**视为放弃仲裁协议**，法院继续审理。
> - **§93【劳动/农业/体育仲裁另定】**：劳动争议仲裁、农村土地承包经营纠纷仲裁、体育仲裁等，适用《劳动争议调解仲裁法》《农村土地承包经营纠纷调解仲裁法》《体育法》等专门规定。

> ⚠️ **诚实标注（本地核验说明）**：本模型对 **§3、§4、§5、§6、§10、§27、§28、§29、§30、§31、§37、§89、§93**（新《仲裁法》本体）**已逐条 grep 本地新法全文核到原文，条号准确**（本地全文源：中国人大网 2025-09-12 修订版，8章96条，2026-03-01施行）。但以下规则**新法正文没有逐字明文**，主要源自**旧《仲裁法司法解释》（法释〔2006〕7号）**及配套法理，2025新法体系是否原样承接、承接后的具体条号，**本地未逐字核验，做题按结论用、勿臆造新法条号**：①"或裁或诉→仲裁协议原则无效"（旧解释§7）；②"约定两个以上仲裁机构→可协议选择其一"（旧解释§5）；③"仅约定仲裁规则未定机构→视情形处理"（旧解释§4）；④"债权债务转让→仲裁条款对受让人有效"（旧解释§9）；⑤"确认仲裁协议效力由中级人民法院管辖"（旧解释§12）；⑥"仲裁机构先作效力决定后当事人再请求法院确认→法院不予受理"（旧解释§13）。以上不确定项一律**以官方 npc.gov.cn / flk.npc.gov.cn 及最高法后续配套解释为准**。

> ⑥ **仲裁协议只绑签字的人**（相对性）：连带责任人没签→不能拉去仲裁；股东派生诉讼、代位权诉讼的"外人债权人"→不受公司/债务人所签仲裁协议约束。

## 二、 五步判别模型（可仲裁 → 有效 → 独立 → 异议 → 约束谁）

```
                   【当事人拿着一份仲裁条款/仲裁协议来主张争议解决】
                                     │
     ▼ 第一关：这争议能不能仲裁？（§3 可仲裁性）
     │
     ├─ 平等主体（自然人/法人/非法人组织）之间的合同纠纷 / 其他财产权益纠纷 ──→ ✅ 可仲裁
     ├─ 婚姻·收养·监护·扶养·继承 ──────────────────────────────→ ❌ 不能仲裁（身份关系）
     ├─ 依法应由行政机关处理的行政争议 ────────────────────────→ ❌ 不能仲裁
     └─ 劳动争议 / 农村土地承包经营纠纷 / 体育仲裁 ─────────────→ 另有专门法（§93），非普通仲裁
                  │
     ▼ 第二关：这份仲裁协议有没有效？（§27 三要件 / §28 无效 / §29 约定不明补救）
     │
     ├─ 三要件齐备？ ①请求仲裁的意思表示 ②仲裁事项 ③选定的仲裁机构（§27）
     ├─ 落入无效情形？ 超范围 / 无·限制行为能力人 / 胁迫（§28）── 无效
     ├─ 机构或事项"约定不明"？（约定的仲裁委不存在 / 约定"本市仲裁机构"而市内有俩 /
     │    约定两个仲裁委 / 只写仲裁规则未定机构）── 可补充协议；补不成→无效（§29）
     └─ 无效/补不成 → 排除仲裁、回归诉讼（协议管辖或法定管辖）
                  │
     ▼ 第三关：主合同出问题，仲裁条款还在吗？（§30 独立性）
     │
     └─ 合同不成立/变更/不生效/终止/被撤销/无效 ──→ 均不影响仲裁协议效力；
        仲裁庭有权确认合同效力（合同烂了，仲裁条款不烂）
                  │
     ▼ 第四关：对效力有异议，找谁、何时提？（§31 + §37）
     │
     ├─ 找谁：可请求"仲裁机构/仲裁庭决定" 或 "人民法院裁定"
     ├─ 撞车：一方请求机构、另一方请求法院 ──→ 由【法院】裁定（法院优先）
     ├─ 何时：必须在【仲裁庭首次开庭前】提出；开庭答辩阶段才提＝逾期，视为放弃
     ├─ 请求法院裁定的：由【中级人民法院】管辖（基层无权｜源自旧司法解释，诚实标注）
     └─ 一方起诉未声明有协议：对方首次开庭前交协议→驳回起诉；未提异议→视为放弃、继续审（§37）
                  │
     ▼ 第五关：这份仲裁协议约束"谁"？（效力扩张 vs 相对性）
     │
     ├─ 扩张（及于）：合并/分立/继承的承继主体；债权债务转让的受让人（明确反对/不知有单独协议除外）；
     │    主合同仲裁条款及于未另约定的补充协议
     └─ 不扩张（相对性，只绑签字人）：未签协议的连带责任人；股东派生诉讼被告；
        代位权诉讼的代位债权人（合同编通则解释§36：相对人/债务人以其间仲裁协议对代位权诉讼提异议→不予支持）
```

> **一句话总诀**：**「先看能不能仲裁（合同财产可仲，婚姻收养监护扶养继承+行政争议不可仲，劳动农业体育另有法）；再看协议有没有效（请求仲裁意思+仲裁事项+选定机构三要件，机构不存在/两个/仅规则=约定不明、补不成就无效）；合同烂了仲裁条款不烂（独立性）；对效力有意见首次开庭前找仲裁机构或法院、撞车法院优先、请求裁定归中院；最后看约束谁——合并分立继承受让人跟着走、连带责任人派生诉讼代位债权人管不着」**

## 三、 高频干扰选项表

命题人最爱在"约定不明的四张脸""独立性""异议时点""相对性"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **约定的仲裁委不存在也能仲裁** | 合同约定"向 E 县仲裁委申请仲裁"，可以去 E 县仲裁委仲裁。 | **❌ 错！县级一般不设仲裁委（§13 不按行政区划层层设立），约定的机构不存在＝约定不明，补不成→仲裁协议无效（§29）**，转诉讼。 |
| **约定"本市仲裁机构"/两个仲裁委有效** | 约定"向 A 市的仲裁机构仲裁"而 A 市有两个仲裁委，或直接写"由甲、乙两个仲裁委仲裁"，协议有效、随便挑一个。 | **❌ 错！属机构约定不明（§29），须补充协议选定其一才有效；补不成→无效**。约定两个的须双方协议选一个，一方不能单方申请。 |
| **只约定仲裁规则=约定了机构** | 约定"在北京适用贸仲仲裁规则仲裁"，就是约定了贸仲/北京仲裁委。 | **❌ 错！只约定仲裁规则和仲裁地≠约定仲裁机构**；双方对机构又有分歧、补不成→无效（§29），转诉讼。 |
| **合同无效仲裁条款当然无效** | 主合同被确认无效，其中的仲裁条款也随之无效，仲裁委无权受理。 | **❌ 错！仲裁协议独立存在（§30），合同无效不影响仲裁条款；仲裁庭还有权确认合同效力**。 |
| **异议可以庭审中/开庭时提** | 当事人对仲裁协议效力有异议，在首次开庭答辩阶段提出即可。 | **❌ 错！必须在"仲裁庭首次开庭前"提（§31Ⅱ）**；答辩阶段才提＝逾期、视为放弃，仲裁庭驳回异议继续审。 |
| **一方找仲裁委一方找法院、仲裁委说了算** | 对效力，一方请求仲裁委决定、另一方请求法院裁定的，以先受理的仲裁委决定为准。 | **❌ 错！一方机构、一方法院→由法院裁定（§31Ⅰ，法院优先）**。 |
| **仲裁协议能捆住连带责任人/受让人不受约束** | 追连带责任可把没签协议的连带责任人一并拉去仲裁；合同转让后仲裁条款对受让人无效。 | **❌ 双向都错！相对性：没签协议的连带责任人不能被强制仲裁；转让时受让人知情/未明确反对的，原仲裁条款对受让人有效**。 |

## 四、 相邻制度对照表

### （1）仲裁 vs 诉讼（主管划界·或裁或审）

| 事项 | 仲裁 | 诉讼 |
|---|---|---|
| 启动前提 | 须有**有效仲裁协议**（§4，无协议不受理） | 无须协议，符合起诉条件即可 |
| 机构确定 | 当事人**协议选定**仲裁机构（§6），不实行级别/地域管辖 | 由法定/协议管辖规则确定法院 |
| 与对方的排除关系 | 有效仲裁协议→**排除法院主管**（§5，一方起诉法院不予受理） | 仲裁协议无效/无协议→回归法院 |
| 审级 | **一裁终局**（§10），无上诉 | 两审终审 |
| 公开性 | 原则**不公开**（§52） | 原则公开 |
| 司法审查 | 只有撤销（§71）/不予执行（§76）两条外部监督通道 | 上诉、再审等内部纠错 |

### （2）仲裁协议三要件（§27）——齐备才有效

| 要件 | 内容 | 常见缺失/陷阱 |
|---|---|---|
| ①请求仲裁的意思表示 | 明确表示"提交仲裁"解决 | "可协商/可诉可裁"含糊 → 意思不明/或裁或诉 |
| ②仲裁事项 | 约定哪些争议提交仲裁 | 约定不明可补充（§29） |
| ③**选定的仲裁机构** | 明确、唯一、真实存在的仲裁机构 | **机构不存在/写两个/只写"某市仲裁委"/只写仲裁规则** → 约定不明（§29），补不成→无效 |

> 🆕 **新法拟制条款（§27Ⅲ）**：一方主张有仲裁协议、另一方**首次开庭前不予否认**、经仲裁庭提示记录的，**视为存在仲裁协议**——书面形式进一步宽泛化。

### （3）可仲裁 vs 不可仲裁事项清单（§3 / §93）

| 类别 | 能否仲裁 | 具体 |
|---|---|---|
| 平等主体间**合同纠纷**、**其他财产权益纠纷** | ✅ 可仲裁 | 买卖/租赁/借款/工程款/侵权财产损害赔偿等 |
| **婚姻、收养、监护、扶养、继承**纠纷 | ❌ 不能仲裁 | 身份关系，专属人身，排除仲裁（也排除协议管辖） |
| 依法应由**行政机关处理的行政争议** | ❌ 不能仲裁 | 行政处罚/行政确权等 |
| **劳动争议** | ⚠️ 另有专门法 | 适用《劳动争议调解仲裁法》（劳动仲裁前置，不适用普通《仲裁法》） |
| **农村土地承包经营纠纷** | ⚠️ 另有专门法 | 适用《农村土地承包经营纠纷调解仲裁法》 |
| **体育纠纷** | ⚠️ 另有专门法 | 适用《体育法》体育仲裁 |

### （4）效力异议：找谁 + 何时（§31）

| 维度 | 规则 |
|---|---|
| 向谁提 | **仲裁机构/仲裁庭**（作决定） 或 **人民法院**（作裁定），二选一 |
| 一方机构、另一方法院 | **由法院裁定**（法院优先） |
| 何时提 | **仲裁庭首次开庭前**；逾期视为放弃 |
| 请求法院裁定的管辖 | **中级人民法院**（基层法院无权｜源自旧司法解释§12，诚实标注） |
| 仲裁机构已先作效力决定 | 当事人再请求法院确认的→法院**不予受理**（源自旧司法解释§13，诚实标注） |

## 五、 万能五步答题模型

> 🚗 **统一案例**：**甲公司**与**乙公司**签订《钢材买卖合同》，货款 **100 万元**，合同中约定"因履行本合同发生争议，提交**丙市仲裁委员会**仲裁"（丙市仅一家仲裁机构）。后乙公司拖欠货款，争议金额 **100 万元**。以此案例贯穿五步，并在每步做"变体"练手。

### 第一步：判可仲裁性——这争议能不能进仲裁的门？

> **合同财产能仲，身份行政不能仲，劳动农业体育另有法**

#### 概述

仲裁不是什么争议都能受理。§3 划了一条清清楚楚的边界：**只有"平等主体之间的合同纠纷和其他财产权益纠纷"才能仲裁**；凡是**婚姻、收养、监护、扶养、继承**这类身份关系纠纷，和**依法应由行政机关处理的行政争议**，一律**不能仲裁**。另外，**劳动争议、农村土地承包经营纠纷、体育纠纷**有各自的专门法律（§93），走的是专门的仲裁/前置程序，不套用普通《仲裁法》。

#### 大白话讲解

甲乙这场官司是"买卖合同拖欠 100 万货款"——**平等主体之间的合同财产争议**，正好落在 §3"可以仲裁"的圈里，能进仲裁的门。

换几个变体感受边界：

| 争议内容 | 能不能仲裁 | 理由 |
|---|---|---|
| 甲乙买卖合同欠 100 万货款（本案） | ✅ 能 | 平等主体合同/财产权益（§3） |
| 甲要和配偶离婚、争抚养权 | ❌ 不能 | 婚姻+监护，身份关系（§3） |
| 甲不服市场监管局的行政处罚 | ❌ 不能 | 应由行政机关处理的行政争议（§3） |
| 甲（劳动者）与公司的欠薪争议 | ⚠️ 走劳动仲裁 | 适用《劳动争议调解仲裁法》，非普通仲裁（§93） |

一句话：**先问"这是不是平等主体之间为钱/为合同打的架"**——是，就能仲裁；沾了身份（婚姻收养监护扶养继承）、沾了行政，就进不来。

#### 一句话闭环记忆

> 🎯 **一眼判**：平等主体的**合同/财产权益**争议＝能仲裁；**婚姻·收养·监护·扶养·继承 + 行政争议**＝不能仲裁；劳动/农业承包/体育另有专门法（§93）——身份和行政永远挡在仲裁门外。

---

### 第二步：判协议效力——这份仲裁协议有没有效？

> **三要件齐备才有效，机构不存在/两个/仅规则＝约定不明，补不成就无效**

#### 概述

争议能仲裁，还得有一份**有效的仲裁协议**才走得下去。§27 要求三要件同时齐备：**①请求仲裁的意思表示 ②仲裁事项 ③选定的仲裁机构**。§28 列了三种当然无效（超范围、无/限制行为能力人、胁迫）。最高频的坑在**第③项"选定的仲裁机构"**：只要机构写得不明确——**约定的仲裁委根本不存在（如"E县仲裁委"）、约定"本市仲裁机构"而市里有两个、直接约定两个仲裁委、只写了仲裁规则没写机构**——都属 §29 的"约定不明"，当事人可以补充协议选定一个；**补充不成的，仲裁协议无效**，争议回归法院。

#### 大白话讲解

本案约定"提交**丙市仲裁委员会**仲裁"，丙市就一家仲裁机构、指向明确，三要件齐备——**协议有效**，甲乙这 100 万只能去丙市仲裁委仲裁，不能起诉。

命题人最爱把第③项的"机构"改成四张"约定不明"的脸，全都导向"补不成→无效→转诉讼"：

| 变体（把"丙市仲裁委"换成……） | 效力 | 依据 |
|---|---|---|
| "E 县仲裁委"（县级一般不设仲裁委，机构不存在） | 约定不明→补不成则**无效** | §29；§13不按行政区划层层设立 |
| "本市的仲裁机构"（本市有两个仲裁委） | 约定不明→补不成则**无效** | §29 |
| "由 A 仲裁委和 B 仲裁委仲裁"（写了两个） | 须协议选定其一，一方不能单方申请；补不成**无效** | §29 |
| "在北京、按贸仲规则仲裁"（只写规则+地点、没写机构） | 只约定规则≠约定机构，有分歧、补不成**无效** | §29 |

**协议无效之后怎么办？** 争议回归法院：能协议管辖的按 §35 民诉法在"原被签履标"五连接点里选（配 [[民诉-管辖-多选-315 · 仲裁协议无效后的协议管辖范围]]）；协议不成就按 §24 法定管辖走被告住所地/合同履行地；**建设工程施工合同**这类不动产纠纷则由工程所在地专属管辖（配 [[民诉-仲裁-单选-315戴鹏 · 仅约定仲裁规则与仲裁地未定机构且有分歧协议无效由工程所在地法院管辖]]）。

> 🆕 **新法拟制条款（§27Ⅲ）**：即便没有白纸黑字的仲裁协议，一方在申请仲裁时主张有仲裁协议、另一方**首次开庭前不否认**、经仲裁庭提示记录的，也**视为存在仲裁协议**——这是新法对"书面形式"的进一步放宽，做题遇到"对方开庭前没否认"要想到这条。

#### 一句话闭环记忆

> 🎯 **一眼判**：三要件＝请求仲裁意思+仲裁事项+**选定的仲裁机构**；机构**不存在/两个/只写规则/只写"某市仲裁委"**＝约定不明（§29），补充选定一个才有效、补不成就**无效**→转诉讼（协议管辖或法定管辖）。

---

### 第三步：判独立性——主合同出事了，仲裁条款还站着吗？

> **合同烂了仲裁条款不烂，仲裁庭还能审"合同有没有效"**

#### 概述

一份合同里的仲裁条款，命运**不跟着主合同走**。§30 讲得很明确：仲裁协议**独立存在**，**合同是否成立及其变更、不生效、终止、被撤销或者无效，都不影响已经达成的仲裁协议的效力**；而且**仲裁庭还有权确认合同的效力**。这就叫"仲裁条款独立性"（自裁管辖权的一半）。命题人最爱设的陷阱是——"合同都无效了，里面的仲裁条款当然也无效，仲裁委无权受理"，这是**错的**。

#### 大白话讲解

假设甲后来主张"这份买卖合同是乙欺诈订立的、应属无效"，跑去丙市仲裁委请求**确认合同无效**。乙抗辩："合同要是无效，仲裁条款也无效，你这仲裁委根本无权管！"

这套逻辑**站不住**：

- **仲裁条款独立**：合同即使被认定无效，其中的仲裁条款仍然有效（§30）——就像一栋楼塌了，但"由谁来鉴定这栋楼塌没塌"的那份委托书还有效；
- **谁来判合同有没有效？** 正是仲裁庭自己——§30 后段明文"**仲裁庭有权确认合同的效力**"。所以"合同是否无效"这个争议，恰恰属于仲裁条款约定的仲裁事项，丙市仲裁委**有权受理和审理**。

所以：合同无效≠仲裁条款无效；仲裁庭有权审合同效力。（配 [[民诉-仲裁-单选-320戴鹏 · 仲裁条款独立于主合同一方请求仲裁委一方请求法院由法院裁定]]）

#### 一句话闭环记忆

> 🎯 **一眼判**：仲裁协议**独立存在**（§30）——合同不成立/变更/不生效/终止/被撤销/无效，**统统不影响**仲裁条款；仲裁庭还**有权确认合同效力**。"合同无效→仲裁条款也无效"是命题人的假话。

### 第四步：判效力异议——对协议效力有意见，找谁、何时提？

> **首次开庭前提，找仲裁机构或法院，撞车法院优先**

#### 概述

对仲裁协议的效力有异议，§31 给了两条路和一个死线：**找谁**——可以请求"**仲裁机构/仲裁庭作出决定**"，也可以请求"**人民法院作出裁定**"；**撞车**——如果一方去找仲裁机构、另一方去找法院，**由法院裁定**（法院优先）；**何时**——异议必须在"**仲裁庭首次开庭前**"提出，逾期就视为放弃、协议对你有效。请求法院裁定的，由**中级人民法院**管辖（基层无权，源自旧司法解释，诚实标注）。另有 §37 的镜像规则：一方直接去法院起诉、没声明有仲裁协议，法院受理后，对方**首次开庭前提交仲裁协议**的→法院**驳回起诉**；对方**首次开庭前没提异议**→**视为放弃仲裁协议**、法院继续审。

#### 大白话讲解

回到本案，乙公司觉得"丙市仲裁委这个约定有问题、仲裁协议无效"，想提异议。几种走法：

- **正常提**：乙在丙市仲裁委**首次开庭前**，请求仲裁庭（或仲裁机构）确认协议无效——合法、有效。
- **撞车了**：乙跑去法院请求裁定协议无效，同时甲跑去请求仲裁委确认协议有效——**一方机构、一方法院＝法院说了算**（§31Ⅰ），由法院裁定。（配 [[民诉-仲裁-单选-320戴鹏 · 仲裁条款独立于主合同一方请求仲裁委一方请求法院由法院裁定]]）
- **提晚了（最毒陷阱）**：乙一直没吭声，直到**首次开庭的答辩阶段**才提异议——**过了"首次开庭前"这条死线**（§31Ⅱ），视为放弃异议、协议对他有效，**仲裁庭驳回异议、继续审理**。（配 [[民诉-仲裁-单选-318戴鹏 · 未在首次开庭前提出效力异议仲裁庭应驳回异议继续审理]]）
- **找错了级别**：乙想请求法院裁定，只能去**中级法院**，去基层法院（区/县法院）没用。（配 [[民诉-仲裁-多选-317戴鹏 · 或裁或诉仲裁协议无效被告住所地基层法院应受理]]、[[民诉-管辖-不定项-328戴鹏 · 确认仲裁条款无效可请求两仲裁委或中院及协议管辖与法定管辖]]）
- **§37 镜像**：如果乙直接跑去法院起诉（没提有仲裁协议），法院受理后甲**首次开庭前**把仲裁协议甩出来→法院**驳回乙的起诉**（协议有效时）；反过来，甲**首次开庭前一直没提**这份仲裁协议→**视为放弃**、法院继续审这个案子。

> ⚠️ **"仲裁委已先定了效力，别再去法院"**：一方已请求仲裁机构作出效力决定、仲裁委也已作出决定后，当事人再向法院申请确认效力的→法院**不予受理**、仲裁**继续**（源自旧司法解释§13，诚实标注）。（配 [[民诉-仲裁-不定项-329戴鹏 · 仲裁委已决效力法院不受理及仲裁调解结案与超裁不予执行]]）

#### 一句话闭环记忆

> 🎯 **一眼判**：效力异议**首次开庭前**提（开庭答辩才提＝晚了，驳回继续审）；找**仲裁机构或法院**都行，**一方机构一方法院→法院裁定**；请求法院裁定的归**中院**（基层无权）；一方起诉没声明有协议，对方首次开庭前不提异议＝**视为放弃仲裁协议**、法院继续审（§37）。

### 第五步：判约束谁——这份仲裁协议管得着"这个人"吗？

> **合并分立继承受让人跟着走，连带责任人派生诉讼代位债权人管不着**

#### 概述

最后一关是"人的范围"。仲裁协议原则上**只约束签它的当事人**（相对性），但有几类"承继情形"会让效力**扩张**到新主体：**当事人合并、分立、继承**的，原仲裁协议对承继主体有效；**债权债务转让**的，原合同的仲裁条款对**受让人**有效（受让时**明确反对**或**不知道有单独仲裁协议**的除外）；**主合同的仲裁条款**及于**未另行约定争议解决方式的补充协议**。反过来，效力**不扩张**到这些"外人"：**没签协议的连带责任人**（不能被强制拉去仲裁）、**股东派生诉讼的被告**（公司所签仲裁协议按题库立场不约束派生诉讼）、**代位权诉讼的代位债权人**（债务人与相对人之间的仲裁协议不约束代位债权人——合同编通则解释 §36 明定）。

> ⚠️ **诚实标注**：合并分立继承/转让受让人/补充协议这几条"扩张"规则，新《仲裁法》正文未逐字明文，主要源自旧《仲裁法司法解释》（法释〔2006〕7号 §8、§9）与法理；"代位权诉讼不受约束"则由《合同编通则解释》（法释〔2023〕13号）§36 明定。做题按结论用，勿臆造新仲裁法条号。

#### 大白话讲解

用本案的甲（100 万债权人）串一遍"约束谁"：

**A. 扩张（跟着走）：**

- **乙被别的公司合并/分立**：乙与丁公司合并成"新公司"，原买卖合同的权利义务由新公司承受——**原仲裁条款对新公司有效**，争议还得去丙市仲裁委。（但注意：若约定的机构本身不存在/无效，则因机构无效转诉讼，而非因"合并"失效——配 [[民诉-仲裁-单选-307 · 约定的仲裁委员会不存在仲裁协议无效应向被告所在地法院起诉]]）
- **甲把合同权利义务转让给丙受让人**：甲把《买卖合同》转给丙，还**把合同原件给了丙**（丙知道里面有仲裁条款、也没明确反对）——**原仲裁条款对受让人丙有效**，丙对乙的货款争议还得去原约定的仲裁委仲裁；甲丙之间《转让协议》里另约的"某法院管辖"是他俩的事、**管不到合同相对方乙**。（配 [[民诉-仲裁-单选-321戴鹏 · 合同权利义务转让仲裁条款对知情受让人有效应申请仲裁]]）
- **甲乙又签了个补充协议**：就工程款/货款计算方式补签协议、**没另约定争议解决方式**——主合同的仲裁条款**及于补充协议**，争议仍走仲裁。（配 [[民诉-仲裁-单选-312戴鹏 · 主合同仲裁条款及于未另约定的补充协议应申请仲裁]]）

**B. 不扩张（只绑签字人，管不着的"外人"）：**

- **追连带责任人**：乙提供的数据是丙伪造的，甲要追丙的**连带责任**，但**丙没签甲乙之间的仲裁协议**——不能把丙强行拉去仲裁；甲只能**一并向法院起诉乙、丙**，或**对乙仲裁、单独起诉丙**。（配 [[民诉-仲裁-多选-310 · 仲裁协议仅约束当事人连带责任人无协议可一并诉讼或分别裁诉]]）
- **股东派生诉讼**：公司与相对方签了仲裁协议，小股东代公司提**派生诉讼**告相对方——按题库立场，公司的仲裁协议**不约束股东派生诉讼**，由被告住所地法院管辖（此点学理有争议）。（配 [[民诉-仲裁-单选-311戴鹏 · 股东派生诉讼不受公司仲裁协议约束由被告住所地法院管辖]]）
- **代位权诉讼**：甲（债权人）代位起诉乙的相对人丙，丙拿"我和乙之间有仲裁协议"来对法院主管提异议——**这份仲裁协议不约束没签它的代位债权人甲**，法院**不予支持、驳回异议继续审**（合同编通则解释§36）；若债权人对债务人的诉讼与代位权诉讼在同一法院，还可**合并审理**。（配 [[民诉-仲裁-单选-308 · 代位权诉讼中相对人以其与债务人仲裁协议提管辖异议不予支持]]、[[民诉-仲裁-单选-309 · 债务人诉讼与代位权诉讼在同一法院可合并审理仲裁异议不成立]]）

一句话：**"承继型"的（合并分立继承、转让、补充协议）仲裁条款跟着走；"外人型"的（连带责任人、派生诉讼、代位债权人）没签就管不着。**

#### 一句话闭环记忆

> 🎯 **一眼判**：**扩张**——合并/分立/继承的承继人、转让的**知情受让人**、未另约定的补充协议，仲裁条款**跟着走**；**不扩张（相对性）**——没签协议的**连带责任人**、**股东派生诉讼**被告、**代位权诉讼**的代位债权人，仲裁协议**管不着**（代位权诉讼提仲裁异议→法院不予支持，合同编通则解释§36）。

## 六、 易混考点辨析

- **可仲裁 vs 协议管辖的排除清单**：
  - 婚姻收养监护扶养继承——**既不能仲裁**（§3），身份关系诉讼**也不能协议管辖**（协议管辖只限合同/财产权益纠纷）。两个清单高度重合，别记混：核心都是"身份关系被排除"。
- **约定不明（§29）vs 无效情形（§28）**：
  - §29 是"机构/事项**没写清**"（不存在/两个/仅规则）→**可补充**、补不成才无效；§28 是"**当然无效**"三情形（超范围/无·限制行为能力人/胁迫）→无补救余地。前者有救、后者没救。
- **独立性（§30）vs 效力异议（§31）**：
  - §30 解决"合同烂了仲裁条款烂不烂"（不烂）；§31 解决"觉得仲裁条款本身有问题，找谁、何时提"。一个是"条款命运独立"，一个是"异议程序"。
- **效力异议时点"首次开庭前" vs 回避申请时点**：
  - 效力异议：**首次开庭前**（§31Ⅱ），逾期视为放弃；仲裁员回避：首次开庭前提，**回避事由在首次开庭后才知道的，可在最后一次开庭终结前提**（§47）——回避有"事后知悉"的宽限，效力异议没有，别张冠李戴。
- **一裁终局 vs 两审终审**：
  - 仲裁**一裁终局**（§10），裁决作出即生效、无上诉；救济只有向中院申请撤销（§71）或执行时不予执行（§76）。诉讼是两审终审。
- **仲裁委员会 vs 仲裁机构（术语）**：
  - 新法多用"仲裁机构"，§89 附则：仲裁机构**包括**仲裁委员会、仲裁院等。真题旧表述"仲裁委员会"与新法"仲裁机构"是同一所指，别当两个概念。

## 七、 命题陷阱清单

1. **"真题里写的是《仲裁法》第 16/18/20 条，就照抄这些条号答主观题"** —— 错！那是**旧法**条号。2025 修订后：三要件旧§16→**新§27**、约定不明旧§18→**新§29**、效力异议旧§20→**新§31**、可仲裁范围旧§2/§3→**新§3**、独立性旧§19→**新§30**、起诉未声明旧§26→**新§37**。用新号。
2. **"约定'E 县仲裁委/本市仲裁机构/两个仲裁委/只写仲裁规则'的协议有效、可以仲裁"** —— 错！全属机构**约定不明**（§29），可补充协议选定一个；**补不成→仲裁协议无效**，转诉讼。
3. **"主合同无效，仲裁条款随之无效，仲裁委无权受理"** —— 错！仲裁协议**独立存在**（§30），合同无效不影响仲裁条款；仲裁庭还**有权确认合同效力**。
4. **"对仲裁协议效力有异议，在首次开庭答辩阶段/庭审中提出即可"** —— 错！必须在"**仲裁庭首次开庭前**"提（§31Ⅱ）；逾期视为放弃，仲裁庭驳回异议继续审。
5. **"一方请求仲裁委决定、另一方请求法院裁定，以仲裁委决定为准"** —— 错！**一方机构、一方法院→由法院裁定**（§31Ⅰ，法院优先）。
6. **"请求法院裁定仲裁协议效力，向基层法院（被告住所地区/县法院）申请"** —— 错！确认仲裁协议效力由**中级人民法院**管辖（源自旧司法解释§12，诚实标注）；被告住所地基层法院受理的是协议无效后的**实体诉讼**，不是"确认效力"。
7. **"追连带责任，可把没签仲裁协议的连带责任人一并拉去仲裁"** —— 错！相对性——**未签协议的第三人不能被强制仲裁**，只能一并起诉，或对签约方仲裁+单独起诉第三人。
8. **"合同转让后，原仲裁条款对受让人一律无效"** —— 错！受让时**知情/未明确反对**的，原仲裁条款**对受让人有效**（源自旧司法解释§9，诚实标注）。
9. **"代位权诉讼中，相对人拿'我和债务人有仲裁协议'就能把案子踢出法院"** —— 错！该仲裁协议**不约束代位债权人**，法院**不予支持异议、继续审**（合同编通则解释§36）；相对人只有在**首次开庭前就该债权债务关系真去申请了仲裁**，法院才**可裁定中止**（不是驳回）。
10. **"劳动争议、农村土地承包经营纠纷可以直接依《仲裁法》申请普通仲裁"** —— 错！它们**另有专门法**（§93：《劳动争议调解仲裁法》《农村土地承包经营纠纷调解仲裁法》《体育法》），不套用普通《仲裁法》。

| [[民诉-管辖-多选-315 · 仲裁协议无效后的协议管辖范围]] | **机构约定不明→协议无效→协议管辖五连接点。**约定"两家仲裁机构"约定不明补不成→无效（§29）；无效后回归诉讼，可在"原被签履标"（原告/被告住所地、签订地、履行地、标的物所在地，民诉法§35）中协议选择——四地全在圈内，ABCD 全选。 | 第二步·约定不明 + 无效后协议管辖 |
| [[民诉-仲裁-多选-316戴鹏 · 或裁或诉条款仲裁协议无效但管辖协议有效及未异议例外]] | **或裁或诉：仲裁协议无效、管辖协议有效、未异议例外。**"可仲裁也可向 B 法院起诉"＝或裁或诉→仲裁协议无效（A），但选法院的管辖协议有效（B，民诉法§35）；一方申请仲裁、对方首次开庭前未异议→仲裁又有效（§31，C）；向有管辖权的 B 法院起诉不驳回（D 错）。或裁或诉规则源自旧司法解释，诚实标注。 | 第二步·或裁或诉 + 第四步·未异议例外 |
| [[民诉-仲裁-多选-317戴鹏 · 或裁或诉仲裁协议无效被告住所地基层法院应受理]] | **或裁或诉无效 + 确认效力归中院、基层受理实体诉讼。**"仲裁委仲裁或被告住所地法院管辖"＝或裁或诉→仲裁协议无效（D）；向被告住所地 J 区（基层）起诉，J 区法院受理**实体案件**（C）；但"确认仲裁协议效力"归**中院**，J/K 区基层无权确认无效（A、B 错）。 | 第二步·或裁或诉 + 第四步·确认效力归中院 |
| [[民诉-仲裁-单选-318戴鹏 · 未在首次开庭前提出效力异议仲裁庭应驳回异议继续审理]] | **效力异议时点"首次开庭前" + 仲裁庭可自行决定。**乙在首次开庭"答辩阶段"才提异议＝逾期（§31Ⅱ），视为放弃、仲裁庭驳回异议继续审（C）；或裁或诉本"原则无效"（A"原则有效"错）；仲裁庭可自行决定效力无须仲裁委授权（B 错）；超期不能再向中院申请（D 错）。 | 第四步·效力异议时点 |
| [[民诉-仲裁-单选-320戴鹏 · 仲裁条款独立于主合同一方请求仲裁委一方请求法院由法院裁定]] | **独立性 + 一方机构一方法院→法院裁定。**投资合同即使无效，仲裁条款独立、照样有效（§30，B 错），A 仲裁委有权审"合同有没有效"（A 错）；大成找仲裁委、华泰找法院→一方机构一方法院＝法院裁定（§31，C）。 | 第三步·独立性 + 第四步·法院优先 |
| [[民诉-管辖-不定项-328戴鹏 · 确认仲裁条款无效可请求两仲裁委或中院及协议管辖与法定管辖]] | **效力异议找仲裁委或中院 + 协议管辖五连接点 + 无协议法定管辖。**(1)约定 B 市仲裁委而市内有丙丁两个→可请求丙/丁仲裁委决定或 B 市中院裁定，C 区基层无权（§29/§31，ABC）；(2)无效后协议管辖五连接点四地全占（民诉法§35，ABCD）；(3)无协议时只剩被告住所地+合同履行地（民诉法§24，BC）。中院管辖源自旧司法解释，诚实标注。 | 第二步·约定不明 + 第四步·效力异议 + 无效后管辖 |
| [[民诉-仲裁-单选-308 · 代位权诉讼中相对人以其与债务人仲裁协议提管辖异议不予支持]] | **代位权诉讼·仲裁协议相对性。**相对人南山以其与债务人西水之间的仲裁协议对法院主管提异议→该协议不约束代位债权人东江，法院不予支持、驳回异议继续审（合同编通则解释§36，B）；相对人只有首次开庭前真去申请仲裁法院才可中止（非本案）。 | 第五步·相对性（代位权诉讼） |
| [[民诉-仲裁-单选-309 · 债务人诉讼与代位权诉讼在同一法院可合并审理仲裁异议不成立]] | **代位权诉讼·合并审理 + 仲裁异议不成立。**丁先诉谢（债务人）、又在同一甲县法院代位诉孔（相对人），可合并审理（合同编通则解释§38，B）；孔以其与谢的仲裁条款主张移送仲裁→不约束代位债权人丁、不移送（§36，C 错）；同院无须中止（A、D 错）。 | 第五步·相对性 + 合并审理 |
| [[民诉-仲裁-多选-310 · 仲裁协议仅约束当事人连带责任人无协议可一并诉讼或分别裁诉]] | **仲裁协议相对性·连带责任人。**甲乙有仲裁协议、丙（连带责任人）没签→不能拉丙一起仲裁（A、C 错，相对性）；追乙丙连带责任可一并向法院起诉（B），或对乙仲裁、单独起诉丙（D）。2025 新题，MEDIUM。 | 第五步·相对性（连带责任人） |
| [[民诉-仲裁-单选-311戴鹏 · 股东派生诉讼不受公司仲裁协议约束由被告住所地法院管辖]] | **仲裁协议相对性·股东派生诉讼（学理有争议）。**按题库立场，公司与相对方的仲裁协议不约束股东派生诉讼，丁的派生诉讼由被告刘记住所地 Z 市法院管辖（A）；丁能行使派生诉权（C 错）；非原告 X 市（B 错）；题库立场不走仲裁（D 错，⚠️学理争议已在卡内标注）。 | 第五步·相对性（派生诉讼） |
| [[民诉-仲裁-单选-312戴鹏 · 主合同仲裁条款及于未另约定的补充协议应申请仲裁]] | **效力扩张·补充协议。**主合同（施工合同）约定丙市仲裁委仲裁，补充协议（工程款计算/支付）未另约定争议解决方式→主合同仲裁条款及于补充协议→工程款争议向丙市仲裁委申请仲裁（D）；有有效仲裁协议排除法院管辖，不能起诉（A、B、C 错）。 | 第五步·效力扩张（补充协议） |
| [[民诉-仲裁-单选-321戴鹏 · 合同权利义务转让仲裁条款对知情受让人有效应申请仲裁]] | **效力扩张·转让受让人。**甲将合同权利义务转让给丙、并交付合同原件（丙知晓仲裁条款、未明确反对）→原仲裁条款对受让人丙有效，丙对乙的货款争议向 M 仲裁委申请仲裁（C）；甲丙《转让协议》约定的法院管辖不约束合同相对方乙（D 错）；仲裁条款对丙有效不能起诉（A、B 错）。转让受让人规则源自旧司法解释，诚实标注。 | 第五步·效力扩张（转让） |
| [[民诉-仲裁-不定项-329戴鹏 · 仲裁委已决效力法院不受理及仲裁调解结案与超裁不予执行]] | **仲裁委已决效力→法院不受理（+仲裁程序·司法审查衔接）。**(1)仲裁委已作"有效"决定后，当事人再请求法院确认→法院不受理、仲裁继续（BD，源自旧司法解释§13，诚实标注）；(2)(3)属仲裁程序/司法审查（调解结案、超裁不予执行），见相邻模型。 | 第四步·仲裁委已决→法院不受理 |
