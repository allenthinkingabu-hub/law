# 📐 合同成立 vs 合同生效 · 完整答题模型（订立→效力的"桥"：两步连贯链 + 兜底层）

> **核心一句**：
> 
> **成立＝有没有合意（事实判断）；生效＝合意有没有约束力（法律价值评价）**。
> 
> 二者是**两个独立判断**，但答题时**捆成一条连贯链**走——**先判成立、再判生效**，主线是"**成立是生效的前提，成立≠生效**"（单向逻辑：未成立则无所谓生效；已成立未必生效）。最后别忘**兜底层**：未成立 / 无效 / 被撤销有缔约过失，成立未生效有报批义务条款独立有效。
>
> 🔗 **为什么"合并成一个模型"而非两个孤立页**：法考主流机构（瑞达·钟秀勇、众合·孟献贵、厚大·张翔、法大）口径一致，把"成立→生效"作为**同一民事法律行为论的连贯两步**讲——钟秀勇精讲第四章第 05 讲标题即"**法律行为的成立与生效、报批条款与相关条款独立生效规则**"，把成立 + 生效 + 报批放在同一讲。二者**共享同一组高频陷阱**（成立时点、附条件 / 期限、报批 / 登记、价款非要件、缔约过失兜底），拆开会割裂因果链。**概念分开（[[合同成立]] / [[合同生效]] 两实体页）、答题合并（本模型）**。
>
> 🔎 **法条已联网核实（2026-06-16；最高检 spp.gov.cn 逐字 + 最高法公报 / court.gov.cn + 通则解释 法释〔2023〕13号 + 对抗复核全 CONFIRMED）**：成立 §483 / §490 / §491 + 通则解释§3；生效 §502 / §143 / §158 / §159 / §160；区分原则 §215（+§209/§224/§225）；兜底 §500 / §157 / 通则解释§12。
>
> ⚠️ **三处务必内化的纠正点（勿照抄旧表述）**：
> ① **"批准"走 §502、"登记"走 §215，两条线分开**：§502 **全文只字未提"登记""物权"**；"未登记不影响合同效力"的规范依据是 **§215 区分原则**，不是 §502。§502Ⅲ 真实内容是"合同的**变更、转让、解除**等情形应当办理批准等手续的，适用前款规定"（**仅指批准**）。
> ② **§502Ⅱ 完整措辞**："不影响合同中**履行报批等义务条款以及相关条款**的效力"——含"**等**"字、含"**以及相关条款**"，勿简写成"报批义务条款"。
> ③ **成立时点是"谱系"不是"四分法"**：实际规则点 **≥ 6 个**（见第二步），"四分法"是助记、非法定术语；锁死"四"会漏掉 §490Ⅰ后段（缺签章·履行治愈）与 §490Ⅱ（缺书面·履行治愈）。

## 二、万能答题模型（两步连贯链 + 兜底层）

> **主线**：`第一步判成立（事实）→ 第二步判生效（评价）→ 兜底层（未成立/未生效也有责任）`。一句话：**谈成是"成立"，算数才"生效"；没谈成、谈崩了、成了但悬着——都还有戏。**

### 第一步【判成立】—— 事实判断：有没有合意

#### **① 三要素够不够？**（成立的最低必备内容）

> 合意三要素: 双方当事人 + 标的 + 数量

> **通则解释§3Ⅰ（逐字）**："当事人对合同是否成立存在争议，人民法院能够确定当事人**姓名或者名称、标的和数量**的，一般应当认定合同成立。但是，法律另有规定或者当事人另有约定的除外。"

| 要素                  | 内容         | 缺了会怎样                      |
| ------------------- | ---------- | -------------------------- |
| **谁**               | 当事人姓名 / 名称 | 缺 → 不成立                    |
| **什么**              | 标的         | 缺 → 不成立                    |
| **多少**              | 数量         | 缺 → 不成立                    |
| 〜价款 / 期限 / 地点 / 方式〜 | **非成立要件**  | 缺 → **仍成立**，按 §510→§511 填补 |
|                     |            |                            |

> ★ **最高频陷阱**：题干"**未约定价款**"诱你答"合同不成立"——错。价款约定不明，先**协议补充**（§510），不成则按**订立时履行地市场价**确定（§511 第二项）；依法应执行政府定价 / 指导价的依规定。**价款绝非成立要件**（§470 八项"一般包括"是示范性条款，缺一两项不必然不成立）。

#### **② 成立时点谱系（≥6 点，非"四分法"）**

> 承诺生效 + 法律另有约定 + 当事人另有约

##### 成立核心原则: **只要法律没有特殊规定、当事人也没有特殊约定，合同就在「承诺生效」的那一刻正式成立**。后面表格里的合同书、确认书、电子合同、履行治愈等，全部都是本条「法律另有规定 / 当事人另有约定」的例外情形。
 
 * 什么是「承诺生效」
 
 承诺是受要约人同意要约的意思表示（比如 “我同意买”“就按这个价格成交”），它的生效时点分三类情形判断：

- **对话方式（当面、电话、实时语音等）**：采「了解主义」—— 对方知道、听懂承诺内容时生效。
    
    例：你打电话问商家 “这件衣服 199 卖吗”，商家说 “卖”，你听到这句话的瞬间，承诺生效、合同成立。
    
- **非对话方式（信件、邮件、微信文字等）**：采「到达主义」—— 承诺到达对方可控制的范围时生效，不要求对方实际看到。

    例：你给卖家发微信 “我下单这件商品”，消息成功发送到对方微信账户时，承诺就生效了，哪怕对方暂时没看手机，也不影响合同成立。
    
- **数据电文形式**：指定了特定接收系统的，进入该系统时生效；未指定的，对方知道或应当知道该数据电文进入其系统时生效。
	*§137 数据电文到达规则**（适用于要约 / 承诺 / 一般意思表示）：

| 情形              | 生效时点                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| 当事人**有约定**      | 按约定                                                                                        |
| 受要约人**指定特定系统**  | 数据电文**进入该特定系统**时                                                                           |
| 受要约人**未指定特定系统** | 数据电文**进入其任一系统的首次时间** 或 受要约人**知道/应当知道**该电文已进入其系统时（看具体规则版本，民法典通常以"进入任一系统的首时间"或"知道/应当知道"为生效点） |

##### 「但书」的两层含义（对应例外规则）

条文里的 “法律另有规定或者当事人另有约定的除外”，就是表格中其他 5 类时点的法律依据：

* ***法律另有规定**：
    
    合同书签章成立、履行治愈、确认书成立、电子合同提交订单成立，都是《民法典》专门规定的特殊成立规则，优先于 “承诺生效” 的一般规则适用。

* ***当事人另有约定**：

    如果双方明确约定 “必须签盖章合同书才算合同成立”“必须付定金后合同才成立”，就按双方约定的时点算，也排除一般规则的适用。

| 时点         | 规则（逐字要点）                                                                       | 条号          |
| ---------- | ------------------------------------------------------------------------------ | ----------- |
| ① 一般       | "承诺生效时合同成立，但是法律另有规定或者当事人另有约定的除外。"                                              | **§483**    |
| ② 合同书      | "采用合同书形式订立合同的，自当事人**均**签名、盖章或者按指印时合同成立。"                                       | **§490Ⅰ前段** |
| ③ 缺签章·履行治愈 | "在签名、盖章或者按指印**之前**，当事人一方已经履行**主要义务**，对方**接受**时，该合同成立。"                         | **§490Ⅰ后段** |
| ④ 缺书面·履行治愈 | "法律、行政法规规定或者当事人约定合同**应当采用书面形式**订立，当事人**未采用**书面形式但是一方已经履行主要义务，对方接受时，该合同成立。"     | **§490Ⅱ**   |
| ⑤ 确认书      | "采用信件、数据电文等形式订立合同**要求签订确认书**的，签订确认书时合同成立。"                                     | **§491Ⅰ**   |
| ⑥ 电子合同     | "一方通过互联网等信息网络发布的商品或者服务信息**符合要约条件**的，对方选择该商品或者服务并**提交订单成功**时合同成立，但是当事人另有约定的除外。" | **§491Ⅱ**   |

> 🔑 **§483 与 §490 / §491 的关系**：§490、§491 都是 §483 但书"**法律另有规定**"的具体例外——合同书以"均签章"为时点、电子合同以"提交订单成功"为时点，替代了"承诺生效"。
>
> ⚠️ **§490 双向陷阱（务必单记）**：签名、盖章、按指印三者是"**或**"（**任一即可**，不要求既签又盖），但前缀"**均**"要求**各方都完成**——"**或**"针对方式、"**均**"针对主体，两个不同维度。命题人两头设坑："必须既签名又盖章"（错，任一即可）/"只有一方签了就成立"（错，须各方均完成）。
>
> ⚠️ **§491Ⅱ 前提**：网页信息须"**符合要约条件**"（构成要约）才"提交订单成功即成立"；若网页只是**要约邀请**，则下单是要约、商家确认 / 发货才是承诺，**不适用本款**。

**③ 未成立？→ 不是无责任** → 走兜底层缔约过失 §500（详见下方兜底层 + 📐 [[民法-合同-缔约过失责任模型]]）。

### 第二步【判生效】—— 法律价值评价（前提：已成立）


#### **默认：成立即生效**

> **§502Ⅰ（逐字）**："依法成立的合同，自成立时生效，但是法律另有规定或者当事人另有约定的除外。"

→ 多数情况下**成立时点 = 生效时点**，二者同一刻发生。

####  **民事法律行为有效 -  三要件正面查**（有效的正面标准）

 * **民事法律行为有效的三大要件:
	 * ** **§143（逐字）**："具备下列条件的**民事法律行为**有效：
		 * （一）行为人具有相应的民事行为能力

			 * **完全民事行为能力人**（成年人、16 岁以上以自己劳动为主要生活来源的人）可以独立签任何合同；

			*  **限制民事行为能力人**（8-18 岁）只能签和年龄智力匹配的合同（买文具），签大额合同就属于 “没有相应行为能力”，对应后面的**效力待定**；

			* **无民事行为能力人**（不满 8 岁）独立实施的民事法律行为一律无效
	
		 * （二）意思表示真实；

			 * 如果意思表示不真实 —— 比如 被欺诈、被胁迫、重大误解、显失公平签的合同，合同并非直接无效，而是属于**可撤销**：受害方有权去法院 / 仲裁机构撤销，撤销后合同自始无效；不撤销就继续有效。

		 * （三）不违反法律、行政法规的强制性规定，不违背公序良俗。
			
			 * 不违法法律、行政规定
				 * 第一层限制： 只认「法律、行政法规」层级的强制性规定: 
					 * 不是违反任何规定都会导致合同无效，法律只认最高两个层级的规则：
						- **法律**：全国人大及其常委会制定的（比如《民法典》《刑法》《证券法》）
						- **行政法规**：国务院制定的（比如《建设工程质量管理条例》）
					- **低于这个层级的，违反了也不当然导致合同无效**：
						违反部门规章（住建部、央行等部委出的规定）、地方性法规、地方政府规章的，合同不会直接无效，最多可能产生行政处罚，但交易本身仍受法律保护。 
				- 第二层限制：强制性规定还要分 效力性 和 管理性 
					- 效力性强制规定
						- 立法目的: 
						 直接禁止这个交易行为本身，保护的是国家利益、社会公共利益
						- 违反后的合同效力: 合同直接无效
						- 法考典型例子:
							买卖毒品 / 枪支、无资质的建设工程施工合同、必须招标却未招标的工程合同、非法集资借贷合同
							
					- 管理性强制规定
						- 管主体资格、管行政流程，不是禁止交易本身，只是规范市场秩序
						- **合同仍然有效**，违规方会受行政处罚
						- 公务员违规经商签订的合同、房屋租赁没办备案、公司超越经营范围签合同、普通商品没贴明码标价签
					
			 * 最后补充 “不违背公序良俗”：比如代孕合同、包养协议、赌债欠条，哪怕不违反具体法条，也因违背公共秩序、善良风俗而直接无效。

			 * 法考做题判断技巧：看这条规定是 “禁止你做这件事”，还是 “要求你做这件事之前先办手续 / 有资质”。前者是效力性，后者多是管理性。

- **三要件不满足 → 进入四级效力分析（无效 / 可撤销 / 效力待定）**，
	详见 [[合同效力分级]] + 📐 [[民法-合同-效力待定模型]] / [[民法-合同-合同可撤销模型]]。
	143 条是「有效」的标准，不满足的话，不是全部按无效处理，而是对应不同的效力瑕疵状态，这就是你之前学的效力分级体系：

	1. **不满足行为能力要求**：限民超能力 → 效力待定；无民 → 无效
	
	2. **不满足意思表示真实**：欺诈、胁迫、重大误解、显失公平 → 可撤销
	
	3. **违反效力性强制规定、违背公序良俗** → 无效
	
	4. **违反管理性强制规定、违反低层级规定** → 合同仍有效，不构成效力瑕疵

简单说，143 条是 “有效入口”，进不去的，就分流到无效、可撤销、效力待定三个瑕疵赛道里去。

#### **三例外 = 成立但未生效**

普通合同遵循「**成立即生效**」原则（《民法典》第 502 条第 1 款）。而以下三类属于法定例外：合同已经合法成立、对双方有形式拘束力（不得随意撕毁变更），但**主给付义务的履行效力尚未启动**，不能直接要求对方交房、付款、过户等核心义务，需满足对应条件后才正式生效。

| 例外          | 规则（逐字要点）                                                           | 条号        |
| ----------- | ------------------------------------------------------------------ | --------- |
| 附**生效条件**   | "附生效条件的民事法律行为，自**条件成就时**生效。"（首句"根据其性质不得附条件的除外"——身份行为如结婚 / 收养不得附条件） | **§158**  |
| 附**生效期限**   | "附生效期限的民事法律行为，自**期限届至时**生效。"（附终止期限自**期限届满时**失效；生效用"届至"、终止用"届满"）    | **§160**  |
| 需**批准（报批）** | "应当办理批准等手续的，依照其规定。未办理批准等手续影响合同生效的，**不影响合同中履行报批等义务条款以及相关条款的效力**。"   | **§502Ⅱ** |


##### 一、附生效条件（《民法典》第 158 条） -> 可能发生、也可能不发生

###### 1. 核心规则

当事人约定以**未来、不确定、合法的事实**作为合同生效的开关；该事实发生（条件成就）时，合同才正式生效。

- 例外：根据行为性质不得附条件的，不能附生效条件，典型如结婚、收养、离婚等身份行为 —— 身份关系的效力由法律强制规定，不允许当事人附加条件限制。
###### 2. 典型案例

- **正常情形**：甲与乙签订房屋租赁合同，约定「若甲的女儿 2027 年成功申请到国外大学，甲就将房屋出租给乙，月租 3000 元」。
    
    - 合同签订当日即**成立**，但未生效；
    - 女儿成功拿到录取通知书时，条件成就，合同正式**生效**，乙有权要求甲交付房屋。
    
- **违法 / 不可能条件**：约定「你帮我打伤竞争对手，我就给你 10 万报酬」—— 条件本身违法，合同直接无效；约定「如果明天太阳从西边升起，合同生效」—— 条件不可能实现，视为合同不生效。
###### 3. 法考考点

判断是否属于附条件，关键看事实是否具有**或然性**（可能发生、也可能不发生）；如果是必然发生的事实，不属于条件，而是期限。

###### 恶意拟制
- 核心规则

	仅适用于附条件合同，不适用于附期限合同，本质是对恶意行为的反向制裁：

	- 当事人**为自己的利益不正当阻止**条件成就 → 视为条件**已经成就**

	- 当事人**为自己的利益不正当促成**条件成就 → 视为条件**不成就**



> 🔑 **§159 恶意拟制（仅附条件，附期限不适用）**："当事人**为自己的利益不正当地阻止**条件成就的，视为条件**已经成就**；不正当地**促成**条件成就的，视为条件**不成就**。"——两个限定缺一不可（"为自己利益"+"不正当"）；"阻止→视为成就 / 促成→视为不成就"方向相反（反向拟制制裁恶意）。



##### 二、附生效期限（《民法典》第 160 条） -> 当事人约定以**未来必然到来的时间 / 事实**作为合同生效的开关

###### 1. 核心规则

当事人约定以**未来必然到来的时间 / 事实**作为合同生效的开关；期限届至时，合同正式生效。

- 对应概念：附终止期限的合同，期限届满时合同失效。
- 法定措辞区分：生效用「**届至**」，终止用「**届满**」，法考常在此设置用词陷阱。

###### 2. 与附生效条件的核心区别

| 类型    | 核心特征                     | 示例                              |
| :---- | :----------------------- | :------------------------------ |
| 附生效条件 | 事实**可能发生、也可能不发生**，具有不确定性 | 「明年考上研究生就租房」                    |
| 附生效期限 | 事实**必然会发生**，只是时间早晚不确定    | 「2027 年 1 月 1 日合同生效」「老人去世时赠与生效」 |

###### 3. 典型案例

甲公司与乙工厂签订原材料供货合同，约定「本合同自 2027 年 3 月 1 日起正式生效」。

- 2026 年 12 月双方签字盖章时，合同**成立**但未生效，双方均无需履行供货、付款义务；
- 2027 年 3 月 1 日期限届至，合同正式**生效**，双方开始按约定履行义务。

###### 4. 法考考点

附期限**不适用恶意拟制规则**（第 159 条）—— 期限是必然到来的，不存在 “不正当阻止 / 促成” 的空间，这是和附条件的高频辨析点。

##### 三、 需批准（报批）生效的合同（《民法典》第 502 条第 2 款）

这类合同双方签字就成立，但需要行政审批才正式生效，处于 “合法但暂时没启动履行” 的中间状态。核心铁则：**主给付义务（交房、过户、付款）未生效，但报批义务条款独立生效**。


####  **物权变动单独走【区分原则 §215】**

> **§215（逐字）**："当事人之间订立有关设立、变更、转让和消灭不动产物权的合同，除法律另有规定或者当事人另有约定外，**自合同成立时生效；未办理物权登记的,未交付物品，不影响合同效力**。"

- **两轨分离**：①债权合同（负担行为）自成立时生效；②物权变动（处分行为）依 **§209**（不动产登记生效）/ **§224**（动产交付生效）/ **§225**（特殊动产交付生效、登记对抗）。

- **"未登记 ≠ 合同未生效"**：登记是"**物权变动**"生效要件，**非"合同"生效要件**。一物二卖未过户，未登记的买受人不取得物权，但**合同有效、可主张违约**（请求交付 / 协助过户 / 赔偿）。

- **动产侧完整版**：普通动产**未交付**同样不影响合同效力（§224 交付是物权变动要件）；特殊动产（船 / 航 / 车）**未登记**亦不影响合同效力，仅**不得对抗善意第三人**（§225）。→ 详见 📐 [[民法-合同-一物多卖模型]] · [[民法-物权-动产交付模型]] · [[区分原则]]。

> ⚠️ **再次分线**：**批准走 §502、登记走 §215**。§502 只管"批准"手续、只字不提"登记 / 物权"；把"未登记不影响效力"挂到 §502 是错的。

### 兜底层（同模型收尾，📐 链接缔约过失模型，不展开重述） - 合同未成立/无效/被撤销

> 看到 “无效、撤销、不成立、不生效”→ 先想 §157 财产清算、赔信赖利益；
> 
> 看到 “合同有效、违约、履行不能”→ 先想违约责任、赔履行利益，清算不是必经步骤

| 合同状态               | 兜底责任                                                      | 条号                          |
| ------------------ | --------------------------------------------------------- | --------------------------- |
| **未成立 / 无效 / 被撤销** | **缔约过失责任**：赔**信赖利益**（**原则上不超**履行利益）；无效 / 被撤销再叠 §157 返还    | **§500**（§501 泄密）+ **§157** |
| **成立但未生效（报批）**     | **报批义务条款独立有效**：可请求继续履行报批义务 / 解除 + 赔偿；批准前不能直接诉请履行**主给付义务** | **§502Ⅱ** + **通则解释§12**     |
#### 第一类：合同未成立 / 无效 / 被撤销 → 缔约过失兜底
##### 1. 适用场景

合同从根源上就不具备有效效力：要么自始至终没成立，要么成立了但被认定无效、被撤销，最终自始没有法律约束力。

##### 责任核心：缔约过失责任 -> 信赖利益损失 + 财产清算

赔偿范围是**信赖利益损失**，也就是你因为相信合同能成立、能生效，白白支出的成本 —— 比如缔约差旅费、调研费、准备履行的材料费、已付款的利息等。

- 法定上限：赔偿原则上**不能超过履行利益**（即合同正常履行你能获得的收益），不能让你比合同履行了还赚得多。

##### 叠加规则：《民法典》§157 财产返还

合同无效、被撤销的，除了赔损失，必须先做**财产清算**：

- 因合同取得的财产，互相返还（比如付了钱退钱、拿了货退货）；
- 返还不了的折价补偿；
- 有过错的一方再按过错程度赔偿对方损失。

##### 补充：§501 泄密责任

缔约过程中知悉的商业秘密，无论合同最终成没成，都不得泄露或不正当使用；泄露造成损失的，同样按缔约过失责任赔偿。

#### 二、第二类：成立但未生效（报批类合同）→ 报批义务独立生效

**不止报批类**。《民法典》框架下，典型的「成立但未生效」合同共有三类，报批类只是其中之一，且是责任规则最特殊、法考考查最集中的一类
##### 三类「成立但未生效」合同
1. 附生效条件的合同（《民法典》第 158 条）
2. ### 附生效期限的合同（《民法典》第 160 条）
3. 需批准生效的合同（报批类，《民法典》第 502 条第 2 款）




> 💡 **通则解释§12 分层**：①不履行报批义务 → 请求继续履行 / 解除 +"违反报批义务的赔偿"；②判决履行后仍不履行 → 解除 +"**参照违约责任**"赔偿（标准升级、可含履行利益）；③批准前直接诉请履行主给付义务、经释明拒不变更诉请 → **驳回**（不影响另诉）；④已尽报批义务但机关不批 → 不担赔偿，但因**可归责迟延**致未获批 → 依 **§157** 处理。机制细节 → 📐 [[民法-合同-缔约过失责任模型]] / [[民法-合同-解除模型]]。

## 三、命题人最爱的陷阱（经对抗复核确认 · 含降权标注）

**真·高频（重点背）：**

1. **【最高频】价款 / 报酬非成立要件** —— "未约定价款"诱你答"不成立"。三要素只看**当事人 + 标的 + 数量**（通则解释§3），价款不明走 §510→§511 填补。
2. **【最高频】未登记 ≠ 合同未生效（§215）** —— 把"物权未变动"误读成"合同未生效"。登记是物权变动要件，非合同生效要件。**§215 管登记、§502 管批准，分属不同条文勿混。**
3. **【高频】附生效条件 / 期限：已成立但未生效（§158 / §160）** —— 经典"已成立未生效"；条件"成就" / 期限"届至"才生效。配套 §159 恶意拟制。
4. **【高频】成立时点谱系坑** —— "网页是要约还是要约邀请"（§491Ⅱ）/"签名盖章是'或'非'且'""要求'均'完成"（§490Ⅰ）。
5. **【高频·易忽略】未成立 / 未生效 ≠ 无责任** —— 未成立有缔约过失（§500）；成立未生效有报批义务条款独立有效（§502Ⅱ + 解释§12）。
6. **【高频】口头 / 无书面也能成立** —— 达成合意即成立，书面非一般成立要件；§490Ⅱ"履行治愈"再次印证。"没签合同"≠"没成立"。
7. **【双向陷阱】§490"签名 / 盖章 / 按指印"是"或"（任一），但"均"要求各方都完成** ——"或"针对方式、"均"针对主体。

**需降权（写但勿夸大）：**

8. **【降权】"成立时点四分法"** —— 助记法非法定术语，实际 ≥6 点；表述为"谱系 / 多分法"，勿锁死"四"而漏 §490Ⅰ后段、§490Ⅱ 治愈。
9. **【降权·相对低频】§491Ⅰ"信件 / 数据电文 + 要求签确认书 = 签确认书时成立"** —— 真考点但出题频率明显低于 §491Ⅱ 电子下单，价值主要在作为 §491Ⅱ 的对照区分项。

## 五、🎯 口诀

> **谈成是"成立"，算数才"生效"；成立看合意（人 / 标 / 数），生效看评价（§143 三要件）。**
> **成立三要素够就成立，价款不明不挡道（§510→§511）；没签字、没书面，履行了也算成立（§490 治愈）。**
> **一般握手即生效（§502），附条件 / 附期限 / 需批准才推迟；条件"成就"、期限"届至"、批准到位才算数。**
> **登记 / 交付动的是物权（§215 区分原则），碰不到合同效力——批准走 §502、登记走 §215，别混。**
> **未成立 / 无效 / 被撤销别忘缔约过失（§500），成立没生效还有报批条款独立有效（§502Ⅱ + 解释§12）。**
