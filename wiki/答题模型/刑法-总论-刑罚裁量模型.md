# 📐 刑罚的裁量 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑法法考教练。一看到"判几年、是不是累犯、自首还是坦白、漏罪怎么算"，绝大多数同学下意识就去比刑期长短、看认罪态度好不好。但命题人最爱在**前置条件**上挖坑——累犯的"执行完毕"、准自首的"异种罪行"、立功的"线索合法性"、数罪并罚的"判决宣告日"，全是一步错则满盘皆输的隐形开关。今天我们用**一套五步流水线**把"量刑情节"一次锁死：**判累犯 → 定减轻 → 辨自首坦白 → 认立功 → 算并罚**。

## 适用场景与解决问题

本模型解决刑法总论"刑罚裁量"（§61–§71）中六大高频判定与计算陷阱：累犯（普通/特别）的构成与排除、减轻处罚的降档限度与核准主体、一般自首与准自首的认定、坦白与自首的界限、立功与"如实供述义务"的划界、数罪并罚（漏罪/新罪）的计算顺序与上限。重点破解：

1. **累犯的"时间窗"与"刑种"**：普通累犯的"执行完毕/赦免后5年内"，特别累犯的"任何时候、三类罪可交叉"，以及考验期内、未成年、过失三大排除。
2. **减轻处罚的"降档"与"核准"**：减轻 vs 从轻的分界（破最低刑线），原则减一档，酌定减轻唯最高法核准。
3. **自首/准自首/坦白的"三岔口"**：主动投案 vs 被动到案；被羁押后供述未掌握罪行的"同种=坦白、异种=准自首"。
4. **立功的"功 vs 义务"**：提供基本信息是义务、带路指认抓获才是立功；非法手段取得的线索一票否决。
5. **数罪并罚的"两条算法"**：判决宣告前的罪（漏罪）先并后减，判决宣告后的罪（新罪）先减后并；35年线分20/25年封顶；刑种相遇的吸收与并科。

> **核心一句**：累犯故意有期五年内（特累三类不限时），减轻破线降一档（酌定专报最高法）；主动投案是自首，被动到案算坦白，羁押供述异种准自首、同种仍坦白；基本信息是义务、带路指认才立功（非法线索一律不算）；漏罪先并后减、新罪先减后并，不满卅五封二十、卅五以上封二五。

> 🔎 **法条已联网核实（2026-06-25，多源 CONFIRMED）**：§63/§65/§66/§67/§68/§69/§70/§71 全文经 国家法律法规数据库 flk.npc.gov.cn、最高检 spp.gov.cn、最高法公报 gongbao.court.gov.cn 逐条核实。
> ⚠️ **易记错点**：①§65 但书为"过失犯罪**和不满十八周岁的人犯罪**的除外"（刑修八增）；②"减轻处罚原则减一档、不跨档"是**《量刑指导意见》及实务规则，并非§63条文明文**（§63 只规定"在法定刑以下判处"+"经最高法核准酌定减轻"两款）；③§69 现行版本是**修八+修九叠加版**（含35年区间、有期徒刑/拘役/管制并存执行规则、附加刑并罚规则）。

## 一、 核心考情

- **频次研判**：刑罚裁量是刑法总论**头号大分值区**——客观题每年稳定 2-3 道单选/多选（约 4-6 分），主观题更是案情定性完成后"量刑收官之笔"的唯一法律依据（是否累犯、能否缓刑假释、自首立功如何并用、漏罪新罪刑期算到几年）。本板块综合定级 **★★★★★（顶级）**：累犯、自首、数罪并罚三个 ★★★★★ 考点扎堆于此。
- **命题核心**：
  1. **累犯（§65-66）**：普通累犯"故意+有期徒刑以上+5年内"三要件，特别累犯三类罪"任何时候、可交叉、不受限"；考验期内/未成年/过失三大排除；累犯一律不得缓刑、不得假释、应当从重。
  2. **减轻处罚（§63）**：减轻 vs 从轻的"最低刑线"；原则减一档；**酌定减轻唯最高人民法院核准**（高频陷阱：误为高级法院/检察院）。
  3. **自首·准自首·坦白（§67）**：主动/被动决定自首/坦白；羁押后供述"同种=坦白、异种=准自首"；坦白因如实供述避免特别严重后果可"减轻"（升级条款）。
  4. **立功（§68）**：提供同案犯基本信息=如实供述义务不算功；带路、指认、约出抓获才算立功；非法手段取得线索一律不算功；立功≠重大立功。
  5. **数罪并罚（§69-71）**：漏罪先并后减、新罪先减后并；35年线分20/25年封顶；徒刑吸收拘役、管制刑后并科。

## 三、 五大核心法理与命题陷阱拆解

### 1. 累犯：普通累犯 vs 特别累犯（§65-66）

| 要素 | 普通累犯（§65） | 特别累犯（§66） |
|---|---|---|
| **罪过** | 前后罪**均为故意**（过失除外） | 前后罪均属三类罪即可 |
| **罪名/类型** | 任何犯罪，**不要求同类** | **危害国家安全 / 恐怖活动 / 黑社会性质组织**三类，**可交叉** |
| **刑度** | 前罪被判、后罪应判**有期徒刑以上** | **不限刑度** |
| **时间窗** | 后罪在前罪刑罚**执行完毕或赦免后5年内**（假释的从**假释期满之日**起算5年） | **任何时候**再犯均构成 |
| **排除** | ①考验期内（未"执行完毕"）②不满18周岁所犯③过失犯罪 | 仅"三类罪之外"才排除 |
| **后果** | 应当从重、**不得缓刑、不得假释** | 同上 |

- **⚠️ 雷区一·"执行完毕"≠"考验期内"**：缓刑考验期内、假释考验期内、暂予监外执行期间再犯新罪，**前罪尚未"执行完毕"，不构成累犯**，应撤销缓刑/假释并数罪并罚。缓刑考验期满后5年内再犯——**仍不构成**（缓刑期满意味"不再执行"，非"执行完毕"）；假释考验期满后5年内再犯——**构成累犯**（假释期满视为执行完毕，从假释期满之日起算）。
- **⚠️ 雷区二·未成年排除看"前罪或后罪任一"**：前罪在不满18周岁时所犯，即排除累犯，哪怕后罪时已成年。
- **⚠️ 雷区三·特别累犯可"交叉"**：前黑社会、后恐怖活动也构成，且无5年与有期徒刑限制。

### 2. 减轻处罚：降档限度与核准主体（§63）

- **减轻 vs 从轻的分界线 = 法定最低刑**：判到"等于最低刑"只是**从轻**；必须**突破最低刑往下**判才是**减轻**。例：法定刑"3年以上10年以下"，判3年=从轻，判2年=减轻。
- **降档限度**：有法定减轻情节的，**原则上只减一档**（下一个量刑幅度内），不跨档；仅在有免除处罚情节或两个以上减轻情节等特殊情形才可减两档。
  > ⚠️ **"减一档/不跨档"是《关于常见犯罪的量刑指导意见》及实务规则，不是§63条文原文**。§63 只有两款：①有法定减轻情节的，应当在法定刑以下判处；②无法定减轻情节但案件特殊的，经**最高人民法院核准**也可在法定刑以下判处。
- **⚠️ 雷区·酌定减轻"唯最高法核准"**：无法定减轻情节而要在法定刑以下判处的（酌定减轻），核准权**专属最高人民法院**——不是中级、不是高级法院，更不是检察院。口诀：**酌定减轻，唯最高法**。

### 3. 自首 · 准自首 · 坦白：三岔口（§67 + 法释〔1998〕8号）

```
                          行为人如实供述自己罪行
                                   │
              ┌────────────────────┴────────────────────┐
         主动投案？                                  被动到案/已被采取强制措施
              │ 是                                          │
        【一般自首 §67Ⅰ】                          供述司法机关"还未掌握"的本人其他罪行？
     自动投案+如实供述主要犯罪事实              ┌─────────┴─────────┐
     (亲友规劝陪同=视为自动投案)              异种罪行              同种罪行 / 已掌握罪行
     可从轻/减轻，较轻可免除               【准自首 §67Ⅱ】        【坦白 §67Ⅲ】
                                          以自首论               可以从轻；
                                                              同种较重罪行可酌情从轻；
                                                              因如实供述避免特别严重
                                                              后果→可以"减轻"
```

- **自首 vs 坦白看"投案主动性"**：自动投案+如实供述=自首；被动到案（传唤、抓获、已被强制措施）+如实供述=坦白。
- **准自首 vs 坦白看"是否同种罪行"**：被羁押/服刑期间供述司法机关**未掌握**的罪行——**异种=准自首（以自首论）**；**同种=坦白**（如实供述同种较重罪行可酌情从轻）。这是命题人最爱的"同种/异种"对照陷阱（[[刑法-总论-单选-29 · 准自首之供述未掌握的异种罪行|29异种]] ⇄ [[刑法-总论-单选-34 · 羁押期间供述未掌握同种罪行|34同种]]）。
- **如实供述的颗粒度**：须供述"主要犯罪事实"；共同犯罪中**主犯须供述所知的全案共同犯罪事实**，仅供述自己行为、隐瞒同案犯的，不算如实供述。
- **⚠️ 坦白"升级条款"**：一般坦白只"可以从轻"；唯有**因如实供述避免特别严重后果发生**（如供述人质藏匿地点救活人质）才"可以减轻"。注意：救本案被害人是**供述义务**，不是立功。

### 4. 立功：与"如实供述义务"划界（§68 + 法释〔1998〕8号 + 法发〔2010〕60号）

| 情形 | 定性 | 依据 |
|---|---|---|
| 提供同案犯**姓名、住址、体貌特征**等基本信息 | **如实供述义务，不算立功** | 法发〔2010〕60号 |
| 按安排将同案犯**约至指定地点**、**当场指认辨认**、**带领侦查人员抓获** | **成立立功**（协助抓捕，对象**含同案犯**） | 法释〔1998〕8号§5、法发〔2010〕60号 |
| 揭发**他人**犯罪查证属实 / 提供重要线索侦破他案 | 成立立功 | §68 |
| 以**贿买、暴力、胁迫**或窃取、串通、本人非法获取的线索揭发 | **一律不算立功**（线索来源不合法） | 法发〔2010〕60号 |

- **功 vs 义务**：在共同犯罪中说出同案犯是谁、在哪，本就是"如实供述（含所知同案犯）"的义务；只有付出**额外的协助抓捕行为**（约出、指认、带路）才升格为立功。
- **立功 ≠ 重大立功**：重大立功须被检举/抓获对象**可能判处无期徒刑以上，或案件在本省、全国有较大影响**（法释〔1998〕8号§7）。题干没给这个标准，就不能拔高为重大立功。

### 5. 数罪并罚：先并后减 vs 先减后并（§69-71）

```
                              判断后一罪行实施于"前罪判决宣告日"哪一侧
                                              │
              ┌───────────────────────────────┴───────────────────────────────┐
        判决宣告【以前】（漏罪 §70）                              判决宣告【以后】（新罪 §71）
              │                                                       │
        【先并后减】                                             【先减后并】
   ① 前罪全部原判刑 + 漏罪刑，按§69并罚                    ① 前罪原判刑 − 已执行 = 余刑
   ② 再减去已经执行的刑期                                  ② 余刑 + 新罪刑，按§69并罚
   （对被告人相对有利）                                    （已执行不退还，对被告人较严厉）
```

- **§69 限制加重上限（数字陷阱）**：在"总和刑期以下、数刑中最高刑期以上"酌定；**总和刑期不满35年→有期徒刑最高20年；总和刑期35年以上（含35年）→最高25年**。35年是分界线。
- **刑种相遇（修九）**：有期徒刑+拘役→**执行有期徒刑（拘役被吸收）**；有期徒刑/拘役+管制→**有期徒刑、拘役执行完毕后，管制仍须执行（并科）**；死刑/无期→**吸收**其他主刑。
- **附加刑（修八）**：仍须执行，**种类相同合并、种类不同分别**执行。

## 四、 万能解题五步

> 一道刑罚裁量题，绝大多数同学拿到手就急着比刑期、看态度。正确姿势是按下面**五步流水线**逐关过筛，每一关都先卡"前置开关"，再下结论。

### 第一步：判累犯

> **教练提示**：一看"以前判过、现在又犯"，绝大多数同学立刻喊"累犯、从重"。但命题人最爱在"**前罪到底执行完了没**"上挖坑——人还在假释考验期里、前罪是十六岁犯的、前罪是过失，统统**不算累犯**。

> # 故意·有期·五年内，三类罪不限时；考验期内不算数

- **普通累犯**：前后罪**均故意 + 均有期徒刑以上 + 后罪在前罪执行完毕/赦免后5年内**（假释从期满之日起算）。
- **特别累犯**：前后罪均属**国安·恐怖·黑社会**三类（可交叉）→ **任何时候**都构成，不受5年与刑度限制。
- **三大排除**：①在**考验期内**犯新罪（前罪未执行完毕）②前罪/后罪在**不满18周岁**时所犯③**过失**犯罪。
- **后果**：累犯**应当从重、不得缓刑、不得假释**。

#### 大白话讲解

##### 💰 完整实案：把"执行完毕"这个开关钉死

> **案情**：老王 2015 年因故意伤害罪被判**有期徒刑5年**，2018 年获**假释**，假释考验期 2 年。**2019 年（考验期内）**他又故意抢劫，应判**有期徒刑10年**。检察官说："前罪故意、后罪故意，都判有期徒刑以上，间隔也没超5年，妥妥累犯！"

1. **查时间窗开关**：累犯要求后罪发生在前罪"**刑罚执行完毕或赦免以后**"。老王此刻还在**假释考验期内**——原判5年的刑罚附条件**尚未执行完毕**。
2. **涵摄**：前置开关没合上 → **不构成累犯**。应当**撤销假释**，把前罪没执行完的部分与新罪**数罪并罚**（§86）。
3. **结论**：不是累犯！👉 检察官那句"没超5年"是干扰项——**考验期内压根谈不上"执行完毕"，5年也无从起算**。
4. **变式对照**：若老王是 2018 年**假释期满**、2021 年（期满后3年）再故意犯应判有期徒刑之罪 → 这次**构成累犯**（假释期满视为执行完毕，从期满之日起算5年内）。

> **🤝 未成年小例**：小李 17 岁犯故意杀人判6年，刑满后第3年（已成年）又故意伤害判3年——**不构成累犯**，因为**前罪是不满18周岁时犯的**（§65但书），后罪成年也不救场。

#### 一句话闭环记忆

> **第一步先卡累犯的"前置开关"：执行完毕了吗？是故意吗？满18吗？**
>
> 🎯 **一眼判**：**考验期内→不算**（撤销缓刑/假释并罚）；**未成年/过失→不算**；**普通累犯=故意·有期·5年内**；**特别累犯=三类罪·任何时候·可交叉**；构成则**从重·禁缓·禁假**。

### 第二步：定减轻处罚

> **教练提示**：一看"有减轻情节"，绝大多数同学以为可以在法定刑以下"想判多低判多低"。但命题人专卡两点——**判到最低刑只是"从轻"不是"减轻"**，以及**没有法定情节想减轻，必须最高法点头**。

> # 破线才叫减轻，原则降一档，酌定专报最高法

- **减轻 vs 从轻**：必须**突破法定最低刑往下**判才是减轻；判到等于最低刑只是从轻。
- **降档**：原则**只减一档**（《量刑指导意见》/实务），不跨档。
- **酌定减轻**：无法定减轻情节而要在法定刑以下判，**唯最高人民法院核准**。

#### 大白话讲解

##### 💰 完整实案：把"最低刑线"画出来

> **案情**：某罪法定刑"**3年以上10年以下有期徒刑**"。被告人戊有**一个法定减轻情节**。法院在 A.判3年 / B.判2年 / C.判8年 三个选项里挑。

1. **画线**：法定**最低刑 = 3年**，这就是"从轻"与"减轻"的分界线。
2. **涵摄**：判3年=踩在最低刑线上=**从轻**（不是减轻）；判8年=幅度内偏上=正常/从重；**只有判2年（低于3年）突破了最低刑线，才是减轻**。
3. **结论**：符合减轻处罚的是**判2年**。👉 口诀：**踩线是从轻，破线才减轻**。
4. **核准变式**：若戊**没有任何法定减轻情节**，只是案件特殊，法院想判到3年以下 → 必须**层报最高人民法院核准**（§63Ⅱ），中级、高级法院和检察院都无权拍板。

#### 一句话闭环记忆

> 🎯 **一眼判**：判=最低刑→**从轻**；判<最低刑→**减轻**；减轻**原则降一档**；**没有法定情节**想减轻→**唯最高法核准**。

### 第三步：辨自首 · 准自首 · 坦白

> **教练提示**：一看"主动交代了"，绝大多数同学张口就是"自首、从轻"。但命题人最爱在两道暗门设伏——**是主动投案还是被抓来的**（决定自首/坦白），以及**被关起来后供述的是同种还是异种罪**（决定坦白/准自首）。

> # 主动投案是自首，被动到案算坦白；羁押供述异种准自首、同种仍坦白

- **自首 vs 坦白**：自动投案=自首；被动到案=坦白。（亲友**规劝陪同**投案=视为自动投案；亲友**捆绑送去**=不算自动投案，但可参照从轻。）
- **准自首 vs 坦白**：被采取强制措施/服刑期间，供述司法机关**未掌握**的**异种**罪行=准自首；**同种**罪行=坦白。
- **坦白升级**：因如实供述**避免特别严重后果**→可以**减轻**。

#### 大白话讲解

##### 🔍 三岔口对照表

| 情形 | 定性 | 从宽 |
|---|---|---|
| 自动投案 + 如实供述 | **一般自首** | 可从轻/减轻，较轻可免除 |
| 被采取强制措施后供述**未掌握·异种**罪 | **准自首** | 以自首论 |
| 被动到案 + 如实供述已掌握/**同种**罪 | **坦白** | 可以从轻（同种较重可酌情从轻） |
| 坦白且**避免特别严重后果** | **坦白·升级** | 可以**减轻** |

##### 💰 完整实案：同一被告，异种 vs 同种两条路

> **案情**：甲因**盗窃**被刑事拘留（已被采取强制措施）。羁押期间他主动交代了办案机关**还没掌握**的另一桩事——

- **情形①（异种）**：交代的是一起**抢劫**。抢劫与盗窃**不同种** → **准自首**（以自首论，§67Ⅱ＋法释〔1998〕8号§2）。注意：他已被拘留，不可能"自动投案"，所以不是一般自首。
- **情形②（同种）**：交代的是另一起**盗窃**。与已掌握的盗窃**同种** → 不成立准自首，只成立**坦白**（同种较重的可酌情从轻）。

> **🆘 升级小例**：戊绑架后被抓获（被动到案=坦白），归案时人质生命垂危，他如实供述并说出藏匿地点，警方据此**救活人质**——因如实供述**避免了人质死亡这一特别严重后果**，可以**减轻处罚**（§67Ⅲ后段）。救本案被害人是**供述义务**，不升格为立功。

#### 一句话闭环记忆

> 🎯 **一眼判**：**主动投案=自首，被动到案=坦白**；羁押后供述未掌握罪→**异种=准自首、同种=坦白**；坦白**避免特别严重后果→减轻**；亲友**规劝陪同=自动投案**。

### 第四步：认立功

> **教练提示**：一看"帮警察抓到了同伙"，绝大多数同学立刻判"立功"。但命题人专卡——**只报了同伙的名字住址，那是你本来就该交代的义务，不算功**；而且**用暴力胁迫套来的线索，再准也一票否决**。

> # 基本信息是义务，带路指认才立功，非法线索一律不算

- **不算立功**：提供同案犯**姓名、住址、体貌特征**等基本信息（属如实供述义务）。
- **算立功**：按安排**约出**、**当场指认辨认**、**带领抓获**其他犯罪嫌疑人（**含同案犯**）；揭发**他人**犯罪查证属实；提供线索侦破他案。
- **一票否决**：以**贿买、暴力、胁迫、窃取、串通**等非法手段取得的线索揭发——**不算立功**。
- **立功 ≠ 重大立功**：重大须达"可能判无期徒刑以上 / 案件有较大影响"。

#### 大白话讲解

##### 💰 完整实案：同样涉及同案犯，三种结局

> **案情**：庚、壬、子三人分别被抓后都"配合"了办案机关——

1. **庚**：只**报出**同案犯辛的真实姓名、住址、体貌特征，警方据此抓获辛 → **不算立功**（这是如实供述义务，法发〔2010〕60号）。
2. **壬**：按警方安排**当场指认**并**带领侦查人员**找到隐蔽出租屋，**抓获**在逃同案犯癸 → **成立立功**（协助抓捕，对象含同案犯）。但题干没说癸要判无期以上，**不能拔高为重大立功**。
3. **子**：羁押中用**暴力胁迫**同监室人员套出他人重大贩毒线索后检举，查证属实、案件侦破 → **不算立功**（线索来源非法，一票否决）。

👉 **一正两反看死**：付出**额外协助抓捕**（带路/指认/约出）才是功；只**报信息**是义务；**手段违法**则再准也不算。

#### 一句话闭环记忆

> 🎯 **一眼判**：**报基本信息=义务（不算功）**；**约出/指认/带路抓获=立功（含同案犯）**；**非法手段取得线索=一律不算**；**立功≠重大立功**（重大看无期以上/重大影响）。

### 第五步：算数罪并罚

> **教练提示**：一看"又犯了一个罪、还有个罪没判"，绝大多数同学随手就把刑期一加完事。但命题人最爱在"**漏罪还是新罪**"上挖坑——分水岭只有一条：**这桩罪行发生在前罪判决宣告之前，还是之后**。一字之差，算法颠倒。

> # 判决前漏罪先并后减，判决后新罪先减后并；不满卅五封二十、卅五以上封二五

- **看分水岭**：后一罪行实施于**前罪判决宣告日**哪一侧。
- **漏罪（判决前·§70）**：**先并后减**——前罪**全部原判刑**+漏罪刑按§69并罚，再减已执行刑期。
- **新罪（判决后·§71）**：**先减后并**——前罪原判刑**减已执行=余刑**，余刑+新罪刑按§69并罚。
- **上限**：总和刑期**不满35年→20年封顶**；**35年以上→25年封顶**。
- **刑种**：徒刑**吸收**拘役；管制在徒刑/拘役执行完后**并科续执行**；死刑/无期**吸收**。

#### 大白话讲解

##### 💰 完整实案A：漏罪——先并后减

> **案情**：甲因**盗窃**判**有期徒刑5年**，送监**执行了2年**时，发现他在**该盗窃判决宣告之前**还抢劫过（没判），抢劫**判8年**。

1. **定性**：抢劫发生在盗窃**判决宣告之前** → **漏罪**，走§70**先并后减**。
2. **先并**：前罪**全部5年**+漏罪8年，按§69在"总和13年以下、最高刑8年以上"即 **8～13年**酌定（13<35，不触20年顶），设法院定**11年**。
3. **后减**：11年 − 已执行**2年** = **还需执行9年**。
4. **避坑**：若误用"余刑3年+8年"那是新罪的先减后并；若直接"5+8=13再减2=11"那是把限制加重写成了相加——都错。

##### 💰 完整实案B：新罪——先减后并

> **案情**：乙因**故意伤害**判**有期徒刑10年**，**执行4年**后在**监狱里**又伤人，新罪**判6年**。

1. **定性**：新罪发生在前罪**判决宣告之后** → **新罪**，走§71**先减后并**。
2. **先减**：前罪10年 − 已执行4年 = **余刑6年**。
3. **后并**：余刑6年+新罪6年，按§69在 **6～12年**酌定，设定**10年**。
4. **补充**：狱内又犯通常还构成**累犯**应从重（呼应第一步），但本题只问并罚方法。

##### 🔢 实案C：上限——35年这条线

> 丙判决宣告前犯三罪：**15+12+10**。总和=**37年≥35年** → 有期徒刑**最高25年**（在最高刑15年以上、25年以下定）。若三罪是12+11+10=33年（<35）→ 封顶**20年**。

##### ⚖️ 实案D：刑种相遇——吸收与并科

> 丁判决宣告前犯三罪：有期徒刑3年 + 拘役5个月 + 管制2年 → **拘役被有期徒刑吸收（不执行）**；**管制在有期徒刑执行完毕后仍须执行**。最终：执行**有期徒刑3年，刑满再执行管制2年**。

#### 一句话闭环记忆

> 🎯 **一眼判**：分水岭看**前罪判决宣告日**——**判决前=漏罪=先并后减（并前罪全刑）**；**判决后=新罪=先减后并（并前罪余刑）**；**不满35封20、35以上封25**；**徒刑吸拘役、管制刑后补**。

| 步 | 干什么 | 🎯 一眼判 |
|---|---|---|
| **一 判累犯** | 普通/特别累犯+排除 | 考验期内/未成年/过失**不算**；普通=**故意·有期·5年内**、特别=**三类罪·任何时候·可交叉**；构成则**从重·禁缓·禁假** |

## 五、 案例演练

### 1. 累犯·假释考验期排除案（[[刑法-总论-单选-23 · 累犯之假释考验期内犯新罪|单选-23]]）
- **案情**：甲 2015 年故意伤害判有期徒刑5年，2018 年假释（考验期2年），2019 年考验期内又故意抢劫应判10年。
- **模型分析**：第一步查"执行完毕"开关——假释考验期内原判刑罚未执行完毕，不满足§65"执行完毕或赦免后"要件 → **不构成累犯**，应撤销假释、数罪并罚（§86）。"没超5年"是干扰项。

### 2. 准自首·异种 vs 坦白·同种对照案（[[刑法-总论-单选-29 · 准自首之供述未掌握的异种罪行|单选-29]] / [[刑法-总论-单选-34 · 羁押期间供述未掌握同种罪行|单选-34]]）
- **案情**：甲因盗窃被刑事拘留，羁押期间交代办案机关未掌握的另一罪。
- **模型分析**：第三步辨准自首/坦白——已被强制措施排除"一般自首"；供述的若是**抢劫（异种）→准自首**，若是**另一盗窃（同种）→坦白**（同种较重可酌情从轻）。试金石是"是否同种罪行"。

### 3. 立功·协助抓捕 vs 如实供述义务案（[[刑法-总论-单选-35 · 提供同案犯基本信息不构成立功|单选-35]] / [[刑法-总论-单选-36 · 带领抓获同案犯构成立功|单选-36]]）
- **案情**：庚仅提供同案犯姓名住址体貌；壬当场指认并带领侦查人员抓获在逃同案犯。
- **模型分析**：第四步分"功/义务"——庚=如实供述义务**不算立功**；壬付出额外协助抓捕（指认+带路抓获）**成立立功**（对象含同案犯），但无"无期以上/重大影响"标准，不拔高为重大立功。

### 4. 数罪并罚·漏罪 vs 新罪计算案（[[刑法-总论-单选-38 · 数罪并罚之漏罪先并后减|单选-38]] / [[刑法-总论-单选-39 · 数罪并罚之新罪先减后并|单选-39]]）
- **案情**：甲盗窃判5年执行2年发现判决前的抢劫（漏罪，判8年）；乙故意伤害判10年执行4年后狱内又伤人（新罪，判6年）。
- **模型分析**：第五步看判决宣告日——漏罪走**先并后减**（前罪全刑5年+8年并罚后减2年=9年）；新罪走**先减后并**（10−4=余刑6年，再与6年并罚）。算法因"判决前/后"而颠倒。
