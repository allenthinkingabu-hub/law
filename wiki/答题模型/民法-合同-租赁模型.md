# 📐 租赁合同 · 答题模型（六板块：形式期限 → 转租 → 买卖不破 → 优先购买权 → 多重租赁 → 维修义务）

> 租赁题不是线性推理，而是**先识别题眼落在哪个板块，再套对应规则**。四个板块各有固定陷阱。
> **姊妹 / 概念** → 概念页 [[租赁合同]] · [[买卖合同]]（买卖不破租赁）· [[融资租赁合同]]（特殊租赁）。
> **适用真题**：[[典型合同-多选-05|C2-多选-05·形式+转租]] · [[典型合同-单选-09|C2-单选-09·擅自转租]] · [[典型合同-单选-25|C2-单选-25·维修义务]] · [[典型合同-单选-26|C2-单选-26·侵害优购]] · [[典型合同-单选-27|C2-单选-27·优购但买卖有效]] · [[典型合同-单选-28|C2-单选-28·一房二租]] · [[典型合同-多选-25|C2-多选-25·买卖不破前提]] · [[典型合同-多选-27|C2-多选-27·擅自转租+买卖不破]] · [[典型合同-多选-31|C2-多选-31·多重租赁]]
>
> 🔎 **法条已联网核实（2026-06-11）**：§705 / §707 / §716 / §718 / §725 / §726 / §728 / §730 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml) + [最高法公报民法典](http://gongbao.court.gov.cn/Details/74143ea5b6d1d47f82d6759fc6ef17.html)逐字核对。
> ⚠️ **重大新旧法变化（必考）**：§707 把旧《合同法》§215"6 个月以上未书面 → **一律**视为不定期"改成"未书面、**且无法确定租赁期限**的，才视为不定期"——**口头但期限明确的，按定期算、不是不定期**。

## 一、核心考情
- **频率**：租赁是典型合同最大户之一，★★★★，单选 / 多选常考，主观题房产纠纷必涉；常与抵押、所有权变动、相对性串考。
- **命题核心**：把四个板块的固定陷阱换皮考——形式（口头 / 不定期）、转租（经同意 / 擅自 / 相对性）、买卖不破（占有前提）、优先购买权（同等条件 / 15 日 / 侵害后果）。
- **六大必考点**：①形式与期限 ②转租 ③买卖不破租赁 ④优先购买权 ⑤多重租赁履行顺序 ⑥出租人维修义务。

## 二、万能六板块模型（按题眼对号入座）

### 板块一：形式与期限（§707 + §705 + §730）

**第 0 步 · 先记后果**（判错就全反）：**定期**＝期限内双方都**不能随便解除**、要守约到期；**不定期**＝**任何一方随时可解除**，提前合理期限通知即可（§730）。所以"定期 / 不定期"真正决定的是"**能不能随时收房 / 退租**"。

**第 1 步 · 一句话判断：租期能不能"定下来"？**
- **能定**（"租 2 年""租到 2026 年底"）→ **定期**。
- **定不下来**（没谈期限 / "长期""先住着再说"）→ **不定期**。

**第 2 步 · "书面形式"只是 ≥6 个月租赁的一道附加关卡（§707），别拿它当主标准**：

| | 旧《合同法》§215 | 现行 民法典 §707 |
|---|---|---|
| 何时打成不定期 | ≥6 月 **且 没签书面** | ≥6 月 **且 没签书面 且 期限定不下来** |

⚠️ **新旧法分水岭（必考）**：新法多加了"**且期限定不下来**"——所以**口头但期限明确**（双方都认租 2 年）的，**仍按定期算**，不再像旧法那样"只要没书面就一律不定期"。

**期限上限 20 年（§705）**：超过部分无效；到期可续订，续订期自续订之日起也不超过 20 年。

**老王小李例子**
- ✅ 定期 / 不定期：老王口头租门面给小李"**2 年**"、双方都认 → 现行法**定期 2 年**（这 2 年老王不能随便赶人）；**旧法反而打成不定期**（老王随时能收）——这正是考点。
- ✅ 不定期：老王只说"**你先住着、住到啥时候再说**" → 期限定不下来 → **不定期**，谁都可随时解除（提前通知）。
- ✅ 20 年上限：约定租 **30 年** → 只有 **20 年**有效，超出部分无效。

### 板块二：转租（§716 / §718 / §719）
**铁则**：
- **经同意转租**：转租有效、原租赁继续有效；**次承租人造成租赁物损害，由承租人对出租人负责**（§716）。
- **擅自转租**（未经同意）：出租人**可解除合同**（§716）；但出租人**知道 / 应知转租满 6 个月未异议 → 视为同意**（§718）。
- **相对性**：出租人与次承租人**无合同关系** → 不能要次承租人"违约"，但可要求**腾退** / 基于**侵权**；次承租人可**代承租人付租金**抵充（§719）。

**老王小李例子**（= [[典型合同-多选-05|多选-05]] / [[典型合同-单选-09|单选-09]]）
- 小李**经同意**转租给小张，小张拆墙 → 老王找**小李**赔（§716），**不能**找小张"违约"（无合同，可侵权 / 腾退）。
- 小李**擅自**转租 → 老王可解约；但老王知道后**半年没吭声** → 视为同意（§718）。

### 板块三：买卖不破租赁（§725 + §405 抵押对照）
**铁则**：租赁物在**承租人按租赁合同占有期间**所有权变动的，**不影响租赁合同**（§725）——买受人成为新出租人，租约继续，不能赶走承租人。
- **核心前提**：承租人**已先占有**（且租赁先于所有权变动成立）；**未占有 → 不适用**。
- **不破"租赁"≠不破"抵押"**（比抵押权与租赁占有谁先设立）：**先租后抵**（抵押设立前已出租**并占有**）→ 租赁**不受抵押影响**（**§405**）；**先抵后租** → 在后的租赁**不能对抗**在先抵押权（抵押权优先，拍卖后租约对买受人不生效）。

**老王小李例子**（= [[典型合同-多选-25|多选-25]] / 27）
- 小李已租住并**入住**老王的房，老王把房卖给老张 → 租约对老张**继续有效**，老张不能赶小李。
- 小李签了租约**还没入住**房就被卖 → 不满足"占有"前提，**不破**。
- **先租后抵**（租赁赢）：小李**先租住并入住**、老王**之后**才把房抵押给银行 → 银行拍卖给老张，小李租赁**不受抵押影响**、继续有效（§405），老张不能赶小李。
- **先抵后租**（抵押赢）：老王**先抵押**给银行、**后租**给小李 → 银行实现抵押权拍卖时，小李租赁**不能对抗**，租约对买受人老张不生效，小李要搬（可找老王赔）。

### 板块四：承租人优先购买权（§726 / §728）
**铁则**：
- 出租人卖租赁**房屋**，应在**出卖前合理期限**通知承租人，承租人**同等条件**优先购买（§726）。
- **15 日**：通知后承租人 **15 日内未明确表示购买 → 视为放弃**（§726 Ⅱ）。
- **两类例外**（承租人优购**让位**）：①房屋**按份共有人**行使优先购买 ②出租人卖给**近亲属**（§726）。
- **侵害后果**：未通知等妨害优购 → 承租人可请求**赔偿损失**；但**出租人与第三人的买卖合同有效**（§728）——**拿不回房、只能要赔偿**。
- **通知 ≠ 征得同意**：优购权是"同等条件**优先**"，**不是否决权**——出租人只须**通知**，无须经承租人**同意**（[[典型合同-单选-27|单选-27]] 的 D 陷阱）。
- **不涉善意取得**：出租人是所有权人、**有权处分**，买受人系**正常继受取得**，与"善意取得"（治**无权**处分）无关（[[典型合同-单选-27|单选-27]] 的 B 陷阱）。

**老王小李例子**（= [[典型合同-单选-26|单选-26]] / 27）
- 老王卖房没通知租户小李、直接卖给老张 → 小李**不能**主张老王老张的买卖无效 / 撤销（**买卖有效**，§728），只能找**老王赔偿**。
- 老王把房卖给**自己儿子**（近亲属）→ 小李优购权**让位**，无权主张。

### 板块五：多重租赁（一房数租）履行顺序（城镇房屋租赁解释 §5）

**铁则**：出租人就**同一房屋**订立**数份租赁合同**、合同都有效、承租人都要求履行时，按顺序定**谁能实际承租**（[城镇房屋租赁解释（2020 修正）**§5**](https://www.waizi.org.cn/doc/98375.html)）：
> **① 已合法占有 ＞ ② 已办理登记备案 ＞ ③ 合同成立在先。**
- **备案非生效要件**：未办登记备案**不影响租赁合同效力**——备案只是**行政管理手续**，合同**自成立即生效**（§502）；它在多重租赁里仅是**第二顺位**的加分项。
- 没抢到房的承租人：只能向**出租人**主张**违约责任**（解除 + 赔偿，§577/§711），**不能**从已占有的承租人处夺房。
- 🆚 **对比 [[民法-合同-一物多卖模型|一物多卖]]（买卖版）**：买卖**转移物权**，看**物权归属**（动产交付 / 不动产登记定所有权）；租赁**不转移物权**，只比**谁能实际用**——顺位是**占有 ＞ 备案 ＞ 在先**，**别套买卖的"登记优先"**。

**老王小李例子**（= [[典型合同-多选-31|多选-31]] / [[典型合同-单选-28|单选-28]]）
- 老王把同一套房先租给小李（已入住**占有**）、又租给小张（办了**备案**）→ **小李赢**（占有 ＞ 备案）；小张只能找老王违约赔偿。
- ⚠️ 小张"我备了案所以优先" → 错，**占有顺位高于备案**。
- ⚠️ 小李"我签得早所以优先" → **理由错**：小李赢是因为**已占有**，"成立在先"只是**第三顺位**。

### 板块六：出租人维修义务（§712 / §713）

**铁则**：
- **义务归属（§712）**：租赁物维修义务**法定在出租人**——**当事人另有约定的除外**（可约定由承租人修）。
- **自行维修求偿（§713 Ⅰ）**：承租人请求出租人在**合理期限**内维修，出租人不修 → 承租人**可自行维修、费用由出租人负担**；维修**影响使用**的，相应**减租 / 延长租期**。
- **承租人过错例外（§713 Ⅱ）**：因**承租人过错**致需维修的 → 出租人**不负**维修义务（承租人自担）。
- 🪤 **第三人致损不转嫁**：第三人（如肇事者）损坏租赁物，**不改变出租人对承租人的维修义务**；出租人**先修**，再**向第三人追偿**（追偿是出租人与第三人的事，合同相对性 + §1165）。

**老王小李例子**（= [[典型合同-单选-25|单选-25]]）
- 老王（出租人）租房给小李，玻璃墙被**逃逸司机**撞坏 → 维修义务仍在**老王**（§712）；老王拒修，小李催告后**自行花 1 万修**，这 1 万由**老王**负担（§713 Ⅰ），老王修后可找司机追偿，但**不能转嫁给小李**。
- 🆚 反例：若是**小李自己**装修施工把墙砸坏（承租人过错）→ 老王**不负**维修义务，小李自担（§713 Ⅱ）。

## 三、命题人最爱的 8 个陷阱
1. **"口头租 6 个月以上一律不定期"** —— 错！**新法§707 要"无法确定期限"才不定期**；期限明确的口头租按**定期**算（重大新旧法陷阱，[[典型合同-多选-05|多选-05]] 的 A）。
2. **"擅自转租后出租人可找次承租人要租金 / 违约"** —— 错！**相对性**，出租人对次承租人**无合同请求权**（可腾退 / 侵权）。
3. **"买卖不破租赁，没占有也能对抗 / 还能破抵押"** —— 错！前提是承租人**已占有**（§725）；**先抵后租不破抵押**（§405）。
4. **"侵害优先购买权 → 买卖合同无效 / 可撤销"** —— 错！**买卖有效**，承租人只能要**赔偿**（§728）。
5. **"优先购买权随时能行使"** —— 错！通知后 **15 日**不表示视为放弃；**近亲属 / 按份共有人**例外让位。
6. **"租赁约定 30 年全有效"** —— 错！**超 20 年部分无效**（§705）。
7. **多重租赁误以为"备案 / 成立在先"优先** —— 错！顺位是**已占有 ＞ 已备案 ＞ 成立在先**（租赁解释 §5）；且**未备案不影响合同效力**（[[典型合同-多选-31|多选-31]] 的 C、D 即此陷阱）。
8. **维修义务记反 / "第三人撞坏归承租人"** —— 错！维修义务**法定在出租人**（§712，无特约）；第三人致损也**不转嫁给承租人**（出租人先修再追偿）；唯**承租人过错**致损才由承租人自担（§713 Ⅱ）（[[典型合同-单选-25|单选-25]] 即此考点）。

## 四、真题演练

### 范例①：[[典型合同-多选-05|C2-多选-05]]（口头 2 年 + 经同意转租，选"不正确"）→ ⚠️ 民法典 **ABD**（旧合同法 BD）
- **板块一**：口头但期限"2 年"明确可确定 → **§707 新法不视为不定期** → A"不定期"**错** → 选 A。（旧合同法§215 下"未书面一律不定期"，A 对，故旧答案 BD；新法 A 错 → **ABD**。）
- **板块二**：经同意转租，冯张之间仍按**原约 1000** 收租（差价 1200-1000 归张）→ B"按 1200 向张收"**错** → 选 B；翁拆墙，冯找**张**赔（§716）→ C 对；冯对翁**无合同**→ D"要翁担违约"**错** → 选 D。
→ 民法典下 **ABD** ✅

### 范例②：[[典型合同-单选-26|C2-单选-26]] / [[典型合同-单选-27|C2-单选-27]]（侵害优先购买权）→ 买卖**有效**、只能找出租人**赔偿**（§728）。

### 范例③：[[典型合同-单选-28|C2-单选-28]] / [[典型合同-多选-31|C2-多选-31]]（多重租赁）→ **板块五**
- 顺位：**已合法占有 ＞ 已登记备案 ＞ 成立在先**（租赁解释 §5）。
- 多选-31：先租**已入住**的孟某（占有）赢过后租**已备案**的马某 → **A 对**（占有优先）；A 合同未备案**仍有效** → **B 对**（备案非生效要件）；**C 错**（孟某优先的理由是"占有"，非"成立在先"）；**D 错**（备案败给占有）→ **AB**。

### 范例④：[[典型合同-单选-25|C2-单选-25]]（玻璃墙被逃逸司机撞坏，维修费谁担）→ **A**
- **板块六**：维修义务法定在**出租人**甲（§712，口头约定未排除）；第三人（逃逸司机）撞坏**不转嫁**——甲拒修，乙催告后自行修的 **1 万由甲负担**（§713 Ⅰ），甲再向司机追偿。→ **A**（不分担、不归乙）。
