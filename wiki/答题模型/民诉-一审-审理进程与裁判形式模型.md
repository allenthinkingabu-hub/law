# 📐 一审审理进程与裁判形式 · 完整答题模型（备庭 + 反诉 + 撤诉/缺席 + 延期/中止/终结 + 流程审限 + 判决裁定决定）

> **核心一句**：[[民诉-一审-起诉与受理模型]]解决"案子怎么**进门**"，本模型解决"进门之后**这场官司怎么走完、走岔了怎么办、最后出什么文书**"，一条主线五站：**备庭（送达副本→答辩十五日→庭前会议§128/解释§224-225）→ 被告反击（反诉三门槛，解释§232-233）→ 有人退场/不来（撤诉§148与按撤诉处理、缺席判决§146-147）→ 程序卡壳三兄弟（延期§149/中止§153/终结§154）→ 收官出文书（调查辩论审限§141-152＋判决裁定决定三分§155-157）**。最毒陷阱是**把"原告不到庭"答成缺席判决**（原则按撤诉处理，被告反诉时才能缺席判）、**把中止与终结的事由混搭**（"等继承人表态"是中止，"继承人放弃"是终结）、**把反诉的时间窗记成"答辩期届满前"**（正确是法庭辩论结束前）、**把可上诉裁定的范围放大**（只有不予受理、管辖权异议、驳回起诉三种，保全裁定只能复议）。
>
> 🔎 **核心条文速查**：
> - **民诉法§128【送达与答辩】**：立案之日起**五日**内将起诉状副本发送被告，被告收到之日起**十五日**内提出答辩状；法院收到答辩状之日起五日内将副本发送原告。**被告不提出答辩状的，不影响人民法院审理**。
> - **民诉法§131【告知审判人员】**：审判人员确定后，应当在**三日**内告知当事人。
> - **解释§224-225【庭前会议】**：答辩期届满后可组织证据交换、召集庭前会议；庭前会议可包括明确诉辩意见、**审查处理增加变更诉请的申请和提出的反诉**、决定调查收集证据、组织交换证据、归纳争议焦点、进行调解。
> - **民诉法§54【反诉权】**：被告可以承认或者反驳诉讼请求，**有权提起反诉**。§143：原告增加诉请、被告提出反诉、第三人提出与本案有关的诉请，**可以合并审理**。
> - **解释§232【反诉时间】**：案件受理后、**法庭辩论结束前**提出，可以合并审理的**应当**合并审理。**解释§233【反诉三款】**：反诉当事人**限于本诉当事人范围**；基于**相同法律关系**、有**因果关系**或基于**相同事实**的应当合并审理；应由其他法院**专属管辖**或与本诉无关联的，**裁定不予受理，告知另行起诉**。**解释§239【反诉独立】**：准许本诉原告撤诉的，**应当对反诉继续审理**；被告申请撤回反诉的，应予准许。
> - **民诉法§148【撤诉】**：**宣判前**原告申请撤诉的，是否准许由法院**裁定**；裁定不准撤诉后原告经传票传唤无正当理由拒不到庭的，可以**缺席判决**。**解释§214【撤诉后再诉】**：撤诉或按撤诉处理后以同一诉请再诉的**应予受理**；离婚案件无新情况新理由**六个月内**又起诉的不予受理。**解释§238**：有违反法律行为需依法处理的，可**不准许撤诉/不按撤诉处理**；法庭辩论终结后原告申请撤诉、**被告不同意**的，可以不予准许。
> - **民诉法§146-147【谁不来怎么办】**：**原告**经传票传唤无正当理由拒不到庭或未经许可中途退庭的，可以**按撤诉处理**；**被告反诉的，可以缺席判决**。**被告**拒不到庭或中途退庭的，可以**缺席判决**。§112＋解释§174：**必须到庭的被告**（负有赡养抚育扶养义务和不到庭无法查清案情的被告）经**两次**传票传唤拒不到庭的可以**拘传**；必须到庭才能查清基本事实的**原告**亦可拘传。
> - **民诉法§149【延期审理】**四情形：必须到庭者有正当理由未到庭、当事人**临时提出回避申请**、需要通知新证人/调取新证据/重新鉴定勘验/补充调查、其他。
> - **民诉法§153【中止】**六情形＋"原因消除后恢复诉讼"；**§154【终结】**四情形（原告死亡无继承人或继承人放弃、被告死亡无遗产无应承担义务的人、**离婚案一方死亡**、追索赡养费扶养费抚养费及解除收养关系案一方死亡）。
> - **民诉法§141【法庭调查顺序】**当事人陈述→证人作证→书证物证视听资料电子数据→鉴定意见→勘验笔录；**§144【法庭辩论顺序】**原告方→被告方→第三人方→互相辩论，辩论终结按**原告、被告、第三人**顺序征询**最后意见**；**§145**辩论终结应依法判决，判决前能调解的可以调解，调解不成的应当**及时判决**；**§152【审限】**普通程序**六个月**，院长批准延**六个月**，还需延长**报上级法院批准**。
> - **民诉法§157【裁定范围】**十一项；**对前款第一项至第三项裁定（不予受理、管辖权异议、驳回起诉）可以上诉**；口头裁定的，记入笔录。§111：对**保全或先予执行**的裁定不服，可申请**复议一次**，复议期间不停止执行。§156：一部分事实已经清楚的，可以就该部分**先行判决**。§50：回避申请由法院**决定**，不服可申请**复议一次**，复议期间被申请回避人员**不停止**参与本案工作。§119：罚款拘留用**决定书**，不服向**上一级法院**申请复议一次，复议期间**不停止执行**。

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已在本地权威全文（ssf.gov.cn 发布的民诉法2023全文PDF转文本、民诉解释2022全文）中**逐条grep到原文**后写入：民诉法§54、§111、§112、§119、§50、§128、§131、§141-§149、§151-§157，民诉解释§174、§213、§214、§224、§225、§230、§232、§233、§236、§237、§238、§239、§240、§241。**特别提示四处易错标注**：①反诉的构成要件**不在民诉法本体**——民诉法只有§54（有权反诉）和§143（可以合并审理），"辩论结束前、当事人范围、牵连关系"三门槛全在**解释§232-233**；②"撤诉后可再诉"的法源是**解释§214**，不是民诉法§127（§127第五项恰恰说"准许撤诉的裁定除外"、第七项是离婚案六个月限制的比照源头）；③"可以上诉的裁定"以**§157第二款**为准——只有**前三项**，中止/终结诉讼的裁定、准许或不准许撤诉的裁定都在§157清单里但**不可上诉**；④回避的复议期间**不停止参与本案工作**（§50），罚款拘留的复议期间**不停止执行**（§119），两个"不停止"对象不同、条号不同，不可互串。官方全文：[民诉法2023（ssf.gov.cn PDF）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)。

> ⚠️ **易记错点**：①**"原告不到庭"两条出路**——原则**按撤诉处理**（§146前段），**被告已反诉**的可以**缺席判决**（§146后段）；被告不到庭才是缺席判决的主场（§147）——主体一换，答案全变；②**反诉的时间窗＝法庭辩论结束前**（解释§232），命题人爱偷换成"答辩期届满前"（那是管辖异议的窗口）；③**本诉撤了，反诉照审**（解释§239）——一审以"原告撤诉"为由驳回反诉是经典错误裁判；④**中止 vs 终结一字之差**：一方死亡"**等待继承人表明是否参加**"→中止，"没有继承人/继承人**放弃**"→终结，**离婚案一方死亡→直接终结**；⑤**延期审理≠中止诉讼**——延期是"这次庭开不成，另约时间"（§149，含临时提回避、需新证据），中止是"程序整体暂停等障碍消除"（§153）；⑥**可上诉裁定只有三种**（不予受理、管辖权异议、驳回起诉），**保全和先予执行裁定只能复议一次且不停止执行**（§111）；⑦**不答辩不影响审理**（§128末款），别把"不答辩"当成自认或缺席；⑧**审限六个月从立案之日起算**，院长批准延六个月，**再延要报上级法院批准**——两级审批别记反；⑨**决定**管回避和罚款拘留强制措施，两者都可**复议一次**，但回避复议期间**不停工作**、罚款拘留复议期间**不停执行**。

## 二、 判别模型（备庭 → 反击 → 退场 → 卡壳 → 收官）

```
        【立案受理（前接：起诉与受理模型）】
                    │
   ▼ 第一站：备庭（§128-136，解释§224-225）
   │  立案后5日送起诉状副本 → 被告15日内答辩（不答辩不影响审理）
   │  → 收答辩状5日内送副本给原告 → 审判人员确定后3日内告知
   │  → 答辩期届满后：证据交换 / 庭前会议（明确诉辩·处理反诉·归纳争点·调解）
                    │
   ▼ 第二站：被告反击——反诉三门槛（§54、§143，解释§232-233）
   │  ①时间：案件受理后、法庭辩论结束前
   │  ②人：限于本诉当事人范围（矛头指向案外人 → 出局）
   │  ③事：同一法律关系 / 因果关系 / 相同事实（任一即牵连）
   │  ├─ 应由其他法院专属管辖 / 与本诉无关联 → 裁定不予受理，告知另行起诉
   │  ├─ 提反诉＝应诉答辩 → 管辖异议失权（§130 II）
   │  └─ 反诉独立：本诉撤诉，反诉照审（解释§239）
                    │
   ▼ 第三站：有人退场 / 不来（§146-148，§112，解释§213-214、§236-241）
   │  原告主动撤：宣判前申请 → 法院裁定（有违法行为可不准；
   │     辩论终结后撤、被告不同意可不准）→ 撤后同一诉请可再诉（离婚6个月限）
   │  原告不来：按撤诉处理；被告已反诉 → 可缺席判决
   │  被告不来：可缺席判决（仍须审理诉请、理由与已交证据）
   │  必须到庭的被告：两次传票传唤拒不到庭 → 拘传
                    │
   ▼ 第四站：程序卡壳三兄弟（§149、§153、§154）
   │  延期审理：当次庭开不成（必须到庭者有正当理由未到／临时提回避／
   │     需新证人新证据重新鉴定勘验补充调查）→ 另定开庭日
   │  中止诉讼：程序暂停（死亡待继承人表态／丧失诉讼行为能力未定法代／
   │     法人终止未定承受人／不可抗拒事由／须以另案结果为依据）→ 原因消除恢复
   │  终结诉讼：不再审（原告死无继承或放弃／被告死无遗产无义务人／
   │     离婚案一方死／赡扶抚·解除收养案一方死）
                    │
   ▼ 第五站：收官——流程·审限·文书（§141-152、§155-157、§50、§111、§119）
   │  法庭调查（陈述→证人→书物证→鉴定→勘验）→ 法庭辩论（原→被→三→互辩）
   │  → 征询最后意见（原被三顺序）→ 辩论终结依法判决（能调则调）
   │  → 公开宣判（§151）；审限：普通6个月＋院长批6个月＋上级批
   │  文书三分：实体→判决（可先行判决§156）
   │           程序→裁定（§157十一项，可上诉仅前三项；口头裁定记笔录；
   │                     保全/先予执行裁定→复议一次§111）
   │           回避/罚款拘留→决定（各复议一次：回避不停工作§50，
   │                     罚款拘留不停执行§119）
```

> **一句话总诀**：**「五日送达十五答、不答照审；反诉辩终前、人限本诉、事要牵连，本诉撤了反诉照审；原告不来按撤诉、被告不来缺席判、有反诉原告也缺席判、必须到庭两传拘；当次开不成叫延期、暂停等恢复叫中止、人死诉亡叫终结；调查辩论最后意见、六月审限两级批；实体判决、程序裁定（可上诉只有不予受理·管辖异议·驳回起诉三种）、回避强措用决定」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **原告缺席＝缺席判决** | 原告经传票传唤无正当理由拒不到庭的，法院可以缺席判决。 | **❌ 原则错误！**原告不到庭的法定处理是**按撤诉处理**（§146前段）；只有**被告已提出反诉**时（反诉里原告成了被告角色），才"可以缺席判决"（§146后段）。缺席判决的常规主场是**被告**缺席（§147）。 |
| **被告不答辩就败诉/不能开庭** | 被告收到起诉状副本后十五日内未提出答辩状，法院不能开庭审理（或视为承认原告主张）。 | **❌ 说法错误！**§128末款明文："被告不提出答辩状的，**不影响人民法院审理**。"答辩是权利不是义务，不答辩既不阻却开庭，也不构成自认。 |
| **反诉须在答辩期内提出** | 反诉必须在答辩期届满前提出，逾期法院不予受理。 | **❌ 说法错误！**反诉的时间窗是"案件受理后，**法庭辩论结束前**"（解释§232）。"答辩期届满前"是**管辖异议**的窗口（§130 I），命题人故意串窗。 |
| **本诉撤诉，反诉一并终结** | 原告撤回起诉后，被告的反诉失去依附对象，法院应裁定驳回反诉。 | **❌ 说法错误！**反诉是**独立之诉**——"准许本诉原告撤诉的，**应当对反诉继续审理**"（解释§239）。反过来，被告申请撤回反诉的，应予准许。 |
| **等继承人表态＝终结诉讼** | 一方当事人死亡，需要等待继承人表明是否参加诉讼的，应当终结诉讼。 | **❌ 说法错误！**"等待继承人表态"是**中止**（§153一款一项）——程序只是暂停，继承人可能接棒；**终结**留给"没有继承人/继承人放弃/离婚案·赡扶抚案一方死亡"这类诉讼确定无法继续的情形（§154）。 |
| **中止/终结的裁定、不准撤诉的裁定可以上诉** | 当事人对中止诉讼（或不准许撤诉）的裁定不服的，可以提起上诉。 | **❌ 说法错误！**§157第二款只放行**前三项**（不予受理、管辖权异议、驳回起诉）上诉；中止/终结诉讼、准许或不准许撤诉虽然都用裁定，但**不可上诉**。保全和先予执行裁定的救济是**复议一次**（§111），也不是上诉。 |

## 四、 相邻制度对照表（同场竞技，勿混规则）

**对照一：程序卡壳三兄弟（延期 vs 中止 vs 终结）——6-8 ★★★★选项混搭区**

| 事项 | 延期审理（§149） | 中止诉讼（§153） | 终结诉讼（§154） |
|---|---|---|---|
| 本质 | **当次开庭**开不成，另定日期，程序照常推进 | **程序整体暂停**，障碍消除后恢复 | **程序永久打住**，不再审理 |
| 典型事由 | 必须到庭者有正当理由未到；**临时提出回避申请**；需新证人/新证据/重新鉴定勘验/补充调查 | 一方死亡**等继承人表态**；丧失诉讼行为能力未定法代；法人终止未定承受人；不可抗拒事由；**须以另案审理结果为依据** | 原告死**无继承人或继承人放弃**；被告死无遗产无义务人；**离婚案一方死**；赡扶抚·解除收养案一方死 |
| 后续 | 另行开庭 | 原因消除后**恢复诉讼** | 无后续（用裁定终结） |
| 记忆钩 | "**这一场**开不成" | "**暂停键**，等人等案" | "四情形**全带死字**" |

**对照二：判决 vs 裁定 vs 决定三分法——6-10 ★★★★文书定性区**

| 事项 | 判决 | 裁定 | 决定 |
|---|---|---|---|
| 解决什么 | **实体**权利义务争议 | **程序**问题（§157列举十一项） | 回避、妨害民事诉讼的强制措施等**特殊程序事项** |
| 典型场景 | 全案判决；一部分事实清楚可**先行判决**（§156） | 不予受理、管辖异议、驳回起诉、保全先予执行、准许/不准撤诉、中止/终结诉讼、补正笔误等 | 回避（§49-50）；拘传、罚款、拘留（§119，须院长批准） |
| 能否上诉 | 可以上诉（一审判决） | **仅前三项可上诉**：不予受理、管辖权异议、驳回起诉（§157 II） | **一律不可上诉** |
| 其他救济 | — | 保全/先予执行裁定：**复议一次**，不停止执行（§111） | 回避决定：复议一次，**不停止参与工作**（§50）；罚款拘留决定：向**上一级法院**复议一次，**不停止执行**（§119） |
| 形式 | 判决书（§155） | 裁定书；**口头裁定记入笔录**（§157末款） | 决定书（罚款拘留，§119） |

## 五、 万能五步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序问题分析），按照以下五步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司支付货款**30万元**，法院**3月2日**立案，适用普通程序。乙公司收到起诉状副本后，以甲公司交付的货物存在质量缺陷为由，反诉请求甲公司赔偿维修损失**10万元**。全案以这条时间线贯穿五步。

### 第一步：备庭诀——五日送达十五答，不答照样审

> **副本五日答十五，庭前会议理争点**

#### 概述

立案只是"进门"，开庭前法院要做完一套标准动作，每个动作都带法定期限：

- **送达起诉状副本**：立案之日起**五日**内发送被告（§128）；
- **答辩**：被告收到之日起**十五日**内提出答辩状；法院收到答辩状之日起**五日**内将副本发送原告；
- **不答辩的后果**：没有后果——"被告不提出答辩状的，**不影响人民法院审理**"（§128末款），答辩是权利不是义务；
- **告知审判人员**：审判人员确定后**三日**内告知当事人（§131），当事人由此获得申请回避的信息基础；
- **必要共同诉讼**：必须共同进行诉讼的当事人没有参加的，法院应当**通知**其参加（§135）；
- **庭前分流与准备**（§136＋解释§224-225）：答辩期届满后，法院可组织**证据交换**、召集**庭前会议**——明确诉辩意见、**审查处理增加变更诉请的申请和提出的反诉**、组织交证、**归纳争议焦点**、进行调解。

#### 大白话讲解

法院3月2日给甲公司立了案，接下来是一串"数日子"的动作：

- 最迟**3月7日**（5日内），法院要把甲公司的起诉状副本寄给乙公司——让被告知道"谁告我、告我什么"；
- 乙公司3月7日收到副本，从收到那天起算**15天**（到**3月22日**）是它的答辩期。乙公司法务犯懒，一个字没写——有事吗？**没事**，法院照样往下审，只是乙公司自己放弃了先亮观点的机会；
- 合议庭组成人员定下来后**3天内**通知双方——通知的意义是给双方一个"看看审我案子的人跟对方有没有关系"的机会（衔接回避）；
- 答辩期一过，法官把双方叫来开**庭前会议**：甲公司把请求讲明，乙公司当场提出反诉（庭前会议正是处理反诉的法定场合之一，解释§225第二项），双方交换证据，法官在白板上写下争议焦点："货物有没有质量缺陷？"

| 备庭动作 | 期限/时点 | 条文 |
|---|---|---|
| 送起诉状副本给被告 | 立案之日起5日内 | §128 |
| 被告提出答辩状 | 收到副本之日起15日内（不答辩不影响审理） | §128 |
| 答辩状副本送原告 | 收到答辩状之日起5日内 | §128 |
| 告知审判人员 | 确定后3日内 | §131 |
| 证据交换/庭前会议 | 答辩期届满后 | 解释§224-225 |

#### 一句话闭环记忆

> 🎯 **一眼判**：**"5—15—5—3"四个数字锁死备庭**（送副本5日、答辩15日、转答辩状5日、告审判人员3日）；见"被告不答辩→不能开庭/视为认可"一律判错——**不答辩不影响审理**。

---

### 第二步：反击诀——辩终前、人限本诉、事要牵连

> **反诉三门槛：时间辩终前，人限本诉，事有牵连**

#### 概述

反诉是被告的"反手一击"——不满足于"驳回甲的请求"，还要法院判**自己的独立请求**。先分清楚：只求驳回对方＝**抗辩**；提出独立请求＝**反诉**。反诉进门要过三道门槛（解释§232-233）：

- **时间**：案件受理后、**法庭辩论结束前**（不是答辩期内——答辩期是管辖异议的窗口）；
- **人**：反诉当事人**限于本诉当事人范围**——矛头指向案外人的请求，牵连性再强也出局；
- **事**：与本诉基于**相同法律关系**、诉讼请求间有**因果关系**、或基于**相同事实**，三者居其一即有牵连，法院**应当合并审理**（§143：可以合并审理）。

两条出口规则：反诉**应由其他法院专属管辖**或与本诉毫无关联的，**裁定不予受理、告知另行起诉**（解释§233 III）；反诉一旦提出即**独立存在**——本诉原告撤诉，法院**应当对反诉继续审理**（解释§239）。

两条联动规则（常跨章出题）：**提反诉本身＝应诉答辩**，视为承认受诉法院管辖权，之后再提管辖异议失权（§130 II）；**当事人提出反诉的案件不适用小额诉讼**（§166五项），因反诉致不符合小额条件的转简易其他规定/普通程序。

#### 大白话讲解

乙公司在庭前会议上说："甲公司卖给我的货是次品，我修了花10万——我不光不付30万货款，还要甲赔我10万修理费。"逐门槛过筛：

| 门槛 | 本案对应 | 是否通过 |
|---|---|---|
| 时间：受理后、法庭辩论结束前 | 庭前会议阶段，远在辩论终结前 | ✅ |
| 人：限于本诉当事人 | 反诉被告是甲公司（本诉原告），没拉案外人 | ✅ |
| 事：同一法律关系/因果/相同事实 | 修理费与货款同源于**同一份买卖合同** | ✅ |

三关全过，法院应当把30万本诉和10万反诉**合并审理**。

**三个变形要会认**：

- **变形一（只抗辩不反诉）**：如果乙公司只说"货有缺陷，我不该付钱，请求驳回甲的诉请"——这是**抗辩**，不是反诉。检验法：把乙的主张单独拎出来能不能立案成诉？"赔我10万"能，是反诉；"驳回他"不能，是抗辩。
- **变形二（矛头指向案外人）**：如果乙公司请求的是"判令**丙物流公司**赔偿运输损坏"——丙不是本诉当事人，**当事人门槛直接出局**，只能另行起诉。
- **变形三（本诉撤了）**：审理中甲公司眼看要输，申请撤诉，法院裁定准许——乙公司的10万反诉怎么办？**照样审**（解释§239）。甲撤诉带不走乙的反诉；一审如果以"原告撤诉"为由裁定驳回反诉，二审应**撤销原裁定＋指令一审法院审理**（那是错误的驳回起诉裁定）。

**顺手带走两个联动分**：乙公司提了反诉，就等于承认了受诉法院的管辖权——庭前会议上再掏出"约定B县管辖"的协议提异议，**已经失权**（§130 II）；如果本案本来走小额诉讼，乙一提反诉，**小额立刻出局**（§166五项）。

#### 一句话闭环记忆

> 🎯 **一眼判**：反诉**先看人再看事最后看表**——人限本诉当事人、事要牵连（同一法律关系/因果/相同事实）、表到"法庭辩论结束前"都来得及；**本诉撤了反诉照审**；见"答辩期届满前才能反诉""原告撤诉反诉一并驳回"直接判错。

---

### 第三步：退场诀——原告不来按撤诉，被告不来缺席判

> **宣判前可撤撤了能再告，主体一换缺席变撤诉**

#### 概述

这一步管"人走了/人不来"，两条线：

**主动退场（撤诉）**：
- 时间窗：**宣判前**申请（§148）——法庭辩论终结后仍可申请，但此时**被告不同意的可以不准**（解释§238 II）；
- 把关：是否准许由法院**裁定**；当事人**有违反法律的行为需要依法处理**的（如虚假诉讼），可不准许撤诉/不按撤诉处理（解释§238 I）；
- 后果：撤诉未经实体裁判，**同一诉请可再诉，法院应予受理**；唯离婚案件无新情况新理由**六个月内**不得再诉（解释§214）；
- 连锁：法院裁定**不准撤诉**后，原告经传票传唤无正当理由拒不到庭的，可以**缺席判决**（§148 II）；本诉撤诉后有独立请求权第三人转为另案原告继续诉讼（解释§237）。

**被动退场（不来）——主体对照是送命题**：
- **原告**不到庭/中途退庭 → **按撤诉处理**；**被告已反诉的 → 可以缺席判决**（§146）；
- **被告**不到庭/中途退庭 → **可以缺席判决**（§147）——但缺席判不是"原告说什么是什么"，法院仍须对诉请、双方诉辩理由和已交证据**审理后**依法判决（解释§241）；
- **必须到庭的被告**（负赡养抚育扶养义务＋不到庭无法查清案情的，解释§174）经**两次**传票传唤拒不到庭 → 可以**拘传**（§112）；必须到庭才能查清基本事实的**原告**同样可拘传（解释§174 II）；
- 外围主体：不预交受理费按撤诉处理（解释§213）；有独三不到庭按撤诉处理其独立请求（解释§236）；**无独三**不到庭**不影响审理**（解释§240）。

#### 大白话讲解

开庭那天，几种剧情：

**剧情A（甲想撤）**：甲公司发现关键证据丢了，开庭前申请撤诉——法院**裁定**准许。撤诉不是"案子死了"：半年后甲找回证据，拿**同一个30万请求**再起诉，法院**应予受理**（解释§214）——撤诉不吃掉起诉权。但如果法官发现甲乙这场官司是串通好的**虚假诉讼**想套取调解书，法院可以**不准撤**、继续查（解释§238 I）。再晚一点，法庭辩论都打完了甲才要撤（眼看要输想溜），乙公司不同意——法院**可以不准**（解释§238 II，辩论终结后撤诉要看对方脸色）。

**剧情B（甲不来）**：甲公司收到传票却无正当理由不到庭——**按撤诉处理**（视为"用脚撤诉"）。但别忘了乙公司还挂着10万**反诉**：反诉里甲是被告，甲不来，反诉部分**可以缺席判决**（§146后段）——所以本案的完整答案是"本诉按撤诉处理＋反诉缺席判决"。

**剧情C（乙不来）**：乙公司收到传票不到庭——法院**可以缺席判决**（§147）。但缺席判决≠自动判甲赢：法院要把甲的30万请求、乙已提交的质量异议材料**都审一遍**再判（解释§241）。

**剧情D（必须到庭的被告）**：换个案型——老太太诉儿子追索赡养费，儿子是"负有赡养义务且不到庭无法查清案情"的**必须到庭的被告**，躲着不来？**两次**传票传唤后，法院可以**拘传**他到庭（§112＋解释§174），不是一传不到就缺席判了事。

#### 一句话闭环记忆

> 🎯 **一眼判**：主体对照口诀——**"被告缺席缺席判、原告缺席按撤诉、有反诉原告也缺席判、必须到庭两传拘"**；撤诉三句——**"宣判前都能申请、撤了还能再告（离婚等六个月）、有违法行为/辩论终结后被告不同意可不准撤"**。

### 第四步：卡壳诀——当次开不成叫延期，暂停叫中止，人死诉亡叫终结

> **延期一场事，中止暂停键，终结带死字**

#### 概述

程序推进途中卡壳，法律给了三个性质完全不同的工具（本模型★★★★重灾区，选项混搭高发）：

- **延期审理（§149）**——只是"**这一场**开庭开不成"，程序整体照走，另定开庭日。四情形：①必须到庭的当事人和其他诉讼参与人**有正当理由**没有到庭；②当事人**临时提出回避申请**；③需要**通知新证人、调取新证据、重新鉴定勘验、补充调查**；④其他。
- **中止诉讼（§153）**——程序按下**暂停键**，事由消除后**恢复**。六情形：①一方当事人死亡，**需要等待继承人表明是否参加诉讼**；②一方**丧失诉讼行为能力**、尚未确定法定代理人；③法人/组织终止、尚未确定权利义务承受人；④一方因**不可抗拒的事由**不能参加诉讼；⑤本案**必须以另一案的审理结果为依据**而另案未审结；⑥其他。
- **终结诉讼（§154）**——程序**就此打住**，不再审理。四情形**全带"死"字**：①原告死亡，**没有继承人或继承人放弃诉讼权利**；②被告死亡，没有遗产也没有应当承担义务的人；③**离婚案件**一方当事人死亡；④**追索赡养费、扶养费、抚养费以及解除收养关系**案件一方当事人死亡。

**一方死亡的三分流**（错题榜条目）：等继承人表态→**中止**；无继承人/继承人放弃→**终结**；离婚案、赡扶抚案、解除收养案→**直接终结**（人身专属，无从继受）。中止和终结都用**裁定**（§157六项），但**不可上诉**。

#### 大白话讲解

回到甲乙公司的30万官司，四个平行剧情各对一个工具：

**剧情A（延期）**：开庭当天，乙公司经理突发急病住院（必须到庭者有正当理由未到）——或者乙公司当庭发现审判长是甲公司法定代表人的表哥，**临时提出回避申请**——这一场开不成了，**延期审理**，法院另定开庭日。程序没停，只是改期。

**剧情B（中止）**：换成个体户版本——原告老甲诉讼中因车祸去世，他儿子在国外，还没表态要不要接着告——**中止诉讼**，等继承人表态后恢复。或者：30万货款是否该付，取决于另案"合同是否有效"之诉的结果，另案还没审完——**中止**，等另案审结再恢复。

**剧情C（终结）**：老甲去世后，唯一继承人明确表示"放弃，不打了"——诉讼失去主体，**终结诉讼**，官司到此为止。注意这与剧情B**一字之差**："等表态"是中止，"已放弃"是终结。

**剧情D（离婚案直通终结）**：换成老甲诉妻子离婚，诉讼中老甲去世——婚姻关系因死亡自然消灭，离婚诉讼失去对象，**直接终结**，不存在"等继承人替他离婚"的问题。

| 卡壳情形 | 工具 | 条文 |
|---|---|---|
| 必须到庭者有正当理由没来／临时提回避／要调新证据重新鉴定 | 延期审理 | §149 |
| 一方死亡，等继承人表态／丧失行为能力未定法代／须以另案结果为依据 | 中止诉讼 | §153 |
| 原告死无继承人或继承人放弃／被告死无遗产无义务人／离婚·赡扶抚·解除收养案一方死 | 终结诉讼 | §154 |

#### 一句话闭环记忆

> 🎯 **一眼判**：**"延期＝这一场，中止＝暂停键，终结＝带死字"**——终结四情形全围着"人死了、诉没法继续"转；一方死亡三分流：**等表态中止、已放弃终结、离婚赡扶抚直接终结**；"临时提回避"归**延期**，别错投中止。

### 第五步：收官诀——调查辩论最后意见，实体判决程序裁定回避强措用决定

> **六月审限两级批，判裁决三分各归位，可上诉裁定只有三**

#### 概述

案子跑完全程，最后两问：**流程怎么走完？出什么文书？**

**流程与审限**：
- **法庭调查**（§141）五步固定顺序：当事人陈述→证人作证（宣读未到庭证人证言）→出示书证物证视听资料电子数据→宣读鉴定意见→宣读勘验笔录；当事人可在法庭上提出**新的证据**（§142）；
- **法庭辩论**（§144）顺序：原告方发言→被告方答辩→第三人方发言或答辩→**互相辩论**；辩论终结，按**原告、被告、第三人**顺序征询各方**最后意见**；
- 经征得当事人同意，调查与辩论**可以合并进行**（解释§230）；
- **辩论终结应依法判决**；判决前能调解的还可以调解，调解不成的**应当及时判决**（§145）；
- **宣判**（§151）：一律**公开**宣告判决；当庭宣判的**十日内**发送判决书，定期宣判的宣判后**立即**发给；宣判必须告知上诉权利、上诉期限和上诉法院；
- **审限**（§152）：普通程序**立案之日起六个月**审结；特殊情况经**本院院长**批准延长**六个月**；还需延长的，**报请上级人民法院批准**。

**文书三分法**（6-10 ★★★★）：
- **判决**管实体；一部分事实已经清楚的可**先行判决**（§156）；
- **裁定**管程序，§157列举十一项；**可以上诉的只有前三项**——不予受理、管辖权异议、驳回起诉；**口头裁定记入笔录**；保全/先予执行裁定的救济是**复议一次、不停止执行**（§111）；
- **决定**管回避与强制措施：回避由院长/审判长等**决定**（§49），不服可**复议一次**，复议期间被申请回避人员**不停止参与本案工作**（§50）；拘传、罚款、拘留须**院长批准**，罚款拘留用**决定书**，不服向**上一级法院**申请复议一次，复议期间**不停止执行**（§119）。

#### 大白话讲解

甲乙公司的案子终于开庭：书记员查明到庭、宣布法庭纪律；审判长核对当事人、告知权利、问要不要申请回避（§140）。然后进入正片——

**法庭调查**像"摆事实"：甲乙先各自陈述，再传质检员出庭作证，然后甲出示购销合同和送货单（书证）、乙出示破损货物照片（物证）和微信记录（电子数据），最后宣读质量鉴定意见。**法庭辩论**像"讲道理"：甲方发言→乙方答辩→互相辩论；辩论终结，审判长按"原告→被告"顺序问最后意见。辩论一结束，能调则调，调不成**及时判**。

**掐审限**：3月2日立案，正常最迟**9月2日**（6个月）要审结；案情复杂，**院长批准**再延6个月到**次年3月2日**；还不够？**报上级法院批准**——注意是"院长→上级法院"两级，不是院长一批再批。

**发文书，对号入座**：
- 法院认定乙欠货款30万成立、反诉修理费10万成立，判"乙付30万、甲赔10万"——实体结论，用**判决**；如果30万货款部分事实早已清楚、10万反诉还要鉴定，可就30万**先行判决**（§156）；
- 审理中甲申请**财产保全**冻结乙的账户——程序事项，用**裁定**；乙不服？只能**复议一次**且不停止执行（§111），**不能上诉**；
- 中途甲申请撤诉被驳回、诉讼因老甲去世中止——都用**裁定**，也都**不可上诉**（§157的可上诉名单只有不予受理、管辖权异议、驳回起诉三项）；
- 乙申请审判长**回避**被驳回——用**决定**，可复议一次，复议期间审判长**照常办案**（§50）；
- 乙的证人当庭撕毁证据被**罚款5万**——**决定书**，向**上一级法院**复议一次，复议期间**照罚不误**（§119）。

#### 一句话闭环记忆

> 🎯 **一眼判**：流程口诀**"查（陈述证人书物鉴勘）→辩（原被三互）→最后意见（原被三）→能调则调及时判→公开宣判"**；审限**"6＋6＋上级批"**；文书**"实体判决、程序裁定、回避强措决定"**——救济一眼分：**上诉只认三裁定（不予受理·管辖异议·驳回起诉），保全复议、回避复议不停工、罚款拘留复议不停罚**。

## 六、 易混提示

*   **按撤诉处理 vs 缺席判决**：
    *   看**主体**：*原告*不到庭→按撤诉处理（§146）；*被告*不到庭→缺席判决（§147）；例外接口：被告已反诉的原告缺席可缺席判（§146后段）、法院不准撤诉后原告缺席可缺席判（§148 II）。
*   **延期审理 vs 中止诉讼**：
    *   *延期*是"**这一次**开庭开不成"（含临时提回避、要调新证据），程序照常推进；*中止*是"**整个程序**暂停"等障碍消除（死亡待表态、以另案结果为依据等）。
*   **中止 vs 终结（一方死亡分流）**：
    *   "等继承人**表明是否参加**"→中止；"**没有**继承人/继承人**放弃**"→终结；**离婚案、赡扶抚案、解除收养案**一方死亡→不等任何人，直接终结。
*   **反诉时间窗 vs 管辖异议时间窗**：
    *   *反诉*：案件受理后至**法庭辩论结束前**（解释§232）；*管辖异议*：**提交答辩状期间**（§130 I）——且提出反诉本身构成应诉，管辖异议随之失权（§130 II）。
*   **上诉 vs 复议（裁定与决定的救济）**：
    *   *上诉*只对**三种裁定**（不予受理、管辖权异议、驳回起诉）和判决；*复议*对保全/先予执行**裁定**（§111）、回避**决定**（§50）、罚款拘留**决定**（§119）——三个复议都"一次"，但回避复议不停止**工作**、罚款拘留复议不停止**执行**。

## 七、 命题人最爱的 6 个陷阱

1.  **"原告经传票传唤无正当理由拒不到庭的，法院可以缺席判决"** —— 错！原告缺席原则**按撤诉处理**；只有**被告已反诉**（或法院已裁定不准撤诉，§148 II）时才可缺席判决。被告缺席才是缺席判决的常规情形。
2.  **"被告未在十五日内提出答辩状的，法院不得开庭/视为承认原告主张"** —— 错！§128末款明文"不影响人民法院审理"，不答辩不产生失权或自认效果。
3.  **"反诉应当在答辩期届满前提出"** —— 错！反诉窗口是**法庭辩论结束前**（解释§232）；"答辩期届满前"是管辖异议的窗口，两窗勿串。
4.  **"本诉原告撤诉后，反诉失去依附，法院应裁定驳回反诉"** —— 错！反诉独立，**应当对反诉继续审理**（解释§239）；一审错误驳回的，二审撤销原裁定并**指令一审法院审理**。
5.  **"一方当事人死亡，需要等待继承人表明是否参加诉讼的，终结诉讼"** —— 错！这是**中止**事由（§153一款一项）；终结留给"无继承人/放弃/离婚案·赡扶抚案死亡"（§154）。反向陷阱同理："继承人放弃诉讼权利的，中止诉讼"也是错。
6.  **"当事人对中止诉讼/不准许撤诉/财产保全的裁定不服的，可以上诉"** —— 错！可上诉裁定**仅三种**（不予受理、管辖权异议、驳回起诉，§157 II）；保全/先予执行裁定只能**复议一次且不停止执行**（§111）；回避、罚款拘留用的是**决定**，也只能复议。
