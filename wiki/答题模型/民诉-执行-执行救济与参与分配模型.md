# 📐 执行救济与参与分配 · 完整答题模型（执行和解双轨救济 + 执行担保 + 变更追加被执行人 + 参与分配）

> **核心一句**：本模型串起执行程序的四大"救济与承担"机关——**执行和解（合意变更）→ 和解不履行的双轨救济（恢复执行原文书 or 就和解协议起诉）→ 执行担保（暂缓兜底）→ 被执行人变了怎么办（变更追加）→ 钱不够分怎么办（参与分配）**。最毒的四个陷阱是：**①把"和解协议"当成有强制执行力、能直接申请执行；②忘了"标的物灭失/损毁→只能就和解协议起诉"这条双轨救济的例外；③把执行担保说成担保人有"先诉抗辩权"、要"另行起诉"；④把"参与分配"（公民/其他组织）与"破产"（企业法人）的界分弄反、把"分配方案异议"（无人反对→法院依异议修正）和"分配方案异议之诉"（有人反对→起诉）搞混。**
>
> 🔎 **《民事诉讼法》（2023修正）核心条文速查**：
> - **第241条【执行和解】**：在执行中，双方当事人**自行和解达成协议**的，执行员应当将协议内容**记入笔录**，由双方当事人签名或者盖章。申请执行人因**受欺诈、胁迫**与被执行人达成和解协议，或者当事人**不履行**和解协议的，人民法院可以根据**当事人的申请**，**恢复对原生效法律文书的执行**。
> - **第242条【执行担保】**：在执行中，被执行人向人民法院**提供担保**，并经**申请执行人同意**的，人民法院可以决定**暂缓执行**及暂缓执行的期限。被执行人**逾期仍不履行**的，人民法院有权**执行被执行人的担保财产或者担保人的财产**。
> - **第243条【被执行人死亡/终止】**：作为被执行人的公民死亡的，**以其遗产偿还债务**。作为被执行人的法人或者其他组织终止的，由其**权利义务承受人**履行义务。
> - **《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（法释〔2022〕11号修正，现行有效）**：§464（和解后请求中止执行/撤回申请→裁定中止或终结执行）；§465（不履行和解协议→对方可申请恢复执行原文书，已履行部分扣除；和解已履行完毕的不予恢复）；§467-469（执行担保细则：暂缓期限=担保期限且最长不超一年；期满不履行可直接执行担保财产或裁定执行担保人财产，担保人以应履行部分为限）；§470/§472/§473（变更追加：分立合并/名称变更/被执行人死亡继承人在遗产范围内担责）；§506-508（参与分配的范围、顺位：优先债权先、普通债权按比例）；§509-510（分配方案异议与分配方案异议之诉）；§511/§513（被执行人破产→中止执行移交、宣告破产→终结执行）；§400①(三)（再审审查期间和解已履行完毕→终结审查）。

> ⚠️ **诚实标注（条号核验说明）**：
> 1. **民诉法§241/§242/§243、民诉解释§464/§465/§467/§468/§469/§470/§472/§473/§506/§507/§508/§509/§510/§511/§513/§400** 均已在官方全文（民诉法 ssf.gov.cn PDF；民诉解释 ssf.gov.cn PDF）中**逐条 grep 核到原文**，条号与内容一致、可信度高。
> 2. **执行章条号存在"2021旧号"陷阱**：民诉解释（2022年修正）内部**仍援引 2021 版民诉法的旧条号**——如 §467、§468 引"民诉法第二百三十八条"（执行担保）、§470 引"民诉法第二百三十九条"（分立合并/死亡终止），而在 **2023 修正的现行民诉法中，这两条已后移为第242条、第243条（偏移 +4）**。**答题以 2023 现行条号为准**：执行和解=§241、执行担保=**§242**（不是旧§238）、被执行人死亡终止=**§243**（不是旧§239）。深度报告与本任务提示中如出现旧号，均以本次 grep 结果订正。
> 3. **合伙人追加、一人公司混同追加**的具体规则**主要出自《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》（法释〔2016〕21号，2020修正）**（合伙人追加、一人公司股东财产混同追加、追加裁定不服提执行异议之诉等），该司法解释**本地无全文，条号未 grep 核到**——本模型只呈现规则本身（与真题卡官方解析一致、可信），不强行标注其未核验的具体条号。分立各方连带责任的实体法依据为**《民法典》第67条**。

> ⚠️ **易记错点**：①**和解协议本身没有强制执行力**——不履行的出路是"恢复执行原文书"或"就和解协议另行起诉"，法院**绝不能**依和解协议径行执行其约定数额；②**"双轨择一"有例外**：原文书标的特定物已**灭失/损毁**，原判决无法恢复执行，就**只能**就和解协议起诉；③**执行担保**期满不履行→法院可**直接**执行担保人财产，担保人**无先诉抗辩权、无须另行起诉**；④**变更追加是执行程序内裁定，无须另行起诉确认**，但对**合伙人/一人公司混同**等涉实体责任的追加裁定不服，救济是**执行异议之诉（另行起诉）**而非复议；⑤**参与分配的对象是"公民或其他组织"**（非企业法人）；被执行人是**企业法人且资不抵债**走的是**破产**（中止执行、移交/终结），别把两者弄反；⑥**分配方案异议 vs 异议之诉**：书面异议后**无人反对**→法院依异议人意见**修正方案**分配；**有人反对**→异议人以反对者为被告提**分配方案异议之诉**。

## 二、判别模型（合意 → 不履行救济 → 担保 → 主体变更 → 分配）

```
        【生效法律文书已进入强制执行，被执行人乙不能/不愿一次清偿】
                                │
   ▼ 第一步：执行中双方达成合意？（执行和解 §241）
   │  ├─ 双方自行和解达成协议 → 执行员记入笔录、双方签名盖章
   │  ├─ 达成后请求中止执行/撤回执行申请 → 法院裁定中止执行/终结执行（解释§464）
   │  └─ 和解协议【无强制执行力】——不能直接申请执行其约定内容
                                │
   ▼ 第二步：一方不履行和解协议怎么救济？（解释§465）——双轨择一，不得重复受偿
   │  ├─ 轨道A：申请【恢复执行原生效文书】（已履行部分扣除；已履行完毕的不予恢复）
   │  ├─ 轨道B：就【履行和解协议】另行起诉
   │  ├─ 受欺诈/胁迫达成和解 → 也可申请恢复执行原文书（§241）
   │  └─ ★例外★：原文书标的【特定物已灭失/损毁】→原判决无法恢复执行
   │        → 只能走【轨道B：就和解协议起诉】；法院不得径行执行和解约定数额
                                │
   ▼ 第三步：被执行人提供担保求缓期？（执行担保 §242 + 解释§467-469）
   │  ├─ 被执行人提供担保 + 【申请执行人同意】 → 法院可决定暂缓执行及期限
   │  │    （暂缓期限=担保期限、最长不超一年；转移隐藏毁损担保物可恢复强制执行）
   │  └─ 期满仍不履行 → 法院【直接】执行被执行人的担保财产 or 裁定执行担保人财产
   │        （担保人以应履行义务部分为限；无先诉抗辩权、无须另行起诉）
                                │
   ▼ 第四步：被执行人变了/不足以自身清偿？（变更追加被执行人 §243 + 解释§470-473）
   │  ├─ 公民死亡、继承人未放弃继承 → 变更继承人为被执行人，遗产范围内担责（§473）
   │  │    （放弃继承的可直接执行遗产；不变更放弃继承的人）
   │  ├─ 法人分立/合并 → 变更后法人为被执行人；分立各方【连带】、内部约定不对抗债权人（§470+民法典§67）
   │  ├─ 法人被注销 → 权利义务承受人为被执行人（§243/§470）
   │  ├─ 合伙字号为当事人、合伙财产不足 → 追加合伙人为被执行人（无限连带）〔变更追加规定〕
   │  ├─ 一人公司股东（被执行人）与公司财产混同 → 追加该一人公司（连带）〔变更追加规定〕
   │  └─ 对【涉实体责任的追加裁定】不服 → 执行异议之诉（另行起诉），不是复议
                                │
   ▼ 第五步：钱不够分怎么办？（参与分配 §506-510 / 破产界分 §511）
   │  ├─ 被执行人=【公民/其他组织】+ 财产不能清偿所有债权 → 参与分配
   │  │    ├─ 有优先权/担保物权 → 可直接申请、优先受偿（§506 II）
   │  │    ├─ 顺位：扣执行费用 → 清偿优先债权 → 普通债权【按债权比例】（§508）
   │  │    └─ 分配方案异议（§509-510）：
   │  │        ├─ 无人反对 → 法院【依异议人意见修正方案】后分配
   │  │        └─ 有人反对 → 异议人以反对者为被告提【分配方案异议之诉】（逾期未诉按原方案分）
   │  └─ 被执行人=【企业法人】+ 资不抵债（破产法§2①）→ 破产：
   │        经申请执行人之一/被执行人同意，中止执行、移交住所地法院（§511）；
   │        受理破产→解除保全、移交管理人；宣告破产→终结执行（§513）
```

> **一句话总诀**：**「和解记入笔录、无强制执行力；不履行走双轨——恢复原文书 or 起诉和解协议，特定物灭失就只能起诉；担保加申请人同意才暂缓、期满直接执行担保财产不用先诉；被执行人变了就变更追加——死亡遗产范围内、分立各方连带、合伙人追加、一人公司混同追加，不服追加提异议之诉；钱不够分，公民/其他组织走参与分配、优先债权先普通按比例、异议无人反对法院修正有人反对提异议之诉，企业法人资不抵债则走破产」**

## 三、高频干扰选项

命题人最爱在"和解协议有没有执行力""参与分配 vs 破产""异议 vs 异议之诉"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **和解协议有强制执行力** | 执行和解协议经法院记入笔录后即具有强制执行力，一方不履行可直接申请强制执行和解协议约定的内容。 | **❌ 错！和解协议无强制执行力。** 依民诉法§241、解释§465，一方不履行的出路是**申请恢复执行原生效文书**（已履行部分扣除）**或就和解协议另行起诉**取得新的执行依据，法院**绝不能**依和解协议径行执行其约定数额。 |
| **特定物灭失仍可恢复执行** | 原判决交付/返还特定物，该物灭失后双方达成赔偿和解，一方不履行的，可申请恢复对原判决的执行。 | **❌ 错！原判决已无法恢复执行。** 特定物已灭失/损毁，"交付/返还特定物"的原判决客观上无从执行，只能**就赔偿/以他物抵债的和解协议另行起诉**，也不能执行原物折价（法院不能替换原判决标的）。 |
| **担保人有先诉抗辩权/须另诉** | 执行担保期满被执行人仍不履行，应先起诉担保人、担保人可主张先诉抗辩权。 | **❌ 错！直接执行、无先诉抗辩权。** 依民诉法§242、解释§469，期满不履行的，法院**直接**执行担保财产或裁定执行担保人财产（以其应履行部分为限），**无须另行起诉**，执行担保人**不享有先诉抗辩权**。 |
| **参与分配适用于企业法人** | 被执行人是企业法人、资不抵债时，其他债权人可申请参与分配、按比例受偿。 | **❌ 错！企业法人资不抵债走破产。** 参与分配对象是**公民或其他组织**（解释§506）；被执行人为**企业法人**且符合破产法§2①的，经申请执行人之一/被执行人同意应**中止执行、移交破产**（§511），不是参与分配。 |
| **异议成立法院直接改方案** | 债权人对分配方案提异议，只要异议有理，法院即直接修改分配方案分配。 | **⚠️ 分情形！** 书面异议后，**无人反对**→法院依异议人意见审查修正后分配（解释§510 I）；**有人反对**→异议人须以反对者为被告提**分配方案异议之诉**（§510 II），法院不能径行改方案。 |

## 四、相邻制度对照

### 4.1 和解不履行的双轨救济：恢复执行 vs 就和解协议起诉（重点·含例外）

| 情形 | 原生效文书能否恢复执行 | 救济路径 | 依据 |
|---|---|---|---|
| **一般金钱/可执行标的**的和解不履行 | 能 | **双轨择一**：①申请恢复执行原文书（已履行部分扣除）②就和解协议另行起诉——不得重复受偿 | §241、解释§465 |
| 受**欺诈、胁迫**达成和解 | 能 | 申请恢复执行原生效文书 | §241 |
| 和解已**履行完毕** | 不予恢复 | 纠纷已了结（再审审查期间→裁定终结审查，解释§400①(三)） | 解释§465、§400 |
| **★以物抵债和解，抵债物有权利瑕疵**（已抵押、查封、无法过户） | 命题人立场：应恢复执行原文书 | 申请**恢复原判决执行**（和解目的落空、起诉和解无实益）〔单264，命题人立场，标MEDIUM〕 | 解释§465 |
| **★原文书标的特定物已灭失/损毁**（花瓶打碎、返还物损毁） | **不能**（原判决无从执行） | **只能就和解协议另行起诉**；法院不得执行原物折价、不得径行执行和解数额 | 〔单292/单293〕；"只能起诉"的例外规则本地无独立全文，据真题官方解析呈现 |

### 4.2 执行担保 vs 执行和解

| 事项 | 执行担保（§242） | 执行和解（§241） |
|---|---|---|
| 触发 | 被执行人提供担保 + **申请执行人同意** | 双方自行和解达成协议、记入笔录 |
| 法律效果 | 法院可决定**暂缓执行**及期限（≤1年、=担保期限） | 中止执行/撤回执行申请（解释§464） |
| 不履行后果 | 期满不履行→**直接执行担保财产/担保人财产**（无须另诉、无先诉抗辩权，解释§469） | 双轨救济：恢复执行原文书 or 就和解协议起诉（解释§465） |
| 是否产生新执行依据 | 否，仍执行原文书+担保财产 | 就和解协议起诉的，判决为新执行依据 |

### 4.3 变更追加被执行人的典型情形横向表

| 触发情形 | 处理 | 责任范围 | 依据 | 真题 |
|---|---|---|---|---|
| 公民（被执行人）**死亡**、继承人未放弃继承 | 裁定变更**继承人**为被执行人 | 继承遗产范围内 | §243、解释§473 | 单276、单284 |
| 继承人**放弃继承** | 直接执行被执行人**遗产**（不变更放弃者） | 以遗产为限 | 解释§473 | 单284 |
| 法人**分立/合并** | 变更后法人为被执行人；分立**各方连带** | 内部约定不对抗债权人、可执行各方 | §243、解释§470、民法典§67 | 单275 |
| 法人**被注销** | 权利义务承受人为被执行人 | 承受范围内 | §243、解释§470 | — |
| **合伙字号**为当事人、合伙财产不足 | 追加**合伙人**为被执行人 | 无限连带 | 〔变更追加规定〕 | 单283 |
| **一人公司**股东（被执行人）与公司财产**混同** | 追加**该一人公司**为被执行人 | 连带 | 〔变更追加规定〕 | 多285 |
| 对**涉实体责任的追加裁定不服** | 提起**执行异议之诉**（另行起诉） | — | 〔变更追加规定〕 | 多285 |

### 4.4 参与分配 vs 破产（界分重点）

| 事项 | 参与分配 | 破产（执行转破产） |
|---|---|---|
| 被执行人主体 | **公民 / 其他组织**（非企业法人） | **企业法人** |
| 触发 | 财产不能清偿所有债权、其他已取债权人申请 | 符合破产法§2①（资不抵债/不能清偿到期债务） |
| 清偿原则 | 优先债权先、普通债权**按比例**（§508） | 破产集体清偿、法定清偿顺序 |
| 执行程序命运 | 继续执行、制作分配方案 | 经申请执行人之一/被执行人同意→**中止执行、移交**住所地法院（§511）；受理破产→解除保全、移交管理人；宣告破产→**终结执行**（§513） |
| 依据 | 解释§506-510 | 解释§511-513、企业破产法 |

## 五、万能五步答题模型

> 🚗 **统一案例**：甲公司持生效判决对乙公司享有 **50万元** 到期债权，乙拒不履行，甲申请强制执行。（各步在此主案上做最小变体，数字一路贯穿。）

### 第一步：判合意——执行中是否达成执行和解？效力如何？

> **和解记笔录，协议无执行力**

#### 概述

执行和解是**执行程序中双方当事人自行达成的处分合意**：变更原生效文书确定的履行主体、标的、期限、方式等。要件与效力两个关键：
- **形式**：双方自行和解达成协议→**执行员记入笔录**、双方签名或盖章（§241）；
- **效力**：和解协议**本身没有强制执行力**——它只是让执行程序中止（达成后可请求中止执行或撤回执行申请，法院裁定中止执行或终结执行，解释§464），并不取代原生效文书成为新的执行依据。

#### 大白话讲解

甲公司拿着"乙还50万"的生效判决去法院强制执行。乙公司说："我一次拿不出50万，能不能分3期、每期还一部分？"甲同意了，双方签了一份**执行和解协议**：乙分3期、每期还一定金额。执行员把这份协议**记入笔录**，甲乙都签了字。

这时候甲可以怎么处置这场执行？

- 甲可以**请求撤回强制执行申请**（基于自己的处分权），法院裁定**终结执行**；也可以请求**中止执行**，法院裁定中止（解释§464）。〔对应单262：达成和解后申请执行人可撤回执行申请〕
- 但要记住——这份和解协议**不是"新判决"**。如果将来乙不还了，甲**不能**拿着这份和解协议直接说"法院你照协议强制执行乙的财产"，因为和解协议**没有强制执行力**。〔单352 把"和解协议具有强制执行力"设为错误项，正是此点〕

**一张表看清执行和解的"能"与"不能"**：

| 事项 | 能否 | 说明 |
|---|---|---|
| 双方自愿达成、记入笔录 | ✅ 能 | §241 |
| 变更原判决的履行内容/期限/方式 | ✅ 能 | 处分权 |
| 达成后撤回执行申请/中止执行 | ✅ 能 | 解释§464 |
| 和解协议本身直接申请强制执行 | ❌ 不能 | 无强制执行力（单352 B错） |

#### 一句话闭环记忆

> 🎯 **一眼判**：执行和解=双方自愿+记入笔录+签名盖章；达成后可撤回执行申请/中止执行；**和解协议无强制执行力**，不能直接申请执行其约定内容——这是本板块第一道送分/送命题。

---

### 第二步：判救济——一方不履行和解协议，怎么办？（双轨 + 例外）

> **双轨择一恢复或起诉，特定物灭失只能起诉**

#### 概述

一方**不履行或不完全履行**执行中自愿达成的和解协议，另一方有**两条**救济路径（解释§465、§241）：
- **轨道A**：申请**恢复对原生效文书的执行**（已履行的部分应扣除；和解已履行完毕的不予恢复）；
- **轨道B**：就**履行和解协议**向法院**另行起诉**（取得新的执行依据）。

二者**择一**、不得同时用来重复受偿。**受欺诈、胁迫**达成和解的，也可申请恢复执行原文书。

**★例外（本步最毒陷阱）**：如果**原生效文书的标的是特定物、而该特定物已灭失/损毁**，"交付/返还特定物"的原判决**客观上已无法恢复执行**——此时只能走**轨道B（就和解协议起诉）**，法院也**不能**径行执行和解约定的赔偿数额、更不能执行原物折价。

#### 大白话讲解

**主案（一般情形，双轨都能走）**：乙按和解协议先还了第一期 **10万**，之后就不还了。甲怎么办？

- **轨道A**：甲可以申请**恢复执行原判决**，把已经还的10万扣掉，法院继续执行剩下的 **40万**。〔多263 A对〕
- **轨道B**：甲也可以**就和解协议起诉**乙，请求乙按和解协议履行。〔多263 B对〕
- 但两条路**不能同时用来拿两份钱**（不得重复受偿）；也不是"只能死板选一次、别无回旋"——A、B 都是可选的救济。〔多263：C"同时申请获双重清偿"错、D"只能选其一"绝对化也错〕

**变体（以物抵债、抵债物有瑕疵）**：和解约定"乙以自有车辆抵50万债务"，结果这车早已抵押给银行且被查封、**无法过户**。命题人认为：以物抵债目的落空、起诉和解已无实益，甲应**申请恢复原判决执行**（须甲申请，法院不依职权恢复）。〔单264 B，标MEDIUM〕

**★例外变体（特定物灭失，只能起诉）**：换一个案子——原判决是"乙交付一只古董花瓶给甲"，执行中发现**花瓶已被打碎灭失**，双方达成和解"乙赔甲60万"，乙又不履行。这时候：
- 原判决"交付花瓶"**已无法恢复执行**（花瓶没了）——**不能**走轨道A；
- 甲**只能就和解协议起诉**乙要那60万；〔单292 A对，B错〕
- 法院**不能**直接执行乙60万（和解协议无强制执行力，D错），也**不能**执行原物价值（原判决标的是花瓶不是钱，C错）。
- 同理，"返还特定物"的原判决，返还物已**损毁**、以他物抵偿的和解不履行，也**只能就和解协议起诉**。〔单293 C对〕

**一表定救济方向**：

| 情形 | 能否恢复执行原文书 | 出路 |
|---|---|---|
| 一般金钱债务和解不履行 | 能 | 恢复执行原文书（扣已履行）**或**就和解起诉，择一 |
| 以物抵债物有瑕疵、目的落空 | 能 | 申请恢复原判决执行（单264命题人立场） |
| **原文书标的特定物已灭失/损毁** | **不能** | **只能就和解协议起诉**（单292/单293） |
| 和解已履行完毕 | 不予恢复 | 纠纷了结（再审审查期→终结审查） |

#### 一句话闭环记忆

> 🎯 **一眼判**：和解不履行→**双轨择一**（恢复执行原文书·扣已履行 / 就和解协议起诉），不得重复受偿；**唯一例外**——原判决标的**特定物已灭失/损毁**，原判决无从恢复，**只能就和解协议起诉**，法院不得径行执行和解数额。

### 第三步：判担保——被执行人提供担保求缓期，效果如何？

> **担保加同意才暂缓，期满直接执行担保财产**

#### 概述

执行担保是被执行人为**换取暂缓执行**而提供的担保（§242）。两个要件、一个后果：
- **要件**：①被执行人（或他人）向法院**提供担保**（财产担保或他人保证）；②**经申请执行人同意**——缺一不可，申请执行人不同意的，法院不能暂缓；
- **效果**：法院可决定**暂缓执行**及暂缓期限（暂缓期限**与担保期限一致、最长不超过一年**，解释§467；担保物被转移隐藏变卖毁损的可恢复强制执行）；
- **后果**：暂缓期满被执行人**仍不履行**的，法院**有权直接执行被执行人的担保财产，或裁定执行担保人的财产**（担保人以其应履行义务部分的财产为限，解释§469）——**无须另行起诉担保人，担保人不享有先诉抗辩权**。

#### 大白话讲解

回到主案：乙暂时拿不出50万，乙的好友丙自愿**以自己的一处房产为乙提供执行担保**，甲（申请执行人）也**同意**了。法院于是决定**暂缓执行6个月**。

6个月到了，乙**还是不还**。甲能怎么办？

- 法院可以**直接执行担保人丙的担保财产**（那处房产），在丙应担保的范围内变价清偿。〔单265 B对〕
- 甲**不需要**"先去起诉丙、拿到判决再执行"——执行担保就是为了让法院能**在执行程序里直接**处置担保财产。〔单265 A错："只能起诉赵某"〕
- 丙**不能**主张"先诉抗辩权"（先诉抗辩权是一般保证人在诉讼中的抗辩，执行担保人没有）。〔单265 D错〕
- 乙还有履行义务、担保财产可供执行，也**不是**"终结执行程序"。〔单265 C错〕

**关键三问自查**：

| 问 | 答 |
|---|---|
| 只提供担保、申请执行人不同意，能暂缓吗？ | ❌ 不能，必须**申请执行人同意** |
| 暂缓最长多久？ | 与担保期限一致、**最长不超过1年**（解释§467） |
| 期满不履行，要先起诉担保人吗？ | ❌ 不用，法院**直接**执行担保财产/裁定执行担保人财产，无先诉抗辩权 |

#### 一句话闭环记忆

> 🎯 **一眼判**：执行担保 = 提供担保 **+ 申请执行人同意** → 法院暂缓执行（≤1年）；期满不履行 → 法院**直接**执行被执行人的担保财产或担保人财产（担保人以应履行部分为限），**无须另诉、无先诉抗辩权**。

### 第四步：判主体——被执行人变了/不足自身清偿，能否变更追加？追加谁？

> **死亡遗产内、分立各方连带、合伙人一人公司都能追**

#### 概述

原被执行人消灭、变更或不足以自身财产清偿时，**在执行程序内**可**变更/追加被执行人**（一般裁定即可、无须另行起诉确认；但涉实体责任的追加裁定不服→执行异议之诉）：
- **公民死亡**：继承人未放弃继承→变更**继承人**为被执行人、**在继承遗产范围内**担责；放弃继承的→直接执行遗产、不变更放弃者（§243、解释§473）；
- **法人分立/合并**：变更后法人为被执行人；**分立各方连带**、内部债务分担约定未经债权人同意**不对抗债权人**（解释§470、民法典§67）；
- **法人被注销**：权利义务承受人为被执行人（§243/§470）；
- **合伙字号为当事人、合伙财产不足**：追加**合伙人**为被执行人（无限连带）〔变更追加规定〕；
- **一人公司股东（被执行人）与公司财产混同**：追加**该一人公司**（连带）〔变更追加规定〕；
- 对**涉实体责任的追加裁定不服**→提**执行异议之诉（另行起诉）**，不是复议。

#### 大白话讲解

主案的乙有四种"变身"，每种追谁不一样：

- **乙是自然人、死了**：乙死亡、留有遗产，儿子小乙表示继承、其他人放弃。法院裁定**变更小乙为被执行人**，小乙**在继承遗产范围内**还这50万——不用甲另行起诉小乙确认债务，小乙也没有"先诉抗辩权"。〔单276、单284 C对；放弃继承的其他继承人不追加，单284 D错〕
- **乙公司分立成丙、丁**：分立时丙丁内部约定"债务全由丙承担"。但这只是**内部约定**，没经债权人甲同意，**不能对抗甲**——甲可以执行**丙、丁两家**（分立各方连带）。〔单275 C对，D错〕
- **乙是合伙"好安逸饭店"、以字号为被告、合伙财产不足**：判决后合伙财产只够还一部分。法院可裁定**追加合伙人**为被执行人、执行其个人财产（合伙人无限连带），不用另行起诉。〔单283 D对〕
- **乙是"皓星一人公司"、股东周某与公司财产混同**：执行股东周某财产不足，发现周某与皓星公司财产混同。法院可**追加皓星公司**为被执行人（连带）；皓星公司/周某若对这个**追加裁定不服**，救济是**提起执行异议之诉（另行起诉）**，**不是**向上一级法院申请复议。〔多285 A、C对，D错〕

**一句话对号**：死亡看遗产、分立看连带、合伙追合伙人、一人公司看混同；**追加裁定不服→执行异议之诉**（复议是"执行行为异议"的救济，别混）。

#### 一句话闭环记忆

> 🎯 **一眼判**：被执行人变了就变更追加、**执行程序内裁定即可无须另诉确认**——公民死亡继承人**遗产范围内**、法人分立**各方连带**（内部约定不对抗债权人）、合伙财产不足**追合伙人**、一人公司**混同追公司**；对涉实体责任的追加裁定不服→**执行异议之诉**，不是复议。

### 第五步：判分配——钱不够分怎么办？参与分配还是破产？

> **公民其他组织参与分配，企业法人资不抵债走破产**

#### 概述

被执行人财产不足以清偿全部债务时，按**主体性质**分两条路：
- **公民 / 其他组织**（非企业法人）→**参与分配**（解释§506-510）：
  - 其他已取得执行依据的债权人可申请参与分配；有**优先权、担保物权**的债权人可**直接**申请、**优先受偿**；
  - **顺位**：执行所得价款**扣执行费用 → 清偿优先债权 → 普通债权按其占全部参与分配债权数额的比例受偿**（§508）；
  - **分配方案异议**（§509-510）：制作分配方案送达各债权人和被执行人→债权人/被执行人15日内书面异议→**无人反对**：法院**依异议人意见修正方案**后分配；**有人反对**：异议人以反对者为被告提**分配方案异议之诉**（逾期未诉按原方案分，诉讼期间分配的提存争议款项）；
- **企业法人**且符合破产法§2①→**破产**：经申请执行人之一/被执行人同意，**中止执行、移交**住所地法院（§511）；受理破产→解除保全、移交管理人；宣告破产→**终结执行**（§513）。

#### 大白话讲解

**主案变体（参与分配）**：乙是"其他组织"（如个人独资企业），甲、戊、己三个债权人都拿着生效文书来执行乙，乙的财产**不够还全部**。

- 三个债权人都可以**申请参与分配**。〔多272 A对〕
- 分钱有顺序：戊如果对乙的某财产有**抵押权（担保物权）**，戊就该财产**优先受偿**；〔多272 B对、单356 B对〕剩下的钱，甲、己等普通债权**按债权比例**分（不是按债权成立时间先后、也不是绝对平均）。〔多272 C对、单356 A/C错〕
- **分配方案异议怎么走**：法院做好分配方案发给大家。
  - 如果债权人李某提异议、**其他人都不反对**——法院就**依李某的异议意见把方案改一改**再分配。〔单274 A对〕
  - 如果李某提异议、**乙、丙两个债权人反对**——李某就要**以乙、丙为被告**提起**分配方案异议之诉**，法院不能自己直接改方案。〔单273 B对，A错〕

**★别弄反（参与分配 vs 破产）**：如果乙是**企业法人**、已经资不抵债，甲申请执行时**B区法院受理了乙的破产申请**——这时候A区法院不能再"个别执行"划钱给甲了，而应**中止执行、把已冻结的存款移交破产管理人**（等破产程序集体清偿）。注意是"**中止**执行、移交管理人"，不是"继续执行划给甲"、也不是马上"终结执行"（宣告破产后才终结）。〔单300 B对〕

**一表定分配路径**：

| 被执行人 | 财产不足 | 走哪条 | 关键动作 |
|---|---|---|---|
| 公民 / 其他组织 | 不能清偿所有债权 | **参与分配** | 优先债权先、普通债权按比例；异议无人反对→法院修正，有人反对→分配方案异议之诉 |
| 企业法人 | 资不抵债（破产法§2①） | **破产** | 同意后中止执行移交（§511）；受理破产解除保全移交管理人、宣告破产终结执行（§513） |

#### 一句话闭环记忆

> 🎯 **一眼判**：钱不够分先看主体——**公民/其他组织→参与分配**（优先债权先、普通债权**按比例**；异议**无人反对法院依异议修正**、**有人反对提分配方案异议之诉**）；**企业法人资不抵债→破产**（中止执行、移交管理人，宣告破产才终结执行）。别把两者主体弄反。

## 六、易混考点辨析

- **和解协议 vs 调解书**：执行和解协议**无强制执行力**（不履行→恢复执行原文书/就和解起诉）；法院制作的**调解书**是执行依据、有强制执行力。
- **恢复执行 vs 就和解协议起诉**：均以"和解不履行"为前提、**择一**；**特定物灭失/损毁**时原判决无法恢复，**只能起诉**。
- **执行担保暂缓执行 vs 执行和解中止执行**：担保暂缓需**申请执行人同意**、期满不履行**直接执行担保财产**；和解中止是双方合意、不履行走双轨救济。
- **变更追加裁定不服的两种救济**：**涉实体责任的追加**（合伙人、一人公司混同、分立各方等）不服→**执行异议之诉（另行起诉）**；**执行行为**违法→**执行行为异议**（不服→向上一级法院**申请复议**）。别把两者的救济通道对调。〔多285 C对、D错正是此点〕
- **参与分配 vs 破产**：主体不同（公民/其他组织 vs 企业法人）、清偿原则不同（按比例 vs 破产顺序）、程序命运不同（继续分配 vs 中止/终结移交）。
- **分配方案异议 vs 分配方案异议之诉**：书面异议后**无人反对**→法院依异议**修正方案**（非诉讼）；**有人反对**→提**异议之诉**。〔单273 vs 单274 是这对孪生题〕

## 七、命题陷阱清单

1. **"执行和解协议记入笔录后即有强制执行力、可直接申请强制执行其内容"** —— 错！和解协议**无强制执行力**，不履行走"恢复执行原文书/就和解起诉"（单352 B错）。
2. **"原判决交付/返还的特定物已灭失，仍可申请恢复执行原判决"** —— 错！原判决无从恢复，**只能就和解协议起诉**（单292/单293）。
3. **"和解不履行只能选恢复执行或起诉其一、别无回旋"或"两条可同时用以获双重清偿"** —— 均错！双轨**择一救济、不得重复受偿**，但都是可选路径（多263 C、D均错）。
4. **"执行担保期满不履行须先起诉担保人、担保人有先诉抗辩权"** —— 错！法院**直接**执行担保财产/担保人财产，无须另诉、无先诉抗辩权（单265）。
5. **"被执行人死亡应直接终结执行"或"须先另行起诉继承人确认债务"** —— 错！有遗产的裁定变更**继承人**在**遗产范围内**担责、执行程序内裁定即可（单276/单284）。
6. **"公司分立后内部约定由某方承担全部债务，可对抗债权人、只能执行该方"** —— 错！内部约定**不对抗债权人**，分立**各方连带**、可执行各方（单275）。
7. **"对追加一人公司/合伙人的裁定不服，向上一级法院申请复议"** —— 错！涉实体责任的追加不服→**执行异议之诉（另行起诉）**（多285 D错）。
8. **"被执行人（企业法人）资不抵债时其他债权人申请参与分配按比例受偿"** —— 错！企业法人走**破产**（中止执行、移交/终结），参与分配对象是**公民/其他组织**（单300）。
9. **"债权人对分配方案提异议，法院一律直接修改方案分配"** —— 错！**无人反对**才依异议修正；**有人反对**须提**分配方案异议之诉**（单273 vs 单274）。
10. **"普通债权按债权成立时间先后 / 一律平均分配"** —— 错！优先债权先受偿，普通债权**按债权比例**（单356 A、C、D错，B对）。

| [[民诉-执行-单选-275 · 公司分立内部债务约定不得对抗债权人可执行分立各方]] | 法人分立各方连带 | 乙公司分立为丙、丁，其债务由分立后各方**连带**承担；丙丁"由丙承担全部债务"是**内部约定、未经债权人甲同意不得对抗甲**；甲可执行**丙、丁两家**财产（C对），非只执行一方（A、B错）、内部约定不对抗债权人（D错）。选 **C**。 |
| [[民诉-执行-单选-276 · 被执行人死亡变更继承人为被执行人遗产范围内担责]] | 被执行人死亡·继承人担责 | 被执行人钱某死亡、遗产由子小钱继承，执行法院可**裁定变更小钱为被执行人、在继承遗产范围内担责**（B对，解释§473）；有遗产不直接终结执行（A错）、执行程序内裁定无须另诉确认（C错）、继承人担责无先诉抗辩权（D错）。选 **B**。 |
| [[民诉-执行-单选-283 · 合伙字号为被告财产不足追加合伙人为被执行人]] | 合伙字号被告·追加合伙人 | 以合伙字号"好安逸"饭店为被告的判决，合伙财产不足清偿（付8万尚欠11万）时，执行法院可**裁定追加合伙人甲、乙、丙为被执行人**、执行其财产（D对，无限连带、无须另诉）；不终结执行/不终结本次执行（有可追加责任人，A、B错）、无须另行起诉（C错）。选 **D**。 |
| [[民诉-执行-单选-284 · 被执行人死亡由继承遗产的继承人变更为被执行人]] | 被执行人死亡·部分继承人放弃 | 甲死亡、乙继承、其他继承人放弃，应裁定**变更继承遗产的乙为被执行人**（遗产范围内担责，C对）；不变更放弃继承的全部继承人（D错）、须先裁定变更主体非"直接执行甲遗产不变更"（B错）、非延期执行（A错）。选 **C**。 |
| [[民诉-执行-多选-285 · 一人公司财产混同追加公司为被执行人不服另行起诉]] | 一人公司混同·追加与救济 | 一人公司股东周某（被执行人）财产与皓星公司财产混同，法院可**追加皓星公司为被执行人**承担连带（A对，B错）；对该涉实体责任的追加裁定不服的，提起**执行异议之诉（另行起诉）**（C对），**不是**向上一级法院申请复议（D错，复议是执行行为异议的救济）。选 **AC**。 |
| [[民诉-执行-多选-272 · 参与分配的申请优先受偿与普通债权按比例分配]] | 参与分配的申请与顺位 | 甲乙丙对丁均有到期债权、丁财产不足清偿，各债权人可**申请参与分配**（A对）；有担保物权的债权**优先于普通债权受偿**（B对）；普通债权**按债权比例**分配（C对）；分配方案异议**有反对意见须提异议之诉**、法院不能直接改方案（D错）。选 **ABC**。 |
| [[民诉-执行-单选-273 · 分配方案异议有反对意见应提起分配方案异议之诉]] | 有反对意见→分配方案异议之诉 | 甲书面异议、乙丙**提出反对意见**，法院不能径行按甲异议改方案（A错）；甲应**以反对的乙、丙为被告提起分配方案异议之诉**（B对，解释§510 II）；不是申请再审（C错）、不是简单中止分配待审查（D错）。选 **B**。 |
| [[民诉-执行-单选-274 · 分配方案异议无人反对法院依异议修正方案分配]] | 无人反对→法院依异议修正 | 李某异议、其他债权人**均未提反对意见**，执行法院应**依李某异议意见对分配方案审查修正后分配**（A对，解释§510 I）；无人反对无须提异议之诉（C错）、不驳回继续原方案（B错）、不中止执行程序（D错）。选 **A**。 |
| [[民诉-执行-单选-300 · 被执行人破产申请被受理执行法院中止执行移交管理人]] | 执行与破产竞合 | B区法院**受理乙公司破产申请**后，个别执行让位于破产集体清偿，A区法院应**中止执行、将已冻结的10万存款移交破产管理人**（B对）；不必等宣告破产后终结再交（A多了等待环节）、不能继续划扣给甲（C错）、此阶段是中止非终结（D错，宣告破产后才终结）。选 **B**。 |
| [[民诉-执行-单选-356 · 执行分配中的优先债权]] | 参与分配清偿顺位 | 多债权人对同一被执行人财产执行，**有担保债权优先于普通债权受偿**（B对）；普通债权**按债权比例**（非成立时间先后 A错、非绝对平均 C错）；工资债权不优先于担保债权（D错，本题设定下）。选 **B**。 |
