## 一、核心考情

- **频率**：[[保证合同]] ★★★★★，单选 / 多选高频，**主观题担保重中之重**；几乎必与物权编担保物权（抵押 / 质押 / 混合担保）串考。
- **命题核心**：专挑 **2021 反转点**设陷阱（方式推定、保证期间、互不追偿），再叠加"一般 vs 连带""主债变动是否免责""混合担保谁先实现 + 谁能向谁追偿"。
- **五大必考点**：①保证人资格 ②方式推定（→ 先诉抗辩权）③保证期间 6 个月 ④主债变动是否免责 ⑤混合担保实现顺序 + 追偿。

## 二、万能五步模型

### 第一步：是不是有效保证？（成立 + 资格）

**铁则**：
- **成立**：在合同 / 单据"**保证人**"栏签字盖章、或出具保函，即成立保证（§685）。
- **资格（§683 + 担保解释§11）——分四类记**：
  - **§683 明文禁两类**（有主体资格、但政策禁止）：① **机关法人**（除经国务院批准为转贷）；② **以公益为目的的非营利法人、非法人组织**（公办学校 / 幼儿园 / 医院、公益社团等）。违反 → **保证合同无效**，按 [[担保]] 无效的过错分责（担保解释§17）。
  - **内设机构 / 职能部门**（如"董事长办公室""财务处"）：**无独立民事主体资格** → 根本不能作保证人（主体不适格，**不是 §683**）。
  - **分支机构**（领营业执照、可自己名义活动）：有相对独立地位，但**对外担保需经公司决议**（**担保解释§11**）；未经决议以自己名义担保、相对人非善意的，公司不担责。⚠️ 旧担保法§10"分支机构经法人**书面授权**即可"的旧说法**已被"决议"规则取代**。
  - **自然人**：有完全民事行为能力即可；**负债累累不影响资格**（清偿能力 ≠ 资格）。

### 第二步：哪种保证方式？→ 决定有没有"先诉抗辩权"（§686-688）

> 🔑 **一句话判断**：合同**写明"连带"**（或约定"债务人不履行时债权人可直接找保证人"）→ **连带保证**；其余一切——**没约定 / 约定不明 / 只写"一般保证" / 写"债务人不能清偿时由保证人承担"** → 一律 **一般保证**（§686 默认）。

**铁则**：
- **方式不明 → 推定一般保证**（§686，**2021 反转旧法"连带"**）。
- **一般保证**：保证人有**先诉抗辩权**（§687）——主合同未经审判 / 仲裁并就债务人财产强制执行**仍不能履行前，可拒绝担责**；
- **4 种丧失**（§687Ⅱ：债务人下落不明且无财产 / 受理破产 / 债权人证明财产不足 / **书面放弃**）。
- **连带责任保证**：**无**先诉抗辩权（§688）——债务人到期不还，债权人**可直接**找保证人。
> 📐 先诉抗辩权 vs 三大履行抗辩权的辨析 → [[民法-合同-履行抗辩权模型]]「易混辨析 A」。

**老王小李例子**
- 老赵在保证人栏盖章但**没写方式** → **一般保证**（§686）；乙公司须**先告债务人甲、执行甲的财产**，不足才找老赵（§687）。若白纸黑字写"连带责任保证" → 甲一违约，乙可**直接**找老赵（§688）。

### 第三步：保证期间（默认 6 个月 · 除斥 · 从主债到期起算）（§692 + 解释§32）

> **“保证期间”与“诉讼时效”的接力运行与衔接规则**。

> **“期间时效接力赛，连带请求即起跑；一般保证有空档，终本送达才开跑。”**

- **“期间时效接力赛”**：债权人必须先在保证期间（6个月除斥窗口）内依法“主张”（出手敲门）。一旦敲门成功，保证期间正式退场，接力棒交给3年的**保证债务诉讼时效**（时效可中止、中断）。若没能在期间内主张，保证人直接免责，根本进不了时效长跑。

- **“连带请求即起跑”**（《民法典》§694）：**连带保证**的衔接是无缝的。债权人在期间内找连带保证人要钱的**那一天（请求之日）**，3年的诉讼时效直接在当天开始起跑。

- **“一般保证有空档”**：**一般保证**的衔接有很长的“时间差”。债权人在保证期间内起诉了主债务人，但此时保证人的3年诉讼时效**并不起跑**，中间存在一个漫长的司法执行“空档期”。

- **“终本送达才开跑”**（《担保制度解释》§28）：一般保证人的3年诉讼时效，必须要等到法院强制执行主债务人财产无果、作出**“终结本次执行程序（终本）”裁定书送达债权人之日**，才正式开始起跑！（_注意：旧法“判决生效之日”已废止！_）

#### 2. 大白话讲解

##### 场景一：连带保证的“无缝接力”（敲门即起跑）

老王欠小李100万，老张是连带保证人，保证期间6个月（2026年6月1日至12月1日）。

- **第一棒（保证期间）**：主债务到期了，保证期间（6个月除斥期间）开始倒计时。小李必须在12月1日前找到老张要钱。
- **接力瞬间**：10月1日，小李给老张发了封催款函：“老王没还钱，你现在替他把100万还了！”老张拒收。
- _法律效果_：就在10月1日这天，小李成功在保证期间内主张了权利，保证期间顺利退场。接力棒交给第二棒——3年的**诉讼时效**，起跑点就是**10月1日当天**。
- 小李必须在接下来的3年内起诉老张，否则老张可以以“诉讼时效已过”为由拒绝还钱。

##### 场景二：一般保证的“漫长空档期”与“终本死穴”

老王欠小李100万，老张是一般保证人，保证期间6个月（2026年6月1日至12月1日）。

- **第一棒（保证期间）**：因为是一般保证，老张享有先诉抗辩权。小李不能直接找老张，必须在12月1日前去**起诉或者仲裁主债务人老王**。
- **接力瞬间**：10月1日，小李一纸诉状把**主债务人老王**告上了法院。
    - _注意_：第一棒（保证期间）的警报解除了。但是！老张的3年诉讼时效**在10月1日并没有起跑**，因为老张还有先诉抗辩权护身，小李还不能执行老张。
- **进入漫长的空档期**：
    1. 法院受理案件，开庭审理，2027年3月1日作出一审判决：老王还钱。
    2. 老王依然没钱，判决生效。小李于2027年5月1日向法院申请强制执行老王的财产。
    3. 法院执行局查封了老王名下的一台烂车，拍卖了5万元。发现老王确实没有其他财产可供执行了。
    4. 2028年1月1日，法院作出了“终结本次执行程序（终本）”的裁定书，该裁定于**2028年1月5日送达给小李**。
- **第二棒时效终于开跑**：
    - 就在**2028年1月5日（终本裁定送达日）**，老张的先诉抗辩权由于老王“确实执行无果”而消灭。老张的3年保证债务诉讼时效在这一天正式迈步起跑！小李必须在2031年1月5日前起诉老张。
- **大白话**：从小李2026年10月1日去告老王，到2028年1月5日拿到终本裁定书，这中间隔了足足一年多，这一段就是**“诉讼时效起算空档期”**。
- _避坑指南_：法考最爱出选择题，说一般保证的诉讼时效从“判决生效之日起算”或“起诉债务人之日起算”，**通通是陷阱**！必须认准**“终本裁定送达债权人之日”**。


#### 3. 一句话闭环记忆

> **保证期间内主张成功，才开始算3年诉讼时效：连带保证自“请求保证人代偿之日”起算（无空档）；一般保证自“强制执行债务人的终本裁定送达债权人之日”起算（有空档）！**


##### **时间轴**（债权人乙、债务人甲、保证人老赵；没约定保证期间）

```
6/1 主债到期 ──── 保证期间 6 个月（除斥·不变动）──── 12/1 期间届满
       │                                              │
       └ 乙必须在 6/1~12/1 内"主张"                     └ 没主张 → 老赵免责
                 │
                 └ 在期间内主张了 → 才开始算"保证债务诉讼时效"（3 年·§694）
```

- **起算 = 主债到期日**（§692Ⅱ）；默认长度 **6 个月**。
- 期间内"主张"指：一般保证 → **对债务人甲**起诉 / 仲裁；连带保证 → **请求保证人老赵**担责。
- ⏱️ **诉讼时效何时起跑（接力点，一般 / 连带不同）**：**连带保证**从"请求保证人之日"即起算；**一般保证**虽在期间内对债务人起诉，但保证债务诉讼时效要等"**先诉抗辩权消灭之日**"（担保解释§28 终本裁定送达日）才起算，与起诉之间**有空档期**。⚠️ 上面时间轴是简化示意——老赵若按第二步认定为**一般保证**，那"3 年"实际从先诉抗辩权消灭日起跑，而非起诉甲当天。
- 🪤 合同写"老赵保证到**本息还清为止**" → 视为约定不明 → **6 个月**（不是 2 年！§692/解释§32）。

**📊 两个期间别混（高频）**

| 维度  | 保证期间                  | 保证债务诉讼时效          |
| --- | --------------------- | ----------------- |
| 起算  | 主债**到期日**             | **连带**：请求保证人之日；**一般**：先诉抗辩权消灭之日（担保解释§28 终本裁定送达·有空档）（§694） |
| 长度  | 默认 **6 个月**           | **3 年**           |
| 性质  | **除斥**（不中止 / 中断 / 延长） | 诉讼时效（可中止 / 中断）    |

> 一句话：**保证期间是"债权人限期出手"的除斥窗口（债务到期起 6 个月）；窗口内出手了才接着跑 3 年保证债务诉讼时效；窗口没赶上 → 保证人直接免责。**

### 第四步：主债务变动，保证人还担不担？（§695-697）

> 当主合同的金额、期限、甚至当事人发生变动，而保证人又没点头时，保证人到底能脱免多少责任？

- **“减担少，加担原”**（《民法典》§695Ⅰ）：主合同内容变更，如果债务减轻了，保证人对减轻后的债务继续担保（占便宜没问题）；如果债务加重了（如本金增加、利息变高），保证人对加重部分不担责，只按原合同限额担保。

- **“期限改动不顺延”**（《民法典》§695Ⅱ）：偷偷修改还款期限，未经保证人书面同意的，**保证期间绝不顺延**！依然按原合同的到期日起算（这往往会导致保证期间早于新到期日届满，进而导致保证人彻底脱责）。

- **“债权转让随便走”**（《民法典》§696）：债权人换人，属于权利转让，**不需要保证人同意**（只需通知即可），保证在原范围内继续随之移转。

- **“债务转移书面签”**（《民法典》§697）：债务人换人，属于债务承担。因为新债务人的信用风险直接影响保证人能否全身而退，必须经过保证人**书面同意**！未经书面同意转移的部分，保证人不再担责。

- **“债务加入继续保”**：第三人仅仅是“加入”债务成为共同债务人（并存的债务承担），原债务人并没有脱身。这没有加重保证人的风险，保证人对债务总额**继续承担保证责任**。


**📊 主债一变 · 判断表（未经保证人书面同意时）**

| 主债怎么变 | 保证人后果 | 法条 |
| --- | --- | --- |
| 减轻 / 免除（金额↓） | 对**减轻后**仍担保 | §695Ⅰ前 + §575 |
| 加重（金额↑ / 义务加重） | 对**加重部分不担**、只担原额 | §695Ⅰ后 |
| 履行期限变更 | **保证期间不受影响**（按原期、不顺延） | §695Ⅱ |
| 债权转让（换债权人） | 保证**随主债权转移**、继续担（**不需保证人同意**） | §696 |
| 债务转移（换 / 减债务人） | 对**未经同意转移部分不再担** | §697 |
| 债务加入（原债务人没走） | 对**全额仍担**（不受影响） | §552 |
#### 2. 大白话讲解

##### 场景一：只准“占便宜”，不能“吃大亏”（加重与减轻）

老王欠小李100万，老张签字提供保证。后来老王和小李觉得利息太低，私下签协议把债务金额改成了120万。老张全程被蒙在鼓里。

- **大白话**：老张是给老王帮个忙，不是来签卖身契的。
- **法律判定**：老张没有签字同意这多出来的20万，所以多出来的20万老张**绝对不保**！老张依然只对原有的100万承担保证责任。
- 反之，如果是小李免除了老王20万债务（主债务变成80万）。债务减少了，老张的担保责任也自动降到80万（减轻了，老张当然愿意，所以继续保80万）。

##### 场景二：最致命的“偷偷延期”（期限变动）

老王欠小李100万，约定2026年6月1日到期。老张提供保证（未约定保证期间，法定6个月，算到12月1日）。 到期前，老王哀求小李：“手头紧，再给我一年时间，改到2027年6月1日还吧。”小李心软同意了，双方签了延期协议，但没让老张签字。

- **小李的如意算盘**：主债到期日变成2027年6月1日了，那老张的保证期间应该也自动顺延到2027年6月1日开始起算。
- **法律无情打脸**：未经保证人书面同意，保证期间**绝不顺延**！老张的保证期间依旧死死卡在**原合同到期日（2026年6月1日）**起算，到2026年12月1日截止。
- **致命后果**：到了2026年12月1日前，小李因为和老王签了延期协议，老王要到2027年才违约。小李这期间没办法起诉老王（一般保证），也没办法找老张要钱（连带保证）。小李只能眼睁睁地看着老张的保证期间在12月1日悄然过期。2027年新履行期届满时，老张早已免责脱身了！

##### 场景三：换老板可以，换下属不行（债转与债移）

老王欠小李100万，老张提供保证。

- **换债权人（债权转让）**：小李把这100万债权卖给了老赵，并发微信通知了老王和老张。
    - **大白话**：对老张来说，替老王还钱，还给小李还是还给老赵没有本质区别。所以，换债权人**不需要老张同意**，老张在原范围内继续对老赵承担保证责任。
- **换债务人（债务转移）**：老王不想还钱了，跟小李商量：“我这100万债务转给我手下的流浪汉小二吧。”小李竟然同意了，但老张根本不知道。
    - **大白话**：老张是看在老王有资产才给他担保的。现在把债务转给一穷二白的小二，这等于百分之百要老张出来掏钱！
    - **法律判定**：债务人换人，老张没有书面签字同意，老张的保证责任直接**当场消灭**！
- **多一个债务人（债务加入）**：老王不仅自己不走，还拉了有钱的老赵加入进来一起还这100万。
    - **大白话**：原债务人没变，还多了一个还款人，老张的风险反而降低了。这叫债务加入，老张对全部债务**继续承担保证责任**。

####  一句话闭环记忆

> **未经保证人书面同意的：变期限保证期间不顺延；加重部分不用担；债权转让继续保；债务转移直接脱免保证责任，而债务加入保证人不得脱免！**。

### 第五步：[[混合担保]]——谁先实现 + 谁能向谁追偿（§392 / §700 / 解释§13）

> 在搞定前四步保证合同的内部分析后，我们要推开门，看看保证人与其他担保人并存时的外部修罗场. 这关乎债权人拿钱时的“排兵布阵”，以及担保人垫钱后的“利益清算”，其中**第三人担保人互不追偿**是近几年必考的超级红线

> **“主物在先，客、人择一；代偿皆可追债务；第三人担保互不追，除非同签一合同。”**

- **“主物在先，客、人择一”**（《民法典》§392）：在混合担保（物保+人保）且没有约定顺序时：如果物保是**主债务人（主）**自己的财产，债权人**必须先**强制实现该物保；如果物保是**第三人（客）**的财产，则第三人物保与保证人（人）地位平等，债权人可以**任意选择**实现顺序。

- **“代偿皆可追债务”**（《民法典》§700）：无论哪个担保人替债务人还了钱（即便是部分清偿），都有权在代偿范围内向**主债务人**全额追偿（并可代位行使债权人对债务人的权利）。

- **“第三人担保互不追，除非同签一合同”**（《担保制度解释》§13）：**重磅反转！** 替债务人背锅的两个第三人（比如保证人老张与提供抵押的第三人老赵）之间，**原则上不得相互追偿**。只有3个例外（约定互追、约定连带共同担保、或在**同一份合同书**上签字盖章）才可以按份分担.

#### 2. 大白话讲解

#####  场景一：实现顺序——谁抵押的物谁先死

老王跟小李借了1000万，到期不还。

- **情形一（主物在先）**：老王拿了**自己**的别墅做抵押（价值800万），老张提供保证。
    - **大白话**：老王自己欠的钱，他自己的财产理应第一个拿去填坑。如果先执行保证人老张，老张回头还要告老王，白白折腾司法资源。
    - **法律规定**：小李必须先去拍卖老王的别墅，拿到800万后，剩下的200万才能找老张要。
- **情形二（客、人平等）**：老王的兄弟老赵拿出了别墅做抵押（第三人物保），老张提供保证。
    - **大白话**：老赵和老张都是替老王拔刀相助的“老铁”，地位平等，法律不偏袒任何一个。
    - **法律规定**：小李爱找谁找谁。他可以先去拍卖老赵的别墅，也可以直接找老张要1000万，没有任何先后顺序限制。

##### 场景二：各扫门前雪——担保人之间“互不追偿”

承接上面的“情形二”：老赵（第三人物保）和老张（人保）共同为老王担保1000万。 小李觉得老张有钱，直接起诉老张。法院判决老张全额还款，老张含泪给小李打过去1000万。

- **老张想**：大家都是做担保的，凭什么我一个人全赔？老赵也有抵押房产，我要找老赵追偿500万！
- **法律无情判定**：老张，你**一分钱都不能**问老赵要！
- **大白话**：这就是《担保制度解释》第十三条新规。老赵和老张之间没有约定，老张凭什么找老赵要钱？老张只能老老实实去找**主债务人老王**全额追偿。如果老王没钱，老张自己认栽。
- **老张如何才能找老赵要钱？（三例外）**
    
    1. 老张和老赵私下签过分担协议（**约定互追**）。
    2. 合同里写了“老张和老赵承担连带共同担保”（**连带共同担保**）。
    3. 老张和老赵在**同一份保证抵押合同**上，肩并肩一起签了字盖了章（**同一合同书签字**）。
    
    - 只有这三类情况，老张代偿后才能去找老赵按比例追回一部分。

#### 场景三：法定代位——部分还钱也能追

老王欠小李100万，老张提供保证。老王逾期，小李向法院申请，直接从老张的银行账户里强行划扣了18万元。

- 老张当即起诉老王，要求老王把这18万还给他。
- 老王辩称：“小李的100万你只帮我还了18万，小李这债权人还没拿够钱呢，你不能找我追！”
- **法律判定**：老王在胡搅蛮缠！根据《担保制度解释》第十八条，只要保证人实际被执行或代偿了部分资金（18万），他就有权在18万范围内**立刻向债务人追偿**，不需要等债务全部结清。



[[民法-物权-共同担保人追偿权模型]]


> 📖 **概念详解** → [[混合担保]]（§392 实现顺序 + §700 追偿 + 解释§13 互不追偿，含对照表与老王小李故事）

**铁则**：
- **实现顺序（§392）**：有约定按约定；无约定 / 不明，**看那个物保是"谁"提供的**——
  - **债务人自己的物保 vs 保证** → 债权人**必须先**实现债务人自己的物保，不足才找保证人（债务人自己的财产是第一还款来源；让保证人先赔、再回头追债务人，徒增环节）。
  - **第三人的物保 vs 保证** → 债权人**可择一**（拍第三人的物 / 找保证人都行，**不分先后**；两者都是"替债务人扛"的第三人，地位平等）。
- **对债务人追偿（§700）**：**前提**＝保证人**已实际承担**保证责任（代偿 / 被扣划 / 被执行）；担责后**在承担范围内向债务人追偿** + **[[法定代位]]**债权人对债务人的权利（含原担保物权等从权利，不得损害债权人利益）。
  - 🪤 **部分清偿即可追**：付了多少就能就该部分向债务人追偿，**不以债权人全部受偿为前提**（担保解释§18；**单选-30 的 C 错点**）。
  - 📌 **追偿主体**：领营业执照的**分支机构**可作诉讼当事人、**以自己名义**追索（**单选-30 的 D**）。
- **第三人担保人之间（解释§13）**：**原则上不得相互追偿**；**3 例外**才可按份分担：①约定相互追偿及份额 ②约定连带共同担保 ③在**同一份合同书**上签字盖章。

**老王小李例子**（= [[典型合同-多选-34|多选-34]]）
- 甲借乙 1000 万，丙在保证人栏盖章（未写方式）、丁以自有房抵押。→ 丙=**一般保证**（§686，A 对）；丙 / 丁担责后都能找**债务人甲**追偿（§700，C/D 对）；但丁**不能**找丙追偿（第三人担保人互不追偿，解释§13，**B 错**——本题无 3 例外）。
- 🆚 **实现顺序——看物保是谁的**（乙借给甲 100 万，到期甲不还）：
  - **甲自己的房**抵押 + 丙保证 → 乙**必须先拍甲的房**受偿，不足部分才找丙（债务人自己物保**强制先实现**，§392）。
  - **丁（第三人）的房**抵押 + 丙保证 → 乙**可择一**：拍丁的房、或直接找丙，**随便选、不分先后**（丁、丙都是第三人担保，地位平等）。
  - 谁垫了钱（丙或丁）→ 都可向**债务人甲**追偿（§700）；但丁、丙**之间**原则**互不追偿**（解释§13）。

## 三、命题人最爱的 6 个陷阱

1. **方式不明记成"连带"** —— 错！2021 起**推定一般保证**（§686）。
2. **保证期间"约定不明 = 2 年"** —— 错！现行法**一律 6 个月**（§692 / 解释§32，"本息还清为止"也是 6 个月；2 年是**已废止**的旧担保法解释）。
3. **保证期间会中止 / 中断 / 延长** —— 错！保证期间**不变动**（≠诉讼时效）；过了不主张，保证人免责。
4. **连带保证人也有先诉抗辩权** —— 错！**只有一般保证人有**（§687）；连带无（§688）。
5. **第三人担保人之间可相互追偿** —— 错！**原则不互相追偿**（解释§13），除三例外（约定 / 连带共同担保 / 同一合同书签字）；但**都能向债务人追偿**（§700）。
6. **债务转移 / 主债加重，保证人当然继续全担** —— 错！债务转移须保证人**书面同意**否则免责（§697）；主债**加重**部分保证人**不担**（§695）。
