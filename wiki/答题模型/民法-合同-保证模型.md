## 一、核心考情

- **频率**：[[保证合同]] ★★★★★，单选 / 多选高频，**主观题担保重中之重**；几乎必与物权编担保物权（抵押 / 质押 / 混合担保）串考。
- **命题核心**：专挑 **2021 反转点**设陷阱（方式推定、保证期间、互不追偿），再叠加"一般 vs 连带""主债变动是否免责""混合担保谁先实现 + 谁能向谁追偿"。
- **五大必考点**：①保证人资格 ②方式推定（→ 先诉抗辩权）③保证期间 6 个月 ④主债变动是否免责 ⑤混合担保实现顺序 + 追偿。

## 二、万能五步模型

### 第一步：是不是有效保证？（成立 + 资格）

**铁则**：
- **成立**：在合同 / 单据"**保证人**"栏签字盖章、或出具保函，即成立保证（§685）。
- **资格（§683 + 担保解释§11）——分四类记**：
  - **§683 明文禁两类**（有主体资格、但政策禁止）：① **机关法人**（除经国务院批准为转贷）；② **以公益为目的的非营利法人、非法人组织**（公办学校 / 幼儿园 / 医院、公益社团等）。违反 → **保证合同无效**，按 [[担保]] 无效的过错分责（担保解释§17）。
  - **内设机构 / 职能部门**（如"董事长办公室""财务处"）：**无独立民事主体资格** → 根本不能作保证人（主体不适格，**不是 §683**）。
  - **分支机构**（领营业执照、可自己名义活动）：有相对独立地位，但**对外担保需经公司决议**（**担保解释§11**）；未经决议以自己名义担保、相对人非善意的，公司不担责。⚠️ 旧担保法§10"分支机构经法人**书面授权**即可"的旧说法**已被"决议"规则取代**。
  - **自然人**：有完全民事行为能力即可；**负债累累不影响资格**（清偿能力 ≠ 资格）。

### 第二步：哪种保证方式？→ 决定有没有"先诉抗辩权"（§686-688）

> 🔑 **一句话判断**：合同**写明"连带"**（或约定"债务人不履行时债权人可直接找保证人"）→ **连带保证**；其余一切——**没约定 / 约定不明 / 只写"一般保证" / 写"债务人不能清偿时由保证人承担"** → 一律 **一般保证**（§686 默认）。

**铁则**：
- **方式不明 → 推定一般保证**（§686，**2021 反转旧法"连带"**）。
- **一般保证**：保证人有**先诉抗辩权**（§687）——主合同未经审判 / 仲裁并就债务人财产强制执行**仍不能履行前，可拒绝担责**；
- **4 种丧失**（§687Ⅱ：债务人下落不明且无财产 / 受理破产 / 债权人证明财产不足 / **书面放弃**）。
- **连带责任保证**：**无**先诉抗辩权（§688）——债务人到期不还，债权人**可直接**找保证人。
> 📐 先诉抗辩权 vs 三大履行抗辩权的辨析 → [[民法-合同-履行抗辩权模型]]「易混辨析 A」。

**老王小李例子**
- 老赵在保证人栏盖章但**没写方式** → **一般保证**（§686）；乙公司须**先告债务人甲、执行甲的财产**，不足才找老赵（§687）。若白纸黑字写"连带责任保证" → 甲一违约，乙可**直接**找老赵（§688）。

### 第三步：保证期间（默认 6 个月 · 除斥 · 从主债到期起算）（§692 + 解释§32）

**一句话定义**：保证期间 = **从主债务到期日起算、债权人必须在内向对方"主张"的固定期间**；**过期不主张 → 保证人彻底免责**。

**铁则**：
- **起算**：主债务履行期**届满之日**（§692Ⅱ）。
- **长度**：①约定**明确且合法**的 → 从约定（**可长于 6 个月**，如约定 2 年就 2 年）；②**没约定 / 约定不明**（含"保证至**本息还清为止**"等类似）→ **6 个月**（解释§32，**旧法"2 年"已废止**）；③约定**早于 / 同于**主债到期 → 视为没约定 → **6 个月**。
- **性质**：**除斥期间**——**不中止、不中断、不延长**（≠诉讼时效，**最爱考**）。
  - 💡 **除斥＝某项权利的"固定存续期"**：到期权利**本身消灭**、不能续，法院可**依职权**审查（区别于诉讼时效：可中断重来、过期只给对方抗辩权、须当事人主张）。
- **期间内要干什么**：**一般保证** → 对**债务人**起诉 / 仲裁（因保证人有先诉抗辩权）；**连带保证** → 直接**请求保证人**担责。
- **后果**：没在期间内主张 → **保证人免责**（保证责任消灭）。
- **衔接（§694）**：在期间内主张后 → 进入**保证债务诉讼时效（3 年）**（期间 → 时效接力，见下表 / 时间轴）。**但两种保证的"时效起算点"不同**：
	  - **连带保证**：从**债权人请求保证人之日**起算（主张即起算，**无空档**）。
	  - **一般保证**：从**"先诉抗辩权消灭之日"**起算——即担保解释§28：对债务人财产强制执行的**终本裁定送达债权人之日**。**注意**：在期间内起诉债务人（主张）与时效起算之间**有空档期**，不是"起诉就起算"；旧法"裁决生效之日"已废止。

**时间轴**（债权人乙、债务人甲、保证人老赵；没约定保证期间）

```
6/1 主债到期 ──── 保证期间 6 个月（除斥·不变动）──── 12/1 期间届满
       │                                              │
       └ 乙必须在 6/1~12/1 内"主张"                     └ 没主张 → 老赵免责
                 │
                 └ 在期间内主张了 → 才开始算"保证债务诉讼时效"（3 年·§694）
```

- **起算 = 主债到期日**（§692Ⅱ）；默认长度 **6 个月**。
- 期间内"主张"指：一般保证 → **对债务人甲**起诉 / 仲裁；连带保证 → **请求保证人老赵**担责。
- ⏱️ **诉讼时效何时起跑（接力点，一般 / 连带不同）**：**连带保证**从"请求保证人之日"即起算；**一般保证**虽在期间内对债务人起诉，但保证债务诉讼时效要等"**先诉抗辩权消灭之日**"（担保解释§28 终本裁定送达日）才起算，与起诉之间**有空档期**。⚠️ 上面时间轴是简化示意——老赵若按第二步认定为**一般保证**，那"3 年"实际从先诉抗辩权消灭日起跑，而非起诉甲当天。
- 🪤 合同写"老赵保证到**本息还清为止**" → 视为约定不明 → **6 个月**（不是 2 年！§692/解释§32）。

**📊 两个期间别混（高频）**

| 维度  | 保证期间                  | 保证债务诉讼时效          |
| --- | --------------------- | ----------------- |
| 起算  | 主债**到期日**             | **连带**：请求保证人之日；**一般**：先诉抗辩权消灭之日（担保解释§28 终本裁定送达·有空档）（§694） |
| 长度  | 默认 **6 个月**           | **3 年**           |
| 性质  | **除斥**（不中止 / 中断 / 延长） | 诉讼时效（可中止 / 中断）    |

> 一句话：**保证期间是"债权人限期出手"的除斥窗口（债务到期起 6 个月）；窗口内出手了才接着跑 3 年保证债务诉讼时效；窗口没赶上 → 保证人直接免责。**

### 第四步：主债务变动，保证人还担不担？（§695-697）

**铁则**：
- **主债务履行期变更（§695Ⅱ）**：未经保证人**书面同意**延长 / 缩短履行期 → **保证期间不受影响＝仍按"原"履行期起算、绝不跟着顺延**（保护保证人，免被偷偷延长责任）；**只有保证人书面同意，才跟新期走**。
- **主合同内容变更（§695Ⅰ）**：**减轻**债务 → 保证人对变更后债务担责；**加重**债务 → 保证人对**加重部分不担责**。
- **债权转让（§696）**：保证债权**一并转移**，保证人对受让人继续担责（除非约定禁转 / 仅对特定债权人保证）。
- **债务转移（§697）**：未经保证人**书面同意**转移债务的，保证人**对未经同意转移的部分不再担责**（债务人换人 / 加人须保证人点头）。
  - 🆚 **债务加入（并存承担 §552）≠ 债务转移**：债加入原债务人**没走**，保证人对**全额仍担**（没减责）；只有**免责的债务转移**才触发 §697 脱责。
- **免除（§575）**：债权人免除部分主债 → 主债消灭、降额，属"减轻"，保证人对**减轻后**继续担保（§695Ⅰ）。
- **限额保证算账顺序**：先卡**约定限额**，再依次扣"免除 / 转移脱责"的部分（见真题演练单选-31）。

**📊 主债一变 · 判断表（未经保证人书面同意时）**

| 主债怎么变 | 保证人后果 | 法条 |
| --- | --- | --- |
| 减轻 / 免除（金额↓） | 对**减轻后**仍担保 | §695Ⅰ前 + §575 |
| 加重（金额↑ / 义务加重） | 对**加重部分不担**、只担原额 | §695Ⅰ后 |
| 履行期限变更 | **保证期间不受影响**（按原期、不顺延） | §695Ⅱ |
| 债权转让（换债权人） | 保证**随主债权转移**、继续担（**不需保证人同意**） | §696 |
| 债务转移（换 / 减债务人） | 对**未经同意转移部分不再担** | §697 |
| 债务加入（原债务人没走） | 对**全额仍担**（不受影响） | §552 |

> 📐 **一句话**：减轻跟着减、加重不担加；期限偷改不顺延；债权换人保证跟着走、债务换人没问我就脱责、债加入不算变。**一切"加重 / 换债务人"都要保证人书面点头。**

**老王小李例子**
- 甲乙**没问老赵**就把还款期从 1 年延到 2 年 → 老赵的保证期间**仍从"原 1 年到期日"起算、不顺延**到第 2 年（§695Ⅱ）。
  - ⚠️ 直觉以为"债延长、保证期也跟着顺延"——**正相反**：没经老赵**书面同意**，顺延不了，这恰恰是**保护**老赵（你们偷偷延期，别连累保证人）。
  - 实际效果：债延到第 2 年才到期，可老赵的保证期间按**原期**早早届满 → 债权人这段时间无从有效主张 → **老赵几乎必然免责**。

  **时间轴**（原 1 年期 2026/6/1 到期；甲乙偷偷延到 2027/6/1、没问老赵）

  ```
  2026/6/1 原到期 ──保证期间 6 个月（从"原期"算）──→ 2026/12/1 保证期间届满
          延期到 2027/6/1（未经老赵书面同意）→ 不顺延
          └ 老赵保证期间仍在 2026/12/1 结束；可债要到 2027 才到期、
            债权人这期间无从对债务人有效主张 → 老赵免责
  ```

- 甲把债务**转给**丙、**没经老赵书面同意** → 老赵对转移部分**不再担责**（§697）。

### 第五步：混合担保——谁先实现 + 谁能向谁追偿（§392 / §700 / 解释§13）

> 📖 **概念详解** → [[混合担保]]（§392 实现顺序 + §700 追偿 + 解释§13 互不追偿，含对照表与老王小李故事）

**铁则**：
- **实现顺序（§392）**：有约定按约定；无约定 / 不明，**看那个物保是"谁"提供的**——
  - **债务人自己的物保 vs 保证** → 债权人**必须先**实现债务人自己的物保，不足才找保证人（债务人自己的财产是第一还款来源；让保证人先赔、再回头追债务人，徒增环节）。
  - **第三人的物保 vs 保证** → 债权人**可择一**（拍第三人的物 / 找保证人都行，**不分先后**；两者都是"替债务人扛"的第三人，地位平等）。
- **对债务人追偿（§700）**：**前提**＝保证人**已实际承担**保证责任（代偿 / 被扣划 / 被执行）；担责后**在承担范围内向债务人追偿** + **[[法定代位]]**债权人对债务人的权利（含原担保物权等从权利，不得损害债权人利益）。
  - 🪤 **部分清偿即可追**：付了多少就能就该部分向债务人追偿，**不以债权人全部受偿为前提**（担保解释§18；**单选-30 的 C 错点**）。
  - 📌 **追偿主体**：领营业执照的**分支机构**可作诉讼当事人、**以自己名义**追索（**单选-30 的 D**）。
- **第三人担保人之间（解释§13）**：**原则上不得相互追偿**；**3 例外**才可按份分担：①约定相互追偿及份额 ②约定连带共同担保 ③在**同一份合同书**上签字盖章。

**老王小李例子**（= [[典型合同-多选-34|多选-34]]）
- 甲借乙 1000 万，丙在保证人栏盖章（未写方式）、丁以自有房抵押。→ 丙=**一般保证**（§686，A 对）；丙 / 丁担责后都能找**债务人甲**追偿（§700，C/D 对）；但丁**不能**找丙追偿（第三人担保人互不追偿，解释§13，**B 错**——本题无 3 例外）。
- 🆚 **实现顺序——看物保是谁的**（乙借给甲 100 万，到期甲不还）：
  - **甲自己的房**抵押 + 丙保证 → 乙**必须先拍甲的房**受偿，不足部分才找丙（债务人自己物保**强制先实现**，§392）。
  - **丁（第三人）的房**抵押 + 丙保证 → 乙**可择一**：拍丁的房、或直接找丙，**随便选、不分先后**（丁、丙都是第三人担保，地位平等）。
  - 谁垫了钱（丙或丁）→ 都可向**债务人甲**追偿（§700）；但丁、丙**之间**原则**互不追偿**（解释§13）。

## 三、命题人最爱的 6 个陷阱

1. **方式不明记成"连带"** —— 错！2021 起**推定一般保证**（§686）。
2. **保证期间"约定不明 = 2 年"** —— 错！现行法**一律 6 个月**（§692 / 解释§32，"本息还清为止"也是 6 个月；2 年是**已废止**的旧担保法解释）。
3. **保证期间会中止 / 中断 / 延长** —— 错！保证期间**不变动**（≠诉讼时效）；过了不主张，保证人免责。
4. **连带保证人也有先诉抗辩权** —— 错！**只有一般保证人有**（§687）；连带无（§688）。
5. **第三人担保人之间可相互追偿** —— 错！**原则不互相追偿**（解释§13），除三例外（约定 / 连带共同担保 / 同一合同书签字）；但**都能向债务人追偿**（§700）。
6. **债务转移 / 主债加重，保证人当然继续全担** —— 错！债务转移须保证人**书面同意**否则免责（§697）；主债**加重**部分保证人**不担**（§695）。

## 📐 口诀

> **"保证人栏没写方式＝一般保证（§686 反转）；一般保证才有先诉抗辩、连带没有。**
> **保证期间一律六个月（约定不明、本息还清也是六个月，不是两年！），过期不主张保证人免责。**
> **债务转移、主债加重——没书面同意保证人免责。**
> **混合担保：债务人自己的物先卖；谁垫了钱都能找债务人，但第三人担保人之间互不追（解释§13）。"**
