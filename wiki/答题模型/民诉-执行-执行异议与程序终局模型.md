# 📐 执行异议与程序终局 · 完整答题模型（执行救济二元结构 + 执行异议之诉 + 中止终结终本 + 执行回转 + 检察监督）

> **核心一句**：执行救济是执行编**最高阶的陷阱区**，全部难点都压在一句判别上——**你到底是"嫌执行的动作违法"，还是"嫌执行错了别人的东西"？** 前者是**执行行为异议（§236）→ 走"复议"、向上一级法院**；后者是**案外人执行标的异议（§238）→ 走"执行异议之诉"、向执行法院，且不服还要再分流"与原判决裁定有关走再审 / 无关走异议之诉"**。最毒陷阱是**把两条道路的期限、救济出口、管辖法院互相张冠李戴**，以及**把"终本"当成"终结执行"、把"执行回转"当成"再审"**。
>
> 🔎 **《民事诉讼法》（2023修正）核心条文速查**：
> - **第236条【执行行为异议→复议】**：当事人、利害关系人认为**执行行为违反法律规定**的，可以向**负责执行的人民法院**提出书面异议。人民法院应当自收到书面异议之日起**15日内审查**，理由成立的裁定撤销或者改正、理由不成立的裁定驳回。当事人、利害关系人对裁定不服的，可以**自裁定送达之日起10日内向上一级人民法院申请复议**。
> - **第238条【案外人对执行标的异议→再审 / 执行异议之诉】**：执行过程中，**案外人对执行标的**提出书面异议的，人民法院应当自收到书面异议之日起**15日内审查**，理由成立的裁定**中止对该标的的执行**、理由不成立的裁定驳回。案外人、当事人对裁定不服，**认为原判决、裁定错误的，依照审判监督程序办理**；**与原判决、裁定无关的，可以自裁定送达之日起15日内向人民法院提起诉讼【执行异议之诉】**。
> - **第244条【执行回转】**：执行完毕后，据以执行的判决、裁定和其他法律文书**确有错误被撤销的**，对已被执行的财产，人民法院应当作出裁定，**责令取得财产的人返还；拒不返还的，强制执行**。
> - **第246条【执行检察监督】**：人民检察院有权对**民事执行活动**实行法律监督。
> - **第267条【应当中止执行】** / **第268条【应当终结执行】**：法定情形见下文第三/五步。
> - **《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（法释〔2022〕11号）**：§302 执行异议之诉由**执行法院管辖**；§303/§304 案外人 / 申请执行人异议之诉的**起诉条件**；§305/§306 两类异议之诉的**当事人地位**；§308 适用**普通程序**；§309 **案外人举证证明**对执行标的享有足以排除强制执行的民事权益；§421 **案外人自执行异议裁定送达之日起6个月内向原判法院申请再审**；§517 **终结本次执行程序（终本）**。

> ⚠️ **诚实标注（条号核验说明 + 深度报告订正）**：
> ①本模型对**民诉法§236/§238/§244/§246/§267/§268** 与**民诉解释§302~§313/§421/§517** 全部条文，已在本地官方全文（ssf.gov.cn 民诉法2023、民诉解释2022）逐条 grep 核到原文，条号与文字准确、可信度高。
> ②**深度报告条号勘误（重要）**：深度报告将"执行行为异议"标注为 **§232**、将"案外人对执行标的异议"标注为 **§234**，此系 **2021 年旧版条文号，已过时错误**。经本地 2023 现行全文核验，正确条号应为 **§236（执行行为异议）** 与 **§238（案外人对执行标的异议）**，本模型已按现行法订正。§234 现行内容实为"利害关系人未在判决前申报的起诉期"，与执行救济无关。
> ③🆕**《执行异议之诉解释》法释〔2025〕10号（据称 2025-07-24 施行、23 条）**：深度报告标注"机构提示未入大纲仍可考、待核"。**本地库无该 2025 新解释全文**，故本模型**不为其编造任何具体条文号**；其可能细化执行异议之诉的受理、审理、既判力等规则，考生可关注官方 [flk.npc.gov.cn](http://flk.npc.gov.cn) 发布，但**是否纳入 2026 法考大纲、具体条文均以官方为准，本模型不硬安条号**。现行答题一律以民诉法§236/§238 + 民诉解释§302~§313 为准即可。

> ⚠️ **易记错点**：①**"执行行为异议"救济是"复议"（向上一级法院、10日），"案外人执行标的异议"救济是"起诉/再审"（向执行法院、15日）**——两条路的期限（10日 vs 15日）、出口（复议 vs 诉讼）、法院（上一级 vs 执行法院）全部相反，命题人最爱互换；②**案外人异议"理由成立"是"中止对该标的的执行"，不是"终结"、更不是"撤销执行行为"**（§236行为异议成立才是"撤销或改正"）；③**案外人异议被"程序性不予受理"（如重复异议）→ 走§236复议，不是异议之诉**（异议之诉须以异议经实体审查裁定驳回为前置）；④**执行异议之诉无论谁当原告，举证责任都在"案外人"**（§309），命题人爱说"申请执行人起诉就由申请执行人举证"；⑤**"终结本次执行程序（终本）"≠"终结执行"**——终本是"暂时查无财产、以后发现可再申请"，终结执行是"程序彻底了结、不再恢复"；⑥**"执行回转"是文书被撤销后责令返还已执行财产（§244），不是再审、也不是国家赔偿**；⑦**拍卖成交、价款付清后案外人再提异议的，法院不予受理**（既成事实、交易安全优先）。

## 二、 判别模型（二元分流：针对行为 vs 针对标的）

```
              【执行程序进行中，有人不满，要救济】
                            │
     ▼ 总闸：你不满的到底是什么？（执行救济二元结构 · 最核心一问）
     │
     ├───────────────【路线一】嫌"执行的动作违法"────────────────┐
     │   （查封超标的额、拍卖程序违法、评估瑕疵、罚款过高、           │
     │    以"重复异议"程序性不予受理……都是对"执行行为"不满）        │
     │                                                          │
     │   § 236 执行行为异议：                                     │
     │   ├─ 主体：当事人、利害关系人                               │
     │   ├─ 向"负责执行的人民法院"提书面异议                        │
     │   ├─ 法院 15日内审查：成立→裁定撤销/改正；不成立→驳回          │
     │   └─ 不服 → 自裁定送达之日起【10日内】向【上一级法院】申请复议  │
     │              （出口是"复议"，不是诉讼！）                     │
     │
     └───────────────【路线二】嫌"执行错了别人的东西"──────────────┐
         （案外人主张被执行的标的物是"我的"，请求停止执行）           │
                                                                  │
         § 238 案外人对执行标的异议：                               │
         ├─ 主体：案外人                                          │
         ├─ 向执行法院提书面异议，法院 15日内审查                    │
         ├─ 理由成立 → 裁定【中止对该标的的执行】（不是"终结"）        │
         ├─ 理由不成立 → 裁定驳回                                  │
         │                                                       │
         └─ 对审查裁定不服，再分两条流（关键二次分流）：              │
             ├─（A）认为【原判决/裁定错误】、与原裁判"有关" ──→        │
             │      走【审判监督程序】= 案外人申请再审               │
             │      （§421：裁定送达之日起【6个月】内向原判法院）      │
             └─（B）与原判决/裁定"无关"（纯粹自己的实体权利）──→       │
                    自裁定送达之日起【15日内】向执行法院              │
                    提起【执行异议之诉】（§302执行法院管辖·§308普通程序）
                            │
     ▼ 执行异议之诉怎么打？（当事人地位·举证）
     │
     ├─ 案外人异议之诉(§305)：以【申请执行人】为被告；
     │     被执行人"反对案外人异议"→列为共同被告；"不反对"→列为第三人
     ├─ 申请执行人异议之诉(§306，前提是异议已致中止执行§304)：
     │     以【案外人】为被告；被执行人"反对申请执行人"→案外人+被执行人共同被告；
     │     "不反对"→列被执行人为第三人
     └─ 举证(§309)：无论谁当原告，【案外人】都要就"对执行标的享有
           足以排除强制执行的民事权益"承担举证证明责任
                            │
     ▼ 收尾：这个执行程序最终怎么了结？
     │
     ├─ 中止执行(§267)：情形消失后【恢复】——如案外人异议确有理由、一方死亡待继承
     ├─ 终结执行(§268)：程序彻底【了结不再恢复】——如文书被撤销、撤回申请、赡养费权利人死亡
     ├─ 终结本次执行/终本(§517)：查无财产→暂时了结，发现财产【可再申请】、不受时效限制
     ├─ 执行回转(§244)：文书被撤销→责令取得财产人返还、拒不返还强制执行
     └─ 检察监督(§246)：检察院有权对民事执行活动实行法律监督
```

> **一句话总诀**：**「先问一句——嫌动作违法还是嫌执行错东西？嫌动作违法走§236行为异议、15日审查、不服10日内向上一级法院【复议】；嫌执行错东西走§238案外人标的异议、15日审查、成立【中止】不成立驳回，不服再分流——与原裁判有关走【再审6个月】、无关走【执行异议之诉15日】；异议之诉找执行法院、走普通程序、案外人恒担举证；收尾看中止（可恢复）/终结（了结）/终本（可再申请）/回转（返还）」**

## 三、 高频干扰选项（二元结构的错位陷阱）

命题人几乎所有"执行异议"陷阱，都是把两条道路的要素错位拼接：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **把"行为异议"救济说成"起诉"** | 当事人对查封行为违法不服的，应当向执行法院提起执行异议之诉。 | **❌ 错！行为异议救济是"复议"，不是诉讼。**§236：对执行行为异议裁定不服的，10日内向**上一级法院申请复议**；"执行异议之诉"只属于案外人标的异议（§238）这条线。 |
| **把"标的异议"救济说成"复议"** | 案外人对执行标的异议被驳回的，向上一级法院申请复议。 | **❌ 错！**§238：案外人对标的异议裁定不服，认为原裁判错误的走**再审**、与原裁判无关的**向执行法院提执行异议之诉**（15日内），根本没有"向上一级法院复议"这条路。 |
| **异议成立="终结/撤销执行"** | 案外人异议理由成立的，法院应裁定终结执行。 | **❌ 错！**§238：案外人异议成立是裁定**"中止对该标的的执行"**（针对该标的、且可恢复）。"撤销/改正"是§236行为异议成立的效果，"终结执行"是§268的独立制度，三者不可混。 |
| **异议之诉举证跟着原告走** | 申请执行人提起执行异议之诉的，由申请执行人对标的权属举证。 | **❌ 错！**§309：**无论案外人还是申请执行人当原告，都由"案外人"就其对执行标的享有足以排除强制执行的民事权益举证**——因为主张"标的物是我的"的始终是案外人。 |
| **"终本"就是"终结执行"** | 查无可供执行财产的，法院裁定终结执行，程序结束。 | **❌ 错！**查无财产是**"终结本次执行程序（终本）"（§517）**，发现被执行人有财产**可以再次申请执行、不受时效限制**；"终结执行"（§268）是彻底了结、不再恢复，二者法律效果迥异。 |
| **文书被撤销走"再审/赔偿"** | 执行完毕后据以执行的判决被撤销，取得财产人应通过再审或国家赔偿返还。 | **❌ 错！**这是**"执行回转"（§244）**：法院直接**裁定责令取得财产的人返还、拒不返还的强制执行**，无需另行起诉或再审。 |

## 四、 相邻制度对照（本模型最核心：执行救济二元结构大表 + 三张配套表）

### 表1：执行救济二元结构（行为异议 §236 vs 案外人标的异议 §238）——必背主表

| 对比项 | **执行行为异议（§236）** | **案外人对执行标的异议（§238）** |
|---|---|---|
| 针对什么 | **执行行为违法**（查封/拍卖/评估/罚款等程序） | **执行标的错误**（案外人主张标的物实体权利足以排除执行） |
| 主体 | **当事人、利害关系人** | **案外人**（非本案当事人） |
| 向谁提异议 | 负责执行的人民法院（执行法院） | 执行法院 |
| 审查期限 | **15日内**审查 | **15日内**审查 |
| 成立的效果 | 裁定**撤销或改正**执行行为 | 裁定**中止对该标的的执行** |
| 不成立 | 裁定驳回 | 裁定驳回 |
| **不服后走向** | **自裁定送达10日内 → 向【上一级法院】申请【复议】** | **认为原判决裁定错误（有关）→ 审判监督程序【申请再审】（6个月）**；<br>**与原判决裁定无关 → 自裁定送达15日内向【执行法院】提【执行异议之诉】** |
| 终局出口 | 复议（非诉讼） | 再审 或 执行异议之诉（诉讼） |

> ⚠️ **一眼锁死**：行为异议→**复议·10日·上一级法院**；标的异议→**诉讼/再审·15日或6个月·执行法院/原判法院**。期限、出口、法院三个维度全部相反。

### 表2：两类执行异议之诉的当事人地位（§305 案外人异议之诉 vs §306 申请执行人异议之诉）

| 对比项 | **案外人执行异议之诉（§305）** | **申请执行人执行异议之诉（§306）** |
|---|---|---|
| 提起前提 | 案外人异议**被裁定驳回**（继续执行） | 依案外人异议，法院已**裁定中止执行**（§304） |
| 谁当原告 | **案外人** | **申请执行人** |
| 原则被告 | **申请执行人** | **案外人** |
| 被执行人"反对异议方主张" | 列为**共同被告** | **案外人 + 被执行人**共同被告 |
| 被执行人"不反对" | 列为**第三人** | 列被执行人为**第三人** |
| 管辖 | 执行法院（§302） | 执行法院（§302） |
| 程序 | 普通程序（§308） | 普通程序（§308） |
| 举证责任 | **案外人**举证（§309） | 仍是**案外人**举证（§309） |

> 记忆钥匙：**"被告永远是对面那个人"**——案外人告，被告是申请执行人；申请执行人告，被告是案外人。**被执行人看态度**：反对异议方就升格共同被告、不反对就降为第三人。**举证永远压在案外人身上**（他才是主张"标的物是我的"那个人）。

### 表3：案外人三大救济择一（对象不同，别混用）

| 救济方式 | 适用情形 | 针对对象 | 期限/条件 | 法条 |
|---|---|---|---|---|
| **执行异议之诉** | 案外人异议被驳回，主张的实体权益**与原判决裁定无关** | **执行标的**（执行行为错了别人的物） | 异议驳回裁定送达**15日内**，向执行法院 | §238 + 解释§303 |
| **申请再审（审判监督）** | 案外人异议被驳回，**认为原判决/裁定本身错误**、损害其权益（与原裁判"有关"） | **原生效裁判** | 异议裁定送达**6个月内**，向原判法院 | §238 + 解释§421 |
| **第三人撤销之诉** | 因不能归责于己的事由未参加诉讼，生效裁判**内容错误损害其权益**（不以先经执行异议为前提） | **原生效裁判** | 自知道或应当知道之日起**6个月内** | 民诉法§59 III |

> ⚠️ **辨析**：案外人**不能"直接"申请再审**（须先经§238执行异议、被驳回，认为原裁判错误的才转入审判监督）；三者是"择一/竞合"关系，命题人爱设"直接申请再审"（跳过异议前置）为错误项（见真题281 A项）。

### 表4：中止执行 vs 终结执行 vs 终结本次执行（终本）

| 对比项 | **中止执行（§267）** | **终结执行（§268）** | **终结本次执行/终本（解释§517）** |
|---|---|---|---|
| 性质 | 暂停，**情形消失后恢复** | **彻底了结，不再恢复** | 暂时了结，**发现财产可再申请** |
| 典型情形 | 申请人同意延期；**案外人异议确有理由**；一方公民死亡待继承；法人终止未定承受人 | 撤回申请；**据以执行的文书被撤销**；被执行公民死亡无遗产无义务承担人；追索赡养/扶养/抚养费权利人死亡；被执行公民生活困难无力偿还无收入又丧失劳动能力 | **经财产调查未发现可供执行财产** |
| 后续 | 恢复执行 | 程序消灭 | 发现财产**再次申请、不受申请执行时效限制** |

## 五、 万能五步答题模型

> 🚗 **统一案例**：甲持生效判决（判乙还款100万）申请执行，执行法院查封并拟拍卖乙名下一套登记在乙名下的房屋。执行推进中冒出两条不满：
> - **不满A（针对行为）**：乙认为法院查封的这套房是自己**唯一住房、且查封价值远超100万债权**，程序违法；
> - **不满B（针对标的）**：案外人丙拿着一份"该房早已卖给我并交付、只是没过户"的材料，主张房子是**自己的**，请求停止执行。
> 五步就用这一个案子把二元结构走通。

### 第一步：判"针对行为"还是"针对标的"——二元分流总闸

> **嫌动作违法找§236，嫌执行错东西找§238**

#### 概述

执行救济的一切判断，都从这一问开始：**不满的对象是"执行的动作"，还是"被执行的东西"？**
- 针对**执行行为**（查封、拍卖、评估、罚款、送达等程序动作违法）→ 走**§236 执行行为异议**；
- 针对**执行标的**（案外人主张标的物是自己的、请求排除执行）→ 走**§238 案外人执行标的异议**。
两条道路的主体、期限、救济出口、管辖法院全部不同，选错道路满盘皆输。

#### 大白话讲解

法院来查封乙的房子拍卖还债，现场冒出两个人不服气：

- **乙（本案被执行人）说**："你查封我这套房，一是它是我唯一的住房，二是它值300万、我才欠100万，你查封整套、程序不对！"——乙不满的是**法院查封这个"动作"违法**（超标的额查封），这是**对"执行行为"的异议**，主体是"当事人"，走**§236**。
- **丙（案外第三人）说**："等等，这房子两年前乙就卖给我、交给我住了，只是没来得及过户！你们执行的是**我的**房子！"——丙不满的是**法院执行错了标的物（把我的房当乙的房执行）**，这是**对"执行标的"的异议**，主体是"案外人"，走**§238**。

同一套房、同一次查封，两个人走的是**两条完全不同的救济轨道**：乙的路通向"复议"，丙的路通向"再审或执行异议之诉"。命题人最爱把这两个人的救济方式对调来挖坑。

| 谁不满 | 不满什么 | 身份 | 走哪条路 |
|---|---|---|---|
| 乙 | 查封这个动作违法（超标的额） | 当事人 | §236 执行行为异议 → 复议 |
| 丙 | 执行错了标的物（房子是我的） | 案外人 | §238 案外人标的异议 → 再审/异议之诉 |

#### 一句话闭环记忆

> 🎯 **一眼判**：先问一句"嫌动作违法（§236）还是嫌执行错东西（§238）"——当事人/利害关系人嫌**行为**违法走行为异议、通向复议；案外人嫌**标的**执行错了走标的异议、通向再审或执行异议之诉。一字定生死。

---

### 第二步：走行为异议路（§236）——15日审查，不服10日内向上一级法院复议

> **行为违法找执行法院，不服复议向上一级**

#### 概述

乙这条"执行行为异议"路径的完整走法（§236）：
- **谁提**：当事人、利害关系人；
- **向谁提**：负责执行的人民法院（执行法院）；
- **审查**：法院自收到书面异议起**15日内审查**——理由成立裁定**撤销或改正**，理由不成立裁定**驳回**；
- **不服怎么办**：自裁定送达之日起**10日内向【上一级】人民法院申请【复议】**（不是起诉、不是向原法院复议）。

特别注意：**"以重复异议为由不予受理"这种程序性处理，也是执行行为，不服同样走§236复议**，而不是执行异议之诉（异议之诉须以异议经实体审查驳回为前置）。

#### 大白话讲解

乙不服"查封整套房"，他该怎么走？

第一步，向**执行法院**（就是现在负责执行的这家法院，不是上一级）递一份**书面异议**："请依法解除对超出100万债权部分的查封。"

第二步，法院收到后**15天内**得给个说法：
- 如果乙说得对（确实超标的额查封），法院裁定**撤销或改正**——比如改成只查封相应价值份额；
- 如果法院认为查封没问题，裁定**驳回**。

第三步，乙对这个裁定还不服，**10天内**可以**往上捅一级**——向**上一级人民法院申请复议**。注意用词是"**复议**"（上级法院书面审查这个执行行为对不对），**不是"起诉"、不是"执行异议之诉"**，也**不是**再向原法院复议。

**顺带记一个真题高频变式**：假如乙的异议被法院以"你上次撤回过、这是重复异议"为由**不予受理**——这个"不予受理"仍然是**执行行为**（对程序事项的处理），乙不服照样走**§236向上一级法院复议**，而不能提执行异议之诉（因为异议根本没被"实体审查驳回"，不满足异议之诉前置）。

#### 一句话闭环记忆

> 🎯 **一眼判**：执行行为异议=当事人/利害关系人→执行法院→**15日审查**（成立撤销改正、不成立驳回）→不服**10日内向上一级法院【复议】**；连"重复异议不予受理"这种程序裁定，不服也走复议，不是异议之诉。

---

### 第三步：走标的异议路（§238）——15日审查，成立中止，不服再分流（再审 / 异议之诉）

> **标的异议成立就中止，不服有关走再审无关走诉讼**

#### 概述

丙这条"案外人对执行标的异议"路径（§238），比行为异议多一道"二次分流"：
- **谁提**：案外人；**向谁提**：执行法院；
- **审查**：**15日内审查**——理由成立裁定**中止对该标的的执行**、理由不成立裁定**驳回**；
- **不服的二次分流（关键）**：
  - 认为**原判决/裁定错误**（异议事由**与原裁判有关**）→ **依审判监督程序办理**（案外人申请再审，§421：裁定送达**6个月内**向原判法院）；
  - **与原判决/裁定无关**（纯粹主张自己的实体权利）→ 自裁定送达之日起**15日内**向执行法院提起**执行异议之诉**。

另有一条硬规则：**拍卖成交、价款付清后案外人再提异议的，法院不予受理**（既成交易、安全优先）。

#### 大白话讲解

丙主张"房子是我的"，他该怎么走？

第一步，丙向**执行法院**递书面异议，法院**15天内**审查：
- 如果丙证据充分（有买卖合同、已交付、已实际居住），法院裁定**中止对这套房的执行**（注意是"中止"、针对"这套房"，不是"终结整个执行"）；
- 如果证据不足，裁定**驳回**。

第二步，丙对裁定不服，这时要**看丙的异议到底冲着谁**——这是最容易错的"二次分流"：
- **如果丙认为"当初判乙欠债、进而执行这套房"的那份【原生效判决本身就错了】**（异议事由和原裁判绑在一起）→ 走**审判监督程序**，即**案外人申请再审**，期限是异议裁定送达后**6个月内**、向作出原判决的法院。
- **如果丙的主张跟那份原判决【没关系】**（原判决只管乙欠不欠甲的钱，压根没涉及"这房归谁"，丙只是纯粹主张"这物权属于我")→ 走**执行异议之诉**，期限是异议裁定送达后**15日内**、向**执行法院**起诉。

本案丙主张的是"房子物权归属"，跟"乙欠甲100万"那份判决无关，所以走**执行异议之诉（15日、执行法院）**。

**再记一个陷阱情形**：如果这套房**已经拍卖成交、买受人也付清了全款**，丙这时才跳出来提异议——**法院不予受理**。因为拍卖已经形成既定交易、买受人已取得权利，为保护交易安全和执行秩序，不能再翻。

#### 一句话闭环记忆

> 🎯 **一眼判**：案外人标的异议→执行法院**15日审查**→成立**中止对该标的执行**、不成立驳回；不服**二次分流**——认为**原裁判错**（有关）走**再审6个月**、**与原裁判无关**走**执行异议之诉15日**；拍卖成交价款付清后再异议，**不予受理**。

---

### 第四步：打执行异议之诉——当事人地位怎么排？谁举证？

> **对面那个人当被告，案外人恒担举证**

#### 概述

丙决定提执行异议之诉，随即遇到三个技术问题：**谁当被告？被执行人（乙）放哪？谁举证？**（§305/§306/§308/§309）
- **案外人异议之诉（§305）**：案外人当原告，**以申请执行人为被告**；被执行人**反对**案外人异议的列**共同被告**、**不反对**的列**第三人**；
- **申请执行人异议之诉（§306）**（前提是案外人异议已致法院裁定中止执行）：申请执行人当原告，**以案外人为被告**；被执行人**反对**申请执行人主张的以**案外人和被执行人为共同被告**、**不反对**的列被执行人为**第三人**；
- **管辖与程序**：执行法院管辖（§302）、适用**普通程序**（§308）；
- **举证责任（§309）**：**无论谁当原告，案外人**都要就"对执行标的享有足以排除强制执行的民事权益"承担举证证明责任。

#### 大白话讲解

**情形一（丙的异议被驳回、丙起诉）——案外人异议之诉**：
丙当原告，**告谁？告申请执行人甲**（因为是甲要执行这套房、跟丙的物权主张正面冲突）。那被执行人乙呢？**看乙的态度**：
- 乙也跳出来说"房子确实还是我的、丙在瞎说"（**反对丙的异议**）→ 乙和甲一起当**共同被告**；
- 乙说"是啊房子早卖给丙了、我不反对"（**不反对**）→ 乙降格为**第三人**。

**情形二（丙的异议成立、法院中止执行，甲不服起诉）——申请执行人异议之诉**：
甲当原告，**告谁？告案外人丙**（因为是丙挡了甲的执行）。被执行人乙呢？
- 乙也主张"房子是我卖给丙的、支持甲继续执行没道理"，即**反对甲的主张** → 丙和乙一起当**共同被告**；
- 乙**不反对**甲 → 乙列为**第三人**。

**再记牢一条铁律——举证永远压在丙（案外人）身上**：哪怕是甲（申请执行人）当原告告丙，**举证责任也不转移给甲**，仍由**丙**证明"我对这套房享有足以排除强制执行的权益"。逻辑很简单：主张"标的物是我的"的始终是丙，谁主张排除执行谁就得拿出足以排除的实体权益证据。

**程序**：执行异议之诉**由执行法院管辖、走普通程序**（不是特别程序、不是简易程序默认）。

#### 一句话闭环记忆

> 🎯 **一眼判**：执行异议之诉"**被告=对面那个人**"（案外人告→告申请执行人；申请执行人告→告案外人），**被执行人看态度**（反对异议方=共同被告、不反对=第三人）；**举证恒在案外人**（§309）；执行法院管辖、**普通程序**。

### 第五步：判程序收尾——中止 / 终结 / 终本 / 回转 / 检察监督

> **中止能恢复终结彻底了，终本可再申请回转要返还**

#### 概述

执行程序最终怎么了结？五个出口别混：
- **中止执行（§267）**：暂停，**情形消失后恢复**（如案外人异议确有理由、一方公民死亡待继承、法人终止未定承受人）；
- **终结执行（§268）**：**彻底了结不再恢复**（如据以执行的文书被撤销、撤回申请、被执行公民死亡无遗产无义务承担人、追索赡养/扶养/抚养费权利人死亡、被执行公民生活困难无力偿还且无收入又丧失劳动能力）；
- **终结本次执行/终本（解释§517）**：**查无可供执行财产**时的暂时了结，发现财产**可再次申请、不受时效限制**；
- **执行回转（§244）**：执行完毕后据以执行的**文书被撤销**，责令取得财产人**返还、拒不返还强制执行**；
- **执行检察监督（§246）**：检察院有权对民事执行活动实行法律监督。

**特定物交付执行不能**的处理（289/290/291/294 高频）：标的物灭失/被毁/被善意取得导致无法交付的，当事人可**协商折价赔偿**或就赔偿/重作费用**另行起诉**，协商不成、无法继续执行的**裁定终结执行**。

#### 大白话讲解

把本案几种可能的结局摆出来，一眼看清五个出口的区别：

- **中止**：丙的异议**确有理由**，法院裁定**中止对这套房的执行**——但这只是"先停下"，等异议之诉结果出来、情形明朗了还能**恢复**。（§267：案外人异议确有理由是法定中止事由。）
- **终结**：甲执行依据的那份判决被上级法院**再审撤销**了——执行的地基没了，法院裁定**终结执行**，程序**彻底结束不再恢复**。（§268）
- **终本**：查来查去乙**名下暂时没有可供执行的财产**（房子被证明是丙的、又没别的财产）——法院裁定**终结本次执行程序**；但哪天发现乙又有钱了，甲**可以再次申请执行、不受申请执行时效限制**。终本≠终结，这是命题人最爱的偷换。
- **回转**：假设甲已经把乙另一笔财产执行到手、钱都给了甲，**事后**那份判决被撤销了——法院直接裁定**责令甲把已拿到的财产返还**给乙，甲**拒不返还就强制执行**（§244），不用乙去打再审或国家赔偿。
- **检察监督**：整个执行过程中如有违法，**检察院有权监督**（§246）。

**再看"特定物给不出来"的经典处理**（真题 289/290/291/294）：判决要求交付某特定物（管线资料/公章/名画/工艺品），但物**丢了/毁了/被善意第三人取得**，客观上无法交付——双方可**协商折价赔偿**（如赔钱、赔重作费用），协商不成的可**就赔偿另行起诉**，而这个"交付特定物"的执行因**执行不能裁定终结执行**（不是终本、不是中止）。命题人爱在"折价赔偿能否在本执行程序中直接裁定"上挖坑——**赔偿数额有争议、双方协商不成的，要另诉解决、本执行终结**，法院不能在执行程序里直接强行确定赔偿额。

#### 一句话闭环记忆

> 🎯 **一眼判**：**中止**（§267，可恢复）／**终结**（§268，彻底了结）／**终本**（§517，查无财产、可再申请）／**回转**（§244，文书被撤销责令返还、拒不返还强制执行）／**检察监督**（§246）；特定物交付**执行不能**→协商折价赔偿或另诉、执行**终结**（非终本非中止）。

## 六、 易混考点辨析

- **执行行为异议（§236） vs 案外人标的异议（§238）**：前者针对"行为违法"、主体是当事人/利害关系人、救济是**10日内向上一级法院复议**；后者针对"标的错误"、主体是案外人、成立则**中止**、救济是**15日内异议之诉或6个月内再审**。期限、出口、法院三维全相反。
- **执行异议之诉 vs 申请再审 vs 第三人撤销之诉**：三者都是案外人救济——异议之诉解决"**与原裁判无关**的实体权利排除执行"；申请再审解决"认为**原裁判本身错误**、须先经执行异议前置"；第三人撤销之诉解决"**未参加诉讼**、生效裁判内容错误损害其权益"（不以先经执行异议为前提）。
- **案外人异议之诉 vs 申请执行人异议之诉**：被告是"对面那个人"（分别为申请执行人、案外人），被执行人视态度定共同被告或第三人；**举证责任无论谁起诉都在案外人**（§309）。
- **中止执行 vs 终结执行 vs 终本**：中止可恢复、终结彻底了结、终本查无财产可再申请。三者法律效果完全不同。
- **执行回转（§244） vs 再审 / 国家赔偿**：回转是文书被撤销后由执行法院**直接裁定责令返还已执行财产**，无需另行起诉、再审或国赔程序。

## 七、 命题人最爱的陷阱清单

1. **"当事人对执行行为违法不服，应提执行异议之诉"** —— 错！执行行为异议救济是**向上一级法院复议（10日）**，执行异议之诉只属于案外人标的异议这条线。
2. **"案外人对执行标的异议被驳回，向上一级法院申请复议"** —— 错！走**再审（认为原裁判错、6个月）或执行异议之诉（无关、15日、执行法院）**，没有"复议"这条路。
3. **"案外人异议理由成立的，裁定终结执行"** —— 错！是裁定**"中止对该标的的执行"**（针对该标的、可恢复）。
4. **"申请执行人提起执行异议之诉的，由申请执行人举证"** —— 错！§309：**无论谁当原告，均由案外人**就"足以排除强制执行的民事权益"举证。
5. **"案外人可以直接以案外人身份申请再审"** —— 错！须先经§238执行异议、被驳回，认为**原裁判错误**的才转入审判监督（真题281 A项）。
6. **"查无可供执行财产的，裁定终结执行、程序结束"** —— 错！是**终结本次执行程序（终本）**，发现财产**可再申请、不受时效限制**。
7. **"执行完毕后文书被撤销，取得财产人须经再审/国家赔偿返还"** —— 错！走**执行回转（§244）**，法院裁定责令返还、拒不返还强制执行。
8. **"拍卖成交、价款付清后案外人仍可提异议中止执行"** —— 错！**不予受理**（交易安全、执行秩序优先，真题271）。
9. **"特定物灭失无法交付，法院可在执行程序中直接裁定赔偿数额"** —— 错！赔偿有争议、协商不成的**另行起诉**、本执行**终结**（真题289/291/294）。
