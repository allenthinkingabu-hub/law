# 📐 物业服务合同 · 答题模型（万能四步）

> 凡"业主 ↔ 物业公司"权利义务题，沿"**订立 → 收费 → 解约 → 退场**"合同生命周期走四步，一步不跳。
> **核心一句话**：物业题 90% 落在四金句——**公开承诺入约、欠费禁停水电、未住照样交费、解聘提前 60 日**；其余靠"六十解九十续"和"退场白干不收费"兜底。
> **对照模型** → [[民法-合同-委托行纪中介模型]]（§946 业主大会任意解除 ∈ 任意解除全家族 vs §933 委托双向）· [[民法-合同-解除模型]]（任意解除 ≠ §563 法定解除）· [[民法-合同-中止模型]]（公用事业欠费可"中止"§654，物业费连中止都不行 §944③）。
> **适用真题**：[[典型合同-多选-14|C2-多选-14·四金句一题打包]] · [[典型合同-多选-24|C2-多选-24·供热§944变形·只能中止不能解除]]。
>
> 🔎 **法条已联网核实（2026-06-14；§937-§950 全章 2 路独立联网 + 6 条高风险条号对抗式复核，全 CONFIRMED）**：依据＝物业服务合同 **§937-§950**；逐字原文经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml) + [最高检《不交物业费可以断水断电吗》专文](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200828_482987.shtml) + 德恒律所逐款解析三源交叉核对。**核出 3 处全库既有条号/款号错误**（见文末"顺手订正"）。最高法 **2025-12-08 物业服务合同纠纷典型案例（5 件）** 经 [court.gov.cn](https://www.court.gov.cn/zixun/xiangqing/483521.html) 验真。
> ⚠️ **三个最易记错的点**：①"公开承诺入约"＝**§938 第②款**（不是 §939——§939 是"前期/选聘合同对业主有约束力"）；②"禁止停水电催费"＝**§944 第③款**、"未住不能拒交"＝**§944 第①款**（二者最爱互换款号）；③"业主解聘提前 **60 日**、物业不续聘提前 **90 日**"（六十解、九十续，别记反）。

## 一、核心考情

- **频率**：★★★★★ 顶级 🆕。民法典 2021 **新设独立章**（立法级强信号）+ **最高法 2025-12 物业纠纷典型案例**（距 2026 考期最近的分则信号）+ 法大 11 类清单点名。客观题"业主 vs 物业"多选高频。
- **命题核心**：①四金句"看着对、其实错"陷阱（公开承诺/停水电/未住拒交/任意解除）；②款号 / 天数偷换（§944 三款互换、60↔90↔30 日）；③转委托"整体禁部分可"；④终止退场不收费。
- **三大必考点**：①内容＝**公开承诺入约**（§938②）；②收费＝**业主不得拒交**（§944①）+ **物业禁停水电**（§944③）；③解约 / 退场＝**业主大会任意解除 60 日**（§946）+ **原物业退场不收费**（§949）。

## 二、万能四步模型

（老王＝业主，小李物业＝物业公司，**业主大会**＝全体业主依 §278 程序"双 2/3 参与 + 双过半同意"**共同决定**）

### 第一步：合同内容怎么定 —— 公开承诺"入约"，前期合同"管全楼"

**铁则**：
- 物业**公开作出的【有利于业主的】服务承诺** → **当然成为合同组成部分**（**§938②**）。⚠️两个限定：必须"**有利于业主**"、必须是"**承诺**"——物业**单方制定的服务细则不当然入约**。
- 合同须**书面形式**（§938③）；内容含服务事项 / 质量 / 收费标准 / 维修资金 / 服务期限 / 交接（§938①）。
- **前期物业合同**（建设单位订）、**业主大会 / 业委会选聘**订的合同 → 对**全体业主**有法律约束力（**§939**），不因业主没签字而免责；新合同生效则前期合同终止（§940）。

**老王小李例子**
- ✅ **入约**：小李物业在售楼 / 公示栏承诺"24h 安保 + 每周两次消杀"（有利于业主的公开承诺）→ 直接是合同内容，事后赖"那只是宣传"——不行（§938②）。
- ❌ **不当然入约**：小李单方贴的"车位最高赔 500"服务细则 → 单方细则不当然约束业主。
- **约束全楼**：业委会替全体业主选聘小李物业 → 老王没单独签字仍受约束、要交费（§939）。

### 第二步：物业费怎么收 —— 业主不能赖账，物业不能拉闸

**铁则**（一张"能 / 不能"表）：

| 谁   | 想干什么                                 | 行不行                | 法条                |
| --- | ------------------------------------ | ------------------ | ----------------- |
| 业主  | 以"没入住 / 没享受服务"**拒交**                 | ❌ 不行（已按约提供服务即应交）   | **§944①**         |
| 业主  | 以"房屋质量 / 设计问题"等**非物业义务范围**事项拒交       | ❌ 不行（找开发商，别赖物业）    | §944①（最高法2025案例二） |
| 物业  | 欠费 → **催告**给合理期限 → 仍不交 → **诉讼 / 仲裁** | ✅ 唯一合法路径           | §944②             |
| 物业  | 以**停电 / 停水 / 停热 / 停燃气**催费            | ❌ 违法               | **§944③**         |
| 物业  | 以**限门禁 / 电梯**等超合理限度方式催费              | ❌ 违法（案例扩张适用 §944③） | 最高法2025案例一        |

**老王小李例子**
- ❌ **业主赖账**：老王出国进修半年，主张"没住 = 没受益 = 不交费" → **错**，物业服务对价是**公共服务**，照交（§944①）。
- ❌ **物业拉闸**：老王欠 3 个月物业费，小李物业**停了他家电** → 违法（§944③）；正解是催告后**起诉 / 仲裁**（§944②）。
- 🪤 **公用事业对照**：若是**供电 / 供水 / 供热公司**对欠费户 → 可**催告后中止供应**（§654、§656 准用），但**物业费连"中止"都不行**——这是 [[典型合同-多选-24]] 的考点，详见 [[民法-合同-中止模型]]。

### 第三步：合同怎么解约 / 续聘 —— "六十解、九十续"

**铁则**：
- **业主大会任意解除权**（**§946**）：业主**依法共同决定**解聘 → **可随时解除**（无需违约理由），但须**提前 60 日**书面通知；解除**造成物业损失的**，除不可归责于业主外，**应赔偿**（≠ 无偿解约）。
- **任意解除权专属业主一方**：物业**无**任意解除权；**单个业主**也不能单独解除（须业主共同决定）——高频陷阱。
- **不定期 → 随时解除**（**§948**）：服务期满、业主没决定续聘 / 另聘而物业继续干 → 原合同**继续有效但转为不定期** → **任何一方可随时解除**，提前 **60 日**书面通知。
- **续聘 / 不续聘**（**§947**）：物业**不同意续聘** → 应在期限届满前 **90 日**书面通知业主 / 业委会。
- **口诀**：解聘 60、不定期解除 60、物业不续聘 90 → **六十解、九十续**。

**老王小李例子**
- ✅ **任意解除**：业主大会嫌服务差，依法表决解聘、**提前 60 日**书面通知 → 即使小李**没违约**也能解（§946）；小李因此的合理损失，业主**要赔**。
- ❌ **单户解除**：老王一个人不满意，自己发函"解除合同" → **无效**，任意解除权要业主**共同决定**。
- ✅ **不定期**：合同到期没人续签、小李物业继续服务 → 转不定期，哪天哪方想散伙，**提前 60 日**通知即可（§948）。

### 第四步：终止之后 —— 退场移交，赖着不走"白干不收费"

**铁则**：
- **退出 / 移交义务**（**§949**）：合同终止 → 原物业应在约定 / 合理期限内**退出**服务区域，**交还**物业用房 / 设施 / 资料，**配合**新物业交接，**如实告知**使用管理状况。**违反**（拒不退场、占用物业用房）→ **不得请求**终止后的物业费；造成业主损失的**应赔偿**。
- **后合同义务**（**§950**）：合同终止后、新物业接管**前**，原物业应**继续处理**物业事项，**并可请求**该期间物业费。
- **区分**：合法过渡期**可收费**（§950）；赖着不走才**不收费**（§949）。

**老王小李例子**
- ❌ **拒不退场**：合同到期，小李物业**赖着不走、占着物业用房** → 这段时间**不能再收物业费**，还要赔业主损失（§949，最高法2025案例三）。
- ✅ **合法过渡**：合同终止但新物业还没接管，小李物业**继续正常服务**等交接 → 过渡期**可以收费**（§950）。

### 🧩 旁支必背（次高频 · 单点设错）

- **转委托 §941**："**部分可、整体禁**"——专项服务（电梯 / 绿化）可委托专业第三人，但**不得将全部物业服务转委托**给第三人，也**不得支解后分别转委托**（化整为零也不行）。
- **安全保障义务 §942**：对区域内违反治安 / 环保 / 消防的行为，物业应**及时制止 + 报告主管部门 + 协助处理**（不作为可担责）。
- **业主告知配合义务 §945**：装修须**事先告知**物业、配合现场检查；转让 / 出租专有部分、设居住权、改变共有部分用途须**及时告知**。
- **信息公开 §943**：物业应**定期公开**收费、维修资金、共有部分经营收益等。

## 三、命题人最爱的 6 个陷阱

1. **公开承诺挂错条 / 当无约束力** —— ＝**§938②**（不是 §939）；且仅"**有利于业主的承诺**"入约，物业**单方细则不算**。"宣传承诺只是要约邀请、无效"→ 错。
2. **§944 三款款号互换** —— "禁停水电"＝**§944③**、"未住不能拒交"＝**§944①**（最爱标反）；"物业可停水电催费 / 业主没住可拒交"→ 全错。
3. **天数偷换 60↔90↔30** —— 业主解聘 / 不定期解除＝**60 日**（§946/§948），物业不续聘＝**90 日**（§947）；改成 30 日或互换 → 错。
4. **任意解除权主体错位** —— 专属**业主一方 + 须共同决定**；"单个业主可任意解除""物业可任意解除"→ 错；"任意解除一律无需赔偿"→ 错（§946 致损要赔）。
5. **转委托"整体转包"当合法** —— §941 禁整体 / 支解转包；但别矫枉过正否定"部分专项可委托"。
6. **退场仍收费 / 占房不退** —— 拒不退场 → **不得收**终止后物业费（§949）；勿与 §950 合法过渡期可收费混。

## 四、真题演练（套四步模型）

### 范例①：[[典型合同-多选-14|C2-多选-14]]（业主与物业公司权利义务，问"**错误**"项）→ **ACD**
1. **A** "公开承诺 / 细则**不是**合同组成" → **错**（公开**有利于业主的承诺**入约，§938②）→ 入选。
2. **B** "无违约业主大会也可解除" → **对**（§946 任意解除权）→ 不选。
3. **C** "欠费可**停水电气热**催缴" → **错**（§944③ 禁止）→ 入选。
4. **D** "未居住可**以未接受服务拒交**" → **错**（§944① 不得拒交）→ 入选。
→ "错误"项 **ACD** ✅

### 范例②：[[典型合同-多选-24|C2-多选-24]]（供热公司 vs 欠费业主吴某，问正确项）→ **CD**
1. **定性**：这是物业第二步"收费铁律"的**公用事业对照变形**——供热属公用事业，§656 准用 §654。
2. **C 对**：吴某拒交供热费、经催告合理期限仍不交 → 供热公司可**中止供热**（§654 准用）。
3. **D 对**：吴某欠费违约 → 担**违约责任**（§577）。
4. **A、B 错**：公用事业强制缔约，**不能直接 / 经催告解除**合同（只能中止）。
5. **与物业差异**：供热公司**能中止**，物业费却**连中止都不行**（§944③）。深辨析见 [[民法-合同-中止模型]]。
→ **CD** ✅

## 📐 口诀

> **物业题，沿"订立 → 收费 → 解约 → 退场"四步走。**
> **公开承诺入约（§938②，有利于业主才算、单方细则不算），前期 / 选聘合同管全楼（§939）。**
> **业主没住照样交（§944①），物业禁拉闸停水电（§944③），欠费只能催告 + 诉讼仲裁（§944②）。**
> **业主大会任意解，提前六十日、致损还要赔（§946）；单户不能解、物业更不能解。**
> **六十解、九十续：不定期随时解 60 日（§948）、物业不续聘 90 日（§947）。**
> **转包整体禁部分可（§941）；散伙退场要移交，赖着不走白干不收费（§949），合法过渡才收钱（§950）。**
