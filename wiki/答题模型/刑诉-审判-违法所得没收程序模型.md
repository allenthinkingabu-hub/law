# 📐 违法所得没收程序 · 答题模型

> **教练开场白**
> 同学你好，违法所得没收程序常被和缺席审判搞混——两个都是应对"人跑了/死了"的特别程序，但命题人最爱在这个混淆点上下手：以为**只要嫌疑人逃匿了、赃款还在，检察院随时都能申请没收**——**错！必须逃匿且"通缉一年后仍不能到案"，逃匿未满一年不能启动**！以为**没收程序也要给嫌疑人定罪**——**错！这是"对物之诉"，不解决定罪问题，只处理财产该不该没收**！以为**在逃嫌疑人一旦归案，没收裁定就自动作废**——**错！应当终止审理，走回正常刑事追诉程序，不是"自动作废"**！今天用"启动要件—管辖公告—裁定救济—中止终止"这条主线，把违法所得没收程序从申请到执行完整锁死。

## 适用场景与解决问题

本模型覆盖《刑事诉讼法》第五编"特别程序"第四章"违法所得的没收程序"（§298-§301）。凡题干出现"犯罪嫌疑人逃匿""通缉一年不能到案""嫌疑人死亡但赃款还在""检察院申请没收违法所得""利害关系人参加诉讼"等表述，立即调用本模型。

- **启动要件（§298）**：对于**贪污贿赂犯罪、恐怖活动犯罪等重大犯罪**案件，犯罪嫌疑人、被告人**逃匿**，且**在通缉一年后不能到案**的，或者犯罪嫌疑人、被告人**死亡**的，依照刑法规定应当追缴其违法所得及其他涉案财产的，人民检察院**可以**向人民法院提出没收违法所得的申请——公安机关认为符合上述情形的，应当写出没收违法所得意见书，移送检察院。**逃匿未满通缉一年**的，不能启动本程序。
- **管辖与公告（§299）**：由**犯罪地或者犯罪嫌疑人、被告人居住地的中级法院**组成合议庭审理；法院受理申请后**应当发出公告**，公告期为**六个月**；犯罪嫌疑人、被告人的**近亲属和其他利害关系人**有权申请参加诉讼，也可以委托诉讼代理人参加诉讼；**利害关系人参加诉讼的，应当开庭审理**。
- **裁定与救济（§300）**：法院在公告期满后审理，经查证**属于**违法所得及其他涉案财产的，**除依法返还被害人的以外，应当裁定予以没收**；对**不属于**应当追缴的财产的，**应当裁定驳回申请**，解除查封、扣押、冻结措施；对裁定，近亲属和其他利害关系人或检察院可以提出**上诉、抗诉**。
- **审理中止与执行错误处理（§301）**：审理过程中，**在逃的**犯罪嫌疑人、被告人**自动投案或者被抓获**的，法院**应当终止审理**；对犯罪嫌疑人、被告人财产的没收**确有错误的，应当予以返还、赔偿**。

> **核心一句**：**「重大犯罪案件+逃匿满通缉一年不能到案或已死亡→检察院可申请没收；中级法院管辖、受理后公告6个月、利害关系人可参诉、参诉的应当开庭；属违法所得应当裁定没收、不属于的应当驳回；在逃人归案应当终止审理，没收错误应当返还赔偿」**

> 🔎 **法条口径**：《刑事诉讼法》§298-§301（违法所得的没收程序全章）。**已于 2026-07-19 通过最高检官网（spp.gov.cn）公布的《中华人民共和国刑事诉讼法》全文逐字核对，CONFIRMED**；该章紧接第三章"缺席审判程序"（§291-§297）之后、属第五编"特别程序"第四章，条号连续无遗漏。

> ⚠️ **易记错点**：①**逃匿必须"通缉一年后仍不能到案"才能启动**，逃匿未满一年（哪怕已经通缉）不能启动本程序，命题人爱把"一年"这个时限门槛省略掉；②**本程序是"对物之诉"，不解决定罪问题**——法院裁定没收或驳回，都不是对犯罪嫌疑人、被告人的定罪判决，命题人爱把这个程序和缺席审判（对人之诉、须定罪判刑）混为一谈；③**利害关系人参加诉讼的，应当开庭审理**，不是一律不开庭的书面审查；④**在逃人自动投案或被抓获的，应当终止审理**，不是"没收裁定继续有效、人回来了另案处理"——终止审理意味着该没收程序本身停止，案件回归正常刑事追诉轨道；⑤**公告期是六个月**，不要和其他程序的公告/异议期限混淆。

> **姊妹模型**：📐 [[刑诉-审判-缺席审判程序模型]]（同为应对逃匿/死亡的特别程序，但缺席审判是**对人之诉、须定罪判刑**，本模型是**对物之诉、不解决定罪**，做题时先分清"这题问的是人还是物"）

## 一、核心考情

> **频次研判**：本板块系深度报告考点12，考频★★★★（深度报告标注），系与缺席审判程序高度关联但性质不同的独立特别程序；本次建模系首次覆盖，法条本体（§298-§301）已逐字核验 CONFIRMED。

命题核心集中在两条线：

1. **启动要件与性质辨析**——逃匿满通缉一年/死亡二选一的启动门槛，以及"对物之诉"这一根本性质，命题人最爱把这两点分别偷换成"逃匿即可启动"和"程序也解决定罪问题"。
2. **管辖公告与裁定救济**——中级法院管辖、六个月公告期、利害关系人参诉应当开庭、裁定没收或驳回的具体标准，命题人爱在时限和"应当/可以"用词上设陷阱。

## 二、违法所得没收决策树

```
                    重大犯罪案件嫌疑人/被告人跑了或死了，赃款还在，能不能申请没收？
                                    │
   ▼ 第一步 · 判启动要件（§298）
   │
   ├─ 逃匿，且通缉一年后仍不能到案 ──→ 可以启动
   ├─ 逃匿，但通缉未满一年 ──→ 不能启动
   └─ 犯罪嫌疑人/被告人死亡 ──→ 可以启动
                                                       │
   ▼ 第二步 · 判管辖与公告程序（§299）
   │
   ├─ 犯罪地或居住地中级法院组成合议庭审理

   │
   ├─ 属违法所得及涉案财产（除依法返还被害人的） ──→ 应当裁定没收
   ├─ 不属于应追缴财产 ──→ 应当裁定驳回，解除查封扣押冻结
   └─ 对裁定不服 ──→ 近亲属/利害关系人/检察院可上诉、抗诉

   │
```

## 三、核心规则拆解

> 四步的底层法理与命题陷阱，做题前先建立整体地图，具体操作细节见"四、万能解题四步"。

1. **"对物之诉"的本质决定了启动门槛与救济方式**：由于犯罪嫌疑人、被告人不在案（逃匿或死亡），无法对其进行正常的定罪量刑审理，立法退而求其次，只针对涉案财产是否属于违法所得这一"物"的问题作出裁判，不涉及"人"的定罪——这正是"通缉一年"这一较长等待期的意义所在：给犯罪嫌疑人足够的到案机会，只有确实长期无法到案（或已经死亡，彻底丧失到案可能）时，才退而处理财产问题，避免过早启动对物程序架空正常的对人追诉。
2. **公告期与利害关系人参诉制度是对第三人财产权的程序保障**：没收违法所得可能涉及善意第三人、近亲属等其他人对涉案财产的合法权益，六个月的公告期给这些潜在利害关系人知悉并申请参加诉讼的机会；一旦有利害关系人实际参加诉讼，程序从书面审查升级为**应当开庭审理**，保障其质证、辩论的权利。
3. **在逃人归案"应当终止审理"，是对物之诉向对人之诉让位的体现**：一旦犯罪嫌疑人、被告人重新到案，就具备了正常刑事追诉（定罪量刑）的条件，法律要求没收违法所得这一特别程序"应当终止"，把案件重新拉回正常轨道，通过普通刑事诉讼程序一并解决定罪和涉案财产处理问题，避免"对物之诉"和"对人之诉"两套程序并行造成的重复处理和裁判冲突。

## 四、万能解题四步

### 第一步：判启动要件

> **教练提示**：这一步的命题眼是"逃匿必须满通缉一年"这个时限门槛，命题人最爱把这个门槛省略，诱导考生认为"逃匿了就能立刻申请没收"。

> # 逃匿满通缉一年不能到案，或死亡，检察院可申请没收

#### 🗣️ 口诀怎么拆

| 字诀分句 | 对应规则 |
|---|---|
| 逃匿满通缉一年不能到案 | 犯罪嫌疑人、被告人逃匿，且在通缉一年后仍不能到案 |
| 或死亡 | 犯罪嫌疑人、被告人死亡，二选一即可启动 |
| 检察院可申请没收 | 依刑法应追缴违法所得及涉案财产的，检察院可以向法院提出没收申请 |

三句话锁死"两种启动情形二选一+谁来申请"的完整链条。

**先懂几个词**：
- **重大犯罪案件**＝贪污贿赂犯罪、恐怖活动犯罪**等**重大犯罪案件（"等"字表明不限于这两类，但须达到"重大"的门槛）；
- **逃匿+通缉满一年不能到案**＝犯罪嫌疑人、被告人**逃匿**，且已被**通缉**、**满一年后仍不能到案**——两个条件叠加，缺"通缉满一年"这一时限要素不能启动；
- **死亡**＝犯罪嫌疑人、被告人已经死亡，无需等待任何时限，可直接启动；
- **谁来申请**＝**人民检察院**可以向法院提出没收违法所得的申请；**公安机关**认为符合上述情形的，应当写出**没收违法所得意见书**，移送检察院（公安无权直接向法院申请）。

**🔍 对号入座表**：

| 题干情形 | 能否启动没收程序 | 易踩的坑 |
|---|---|---|
| 甲贪污后逃匿，通缉刚满6个月仍未到案 | **不能**，未满通缉一年 | 误以为逃匿即可启动 |
| 甲贪污后逃匿，通缉满一年仍未到案 | **可以** | — |
| 甲贪污后已死亡 | **可以**，无需等待时限 | — |
| 公安机关直接向法院提出没收申请 | **不可以**，公安只能写意见书移送检察院 | 误以为公安可直接申请 |

**💰 完整数字案例**：甲因贪污被立案侦查后潜逃境外，公安机关发出通缉令，**通缉满一年后甲仍未到案**，公安机关经审查认为符合没收违法所得的情形，写出**没收违法所得意见书**移送检察院，检察院据此向法院提出没收申请——这是完整合规的启动路径。若甲在**通缉刚满六个月**时仍未到案，此时**不能**启动没收程序，须等满一年这一时限届满。若甲在潜逃期间**死亡**，则**无需**等待任何通缉时限，检察院可以立即向法院申请没收其违法所得及涉案财产。 → 对应 [[刑诉-审判-单选-19 · 违法所得没收程序对物之诉与启动要件（仿真题）|单选-19]]。

#### 一句话闭环记忆

> 🎯 **一眼判**：**逃匿+通缉满一年后仍不能到案**，或**死亡**，二选一即可启动；**逃匿未满通缉一年不能启动**；申请主体是**检察院**（公安只能写意见书移送）。

### 第二步：判管辖与公告程序

> **教练提示**：这一步记住"中级法院管辖+六个月公告期+利害关系人参诉应当开庭"三个要点，命题人爱在"是否一律不开庭"上设陷阱。

> # 中级法院管辖，公告六个月，利害关系人参诉应当开庭

#### 🗣️ 口诀怎么拆

| 字诀分句 | 对应规则 |
|---|---|
| 中级法院管辖 | 犯罪地或犯罪嫌疑人被告人居住地的中级法院组成合议庭审理 |
| 公告六个月 | 法院受理申请后应当发出公告，公告期为六个月 |
| 利害关系人参诉应当开庭 | 近亲属和其他利害关系人有权申请参加诉讼；参诉的应当开庭审理 |

三句话锁死管辖法院、公告时限、参诉后的审理方式。

**先懂几个词**：
- **管辖法院**＝**犯罪地**或**犯罪嫌疑人、被告人居住地**的**中级人民法院**组成合议庭审理；
- **受理后公告**＝法院受理没收违法所得的申请后，**应当发出公告**，公告期为**六个月**；
- **利害关系人参诉**＝犯罪嫌疑人、被告人的**近亲属**和**其他利害关系人**（如财产的其他权利人）**有权申请参加诉讼**，也可以**委托诉讼代理人**参加诉讼；
- **参诉后应当开庭**＝**利害关系人参加诉讼**的，法院**应当开庭审理**（不再是纯书面审查）。

**🔍 对号入座表**：

| 题干情形 | 规则 |
|---|---|
| 没收申请由哪一级法院管辖 | 犯罪地或居住地的**中级法院** |
| 法院受理申请后 | 应当发出公告，公告期**六个月** |
| 犯罪嫌疑人的近亲属对涉案财产主张权利 | 有权申请参加诉讼，也可委托诉讼代理人 |
| 利害关系人已经参加诉讼 | 法院**应当开庭审理** |
| 无人申请参加诉讼 | 可不开庭，书面审查即可 |

**💰 完整数字案例**：甲因贪污逃匿满通缉一年，检察院向**犯罪地中级法院**提出没收违法所得的申请。法院受理后**应当发出公告**，公告期**六个月**。公告期间，甲的近亲属乙认为部分被查封的财产属于自己的合法财产、与甲的违法所得无关，**申请参加诉讼**；乙参加诉讼后，法院**应当开庭审理**，听取乙的意见和证据，而不能仅凭书面材料径行裁定。 → 本考点目前调研未见专门测试真题，以上为依据§299自编的仿真情境，不冒充真题。

#### 一句话闭环记忆

> 🎯 **一眼判**：**犯罪地或居住地中级法院**管辖；受理后**应当公告**，公告期**六个月**；近亲属和利害关系人**有权申请参诉**；**参诉的应当开庭审理**。

### 第三步：判裁定与救济

> **教练提示**：这一步记住"属违法所得应当没收、不属于应当驳回"这两条对称规则，以及对裁定不服的救济主体。

> # 属违法所得应当没收，不属于应当驳回，可上诉抗诉

#### 🗣️ 口诀怎么拆

| 字诀分句 | 对应规则 |
|---|---|
| 属违法所得应当没收 | 经查证属于违法所得及其他涉案财产的，除依法返还被害人的以外，应当裁定予以没收 |
| 不属于应当驳回 | 不属于应当追缴的财产的，应当裁定驳回申请，解除查封扣押冻结 |
| 可上诉抗诉 | 对裁定，近亲属和其他利害关系人或检察院可以提出上诉、抗诉 |

三句话锁死两种裁定结果+救济途径。

**先懂几个词**：
- **裁定没收**＝经审理查证**属于**违法所得及其他涉案财产的，**除依法应返还被害人的部分以外**，法院**应当**裁定予以**没收**；
- **裁定驳回**＝经审理查证**不属于**应当追缴的财产的，法院**应当**裁定**驳回申请**，并**解除**查封、扣押、冻结措施；
- **救济途径**＝对法院作出的裁定，犯罪嫌疑人、被告人的**近亲属和其他利害关系人**，或者**人民检察院**，可以提出**上诉、抗诉**。

**🔍 对号入座表**：

| 题干情形 | 裁定结果 |
|---|---|
| 查证涉案财产确属违法所得，无被害人合法权益 | 应当裁定没收 |
| 查证部分财产应依法返还被害人 | 该部分先返还被害人，其余应当裁定没收 |
| 查证财产不属于应追缴的违法所得 | 应当裁定驳回申请，解除查封扣押冻结 |
| 利害关系人对没收裁定不服 | 可以提出上诉 |
| 检察院对驳回裁定不服 | 可以提出抗诉 |

**💰 完整数字案例**：甲贪污案没收申请审理后，法院查明其中一笔存款确属违法所得且无被害人合法权益主张，**应当裁定予以没收**；另一笔房产经查证系甲以合法收入购置、与贪污行为无关，**不属于**应当追缴的财产，法院**应当裁定驳回**该部分没收申请、**解除**对该房产的查封措施。甲的近亲属对没收部分的裁定不服，**可以提出上诉**；检察院对驳回部分的裁定不服，**可以提出抗诉**。 → 本考点目前调研未见专门测试真题，以上为依据§300自编的仿真情境，不冒充真题。

#### 一句话闭环记忆

> 🎯 **一眼判**：**属违法所得**（除依法返还被害人部分）→**应当裁定没收**；**不属于**应追缴财产→**应当裁定驳回**、解除查封扣押冻结；对裁定，**近亲属/利害关系人/检察院**均可**上诉、抗诉**。

### 第四步：判审理中止与执行错误处理

> **教练提示**：在逃人一旦归案，没收程序应当终止、案件回归正常刑事追诉轨道，这是命题人最爱设的"没收裁定是否继续有效"陷阱。

> # 在逃人归案应当终止审理，没收错误应当返还赔偿

#### 🗣️ 口诀怎么拆

| 字诀分句 | 对应规则 |
|---|---|
| 在逃人归案应当终止审理 | 在逃的犯罪嫌疑人、被告人自动投案或被抓获的，应当终止审理 |
| 没收错误应当返还赔偿 | 对犯罪嫌疑人、被告人财产的没收确有错误的，应当予以返还、赔偿 |

两句话锁死"人回来了怎么办"和"没收错了怎么办"两条独立救济线。

**先懂几个词**：
- **审理中止（终止）**＝没收违法所得程序审理过程中，**在逃**的犯罪嫌疑人、被告人**自动投案**或**被抓获**的，法院**应当终止审理**——没收程序本身停止，案件回归正常刑事追诉程序，由法院对其定罪量刑并一并处理涉案财产；
- **执行错误的救济**＝对犯罪嫌疑人、被告人财产的没收**确有错误**的，**应当予以返还、赔偿**。

**🔍 对号入座表**：

| 题干情形 | 规则 |
|---|---|
| 没收程序审理中，在逃人自动投案 | 应当终止审理 |
| 没收程序审理中，在逃人被抓获 | 应当终止审理 |
| 已没收的财产事后查明确有错误 | 应当返还、赔偿 |
| 误以为"没收裁定已生效，人回来了另案单独处理财产" | **错误**，应当终止本程序，案件回归正常追诉轨道 |

**💰 完整数字案例**：甲贪污逃匿满通缉一年，检察院已启动违法所得没收程序，审理过程中甲**主动投案**——法院**应当终止**没收违法所得程序的审理，案件回归正常刑事诉讼程序，由法院对甲定罪量刑，并在该案中一并处理涉案财产，而不是让没收程序继续单独走完。若此前已裁定没收的某项财产事后查明**确属错误**（如误将合法财产认定为违法所得），**应当予以返还**，造成损失的还应当**赔偿**。 → 本考点目前调研未见专门测试真题，以上为依据§301自编的仿真情境，不冒充真题。

#### 一句话闭环记忆

> 🎯 **一眼判**：在逃人**自动投案或被抓获的，应当终止**没收程序审理，案件回归正常追诉轨道；没收**确有错误**的，**应当返还、赔偿**。
