# 📐 抗辩识别（请求权的防御全景）· 答题模型

> 凡"被要求给付、**能不能拒绝 / 对抗**"的题，先别急着背具体抗辩——**先问"针对这个请求权，我能做哪个动作"**（履行 / 抗辩 / 抵销 / 撤销解除 / 反诉），锁定到"抗辩"后再**三刀切**对号入座。
> **本模型的独有维度**：站在 [[请求权基础]] 的对面，给"应对一个请求权"列一张**动作菜单**——这是 [[抗辩]] 枢纽（概念地图）和 [[民法-合同-履行抗辩权模型]]（双务三抗辩细则）都没强调的"识别层"。**概念体系树看 [[抗辩]]；双务三大履行抗辩权细则看 [[民法-合同-履行抗辩权模型]]；本模型只解决"先认出我在打哪种牌"。**
> **适用真题**：[[合同通则-多选-11|C1多选-11·§548抗辩继受四类全家福ABCD]] · [[合同通则-单选-16|C1单选-16·双务先履行方不安抗辩·先诉作干扰B]] · [[典型合同-多选-08|C2多选-08·一般保证先诉抗辩权丧失4情形AC]]
>
> 🔎 **法条沿用已联网核实页面**（不引入新条号）：§192/§193（[[诉讼时效]]/[[抗辩]]）· §525-§528 + §687（[[民法-合同-履行抗辩权模型]]，最高检官网逐字 CONFIRMED）· §548/§549/§547（[[债权转让]]）· §763/§765/§769（[[2026-06-15-保理合同章联网核实]]，CONFIRMED·HIGH）· §568 法定抵销 / §147 可撤销 / §562-§565 解除（[最高检民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)）。
> ⚠️ **最易错**：① 抗辩权（时效/同时履行等）**不喊就输**——法院**不得依职权**适用（§193）。② **形成权≠抗辩**：撤销（§147）/ 解除（§562）是"主动改变法律关系"，不是单纯一挡。③ 先诉（§687·保证）、时效（§192）**不属于**双务"履行抗辩权"。

## 一、核心考情

- **频率**：★★★★（学理 / 机构研判）。抗辩是**请求权分析法的"另一半"**，主观题"某方能否拒绝 / 对抗"几乎必触；客观题常把不同抗辩、抗辩与形成权混在一起设陷。
- **命题核心**：考生最容易"一上来就背具体抗辩"，却分不清**手里这张牌到底是抗辩、抵销、形成权还是反诉**，以及**法院要不要你主动喊**（§193）。本模型把"先定动作、再三刀切"前置，专治这个乱。
- **三大必考点**：① 动作定性（抗辩 vs 抵销 / 形成权 / 反诉）② 广义抗辩 vs 抗辩权（§193 法院管不管）③ §548：抗辩随债权转让 / 保理**过户**。

## 二、万能四步模型

### 第一步：先定"动作"——针对这个请求权，我打哪张牌？（动作菜单）

**铁则**：有人对你主张一个**请求权**（"你要给我 X"），应对动作分五类，**先认出你打的是哪一类**，别一上来就背抗辩：

| 动作 | 干什么 | 性质 | 法条 |
|---|---|---|---|
| ① 履行 | 认了，照办 | —— | —— |
| ② **抗辩**（本模型主角）| 让请求权**落空 / 打折**，**只挡不改**法律关系 | 防御 | 见第二步 |
| ③ 抵销 | 拿自己对他的**对待债权**去对冲 | **形成权** | §568 |
| ④ 撤销 / 解除 | 把请求权赖以存在的**合同**消灭掉 | **形成权** | §147 / §562 |
| ⑤ 反诉 | 另起一个**独立的诉** | 程序行为 | —— |

- 🔑 **分界**：**②抗辩"只挡不改"**（不动法律关系，只否认 / 拒绝那个请求）；**③④是形成权**——主动**改变**法律关系（抵销让债消灭、撤销解除让合同消灭），改完往往再以"权利消灭 / 未发生抗辩"收口；**⑤反诉是程序**手段。
- ⚠️ 最常见混淆：把"撤销 / 解除"当成一种"抗辩"。它们是**形成权**，要**行使**（甚至要在除斥期内、或通知 / 诉讼），不是单纯举一面盾。

> 🌰 老王小李（老王＝请求权人 / 债权人，小李＝被请求人 / 债务人）：老王诉小李"还 100 万"。小李能打的牌——
> ② 抗辩："没欠 / 还过了 / 没到期 / 过时效了"；③ 抵销："你也欠我 40 万，§568 抵了"；④ 形成权："这合同是你骗我签的，我**撤销**（§147）"→ 合同没了、请求权落空；⑤ 反诉："我反过来诉你赔偿"。

### 第二步：锁定"抗辩"后——三刀切（决定法院管不管 + 归哪类）

**铁则**（完整体系树见 [[抗辩]]，这里给"答题切法"）：
- **第一刀**：**广义抗辩**（**否认**债：根本没生 / 已消灭，法院**可依职权**审查）vs **抗辩权**（**认**债但**拒绝履行**，**必须当事人主张**，法院**不得依职权**适用 §193）。→ **决定"不喊会不会白输"**。
- **第二刀（广义抗辩内部）**：**权利未发生**（合同无效 / 不成立 / 被撤销）vs **权利消灭**（已清偿 / 抵销 / 解除 / 免除 / 提存）。
- **第三刀（抗辩权内部）**：**永久性**（时效 §192，永久拒付）vs **延期性**（三大履行抗辩 §525-528、先诉 §687，条件成就即不能再挡）。

> 🌰 小李那四张抗辩牌，正好各踩一类（沿用 [[抗辩]] "一辆车"）：①"合同无效，没欠"＝权利未发生（广义·法院依职权）②"早还清了"＝权利消灭（广义）③"还没到付款日"＝延期性抗辩权 ④"过 3 年时效了"＝永久性抗辩权（**必须自己喊**，§193）。

### 第三步：对号入座——把具体抗辩交给细则页

**铁则**：认出类别后，落到对应专页（本模型不重复细则）：

| 抗辩落点 | 去哪 | 法条 |
|---|---|---|
| **双务合同**对待给付（同时 / 后履行 / 不安）| 📐 [[民法-合同-履行抗辩权模型]] | §525 / §526 / §527-528 |
| **时效抗辩**（永久 · 须主张）| [[诉讼时效]] | §192 / §193 |
| **保证**人（一般保证先诉抗辩权）| [[先诉抗辩权]] · [[民法-合同-保证模型]] | §687 |
| 权利未发生 / 消灭 | [[合同无效]] / [[抵销]] / [[解除]] | —— |

> 🚩 **干扰套路**：双务买卖题里塞一个"**先诉抗辩权**"（保证才有）当干扰项（[[合同通则-单选-16]] 的 A）；只要不是保证三方关系，先诉一律排除。

### 第四步：动态维度——§548 抗辩继受（请求权被转让 / 保理了怎么办）

**铁则**：前三步是**静态**看一个请求权怎么被防御；**§548 加"动态"**——当请求权被**转让 / 保理**给新债权人，债务人原来对老债权人的**全部抗辩（广义＋抗辩权）随债权一起过户**给受让人，"**受让人接的是带病债权**"；抵销另循 §549。
- **保理**：§769 准用债权转让 → 原则同上，但被 **§763**（虚构账款不得对抗善意保理人）、**§765**（通知后无正当理由改约不利保理人无效）**砍两刀**。
- 三场景（债权转让 / 保理 / 债务承担）抗辩怎么走的**全景对照表** → [[抗辩]]"抗辩继受的应用"节。

> 🌰 老王把对小李的债**转让 / 保理**给老张 → 小李原来能对老王打的四张牌，**对老张照样打**（§548）——[[合同通则-多选-11]] 全选 ABCD 的底层逻辑。

## 三、命题人最爱的陷阱

1. **抗辩权"不喊就输"**——时效、同时履行等**抗辩权**法院**不得依职权**适用，当事人不主张就照判（§193）；但合同无效 / 已清偿等**广义抗辩**法院**可主动**认定。最大分水岭。
2. **把形成权当抗辩**——撤销（§147）/ 解除（§562）是**形成权**（改变法律关系、要行使、受除斥期 / 程序约束），不是单纯一挡；抵销（§568）同理。
3. **先诉 / 时效混进"履行抗辩权"**——先诉（§687）只属**一般保证人**（保证三方）、时效（§192）是任何债，二者**都不是**双务合同的"履行抗辩权"。
4. **以为债权一转让债务人抗辩就没了**——§548 让抗辩**全继受**，债不会因转让"满血复活"。
5. **抵销＝抗辩**——抵销是**形成权**（§549 在转让里还单设通道、要"同种类 + 到期"），与单纯抗辩并列、不混同。

## 📐 口诀

> **"先定动作再背抗辩：履行 / 抗辩 / 抵销(§568) / 撤销解除(形成权) / 反诉——抗辩只挡不改，形成权改变关系。**
> **锁定抗辩三刀切：广义(否认·法院依职权) vs 抗辩权(拒付·须自己喊§193)；广义分'没生 / 死了'；抗辩权分'永久(时效) / 一时(履行·先诉)'。**
> **§548：债权一转让 / 保理，抗辩全过户——受让人接的是带病债权。"**
