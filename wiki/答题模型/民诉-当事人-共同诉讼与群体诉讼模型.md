# 📐 共同诉讼与群体诉讼 · 完整答题模型（必要共同 + 普通共同 + 代表人诉讼 + 公益诉讼）

> **核心一句**：一方当事人变成"一群人"时，按四步走：**「必须绑一起打（必要共同）→ 可合可分（普通共同）→ 人多推代表（代表人）→ 为公共利益出头（公益）」**。最毒陷阱是**把"担责的人"错列为"无独立请求权第三人"**、**把必要共同诉讼当事人推去"另行起诉"**、**代表人擅自和解/放弃对全体生效**、**未登记权利人去提第三人撤销之诉**、**检察机关抢在机关组织前面起诉公益诉讼**、**公益诉讼达成和解后"裁定准予撤诉"**。
>
> 🔎 **核心条文速查**（条号均已在本地官方全文中逐条 grep 核验）：
> - **《民事诉讼法》（2023年修正）第55条【共同诉讼】**：当事人一方或者双方为二人以上，其**诉讼标的是共同的**（→必要共同诉讼），或者诉讼标的是**同一种类、人民法院认为可以合并审理并经当事人同意的**（→普通共同诉讼），为共同诉讼。第2款：对诉讼标的**有共同权利义务**的，其中一人的诉讼行为**经其他共同诉讼人承认**，对其他共同诉讼人发生效力；**没有共同权利义务**的，其中一人的诉讼行为对其他共同诉讼人**不发生效力**。
> - **第56条【人数确定的代表人诉讼】**：当事人一方**人数众多**的共同诉讼，可以由当事人**推选代表人**进行诉讼。代表人的诉讼行为对其所代表的当事人发生效力，但代表人**变更、放弃诉讼请求或者承认对方当事人的诉讼请求，进行和解**，必须经被代表的当事人**同意**。
> - **第57条【人数不确定的代表人诉讼】**：诉讼标的是同一种类、当事人一方人数众多**在起诉时人数尚未确定**的，法院可以**发出公告**，通知权利人在一定期间**向法院登记**。登记的权利人可以推选代表人；推选不出的，法院可以与参加登记的权利人**商定**代表人。判决、裁定对**参加登记的全体权利人**发生效力；**未参加登记的权利人在诉讼时效期间提起诉讼的，适用该判决、裁定**。
> - **第58条【公益诉讼】**：对污染环境、侵害众多消费者合法权益等损害社会公共利益的行为，**法律规定的机关和有关组织**可以向法院提起诉讼。第2款：**人民检察院**在履行职责中发现破坏生态环境和资源保护、食品药品安全领域侵害众多消费者合法权益等损害社会公共利益的行为，**在没有前款规定的机关和组织或者前款规定的机关和组织不提起诉讼的情况下**，可以起诉；前款机关或组织起诉的，检察院可以**支持起诉**。
> - **第135条【追加通知】**：必须共同进行诉讼的当事人没有参加诉讼的，人民法院**应当通知其参加诉讼**。
> - **《民诉法解释》（法释〔2022〕11号修正）**：第73条（追加程序：法院通知＋当事人申请，申请理由不成立裁定驳回）、第74条（应追加的原告放弃实体权利可不追加；既不参加又不弃权仍追加，其不参加不影响审理判决）、第75条（"人数众多"一般指**十人以上**）、第76条（人数确定的可推选共同或各自的代表人；推选不出的，**必要共同诉讼中自己参加，普通共同诉讼中可另行起诉**）、第77条（人数不确定的推选不出→法院提出人选**协商**→协商不成在起诉当事人中**指定**）、第78条（代表人**二至五人**，每位可委托一至二人作诉讼代理人）、第79条（登记公告**不得少于三十日**）、第80条（登记须证明法律关系和损害，证明不了不予登记可另诉；裁判**在登记范围内执行**；未登记权利人起诉、请求成立的**裁定适用原判决**）、第325条（必须参加诉讼的当事人一审未参加，二审可自愿调解，**调解不成发回重审**）、第282-289条（公益诉讼：受理四条件；**侵权行为地或被告住所地中级法院**管辖、同一侵权行为**最先立案法院**管辖；受理后十日内告知行政主管部门；其他适格机关组织**开庭前申请参加列共同原告**；**不影响私益诉讼**；和解调解协议**公告≥30日**、不违公益出调解书；**法庭辩论终结后撤诉不予准许**；裁判生效后同一行为再提公益诉讼**不予受理**）。
> - **《环境公益诉讼解释》（2020修正）**：第1-5条（适格社会组织：设区的市级以上民政登记＋章程宗旨维护公益并专事环保＋起诉前五年无违法记录）、第6条（**中院以上**管辖，经批准可交基层法院；最先立案法院管辖）、第9条（法院**可释明变更或增加**停止侵害、修复生态等诉请）、第10条（受理后公告；其他适格主体**公告之日起三十日内**申请参加列**共同原告**、逾期不准；**私益受害人申请参加的告知另行起诉**）、第25条（和解调解协议公告**不少于三十日**、不损害公益**应当出具调解书**、**以达成和解协议为由申请撤诉不予准许**）、第26条（监管部门依法履职使诉请**全部实现**的撤诉应准许）、第27条（法庭辩论终结后撤诉不准，第26条情形除外）、第28-30条（生效后另行起诉的受理情形；不影响私益诉讼；生效裁判认定事实的预决效力）。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型正文引用的《民事诉讼法》第55、56、57、58、135条，《民诉法解释》第58、63、66、70-80、282-289、325条，《环境公益诉讼解释》第1-6、9、10、25-30条，**均已在本地官方全文（ssf.gov.cn PDF 转存文本）中逐条 grep 到原文**后写入，条号核验清单见文末交付说明。两处**转引提示**：①《证券法》第95条第3款（特别代表人诉讼"默示加入、明示退出"）与《公司法解释二》第4条（解散之诉以公司为被告）系转引自本库已核验真题卡（[[民诉-代表人诉讼-单选-76 · 证券特别代表人诉讼的判决效力]]、[[民诉-当事人-单选-320 · 公司解散之诉的被告与当事人地位]]），未在本地全文二次核验；②"必要共同诉讼／普通共同诉讼"是**学理分类名称**，民诉法第55条本身只在同条两款并列规定两类情形，未使用这两个术语，条文不含此名目。

> ⚠️ **易记错点**：①**承担赔偿责任的人（监护人、补充责任人、连带责任人、分立后企业）都是"被告/共同诉讼人"，不是"无独立请求权第三人"**——凡把担责主体写成第三人的选项直接排除；②**必要共同诉讼漏了人是"追加"，不是"另行起诉"**；被追加的人拒不参加，缺席照判、不影响担责，但**不能拘传**（拘传仅限赡养抚育扶养类必须到庭的被告）；③**代表人的一般诉讼行为对被代表人当然生效，但"变更/放弃/承认诉请、和解"四类重大处分必须经被代表人本人同意**——代表人调解，不同意的当事人不受拘束；④**普通代表人诉讼是"明示加入"（登记才参加），证券特别代表人诉讼是"默示加入、明示退出"**，方向正好相反；⑤**未参加登记的权利人的救济是"诉讼时效内另行起诉、裁定适用原判决"这条专门通道**，不是第三人撤销之诉（提了裁定不予受理）；⑥**检察机关提起民事公益诉讼有"补充顺位"**——法定机关组织没有或不起诉时才提，且需公告前置；社会组织自己起诉**没有**"先通知环保局"的前置程序；⑦**公益诉讼以达成和解为由申请撤诉不予准许**——正确出口是"协议公告≥30日→审查不损害公益→出具调解书"；⑧**公益诉讼裁判生效后**，其他适格主体就同一行为再提**民事公益诉讼**原则上不受理，但**私益诉讼、刑事追责照走不误**。

- **命题常见场景**：①给一个侵权/合同案件，问"谁是（共同）被告、漏了谁怎么办、被追加者不来怎么办"（3-4 与 3-2 适格判断叠考，几乎每卷必有）；②给多个受害人/多个责任人，制造"必要还是普通、能否合并、能否另诉"之辨（3-5）；③给"人数众多"场景，考代表人推选路径、代表人权限边界（和解须同意）、判决效力扩张与未登记者救济（3-6）；④给污染/消费侵权，考适格原告、检察补位、管辖级别、和解公告、公益与私益并行（3-7）。

## 二、 四步判别模型（绑 → 合 → 代 → 公）

```
              【一方当事人为二人以上（或人数众多 / 涉公共利益）】
                                │
   ▼ 第一关：诉讼标的是不是"共同的"？（民诉法55 I 前段）
   │
   ├─ 连带债务 / 共有财产 / 合伙 / 继承 / 共同侵权 / 保证连带 /
   │  企业分立 / 监护人＋行为人 …… ──→ 必要共同诉讼（必须绑一起打）
   │      ├─ 漏了人：法院应当通知参加（民诉法135），当事人也可申请追加（解释73）
   │      ├─ 应追加的原告：弃权可不追加；不参加又不弃权→仍追加，缺席照判（解释74）
   │      ├─ 一人的诉讼行为：经其他共同诉讼人承认才对全体生效（民诉法55 II）
   │      └─ 一审漏人：二审调解，调解不成→撤销原判发回重审（解释325）
   │
   ├─ 只是"同一种类"标的 ──→ 第二关：能不能合？（民诉法55 I 后段）
   │      └─ 同类标的 ＋ 法院认为可以合并审理 ＋ 当事人同意
   │         三要件齐 → 普通共同诉讼（可合）；缺一 → 分开审（可分，可另行起诉）
   │         一人的诉讼行为对其他人不发生效力（各管各的）
   │
   ▼ 第三关：人数众多（一般十人以上，解释75）？──→ 代表人诉讼
   │
   ├─ 起诉时人数【确定】（民诉法56）：推选共同/各自的代表人（2-5人，解释78）
   │      └─ 推不出：必要共同→自己参加；普通共同→另行起诉（解释76）
   ├─ 起诉时人数【不确定】（民诉法57）：法院公告≥30日通知登记（解释79）
   │      ├─ 代表人：登记权利人推选→法院商定→在起诉当事人中指定（解释77）
   │      ├─ 登记：须证明法律关系与损害，证明不了另诉（解释80）
   │      └─ 效力扩张：判决对参加登记的全体生效、登记范围内执行；
   │         未登记者时效内另诉→请求成立即裁定适用原判决（57 III＋解释80）
   └─ 代表人权限：一般行为对被代表人生效；变更/放弃/承认诉请、和解
      必须经被代表人同意（56/57）
   │
   ▼ 第四关：损害的是"社会公共利益"？──→ 公益诉讼（民诉法58）
   │
   ├─ 适格原告第一顺位：法律规定的机关和有关组织（环境：设区市级以上
   │  民政登记＋宗旨专事环保＋前五年无违法记录的社会组织，环境解释1-5）
   ├─ 第二顺位（补充）：检察机关——没有前者或前者不起诉时才提；
   │  前者起诉的，检察院支持起诉（58 II）
   ├─ 管辖：侵权行为地/被告住所地【中级】法院（解释283；环境解释6可批准下放）；
   │  同一行为多院起诉→最先立案法院管辖，其他适格主体列共同原告（解释285/环境解释10）
   ├─ 程序特则：法院可释明增加诉请（环境解释9）；和解调解协议公告≥30日→
   │  不损害公益出调解书；以和解为由撤诉不准（环境解释25）；辩论终结后撤诉不准（解释288）
   └─ 关系：不影响私益诉讼另行提起（解释286/环境解释29）；
      裁判生效后同一行为再提【民事公益诉讼】不受理（解释289），私益、刑事照走
```

> **一句话总诀**：**「标的共同必须绑（漏人追加不另诉），同类同意才可合（可分可合各自判）；十人以上推代表（确定推选、不定公告登记，和解处分须本人点头，判决罩住登记者、漏网者另诉套原判）；公共利益机关组织先出头、检察补位不抢跑（中院管、公告卅日才能调、和解不许偷撤诉，私益刑责各走各）」**

## 三、 三个高频干扰（担责者≠第三人 / 追加≠另诉 / 检察≠首选）

命题人极喜欢在"诉讼地位错置"和"程序出口错接"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **把担责主体降格为"无独三"** | 监护人/补充责任的幼儿园/派遣单位/分立后的丙公司"作为无独立请求权第三人参加诉讼"。 | **❌ 错误！承担实体责任的人一律是被告/共同诉讼人。**无独三是"案件处理结果与其有法律上利害关系"的旁侧主体；直接对原告负赔偿义务的主体（民诉解释58、63、66、67条等情形）是**当事人**。见"担责却当第三人"直接排除。 |
| **必要共同诉讼人漏诉的出口** | 原告不愿告魏某，法院"可告知对魏某另行起诉"，或"不追加但在判决书中判其承担连带责任"。 | **❌ 均错！必要共同诉讼必须合一确定。**法院**应当通知（追加）参加**（民诉法135）；被追加者不来→缺席照判、不影响担责（民诉解释74精神），但不能拘传；未被追加为当事人的人不能被判决直接课责。"另行起诉"是**普通**共同诉讼（可分）与代表人诉讼推选不出时的出口（解释76）。 |
| **检察机关抢跑 / 公益和解撤诉** | "检察机关发现污染即可直接起诉""当事人达成和解协议后法院裁定准予撤诉"。 | **❌ 错误！**检察公益诉讼是**补充顺位**——法定机关组织没有或不起诉时才提（民诉法58 II），已有消协/环保组织起诉的，检察院只能**支持起诉**；公益诉讼和解的法定出口是**公告≥30日→审查不损害公益→出具调解书**，**以达成和解为由申请撤诉不予准许**（环境解释25、民诉解释287-288）。 |

## 四、 四种诉讼形态对照表（一表定乾坤）

| 事项 | 必要共同诉讼 | 普通共同诉讼 | 代表人诉讼（人数确定/不确定） | 公益诉讼 |
|---|---|---|---|---|
| 法条锚点 | 民诉法55 I前段＋135 | 民诉法55 I后段 | 民诉法56 / 57 | 民诉法58 |
| 成立标志 | 诉讼标的**共同**（连带、共有、合伙、继承、共同侵权） | 标的**同一种类**＋法院认为可合并＋**当事人同意** | 共同诉讼＋一方**人数众多**（一般≥10人，解释75） | 损害**社会公共利益**（污染环境、侵害众多消费者） |
| 可分性 | 不可分，**必须合一确定** | **可分可合**，可另行起诉 | 依其基础属必要或普通；不确定型以同类标的为前提 | 独立诉讼形态，与私益诉讼**分轨并行** |
| 漏人处理 | 法院**依职权追加**（135＋解释73/74） | 不追加，可另诉 | 未登记权利人：时效内另诉**裁定适用原判决**（57 III＋解释80） | 其他适格主体开庭前/公告30日内申请参加→**共同原告**（解释285/环境解释10） |
| 一人行为效力 | 经其他共同诉讼人**承认**对全体生效（55 II） | 对其他人**不生效** | 代表人一般行为对被代表人生效；**变更/放弃/承认/和解须本人同意** | 原告处分受限：辩论终结后不得撤诉、和解须公告出调解书 |
| 裁判效力范围 | 全体当事人 | 各自当事人 | 参加登记的**全体权利人**（登记范围内执行）＋未登记者另诉套用 | 生效后同一行为**再提公益诉讼不受理**（解释289）；不碍私益、刑事 |

> ⚠️ **易混条号**：民诉法**56条＝人数确定**、**57条＝人数不确定**（公告登记、效力扩张都挂在57条），别互换；解释**76条**（确定型推选不出的出路）与**77条**（不确定型推选→商定→指定）方向相反；公益诉讼管辖是民诉解释**283条**（中院），环境案件另有环境解释**6条**（中院以上＋批准可下放基层）。

## 五、 万能四步答题模型

在法考答题中（无论客观题选项判断，还是主观题当事人确定），按照以下四步进行涵摄：

*   🏭 **统一案例（贯穿四步）**：清河市甲化工厂与乙运输公司合谋，将 100 吨废酸倾倒入清河。①下游老赵的鱼塘首当其冲，死鱼损失 **30 万元**；②沿岸 **12 户**渔民各损失 **10 万元**；③随污染扩散，受损养殖户增至 **120 户**、起诉时还在陆续冒头；④清河生态本身修复费用预估 **2000 万元**，绿水环保组织（设区的市级民政部门登记、专事环保 8 年、无违法记录）拟提起公益诉讼。

### 第一步：判必要共同诉讼——标的共同就必须绑一起打

> **标的共同必合一，漏人追加不另诉**

#### 概述

一方当事人为二人以上、**诉讼标的是共同的**，就是必要共同诉讼（民诉法55 I 前段）——必须全体参加、合一裁判：

- **典型清单**（记熟＝送分）：连带债务（共同侵权 1168 条连带）、共有财产受侵（解释72）、合伙、继承（解释70：不愿参加又不弃权仍列共同原告）、保证连带（解释66）、监护人与行为人（解释67）、企业分立后的乙丙公司（解释63）、劳务派遣以用工单位为当事人（解释58）；

- **漏了人怎么办**：法院**应当通知其参加诉讼**（民诉法135），当事人也可申请追加、法院审查（解释73）；

- **被追加的人不配合**：应追加的**原告**明确放弃实体权利的可不追加；既不参加又不弃权的仍追加，**其不参加不影响审理和判决**（解释74）——但普通被告不能拘传；

- **行为效力**：有共同权利义务的一方，其中一人的诉讼行为**经其他共同诉讼人承认**才对全体生效（民诉法55 II）——承认、放弃、变更这类处分不能一人拍板拖全体下水；

- **一审就漏了人**：二审发现的，可自愿调解，**调解不成撤销原判、发回重审**（解释325）。

#### 大白话讲解

老赵的鱼塘死鱼损失 30 万元，是甲化工厂和乙运输公司**合谋倾倒**造成的——两家共同侵权、负连带责任，这 30 万元的诉讼标的对甲乙是"一笔账"，属**必要共同诉讼**。

老赵跟乙公司老板沾亲带故，起诉时只告了甲厂。法院一看：这是连带责任，乙公司是"必须共同进行诉讼的当事人"，**不能由着原告挑**——依民诉法135条**通知乙公司参加诉讼**（追加为共同被告）。乙公司老板赌气不来？没关系：**缺席照样审、照样判它连带**；但法院也不能派人把他拘传来——拘传只留给赡养抚育扶养那类必须到庭的被告。

| 要素拆解 | 本案对应 | 处理 |
| --- | --- | --- |
| 诉讼标的是否共同 | 甲乙合谋倾倒，对老赵 30 万损失负连带责任 | ✅ 必要共同诉讼 |
| 原告漏告乙公司 | 法院应当通知乙参加（民诉法135） | 追加为共同被告，不是"另行起诉" |
| 乙拒不参加 | 不影响审理和判决（解释74精神） | 缺席判决，不能拘传 |
| 甲单方承认老赵全部请求 | 须经乙承认才对乙生效（55 II） | 一人行为不当然拖全体 |

#### 一句话闭环记忆

> 🎯 **一眼判**：连带/共有/合伙/继承/共同侵权＝标的共同＝必要共同诉讼——漏了人法院**追加**（不是另行起诉），追加了不来**缺席判**（不是拘传），担责的人永远是**共同被告**（不是第三人）。

---

### 第二步：判普通共同诉讼——同类同意才可合，可分可合

> **同类同意同管辖，可分可合各自判**

#### 概述

诉讼标的只是**同一种类**（不是同一个），本来可以各打各的官司；三个条件齐备才"拼团"审理（民诉法55 I 后段）：

- **标的同一种类**——各原告对被告的请求基于同类法律关系（如同一次污染对各户的赔偿）；
- **法院认为可以合并审理**——隐含各请求须落在**同一法院管辖**之内；
- **当事人同意**——拼团要自愿，任何一方不同意就拆开审。

法律后果与必要共同诉讼针锋相对：**可分可合**；其中一人的诉讼行为（承认、撤诉、和解）**对其他共同诉讼人不发生效力**（民诉法55 II 后段）——普通共同诉讼只是"程序拼车"，实体上各管各的。

#### 大白话讲解

沿岸 12 户渔民各损失 10 万元。每一户对甲乙两公司都有**自己独立的**赔偿请求权——12 个"同一种类"的标的，不是一个共同标的。12 户可以各自起诉，也可以拼在一起：只要都归清河市法院管、法院觉得合并省事、**12 户都点头**，就合并成普通共同诉讼，一案审 120 万。

开庭后第 3 户跟甲厂私下和解拿了 8 万撤诉——**只灭他自己那一份**，其余 11 户的官司照打不误；反过来第 5 户承认"污染与死鱼无关"，也**拖累不了**别人。这就是"可分可合、各自判"：拼的是车，不拼命运。

对照第一步：老赵那 30 万里甲乙两被告是"一荣俱荣一损俱损"（必要）；12 户原告之间是"各领各的粮票"（普通）——**被告侧连带绑死、原告侧同类拼团**，一题里经常两头一起考。

#### 一句话闭环记忆

> 🎯 **一眼判**：同类标的＋法院认为可合并＋当事人同意＝普通共同诉讼——**可分可合**，一人的承认/和解/撤诉**只管自己**；缺"同意"或不同管辖就拆开各审，谁也不能强拼。

---

### 第三步：判代表人诉讼——人多推代表，处分须点头

> **十人以上推代表，公告登记效力张，重大处分须同意**

#### 概述

共同诉讼一方**人数众多**（一般指**十人以上**，解释75）时，全员出庭不现实，制度给出"代表人"方案，分两轨：

- **人数确定型（民诉法56）**：起诉时人头数得清——由当事人**推选**代表人（可共同推选，也可部分当事人推自己的，解释76）；推选不出的，**必要共同诉讼中自己参加诉讼，普通共同诉讼中可另行起诉**；
- **人数不确定型（民诉法57）**：起诉时人数还在滚动——法院**发出公告**说明案情、通知权利人**登记**（公告期**不少于三十日**，解释79）；登记须证明法律关系和损害，证明不了的不予登记、可另诉（解释80）；代表人产生按"登记权利人推选→法院提人选**协商**→在起诉当事人中**指定**"三级递进（解释77）；
- **代表人人数与权限**：代表人**二至五人**、每位可委托一至二名诉讼代理人（解释78）；代表人的诉讼行为对被代表人生效，**但变更、放弃诉讼请求、承认对方诉讼请求、进行和解，必须经被代表的当事人同意**（56/57 条同款）；
- **效力扩张（不确定型独有）**：判决裁定对**参加登记的全体权利人**生效、裁判**在登记范围内执行**；**未登记的权利人在诉讼时效期间起诉的，认定其请求成立即裁定适用原判决**（57 III＋解释80）——这是专门救济通道，**不走第三人撤销之诉**。

#### 大白话讲解

受损养殖户滚到 **120 户**、起诉时还在陆续冒头——人数众多（120≥10）且**起诉时不确定**，走民诉法57条：清河市法院发**公告 30 日**："因甲乙倾倒废酸受损的养殖户，请来登记。"到期 **100 户**登记在册（各须拿出养殖合同、死鱼照片证明关系与损害），推选出老赵等 **3 名代表人**（2-5 人区间内）打这场官司。

庭审中代表人能干什么？举证、质证、辩论——这些**一般诉讼行为**代表 100 户当然有效。但甲厂提出"总额打七折和解"，3 名代表人**不能自己拍板**——和解属四类重大处分，**必须经被代表的当事人同意**；90 户同意、10 户反对，则调解只拘束同意的 90 户，反对的 10 户继续判（对照 [[民诉-代表人诉讼-单选-75 · 代表人调解对不同意当事人的效力|单75]]）。

判决下来：甲乙连带赔偿——**对登记在册的 100 户全体生效、在登记范围内执行**。漏网的第 101 户老孙怎么办？**在诉讼时效内自己另案起诉**，法院认定他确属受害人，**裁定直接适用原判决**——不用重打一遍，也**轮不到第三人撤销之诉**（提了就是裁定不予受理，[[民诉-第三人撤销之诉-单选-194 · 代表人诉讼未登记权利人的救济不是第三人撤销之诉|单194]]）。

**加一个反向对照**：证券纠纷特别代表人诉讼（证券法95条3款，转引自已核验题卡）恰好反过来——投保机构受 50 名以上投资者委托后，为**全体确认权利人**默示登记，**只有明示退出的才被排除**（"默示加入、明示退出"）；普通代表人诉讼则是"**明示加入**"（登记才算）。方向一正一反，多选题最爱对拼。

#### 一句话闭环记忆

> 🎯 **一眼判**：人数众多（≥10）→ 推代表（2-5人）；起诉时**确定**走56条（推选，推不出必要共同自己上/普通共同另诉），**不确定**走57条（公告≥30日登记，推选→商定→指定）；代表人**和解/变更/放弃/承认须本人同意**；判决罩住**登记者**，**未登记者时效内另诉套用原判**——不是第三人撤销之诉。

### 第四步：判公益诉讼——为公共利益出头，机关组织先、检察补位

> **机关组织先出头，检察补位公告前；中院管辖卅日告，和解不许偷撤诉**

#### 概述

损害的不是哪一户的鱼塘，而是**社会公共利益**（生态本身、众多不特定消费者）时，进入公益诉讼（民诉法58）：

- **适格原告两顺位**：第一顺位是**法律规定的机关和有关组织**（环境类社会组织须：设区的市级以上民政部门登记＋章程宗旨维护公益且专事环保＋起诉前五年无违法记录，环境解释1-5）；第二顺位是**检察机关**——仅在"没有前述机关组织，或其不提起诉讼"时才起诉（补充性），前者起诉的检察院**支持起诉**（58 II）；
- **受理与管辖**：受理四条件（明确被告＋具体诉请＋公益受损**初步证据**＋属受案范围与管辖，解释282）；**侵权行为地或被告住所地中级法院**管辖（解释283；环境案件中院以上、经批准可交基层，环境解释6）；同一行为多院起诉由**最先立案**法院管辖；
- **参加与释明**：受理后公告，其他适格机关组织**公告之日起三十日内（或开庭前）申请参加→列共同原告**、逾期不准（环境解释10/解释285）；**私益受害人申请参加的，告知另行起诉**（环境解释10 III）；法院认为诉请不足以保护公益的，**可释明变更或增加**停止侵害、修复生态等诉请（环境解释9，不违反处分原则）；
- **处分限制**：和解调解协议**公告不少于三十日**→审查不损害公益的**应当出具调解书**；**以达成和解协议为由申请撤诉不予准许**（环境解释25）；**法庭辩论终结后申请撤诉不予准许**（解释288/环境解释27，唯一例外：监管部门依法履职使诉请**全部实现**，环境解释26）；
- **与私益、刑事的关系**：公益诉讼**不影响**私益受害人依民诉法122条另行起诉（解释286/环境解释29）；裁判生效后其他适格主体就同一行为**再提民事公益诉讼裁定不予受理**（解释289，另有法定情形除外），但**私益诉讼、刑事公诉照常进行**；生效裁判认定的事实在后续私益诉讼中免证（环境解释30）。

#### 大白话讲解

清河生态修复要 **2000 万元**——这笔账不属于任何一户渔民，是"公共的账"。谁来出头？

**第一顺位**：绿水环保组织——设区的市级民政登记、专事环保 8 年、前五年无违法记录，三项全中，**适格**。它**不需要先通知环保局**（社会组织起诉没有行政前置——"前置"是检察机关自己的公告程序），直接向**清河市中级法院**（侵权行为地中院）起诉。**第二顺位**：市检察院也盯上了此案——但绿水已经起诉，检察院**不能再提**，只能**支持起诉**；只有当绿水们都不出手时，检察院履行公告程序后才自己上。

受理后法院公告案情。邻市"蓝天协会"（同样适格）30 日内申请参加——列为**共同原告**；渔民老赵也想挤进来主张自己 30 万——**告知另行起诉**（他的私益诉讼在第一步早已解决，两条轨道互不影响）。绿水只诉了"赔偿 2000 万"，法院觉得不够：**释明**增加"停止排污＋修复生态"诉请——这是法定释明权，不算替原告做主。

审到一半，甲厂找绿水私下和解"给 800 万撤诉了事"？**门都没有**：和解协议必须**公告 30 日**、法院审查**不损害公益**才**出具调解书**；想以和解为由撤诉，**不予准许**——公共利益不许暗箱交易。判决生效后：蓝天协会想就同一次倾倒**再打一场公益官司**→裁定**不予受理**（账已算清）；但第 101 户老孙的**私益另诉**、检察院对甲厂负责人的**污染环境罪公诉**，都照走不误——而且公益判决认定的排污事实，老孙**免证**直接用。

#### 一句话闭环记忆

> 🎯 **一眼判**：公益诉讼原告＝**法定机关和组织**（环境社会组织三条件），检察机关**补位不抢跑**（有人告就只支持起诉）；**中院管**、同一行为**先立案者管**、后来的适格者当**共同原告**、私益者**另行起诉**；和解必须**公告≥30日出调解书**、**不许以和解撤诉**、辩论终结后不许撤；生效后**公益不二告**，私益、刑责**照追**。

## 六、 易混提示

*   **必要共同诉讼 vs 普通共同诉讼**：
    *   *必要*＝标的**共同**（连带/共有/合伙/继承/共同侵权），不可分、须追加、一人行为经承认及于全体；*普通*＝标的**同一种类**＋法院认为可合并＋当事人同意，可分可合、一人行为不及于他人。同一题里"被告侧连带（必要）＋原告侧同类（普通）"经常并存，逐侧判断。
*   **民诉法56条 vs 57条（代表人诉讼两轨）**：
    *   *56条*＝人数**确定**，直接推选，推不出→必要共同自己参加/普通共同另诉（解释76）；*57条*＝人数**不确定**，公告≥30日登记（解释79）、推选→商定→指定（解释77）、判决效力扩张与未登记者套用（解释80）——"公告、登记、效力扩张"三件套全挂在 57 条，勿记到 56 条头上。
*   **普通代表人诉讼 vs 证券特别代表人诉讼**：
    *   *普通*＝**明示加入**（登记才参加）；*特别*＝**默示加入、明示退出**（证券法95条3款，转引自已核验题卡）——判决约束"全体确认权利人减去声明退出者"。
*   **未登记权利人的救济 vs 第三人撤销之诉**：
    *   代表人诉讼漏网者走**"时效内另行起诉＋裁定适用原判决"专门通道**（民诉法57 III＋解释80）；提第三人撤销之诉的，**裁定不予受理**。
*   **社会组织起诉 vs 检察机关起诉（公益）**：
    *   *社会组织*：**无行政前置**、无"先通知环保局"义务；*检察机关*：**补充顺位＋公告前置**，法定机关组织已起诉的只能支持起诉。"前置程序"只长在检察机关身上。

## 七、 命题人最爱的 6 个陷阱

1.  **"监护人/补充责任人/派遣单位/分立后公司作为无独立请求权第三人参加诉讼"** —— 错！承担实体赔偿责任的主体一律是**被告/共同诉讼人**（民诉解释58、63、66、67等），无独三是旁侧利害关系人，不是担责者。
2.  **"原告未起诉的连带责任人，法院可告知对其另行起诉／不追加但判其承担连带责任"** —— 错！必要共同诉讼须合一确定：法院**应当通知参加**（民诉法135）；未成为当事人不能被课责；"另行起诉"是普通共同诉讼的出口。被追加者拒不参加→**缺席判**，不能拘传。
3.  **"代表人经多数当事人推选产生，其达成的调解协议对被代表的全体当事人生效"** —— 错！变更、放弃、承认诉讼请求与**和解**必须经**被代表的当事人本人同意**（民诉法56/57）；不同意者不受调解拘束，其部分继续审判。
4.  **"未参加登记的权利人可提起第三人撤销之诉救济"** —— 错！专门通道是**诉讼时效内另行起诉、请求成立即裁定适用原判决**（民诉法57 III＋解释80）；提第三人撤销之诉的裁定不予受理。
5.  **"社会组织提起环境公益诉讼须先通知环保局／检察机关发现污染可径行起诉"** —— 错！社会组织**无行政前置**；检察机关是**补充顺位**（民诉法58 II），法定机关组织没有或不起诉时才提，已有人起诉的只能支持起诉。
6.  **"公益诉讼当事人达成和解协议，公告期满无异议的裁定准予撤诉"** —— 错！**以达成和解协议为由申请撤诉不予准许**（环境解释25 II）；法定出口是"协议公告≥30日→审查不损害公益→**出具调解书**"；法庭辩论终结后撤诉同样不准（唯一例外：监管部门履职使诉请全部实现，环境解释26）。
