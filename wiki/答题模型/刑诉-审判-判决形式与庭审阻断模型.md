# 📐 判决形式与庭审阻断 · 答题模型

> **教练开场白**
> 同学们好，我是你们的刑诉法考教练。这一关讲庭审的"**怎么停**"和"**怎么结**"——两大高频雷区：
> 
> **庭审阻断四分法（休庭/延期/中止/终止）**和**评议后三种判决（尤其"证据不足的无罪"）**，外加量刑程序、判决与裁定的区别。
> 大多数人凭惯性会踩三个坑：
> - 以为"证据不足＝中止审理，等补了证据再判"——**错！证据不足直接判无罪（疑罪从无），而且这种无罪判决一样有既判力**；
> - 把"被告人患病"当延期审理——**错！患病/脱逃/不可抗力＝中止审理（用裁定、不计审限）；补侦/重鉴/新证人才是延期（用决定）**；
> - 忘了"延期用**决定**、中止终止用**裁定**"这条文书铁律。
> 今天用**一张"庭审卡壳怎么办"四分法决策表＋三种判决辨识表**把它锁死。

## 适用场景与解决问题

本模型覆盖 [[刑诉-审判程序-深度报告]] **板块一考点14(评议后三种判决)、15(延期/中止/终止)、19(量刑程序相对独立性)、25(判决与裁定区别)**。凡题干出现"证据不足怎么判/能不能再诉""被告人患病/死亡/脱逃怎么处理""该延期还是中止/用决定还是裁定""量刑建议法院要不要采纳/明显不当怎么办""这个事项用判决还是裁定"等，立即调用本模型。

- **评议后三种判决（§200）**：①**有罪判决**（事实清楚、证据确实充分）；②**确定无罪判决**（依法认定无罪）；③**"证据不足、指控犯罪不能成立"的无罪判决**（疑罪从无）。**两类无罪都有既判力**、不得随意重新起诉（存疑无罪虽因**新证据**可再诉，但不是"随时可诉"、更非"无既判力"）；**绝不允许"留有余地"判决**（如"疑罪从轻"）。
- **庭审阻断四分法**：
  - **休庭**：当庭暂停、择期继续（如当庭申请回避需检察长决定→休庭等结果）；时间最短。
  - **延期审理（§204）**：为**取证/补程序**——需**补充侦查**（1个月、最多两次）、**重新鉴定**、**通知新证人到庭/调取新证据**；用**"决定"**。
  - **中止审理（§206）**：因**客观障碍暂时开不了**——被告人**患严重疾病无法出庭**、**脱逃**、**不可抗力**、自诉人患病等；用**"裁定"**，**期间不计入审限**。
  - **终止审理**：案件不必/不能再审——被告人**死亡（且非无罪）**、**超过追诉时效**、**告诉才处理的撤回告诉**等；用**"裁定"**。
- **被告人死亡双轨**：原则**裁定终止审理**；**例外**——有证据证明**无罪**、经（缺席）审理确认无罪的，**判决宣告无罪**（死亡只为还清白，不能借此定罪）。
- **量刑程序相对独立性（§201）**：法庭辩论中提出**新的定罪/量刑事实、证据**的，应**恢复法庭调查**；**定罪量刑证据可一次调查兼顾**、无须分别出示；法院对检察院量刑建议保留**独立审查权**，认为**明显不当**可建议检察院调整、不调整或调整后仍明显不当的**法院依法判决**；裁判文书说明量刑理由，该制约**覆盖全部刑案**（非仅认罪认罚）。
- **判决与裁定的区别**：**判决**解决**实体**问题（罪与非罪、罪轻罪重）；**裁定**解决**程序**问题（诉讼能否继续），但有**死刑复核裁定**等例外，不宜绝对化；**上诉/抗诉期限：判决10日、裁定5日**（是二者区别中**唯一无例外的刚性规则**）；**精神病人不能辨认/控制自己行为造成危害结果的应以"无罪判决"处理**（实体认定，不是裁定）。

> **核心一句**：**「§200三种判决＝有罪/确定无罪/存疑无罪，两类无罪都有既判力、疑罪从无不留余地；卡壳四分法＝取证延期(决定)、患病脱逃中止(裁定不计审限)、死亡且非无罪终止(裁定)、当庭回避休庭；量刑＝新证据恢复调查、建议明显不当法院可判；判决管实体、裁定管程序，上诉期判10裁5。」**

> 🔎 **法条口径**：刑诉法§200（三种判决）、§201（量刑建议采纳与调整）、§204（延期审理）、§206（中止审理）+ 判决与裁定的实体/程序区分与上诉期限（判决§230=10日、裁定§230=5日）。

> ⚠️ **易记错点**：①**证据不足＝判无罪（疑罪从无），不是中止审理**；②**两类无罪都有既判力**，存疑无罪仅"有新证据"才可再诉、非"随时"；③**留有余地判决绝对禁止**；④**患病/脱逃/不可抗力＝中止（裁定、不计审限）；补侦/重鉴/新证人＝延期（决定）**；⑤**被告人死亡原则终止、例外确证无罪判无罪**；⑥**量刑建议明显不当→法院可依法判决**（法院有独立审查权）；⑦**上诉期判决10日、裁定5日**（唯一无例外刚性）；⑧**精神病人危害结果＝无罪判决**（不是裁定）。

## 一、 "庭审卡壳怎么办"四分法决策表（做题先查这张）

```
            【庭审开不下去了，怎么处理？】
                       │
   为什么开不下去？
   ├─ 当庭要处理小事(申请回避待决定)──► 休庭（当庭暂停、择期续）
   ├─ 需要"取证/补程序"(补侦/重鉴/新证人)──► 延期审理§204【用决定】(补侦1月·最多2次)
   ├─ 遇"客观障碍暂时来不了"(患病/脱逃/不可抗力)──► 中止审理§206【用裁定·不计审限】
   └─ 案件"不必/不能再审"(死亡且非无罪/超追诉时效)──► 终止审理【用裁定】
```

| 情形 | 处理 | 文书 | 审限 |
|---|---|---|---|
| 当庭申请回避待检察长决定 | **休庭** | — | 短暂 |
| 需补充侦查 | 延期审理 | **决定** | 补侦1月、最多2次 |
| 需重新鉴定 / 通知新证人 | 延期审理 | **决定** | 计入 |
| 被告人患病无法出庭 / 脱逃 / 不可抗力 | **中止审理** | **裁定** | **不计入审限** |
| 被告人死亡且非无罪 / 超追诉时效 | **终止审理** | **裁定** | 了结 |

> 🎯 **一眼扫**：**取证→延期(决定)；障碍→中止(裁定·不计审限)；了结→终止(裁定)；小事当庭→休庭。患病是"中止"不是"延期"，重鉴是"延期"不是"中止"。**

## 二、 第一关：评议后三种判决（证据不足＝判无罪，不是中止）

> **教练提示**：这一关的杀手锏是第③种判决——"**证据不足、指控犯罪不能成立的无罪判决**"。记死三点：**它是无罪判决（不是中止）、它有既判力、它是疑罪从无的落地**。

### `判` 字诀——三种判决，两类无罪都算数

**先懂几个词**：

- **既判力**：判决生效后"一事不再理"，不能就同一事随意再诉。

- **存疑无罪（疑罪从无）**：证据不足、指控不能成立时判的无罪。

- **留有余地判决**：证据不足却"疑罪从轻"判个轻罪——**绝对禁止**。


**🔍 对号入座表（§200 三种判决）**：

| #   | 判决         | 触发              | 效力                   |
| --- | ---------- | --------------- | -------------------- |
| ①   | 有罪判决       | 事实清楚、证据确实充分     | 生效有既判力               |
| ②   | 确定无罪判决     | 依法认定无罪          | 有既判力                 |
| ③   | **存疑无罪判决** | **证据不足、指控不能成立** | **有既判力**；仅"有新证据"才可再诉 |
| —   | ❌ 中止审理     | 证据不足**不是**中止事由  | —                    |
| —   | ❌ 留有余地判决   | 疑罪从轻            | **绝对禁止**             |

**特殊情形**：
- ①**精神病人**不能辨认/控制自己行为造成危害结果的→**无罪判决**（实体认定）；
- ②**未满16周岁**又证据不足的→仍作**无罪判决**（择"证据不足"这一无罪路径）；
- ③被告人**死亡**但有证据证明无罪、经审理确认的→**判决宣告无罪**（其余死亡情形裁定终止）。

**💰 完整数字案例**：某故意杀人案合议庭评议后认为"在案证据不足、指控不能成立"——法院**不能裁定中止审理等补证据**，而应依§200第三项直接作**"证据不足、指控犯罪不能成立"的无罪判决**；该无罪判决**与确定无罪一样有既判力**，检察院只有**发现新证据**（如新的目击者、DNA）时才能重新起诉，而非"随时可诉"。→ 对应 [[刑诉-审判-单选-10 · 评议后三种判决与两类无罪的既判力（仿真题）|单选-10]]、[[刑诉-审判-单选-49 · 故意伤害证据不足判无罪后新证据重新起诉|单选-49]]、[[刑诉-审判-单选-69 · 盗窃案证据不足兼未满十六周岁的无罪判决形式|单选-69]]、[[刑诉-审判-单选-32 · 精神病人危害结果特殊情形应以判决处理|单选-32]]。

> 🎯 **一眼判**：**§200三种判决＝有罪/确定无罪/存疑无罪；证据不足＝判无罪(疑罪从无)不是中止；两类无罪都有既判力；留有余地判决绝对禁止；精神病人危害结果＝无罪判决。**

## 三、 第二关：庭审阻断四分法（延期决定/中止裁定/终止裁定/休庭）

> **教练提示**：这一关背两张对应表——"**事由→处理**"和"**处理→文书**"。三组条件反射："**患病＝中止、重鉴＝延期、死亡且非无罪＝终止**"；文书："**延期用决定、中止终止用裁定**"。

### `断` 字诀——取证延期，障碍中止，了结终止

**🔍 对号入座表（事由 → 处理 → 文书）**：

| 题干事由                  | 处理       | 文书     | 记忆             |
| --------------------- | -------- | ------ | -------------- |
| 需补充侦查                 | 延期审理     | **决定** | 补侦1月·最多2次      |
| 需重新鉴定 / 通知新证人 / 调取新证据 | 延期审理     | **决定** | "取证"就延期        |
| 被告人患严重疾病无法出庭          | **中止审理** | **裁定** | 病好才恢复·**不计审限** |
| 被告人脱逃 / 不可抗力 / 自诉人患病  | **中止审理** | **裁定** | 障碍消除才恢复        |
| 被告人死亡（且非无罪）           | **终止审理** | **裁定** | 案件了结           |
| 超过追诉时效 / 撤回告诉         | **终止审理** | **裁定** | 不再审            |
| 当庭申请回避待检察长决定          | **休庭**   | —      | 短暂暂停           |
|                       |          |        |                |

**💰 完整数字案例**：四个被告人四种卡壳——① 甲患新冠需隔离、无法出庭→**中止审理（裁定、不计审限）**（不是延期！）；② 乙当庭以法定理由申请公诉人回避、需检察长决定→**休庭**等结果；③ 丙审理中自杀身亡、已查明构成犯罪→**裁定终止审理**（若查明无罪则判决宣告无罪）；④ 丁申请重新鉴定→**延期审理（用决定）**（不是"裁定中止"，处理方式和文书都别搞反）。→ 对应 [[刑诉-审判-多选-69 · 审理程序中断休庭延期中止终止四分法|多选-69]]、[[刑诉-审判-多选-12 · 延期中止终止审理的区分与审限计算（仿真题）|多选-12]]、[[刑诉-审判-单选-70 · 中止审理适用情形的甄别|单选-70]]、[[刑诉-审判-多选-63 · 被告人审理期间死亡终止审理与确证无罪宣告|多选-63]]。

> 🎯 **一眼判**：**取证(补侦/重鉴/新证人)→延期用决定；障碍(患病/脱逃/不可抗力)→中止用裁定不计审限；了结(死亡且非无罪/超时效)→终止用裁定；当庭小事→休庭。**

## 四、 第三关：量刑程序的相对独立性（新证据恢复调查·建议明显不当法院可判）

> **教练提示**：量刑程序这几年是新热点。抓两条主线："**辩论中冒出新事实/证据→恢复法庭调查**"和"**法院对量刑建议有独立审查权、明显不当可自己判**"。

### `量` 字诀——新证据回炉，量刑建议法院说了算

**🔍 对号入座表**：

| 情形                  | 规则                                                  |
| ------------------- | --------------------------------------------------- |
| 法庭辩论中提出新的定罪/量刑事实、证据 | **恢复法庭调查**（不能带着新证据直接辩论/判决）[[200-刑诉-程序-庭审阻断-恢复法庭调查]] |
| 定罪证据与量刑证据           | **可一次调查兼顾**、无须分别出示                                  |
| 未经庭审质证的材料           | **不得作为定案根据**                                        |
| 检察院量刑建议             | 法院保留**独立审查权**（量刑程序相对独立性）                            |
| 量刑建议**明显不当**        | 法院建议检察院调整；不调整或调整后仍明显不当→**法院依法判决**                   |
| 速裁程序量刑建议            | 检察院可**当庭调整**                                        |
| 量刑建议约束力覆盖           | **全部刑事案件**（非仅认罪认罚）                                  |

**💰 完整数字案例**：刘某交通肇事案法庭辩论阶段，被害人方突然提交一份新的伤情鉴定（影响量刑）——法院应**恢复法庭调查**、就该新证据质证，而不能直接进入判决。若检察院量刑建议"判 3 年"但法院认为**明显偏轻不当**，先建议检察院调整；检察院不调整或调整后仍明显不当的，**法院依法自行判决**（体现量刑程序相对独立性、法院独立审查权）。→ 对应 [[刑诉-审判-单选-28 · 刘某丈夫酒后驾车送医案量刑程序法庭调查恢复规则|单选-28]]、[[刑诉-审判-多选-31 · 量刑程序相对独立性与检察院制约辨析|多选-31]]、[[刑诉-审判-多选-57 · 庭审证据质证与量刑辩论重开规则|多选-57]]。

> 🎯 **一眼判**：**辩论冒新证据→恢复法庭调查；量刑建议明显不当→法院可依法判决；未质证材料不得定案；量刑建议约束覆盖全部刑案。**

## 五、 第四关：判决与裁定的区别（实体vs程序·上诉期10/5）

> **教练提示**：这一关记一条"唯一无例外"的刚性规则——**上诉/抗诉期限：判决 10 日、裁定 5 日**。实体/程序的分法有例外（死刑复核用裁定），别绝对化。

### `裁` 字诀——判决管实体，裁定管程序，唯期限最硬

**🔍 对号入座表**：

| 维度 | 判决 | 裁定 |
|---|---|---|
| 解决问题 | **实体**（罪与非罪、罪轻罪重） | **程序**（诉讼能否继续） | 
| 上诉/抗诉期 | **10 日** | **5 日** |（★唯一无例外的刚性区别）
| 典型 | 有罪/无罪判决、改判 | 终止审理、驳回起诉、管辖异议；**死刑复核核准/不核准用裁定**（实体例外） |
| 精神病人危害结果 | **无罪判决**（实体认定） | ❌ 不是裁定 |
| 追诉时效届满/死亡且非无罪/退庭 | — | **裁定终止审理**或按撤诉处理 |

> ⚠️ **别绝对化**：说"判决只管实体、裁定只管程序"大方向对，但**死刑复核裁定**是实体问题却用裁定——所以"实体/程序"区分**有例外**；真正**没有例外**的只有"**上诉期判决10日、裁定5日**"。

**💰 完整数字案例**：某案追诉时效已过→法院**裁定终止审理**（程序），当事人不服的**5 日**内上诉；同案另一被告人被判有罪（实体判决），不服的**10 日**内上诉。精神病人甲不能辨认自己行为、砍伤他人→应作**无罪判决**（实体认定，不是"裁定不予追究"）。→ 对应 [[刑诉-审判-单选-33 · 刑事判决与裁定的性质区别辨析|单选-33]]、[[刑诉-审判-单选-32 · 精神病人危害结果特殊情形应以判决处理|单选-32]]。

> 🎯 **一眼判**：**判决管实体、裁定管程序（有死刑复核裁定例外）；唯一无例外＝上诉期判决10日、裁定5日；精神病人危害结果＝无罪判决。**

## 七、 命题陷阱拆解（8 大高频坑）

1. **"证据不足→中止审理等补证据"**——错。证据不足**直接判无罪**（疑罪从无§200第三项）。
2. **"存疑无罪判决无既判力、可随时重新起诉"**——错。**有既判力**，仅"有新证据"才可再诉。
3. **"疑罪从轻/留有余地判决"**——绝对禁止。
4. **"被告人患病→延期审理"**——错。患病/脱逃/不可抗力＝**中止（裁定、不计审限）**。
5. **"重新鉴定→中止审理"**——错。重鉴/补侦/新证人＝**延期（决定）**。
6. **"被告人死亡一律终止审理"**——不全对。原则终止，**例外确证无罪则判决宣告无罪**。
7. **"量刑建议法院必须采纳"**——错。法院有**独立审查权**，明显不当可建议调整、仍不当则**依法判决**。
8. **"判决裁定都是10日上诉/实体程序区分无例外"**——错。**裁定5日**；实体/程序区分**有死刑复核裁定例外**，唯"判10裁5"无例外。

## 八、 主观题万能说理模板

**【判决形式】** 本案经评议，〔证据确实充分→有罪判决／依法无罪→无罪判决／证据不足指控不能成立→§200第三项存疑无罪判决，具既判力、非中止〕，不得作留有余地判决。

**【庭审阻断】** 审理中出现〔补侦/重鉴/新证人→依§204延期审理，用决定；被告人患病/脱逃/不可抗力→依§206中止审理，用裁定、不计审限；被告人死亡且非无罪/超追诉时效→裁定终止审理〕。

**【量刑与文书】** 辩论中提出新事实证据的依§201恢复法庭调查；量刑建议明显不当的，法院建议调整、仍不当依法判决。所涉事项属〔实体→判决、10日上诉／程序→裁定、5日上诉〕。
