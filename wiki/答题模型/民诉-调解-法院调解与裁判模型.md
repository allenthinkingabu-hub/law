# 📐 法院调解与裁判 · 完整答题模型（调解原则 + 调解书生效与反悔 + 不得调解清单 + 判决种类与生效）

> **核心一句**：法院调解是**诉讼内**的"劝和"，判决是"劝不成"之后的出口，一条主线四站：**劝和的规矩（自愿+合法+查明事实分清是非，不愿调就及时裁、离婚必调但不久调，§96/§99/§125/解释§145）→ 和解书何时算数（调解书**签收**生效、送达前一方反悔就判，免制作调解书四情形记入笔录签名即生效，§100-102）→ 哪些案不能劝（特别/督促/公示催告程序＋身份关系确认案件不得调解，解释§143）→ 判决的出生与生效（给付/确认/形成三类＋一审满上诉期生效、二审终审＋笔误裁定补正，§155-158/§171/§182）**。最毒陷阱是**把"调解书"的生效时点从"签收"偷换成"送达/作出"**、**把"调解和好的离婚案件（可不制作调解书）"与"离婚案件不得调解/身份关系确认不得调解"搅在一起**、**把"调解协议超出诉讼请求"当成违法**、**把"调解书与协议不一致"的救济答成再审或无效**。
>
> 🔎 **核心条文速查**：
> - **民诉法§96【调解原则】**：人民法院审理民事案件，根据当事人**自愿**的原则，在**事实清楚**的基础上，**分清是非**，进行调解。**§99**：调解达成协议必须双方**自愿，不得强迫**；调解协议的内容**不得违反法律规定**。
> - **民诉法§97-98【组织形式】**：可由**审判员一人**主持，也可由**合议庭**主持，并尽可能**就地**进行；可用**简便方式**通知当事人、证人到庭；可**邀请有关单位和个人协助**，被邀请者应当协助。
> - **民诉法§125【先行调解】**：当事人起诉到法院的民事纠纷，适宜调解的，**先行调解**，但**当事人拒绝调解的除外**。**解释§142【径行调解】**：受理后经审查认为法律关系明确、事实清楚，**征得当事人双方同意**后，可以径行调解。
> - **解释§145【不愿调及时裁＋离婚不久调】**：应当根据**自愿、合法**的原则进行调解，一方或双方**坚持不愿调解**的，应当**及时裁判**；审理**离婚案件应当进行调解**，但**不应久调不决**。**民诉法§145**：法庭辩论终结应当依法作出判决，判决前能够调解的还可以调解，**调解不成的，应当及时判决**。
> - **民诉法§100【调解书与签收生效】**：调解达成协议，法院**应当制作调解书**，写明**诉讼请求、案件的事实和调解结果**；由审判人员、书记员署名，加盖法院印章，送达双方当事人；**经双方当事人签收后，即具有法律效力**。**解释§149**：以**最后**收到调解书的当事人签收的日期为生效日期。**解释§133**：调解书应当**直接送达**当事人本人，**不适用留置送达**。
> - **民诉法§101【可不制作调解书四情形】**：（一）调解**和好的离婚**案件；（二）调解**维持收养关系**的案件；（三）能够**即时履行**的案件；（四）其他不需要制作调解书的案件。对不需要制作调解书的协议，**记入笔录**，由双方当事人、审判人员、书记员**签名或者盖章后，即具有法律效力**。
> - **民诉法§102【反悔→判决】**：调解**未达成协议**或者**调解书送达前一方反悔**的，人民法院**应当及时判决**。
> - **解释§143【不得调解】**：适用**特别程序、督促程序、公示催告程序**的案件，**婚姻等身份关系确认案件**以及其他根据案件性质不能进行调解的案件，**不得调解**。**解释§150**：调解需由**无独立请求权第三人承担责任**的，应当**经其同意**；该第三人在调解书**送达前反悔**的，应当**及时裁判**。**解释§148**：请求按和解/调解协议的内容**制作判决书**的，**不予准许**（无民事行为能力人的离婚案件，法定代理人与对方达成协议要求发判决书的除外）；**解释§528**：**涉外**诉讼中经调解达成协议应制发调解书，当事人要求发给判决书的，**可以**依协议内容制作判决书。
> - **民诉法§155-158【判决与生效】**：判决书写明判决结果与理由（§155）；一部分事实已经清楚的可**先行判决**（§156）；裁定第（七）项＝**补正判决书中的笔误**（§157），笔误指法律文书**误写、误算**，诉讼费用漏写、误算和其他笔误（解释§245）；最高法院的判决裁定、依法**不准上诉**或**超过上诉期没有上诉**的判决裁定，是发生法律效力的判决裁定（§158）。**§171**：不服一审判决的上诉期＝判决书送达之日起**15日**，裁定**10日**；不能同时送达的，上诉期**各自计算**（解释§244）。**§182**：第二审法院的判决、裁定是**终审**的判决、裁定。
> - **民诉法§179【二审调解】**：二审可以调解，调解书**送达后**，**原审判决即视为撤销**。**§212**：对已生效调解书提出证据证明**调解违反自愿原则**或**调解协议内容违反法律**的，可以申请再审。**§205-206【司法确认】**：调解组织的调解协议生效后**30日内双方共同**申请司法确认，裁定有效后一方不履行的，对方可**申请执行**。

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已在本地权威全文（ssf.gov.cn 发布的民诉法2023全文PDF转文本、民诉解释2022全文）中**逐条grep到原文**后写入：民诉法§96、§97、§98、§99、§100、§101、§102、§115、§125、§145、§146-148（缺席撤诉衔接）、§155、§156、§157、§158、§171、§179、§182、§205、§206、§212，民诉解释§61、§133、§142、§143、§144、§145、§146、§147、§148、§149、§150、§151、§244、§245、§528。**特别提示四处易错标注**：①**"调解协议可以超出诉讼请求"没有一个民诉法/民诉解释的专门条文**——本地2022民诉解释全文grep"超出诉讼请求"仅命中再审章节（§390），该规则的直接出处在《关于人民法院民事调解工作若干问题的规定》（法释〔2004〕12号，2020修正）系列调解规范中，其具体条号**未经本地全文核验，本模型不标注**，只依民诉法§96/§99（自愿＋不违法即可）＋通说呈现规则本身（与[[民诉-调解-单选-139 · 调解协议超诉请与担保人拒签调解书]]题卡口径一致）；②**判决"给付/确认/形成"三分是学理分类，无条文号**，不得虚标；③**"不得调解"清单的法源是解释§143**，不在民诉法本体——民诉法第十五章特别程序§185只规定特别程序"一审终审"，"非讼不适用调解"的明文归置在解释§143；④**"笔误"的裁定形式在民诉法§157一款（七）项，"笔误"的定义在解释§245**，两个条号分工不同；调解书与调解协议不一致的"裁定补正"救济系§157（七）的参照适用（与题卡[[民诉-调解-单选-144 · 调解书与调解协议不一致的补正]]口径一致）。仲裁调解书"签收生效、与裁决书同等效力"依《仲裁法》，其条号未在本地全文核验，本模型不标注。官方全文：[民诉法2023（ssf.gov.cn PDF）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)。

> ⚠️ **易记错点**：①**调解书生效＝双方"签收"，不是"送达"更不是"作出"**（§100）——双方分别签收的，以**最后签收日**为生效日（解释§149）；一方拒签，调解书**整体不生效**，且调解书**不适用留置送达**（解释§133）；②**"送达前一方反悔→及时判决"（§102）里能反悔的是"尚未签收的一方"**——已当庭签收的当事人受签收拘束，不能次日反悔（题卡142/143的命题眼）；③**免制作调解书四情形口诀"和好·维持·即时·其他"**——是"调解**和好**的离婚"和"调解**维持**收养"可免书（关系**继续**，无需执行依据），若调解**离掉了**/解除收养了，必须制作调解书；④**离婚案件"应当调解"，但"婚姻等身份关系确认案件"不得调解**——离不离可以劝，"婚姻是否有效/亲子关系是否存在"不能拿来讨价还价；离婚案中的**财产分割**部分可调；⑤**国内案件不得按调解协议制作判决书（解释§148），涉外案件当事人要判决书可以给（解释§528）**——内外有别，反向互为陷阱；⑥**调解书与调解协议不一致→裁定补正**（§157（七）参照），不是再审（再审事由是"违反自愿/内容违法"§212）、不是无效、不用重新起诉；⑦**一审判决"满上诉期未上诉"才生效（§158＋§171十五日），二审判决作出即终审生效（§182）**——别把一审判决说成"送达即生效"；⑧**二审调解书送达后，原审判决"视为撤销"**（§179），不需要再裁定撤销原判。

## 二、 判别模型（劝和的规矩 → 何时算数 → 哪些不能劝 → 判决出生与生效）

```
        【案件进入诉讼（起诉受理后 → 宣判前全程可调）】
                    │
   ▼ 第一站：劝和的规矩（§96-99、§125、§145，解释§142/§145-147）
   │  三原则：自愿（不得强迫）＋ 合法（协议内容不违法）＋ 事实清楚分清是非
   │  时机：起诉后先行调解（拒绝除外）→ 受理后径行调解（双方同意）
   │        → 判决前能调则调；坚持不愿调 → 及时裁判
   │  离婚案：应当调解，但不应久调不决
   │  形式：独任/合议庭主持、就地调、简便通知、邀请单位个人协助；过程不公开
                    │
   ▼ 第二站：和解书何时算数（§100-102，解释§133/§148-151）
   │  达成协议 → 原则应当制作调解书（写明诉请·事实·调解结果）
   │  ├─ 免书四情形：和好离婚／维持收养／即时履行／其他
   │  │     → 记入笔录，双方＋审判人员＋书记员签名盖章即生效
   │  ├─ 生效：双方签收后生效（最后签收日为准）；直接送达、不留置
   │  ├─ 反悔：未达成协议 or 调解书送达前一方（未签收方）反悔 → 及时判决
   │  │     已签收方受拘束不能反悔；无独三担责须同意、送达前可反悔
   │  ├─ 超诉请：自愿＋合法即可，可以超出诉讼请求
   │  └─ 判决书替代：国内不予准许（解释§148）；涉外可以（解释§528）
                    │
   ▼ 第三站：哪些案不能劝（解释§143-144，§115）
   │  不得调解：特别程序／督促程序／公示催告程序案件
   │            ＋ 婚姻等身份关系确认案件 ＋ 性质不能调解的案件
   │  可调对照：离婚本身应当调解；离婚案中的财产分割可调
   │  防线：恶意串通借调解侵害他人权益 → 按§115虚假诉讼处理
                    │
   ▼ 第四站：判决的出生与生效（§155-158、§171、§179、§182，解释§244-245）
   │  种类（学理）：给付判决／确认判决／形成判决；部分事实清楚可先行判决§156
   │  生效：一审判决满15日上诉期未上诉生效（裁定10日；各自送达各自算）
   │        二审判决裁定＝终审，作出即生效；不准上诉的作出即生效
   │  笔误：误写误算 → 裁定补正（§157七项）；调解书与协议不一致同理补正
   │  调解书善后：二审调解书送达 → 原判视为撤销§179；
   │              生效调解书再审事由＝违反自愿/内容违法§212
```

> **一句话总诀**：**「自愿合法查清是非，不愿调就及时裁、离婚必调不久调；调解书签收才生效、最后签收日为准，未签收方可反悔、反悔就判，和好维持即时可免书、笔录签名即生效，超诉请不违法、国内不给判决书涉外给；非讼程序＋身份确认不得调，离婚财产可以调；判决给付确认形成三张脸，一审满十五日生效、二审终审即生效，写错字裁定补正不再审」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **调解书送达即生效** | 调解书经送达双方当事人后即发生法律效力。 | **❌ 说法错误！**调解书经双方当事人**签收**后才生效（§100）；双方分别签收的以**最后签收日**为生效日（解释§149）。"送达"与"签收"一字之差——拒签＝未签收＝不生效，且调解书**不适用留置送达**（解释§133），不能"视为送达"强行生效。 |
| **签收后还能反悔** | 当事人当庭签收调解书后，在生效前仍可以反悔，法院应当及时判决。 | **❌ 说法错误！**§102"送达前一方反悔"指**尚未签收的一方**。已签收的当事人受签收行为拘束——双方都当庭签收的，调解书**即已生效**，次日反悔无效（题卡142）；一方签收一方未签收的，能让调解书流产的是**未签收方**，已签收方不能反悔（题卡143，从题库口径）。 |
| **超诉请的调解协议违法** | 原告只诉请280万元本金，调解协议约定另付5万元利息并由第三人担保，超出诉讼请求范围，不具有合法性。 | **❌ 说法错误！**调解以**处分原则**为底色，协议内容只要**双方自愿、不违反法律规定**（§96/§99）即可**超出诉讼请求**——加利息、加担保都行（题卡139）。判决不得超诉请，调解可以，两种结案方式的"半径"不同。 |
| **离婚案件不得调解** | 离婚案件涉及身份关系，人民法院不得进行调解。 | **❌ 说法错误！**恰恰相反——审理**离婚案件应当进行调解**（解释§145 II），只是不应久调不决。不得调解的是**婚姻等身份关系"确认"案件**（婚姻是否有效、亲子关系是否存在，解释§143）——"要不要离"可以劝，"婚姻效力/血缘真假"不能谈判。离婚案中的**财产分割**更是常规可调事项。 |
| **国内案件可按调解协议发判决书** | 双方达成调解协议后，请求法院按照协议内容制作判决书的，法院应当准许。 | **❌ 说法错误！**国内案件**不予准许**（解释§148）——想要生效文书就走调解书。**涉外**案件是镜像例外：应制发调解书，当事人要求发判决书的**可以**依协议内容制作判决书（解释§528，题卡140/141）。 |
| **调解书写错了申请再审** | 调解书内容与调解协议不一致的，当事人可以申请再审（或主张调解书无效、重新起诉）。 | **❌ 说法错误！**这是**制作差错（笔误）**，救济是申请法院**裁定补正**（§157一款七项参照，解释§245；题卡144）。再审留给"调解**违反自愿原则**或协议内容**违反法律**"（§212）；差错既不导致无效，也无须另诉。 |
| **一审判决送达即生效** | 一审判决书送达双方当事人后即发生法律效力，当事人应当履行。 | **❌ 说法错误！**一审判决要等**上诉期（送达之日起15日，裁定10日）届满无人上诉**才生效（§158＋§171）；判决书不能同时送达的，上诉期**各自计算**（解释§244），以**最后届满**者为全案生效时点。**二审**判决裁定才是**终审**、作出即生效（§182）。 |

## 四、 相邻制度对照表（法院调解 vs 人民调解 vs 仲裁调解）

三种"调解"同名不同命，命题人爱拿甲制度的规则安到乙制度头上：

| 事项 | 法院调解（诉讼中） | 人民调解（诉讼外） | 仲裁调解（仲裁中） |
|---|---|---|---|
| 主持者 | 人民法院（独任/合议庭，§97） | 人民调解委员会等依法设立的调解组织 | 仲裁庭 |
| 成果文书 | **调解书**（或免书情形记入笔录） | **调解协议**（民事合同性质，本身无强制执行力） | 仲裁**调解书**（与裁决书同等法律效力，条号未经本地核验不标注） |
| 生效方式 | 双方**签收**后生效（§100，最后签收日为准，解释§149） | 达成即在当事人间有约束力，但**须经司法确认才能强制执行** | 双方**签收**后生效 |
| 强制执行力 | 有——生效调解书是执行依据 | 无——须走**司法确认**（§205-206：协议生效后**30日内双方共同**向基层法院申请，裁定有效后可申请执行） | 有——与裁决书同等效力 |
| 反悔出口 | 调解书送达前未签收方反悔→法院**及时判决**（§102） | 一方不履行调解协议→另一方**以对方当事人为被告起诉**（解释§61），或确认后申请执行 | 签收前反悔→仲裁庭**及时作出裁决** |
| 生效后翻盘 | 证明**违反自愿/内容违法**→申请再审（§212） | 确认裁定驳回的→变更协议/达成新协议/另行**起诉**（§206） | 依仲裁法申请撤销/不予执行裁决的路径（另章） |

> ⚠️ **一眼分家**：见"调解"先问**谁主持**——法院主持出**调解书**（签收生效、直接执行），调解组织主持出**调解协议**（合同效力、要司法确认），仲裁庭主持出**仲裁调解书**（等同裁决）。人民调解协议"当然可以强制执行"是经典错句。司法确认程序详见[[民诉-总论-主管与诉模型]]。

## 五、 万能四步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序问题分析），按照以下四步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司支付货款**50万元**，法院受理后适用普通程序。审理中双方愿意调解，最终达成协议：乙公司在10日内支付本金50万元**另加利息3万元**，并由**丙公司提供担保**。全案以这条"劝和→出书→签收→出岔"的时间线贯穿四步（离婚、身份关系情节以变体形式插入）。

### 第一步：规矩诀——自愿合法查清是非，不愿调就及时裁

> **自愿合法分是非，先行径行判前调，离婚必调不久调**

#### 概述

法院调解不是"和稀泥"，是有三条铁规矩的诉讼行为（§96/§99）：

- **自愿**：调解的启动、进行、达成协议全程自愿，**不得强迫**；一方或双方**坚持不愿调解**的，应当**及时裁判**（解释§145 I）——"劝"可以，"逼"不行，"拖"更不行；
- **合法**：调解**协议的内容**不得违反法律规定（§99）——程序上让步随意，底线是不违法、不损害他人；
- **事实清楚、分清是非**：在**事实清楚的基础上分清是非**进行调解（§96）——调解不是糊涂账，法院心里要有本明白账。

**时机上三个入口**：起诉后**先行调解**（适宜调解的先调，当事人**拒绝的除外**，§125）；受理后法律关系明确、事实清楚，**征得双方同意**可**径行调解**（解释§142）；一路到**判决前**都"能调则调"，调解不成**及时判决**（§145）。**离婚案件特殊**：**应当**进行调解（必经），但**不应久调不决**（解释§145 II）。

**形式上一把抓**：**审判员一人**或**合议庭**主持均可、尽可能**就地**进行、**简便方式**通知当事人证人（§97）、可**邀请有关单位和个人协助**（§98）；调解**过程不公开**、协议内容原则不公开（解释§146）；当事人不能出庭的，经**特别授权**可由委托代理人参加调解并签名（解释§147）。

#### 大白话讲解

甲公司起诉乙公司要50万货款。案子刚递进来，立案庭法官先问一句："这纠纷挺适合坐下来谈的，愿不愿意先调调？"——这就是**先行调解**（§125）。乙公司说"愿意谈"，那就先谈；如果甲公司一口回绝"不谈，就要判决"——**拒绝调解的除外**，法院不能硬按着谈。

案子受理后，法官看卷宗：合同明确、欠款清楚，**征得双方同意**后径行组织调解（解释§142）。调解那天不用开庭那套阵仗：法官**一个人主持**就行，打电话**简便通知**双方到场（§97），还把双方共同的行业协会请来**帮着劝**（§98）。谈的过程**不公开**——门一关，说什么外人无权旁听（解释§146）。甲公司老板出差在外？给律师出具**特别授权**委托书，律师可以代为谈、代为签（解释§147）。

三条底线时刻在场：乙公司如果中途拍桌子"不谈了"——**坚持不愿调解的，及时裁判**（解释§145），法官不能说"不谈完不许走"；双方如果商量出"乙把欠税的钱先拿来还甲"这种违法安排——**内容违法，不能认**（§99）；法官也不能两眼一抹黑就劝"一人让一步"——得先把**账查清楚、是非分清楚**（§96）。

**离婚变体**：换成朱某诉刘某离婚——离婚案**必须先调解**（必经程序），但调三次五次还没结果就该判了，**不应久调不决**。

| 规矩要素 | 内容 | 条文 |
|---|---|---|
| 三原则 | 自愿（不得强迫）、合法（内容不违法）、事实清楚分清是非 | §96、§99 |
| 三入口 | 起诉后先行调（拒绝除外）→受理后径行调（双方同意）→判决前能调则调 | §125、解释§142、§145 |
| 两出口 | 坚持不愿调→及时裁判；调解不成→及时判决 | 解释§145、§145/§102 |
| 离婚特则 | 应当调解＋不应久调不决 | 解释§145 II |

#### 一句话闭环记忆

> 🎯 **一眼判**：调解三原则**"自愿、合法、查清事实分清是非"**缺一不可；见"法院应当继续做调解工作直至达成协议""强制调解"一律判错——**不愿调就裁、调不成就判、离婚必调但不许拖**。

### 第二步：算数诀——调解书签收才生效，未签收方才能反悔

> **签收生效最后日，反悔限于未签方，和好维持即时免书，超诉请不违法**

#### 概述

达成协议只是"口头握手"，什么时候"算数"要看文书规则（§100-102）：

- **原则要出调解书**：写明**诉讼请求、案件的事实和调解结果**三件事，审判人员、书记员署名＋法院盖章，送达双方（§100 I/II）；
- **生效＝双方签收**：调解书经**双方当事人签收**后即生效（§100 III）；分别签收的，以**最后签收日**为生效日（解释§149）；调解书**直接送达本人、不适用留置送达**（解释§133）——拒签就是没签收，不能"留置视为送达"；
- **反悔窗口**：调解**未达成协议**，或调解书**送达前一方反悔**的，法院**应当及时判决**（§102）——能反悔的是**还没签收的一方**；已签收方受签收拘束（当庭双方都签收＝当场生效，谁都不能反悔）；调解需由**无独三承担责任**的应**经其同意**，其送达前反悔的**及时裁判**（解释§150）；
- **免制作调解书四情形**（§101）：**调解和好的离婚**案件、**调解维持收养关系**的案件、**能够即时履行**的案件、其他——协议**记入笔录**，双方＋审判人员＋书记员**签名或盖章后即生效**；
- **两条边界**：调解协议**可以超出诉讼请求**（自愿＋合法即可，§96/§99＋通说，无专门条号）；国内案件**不得**按调解协议制作判决书（解释§148），**涉外**案件当事人要判决书**可以**给（解释§528）。

#### 大白话讲解

甲乙谈成了：50万本金＋**3万利息**＋丙公司担保。先过第一道坎——甲当初只告了50万，现在协议多出3万利息、还拉进担保人，**超出诉讼请求**了，行吗？**行**。判决不能超诉请，但调解是双方自己处分权利，**多谈出来的，只要自愿、不违法，都算数**（题卡139的A选项）。

法院制作调解书写清"诉请—事实—调解结果"，通知三方来签收。剧情开始分岔：

**剧情A（都签了）**：甲、乙、丙**当庭签收**——调解书**当场生效**。乙公司第二天觉得亏了想反悔？**没门**，签收＝认账（题卡142：连"协议约定须代理人签字生效、律师没签字"都救不了当庭签收的效力）。

**剧情B（丙拒签）**：丙公司反悔拒绝签收——调解书要**各方签收才生效**，丙不签，调解书**整体没生效**，不能说"对甲乙仍有约束力"；法院也**不能对丙留置送达**（调解书不适用留置，解释§133）（题卡139的B/C选项）。
 
**剧情C（一签一拖）**：换成离婚变体——朱某签收了，刘某一直不来领取，朱某又反悔不想离了。能让调解书"流产"的是**没签收的刘某**，**已签收的朱某不能反悔**；朱某真不想离，正道是**申请撤回起诉**（题卡143，题库口径，学理有争议如实标注）。

**剧情D（真反悔了）**：如果是**未签收的**乙公司在送达前明确反悔——调解流产，法院**应当及时判决**（§102），案子回到判决轨道，不是"重新调解到成为止"。

**免书清单**（离婚变体续）：朱某刘某调解**和好**不离了——关系照旧，没什么可执行的，法院**可以不制作调解书**，把协议**记入笔录**、双方＋审判人员＋书记员签名盖章**即生效**（§101）。同理：调解**维持**收养、**即时履行**（当场一手交钱一手交货）。⚠️ 反面：调解**离掉了**——财产要分、孩子要养，必须制作调解书。

**最后一问（要判决书行不行）**：乙公司说"调解书不好听，按协议给我们出份判决书吧"——国内案件**不予准许**（解释§148）；但如果乙是美国公司（涉外），**可以**依协议内容制作判决书（解释§528，题卡140/141的命题眼）。

#### 一句话闭环记忆

> 🎯 **一眼判**：调解书**"签收生效、最后签收日为准、不留置"**；反悔权**只属于未签收方**，签了就锁死；免书四情形**"和好·维持·即时·其他"**（记入笔录签名即生效）；**超诉请合法**；判决书替代**"国内不给、涉外给"**。

### 第三步：禁劝诀——非讼程序不调解，身份确认不能谈

> **特别督促公示催告不调解，身份确认不能谈，离婚财产照样调**

#### 概述

不是所有案件都能"劝和"。解释§143划出**不得调解**清单：

- **三类非讼程序**：适用**特别程序**（宣告失踪死亡、认定行为能力、选民资格等）、**督促程序**（支付令）、**公示催告程序**的案件——这些程序里**没有对立的双方在争权利**，无"和"可劝；
- **身份关系确认案件**：**婚姻等身份关系确认**案件（婚姻是否有效、收养关系是否成立、亲子关系是否存在）——身份关系的真假**由法律和事实决定，不能由当事人合意创设或处分**；
- **兜底**：其他根据案件性质不能进行调解的案件。

**两条对照边界**：①**离婚案件本身应当调解**（解释§145 II）——"要不要维持婚姻"是可处分的，"婚姻是否有效"不可处分；②离婚案中的**财产分割、子女抚养**属于常规可调事项。**一道防线**：当事人**恶意串通**，企图通过调解、和解方式**侵害他人合法权益**的，按§115虚假诉讼处理（解释§144）——罚款、拘留直至追究刑责，法院不但不准调，还要办人。

#### 大白话讲解

回到甲乙丙的案子——货款纠纷是典型的财产争议，**随便调**。但把案型换一圈，就能看出清单的边界：

- 乙公司老板失联两年，家属申请**宣告失踪**——这是特别程序，只有申请人没有"对方当事人"，跟谁调解去？**不得调解**；
- 甲公司拿着借条直接申请**支付令**（督促程序）——程序设计就是"快刀斩乱麻"，**不得调解**；
- 甲公司的支票丢了申请**公示催告**——同理，**不得调解**；
- 朱某起诉请求**确认与刘某的婚姻无效**（重婚）——婚姻有效无效是法律说了算的**身份关系确认**问题，不能"双方商量着算它有效"，**不得调解**；
- 但朱某起诉**离婚**——"离不离"恰恰**应当调解**（还记得第一步吗）；离婚案里**房子怎么分、孩子谁来养**，更是可以敞开谈。

**一句话分清**："身份关系**确认**"不能谈（真假不由人），"身份关系**解除**（离婚）＋财产后果"可以谈（去留由人）。

**防线剧情**：甲乙两公司其实是关联企业，串通虚构50万债务想借调解书转移财产躲避乙的其他债主——法院发现后**不准调解**，按**虚假诉讼**处理：驳回请求＋罚款拘留，构成犯罪的追究刑事责任（§115＋解释§144）。

| 案件类型 | 能否调解 | 条文 |
|---|---|---|
| 特别程序／督促程序／公示催告程序案件 | ❌ 不得调解 | 解释§143 |
| 婚姻等身份关系**确认**案件 | ❌ 不得调解 | 解释§143 |
| 离婚案件（离不离） | ✅ 应当调解（不久调） | 解释§145 II |
| 离婚案中财产分割、普通财产纠纷 | ✅ 可以调解 | §96 |
| 恶意串通借调解侵害他人权益 | ❌ 按虚假诉讼处理 | §115＋解释§144 |

#### 一句话闭环记忆

> 🎯 **一眼判**：**"非讼三程序（特别·督促·公示催告）＋身份确认"不得调解**；镜像陷阱两面防——"离婚案不得调解"错（应当调解），"婚姻效力确认也可以调解"也错（不得调解）；串通假调解＝虚假诉讼办你。

### 第四步：判决诀——三张脸出生，满期生效，写错补正

> **给付确认形成三张脸，一审满期二审终审，笔误裁定补正不再审**

#### 概述

调解不成，出口是判决。三问收官：

**判决长什么样（种类，学理分类·无条文号）**：
- **给付判决**：命被告为/不为一定行为（付款、腾房）——**可以强制执行**；
- **确认判决**：宣告法律关系存在与否（确认合同无效、确认亲子关系）——**无执行内容**；
- **形成判决**：直接改变法律关系（判决离婚、撤销合同）——**生效即变动，也无须执行**。
- 附：一部分事实已经清楚的，可就该部分**先行判决**（§156）。

**什么时候生效（§158＋§171＋§182）**：
- **一审判决**：上诉期＝判决书**送达之日起15日**（裁定10日，§171）；**超过上诉期没有上诉**的才生效（§158）；不能同时送达的，上诉期**各自计算**（解释§244），全案以最后届满者为生效时点；
- **二审判决、裁定＝终审**（§182），作出（宣告/送达）即生效；**依法不准上诉**的（如最高法院一审、小额诉讼一审终审、特别程序）作出即生效（§158）；
- 生效判决的**既判力**：当事人不得就同一诉再行起诉、法院不得作矛盾裁判（一事不再理的效力面，衔接[[民诉-一审-起诉与受理模型]]）。

**写错了怎么办（§157七项＋解释§245）**：判决书中的**笔误**——法律文书**误写、误算**，诉讼费用漏写、误算和其他笔误——用**裁定补正**；**调解书与调解协议不一致**同样是制作差错，**裁定补正**（不是再审、不是无效、不用另诉）。调解书的"再审"另有门槛：证明**调解违反自愿原则**或**协议内容违反法律**（§212）；**二审中达成调解**的，调解书**送达后原审判决视为撤销**（§179）。

#### 大白话讲解

设乙公司最终反悔、调解流产，法院**及时判决**："乙公司10日内支付甲公司货款50万元"——命令乙掏钱，这是**给付判决**，乙不掏可以申请强制执行。对照两张脸：如果判的是"确认甲乙之间的买卖合同无效"——只宣告状态，**确认判决**，没什么可执行；如果是朱某案判"准予朱某与刘某离婚"——判决一生效婚姻关系直接消灭，**形成判决**，不用"执行离婚"。

**掐生效表**：一审判决书**3月1日送达**乙公司、**3月3日才送达**甲公司——两家的15日上诉期**各自起算**（解释§244），乙的到3月16日、甲的到3月18日，**3月18日届满无人上诉**，判决才生效。命题人写"判决书送达后即发生法律效力，乙应立即付款"——**错**，上诉期内判决是"未生效裁判"。如果乙上诉、二审维持——**二审判决是终审判决**（§182），作出即生效，没有"再等15日"。如果二审期间双方又谈拢了签收了**二审调解书**——**原一审判决视为撤销**（§179），自动作废不用专门撤。

**写错字剧情**：生效文书把"50万元"误打成"5万元"，或把甲公司名字写错——这是**笔误**（误写误算，解释§245），法院**裁定补正**（§157一款七项）就完事。同理，甲发现**调解书**内容跟当初的调解协议对不上——**申请裁定补正**（题卡144），别答成申请再审（那要证明"违反自愿/内容违法"§212）、更别答"调解书无效、重新起诉"。

| 出口问题 | 答案 | 条文 |
|---|---|---|
| 判决三类 | 给付（可执行）／确认（宣告）／形成（生效即变动） | 学理·无条文号 |
| 一审判决生效 | 满上诉期（判决15日/裁定10日，各自计算）无人上诉 | §158＋§171＋解释§244 |
| 二审/不准上诉的裁判生效 | 终审，作出即生效 | §182、§158 |
| 笔误／调解书与协议不一致 | 裁定补正 | §157（七）＋解释§245 |
| 生效调解书翻盘 | 证明违反自愿/内容违法→再审 | §212 |
| 二审调解书送达 | 原审判决视为撤销 | §179 |

#### 一句话闭环记忆

> 🎯 **一眼判**：判决三张脸**"给付可执行、确认只宣告、形成即变动"**（学理不标条号）；生效口诀**"一审等十五、裁定等十、各自送达各自算；二审终审、不准上诉即生效"**；**"写错找补正（裁定），骗调找再审（自愿/合法），二审调解原判自动撤"**。

## 六、 易混提示

*   **签收生效 vs 送达生效**：
    *   *调解书*＝双方**签收**生效（§100，最后签收日，解释§149，不适用留置送达）；*二审调解书使原判视为撤销*的触发点是**送达后**（§179）；*一审判决*＝送达只是**起算上诉期**，满期未上诉才生效（§158/§171）。三个时点三套规则，不可互串。
*   **"送达前一方反悔" vs "已签收方反悔"**：
    *   §102 的反悔主体是**尚未签收的一方**；已签收方（尤其**当庭双方签收**后）受签收拘束不能反悔——见"签收次日反悔、主张代理人未签字"等说辞一律不认（题卡142/143）。
*   **调解和好的离婚（免调解书） vs 离婚不得调解 vs 身份确认不得调解**：
    *   *调解**和好***→关系维持，可**不制作调解书**（§101）；*离婚案本身*→**应当调解**（解释§145 II）；*婚姻等身份关系**确认***→**不得调解**（解释§143）。三句话各管一段，混搭即坑。
*   **补正裁定 vs 调解书再审**：
    *   *调解书与协议不一致/文书误写误算*→**裁定补正**（§157（七）＋解释§245）；*调解违反自愿原则或协议内容违法*→**申请再审**（§212）。差错走补正，瑕疵合意才走再审。
*   **法院调解书 vs 人民调解协议**：
    *   *法院调解书*签收后即是**执行依据**；*人民调解协议*只有合同效力，要么**司法确认后申请执行**（§205-206），要么一方不履行时**以对方当事人为被告起诉**（解释§61）——不能拿着人民调解协议直接申请强制执行。

## 七、 命题人最爱的 6 个陷阱

1.  **"调解书经送达双方当事人后即发生法律效力"** —— 错！调解书经双方**签收**后生效（§100），分别签收以**最后签收日**为生效日（解释§149）；拒签＝不生效，且**不适用留置送达**（解释§133）。
2.  **"当事人当庭签收调解书后，次日仍可反悔，法院应及时判决"** —— 错！反悔窗口只开给**未签收方**（§102"送达前一方反悔"）；双方当庭签收即生效，签收方受拘束不得反悔。
3.  **"调解协议约定的内容超出原告诉讼请求范围，不具有合法性"** —— 错！调解贯彻处分原则，**自愿＋内容不违法**即可（§96/§99），加利息、加担保等超诉请安排均有效——"判决不得超诉请"的规则不适用于调解。
4.  **"离婚案件涉及身份关系，法院不得调解"** —— 错！离婚案**应当调解**（只是不应久调不决，解释§145 II）；不得调解的是**特别/督促/公示催告程序案件与婚姻等身份关系确认案件**（解释§143）。反向陷阱"确认婚姻无效案件也可以调解"同样错。
5.  **"当事人达成调解协议后请求法院按协议内容制作判决书的，应予准许"** —— 错！国内案件**不予准许**（解释§148，唯无民事行为能力人离婚案件的法定代理人协议除外）；只有**涉外**案件当事人要求发判决书的**可以**依协议制作（解释§528）。
6.  **"调解书内容与调解协议不一致的，当事人可以申请再审／调解书无效"** —— 错！属制作差错，救济是**裁定补正**（§157一款（七）项参照＋解释§245）；再审事由限于**调解违反自愿原则或协议内容违法**（§212）。
（加赠第7枪：**"一审判决送达后即生效"**——错！满15日上诉期无人上诉才生效，且不能同时送达的**各自计算**；二审判决才是作出即生效的**终审**判决。）
