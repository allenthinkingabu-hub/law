# 📐 代位权 · 完整答题模型（代位保存权 + 直接受偿 + 仲裁条款不影响 + 专属除外）

> **核心一句**：代位权是债权人**以自己名义**代债务人向**相对人（次债务人）**主张权利的**保全**制度。考试核心在于**"四要件成立 → 专属排除 → 直接受偿 → 三类抗辩"**这条主线；最毒陷阱是**把"专属债权"和"专属人格权已到期的财产化收益"混为一谈**、**把"直接受偿"当成"入库"分配**、**用"仲裁条款/管辖协议"对抗代位权诉讼**、**把"诉讼时效中断"说成"中止"**。
>
> 🔎 **《民法典》核心条文速查**：
> - **第535条【债权人代位权】**：因债务人**怠于行使**其债权或者与该债权有关的**从权利**，影响债权人**到期债权**实现的，债权人可以向法院请求**以自己的名义代位行使**债务人对相对人的权利，但**该权利专属于债务人自身的除外**。代位权的行使范围**以债权人的到期债权为限**。
> - **第536条【债权人代位保存权】**：债权人的债权**到期前**，债务人的债权或者与该债权有关的从权利存在**诉讼时效期间即将届满**或者**未及时申报破产债权**等情形、影响债权人的债权实现的，债权人可以代位向债务人的相对人请求其**向债务人履行**、**向破产管理人申报**或者**作出其他必要的行为**。
> - **第537条【代位权行使后的法律效果·直接受偿】**：法院认定代位权成立的，由债务人的**相对人向债权人履行义务**，债权人**接受履行后**，债权人与债务人、债务人与相对人之间**相应的权利义务终止**。债务人对相对人的债权或者与该债权有关的从权利被**采取保全、执行措施**，或者债务人**破产的**，依照相关法律规定处理。
> - **《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号，2023年12月4日发布、12月5日施行）**：第34条明确**专属于债务人自身的权利清单**；第35条规定代位权诉讼的**管辖规则**（被告住所地法院管辖，专属管辖除外，管辖协议不能对抗代位权人）；第36条明确**仲裁协议不能对抗代位权诉讼**（但债务人/相对人在首次开庭前就该债权债务关系申请仲裁的，法院可以裁定中止）；第37条规定代位权诉讼**应当追加债务人为第三人**。

> ⚠️ **诚实标注（条号核验说明）**：本模型对§535-537（民法典本体）、通则解释§34（专属清单）、§35（管辖）、§36（仲裁）、§37（第三人地位）五条已通过多个独立网络信源交叉核实，内容一致、可信度高。**"怠于行使"的认定标准**（须以诉讼/仲裁方式主张，私下催讨不构成"行使"）确系通则解释配套规则，但本次核验各信源对其**具体条号**（多指向第33条前后）存在轻微出入，本模型不强行标注一个未完全统一确认的具体条号，只呈现规则本身（规则内容多源一致，可信）。**特别订正**：本库既往部分资料曾把"直接受偿"标注为"通则解释§37"，经本次核验，"直接受偿"的确切法源是**《民法典》第537条本身**，通则解释第37条实际内容是"**应当追加债务人为第三人**"，二者不可混同，本模型已按核验结果订正。

> ⚠️ **易记错点**：①**专属债权 ≠ 该专属权利产生的、已到期的财产性收益**——人身损害赔偿请求权本身专属不可代位，但**已届期的肖像许可费**这类人格权商业化后的确定金钱债权**可以**代位；②**§536代位保存权不要求债权到期**，这是与§535最大的区别，命题人爱把"债权未到期不能行使任何保全措施"当成绝对规则；③**"直接受偿"不是"入库"再按比例分配**，而是相对人直接向代位债权人履行，超出部分才归还债务人，这是2021年之后的新规则；④**仲裁条款/管辖协议只能约束债务人与相对人自己**，不能对抗代位权人这个"法定第三方"，但债务人/相对人在首次开庭前就该债权债务关系申请仲裁的，法院**可以裁定中止**（不是驳回）代位权诉讼；⑤**必要费用由债务人负担**，不是相对人或代位债权人自己承担；⑥**代位权诉讼引起的是诉讼时效"中断"，不是"中止"**，且是"双重中断"（债权人对债务人、债务人对相对人两条债权关系同时中断）。

## 二、 四要件判别模型（成立 → 排除 → 受偿 → 抗辩）

```
                【债权人甲对债务人乙有到期债权，乙对相对人丙享有权利】
                                    │
     ▼ 第一关：代位权成立四要件（§535）
     │
     ├─ 乙对丙有到期债权（或与该债权有关的从权利）
     ├─ 乙怠于行使（未以诉讼/仲裁方式向丙主张——私下催讨不算）
     ├─ 影响甲的到期债权实现
     └─ 该权利不专属于乙自身
                  │
     ▼ 若甲对乙的债权尚未到期，能否行使？
     │
     └─ 例外：§536代位保存权——乙对丙的债权存在诉讼时效即将届满/
        未及时申报破产债权等情形、影响甲的债权实现的，甲仍可代位
        请求丙向乙履行/申报/作出必要行为（不要求甲的债权已到期）
                  │
     ▼ 第二关：是否落入专属排除清单？（通则解释§34）
     │
     ├─ 身份关系（赡养/抚养/扶养/继承）──→ 专属，不可代位
     ├─ 人身损害赔偿（含精神损害赔偿）──→ 专属，不可代位
     ├─ 劳动报酬（超出必要生活费用部分除外）──→ 专属，不可代位
     ├─ 基本养老/失业保险、最低生活保障等基本生活保障权利 ──→ 专属，不可代位
     └─ 人格权已到期的财产化收益（如已届期的肖像许可费）──→ 已财产化，可以代位
                  │
     ▼ 第三关：代位权成立后怎么受偿？范围多大？（§535 II/III + §537）
     │
     ├─ 范围以债权人（甲）的到期债权为限（取小）
     ├─ 必要费用由债务人（乙）负担
     └─ 相对人（丙）直接向债权人（甲）履行，超出部分仍归乙；甲乙丙相应权利义务终止（不再"入库"分配）
                  │
     ▼ 第四关：相对人（丙）能提出哪些抗辩？管辖/仲裁条款能否对抗？
     │
     ├─ 对债务人（乙）的继受抗辩（已清偿/抵销/时效/同时履行）── 可以主张
     ├─ 质疑代位权成立要件的瑕疵抗辩（甲对乙的债权有瑕疵/未到期、丙不适格等）── 可以主张
     ├─ 专属债权/乙未怠于行使等针对代位成立本身的抗辩 ── 可以主张
     ├─ 替乙行使其积极权利/形成权（如替乙抵销、解除合同）── ❌ 不可以
     ├─ 乙丙间的管辖协议对抗甲的代位权诉讼 ── ❌ 不予支持（通则解释§35 II）
     └─ 乙丙间的仲裁条款对抗甲的代位权诉讼 ── ❌ 不予支持（通则解释§36），
        但乙/丙在首次开庭前就该债权债务申请仲裁的，法院可裁定中止代位权诉讼
```

> **一句话总诀**：**「四要件（到期+怠于+影响+非专属）成立代位权，未到期靠§536保存权兜底；专属清单挡人身/身份/劳动报酬/基本生活，已到期的人格权收益不挡；受偿看§537直接给债权人、不再入库，范围取小、费用债务人担；抗辩三类都能提，唯不能替债务人行权；管辖协议、仲裁条款都挡不住代位权人」**

## 三、 两个高频干扰（专属排除 vs 已财产化 / 直接受偿 vs 入库）

命题人极喜欢在"专属债权的边界"和"受偿方式"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **专属权利产生的钱也专属** | 债务人许可他人使用其肖像获得的许可费属于人格权范畴，专属于债务人自身，不可代位。 | **❌ 说法错误！已到期的财产化收益可以代位。**肖像权本身专属，但许可他人商业使用产生的、**已届期**的许可费是**确定的金钱债权**，已经从人格利益转化为财产利益，不再属于通则解释§34排除清单中的"专属"范畴。 |
| **代位权成立后债权先"入库"再分配** | 代位权诉讼胜诉后，相对人应先向债务人清偿，纳入债务人的责任财产，再由全体债权人按比例分配。 | **❌ 说法错误！2021年后是"直接受偿"，不是"入库"。**依§537，相对人**直接向代位债权人履行**，债权人接受履行后，三方相应权利义务**终止**，不再有"先入库再分配"这道环节。 |

## 四、 与撤销权的对照（保全双子星，勿混同法条号）

代位权（§535-537）与撤销权（§538-542）同属"保全"制度，命题人常混用条号：

| 事项 | 代位权 | 撤销权 |
|---|---|---|
| 行使对象 | 债务人**怠于行使**对相对人的**债权**（消极不作为） | 债务人**积极处分**财产的行为（如低价转让、放弃债权） |
| 是否要求债权到期 | 原则要求到期（§535），例外见§536代位保存权 | 不要求债权到期 |
| 行使方式 | 代位**行使权利**，以自己名义直接向相对人主张 | 请求法院**撤销**债务人的行为 |
| 必要费用 | 由**债务人**负担（§535 III） | 由**债务人**负担（§540，非§535 III） |
| 受偿方式 | **直接受偿**（§537） | 撤销后财产回归债务人责任财产，非直接归撤销权人 |

> ⚠️ **易混条号**：代位权必要费用是**§535 III**，撤销权必要费用是**§540**，不可互换；代位保存权是**§536**（债权未到期），不要与代位权成立后的受偿规则§537混淆。

## 五、 万能五步答题模型

在法考答题中（无论客观题选项判断，还是主观题第一步定性与第二步效力分析），按照以下五步进行涵摄：

*   🚗 **统一案例**：甲公司对乙公司享有10万元到期债权，乙公司对丙公司享有20万元到期债权（该债权有丙的房屋作抵押担保）。乙公司经营困难，仅每天发微信向丙催讨，从未提起诉讼或申请仲裁。甲公司诉请对丙公司行使代位权。

### 第一步：判成立要件——是否满足代位权四要件？

> **到期怠行影响，非专属才成立**

#### 概述

代位权不是"债权人看不惯就能代替出头"，而是四个要件**同时**齐备才成立的严格制度：

- 债务人**对相对人有到期债权**（或与该债权有关的从权利，如抵押权、保证债权）；

- 债务人**怠于行使**——法律上的"行使"特指**以诉讼或仲裁方式**向相对人主张，私下打电话、发微信、上门催讨**都不算**"行使"；

- 该"怠于行使"**影响**了债权人自己到期债权的实现（因果关系：债务人没钱还债权人，恰恰是因为他不去问相对人要钱）；

- 该权利**不专属**于债务人自身（专属清单见第三步）
	- 凡是法定专属于债务人本人的债权，债权人一律不能代位索要；只有纯财产类、不绑定人身生存的债权，才能代位。

四个要件像四把锁，缺一把都打不开代位权的门。


#### 大白话讲解

老王（甲公司）借给老李（乙公司）10万元，早就到期了，老王三天两头去要账，老李总说"没钱"。老王一打听才知道：老李手里其实捏着一张更大的牌——老张（丙公司）欠老李20万元货款，也早就到期了，而且这20万元还有老张的一套房子做抵押担保。

老王纳闷："老李，你不是没钱吗？你不会跟老张要那20万？"老李支支吾吾："唉，天天在微信里念叨老张，老张也不理我，我也就不多想了。"

老王一听就火了——**老李根本没去法院告老张，也没申请仲裁，只是嘴上念叨念叨**。这就是典型的"怠于行使"：

| 要素拆解                   | 本案对应                        | 是否满足     |
| ---------------------- | --------------------------- | -------- |
| 债务人对相对人有到期债权（或从权利）     | 老李对老张有20万到期债权 + 房屋抵押权（从权利）  | ✅        |
| 债务人怠于行使（须诉讼/仲裁，私下催讨不算） | 老李只在微信里念叨，从未起诉/仲裁           | ✅ 仍属怠于行使 |
| 影响债权人到期债权实现            | 老李没钱还老王的10万元，正是因为老张的20万没要回来 | ✅ 有因果关系  |
| 权利不专属于债务人自身            | 20万元货款+房屋抵押权都是普通经营性财产权利     | ✅ 不专属    |

四个条件都对上了号，老王**有权**以自己的名义，直接去法院起诉老张，代位行使老李对老张的20万元债权（及其抵押权）。

**特别提醒（从权利同样可以代位）**：老李对老张的抵押权本身不是独立债权，而是**"与债权有关的从权利"**——老王不仅可以代位主张那20万元本金，连**带着的抵押权**也可以一并代位行使，不需要另外单独证明抵押权本身"怠于行使"。

#### 一句话闭环记忆

> 🎯 **一眼判**：到期债权（含从权利）+ 怠于行使（诉讼/仲裁方式主张才算行使）+ 影响债权人实现 + 不专属——四要件缺一不可，私下催讨永远不构成"已行使"。

---

### 第二步：判是否需要§536代位保存权——甲的债权是否已到期？

> **未到期靠保存兜底，时效届满破产申报**

#### 概述

§535代位权原则上要求**债权人自己的债权也已到期**才能行使。但立法者担心：如果债权人的债权还没到期，就只能眼睁睁看着债务人的债权"烂在手里"（比如诉讼时效快过了、破产程序申报期快截止了却没人管），这不合理——于是§536专门开了一个**"抢救通道"**：即使债权人的债权**尚未到期**，只要债务人的债权（或从权利）存在**紧急灭失风险**（诉讼时效即将届满、未及时申报破产债权等），且影响债权人未来债权的实现，债权人也可以提前出手，代位做一些"**保存性**"的动作,属于保存行为（§536 代位保存权）（请求相对人向债务人履行、代为申报破产债权、或作出其他必要行为）。

- 次债务人破产、债务人躺平不申报，这笔债权直接作废，等于债务人少一笔可用来还债的财产，你的债权将来要不回来。代位申报就是保住这笔回款资格。

#### 大白话讲解

换一个场景：老王借给老李的10万元**要到明年6月才到期**，现在还没到期。老王听说老李对老张的20万元债权，诉讼时效**再过一个月就要过了**，老李却毫无动静（既不起诉，也不申请仲裁去中断时效）。

老王急了："我的10万元虽然还没到期，但你老李这债权要是过了时效变成'自然债务'，将来我到期了问谁要钱去？"

这种情况下，老王**不需要**等自己的债权到期，可以直接依据**§536代位保存权**，代位请求老张**向老李履行**（或者，如果老张已经进入破产程序，老王可以代位老李**向破产管理人申报债权**），从而阻止老李的债权因时效届满或破产程序申报期截止而"灭失"。

**两条路线，别选错**：

| 情形 | 债权人自己的债权是否已到期 | 适用条文 | 请求内容 |
|---|---|---|---|
| 本案原始设定（甲对乙10万已到期） | 已到期 | **§535** | 直接代位行使乙对丙的20万债权，可以请求丙直接向自己（甲）履行 |
| 变体情形（甲对乙10万未到期，但乙对丙的债权时效将届满/破产未及时申报） | 未到期 | **§536** | 只能代位请求丙**向乙**履行（或申报债权、作出其他必要行为），**不能**直接请求丙向自己履行——这是"保存"，不是"受偿" |

**关键提醒**：§536只是"保住债务人的责任财产不缩水"，效果是让相对人**向债务人**履行或申报，**不产生§537那种"直接受偿"效果**——毕竟债权人自己的债权都还没到期，谈不上"受偿"这一步。

回到本案：老王对老李的10万元债权**已经到期**，四要件也齐备，**直接依§535行使代位权即可**，不需要、也不能援引§536（§536是留给"未到期却情况紧急"的场景用的）。

#### 一句话闭环记忆

> 🎯 **一眼判**：债权已到期 → 走§535，可直接受偿；债权未到期但债务人的权利面临时效届满/破产申报截止等紧急情形 → 走§536代位保存权，只能让相对人向债务人履行/申报，不能跳过"到期"直接向自己受偿。

---

### 第三步：判专属排除——该权利是否落入专属清单？

> **身份人身劳动生活保障不代位，已到期的人格收益能代位**

#### 概述

代位权打的是债务人"该拿的钱不去拿"，但有一类权利，法律**无论如何都不允许**债权人插手——凡是**跟人身、身份、基本生存尊严紧密绑定**的权利，一律排除在代位权之外。通则解释§34划出了四条红线：

1. **身份关系**——赡养费、抚养费、扶养费、继承请求权；
2. **人身损害赔偿**——含精神损害赔偿；
3. **劳动报酬**——但**超出必要生活费用部分除外**（超出部分仍可代位）；
4. **基本生活保障权利**——基本养老保险金、失业保险金、最低生活保障等。

这四条线的共同逻辑是："这笔钱是用来**活命、尽义务、抚慰创伤**的，不能被债权人拿去抵债。"

但有一个边界要特别小心：**专属的是"权利本身"，不是"权利变现后的钱"**——一旦人格权已经**商业化、已经到期确定**成为一笔明确的金钱债权（比如已经到期该收的肖像许可费、稿酬），这笔"已经赚到手"的钱，**不再受专属保护**，照样可以被代位。

#### 大白话讲解

老王想代位老李的四笔"债权"，法院逐一给他划红线：

- **老李对儿子的赡养费请求权（10万元）**——这是**身份关系**产生的权利，专门用来保障老李的晚年生活，**不可代位**。老王不能替老李去问儿子要赡养费。
- **老李被撞伤后对肇事者的50万元人身损害赔偿（含精神损害抚慰金）**——这是**人身损害赔偿**，是用来治伤、抚慰老李身心创伤的钱，**不可代位**。
- **老李单位欠发的8万元基本工资**——这是**劳动报酬**，是老李吃饭穿衣的基本生活费用，**不可代位**（如果这8万元里有明显超出必要生活费用的部分，比如是一笔天价年终奖，超出部分理论上可以代位，但普通工资通常整体视为生活保障）。
- **老李领取的养老金、失业金**——这是**基本生活保障权利**，**不可代位**。

但是——老王又发现老李还有**第五笔钱**：老李把自己的肖像许可给某广告公司使用，约定的10万元许可费**已经到期该付了**。这笔钱专属吗？

法院说：**不专属，可以代位。** 逻辑是这样的——肖像权本身（作为一种人格权）当然是专属的，谁也不能替老李"决定要不要授权自己的脸拍广告"；但一旦**授权已经完成、许可费已经到期变成一笔确定的金钱债务**，这笔钱的性质就从"人格利益"转化成了"财产利益"——就像老李把自己的一项才能变现赚到的工资（超出生活必需部分）一样，**已经是钱了，不再是"脸"本身**，自然可以被代位。

**四类专属 + 一条"已财产化"的例外，列成表方便记**：

| 类型                      | 是否可代位  | 理由               |
| ----------------------- | ------ | ---------------- |
| 赡养费/抚养费/扶养费/继承请求权（身份关系） | ❌ 不可代位 | 身份专属             |
| 人身损害赔偿（含精神损害赔偿）         | ❌ 不可代位 | 抚慰人身创伤           |
| 劳动报酬（必要生活费用部分）          | ❌ 不可代位 | 基本生存保障           |
| 劳动报酬（超出必要生活费用部分）        | ✅ 可以代位 | 超出保障范围即"财产化"     |
| 基本养老/失业保险、最低生活保障        | ❌ 不可代位 | 基本生活保障           |
| 人格权已到期的财产化收益（肖像许可费、稿酬等） | ✅ 可以代位 | 已从人格利益转化为确定的金钱债权 |

回到本案：老李对老张的20万元债权是**普通经营性货款**，不涉及身份、人身、劳动报酬或基本生活保障中的任何一条，**不落入专属清单**，老王**可以**代位。

#### 一句话闭环记忆

> 🎯 **一眼判**：身份关系、人身损害赔偿、劳动报酬（生活费用部分）、基本生活保障——四类专属挡代位；但**已到期的人格权财产化收益**（如已届期的肖像许可费）已经"变现"，不再挡代位。

### 第四步：判范围与受偿——代位多少？怎么受偿？

> **范围取小费用债担，直接受偿告别入库**

#### 概述

代位权成立后，紧接着要回答三个问题：**代位多大范围？谁出律师费等必要开支？钱最终怎么到债权人手里？**

- **范围**：以债权人**自己的到期债权数额**为限，哪怕债务人对相对人的债权数额更大，也**只能取小**——代位权是"保全"手段，不是让债权人借机额外获利的工具。

- **必要费用**：
	- 债权人为行使代位权支出的诉讼费、差旅费、律师费等必要费用，由**债务人**负担——毕竟债务人才是"惹麻烦"的那个。

- **受偿方式**：
	- 2021年以后的规则是相对人**直接向债权人履行**，不再像过去的旧规则那样"先归入债务人的责任财产（入库），再由全体债权人按比例分配"。

#### 大白话讲解

法院最终认定老王的代位权成立。这时候一连串问题冒出来：老王能问老张要多少钱？打官司花的律师费谁掏？老张的钱是直接给老王，还是要先"过一道手"？

**先算范围**：老王对老李的债权是**10万元**，老李对老张的债权是**20万元**——两个数字不一样大，代位权只能按**较小的那个数**走，也就是**10万元**为限。哪怕老张欠老李的钱再多，老王也不能"顺手"多要，代位权解决的是"老王自己的10万元怎么受偿"，不是"帮老李把20万元全要回来"。

**再算费用**：老王打这场代位权官司，请律师花了8000元。这笔钱该谁出？答案是——**老李（债务人）**。逻辑很朴素：要不是老李自己怠于行使权利，老王根本用不着自己掏钱去起诉老张，这笔"额外支出"是老李的懒惰造成的，自然该老李买单。

**最后看受偿方式（本考点的重头戏）**：法院判决代位权成立后，**老张不是把20万元还给老李**，而是**直接把10万元付给老王**（以老王的10万元债权为限）；老王收到这10万元后，**老王和老李之间**关于这10万元的债权债务关系**终止**，**老李和老张之间**对应部分的债权债务关系也**终止**。至于剩下的10万元（20万-10万），老张仍然要**照常还给老李**——因为超出老王代位范围的部分，本来就跟这场代位权诉讼无关。

> ⚠️ **告别"入库"的历史包袱**：在旧的司法解释体系下，曾经有过"相对人应先把钱还给债务人、纳入债务人的责任财产、再由全体债权人按比例分配"这套"入库规则"——**2021年以后，这套规则被彻底改掉**，现在是老张**直接**把该给老王的那部分钱**付给老王本人**，不再经过老李这道"中转站"，也不用管老李手里还有没有其他债权人排队分钱。这是"直接受偿"制度设计的核心突破，命题人极爱在这里设"入库"陷阱句。

#### 一句话闭环记忆

> 🎯 **一眼判**：代位范围以**债权人自己的到期债权**为限（取小，不是取大）；必要费用**债务人**掏；相对人**直接**向债权人履行、超出部分仍还给债务人——**不再"入库"**统一分配。

---

### 第五步：判抗辩与程序限制——丙能提出哪些抗辩？管辖仲裁条款有用吗？

> **三类抗辩皆可提，管辖仲裁挡不住**

#### 概述

代位权诉讼中，被告是相对人（次债务人），他当然不会束手就擒。法律允许他提出**三类抗辩**，但**堵死**了两条常见的"投机取巧"路线：

- **可以主张**：
	- ①对债务人本来就有的抗辩（继受抗辩，如已清偿、抵销、时效届满、同时履行抗辩）；

	- ②质疑代位权本身成立要件的瑕疵抗辩（比如"债权人对债务人的债权根本不存在/没到期"，或者"我压根不是合法的相对人"）；
	
	- ③专属债权、债务人并未怠于行使等针对代位权成立本身的抗辩。

- **不能主张**：
	- 替债务人去**行使**他自己的积极权利或形成权（比如替债务人主张抵销、替债务人解除合同）——这是"代为决策"，不是"抗辩"，法律不允许。

- **管辖协议、仲裁条款**：
	- 这些都是债务人和相对人之间私下的约定，**约束不了**基于法律直接取得诉权的代位权人；但如果债务人或相对人真的在首次开庭前就这层债权债务关系去申请仲裁了，法院可以裁定**中止**（不是驳回）代位权诉讼，等仲裁结果出来再说。

#### 大白话讲解

老张不服，请了律师琢磨怎么抗辩。律师给他支了几招，但每一招都要先看合不合法：

**招数一（继受抗辩，合法）**："我上个月已经还了老李5万元，这笔钱应该先抵扣！"——这是老张**对老李本来就有的抗辩**（已部分清偿），**可以**向老王主张，直接影响老王能拿到的金额。

**招数二（瑕疵抗辩，合法）**："老王你说老李欠你10万，可我压根没见过你们之间的借条，你俩这10万债权是不是假的？"——这是在**质疑代位权成立要件**（老王对老李的债权是否真实存在），**可以**主张，一旦坐实，整个代位权诉讼的地基就塌了。

**招数三（针对代位成立本身，合法）**："老李根本没怠于行使，他上周还专门写信催我了！"——如果老张能证明老李其实**已经**以合法方式（比如仲裁）主张过权利，那"怠于行使"这个要件就不成立，**可以**据此抗辩，整个代位权直接不成立。

**招数四（企图行使老李的权利，不合法）**："老李欠我一笔加工费还没结，我要替老李把这笔钱和欠款抵销掉！"——律师立刻摇头："不行，**抵销是老李自己的权利**，你没有资格替老李去'行使'这项权利，你只能拿'已经发生的事实'来抗辩，不能自己去'创造'一个新的法律效果替老李决策。"这一招**不能**用。

**招数五（拿管辖协议/仲裁条款挡）**："我和老李之间的合同里写了，有纠纷去仲裁委解决，你老王凭什么直接在法院告我？"——律师叹气："这条也挡不住。管辖协议、仲裁条款只是**你和老李两个人之间**的私下约定，老王的代位权是**法律直接赋予**的诉权，不受你们俩的约定约束，法院照样受理并审理。**除非**你或老李真的赶在**第一次开庭前**就这笔20万元的债权债务关系向仲裁委**申请了仲裁**，法院才会考虑裁定**中止**代位权诉讼、等仲裁结果——但这只是'先等等'，不是'驳回'，更不是'仲裁条款生效、代位权诉讼作废'。"

最后，法院还提醒一句：**这场官司里，老李（债务人）必须被列为第三人**——如果老王起诉时漏掉了老李，法院**应当依职权追加**老李进来，让三方的法律关系在一个诉讼里说清楚。

顺带一提**诉讼时效**：老王一旦提起代位权诉讼，**老王对老李的10万元债权、老李对老张的20万元债权**，这**两条**诉讼时效**同时中断**、重新起算——注意用词是"**中断**"，不是"中止"："中断"是已经走过的时效清零重来，"中止"是暂停计时、原地等待，两者性质完全不同，命题人极爱在这里偷换概念。

#### 一句话闭环记忆

> 🎯 **一眼判**：相对人能提**对债务人的继受抗辩** + **质疑代位权要件的瑕疵抗辩** + **专属/未怠于行使的成立抗辩**，唯**不能替债务人行使其积极权利/形成权**；**管辖协议、仲裁条款均挡不住**代位权人（除非债务人/相对人在首次开庭前就该债权债务关系申请仲裁，法院可裁定中止）；诉讼引起**双重诉讼时效中断**（非中止）；债务人**应当被追加为第三人**。

## 六、 易混提示

*   **代位权 vs 撤销权**：
    *   *代位权*针对债务人**消极怠于行使**权利的不作为；*撤销权*针对债务人**积极处分财产**的作为。二者必要费用条款不同（§535 III vs §540），勿混用。
*   **专属债权 vs 已到期的人格权财产化收益**：
    *   *专属债权本身*（如人身损害赔偿请求权）不可代位；*该专属权利已产生并到期的金钱收益*（如已届期的肖像许可费）可以代位。
*   **诉讼时效"中断" vs "中止"**：
    *   代位权诉讼引起的是**中断**（已经过的时效期间归零重算），不是**中止**（暂停计算、期满后继续）。

## 七、 命题人最爱的 5 个陷阱

1.  **"人身损害赔偿等专属权利产生的钱也一律不能代位"** —— 错！已到期的人格权财产化收益（如已届期的肖像许可费）可以代位，专属的是权利本身，不是已经变现的确定收益。
2.  **"债权未到期，债权人对债务人的任何权利都不能采取保全措施"** —— 错！§536代位保存权允许在债权到期前、存在诉讼时效届满/未及时申报破产债权等紧急情形时提前代位。
3.  **"代位权成立后，相对人应先清偿给债务人，纳入责任财产统一分配（入库）"** —— 错！依§537，相对人**直接向代位债权人履行**，不再"入库"。
4.  **"债务人与相对人之间订有仲裁条款/管辖协议，可以对抗代位权人的诉讼"** —— 错！仲裁条款、管辖协议只约束签字双方，不能对抗基于法律规定取得诉权的代位权人（通则解释§35/§36）。
5.  **"代位权诉讼导致相关债权诉讼时效中止"** —— 错！是诉讼时效**中断**（双重中断：债权人对债务人、债务人对相对人），不是中止。
