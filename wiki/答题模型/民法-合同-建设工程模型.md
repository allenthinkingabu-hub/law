# 📐 建设工程合同 · 答题模型（定性 → 效力 → 折价/赔偿 → 优先受偿权 → 实际施工人）

> 建设工程合同是 [[承揽合同]] 的**特殊类型**（§808 未规定的适用承揽），但客观题陷阱高度集中在**专门司法解释**里——按"**定性 → 效力 → 无效后果 → 工程价款优先受偿权 → 实际施工人**"五步走。
> **姊妹 / 概念** → [[建设工程合同]] · [[承揽合同]]（[[民法-合同-委托行纪中介模型]] 旁系：任意解除权对照）· [[民法-合同-无效撤销返还模型]]（无效合同折价/返还的通则母法）· [[民法-物权-担保物权模型]]（优先权 vs 抵押权顺位）· [[物权编]]。
> **适用真题**：[[典型合同-单选-28|单选-28·冶炼炉定性]] · [[典型合同-单选-29|单选-29·挂靠施工]] · [[典型合同-多选-28|多选-28·无资质效力]] · [[典型合同-单选-30|单选-30·实际施工人讨薪]] · [[典型合同-单选-31|单选-31·优先受偿权全景]]。
>
> 🔎 **法条已联网核实（2026-06-14，3 路独立源对抗交叉，全 CONFIRMED·HIGH）**：
> - **民法典**（国家法律法规数据库 / 政府门户全文 ×2-3 源）：§770 承揽定义 · §788 建设工程定义（勘察/设计/施工）· §789 书面 · **§793 无效合同折价补偿** · **§807 工程价款优先受偿权** · §808 未规定的适用承揽。
> - **建工解释一**（法释〔2020〕25 号，[最高法官网](https://www.court.gov.cn/zixun/xiangqing/282111.html) 逐字核）：**§1 无效三情形**（无资质/挂靠借用资质/必须招标未招标）· **§2 验收合格→折价补偿** · **§3 验收不合格→修复费/赔偿** · **§35 优先权主体=直接承包人** · **§36 优先权优于抵押权** · **§40 优先权范围**（不含利息/违约金/损害赔偿）· **§41 优先权期限**（合理期限**最长 18 个月**，自**发包人应当给付价款之日**起算）· **§43 实际施工人**（**应当**追加转包/违法分包人为**第三人**，发包人欠付范围内担责）。
> - **商品房消费者批复**（法释〔2023〕1 号，court.gov.cn ×3 源）：**§2 消费者（居住+全款）房屋交付请求权优先**于工程价款优先权、抵押权及其他债权（"**超级优先权**"）。
>
> ⚠️ **两个法考头号新旧法陷阱（必考·既有真题卡曾踩中）**：
> ① **优先权期限**：「**6 个月 + 竣工之日**」= 已废止的法释〔2002〕16 号旧规则；现行 §41 = 「**最长 18 个月 + 应当给付价款之日**」。
> ② **实际施工人追加**：「**可以 + 当事人**」= 已废止的建工解释二（法释〔2004〕14 号§26）；现行 §43 = 「**应当 + 第三人**」。
> ⚠️ **易记错条号**：折价补偿是 **§2**、不合格赔偿是 **§3**（**不是 §6**——§6 是黑白合同结算）；优先权**范围是 §40**、**期限是 §41**（**§37 其实是装饰装修工程优先权**，别记成范围条）。

## 一、核心考情

- **频率**：[[建设工程合同]] 整章 **★★★**（机构未把整章单列加星，多作分则普通条目）；但**工程价款优先受偿权**子专题 **★★★★**——建工解释一专门制度 + **法释〔2023〕1 号（2023 最新·距 2026 考期最近的分则信号）** + 高度跨 [[物权编]]（担保顺位）/ 民诉（实际施工人诉讼地位）。
- **命题核心**：专挑 **2020/2023 新旧法反转**（期限 18 个月/应付款日、实际施工人"应当追加第三人"、消费者超级优先）设陷阱，再叠加**条号易混**（§2/§3、§40/§41）+ **跨章顺位**（消费者 > 工程价款 > 抵押权 > 普通债）。
- **五大必考点**：①**定性**（承揽 vs 建设工程）②**无效三情形**（无资质/挂靠/未招标）③**无效后果**（合格折价补偿 / 不合格赔偿）④**工程价款优先受偿权**（主体/顺位/范围/期限/超级优先）⑤**实际施工人**请求权（突破合同相对性）。

## 二、万能五步模型

### 第一步：是不是建设工程合同？（定性 §788 vs §770/§595/技术服务）

> 🔑 **一句话判断**：标的物是**钉在土地上的不动产建设**（建筑物/构筑物）→ **建设工程合同**；标的物是**造出来交付的动产 / 工作成果**（哪怕是巨型设备）→ **承揽合同**；交付**现成商品**、无定制制造义务 → **买卖合同**。

**铁则**：
- **建设工程合同（§788）**：承包人**进行工程建设**（在土地上建房屋、道路、桥梁、水坝、管道等**不动产**），发包人付款；含**勘察 / 设计 / 施工**三类。
- **承揽合同（§770）**：承揽人按定作人要求**完成工作、交付工作成果**（加工、定作、修理、复制、测试、检验）。**标的是动产 / 专属定制品**。
- **判断标准 = 标的是否"不动产建设"，绝不看体积大小**：再大的工业设备（冶炼炉、锅炉、机床、船舶）也是**承揽**，不是建设工程。
- **附随义务不改变主性质**：安装 + 调试 + 培训附随于主给付，按**主要义务**定性（§808 建设工程未规定的适用承揽，二者本就同源）。

**老王小李例子**
- 老王（甲）要小李（乙）按图纸**造一台 20 米高的冶炼炉**、运到指定地点安装、再调试 + 培训 → 标的是**工业设备（动产）**，体积虽大仍是**承揽（定作，§770）**；不因"安装/调试/培训"变成建设工程或技术服务。
- 若老王要小李**在自家地块上盖一栋办公楼** → 标的是**不动产建设** → **建设工程合同（§788）**。

### 第二步：合同有没有效？（§1 三种无效 + 挂靠"对外合同"看发包人善意）

> 🔑 **一句话**：先用 §1 三把尺子量有没有无效事由（**资质 / 挂靠 / 招标**）；其中"**挂靠**"最容易乱，必须**拆成两份合同**分别看——内部挂靠协议**必无效**，对外施工合同**看发包人善意**。

**① §1 三种无效情形**（违反民法典 §153 Ⅰ 强制性规定 → 合同无效）

| 情形 | 内容 | 条号 |
|---|---|---|
| 无资质 | 承包人未取得资质 / 超越资质等级 | §1(一) |
| 挂靠 | 无资质者借用有资质企业名义 | §1(二) |
| 招标 | 必须招标而未招标 / 中标无效 | §1(三) |

> 转包、违法分包签订的施工合同同样无效。

**② 挂靠"拆两份合同"看**（核心 · 最易混）

| 合同         | 谁和谁           | 效力                                                                    |
| ---------- | ------------- | --------------------------------------------------------------------- |
| **内部挂靠协议** | 无资质方借名 + 交管理费 | **永远无效**（§1(二) 违法借资质）                                                 |
| **对外施工合同** | 有资质方名义 ↔ 发包人  | **看发包人善意**：不知挂靠（善意）→ **有效**（类推表见代理 §172，认有资质方为承包人）；明知 → **无效**（§1(二)） |

> **三句话定调**：
> 1. "**对外合同有效 ≠ 挂靠有效**"——两份不同合同，挂靠协议**永远无效**。
> 2. 对外合同**有效**时：有资质方 = **承包人**，借名人**退为"实际施工人"**（只干活、非合同当事人）。
> 3. 全程都**不是"效力待定"**（效力待定专指限制行为能力 / 无权代理 / 无权处分，别混）。
>
> 📍 真题 [[典型合同-单选-29]]：发包人乙**不知情（善意）**→ 对外施工合同**有效**、挂靠协议无效、施工队（实际施工人）向被挂靠方主张折价补偿。

**③ 完工不治愈**：工程完工 / 封顶 / 竣工 **≠ 合同有效**——效力只看**资质 / 招标**；完工只决定**第三步怎么拿钱**（折价 or 赔偿）。

**老王小李例子**（一例讲透）
- 无资质的老张借有资质小李的名义、投老王（发包人）的标、交管理费：
  - **挂靠协议（老张 ↔ 小李）必无效**（§1(二)）；
  - **对外合同（小李名义 ↔ 老王）**：老王**不知**（善意）→ **有效**（小李 = 承包人，老张退为实际施工人）；老王**明知** → **无效**（老张是实际承接方但无资质）。
- 老张干完活怎么拿折价补偿 → **见第三步**（分"找老王"还是"找小李"）。

### 第三步：合同无效，工程款怎么办？（§793 + 解释 §2 合格→折价补偿 / §3 不合格→修复·赔偿）

> 🔑 **记忆锚：「合格补，不合格赔」**——质量是分水岭。

**铁则**：
- **民法典 §793 是总基础**（建设工程无效但**验收合格→参照合同折价补偿**；**不合格→修复 / 赔偿**）；建工解释一 §2 / §3 是其细化，别只记司法解释。
- **§2 验收合格**：合同虽无效，但建设工程**经竣工验收合格** → 承包人请求**参照合同关于工程价款的约定折价补偿**的，法院支持（干得好、质量过关，照样给钱）。
- **§3 验收不合格**，分两种：
  - **修复后验收合格** → 发包人请求承包人**承担修复费用**，支持；
  - **修复后仍不合格** → 承包人请求支付工程价款**不予支持**（且发包人可在工程合理使用寿命内主张承包人民事责任）。
- ⚠️ **条号**：折价补偿 = **§2**、不合格处理 = **§3**（**不是 §6**）。

**无效合同"效力 + 救济"双轨全景**

| 情形                      | 合同效力   | 救济方式                  | 条号    |
| ----------------------- | ------ | --------------------- | ----- |
| 无资质 / 挂靠 / 未招标          | **无效** | —                     | §1    |
| 无效 + 验收**合格**           | 无效     | 承包人→发包人：**参照合同价折价补偿** | §2    |
| 无效 + 验收**不合格** + 可修复合格  | 无效     | 发包人→承包人：**支付修复费用**    | §3(一) |
| 无效 + 验收**不合格** + 修复仍不合格 | 无效     | 承包人**无权**请求工程款        | §3(二) |

**老王小李例子 + 挂靠施工队到底找谁要钱**
- 老张施工队（无资质·挂靠）盖的楼**验收合格** → 挂靠协议虽无效，老张**不会白干**；但"找谁要折价补偿"取决于**对外合同效力**（即第二步老王是否善意）：

| 对外合同（小李 ↔ 老王） | 老张找谁要折价补偿 | 依据 |
|---|---|---|
| 老王**明知** → 对外合同**无效** | 直接找**发包人老王**（欠付工程款范围内担责）| 明知 + 验收合格 → 折价补偿（§793，§43 不适用挂靠）|
| 老王**善意** → 对外合同**有效** | 找**被挂靠的小李**（小李已从老王收 / 应收工程款）、参照合同价 | **挂靠协议无效** + 验收合格 → 折价补偿（[[典型合同-单选-29]] C）|

> ⚠️ **挂靠协议永远无效**，但**只要验收合格，老张都拿得到折价补偿**（区别只是找老王还是找小李）；**验收不合格 → 都拿不到**（§793 / §3），老王还能就质量损失追责。

### 第四步：工程价款优先受偿权（§807 + 解释 §35/§36/§40/§41 + 法释〔2023〕1 号）

> 🔑 **五要素一把抓：谁有（主体）· 排第几（顺位）· 保多少（范围）· 多久内行使（期限）· 谁能压它一头（超级优先权）。**
> 📖 **概念详解** → [[工程款优先受偿权]]（独立概念页 · 含顺位图 / 新旧法陷阱 / 与抵押权·留置权·实际施工人区别）

**铁则**：
- **性质（§807）**：发包人逾期不付价款，承包人催告合理期限仍不付的，除工程性质不宜折价/拍卖外，可协议折价或**请求人民法院依法拍卖**，就该工程折价/拍卖款**优先受偿**——法定优先权。
- **主体（§35）**：**仅与发包人直接订立施工合同的承包人**享有；**实际施工人 / 分包人不享有**优先受偿权。⚠️ 别和第五步实际施工人的 §43 请求权混为一谈。
- **顺位（§36）**：工程价款优先受偿权 **优于抵押权和其他债权**——**即便抵押权已先登记**，仍排在工程价款之后。
- **超级优先权（法释〔2023〕1 号 §2）**：**商品房消费者**（**以居住为目的 + 已付全部价款**）的**房屋交付请求权**，**优先于**工程价款优先权、抵押权及其他债权；只付部分价款者，在**一审法庭辩论终结前付清剩款**亦可适用。房屋不能交付时，**价款返还请求权**同样优先（§3）。学界称"**超级优先权**"。
- **范围（§40）**：依国务院主管部门关于工程价款范围的规定确定（人工、材料、机械等实际支出）；**逾期付款的利息、违约金、损害赔偿金不在优先受偿范围**（这部分只能作普通债权）。
- **期限（§41）** 🪤：承包人应当在**合理期限内**行使，但**最长不得超过 18 个月，自发包人应当给付建设工程价款之日起算**。

**完整优先顺位图**

```
商品房消费者（居住目的 + 已付全部价款）  ← 法释〔2023〕1 号 §2「超级优先权」
         ↓ 优先
工程价款优先受偿权（§807 / 解释§35-§41）
         ↓ 优先
已登记抵押权（哪怕登记在先）            ← 解释§36
         ↓ 优先
普通债权（含逾期利息 / 违约金 / 损害赔偿）  ← §40 把这些挡在优先权范围外
```

**🪤 优先权期限·新旧法时间轴（最爱考）**

```
旧·法释〔2002〕16号（已废止）  ：6 个月，自「竣工之日 / 约定竣工日」起算
过渡·建工解释二〔2018〕20号§22 ：6 个月，起算点已改为「应当给付价款之日」（已被吸收）
现行·建工解释一§41           ：合理期限「最长 18 个月」，自「发包人应当给付价款之日」起算
                              └ 题目出现「6 个月」或「竣工之日起算」→ 一律是错误项（旧法）
```

**老王小李例子**
- 小李公司（乙，直接与发包人老王签约的承包人）才有优先权（§35）；老张施工队（实际施工人）**没有**优先权。
- 老王把在建写字楼抵押给银行**并已登记**，可小李的工程价款优先权**仍优先于银行抵押权**（§36）。
- 但若业主老周**以居住为目的买下其中一套、已付全款**，老周的房屋交付请求权**压过**小李的工程价款优先权（法释〔2023〕1 号 §2「超级优先权」）。
- 小李能优先受偿的只有**工程价款本身**；老王拖欠造成的**逾期利息、违约金**小李只能作普通债权要（§40）。
- 小李必须在**应当给付价款之日起 18 个月内（合理期限）**行使优先权（§41）——**不是"竣工之日起 6 个月"**。

### 第五步：实际施工人——突破合同相对性向发包人主张（§43）

> 🔑 **一句话**：层层转包/违法分包，最末端实际干活的人（农民工施工队）和发包人没合同，但 §43 让他**可以直接告发包人**——这是合同相对性的**法定例外**。

**铁则**：
- **背景**：非法转包 / 违法分包链条中，**实际施工人**与发包人**无直接合同关系**。
- **§43 突破相对性**：
  - 实际施工人以转包人 / 违法分包人为被告起诉的，法院**应当受理**；
  - 实际施工人以**发包人为被告**主张权利的，法院**应当追加**转包人 / 违法分包人为**本案第三人**，查明发包人**欠付**转包人 / 违法分包人工程价款数额后，判决**发包人在欠付建设工程价款范围内**对实际施工人承担责任。
- **三个要点**：① 可以**告发包人**（突破相对性）；② 发包人责任**以其欠付的工程款为限**（**不是无限连带**——甲欠乙多少，最多担多少）；③ 追加转包/分包人为**第三人**（不是当事人），且现行法是"**应当**追加"。
- 🪤 **新旧法**：旧·建工解释二（法释〔2004〕14 号§26）="**可以**追加…为本案**当事人**"；现行 §43 ="**应当**追加…为本案**第三人**"。题目出现"可以 / 当事人"是**旧法**。
- 📖 **"第三人"≠"当事人"（民诉法 §59，旧法 §56）**：
  - **当事人** = 原告 + 被告（争议核心，判决直接定其权利义务）——§43 里 **实际施工人 = 原告、发包人 = 被告**。
  - **第三人** = 加入他人诉讼的利害关系人；转包 / 违法分包人被追加为**无独立请求权第三人**，作用是**查清"发包人欠付转包人多少"**（发包人责任以此为限）、**不是被告**；无独三**只有被判担责时**才取得当事人诉讼权利（含上诉权）。
  - → 现行"追加为**第三人**"比旧法"追加为**当事人**（共同被告）"定位更准（实际施工人与发包人本无合同，列共同被告法理别扭）。
- ⚠️ **实际施工人 ≠ 优先受偿权人**：实际施工人有 §43 请求权，但**不享有** §35 工程价款优先受偿权（优先权主体限直接承包人）。两条路别混。
- ⚠️ **§43 范围被最高法限缩（民一庭 2022-01-07）**：能用 §43 突破相对性告发包人的实际施工人，**只含"转包""违法分包"两种**；**借用资质（挂靠）、多层转包、多层违法分包均不在内**。
- **挂靠实际施工人怎么保权益**（呼应第二步"明知→无效"）：不能用 §43，但走**折价补偿**路径——**工程验收合格** + 发包人**明知**借用资质 → 可**参照合同价款直接向发包人主张折价补偿**（民法典 §793 / 建工解释一 §2），发包人在欠付工程款范围内担责；**验收不合格则拿不到**（§793 / §3）。即"都无效"≠白干，**验收合格是拿钱分水岭**。

**老王小李例子**
- 老王（发包人）→ 小李公司（乙，总包）→ 老张公司（丙，非法转包）→ 农民工施工队（实际施工人）。丙欠施工队 500 万、乙欠丙 800 万、甲欠乙 1000 万。
- 施工队可**直接告发包人老王**（§43）；法院**应当追加**乙、丙为**第三人**；查明老王欠乙的数额后，判老王**在欠付范围内**对施工队担责（最多 1000 万，若甲只欠乙 200 万则只在 200 万内）。
- 但施工队**不能**主张工程价款优先受偿权（那是小李公司 §35 的权利）。

## 三、命题人最爱的 8 个陷阱

1. **体积大 = 建设工程** —— 错！判断看**标的是否不动产建设**，巨型设备（冶炼炉）仍是**承揽**（§788/§770）。
2. **工程完工 / 竣工 → 合同有效（治愈无效）** —— 错！效力只看**资质 / 招标**（§1），完工只影响救济方式。
3. **挂靠 → 对外合同也无效 / 效力待定** —— 不准确！**内部挂靠协议必无效**（§1(二)）；**对外合同看发包人善意**（善意→有效·类推表见代理 §172；明知→无效·§1(二)）；二者都**不是效力待定**。
4. **折价补偿 / 赔偿记成 §6** —— 错！**合格折价补偿 = §2**、**不合格 = §3**（§6 是黑白合同结算）。
5. **优先权范围含利息 / 违约金 / 损害赔偿** —— 错！**仅工程价款本身**（§40），利息违约金只能作普通债权。
6. **优先权期限"6 个月 / 竣工之日"** —— 错！现行 **18 个月 / 应当给付价款之日**（§41）；"6 个月/竣工"是已废止旧法。
7. **优先权 < 已登记抵押权** —— 错！优先权 **> 抵押权**（§36，哪怕登记在先）；但 **< 商品房消费者超级优先权**（法释〔2023〕1 号）。
8. **实际施工人享有优先权 / 法院"可以追加为当事人"** —— 错！优先权主体限**§35 直接承包人**；§43 是"**应当**追加为**第三人**"（旧法才是"可以/当事人"）。

## 📐 口诀

> **定性**：钉地上的不动产才是建设工程，设备再大也是承揽；安装培训是附随，主义务定性。
> **效力**：无资质、挂靠、该招标没招标——**合同无效**；挂靠拆两份（内部协议必无效；对外合同**看发包人善意**：善意有效 / 明知无效），完工不治愈。
> **无效后果**：**合格折价补（§2），不合格修复/赔（§3）**。
> **优先权**：**主体只认直接承包人（§35）**；**优于抵押权（§36）**，但**输给居住全款的消费者（2023 超级优先）**；**范围只算工程款、不含利息违约金（§40）**；**18 个月、自应付款之日（§41，不是 6 个月竣工日！）**。
> **实际施工人**：可**直接告发包人**、**应当追加为第三人**、**以欠付款为限**（§43，不是"可以/当事人")；但**无优先受偿权**。
