# 📐 第三人 · 完整答题模型（有独三 + 无独三权利清单 + 第三人撤销之诉）

> **核心一句**：第三人制度回答的是"**别人的官司，我怎么掺和 / 没掺和上怎么救**"三个问题：**有独三=以起诉方式主动进场、地位相当于原告**；**无独三=申请或被法院通知进场、只是"半个当事人"（被判担责才有当事人的诉讼权利义务）**；**没能掺和的第三人=事后提第三人撤销之诉**（非因己过未参加+裁判内容错误损害权益+知道或应当知道起六个月+向作出生效裁判的法院）。最毒陷阱是**给无独三发"完整当事人权利包"**（提管辖异议/申请撤诉——都无权）、**把"主张分一份的继承人"当有独三**（其实是共同原告）、**让普通债权人提三撤**（无原告资格）、以及**三撤与案外人申请再审"两条路都走"**（择一衔接、不得并用）。
>
> 🔎 **核心条文速查**：
> - **《民事诉讼法》第59条第1款【有独三】**：对当事人双方的诉讼标的，第三人**认为有独立请求权的，有权提起诉讼**。
> - **《民事诉讼法》第59条第2款【无独三】**：对当事人双方的诉讼标的，第三人虽然没有独立请求权，但**案件处理结果同他有法律上的利害关系**的，可以**申请参加诉讼，或者由人民法院通知他参加诉讼**。人民法院**判决承担民事责任的第三人，有当事人的诉讼权利义务**。
> - **《民事诉讼法》第59条第3款【第三人撤销之诉】**：前两款规定的第三人，**因不能归责于本人的事由未参加诉讼**，但有证据证明发生法律效力的判决、裁定、调解书的**部分或者全部内容错误，损害其民事权益**的，可以**自知道或者应当知道其民事权益受到损害之日起六个月内**，向**作出该判决、裁定、调解书的人民法院**提起诉讼。诉讼请求成立的，应当**改变或者撤销**原判决、裁定、调解书；不成立的，**驳回**诉讼请求。
> - **《民诉法解释》（法释〔2022〕11号修正）**：第81条（有独三成为当事人；无独三申请或法院通知参加；一审未参加的第三人申请参加二审的可以准许）；**第82条（一审中无独三无权提管辖异议、无权放弃变更诉讼请求或申请撤诉，被判决承担民事责任的有权上诉）**；第237条（有独三参加后原告撤诉：有独三作另案原告、原案原被告作另案被告，诉讼继续）；第249条（争议权利转移不影响当事人地位，受让人三种介入方式）；第290-301条（三撤配套：起诉条件与期限/审查立案/合议庭开庭/"不能归责于本人"四情形/"内容"指主文/排除清单/当事人列置/担保中止执行/三档处理/与再审衔接/择一衔接）；第127条（三撤六个月为**不变期间**，不适用中止中断延长）。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已逐条 grep 本地权威全文核验——民诉法§59三款（有独三/无独三/三撤总纲）出自 2023 年修正版官方 PDF 文本；民诉解释§81、§82、§127、§237、§249、§290-§301 均逐条对照法释〔2022〕11号修正版官方 PDF 原文，无一凭记忆写入。"三撤与案外人申请再审的**择一衔接**"的规范落点是**解释§301**（提三撤后不服驳回执行异议裁定的，不得再申请原裁判再审；已走§234案外人申请再审路径的，提三撤不予受理），"择一"系对该条两款的通行概括表述（与深度报告 9-7"两者不得并用"一致），非法条原文用语。"有独三地位相当于原告""无独三是'半个当事人'"为通行学理概括，不虚标条号。

> ⚠️ **易记错点**：①**无独三在一审中无权提管辖异议、无权放弃/变更诉讼请求或申请撤诉**（解释§82）——命题人最爱给无独三发"完整权利包"；②无独三**只有被判决承担民事责任时**才有当事人的诉讼权利义务、才有权上诉（民诉法§59 II 后句+解释§82），没被判担责就不能上诉；③**"主张标的全归我"（排斥双方）＝有独三，"我也依法分一份"（与一方同立场）＝共同原告**——继承题的经典分水岭；④三撤的**六个月是不变期间**（解释§127），不适用诉讼时效中止、中断、延长，且起算点是"知道或应当知道**权益受损**"，不是"裁判生效"；⑤三撤管辖是**作出生效判决、裁定、调解书的法院**，不是被告住所地法院；⑥三撤原告资格**限于两类第三人**——普通金钱债权人、代表人诉讼未登记权利人、公益诉讼受害人都**不适格**（解释§295）；⑦受理三撤**不当然中止执行**，须原告提供担保并申请、法院**可以**准许（解释§297）；⑧三撤撞上再审：一般**并入再审**，只有原审当事人**恶意串通**时才反过来先审三撤、中止再审（解释§299）。

## 二、 三关判别模型（进场姿势 → 权利清单 → 事后救济）

```
              【甲乙之间的本诉正在进行 / 已出生效裁判，案外人X要不要管？】
                                │
   ▼ 第一关：X 以什么姿势进场？（民诉法§59 I/II + 解释§81）
   │
   ├─ X 对本诉标的主张"这是我的"（排斥原被告双方）
   │      └─→ 有独三：以起诉方式参加，地位相当于原告
   │          （⚠️ 若 X 只是"与一方同立场分一份"→ 共同诉讼人，不是有独三）
   ├─ X 无独立请求，但案件处理结果与其有法律上利害关系
   │      └─→ 无独三：申请参加，或由法院通知参加
   │          （⚠️ 若 X 只被通知"到庭说明事实"、不主张权利 → 证人，连无独三都不是）
   └─ 一审未参加的第三人申请参加二审 → 法院可以准许（解释§81 II）
                                │
   ▼ 第二关：进场之后各有什么权利？（民诉法§59 II 后句 + 解释§82/§237/§240/§249）
   │
   ├─ 有独三 ＝ 完整当事人：可上诉、可撤诉（撤自己的诉）
   │      └─ 本诉原告撤诉的 → 有独三作另案原告，原案原告+被告作另案被告，
   │         诉讼继续进行（解释§237，不终结）
   ├─ 无独三 ＝ "半个当事人"（一审中）：
   │      ├─ ❌ 无权提出管辖异议
   │      ├─ ❌ 无权放弃、变更诉讼请求或申请撤诉
   │      ├─ ✅ 被判决承担民事责任的 → 有当事人的诉讼权利义务，有权上诉
   │      └─ 经传票传唤无正当理由拒不到庭/中途退庭 → 不影响案件审理（解释§240）
   └─ 诉讼中争议权利转移（解释§249）：不影响原当事人地位；
      受让人①申请以无独三身份参加→可准许 ②申请替代当事人→法院视情况决定
      ③不准替代的→可追加为无独三
                                │
   ▼ 第三关：X 没能掺和、裁判已生效，怎么救？（民诉法§59 III + 解释§290-§301）
   │
   ├─ 四要件（缺一不受理）：
   │      ① 主体适格：两类第三人（普通债权人/未登记权利人/公益诉讼受害人 ❌）
   │      ② 因不能归责于本人的事由未参加（不知道诉讼/申请未准/客观无法参加等，§293）
   │      ③ 有证据证明生效判决、裁定、调解书内容错误（指主文，§294）且损害其民事权益
   │      ④ 期限+管辖：知道或应当知道权益受损起六个月（不变期间，§127）
   │         → 向作出该生效裁判的法院提起
   ├─ 排除清单（§295）：非讼程序案件 / 身份关系内容 / 未登记权利人 / 公益诉讼受害人
   ├─ 当事人列置（§296）：X 为原告；原裁判当事人为被告；
   │      原案未承担责任的无独三 → 仍列第三人
   ├─ 三档处理（§298）：撤销请求成立+权利主张成立→改变；
   │      成立但权利主张不成立/未提出→撤销；不成立→驳回（均可上诉）
   ├─ 撞上再审（§299/§300）：一般并入再审（恶意串通例外→先审三撤、中止再审）；
   │      按一审程序→一并审理可上诉；按二审程序→可调解，调解不成→撤销原判发回重审
   ├─ 中止执行（§297）：原告提供担保+申请 → 法院可以准许（非当然中止）
   └─ 择一衔接（§301）：三撤 与 案外人申请再审（§234路径）两条道路
          只能选一条，选定后不得再走另一条
```

> **一句话总诀**：**「起诉进场是有独（原告待遇），申请被通知是无独（半个当事人：管辖异议撤诉碰不得，判我担责才能上诉）；没掺和上提三撤：非因己过+裁判错误害了我+六个月不变期间+找作出裁判的原法院；原告被告列被告、旧第三人还第三人；三档改撤驳，撞再审就并入，想停执行先担保，与案外人再审两条路只能走一条」**

## 三、 三个高频干扰（权利清单 / 身份识别 / 原告资格）

命题人极喜欢在"无独三有什么权利""谁是有独三""谁能提三撤"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **给无独三发"完整权利包"** | 无独立请求权第三人认为受诉法院无管辖权的，可以提出管辖异议；不想打了也可以申请撤诉。 | **❌ 说法错误！**依解释§82，一审中无独三**无权提出管辖异议，无权放弃、变更诉讼请求或者申请撤诉**；只有**被判决承担民事责任**时，才依民诉法§59 II 后句取得当事人的诉讼权利义务、**才有权上诉**。无独三是"半个当事人"。 |
| **把"分一份的"当有独三** | 继承诉讼中，另一继承人向法院主张继承遗产，应作为有独立请求权第三人参加诉讼。 | **❌ 看主张内容定身份！**主张**遗产全归自己**（如持遗嘱独占）＝排斥原被告双方＝**有独三**；主张**依法分得自己一份**＝与其他继承人**同立场**＝必要共同诉讼的**共同原告**（遗产继承为必要共同诉讼，应追加）。"全要的是外人（有独三），分一块的是自己人（共同原告）"。 |
| **让不适格主体提三撤** | 债务人的房屋被生效判决确认归他人，其普通金钱债权人可以提起第三人撤销之诉。 | **❌ 主体不适格！**三撤原告**限于民诉法§59前两款的两类第三人**。普通金钱债权人对标的物无独立请求权、与案件处理结果亦无法律上利害关系，救济路径是**保全/起诉债务人+诉中保全**；代表人诉讼未登记权利人（另行起诉套用原裁判）、公益诉讼受害人、非讼程序案件、身份关系内容，均在解释§295排除清单内，**裁定不予受理**。 |

## 四、 与案外人申请再审的对照（案外人救济道路，择一不得并用）

第三人撤销之诉（民诉法§59 III）与案外人申请再审（民诉法§234路径）同属"案外人救济"，深度报告 9-7 列为民诉最高阶综合陷阱区，命题人常考"该走哪条路、能否两条都走"：

| 事项 | 第三人撤销之诉 | 案外人申请再审（§234路径） |
|---|---|---|
| 适用场景 | **非执行场景**：裁判生效后直接损害第三人权益 | **执行场景**：先提执行异议，对驳回裁定不服、认为原裁判内容错误的，申请再审 |
| 主体 | 民诉法§59前两款的**两类第三人** | 执行程序中的**案外人** |
| 前置程序 | 无（直接起诉） | **执行异议前置**（先依§234提执行异议） |
| 管辖法院 | **作出生效判决、裁定、调解书的法院** | 依审判监督程序确定 |
| 与另一条路的关系 | 已提三撤、不服驳回执行异议裁定的，**不得再申请原裁判再审**（解释§301 I） | 已走§234申请再审路径的，**再提三撤不予受理**（解释§301 II）——**择一衔接、不得并用** |

> ⚠️ **易混条号**：三撤起诉条件是**解释§290**（六个月+生效法院+三项证据材料），"不能归责于本人的事由"四情形是**§293**，当事人列置是**§296**，三档处理是**§298**，与再审衔接是**§299/§300**，择一衔接是**§301**——三撤配套条文全部集中在解释"十四、第三人撤销之诉"一节，勿与再审（§59 III 只是总纲）混标。

## 五、 万能三步答题模型

在法考答题中（无论客观题选项判断，还是主观题当事人地位分析），按照以下三步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司，请求确认一批**价值100万元的精密设备**归甲所有（本诉）。案外出现两个人：**丙公司**主张这批设备是自己全款购买、只是暂放乙处，"设备是我的"；**丁公司**是设备的保管人，与乙订有保管合同，若设备被判归甲、须搬迁交付，丁可能要按合同向乙承担**20万元**违约赔偿责任。（第三步变体：丙出国一年不知诉讼，甲乙达成调解书把设备确认归甲。）

### 第一步：判进场姿势——有独三还是无独三？（还是共同诉讼人/证人？）

> **全要进场是有独，利害挂钩是无独，同边分份共同诉，只说事实是证人**

#### 概述

案外人往别人官司里"掺和"，法定姿势只有两种（民诉法§59 I/II + 解释§81）：

- **有独三**：对本诉的**诉讼标的**主张**自己的独立请求权**——这个请求**同时排斥原被告双方**（"东西是我的，你们俩谁都别想要"）。参加方式是**以起诉方式参加**（向法院提出诉讼请求和事实理由），**成为当事人**，地位相当于原告。

- **无独三**：对本诉标的**没有**独立请求，但**案件处理结果同他有法律上的利害关系**（判决结果会传导性地影响他的实体权利义务）。参加方式是**自己申请参加**，或**由法院通知参加**。

判身份前先排除两个"假第三人"：

- 与一方**同立场**、对诉讼标的有共同权利义务的 → **共同诉讼人**（如主张分一份遗产的继承人是共同原告），不是第三人；
- 只被通知**到庭陈述事实**、不主张任何权利的 → **证人**，连无独三都不是。

另外记一个时点规则：**一审未参加诉讼的第三人，申请参加二审的，法院可以准许**（解释§81 II）。

#### 大白话讲解

法院开庭审甲乙的设备确权案，门口站着丙、丁两位，法官逐一问话：

**丙公司**拍着桌子说："这批设备根本不是你们俩谁的——**是我全款100万买的**，只是暂放在乙的仓库里！"——丙对**本诉标的（设备）**主张了自己的所有权，而且这个主张**跟甲、乙都对着干**（设备归丙，则甲的确权请求落空、乙也不能留）。这就是**有独三**：丙要**递诉状、提出自己的诉讼请求**（起诉进场），进来之后地位**相当于原告**。

**丁公司**则小声说："设备是谁的我不管，但我是保管人——**要是判归甲、得搬走交付，我就要按保管合同赔乙20万**。"——丁对设备本身**没有任何请求**（不主张设备是自己的），但**判决结果会牵连他的钱包**（法律上的利害关系）。这就是**无独三**：丁可以**自己申请**参加，法院也可以**主动通知**丁参加。

对照两个"假第三人"，一张表分清四种人：

| 身份拆解 | 识别标志 | 本案对应 | 进场方式 |
| --- | --- | --- | --- |
| 有独三 | 对本诉标的有**排斥双方**的独立请求 | 丙："设备是**我的**" | **起诉**方式参加，地位相当于原告 |
| 无独三 | 无独立请求，但**处理结果与其有法律上利害关系** | 丁："判归甲我就要赔乙20万" | **申请**参加或法院**通知**参加 |
| 共同诉讼人 | 与一方**同立场**、对标的有共同权利义务 | （对照：若丙丁是共有人一起主张"设备是我们俩的"，则为共同原告） | 起诉或追加 |
| 证人 | 只**陈述亲历事实**、不主张任何权利 | （对照：仓库管理员被通知"到庭说明设备存放情况"） | 通知**到庭**（非"参加诉讼"） |

真题里的两对经典镜像务必记死：**共有人之一擅自卖共有物，另一共有人跳出来主张产权＝有独三**（对买卖双方都对立）；**继承人主张"我也依法分一份"＝共同原告**（与其他继承人同立场），只有持遗嘱主张"**遗产全归我**"的才是有独三。

#### 一句话闭环记忆

> 🎯 **一眼判**：看他**嘴里主张什么**——"标的是**我的**"（排斥双方）＝有独三（起诉进场）；"结果**牵连我**"（不主张标的）＝无独三（申请或被通知）；"我跟原告**一伙、也分一份**"＝共同诉讼人；"我**只说我看到的**"＝证人。

### 第二步：查无独三权利清单——进场之后哪些不能干？

> **无独三半个当事人：管辖撤诉碰不得，判我担责才上诉**

#### 概述

有独三是完整当事人，权利不必多说；命题的富矿全在**无独三的权利清单**（解释§82 + 民诉法§59 II 后句）：

- **一审中一律无权**：
	- ❌ 提出**管辖异议**（管辖异议是被告的武器，无独三是"搭车进场"的，无权挑法院）；
	- ❌ **放弃、变更诉讼请求**或**申请撤诉**（诉讼请求是原告的，无独三根本没有"自己的诉"可处分）。

- **附条件取得当事人权利**：
	- 只有**被判决承担民事责任**的无独三，才"有当事人的诉讼权利义务"——最实惠的一项就是**有权提起上诉**；没被判担责的无独三，判决没动他的实体权利，**不能上诉**。

- **配套两条**：
	- 无独三经传票传唤无正当理由拒不到庭、或未经许可中途退庭的，**不影响案件审理**（解释§240）；
	- 诉讼中争议债权转让的，**不影响原当事人的主体资格和诉讼地位**，受让人可申请以**无独三**身份参加（可准许）、申请**替代**当事人（法院视具体情况决定是否准许）、不准替代的可**追加为无独三**（解释§249）。

另记有独三专属的一条程序规则：**有独三参加诉讼后，本诉原告撤诉的，有独三作为另案原告、原案原告和被告作为另案被告，诉讼继续进行**（解释§237）——原告跑了，第三人顶上当原告，接着打，**不终结**。

#### 大白话讲解

丁公司作为无独三进场后，请律师盘点了一下"我能干什么"：

**想挑法院**："这案子怎么在甲住所地法院审？我要提管辖异议！"——律师摇头："**不行**。管辖异议是被告的权利，你是搭别人官司的车进来的，**车开去哪儿轮不到你指挥**（解释§82）。"

**想撤退**："那我申请撤诉行不行？"——"**也不行**。撤诉撤的是'诉'，这场诉是甲提的，你丁公司**手里根本没有诉**，拿什么撤？同理你也无权替甲放弃或变更那100万设备的诉讼请求。"

**能不能上诉**要分两种结局：

| 一审结局 | 丁能否上诉 | 理由 |
| --- | --- | --- |
| 判决设备归乙，丁不担责 | ❌ 不能 | 判决未让丁承担责任，丁未取得当事人的诉讼权利义务 |
| 判决设备归甲，**并判丁向乙赔20万** | ✅ 能 | **被判决承担民事责任**的第三人，有当事人的诉讼权利义务（民诉法§59 II 后句），当然含上诉权 |

丁又问："我干脆不去开庭呢？"——"你经传票传唤无正当理由不到庭，**不影响案件审理**（解释§240），法院照审，判你赔20万你哭都来不及。"

再看一个衍生场景（解释§249）：诉讼中甲把对乙的争议债权作价转让给了戊。这**不换人**——甲仍是原告、照样可以撤诉；戊想介入有三条路：①申请当**无独三**→法院可准许；②申请**顶替**甲当原告→法院看情况决定；③想顶替没被批准→法院可**追加戊为无独三**兜底。口诀："转让不换人，受让人三条路，最差也能当无独三。"

最后回头看丙（有独三）这边的独门规则：假如诉讼中**甲撤诉了**，案子不是就地解散——依解释§237，**丙升格为另案原告，甲和乙都变成另案被告**，丙主张"设备100万归我"的诉讼**继续进行**。原告跑了，有独三顶上。

#### 一句话闭环记忆

> 🎯 **一眼判**：无独三在一审=**半个当事人**——管辖异议❌、放弃/变更诉请❌、申请撤诉❌、缺席不影响审理；**唯一翻身点：被判担责→秒变完整当事人→可上诉**。有独三遇原告撤诉→**自己当另案原告，原案原被告都当另案被告，诉讼继续**（解释§237）。

### 第三步：判事后救济——没掺和上的第三人怎么提三撤？

> **非因己过没参加，六个月找原审院，改撤驳三档，撞再审并入，与再审择一**

#### 概述

两类第三人若**没能参加诉讼**、生效裁判又损害了其权益，法律给的"事后翻案"通道是**第三人撤销之诉**（民诉法§59 III + 解释§290-§301）。答题按"**四要件 → 排除清单 → 当事人列置 → 三档处理 → 两个衔接**"过筛：

- **四要件**（§59 III + 解释§290/§293）：
	- ① **主体**：限民诉法§59前两款的**两类第三人**；
	- ② **因不能归责于本人的事由未参加诉讼**——指未被列为当事人且无过错/无明显过错，含四情形：不知道诉讼、申请参加未获准许、知道但因客观原因无法参加、其他非因本人事由（解释§293）；
	- ③ **有证据证明**生效判决、裁定、调解书的部分或全部**内容错误**（"内容"指判决裁定的**主文**、调解书中处理权利义务的结果，§294），**损害其民事权益**；
	- ④ **期限与管辖**：自**知道或应当知道其民事权益受到损害之日**起**六个月**内（**不变期间**，不适用中止/中断/延长，§127），向**作出该生效裁判的法院**提起。

- **排除清单**（§295，四类不予受理）：非讼程序（特别/督促/公示催告/破产等）案件；婚姻等**身份关系**内容；代表人诉讼**未参加登记的权利人**（其通道是另行起诉套用原裁判）；公益诉讼受害人。

- **当事人列置**（§296）：第三人为**原告**；生效裁判的**当事人列为被告**（不因其"同意"第三人主张而改变）；原案**未承担责任的无独三仍列第三人**。

- **三档处理**（§298）：撤销请求成立＋权利主张成立→**改变**错误部分；撤销请求成立但权利主张不成立或未提出→**撤销**错误部分；撤销请求不成立→**驳回**。均可上诉；未改变/未撤销部分继续有效。

- **两个衔接**：
	- **撞上再审**（§299/§300）：三撤审理期间原裁判被裁定再审的→诉请**并入再审**；**恶意串通**例外→先审三撤、中止再审。并入后按**一审**程序→一并审理、判决可上诉；按**二审**程序→可**调解**，调解不成→**撤销原判、发回一审重审**（列明第三人）；
	- **与案外人申请再审择一**（§301）：提三撤后不服驳回执行异议裁定的不得再申请再审；已走§234申请再审路径的提三撤不予受理。
	- 另：受理三撤后原告**提供担保**、请求**中止执行**的，法院**可以**准许（§297，非当然中止）。

#### 大白话讲解

变体场景：丙公司出国考察一整年，压根不知道甲乙在打设备官司。期间甲乙达成**调解书**，把100万设备确认归甲。丙 **2026年3月1日**回国发现设备被拉走了，才知道权益受损。

**第一问：丙能不能告？**四要件逐项对号：

| 要件拆解 | 本案对应 | 是否满足 |
| --- | --- | --- |
| 主体是两类第三人 | 丙对设备主张所有权，是本可作为**有独三**参加之人 | ✅ |
| 非因本人事由未参加 | 丙出国**不知道诉讼**（§293第一项） | ✅ |
| 生效裁判内容错误、损害其权益 | 调解书把**丙的100万设备**确认归甲 | ✅（须举证） |
| 六个月＋作出裁判的法院 | 2026-03-01知道→**2026-09-01前**，向**作出调解书的法院**提起 | ✅（调解书也能撤） |

注意两个数字陷阱：这**六个月是不变期间**（解释§127）——丙哪怕住院三个月，也不能主张"中止"往后顺延；起算点是"知道或应当知道**权益受损**"（2026-03-01），**不是调解书生效日**。

**反面对照（谁没资格告）**：若来告的不是丙，而是乙的**普通债权人**（担心乙的财产被判走影响还钱）——不适格，他该去保全、去起诉乙；若是**代表人诉讼没登记上的权利人**——不适格，他该另行起诉套用原裁判（§295）。

**第二问：告谁？**丙为**原告**；调解书的当事人**甲、乙都列被告**——哪怕乙当庭表态"我支持丙"，乙照样是被告；假如原案还有个没担责的无独三丁，丁**仍列第三人**（§296）。

**第三问：怎么判？**三档（§298）：法院查明调解书确实错了（设备确系丙所有）＋丙的所有权主张成立→**改变**错误部分、设备归丙；查明调解书错了（如证据伪造）、但丙证不了设备是自己的→只**撤销**错误部分、不帮丙确权；查明调解书没错→**驳回**丙的诉讼请求。

**第四问：半路撞上再审怎么办？**假如丙的三撤正在审，检察院又对该调解书抗诉、原裁判被裁定**再审**——一般把丙的诉请**并入再审**一起审（§299）；只有丙能拿出证据证明**甲乙恶意串通**坑他时，才反过来**先审三撤、中止再审**（恶意串通虚假诉讼的还可依解释§190按民诉法§115处罚）。并入后按**一审**程序审→一并判、可上诉；按**二审**程序审→可以把甲乙丙叫到一起**调解**，调不成→**撤销原判、发回重审**（§300）。

**第五问：设备正在被执行拉走，能叫停吗？**不是提了三撤就自动停——丙要**提供担保**并**申请中止执行**，法院才"**可以**"准许（§297）。而且丙要想清楚走哪条路：如果案件已进**执行程序**，丙也可以走"**执行异议→不服驳回→案外人申请再审**"（§234）那条道——但**两条路只能选一条**（§301）：提了三撤，就不能再对驳回执行异议的裁定申请原裁判再审；反过来已申请再审的，再提三撤**不予受理**。

#### 一句话闭环记忆

> 🎯 **一眼判**：三撤四件套——**两类第三人 + 非因己过没参加 + 裁判主文错误害了我（判决/裁定/调解书都行）+ 知道受损起六个月（不变期间）找作出裁判的原法院**；告状时**原被告全列被告、旧无独三还当第三人**；判决**改/撤/驳三档**看"裁判错没错"与"我有没有权利"两把尺；**撞再审→并入**（恶意串通才先审三撤）；**想停执行→担保+申请**；与案外人申请再审**择一、不得并用**。

## 六、 易混提示

*   **有独三 vs 必要共同诉讼人**：
    *   *有独三*对本诉标的提出**排斥原被告双方**的独立请求（"全归我"）；*共同诉讼人*与一方**同立场**、对标的有共同权利义务（"我也分一份"）。继承题分水岭：持遗嘱主张独占遗产＝有独三；主张法定继承份额＝共同原告。
*   **无独三 vs 证人**：
    *   *无独三*被通知"**参加诉讼**"、案件结果与其有法律上利害关系；*证人*被通知"**到庭**"陈述亲历事实、不主张任何权利。"通知参加诉讼＝第三人，通知到庭说情况＝证人"。
*   **三撤"六个月" vs 诉讼时效**：
    *   三撤六个月是**不变期间**（解释§127），不适用中止、中断、延长；起算自"知道或应当知道**权益受损**"，非裁判生效日。
*   **三撤 vs 案外人申请再审**：
    *   非执行场景/直接受害→三撤；执行场景→执行异议前置→申请再审。**择一衔接**（解释§301），选了一条就堵死另一条。

## 七、 命题人最爱的 5 个陷阱

1.  **"无独立请求权第三人可以提出管辖异议 / 申请撤诉"** —— 错！解释§82：一审中无独三**无权**提管辖异议，**无权**放弃、变更诉讼请求或申请撤诉；只有被判决承担民事责任的才有当事人的诉讼权利义务（含上诉权）。
2.  **"继承人向法院主张继承遗产，是有独立请求权第三人"** —— 看主张！主张**分得法定份额**＝与其他继承人同立场＝**共同原告**（必要共同诉讼应追加）；只有主张**遗产全归自己**（如持遗嘱）才是有独三。
3.  **"债务人的财产被生效判决确认归他人，其普通债权人可提第三人撤销之诉"** —— 错！三撤原告限**两类第三人**；普通金钱债权人不适格，救济是保全/起诉+诉中保全；代表人诉讼未登记权利人、公益诉讼受害人、非讼程序案件、身份关系内容均不予受理（解释§295）。
4.  **"受理第三人撤销之诉后，法院应当同时裁定中止执行"** —— 错！须**原告提供担保并申请**，法院**可以**准许（解释§297）——不是"应当"、更不是"当然中止"。
5.  **"三撤审理期间原判决被裁定再审的，应中止再审、先审撤销之诉"** —— 一般反了！原则是三撤诉请**并入再审程序**（解释§299）；只有**有证据证明原审当事人恶意串通**损害第三人权益时，才先审三撤、裁定中止再审。并入后按二审程序审理的，调解不成是**撤销原判发回重审**，不是径行判决（解释§300）。
