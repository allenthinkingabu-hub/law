# 📐 一物多卖（多重买卖） · 答题模型（效力 → 物权/顺序 → 救济 → 违约金衔接）

> 凡"一物二卖 / 一房二卖 / 一物数卖 / 多重买卖"题，按这四步走，一步不跳。**核心一句话**：**合同有效 ≠ 能拿到物**——把"债权效力"和"物权变动"用 [[区分原则]] 拆开，再按标的物类型定物权 / 顺序，最后给没拿到物的人配救济。
> **姊妹模型** → [[民法-合同-违约金模型]]（§585 酌减）· [[民法-合同-定金模型]]（§588 二选一）· 概念页 [[区分原则]]。
> **适用真题**：[[典型合同-单选-23|C2-单选-23·普通动产顺序]] · [[典型合同-单选-24|C2-单选-24·动产交付定权属]] · [[典型合同-多选-23|C2-多选-23·占有改定]] · [[典型合同-单选-22|C2-单选-22·恶意串通§154]] · [[C1-多选-43 · 一房二卖与违约金酌减|C1-多选-43·不动产+酌减]]
>
> 🔎 **法条已联网核实（2026-06-11，多源 CONFIRMED）**：普通动产顺序＝[买卖合同司法解释 §9](http://www.sdcourt.gov.cn/zzszqfy/387397/387371/1081479/index.html)（先受领交付＞先付款＞成立在先）· 特殊动产顺序＝**买卖合同司法解释 §10**（交付＞登记＞成立在先，且**交付优先于登记**·第4款）· 不动产顺序＝[**八民纪要**](https://www.lantai.cn/news_view.aspx?nid=2&typeid=5&id=1365)（登记＞预告登记＞合法占有＞综合履行/成立先后；恶意登记不优先于合法占有）· 物权归属＝《民法典》§224 动产交付 / §209 不动产登记；合同均有效＝§215 区分原则 / §597。

## 一、核心考情

- **频率**：近 20 年高频。客观题单选 / 多选常考（[[买卖合同]] ★★★ 档），主观题房产 / 买卖纠纷案例几乎必涉；常与**违约金、定金、善意取得、债权人撤销权**串考。
- **命题核心**：永远围绕"**合同有效 ≠ 取得物权**"——把"债权效力"和"物权变动"故意搅在一起，看你会不会用 [[区分原则]] 拆开。再叠加"按标的物类型定顺序"的细节陷阱。
- **四大必考点**：①数份合同的效力（债权平等、都有效）②物权归谁 + 履行顺序（动产交付 / 不动产登记 / 特殊动产交付优先于登记）③没拿到物只能要违约责任（履行不能）④违约金酌减 / 与定金二选一。

## 二、万能四步模型

### 第一步：数份合同各自有没有效？（区分原则）

**铁则**：出卖人就同一标的物签的**数份买卖合同，原则上全部有效**。债权**平等无排他**、合同在先**不能**让后合同无效；买卖是负担行为，**有无处分权 / 能否交付不影响合同效力**（§215 区分原则 · §597 无权处分不破合同）。
**唯一无效例外**：**恶意串通损害他人**（§154）——须后买受人**明知 + 串通**；单纯"知道卖过一次"不算。

**老王小李例子**
- ✅ 都有效：老王的房先卖小李、后卖小张，两份合同**都有效**；小李不能以"我先签"主张小张那份无效。
- ❌ 后合同无效：小张**明知**小李已买，与老王**串通**低价过户专坑小李 → 因**恶意串通**无效（§154）。
- ⚠️ 易混："知道老王卖过" ≠ 串通；须"串通 + 损害故意"才无效。

### 第二步：物权归谁 + 履行顺序？（按标的物分三类）

**总铁则**：合同有效 ≠ 取得所有权，物权变动**另看公示**——动产看**交付**（§224）、不动产看**登记**（§209）。多个买受人都要求实际履行时，按下表定顺序：

| 标的物                  | 终局物权归谁           | 都要求实际履行时的顺序                                              | 依据                  |
| -------------------- | ---------------- | -------------------------------------------------------- | ------------------- |
| **普通动产**（玉器/挖掘机/设备）  | 谁先**受领交付**       | ① 已受领交付 ＞ ② 均未交付→**先付款** ＞ ③ 均未付款→**成立在先**               | §224 + 买卖解释 **§9**  |
| **特殊动产**（船舶/航空器/机动车） | 谁先**受领交付**（登记对抗） | ① 已受领交付 ＞ ② 均未交付→**先登记** ＞ ③ 均未交付未登记→成立在先；**④ 交付优先于登记**  | §225 + 买卖解释 **§10** |
| **不动产**（房屋）          | 谁先**过户登记**       | ① 已转移登记 ＞ ② 预告登记 ＞ ③ 合法占有 ＞ ④ 综合履行+成立先后；**恶意登记不优先于合法占有** | §209 + **八民纪要**     |

**三条最常被考的铁则**：
1. **"交付"含四种**：现实交付 + **简易交付**（§226）+ **指示交付**（§227）+ **占有改定**（§228）——占有改定也是交付，受让人照样取得所有权。
	1. 法考做题秒杀：只要看到 “已交付”，先圈这个人，他就是动产的赢家，别去纠结所有权和登记。
		1. **法考铁则拆解（用同一辆车讲透）**
			1. **交付 = 实际控制权转移**：只看**谁现在能开走、能锁车、能支配这辆车**，和法律上这车归谁、车管所写谁名字**完全无关**。
			- **所有权 = 法律归属**：看约定（如所有权保留）或法律规定，和谁开着没关系。
			- **登记 = 对外公示**：车管所的本子，和谁开着没关系。
2. **"先付款"比的是时间，不是金额**——先掏钱的赢，付得多的不一定赢（普通动产第②顺位）。
3. **特殊动产：交付优先于登记**——已提车的买受人，赢过已登记但没提车的（买卖解释 §10 第 4 款）。

**老王小李例子**
- 普通动产（看交付）：老王的二手挖掘机先卖小李（未交）、后卖小张并**交车** → 机归小张；若都没交，**先付款**的赢。
- 特殊动产（交付＞登记）：老王的车过户登记给小张、却把车**交付**给了小李 → **车归小李**（交付优先于登记）。
- 不动产（看登记）：老王的房先卖小李（未过户）、后卖小张并**过户登记** → 房归小张，小李只剩债权。

### 第三步：没拿到物的人怎么救济？（履行不能 → 违约责任）

**铁则**：标的物已交付 / 登记给他人 → 对其他买受人构成**履行不能**（§580 事实 / 法律上不能履行）。没拿到物的买受人**不能请求实际履行 / 把物从第三人处要回来**，只能**解除 + 主张违约责任**（违约金 / 损害赔偿 §577、§583）。
**附带**：①出卖人对他人订的**租赁等债权合同照样有效**（不以出租人有所有权为要件）；②若标的物尚在出卖人处、各买受人都没拿到，才进入第二步的"履行顺序"之争。

**老王小李例子**
- ✅ 要赔偿：老王把设备以占有改定给了小张，对小李陷于履行不能 → 小李**要不到设备**，但可告老王**违约赔偿**（§577）。
- ❌ 强求不能：小李**不能**要求法院判"把设备从小张处收回来交给我"——这是不可能的（§580）。
- 🆚 租赁仍有效：老王已非所有权人仍把设备出租给老丁，**租赁合同有效**（债权合同不看所有权），能否实际使用是履行问题。

### 第四步：与违约金 / 定金的衔接

**铁则**：①约定违约金**可司法调整**（§585 Ⅱ）——过分高于损失（参考线超损失 **30%**）违约方**可请求**酌减，低于损失守约方可请求酌增；**须"请求"**，不能自行少付，法院一般不主动减。②同时约定定金的，违约金与定金**二选一**（§588）。
> 📐 完整调整规则 → [[民法-合同-违约金模型]] · [[民法-合同-定金模型]]

**老王小李例子**
- 老王卖房给小李、约定违约金 35%（远超损失 30% 参考线），老王一房二卖违约 → 小李索 35%，**老王可请求**法院适当减少（§585 Ⅱ）；老王**不能**自己只付一部分了事。

### ⚠️ 易混提示（一句话防混）

- **物权归属 vs 履行顺序**：物已交付 / 登记完毕 → 直接定**物权归属**；物还在出卖人手里、大家都没拿到 → 才谈**履行顺序**（谁有权请求出卖人履行）。
- **可撤销合同地位最弱**：被胁迫 / 欺诈订立的那份合同在**撤销前仍有效**，但既易被撤销、又往往未受领未付款，履行顺序上垫底。

## 三、命题人最爱的 6 个陷阱

1. **"合同在先就优先 / 能让后合同无效"** —— 错！债权平等无排他，数份合同都有效，唯一无效是**恶意串通**（§154）。
2. **"付款多 / 付全款的优先"** —— 错！普通动产第②顺位比的是**先付款的时间**，不是金额（[[典型合同-单选-23|单选-23]]：丁付全款却排在先付 20% 的丙之后）。
3. **"占有改定 / 指示交付不算交付，物权没动"** —— 错！四种交付都算，**占有改定**也使受让人取得所有权（[[典型合同-多选-23|多选-23]]）。
4. **"特殊动产已登记者优先于已提车者"** —— 错！**交付优先于登记**（买卖解释 §10 Ⅳ）。
5. **"没拿到物可以请求实际履行 / 把物从第三人处要回"** —— 错！已交付 / 登记给他人＝**履行不能**（§580），只能要违约责任。
6. **"出卖人已非所有权人，其再订的租赁 / 买卖合同无效"** —— 错！债权合同不以处分权为要件（§215 / §597），**照样有效**（[[典型合同-多选-23|多选-23]] 的 C）。

## 四、真题演练（套四步模型）

### 范例①：[[典型合同-单选-23|C2-单选-23]]（挖掘机·普通动产·胁迫合同）→ **A**
- **第一步**：四份合同均有效；乙被胁迫订立=**可撤销**（撤销前仍有效，地位最弱）。
- **第二步（普通动产 §9）**：戊已**受领交付**（6/1）→ 第一；丙丁均未受领但已付款，**比付款时间**：丙 4/1（20%）先于丁 5/1（全款）→ 丙第二、丁第三；乙"货到付款"=**未付款**，落第三顺位且合同可撤销 → 第四。
- → 顺序 **戊、丙、丁、乙 = A** ✅。（B 错在以"付款金额"定先后。）

### 范例②：[[典型合同-单选-24|C2-单选-24]]（玉器·动产·谁受领谁得所有权）→ **A**
- **第二步（§224）**：丁**当场受领交付** → 取得所有权，与只付 30% 无关（A 对）。
- **第三步**：丙付 80% 但未受领 → 履行不能，只能要违约责任（B 错）；乙未付未受领（C 错）。
- **第一步**：三份合同都有效（区分原则，D"二三份无效"错）。
- → **A** ✅。

### 范例③：[[典型合同-多选-23|C2-多选-23]]（设备·占有改定 + 租赁效力）→ **ACD**
- **第二步**：甲丙以**占有改定**（§228）交付 → 设备归**丙**（A 对、B 错）。
- **第三步**：甲对乙履行不能 → 乙可请求**违约赔偿**（D 对）；甲虽非所有权人，**甲丁租赁仍有效**（C 对）。
- → **ACD** ✅。

### 范例④：[[C1-多选-43 · 一房二卖与违约金酌减|C1-多选-43]]（房屋·不动产 + 违约金酌减）→ **CD**
- **第一步**：甲卖乙、甲卖丙两份合同都有效 → A"主张丙合同无效"错。
- **第二步（§209/八民纪要）**：房已**过户登记给丙** → 丙得所有权。
- **第三步**：甲对乙履行不能 → 乙**不能**要求实际交付（B 错），但**可**要违约责任（C 对）。
- **第四步**：35% 违约金过分高于损失 → 违约方甲**可请求**法院酌减（D 对，§585 Ⅱ）。
- → **CD** ✅。

### 范例⑤：[[典型合同-单选-22|C2-单选-22]]（一房二卖 + 恶意串通§154）→ 印证第一步
- **第一步**：甲一房二卖给乙、丙，两份合同**本都有效**（债权平等）；但若证明后买受人与甲**恶意串通损害**在先买受人 → 该合同**§154 无效**——这正是"都有效"的**唯一例外**。
- → 印证第一步"数份合同都有效，恶意串通才作废"。（本题主考点为分期付款认定，详见 [[民法-合同-分期付款买卖模型]]。）

## 📐 口诀

> **"数份合同都有效（恶意串通才作废）；动产交付不动产登记，特殊动产交付压登记；先付钱比时间不比多少，占有改定也算交；要不到货别强求，履行不能找赔偿；违约金过头法院砍，碰上定金二选一。"**
