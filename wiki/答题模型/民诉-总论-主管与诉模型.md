# 📐 主管与诉 · 完整答题模型（进门主管 + 诉的种类 + 合并变更 + 一事不再理）

> **核心一句**：一个纠纷进法院要闯四道门：**先看法院管不管（主管）→ 再看告的是哪种诉（给付/确认/形成）→ 再看几个请求几个人怎么并案（合并变更追加）→ 最后拦住重复起诉（三同）**。最毒陷阱是**把"解除合同"当形成之诉**（民法典§565通知即解除，法院只确认）、**照请求条数去数诉讼标的**（诉讼标的=法律关系个数）、**把"撤诉后再诉"当重复起诉**（三同针对的是经过实体裁判或正在系属中的同一诉）、**把普通共同诉讼当必要共同诉讼"无需同意"**。
>
> 🔎 **核心条文速查**：
> - **民诉法§3【主管范围】**：人民法院受理公民之间、法人之间、其他组织之间以及他们相互之间**因财产关系和人身关系**提起的民事诉讼，适用本法的规定。
> - **民诉法§122【起诉四条件】**：①原告是与本案有**直接利害关系**的公民、法人和其他组织；②有**明确的被告**；③有**具体的诉讼请求**和事实、理由；④属于人民法院**受理民事诉讼的范围**和受诉人民法院**管辖**。
> - **民诉法§126【必须受理与7日立案】**：对符合§122的起诉必须受理，7日内立案；不符合的7日内裁定**不予受理**，原告不服可以**上诉**。
> - **民诉法§127【七类告知处理】**：属行政诉讼受案范围的告知提行政诉讼；有书面仲裁协议不得起诉的告知申请仲裁；应当由其他机关处理的告知向有关机关申请解决；不属本院管辖的告知向有管辖权的法院起诉；对已生效裁判/调解书又起诉的告知申请**再审**（准许撤诉的裁定除外）等。
> - **民诉法§55【共同诉讼】**：诉讼标的**共同**的，或者诉讼标的**同一种类**、法院认为可以合并审理**并经当事人同意**的，为共同诉讼。
> - **民诉法§143【合并审理】**：原告增加诉讼请求，被告提出反诉，第三人提出与本案有关的诉讼请求，**可以合并审理**。
> - **民诉解释§232【应当合并】**：案件受理后、**法庭辩论结束前**，原告增加诉讼请求、被告反诉、第三人提出相关请求，可以合并审理的，法院**应当合并审理**。
> - **民诉解释§247【重复起诉三同】**：就已经提起诉讼的事项在**诉讼过程中或者裁判生效后**再次起诉，同时符合：①后诉与前诉**当事人相同**；②**诉讼标的相同**；③**诉讼请求相同**，或者后诉请求**实质上否定前诉裁判结果**——构成重复起诉；构成的裁定不予受理，已受理的裁定驳回起诉，但法律、司法解释另有规定的除外。
> - **民诉解释§248【新事实再诉】**：裁判发生法律效力后，**发生新的事实**，当事人再次提起诉讼的，法院**应当依法受理**。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [民诉解释（法释〔2022〕11号，国家法律法规数据库检索）](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已在本地权威全文（ssf.gov.cn发布的民诉法2023全文PDF转文本、民诉解释2022全文）中**逐条grep到原文**后写入：民诉法§3、§13、§54、§55、§122、§123、§124、§126、§127、§143、§205，民诉解释§214、§232、§233、§247、§248、§326。**特别订正**：民诉法**§124是"起诉状应当记明的事项"**（当事人信息、请求与事实理由、证据），**不是**"不予受理情形"——不予受理的程序在**§126**（7日内裁定、可上诉），七类"告知处理"情形在**§127**，三条不可混标。另：**诉讼标的（法律关系说）、诉的三种类型、诉的客体/主体合并、预备合并/重叠合并等分类均系学理通说，无单一对应条文**，本模型不为其虚标条号。
>
> 🆕 **2026-07-23 新增并核实**：《最高人民法院关于民事诉讼证据的若干规定》**第五十三条**（法释〔2019〕19号，2019-10-14 修正、**2020-05-01 施行**）——已由[最高法官网](https://www.court.gov.cn/fabu/xiangqing/212721.html)与[最高法知识产权法庭](https://ipc.court.gov.cn/zh-cn/news/view-393.html)**两个独立官方源逐字核对**。**两点务必注意**：①该条在**《证据规定》**而非**《民诉解释》**，民诉解释中**无**对应条文，极易张冠李戴；②旧《证据规定》（法释〔2001〕33号）**第三十五条**"人民法院**应当告知**当事人可以变更诉讼请求"**已被2019年修订取代**，现行表述为"**作为焦点问题进行审理**"+但书，且重新指定举证期限由"应当"改为"**可以**"——沿用旧表述即为**错误**（[旧版原文·最高法公报](http://gongbao.court.gov.cn/Details/0d82ddc253c5a8a44fbea92ea600bb.html)）。

> ⚠️ **易记错点**：①**解除合同=确认之诉、撤销合同=形成之诉**——分界线是"谁离得开法院"：解除靠通知就生效（民法典§565），法院只确认；撤销非经法院/仲裁不生效（民法典§147-151），判决亲手变动法律关系；②**诉讼标的个数=法律关系个数**——本金、利息、罚息列三条请求，法律关系只有一个借款合同，诉讼标的就是一个；③**确认之诉只确认"法律关系"不确认"事实"**——"确认对方存在违规行为""确认债务已过时效"都不成立（时效届满只生抗辩权且法院不得主动适用）；④**重复起诉的分水岭=有无实体裁判/是否仍在系属**——判决驳回**诉讼请求**后再诉=重复；撤诉、裁定不予受理、裁定驳回**起诉**后再诉=可以再来（解释§214）；⑤裁判生效后**发生新的事实**再诉，应当受理（解释§248），不是重复起诉；⑥**普通共同诉讼合并须经当事人同意**（民诉法§55"并经当事人同意"），只有必要共同诉讼（标的共同）才不问同意；⑦二审新增独立诉请：**调解不成告知另行起诉**（解释§326），不是"应当一并审理"。

## 二、 五步判别模型（进门 → 定性 → 变更 → 并案 → 拦重复）

```
                     【一个民事纠纷来了】
                            │
     ▼ 第一步：进门——法院管不管？（主管，民诉法§3/§122/§126/§127）
     │
     ├─ 平等主体因财产关系/人身关系的纠纷 ──→ 法院民事主管（§3）
     ├─ 起诉四条件（§122）：利害关系原告+明确被告+具体请求和事实理由+主管与管辖
     ├─ 符合的必须受理、7日立案；不符合的7日裁定不予受理，可上诉（§126）
     └─ 分流通道（§127）：行政案→提行政诉讼；有效仲裁协议→申请仲裁；
        其他机关处理→告知申请解决；无管辖→告知去有管辖权法院；
        生效裁判又起诉→告知申请再审（准许撤诉的裁定除外）
        
     |-多元解纷:和解/人民调解/仲裁/上诉 - 司法确认
                            │
     ▼ 第二步：定性——告的是哪种诉？（诉的要素与种类，学理通说）
     │
     ├─ 诉讼标的＝争议的民事法律关系；数标的数"法律关系"，不数请求条数
     ├─ 要钱要物要行为 ──→ 给付之诉
     ├─ 问法律关系存否/有没有效（含"确认合同已解除"§565）──→ 确认之诉
     └─ 须法院判决才变动法律关系（撤销合同§147-151、离婚、
        再审撤销改判生效判决）──→ 形成之诉（变更之诉）
                            │
     ▼ 第三步：变更——诉变了没有？变了怎么办？（解释§232，证据规定§53）
     │
     ├─ 先看变的是哪个要素：当事人→走追加/变更当事人（另见当事人模型）；
     │  诉讼标的→质变；请求数额或项目→量变
     ├─ 量变（法律关系没换）──→ 增加/减少诉讼请求：标的不变、类型可能变
     ├─ 质变（换请求权基础/法律关系）──→ 诉的变更：同案内以新标的替换旧标的
     ├─ 时点闸门：受理后~法庭辩论结束前=窗口开；辩论终结后提出=不生效，按原请求判
     ├─ 法院认定的法律关系性质/行为效力与当事人主张不一致 ──→ 作为焦点问题审理
     │  （证据规定§53Ⅰ，但书：对裁判无影响或已充分辩论的除外）；当事人据此变更的，
     │  法院应当准许 + 可以重新指定举证期限（§53Ⅱ）
     └─ 连锁反应：标的额变动不影响已定管辖（管辖恒定）；审理中变更≠重复起诉
                            │
     ▼ 第四步：并案——几个请求几个人，怎么并？（民诉法§55/§143，解释§232/§233）
     │
     ├─ 同一原告对同一被告数项请求 ──→ 客体合并，法院决定，无需被告同意
     ├─ 当事人一方为复数：标的共同=必要共同诉讼（不问同意）；
     │  标的同一种类=普通共同诉讼（法院认为可合并＋当事人同意）
     └─ 法庭辩论结束前增加诉请/反诉/第三人请求，可以合并的应当合并（解释§232）
                            │
     ▼ 第五步：拦重复——后诉是不是同一个诉？（解释§247/§248/§214）
     │
     ├─ 三同齐备（当事人同+标的同+请求同或实质否定前诉裁判）──→ 重复起诉：
     │  裁定不予受理；已受理的，裁定驳回起诉
     ├─ 撤诉/按撤诉处理后同一请求再诉 ──→ 应予受理（解释§214，离婚案6个月除外）
     ├─ 裁定不予受理/驳回起诉后补正再诉 ──→ 可以受理（未经过实体裁判）
     └─ 裁判生效后发生"新的事实"再诉 ──→ 应当依法受理（解释§248）
```

> **一句话总诀**：**「进门看主管（财产人身平等主体，四条件七分流）；定性看类型（要给付、问确认、判形成——解除确认撤销形成）；变更看关系与时点（法律关系换没换定量变质变，辩论终结前是唯一窗口）；并案看主客（客体合并法院定，普通共同要同意）；拦重复查三同（当事人+标的+请求，撤诉不予受理新事实都拦不住）」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **照请求条数数诉讼标的** | "本金、利息、罚息三项请求，本案有三个诉讼标的。" | **❌ 错！** 三笔钱同出一个借款合同法律关系，诉讼标的**只有一个**、诉讼请求三项（我国传统通说：诉讼标的=争议的民事法律关系；民诉法§122(三)把"诉讼请求"单列）。 |
| **解除合同是形成之诉** | "解除权是形成权，起诉解除合同当然是形成之诉。" | **❌ 错！** 解除权靠**通知**行使、通知到达即解除（民法典§565），法院只**确认解除行为的效力**——是**确认之诉**。形成权≠形成之诉，关键看法律关系的变动靠不靠判决。 |
| **确认"事实"也是确认之诉** | "请求确认对方存在违规操作行为/确认债务已过诉讼时效，法院应作为确认之诉受理。" | **❌ 错！** 确认之诉对象原则上限于**法律关系**；"某行为存在"是攻击防御事实，"时效已过"只是抗辩事由（民法典§192，且§193法院不得主动适用），均不成立确认之诉。 |
| **撤诉后再诉=重复起诉** | "前诉已经起诉过又撤诉，同一请求再起诉构成重复起诉，不予受理。" | **❌ 错！** 撤诉未经过实体裁判，同一请求再诉**应予受理**（解释§214；离婚案6个月限制除外）。重复起诉针对的是**诉讼系属中或裁判生效后**且三同齐备的后诉（解释§247）。 |
| **必要/普通共同诉讼混同** | "数个担保人一起被诉构成必要共同诉讼，合并审理无需任何人同意。" | **❌ 错！** 各担保人分别为**不同**借款担保，标的仅"同一种类"，是**普通共同诉讼**，合并须"法院认为可以合并**并经当事人同意**"（民诉法§55）。 |

## 五、 万能五步答题模型

在法考答题中（客观题逐项判断按此顺序定位考点），按以下五步涵摄：

*   🚗 **统一案例**：甲公司借给乙公司**10万元**，约定利息**2万元**，已到期未还；甲乙之间另有一份设备买卖合同，乙严重违约，甲**书面通知**乙解除买卖合同，乙置之不理。甲起诉：①请求返还借款本金10万元、支付利息2万元；②请求确认买卖合同已解除。诉讼中甲又增加请求：判令乙支付逾期罚息1万元。判决生效后，甲不服金额，又想就同一笔借款再告一次。

### 第一步：进门诀——这纠纷法院管不管？

> **财产人身平等主体，四条件进门七分流**

#### 概述

民事诉讼的第一道门是**主管**：
- 第一, 法院受理的是**平等主体**（公民/法人/其他组织相互之间）**因财产关系和人身关系**提起的民事诉讼（民诉法§3）。[[300-民法-总则-民法基础法条：人身关系与财产关系区分指南]]

- 第二、进门要过**起诉四条件**（§122）：

	- 直接利害关系的原告
	- 明确的被告
	- 具体的诉讼请求和事实理由
	- 属于法院受理民事诉讼的范围和受诉法院管辖——第(四)项一句话装了"主管+管辖"两道闸。[[300-民事-总则-法考：受诉法院管辖 定义+判断标准（2026现行法条）]] -> 先定级别管辖、再定地域管辖
##### 进门/不进门 流程

- 符合的**必须受理、7日内立案**；不符合的7日内裁定**不予受理**，原告可以**上诉**（§126）。

##### 分流指路牌

不归法院或不归本院的，§127给了**分流指路牌**：
- 行政案→行政诉讼；-> 民庭不审官民行政纠纷，行政争议应当走行政诉讼渠道。
	- 纠纷是**公民、法人与行政机关之间因行政行为产生的公法争议**，不属于民事主管范围；当事人错误向民事庭起诉时，民事法院不能作为民事案件审理，应当告知当事人另行提起行政诉讼。
- 有效仲裁协议→仲裁；
- 应由其他机关处理→告知申请解决；
- 无管辖→有管辖权的法院；
- 生效裁判又起诉→告知申请再审。

##### 多元纠纷解决机制
法院之外还有一整套**多元解纷**通道：
- 和解（处分权，随时可以）、
- 人民调解（自愿，一家调不成可换一家再调）、[[300-民诉-调解委员会]]
- 仲裁（前提是仲裁协议**有效**——约定"某区仲裁委员会"这种不存在的机构，约定不明、补充不成即无效）、诉讼兜底。

	- 当事人对仲裁协议的效力有异议的，可以请求仲裁机构或者仲裁庭作出决定，也可以请求人民法院作出**裁定**。一方请求仲裁机构或者仲裁庭作出决定，另一方请求人民法院作出裁定的，由人民法院裁定。

###### 人民调解
- 人民调解协议达成后不履行的，**告对方当事人**；想要强制执行力的，走民诉法§205**司法确认**：协议生效之日起**30日内双方共同**申请。 被告是对方当事人而非调解委员会.

###### **司法确认（调解协议司法确认）**

人民调解委员会调解达成协议后，**双方共同向法院申请**，法院审查协议自愿、合法，出具裁定，**给人民调解协议加上强制执行力**，属于民诉特别程序、一审终审。

> 未经司法确认的人民调解协议：**只是一份民事合同**。对方不履行，**不能直接强制执行，只能起诉对方**。经过司法确认裁定有效：对方违约，**直接拿裁定书申请强制执行，不用再打官司**。


- 硬性三大条件（讲义原文考点）

	1. **主体**：必须**双方共同申请**，单方申请法院不受理；
	2. **期限**：调解协议生效之日起**30 日内**（不变期间，过期不能走司法确认）；
	3. **前提**：调解是人民调解委员会等合法调解组织主持。


#### 大白话讲解

老王（甲公司）拿着借条和买卖合同来找律师："我这官司法院收不收？"律师掰着指头过四条件：

| 起诉条件（§122） | 本案对应 | 是否满足 |
|---|---|---|
| ①直接利害关系的原告 | 老王是出借人、买卖合同当事人 | ✅ |
| ②明确的被告 | 乙公司，名称住所都明确 | ✅ |
| ③具体的诉讼请求和事实理由 | 还10万本金+2万利息；确认合同已解除 | ✅ |
| ④主管+管辖 | 平等主体间借款/买卖合同纠纷，纯财产关系 | ✅ |

四条全过，法院**必须受理**，7日内立案；就算法院不收，也得出**裁定**，老王还能上诉（§126）。

换个剧本试试分流：如果老王和乙公司当年在合同里写了"争议提交B市仲裁委员会仲裁"（有效仲裁协议），法院就会告知老王去仲裁（§127(二)）；但如果写的是"B市东城**区**仲裁委员会"——**区级仲裁机构根本不存在**，约定不明、补充协议达不成，仲裁协议**无效**，诉讼大门重新打开。

再换一个剧本：老王先拉着乙去厂里的人民调解委员会调解——调不成，可以自行和解、可以换街道居委会的调委会再调（双方同意即可）、可以起诉；调成了达成"5月15日前还本付息"的协议而乙赖账，老王**告乙公司**（调解委员会不是被告）；两家都想给协议上个"强制执行"保险，就在协议生效**30日内一起**去基层法院申请**司法确认**（§205）——注意是"**双方共同**"，一个人单独去不行。

#### 一句话闭环记忆

> 🎯 **一眼判**：平等主体+财产/人身关系=法院管（§3）；四条件齐=必须受理、7日立案，不收出裁定可上诉（§122/§126）；见"某区仲裁委员会"=机构不存在、仲裁协议无效；调解协议赖账告**对方**，司法确认**双方共同+30日+基层法院**。

#### 备注

##### 什么是 人身关系 和 财产关系
###### 1. 人身关系

- 客体：**人身利益（人格利益 / 身份利益）**
- 特征：原则和主体人身不可分离、一般**不能转让、不能单纯金钱对价置换**。
- 两类：
	- ①人格关系：生命、健康、姓名、肖像、名誉、隐私、个人信息等人格权纠纷；
	- ②身份关系：因亲属、婚姻、收养产生：结婚、离婚、收养、亲子关系、监护。

###### 2. 财产关系

- 客体：**财产利益（物、债权、股权、知识产权财产部分等）**
- 特征：核心是经济价值，权利通常可转让、可用金钱衡量。
- 包含：
	- 物权、合同之债、不当得利、无因管理、财产侵权损害赔偿、继承（财产流转）。

### 第二步：定性诀——告的是哪种诉？

> **要给付、问确认、判形成，解除确认撤销形成**

#### 概述

诉有三要素：**当事人、诉讼标的、诉的理由**。其中**诉讼标的=当事人争议、请求法院裁判的民事法律关系**（我国传统通说，学理概念、无单一对应条文）——所以**数诉讼标的数"法律关系"个数，不数请求条数**。诉的类型看"请求法院做什么"：

- **给付之诉**：要钱、要物、要行为（返还借款、支付违约金、返还设备）；

- **确认之诉**：问法律关系存不存在、有没有效（确认合同无效、确认亲子关系、**确认合同已解除**[[解除合同-确认之诉法条依据]]）——对象原则上限于**法律关系**，纯粹事实、抗辩事由不行；

- **形成之诉（变更之诉）**：必须靠法院判决才能变动法律关系（**撤销合同**、离婚、再审**撤销改判**生效判决）。

最高频的分界题是"解除 vs 撤销"：解除权是形成权，但它靠**通知**就行使完毕、通知到达即解除（民法典§565），法院只做"确认解除行为效力"——**确认之诉**；撤销权必须"请求人民法院或者仲裁机构予以撤销"（民法典§147-151），判决亲手把有效行为变成自始无效——**形成之诉**。

诉讼标的 = 案件争的底层法律关系（骨架）；诉讼请求 = 你要求法院做什么（表层主张）

判断规则：**一个民事法律关系 = 一个诉讼标的；同一法律关系上，可以同时提出多条诉讼请求，依然只算 1 个诉。**
#### 大白话讲解

先数**诉讼标的**：老王要乙还本金10万、利息2万，之后又加了罚息1万——三笔钱、三条请求，可是它们全长在**同一份借款合同**上，法律关系就一个，**诉讼标的只有一个**（诉讼请求三项）。要出现第二个诉讼标的，得出现第二个法律关系——本案确实有：那份**设备买卖合同**是另一个法律关系，所以"确认买卖合同已解除"是**另一个诉讼标的**。本案=两个法律关系=两个诉讼标的，而不是"四条请求=四个标的"。

再定**类型**，逐项对号入座：

| 请求                     | 类型             | 判断理由                                   |
| ---------------------- | -------------- | -------------------------------------- |
| 还本金10万+利息2万+罚息1万       | **给付之诉**       | 要钱                                     |
| 确认买卖合同已解除              | **确认之诉**       | 老王的解除**通知到达乙时**合同已解除（§565），法院只确认这个既成状态 |
| （对照）如乙以受欺诈为由请求撤销合同     | **形成之诉**       | 撤销非经法院/仲裁不生效（§148），判决变动法律关系            |
| （对照）如老王请求"确认乙存在违约操作行为" | **不成立确认之诉**    | 那是事实，不是法律关系——只能当审理中的事实认定               |
| （对照）如判决生效后老王申请再审请求撤销改判 | **形成之诉（变更之诉）** | 推翻生效判决须由法院作形成性变动                       |

**谁离得开法院，谁就不是形成之诉**——解除离得开（通知就生效），撤销离不开（非判不生效）。这一句能杀掉01-06、217、225、295等一串题。

#### 一句话闭环记忆

> 🎯 **一眼判**：数标的数**法律关系**不数请求条数；要钱要物=给付，问关系存否/效力=确认，非判不变动=形成；**解除=确认之诉（§565通知即解除），撤销=形成之诉（§147-151非判不生效）**；确认之诉不确认"事实"和"时效抗辩"。

### 第三步：变更诀——诉变了没有？变了怎么办？

> **量变质变看关系，辩论终结是闸门；焦点审理不释明，准许变更补举证**

#### 概述

这一步是**六环判定链**，任何一环判错后面全错：

**① 变的是三要素（当事人 / 诉讼标的 / 诉的理由）里的哪一个？**

- **当事人变**（追加被告、变更适格被告）＝**主体变更**，走当事人追加规则（另见 [[民诉-当事人-当事人适格与代理模型]]），**不走 §232 的"增加诉请"通道**。
- **诉讼标的变** → 质变，见 ②；**请求数额/项目变** → 量变，见 ②。

**② 量变还是质变？——判断主线只有一条：法律关系换没换**

- **没换＝量变**：数额增减、加要利息/违约金/罚息。诉讼标的**不变**，但**诉的类型可能变**（原只求确认解除，加了违约金请求 → 从单一确认之诉转入给付之诉）。**"标的看法律关系，类型看请求内容"，两层各算各的。**
- **换了＝质变**：原以**违约**起诉改主张**侵权**（换请求权基础/法律关系）——这才是"诉的变更"的核心情形，在同一程序内**以新标的替换旧标的**。

**③ 什么时点提的？——最常考的胜负手**

- **受理后、法庭辩论结束前**＝窗口开（解释§232）。
- **法庭辩论终结之后**（哪怕合议庭已评议完毕、法官正在写判决书）＝**窗口已关**，该变更**不发生效力**，法院**按原诉讼请求判决**即可。

**④ 谁提的？**

- **原告**增加诉讼请求 / **被告**提出反诉 / **第三人**提出与本案有关的诉讼请求——三者都在 §232 射程内，但性质不同（反诉、第三人之诉**各有自己的标的**，是"新的诉"与本诉合并）。
- 反诉另有门槛：当事人**限于本诉范围** + 基于**相同法律关系/因果关系/相同事实**（解释§233）。

**⑤ 法院怎么办？**

- 一审、辩论结束前、可以合并的 → **应当合并审理**（解释§232 原文）：

> 在案件受理后，法庭辩论结束前，原告增加诉讼请求，被告提出反诉，第三人提出与本案有关的诉讼请求，可以合并审理的，人民法院应当合并审理。

- **法院认定的法律关系性质/民事行为效力与当事人主张不一致时**（《证据规定》§53 原文，法释〔2019〕19号，2020-05-01 施行）：

> 诉讼过程中，当事人主张的法律关系性质或者民事行为效力与人民法院根据案件事实作出的认定不一致的，人民法院应当将法律关系性质或者民事行为效力**作为焦点问题进行审理**。但法律关系性质对裁判理由及结果没有影响，或者有关问题已经当事人充分辩论的除外。
> 存在前款情形，当事人根据法庭审理情况变更诉讼请求的，人民法院**应当准许**并**可以**根据案件的具体情况重新指定举证期限。

- **二审**才新增独立诉请/反诉 → **只能调解**；调解不成**告知另行起诉**；双方同意的二审可以一并裁判（解释§326）：

> 第二审人民法院可以根据当事人自愿的原则就新增加的诉讼请求或者反诉进行调解；调解不成的，告知当事人另行起诉。双方当事人同意由第二审人民法院一并审理的，第二审人民法院可以一并裁判。

**⑥ 连锁反应：变更之后还牵动什么？**

- **管辖**：受理时确定管辖权的法院，**不因标的额等事后变化而丧失管辖**（**管辖恒定**，详见 [[民诉-管辖-管辖变动与异议模型]]）。反过来更要注意：一个**已经失效的变更**（辩论终结后才提出的）**不能拿来撑"标的额超标、应移送中院"的结论**——干扰项常这么设（见下方真题 [[民诉-管辖-单选-31 · 法庭辩论终结后变更诉请的处理]]）。
- **重复起诉**：审理中变更诉请是**同一个案子内部的处分**，**不是"再次起诉"**，不构成重复起诉（与第五步"三同"对照）。

> ⚠️ **2026-07-23 订正（两处，均经官方原文核实）**
>
> 1. **删除原"诉讼标的变更＝必须另行起诉"的表述。** 原文曾称质变"本质等于撤回本诉、提出全新独立的诉，不适用§232，法院不能直接在本案合并审理，一般告知原告另行起诉"——**该结论不成立**。《证据规定》§53Ⅱ明文"当事人根据法庭审理情况变更诉讼请求的，人民法院**应当准许**并**可以重新指定举证期限**"，既然要为**本案**重新指定举证期限，案件显然**在本案继续审理**，而非打发去另行起诉。准确表述是：§232 管的是"**增加**请求/反诉/第三人请求"的**合并**通道，标的变更走的是"**替换**"通道，说"不适用§232"没错，但由此推出"法院不能审、须另诉"是错误推导。

##### 🔍 对号入座表：诉的新增/变更常见情形一张表判清

> 判断主线只有一条：**法律关系换没换**——没换是"量变"（增加/减少诉讼请求，同一个诉内部处理）；换了才是"质变"（诉的变更/新的诉）。再叠加**时点**（一审辩论结束前 vs 二审）看处理方式。

| 常见情形 | 定性 | 诉讼标的变没变 | 处理方式 |
|---|---|---|---|
| 同一合同，租金从60元**增至70元**（加数额） | **增加诉讼请求**（量变） | ❌ 不变 | 辩论结束前提出→**应当合并审理**，本案继续审（解释§232） |
| 同一合同，原只要本金，**加要利息/违约金/罚息**（加请求项） | **增加诉讼请求**（量变） | ❌ 不变（同一法律关系派生） | 同上，应当合并审理；⚠️诉的**类型**可能变（确认→含给付） |
| 原以**违约**起诉，改主张**侵权**（换请求权基础/法律关系） | **诉的变更**（质变，诉讼标的变更） | ✅ 变了 | 辩论结束前可以变更；变更后按新标的审理（旧标的不再审） |
| 原告**减少**诉讼请求/放弃部分请求 | 减少诉讼请求（量变，处分权） | ❌ 不变 | 随时可以，法院照准（处分原则，民诉法§13） |
| **被告**对原告提出独立反请求 | **反诉**（新的诉，与本诉合并） | ✅ 反诉有自己的标的 | 辩论结束前提出+当事人限本诉范围+与本诉有牵连（解释§232/§233）→应当合并 |
| **第三人**提出与本案有关的诉讼请求 | 第三人之诉（新的诉） | ✅ 有自己的标的 | 辩论结束前提出，可以合并的应当合并（解释§232） |
| **追加/变更当事人**（追加被告、变更适格被告） | 主体变更（不是诉讼请求增减） | 视情形 | 依当事人追加规则处理（另见当事人模型），非§232的"增加诉请"通道 |
| **二审**才新增独立诉讼请求/反诉 | 二审新请求 | ✅/❌ 均可能 | **只能调解**；调解不成**告知另行起诉**；双方同意才可一并裁判（解释§326） |
| 判决生效后**发生新的事实**再起诉 | **新的诉**（不是重复起诉） | ✅ 新事实=新的诉 | 应当依法受理（解释§248），走新立案 |

#### 大白话讲解

老王起诉后开庭前一算账："逾期这么久，罚息1万也得要！"能加吗？——能。时点在**法庭辩论结束前**，加的还是同一份借款合同下的钱，法院**应当合并审理**（解释§232），不用另立案、更不会"不予受理让你另行起诉"。加了这1万，**诉讼标的变了吗？没变**（还是那个借款合同）；**诉的类型变了吗**？如果原来某个诉只是确认（如确认解除），加了要钱的请求，案件类型就从单一确认之诉**转入给付之诉**——"标的看法律关系，类型看请求内容"，两层各算各的。

最后一个坑：乙一审输了上诉，在**二审**才提出"就算解除了，老王也得返还设备"——这是二审新增的独立诉请，二审法院**不能顺手一并审理**，只能组织调解，调解不成**告知另行起诉**（双方都同意二审一并处理的除外，解释§326）。

#### 一句话闭环记忆

> 🎯 **一眼判**：**法律关系换没换**定量变质变——没换=增加诉请（标的不变、类型可能变），换了=诉的变更（同案内换标的、法院应当准许）；**辩论终结前是唯一窗口**，终结后再变**不生效、按原请求判**；法院认定的法律关系性质与你主张的不一致，法院**作为焦点问题审理**（不是"告知你变更"，旧表述已废）；二审冒新请求=**调解不成另行起诉**；标的额变了**管辖恒定**、变更**不算重复起诉**。

### 第四步：并案诀——几个请求几个人怎么并？

> **客体合并法院定，普通共同要同意，辩论结束前应当并**

#### 概述

##### 合并的核心原理

 - 客体合并和主体合并: 
	 - 客体合并
		 原告、被告不变（当事人主体不变），只是把**好几组请求 / 多个法律关系**塞进同一个案子。
	- 主体合并
		 原本单一原被告，现在追加多人一起打官司，**变动的是参与诉讼的主体**。
	
- 备注
	- 什么是主体和客体
		- **诉讼主体**：打官司的**人**（原告、被告、第三人）
		- **诉讼客体**：打官司争的**对象**（诉讼标的、诉讼请求，双方争议的民事法律关系）

##### 具体讲解

并案分两个维度：

- **客体（客观）合并**——
	- 同一原告对同一被告的**数项请求**放进一个诉讼（民诉法§143：**增加诉讼请求、反诉、第三人相关请求"可以合并审理"**）。是否合并**法院决定，不需要对方同意**。学理再细分：
		- 预报合并: **有先后依存关系的两项请求**（撤销合同+返还款项）按题库口径归入**预备（牵连）合并**；
			- 两项请求存在先后依存逻辑：先审理主位请求；主位不支持，才审理备位请求；主位胜诉，则不再审理备位。

			- 案例：原告诉请①撤销买卖合同（形成之诉，主位）；一旦撤销成立，不必再审；若撤销不支持，再请求②判令支付货款（给付之诉，备位）。

		- 重叠合并: **数请求同一目的、支持其一即达目的**=**重叠合并**（学理分类，无对应条文）。
			- 多项请求基于不同法律关系，但**追求同一个给付结果，支持任意一项即可实现目的** 。
			- 案例：设备被侵占，原告同时主张：①基于所有权返还设备；②基于租赁合同到期返还设备。任一请求成立，诉求目的达成。

- **主体（主观）合并**——**共同诉讼**（民诉法§55）：诉讼标的**共同**=必要共同诉讼，合并不问当事人同意；诉讼标的**同一种类**=普通共同诉讼，须"法院认为可以合并审理**并经当事人同意**"。
	- 一方 / 双方当事人为两人以上，多个主体并入同一案件审理。
		- - **必要共同诉讼（诉讼标的共同）**
			- 多人共享同一个民事法律关系，诉不可拆分；**法院可以直接合并，无需当事人同意**。
			- 案例：甲乙共同共有房屋，起诉第三人返还房屋；只有一个所有权法律关系，必须一并审理。
    
		- **普通共同诉讼（诉讼标的同一种类）
			- **多个相互独立、性质同类的法律关系，属于可分之诉；**两个条件同时满足：法院认为适合合并 + 当事人同意，才能合并**。
			
			- 案例：三名购房者分别和开发商订立购房合同，各自主张违约金；三份独立合同，不经当事人同意不能强行合并。



#### 大白话讲解

再看**并人**的剧本：假设老王的10万借款，2018年那笔由小张担保、2019年另一笔由小李担保，老王一并起诉乙+小张+小李。小张、小李各保各的借款，两个**独立的**保证法律关系，标的只是"同一种类"——**普通共同诉讼**，合并审理要**经当事人同意**（§55）。谁要在选项里说"这是必要共同诉讼、无需同意"，直接排除。而老王对乙一个人的"两笔借款一起告"，是**客体合并**，法院说了算，不用乙点头。

#### 一句话闭环记忆

> 🎯 **一眼判**：一人对一人加请求=**客体合并**，法院定、无需对方同意；各保各的=**普通共同诉讼**，合并**须当事人同意**；标的共同=必要共同诉讼，不问同意。（变更/时点相关口诀见第三步）

### 第五步：拦重复诀——后诉是不是同一个诉？

> **三同齐备拦重复，撤诉新事实放行**

#### 概述

一事不再理由两部分组成：诉讼系属 + 既判力

- **诉讼系属**（前诉正在审理中，禁止就同一诉另行起诉）
- +**既判力**（裁判生效后，禁止再诉同一诉）。

构成重复起诉: 

- 操作标准就是解释§247的**三同**：后诉与前诉 ①**当事人相同**；②**诉讼标的相同**；③**诉讼请求相同**，

- 或者后诉请求**实质上否定前诉裁判结果**——**同时符合**才构成重复起诉；构成的**裁定不予受理**，已受理的**裁定驳回起诉**。
 

- 原告在本案审理中变更诉讼请求，属于诉的变更（同一诉讼内的程序行为），并非另行提起后诉，与重复起诉无关。

三条放行通道必须配对记忆：

- **撤诉/按撤诉处理后**以同一诉讼请求再诉→**应予受理**（解释§214；离婚案无新情况新理由6个月内除外）——没经过实体裁判，谈不上"一事已理"；
- **裁定不予受理/裁定驳回起诉后**补正再诉→可以受理——同样没有实体裁判（对照：**判决驳回诉讼请求**是实体裁判，再诉=重复）；
- **裁判生效后发生新的事实**再诉→**应当依法受理**（解释§248）——新事实=新的诉，不是旧诉重来。

#### 大白话讲解

判决生效了：法院判乙还老王本息合计12万（老王要的13万里罚息没全支持）。老王不甘心，又拿同一张借条、同一套事实去法院**再告一次，还是要那笔钱**——法院拿三同尺子一量：当事人同（老王v乙）✅、诉讼标的同（同一借款合同关系）✅、诉讼请求同（还是这笔本息罚息）✅——**三同齐备，重复起诉**，立案庭直接裁定**不予受理**；万一收进来了，也是裁定**驳回起诉**。老王的正确出路在§127(五)：认为生效判决错了，去**申请再审**，而不是再起诉。

但换三个剧本，结论全翻：

| 剧本 | 是否重复起诉 | 理由 |
|---|---|---|
| 老王一审中途**撤诉**，隔月同一请求再诉 | ❌ 不构成，应予受理 | 撤诉没经过实体裁判（解释§214） |
| 老王起诉被**裁定不予受理**，补齐材料再诉 | ❌ 不构成，可以受理 | 程序裁定≠实体裁判 |
| 判决生效后乙**又逾期了新一期利息**（新的事实），老王就新利息起诉 | ❌ 不构成，应当受理 | 解释§248新事实=新诉 |
| 判决驳回老王**诉讼请求**后，老王同一标的同一请求再诉 | ✅ 构成 | 实体裁判已作出，三同齐备 |

还有一个反向陷阱（第06题）：甲起诉请求**解除**合同、乙同时起诉请求**撤销**同一合同——当事人同、标的同，但**请求不同**（解除向将来终止 vs 撤销自始无效），三同缺一，**不构成重复起诉**；乙的请求基于同一合同、当事人限于本诉范围，实质是**反诉**，应合并审理（解释§233）。

#### 一句话闭环记忆

> 🎯 **一眼判**：重复起诉查三同——当事人同+标的同+请求同（或实质否定前诉裁判），**缺一不成立**；分水岭=有无**实体裁判**：判决驳回**诉请**后再诉=重复，撤诉/不予受理/驳回**起诉**后再诉=放行；**新事实再诉**放行（§248）；生效裁判不服→申请**再审**，不是再起诉。

## 六、 易混提示

*   **诉讼标的 vs 诉讼请求 vs 诉的类型**：
    *   *诉讼标的*跟着**法律关系**走（一个合同不管列几条请求都是一个标的）；*诉讼请求*是具体主张（可以有很多项）；*诉的类型*跟着**请求法院做什么**走（加了要钱的请求就多了给付之诉）。三个层次各算各的。
*   **解除之诉 vs 撤销之诉**：
    *   *解除*：通知到达即解除（民法典§565），法院只确认→**确认之诉**；*撤销*：非经法院/仲裁不生效（§147-151）→**形成之诉**。学理提示：民法典施行前曾有形成之诉说（含公报案例），现行考试口径统一按确认之诉。
*   **判决驳回诉讼请求 vs 裁定驳回起诉/不予受理**：
    *   前者是**实体裁判**，再诉构成重复起诉；后者是**程序处理**，补正后再诉可以受理。用语一字之差，结论天壤之别。
*   **必要共同诉讼 vs 普通共同诉讼**：
    *   标的**共同**（同一保证/共有关系）=必要，合并不问同意；标的**同一种类**（各保各的、各欠各的）=普通，合并须"法院认为可以+当事人同意"（民诉法§55）。

## 七、 命题人最爱的 6 个陷阱

1.  **"三项诉讼请求就是三个诉讼标的"** —— 错！诉讼标的以争议的**民事法律关系**为准（通说），同一合同下本金、利息、罚息只有一个标的；要有第二个标的，必须有第二个法律关系。
2.  **"解除权是形成权，所以解除合同之诉是形成之诉"** —— 错！形成权已在诉外靠**通知**行使完毕（民法典§565），法院只确认解除行为的效力——**确认之诉**。撤销合同才是形成之诉。
3.  **"请求确认对方存在某行为/确认债务已过诉讼时效，法院应受理为确认之诉"** —— 错！确认之诉的对象限于**法律关系**；"某行为存在"是事实，"时效已过"只是抗辩事由（民法典§192/§193），均不成立。
4.  **"增加诉讼请求导致诉讼标的变更，应另案审理"** —— 错！法律关系未变则标的不变；法庭辩论结束前增加诉请，可以合并审理的**应当合并审理**（解释§232），无"另案""不予受理"的余地。
5.  **"前诉撤诉后同一请求再诉构成重复起诉"** —— 错！撤诉未经实体裁判，再诉**应予受理**（解释§214）；同理裁定不予受理/驳回起诉后再诉、裁判生效后**新事实**再诉（解释§248）都不构成重复起诉。只有经过实体裁判（如判决驳回诉讼请求）后三同齐备的再诉才是重复起诉。
6.  **"数个担保人一案被诉=必要共同诉讼，合并无需同意"** —— 错！分别为不同借款担保的，标的仅同一种类，是**普通共同诉讼**，合并须经当事人同意（民诉法§55）。

| [[民诉-诉讼总论-单选-01 · 诉讼标的的个数认定]]                      | **诉讼标的个数=法律关系个数。**本金10万+利息2万+罚息10万三项请求同出一个借款合同，诉讼标的只有一个（C）；照请求条数数标的（D）是最典型错误。                                                 | **第二步·数诉讼标的**                  |

| [[民诉-诉讼总论-多选-03 · 诉的三种类型辨析]]                       | **三类型辨析双坑。**返还设备、付违约金=给付之诉（AB）；"确认存在违规操作行为"指向事实非法律关系，不成立确认之诉（C错）；解除合同=确认之诉非形成之诉（D错，民法典§565）。                                  | **第二步·类型三分+确认对象**              |
| [[民诉-诉讼总论-多选-04 · 应予受理的确认之诉]]                      | **确认之诉过三关。**亲子关系是身份法律关系可确认（A）；解除合同之诉应受理（D）；仲裁协议效力走仲裁法§31裁定通道非确认之诉（B错）；"债务已过时效"是抗辩事由且法院不得主动适用（C错）。                             | **第二步·确认之诉成立条件 + 第一步·主管分流**    |
| [[民诉-诉讼总论-多选-05 · 增加诉讼请求对诉的类型的影响]]                 | **标的与类型分层。**加违约金请求：诉的类型变（B，确认→含给付），诉讼标的不变（A错，同一买卖合同）；起点是确认之诉非形成之诉，故选D不选C。                                                     | **第二步·类型 + 第三步·变更（标的不变、类型可变）**      |
| [[民诉-诉讼总论-多选-06 · 解除与撤销的诉的类型对照]]                   | **解除确认撤销形成正面对照+三同+反诉。**解除=确认之诉（A）、撤销=形成之诉（B）；请求不同（解除≠撤销）三同不齐不构成重复起诉（C错）；同一合同、当事人限于本诉范围构成反诉（D，解释§233）。                         | **第二步·类型分界 + 第五步·三同 + 第四步·反诉** |
| [[民诉-二审程序-多选-217 · 确认合同解除之诉的性质与二审新增返还请求]]          | **通知解除时点+二审新增诉请。**合同自乙收到书面解除通知时解除（D，民法典§565）；起诉确认合同解除=确认之诉（B）；解除权已用通知"用掉"故非形成之诉（C错）；乙二审才提返还商品，非预备合并、二审不应径行一并审理（A错，解释§326）。    | **第二步·解除=确认 + 第三步·变更（二审新增诉请）**     |
| [[民诉-审判监督程序-多选-225 · 再审请求撤销改判原判的诉的类型]]             | **推翻生效判决=形成之诉。**再审请求撤销、改判已生效二审判决，须法院对生效裁判作形成性变动=变更之诉（C）=形成之诉（D）；"确认判决有误"只是前提非确认之诉（A错），先撤销才谈得上给付（B错）。                          | **第二步·形成之诉（变更之诉）**             |
| [[民诉-总论-多选-295 · 确认合同解除之诉的性质与解除时点]]                | **与217同题干互印。**确认合同解除=确认之诉（B）、通知到达即解除（D）；解除权虽为形成权但已诉外行使完毕，非形成之诉（C错）；二审新增请求非"诉的预备合并、应当一并审理"（A错）。                                | **第二步·解除=确认 + 第三步·变更（二审新增诉请）**     |
| [[民诉-总论-多选-296 · 债权人撤销权之诉的合并类型]]                   | **客体合并子类型。**撤销乙丙买卖合同+返还款项两项请求：属客体合并（D）；返还以撤销获支持为前提，按题库口径归预备（牵连）合并（C）；非主体合并（A错）、非择一支持的重叠合并（B错）。学理分类无直接法条。                      | **第四步·客体合并（预备/重叠）**            |
| [[民诉-总论-多选-297 · 人民调解不成后的纠纷解决途径]]                  | **多元解纷+仲裁协议无效。**调解失败可自行和解（A）、换调委会再调（B）、诉讼（D）；"B市东城区仲裁委员会"区级机构不存在→约定不明补充不成→仲裁协议无效，不能径行仲裁（C错，新仲裁法§13/§29）。                      | **第一步·主管与多元解纷分流**              |
| [[民诉-调解-不定项-327戴鹏 · 人民调解失败救济与调解协议起诉被告及司法确认双方共同申请]] | **调解三连问。**(1)调解失败出路同297（ABD）；(2)调解协议不履行，起诉被告是对方钟阳，调解委员会不当被告（B）；(3)司法确认须双方共同申请、30日内、书面口头皆可、住所地/标的物地/调解组织地基层法院均可管（BCD，民诉法§205）。 | **第一步·调解衔接与司法确认**              |
| [[民诉-总论-单选-330 · 重复起诉的构成辨析]]                       | **三同与放行通道对照。**判决驳回诉讼请求（实体裁判）后同一标的再诉=重复起诉（B）；撤诉后再诉应受理（A错，解释§214）、审理中变更诉请是诉的变更非再次起诉（C错）、不予受理后补正再诉可受理（D错）。                       | **第五步·三同+分水岭**                 |
| [[民诉-总论-单选-331 · 诉的要素与诉的变更辨析]]                     | **诉的变更理论题（置信度LOW）。**请求数额变更=量的变更，属诉的变更（B）；标的变更正是诉的变更核心情形（A错）；事实理由变更不"必然"变标的（C错）；D项存在教材口径争议，按题库口径处理。                            | **第三步·变更（量变/质变）**            |
| [[民诉-当事人-多选-294 · 两笔担保借款的诉的合并与共同诉讼]]               | **客体合并 vs 普通共同诉讼。**银行对甲两笔借款请求=客体合并，无需甲同意（A）；乙丙各保一笔，标的同一种类=普通共同诉讼，合并须经乙丙同意（D，民诉法§55），非必要共同诉讼（B错）。                              | **第四步·客体合并+主体合并（共同诉讼）**        |
