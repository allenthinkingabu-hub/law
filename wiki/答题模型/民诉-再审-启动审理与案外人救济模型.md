# 📐 再审 · 启动审理与案外人救济模型（依职权再审 + 检察监督 + 再审审理 + 案外人三条路）

> **核心一句**：再审是对**生效裁判**的非常救济，考试主线是**"谁能启动 → 裁定再审有什么效力 → 按什么程序审 → 审多宽 → 案外人走哪条路"**五连问；最毒陷阱是**把"抗诉必然再审（30日刚性）"说成"法院审查后决定是否再审"**、**把"裁定再审"当成"撤销原判"**、**再审审理（围绕再审请求）与发回重审（一审全面重开）两种"宽度"混为一谈**、以及**案外人救济三条道路（执行异议→案外人申请再审 / 执行异议之诉 / 第三人撤销之诉）的选路与"择一不得并用"**。
>
> 🔎 **《民事诉讼法》（2023修正）核心条文速查**（条号均经本地官方全文逐条 grep 核验）：
> - **第209条【法院依职权再审】**：各级法院**院长**对**本院**生效判决、裁定、调解书发现确有错误，认为需要再审的，**应当提交审判委员会讨论决定**；最高法对地方各级、上级对下级生效裁判发现确有错误的，有权**提审或者指令下级法院再审**。
> - **第217条【裁定再审→中止执行】**：按照审判监督程序决定再审的案件，**裁定中止**原判决、裁定、调解书的执行，但**追索赡养费、扶养费、抚养费、抚恤金、医疗费用、劳动报酬**等案件，**可以不中止**执行。
> - **第218条【再审审理程序分流】**：原生效裁判由**一审法院**作出的，按**第一审程序**审理，所作判决、裁定**可以上诉**；由**二审法院**作出的，按**第二审程序**审理，所作判决、裁定**是生效裁判**；上级法院**提审**的，按第二审程序审理，所作判决、裁定是生效裁判。再审案件**另行组成合议庭**。
> - **第219条【抗诉与检察建议的主体分层】**：最高检对各级、上级检察院对下级法院的生效判决、裁定发现有§211情形之一，或发现**调解书损害国家利益、社会公共利益**的，**应当提出抗诉**；地方各级检察院对**同级**法院可提出**检察建议**（报上级检察院备案），也可提请上级检察院抗诉；各级检察院对审判监督程序以外其他审判程序中**审判人员的违法行为**，有权向同级法院提出检察建议。
> - **第220条【当事人申请检察监督：前置＋一次性】**：①法院**驳回再审申请**；②法院**逾期未对再审申请作出裁定**；③**再审判决、裁定有明显错误**——三种情形之一，当事人才可以向检察院申请检察建议或抗诉。检察院应当在**3个月内**审查并作出决定，**当事人不得再次向检察院申请**。
> - **第221条【调查核实权】**：检察院因提出检察建议或抗诉的需要，可以向**当事人或者案外人**调查核实有关情况。
> - **第222条【抗诉必然再审】**：检察院提出抗诉的案件，接受抗诉的法院**应当自收到抗诉书之日起30日内作出再审的裁定**；有§211第1项至第5项情形之一的，可以**交下一级法院再审**，但经该下一级法院再审的除外。
> - **第59条第3款【第三人撤销之诉】**：两类第三人**因不能归责于本人的事由未参加诉讼**，有证据证明生效判决、裁定、调解书的部分或全部内容**错误、损害其民事权益**的，可以自**知道或应当知道**其民事权益受损之日起**6个月内**，向**作出该裁判的法院**提起诉讼。
> - **第238条【案外人执行异议及后续分流】**：执行过程中，案外人对**执行标的**提出书面异议的，法院15日内审查：理由成立裁定中止对该标的的执行；不成立裁定驳回。案外人、当事人对裁定不服——**认为原判决、裁定错误的，依照审判监督程序办理**；**与原判决、裁定无关的**，可以自裁定送达之日起**15日内**向法院**提起诉讼**（执行异议之诉）。
> - **《民诉法解释》（法释〔2022〕11号修正）**：§403（再审围绕再审请求、新请求另诉）；§252（发回重审可变更增加诉请、反诉、追加当事人）；§239（本诉撤诉反诉继续审理）；§400（终结审查，含和解履行完毕）；§424（小额诉讼再审两条路）；§297（撤销之诉担保申请中止执行）；§299-300（撤销之诉并入再审及两种处理）；§301（三条道路择一）；§302-303（执行异议之诉的管辖与条件）；§420-422（案外人申请再审）；§381（再审被驳回后不得再申请、告知走检察监督）；§419 II（检察院调查核实情况提交法庭质证）。
> - 官方全文：[民诉法2023 PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [民诉解释 PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf) · 民诉解释亦可查 [flk.npc.gov.cn 国家法律法规数据库](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（本地不可核验/需注意来源）**：①**《民诉法解释》内部引用的民诉法条号仍是2021旧版**（如解释§421引"民事诉讼法第二百三十四条"＝2023版**§238**；解释§403 II 引"第二百一十二条"＝2023版**§216**）——审判监督程序一章旧新条号大致**＋4**偏移（旧205→新209、旧213→新217、旧218→新222），引用时一律以2023新号为准并注明。②**"再审调解书生效即取代原判决"**：本地两份官方全文中无直接明文，系"调解书经签收生效＋案件因再审调解结案"推出的通说结论（真题卡238以§247调解书的执行力为落点），按通说掌握。③**"再审利益"**（部分胜诉未上诉方不得再审，真题卡228）与**"再审审查可以听证"**均无明文法条，属命题人立场/审判实践通行做法，卡228置信度 MEDIUM。④各考点星级为深度报告讲义共识级评估，本地无法据真题统计复核。

> ⚠️ **易记错点**：①**抗诉≠"法院审查后决定是否再审"**——抗诉是刚性启动，30日内**应当**裁定再审（§222）；检察建议才需法院组成合议庭3个月内审查决定。②**裁定再审≠撤销原判**——只是中止执行＋进入再审审理，原判撤不撤要等审完（§217）。③**再审审理"围绕再审请求"（解释§403）** 与 **发回重审"一审全面重开"（解释§252）** 是两个完全不同的宽度：前者新请求一律另诉，后者反诉、追加当事人都行。④**当事人申请检察监督有前置＋一次性**（§220）：没被驳回/没逾期/再审裁判无明显错误就不能找检察院；找过一次被拒不能再找（含跳级找上级检察院）。⑤**案外人三条路不能混走**（解释§301）：执行中必须先走执行异议（§238前置）；异议被驳回后"嫌原判错"→案外人申请再审（解释§421），"与原判无关"→执行异议之诉（15日）；已提撤销之诉的不能再申请再审，反之亦然。⑥**撤销之诉撞上再审→并入再审**（解释§299），只有**恶意串通**才反过来先审撤销之诉；并入后按二审程序审的，调解不成**撤销原判发回一审重审**，不是径行判决（解释§300）。

## 二、 判别模型（启动 → 效力 → 程序 → 范围 → 案外人选路）

```
                    【生效判决/裁定/调解书 出了问题，谁来推翻？】
                                      │
     ▼ 第一关：谁能启动再审？（三大渠道）
     │
     ├─ 当事人申请（§210-216）：向上一级法院；双方公民/一方人数众多可选原审；6个月
     ├─ 法院依职权（§209）：本院院长→审委会讨论决定；最高法/上级法院→提审或指令再审
     └─ 检察院（§219-222）：
          ├─ 抗诉（上级/最高检）──→ 必然再审：法院30日内应当裁定再审（§222）
          ├─ 检察建议（同级，报上级备案）──→ 法院合议庭3个月审查决定（解释§417）
          └─ 当事人申请检察监督（§220）：前置（驳回/逾期/再审裁判明显错误）＋一次性
                                      │
     ▼ 第二关：裁定再审的效力（§217）
     │
     ├─ 中止原裁判的执行（追索赡养费/扶养费/抚养费/抚恤金/医疗费/劳动报酬 可不中止）
     └─ 不撤销原判——撤不撤等再审审完再说
                                      │
     ▼ 第三关：按什么程序审？（§218，一律另行组成合议庭）
     │
     ├─ 原生效裁判是一审作出 ──→ 按一审程序审，判决可以上诉
     ├─ 原生效裁判是二审作出 ──→ 按二审程序审，一锤定音（终审）
     ├─ 上级法院提审 ──→ 按二审程序审，终审
     └─ 撤销原判发回一审重审 ──→ 一审全面重开：可变更增加诉请、反诉、
        追加新当事人（解释§252），不受抗诉范围限制；本诉撤诉反诉继续审（解释§239）
                                      │
     ▼ 第四关：审多宽？（解释§403）
     │
     ├─ 围绕再审请求进行；超出原审诉请的新请求 → 不予审理，告知另行起诉
     ├─ 例外一并审理：损害国家利益/社会公共利益/他人合法权益
     └─ 再审可以调解；再审调解书生效即取代原判（通说），执行依据换成调解书
                                      │
     ▼ 第五关：案外人（没参加过诉讼的人）走哪条路？
     │
     ├─ 已进入执行 ──→ 必须先提执行异议（§238，15日审查）【前置】
     │     ├─ 异议被驳回＋"嫌原判错" ──→ 案外人申请再审（解释§421：
     │     │     裁定送达之日起6个月内，向作出原裁判的法院）
     │     └─ 异议被驳回＋"与原判无关" ──→ 执行异议之诉（15日内，执行法院管辖，
     │           解释§302-303）
     ├─ 未进入执行/不能归责于己未参加诉讼 ──→ 第三人撤销之诉（§59 III：
     │     知道受损之日起6个月，向作出原裁判的法院；担保可申请中止执行，解释§297）
     ├─ 三条路择一不得并用（解释§301）：提了撤销之诉→不能再申请再审；
     │     执行异议被驳回该走再审的→不能再提撤销之诉
     └─ 撤销之诉审理期间原裁判被裁定再审 ──→ 并入再审（解释§299；恶意串通例外
           先审撤销之诉、中止再审）；并入后：按一审程序→一并审理可上诉；
           按二审程序→可调解，调解不成撤销原判发回一审重审、列明第三人（解释§300）
```

> **一句话总诀**：**「三渠道启动看关键词（申请=六个月、依职权=院长审委会、抗诉=必然三十日）；裁定再审只中止不撤判；程序随原审级走、提审二审终审；审理围绕再审请求、新账另诉，发回重审才全面重开；案外人执行中先异议、嫌判错走再审、无关另起诉、没执行走撤销之诉，三路择一，撞上再审就并入」**

## 三、 高频干扰选项

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **抗诉也要"审查决定"** | 检察院抗诉后，应当由接受抗诉的法院审查后，作出是否再审的裁定。 | **❌ 错！抗诉必然再审。**§222：接受抗诉的法院**应当**自收到抗诉书之日起30日内**作出再审的裁定**，没有"是否"的裁量空间。需要审查的是**检察建议**（合议庭3个月内审查决定，解释§417）。 |
| **裁定再审＝撤销原判** | 法院应当在裁定再审的同时，裁定撤销原判。 | **❌ 错！**裁定再审只产生**中止执行**的效力（§217，赡养费医疗费等可不中止），原判是否撤销须经再审**审理后**依结果决定。 |
| **再审什么都能审** | 再审审理范围不受当事人再审请求限制 / 再审中新增违约金请求应调解处理。 | **❌ 错！**解释§403：再审**围绕再审请求**进行，超出原审诉请的新请求**不予审理、告知另行起诉**（既不审也不调解）；仅损害国家/公共/他人利益的才一并审理。 |
| **案外人直接申请再审/直接起诉** | 执行中案外人对执行标的有异议，可直接向法院申请再审（或直接提执行异议之诉）。 | **❌ 错！执行异议前置。**§238：案外人须**先提执行异议**；被驳回后才分流——嫌原判错→案外人申请再审（解释§421，6个月），与原判无关→执行异议之诉（15日）。 |
| **撤销之诉与再审并行/互换** | 案外人执行异议被驳回后，可提第三人撤销之诉；撤销之诉审理期间原判被裁定再审的，中止撤销之诉等待再审结果。 | **❌ 双重错！**解释§301：执行异议被驳回、该按§238走再审的，提撤销之诉**不予受理**（择一）；解释§299：撤销之诉撞上再审是**并入再审**，不是中止等待（恶意串通才先审撤销之诉、中止再审）。 |

## 四、 相邻制度对照 · 案外人救济三条道路（民诉最高阶陷阱区）

| 事项 | 案外人申请再审（解释§421-422） | 第三人撤销之诉（§59 III＋解释§290-301） | 案外人执行异议之诉（§238＋解释§302-303） |
|---|---|---|---|
| 前置程序 | **执行异议被驳回**（§238前置） | **无前置**，直接起诉 | **执行异议被驳回**（§238前置） |
| 适用场景 | 执行中，认为**原判决、裁定、调解书内容错误**损害其权益 | 因不能归责于己**未参加诉讼**，生效裁判内容错误损害其权益（不以进入执行为前提） | 执行中，对执行标的主张足以排除执行的权益，**与原判决、裁定无关** |
| 期限 | 执行异议**裁定送达之日起6个月** | **知道或应当知道**权益受损之日起**6个月** | 执行异议**裁定送达之日起15日** |
| 管辖法院 | **作出原判决、裁定、调解书的法院** | **作出原判决、裁定、调解书的法院** | **执行法院** |
| 审理对象 | 原裁判对其权益造成损害的内容（非必要共同诉讼人的，仅审该部分，解释§422） | 原裁判错误部分：改变/撤销/驳回（解释§298，可上诉） | 能否**排除对执行标的的执行**（诉请须与原判无关，解释§303） |
| 中止执行 | 裁定再审→依§217中止 | 不当然中止：**原告提供担保＋申请**，法院**可以**准许（解释§297） | 异议审查阶段理由成立即裁定中止对该标的执行（§238） |
| 相互关系 | 与撤销之诉**择一**：提了撤销之诉后不服驳回异议裁定又申请再审的，不予受理（解释§301 I） | 与案外人再审**择一**：执行异议被驳回该走再审的，提撤销之诉不予受理（解释§301 II）；撞上再审→**并入**（解释§299-300） | 与前两条的分水岭就一句话：**诉请与原判有关走左边两条，无关走本条** |

> 🎯 **选路口诀**：**「先问执没执行，再问怨不怨原判」**——①没进执行程序：只有**第三人撤销之诉**一条路；②进了执行程序：一律**先提执行异议**；③异议被驳回后，**怨原判**（认为原裁判错）→ 案外人申请再审，**不怨原判**（只是这东西是我的、与原判无关）→ 执行异议之诉；④走过一条就别回头换道（择一）。

## 五、 万能五步答题模型

在法考答题中（客观题选项判断或主观题程序分析），按以下五步涵摄：

*   🚗 **统一案例**：甲公司诉乙公司买卖合同纠纷，请求付货款100万元。A区法院一审判决乙公司支付80万元，双方均未上诉，判决生效。执行中，法院查封了乙公司厂房里的一台机床（价值30万元）。此后剧情分头发展：乙公司发现新证据想翻案；市检察院认为原判适用法律错误；案外人丙公司主张被查封的机床是自己租给乙公司的。

### 第一步：判启动渠道——谁能把生效判决拉回法庭？

> **申请六个月、依职权院长审委会、抗诉必然三十日**

#### 概述

再审有且只有三大启动渠道，每条渠道各有一个"身份关键词"：

- **当事人申请**（§210-216）：向**上一级**法院申请（双方为公民或一方人数众多的可选原审法院）；**6个月**大限（§211第1、3、12、13项自知道之日起算）；申请再审**不停止执行**。
- **法院依职权**（§209）：**本院院长**发现本院生效裁判确有错误→**提交审委会讨论决定**（"各级"法院院长都可以，含基层法院）；**最高法对地方各级、上级对下级**→**提审**或**指令再审**。
- **检察院**（§219-222）：**上级/最高检→抗诉**（应当提出）；**同级→检察建议**（报上级备案）；调解书只有**损害国家利益、社会公共利益**才被抗诉/建议。**抗诉是刚性启动**：接受抗诉的法院**应当30日内裁定再审**（§222）。
- **当事人申请检察监督**（§220）有两把锁：**前置**（法院驳回再审申请/逾期未裁定/再审裁判有明显错误，三者居一）＋**一次性**（检察院3个月内审查作出决定后，**不得再次申请**，包括跳级找上级检察院）。

#### 大白话讲解

乙公司（输了80万的一方）想翻案，摆在面前的是"三扇门"：

**第一扇门（自己申请）**：判决生效后6个月内，拿着新证据向**上一级的B市中院**申请再审（甲乙都是公司，不是"双方公民"，没得选原审）。注意：申请了也**照样执行**，不是一申请就叫停。

**第二扇门（法院自己纠错）**：A区法院**院长**某天发现这判决确有错误——他不能自己拍板，得**提交审委会讨论决定**；或者B市中院/省高院发现了，可以**提审**（拿上来自己审）或**指令A区再审**。

**第三扇门（找检察院）**：乙公司先向中院申请再审**被驳回了**，这才攒够了找检察院的"门票"（§220前置）。市检察院审查后若认为原判确有错误，提请省检察院向省高院**抗诉**——抗诉书一到，法院**30日内必须裁定再审**，没有讨价还价（§222）；如果只是市检察院向**同级**中院发**再审检察建议**，那中院要组成合议庭3个月内**审查决定**要不要再审（这才是"审查后决定"）。要是检察院审查后**决定不提**，乙公司**不能再找检察院第二次**——哪怕换成省检察院也不行（一次性）。

| 渠道 | 身份关键词 | 效力 |
|---|---|---|
| 当事人申请 | 上一级法院＋6个月＋不停止执行 | 法院3个月审查，裁定再审或驳回（§215） |
| 法院依职权 | 本院：院长→审委会；上级：提审/指令再审 | 直接决定再审 |
| 检察院抗诉 | 上级/最高检 | **必然再审：30日内应当裁定**（§222） |
| 检察建议 | 同级检察院（报上级备案） | 法院合议庭3个月审查决定（解释§417） |
| 当事人申请检察监督 | 前置（驳回/逾期/明显错误）＋一次性 | 检察院3个月审查决定 |

**顺带一记（调查核实权，§221）**：检察院为提抗诉/检察建议，可以向**当事人或案外人**（甲、乙、丙都行）调查核实情况；这些情况在再审开庭时要**提交法庭并说明，由双方当事人质证**（解释§419 II）——但检察院自己**不是质证主体**，它只是"派员出席法庭"（§224）。

#### 一句话闭环记忆

> 🎯 **一眼判**：三渠道三关键词——申请＝"上一级＋六个月"；依职权＝"院长＋审委会（上级＝提审/指令）"；抗诉＝"必然（30日内裁定再审）"。见"随时申请""抗诉后审查决定是否再审""驳回后再找上级检察院"一律错。

---

### 第二步：判裁定再审的效力——中止执行，但不撤原判

> **裁定再审先中止，原判不撤养命钱照执**

#### 概述

法院裁定再审，只产生两件事、不产生第三件事：

- **产生①：中止执行**（§217）——原判决、裁定、调解书的执行**裁定中止**；但**追索赡养费、扶养费、抚养费、抚恤金、医疗费用、劳动报酬**等"养命钱"案件，**可以不中止**。
- **产生②：进入再审审理**——另行组成合议庭（§218 II）。
- **不产生：撤销原判**——原判决在再审审结前依然"活着"，撤不撤、改不改要等审完。

对照记忆：**当事人申请再审**（还没裁定再审时）**不停止执行**（§210）；**裁定再审后**才**中止执行**（§217）——"申请不停、裁定才停"。

#### 大白话讲解

省高院裁定本案再审了。乙公司高兴地问律师："是不是那80万不用付了、原判决作废了？"律师摇头，把三句话掰开：

**第一句：执行先停下**。甲公司正在申请强制执行那80万，裁定再审后，法院**裁定中止执行**——已经查封的先封着，但暂不划扣。**例外**：如果这案子判的是赡养费、抚养费、医疗费、工资这类"养命钱"，法院**可以不停**——总不能让老人孩子等再审审完再吃饭。

**第二句：原判还活着**。裁定再审**不等于撤销原判**。要是再审审完认为原判是对的，**维持原判、恢复执行**（解释§404 III：再审程序终结后，中止执行的原生效判决**自动恢复执行**）。

**第三句：换一拨法官重审**。再审案件**另行组成合议庭**，原来审这案子的合议庭得回避开。

**变体（执行和解把再审"熔断"）**：如果甲乙在执行中达成**和解协议并已履行完毕**（乙付了60万甲认了），之后乙又拿新证据申请再审——法院**裁定终结对再审申请的审查**（解释§400(三)，除非和解协议中声明不放弃再审权）。纠纷已经用自己的手了结了，再审的门就关上了。

#### 一句话闭环记忆

> 🎯 **一眼判**：申请再审**不停止**执行，**裁定**再审才**中止**执行（养命钱案件可不停）；裁定再审**不撤原判**；和解履行完毕再来申请再审→**终结审查**（不是驳回）。

---

### 第三步：判审理程序——程序随原审级走，发回重审全面重开

> **原审级别定程序，提审二审一锤音；发回重审一审重开**

#### 概述

再审按什么程序审，就看**被再审的那份生效裁判是谁作出的**（§218）：

- 原生效裁判由**一审法院**作出 → 按**第一审程序**审理，所作判决**可以上诉**；
- 原生效裁判由**二审法院**作出 → 按**第二审程序**审理，所作判决**终审**；
- 上级法院**提审** → 一律按**第二审程序**，终审。

若再审中撤销原判**发回一审重审**（如发现遗漏必要共同诉讼人），进入的是彻底的**一审重开**：

- 当事人申请**变更、增加诉讼请求**、提出**反诉**、**追加新的诉讼当事人**，符合法定情形的**应当准许**（解释§252）；
- **全面审理，不受抗诉范围限制**；
- 反诉具有独立性：**本诉原告撤诉，反诉继续审理**（解释§239）。

**小额诉讼再审的特殊两条路**（解释§424）：都向**原审法院**申请、都**组成合议庭**——以**再审事由**（判错了）申请的，再审裁判**不得上诉**；以**"不应按小额审理"**（数额超标等）为由申请的，再审裁判**可以上诉**。

#### 大白话讲解

本案原判是**A区法院一审**作出的（双方没上诉），现在分几种走法：

- **B市中院提审**：按**二审程序**审，判了就是终审——乙公司别指望再上诉；
- **中院指令A区法院自己再审**：A区按**一审程序**审，判完**还能上诉**——因为原来那次"二审机会"双方都没用过，法律把它补回来。

**发回重审是另一个世界**：再审中发现当年漏了**必须参加诉讼的丁公司**（与乙就该合同承担连带责任），裁定撤销原判、**发回A区重审**。这一下等于官司**推倒重打**：甲可以把诉请从80万改成100万；乙可以**反诉**甲的货有质量问题、要求赔15万；丁被**追加**进来。检察院当年只对"利息计算"抗诉？不管——发回重审**全面审**，不受抗诉范围限制。审到一半甲说不打了要撤诉——法院准许后，乙的**反诉照样审**（反诉独立）。

| 情形 | 按什么程序 | 结果能否上诉 |
|---|---|---|
| 原一审生效 → 原审/同级再审 | 一审程序 | **可以上诉** |
| 原二审生效 | 二审程序 | 终审 |
| 上级提审（无论原一审二审生效） | 二审程序 | 终审 |
| 再审中撤销原判发回一审重审 | 一审程序（全面重开：可反诉/追加/变更诉请） | 重审判决可上诉 |
| 小额案件以"再审事由"再审 | 原审法院＋合议庭 | **不得上诉** |
| 小额案件以"不应按小额审理"再审 | 原审法院＋合议庭 | **可以上诉** |

#### 一句话闭环记忆

> 🎯 **一眼判**：程序看**原生效裁判出自几审**——一审→一审程序可上诉；二审/提审→二审程序终审；一律另组合议庭。见"一律按二审程序"即错。**发回重审＝一审重开**：反诉、追加、变更诉请都行，不看抗诉范围；本诉撤了反诉还审。小额再审"嫌判错不能上诉、嫌不该小额能上诉"。

---

### 第四步：判审理范围——围绕再审请求，新账另诉

> **再审只审老请求，新账另诉别进门**

#### 概述

再审审理的"宽度"由解释§403一锤定音：

- **围绕再审请求进行**——再审不是把整个案子从头到尾重新过一遍；
- 当事人的再审请求**超出原审诉讼请求**的，**不予审理**；符合另案诉讼条件的，**告知另行起诉**（不是调解处理）；
- **例外一并审理**：原生效裁判损害**国家利益、社会公共利益、他人合法权益**的；被申请人在庭审辩论结束前提出的符合条件的再审请求也一并审理；
- **再审可以调解**（§96调解原则贯穿各程序）——达成协议制作**再审调解书**，生效即**取代原判决**（通说），此后执行依据是调解书而非原判（一方不履行的，对方**申请执行调解书**，§247）。

#### 大白话讲解

本案进入再审审理。庭上双方都想"加戏"：

- 甲公司说："再审正好，我**追加违约金20万**！"——法院：**不审**。原审你只要了货款，违约金是**新请求**，**另行起诉**去。
- 乙公司说："那我主张**解除合同**！"——法院：同样**不审、另诉**。
- 注意：这些新请求**连调解都不进**——命题人最爱给"对新增请求调解处理"的选项，错；再审调解也只能围绕原审请求的盘子。

**但调解本身是开的**：就"80万货款怎么付"，甲乙可以在再审中达成调解——乙一个月内付60万、甲放弃其余。中院制作**再审调解书**，双方签收生效后，**原一审判决就被取代了**。之后乙耍赖不付？甲应当**申请执行这份调解书**——不能"恢复执行原判决"（原判已被取代），也不用"就调解协议另行起诉"（调解书自己就是执行依据）。

**对照第三步防混**：同样是"乙想反诉质量问题"——在**再审审理**中：不行，另诉（解释§403）；在**发回重审**中：行，一并审（解释§252）。一字之差，天壤之别——先看清楚案件此刻在"再审审理"还是"发回重审后的一审"。

#### 一句话闭环记忆

> 🎯 **一眼判**：**再审审理**围绕再审请求，超出原审诉请的新请求"不审理＋告知另诉"（不是调解）；只有损害国家/公共/他人利益才主动扩审。再审能调解，**再审调解书生效即顶掉原判决**——之后只能执行调解书。

### 第五步：判案外人选路——执行先异议，怨判走再审，无关另起诉，没执行走撤销之诉

> **先问执没执行，再问怨不怨原判；三路择一，撞上再审就并入**

#### 概述

案外人（如对执行标的主张权利的人）的救济按两个问题选路：

- **问①：进入执行程序了吗？**
  - **没有** → 只有**第三人撤销之诉**（§59 III）：因不能归责于己未参加诉讼＋生效裁判内容错误损害其权益，知道之日起**6个月**，向**作出原裁判的法院**起诉；想停执行须**提供担保＋申请**，法院可以准许（解释§297）。
  - **进入了** → **必须先提执行异议**（§238）：法院15日审查，成立→中止对该标的执行；驳回→进入问②。
- **问②（异议被驳回后）：怨不怨原判？**
  - **怨**（认为原判决、裁定、调解书内容错误）→ **案外人申请再审**：裁定送达之日起**6个月**，向**作出原裁判的法院**（解释§421）；裁定再审后，案外人是必要共同诉讼人的按解释§420 II 处理（一审程序追加／二审程序调解不成发回重审），不是的**仅审原裁判损害其权益的内容**（解释§422）。
  - **不怨**（主张与原判无关、只是要排除执行）→ **执行异议之诉**：裁定送达之日起**15日**，**执行法院**管辖（解释§302-303）。
- **择一不得并用**（解释§301）：提了撤销之诉，后续不能再就驳回异议裁定申请再审；执行异议被驳回该走案外人再审的，再提撤销之诉不予受理。
- **撤销之诉撞上再审 → 并入**（解释§299）：撤销之诉审理期间原裁判被裁定再审的，受理撤销之诉的法院裁定将第三人诉请**并入再审程序**；**唯一例外**：有证据证明原审当事人**恶意串通**损害第三人权益的，**先审撤销之诉、中止再审**。并入后的处理（解释§300）：按**一审程序**审的→第三人诉请**一并审理**，判决可上诉；按**二审程序**审的→**可以调解**（三方一起调），调解不成→**裁定撤销原判、发回一审重审，重审时列明第三人**（不是径行判决）。

#### 大白话讲解

回到统一案例：执行法院查封了乙公司厂房里那台30万的机床，**丙公司**跳出来："机床是我租给乙用的，是我的！"丙该怎么走？

**先问执没执行**：已经在执行了 → 丙**不能**直接去起诉或申请再审，必须**先向执行法院提书面执行异议**（§238）。法院15日审查：

- 理由成立 → 裁定**中止对机床的执行**，完事；
- 被**驳回** → 丙走到岔路口，**再问怨不怨原判**：
  - **情形一（怨原判）**：原判决主文写明"乙以该机床折抵货款30万"——丙认为**原判决本身错了**（拿别人的机床抵债）→ **案外人申请再审**：驳回裁定送达之日起**6个月**内，向**作出原判决的A区法院**申请（解释§421）。裁定再审后，丙不是原案必要共同诉讼人 → 法院**只审"机床归属"这一块**，不把整个80万货款案翻个底朝天（解释§422）；
  - **情形二（不怨原判）**：原判决只判"乙付80万"，根本没提机床——查封机床纯属执行环节的事，**与原判无关** → **执行异议之诉**：裁定送达之日起**15日**内，向**执行法院**起诉，请求排除对机床的执行（解释§302-303）。

**变体（没进执行）**：如果案件根本还没执行，丙发现甲乙那场官司的判决把自己的机床处分了——只有一条路：**第三人撤销之诉**（§59 III），知道权益受损之日起6个月内向A区法院起诉；想让判决先别执行？拿出**担保**来申请，法院**可以**准许（不是受理后当然中止，解释§297）。

**变体（撞车）**：丙的撤销之诉正在A区法院审着，检察院忽然抗诉、B市中院裁定本案再审——A区法院应**裁定将丙的诉讼请求并入再审程序**，移送中院合并处理（解释§299；甲乙**恶意串通**坑丙的除外，那时反过来先审撤销之诉、中止再审）。并入后中院按**二审程序**审（一审生效判决被上级再审＝提审逻辑）：可以组织**甲、乙、丙三方调解**；调不成→**撤销原判、发回A区重审，列明丙为第三人**——注意不是"径行作出判决"。

**最后一道锁（择一）**：丙如果已经提了撤销之诉，就不能再就驳回异议的裁定申请再审；反过来，执行异议被驳回、法定路径是案外人再审的，再提撤销之诉法院**不予受理**（解释§301）。三条路，**走对一条、走完一条**。

#### 一句话闭环记忆

> 🎯 **一眼判**：**没执行→撤销之诉（6个月＋担保才可中止执行）；在执行→先异议；异议驳回后：怨原判→案外人再审（6个月、原审法院），与判无关→执行异议之诉（15日、执行法院）**。三路择一。撤销之诉撞上再审→**并入**（恶意串通才先审撤销之诉）；并入按二审程序审的→可三方调解，调不成**撤原判发回重审列明第三人**。

## 六、 易混考点辨析

*   **抗诉 vs 检察建议**：
    *   *抗诉*＝**上级/最高检**提出，**必然再审**（30日内应当裁定，§222）；*检察建议*＝**同级**检察院提出（报上级备案），法院**合议庭3个月内审查决定**是否再审（解释§417）。"必然"只属于抗诉。
*   **申请再审不停止执行 vs 裁定再审中止执行**：
    *   当事人*申请*阶段**不停止**执行（§210）；法院*裁定再审*后才**中止**执行（§217，养命钱案件可不中止）。
*   **再审审理（解释§403） vs 发回重审（解释§252）**：
    *   *再审审理*围绕再审请求，新请求一律另诉；*发回重审*是一审全面重开，可反诉、追加当事人、变更诉请，不受抗诉范围限制。
*   **终结审查（解释§400） vs 裁定驳回再审申请（§215）**：
    *   *终结审查*是程序性了结（如和解协议已履行完毕、原审或上级法院已裁定再审）；*驳回*是对再审事由的实体性否定。执行和解履行完毕后又申请再审→**终结审查**，不是驳回。
*   **第71条证据不公开出示 vs 第137条不公开审理**：
    *   涉国家秘密、商业秘密、个人隐私的**证据**"应当保密、不得在公开开庭时出示"——**依职权**、强制（§71）；离婚/商业秘密案件**不公开审理**须**当事人申请**、法院"可以"（§137 II）。再审质证主体只有**当事人**，抗诉检察院是"出席法庭"不是质证一方（§224）。
*   **案外人申请再审 vs 第三人撤销之诉 vs 执行异议之诉**：见第四节对照表——分水岭是"执没执行＋怨不怨原判"，且三路**择一**（解释§301）。

## 七、 命题陷阱清单（命题人最爱的 7 个坑）

1.  **"检察院抗诉后，法院审查后决定是否再审"** —— 错！抗诉必然再审，30日内**应当**裁定再审（§222）；要"审查决定"的是检察建议。
2.  **"法院应在裁定再审的同时裁定撤销原判"** —— 错！裁定再审只**中止执行**（§217），原判撤不撤等再审审完。
3.  **"再审申请被驳回后，可再次向法院申请再审／再向上级检察院申请抗诉"** —— 错！驳回后再次申请**不予受理**（解释§381），只能走检察监督；检察监督**一次性**（§220 II），被拒后不得再次申请（含跳级）。
4.  **"再审中当事人新增的诉讼请求应调解处理／一并审理"** —— 错！超出原审诉请的新请求**不予审理、告知另行起诉**（解释§403）；别与发回重审（可反诉可追加，解释§252）混淆。
5.  **"再审调解书生效后，一方不履行的可恢复执行原判决"** —— 错！再审调解书**取代原判决**，只能**申请执行调解书**（§247；通说）。
6.  **"执行中案外人认为查封物是自己的，可直接提起执行异议之诉／直接申请再审"** —— 错！**执行异议前置**（§238）；被驳回后才分流：怨原判→案外人再审（6个月），与判无关→执行异议之诉（15日）。
7.  **"第三人撤销之诉审理期间原判被裁定再审的，应中止撤销之诉等待再审结果"** —— 错！应**并入再审**（解释§299）；只有**恶意串通**才先审撤销之诉、中止再审；并入后按二审程序调解不成是**撤销原判发回重审**，不是径行判决（解释§300）。

| [[民诉-第三人撤销之诉-单选-200 · 撤销之诉并入再审按二审程序审理的处理]] | 解释§300两种处理 | 一审生效判决被上级中院抗诉再审＝按**二审程序**→可调解，调解不成**撤销原判、发回一审重审、列明第三人**（C对）；"一并审理作出判决"是按一审程序的处理（A错）；"告知另行起诉"是二审新增诉请的处理（B错，解释§326）。 |
| [[民诉-第三人撤销之诉-单选-201 · 撤销之诉并入再审后的调解与中止执行]] | 并入后的调解＋中止执行 | 并入再审按二审程序**可组织三方调解**（C对，解释§300(二)）；受理撤销之诉不当然中止执行——须**原告担保＋申请**、法院"可以"准许（A错，解释§297）；一般并入、非先审撤销之诉（B错）；调解不成是发回重审非径行判决（D错）。 |
