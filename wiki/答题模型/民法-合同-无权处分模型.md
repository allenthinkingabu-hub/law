# 📐 无权处分 · 完整答题模型（负担行为 vs 处分行为二分主轴）

> **核心一句**：无权处分**不影响债权合同的效力（合同有效）**，只影响"东西能不能给得出去"（物权能否变动）。一行为，**两层评价**——负担层（合同 §597）有效，处分层（物权 §311/§209/§224）才看处分权是否补正或买受人是否善意取得。
> 🔎 **两处核实纠正点（务必内化）**：
> ① **无权处分合同有效，不再是效力待定**——旧《合同法》§51（及§132Ⅰ）"无权处分合同效力待定"**已被《民法典》删除**，§597 改采合同有效（吸收《买卖合同解释》第3条）。**别再把无权处分塞进"合同效力待定"清单。**
> ② **§503 是"无权代理"的默示追认，与无权处分无关**——§503 原文是"无权代理人以被代理人的名义订立合同，被代理人已经开始履行……视为对合同的追认"。无权处分的正确条号是 **§597（合同效力）+ 物权编 §311（善意取得）**，绝不写 §503/§51。

## 二、负担行为 vs 处分行为二分（模型的脊柱）

> ⚠️ **措辞核实纠正**：我国《民法典》**不采物权行为无因性 / 独立性**，故严格说**不存在一个与债权行为分立、可单独"效力待定"的处分行为**。准确表述是——**债权合同有效，但因处分人无处分权，物权变动（所有权移转）不能发生**（§597"所有权不能转移"），除非 (a) 处分人事后取得处分权、(b) 权利人追认、或 (c) 买受人构成善意取得（§311）。"待定 / 不生效"的对象是**物权变动结果**，不是一个独立法律行为。**不可照搬德国式"处分行为效力待定"表达。**

| | 负担层（债权 / 合同） | 处分层（物权变动 / 所有权移转） |
|---|---|---|
| 解决什么 | 合同**有没有效** | 买受人**能不能拿到所有权** |
| 法条 | **§597**（合同有效，可解除 + 违约责任） | **§311** 善意取得 / 处分权补正 + **§209**(不动产登记)/**§224**(动产交付) |
| 无权处分的影响 | **不影响**——合同自始有效 | **影响**——物权变动不能发生，除非三条路之一成立 |
| 立法演变 | 旧《合同法》§51 效力待定 → **删除** → §597 有效 | 始终在物权编解决 |

→ **一句话脊柱**：**"合同效力看 §597（有效）；所有权能否移转看 §311 善意取得 或 处分权是否经追认 / 事后取得而补正（+§209/§224 物权变动规则）。"**

## 三、万能五步模型（每步铁则 + 老王小李例子）

### 第一步：认定"是不是无权处分"（三要件 + 三方辨析）

**铁则**：同时满足 → ①**以自己的名义** ②处分**他人之物 / 他人之权** ③**无处分权**。无权处分是**物的层面（处分权欠缺）**问题，**不是代理问题**。
- ⚠️ **vs 无权代理**：代理须**以被代理人名义**（§162）；以**他人名义**、无代理权 = 无权代理（§171，相对人有 30 日催告权、善意相对人有撤销权）。**分水岭就一个字：以谁的名义。**
- ⚠️ **vs 隐名代理 §925**（准确叫"被代理人身份公开但以受托人名义"）：受托人**以自己名义** + **在委托人授权范围内（有授权）** + **第三人订约时知道**委托关系 → 合同**直接约束委托人和第三人**，受托人**有权**，**不是无权处分**。成对条文是 **§926**（被代理人身份不公开时的委托人介入权 + 第三人选择权）——口诀记**"§925/§926 一对"**，别只点 §925。

**老王小李例子**
- ✅ 无权处分：老王借住小李家，**以自己名义**把小李的电视卖给老张——自己名义、卖他人之物、无权。
- ❌ 无权代理：老王**以小李名义**（冒签小李）卖电视——以他人名义。
- ❌ §925 隐名代理：小李**真授权**老王代卖，老王以自己名义卖给老张、**并告诉老张"这是小李的、小李让我卖"**——有授权 + 老张知情 → 合同直接约束小李与老张，老王**有权**。

### 第二步：定合同效力——§597"合同有效"（负担层 / 区分原则）

**铁则**：无权处分**不影响买卖合同效力**——**合同自始有效**（§597）。影响的只是"物权能不能变动 / 能不能履行"。
> 🔑 **§597 原文（须补全后段，勿漏）**："因出卖人未取得处分权致使标的物所有权不能转移的，买受人可以解除合同并请求出卖人承担违约责任。**法律、行政法规禁止或者限制转让的标的物，依照其规定。**"
> ⚠️ **§597 边界**：本条只导出"**合同有效 + 买受人可解除并主张违约责任**"，**本身不解决买受人取得所有权**——取得所有权另靠 §311 善意取得或处分权补正，勿让 §597 越位到物权变动层。
> ❌ **别回退到旧话术**：《民法典》已删旧《合同法》§51（及 §132Ⅰ）"无权处分效力待定"——**现在合同有效，不需要权利人追认才有效**。历史上确有无效说 / 效力待定说之争，物权法颁行前以效力待定说为主流，§597 之后已终结，仅具学说史意义。

**老王小李例子**
- 老王把小李的电视卖给老张、签了买卖合同 → 这份**买卖合同有效**（哪怕小李不同意）；只是老王可能交不出有效所有权，那是履行 / 物权层面的事。

**追认结果只有一个**
处分权欠缺被补正 → 物权变动发生 → 买受人取得所有权**(价款归权利人)。

注意两点(别答偏):

- **不是"让合同生效"**——合同从一开始就有效(§597),追认管的是"东西能不能给得出去",不是合同效力。
- 叠加一般物权变动规则:动产**已交付**(§224)/ 不动产**已登记**(§209),买受人**自追认时**取得所有权。

一句话:**追认 = 把"卖得成"补齐,让所有权真正过到买受人手里;合同效力跟追认无关。**

### 第三步：看买受人"能不能拿到所有权"（处分层三条路）

**铁则**：
1. **权利人追认** 或 **处分人事后取得处分权**
		（如老王后来买下了电视）→ 处分权欠缺被**补正**，叠加一般物权变动规则（§209 不动产登记 / §224 动产交付）→ 买受人**取得所有权**。
			⚠️ 追认管的是**物权变动 / 处分权补正**，**不是**"让合同生效"（第二步已有效）。
			⚠️ **法律依据核实纠正**：《民法典》并无像旧 §51 那样"无权处分→追认后有效"的**统一明文条款**；权利人事后追认在现行法下属**学理 / 体系解释结论**（崔建远 / 朱庆育 / 王利明通说），**不是某一条逐字规定，更不是 §503**（§503 是无权代理追认）。

   **🏠 实际案例（处分权补正两条路，一案看全）**

   > 老王借住小李家期间，背着小李把小李那台电视**以自己的名义**卖给老张，2000 元成交、当场搬走交付。此刻：买卖**合同有效**（§597）；但电视仍是小李的，老张**暂时拿不到所有权**（处分权欠缺）。要让老张真正取得所有权，补正有两条路——

   | 补正路径 | 案例情节 | 法律效果 |
   |---|---|---|
   | **① 权利人追认** | 小李回来知道后说："那台旧电视我也不用了，卖了就卖了，2000 块给我就行。" | 小李**追认补正处分权** + 电视**已交付**（§224）→ 老张**自追认时取得所有权**，价款归小李。 |
   | **② 处分人事后取得处分权** | 小李不追认、本想追回；但半个月后老王干脆花 2500 把这台电视**从小李手里买了下来**，自己成了电视所有权人。 | 老王**取得处分权**→ 当初对老张的处分**被补正**→ 老张**取得所有权**（电视已在老张处，无须再交付一次）。 |

   > ⚠️ 两条路补的都是"**电视最终能不能归老张**"（物权变动 / 处分权补正），**不是**"合同生不生效"——合同从签字起就有效，第二步已定。
   > ⚠️ 路径②"事后买下即补正"是**体系解释 + 区分原则**的当然结论，**民法典无逐字明文**，更**与 §503 无关**（§503 管的是无权代理追认合同）。

2. **善意取得（§311，须三要件"同时"具备）**：①受让人**受让时善意**（不知道且无重大过失，《物权编解释一》§14-19，真实权利人负举证）②**以合理的价格转让** ③应登记的**已登记** / 不需登记的**已交付**→ 受让人**取得所有权**，原所有权人**有权向无处分权人请求损害赔偿**（法言法语，勿用"索赔"）。⚠️ 逻辑起点是 **§311"所有权人有权追回"** 为原则，善意取得是**例外**，三要件齐备才阻断追回，别讲成常态。
3. 三者都不成立 → **履行不能** → 进第五步救济。

**老王小李例子**
- 追认：小李事后说"卖了就卖了吧" → 老张取得所有权；价款归小李。
- 善意取得：老张**不知道**电视是小李的、按市价付钱、电视已交付 → 老张**善意取得**，小李向老王请求损害赔偿。
- 都不成立：小李不追认、老张明知是小李的（非善意）→ 老张拿不到所有权 → 老王对老张构成履行不能。

### 第四步：（若涉及）接入解除 / 履行抗辩

**铁则**：无权处分常作"履行不能→解除"的事实起点——标的物可能无法交付 → 买受人可依 **§563** 解除（致不能实现合同目的兜底），先付款方可主张**不安抗辩权 §527-528**。此步只在题干叠加该情节时启用（见 [[典型合同-多选-18|C2-多选-18]]）。详见 [[民法-合同-履行抗辩权模型]] / [[民法-合同-解除模型]]。

**🏠 实际案例（[[典型合同-多选-18|C2-多选-18]] · 代保管的画被卖）**

> 包某把**替朋友花某代为保管**的《春闻秋意图》，**以自己名义**卖给不知情的管某 = **无权处分**（合同有效 §597，但包某未必交得出画）。
> 合同约定：管某**先在 7 日内付全款**，付完次日包某再交画 → 管某是**先履行方**。付款前，管某**得知包某只是代保管**（很可能交不出货）。这时第四步的两件工具登场——

| 工具        | 管某怎么用                                                   | 依据 / 结论                                    |
| --------- | ------------------------------------------------------- | ------------------------------------------ |
| **不安抗辩权** | 先付款方有确切证据对方可能丧失履行能力（交不出画）→ **中止付款**，除非包某**提供担保**或恢复履行能力 | §527-528；中止付款是**合法抗辩，不构成违约**（故 D"未付款=违约"错） |
| **解除合同**  | 若包某**最终无法交付** → 管某可**解除**合同                             | §563（致不能实现合同目的）；亦可走 §597"解除 + 违约责任"        |

> 🔑 **为什么第四步只在"叠加情节"时启用**：单纯无权处分走到第三步就能定所有权归属；只有题干**额外**给出"**先付款 / 卖家可能交不出货**"这类**履行环节**情节，才需要接上"**不安抗辩中止 → 交不出就解除**"这条链。本题 **B（解除）+ C（不安抗辩）对、D（中止付款=违约）错**，正是这两件工具的标准考法。
> ⚠️ 注意区分：A 项"著作权归所有权人花某"是另一陷阱——**著作权随作者（画家方某）走**，不随保管 / 买卖的所有权转移，与第四步无关。

### 第五步：救济与责任（§597 首引）

**铁则**：
- **买受人**：所有权不能转移 → **解除合同 + 请求违约责任**（**§597 是专门、直接依据，首引**；§563(四) 作兜底）。
- **真正权利人**：①追认 → 取得价款；②不追认且未被善意取得 → 向无权处分人主张返还原物；③已被善意取得 → 向无权处分人请求损害赔偿（§311Ⅱ）/ 不当得利 / 侵权。

**老王小李例子**
- 老张拿不到电视所有权 → 可**解除**与老王的合同、要老王赔违约（§597）。
- 小李不追认 → 向老王要回电视（若在）或请求损害赔偿（已被善意取得）。

## 四、易混提示

- **无权处分（自己名义 + 无处分权）vs 无权代理（他人名义 + 无代理权）vs 隐名代理 §925（自己名义 + 有授权 + 相对人知情）**——靠"名义 + 有无授权 + 相对人是否知情"三维区分。无权处分看**处分权（物的层面）**，代理看**名义 + 代理权（意思表示归属层面）**，§925/§926 是"以自己名义但效果归属委托人"的间接代理特例（授权充分，是效果归属问题，非物权变动问题）。
- **合同效力（§597 有效）vs 物权变动（追认 / 善意取得才定）**——两层别混。
- **追认对象**：无权**代理**追认指向**合同**（§503/§171）；无权**处分**追认指向**物权变动 / 处分权补正**（合同本就有效）。**§503 ≠ 无权处分。**
- **效力待定家族对照**：限制行为能力人（§145）、无权代理（§171/§503）仍属合同效力待定；**无权处分已不在此列**（合同有效）。三者共享"追认"机制，是孪生对照，但条号、追认对象各异。

## 五、命题人最爱的 5 个陷阱

1. **"无权处分 → 合同无效 / 效力待定"** —— 错！§597 **合同有效**（已删旧《合同法》§51）。
2. **"无权处分就是无权代理"** —— 错！看**以谁的名义**：自己名义 = 处分，他人名义 = 代理。
3. **"权利人追认后合同才有效"** —— 错！合同**本就有效**，追认管**物权能否变动 / 处分权补正**；且依据是物权变动规则 + 区分原则，**不是 §503、不是旧 §51**。
4. **漏掉善意取得 §311** —— 买受人善意 + 合理对价 + 交付 / 登记，可**直接取得所有权**；非善意（如关联关系、明知）则落空。
5. **§925 隐名代理陷阱** —— 题干出现"**有授权 + 相对人知道是替谁卖**"，就**不是无权处分**，合同直接约束委托人与相对人；价款请求权基础是 §925 而非追认。
6. **"违反对别人的不卖承诺 = 无权处分"反向陷阱** —— 错！破解钥匙："**无权处分看东西是不是你的、处分权在不在手里，不看有没有承诺过不卖。**"自卖自有之物 = 有权处分 + 违约（债权层面），不是 §597 无权处分。
