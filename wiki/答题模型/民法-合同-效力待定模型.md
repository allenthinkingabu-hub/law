# 📐 效力待定 · 完整答题模型（状态 / 分类视角：哪些进待定 · 4 种归宿 · 与四邻区分）

> **核心一句**：效力待定是合同**已成立、效力悬而未决**的一种**中间状态**——既非有效、也非无效，须经**有追认权人**（§145 法定代理人 / §171 被代理人）补正才终局化。进入这个状态的**只有两类典型**：①限制行为能力人非纯获利益且不相适应的合同（§145）；②无权代理（§171·§503）。**无权处分已被 §597 摘出（合同有效，待定的只是物权变动）**。本模型主攻"**这个状态本身**"——谁能进、4 种出口、与无效 / 可撤销 / 未生效 / 有效的边界，以及主观题第二步怎么定位。
>
> 🔗 **与 [[民法-合同-追认模型]] 的分工**：追认 / 拒绝 / 催告 30 日 / 善意撤销这套**机制四要素**的细节（形成权 / 溯及力 / 默示 vs 沉默 / 款号 §171Ⅱ·§145Ⅱ / 表见代理 §172 无需追认 / 追认权与撤销权并存）全部在 [[民法-合同-追认模型]] 讲透，本页只在"4 种归宿"处一句话带过、不整段重复。
>
> 🔎 **三处核实纠正点（务必内化，勿照抄旧表述）**：
> ① **"效力待定"是学理通说术语，民法典无此逐字明文用语**：§145 言"经法定代理人同意或者追认后有效"、§171 言"未经被代理人追认……对被代理人不发生效力"，"效力待定"四字系学理 / 体系解释命名。表述须标"学理通说"，勿伪称"§X 规定'效力待定'"。
> ② **无权代理拒绝追认的精确效果是"对被代理人不发生效力"（§171），不是笼统"合同无效"**：这是《民法典》§171 与旧《合同法》§48 的细微但要命的区别——合同在本人与相对人间确定地不对本人生效，行为人另对善意相对人负无权代理责任（§171Ⅲ）。答主观题写"对被代理人不发生效力"，不写"自始无效"。
> ③ **"仅此两类"宜表述为"最典型 / 主要两类"**：就合同而言，§145 限制行为能力人合同 + §171 无权代理合同确为效力待定两大典型（法考通说二分），但严格说担保制度司法解释下若干场景、§551 债务承担经债权人同意前等亦被部分学说归入广义效力待定，绝对化"仅两类"易被反例攻破。**§597 无权处分摘出这一点则完全正确、是必考对比点，务必保留并强调旧《合同法》§51 已被取代。**

## 二、什么是效力待定（这个"状态"的特征）

| 维度 | 要点 | 依据 / 提醒 |
| --- | --- | --- |
| 命名 | **学理通说术语**，法典无此四字明文 | §145 / §171 只写"追认后有效""对被代理人不发生效力"（纠正点①） |
| 已成立 | 合同**已成立**（合意 + 形式齐备），不是"没合同" | 与"未成立 / 缔约过失"分阶段，别混 |
| 效力悬置 | 当前**既非有效、也非无效**，是会终局化的**中间状态** | 终将朝某一终点收口：追认→有效 / 拒绝→对本人不生效 |
| 命运决定者 | **有追认权人**（§145 法定代理人 / §171 被代理人）的态度 | 决定变量＝"有权第三人的意思表示" |
| 善意相对人保护 | 追认作出前，**善意相对人有撤销权**；任何相对人有催告权（30 日） | 这是效力待定的完整特征之一（旧表述常漏列） |

> 💡 **一句话状态画像**：合同"**先悬着、等老板拍板**"——拍板认（追认）就自始有效，拍板不认（拒绝）就对本人不生效；老板装死满 30 天＝视为不认；相对人善意的还能在拍板前自己撤退。机制细节 → [[民法-合同-追认模型]]。

## 三、哪些情形进入待定（进门名单 + 已被摘出者）

| # | 情形 | 追认人 | 待定的是什么 | 条号 |
| --- | --- | --- | --- | --- |
| ① | **限制民事行为能力人**实施的、**非纯获利益且与年龄智力不相适应**的合同 | 法定代理人 | **合同效力** | §145 |
| ② | **无权代理**（无代理权 / 超越代理权 / 代理权终止后） | 被代理人 | **合同对本人是否生效** | §171（§503 默示追认） |

> ✅ **§145 的分层（务必背）**：限制行为能力人的合同分三档——**纯获利益 / 与年龄智力相适应 → 直接有效**（无须追认）；**其他（不相适应）→ 效力待定**（待法代追认）。只有第三档才进待定区。
>
> 🚫 **§597 无权处分已摘出本名单**：旧《合同法》§51 曾把无权处分合同列为效力待定，《民法典》**已删除**，§597 改采"出卖人未取得处分权致标的物所有权不能转移的，买受人可解除合同并请求承担违约责任"——即**债权合同有效**，待定的只是**物权变动 / 处分权补正**（靠 §311 善意取得或 §209/§224 物权变动规则）。**无权处分追认管物权、不管合同效力，且不写 §503 / 不写旧 §51。** 详见 [[民法-合同-无权处分模型]]。
>
> ⚠️ **"两类"措辞校准**：就**合同**而言 §145 / §171 是效力待定的**最典型、主要两类**（法考通说二分）；严格说担保制度司法解释下若干无权代理场景、§551 债务承担经债权人同意前等亦被部分学说归入广义效力待定，故用"最典型 / 主要"而非"仅此两类"，以免被反例攻破（纠正点③）。

## 四、4 种归宿（机制一句话 + 链接追认模型，不展开）

> 效力待定的状态有**四个出口**，决定它最终收口到哪个终点。机制细节（形成权性质 / 溯及力 / 默示 vs 沉默 / 表见代理 §172 / 追认权与撤销权并存）全在 [[民法-合同-追认模型]]，此处仅给状态归宿。

| 出口 | 谁 · 做什么 | 状态归宿 | 条号 |
| --- | --- | --- | --- |
| **① 追认** | 有权人事后认可（明示或§503默示） | → **自始有效**（通说溯及） | §145 / §171Ⅰ；§503 默示 |
| **② 拒绝** | 有权人明确不认 | → 限制行为能力合同不生效 / 无权代理"**对被代理人不发生效力**"（**非"自始无效"**，纠正点②） | §171Ⅰ |
| **③ 催告 30 日未表示** | 任何相对人催告，有权人 30 日内不表态 | → **视为拒绝追认**（≠默认同意！最毒反向陷阱） | §171Ⅱ / §145Ⅱ |
| **④ 善意相对人撤销** | 善意相对人在追认前以通知方式撤销 | → 合同消灭，相对人退出；**追认后撤销权消灭** | §171Ⅱ / §145Ⅱ |

> ✅ **款号已校正**：§171 的"催告 30 日 / 视为拒绝 / 善意撤销"三项**同在第二款 §171Ⅱ**；§145 对应在 §145Ⅱ。**催告权属任何相对人；撤销权专属善意相对人。** 四要素的生活实例、默示 vs 沉默红线、表见代理分水岭 → [[民法-合同-追认模型]]。

## 五、🔑 与四邻的区分大表（效力待定的本职考点）

> 这是本模型的**增量核心**。命题人最爱把"效力待定"和它的四个邻居互相错安。一把钥匙三问：**谁决定命运？能不能救活？用什么权利？**

| 维度 | **效力待定** | 无效 | 可撤销 | 未生效 | 有效 |
| --- | --- | --- | --- | --- | --- |
| 典型条号 | §145 / §171·§503 | §144 / §146 / §153 / §154 | §147-§151（除斥期 §152） | §158 / §160 / §502Ⅱ | §143 |
| 合同已成立？ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 当前是否有效？ | ❌（悬置·待决） | ❌（确定·绝对） | ✅（撤销前有效） | ❌（暂时·待条件 / 批准） | ✅ |
| **谁决定命运** | **有权第三人**（法代 §145 / 被代理人 §171 / 权利人 §503 物权） | 法律直接评价，**无人能救活** | **受损方**（单方） | 客观事实（条件 / 期限）或行政行为（批准） | — |
| **用什么权利** | **追认权**（未表示视为拒绝） | — | **撤销权**（过期失权） | 条件成就 / 期限届至 / 获批准 | — |
| 能否救活 | 追认→有效 | **永远无效** | 不撤→确定有效 | 条件 / 期限 / 批准成就→自动生效 | — |
| 救活后效果 | 自始有效（通说溯及） | 不可能 | 不撤即有效 / 撤则自始无效（§155） | 生效时起向后生效 | — |

### 5.1 无效区（§144 / §146 / §153 / §154）—— 自始绝对无效，无人能追认救活

- **§144 无民事行为能力人**实施（注意：是"**无**民事行为能力人"完全无能力，**绝不可简称"无行为能力"、更不可与 §145"限制"混淆**——这是最高频反向陷阱）。
- **§146Ⅰ 通谋虚假表示**无效；§146Ⅱ：被掩盖的**隐藏行为**按其真实意思 / 相关法律评价，**不必然无效**。
- **§153 一条两款**：第 1 款违反强制性规定，**但书"该强制性规定不导致无效的除外"** → 须区分**效力性强制性规定（无效）vs 管理性强制性规定（合同有效·仅行政违法）**；第 2 款违背公序良俗。**违反管理性规范的合同不无效，别误判。**
- **§154 恶意串通**损害他人合法权益无效。
- 详见 [[合同无效]]。

### 5.2 可撤销区（§147-§151）—— 撤销前有效，命运由受损方掌握

- 五情形：§147 重大误解 / §148 欺诈 / §149 第三人欺诈（对方知道或应知才可撤）/ §150 胁迫（含第三人胁迫亦可撤）/ §151 显失公平。
- **撤销权专属受损方**，须**请求人民法院或仲裁机构撤销**（形成诉权，非自行通知即可），过除斥期间失权。
- 与效力待定的对照：**待定＝有权第三人追认（未表示视为拒绝）；可撤销＝受损方单方撤销（过期失权）**；待定撤销前效力悬置、可撤销撤销前已生效。
- 详见 [[合同可撤销]] · [[民法-合同-合同可撤销模型]]。

> ⚠️ **两套"撤销"别混**：效力待定中善意相对人的撤销权 / 无权代理相对人催告是"**以通知方式**作出"；可撤销合同的撤销须"**请求法院 / 仲裁**"。两个"撤销"性质不同。

### 5.3 未生效区（§158 / §160 / §502Ⅱ）—— 已成立暂不生效，靠条件 / 期限 / 批准

- **§158 附生效条件**（条件成就时生效）；**§160 附生效期限**（期限届至时生效，**附期限本条是 §160 不是 §158**）；**§159** 不正当阻止条件成就视为已成就 / 不正当促成视为不成就。
- **§502Ⅱ 报批合同**：未办批准等手续影响合同生效的，不影响合同中**报批义务条款及相关条款（含争议解决条款）的效力** → "报批义务条款独立有效"。
- 与效力待定的对照：二者均已成立、均当前未生效，但**未生效靠条件 / 期限 / 批准这类客观事实或行政行为，效力待定靠有权第三人追认这一意思表示**——决定变量不同。
- ⚠️ **经典陷阱**：不动产**未登记 ≠ 合同未生效**（登记是物权变动要件，非合同生效要件）；债权转让**未通知 ≠ 效力待定**（通知即对债务人生效，不需债务人同意）。
- 详见 [[合同未生效]]。

### 5.4 有效区（§143）—— 三要件齐备

合同**有效**须同时满足：①行为人具相应民事行为能力；②意思表示真实；③不违反法律行政法规强制性规定、不违背公序良俗。**效力判断务必正面写明 §143 三要件作起点。**

## 六、不可追认区（§144 无民事行为能力人一律无效）

> §144 逐字："**无民事行为能力人实施的民事法律行为无效**"——文本**无任何例外**（不区分是否纯获利益、是否与智力相适应），故**一律绝对无效，根本进不了效力待定、谈不上追认**。

| 行为人 | 处理 | 条号 |
| --- | --- | --- |
| **无民事行为能力人**（不满 8 周岁 / 完全不能辨认自己行为的成年人） | **一律无效**，纯获利益也无效，**不可追认** | §144 |
| **限制民事行为能力人** | 纯获利益 / 相适应→直接有效；其他→**效力待定**（可追认） | §145 |

> 📌 **临界对照（[[C1-单选-67 · 行为能力分龄与受赠效力|C1-单选-67]] 标杆）**：7 岁（无行为能力）受赠口琴即使纯获利益**也无效**（§144）；9 岁 / 15 岁（限制行为能力）受赠钢琴 / 小提琴纯获利益**直接有效**（§145，无须法代追认）。钥匙＝"纯获利益"能救 §145、救不了 §144。
> 🔖 旁注：学理上申卫星等曾主张无行为能力人纯获利益行为亦应有效，属**立法论批评**，非现行法解释论，法考仍以 §144 文本"一律无效"为准。

## 七、主观题第二步"效力判断"五选一定位

> 主观题案例分析第二步＝**效力判断**，主流采**五分法**（有效 / 无效 / 可撤销 / 效力待定 / 未生效）。"效力待定"在其中的定位是**行为能力欠缺（限制档）或代理权欠缺时的归宿**。务必写明依据条号。

**得分排除顺序（建议语序）**：
1. **先 §143 正面检验有效三要件**（行为能力 + 真实意思 + 不违法不违背公序良俗）；
2. **欠缺行为能力** → 查是"**无**"（§144 无效）还是"**限制**"（§145 → 纯获利益 / 相适应即有效，否则**效力待定**）；
3. **意思表示不真实** → 区分"**通谋虚假 / 恶意串通**"（§146 / §154 无效）与"**误解 / 欺诈 / 胁迫 / 显失公平**"（§147-151 可撤销）；
4. **违法** → 查**效力性 vs 管理性**强制性规定（§153）；
5. **最后查是否仅"未生效"**（附条件期限 §158 / §160、报批 §502Ⅱ）。
6. **特殊**：无权代理 → **效力待定**（§171，定位在第 2 步代理权欠缺侧）；⚠️ **无权处分 → 合同有效**（§597，**不进待定 / 不进未生效**，待定的只是物权变动）。

> 📍 **效力待定在排除链中的两个落点**：行为能力欠缺且"限制档不相适应"（§145）、代理权欠缺（§171）。判定后接 4 种归宿（第四节）→ [[民法-合同-追认模型]]。

## 八、易混 · 三组高频错安（A 级背诵）

| 易混对 | 一句话切开 | 条号 |
| --- | --- | --- |
| **效力待定 vs 无效** | 待定能被追认救活；无效自始确定、无人能救（尤其 §144"无"vs §145"限制"、违法 §153"无"vs 待定） | §145/§171 vs §144/§153 |
| **效力待定 vs 可撤销** | 待定＝有权第三人追认（未表示视为拒绝）；可撤销＝受损方撤销（过期失权、撤销前已有效） | §171 vs §147-151 |
| **效力待定 vs 未生效** | 待定靠"追认"（意思表示）；未生效靠"条件 / 期限 / 批准"（客观事实 / 行政行为） | §171 vs §158/§160/§502Ⅱ |

**两套数字别混**（详见 [[民法-合同-追认模型]]）：效力待定**催告 30 日**（未表示视为拒绝，§145Ⅱ/§171Ⅱ）vs 可撤销**除斥期间**（一般 1 年 / 重大误解 90 日 / 胁迫自终止起 1 年 / 最长 5 年兜底，§152）。

**两个"同意 / 追认"别混**：免责债务承担须债权人**同意**（§551，生效要件），≠ 效力待定的**追认**；债权人单方催讨更不是同意（[[合同通则-单选-52|C1-单选-52]] 甄别）。

## 九、命题人最爱的陷阱（状态视角）

1. **把"无效 / 违法 / 无权处分 / 债权转让未通知"错塞进"效力待定"** —— 反向干扰最常见（[[合同通则-单选-28]] / 55、[[典型合同-单选-29]]、[[C1-单选-61 · 无资质施工与强制性规定|C1-单选-61]]）。
2. **§144"无行为能力人"误当 §145"限制" → 误判可追认** —— 无行为能力人一律无效不可追认。
3. **无权处分要权利人追认合同才有效** —— 错！§597 合同本就有效，追认管物权变动（旧 §51 已废）。
4. **拒绝追认 = "自始无效"** —— 无权代理拒绝追认是"**对被代理人不发生效力**"（§171），不是自始无效。
5. **"催告后不回复 = 默认同意"** —— 恰相反，§145Ⅱ/§171Ⅱ 明文"视为拒绝追认"。
6. **"有授权 = 还要追认 / 还是效力待定"** —— 有授权即非无权代理、不进待定（[[C1-单选-62 · 代理人收回扣与恶意串通|C1-单选-62]]）。
