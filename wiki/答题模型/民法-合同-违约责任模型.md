# 📐 违约责任 · 总模型（违约救济总调度——五种责任方式怎么选）

> **核心一句**：
> 
> 违约责任是合同救济的"**交通枢纽**"——违约发生后，把你导向正确的救济出口（继续履行 / 补救 / 赔偿 / 违约金 / 定金），每个出口给一句**判别口径 + 指针**；具体怎么走，交给子模型。本模型**独占**的是目前没有专门子模型的"无主线"：**继续履行 §579/§580、可预见 §584、减损 §591、过失相抵 §592、第三人原因 §593、归责原则**。
> 
> 🔎 **三处务必内化**：
> ① **违约责任 = 严格责任（无过错）**，与侵权"过错责任"方向相反（§577；"严格责任"是法理定性，**条文本身无"过错"二字**，勿说"§577 明文规定无过错")。例外：赠与 §662、无偿保管 §897 等无偿合同对债务人采过错责任。
> ② **能并 / 不能并**：继续履行 + 赔偿损失**可并存**（§581）；违约金与定金**二选一**（§588Ⅰ）；解除 + 赔偿损失**可并存**（§566）。
> ③ **继续履行被排除 ≠ 免责**——非金钱债务即便落入 §580Ⅰ 三除外不能强制履行，违约方**仍须赔偿损失**。

## 一、核心考情（含考频 + 机构研判免责）

> ⚠️ **考频免责声明**：司法部自 2018 年法考改革起，官方**仅公布大纲、合格分数线、成绩，从不公开历年真题原题及任何"考点频次"统计**。下列"高 / 中频""核心"均系厚大 / 瑞达 / 众合等机构据**学员回忆卷**研判，**非官方一手数据**，不得伪造频次。可溯源的定性：违约责任是机构公认的**合同编最高频核心模块之一**（继续履行 / 赔偿 / 违约金 / 定金 / 解除几乎每年客观＋主观都考）。

- **命题核心**：给一段违约情节，问"守约方有哪些救济 / 能不能解除 / 赔多少 / 违约金能不能砍 / 第三人捣乱谁担责"。考点全在**把五种责任方式各自的适用前提与能否并用切清**。
- **三大必考维度**：①**继续履行**金钱(§579) vs 非金钱(§580 三除外) ②**损害赔偿**三把尺（可预见 §584 / 减损 §591 / 过失相抵 §592Ⅱ）③**归责原则**严格责任 + 第三人原因 §593 不免责。
- **考查形态**：客观题案例选择为主；主观题作请求权基础分析的主线（"守约方得向违约方主张……"）。

## 🧭 速判框架：是不是违约 → 违约还是侵权 → 怎么处理（考场速查）

> 拿到一段履行情节，按"**判定 → 定性 → 选救济**"三关走。本节是**一页速查**，细则见下方各节。

### 1. 怎么判断"这是违约"（三问 + 一个底层逻辑）
- **一问 有没有有效合同？** 无效 / 未成立 → 不是违约（可能落 **缔约过失 / 侵权 / 不当得利**）。
	- **欺诈是特例——受欺诈方有"选择权"，不是非黑即白**：一方以欺诈手段促成合同（如以次充好、隐瞒瑕疵），受欺诈方可以**二选一**：①行使撤销权（§148/§149），合同**自始无效**，走返还 + 缔约过失赔偿（→ [[民法-合同-无效撤销返还模型]]）；②**不撤销**，把欺诈内容（如货物不合格）当成**瑕疵履行**来主张**违约责任**（继续履行/减价/赔偿）。两条路**互斥**——一旦行使撤销权，合同关系消灭，就不再有"违约"可言；没撤销、合同仍有效，才谈得上违约。做题先看题干问的是"撤销"还是"违约责任"，别把二者混用。

- **二问 有没有合同义务没做到？** 义务 = **约定主给付** + **法定从给付 / 附随义务**（妥善保管、按约定方法使用、通知协助保密、完好返还…）。
	- 根据《民法典》第577条，违约的定义是：**不履行合同义务，或者履行合同义务不符合约定。造成违约的行为主要有以下三种
		1. 根本不履行（拒绝履行 / 履行不能） 直接耍赖或者由于客观原因做不到。
			- **履行拒绝**：合同签了，到了交房日子，卖方直接说“我不卖了，也不给你钥匙”。
			- **履行不能**：在交房前，房子因为地震塌了（虽然是不可抗力可免责，但也属于客观不履行），或者卖方一房二卖已经过户给了别人，导致无法给你过户。

		2. 履行得不好（迟延履行 / 瑕疵履行）做是做了，但打折了。
			- **迟延履行**：合同约定 10 号交房，卖方拖到 30 号才交。
			- **瑕疵履行（质量不合格）**：交了房，但漏水严重；或者交了货，但货物有破损。

		3. 违反附随义务（协助、通知、保密等）虽然交了房，但没做好配套工作。
			- **不配合登记**：签了抵押合同，但**不配合银行去办抵押登记**。这属于违反了“协助义务”，构成违约（如多选-20）。
			- **不通知**：转让抵押物时没有“及时通知”抵押权人（虽然不影响买卖效力，但构成对抵押合同中法定通知义务的违反）。
			- **三问 有没有免责事由？** 行使抗辩权中止（§525-528）、意外灭失走**风险负担**、**不可抗力**（§590）→ 这些**不构成违约 / 可免责**。
			
- **底层逻辑**：违约是**严格责任**——客观上"没履行 / 不符约定"即成立，**不问过错**（§577）；这是与侵权（过错责任）的总开关。

### 2. 违约 vs 侵权：就看一句话
> **有合同、违反的是合同义务 → 违约；没合同（违反"不得侵害他人"的法定义务）→ 侵权。**
- 同一行为对**同一人**可竞合（§186 二选一，→ [[民法-合同-责任竞合模型]]）；对**不同人**分别定性（如转租：承租人对出租人**违约** §711/§716、次承租人对出租人**侵权** §1165）。

### 3. 违约长什么样——4 种形态（认出来就好判）
> 例：老王卖二手车给小李，车价 10 万，约定 9/1 交车。

| 形态 | 表现 | 老王小李例（卖二手车，9/1 交车） |
|---|---|---|
| 拒绝履行 / 履行不能 | 根本不给 / 给不了 | **拒绝**：老王到期说"不卖了"拒交车；**不能**：老王把车又卖给老张并过户 → 对小李交车已**履行不能** |
| 迟延履行 | 该给的晚给 | 老王拖到 9/20 才把车交给小李（晚交 19 天） |
| 不完全 / 瑕疵履行 | 给了但不合约定（瑕疵 / 加害给付） | 交的车是**调表 / 事故车**（质量瑕疵）；若因刹车故障致小李开车受伤＝**加害给付** |
| 预期违约（§578） | 履行期**前**明示 / 以行为表明不履行 | 8/15 老王就告诉小李"涨价了不卖你了"（**明示**）；或 8/15 把车挂高价另卖（行为表明＝**默示**） |

### 4. 判为违约后——处理方式 5 + 1（细则见下「五种责任方式全景」+「万能五步模型」）
- ① 继续履行（§579 金钱恒可 / §580 非金钱三除外）② 补救措施（§582）③ 赔偿损失（§584 + §591 + §592）④ 违约金（§585）⑤ 定金（§586-588）（+）解除（§563 根本违约）。
- **能否并用**：继续履行 **+** 赔偿 ✅ 可并（§581）｜ 违约金 **/** 定金 ❌ 二选一（§588）｜ 解除 **+** 赔偿 ✅ 可并（§566）｜ 继续履行 **/** 解除 ❌ 互斥。

**老王小李例（车价 10 万 · 小李已交定金 1 万 · 约定违约金 1 万 · 9/1 交车，老王违约）**
- ① **继续履行**：车还在老王手里、没卖别人 → 小李可请求**老王继续交车**（§580，不属三除外）；反过来若小李欠尾款，老王可请求**继续付款**（§579 金钱恒可）。
- ② **补救措施**：车交了但空调 / 刹车有瑕疵 → 小李可请求**修理**或**减价**（§582）。
- ③ **赔偿损失**：老王不交车，小李被迫**另买同款多花 2 万** → 可请求老王赔这 **2 万差价**（§584，受可预见 + 减损约束）。
- ④ **违约金**：依约老王付**违约金 1 万**；若约得**过分高于损失**（超 30%），老王可请求酌减（§585）。
- ⑤ **定金**：小李已交 **1 万定金** → 老王违约**双倍返还 2 万**（§587，须"致不能实现合同目的"才罚）；与违约金**二选一**（§588）。
- （+）**解除**：老王把车卖给老张、对小李交车已不能＝**根本违约** → 小李可**解除合同 + 并请求赔偿**（§563 / §566）。

### 5. 考场套用口诀
> **一问有效合同、二问义务做没做到（严格责任不看过错）、三问有无免责** → 定了违约开"五个出口"：**能继续履行就继续 → 不能就补救 / 赔偿 → 看有没有违约金 / 定金（二选一）→ 够根本违约就解除（解除还能并赔）**。

## 二、五种责任方式全景（§577 / §578）

> 一行为违约，**最多五种**承担方式（解除是"合同终止"板块、不在 §577 五方式内，但根本违约时可叠加）。

| 责任方式 | 条文 | 一句话适用前提 | 能否并用 | 归哪个模型 |
|---|---|---|---|---|
| ① **继续履行**（实际履行） | §579 金钱 / §580 非金钱 | 金钱恒可；非金钱过 §580 三除外 | 与赔偿**可并**（§581） | **本模型独占** |
| ② **采取补救措施** | §582 | 瑕疵履行：修理/重作/更换/退货/减价/报酬 | 与赔偿可并 | **本模型** |
| ③ **赔偿损失** | §584(+§591/§592/§593) | 造成损失即可，受可预见封顶 | 与①②可并、与④⑤不重复填补 | **本模型独占** |
| ④ **违约金** | §585 | 有约定；补偿为主 | 与定金**二选一**（§588） | 细算 → [[民法-合同-违约金模型]] |
| ⑤ **定金** | §586-588 | 实践合同+20%上限+不能实现目的才罚 | 与违约金**二选一** | 细算 → [[民法-合同-定金模型]] |
| （+）**解除** | §562-566 | 根本违约 / 约定 / 协议 | 解除 + 赔偿**可并**（§566） | 细算 → [[民法-合同-解除模型]] |

## 三、万能五步模型

### 第〇步（前置过滤）：先确认"真的构成违约"

#### **铁则**：救济之前先排除三种"其实不构成违约 / 不归违约责任"的情形——

- **有无履行抗辩权阻却**：互负债务中行使同时 §525 / 后履行 §526 / 不安 §527-528 抗辩的，**中止履行不构成违约** → [[民法-合同-履行抗辩权模型]]。

- **是否属意外毁损灭失（无人违约）**：标的物意外灭失走**风险负担**，与违约责任是并列两条线（§611 风险移转不影响违约追责）→ [[民法-合同-风险负担模型]]。

- **归责原则**：违约责任**严格责任**为原则（§577，**不问过错**），过错责任为例外（赠与 §662 / 无偿保管 §897 / 无偿委托等）；**不可抗力 §590** 可部分 / 全部免责，但**迟延后**发生不可抗力**不免责**（§590Ⅱ），金钱债务等"法律另有规定除外"。

> 🏠 **实际案例**：① **不可抗力 ≠ 一律免责**——[[C1-单选-75 · 不可抗力不免金钱债务|C1-单选-75]]：抵押房被**洪水冲毁**（不可抗力），但**金钱借款债务不能免除**（§590"法律另有规定除外"，金钱无履行不能）。② **抗辩阻却**——[[典型合同-多选-18]]：先付款方查知对方可能交不出货，**行使不安抗辩中止付款，不构成违约**，根本不进违约责任。

### 第一步：能否"继续履行"（本模型核心独占线 · §579/§580/§581）

**铁则**：
1. **金钱债务（§579）→ 恒可请求继续履行**——价款 / 报酬 / 租金 / 利息，"金钱无履行不能"，债务人**不得以资金困难抗辩**，**无任何 §580 除外**。
2. **非金钱债务（§580Ⅰ）→ 原则可请求，但三除外**（逐字记）：
   - ① **法律上或事实上不能履行**；
   - ② 债务**标的不适于强制履行 _或_ 履行费用过高**（"或"——择一即可）；
   - ③ 债权人**在合理期限内未请求**履行。
3. **§580Ⅱ 合同僵局（民法典新增）**：有上述除外致**不能实现合同目的**的，**违约方**可请求**法院 / 仲裁机构终止**合同——⚠️是**司法终止**，**违约方无单方解除权**（区别于 §565 守约方解除）；终止后**不影响违约责任**。
4. **§581 替代履行（新增）**：债务**根据性质不得强制履行**的（非人身专属、可由他人完成），守约方可请求由**第三人替代履行，费用由违约方负担**。

⚠️ **继续履行被排除 ≠ 免责**：落入 §580Ⅰ 三除外后，转入第二 / 三步求补救、赔偿。
⚠️ **措辞别张冠李戴**：§581"根据债务的**性质**不得强制履行" vs §580Ⅰ(二)"标的**不适于**强制履行"——两条近义易混。

> 🏠 **实际案例**：① **事实不能 → 排除继续履行**——[[C1-多选-43 · 一房二卖与违约金酌减|C1-多选-43]]：甲一房二卖、房**已过户给丙**，乙再要求"继续履行把房给我"已属**事实不能**（§580Ⅰ①）→ 只能转违约赔偿。② **金钱债务恒须履行**——[[典型合同-多选-24]]：供热户**欠费** = 金钱债务，无"履行不能"，供热方只能催告后中止供应、用户仍负违约责任（§579）。

### 第二步：瑕疵履行的"补救措施"（§582）

**铁则**：履行不符约定（瑕疵 / 不适当履行）→ 先按**约定**；约定不明且依 **§510**（解释 / 补充）仍不能确定 → 受损害方依标的性质与损失大小**合理选择**：**修理、重作、更换、退货、减少价款或报酬**（六类）。⚠️是"**合理**选择"非任意选择；别漏 **§510 兜底**这一环。

> 🏠 **实际案例**（[[合同通则-单选-48]]）：卖方交了机器却**没附说明书**——属**从给付义务的轻微瑕疵**，够不上根本违约，买方**不能解除**，只能请求**补救**（补交 / 修理，§582）。"瑕疵但能救"就走补救出口，别张口就要解除。

### 第三步：算"赔偿损失"——三把尺（本模型核心独占线 · §584/§591/§592/§593）

**铁则**：
- **范围 + 可预见封顶（§584）**：赔偿 = 实际损失 **+ 可得利益**（完全赔偿）；但**不超过违约方"订立合同时"预见 / 应预见的损失**。⚠️预见**时点是订约时（非违约时）**、**主体是违约方**、只需预见损失**类型**非具体数额。
- **减损规则（§591）**：守约方**应采取适当措施防止损失扩大**；未减损 → **扩大部分不赔**（原有损失仍可主张）；为减损支出的**合理费用由违约方负担**。
- **过失相抵 / 与有过失（§592Ⅱ，新增）**：守约方对损失**发生**有过错 → **可减少**赔偿额。⚠️与 §591 减损（损失**扩大**）是**两个独立规则、两个条款**，最爱张冠李戴。
- **双方违约（§592Ⅰ）**：各自承担相应责任（**各担其责，非相互抵销**）。
- **损益相抵（法理，民法典无独立条号）**：同一违约既受损又获利 → 赔偿额**扣除所获利益**。⚠️**民法典无专条**，依 §584 完全赔偿原则 + 司法解释，**切勿臆造条号**。
- **第三人原因违约（§593）**：因第三人原因违约的，**仍应向对方承担违约责任**，再依其与第三人间法律关系 / 约定**追偿**。⚠️合同相对性——**不得以"第三人原因"对守约方免责**，也勿与 §590 不可抗力混。

> 🏠 **实际案例**：① **可预见 / 替代成本**——[[合同通则-单选-34]]：约定"钢琴辅导抵租"，乙寒假**擅自离开一个月** = 违约，甲花 **2000 元请人补课** → 赔偿 = 守约方**实际替代支出 2000 元**（§584 填补实损，非按市场价虚高）。② **第三人原因**——[[合同通则-单选-45]]：余某的**履行辅助人**朱某闯祸致损 → 视为**余某自己违约**，先对相对人担责、再向朱某追偿（§593），不得拿"第三人"对守约方免责。

### 第四步：有约定"违约金 / 定金"→ 走约定救济（指针子模型）

**铁则**：
- **违约金（§585）**：约定优先、**补偿为主**；约定**过分高于**损失（司解口径**超 30%**）→ **违约方可"请求"**法院 / 仲裁**酌减**（法院不主动调）；低于损失可请求增加；**迟延履行**违约金**支付后仍须继续履行**（§585Ⅲ）。细算 → [[民法-合同-违约金模型]]。
- **定金（§586-588）**：**实践合同**（交付才成立）+ **20% 上限**（超过部分不产生定金效力）+ 罚则须"**致不能实现合同目的**"才触发（§587，**单款无款号**）；**定金 / 违约金二选一**（§588Ⅰ，**守约方选**），定金不足可**补差**（§588Ⅱ）。细算 → [[民法-合同-定金模型]]。
- ⚠️ 违约金与定金**不并用**（择一）；但"选定金 + 就超出定金的损失另请求赔偿"（§588Ⅱ）**不矛盾**。

> 🏠 **实际案例**（违约金"砍不砍"对照）：① **不砍**——[[C1-单选-72 · 违约金未超损失30%照约付|C1-单选-72]]：违约金 18 万 / 损失 15 万，**未"过分高于"**（红线 = 损失×130% = 19.5 万）→ **照约付**、不再另赔。② **砍**——[[典型合同-多选-16]]：违约金 1 万 / 价款仅 6000，**过分高于** → 违约方可**请求**法院酌减（§585Ⅱ，不能自行少付）。③ **定金择一**——[[C1-不定项-01 · 定金上限与择一适用|C1-不定项-01]]：又约违约金又约定金，守约方**二选一**不并用（§588）。

### 第五步：违约严重到"根本违约"→ 可叠加解除（指针子模型）

**铁则**：
- **根本违约 / 法定解除（§563Ⅰ）**：

	- (一)不可抗力致目的不达；
	- (二)预期违约；
	- (三)迟延主要债务+**催告**后合理期未履（**催告解除，不要求目的不达**）；
	- (四)迟延或其他违约**致不能实现合同目的**（**根本违约，不要求催告**）；
	- (五)法定其他。

- **解除 ≠ 归零**：解除后**仍可请求赔偿损失**（§566Ⅰ）、因违约解除可**追违约责任 / 违约金**（§566Ⅱ）、**担保责任不当然消灭**（§566Ⅲ）。
- 解除权来源 §562 / 除斥期间 §564（无约定无规定时**一年**兜底）/ 通知主义 §565（到达解除；径行起诉则**副本送达**时解除）/ 后果 §566 —— 全部 → [[民法-合同-解除模型]]。
- ⚠️ **预期违约两条别混**：请求担责依据 **§578**；解除依据 **§563Ⅰ(二)**。

> 🏠 **实际案例**（[[典型合同-多选-16]]，本模型起源题）：祝某**拒收拒付**致合同目的落空 = **根本违约** → 守约方孟某可**解除**（§563Ⅰ(四)），也可不解除而请求**继续付款**。⚠️ 解除 ≠ 归零——再看 [[合同通则-多选-16]]：煤含硫不能燃烧 = 根本违约，解除采**通知到达主义**（§565），且解除后**仍可并请求赔偿损失**（§566）。

## 四、守约方 / 违约方 权利归位（主体别张冠李戴）

| 谁 | 能干什么 |
|---|---|
| **守约方** | 请求继续履行（§579/§580）、补救（§582）、赔偿损失（§584）、违约金 _或_ 定金**择一**（§588）、根本违约时**解除**（§563）；解除后仍可索赔（§566） |
| **违约方** | 多为义务方，但有三项"主动权"：①**请求酌减违约金**（§585Ⅱ，须请求法院）②**合同僵局申请司法终止**（§580Ⅱ，**非解除权**）③**不可抗力免责**（§590，迟延后不免） |
| **相对人 / 第三人** | 第三人原因违约由**违约方**对守约方担责再追偿（§593）；向第三人履行中只有**合同当事人**可追违约 / 解除（§522/§523 另议） |

> ⚠️ 三大主体陷阱：**酌减 = 违约方"请求"权**（非守约方、非法院主动）；**解除 / 继续履行 = 守约方权利**；**催告 = 相对人**。

## 五、命题人最爱的 10 个陷阱（综合，子模型陷阱另见各模型）

1. **归责原则对调** —— 违约责任**严格责任**、侵权**过错责任**，方向相反；且 §577 条文无"过错"字样。
2. **金钱债务也能"履行费用过高"拒付** —— 错！§579 金钱债务**无任何除外**，资金困难不抗辩（§580 三除外只管非金钱债务）。
3. **可预见时点记成"违约时"** —— 错！是**订立合同时**、主体是**违约方**（§584）。
4. **减损 §591 ↔ 过失相抵 §592Ⅱ 混** —— 损失"**扩大**"不防止 = §591；对损失"**发生**"有过错 = §592Ⅱ。
5. **损益相抵臆造条号** —— 民法典**无独立明文**，依 §584 + 司法解释，别编条号。
6. **§580Ⅱ 合同僵局 = 违约方"解除权"** —— 错！是**司法终止**，违约方**无解除权**。
7. **预期违约解除依据记成 §578** —— 错！解除是 **§563Ⅰ(二)**，§578 只是"请求担责"。
8. **§587 定金罚则写款号 §587Ⅰ/Ⅱ** —— 错！§587 **单款无款号**。
9. **"解除即一切归零"** —— 错！解除可**并请求赔偿**（§566），担保责任不当然消灭（§566Ⅲ）。
10. **§581 替代履行 ↔ §580Ⅰ(二) 不适于强制履行 措辞混**；金钱(§579) / 非金钱(§580) 顺序对调。
