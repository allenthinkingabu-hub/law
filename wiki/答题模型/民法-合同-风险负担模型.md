# 📐 风险负担（风险移转）· 答题模型（万能四步）

> 凡"标的物意外毁损灭失、价金风险归谁"题，按这四步走，一步不跳。
> **适用真题**：[[典型合同-单选-03|单选03·买受人迟延受领（核心）]] · [[典型合同-多选-20|多选20·已收货+缺单证]] · [[典型合同-单选-22|单选22·综合题 C 项交付主义]]
> 🔎 **法条核实（2026-06-11，3 路联网 + 对抗复核）**：§604–§611、§598/§599 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对，全部 CONFIRMED。两处**"学理 ≠ 法条"**提醒已在下文标注：①§606 路货"出卖人明知未告知"例外、②受领迟延后"出卖人注意义务降低"——均为学理通说（参照德国法 / CISG），《民法典》无字面明文，答题援用须标"通说"。

## 一、核心考情

- **频率**：典型合同（买卖）头号高频（[[典型合同考点-深度报告]] 第 2 行 ★★★★），客观题常考、主观题买卖纠纷几乎必涉；常与违约责任、不可抗力、所有权保留串考。
- **命题核心**：永远围绕"**风险移转的时点**"——交付主义为轴，4 个特殊场景挪动时点，再用"东西还在谁手上 / 所有权归谁 / 缺几张单证 / 有点小瑕疵"误导你。**不考定义，全考时点 + 三条边界线**。
- **三大必考点**：①交付主义（风险随**交付**、不随所有权）②特殊场景提前 / 改变移转时点 ③三条边界——风险 ≠ 所有权、风险 ≠ 违约责任（§611）、风险移转 ≠ 给付义务无瑕疵。

## 二、万能四步模型

### 第一步：定基准线——"交付了没有"（§604 交付主义）

**铁则**：标的物毁损灭失风险，**交付前出卖人担、交付后买受人担**（§604）。风险随"**交付（占有移转）**"走，**不随所有权**——哪怕出卖人保留所有权 / 不动产未过户，只要交付了，风险就归买受人。

**老王小李例子**
- 老王把车交付小李（钥匙、行驶证都给了），约定下月付清才过户。次日冰雹砸坏车 → **风险已随交付转给小李**（虽未过户），小李照付车款。

### 第二步：套"特殊场景"修正移转时点（4 张牌）

**铁则**：

| 场景          | 法条       | 移转时点         | 一句话抓手           |
| ----------- | -------- | ------------ | --------------- |
| 路货买卖（在途标的物） | **§606** | **合同成立时**    | 货在路上才签约，签完出事买家担 |
| 代办托运 / 需运输  | **§607** | 交付**第一承运人**时 | 货一上物流车，风险就走     |
| 买受人自提却不收取   | **§608** | **违约（没收取）时** | 备好货你不来，过点你担     |
| 买受人原因致未按期交付 | **§605** | **违约时**      | 你的原因推迟，按违约时点你担  |

> ⚠️ **§606 路货的例外要标对出处**：出卖人**订约时明知 / 应知**标的物已毁损灭失却**未告知**的，风险**仍由出卖人**——这是**学理 / CISG 第 68 条**规则，**不是 §606 字面**（§606 原文只有"自合同成立时起由买受人承担，当事人另有约定除外"）。

**老王小李例子**
- 路货 §606：老王把在途的一船煤卖给小李、当场签约 → 风险**自签约时**即归小李，船半路沉了也由小李担。
- 代办托运 §607：小李网购瓷砖，老王（卖家）联系物流、把货交给货车司机 → 物流途中翻车，风险归小李。
- 自提不取 §608（= [[典型合同-单选-03|单选-03]]）：约定当晚自提，小李不来取、当晚暴雨淋毁货 → 风险**自当晚（违约没收取时）**转给小李，即便货还在老王仓库。
- 买受人致迟延 §605（= [[典型合同-单选-03|单选-03]] 另一面）：本可按时交，因小李改期 / 不在 → 风险自**原定交付时**起归小李。

### 第三步：检查"阻断 / 反推"——谁有错，风险偏谁

**铁则**：
1. **质量瑕疵阻断（§610）**：标的物**不符合质量要求致不能实现合同目的**的，买受人可拒收 / 解除，风险**仍由出卖人**承担——根本性瑕疵给付**阻断**风险移转。
2. **出卖人原因致未按期交付**：风险**不转**，继续由出卖人担。
3. ⚠️ **别把"缺单证"当质量瑕疵**：缺产品合格证 / 原产地证明等**从给付单证（§599）**，**不影响**标的物本身可用，**不阻断**风险移转（详见第四步）。

**老王小李例子**
- §610 阻断：老王交的水泥是受潮废品（根本不能用）→ 小李有权拒收，风险**不转**、仍归老王，哪怕已"交付"。
- 出卖人致迟延：老王自己车坏了没按时送 → 这期间货出意外，**老王自担**（该交没交是卖家的错）。
- 对照[[典型合同-单选-03|单选-03]]：乙的水泥**无瑕疵**、还**抢救**了货（无违约无过错）→ 不阻断，风险照转给甲。

### 第四步：三笔账分开算——风险 / 违约责任 / 给付义务层次（§611 + §598/§599）

**铁则**：
- **风险 ≠ 违约责任（§611）**：风险移转给买受人，**不影响**买受人就出卖人的瑕疵 / 违约**另行追责**。货物损失（风险）归买受人 **＋** 违约赔偿 / 补正（责任）追出卖人，两条线并行。
- **给付义务分层（§598 / §599）**：
  - **主给付义务（§598）**：交标的物本身、转移所有权、交"**提取标的物的单证**"（提单 / 仓单，凭它就能提货）。
  - **从给付义务（§599）**：交"提取单证**以外**"的单证资料——产品合格证、质量保证书、原产地证明、发票、使用说明书、保险单等。
  - **判断口诀**：缺了它合同目的还能不能实现？**能 → 从给付；不能 → 主给付**。
- **从给付瑕疵 ≠ 根本违约**：缺从给付单证，**原则上无 §563 法定解除权**，只能请求补正 + 赔偿；**例外**：若从给付违反**致合同目的不达**，仍可解除（保留层次，别写成"一律不得解除"）。
- **受领迟延期间**：出卖人仍负**妥善保管**义务，保管不善致损另担赔偿。⚠️ "受领迟延后出卖人**注意义务降低、仅就故意 / 重大过失负责**"是**学理通说（参照德国法）**，《民法典》**无直接明文**——§589 字面只给两项后果："债权人无正当理由拒收 → 债务人可请求赔偿**增加的费用** + 受领迟延期间**无须支付利息**"。答题援用此规则须标"通说 / 学理"，不可挂某条号。

**📦 例子·受领迟延"注意义务三档"**（先懂这件事：风险虽已转给买受人，但**货还在卖家手里、卖家仍要替你保管**——那卖家保管时该多上心还是少上心？这就是"注意义务"）

> 老王按约把一批 10 万元冷冻海鲜备好、约定 6/1 小李来提；小李无正当理由拖到 6/20 才提。这 20 天货还在老王冷库，**风险已随过期提货转给小李（§608）**。期间海鲜出了损：

| 谁的原因                               | 谁担                                               |
| ---------------------------------- | ------------------------------------------------ |
| **意外**（6/10 雷击停电化了一批，谁都没错）         | **小李**（风险已转）                                     |
| 老王**一般过失**（漏了一次常规巡检的轻微疏忽致损耗）       | **小李**——受领迟延后老王**注意义务降低、只对故意/重大过失负责**，**一般过失不赔** |
| 老王**故意 / 重大过失**（故意拔电源 / 明知制冷坏了仍放任） | **老王**（这部分赔回去）                                   |

> ⚖️ **能挂法条的只有 §589 两项**：①老王这 20 天**多花的冷库电费、保管费**可向小李索回（**增加费用**）；②"受领迟延期间债务人**免付利息**"——这项多用在"**还钱被拒**"（欠债人要还、债主不收，这期间不计息），本例老王不涉付息、用不上。
> 而上表中间那档"**一般过失不赔**"——**民法典没写**，是**学理通说**（参照德国法），答题标"通说"即可，别挂条号。

**老王小李例子**（一条挖掘机故事收尾）
- 老王把二手挖掘机开到小李工地、小李验收签字 → 当晚泥石流冲走 → **风险在小李**（损失自担、货款照付）；
- **同时**老王迟迟不补开发票 / 合格证（§599 从给付）→ 小李**仍可单独告老王违约**，要补开 / 赔偿（§611）——**冲走的损失算小李的，缺的单证算老王的**，两笔账互不相妨。
- 但缺的只是发票合格证（挖掘机能用）→ **非根本违约**，小李**不能退机解约**（§563）；除非老王交的挖掘机**发动机报废开不动**（目的落空）才可解除。

### ⚠️ 易混提示
- **风险移转 vs 所有权移转**：随交付，**不随所有权**（保留所有权 / 未过户照转）。
- **风险负担 vs 违约责任**：§611 两笔账，风险归买受人 ≠ 出卖人免责。
- **从给付瑕疵 vs 质量瑕疵阻断**：缺单证（§599）**不阻断**风险；质量根本瑕疵（§610）**阻断**风险。

## 三、命题人最爱的 5 个陷阱
1. **"东西还在出卖人手上 → 出卖人担风险"** —— 错！买受人违约 / 不收取，风险已**提前**移转（§605 / §608）。
2. **"风险随所有权走"** —— 错！风险随**交付**，与所有权脱钩；保留所有权 / 未过户也照转。
3. **"损失双方均摊 / 按公平分担"** —— 错！风险负担是**全有或全无**，没有"均摊"。
4. **"缺单证 = 没完成交付 = 风险没移转 / 能解约退款"** —— 错！标的物本身交付即移转风险（§604）；从给付瑕疵（§599）非根本违约，不能解除（§563）。
5. **"风险一转移，出卖人就全免责 / 货毁了得补交"** —— 错！§611 买受人仍可追违约责任；交付后标的物已特定化、风险在买受人，出卖人无须补交货物。
