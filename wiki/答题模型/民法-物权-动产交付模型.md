# 📐 动产交付（动产物权变动）· 答题模型（万能四步）

> 凡"动产卖了 / 转了、所有权归谁、能不能要回"的题，按四步走：**认方式 → 定时点 → 善意取得交叉 → 特殊动产竞存**。
> **核心一句话**：动产物权变动靠**交付**（不动产靠登记）；交付有"现实 + 三种观念交付"，**看物在谁手里**定方式、**各自时点**定归属；占有改定是头号坑（约定即转移 + 不适用善意取得）。
> **对照概念** → [[区分原则]]（合同效力 ≠ 物权变动）· [[善意取得]]（§311 与交付的交叉）· [[不动产登记]]（不动产对照）。
> **适用真题**：[[物权编-单选-01|物权-单选-01·简易+占有改定连环→D]] · [[物权编-多选-28|物权-多选-28·占有改定→AC]] · [[物权编-单选-39|物权-单选-39·特殊动产交付优先→B]]。
>
> 🔎 **法条已联网核实（2026-06-15；§224-§228 / §225 两路 gov.cn 逐字 + 占有改定善意取得 / 多重买卖顺位 + 6 条对抗复核全 CONFIRMED）**：依据＝动产物权变动 **§224-§228**（+ 善意取得 §311 / 物权编解释一 §17·§19·§20·§6 / 买卖合同解释 §6·§7）。⚠️ §227/§228 用官方措辞；"占有改定不适用善意取得"为**法考通说**（学理有争议）。

## 一、核心考情

- **频率**：★★★★（客观题）。法大《物权黄金考点》点名"交付 / 多重买卖"；占有改定 + 善意取得是综合题常客。
- **命题核心**：①四方式区分（看占有谁）+ 各自所有权转移时点；②占有改定双坑（约定即转移 + 不适用善意取得）；③特殊动产"交付生效·登记对抗"+ 交付优先于登记。
- **三大必考点**：①简易§226 / 指示§227 / 占有改定§228 的时点；②占有改定不适用善意取得（简可指可占不可）；③特殊动产一物二卖"交付为王"。

## 二、万能四步模型

（老王＝出让人 / 卖方，小李＝受让人 / 买方，老张＝第三人 / 后买受人）

### 第一步：认交付方式 —— 看"物在谁手里"

| 方式       | 触发（物在谁手）                    | 🚗 真实例子（🟦真题原型 / 📘权威教材通例·2026-06-16 联网核实 is_classic 全 true）                                            | 法条   |
| -------- | --------------------------- | ------------------------------------------------------------------------------------------------------- | ---- |
| 现实交付     | 实际移转占有（默认）                  | 📘 菜场买 5 斤菜、当面递到你篮里；店里买冰箱付款搬走（一手交钱一手交货）                                                                 | §224 |
| **简易交付** | **受让人已占有**（先借 / 先租再买）       | 🟦 [[物权编-多选-03]]（2023 金题）：甲把**租给乙**的车、租期满后卖给乙——乙已占有，**合同生效即取得**所有权                                      | §226 |
| **指示交付** | **第三人占有** → 让与"返还请求权"       | 📘 最经典：甲存在**丙仓库**的一批货卖给乙，甲把"**向丙提货的返还请求权（仓单 / 提单）**"让与乙以代交付（§910 仓单背书）                                  | §227 |
| **占有改定** | **出让人继续占有**（卖后自己留用）         | 🟦 [[物权编-多选-28]]（2021 金题）：张某把车卖给王某、约定张某**继续有偿使用 2 个月**，车没动 → **约定生效即归王某**                               | §228 |
| 特殊动产     | 船舶 / 航空器 / 机动车（交付生效 + 登记对抗） | 🟦 [[物权编-单选-39]]：车交付乙、**未过户**；甲又卖丙并登记 → **交付优先**乙得（📘对照：未过户的车被甲抵押给**善意银行**并登记 → 银行善意取得抵押权，这才是"登记对抗"咬人处） | §225 |

> 五方式逐一举例 + 时点 + 善意取得能否，见概念页 [[动产交付]]。
> 🔎 **例子已联网核实（2026-06-16，教材 / 法考机构讲义 / §910 仓单）**：⚠️ 占有改定**别用"售后回租"举例**——纯粹卖后自用是占有改定，但**融资性售后回租**实务多认定为**让与担保**（甚至"名为回租实为借贷"所有权不转移），定性有歧义；用上面"卖后约定继续用一段时间"的干净例（多选-28）。

> 🔑 区分指示 vs 占有改定：**物在第三人手＝指示；物在出让人自己手＝改定**。
> ⚠️ 官方措辞：§227＝"负有交付义务的人**通过转让请求第三人返还原物的权利**代替交付"（可让与的含物权 + 债权两类返还请求权）；§228＝"动产物权转让时，**当事人又约定由出让人继续占有**该动产的，物权自该约定生效时发生效力"。

### 第二步：定所有权转移时点

| 方式            | 转移时点                    |
| ------------- | ----------------------- |
| 现实交付 §224     | 交付时                     |
| 简易交付 §226     | **民事法律行为生效时**（不用再交一次）   |
| 指示交付 §227     | 返还请求权**让与协议生效时**        |
| **占有改定 §228** | **约定生效时**（⚠️不是期满 / 交回时） |
| 特殊动产 §225     | **交付时**（登记仅对抗，非生效）      |

**老王小李**
- 简易：小李借用老王的车期间买下它 → 合同生效即归小李（§226，单选-01 庞→黄）。
- 占有改定：老王把车卖小李、约定老王再用 1 个月 → **约定生效即归小李**，老王成有权占有人（§228，单选-01 黄→洪、多选-28 张→王）。

### 第三步：善意取得交叉 —— "简可、指可、占不可"

**铁则**（§311 + 物权编解释一）：无权处分时——
- ✅ **简易交付 §226、指示交付 §227** → **可**适用善意取得（解释一 §17 设了交付时点）。
- ❌ **占有改定 §228** → **不适用**善意取得（公示未完成；解释一 §17 独缺占有改定）。**法考通说**（学理有四说争议，答题写"不适用"+ 标通说）。
- ❌ **合同无效 / 被撤销** → 不适用（解释一 §20）。
- 特殊动产：**交付即可**善意取得，登记仅对抗（解释一 §19）。
- §311 III：善意取得**参照适用**于其他物权（抵押权 / 质权）。

### 第四步：特殊动产竞存 —— "交付为王"

**铁则**：船 / 航 / 车 = **交付生效（§224）+ 登记对抗（§225）**。
- §225 的"**善意第三人**"**不含**转让人的一般债权人（物权编解释一 §6）。
- **多重买卖顺位**：
  - 普通动产：**先受领交付 ＞ 先付款 ＞ 合同成立在先**（买卖合同解释 §6）。
  - 特殊动产：**先受领交付 ＞ 先登记 ＞ 合同成立在先**；**交付优先于登记**（已交付者优先于仅登记者，买卖合同解释 §7(四)）。
  - （旁注：不动产 先登记 ＞ 先合法占有 ＞ 合同在先——出自八民会纪要，**非司法解释**，别标条号。）

**老王小李**：老王把车交付小李（未过户），又卖老张并过户 → **小李（已交付）优先**，老张的登记不能对抗小李（§7(四)，单选-39 正解 B）。

## 三、命题人最爱的 7 个陷阱

1. **占有改定误以为"期满 / 交回"才转移** —— 实为约定生效时（§228）。
2. **简易交付误以为要再交一次** —— 已占有，合同生效即变动（§226）。
3. **特殊动产登记对抗误当登记生效** —— "没过户 = 没所有权"是错的（§225 交付即生效）。
4. **占有改定能善意取得** —— 不能（缺公示，§228）。
5. **指示 vs 占有改定混淆** —— 看物在谁手。
6. **特殊动产"已登记未交付"误当优先** —— **交付为王**（§7(四)）；误用不动产"登记优先"是高频失分点（单选-39 踩点）。
7. **§225"善意第三人"扩大到一般债权人** —— 不含（解释一 §6）。

## 四、真题演练（套四步模型）

### 范例①：[[物权编-单选-01|物权-单选-01]]（自行车连环转让）→ **D**
庞→黄＝简易交付 §226（黄借用期间买下，合同生效即得）；黄→洪＝占有改定 §228（约定黄继续用 1 个月，**约定生效即归洪**，非 1 个月后）。两次交付均完成 → 庞对黄、对洪均无原物返还请求权。→ **D** ✅（C"1 个月后取得"是占有改定时点陷阱）

### 范例②：[[物权编-多选-28|物权-多选-28]]（豪车未登记抵押 + 占有改定 + 修车留置）→ **AC**
A 动产抵押合同生效即设立（§403）✅；**C 张某约定继续有偿使用 2 个月＝占有改定 §228，王某于约定生效时取得所有权**（"未实际交付不影响取得所有权"成立）✅；B 留置无比例要求（错）；D 留置只看合法占有不看车主（错）。→ **AC** ✅

### 范例③：[[物权编-单选-39|物权-单选-39]]（机动车一车二卖：乙先交付、丙后善意登记）→ **B**
乙已受领交付 → 依 §224 取得所有权；特殊动产**交付优先于登记**（买卖合同解释 §7(四) + 物权编解释一 §6），丙仅登记不能对抗已交付的乙。→ **B** ✅（C"丙登记取得"＝陷阱 6"登记优先"误用）

## 📐 口诀

> 动产变动靠交付，看物在谁手定方式：自己留＝改定，别人占＝指示，受让人已在手＝简易，实际给＝现实。
> 时点：现实看占有，简易合同生效变，指示让与请求权变，**占有改定约定一成就变（不等交回）**。
> 善意取得："**改定无公示取不得，其余三交付善意皆可得**"；合同无效也不得（解释一 §20）。
> 特殊动产船航车：**交付生效、登记对抗**；多重买卖**交付 ＞ 登记 ＞ 合同在先，交付为王**；"善意第三人"不含一般债权人。
