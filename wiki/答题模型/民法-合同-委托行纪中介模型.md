# 📐 委托·行纪·中介 · 答题模型（万能两步）

> 凡"替别人办事 / 牵线 / 代买卖"这类**事务·劳务处理型合同**题，按这两步走，一步不跳。**核心一句话**：三者都是"**替别人办事 + 收报酬**"，胜负全在**第一步定性**——区别只看 **以谁的名义、要不要自己当合同当事人、办的是什么事**；定错性，后面全错（这就是目标真题 [[典型合同-单选-15|Q15]] 的命门）。
> **对照模型** → [[民法-合同-解除模型]]（委托/承揽/物业的"任意解除权" vs §563 法定解除，本页第三部分横向打通）。**姊妹** → [[民法-合同-租赁模型]]（不定期租赁随时解除 §730，同属任意解除家族）。
> **适用真题**：[[典型合同-单选-15|C2-单选-15·三类区分命门]] · [[典型合同-单选-13|C2-单选-13·委托任意解除]] · [[典型合同-单选-14|C2-单选-14·行纪四规则]] · [[典型合同-单选-16|C2-单选-16·中介报酬]] · [[典型合同-多选-13|C2-多选-13·律所随时解除+归责]]
>
> 🔎 **法条已联网核实（2026-06-14 首验 4 路；同日 7 路对抗式复核——28 条 + 易混条号 + 5 真题答案逐条再核）**：依据＝委托 **§919-§936**、行纪 **§951-§960**、中介 **§961-§966**；逐字原文经[最高检官网民法典合同编](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml) + 国家法律法规数据库 flk.npc.gov.cn 双重核对。**复核订正 2 处**：§934"丧失行为能力"主体归属（仅受托人；委托人走 §935 过渡）、§925/§926 拆为"间接代理两条线"（原误并为一行、漏 §925 直接归属）；§730「双方·合理期限通知」、§946「60 日」经复核**确认无误**。
> ⚠️ **两个最易记错的条号**：行纪"费用自负"＝**§952**（§954 是"瑕疵 / 易腐物处置"，别记串）；行纪"介入权"＝**§956**、"高价差归委托人"＝**§955**（二者紧邻，最爱互换）。

## 一、核心考情

- **频率**：典型合同章的"小三章"，★★★，单选每年常出 1 道、多选偶见；主观题里律师代理、代购代卖、房产中介纠纷会带出委托 / 中介规则。
- **命题核心**：①**三类定性**（委托 / 行纪 / 中介，最爱设"看着像委托、其实是中介 / 行纪"的陷阱）；②**委托的双向任意解除权**（§933，全章第一高频）；③行纪"高价差归委托人"、中介"跳单 / 未促成 / 双方均分"等单点规则。
- **三大必考点**：①**三把尺子定性**（名义 / 是否当事人 / 办什么事）②**委托 §933 任意解除 + §929 有偿无偿归责**③**中介报酬三连坑**（促成 / 双方均分 / 跳单）。

## 二、万能两步模型

### 第一步：三把尺子定性 —— 委托？行纪？中介？★全题命门

**铁则**：三者都"替人办事 + 收报酬"，用三把尺子一量就分家——

| 尺子            | [[委托合同]]（§919）         | [[行纪合同]]（§951）   | [[中介合同]]（§961）      |
| ------------- | ---------------------- | ---------------- | ------------------- |
| ① **以谁的名义**   | 委托人名义（受托人＝代理人）         | **以自己（行纪人）名义**   | 谁的名义都不是，只**牵线**     |
| ② **是否合同当事人** | 否                      | **是**（自己作买 / 卖方） | **否**（只报告机会 / 做媒介）  |
| ③ **办什么事**    | 处理事务（**广义**：事实 + 法律行为） | **从事贸易活动**（买卖）   | **报告订约机会 / 提供媒介服务** |
| ④ **报酬**      | 可有偿可无偿                 | **必有偿**          | **必有偿**             |

**三秒决策树**：
- 只是"**报信息 / 拉双方见面**"、自己不签约不办事 → **中介**（旧名"居间"，2021 改名）。
- "**以自己名义**"替别人**买卖货物**、自己当合同一方 → **行纪**。
- 替委托人"**处理事务**"（含以委托人名义对外）→ **委托**。

**老王小李例子**（委托人＝老王，受托人 / 行纪人 / 中介人＝小李，相对第三人＝老张）
- ✅ **中介**：小李**告诉**老王"老张想卖二手车"，老王老张自己谈成、事后给小李辛苦费 → 小李只牵线、非当事人。
- ✅ **行纪**：老王让小李商行"**用小李自己的名义**"把 10 吨大米卖出去 → 小李是买卖合同当事人。
- ✅ **委托**：老王委托小李"**以老王名义**"去签收一批货、办过户 → 小李是代理人、处理事务。

### 第二步：套该类合同的"特色规则"
定性后对号入座，背这三套：

#### A. [[委托合同]] · §919-§936（双向任意解除 + 有偿无偿两条线）
| 规则               | 要点                                                                                                                         | 法条       |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- | -------- |
| **双向任意解除权** ★最高频 | **委托人或受托人均可随时解除**；解除 ≠ 违约（不是 §563 法定解除）                                                                                    | **§933** |
| 解除赔偿范围           | **有偿**：赔对方**直接损失 ＋ 合同履行后可获利益**；**无偿**：赔**因解除时间不当造成的直接损失**；不可归责于解除方的事由除外                                                    | §933     |
| 受托人注意义务 / 归责     | **有偿**＝一般过失即赔；**无偿**＝仅故意或重大过失才赔；**超越权限**造成损失一律赔                                                                            | §929     |
| 转委托              | 原则**须经委托人同意**：经同意 → 受托人**仅就第三人的选任及指示负责**（减责）；未经同意 → 对转委托人行为**全责**，紧急情况为维护委托人利益除外                                           | §923     |
| 报酬               | 完成事务付酬；**因不可归责于受托人的事由**致解除 / 不能完成 → 付**相应报酬**（≠ 全额，也 ≠ 不给）                                                                 | §928     |
| 法定终止             | **委托人死亡 / 终止**、或**受托人死亡 / 丧失民事行为能力 / 终止** → 合同终止（另有约定或性质不宜终止除外）。⚠️"丧失民事行为能力"**只挂受托人**——**委托人**丧失行为能力**不当然终止**，走 §935 过渡    | §934     |
| （配套）委托人侧过渡       | 因委托人**死亡 / 丧失行为能力 / 终止**致合同终止**将损害委托人利益**的，在其**继承人 / 法定代理人 / 清算义务人**接手前，受托人应**继续处理委托事务**                                   | §935     |
| 间接代理①·直接归属       | 受托人以自己名义在授权范围内与第三人订约，第三人订立时**知道**代理关系 → 合同**直接约束委托人和第三人**（但有确切证据证明只约束受托人与第三人的除外）                                           | §925     |
| 间接代理②·披露+介入 / 选择 | 第三人**不知**委托关系 + **受托人不履行义务（共同前提）**：受托人因**第三人**原因对**委托人**不履行 → 披露第三人，**委托人介入权**；受托人因**委托人**原因对**第三人**不履行 → 披露委托人，**第三人选择权** | §926     |

**📎 逐条案例**（✅ 真题 / 🔧 实务）
- **§933 双向任意解除**：✅ [[典型合同-单选-13|单13]] 甲电话取消"委托乙买木材" → 委托人可随时解除（答 C）；✅ [[典型合同-多选-13|多13]] 律所代理中途想退、当事人坚持 → 受托人也可随时解除（答 AC）。
- **§933 赔偿范围（有偿↔无偿）**：🔧 老王**付佣金**委托小李代购钢材、小李已联系好货源，老王临时反悔解除 → 赔小李**直接损失**（白跑的差旅）**＋ 可得利益**（本可挣的佣金）；若小李是**无偿**帮忙，只赔"因解除时机不当"的直接损失。
- **§929 有偿/无偿归责**：✅ **有偿锚点** [[典型合同-多选-13|多13]]（答 AC）D 项"律所只在故意/重大过失才担责"= 错——有偿委托**一般过失即赔**；✅ **无偿锚点（同构）** [[典型合同-单选-11|保管单11]]（答 D）无偿保管、无重大过失 → **免责**（§897 与 §929 姊妹条、归责同构，无偿侧"故意/重大过失才赔"一样适用于无偿委托）。🔧 一句话类比（教学例，非判决）：同是疏忽少卖，无偿帮邻居代卖旧物 → 不赔；收费平台代卖（有偿）→ 要赔。
- **§923 转委托**：✅ **真题锚点** [[典型合同-多选-36|多36]]（1999 律考·答 BD）B 项"经甲同意转委托 → 乙仅就选任及指示负责"= 对，正是 §923 减责。🔧 老王委托小李办过户、小李**擅自**转给老张、老张办砸 → 未经同意，小李对老张**全责**；若老王**事先同意**，小李只担"选错老张 / 指示不当"。
- **§928 相应报酬**：✅ [[典型合同-单选-13|单13]]（答 C）D 项"仍按约定全额付酬"= 错——事务因甲取消而未完成，乙得 §928"**相应报酬**"、损失另依 §933 索赔（两条线别混）。
- **§934 终止 / §935 过渡**：🔧 老王委托律所小李打官司，诉讼中老王**病故** → 原则合同终止（§934）；但开庭在即、终止会损害老王利益的，小李须在老王**继承人**接手前继续办（§935）。若老王**丧失行为能力**（昏迷）→ 不属 §934 当然终止，由其**法定代理人**接手。
- **§925 / §926 间接代理两条线**：🔧 小李受老王委托、**以自己名义**向老张买货——① 老张签约时**知道**是替老王买 → 合同直接约束老王与老张（§925）；② 老张**不知**有老王、后小李因老张迟延而交不出货 → 小李披露老张，老王可直接向老张追（**介入权** §926）；反之小李因老王不付款而违约 → 披露老王，老张可**选择**告小李或老王（**选择权** §926）。
  > ⚠️ **铁则（§926 的发动闸）**：介入权 / 选择权**都以"受托人（小李）不履行义务"为共同前提**——受托人不违约就不穿透；只是再分"对谁不履行 + 因谁的原因"：对委托人不履行（因第三人原因）＝介入权 / 对第三人不履行（因委托人原因）＝选择权。**对照 §925：直接归属"知道就通"、根本不问违约。** 一句话——**§925 知道就通，§926 违约才通。**

#### B. [[行纪合同]] · §951-§960（以自己名义 + 高价差归委托人）
| 规则                     | 要点                                                                  | 法条                 |
| ---------------------- | ------------------------------------------------------------------- | ------------------ |
| 以自己名义                  | 行纪人是合同**当事人**，不是代理人；与第三人订约**自己**直接受权利义务                             | §951               |
| **费用自负**               | 行纪人处理事务支出的费用**自己负担**（除非另有约定）                                        | **§952**（⚠️非 §954） |
| **高价卖 / 低价买 → 利益归委托人** | 高于指定价卖、低于指定价买：可按约定增报酬，无约定 → **利益归委托人**（不是平均分！）；反向（低价卖 / 高价买）须经委托人同意 | §955               |
| 介入权                    | 商品**有市场定价**的，除委托人反对外，行纪人可**自任买受人 / 出卖人**，且仍可请求报酬                    | §956               |
| 直接享有权利义务               | 行纪人与第三人订约 → **行纪人直接**享有权利、承担义务；第三人不履行致委托人受损 → 行纪人赔（另有约定除外）          | §958               |
| 报酬 + 留置权               | 完成 / 部分完成付**相应报酬**；委托人逾期不付 → 行纪人对**委托物有留置权**                        | §959               |
| 兜底                     | 本章没规定的，**参照适用委托合同**                                                 | §960               |

**📎 逐条案例**（✅ 真题 / 🔧 实务）—— §951 / §952 / §955 / §958 四条被 ✅ [[典型合同-单选-14|单14]] 一题打包考
- **§951 以自己名义**：✅ [[典型合同-单选-14|单14]] A 项 乙商行**以自己名义**卖甲的大米 = 行纪（对）。
- **§952 费用自负**：✅ [[典型合同-单选-14|单14]] B 项 乙的销售费用**自己负担**（对）。
- **§955 高/低价差归委托人**：✅ [[典型合同-单选-14|单14]] C 项 乙以高于约定价卖出、无增酬约定 → 差价**全归委托人甲**、不平均分（C"平均分配"= **错**）。
- **§956 介入权**：🔧 老王委托小李行纪卖出**有市场定价**的某型号螺纹钢，小李自己正缺货 → 除老王反对外，小李可**自任买受人**按市场价买下，且仍可收报酬。
- **§958 直接享有权利义务**：✅ [[典型合同-单选-14|单14]] D 项 乙与丙食品厂订约 → **乙直接**享有权利义务、丙找乙不找甲（对）。
- **§959 报酬 + 留置权**：🔧 小李卖完大米、老王迟迟不付报酬 → 小李对**仍在自己手中的委托物**（未卖完的余货）享有**留置权**。

#### C. [[中介合同]] · §961-§966（促成才付酬 + 跳单 + 双方均分）
| 规则           | 要点                                                                                                                   | 法条   |
| ------------ | -------------------------------------------------------------------------------------------------------------------- | ---- |
| 如实报告         | 应如实报告订约事项；**故意隐瞒重要事实 / 提供虚假情况**损害委托人 → **不付酬 ＋ 赔偿**                                                                  | §962 |
| **促成才付酬**    | 中介人**促成合同成立** → 委托人按约付酬；约定不明依 §510 按劳务**合理确定**                                                                       | §963 |
| 媒介双方均分       | 因提供**媒介服务**促成的 → 由**该合同当事人平均负担**报酬（买卖双方都委托同一中介时最常考）。⚠️**边界**：仅限"**双方都委托 + 媒介促成**"；**单方委托**或**仅报告订约机会**的，仍由**委托人一方付** | §963 |
| **未促成仅必要费用** | 未促成 → **不得请求报酬**；但**有约定**时可请求从事中介活动的**必要费用**（无约定连费用也不能要）                                                             | §964 |
| **跳单条款**     | 委托人接受服务后，**利用中介提供的机会 / 媒介绕开中介**直接订约 → **仍应付报酬**（约定有效，2021 新增）                                                        | §965 |
| 兜底           | 本章没规定的，**参照适用委托合同**                                                                                                  | §966 |

**📎 逐条案例**（✅ 真题 / 🔧 实务）
- **§962 如实报告**：🔧 房屋中介小李**明知是凶宅却隐瞒**、促成老王买下 → 故意隐瞒重要事实，**不得请求报酬并赔偿**。
- **§963 促成才付酬（单方委托）**：🔧 小李带老王看房、老王看中并签约 → 促成，由**老王一方**付中介费。
- **§963 双方均分**：✅ [[典型合同-单选-16|单16]] 乙找房、丙出租都在中介甲处登记，甲促成乙丙成交 → 报酬由**乙丙平均负担**（答 C）。
- **§964 未促成仅必要费用**：✅ [[典型合同-单选-16|单16]] D 项 + 🔧 小李带老王看了十套房都没成 → **不能要报酬**；只有**事先约定**了才可主张交通费等必要费用。
- **§965 跳单**：🔧 小李带老王看了老张的房，老王为省佣金**私下绕开小李**直接与老张签约 → **仍要付报酬**（跳单约定有效，2021 新增）。

## 三、专题打通：任意解除权"全家族"（委托是龙头）

委托 §933 是全章第一考点，且常和承揽、物业、租赁的"随时解除"放一起设混淆题。**横向记一张表**（对照 [[民法-合同-解除模型]]）：

| 合同 | 谁能随时解除 | 限制 / 赔偿 | 法条 |
|---|---|---|---|
| **委托** | **委托人 + 受托人（双向）** | 有偿赔直接损失 + 可得利益；无偿赔因解除时间不当的直接损失 | **§933** |
| 承揽 | **定作人（单向）** | 承揽人完成工作**前**；赔承揽人**损失**（不分有偿无偿） | §787 |
| 不定期租赁 | 双方 | 应在**合理期限前通知** | §730 |
| 不定期合伙 | 各合伙人 | 应在**合理期限前通知** | §976 |
| 保管 | **寄存人随时领取** | —— | §899 |
| 物业服务 | 业主**依法共同决定**解聘 | **提前 60 日书面通知**（⚠️不是 30 日） | §946 |

> **共同点**：任意解除权是**法定特权 ≠ 违约**，别套 §563 五情形；多数仍需赔对方损失。
> **关联真题**：[[典型合同-单选-13|委托·单选13]] · [[典型合同-多选-11|承揽定作人·多选11]] · [[典型合同-多选-13|律所·多选13]] · [[典型合同-多选-14|物业·多选14]]。
> 📐 **物业专题模型** → [[民法-合同-物业服务合同模型]]（§946 业主大会任意解除 60 日 + §948 不定期随时解除 60 日 + §944/§949 物业全章四步）。

## 四、命题人最爱的 6 个陷阱

1. **拿"委托"当筐什么都装** —— 报信息 / 牵线＝**中介**、以自己名义代买卖＝**行纪**，都不是委托。先过"三把尺子"。
2. **任意解除权"贯穿始终"** —— 委托即使一审已败诉、二审已开庭，**仍可随时解除**（§933）；解除**不构成违约**。
3. **有偿 / 无偿归责弄反** —— **有偿**委托一般过失即赔（§929），无偿仅故意 / 重大过失；律师、中介这类专业服务都是**有偿**。
4. **行纪"高价差"以为能分成** —— **全归委托人**（§955），不平均分；且 §955（价格偏离归属）别和 §956（介入权）互换。
5. **中介报酬三连坑** —— ①未促成不付酬、必要费用还得"**有约定**"才能要（§964）；②双方都委托 → 报酬**平均负担**（§963）；③**跳单约定有效**，绕开中介仍付酬（§965）；④故意隐瞒 / 虚假 → **不付酬 ＋ 赔偿**（§962）。
6. **条号陷阱** —— 行纪费用自负是 **§952**（不是 §954）；行纪人与第三人订约 → 第三人**找行纪人不找委托人**（§958，直接享有权利义务）。

## 五、真题演练（套两步模型）

### 范例①：[[典型合同-单选-15|C2-单选-15]]（甲委托乙公司"提供出借人信息"，与出借人订约后付酬，后从丙借 50 万；问性质）→ **C 中介**
1. **第一步（三尺定性·命门）**：乙只**报告出借人信息**（报告订约机会）、不以甲名义签约、**借款合同发生在甲与丙之间**、乙非当事人 → **中介**（§961）。
2. 排除：A 委托——乙不为甲"处理事务"、只信息牵线；B 行纪——乙不以自己名义参与买卖 / 借款；D 借款——借款是甲↔丙的关系。
→ **C** ✅

### 范例②：[[典型合同-单选-13|C2-单选-13]]（甲委托乙买木材、乙已花时间精力，甲电话取消、乙不同意；问正确项）→ **C**
1. **第一步**：甲委托乙"买木材"＝以甲名义处理事务 → **委托合同**（甲＝委托人，乙＝受托人）。
2. **第二步 A（§933）**：委托人可**随时解除**、无需书面、无需对方同意 → A（无权）、B（须书面）**错**；解除**致乙损失须赔** → **C 对**。
3. **D 错**：解除后**不再按原约全额付酬**——事务因甲取消（不可归责于受托人）未完成，乙依 **§928** 得"**相应报酬**"、损失另依 **§933** 索赔（§928 报酬 ≠ §933 赔偿，两条线别混）。
→ **C** ✅

### 范例③：[[典型合同-多选-13|C2-多选-13]]（律所代理一、二审，一审后建议不再代理被拒、终致败诉；问正确项）→ **AC**
1. **第一步**：律师代理＝**有偿委托合同**。
2. **第二步 A**：①受托人（律所）**可随时解除** + 担赔偿 → **A 对**；②委托人即使一审**胜诉**也可解除 + 担赔偿 → **C 对**；B"败诉后不能解除"**错**（§933 贯穿始终，陷阱②）；D"只故意 / 重大过失才担责"**错**（有偿委托一般过失即责，§929，陷阱③）。
→ **AC** ✅

### 范例④：[[典型合同-单选-14|C2-单选-14]]（甲委托乙商行卖 10 吨大米、乙以自己名义出售、5% 报酬；问"不正确"项）→ **C**
1. **第一步**：乙**以自己名义**为甲从事贸易 → **行纪**（§951）。
2. **第二步 B**：A 以自己名义卖＝行纪 → 对；B 销售费用**自负** → 对（**§952**）；D 与第三人订约**直接受权利义务** → 对（§958）；**C 错**——高于指定价卖出、无增报酬约定的，差价**全归委托人**（§955），不"平均分配"。
→ "不正确"为 **C** ✅

### 范例⑤：[[典型合同-单选-16|C2-单选-16]]（甲房屋中介，乙委托找房、丙住房也在甲处登记，甲撮合乙丙成交；问正确项）→ **C**
1. **第一步**：甲提供**媒介服务并促成**租赁合同成立 → **中介**（§961）。
2. **第二步 C**：乙、丙**双方都委托**了同一中介、且因媒介服务促成 → 报酬由**乙丙平均负担**（§963）→ **C 对**；A / B"只一方付"**错**；D 错——必要费用仅在**未促成**时才可主张（§964），已促成则并入报酬。
→ **C** ✅

### 范例⑥：[[典型合同-单选-27|C2-单选-27]]（**2011-3-4 真题** · 甲委托乙卖首饰、乙经同意转委托丙、丙以自己名义卖丁、丁不知甲；丁拒付货款）→ **C**（间接代理主场）
1. **§923 转委托**：经甲**同意** → 转委托有效 → A"无效"错。
2. **§925 直接归属（反面）**：丙以自己名义、丁订约时**不知甲** → 合同**不直接约束甲**（§925 须丁"知道"才直接归属）→ B 错。
3. **§926 介入权**：丁拒付＝**第三人原因**致丙对甲不履行 → 丙须向甲**披露丁** → 甲可**行使丙对丁的权利** → **C 对**。
4. **D 错**：丁不在"丙—戊"委托链上（丁是买首饰方，非委托丙买箱包的人），无法穿透向戊主张。
→ **C** ✅　**📌 这是 §925/§926 在客观题里的典型形态**——多以"转委托 + 间接代理"缝合的综合题出现、极少单独成题（这也是本模型早先未单挂间接代理真题的原因）。

### 范例⑦：[[典型合同-多选-25|C2-多选-25]]（模拟 · 甲委托乙以乙名义向丙采购、丙不知甲；乙迟延未付货款）→ **BD**（§926 双向穿透）
1. **§926 选择权**：因委托人甲一方原因致乙对丙不履行 → 披露甲后，丙可**选择**告乙或甲、且不得变更 → A"只能向乙"错、**B 对**。
2. **§926 介入权**：甲可介入直接向丙主张 → **D 对**；C 把选择权误当"代位权"（无先诉顺位）→ 错。
3. ⚠️ **条号铁则**：**介入权与选择权同属 §926**；§925 是"第三人**知道**→直接归属"的**另一条线**（本题丙不知甲，不走 §925）。原卡曾把介入权误标 §925，已订正。
→ **BD** ✅

## 📐 口诀

> **"替人办事收报酬，三尺一量定身份：以谁名义、是不是当事人、办的什么事。**
> **牵线报信息＝中介，自己名义代买卖＝行纪，以你名义办事务＝委托。**
> **委托双向随时解（§933），有偿赔到可得利、无偿只赔时机损；有偿一般过失担、无偿故意重过失（§929）。**
> **行纪费用自己扛（§952），高卖低买差归东（§955），自任买卖是介入（§956），对外签约自担责（§958）。**
> **中介促成才给钱（§963），双方都托各付半，没成只讨必要费、还得白纸黑字算（§964）；绕开中介也得付——跳单照样要报酬（§965）。"**
