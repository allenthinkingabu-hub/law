# 📐 所有权保留 · 答题模型（万能四步）

> 凡"所有权保留买卖（约定付清价款前所有权不转移）"题，按这四步走，一步不跳。
> **姊妹模型** → [[民法-合同-分期付款买卖模型]]（§634 加速到期 / 解除细则）· [[民法-合同-风险负担模型]]（§604 风险移转细则）。
> **适用真题**：[[典型合同-多选-21|C2-多选-21 · 所有权保留≠风险]] · [[典型合同-多选-22|C2-多选-22 · 取回权·善意取得]]
>
> 🔎 **法条已联网核实（2026-06-11）**：§641-§643、§634、§604 / §226、§311 经[最高检官网民法典全文](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对；取回权**两上限（已付 75% / 善意取得）**见《买卖合同司法解释》(法释〔2012〕8号 · **法释〔2020〕17号修正**)**第 26 条**。

## 一、核心考情
- **频率**：所有权保留是 [[买卖合同]] ★★★★ 高频多选点，最爱与**风险负担、善意取得、分期付款、担保物权**塞进同一道题。
- **命题核心**：故意把"**所有权归谁**"和"**风险 / 取回 / 善意取得 / 加速到期**"混在一起，看你会不会把"所有权"这条线和其他线**拆开**。
- **四大必考点**：①不要式 + 登记对抗（§641）②所有权 ≠ 风险（§604）③取回权条件 + 两上限（§642 + 司法解释§26）④加速到期 / 解除 + 使用费（§634）。

## 二、万能四步模型

### 第一步：认定 + 形式 —— 不要式，但"登记才对抗善意第三人"（§641）
**铁则**：约定"买受人付清价款（或完成其他义务）前，标的物所有权属出卖人"= **所有权保留**。**不要式**（口头即有效、无须书面）；但出卖人保留的所有权**未经登记，不得对抗善意第三人**（§641Ⅱ，2021 新规）。

**老王小李例子**
- 老王口头约定"小李付清前车归我"——**有效**（不要式）；但老王**没去登记**，小李又把车转卖给善意的老张 → 老王**不能**拿"保留所有权"对抗老张。
**善意取得**：
	无权处分人卖他人财产，**不知情的善意第三人**付合理对价+完成交付/登记，就合法取得所有权，原权利人只能找无权处分人索赔。 **例子**：老王卖车给小李（约定付清全款前车归老王），小李没付清就把车卖给不知情的小张，小张付了合理价并开走，小张就善意取得了车的所有权。
**没登记 法考特指：
	没去「中国人民银行征信中心动产融资统一登记公示系统」登记所有权保留这个权利**。 不是指车辆/设备本身的过户登记。 - 没登记：只有你俩知道所有权保留，外人查不到 - 登记了：全天下人都能查到，第三人就不能主张“不知情”

### 第二步：拆两条线 —— 所有权 ≠ 风险（§604 + 简易交付§226）
**铁则**：所有权虽留在出卖人，但**风险随交付走**（§604 交付主义）——标的物一经交付买受人，毁损灭失风险即移转买受人，烧了买受人**照付价款**。**所有权归谁，不影响风险**。
- **简易交付**：买受人在订约前已占有标的物的（如借用转买卖），合同生效时即视为**交付完成**（§226）。

**老王小李例子**（= [[典型合同-多选-21|多选-21]]）
- 小李借用的设备买下来、约定保留所有权，付款前车间失火烧毁 → 设备订约前已在小李处（简易交付、交付已完成）→ 风险在小李 → 小李仍须付原价款；"所有权还在老王名下"**不改变**风险归属。
**不要式**
	法律**不强制要求**采用书面、公证等特定形式，只要双方**口头达成一致意思表示**，约定就合法有效。 **例子**：老王小李口头约定“付清车款前车归老王”，这个所有权保留约定就有效，不用写在合同里。 （反之，房屋买卖合同是**要式**，必须书面，口头无效）
### 第三步：出卖人救济① —— 取回权：三条件 + 两上限（§642 + 司法解释§26）★最易混
**铁则**：所有权转移前，买受人有下列之一**造成出卖人损害**的，出卖人可取回标的物（§642）：(一)**催告后合理期限内仍未付**价款；(二)未完成约定的特定条件；(三)将标的物**出卖 / 出质 / 其他不当处分**。
**两个天花板**（《买卖合同司法解释》§26）：
- ① 买受人**已付 ≥ 75%** → 出卖人**不得取回**（保护买受人期待权）；
- ② 标的物已被第三人**善意取得**（§311）→ 取回**对抗不能**（取不回）。
取回后：买受人可在合理期限**回赎**；逾期不赎 → 出卖人**合理价再出卖**，价款扣未付款及必要费用后**多退少补**（§643）。
> ⚠️ 取回权门槛是"**催告未付 / 不当处分**"，**不是"欠款 1/5"**——1/5 是第四步 §634 的门槛，别混。

**🔑 辨析：取回权的"3 条件 + 2 上限"里，为什么没有 1/5？**

数一遍取回权的 5 个要素——触发条件①催告未付 ②未完成特定条件 ③不当处分，上限①已付 75% ②被善意取得——**全程没有"1/5"**。1/5 根本不属于取回权，它是 §634 **另一套救济**的专属门槛。

| 维度 | **取回权（§642）** | **加速到期 / 解除（§634）** |
|---|---|---|
| **干嘛用** | 把**货**拿回来（实现担保） | 要**钱**（全款）或散伙（解约） |
| **触发门槛** | 催告未付 / 不当处分（**无 1/5**） | 欠款达 **1/5** + 催告 |
| **数字** | 上限＝已付 **75%**（封顶取不回） | 下限＝欠 **1/5**（够线才能用） |
| **障碍 / 上限** | 已付≥75% 或被善意取得 → 取不回 | —— |

- **为什么命题人爱挖坑**：§642(一) 和 §634 **都含"催告未付价款"**、长得像 → 故意把"1/5"粘到取回权上骗你。识破：想**拿货**，催告没付就能动（**不问欠多少**）；想**要全款 / 解约**，才须欠够 **1/5**。
- **立法逻辑**：取回货物只是"把担保物收回"，门槛低（但用 75% + 善意取得护着买家）；而"逼买家一次付清全款或撕毁合同"对买家更狠，故要求违约更严重（欠够 1/5）才允许。
- **一句话**：取回权（拿货）跟 1/5 没半毛钱关系；**一个管"物"（§642）、一个管"钱"（§634）**。

**老王小李例子**
- **取回条件 + 两上限**：小李催告后仍不付、且**已付不到 75%** → 老王可取回车；但若小李**已付 80%**，或车已被善意的老张买走 → 老王**取不回**（分别撞上两个上限）。
- **回赎 / 再出卖·多退少补（§643）**：小李分期买老王的车（总价 **6 万**），已付 **4 万**（67%<75%，可取回）、尚欠 **2 万**，催告不付，老王取回车。① **回赎**：小李在合理期限内**补清 2 万欠款 + 必要费用** → 赎回车、合同继续；② **再出卖**：小李逾期不赎 → 老王以合理价 **5 万**把车卖给老张，这 5 万先抵小李**欠款 2 万 + 必要费用 0.5 万**，**剩 2.5 万退还小李**（多）；若只卖得 2 万、不够抵 2.5 万，差 **0.5 万由小李补足**（少）。→ 小李净担"折旧 1 万 + 费用 0.5 万"，老王不亏不赚。
- **"1/5"与"取回权"是两套门槛，别混**：想**要钱 / 散伙**走 §634（门槛 = 欠款达 **1/5** + 催告 → 加速到期 / 解除）；想**把货拿回来**走 §642 取回权（门槛 = **催告未付** 或买受人**不当处分**，**与 1/5 无关**）。例：小李把没付清的车**偷偷出质**给老张 → 老王**立刻**可主张取回（§642 三，不看欠款够不够 1/5）；但若老王想"加速要全款 / 解约"，则须欠款到 **1/5**（§634）。一个管"物"、一个管"钱"。

### 第四步：出卖人救济② —— 分期付款的加速到期 / 解除 + 使用费（§634，详见姊妹模型）
**铁则**：所有权保留常与**分期付款**叠加。分期付款买受人**未付到期款达全部价款 1/5** + **催告后合理期限仍不付** → 出卖人可（二选一）：①请求**支付全部价款**（加速到期）；②**解除合同**，并可请求标的物**使用费**（§634）。完整分期付款规则 → [[民法-合同-分期付款买卖模型]]。

**老王小李例子**（= [[典型合同-多选-22|多选-22]] C / D）
- 小李欠款达 30%(>1/5)、经催告仍不付 → 老王可**加速到期**要全部余款，或**解约**并要小李付这段时间的**使用费**。

## 三、命题人最爱的 5 个陷阱
1. **"保留所有权 = 保留风险"** —— 错！风险随**交付**走（§604），所有权归谁不影响风险（[[典型合同-多选-21|多选-21]] **B 陷阱**）。
2. **"所有权保留必须书面"** —— 错！**不要式**、口头有效；但**未登记不得对抗善意第三人**（§641）（[[典型合同-多选-21|多选-21]] **D 陷阱**）。
3. **"取回权门槛是欠款 1/5"** —— 错！1/5 是 §634 加速到期 / 解除的门槛；**取回权**门槛是催告未付 / 不当处分（§642），且**已付 ≥ 75% 或被善意取得就取不回**。
4. **"出卖人留着所有权，第三人就买不走"** —— 错！第三人**善意取得**（§311）/ 保留所有权未登记不得对抗善意第三人 → 第三人得所有权、取回落空（[[典型合同-多选-22|多选-22]] **A 对、B 错**）。
5. **"解除合同后买受人白用一场"** —— 错！出卖人解除可请求**使用费**（§634）。

## 四、真题演练（套四步模型）

### 范例①：[[典型合同-多选-21|C2-多选-21]]（借用设备买下、口头保留所有权、付款前烧毁）→ **AC**
- **第一步**：所有权保留**不要式**、口头有效 → **D 错**（"应采用书面形式"）。
- **第二步**：设备订约前已在甲处（简易交付 §226）→ 乙交付已完成、风险移转甲（§604）→ **A 对**；烧毁后甲仍付原价款 → **C 对**；所有权虽属乙但 ≠ 风险 → **B 错**。
→ **AC** ✅

### 范例②：[[典型合同-多选-22|C2-多选-22]]（电脑分期 + 所有权保留，卖给不知情王某）→ **ACD**
- **善意取得**：周某将电脑卖给**不知情、合理价、已交付**的王某 → 王某**善意取得**所有权（§311；且保留所有权未登记不得对抗善意第三人 §641Ⅱ）→ **A 对**。
- **取回权**：吴某欠最后一期时已付 80%(>75%)、且电脑已被王某善意取得 → **两个上限都撞** → 取回不能 → **B 错**。
- **§634**：欠款达 30%(>1/5)、催告仍不付 → 加速到期要全款（**C 对**）/ 解除 + 使用费（**D 对**）。
→ **ACD** ✅

## 📐 口诀

> **"保留所有权 ≠ 保留风险——交付一过，烧了也付钱（§604）；口头就算数、不登记顶不住善意第三人（§641）。**
> **取回权认'催告 + 不当处分'，已付七成五、或被善意取走，就取不回（§642 + 司法解释）；欠款过两成又催了，加速到期或解约要使用费（§634）。"**
