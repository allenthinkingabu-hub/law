# 📐 上诉抗诉与开庭审理 · 答题模型

> **教练开场白**
> 又见你在"上诉抗诉"这块栽跟头了吧？这一节几乎所有人都会踩同样几个坑：以为"被害人不服判决也能像被告人一样直接上诉"——**错！被害人及其法定代理人根本没有独立上诉权，只能在5日内请求检察院抗诉**；以为"上诉期限从法官宣判那天就开始算"——**错！要从接到判决书、裁定书的次日才起算**；以为"二审只要上诉人喊一声'有异议'就必须开庭"——**错！事实证据异议必须叠加"可能影响定罪量刑"才触发开庭**。今天用"主体—期限—开庭—到庭"四关，把上诉抗诉与二审开庭这块彻底锁死。

## 适用场景与解决问题

本模型覆盖刑诉法二审程序中的两大高频考点：**上诉抗诉的主体、期限与起算点**（§227/229/230）+ **第二审应当开庭审理的法定情形**（§234）。凡题干出现"不服一审判决/裁定""被害人能否上诉""上诉、抗诉期限""判决何时生效""检察院抗诉""二审是否应当开庭""被告人是否须到庭"等表述，立即调用本模型。

核心规则：

- **上诉权主体**：被告人、自诉人及其法定代理人享有**独立上诉权**；辩护人、近亲属须经**被告人同意**方可代为上诉；附带民事诉讼当事人及其法定代理人可就**附民部分**独立上诉（§227）。
- **被害人无上诉权**：被害人及其法定代理人（含近亲属）**无独立上诉权**，只能在收到判决书后**5日内**请求人民检察院提出抗诉（§229）。
- **上诉抗诉期限**：不服**判决10日**、不服**裁定5日**，自**接到判决书、裁定书的次日**起算，非宣判日、非判决作出之日（§230）。
- **判决生效**：上诉抗诉期满、无人上诉抗诉的，判决于期满**之次日**0时生效；共同犯罪中只要一人上诉，**全案（含未上诉者）均不生效**。
- **应当开庭四情形**：①事实证据异议且**可能影响定罪量刑**；②被告人被判处**死刑**（2021《高法解释》后含**死缓**）的上诉案件；③人民检察院**抗诉**的案件（一律开庭）；④其他应当开庭的情形（§234）。

> **核心一句**：**「被告自诉可独诉，被害无权只能请；十日五日次日起，证死抗兜要开庭」**

> 🔎 **法条口径**：§227（上诉权主体）、§229（被害人请求抗诉）、§230（上诉抗诉期限与起算）、§234（二审应当开庭情形）。

> ⚠️ **易记错点**：①把期限条款§230误记成主体条款§227；②把"判决10日、裁定5日"误记成"均10日"；③以为期限从宣判/判决作出之日起算，实为接到之次日；④以为被害人也能直接上诉；⑤以为共同犯罪未上诉者的判决先行生效；⑥以为检察院可越级抗诉或直接向原审法院抗诉；⑦以为认为原判正确也能"补充抗诉"；⑧以为"有异议就一律开庭"，漏掉"可能影响定罪量刑"限定；⑨把死刑等同于无期，或忽略2021年后死缓已纳入应当开庭；⑩混淆"案件应当开庭"与"被告人必须到庭"两个层次。

## 二、主体关

> **教练提示**：这一关的坑全在"谁能诉、谁不能诉"——大多数人把被害人和被告人的上诉权当成对等的，其实两者天差地别。

### `诉权三分` 字诀

**先懂几个词（翻成人话）**：
- 独立上诉权 = 不用经过任何人同意，自己签字就能提出上诉。
- 代为上诉 = 辩护人/近亲属不是自己想诉就能诉，必须先经被告人点头同意。
- 请求抗诉 = 被害人不能自己上诉，只能"打申请"求检察院出面抗诉，抗不抗诉检察院说了算。
- 抗诉层级对应 = 检察院抗诉必须"原审同级检察院→上一级法院"，不能越级，也不能"向原审法院抗诉"。

**🔍 对号入座表**：

| 题干情形 | 规则 | 结论/陷阱 |
|---|---|---|
| 被告人本人不服判决 | §227独立上诉权 | 有权直接上诉，无须同意 |
| 自诉人本人不服判决 | §227独立上诉权 | 有权直接上诉，与被告人对等 |
| 辩护人认为量刑畸重想上诉 | §227需经同意 | 须经被告人同意方可代为上诉 |
| 被告人近亲属想上诉 | §227需经同意 | 须经被告人同意方可代为上诉 |
| 附民原告不服附民判赔部分 | §227独立上诉权 | 可就附带民事部分独立上诉 |
| 被害人不服量刑过轻 | §229无上诉权 | 5日内只能请求检察院抗诉，不能自己上诉 |
| 被害人近亲属不服判决 | §229无上诉权 | 与被害人本人一样无上诉权 |
| 检察院对基层法院一审判决抗诉 | 抗诉层级 | 由同级（基层）检察院向上一级法院提出，经原审法院转送 |
| 检察院认为原判正确却想"补充抗诉" | 补充抗诉前提 | 须先有抗诉在先，且认为原判确有错误才可提出 |

**💰 完整数字案例**：
赵某因故意伤害罪被某县法院一审判处有期徒刑3年，被害人钱某不服，认为量刑过轻。钱某能不能自己去中院提上诉？不能——钱某只是被害人，没有独立上诉权，他能做的只有在收到判决书后**5日内**向检察院提交书面申请，请求检察院提出抗诉，抗不抗诉的决定权在检察院，不在钱某。同一案件里，如果是赵某本人不服判决，他自己签字就能在**10日**内直接提上诉，无须经任何人同意；如果是赵某的辩护人替他上诉，则必须先经赵某本人点头同意。→ 对应 [[刑诉-审判-单选-13 · 上诉抗诉主体与期限起算辨析（仿真题）|赵某案]]、[[刑诉-审判-单选-91 · 各类诉讼主体法定代理人上诉权辨析|单选-91]]、[[刑诉-审判-多选-85 · 廖某之子被推下楼案死刑审委会与被害人上诉权|廖某案]]。

> 🎯 **一眼判**：**「被告自诉可独诉，被害无权只能请（求抗诉）」**

## 三、期限关

> **教练提示**：这一关专治"起算点乱猜"和"生效时点算错一天"，尤其是当庭宣判的场景，很多人误以为宣判当天就开始计算期限。

### `十五次日起算` 字诀

**先懂几个词（翻成人话）**：
- 送达 = 法院把判决书/裁定书实际交到当事人手上的那一天。
- 次日起算 = 送达当天不算第1天，从送达的第二天才开始数第1天。
- 期满之次日生效 = 10天（或5天）数完的那天叫"期满日"，判决从期满日的**第二天**0点才正式生效，不是期满当天生效（此处存在官方答案争议，不可断然取一说）。
- 全案不生效 = 共同犯罪里只要有一个人上诉，其他没上诉的同案人的判决也一并按下暂停，不能提前生效。

**🔍 对号入座表**：

| 题干情形 | 规则 | 结论/陷阱 |
|---|---|---|
| 不服一审判决 | §230 | 上诉抗诉期10日 |
| 不服一审裁定 | §230 | 上诉抗诉期5日 |
| 当庭宣判、次日送达 | §230起算点 | 从**送达**次日起算，不是宣判当日 |
| 判决作出后再送达 | §230起算点 | 同样从送达次日起算，不是"判决作出之日" |
| 10日期满、无人上诉抗诉 | 生效时点 | 通说期满之次日0时生效（存在"期满当日生效"的官方答案争议） |
| 共犯之一上诉、其余未上诉 | 全案效力 | 全案（含未上诉者）都不生效，非"未上诉部分先生效" |
| 检察院对基层法院判决抗诉 | 抗诉层级 | 同级检察院向上一级法院提出，经原审法院转送 |

**💰 完整数字案例**：
黄某倒卖文物案，一审6月9日（周一）宣判并当庭送达判决书，黄某当日提出上诉、6月13日又撤回；检察院6月12日提出抗诉、上级检察院6月17日撤回抗诉。两次上诉抗诉都撤回后，一审判决何时生效？起算点是6月9日送达的次日，即6月10日为第1日，10日期满为6月19日。但"期满之日生效"还是"期满之次日生效"，官方答案存在争议：原答案C（6月19日，期满当日说），杨雄真金题更正为D（6月20日，期满之次日说）——本模型如实并列两说，不擅自取舍。没有争议的同类案情如甲盗窃案：3月5日当庭宣判、3月6日送达，甲服判、被害人乙申请抗诉但检察院未同意，起算点3月7日，10日期满3月16日，判决3月17日0时生效（期满次日说）。→ 对应 [[刑诉-审判-单选-90 · 黄某倒卖文物案撤回上诉与撤回抗诉后一审判决生效时间|黄某案]]、[[刑诉-审判-单选-153 · 甲盗窃案当庭宣判服判被害人请求抗诉的判决生效时间|甲盗窃案]]、[[刑诉-审判-多选-157 · 张某李某共同犯罪部分上诉全案不生效与抗诉主体上诉不加刑|张某李某案]]（多选-153补充抗诉/抗诉主体案例见二·主体关）。

> 🎯 **一眼判**：**「送达次日起，十日五日算，期满次日才生效」**

## 四、开庭关

> **教练提示**：这一关专治"一有异议就以为要开庭"，实际死刑（含死缓）、抗诉才是真正一律开庭的两把硬钥匙，事实证据异议还得叠加"影响定罪量刑"的门槛。

### `证死抗兜` 字诀

**先懂几个词（翻成人话）**：
- 应当开庭 = 法定必须开庭审理，法院没有自由裁量权可以不开。
- 事实证据异议 = 上诉人对一审认定的犯罪事实、证据提出不同意见，但要"可能影响定罪量刑"，鸡毛蒜皮的异议不算数。
- 死刑（含死缓）= 2021《最高法解释》把"死刑"扩张理解为包含死刑缓期二年执行，死缓上诉案件也纳入应当开庭。
- 全面审查 = 二审对全案事实、证据、法律适用、诉讼程序都要审查，**审查范围**不受上诉/抗诉范围限制，但**改判处理**仍受上诉不加刑约束。

**🔍 对号入座表**：

| 题干情形 | 规则 | 结论/陷阱 |
|---|---|---|
| 对事实证据有异议，但与定罪量刑无关 | §234第一项 | 不属于应当开庭情形 |
| 对事实证据有异议，且可能影响定罪量刑 | §234第一项 | 应当开庭 |
| 判处死刑立即执行后上诉 | §234第二项 | 应当开庭 |
| 判处死缓后上诉（2021年后） | §234第二项（扩张） | 应当开庭 |
| 判处无期徒刑后上诉 | 非法定情形 | 不属于应当开庭，可以书面审理 |
| 检察院抗诉的案件 | §234第三项 | 一律应当开庭，不得径行书面审理 |
| 共同犯罪仅一人被判死刑、其余人上诉 | 全案审查触发 | 因触及死刑部分，全案应当开庭 |
| 检察院仅对甲抗诉、甲乙均未上诉 | 全面审查≠处理不受限 | 应当开庭且全案审查含乙，但只能改判甲，不得加乙 |

**💰 完整数字案例**：
甲、乙共同故意杀人，一审判甲死刑立即执行、乙10年，仅甲上诉、乙未上诉、检察院未抗诉。二审是否要开庭？要——因为甲被判死刑立即执行，落入§234第二项的法定应当开庭情形。同一案情如果换成鲁某、关某贩毒案，一审判鲁某死刑立即执行、关某死缓，仅关某上诉、无抗诉，二审依然应当开庭，因为关某上诉触发了对全案（含鲁某死刑立即执行部分）的审查。再看甲乙抢夺案，检察院仅对甲抗诉、甲乙均未上诉，二审同样应当开庭（抗诉一律开庭），且全面审查及于全案（含乙），但改判只能加重甲，乙受上诉不加刑保护不得加刑。→ 对应 [[刑诉-审判-多选-93 · 甲乙共同杀人甲死刑立即执行上诉的二审程序|甲乙杀人案]]、[[刑诉-审判-多选-98 · 鲁某关某贩毒死刑案仅关某上诉的二审开庭|鲁某关某案]]、[[刑诉-审判-单选-97 · 甲乙抢夺检察院抗诉甲的全面审查与上诉不加刑|甲乙抢夺案]]、[[刑诉-审判-多选-99 · 二审应当开庭审理的情形死刑死缓抗诉|多选-99]]。

## 五、到庭关

> **教练提示**：这一关专治"案件该不该开庭"和"某个人该不该到庭"混为一谈——两者是完全不同层次的问题，别再把它们捆一块判断。

### `案开人不必到` 字诀

**先懂几个词（翻成人话）**：
- 案件应当开庭 ≠ 被告人必须到庭 = 前者问"这个案子要不要开法庭"，后者问"某个具体的人要不要人到现场"，是两个层次。
- 未上诉同案人 = 案子里没有提起上诉的被告人，虽然案子因为别人上诉而开庭审理，但他本人可以不出庭。
- 要求出庭应当准许 = 未上诉的人如果自己主动要求到庭参加，法院不能拒绝。
- 死刑复核 = 死刑立即执行案件，二审维持原判后还必须报最高人民法院核准，核准前不能执行，二审维持≠可以立刻执行。

**🔍 对号入座表**：

| 题干情形 | 规则 | 结论/陷阱 |
|---|---|---|
| 甲死刑、乙无期、丙10年，仅丙上诉 | 全案审查触及死刑 | 应当开庭，但未上诉的甲可以不出庭 |
| 未上诉的乙要求出庭 | 出庭申请权 | 应当准许，不得拒绝 |
| 未上诉的乙想重新委托辩护人 | 辩护权不受影响 | 有权重新委托，不因未上诉而受限 |
| 甲死刑立即执行、二审维持原判 | 死刑复核程序 | 须经死刑复核核准后才能执行，非维持即可执行 |
| 甲死刑立即执行案，二审开庭前甲要求撤回上诉 | 撤回上诉限制 | 不予准许，应当继续审理 |
| 仅丙上诉、无抗诉，发回重审 | 上诉不加刑 | 不得加重丙的刑罚 |
| 被告人本人能否选择二审是否开庭 | 程序选择权边界 | 无选择权，由法院依法定情形决定 |

**💰 完整数字案例**：
甲、乙、丙共同故意杀人，一审判甲死刑立即执行、乙无期徒刑、丙有期徒刑10年，仅丙提起上诉。二审因触及甲的死刑立即执行部分而应当开庭，但甲、乙均未上诉，甲可以不出庭；如果乙主动要求出庭，法院应当准许，且乙仍有权重新委托辩护人，不因未上诉而丧失辩护权。即便二审最终维持甲的死刑判决，也不能立即执行，必须先报请最高人民法院复核核准。此外，二审开庭前甲若反悔想撤回上诉，法院不予准许，因为死刑立即执行案件为保障案件质量必须继续审理，不能靠撤回上诉规避二审监督。被告人自己也无权选择"这个案子要不要开庭"，开庭与否由法院依法定情形决定，不是被告人的程序选择权范围。→ 对应 [[刑诉-审判-单选-96 · 甲乙丙共同杀人仅丙上诉的二审开庭与到庭规则|甲乙丙案]]、[[刑诉-审判-多选-93 · 甲乙共同杀人甲死刑立即执行上诉的二审程序|甲乙杀人案]]、[[刑诉-审判-多选-95 · 被告人程序选择权的边界辨析|多选-95]]。

> 🎯 **一眼判**：**「案子该不该开庭看法定情形，人到不到庭看是否上诉」**

## 命题陷阱拆解

1. ❌"被害人不服判决可以直接上诉"——错，被害人及其法定代理人无独立上诉权，只能5日内请求检察院抗诉（§229）。
2. ❌"上诉抗诉的期限规定在§227"——错，主体规定在§227，期限规定在§230。
3. ❌"不服判决和裁定的上诉期限均为10日"——错，判决10日、裁定5日。
4. ❌"上诉期限从判决作出之日起算"——错，从接到判决书/裁定书的次日起算，当庭宣判的从送达次日起算。
5. ❌"上诉抗诉期满当日判决即生效"——存在官方答案争议（单选-90），起草与答题时须知悉"期满当日"与"期满之次日"两说并存，不可断然取一说当唯一正确。
6. ❌"共同犯罪一人上诉，其余未上诉人的判决先行生效"——错，全案（含未上诉者）都不生效。
7. ❌"检察院可以直接向原审法院抗诉"或"越级向上级法院抗诉"——错，应由同级检察院向上一级法院提出，经原审法院转送。
8. ❌"检察院认为原判正确，也可以提补充抗诉巩固立场"——错，补充抗诉须以已有抗诉、且认为原判确有错误为前提。
9. ❌"上诉人对事实证据有任何异议，二审都必须开庭"——错，须叠加"可能影响定罪量刑"。
10. ❌"判处无期徒刑的上诉案件应当开庭"——错，法定应当开庭的是死刑（含死缓，2021年后），无期不在此列。
11. ❌"检察院抗诉的案件可以书面审理"——错，抗诉案件一律应当开庭。
12. ❌"未上诉的同案被告人也必须到庭"或"被告人可以自主选择二审是否开庭"——错，未上诉人可以不出庭（但要求出庭应准许），开庭与否由法院依法定情形决定，被告人无程序选择权。

## 主观题万能说理模板

【第一步·锁定诉讼主体资格】本案中，_____（列明主体身份：被告人/自诉人/附民当事人/被害人）对一审判决/裁定不服。根据《刑事诉讼法》第227条，被告人、自诉人及其法定代理人享有独立上诉权，_____（若为辩护人/近亲属，须说明"经被告人同意后代为上诉"）；根据第229条，若为被害人及其法定代理人，则无独立上诉权，只能在收到判决书后5日内请求人民检察院提出抗诉。

【第二步·核算期限与起算点】本案判决/裁定于_____年_____月_____日（宣判/送达），上诉、抗诉期限应自接到判决书、裁定书的**次日**起算，即自_____日起算。根据第230条，不服判决的上诉、抗诉期限为10日，不服裁定的为5日，本案期满日应为_____日。若期内_____（有/无）人提出上诉或抗诉，则判决于期满之次日0时生效／因_____上诉而全案（含未上诉的_____）不生效，进入二审程序。

【第三步·判断是否应当开庭审理】根据第234条，本案_____（是/否）属于法定应当开庭情形：①对一审认定事实、证据提出异议且可能影响定罪量刑；②被告人被判处死刑（含死缓）的上诉案件；③人民检察院抗诉的案件；④其他应当开庭的情形。本案因_____（具体触发事由），应当/无须开庭审理。

【第四步·区分到庭规则与处理边界】本案中，_____（列明各被告人上诉/未上诉状态），未上诉的_____是否需要出庭，如其要求出庭，法院_____（应当准许/无须准许）；二审改判时，因_____（是否有抗诉/是否仅被告人上诉），对_____（可以/不得）加重刑罚，体现上诉不加刑原则。
