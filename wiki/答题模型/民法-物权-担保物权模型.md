# 📐 担保物权 · 答题模型（设立 → 顺位 → 实现 → 权利质押）

> 担保物权 = **抵押 / 质押 / 留置**（物的担保），在 [[物权编]]；与保证（人保，[[合同编]]）同属 [[担保]]，源素材建议**合并成一个"担保"专题**学，比分开省一半力气。法考**人保物保混着考**——本模型管"**物保自己的设立、顺位、实现**"；**物保 + 人保并存**的实现顺序 → [[混合担保]] / [[民法-合同-保证模型]] 第五步（§392）。
> **姊妹 / 概念** → [[担保]] · [[混合担保]]（§392）· [[保证合同]]（人保一侧）· [[区分原则]]（§215 合同生效 ≠ 物权变动）· [[债权转让]]（§548 抗辩，债权质押准用）。
> **适用真题**：[[典型合同-单选-36|单选-36·抵押权vs质权竞存§415]] · [[典型合同-单选-37|单选-37·债权质押+抗辩§548]] · [[典型合同-多选-35|多选-35·共同抵押]] · [[典型合同-单选-33|单选-33·应收账款质押]] · [[典型合同-单选-34|单选-34·浮动抵押]]。
>
> 🔎 **法条已联网核实（2026-06-13，[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/) + [担保制度解释全文](https://ghzyj.gz.gov.cn/sjb/zw/zcfg/content/post_9466449.html)）**：§402 不动产抵押登记生效 · §403 动产抵押登记对抗 · **§409 抵押权 / 顺位处分 + 放弃后其他担保人免责** · §410 实现 · **§414 多个抵押权按登记先后** · **§415 抵押权与质权竞存按公示先后** · §416 价金抵押超级优先 · §429 动产质押交付生效 · **§445 应收账款质押登记设立** · §447 留置 · §548 债权转让债务人抗辩（债权质押准用）。
> ⚠️ **重大新旧法反转（必考）**：① §415 **抵押权与质权竞存按"登记 / 交付时间先后"**（**改了**旧担保法解释§79"抵押权一律优先于质权"）；② §414 多个已登记抵押权**按登记先后**（**删了**旧物权法§199"顺序相同按债权比例"）。

## 一、核心考情

- **频率（2026-06-13 联网核验·可溯源·不杜撰数字）**：
  - **担保物权整体**＝民法**超级重点、分值最高**（[233网校](https://www.233.com/sf/xueba/minfa/202205/06091529201064.html)）；物权编客观卷约 **9 题 / 13 分**、仅次于合同（约 12 题 / 19 分），二者并称"民法两大支柱"（[233网校·机构估算](https://www.233.com/sf/jingyan/202211/18112344624470.html)，非司法部官方）。
  - **抵押权**＝机构明确"**每年必考**"；**质押 / 留置**被列为担保物权重点子目（机构口径"需熟悉并能运用"），但**无任何来源给"质押本身"单独的星级 / 分值 / 频次** → 质押考频**只能定性为"常考重点子目"**，确切量级无出处、不杜撰。
  - **主观题**：**担保整体为"重中之重"**（中国政法大学法考学院），多以保证 / 非典型担保形态出现；质押作主观题独立考点缺可靠出处、存疑。
  - 真题层（据真题观察、非机构频次）：质押**题中常见、独立成题少**，多作"串考组件"（如 §415 抵押vs质权竞存、§548 债权质押抗辩、§445 应收账款质押 + 混合担保）。
- **命题核心**：①**顺位**（同一物上多个担保物权谁先受偿）②**公示效力**（登记生效 vs 登记对抗）③**权利质押**（应收账款 / 债权出质的设立与抗辩）④叠加 [[混合担保]] §392。
- **必抓四点**：①抵押设立"登记生效（不动产）vs 登记对抗（动产）" ②**§414 / §415 顺位口诀** ③**§416 价金抵押超级优先** ④应收账款质押**登记设立** + 债权质押**准用 §548 抗辩**。

## 二、万能四步模型

### 第一步：担保物权设立了吗？（公示是关键）

| 类型 | 设立要件 | 公示效力 |
|---|---|---|
| **不动产抵押**（建筑物 / 建设用地使用权等） | 抵押合同 + **登记** | **登记生效**（§402，自登记时设立） |
| **动产抵押**（机器 / 车辆 / 浮动抵押等） | 抵押合同**生效即设立** | **登记对抗**——未登记**不得对抗善意第三人**（§403） |
| **动产质押** | 书面合同 + **交付（移转占有）** | 交付生效（§429） |
| **权利质押·应收账款** | 书面合同 + **出质登记** | **登记设立**（§445，自办理出质登记时设立） |
| **权利质押·汇票/债券/存单/仓单/提单等** | 交付权利凭证；无凭证的办登记 | 交付 / 登记设立（§441 等） |
| **留置** | 债权人**已合法占有**债务人动产 + 债务到期未清偿 + **牵连关系**（企业间留置除外，§448） | 占有即可（§447） |

> 🪤 **登记生效 ≠ 登记对抗**：动产抵押**不登记照样有效**（区分原则 [[区分原则]]§215），只是**不能对抗善意第三人**；别答成"没登记抵押无效"。

### 第二步：同一物上多个担保物权，谁先受偿？（顺位口诀·最高频）

- **§414 多个抵押权**：①都登记 → **按登记时间先后**；②已登记**先于**未登记；③都没登记 → **按债权比例**。其他可登记的担保物权参照。
- **§415 抵押权 + 质权竞存**：**按"登记、交付的时间先后"**定清偿顺序（**先公示者先受偿**，不再是"抵押一律优先"）。
- **§416 价金抵押·超级优先（PMSI）**：动产抵押担保的主债权**是该动产的价款**，标的物**交付后 10 日内**办理抵押登记的，该抵押权**优先于**买受人在该动产上设立的**其他担保物权**（**留置权人除外**）。
- **§409 顺位处分 / 放弃**：抵押权人可**放弃**抵押权或顺位、可与抵押人协议变更顺位 / 债权数额；但**未经其他抵押权人书面同意，不得对其不利**。**债务人自己**的物保被抵押权人放弃 / 降顺位的，**其他担保人在丧失优先受偿权益的范围内免责**（除非其承诺仍担保）。

> 🔑 **顺位口诀**：**"抵押比抵押——看登记先后（§414）；抵押碰质权——看公示（登记 / 交付）先后（§415）；价款抵押 10 日内登记——超级优先、连留置都得让吗？不，留置仍最强（§416）。"**

### 第三步：怎么实现？（§410 + 混合担保 §392）

- **§410 实现方式**：债务人不履行到期债务或发生约定实现事由 → 抵押权人**与抵押人协议**折价 / 拍卖 / 变卖；协议不成，可**请求法院**拍卖、变卖。
- **共同抵押**（同一债权、数个财产抵押）：债权人可就**任一或全部**抵押物受偿（**抵押权不可分性**；无份额约定时不受比例 / 顺序限制）。
  - ⚠️ **如实标注**：现行《民法典》**无共同抵押实现顺序的专条**，此结论系**抵押权不可分性的当然解释 + 实务通说**（旧担保法解释§75 已废止，但精神延续）；若债权人**放弃**其中一个抵押物 → 适用 **§409**（其他担保人在丧失优先受偿范围内免责）。
- **物保 + 人保并存（混合担保）**：实现顺序看物保是"谁"的 → **§392**，详见 [[混合担保]] / [[民法-合同-保证模型]] 第五步（债务人自己物保**强制先实现**；第三人物保 vs 保证**可择一**）。

### 第四步：权利质押特殊点（债权 / 应收账款出质）

- **应收账款质押（§445）**：**登记设立**（自办理出质登记时设立）；出质后**不得转让**，除非出质人与质权人**协商同意**；出质人转让所得价款应向质权人**提前清偿或提存**。
- **债权质押的抗辩（准用 §548）**：质权人向**次债务人**（出质债权的债务人）实现质权时，次债务人**可以向质权人主张**其对**出质人（原债权人）**享有的**抗辩**——**准用债权转让规则**（§548："债务人接到债权转让通知后，对让与人的抗辩可向受让人主张"）。
  - 💡 道理：出质 / 转让都**不改变债的同一性**，债务人原有的抗辩（已清偿 / 质量瑕疵 / 诉讼时效届满等）不因债权易手而丧失。

**老王小李例子**
- 甲把**机器**抵押给乙（先登记）、又质押给丙（后交付）→ 同一物抵押 + 质权竞存，**乙先于丙**（§415，乙登记在先）。
- 甲买丁的设备欠价款，丁就该设备办**价金抵押**并在**交付后 10 日内登记** → 丁**优先于**甲在该设备上给别人设的其他担保物权（§416），但若戊**留置**了该设备修理，**留置权仍最优先**。
- 甲把对戊的 100 万**应收账款**质押给乙（已登记）→ 质权设立；戊（次债务人）若对甲本有"货物质量不合格少付 20 万"的抗辩，**可向乙主张**（准用 §548）。

## 三、命题人最爱的 6 个陷阱

1. **抵押权 + 质权竞存"抵押一律优先"** —— 错！§415 **按登记 / 交付时间先后**（旧规则已改）。
2. **动产抵押不登记就无效** —— 错！**登记是对抗要件**，不登记仍有效、只是不得对抗善意第三人（§403）。
3. **多个已登记抵押权"按债权比例"** —— 错！**按登记先后**（§414，删了旧"顺序相同按比例"）。
4. **应收账款质押交付凭证 / 签合同就设立** —— 错！**登记设立**（§445）。
5. **债权质押次债务人不能向质权人抗辩** —— 错！**准用 §548 可主张**。
6. **价金抵押要先登记才优先 / 能压过留置** —— 错！**交付后 10 日内登记**即超级优先（§416），但**留置权人除外**（留置仍最强）。

## 📐 口诀

> **"抵押比抵押看登记（§414）；抵押碰质权看公示先后（§415，不再'抵押一律先'）；价款抵押 10 日内登记超级优先，留置仍最强（§416）。**
> **不动产抵押登记生效，动产抵押登记对抗（不登记仍有效，不能对抗善意第三人）。**
> **应收账款质押登记才设立（§445）；债权出质，次债务人对原债权人的抗辩照样能向质权人主张（准用 §548）。**
> **物保 + 人保一起上 → 看物保是谁的（§392，去保证模型第五步 / 混合担保）。"**
