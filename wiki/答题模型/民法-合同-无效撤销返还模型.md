# 📐 合同无效 / 撤销后的返还（§157）· 答题模型（万能四步）

> 凡"合同无效 / 被撤销了，东西、钱怎么算"题，按这四步走。**一句话**：自始没约束力 → **互相还回去**，还不了**折价**，谁有错谁**赔**。
> **适用真题**：[[典型合同-多选-19|多选19·欺诈撤销后返还·同时履行·风险]]
> 🔎 **法条核实（2026-06-11，3 路联网 + 对抗复核）**：§157、§155、§500 经[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202005/t20200512_478406.shtml)逐字核对；双向返还同时履行与折价时点另引[最高法《合同编通则解释》§24-25](https://www.court.gov.cn/fabu/xiangqing/419382.html)。
> ⚠️ **考频说明**：**2024 法考新大纲明确新增**"民事法律行为被确认无效、被撤销或确定不发生效力的法律后果"考点（即 §157，**官方点名**），2025/2026 延续未删；星级据此 + 机构 / 学者研判。

## 一、核心考情

- **考频**：★★★★（高频·官方大纲新增）。依据：2024 新大纲把 §157 后果规则**单列为考点**；与可撤销事由（欺诈 / 胁迫 / 重大误解 / 显失公平）、[[缔约过失责任]] §500、[[不当得利]] §985-988、同时履行抗辩 §525 高度联动，**串题型高产**。
- **命题核心**：用"合同没了"诱你得出"东西不用还 / 钱不用退 / 风险全归对方"的错误结论；真正的考点是 §157 的**返还 → 折价 → 过错赔偿**三段 + 两个配套（同时履行、返还前风险）。
- **三大必考点**：①返还 / 折价补偿（§157 前段）②过错方赔偿（§157 后段＝缔约过失性质）③双向返还可主张同时履行（《合同编通则解释》§25）。

## 二、万能四步模型

### 第一步：定性后果——"自始没有法律约束力"（§155）

**铁则**：合同**无效 / 被撤销 / 确定不发生效力** → **自始没有法律约束力**（§155，逐字；"自始无效"是学理简称）。因该合同取得的财产**丧失保有依据** → 应返还。
> ❌ "合同没了就两不相欠 / 不用返还" —— 错！恰恰**要互相返还**。

**老王小李例子**
- 老王欺诈把设备卖小李、合同被撤销 → 合同自始没约束力 → 老王收的钱、小李拿的设备，**都得还回去**。

### 第二步：能不能/要不要返还原物——"事实不能 → 法律不能 → 没必要"三步排查（§157 前段）

**铁则**：①因该行为取得的财产，**原物返还优先**；②**不能返还或没有必要返还**的 → **折价补偿**。"不能/没必要"按**严格递进顺序**排查，**前一步命中即定折价、后面不用再判**（⚠️ 三者**殊途同归都 → 折价**，排序只是**答题秒杀技巧**、不是影响结果的法律位阶；②"法律不能"严格说是 §157"不能返还"的子类）：

| 排查序 | 问什么 | 触发 | 结论 |
|---|---|---|---|
| **①事实不能**（最刚性） | 物理上还有没有东西可退 | 灭失 / 损毁报废 / 已消耗 / 劳务等无形给付 | → **折价**（不必再问归谁、值不值）|
| **②法律不能** | 原物在，但法律允不允许退 | 已被**善意第三人取得**、被**查封 / 强制执行** | → **折价**（不必再算成本）|
| **③没有必要**（弹性最大）| 都能退，但退了划不划算 | **附合**（拆即报废）/ 返还成本远超物值 / 持续使用利益 | → 没必要则**折价**，有必要则**原物返还** |

- 💡 **底层逻辑**：事实不能（绝对不能）> 法律不能（规则不能）> 没有必要（经济不能）——越靠前越刚性、越无争议。**先看东西在不在，再看东西归不归你，最后算退回去值不值。**
- 💡 **折价时点**：以**认定无效 / 被撤销之日**的市场价值或其他合理方式计算（《合同编通则解释》§24-25）。

**老王小李例子**（合同被确认无效，车怎么退）
- ①事实不能：小李把车开报废 → 物理上没车可退 → **直接折价**，不用再问"卖没卖给别人""运费贵不贵"。
- ②法律不能：车完好，但小李已按市价卖给不知情的老张并过户 → 车在法律上归老张、退不了 → **折价**，不用算运费。
- ③没必要：老王卖小李一批定制脚垫——没装就退原物（有必要）；已粘死在车里、拆下即毁 → **没必要返还、折价**。

**📐 秒杀口诀（§157 返还）**
> **物退人赔，三步排查：物灭直接折，权移也不还，都能再算账，不划算也折。**

### 第三步：谁有错谁赔（§157 后段＝缔约过失性质）

**铁则**：**有过错的一方赔偿**对方由此所受损失；**各方都有过错的，各自承担相应责任**（与有过失）。
- 🔑 **定性精确**：§157 后段的赔偿**本身就是缔约过失性质**，与 [[缔约过失责任]]（§500）属**同一谱系、分情形适用**（**不是**两套互不相干的"竞合"责任）。欺诈致撤销时，请求权基础可**同时援引 §157 后段 + §500 第（二）项**（故意隐瞒 / 提供虚假情况）。

**老王小李例子**
- 老王欺诈（过错方）→ 依 §157 后段 + §500(二) 赔小李信赖利益损失（白跑的检测费、资金占用等）。

### 第四步：两个配套——同时履行 + 返还前风险

**铁则**：
1. **双向返还可主张同时履行**：双方互负返还义务、无先后，一方主张**同时履行的，人民法院应予支持**（**《合同编通则解释》§25**，司法解释明文，非单纯学理）。详见 [[民法-合同-履行抗辩权模型]]。
2. **返还前的毁损灭失风险**（⚠️ **学理 / 有争议，非 §157 明文**）：
   - **原则**：返还前由**占有人**承担（参照不当得利 §986、占有人责任 §459-461、类推交付主义 §604）。
   - **重要例外**：合同因**欺诈 / 胁迫 / 乘人之危**被撤销时，**受欺诈 / 受胁迫一方（占有人）对意外灭失不承担风险**（叶名怡通说），风险回到有过错方。
   - **答题分两档**：①标的物因**占有人过错**毁损 → 占有人担（§459/§1188）；②**意外**毁损 + 合同因对方过错（欺诈等）被撤销 → **受害方占有人不担**意外风险。

**老王小李例子**
- 设备返还前在小李处：①小李自己摔坏 → 小李担；②地震砸坏（意外）、且合同是因老王欺诈才撤销 → 小李（受欺诈占有人）**不担**意外风险，风险归过错方老王。

### ⚠️ 易混提示
- **§155 措辞**：原文是"**自始没有法律约束力**"，"自始无效"是学理简称（引原文勿混）。
- **§157 后段 vs §500**：同一缔约过失谱系、分情形，不是独立竞合。
- **返还前风险**：是**学理 / 参照**规则、非 §157 字面，且欺诈撤销时有"受害占有人不担意外风险"的例外。

## 三、命题人最爱的 5 个陷阱
1. **"合同没了就不用返还"** —— 错！自始无约束力 → **互负返还**（§157）。
2. **"不能返还就一笔勾销"** —— 错！转为**折价补偿**（按撤销之日价值，通则解释§24-25）。
3. **"双向返还不能主张同时履行"** —— 错！《合同编通则解释》§25 法院**应予支持**。
4. **"§157 赔偿和缔约过失是两码事"** —— 错！§157 后段赔偿**本身就是缔约过失性质**，同 §500 一个谱系。
5. **"返还前风险一律占有人担"** —— 不严谨！**欺诈 / 胁迫**撤销时，**受害的占有人对意外灭失不担风险**（区分意外 vs 占有人过错）。
