# 📐 管辖变动与异议 · 完整答题模型（先立案优先 + 移送/指定/转移 + 异议与应诉管辖 + 管辖恒定）

> **核心一句**：[[民诉-管辖-管辖确定模型]]解决"案子**该**归谁"（其中"**要不要**移送"的触发情形已在该模型「🚚 移送触发清单」收口，含"不该移送却移送＝违法"的假触发陷阱），本模型解决"案子**动**起来之后怎么办"——即移送**怎么走**的操作规则，本模型是权威源，一条主线四站：**多头有权谁先立案（§36）→ 立错了怎么走（移送§37/指定§38/转移§39）→ 被告怎么反抗（异议§130 I）与沉默的代价（应诉管辖§130 II）→ 定了就不变（恒定，解释§37-39）**。最毒陷阱是**受移送法院"退回"或"再移送"**（唯一出路是报请上级指定）、**用应诉管辖/管辖恒定去治愈级别管辖、专属管辖的违反**（两条治愈路径的法条里都写着"除外"）、**二审才提管辖异议还指望法院审查**（一审答辩期是唯一窗口）、**把"下级报请上级审理"和"上级交下级须报批"两个方向搞反**。
>
> 🔎 **核心条文速查**：
> - **民诉法§36【共同管辖·先立案优先】**：两个以上人民法院都有管辖权的诉讼，原告可以向其中一个人民法院起诉；原告向两个以上有管辖权的人民法院起诉的，由**最先立案**的人民法院管辖。
> - **民诉法§37【移送管辖·一次性】**：人民法院发现受理的案件不属于本院管辖的，应当**移送**有管辖权的人民法院，受移送的人民法院**应当受理**。受移送的人民法院认为受移送的案件依照规定不属于本院管辖的，应当**报请上级人民法院指定管辖，不得再自行移送**。
> - **民诉法§38【指定管辖】**：有管辖权的人民法院由于**特殊原因**不能行使管辖权的，由上级人民法院指定管辖。人民法院之间因管辖权发生争议，由争议双方**协商**解决；协商解决不了的，**报请它们的共同上级人民法院指定管辖**。
> - **民诉法§39【管辖权转移】**：上级人民法院**有权审理**下级人民法院管辖的第一审民事案件；确有必要将**本院**管辖的第一审民事案件**交下级**人民法院审理的，**应当报请其上级人民法院批准**。下级人民法院对它所管辖的第一审民事案件，认为需要由上级人民法院审理的，**可以报请**上级人民法院审理。
> - **民诉法§130【管辖权异议与应诉管辖】**：受理案件后，当事人对管辖权有异议的，应当在**提交答辩状期间**提出。法院应当审查：异议成立的，**裁定移送**有管辖权的法院；不成立的，**裁定驳回**。当事人未提出管辖异议，并**应诉答辩或者提出反诉**的，**视为**受诉法院有管辖权，但违反**级别管辖和专属管辖**规定的**除外**。
> - **民诉法§157【可上诉三裁定】**：裁定适用于（一）不予受理、（二）**对管辖权有异议的**、（三）驳回起诉……对前款第一项至第三项裁定，**可以上诉**。
> - **民诉解释§36【先立案法院不得移送】**：两个以上法院都有管辖权的，**先立案的法院不得将案件移送**给另一个有管辖权的法院；立案前发现其他有管辖权的法院已先立案的，**不得重复立案**；立案后发现的，**裁定将案件移送给先立案的法院**。
> - **民诉解释§37/§38/§39 I【管辖恒定】**：案件受理后，管辖权**不受当事人住所地、经常居住地变更的影响**（§37）；不得以**行政区域变更**为由移送（§38 I）；对管辖异议审查后确定有管辖权的，**不因当事人提起反诉、增加或者变更诉讼请求等改变管辖**，但违反级别管辖、专属管辖规定的**除外**（§39 I）。
> - **民诉解释§39 II【发回重审/再审不审异议】**：人民法院**发回重审或者按第一审程序再审**的案件，当事人提出管辖异议的，人民法院**不予审查**。
> - **民诉解释§329【二审专属管辖纠错】**：二审程序中认为**一审受理案件违反专属管辖**规定的，应当**裁定撤销原裁判并移送**有管辖权的法院。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [民诉解释（法释〔2022〕11号修正，国家法律法规数据库检索）](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已在本地权威全文（ssf.gov.cn发布的民诉法2023全文PDF转文本、民诉解释2022全文）中**逐条grep到原文**后写入：民诉法§36、§37、§38、§39、§130、§157、§278，民诉解释§35、§36、§37、§38、§39、§40、§41、§42、§82、§223、§243、§276、§329、§331。**特别提示三处易错标注**：①管辖恒定**没有一个统一的"管辖恒定条"**，它散落在解释§37（住所变更）、§38（行政区划变更＋审级恒定）、§39 I（反诉/增加变更诉请）三处，均带"级别/专属除外"或各自限定，不可虚标一个总条号；②"受移送法院不得再自行移送"在**民诉法§37本条之内**（2023条号，勿写成旧法§36）；③涉外案件的应诉管辖是**民诉法§278**（2023修正新增，且该条**未写**"级别/专属除外"的但书），与国内案件§130 II表述不同，题目未特别指涉涉外时一律按§130 II作答。

> ⚠️ **易记错点**：①**受移送法院只有两个动作**——受理，或报请上级指定管辖；**退回、再移送第三家、移给自认为有管辖权的法院统统违法**（民诉法§37）；②**应诉管辖和管辖恒定都治不了级别管辖、专属管辖的违反**——§130 II和解释§39 I的但书是命题人年年踩的同一块砖；③**管辖异议的唯一窗口=一审提交答辩状期间**——二审才提、发回重审后才提、按一审程序再审时才提，法院一律**不予审查**（解释§39 II）；④**"提出反诉"本身就是应诉**——反诉后再提管辖异议已经失权（§130 II"应诉答辩**或者提出反诉**"）；⑤管辖权转移的方向性：**上级提审下级案件不需要任何批准**，**上级把自己的案件下放才须报请其上级批准**（§39），别把"报批"安到提审头上；⑥**先立案的法院不得把案件让给另一个有管辖权的法院**（解释§36）——"两家都有权，先立案的谦让一下"恰恰违法；⑦管辖异议裁定**可以上诉**（§157），但**小额诉讼**的管辖异议裁定**一经作出即生效**（解释§276）；⑧"管辖错误"**不是再审事由**——救济靠异议＋裁定上诉，不靠再审。

## 二、 判别模型（抢滩 → 纠错 → 反抗 → 恒定）

```
              【管辖权已按确定规则算出，案件开始"动"】
                            │
     ▼ 第一站：多头有权，谁审？（共同管辖，民诉法§36 + 解释§36）
     │
     ├─ 两个以上法院都有管辖权 ──→ 原告任选其一起诉（选择管辖）
     ├─ 原告向两个以上法院都起诉 ──→ 最先立案的法院管辖（§36）
     └─ 先立案的法院不得移送给另一有管辖权的法院；
        后立案的应裁定移送先立案法院；立案前发现他院已立案的不得重复立案（解释§36）
                            │
     ▼ 第二站：立错了/审不了，怎么走？（移送·指定·转移）
     │
     ├─ 移送管辖（§37）：受理后发现不属本院管辖 → 移送有管辖权的法院，
     │  受移送法院应当受理；仍认为无管辖权 → 报请上级指定，不得再自行移送
     │  （被告未应诉答辩的，一审开庭前发现即裁定移送，解释§35）
     ├─ 指定管辖（§38）：①特殊原因不能行使 → 上级指定；
     │  ②管辖权争议 → 先协商，协商不成报共同上级指定
     │  （逐级报请：同地市→中院，同省→高院，跨省→最高院，解释§40；
     │   指定应作裁定，报请期间下级中止审理，解释§41）
     └─ 管辖权转移（§39）：上级审下级的一审案件 → 有权，径行提审；
        本院一审案件交下级审 → 须报请其上级批准（可下放仅三类，解释§42）；
        下级认为需上级审 → 可以报请上级审理
                            │
     ▼ 第三站：被告怎么反抗？沉默什么代价？（§130 + §157，本模型重头）
     │
     ├─ 提出：当事人（本诉被告为典型；无独三无权提，解释§82）
     │  在【提交答辩状期间】提出——唯一窗口
     ├─ 审查：异议成立 → 裁定移送；不成立 → 裁定驳回；
     │  该裁定可上诉（可上诉三裁定之一，§157）；审查期间不计审限（解释§243）；
     │  小额诉讼的异议裁定一经作出即生效（解释§276）
     ├─ 沉默的代价（应诉管辖，§130 II）：未提异议＋应诉答辩或提出反诉
     │  → 视为受诉法院有管辖权；但违反【级别管辖/专属管辖】的除外——治不了
     └─ 二审四情形：①一审没提二审才提 → 不予审查；
        ②发回重审/按一审程序再审中提 → 不予审查（解释§39 II）；
        ③二审查明一审违反【专属管辖】 → 裁定撤销原裁判并移送（解释§329）；
        ④二审查明违反的仅是【协议管辖】等非专属规则 → 继续审理依法裁判
                            │
     ▼ 第四站：定了就不变（管辖恒定，解释§37/§38/§39 I）
     │
     ├─ 受理后当事人住所地/经常居住地变更 ──→ 不影响管辖（§37）
     ├─ 受理后行政区域变更 ──→ 不得以此为由移送（§38 I）
     ├─ 反诉、增加或变更诉讼请求 ──→ 不改变管辖，
     │  但违反级别管辖、专属管辖的除外（§39 I）
     └─ 审级恒定：上诉/提审 → 原审的上级审；指令再审、发回重审 → 原审法院审（§38 II）
```

> **一句话总诀**：**「多头有权先立案，先立案的不许让（§36+解释§36）；立错只移送一次，再错报请指定不退回（§37）；争议协商不成共同上级指定（§38）；转移上提免批、下放报批（§39）；异议只在答辩期，裁定可上诉；沉默应诉即认账，级别专属治不了（§130）；二审一律不审新异议，只纠专属不纠协议；定了就不变——搬家、划界、加诉请都动不了管辖，超级别线除外」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **受移送法院退回/再移送** | "受移送法院经审查确无管辖权，应当将案件退回原法院/移送真正有管辖权的法院。" | **❌ 错！** 移送只能一次。受移送法院认为不属本院管辖的，**报请上级法院指定管辖，不得再自行移送**（民诉法§37）——退回原法院、移给第三家都属"再自行移送"。 |
| **先立案法院谦让移送** | "两地法院都有管辖权，先立案的法院发现对方更方便审理，将案件移送对方，合法。" | **❌ 错！** 先立案的法院**不得**将案件移送给另一个有管辖权的法院（解释§36）；该移送的是**后立案**的法院（裁定移送先立案法院）。 |
| **应诉管辖治愈级别违反** | "被告已应诉答辩，基层法院对这起远超级别线的案件取得应诉管辖，应继续审理。" | **❌ 错！** 应诉管辖的但书明写"**违反级别管辖和专属管辖规定的除外**"（§130 II）——级别/专属的违反既不被应诉治愈，也不被管辖恒定挡住（解释§39 I同有但书）。 |
| **提了反诉还能提异议** | "被告虽已提出反诉，但答辩期内仍可提出管辖权异议，法院应当审查。" | **❌ 错！** "应诉答辩**或者提出反诉**"即视为受诉法院有管辖权（§130 II）——反诉本身就是应诉，之后再提异议已失权，法院继续审理本诉和反诉。（对照：答辩期内**先提异议**又针对起诉状内容答辩的，法院**仍应审查异议**，解释§223 I。） |
| **二审受理管辖异议** | "上诉人在二审中提出一审无管辖权，二审法院应审查；成立的撤销原判、移送或发回。" | **❌ 错！** 管辖异议的窗口只在**一审提交答辩状期间**；二审才提、发回重审/按一审程序再审中提，一律**不予审查**（解释§39 II）。二审只主动纠一种错：一审**违反专属管辖**的，裁定撤销原裁判并移送（解释§329）；仅违反**协议管辖**的，继续审理依法裁判。 |
| **管辖错误申请再审** | "生效判决系无管辖权的法院作出，当事人可以'管辖错误'为由申请再审。" | **❌ 错！** 现行民诉法再审事由清单中**没有"管辖错误"**。管辖问题的救济通道是：答辩期内提异议＋对异议裁定上诉（§130+§157）；过时不候。 |

## 四、 相邻制度对照表（同场竞技，勿混规则）

| 事项 | 本模型规则 | 相邻制度对照 |
|---|---|---|
| 移送管辖（§37） | **横向**纠错：无管辖权法院 → 有管辖权法院；移送一次为限，受移送法院不服只能报请**指定** | **管辖权转移（§39）**：**纵向**调整：上下级之间；前提是移出法院**本有**管辖权；上提免批、下放报批 |
| 指定管辖（§38） | 两种起因：特殊原因不能行使／管辖权争议协商不成；**逐级**报共同上级，应作**裁定**（解释§40/§41） | **移送后的指定（§37后段）**：受移送法院不服的唯一出路，也归入指定管辖轨道 |
| 管辖权异议（§130 I） | 当事人**主动反抗**：答辩期内提出→审查→裁定移送/驳回→**可上诉**（§157） | **应诉管辖（§130 II）**：当事人**沉默认账**：不提异议＋应诉答辩/反诉→视为有管辖权（级别/专属除外）；**涉外应诉管辖（§278）**：条文未附级别/专属但书 |
| 管辖异议裁定可上诉（§157） | 与不予受理、驳回起诉并列**可上诉三裁定**；上诉审可不开庭（解释§331） | **小额诉讼**：管辖异议裁定**一经作出即生效**（解释§276），无上诉 |
| 管辖恒定（解释§37/§38 I/§39 I） | 住所变更、行政区划变更、反诉/增加变更诉请均**不改变管辖** | **例外**：违反**级别管辖、专属管辖**的除外（§39 I但书）——加诉请加到超过级别线，恒定失灵，应移送有管辖权的上级法院 |
| 本模型（管辖变动） | 管辖权**算出来之后**的运行规则 | **[[民诉-管辖-管辖确定模型]]**：级别、一般/特殊地域、协议、专属——先用它算出"谁有权"，再进本模型 |

## 五、 万能四步答题模型

在法考答题中（客观题逐项判断按此顺序定位考点），按以下四步涵摄：

*   🚗 **统一案例**：老王的甲公司（住所地A市B区）起诉老李的乙公司（住所地C市D区）支付货款**100万元**，合同履行地为C市E区——依确定规则，**D区法院（被告住所地）和E区法院（合同履行地）都有管辖权**。设该省规定标的额**300万元以上**一审归中院。围绕这一个案子，四站剧情轮流上演。

### 第一步：抢滩诀——多头有权，谁先立案谁审

> **任选其一告，两头都告先立案**

#### 概述

- 共同管辖:
	- 管辖确定规则经常算出**不止一个**有管辖权的法院（被告住所地+合同履行地、多个侵权行为地……），这叫**共同管辖**；原告从中挑一家起诉，叫 **选择管辖**。规则两句话（民诉法§36）：
		- 原告**可以向其中一个**法院起诉；原告**向两个以上都起诉**的，由**最先立案**的法院管辖。解释§36把配套堵漏也写死了：**先立案的法院不得**把案件移送给另一个有管辖权的法院（不许"谦让"）；后立案的法院立案前发现他院已先立案的**不得重复立案**，立案后才发现的**裁定移送先立案的法院**。

#### 大白话讲解

老王咨询律师："D区、E区两家法院都能管，我告哪家？"律师说："随便挑，这是你的权利（选择管辖）。"老王贪心，两家**都**递了起诉状——D区法院周一立案，E区法院周三立案。归谁？**最先立案的D区**（§36）。

接下来两个法院各有一个动作要判合法性：

| 法院动作 | 是否合法 | 理由 |
|---|---|---|
| E区法院（后立案）发现D区已先立案，裁定移送D区 | ✅ 合法 | 解释§36：立案后发现他院已先立案的，裁定移送先立案法院 |
| D区法院（先立案）觉得E区离证据更近，把案子移送E区 | ❌ 违法 | 解释§36：**先立案的法院不得**将案件移送另一有管辖权的法院 |
| E区法院立案前就查到D区已立案，仍然立案 | ❌ 违法 | 解释§36：不得重复立案 |

记住方向感：**共同管辖里的移送永远是"后立案→先立案"单行道**，先立案的没有"让贤"的自由。

#### 一句话闭环记忆

> 🎯 **一眼判**：多家法院构成共同管辖时原告有权任选其一起诉；原告向多家法院起诉，由最先立案法院管辖，先立案法院不得移送案件，后立案法院发现在先立案的，立案前禁止重复立案、立案后应当裁定移送先立案法院。

---

### 第二步：纠错诀——立错了/审不了怎么走（移送·指定·转移）

> **移送一次不回头，争议指定上级说，转移上提免批下放批**

#### 概述

案件落错了地方或原法院审不了，三条轨道，各管各的：

- **移送管辖（§37）**——**横向纠错**：法院发现受理的案件**不属于本院管辖**，应当移送有管辖权的法院；受移送法院**应当受理**；受移送法院仍认为自己无管辖权的，**报请上级法院指定管辖，不得再自行移送**——移送以**一次**为限。被告在答辩期届满后未应诉答辩的，法院在**一审开庭前**发现无管辖权即应裁定移送（解释§35）。

- **指定管辖（§38）**——**上级拍板**：
	- ①有管辖权的法院因**特殊原因**（法定回避事由致无法组庭、自然灾害等）不能行使管辖权；
	- ②法院之间发生**管辖权争议**，协商不成——
	
	都由**上级/共同上级**法院指定。报请要**逐级**：同一地市的两基层法院→该地市中院；同省→该省高院；跨省且高院协商不成→最高院（解释§40）。指定管辖应当作出**裁定**；报请期间下级**中止审理**，裁定作出前下级抢着判了的，上级指定时**一并撤销**其判决、裁定（解释§41）。

- **管辖权转移（§39）**——**纵向调整**（前提：移出法院**本来有**管辖权）：
	- 提审: **上级审下级的一审案件**，法条只说"有权审理"，**不需要任何批准**；

	- 下放: **上级把本院的一审案件交下级审**，方向朝下，**应当报请其上级法院批准**，且可下放的仅三类案件

		- 破产程序中有关债务人的诉讼、
		- 当事人人数众多不方便诉讼、
		- 最高院确定的其他类型；

	- **下级报请上级审理** 下级认为案件不宜自身审理，**可以报请，最终由上级决定是否同意**。

- 案件落错了地方 和 原法院审不了
	- 有管辖权，但因法定 / 客观障碍无法开庭审理，即为原法院审不了，适用指定管辖。
	- 案件落错地方 = 法院已经受理，事后发现本院无管辖权，适用移送管辖横向纠错。

#### 大白话讲解

**剧情一（移送）**：老王没听律师的，把乙公司告到了自家门口的**B区法院**（原告住所地，无管辖权）。B区法院受理后发现不对，裁定移送**D区法院**。D区法院翻卷后嘀咕："合同履行地在E区，证据都在那边，我不想接。"它有几个选项：退回B区？移给E区？都**不行**——受移送的D区法院只有两个合法动作：**受理**，或者**报请上级（C市中院）指定管辖**。一个字都不能多走（§37）。真题里那个经典问法"受移送法院如何处理"，答案永远是"**报请上级指定**"（单46/单301的A项）。

**剧情二（指定）**：假设D区、E区两法院为这100万的案子**互相推**，都说自己没管辖权（消极争议）。先**协商**；协商崩了，两家同属C市，**报请C市中院指定**（§38 II+解释§40）。中院指定要出**裁定**；报请期间，下级手里的案子**先停**（中止审理），谁要抢跑先判，中院指定时连判决一起撤（解释§41）。

**剧情三（转移）**：案子在D区法院审着，C市中院认为此案影响重大，发函**提审**——需要谁批准吗？**不需要**，上级审下级的一审案件是法定权力（§39 I前段）。反过来，如果C市中院受理的一件破产程序中有关债务人的诉讼想**交给D区法院**审，方向朝下，就**必须报请该省高院批准**（§39 I后段+解释§42）。一句口诀定方向：**上提免批，下放报批**——多47的C项（中院受理了超出自己级别权限的案件还"报请高院审理"想截留）正是把"下级可报请上级审理"用在了自己**本无管辖权**的案件上，违法。

#### 一句话闭环记忆

> 🎯 **一眼判**：立案后本院无管辖权适用**移送管辖（横向、移送仅限一次，受移送法院不得自行再移送）**；有管辖权但客观不能审理、法院间管辖争议协商不成适用**指定管辖（上级裁定）**；本院原本享有管辖权，上下级之间级别变通适用**管辖权转移**: 上级可直接提审下级案件无需报批、下级也可报请上级审理，决定权归上级；上级下放案件仅限三类且必须报请上级批准 。
---

### 第三步：反抗诀——异议只有一扇窗，沉默应诉即认账（本模型重头）

> **答辩期内提异议，裁定两分可上诉；答辩反诉即应诉，级别专属治不了**

#### 概述

被告认为受诉法院无管辖权，法律给了一件正式武器——**管辖权异议**（民诉法§130 I），但配了严格的使用说明：

- **谁能提**：当事人（典型是本诉被告）；**无独立请求权第三人无权提**（解释§82）。向**受诉法院**提，不能越级直接向上级法院提。

- **何时提**：**提交答辩状期间**（唯一窗口）。答辩期内**既提异议又答辩实体内容**的，不算放弃，法院**仍应审查异议**（解释§223 I）。 管辖异议只能在答辩期内提出；答辩期未提异议又反诉 / 实体答辩，应诉管辖即时生效；庭前会议、开庭阶段再提管辖异议一律不予审查

- **怎么处理**：
	- 法院**应当审查**——异议成立，**裁定移送**有管辖权的法院；不成立，**裁定驳回**。

	- 对 裁定驳回 可以上诉: 
		- 这个裁定与"不予受理""驳回起诉"并列**可上诉三裁定**（§157 I(一)~(三)+§157 II）；上诉审可**不开庭**（解释§331）；
			- **裁定不予受理**
				- 立案受理前，法院审查发现起诉**不满足法定起诉条件**，作出不予立案裁定。
    
			- **裁定驳回起诉**
			    
			    案件已经立案受理，审理中发现起诉**不满足法定起诉条件**，裁定从程序上驳回原告起诉。
			    
			- **驳回管辖权异议裁定**
			    
			    一审受理案件后，被告在答辩期提出管辖异议；法院审查认为本院享有管辖权，裁定驳回异议。

		- 二审上诉处理
			- 对该裁定上诉的二审**只审管辖权归属，不碰实体**（实体尚未经一审）。

			- 审理异议和处理管辖争议的期间**不计入审限**（解释§243）。

			- 例外：**小额诉讼**的管辖异议裁定**一经作出即生效**，不可上诉（解释§276）。

- 应诉答辩
	- **沉默的代价（应诉管辖，§130 II）**：当事人**未提管辖异议**，并**应诉答辩或者提出反诉**的，**视为**受诉法院有管辖权——本来无权的法院被"坐实"。就实体内容进行答辩、陈述或反诉即构成应诉答辩（解释§223 II）。**但书**：违反**级别管辖和专属管辖**规定的**除外**——这两种违反是"制度级"的，当事人的沉默治愈不了。

- **二审阶段四分法**：
	- ①一审没提（或已应诉）、**二审才提**→**不予审查**；
	- ②**发回重审/按一审程序再审**的案件中提→**不予审查**（解释§39 II）；
	- ③二审查明一审**违反专属管辖**→裁定**撤销原裁判并移送**（解释§329）；
	- ④二审查明违反的仅是**协议管辖**等非专属规则→**继续审理依法裁判**（避免程序空转）。

- **管辖错误不是再审事由**：救济通道到"异议+裁定上诉"为止。

#### 大白话讲解

剧本回到主线：老王在**B区法院**（本无管辖权）起诉乙公司100万。老李收到起诉状副本，答辩期15天开始倒计时，他面前有两条路：

**路线一（反抗）**：老李在答辩期第10天向B区法院书面提出管辖权异议："双方约定和法定的管辖法院里没有B区。"B区法院审查后认为异议**成立**，**裁定**将案件**移送D区法院**；如果法院认为不成立，**裁定驳回**——老李对驳回裁定不服，**10日内可以上诉**到中院，中院**只审"B区有没有管辖权"这一件事**，绝不顺手审100万货款的实体问题（单348的A项）。提异议的同时，老李完全可以"防御性"地把实体答辩状也交了——解释§223 I说了，先提了异议的，答辩不算认账，法院照样审异议。

**路线二（沉默）**：老李没当回事，答辩状里只争"货有质量问题不该付款"（实体答辩），甚至反手提了个**反诉**要老王赔运费。这一答辩/一反诉，**应诉管辖**触发（§130 II）：B区法院**视为有管辖权**。等庭前会议老李翻出管辖协议再喊异议——**晚了，失权**，法院**继续审理本诉和反诉**（单50/单308的A项）。等一审败诉、上诉时才喊"一审没管辖权"——二审**不予审查、裁定驳回**（单49/单300的B项，单51/单302的C项）。

**但沉默也有治不了的病**：换个数字——老王诉请不是100万而是**350万**，超过了级别线（300万以上归中院），案子却在D区基层法院审。老李应诉答辩了，基层法院就能审了吗？**不能**——应诉管辖的但书明写"违反**级别管辖**和**专属管辖**规定的除外"，老李照样**有权提异议**，法院也应当把案件移送中院（多30的BC项）。

**二审的两副面孔**：二审对"当事人新提的异议"一律冷脸（不予审查，含发回重审、按一审程序再审的场合，解释§39 II——单48的D项）；但对"一审**违反专属管辖**"会主动出手：裁定撤销原裁判并移送（解释§329）。夹在中间的是**协议管辖**：二审查明双方确有管辖协议、一审违反了它——**不撤销、不移送，继续审理依法裁判**（单52/单309的C项）。逻辑是：专属管辖是公益底线，必须纠；协议管辖是私益安排，被告一审不吭声等于弃权，程序安定优先。

**最后一格：救济地图**（多311）——向**受诉法院**提异议✅；越级向上级法院提❌；异议裁定**上诉**✅；以"管辖错误"申请**再审**❌（不在再审事由清单里）。

#### 一句话闭环记忆

> 🎯 **一眼判**：管辖权异议由一审被告在答辩期内向受诉法院提出，无独三无权提出；答辩期内同时提管辖异议又作出实体答辩不阻碍异议审查，异议成立裁定移送、不成立裁定驳回，普通程序该裁定可上诉，小额诉讼管辖异议裁定一审终审；普通程序的不服驳回管辖权异议裁定在裁定书送达 10 日内上诉期间上诉, **一审法院**暂停实体审理（不能开庭、不能调查实体、不能做实体裁判）,二审只审管辖、不审实体，该案可以不开庭审理；;  答辩期内(**收到起诉状 15 日**) ,唯一可以【向一审法院提交管辖权异议】的窗口期 , 被告没有提管辖异议，同时作出实体答辩或提起反诉，应诉管辖成立，受诉法院取得管辖权；应诉管辖不能对抗级别管辖、专属管辖；一审未提管辖异议二审新提管辖异议,二审原则不予审查并驳回异议; 发回重审与一审再审阶段提异议均不予审查；二审只纠错专属管辖错误，协议、地域管辖错误因当事人一审弃权不予纠正；所有管辖错误均不得作为再审理由。

### 第四步：恒定诀——定了就不变，只有级别专属能掀桌

> **搬家划界加诉请，管辖恒定都不理；一旦踩线级别专属，恒定应诉全失灵**

#### 概述

案件受理这一刻，管辖权就**冻结**了——诉讼中的各种变化原则上都动不了它：

- **当事人住所地、经常居住地变更**→不影响（解释§37）；
- **行政区域变更**→不得以此为由移送（解释§38 I）;
- **反诉、增加或变更诉讼请求**→不改变管辖（解释§39 I）——哪怕加得标的额变了；
- **审级恒定**（解释§38 II）：上诉案件、提审案件由**原审法院的上级**审判；指令再审、发回重审的案件由**原审法院**审理——发回重审回到原一审法院，不因当事人此间搬家而换法院（与解释§39 II"重审中异议不予审查"互为表里）。

唯一的掀桌者仍是那对老搭档：解释§39 I的但书——**违反级别管辖、专属管辖规定的除外**。增加诉请把标的额顶破级别线的，恒定失灵，案件应当移送有管辖权的上级法院。另注意一个前置问题：变更/增加诉讼请求本身有时间窗口（法庭辩论终结前），**辩论终结后才变更的，变更根本不生效**，连"要不要动管辖"的问题都不产生（单31）。

#### 大白话讲解

案子在**D区法院**安稳审着，剧情连环试探：

| 诉讼中发生的变化 | 管辖动不动 | 理由 |
|---|---|---|
| 乙公司把住所迁到了F区 | 不动 | 解释§37：受理后住所地变更不影响（单48里海北公司迁址提异议，法院连审查都不审查） |
| 行政区划调整，D区并入G区 | 不动 | 解释§38 I：不得以行政区域变更为由移送（多47的A项"被告搬家就移送"、多316的A项，皆违法） |
| 老李反诉、老王加了50万利息诉请（合计150万，未过级别线） | 不动 | 解释§39 I：反诉、增加变更诉请不改变管辖 |
| 老王把诉请加到**350万**（过了300万级别线） | **动！** | 解释§39 I但书：违反级别管辖的除外——D区基层法院应将案件移送中院（多30的B项） |
| 法庭辩论**终结后**、法官写判决书时，老王才把诉请变更为350万 | 不动（变更无效） | 变更窗口是"法庭辩论结束前"，逾期变更不发生效力，法院按原20万/100万诉请径行判决（单31的C项），350万的级别问题根本不产生 |
| 二审撤销原判**发回重审**，重审期间乙公司又迁址并提管辖异议 | 不动＋不审 | 解释§38 II发回原审法院重审＋解释§39 II重审中异议不予审查（单48的D项） |

把这张表看熟，"管辖恒定"类选项基本是**送分**：诉讼中的世事变迁（搬家、划界、加请求）一概挡在门外；唯独看到"**超级别线**""**专属管辖**"字眼时立刻警觉——那是恒定和应诉都罩不住的两个天窗。

#### 一句话闭环记忆

> 🎯 **一眼判**：管辖恒定以案件受理时为准，受理后当事人住所地变动、行政区划调整、反诉或增减变更诉讼请求，原则不改变管辖；**例外为违反级别管辖、专属管辖；法庭辩论终结后变更诉请不生效；发回重审、一审再审阶段提出管辖异议不予审查**。

## 六、 易混提示

*   **移送管辖 vs 管辖权转移**：
    *   *移送*是**横向**的纠错（无管辖权→有管辖权，民诉法§37）；*转移*是**纵向**的调整（上下级之间，且以移出法院**本有管辖权**为前提，§39）。方向、前提、程序全不同：移送不需批准但一次为限；转移中**上提免批、下放报批**。
*   **指定管辖的两个入口**：
    *   入口一：特殊原因不能行使/管辖权争议协商不成（§38）；入口二：**受移送法院不服移送**（§37后段）。两个入口最终都汇入"上级指定"轨道——所以"受移送法院怎么办"的答案永远是"报请上级指定"，不是"发回""退回""再移送"。
*   **应诉管辖 vs 管辖恒定**：
    *   *应诉管辖*治的是**当事人不反抗**（沉默认账，§130 II）；*管辖恒定*治的是**客观情况变化**（搬家划界加诉请，解释§37-39）。两者是不同问题的答案，但共享同一条但书：**级别管辖、专属管辖的违反谁都治不了**。
*   **"提异议+答辩" vs "只答辩"**：
    *   答辩期内**先提异议**再实体答辩的→异议**仍应审查**（解释§223 I）；**未提异议**径行实体答辩/陈述/反诉的→构成**应诉答辩**（解释§223 II）。一步之差，天壤之别。
*   **二审纠专属 vs 不纠协议**：
    *   二审查明一审违反**专属管辖**→撤销原裁判+移送（解释§329）；查明违反的仅是**协议管辖**→继续审理依法裁判。专属=公益底线必纠；协议=私益安排，一审不吭声即弃权。

## 七、 命题人最爱的 6 个陷阱

1.  **"受移送法院认为无管辖权的，应退回原法院或移送有管辖权的法院"** —— 错！唯一出路是**报请上级法院指定管辖**，退回、再移送都被"不得再自行移送"（民诉法§37）明文封死。
2.  **"两地法院都有管辖权，先立案的法院可以将案件移送更方便的另一法院"** —— 错！**先立案的法院不得移送**给另一有管辖权的法院（解释§36）；单行道方向是"后立案→先立案"。
3.  **"被告已应诉答辩（或已提出反诉），基层法院对超级别线/违反专属管辖的案件取得应诉管辖"** —— 错！应诉管辖的但书：**违反级别管辖和专属管辖规定的除外**（§130 II）；同理管辖恒定也有同款但书（解释§39 I）。
4.  **"二审中提出管辖异议的，二审法院应当审查；发回重审中提异议的，重审法院应当审查"** —— 错！异议窗口只在**一审提交答辩状期间**；二审才提、发回重审或按一审程序再审中提，一律**不予审查**（解释§39 II）。
5.  **"二审查明双方确有管辖协议而一审违反的，应撤销原判、移送协议法院"** —— 错！二审只主动纠**专属管辖**的违反（撤销+移送，解释§329）；违反**协议管辖**（非专属）的，为程序安定**继续审理依法裁判**。
6.  **"上级法院提审下级法院的一审案件须报请批准／下级法院可将超出自己权限的案件报请上级审理予以截留"** —— 错！方向别搞反：**上级提审不需要批准**；**上级下放本院案件才须报请其上级批准**（且限三类案件，§39+解释§42）；下级对**本无管辖权**的案件谈不上"报请上级审理"，应径行移送。

| [[民诉-管辖-单选-309 · 管辖异议被驳回后缺席判决与二审处理]] | **异议裁定的既定力。**管辖异议被裁定驳回且**未上诉**即生效，管辖权就此确定；其后拒不到庭，法院缺席判决程序合法；二审**继续审理**（C对），不因事后又搬出管辖协议而撤销原判（协议管辖非专属，二审不纠）。                                                                     | **第三步·异议裁定可上诉（未上诉即定）+ 二审纠专属不纠协议** |
| [[民诉-管辖-多选-311 · 管辖权异议的合法救济途径]]      | **救济地图。**向**受诉法院**提异议（A对）；越级直接向上级法院提（B错）；异议裁定属可上诉三裁定，**可上诉**（C对，§157）；"管辖错误"**不是再审事由**（D错）。选AC。                                                                                | **第三步·提出对象+裁定上诉+非再审事由**           |
| [[民诉-二审-单选-348 · 管辖异议裁定上诉的二审审查范围]]   | **裁定上诉只解决程序问题。**对管辖异议裁定的上诉，二审**仅审查管辖权归属，不审理实体案件**（A对）——实体争议尚未经一审，二审无从触碰，更谈不上改判实体（C错）。                                                                                          | **第三步·异议裁定上诉的审查范围**               |
