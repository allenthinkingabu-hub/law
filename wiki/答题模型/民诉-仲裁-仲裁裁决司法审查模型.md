# 📐 仲裁裁决司法审查 · 完整答题模型（撤销 vs 不予执行 · 新《仲裁法》2026-03-01施行）

> **核心一句**：当事人对仲裁裁决不服，只有**「撤销」与「不予执行」两条路**（既不能起诉、也不能申请再审）。考试主线是 **「两条路 → 撤销事由/期限/中院 → 不予执行事由/执行法院 → 两者择一与衔接 → 被否之后重新签协议再仲裁或起诉」**。本章头号背景是**新《仲裁法》（2025-09-12修订通过、2026-03-01施行、8章96条）已把撤销与不予执行的事由清单、条文号全面重排**：真题卡旧号（撤销§58、期限6个月、一裁终局§9、效力异议§20）必须换成新号（撤销**§71**、期限**3个月**、一裁终局**§10**、效力异议**§31**）。最毒陷阱是**把撤销期限仍写"6个月"（新法已改3个月）**、**把撤销和不予执行的管辖/时机搞混**、**以为撤销被驳回后还能拿同一事由申请不予执行**、**把国内与涉外的审查事由混用（涉外只审程序、不审实体）**、**以为裁决被撤销后原仲裁协议还继续有效**。
>
> 🔎 **《仲裁法》（2025修订，2026-03-01施行）核心条文速查**：
> - **第10条【一裁终局＋被否后果】**：仲裁实行**一裁终局**，裁决作出后当事人就同一纠纷再申请仲裁或起诉的，**不予受理**。裁决被法院依法裁定**撤销或者不予执行**的，当事人就该纠纷可以**根据双方重新达成的仲裁协议申请仲裁，也可以向法院起诉**。
> - **第39条【财产保全/行为保全】**：一方当事人的行为或其他原因可能使裁决难以执行的，可申请财产保全、请求责令对方作出或禁止作出一定行为；当事人申请的，**仲裁机构应当将申请依民诉法提交法院**；情况紧急的，可在申请仲裁前直接向法院申请。
> - **第58条【证据保全·国内】**：证据可能灭失或以后难以取得的，当事人可申请证据保全；仲裁中申请的，**仲裁机构应当将申请提交证据所在地的基层人民法院**；情况紧急的，可在申请仲裁前直接向法院申请。
> - **第71条【撤销裁决·国内·事由清单】**：当事人提出证据证明裁决有下列情形之一的，可以**向仲裁机构所在地的中级人民法院申请撤销**：（一）没有仲裁协议；（二）裁决的事项不属于仲裁协议的范围或者仲裁机构无权仲裁；（三）仲裁庭的组成或者仲裁的程序违反法定程序；（四）裁决所根据的证据是伪造的；（五）对方当事人隐瞒了足以影响公正裁决的证据；（六）仲裁员在仲裁该案时有索贿受贿、徇私舞弊、枉法裁决行为。法院经**组成合议庭审查核实**有前款情形之一的，应当裁定撤销。法院认定裁决**违背公共利益**的，应当裁定撤销。
> - **第72条【撤销期限】**：当事人申请撤销裁决，应当**自收到裁决书之日起三个月内**提出。（⚠️旧法§59为**六个月**）
> - **第73条【撤销审查期限】**：法院应当在受理撤销申请之日起**两个月内**作出撤销或者驳回申请的裁定。
> - **第74条【通知重新仲裁】**：法院受理撤销申请后认为可以由仲裁庭重新仲裁的，**通知仲裁庭在一定期限内重新仲裁，并裁定中止撤销程序**；仲裁庭开始重新仲裁的，法院裁定**终结**撤销程序；仲裁庭**拒绝**重新仲裁的，法院裁定**恢复**撤销程序。
> - **第76条【不予执行·国内】**：被申请人提出证据证明裁决有**本法第71条第一款规定情形之一**的，经法院组成合议庭审查核实，裁定不予执行。法院认定执行该裁决违背公共利益的，应当裁定不予执行。
> - **第77条【执行与撤销的衔接】**：一方申请执行、另一方申请撤销的，法院应当裁定**中止执行**；法院裁定**撤销**裁决的，应当裁定**终结执行**；撤销申请被裁定**驳回**的，法院应当裁定**恢复执行**。
> - **第83条【撤销·涉外·事由】/第84条【不予执行·涉外】**：涉外仲裁裁决撤销/不予执行的事由为纯程序性**4项**：无仲裁协议 / 被申请人未获指定仲裁员或仲裁程序通知、或因不属自己负责的原因未能陈述意见 / 组庭或程序与**仲裁规则**不符 / 超裁；＋违背公共利益。（**不审实体**，无"证据伪造/枉法裁决"）
> - **对应民诉法（2023修正）**：**第248条**（不予执行国内仲裁裁决的6项事由与后果，旧号§244）；**第291条**（不予执行涉外仲裁裁决的4项事由）；**第84条**（诉前/诉中证据保全）。
> - **官方链接**：[中国人大网·新《仲裁法》（2025修订）](http://www.npc.gov.cn/npc/////c2/c30834/202509/t20250912_447759.html)｜[民诉法2023全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)｜[国家法律法规数据库（flk.npc.gov.cn）](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：①新《仲裁法》撤销事由§71、期限§72（3个月）、审查期限§73（2个月）、重新仲裁§74、不予执行§76、执行衔接§77、涉外撤销§83/不予执行§84、一裁终局§10、效力异议§31、财产保全§39、证据保全§58/§79，均已在**本地新法官方全文（npc）逐字grep核到**，可信度高。②民诉法§248（国内不予执行）、§291（涉外不予执行）已在**民诉法2023官方全文（ssf）逐字核到**。③**下列三条规则本地全文未核到，源自单行仲裁司法解释、标注可信但非本地逐字核验**：**a.**「撤销申请被驳回后又以同一事由申请不予执行的不予支持」——原《仲裁法司法解释》（法释〔2006〕7号）§26精神；**b.**「确认仲裁协议效力由仲裁机构所在地或签订地中院管辖」「仲裁机构已就效力作出决定后当事人再请求法院确认的不予受理」——法释〔2006〕7号§12、§13；**c.**「中院拟撤销/不予执行境内裁决须报请高院审核」——《最高法关于仲裁司法审查案件报核问题的有关规定》（法释〔2017〕21号，2021修正）。这三条2025新法体系下的具体承接条文本地未逐字核到，凡引用处均已注明"以官方文本为准"。④官方NPC文章URL在各信源间略有出入（本模型采用任务指定的 t20250912_447759.html；真题卡中另见 t20250912_446000 / 447762 等编号），以中国人大网发布的《仲裁法》2025修订正式文本为准。

> ⚠️ **易记错点（撤销 vs 不予执行 · 新旧条号）**：
> ① **撤销期限＝3个月（新法§72），不是6个月**——旧法§59是6个月，2025新法改为3个月，是本章最高频的"新旧陷阱"，真题卡凡写"6个月"的均系旧号，一律换3个月；
> ② **管辖别搞混**：撤销找**仲裁机构所在地中院**（§71），不予执行找**执行法院**（§76、民诉法§248）——不是都找中院、也不是都找执行法院；
> ③ **新法下撤销事由＝不予执行事由**：新§76直接援引§71第一款，二者事由**完全一致**（旧法时代民诉法与仲裁法的清单曾有细微措辞差异，新法已彻底统一）；
> ④ **国内审实体、涉外只审程序**：国内§71有"证据伪造/隐瞒证据/枉法裁决"等实体性事由，涉外§83只有"无协议/未获通知未陈述/程序与规则不符/超裁"4项纯程序事由，**涉外不审证据真伪、不审枉法**；
> ⑤ **违背公共利益是法院依职权的独立事由**（§71III/§76II），不需当事人举证，与前款"当事人提出证据证明"的6项并列；
> ⑥ **撤销被驳回后，同一事由不能再申请不予执行**（择一衔接，防重复审查）；但**不同事由**仍可另行主张；
> ⑦ **裁决被撤销/不予执行后原仲裁协议不当然有效**——须**重新达成**仲裁协议方可再仲裁（§10II），否则只能起诉；
> ⑧ **重新仲裁是"通知"不是"命令"**：仲裁庭**可以拒绝**（拒绝则法院恢复撤销程序，§74），且重新仲裁由**原仲裁庭**进行、裁决仍**终局**；
> ⑨ **对裁决/撤销裁定的"三不"**：不能起诉（一裁终局）、不能再审（非法院裁判）、不能抗诉（撤销裁定作出即生效、无检察监督）；
> ⑩ **仲裁无"先予执行"**：仲裁中能申请的是财产保全/证据保全/行为保全（由仲裁机构转交法院），没有先予执行制度。

## 二、 判别模型（不服 → 撤销/不予执行 → 择一衔接 → 被否之后）

```
                【当事人对仲裁裁决不服 / 或被申请执行】
                                │
     ▼ 第一关：只有两条路（起诉、再审都堵死）
     │
     ├─ 一裁终局（§10）：有仲裁协议 → 不能就同一纠纷起诉
     ├─ 仲裁裁决非法院裁判 → 不能申请再审、不能抗诉
     └─ 能走的只有：① 申请【撤销】  ② 申请【不予执行】
                  │
     ▼ 第二关：走【撤销】——凭什么、去哪、多久？（§71/§72/§73/§74）
     │
     ├─ 主体：任一当事人（不服的一方，主动出击）
     ├─ 管辖：仲裁机构所在地【中级人民法院】，组成合议庭审查
     ├─ 期限：自收到裁决书之日起【3个月】内（新法§72，旧法6个月❌）
     ├─ 国内事由（§71，6项）：无协议/超裁或无权仲裁/组庭或程序违法/
     │  证据伪造/隐瞒证据/仲裁员枉法裁决 ＋ 违背公共利益（法院依职权）
     ├─ 涉外事由（§83，仅4项纯程序）：无协议/未获通知未陈述/程序与规则不符/超裁
     └─ 法院可通知仲裁庭重新仲裁（§74）：中止撤销程序；仲裁庭开始→终结，
        仲裁庭【拒绝】→恢复撤销程序（仲裁庭可以拒绝，原庭进行，裁决仍终局）
                  │
     ▼ 第三关：走【不予执行】——凭什么、去哪、何时？（§76/民诉§248）
     │
     ├─ 主体：被申请执行人（被动防守，只有被执行时才用）
     ├─ 管辖：【执行法院】（不是中院！）
     ├─ 时机：执行程序中、执行终结前提出（民诉解释§479）
     ├─ 国内事由：§76援引§71第一款（＝撤销事由）＋违背公共利益
     └─ 涉外事由：§84援引§83（民诉§291，4项纯程序）
                  │
     ▼ 第四关：两者什么关系？（择一/衔接铁律）
     │
     ├─ 一方申请执行＋另一方申请撤销 → 法院裁定【中止执行】（§77）
     ├─ 撤销 → 终结执行；驳回撤销 → 恢复执行（§77）
     └─ 撤销申请被【驳回】后，又以【同一事由】申请不予执行 → 不予支持/不予受理
        （法释〔2006〕7号§26精神，防重复审查；不同事由仍可另行主张）
                  │
     ▼ 第五关：裁决被否之后怎么办？（§10II）
     │
     ├─ 原仲裁协议【不当然继续有效】——须重新达成
     ├─ 想再仲裁：根据【双方重新达成的仲裁协议】申请仲裁
     └─ 或径行【向法院起诉】（按普通管辖规则；不动产/房屋租赁→专属管辖）
```

> **一句话总诀**：**「对裁决不服只有撤销＋不予执行两条路，起诉再审都不行；撤销找中院、3个月、任一当事人主动打，不予执行找执行法院、被执行时被动防；新法下两者事由已统一（§71＝§76），涉外只审程序4项、不审实体；一方执行一方撤销就中止执行，撤销被驳回后同一事由不能再不予执行；裁决被否后原协议失效，重新签协议再仲裁或直接起诉」**

## 三、 高频干扰选项（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（新法依据） |
|---|---|---|
| **撤销期限仍写6个月** | 当事人申请撤销裁决，应当自收到裁决书之日起**六个月内**提出。 | **❌ 错！新法§72已改为3个月。**旧《仲裁法》§59是6个月，2025修订（2026-03-01施行）缩短为**3个月**，凡"6个月"均系旧号失效表述。 |
| **撤销/不予执行管辖混同** | 当事人既可向中院申请撤销，也可向**中院**申请不予执行。 | **❌ 错！**撤销找**仲裁机构所在地中院**（§71），不予执行找**执行法院**（§76、民诉§248），后者未必是中院。 |
| **撤销被驳回后再不予执行** | 撤销申请被驳回后，当事人仍可就**同一事由**向执行法院申请不予执行。 | **❌ 错！**同一事由已经中院审查并被驳回，再申请不予执行属重复审查，**不予支持/不予受理**（法释〔2006〕7号§26精神）；撤销被驳回后应**恢复执行**（§77）。 |
| **涉外也能审证据真伪** | 涉外仲裁裁决"所依据证据伪造"的，可申请撤销/不予执行。 | **❌ 错！**涉外事由§83/§84仅4项**纯程序性**（无协议/未获通知未陈述/程序与规则不符/超裁），**不审实体、不审证据真伪、不审枉法裁决**。 |
| **裁决被撤销后原协议仍有效** | 裁决被撤销后，原仲裁协议继续有效，可径行再申请仲裁。 | **❌ 错！**原协议**不当然继续有效**，须**重新达成**仲裁协议方可再仲裁，否则只能起诉（§10II）。 |
| **仲裁裁决可申请再审/抗诉** | 对裁决或撤销裁定不服，可申请再审或申请检察院抗诉。 | **❌ 错！**仲裁裁决非法院裁判、不适用审判监督；撤销/不予执行裁定作出即生效，**无上诉、无再审、无抗诉**。 |
| **仲裁中可先予执行** | 仲裁中当事人可向法院/仲裁委申请先予执行。 | **❌ 错！**仲裁**无先予执行制度**；能申请的是财产保全/证据保全/行为保全，由仲裁机构转交法院（§39/§58）。 |

## 四、 相邻制度对照（本章最核心两张表）

### 表A：撤销 vs 不予执行（务必做透）

| 事项 | **撤销仲裁裁决**（§71-§74） | **不予执行仲裁裁决**（§76、民诉§248） |
|---|---|---|
| 管辖法院 | 仲裁机构所在地**中级人民法院**（合议庭审查） | **执行法院**（受理执行申请的法院，合议庭审查） |
| 申请主体 | **任一当事人**（对裁决不服的一方，主动进攻） | **被申请执行人**（被动防守，只有进入执行才用） |
| 启动时机 | 自**收到裁决书之日起3个月内**（§72，主动型） | 执行程序中、**执行终结前**提出（民诉解释§479，被动型） |
| 国内事由清单 | §71：①无协议 ②超裁/无权仲裁 ③组庭或程序违法 ④证据伪造 ⑤隐瞒证据 ⑥仲裁员枉法裁决 ＋违背公共利益 | §76**援引§71第一款**（＝撤销事由）＋违背公共利益；民诉§248并列6项，实质相同 |
| 涉外事由清单 | §83：仅4项纯程序（无协议/未获通知未陈述/程序与规则不符/超裁）＋违背公共利益 | §84**援引§83**；民诉§291同为4项 |
| 可否通知重新仲裁 | **可以**（§74，法院认为可重新仲裁的通知仲裁庭，中止撤销程序） | **不可以**（不予执行程序无"通知重新仲裁"制度） |
| 与执行的衔接 | 一方执行＋一方撤销→中止执行；撤销→终结执行，驳回→恢复执行（§77） | 裁定不予执行即终结本次执行 |
| 裁定救济 | 作出即生效，**不得上诉/抗诉/再审**（境内裁决须报请高院审核） | 同左，作出即生效，不得上诉/抗诉/再审 |
| 被否后果 | §10II：原协议不当然有效→重新达成仲裁协议再仲裁 或 起诉 | §10II：同左（重新达成协议再仲裁 或 起诉） |
| **择一衔接铁律** | 撤销被**驳回**后，同一事由**不得**再申请不予执行（防重复审查，法释〔2006〕7号§26） | 反向亦然：已被审查驳回的同一事由不再重复审 |

> ⚠️ **一句话抓总（表A）**：**撤销＝"主动·中院·3个月·可重新仲裁"；不予执行＝"被动·执行法院·执行中·不重新仲裁"；新法下事由已统一（§71＝§76）；撤销被驳回，同一事由的不予执行就此关门。**

### 表B：国内仲裁 vs 涉外仲裁 · 司法审查事由

| 审查维度 | **国内仲裁**（§71撤销 / §76不予执行） | **涉外仲裁**（§83撤销 / §84不予执行；民诉§291） |
|---|---|---|
| 事由数量 | 6项＋公共利益 | **仅4项**＋公共利益 |
| 是否审实体 | **审**（含"证据伪造""隐瞒证据""仲裁员枉法裁决"等实体性瑕疵） | **不审实体**（纯程序性审查） |
| 具体事由 | 无协议 / 超裁·无权仲裁 / 组庭·程序违法 / 证据伪造 / 隐瞒证据 / 枉法裁决 | 无协议 / 被申请人未获通知或未能陈述意见 / 组庭·程序与**仲裁规则**不符 / 超裁 |
| 程序违反的参照系 | 违反**法定程序** | 与**仲裁规则**不符（更尊重当事人约定的规则） |
| 证据保全移交法院 | 证据所在地**基层法院**（§58） | 证据所在地**中级法院**（§79） |

> ⚠️ **一句话抓总（表B）**：**国内"6项审到实体"，涉外"4项只审程序"；看到"涉外仲裁 + 证据伪造/枉法裁决可撤销"直接判错。**

## 五、 万能五步答题模型

无论客观题选项判断还是主观题分析，按以下五步涵摄：

*   🧾 **统一案例**：甲公司（住所A市）与乙公司（住所B市）签订买卖合同，约定"因本合同纠纷提交C市仲裁委员会仲裁"（C市仅此一家仲裁委）。后发生纠纷，甲申请仲裁，C市仲裁委组成三人仲裁庭作出裁决：**乙向甲支付货款100万元**。乙不服，且发现裁决所依据的一份验收单系甲伪造。乙拒不履行，甲向乙住所地B市法院申请强制执行。

### 第一步：判救济路径——不服裁决有几条路？

> **一裁终局堵起诉，非法院裁判堵再审，只剩撤销＋不予执行**

#### 概述
仲裁实行**一裁终局**（§10）：有有效仲裁协议、裁决已作出的，当事人**不能就同一纠纷向法院起诉**；仲裁裁决也**不是人民法院的生效裁判**，不适用审判监督程序，**不能申请再审、不能申请检察院抗诉**。当事人对裁决不服，法律只留了两条路：**①申请撤销（主动进攻）②申请不予执行（被动防守）**。

#### 大白话讲解
乙不服这份"付100万"的裁决，脑子里冒出四个念头，仲裁老师逐一给他划掉两个：
- "我去法院**起诉**行不行？"——不行。你和甲白纸黑字约定了仲裁、裁决也出了，**一裁终局**，法院不受理（§10）。
- "那我申请**再审**？"——也不行。再审是针对法院判决的，仲裁裁决不是法院判的，没有再审这一说，检察院也不会抗诉。
- 剩下两条真能走的：**申请撤销**（自己主动去中院把裁决"撤掉"）、**申请不予执行**（等甲来执行时，我在执行法院这一头"顶回去"）。

本案甲已经向B市法院申请强制执行了，所以乙**两条路都摆在面前**：既可以（3个月内）去C市中院申请撤销，也可以在B市执行法院这边申请不予执行。

#### 一句话闭环记忆
> 🎯 **一眼判**：对仲裁裁决不服＝**"撤销＋不予执行"两条路**；一裁终局→**不能起诉**、非法院裁判→**不能再审/抗诉**。见"可以起诉""可以申请再审"直接判错。

---

### 第二步：判撤销——凭什么撤、去哪撤、多久内撤？

> **中院3个月任一方，六项事由加公益，程序违法可重裁**

#### 概述
撤销是**主动进攻型**救济：**任一当事人**（不服的一方）**自收到裁决书之日起3个月内**（新法§72，旧法6个月已失效），向**仲裁机构所在地的中级人民法院**申请，法院**组成合议庭审查**。国内撤销事由（§71）共**6项**——①无仲裁协议 ②超裁或仲裁机构无权仲裁 ③仲裁庭组成或仲裁程序违反法定程序 ④裁决所根据的证据是伪造的 ⑤对方隐瞒了足以影响公正裁决的证据 ⑥仲裁员索贿受贿、徇私舞弊、枉法裁决——加上法院**依职权**认定的"违背公共利益"。法院受理后认为可以重新仲裁的，**通知仲裁庭重新仲裁**并中止撤销程序（§74）。

#### 大白话讲解
乙决定先走撤销这条路。他要搞清三件事：**去哪、多久、凭什么**。
- **去哪**：仲裁委在C市，就去**C市中级法院**（不是乙自己所在的B市，也不是甲的A市），而且法院得**组成合议庭**审，不能一个法官独任。
- **多久**：从**收到裁决书那天起3个月**内提出。⚠️这里最容易踩坑——很多旧资料写"6个月"，那是2025年前的旧法§59；**新法§72已经改成3个月**，2026年考试按3个月。
- **凭什么**：乙手里正好攥着"验收单是甲伪造的"这张牌——这落在§71第（四）项"**裁决所根据的证据是伪造的**"，是法定撤销事由。乙以此申请撤销，法院审查核实属实的，**应当裁定撤销**。

假设换个情节：如果双方约定"3名仲裁员合议"，仲裁委却违规**独任**裁了——那就落在第（三）项"仲裁庭组成违反法定程序/约定"，同样可撤销（真题§324即此）。

**重新仲裁的插曲**：C市中院受理撤销申请后，如果觉得"这案子瑕疵可以由仲裁庭自己纠正"，可以**通知原仲裁庭重新仲裁**，同时裁定**中止**撤销程序。仲裁庭愿意重裁→法院**终结**撤销程序；仲裁庭**拒绝**重裁（它有权拒绝）→法院**恢复**撤销程序继续审。重新仲裁**用原班人马、无需另组庭，裁决仍是终局的**。

#### 一句话闭环记忆
> 🎯 **一眼判**：撤销＝**仲裁机构所在地中院·合议庭·收到裁决书3个月内·任一当事人**；国内**6项事由＋违背公共利益**；法院可**通知仲裁庭重新仲裁**（仲裁庭可拒绝、原庭进行、裁决仍终局）。凡写"6个月""向被告住所地法院""可独任审查"均错。

---

### 第三步：判不予执行——凭什么、去哪、什么时候提？

> **执行法院被动防，事由同撤销六项，执行终结前须提**

#### 概述
不予执行是**被动防守型**救济：只有在对方**申请强制执行**时，**被申请执行人**才能向**执行法院**（不是中院）提出，且须在**执行程序中、执行终结前**提出（民诉解释§479）。新法§76直接**援引§71第一款**——即**不予执行事由与撤销事由完全一致**（无协议/超裁/程序违法/证据伪造/隐瞒证据/枉法裁决），加违背公共利益；民诉法§248另有并列的6项清单，实质相同。法院同样**组成合议庭审查核实**后裁定。

#### 大白话讲解
假设乙没在3个月内去撤销，而是等甲来执行时"顶回去"。甲已向**B市法院**（乙住所地、执行法院）申请执行，那么：
- **去哪提**：就向**B市这个执行法院**提出不予执行申请（不是去C市中院）。
- **什么时候**：得在**执行还没结束之前**提出，执行都终结了就来不及了。
- **凭什么**：还是那张"验收单伪造"的牌——§76援引§71，"证据伪造"同样是不予执行事由。B市执行法院组成合议庭一审，属实→**裁定不予执行**。

**新法一个关键变化**：过去有人纠结"撤销事由和不予执行事由是不是一样"，2025新法用§76"援引§71第一款"一锤定音——**两者事由现在完全相同**，你拿同一个理由，走撤销走不予执行都成立（只是管辖、时机不同）。

#### 一句话闭环记忆
> 🎯 **一眼判**：不予执行＝**执行法院·合议庭·执行终结前·被申请执行人**；国内事由**§76援引§71（＝撤销事由）＋违背公共利益**。凡写"向中院申请不予执行""随时都能提"均错。

---

### 第四步：判两者关系——择一还是并用？衔接怎么走？

> **一执一撤先中止，撤销驳回同由封，重复审查法不理**

#### 概述
撤销与不予执行是**两条并行的救济路径**，但存在严格的**衔接与择一规则**：
- **执行与撤销同时发生**：一方申请执行、另一方申请撤销的，法院应当裁定**中止执行**（§77）；法院裁定**撤销**→**终结执行**；撤销申请被**驳回**→**恢复执行**。
- **先后择一（防重复审查）**：当事人向法院申请撤销被**裁定驳回**后，又以**同一事由**申请不予执行的，法院**不予支持/不予受理**（法释〔2006〕7号§26精神）——同一个理由，中院审过了、驳了，就不能再拿到执行法院重审一遍。但以**不同事由**申请仍可另行主张。

#### 大白话讲解
现实中乙很可能"两手都想用"，法院给他立规矩：
- **同时用**：乙一边在C市中院申请撤销，甲一边在B市申请执行——这时B市执行法院不会闷头执行，而是**先裁定中止执行**，等撤销结果（§77）。如果C市中院真撤了→B市**终结执行**（没依据可执行了）；如果C市中院**驳回**了乙的撤销→B市**恢复执行**（照付100万）。
- **先后用（陷阱高发）**：乙先去C市中院申请撤销，理由是"验收单伪造"，结果中院审查后认为证据不足、**驳回**了。乙不死心，又拿**同样的"验收单伪造"**去B市执行法院申请不予执行——**法院不予受理**！因为这个理由已经被中院这道司法审查程序审过、否掉了，不能换个法院再审一遍（真题§280即此）。⚠️但假如乙这次换了个**新理由**（比如"仲裁员受贿"），那是没审过的事由，仍可另行主张。

#### 一句话闭环记忆
> 🎯 **一眼判**：一方执行＋一方撤销→**中止执行**（撤销则终结、驳回则恢复，§77）；**撤销被驳回后，同一事由的不予执行一律不受理**（防重复审查）；换新事由则不受此限。

---

### 第五步：判被否之后——裁决被撤销/不予执行了，怎么办？

> **原协议不当然有效，重新签约再仲裁，或按管辖去起诉**

#### 概述
裁决被依法**撤销或不予执行**后，依§10II，当事人就该纠纷有两个出路：**①根据双方重新达成的仲裁协议申请仲裁 ②向法院起诉**。关键点：**原仲裁协议不当然继续有效**——它随裁决被否而"用尽"，想再仲裁必须**重新达成**协议；谈不拢就只能起诉，起诉按普通管辖规则，**不动产/房屋租赁纠纷走专属管辖**（不动产所在地法院）。裁决/撤销裁定本身**不能上诉、不能再审、不能抗诉**。

#### 大白话讲解
C市中院最终裁定**撤销**了这份裁决。乙松口气，但甲的100万货款纠纷还没解决，接下来怎么走？
- **想继续仲裁**：甲乙得**重新签一份仲裁协议**才能再去仲裁——原来那份约定"C市仲裁委仲裁"的条款**不能再单独当依据**用了（它已经"用尽"）。没重新签，就别想再仲裁（真题§326：没重新签就只能起诉）。
- **直接起诉**：甲也可以就货款纠纷**去法院起诉**。普通合同纠纷按被告住所地/合同履行地定管辖；但如果是**房屋租赁**这类**不动产纠纷**，走**专属管辖**——只能告到**房屋所在地**法院（真题§326：房子在C区就只能告C区）。
- **别走错路**：乙/甲若对撤销裁定不服，想申诉、再审、找检察院抗诉——**都不行**，撤销裁定作出即生效（真题§325、§326的C/D项）。

**再对照不予执行**：如果是走的不予执行、裁决被裁定不予执行，后果**完全一样**（§10II同款）——原协议失效，重新签协议再仲裁或起诉（真题§278、§279C）。

#### 一句话闭环记忆
> 🎯 **一眼判**：裁决被撤销/不予执行后→**原仲裁协议不当然有效**，须**重新达成协议**方可再仲裁，否则**起诉**（不动产/房屋租赁→专属管辖）；对裁决/撤销裁定**不能起诉·再审·抗诉**。

## 六、 易混考点辨析

*   **撤销 vs 不予执行**：撤销＝主动、中院、收到裁决书3个月内、可通知重新仲裁；不予执行＝被动、执行法院、执行终结前、无重新仲裁。新法下**事由已统一**（§76援引§71）。
*   **撤销期限 3个月 vs 6个月**：新《仲裁法》§72＝**3个月**（旧法§59＝6个月，已失效）。这是2025修法后最高频的新旧陷阱。
*   **国内事由（6项·审实体）vs 涉外事由（4项·只审程序）**：涉外§83/§84**不审证据真伪、不审枉法裁决**；"涉外＋证据伪造可撤销"必错。
*   **违背公共利益（法院依职权）vs 当事人举证的6项事由**：前者无须当事人举证，是法院主动审查的独立事由（§71III/§76II）。
*   **重新仲裁"通知"（可拒绝）vs "命令"（应当）**：§74是"通知"，仲裁庭**可以拒绝**（拒绝则恢复撤销程序）；原庭进行、裁决仍终局。
*   **裁决被否后：原协议失效 vs 继续有效**：§10II须**重新达成**协议，原协议**不当然有效**。
*   **对裁决/撤销裁定：不能起诉·再审·抗诉**（一裁终局＋非法院裁判＋裁定即生效）。
*   **仲裁保全 vs 先予执行**：仲裁有财产/证据/行为保全（转交法院），**无先予执行**。
*   **证据保全法院层级：国内基层（§58）vs 涉外中院（§79）**；仲裁前可直接申请、仲裁中须经仲裁机构转交。
*   **确认仲裁协议效力管辖**：约定了仲裁机构的，由**仲裁机构所在地或仲裁协议签订地中院**管辖（不看当事人住所地）；仲裁机构已作效力决定后，当事人再请求法院确认的**不予受理**（法释〔2006〕7号§12/§13，本地未逐字核到）。

## 七、 命题人最爱的 7 个陷阱

1.  **"撤销申请应自收到裁决书之日起6个月内提出"** —— 错！新《仲裁法》§72已改为**3个月**（旧法§59的6个月已失效）。
2.  **"当事人可向中院申请不予执行"** —— 错！不予执行向**执行法院**提出（§76、民诉§248）；只有撤销才向中院（§71）。
3.  **"撤销申请被驳回后，可就同一事由再申请不予执行"** —— 错！同一事由已审查驳回，再申请**不予受理**（防重复审查）；且撤销被驳回后应**恢复执行**（§77）。
4.  **"涉外仲裁裁决所依据证据伪造的，可申请撤销/不予执行"** —— 错！涉外事由§83/§84仅4项**纯程序**，**不审实体、不审证据真伪**。
5.  **"裁决被撤销后原仲裁协议继续有效，可径行再申请仲裁"** —— 错！原协议**不当然有效**，须**重新达成**仲裁协议（§10II），否则起诉。
6.  **"对仲裁裁决或撤销裁定不服，可申请再审/申请检察院抗诉"** —— 错！仲裁裁决非法院裁判、不适用再审；撤销裁定作出即生效，**无上诉/再审/抗诉**。
7.  **"仲裁中当事人可申请先予执行"** —— 错！仲裁**无先予执行制度**；能申请的是财产/证据/行为保全，由仲裁机构转交法院（§39/§58）。
