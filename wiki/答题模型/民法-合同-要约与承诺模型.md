# 📐 要约与要约邀请、承诺 · 完整答题模型（订立第一步：谁在向谁"发盘"）

> **核心一句**：
>
> **要约＝我说了算，你同意就成交；要约邀请＝我还没拍板，等你来跟我谈**。
>
> 合同订立永远是一条链：**要约（生效）→ 承诺（生效）＝ 合同成立**（§483）。命题人几乎所有陷阱都埋在这条链的三个关节上——① **定性**（这句话是要约还是要约邀请？）② **时间轴**（撤回 / 撤销 / 迟到，谁先到达谁生效？）③ **内容比对**（承诺改了要约的内容，算不算数？）。三关过了，"要约与承诺"这一章的题基本不会错。
>
> 🔗 **与 [[民法-合同-成立与生效模型]] 的分工**：本模型管"**订立的前半段**"——要约 / 要约邀请怎么定性、要约承诺怎么生效撤回撤销、迟到承诺怎么判、内容变更怎么定性；成立与生效模型管"**订立的后半段**"——承诺生效之后，合同何时成立（谱系）、成立后是否生效（三要件 + 三例外）。两个模型首尾相接，**先本模型判出"承诺生效"，再交给成立与生效模型判"合同何时成立、是否生效"**。
>
> 🔎 **法条已核实**：要约 §472-§478；承诺 §479-§491；成立 §483。

## 一、核心考情（含考频免责）

> ⚠️ **考频免责声明**：司法部自 2018 年法考改革起不公开历年真题原题及考点频次统计。下列 ★ 星级系培训机构依学员回忆卷研判，**非官方一手数据**。可溯源硬事实仅：本主题落在《民法典》合同编 §472-§491，2026 年法考大纲民法无修订。

| 知识点 | 机构研判星级 | 说明 |
| --- | --- | --- |
| 要约 vs 要约邀请辨认 | ★★★★★ | 客观题第一坑，几乎每年都考；广告 / 价目表 / 招标 / 悬赏是高频素材 |
| 要约的撤回 vs 撤销（时间轴题） | ★★★★ | 常与承诺撤回、要约失效混合出一道"时间轴"综合题 |
| 迟到承诺 §486 / §487 | ★★★ | 经典"两条对称规则反着考"，易与撤回撤销混淆 |
| 实质性变更 vs 非实质性变更 | ★★★ | 承诺改内容后"算不算承诺"，与新要约衔接 |
| 承诺方式 / 沉默不构成承诺 | ★★★ | "不回复视为同意"条款效力、拍卖落槌时点等场景题 |

- **命题核心**：制造"看起来像要约"（价目表、招标公告、广告）或"看起来像要约邀请"（超市标价陈列、悬赏广告）的假象，诱你在**定性第一步**就答错；或在**时间轴**上颠倒撤回 / 撤销 / 迟到的先后顺序。
- **考查形态**：客观题以案例单选 / 多选为主（"下列哪一项属于要约""要约何时失效"）；主观题常作为合同纠纷案例的开场定性句。

## 二、万能答题模型（三关连贯走）

> **主线**：`第一关定性(要约/要约邀请) → 第二关时间轴(生效/撤回/撤销/失效/迟到) → 第三关内容比对(承诺是否照单全收) → 交棒成立与生效模型`

### 第一关【定性】—— 这句话是要约还是要约邀请？

#### ① 要约二要件（§472）

> **§472（逐字）**："要约是希望与他人订立合同的意思表示，该意思表示应当符合下列条件：（一）内容具体确定；（二）表明经受要约人承诺，要约人即受该意思表示约束。"

**一眼判口诀**：**看"最终决定权"交出去了没**——
- 对方一说"同意"，我这边就**没得改、直接成交** → 要约（承诺即受约束）
- 我这边还留着"我说了才算""还得再谈"的空间 → 要约邀请

| 要件 | 内容 | 缺了会怎样 |
| --- | --- | --- |
| **具体确定** | 标的、数量等主要条款明确到可直接履行 | 缺 → 只是磋商 / 邀请，不是要约 |
| **受约束表示** | 明示或依交易习惯可知"你同意我就得履行" | 缺 → 只是要约邀请，对方"承诺"不产生合同拘束力 |

#### ② 法定要约邀请五项 + 广告例外（§473）

> **§473（逐字）**："要约邀请是希望他人向自己发出要约的意思表示。**寄送的价目表、拍卖公告、招标公告、招股说明书、基金招募说明书、债券募集办法、商业广告和宣传**等为要约邀请。**商业广告和宣传的内容符合要约条件的，构成要约。**"

| 法定要约邀请（原则） | 例外反转为要约的条件 |
| --- | --- |
| 价目表、拍卖公告、招标公告、招股说明书、债券募集办法、**商业广告和宣传** | 广告 / 宣传**内容具体确定 + 表明经承诺即受约束** → 视为要约 |

> ★ **最高频陷阱**：题干给"商品实物标价陈列"（[[合同通则-单选-06]] D）——这不是"商业广告"，而是**要约本身**（陈列 + 标价 = 内容具体确定 + 顾客付款即成交，商家无磋商空间），属于**《消费者权益保护法》承认的经营者要约**类型；命题人常用"标价陈列"来对冲"价目表寄送"（要约邀请），两者极易混淆——**寄送价目表**是邀请（对方还要来问、来谈），**标价陈列供当场选购**是要约（拿了就买、一手交钱一手交货）。
>
> ★ 商品房销售广告：对房屋及配套设施的说明、允诺**具体确定**，且对合同订立、房屋价格有**重大影响**的，视为要约（源自《商品房买卖合同解释》）——即使未写入正式合同，开发商做不到也要担违约责任。
>
> ★ **悬赏广告**（"假一罚十"/寻物悬赏）：是要约人**自愿作出的真实意思表示**，内容具体确定（找到东西给多少钱 / 假一罚十），对方完成行为即视为承诺 → **有效要约**，不是显失公平、不是未订入合同（[[合同通则-单选-31]] D）。
>
> ★ **"以重要合作为名的邀约磋商"陷阱**（[[合同通则-多选-19]]）：即便对方言辞恳切、反复邀约，只要**没有具体确定的合同主要条款、没有表明"你同意我就受约束"**，本质仍是**要约邀请层面的磋商**，不构成要约（A 项"丙公司发出邀请书属于要约"是**错误项**）；但无真实交易意图、恶意拖延磋商致对方遭受损失的，仍可能构成**缔约过失责任**（§500），不需要合同成立或要约存在为前提。

#### ③ 谁向谁要约？—— 沉默 / "再考虑一下"不构成承诺

> [[合同通则-单选-39]] 经典陷阱：卖家开价、买家当场表示"愿意购买"——此时**买家的"愿意购买"才是要约**（卖家开价尚未表明"你同意我就卖"，卖家还说"次日再考虑"，说明卖家保留决定权，卖家的开价只是要约邀请层面的磋商）；次日买家再问，卖家**拒绝** → 卖家没有承诺，谈判破裂，**李某无需承担任何责任**（不构成缔约过失，因为拒绝磋商是正当权利）。
>
> 🔑 **判断技巧**：**谁的话里带"你同意我就受约束"，谁就是要约人；谁只是"考虑一下""再议"，谁保留的是决定权，对方的表态才是要约**。

### 第二关【时间轴】—— 生效 / 撤回 / 撤销 / 失效 / 迟到，谁先到达谁生效

#### ① 要约生效：到达主义（§474）

要约到达受要约人时生效——参照 [[民法-合同-成立与生效模型]] 中 §137 数据电文到达规则（对话方式了解主义 / 非对话方式到达主义 / 数据电文进入系统）。

#### ② 撤回 vs 撤销（核心区分表）

| 维度 | 撤回 | 撤销 |
| --- | --- | --- |
| **时间节点** | 该意思表示**生效前或同时**到达 | 要约**已生效**、受要约人**发出承诺前**到达 |
| **适用对象** | 要约（§475）+ 承诺（§485）**均可** | **仅限要约**（§476）；承诺**不可撤销** |
| **本质** | 原意思表示尚未生效，可"取消" | 要约已生效但承诺未发出，要约人"反悔" |
| **限制** | 无特别限制 | §476 **两种情形不可撤销** |

> **§476 两种不可撤销情形（逐字要点）**：① 要约人**确定了承诺期限**或者**以其他形式明示要约不可撤销**；② 受要约人**有理由认为**要约不可撤销，并**已经为履行合同做了合理准备工作**。

> 🔑 **一眼判口诀**：**"生效前/同时到达"→撤回；"承诺前到达"→撤销；承诺一旦作出→谁都撤不了**。

#### ③ 要约失效（§478，学理上常列五种情形；条文本身为四项 + 通说补充"要约人死亡/丧失行为能力致履行不能"）

> **§478（逐字）**：有下列情形之一的，要约失效：（一）拒绝要约的通知到达要约人；（二）要约人依法撤销要约；（三）承诺期限届满，受要约人未作出承诺；（四）受要约人对要约的内容作出**实质性变更**。

| # | 情形 | 触发 |
| --- | --- | --- |
| ① | 被拒绝 | 拒绝通知到达要约人 |
| ② | 被撤销 | 撤销到达 + 在受要约人发出承诺前（§476） |
| ③ | 期限届满未承诺 | 沉默到死线，自动失效，不需通知/主张/判决 |
| ④ | 实质性变更 | 受要约人对内容作实质性变更，视为新要约（§488） |
| ⑤（学理补充） | 要约人死亡 / 丧失行为能力 + 影响履行 | 通说延伸，非§478 条文明列项 |

多种失效情形竞合时，**逐一筛 + 取最早的那一天**（先发生的情形吃掉后面的）——详见 [[要约]] 实体页"老王卖车"完整案例演练。

**[[合同通则-单选-07]] 综合演练**（甲 9/10 发要约给乙、承诺期限至 9/15；甲 9/12 发撤销信、9/14 到达乙；乙 9/13 回复"能否用华硕代替"）：
- 9/13 乙提出"能否代替"——这是**询问/试探性磋商**，不构成对要约的实质性变更（未明确拒绝、未明确变更条款，仅为询价式回应），不导致要约在 9/13 失效；
- 9/14 甲的撤销信到达乙，此时乙**尚未作出承诺**（只是在询问），撤销**有效**（符合§476"承诺前到达"要件、且不构成两种不可撤销情形）→ **要约于 9 月 14 日失效**（答案 C）。
- 🔑 本题教学价值：区分"实质性变更承诺"（导致要约因④失效）与"单纯询价/磋商"（不导致失效，要约仍可被②撤销），二者常被命题人混同。

### 第三关【内容比对】—— 承诺内容变了，算不算承诺？

#### ① 承诺方式与生效（§479-§484）

- 承诺 = 受要约人**同意要约**的意思表示（§479），原则上**以通知方式**作出（§480）
- 承诺**到达要约人时生效**（§484）——到达主义，与要约同步
- **拍卖场景**：拍卖公告是要约邀请，竞买人应价是要约，**拍卖师落槌或以其他公开表示买定才是承诺**（[[合同通则-单选-09]] C）——不是"应价"（那是要约）、也不是"事后签成交确认书"（那是履行确认，成立时点已在落槌时锁定）。

#### ② 迟到承诺：§486 vs §487（口诀：怪受要约人→新要约；怪传递→有效）

| 维度 | §486 | §487 |
| --- | --- | --- |
| **情形** | 承诺**发出就晚**，或按通常情形**不能及时到达** | 承诺**发出及时**、通常能及时到达，但因**其他原因**迟到 |
| **归责对象** | 怪**受要约人**（自己拖了才发） | 怪**传递过程**（邮路 / 系统延误等） |
| **默认效力** | **视为新要约**（不构成承诺） | **原则有效**（视为未迟到，构成承诺） |
| **翻转条件** | 要约人**及时通知**该承诺有效，才有效 | 要约人**及时通知**不接受，才失效 |

> 🔑 **翻转方向相反**：§486 默认无效、要约人"点头"才有效；§487 默认有效、要约人"摇头"才无效——两条规则**对称但方向相反**，命题人爱互换考。

#### ③ 实质性变更 vs 非实质性变更（§488 / §489）

> **§488（逐字）**："承诺的内容应当与要约的内容一致。受要约人对要约的内容作出**实质性变更**的，为**新要约**。有关合同标的、数量、质量、价款或者报酬、履行期限、履行地点和方式、违约责任和解决争议方法等的变更，是对要约内容的**实质性变更**。"
>
> **§489（逐字）**："承诺对要约的内容作出**非实质性变更**的，除**要约人及时表示反对**或者**要约表明承诺不得对要约的内容作出任何变更**外，该承诺**有效**，合同的内容以承诺的内容为准。"

**实质性变更 7 项**（一定构成新要约）：**标的、数量、质量、价款/报酬、履行期限/地点/方式、违约责任、争议解决方法**。

- 变了这 7 项之一 → **新要约**（原受要约人变成新要约人，原要约人需重新作出承诺，双方角色互换）
- 变了这 7 项之外的内容（非实质性）→ **承诺有效**，合同内容以承诺内容为准——**除非**①要约人及时表示反对，或②要约本身就表明"不得作任何变更"

> 🔑 **一眼判口诀**：**"7 项清单内 → 新要约（角色互换）；7 项之外 → 照单有效（除非要约人反对/要约禁止变更）"**。

## 三、命题人最爱的陷阱（含降权标注）

**真·高频（重点背）：**

1. **【最高频】要约 vs 要约邀请定性反转** —— 广告/宣传原则是要约邀请，但**内容具体确定 + 影响缔约**（商品房广告）例外构成要约；"标价陈列供选购"是要约（非价目表寄送）；悬赏广告是要约（非无效格式条款、非未订入合同）。
2. **【高频】撤回 vs 撤销时间节点混淆** —— 撤回="生效前/同时"到达；撤销="承诺前"到达，且承诺一旦作出、撤销就来不及了。命题人常给出精确到"日"的时间轴让你排序。
3. **【高频】§476 两种不可撤销情形常被忽略** —— 确定承诺期限 / 明示不可撤销，或受要约人已合理准备履行——满足任一，撤销通知即使先到达也**不发生效力**。
4. **【高频】迟到承诺两条规则方向相反** —— §486（怪自己→默认无效）与 §487（怪传递→默认有效）互换出题，翻转条件也相反（要约人"点头"vs"摇头"）。
5. **【高频】实质性变更 7 项清单** —— 漏记任何一项都可能在多选题里丢分；争议解决方法、履行地点/方式常被误认为"细枝末节"（非实质性），实则在清单内。
6. **【高频·易忽略】"再考虑一下"/沉默≠承诺** —— 拒绝磋商是正当权利，不构成缔约过失；判断"谁是要约人"要看谁的话里"交出了最终决定权"。

**需降权（写但勿夸大）：**

7. **【降权】拍卖场景承诺时点** —— 真考点但出现频率低于要约邀请辨识题，价值主要在与"应价=要约"的对照。

## 五、🎯 口诀

> **要约邀请我做主，要约一发就受约束；广告原则是邀请，具体确定又例外。**
> **撤回赶在生效前，撤销要在承诺前；承诺已发不可撤，撤销落空空一趟。**
> **迟到承诺看归责：怪自己→新要约（要约人点头才算数）；怪传递→原则有效（要约人摇头才失效）。**
> **实质变更七项清单（标数质价、期地方式、违约争议）→新要约；非实质→照单有效，除非反对或禁止变更。**
> **判要约还是要约邀请，看"最终决定权"交没交出去——你说了才算，是邀请；我同意就成交，是要约。**
