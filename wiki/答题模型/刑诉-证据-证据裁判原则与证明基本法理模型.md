# 📐 证据裁判原则与证明基本法理 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。这一节是证据制度的"地基"——
> 
> **证据裁判原则、无罪推定、疑罪从无、不得强迫自证其罪，加上证明对象与免证事实**。
> 
> 它们看着抽象，命题人却把坑挖得极深，专治两类惯性：
> 
> 一是**把"不得作为定案根据"和"排除"混为一谈**、把"证据能力"和"证明力"搅在一起；
> 
> 二是**把定罪权乱安给检察院、把"不得强迫自证其罪"当成"沉默权"、把该证明的程序事实当成不用证明**。
> 
> 破解的钥匙是三句话：**「能不能用（证据能力）先过三性关，能定案还得查证属实（证据裁判）」、「定罪只能靠法院、证据不足就无罪（无罪推定＋疑罪从无）」、「哪些事实要证、哪些不用证（证明对象 vs 免证事实）」**。
> 今天用**一张"证据资格→证明→裁判"的三层框架图＋原则群速记＋证明对象/免证清单**把这块地基夯死。

## 适用场景与解决问题

本模型覆盖 [[刑诉-刑事证据制度-深度报告]] 第一板块的**基本原理与原则类考点（考点5、6、7、10）**。凡题干出现"下列体现……原则""能否作为定案根据""证据能力/证明力""哪些属于证明对象""无须证明的事实""检察院能否确定有罪""是否享有沉默权"等，立即调用本模型。

- **证据裁判原则（§50③）**：认定案件事实必须有证据；证据**必须经过查证属实**才能作为定案根据。未经查证属实的后果是"**不得作为定案根据**"，与"非法证据排除"是**两种不同后果**，勿混。
- **证据能力 vs 证明力**：证据能力＝**能不能进法庭用**（资格问题，受合法性、关联性等门槛约束，属规则判断）；证明力＝**能证明到什么程度**（价值问题，由法官依关联度、可靠性自由判断）。
- **无罪推定（§12）与疑罪从无（§200③）**：未经**人民法院**依法判决，对任何人都不得确定有罪——**定罪权专属法院**，检察院、公安**不能"确定有罪"**；证据不足不能认定有罪的，**应作无罪判决**。
- **不得强迫自证其罪（§52）**：严禁刑讯逼供及威胁、引诱、欺骗等非法取证，不得强迫任何人证实自己有罪。**≠沉默权**——嫌疑人对侦查人员的提问仍负§120"**应当如实回答**"义务（对与本案无关问题有拒绝权）。
- **证明对象与免证事实（§55＋学理）**：需要证明的是**实体法事实（定罪＋量刑）与程序法事实（管辖、回避、取证合法性、强制措施等）**；**免证事实**（众所周知、自然规律定理、法律推定、生效裁判预决、公证事实）无须证明。

> **核心一句**：证据法的地基就是**「先问能不能用（证据能力·三性），再问要证什么（证明对象／免证），最后靠查证属实定案（证据裁判）；而定罪权只归法院、证据不足即无罪」**。

> 🔎 **法条已核实**：§50③/§52/§12/§200③/§55 系刑诉法基石条文，逐一核实无误（法条准确性详见文末"真题性质与出处说明"）。
> ⚠️ **易记错点（勿望文生义）**：①**"未经查证属实"≠"非法证据排除"**——前者是"不得作为定案根据"，后者是取证程序违法的排非，后果不同；②**证据能力（资格）≠证明力（分量）**——前者是规则判断，后者由法官自由心证；③**程序法事实（取证合法性、供述自愿性）照样是证明对象**，不是免证事实；④**检察院/公安无权"确定"有罪**，定罪权专属法院；⑤**不得强迫自证其罪≠沉默权**，仍负§120如实回答义务（无关问题可拒答）。

> **适用真题**：[[刑诉-证据-单选-04 · 质证程序体现证据合法性原则|单选-04]]（证据裁判/合法性）、[[刑诉-证据-单选-06 · 责任能力法律判定的司法独立性|单选-06]]（责任能力是法律问题）、[[刑诉-证据-单选-19 · 关联性判断与意见证据例外及程序法事实证明|单选-19]]（程序法事实证明对象）、[[刑诉-证据-多选-45 · 证明对象之主观明知与量刑事实及免证事项界限|多选-45]]／[[刑诉-证据-多选-46 · 生效裁判事实免证与虚假陈述证据性质及伪证被诬陷人身份判定|多选-46]]（证明对象与免证事实界限）（全部 11 道见文末"关联真题"）。
>
> **姊妹模型**：📐 [[刑诉-证据-法定种类识别模型]]（§50八种）· [[刑诉-证据-学理分类判定模型]]（学理四分）· [[刑诉-证据-补强证据与意见证据规则模型]]（口供补强·意见证据规则）——本模型只管**基本原则与证明对象/免证**，证明责任分配与证明标准属报告第四板块另一专题。

## 一、 "证据资格 → 证明 → 裁判"三层框架图

```
              【一份材料要成为定案根据，须过三层】
                              │
   第一层：证据能力（能不能用·资格问题）
        三性关卡： ①客观性(真实) ②关联性(与案相关) ③合法性(来源程序合法)
        —— 缺关联/合法 → 无证据能力，不得进入定案；非法证据→排除
                              │
   第二层：证明（要证什么·怎么证）
        证明对象：实体法事实(定罪构成+量刑情节) + 程序法事实(管辖/回避/取证合法性/强制措施)
        免证事实：众所周知·自然规律定理·法律推定·生效裁判预决·公证 → 无须证明
        证明力：由法官依关联度/可靠性自由判断（≠证据能力）
                              │
   第三层：证据裁判（能不能定案·§50③）
        认定事实须有证据；证据须"查证属实"才能作为定案根据
        —— 未经查证属实：不得作为定案根据（≠排除，后果不同）
                              │
   ★贯穿全程的原则：
     · 无罪推定§12：未经法院判决不得确定有罪（定罪权专属法院）
     · 疑罪从无§200③：证据不足 → 无罪判决
     · 不得强迫自证其罪§52：严禁刑讯逼供威胁引诱欺骗（≠沉默权·仍负§120如实回答）
```

> **一句话总诀**：**「三性定资格，查证属实定定案；定罪只归法院，证据不足即无罪；不强迫自证≠可沉默」**。

## 二、 黑话 → 人话 对号入座表

| 黑话术语 | 翻成人话 | 对号入座（一句话定位） |
| :--- | :--- | :--- |
| **证据能力（证据资格）** | 这材料**够不够格**进法庭当证据 | 非法口供无证据能力（排除）；传闻/无关材料不合格 |
| **证明力** | 这份证据**能证明到多深**、分量多大 | 直接目击 > 间接痕迹；关联越紧，证明力越强（法官判断） |
| **证据裁判原则** | **有几分证据说几分话**，且证据得"验过是真的"才能定案 | 未经查证属实的材料，不得作为定案根据 |
| **无罪推定** | 没经**法院**判决，谁都不算罪犯 | 检察院起诉≠有罪；只有法院能"定罪" |
| **疑罪从无** | 证据不够就**判无罪**，不能"疑罪从轻" | 证据不足 → 证据不足、指控不成立的无罪判决 |
| **不得强迫自证其罪** | 不许拿刑讯威胁引诱逼你自己认罪 | ≠沉默权；对提问仍要如实回答（无关问题可拒答） |
| **证明对象** | 这案子**哪些事儿需要拿证据说话** | 定罪事实、量刑情节、取证是否合法、该不该回避 |
| **免证事实** | **不用举证**、大家都认或法律推定的事 | 太阳东升、生效判决已认定的事、公证过的事 |

## 三、 三大判定关卡（字诀 + 先懂几个词 + 数字案例 + 🎯做题眼）

> 拿到一道"能不能定案""要不要证明""谁能定罪"的题，别凭直觉套现实经验，按下面三关逐层拆开。

### 第一关：证据能力 vs 证明力 & 证据裁判 —— 盯死"资格 vs 分量""能不能定案"

> **教练提示**：一看到"某证据未经查证属实能不能定案"，绝大多数同学张口就说"排除"，把证据裁判原则和非法证据排除规则揉成一团；一看到"关联性强不强"，又习惯性说成"证明力大不大"。命题人专卡这两组概念的**后果不同、层次不同**——差一个字，整句话的法律效果就变了。

> # 能不能用看资格（能力），有多大用看分量（证明力）；查证属实才定案（§50③）

- **先懂几个词**：
	- **证据能力**（证据资格）
		- 这份材料**够不够格**进法庭当证据用——受 **客观性、关联性、合法性**三性门槛约束，是"能不能用"的规则问题；
			- 合法性：
				- 收集主体、程序、形式都符合法律规定” 我还是没有明白. 合法性可以拆成三个独立的审查维度，通俗讲就是：**谁来取、怎么取、做成什么样**，三件事都必须符合法律规定，任何一项出问题，证据都可能因不合法而不能作为定案根据。
			- 关联性
				- 关联性（客观关联性）是指作为**证据的内容必须与案件的证明对象**（待证事实）之间存在客观的、实质性的联系（§证据学理论）。这种联系不限于因果关系，也可以是时空伴随关系、条件关系等其他逻辑关联。

	- **证明力**
		- 这份材料**能证明到多深、分量多大**——由法官依关联度、可靠性**自由判断**，是"进来后有多重"的价值问题；

	- **证据裁判原则**
		- 认定案件事实**必须有证据**，且证据要**经过查证属实**才能作为定案根据——这是"能不能定案"的最后一道闸门；
	
	- **未经查证属实**
		- 证据**还没被验证是真的**，后果是"**不得作为定案根据**"——这**不是**"非法证据排除"（排除针对的是取证程序违法，两者后果、依据都不同，别混）。

- **判"能力 vs 证明力"**：
	- 先问"这份材料**够不够格用**"（有没有过合法性、关联性关）→证据能力；再问"用了之后**分量多大**"（法官自由心证）→证明力。

- **判"未经查证属实的后果"**：
	- 不是"排除"，而是**不得作为定案根据**——二者是**两套不同规则、两种不同后果**。

#### 大白话讲解

##### 🔍 对号入座表：危险驾驶案里的两份材料

| 材料                 | 要过的关         | 定性             |
| ------------------ | ------------ | -------------- |
| 现场呼气检测记录           | 合法性（取证程序对不对） | 证据能力问题         |
| 血液酒精鉴定             | 认定醉驾的"金标准"   | 证明力最强          |
| 与案件"沾边"但不影响待证事实的材料 | 关联性          | 无证据能力，不被采信     |
| 任何证据要定案            | 查证属实         | 证据裁判原则（§50③）总闸 |

##### 💰 完整数字案例：三性关+查证属实，缺一不可

> **案情**：危险驾驶案中，控方提交"现场呼气检测记录"和"抽血送检的血液酒精鉴定"两份材料。
>
> - 现场呼气记录属于办案过程记录（非讯问笔录），要看**取证程序合不合法**——这是"**能不能用**"的证据能力问题；
> 
> - 血液酒精鉴定是认定醉驾的"**金标准**"，一旦被采信，其**证明力**在本案中最强；
> 
> - 与本案沾边但对"是否醉驾"这个待证事实起不到实质证明作用的材料（比如司机的行车习惯记录），**不具有关联性**，没有证据能力，进不了法庭；
> 
> - 无论哪份材料，最终都要**经查证属实**才能作为定案根据（§50③）——这是压在最后的"能不能定案"总闸，跟前面"能不能用（证据能力）"是两道不同的关。

👉 三性关卡（客观、关联、合法）决定材料**能不能进场**；查证属实决定材料**能不能拍板定案**——这是两道不同的关，别用后一道的后果去描述前一道的问题。

#### 一句话闭环记忆

> 🎯 **一眼判**："能不能进来用"＝证据能力（规则/资格）；"进来后有多重"＝证明力（法官判断）。把"未经查证属实"的后果写成"非法证据排除"的——**排除**；二者后果不同（前者"不得作为定案根据"，后者是排非）。



### 第二关：证明对象 vs 免证事实 —— 盯死"哪些要证、哪些不用证"

> **教练提示**：一看到"程序上的事"（管辖对不对、有没有回避、取证合不合法），绝大多数同学下意识觉得这些"不是案子本身"，不用证明。命题人专卡这条——**程序法事实照样要证明**，真正不用证明的只有那五类法定免证事实；此外"责任能力"到底是医学问题还是法律问题，也是常年必踩的坑。

> # 定罪＋量刑＋程序事实都要证；众所周知·自然规律·法律推定·生效裁判·公证不用证

> **刑事诉讼不能直接套用民事诉讼的「谁主张谁举证」，这是法考高频易错点**。核心规则是「控方承担有罪终局责任，被告人仅需提供线索」，和民事规则完全不同

- **先懂几个词**：
	- **证明对象**
		- 这个案子里**哪些事儿需要拿证据去证明**——分两大类：

			- **实体法事实**（犯罪构成含主观明知、量刑情节）
				- 犯罪构成 - 主客冠明知
				- 量刑情节
					- 法定量刑情节
						- 刑法条文明确规定的情节，比如：
							- 从轻 / 减轻：自首、立功、未成年人犯罪、犯罪未遂、犯罪中止、从犯、胁从犯
							- 从重：累犯、教唆未成年人犯罪

					- 酌定量刑情节
						- 无法律明文强制要求，法官酌情参考的情节，比如：

							- 退赃退赔、取得被害人谅解
							- 犯罪动机、悔罪态度、平时一贯表现
							- 被害人存在一定过错、犯罪造成的实际损失大小

			- **程序法事实**（管辖对不对、该不该回避、取证合不合法、供述是不是自愿）；

	- **免证事实**
		- 法律规定**不用举证**、大家默认为真的事——只有五类：

			- **众所周知的常识

			- 自然规律与定理

			- 法律推定的事实
				- **定义**：由法律明文规定，只要某一基础事实被证实存在，就直接认定另一事实成立，无需单独举证证明。

				- **法考典型例子**：
				    
				    巨额财产来源不明罪中，只要证明 “国家工作人员的财产、支出明显超过合法收入，差额巨大” 这一基础事实，就直接推定差额部分为非法所得，控方无需再逐一证明这笔钱来自哪项具体犯罪。
				- **考点**：必须是法律明文规定的才算；仅凭日常经验推导的 “事实推定” 不属于免证范围。
							- 已为生效裁判确认的事实
			- 公证证明的事实

	- **责任能力**
		- 行为人**有没有能力对自己行为负刑事责任**——这是**法律判定问题**，最终由**法官**依法认定；精神医学鉴定只能回答"有没有精神病"这个**医学问题**，回答不了"该不该负刑责"。

- **判"要证 vs 不用证"**：
	- 程序上的事（管辖、回避、取证合法性、供述自愿性）**照样要证明**，不因为"看起来像走流程"就免证；真正免证的**只有五类法定事项**，清单外的一律要证。

- **判"责任能力谁说了算"**：
	- 鉴定意见只解决"有没有病"的医学问题；"**有没有责任能力**"是法律问题，**由法官下最终结论**，鉴定意见不能替代法官判断。

#### 大白话讲解

##### 🔍 对号入座表：要证 vs 不用证，一次分清

| 事项           | 需要证明吗            | 定性               |
| ------------ | ---------------- | ---------------- |
| 犯罪构成（含主观明知）  | 需要               | 实体法事实            |
| 量刑情节         | 需要               | 实体法事实            |
| 管辖、回避是否适当    | 需要               | 程序法事实            |
| 取证合法性、供述自愿性  | 需要               | 程序法事实（最容易被误判为免证） |
| 众所周知的常识、自然规律 | 不需要              | 免证事实             |
| 已为生效裁判确认的事实  | 不需要              | 免证事实             |
| 责任能力有无       | 由法官依法判定，鉴定只答医学问题 | 法律问题非免证/非鉴定终局    |

##### 💰 完整数字案例：程序事实照样要证，责任能力鉴定不能拍板

> **案情①**：一起案件中，被告人主张自己的供述是被刑讯逼出来的。法庭要不要审查"这份供述是不是自愿作出的"？——**要**！取证合法性、供述自愿性属于**程序法事实**，是证明对象，不能因为"这是程序问题"就跳过不证。
>
> **案情②**：一起故意伤害案，被告人辩称自己有精神病、不应负刑责。法院委托司法精神病鉴定机构鉴定，结论是"限制刑事责任能力"。这份鉴定意见能不能**直接**决定被告人"负不负刑责"？——**不能**！鉴定意见只回答"有没有精神病、精神状态如何"这个**医学问题**；"**有没有刑事责任能力、该负多重的责**"是**法律判断**，最终由**法官**结合鉴定意见和案情依法认定，鉴定意见不是终局结论。

👉 别把"程序上的事"和"大家都认的常识"搞混——前者是要证明的程序法事实，后者才是真正免证；责任能力更是"鉴定管医学问题、法官管法律结论"的分工典范。

#### 一句话闭环记忆

> 🎯 **一眼判**：要证的＝定罪事实＋量刑情节＋程序事实（含取证合法性、自愿性）；不用证的＝五类免证事实。把"取证合法性/供述自愿性"说成"无须证明"的——**排除**（它是程序法证明对象）；把"责任能力由鉴定意见最终决定"的——**排除**（是法律问题，法官定）。

### 第三关：无罪推定·疑罪从无·不得强迫自证其罪 —— 盯死"谁能定罪""能否沉默"

> **教练提示**：一看到"检察院经审查认为甲有罪"这种表述，绝大多数同学不会警觉，觉得"起诉了不就是认定有罪吗"；一看到"不得强迫自证其罪"，又容易脑补成"嫌疑人可以全程不说话"。命题人专卡这两处最容易被现实经验带偏的地方——**定罪权只归法院**、**不强迫自证其罪不等于沉默权**。

>  定罪权只归法院（§12）；证据不足即无罪（§200③）；不强迫自证≠沉默权（§52＋§120如实回答）

- **先懂几个词**：
	- **无罪推定**
		- 在**人民法院依法判决**之前，任何人**在法律上都不算有罪**——**定罪权专属法院**，检察院、公安**无权"确定"有罪**，只能提起公诉/侦查；

	- **疑罪从无**
		- 证据不足、达不到"确实充分、排除合理怀疑"的标准时，**应当判无罪**，不是"降格判轻罪"（没有"疑罪从轻"这回事）；

	- **不得强迫自证其罪**
		- 严禁**刑讯逼供、威胁、引诱、欺骗**等手段逼人认罪——但这**不等于沉默权**，嫌疑人对侦查人员就**本案相关问题**仍负§120"**应当如实回答**"的义务，只是对**与本案无关**的问题有权拒绝回答。

- **判"谁能定罪"**：
	- 能"**确定**"一个人有罪的，**只有人民法院**依法判决——检察院起诉、公安侦查都不是"确定有罪"。

- **判"证据不足怎么判"**：
	- 证据不足不能认定有罪的，**应作无罪判决**（疑罪从无），不存在"疑罪从轻"这种中间选项。

- **判"能不能沉默"**：
	- 不得强迫自证其罪≠沉默权——嫌疑人对**本案相关提问**仍要如实回答，只能对**无关问题**拒答。

#### 大白话讲解

##### 🔍 对号入座表：三个常见错误说法，对照正解

| 常见错误说法 | 为什么错 | 正解 |
| --- | --- | --- |
| "检察院经审查确定甲有罪" | 定罪权不在检察院 | 只有**法院**判决才能确定有罪（§12） |
| "证据存疑，先按较轻罪名判" | 疑罪从无≠疑罪从轻 | 证据不足→**无罪判决**（§200③） |
| "甲有权全程保持沉默、拒答一切问题" | 混淆"不强迫自证其罪"与"沉默权" | 仍负§120**如实回答**义务，仅无关问题可拒答 |

##### 💰 完整数字案例：起诉抢劫案里的三个陷阱

> **案情**：甲被检察院以抢劫罪提起公诉。审理过程中出现三种说法：
>
> 1. "检察院经审查**确定**甲有罪，法院照办即可。"——**错**！未经人民法院依法判决，对任何人都**不得确定有罪**（§12）。检察院只能**提起公诉**，定罪权专属法院。
> 
> 2. "现有证据对甲是否持凶器有争议，法院可以先按'普通抢夺'这个较轻罪名判甲有罪。"——**错**！证据不足、不能排除合理怀疑时，应当依**疑罪从无**（§200③）作出**证据不足、指控的犯罪不能成立的无罪判决**，而不是降格从轻处理。
> 
> 3. "甲主张自己有权对侦查人员的所有提问保持沉默。"——**不准确**！§52 禁止刑讯逼供、不得强迫甲自证其罪，但这**不等于确立沉默权**——甲对与本案相关的提问仍负§120"**应当如实回答**"的义务，只有对**与本案无关**的问题才有权拒绝回答。

👉 三个陷阱共享同一个思维误区：**把现实中的"感觉像是"当成法律上的"就是"**——起诉感觉像定罪、疑罪感觉该从轻、禁止逼供感觉等于能沉默，命题人专挑这种直觉偏差下手。

#### 一句话闭环记忆

> 🎯 **一眼判**："确定有罪"只能是**法院**；证据不足＝**无罪**；不强迫自证其罪≠可沉默。选项把"确定有罪"的主体写成**检察院/公安**的——**排除**；把"不得强迫自证其罪"直接等同"确立沉默权/可拒绝如实回答"的——**排除**。

## 五、 主观题万能说理模板

### 模板一：证据裁判与证据能力/证明力
> "根据证据裁判原则（§50③），认定案件事实必须以证据为根据，且证据**必须经过查证属实**才能作为定案的根据。判断一份材料，应先审查其**证据能力**（是否具备合法性、关联性等法定资格，无资格者不得作为定案根据、非法证据依法排除），再评价其**证明力**（对待证事实的证明程度，由裁判者依关联度与可靠性判断）。二者层次不同，不可混淆。"

### 模板二：无罪推定与疑罪从无
> "依无罪推定原则（§12），未经人民法院依法判决，对任何人都不得确定有罪，**定罪权专属于人民法院**，侦查、起诉机关无权'确定有罪'。据此，当在案证据未达到'证据确实、充分'的法定证明标准、不能排除合理怀疑时，应依疑罪从无原则（§200③）作出**证据不足、指控的犯罪不能成立的无罪判决**，而非降格从轻处理。"
