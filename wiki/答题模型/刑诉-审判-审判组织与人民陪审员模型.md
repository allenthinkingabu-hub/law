# 📐 审判组织与人民陪审员 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。一道"合议庭怎么组成"的题，绝大多数同学张口就按感觉答"3人或5人呗"。但命题人挖的坑全在**"人数、独任边界、陪审员表决范围、审委会启动链条"**这四处——有陪审员的合议庭可以5人吗（**错，只能3或7人，天下没有"5人陪审庭"**）？七人合议庭陪审员什么都能表决吗（**错，只对事实表决，法律适用只能发言**）？基层普通程序能不能独任（**错，那是民诉的规则，刑诉独任死死锁在"基层＋简易/速裁"**）？案件疑难就能合议庭自己交审委会吗（**错，须先提请院长决定**）？今天用**一条四步流水线**把审判组织一次拆清：**判亲历性 → 定人数与独任 → 走评议与审委会 → 判陪审员表决范围**。

## 适用场景与解决问题

本模型解决"审判组织与人民陪审员"全部判定与陷阱（对应 [[刑诉-审判程序-深度报告]] 板块六「刑事审判概述与基本制度」考点1/3/5/6，并兼服务板块一考点8/9/10）：

1. **审判亲历性与集中审理（考点1/3）**：直接审理＋言词审理；开庭后更换合议庭成员须由新庭重新开庭；集中审理不间断、审判人员不更换。
2. **合议庭组成与独任边界（考点8/9）**：一审有陪审员只能3或7人（无5人陪审庭）；二审只能3或5人；独任绝对限于"基层＋简易/速裁"。
3. **评议规则与审判委员会（考点5/10）**：评议少数服从多数、少数意见"应当"记笔录、全体签名；审委会须合议庭提请院长决定、院长主持、合议庭应当执行。
4. **人民陪审员制度（考点6）**：选任任命、资格排除、参审权利、三人庭/七人庭表决范围、分歧救济。
5. **两审终审制及例外、审判模式（附）**：两审终审四类例外；职权主义向控辩式改革的标志。

> **核心一句**：先判**亲历性**（开庭后换合议庭成员＝新庭重新开庭，旧审不生效）→ 再定**人数与独任**（有陪审员＝3或7人无5人；独任只限"基层＋简易/速裁"，二审3或5人不含陪审员不能独任不能7人）→ 走**评议与审委会**（少数服从多数、少数意见"应当"记笔录、全体签名；审委会须合议庭提请院长决定、院长主持、合议庭应当执行）→ 判**陪审员表决范围**（三人庭事实法律同权，七人庭只表决事实、法律仅发言；基层法院同级人大常委会任命）。

> 🔎 **法条口径**：刑诉法§10（两审终审）、§183（合议庭组成与独任）、§184（评议规则）、§185（审判委员会）、§188/§202（公开审判，另见 [[刑诉-审判-单选-09 · 公开审判与不公开审理的两档区分（仿真题）|单选-09]]）+ 《人民陪审员法》（选任任命、参审范围、三人/七人庭表决范围）。

> ⚠️ **易记错点（命题人最爱反向设陷）**：①**有陪审员的合议庭只能3或7人，无5人陪审庭**；②**独任绝对限于"基层＋简易/速裁"**，普通程序、中院一审都不能独任（防民诉带偏）；③**七人合议庭陪审员只表决事实、不表决法律适用**（三人庭才事实法律同权）；④**换合议庭成员须"新庭重新开庭"**，不是换完接着审；⑤**审委会由合议庭"提请院长决定"提交**，合议庭不能自行直接提交，审判长个人也不能；⑥**陪审员任命机关＝基层法院同级人大常委会**（中院所需陪审员从基层名单随机抽取，不是中院所在市人大直接任命）；⑦**两审终审例外**别把"一审期满无上诉自动生效""再审改判"当例外（前者是"生效"、后者是纠错程序）。

## 一、 核心考情

- **频次研判**：**人民陪审员制度 ★★★★，题量最大、近5年年年考**；合议庭组成与独任边界、评议与审委会 ★★★★；审判亲历性与集中审理 ★★★★；两审终审制 ★★★、审判模式 ★★（分值较低，选择题干扰项常出现）。
- **命题核心**：

## 三、 四大核心规则与命题陷阱拆解

### 1. 审判亲历性与集中审理（§183相关司法解释精神）

- **审判亲历性**＝**直接审理**（法官自始至终亲历庭审全程）＋**言词审理**（举证质证辩论以言词进行）。开庭后、评议前更换合议庭成员（含陪审员），须由**新组成的合议庭重新开庭审理**。
- **集中审理原则**＝审理集中、不间断、审判人员不更换。**陪审员中途离场40分钟＝违反集中审理原则**（不是"直接言词"，这是最常见的偷换项）。
- **⚠️ 命题陷阱**：把"换人后接着审"当合法（错，须新庭重新开庭）；把"陪审员离场"定性成违反直接言词原则（错，是违反集中审理原则）。

### 2. 合议庭组成与独任边界（§183）

- **合议庭组成**：一审"审判员＋人民陪审员"只能**3人或7人**（**无5人陪审庭**）；二审只能**3人或5人**（不能独任、不能7人、不含陪审员）。
- **独任审判**：**绝对限于"基层法院＋简易/速裁程序"**，审判员一人；**普通程序绝不能独任**（民诉2021把独任扩张到基层普通一审，刑诉没有）。
- **⚠️ 命题陷阱**：把"5人含陪审员"当合法组成（错，不存在）；把"基层普通程序独任"当合法（错，那是民诉规则）。

### 3. 评议规则与审判委员会（§184/§185）

- **评议**：**少数服从多数**；不同意见**"应当"记入笔录**；评议笔录由**合议庭全体成员签名**、书记员亦签。
- **审判委员会**：疑难/复杂/重大且合议庭难以决定的→**合议庭"提请院长决定"提交**（非合议庭自己直接交、非审判长个人决定）→审委会讨论决定→**合议庭"应当执行"**；审委会由**院长主持**、实行**民主集中制过半数**。
- **⚠️ 命题陷阱**：把"少数意见可以不记"当合法（错，"应当"记）；把"合议庭自行提交审委会"当合法（错，须提请院长决定）。

### 4. 人民陪审员制度（人民陪审员法＋§183）

- **选任任命**：**基层法院**会同司法行政/公安从常住居民名单随机抽选、**提请基层法院同级人大常委会任命**。
- **表决范围**：**三人合议庭**陪审员对事实认定与法律适用**与法官同权**；**七人合议庭**陪审员**只对事实认定参与表决，对法律适用可发表意见但不参与表决**。
- **⚠️ 命题陷阱**：把"中院所在市人大常委会任命"当合法（错，是基层法院同级人大常委会）；把"七人庭陪审员对法律适用也表决"当合法（错，只表决事实）。

## 四、 万能解题四步

> 拿到一道"审判组织"的题，别凭感觉答人数，按下面四步逐层拆。

### 第一步：审判亲历性与集中审理（换人必重审）

> **教练提示**：这一步的题干模板永远是"庭审到一半，某法官/陪审员生病、离场、被换了，接下来怎么办？"——你只要抓住一根主线：**"裁判者必须亲眼亲耳把整场庭审经历一遍"**，答案自然浮出来。

> # 换合议庭成员须新庭重新开庭；陪审员中途离场违反集中审理原则

- **先懂几个词（翻成人话）**：
	- ：判案子的法**亲历性**官，必须自己**从头到尾坐在审判台上**、亲耳听证人说、亲眼看证据质证。不能"张三审、李四判"。 -> 承办法官亲自接触证据、亲自听取控辩意见.
		- **直接审理**：法官须直接接触案件、亲历全程（对应"人"）。
		- **言词审理**：举证、质证、辩论都要**当庭用嘴说出来**（对应"方式"）。-> 裁判法官必须**直接接触当事人、接收诉辩意见**，而非单纯依靠书面卷宗定案。
	- **集中审理**：一个案子要**集中、不间断地一口气审完**，审判人员中途不换。

- **判法**：开庭后有人员更换→**新合议庭重新开庭审理**（旧审不生效）；只换缺位那一名成员、其余不必更换；陪审员中途离场超时→**违反集中审理原则**（非直接言词）。

| 证人远程视频出庭作证           | ✅ 不违亲历性     | 仍是当庭言词质证                 |
| 控辩双方在场下庭外核实证据        | ✅ 不违亲历性     | 法官仍亲历该核实                 |
| 二审不开庭、讯问被告人+听取各方意见   | ✅ 合法书面审     | 法定例外，不违亲历性               |
###### 控辩双方在场下庭外核实证据
证据涉及涉密、隐私、物证体积过大 / 不便搬入法庭、鉴定材料需现场比对等，无法当庭出示质证，法庭可组织**庭外核实**。

###### 二审不开庭\讯问被告人+听取各方意见

原判事实清楚、证据无实质争议，上诉仅针对**法律适用、量刑**，不属于法定必须开庭四类案件（死刑上诉、抗诉、事实证据异议、其他应当开庭情形）. 不开庭≠只看卷宗，法定强制两步： 
- 法官亲自讯问被告人（面对面听取本人陈述）；
- 主动听取辩护人、公诉方、其他当事人书面 / 口头意见。

##### 💰 完整数字案例：突发心梗的王法官

> **案情**：某故意伤害案在基层法院公开开庭，审到法庭辩论、还没评议，合议庭3名成员之一的王法官突发心梗住院。法院把王法官换成没参加过庭审的赵法官后——正确做法是：**只换王法官这一人**（另2名照旧），由"赵法官＋原2名"组成的**新合议庭重新开庭、从头审一遍**；之前审过的那半场，对新合议庭**不发生效力**、须重来。这一重来**恰恰体现集中审理**（一口气重审、不间断），也是为满足**亲历性**（赵法官得亲历全程）。→ 对应 [[刑诉-审判-多选-54 · 庭审中更换合议庭成员与集中审理原则|多选-54]]（答案ACD）。

> 🎯 **一眼判**：**换合议庭成员 → 新人须亲历 → 新庭重新开庭（旧审对新庭不生效）；只换缺位那位，不必全换。陪审员离场＝违"集中审理"（非直接言词）。**

### 第二步：合议庭组成与独任边界（3/7人·独任只限简易速裁）

> **教练提示**：这一步就是背**人数**和**独任的红线**。人数记"**有陪审员＝3或7、二审＝3或5**"，独任记"**只有基层＋简易/速裁能独任**"。民诉考生尤其注意别把民诉的独任扩张搬过来。

> # 3/7人组庭；独任绝对限于"基层＋简易/速裁"

- **先懂几个词**：
	- **合议庭**：由多名审判人员（法官±陪审员）合议审判的组织。
	- **独任审判**：审判员**一人**独审。
	- **人民陪审员**：非职业法官、经选任参加审判的普通公民。

- **判法**：
	- 基层+简易/速裁→**可独任**；
	- 基层/中院普通一审→**3人或7人**（无5人陪审庭）；
	- 二审→**3人或5人**（不含陪审员，不能独任不能7人）。

### 第三步：评议规则与审判委员会（多数决·记笔录·提请院长）

> **教练提示**：评议记三个动作"**多数决、记笔录、全签名**"；审委会记一条链"**合议庭提请→院长决定→审委会讨论→合议庭执行**"，任何"跳过院长""审判长个人决定""合议庭自己直接交"都是错的。

> # 评议多数决记笔录全签名；审委会须合议庭提请院长决定

- **先懂几个词**：
	- **评议**：合议庭闭门讨论、对定罪量刑作决定。
	- **审判委员会（审委会）**：法院内部最高审判业务组织，讨论决定重大疑难案件。

- **判法**：评议表决→**少数服从多数**，少数意见**"应当"记笔录**、**全体签名**；案件疑难→**合议庭提请院长决定提交**→审委会讨论→**合议庭应当执行**。

#### 大白话讲解

##### 🔍 对号入座表

| 环节    | 规则                    | 陷阱                       |
| ----- | --------------------- | ------------------------ |
| 评议表决  | 少数服从多数（民主集中制）         | —                        |
| 少数意见  | **"应当"记入笔录**（不是"可以"）  | 漏记＝程序违法                  |
| 笔录签名  | 合议庭**全体成员**签名＋书记员签    | 持异议者也须签                  |
| 审委会启动 | **合议庭提请→院长决定提交**      | ❌ 合议庭直接交、❌ 审判长个人决定       |

##### 💰 完整数字案例：贪污案评议2票有罪1票无罪

> 🎯 **一眼判**：**评议＝多数决＋少数意见"应当"记笔录＋全体签名；审委会＝合议庭提请、院长决定、院长主持、过半数、合议庭应当执行。**

### 第四步：人民陪审员制度（选任·资格·权利·表决范围）★★★★ 高频

> **教练提示**：这一步是本板块**唯一★★★★、题量最大**（近5年年年考）。四个抓手："**谁任命、谁不能当、有啥权、表决管到哪**"。最毒的坑是**七人庭表决范围**——务必背死"事实能表决、法律只发言"。

> 基层法院同级人大任命；七人庭陪审员只表决事实

- **先懂几个词**：
	- **选任**：从常住居民中随机抽选产生陪审员。
	- **参审**：陪审员参加合议庭审理案件。

- **判法**：
	- 任命→**基层法院提请同级人大常委会**；
	- 表决范围→**三人庭事实法律同权、七人庭只表决事实**；
		- 三人庭: 陪审员**事实认定、法律适用均独立发表意见、完整投票**，和法官权利完全平等‘
		- 七人庭:
			- 事实部分：陪审员可发言、共同表决；
			- 法律适用（罪名、量刑、程序规则）：仅能提意见，**无投票权，只有法官表决**。
	- 分歧→**只能经合议庭提请院长**决定是否交审委会。

#### 大白话讲解

##### 🔍 对号入座表：四抓手

| 抓手         | 规则                                                          | 陷阱/易错                            |
| ---------- | ----------------------------------------------------------- | -------------------------------- |
| **① 选任任命** | 基层法院会同司法行政/公安从常住居民名单**随机抽选**，**提请基层法院同级人大常委会任命**            | ❌ 中院所在市人大直接任命；中/高院所需陪审员从基层名单随机抽取 |
| **② 资格排除** | 被吊销执业证的律师/公证员、**在职法官/检察官/公安等公职人员**、失信被执行人**不得任**            | 一般应具**高中以上文化**（非大专），农村等地可放宽      |
| **③ 参审权利** | 庭前**有权阅卷**；经审判长许可**可向证人发问**；结案后**送达裁判文书副本**                 | 与法官同职权（在其表决范围内）                  |
| **④ 表决范围** | **三人庭**：事实认定＋法律适用**与法官同权**；**七人庭**：只对事实认定表决（同权），法律适用可发言、不表决 | 🚫 别答"七人庭陪审员对法律适用也表决"            |
| **⑤ 分歧救济** | 陪审员与审判长分歧，**只能通过合议庭提请院长**决定是否交审委会                           | ❌ 自行提请院长、❌ 直接提交审委会               |
| **⑥ 中外对比** | 国外陪审团**只定罪（管事实）**、量刑归法官；我国陪审员**事实法律皆参与（三人庭）**               | 目的不仅"制约法官"                       |

##### 💰 完整数字案例：罗某在七人合议庭里的权利边界

> **案情**：罗某被选为陪审员，参加D市**中级**法院一起重大案件的**七人**合议庭——①罗某由**基层法院提请其同级人大常委会任命**（不是"D市人大常委会必须任命"）；②在这个七人庭里，罗某**对事实认定**与法官一样投票，但**对法律适用只能发表意见、不参与表决**；③罗某庭前可阅卷、经许可可向证人发问、结案后收到裁判文书副本；④若罗某与审判长意见分歧，**只能通过合议庭提请院长**决定是否提交审委会，不能自己直接提请或提交。→ 对应左宁真金题212/213（2015-2-35、2021金题）、杨雄真金题17/18/20/21/22（陪审员权利/资格/中外对比/分歧救济）。

#### 一句话闭环记忆

> 🎯 **一眼判**：**陪审员＝基层法院同级人大任命；七人庭只表决事实、法律只发言；三人庭事实法律同权；分歧只能经合议庭提请院长；吊销执业证/在职公职人员/失信人不能当。**

### 两审终审制及例外（§10）

**两审终审**＝案件经两级法院审理后，普通审判程序即告终结、裁判生效。**四类例外**：

| 例外 | 说明 |
|---|---|
| ① 死刑复核程序 | 死刑案在二审后还须复核核准才生效 |
| ② 最高人民法院一审 | 最高法一审即终审、不得上诉 |
| ③ 法定刑以下判刑 | 报最高法核准后生效 |
| ④ 自诉刑事调解书 | 经双方当事人签收即生效、不得上诉 |

> ⚠️ **干扰项**：**"一审期满无上诉抗诉自动生效"是"生效"，不是"例外"**；**"再审撤销改判二审生效裁判"是纠错程序，不改变审级制度、不是例外**。

### 审判模式（速览）

我国审判模式由**职权主义**逐步引入当事人主义、弱化职权色彩（**混合式**，非纯当事人主义）。改革标志抓两点：**2012修法"强制证人出庭"**、庭前审查由**实体审查改为程序审查**。"让审理者裁判、由裁判者负责"体现**审判亲历性/直接审理**（不是"细化三大职能"）。证人出庭率低→说明控辩式改革仍需完善。

> 🎯 **一眼判**：**两审终审四例外＝死刑复核/最高法一审/法定刑以下核准/自诉调解书；"强制证人出庭"＝控辩式改革标志。**
