# 📐 起诉与受理 · 完整答题模型（四要件登记立案 + 七类告知清单 + 三种"不行"的分流）

> **核心一句**：一张起诉状进法院要走三步：**先看四要件齐不齐（§122，登记立案7日，§126）→ 再看撞没撞上"挡在门外的清单"（§127七类告知处理）→ 最后分清三种"不行"（不予受理=门口裁定、驳回起诉=进门后请出去的裁定、驳回诉讼请求=审完输了的判决）**。最毒陷阱是**把"驳回起诉"和"驳回诉讼请求"当同一回事**（前者程序裁定、再诉可受理；后者实体判决、再诉即重复起诉）、**把生效裁判后又起诉说成"告知另行起诉"**（正确是告知申请**再审**）、**把撤诉后再诉当禁区**（应予受理，唯离婚案6个月除外）、**把"立案后发现不符合条件"处理成"裁定不予受理"**（立案后只能裁定**驳回起诉**）。
>
> 🔎 **核心条文速查**：
> - **民诉法§122【起诉四条件】**：①原告是与本案有**直接利害关系**的公民、法人和其他组织；②有**明确的被告**；③有**具体的诉讼请求**和事实、理由；④属于人民法院**受理民事诉讼的范围**和受诉人民法院**管辖**。
> - **民诉法§123【起诉形式】**：起诉应当递交起诉状，并按被告人数提出副本；书写起诉状确有困难的，可以**口头起诉**，由法院记入笔录并告知对方当事人。
> - **民诉法§126【必须受理与7日立案】**：对符合§122的起诉**必须受理**；符合起诉条件的**7日内立案**并通知当事人；不符合的**7日内作出裁定书，不予受理**；原告不服**可以上诉**。
> - **民诉法§127【七类告知处理】**：(一)属行政诉讼受案范围→告知提**行政诉讼**；(二)有书面仲裁协议不得起诉→告知申请**仲裁**；(三)应由其他机关处理→告知向**有关机关**申请解决；(四)不属本院管辖→告知向**有管辖权的法院**起诉；(五)对已生效判决、裁定、调解书又起诉→告知申请**再审**（准许撤诉的裁定除外）；(六)法定期限内不得起诉的案件在期限内起诉→**不予受理**；(七)判决不准离婚和调解和好的离婚案件、判决/调解**维持收养关系**的案件，无新情况新理由**6个月内**又起诉→**不予受理**。
> - **民诉法§157【裁定范围与可上诉三裁定】**：裁定适用于不予受理、管辖权异议、驳回起诉、保全和先予执行等十一项；对**前三项**（不予受理、管辖权异议、驳回起诉）裁定**可以上诉**。
> - **民诉解释§208【登记立案】**：符合§122且不属§127情形的**应当登记立案**；当场不能判定的接收材料、出具**注明收到日期的书面凭证**；需补材料的及时告知，补齐后**7日内**决定是否立案；**立案后发现**不符合起诉条件或属§127情形的，**裁定驳回起诉**。
> - **民诉解释§212【程序裁定后的再诉】**：裁定不予受理、驳回起诉的案件，原告再次起诉，符合起诉条件且不属§127情形的，**应予受理**。
> - **民诉解释§214【撤诉后再诉】**：撤诉或按撤诉处理后以同一诉讼请求再诉，**应予受理**；离婚案件无新情况新理由6个月内又起诉的，**比照§127(七)不予受理**。
> - **民诉解释§219【时效届满的处理】**：超过诉讼时效期间起诉的，法院**应予受理**；受理后对方提出时效抗辩且成立的，**判决驳回原告的诉讼请求**（判决、非裁定）。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [民诉解释（法释〔2022〕11号修正，国家法律法规数据库检索）](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已在本地权威全文（ssf.gov.cn发布的民诉法2023全文PDF转文本、民诉解释2022全文）中**逐条grep到原文**后写入：民诉法§122、§123、§124、§126、§127、§157，民诉解释§208、§209、§211、§212、§213、§214、§215、§217、§218、§219、§247、§248、§328、§330、§331、§406。**特别订正**：①民诉法**§124是"起诉状应当记明的事项"**（当事人信息、诉请与事实理由、证据），**不是**不予受理条款——7日立案/不予受理在**§126**、七类告知处理在**§127**，三条不可混标；②"立案登记制"在民诉法本体中没有以"登记立案"字样出现，其规范落点是**解释§208**（grep"登记立案"命中该条）；③"判决驳回诉讼请求"作为实体处理，其在起诉受理板块最直接的条文示例是**解释§219**（时效抗辩成立判决驳回诉讼请求），"三分"框架本身系条文组合＋学理通说，本模型不为框架虚标单一条号。深度报告6-1/6-2/6-3三行真题栏均为"—（待真题入库）"，本模型如实注明，不编造真题。

> ⚠️ **易记错点**：①**驳回起诉（裁定）≠驳回诉讼请求（判决）**——前者说"这案子不该审"，程序出口、可上诉、补正后再诉可受理（解释§212）；后者说"审完了你输了"，实体出口、按判决上诉、同一诉再诉构成重复起诉（解释§247）；②**立案前不符合条件→裁定不予受理（§126）；立案后才发现→裁定驳回起诉（解释§208 III）**——分水岭是"立案"这个动作，不看案件性质；③**生效裁判又起诉→告知申请再审**（§127(五)），不是"另行起诉"，也不是直接裁定驳回；但**准许撤诉的裁定**除外——撤诉未经过实体裁判，再诉应予受理（解释§214）；④**离婚6个月限制是"双向"的**：判决不准离婚/调解和好后6个月内原告无新情况新理由又起诉→不予受理（§127(七)），撤诉的离婚案6个月内再诉→**比照**处理（解释§214 II）；维持**收养关系**的判决/调解同此待遇；⑤**超过诉讼时效起诉，法院应予受理**（解释§219），不是不予受理——时效届满只产生抗辩权，法院不得主动适用，抗辩成立后用**判决**驳回诉讼请求；⑥**可上诉的裁定只有三种**：不予受理、管辖权异议、驳回起诉（§157末款），保全、中止诉讼等裁定都不可上诉；⑦被告不明确的处理是**先告知补正，补正后仍不能确定才裁定不予受理**（解释§209），不是一上来就拒收。

## 二、 三步判别模型（递状子 → 挡门清单 → 三种"不行"的分流）

```
                【原告拿着起诉状来法院立案】
                        │
     ▼ 第一步：递状子——四要件齐不齐？（§122/§123/§126，解释§208/§209）
     │
     ├─ 四要件（§122）：直接利害关系原告 + 明确被告 + 具体诉请和事实理由
     │                 + 主管与管辖
     ├─ 形式（§123/§124）：起诉状+按被告人数副本；书写困难可口头起诉
     ├─ 登记立案（解释§208）：符合§122且不属§127 → 应当登记立案；
     │   当场不能判定 → 接收材料+出具注明收到日期的书面凭证；
     │   补材料 → 补齐后7日内决定是否立案
     ├─ 符合 → 必须受理，7日内立案并通知（§126）
     └─ 不符合 → 7日内裁定不予受理，原告可上诉（§126）
     　　（被告不明确：先告知补正 → 仍不能确定才裁定不予受理，解释§209）
                        │
     ▼ 第二步：挡门清单——撞上§127七类了吗？（告知处理）
     │
     ├─ (一)行政诉讼受案范围 ──→ 告知提行政诉讼
     ├─ (二)有书面仲裁协议不得起诉 ──→ 告知申请仲裁（坚持起诉→裁定不予受理，解释§215）
     ├─ (三)应由其他机关处理 ──→ 告知向有关机关申请解决
     ├─ (四)不属本院管辖 ──→ 告知向有管辖权法院起诉（坚持起诉→裁定不予受理；
     │      立案后才发现无管辖权→移送，不是驳回，解释§211）
     ├─ (五)生效判决/裁定/调解书又起诉 ──→ 告知申请再审（准许撤诉的裁定除外）
     ├─ (六)法定期限内不得起诉的案件在期限内起诉 ──→ 不予受理
     └─ (七)判决不准离婚/调解和好、判决/调解维持收养关系，
            无新情况新理由6个月内又起诉 ──→ 不予受理
            （撤诉的离婚案6个月内再诉→比照处理，解释§214 II）
                        │
     ▼ 第三步：三种"不行"的分流——阶段+文书形式+救济（§157，解释§208/§212/§219/§247）
     │
     ├─ 立案前就不符合条件 ──→ 裁定【不予受理】：程序性，可上诉（§126/§157），
     │      补正后再诉应予受理（解释§212）
     ├─ 立案后才发现不符合条件或属§127情形 ──→ 裁定【驳回起诉】：程序性，
     │      可上诉（§157），补正后再诉应予受理（解释§212）
     └─ 实体审理后请求不成立（如时效抗辩成立）──→ 判决【驳回诉讼请求】：实体裁判，
            按判决上诉；同一诉再诉=重复起诉（解释§247三同）
```

> **一句话总诀**：**「递状子看四件（原告被告请求主管管辖，登记立案七日出结果）；挡门看七类（行政仲裁他机关、无管辖去别家、生效裁判找再审、期限未满和离婚收养六个月不收）；三个'不行'分阶段（门口不予受理、进门驳回起诉——都是裁定可上诉；审完驳回诉请是判决——再诉就是重复起诉）」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **驳回起诉=驳回诉讼请求** | "法院经审理认为甲的请求已过诉讼时效，应当裁定驳回起诉。" | **❌ 错！** 时效抗辩成立是**实体**问题，用**判决驳回诉讼请求**（解释§219）；"裁定驳回起诉"只用于立案后发现**不符合起诉条件**的程序出口（解释§208 III）。文书形式一换，救济途径、再诉命运全变。 |
| **立案后不符合条件裁定不予受理** | "立案后发现原告与本案没有直接利害关系，法院应裁定不予受理。" | **❌ 错！** "不予受理"只存在于**立案前**；立案这个动作一旦完成，出口只剩**裁定驳回起诉**（解释§208 III）。分水岭是"立案"，不是案件毛病的种类。 |
| **生效裁判又起诉告知另行起诉** | "对已发生法律效力的判决，当事人又起诉的，法院应告知其另行起诉。" | **❌ 错！** §127(五)：告知申请**再审**（准许撤诉的裁定除外）。"另行起诉"是二审新增独立诉请调解不成时的通道（解释§326），别搬错场景。 |
| **超过时效的起诉不予受理** | "债权已过诉讼时效，法院应当裁定不予受理。" | **❌ 错！** 应予**受理**（解释§219）——时效届满只生抗辩权、法院不得主动适用（民法典§193）；对方抗辩成立的，**判决**驳回诉讼请求。 |
| **撤诉后再诉不予受理** | "原告撤诉后就同一诉讼请求再次起诉的，法院不予受理。" | **❌ 错！** 撤诉未经过实体裁判，再诉**应予受理**（解释§214）；唯**离婚案件**无新情况新理由**6个月内**再诉，比照§127(七)不予受理。 |
| **所有裁定都能上诉** | "对保全裁定、中止诉讼裁定不服的，均可提起上诉。" | **❌ 错！** 可上诉的裁定只有**三种**：不予受理、管辖权异议、驳回起诉（§157末款）；保全裁定走复议，不能上诉。 |

## 四、 相邻制度对照表（同场竞技，勿混规则）

| 事项 | 本模型规则 | 相邻制度对照 |
|---|---|---|
| 不予受理（裁定，立案前） | 7日内作出裁定书，可上诉（§126）；补正后再诉应予受理（解释§212） | **驳回起诉**（裁定，立案后，解释§208 III，可上诉）；**驳回诉讼请求**（判决，实体审理后，解释§219，按判决上诉） |
| 判决驳回诉讼请求后再诉 | 三同齐备=重复起诉，裁定不予受理/驳回起诉（解释§247） | **新事实再诉**应当受理（解释§248）；撤诉后再诉应予受理（解释§214）——详见[[民诉-总论-主管与诉模型]]第四步 |
| 有仲裁协议的起诉 | 告知申请仲裁（§127(二)）；坚持起诉裁定不予受理（解释§215） | 仲裁协议**无效/不存在**（如约定了不存在的"某区仲裁委员会"）→诉讼大门打开；仲裁协议效力异议走仲裁法裁定通道 |
| 立案后发现不属本院管辖 | **移送**有管辖权的法院（解释§211），不是驳回起诉 | 立案**前**发现无管辖权：告知向有管辖权法院起诉，坚持起诉→裁定不予受理（解释§211） |
| 离婚案6个月限制（§127(七)） | 判决不准离婚/调解和好后，原告无新情况新理由6个月内又起诉→不予受理；撤诉的离婚案比照（解释§214 II） | **被告**另行起诉不受此限（限制的是"原告"）；**维持收养关系**的判决/调解同享6个月限制；赡养费/扶养费/抚养费案裁判生效后有新情况再诉→**作新案受理**（解释§218） |
| 一审程序裁定错误的纠正 | 二审查明**不予受理**裁定错误→撤销+指令立案受理；**驳回起诉**裁定错误→撤销+指令审理（解释§330） | 二审认为依法不应由法院受理→直接裁定撤销原裁判、驳回起诉（解释§328）；再审发现不符合起诉条件→裁定撤销一、二审**判决**，驳回起诉（解释§406）；不服三裁定的上诉可**不开庭审理**（解释§331） |

## 五、 万能三步答题模型

在法考答题中（客观题逐项判断按此顺序定位考点），按以下三步涵摄：

*   🚗 **统一案例**：老王借给老李**10万元**，借条写明2025年1月1日到期，到期老李不还。2026年3月，老王写好起诉状去法院告老李。三个变体剧本备用：**剧本B**——借款合同里有一条"争议提交B市仲裁委员会仲裁"；**剧本C**——立案后法院才发现起诉的"老王"其实是替真债权人出头的表哥，与本案没有直接利害关系；**剧本D**——这笔借款其实2022年就到期了，老李开庭时抗辩"已过3年诉讼时效"。

### 第一步：递状子诀——四要件齐不齐？7日内出什么结果？

> **原告被告请求主管管辖，登记立案七日两条路**

#### 概述

起诉要过**四要件**（民诉法§122）：①**直接利害关系**的原告——自己的权利自己主张，替别人出头不行；②**明确的被告**——告谁得说清楚，标准是"信息具体明确、**足以与他人相区别**"（解释§209），列写不足的**先告知补正**，补正后仍不能确定才裁定不予受理；③**具体的诉讼请求**和事实、理由——"还我血汗钱"不行，得写明还多少、依据什么；④**主管+管辖**——归法院管、且归**这家**法院管。

形式上递**起诉状**+按被告人数的**副本**（§123），书写确有困难可以**口头起诉**、法院记入笔录并告知对方。起诉状记明事项在§124（当事人信息、诉请与事实理由、证据和证据来源、证人姓名住所）。

**立案登记制**（解释§208）把法院的动作定死：符合§122且不属§127的，**应当登记立案**；当场判定不了的，**接收材料+出具注明收到日期的书面凭证**（不许"不收材料不出手续"）；要补材料的及时告知，**补齐后7日内**决定是否立案。最终两条路（§126）：符合→**必须受理，7日内立案**并通知；不符合→**7日内作出裁定书，不予受理**，原告不服**可以上诉**。

#### 大白话讲解

老王到立案窗口递材料，法官拿四要件过筛：

| 起诉条件（§122） | 本案对应 | 是否满足 |
|---|---|---|
| ①直接利害关系的原告 | 老王是借条上的出借人本人 | ✅ |
| ②明确的被告 | 老李，姓名、住址写得清清楚楚 | ✅ |
| ③具体的诉讼请求和事实理由 | 请求判令归还借款10万元+借条为证 | ✅ |
| ④主管+管辖 | 平等主体借款纠纷归法院管，被告住所地法院受诉 | ✅ |

四条全过，法院**必须收**，最迟**7日内立案**并通知老王——立案登记制下，窗口没有"看不顺眼就不收"的权力：就算当场判定不了，也得**收下材料、给一张写明收到日期的凭证**；材料缺了让补，补齐后**7日内**必须给答复。

反过来试两个失败版本：如果老王只写"被告：住我家隔壁的'四川小老板'"——被告不明确，法院**先告知补正**，实在补不出来才**裁定不予受理**（解释§209，注意不是直接拒收）；如果老王的起诉状写得潦草，他还可以**口头起诉**，由法院记入笔录（§123）。而无论哪种"不收"，法院都必须出**裁定书**，老王都能**上诉**——"不予受理"永远是一份可上诉的法律文书，不是窗口的一句"回去吧"。

#### 一句话闭环记忆

> 🎯 **一眼判**：四要件=利害关系原告+明确被告（足以区别即可，先补正后裁定）+具体诉请事实理由+主管管辖；登记立案：符合必须收、**7日立案**，不符合**7日裁定不予受理、可上诉**；当场定不了→收材料出凭证。

### 第二步：挡门诀——撞上§127七类告知清单了吗？

> **行政仲裁他机关，无管辖去别家；生效找再审，期限离婚收养六个月**

#### 概述

有些起诉四要件表面齐了，却撞上法定的"此路不通"清单——民诉法§127对七类起诉**分别情形予以处理**，本质是把当事人**指去正确的救济通道**：

- **(一)行政诉讼受案范围**→告知提**行政诉讼**（民告官走行政庭）；
- **(二)有书面仲裁协议、不得起诉**→告知申请**仲裁**——原告坚持起诉的，**裁定不予受理**（解释§215）；
- **(三)应由其他机关处理的争议**→告知向**有关机关**申请解决（如劳动争议先仲裁）；
- **(四)不属本院管辖**→告知向**有管辖权的法院**起诉——坚持起诉的裁定不予受理；但**立案后**才发现无管辖权的，是**移送**，不是驳回（解释§211）；
- **(五)生效判决、裁定、调解书又起诉**→告知申请**再审**——但**准许撤诉的裁定**除外（撤诉没经过实体裁判，再诉应予受理，解释§214）；
- **(六)法定期限内不得起诉的案件**在期限内起诉→**不予受理**；
- **(七)判决不准离婚和调解和好的离婚案件、判决/调解维持收养关系的案件**，没有新情况、新理由，**原告6个月内又起诉**→**不予受理**——撤诉的离婚案6个月内再诉，**比照**本项处理（解释§214 II）。

#### 大白话讲解

拿三个剧本往清单上撞：

**剧本B（仲裁条款）**：法官翻到借款合同最后一页："你们约定了'争议提交B市仲裁委员会仲裁'——有书面仲裁协议，**这案子该去仲裁**，我告知你去申请仲裁（§127(二)）。"老王梗着脖子："我就要在法院告！"法官摇头："那我只能**裁定不予受理**（解释§215）。"——注意整个流程是"**先告知、坚持才裁定**"，不是一上来就裁定。

**剧本变体（挑错法院）**：老王跑到自己住所地法院起诉——借款纠纷该去被告老李住所地法院。**立案前**发现：告知老王去有管辖权的法院，他坚持就裁定不予受理；**立案后**才发现：**移送**有管辖权的法院（解释§211）——同一个毛病，立案前后处理完全两样，这是(四)项最爱考的细节。

**剧本变体（离婚6个月）**：老王他妹起诉离婚，法院**判决不准离婚**；5个月后她**没有任何新情况新理由**又去起诉——**不予受理**（§127(七)），得等满6个月。三个联动细节：①限制的是**原告**，那5个月里她丈夫想起诉离婚，**不受限制**；②她如果当时是**撤诉**而非被判不准离婚，6个月内再诉同样**比照**不予受理（解释§214 II）——离婚案是"撤诉后再诉应予受理"的唯一例外；③**维持收养关系**的判决/调解享受同款6个月限制。对照记一个"放行"情形：赡养费案判完后物价大涨（**新情况**），再诉要求增加费用→**作新案受理**（解释§218）。

**剧本变体（生效判决又起诉）**：老王的案子判完生效了，他嫌判少了，拿同一张借条**再起诉一次**——法院告知他去**申请再审**（§127(五)），不是"另行起诉"，也不是先收进来再驳回。

#### 一句话闭环记忆

> 🎯 **一眼判**：七类清单=四条"指路"（行政诉讼/仲裁/其他机关/有管辖权法院）+一条"找再审"（生效裁判又起诉，准许撤诉的裁定除外）+两条"直接不收"（法定期限内不得起诉；离婚·收养6个月无新情况新理由）；仲裁/管辖两项都是**先告知、坚持起诉才裁定不予受理**；立案后发现无管辖权=**移送**。

### 第三步：分流诀——三种"不行"，阶段、文书、救济各是什么？

> **门口不予受理、进门驳回起诉，都是裁定可上诉；审完驳回诉请是判决，再诉重复**

#### 概述

法院说"不行"有三种说法，**阶段、文书形式、救济途径**一一对应，错位即失分：

| 维度 | 不予受理 | 驳回起诉 | 驳回诉讼请求 |
|---|---|---|---|
| 发生阶段 | **立案前**（门口） | **立案后**发现不符合起诉条件或属§127情形（解释§208 III） | **实体审理后**（请求不成立，如时效抗辩成立，解释§219） |
| 解决的问题 | 程序：该不该收 | 程序：该不该继续审 | **实体**：原告赢不赢 |
| 文书形式 | **裁定**（§126） | **裁定**（解释§208 III） | **判决**（解释§219"判决驳回"） |
| 能否上诉 | 能（§126/§157(一)） | 能（§157(三)） | 能（按**判决**上诉，非"可上诉三裁定"） |
| 再诉命运 | 补正后再诉**应予受理**（解释§212） | 补正后再诉**应予受理**（解释§212） | 同一诉再诉=**重复起诉**（解释§247三同），裁定不予受理/驳回起诉 |
| 上级纠错 | 二审查明错误→撤销+**指令立案受理**（解释§330） | 二审查明错误→撤销+**指令审理**（解释§330） | 走二审改判/再审；再审中发现根本不符合起诉条件→撤销一、二审判决**裁定驳回起诉**（解释§406） |

记忆锚点：**§157可上诉三裁定=不予受理+管辖权异议+驳回起诉**——"驳回诉讼请求"根本不是裁定，自然不在这张清单里；它是判决，走判决的上诉。

#### 大白话讲解

用剧本C和剧本D把三个"不行"演全：

**剧本C（进门后请出去=驳回起诉）**：法院立案后开庭前才发现，来告状的"老王"其实是真债权人的**表哥**，借条上的出借人根本不是他——**没有直接利害关系**，§122第①项不满足。但案子**已经立案**了，"不予受理"这个门口动作用不上了，只能**裁定驳回起诉**（解释§208 III）。表哥不服可以**上诉**（§157(三)）；真老王本人拿着借条来起诉，符合条件，**应予受理**（解释§212）——因为"驳回起诉"只说"你这次告的方式不对"，从没碰过实体问题。

**剧本D（审完输了=驳回诉讼请求）**：这笔借款2022年就到期，老王2026年才起诉，3年时效早过了。第一问：法院收不收？——**收**（解释§219，时效不是立案门槛）。第二问：老李开庭抗辩"过时效了"，法院查明属实怎么办？——**判决**驳回老王的**诉讼请求**。注意两个字眼：是"**判决**"不是"裁定"，驳回的是"**诉讼请求**"不是"起诉"。第三问：老王拿同一张借条**再告一次**行不行？——不行，实体裁判已经作出，当事人同+标的同+请求同，**三同齐备构成重复起诉**（解释§247），裁定不予受理、已受理的裁定驳回起诉。

**一个快速自检法**：看到题目说"驳回"，先问**驳回的宾语**——宾语是"**起诉**"，程序问题，裁定，可上诉三裁定之一，再诉有活路；宾语是"**诉讼请求**"，实体问题，判决，再诉是死路（除非新事实，解释§248）。命题人把两个词互换着出，宾语一字定乾坤。

**上级法院怎么纠错也考**：一审错误裁定不予受理，二审查明后**撤销裁定+指令一审法院立案受理**；一审错误裁定驳回起诉，二审**撤销+指令一审法院审理**（解释§330）——都是"指令"，不是二审自己审。反向剧本：一二审都实体判完了，再审才发现这案子压根不符合起诉条件——**裁定撤销一、二审判决，驳回起诉**（解释§406），实体判决让位于程序出口。

#### 一句话闭环记忆

> 🎯 **一眼判**：看**阶段**——立案前不予受理、立案后驳回起诉、审完实体驳回诉讼请求；看**文书**——前两个是裁定（可上诉三裁定占其二），第三个是判决；看**再诉**——程序性驳回后补正再诉应予受理（解释§212），实体判决后再诉=重复起诉（解释§247）；看**宾语**——驳回"起诉"是程序、驳回"诉讼请求"是实体。

## 六、 易混提示

*   **不予受理 vs 驳回起诉**：
    *   都是**程序性裁定、可上诉、再诉可受理**，唯一区别是**发生在立案前还是立案后**（解释§208 III）——立案这个动作是分水岭；二审纠错也对应两种指令（指令**立案受理** vs 指令**审理**，解释§330）。
*   **驳回起诉 vs 驳回诉讼请求**：
    *   *驳回起诉*=裁定、程序出口、再诉应予受理（解释§212）；*驳回诉讼请求*=判决、实体出口、同一诉再诉构成重复起诉（解释§247）。宾语一字之差，结论天壤之别。
*   **§127(五)"告知申请再审" vs 解释§214"撤诉后再诉应予受理"**：
    *   分水岭仍是**有无实体裁判**：生效判决/裁定/调解书挡路→找再审；**准许撤诉的裁定**不挡路→再诉应予受理（离婚案6个月限制除外）。
*   **§124起诉状记明事项 vs §126不予受理 vs §127告知处理**：
    *   §124管"起诉状怎么写"，§126管"7日内立案或裁定"，§127管"七类分流"——三条各司其职，选项里把条文功能张冠李戴是常见干扰。
*   **时效届满的起诉**：
    *   **应予受理**（解释§219）→对方抗辩且成立→**判决**驳回诉讼请求；全程没有"不予受理""裁定驳回起诉"什么事。

## 七、 命题人最爱的 6 个陷阱

1.  **"法院经审理认为原告的债权已过诉讼时效，应裁定驳回起诉"** —— 错！时效是实体抗辩，应**判决驳回诉讼请求**（解释§219）；且超过时效的起诉本身**应予受理**，不是不予受理。
2.  **"立案后发现原告不适格/不符合起诉条件，应裁定不予受理"** —— 错！立案后只能**裁定驳回起诉**（解释§208 III）；"不予受理"是立案前的专属出口（§126）。
3.  **"对已生效判决又起诉的，法院应告知其另行起诉"** —— 错！应告知申请**再审**（§127(五)）；"另行起诉"是别的场景（二审新增独立诉请调解不成）的通道。
4.  **"原告撤诉后以同一诉讼请求再次起诉的，不予受理"** —— 错！撤诉后再诉**应予受理**（解释§214）；唯离婚案件无新情况新理由**6个月内**再诉，比照§127(七)不予受理——且该6个月限制只拘束**原告**，对方起诉不受限。
5.  **"当事人对保全裁定、驳回起诉裁定均可上诉"** —— 半对半错的混搭陷阱！可上诉的裁定**只有**不予受理、管辖权异议、驳回起诉三种（§157末款）；保全裁定不可上诉（救济是复议）。
6.  **"立案后发现本院没有管辖权的，应裁定驳回起诉"** —— 错！应**移送**有管辖权的法院（解释§211）；"告知向有管辖权法院起诉、坚持起诉裁定不予受理"是**立案前**的处理。
