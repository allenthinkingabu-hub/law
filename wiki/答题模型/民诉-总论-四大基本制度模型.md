# 📐 民诉四大基本制度 · 完整答题模型（合议/独任 + 回避 + 公开审判 + 两审终审及一审终审清单）

> **核心一句**：民诉法§10把**合议、回避、公开审判、两审终审**并列为四大基本制度，答题主线是**「谁来审（合议还是独任）→ 谁得走（该回避的回避）→ 开不开门（公开还是不公开）→ 审几次（两审终审还是一审终审）」**。最毒陷阱是**把2021修法后"普通程序可独任、二审经双方同意可独任"当成不存在**、**把审判长的回避决定主体说成审判委员会**、**把"依申请不公开"的离婚/商业秘密混进"依法不公开"**、**一审终审清单丢项（小额/特别程序/督促/公示催告丢一个就丢分）**、以及**忘了"宣判一律公开、复议期间不停止工作、再审必须合议"三个绝对项**。
>
> 🔎 **《民事诉讼法》（2023年修正）核心条文速查**：
> - **第10条【四大基本制度】**：人民法院审理民事案件，依照法律规定实行**合议、回避、公开审判和两审终审**制度。
> - **第40条【一审审判组织】**：一审由审判员、人民陪审员共同组成合议庭**或者**由审判员组成合议庭，成员人数**必须是单数**；**适用简易程序的案件由审判员一人独任审理**；**基层法院**审理的**基本事实清楚、权利义务关系明确**的一审案件，**可以由审判员一人适用普通程序独任审理**。
> - **第41条【二审/发回/再审的审判组织】**：二审由**审判员**组成合议庭（人数单数）；**中院**对**一审适用简易程序审结**或**不服裁定提起上诉**的二审案件，事实清楚、权利义务关系明确，**经双方当事人同意**，可以独任审理；**发回重审**按一审程序**另行组成合议庭**；**再审**原来是一审的按一审程序、原来是二审或提审的按二审程序，均**另行组成合议庭**。
> - **第42条【不得独任的六类案件】**：涉国家利益、社会公共利益／群体性纠纷可能影响社会稳定／人民群众广泛关注或社会影响较大／新类型或疑难复杂／法律规定应当合议／其他不宜独任。
> - **第43条【转合议与当事人异议】**：审理中发现不宜独任的，**应当裁定**转合议庭；当事人认为独任违法可提异议，成立的裁定转合议庭，不成立的裁定驳回。
> - **第47条【回避事由与适用人员】**：审判人员是本案当事人或当事人、诉讼代理人**近亲属**／与本案有**利害关系**／有**其他关系可能影响公正审理**的，应自行回避，当事人有权申请回避；接受请客送礼、违规会见的，当事人有权要求回避；前三款**适用于法官助理、书记员、司法技术人员、翻译人员、鉴定人、勘验人**。
> - **第48条【申请时间与暂停工作】**：开始审理时提出，事由后知的可在**法庭辩论终结前**提出；决定作出前被申请人**应当暂停参与本案工作**，但需采取**紧急措施**的除外。
> - **第49条【决定主体】**：**院长担任审判长或独任审判员**时的回避由**审判委员会**决定；**审判人员**的回避由**院长**决定；**其他人员**的回避由**审判长或独任审判员**决定。
> - **第50条【三日决定与复议】**：申请提出的**三日内**以口头或书面形式作出决定；不服的可在接到决定时**申请复议一次**；**复议期间被申请回避的人员不停止参与本案工作**；复议申请三日内作出复议决定并通知。
> - **第137条【公开审判】**：除涉及**国家秘密、个人隐私**或法律另有规定外应当公开进行；**离婚案件、涉及商业秘密的案件，当事人申请**不公开审理的，**可以**不公开。
> - **第151条【宣判一律公开】**：对公开审理或者不公开审理的案件，**一律公开宣告判决**。
> - **第165/166条【小额诉讼一审终审】**：基层法院审理简单金钱给付案件、标的额为省级上年度就业人员年平均工资**50%以下**的，适用小额程序，**实行一审终审**；50%以上2倍以下可**约定**适用；§166排除六类（人身关系财产确权／涉外／需评估鉴定或对诉前评估鉴定结果有异议／一方下落不明／提出反诉／其他不宜）。
> - **第185条【特别程序一审终审+审判组织】**：特别程序案件**实行一审终审**；**选民资格案件或重大、疑难案件**由审判员组成**合议庭**，其他案件**独任**审理。
> - **《民诉法解释》（法释〔2022〕11号修正）**：§43/§44细化应当自行回避与可申请回避的具体情形；§45**同一案件不同程序不得再参与**（发回重审后再上诉的原二审人员除外）；§46无人申请时由院长或审判委员会**决定其回避**；§48"审判人员"包括院长、副院长、审判委员会委员、庭长、副庭长、审判员和人民陪审员；§49书记员和执行员参照适用；§323应回避未回避=严重违反法定程序；§452公示催告一般独任、**宣告票据无效判决应当合议**。

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已逐条 grep 本地官方全文（民诉法2023全文-ssf.txt，来源 ssf.gov.cn 官方PDF；民诉解释2022全文-ssf.txt，法释〔2022〕11号修正版）核对，非凭记忆书写。特别核验点：①"普通程序独任"与"简易程序独任"同在**§40第2款**（不是两个条文）；②二审独任的条件原文是"**中级人民法院**对第一审适用简易程序审结**或者不服裁定提起上诉**的第二审民事案件"——含"不服裁定上诉"这一支，多数讲义漏写；③回避决定主体在**§49**、复议在**§50**（旧法条号为44/47系，2021修法后整体后移，勿用旧条号）；④应回避未回避的再审事由是2023版**§211第(七)项**（旧版207条，条号已后移）；⑤一审终审的"确认调解协议、实现担保物权"不是独立法条，而是**§184列举+§185统一规定**一审终审。官方链接：[民诉法2023全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)、[国家法律法规数据库](https://flk.npc.gov.cn/)。

> ⚠️ **易记错点**：①**"简易程序一审终审"是假命题**——简易程序照样两审终审、可上诉，一审终审的是**小额诉讼**；②**二审独任要"经双方当事人同意"**，一方异议就必须合议，法院无权直接指定独任；③**再审一律另行组成合议庭**，是独任制扩张后仅存的"必合议"绝对区（发回重审同样须另行合议）；④回避决定主体三分：**院长自己当审判长/独任审判员→审判委员会**，普通审判人员→院长，书记员翻译等其他人员→审判长/独任审判员——"审判长的回避由审委会决定"是高频错句；⑤**决定前暂停工作、复议期间不停止工作**——两个阶段方向相反，命题人爱对调；⑥**证人不适用回避**（不可替代，利害关系只影响证明力），鉴定人、勘验人、书记员、翻译人员、法官助理、司法技术人员都适用；⑦公开审判两轨：**依法不公开=国家秘密+个人隐私**（法定、不用申请），**依申请可不公开=离婚+商业秘密**（要申请、法院"可以"），且**宣判一律公开**、判决书不因不公开审理而保密宣告；⑧小额诉讼"50%以下**强制**适用、50%~2倍**合意**适用"，两档别混。

## 二、 四步判别模型（谁来审 → 谁得走 → 开不开门 → 审几次）

```
                    【一个民事案件进入法院】
                              │
     ▼ 第一步：谁来审？——合议还是独任（§40-§45）
     │
     ├─ 一审合议庭：审判员+陪审员 或 全审判员，人数必须单数（§40 I）
     ├─ 简易程序 → 一律独任（§40 II 前句）
     ├─ 基层法院+基本事实清楚+权利义务关系明确 → 可普通程序独任（§40 II 后句）
     ├─ 二审：原则合议（全审判员）；例外=中院+一审简易审结或不服裁定上诉
     │        +事实清楚权利义务明确+经双方当事人同意 → 可独任（§41 I/II）
     ├─ 发回重审/再审 → 一律另行组成合议庭，再审无独任（§41 III/IV）
     ├─ 不得独任六情形（§42）：国益公益/群体稳定/广泛关注/新类型疑难/法定合议/其他
     └─ 不宜独任→应当裁定转合议；当事人异议→成立转合议，不成立裁定驳回（§43）
                              │
     ▼ 第二步：谁得走？——回避（§47-§50 + 解释§43-§49）
     │
     ├─ 对象：审判人员（含院长副院长审委会委员庭长副庭长审判员陪审员，解释§48）
     │        +法官助理/书记员/司法技术人员/翻译/鉴定人/勘验人（§47 IV）——证人✗
     ├─ 事由：近亲属/利害关系/其他关系影响公正（自行+申请）；请客送礼违规会见（要求回避）
     ├─ 时间：开始审理时；事由后知→法庭辩论终结前（§48 I）
     ├─ 决定主体：院长任审判长或独任审判员→审判委员会；审判人员→院长；
     │            其他人员→审判长或独任审判员（§49）
     ├─ 程序：3日内决定；不服→复议一次；决定前暂停工作（紧急措施除外），
     │        复议期间不停止工作（§48 II、§50）
     └─ 应回避未回避：二审→撤销原判发回重审（§177①(四)+解释§323(二)）；
                       生效后→再审事由（§211(七)）
                              │
     ▼ 第三步：开不开门？——公开审判（§137、§139、§151）
     │
     ├─ 依法不公开（不用申请）：国家秘密/个人隐私/法律另有规定（§137 I）
     ├─ 依申请可不公开：离婚案件/涉商业秘密案件+当事人申请→法院"可以"（§137 II）
     ├─ 公开审理的：公告当事人姓名、案由和开庭时间地点（§139 II）
     └─ 宣判一律公开：无论审理是否公开（§151）
                              │
     ▼ 第四步：审几次？——两审终审+一审终审清单（§10 + 各程序条文）
     │
     ├─ 原则：两审终审（§10），简易程序同样可上诉（§171）
     └─ 一审终审例外清单（缺一不可）：
        ├─ 小额诉讼（§165：≤年平均工资50%强制，50%~2倍可合意；§166六类排除）
        ├─ 特别程序（§185：选民资格/宣告失踪死亡/指定遗产管理人/认定行为能力/
        │            认定财产无主/确认调解协议/实现担保物权——§184列举）
        ├─ 督促程序（支付令不可上诉；异议成立→裁定终结、支付令失效§228）
        ├─ 公示催告程序（除权判决不可上诉；正当理由未申报→1年内可另行起诉§234）
        └─ 最高人民法院审理的一审案件（§21：没有更高审级，一审即终审）
```

> **一句话总诀**：**「谁来审——简易必独任、基层普通可独任、二审双方同意可独任、再审发回必合议；谁得走——亲近利害要回避、证人除外，院长找审委、法官找院长、其他找审判长，决定前停、复议中不停；开不开门——秘密隐私法定关门、离婚商秘申请关门、宣判永远开门；审几次——原则两审，小额特别督促公示加最高法一审，五路一审终审」**

## 三、 高频干扰表（独任版图 / 回避主体 / 不公开两轨 / 一审终审）

命题人最喜欢在"新旧法交界"和"清单边界"上挖坑：

| 干扰类型                     | 命题人常见说辞（陷阱）                         | 法律真实（依据与法理）                                                                                                                 |
| ------------------------ | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **普通程序必须合议**             | 适用普通程序审理的一审民事案件，必须组成合议庭。            | **❌ 2021修法后错误！**基层法院审理的基本事实清楚、权利义务关系明确的一审案件，**可以由审判员一人适用普通程序独任审理**（§40 II 后句）。"普通程序=必合议"是旧法记忆。                              |
| **二审绝对不能独任 / 法院可直接指定独任** | 二审一律合议；或：二审法院认为事实清楚即可指定独任。          | **❌ 均错误！**中院对一审简易审结或不服裁定上诉的二审案件，事实清楚+权利义务明确+**经双方当事人同意**才可独任（§41 II）；一方异议即须合议——"双方同意"是硬门槛，法院不能单方指定。                         |
| **审判长回避由审委会决定**          | 当事人申请审判长回避的，由审判委员会作出决定。             | **❌ 错误！**只有**院长自己担任审判长或独任审判员**时才由审判委员会决定；普通审判长属"审判人员"，其回避由**院长**决定（§49）。                                                    |
| **复议期间也停止工作**            | 申请人对驳回回避申请的决定申请复议的，复议期间被申请人应停止参与本案。 | **❌ 方向反了！**是**决定作出前**暂停参与本案工作（紧急措施除外，§48 II）；**复议期间不停止**参与本案工作（§50）。                                                        |
| **离婚案件依法不公开**            | 离婚案件涉及个人隐私，人民法院应当不公开审理。             | **❌ 错误！**离婚案件、涉商业秘密案件是**依申请可以不公开**（§137 II），当事人不申请照样公开；**依法（当然）不公开**的只有国家秘密、个人隐私和法律另有规定（§137 I）。且无论是否公开审理，**宣判一律公开**（§151）。 |
| **简易程序一审终审**             | 适用简易程序审理的案件实行一审终审，不得上诉。             | **❌ 错误！**简易程序照常两审终审、可上诉（§171）；一审终审的是**小额诉讼**（§165）以及特别程序、督促程序、公示催告程序、最高法一审案件。                                               |

## 五、 万能四步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序合法性分析），按照以下四步进行涵摄：

*   🚗 **统一案例**：甲公司诉乙公司支付货款**8万元**，某县法院（基层）适用**简易程序**，由**王法官一人独任**审理。开庭前甲公司发现王法官是乙公司法定代表人的**近亲属**；本案证据涉及乙公司**商业秘密**，乙公司申请不公开审理。一审判决甲公司败诉，甲公司**上诉**，市中院拟由**吴法官独任**审理二审，甲公司当庭表示异议。（变体：若甲只索要**1万元**——低于该省上年度就业人员年平均工资的50%——则适用小额诉讼程序。）

### 第一步：判"谁来审"——本案能不能独任？

> **简易必独、普通可独，二审同意独，再审发回必合议**

#### 概述

2021年修法把独任制的地盘扩大了，现在的"独任版图"必须整块记：

- **简易程序**：一律独任（§40 II 前句），没有合议选项；
- **基层普通程序**：基本事实清楚+权利义务关系明确的，**可以**独任（§40 II 后句）——这是修法后最大的新增点；

- **二审**：原则全审判员合议；**中院**对一审简易审结或不服裁定上诉的案件，事实清楚+权利义务明确+**经双方当事人同意**，可独任（§41 II）；

- **再审、发回重审**：一律**另行组成合议庭**（§41 III/IV），独任制扩张没有扩到这里；
	- 再审:
		- 再审是生效裁判纠错监督程序，**一律合议庭、禁止独任**；离婚身份案禁再审；原一审再审可上诉、原二审 / 提审再审终审。[[300-民诉-再审法条依据]]
	- 提审
		- **提审一律二审程序、一律合议庭、裁判终审不上诉**。[[300-民诉-提审]]

- **六类案件绝对不得独任**（§42）：国益公益/群体稳定/广泛关注/新类型疑难/法定合议/其他不宜；

- **纠错通道**（§43）：法院发现不宜独任→应当裁定转合议；当事人异议→成立转合议、不成立裁定驳回。

- 当事人一方人数众多的共同诉讼，可以由当事人推选代表人进行诉讼。**代表人的诉讼行为对其所代表的当事人发生效力**，但代表人变更、放弃诉讼请求或者承认对方当事人的诉讼请求，进行和解，必须经被代表的当事人同意。

合议庭本身的规则：人数**必须单数**；一审可有陪审员、二审只能全审判员；审判长由院长或庭长**指定**（自己参审自己当，§44）；评议**少数服从多数**、不同意见如实记入笔录（§45）。


##### 基础知识
###### 什么是  基本事实清楚 , 权利义务明确

**事实清楚 = 不用法院查证据；权利明确 = 不用纠结谁担责**

- 基本事实清楚: 双方对**关键案情说法基本一致**、证据齐全，**法院不用主动调查取证**，就能查清整件事的来龙去脉。

- 权利明确: 不用复杂法律推导，**一眼分清谁该拿钱、谁该担责**，法律关系单一、无争议、无叠加。

###### 普通程序,简易程序,小额诉程序准入条件
- 
	[[300-民诉- 简易程序、小额诉讼 法定准入要件（2026法考完整版）]]

| 对比维度             | 一审普通程序（可例外独任）                                    | 一审简易程序（强制独任）                       | 一审小额诉讼程序（终极独任）                          |
| ---------------- | ------------------------------------------------ | ---------------------------------- | --------------------------------------- |
| **审判组织规则（核心考点）** | **原则合议，例外独任**同时满足四要件才可独任：基层一审+普通程序+事清责明+无42条禁止案件 | **一律强制独任**无合议选项，只要适用简易程序，必须审判员一人审理 | **一律强制独任**法定最简程序，全程独任，无合议可能             |
| **适用法院/审级**      | 仅限基层法院一审；中院及以上、二审、再审、重审一律合议                      | 仅限基层法院/派出法庭一审；二审、再审绝对不适用           | 仅限基层法院一审，门槛最严格                          |
| **准入核心条件**       | 不满足简易/小额条件，走普通程序；案情简单可破例独任                       | 基层一审+事实清楚、权利义务明确、争议不大              | 简易全部条件+**纯金钱给付**+标的额达标+无复杂程序需求          |
| **终审效力**         | 两审终审，不服可上诉                                       | 两审终审，不服可上诉                         | **一审终审，绝对不得上诉**（核心区分点）                  |
| **程序属性**         | 完整正式程序，独任只是审判组织简化，**程序仍是普通程序**                   | 简化一审程序，独立程序类型                      | 简易程序的**特殊子集**，不属于独立大类程序                 |
| **程序转换规则**       | 普通可在开庭前，双方同意转简易；开庭后禁止转换                          | 审理中案情复杂，法院可依职权转普通，无需当事人同意          | 出现超标、反诉、鉴定、争议变大，**必须转出**，转为简易/普通，恢复两审终审 |
| **禁止适用情形**       | 触碰42条六类案件，一律禁止独任，必须合议                            | 被告下落不明、重审再审、人数众多诉讼等                | 含所有简易禁止情形+非金钱诉求+需专业鉴定评估                 |

##### 小额案例
假如甲公司只索要**1万元**货款，而该省上年度就业人员年平均工资是10万元——1万<10万×50%=5万，属于"简单金钱给付+标的额在50%以下"，县法院**必须**适用**小额诉讼程序**，判完**一审终审**，甲公司**不能上诉**。如果标的是**8万元**（在5万~20万这个"50%~2倍"档），则**只有甲乙双方约定**才能走小额程序；不约定就走普通的简易/普通程序、照常两审。

#### 大白话讲解

县法院立案庭一看甲乙这场8万元货款官司：事实简单、证据就几张对账单——走**简易程序**。简易程序连"要不要合议"都不用讨论，**法律直接规定一个审判员独任审**，所以王法官一个人开庭，完全合法。

假如案情稍复杂、法院决定用**普通程序**呢？旧法时代答案是"普通程序必须三人合议"；但2021年修法后，**县法院（基层）**只要案件"基本事实清楚、权利义务关系明确"，照样**可以让王法官一个人用普通程序独任审**——这是命题人最爱考的新旧分水岭。

再往后看二审：甲公司上诉到市中院，中院想让吴法官独任。核对§41 II 的四个门槛：

| 二审独任门槛                     | 本案对应        | 是否满足  |
| -------------------------- | ----------- | ----- |
| 审级：中级人民法院                  | 市中院         | ✅     |
| 案件来源：一审**简易程序审结**（或不服裁定上诉） | 一审正是简易程序    | ✅     |
| 事实清楚、权利义务关系明确              | 货款纠纷，账目清楚   | ✅     |
| **经双方当事人同意**               | 甲公司**当庭异议** | ❌ 不满足 |

四个门槛缺了最后一个，**吴法官不能独任，中院应当转为审判员合议庭审理**——这正是题卡209的考法。注意：这里当事人的"同意权"是实打实的一票否决，法院不能以"事实清楚"为由硬指定独任。

最后补一刀：如果本案将来**发回重审**或者进入**再审**，无论原来是独任还是合议，都必须**另行组成合议庭**——"另行"意味着原班人马不能原样接着审（与回避制度的解释§45呼应），"合议庭"意味着再审绝无独任。

#### 一句话闭环记忆

> 🎯 **一眼判**：独任版图四句话——**简易必独任、基层普通可独任、中院二审"简易上诉+事实清楚+双方同意"可独任、再审发回必另行合议**；见"普通程序必须合议""二审法院直接指定独任""再审独任"三句话，一律判错。

### 第二步：判"谁得走"——王法官该不该回避？谁说了算？

> **亲近利害走人，院长审委分层，决定前停复议不停**

#### 概述

回避制度回答三个小问题：**谁要走、为什么走、谁批准走**。

- **谁适用**：审判人员（解释§48明确含院长、副院长、审委会委员、庭长、副庭长、审判员、陪审员）+ 法官助理、书记员、司法技术人员、翻译人员、鉴定人、勘验人（§47 IV）；解释§49再加书记员、执行员参照。**唯独证人不适用**——证人亲历案件、不可替代，有利害关系只影响证言的证明力；

- **为什么走**（§47 I/II）：
	- ①是本案当事人或当事人、诉讼代理人的**近亲属**；
	- ②与本案有**利害关系**；
	- ③有**其他关系可能影响公正审理**—— 这三项"**应当自行回避+当事人有权申请**"；
	- ④接受请客送礼、违规会见的，当事人有权**要求**回避（解释§44细化为宴请、收财物、借款物、介绍代理等六情形）；

- **什么时候提**（§48 I）：案件开始审理时；事由后知的，**法庭辩论终结前**都能提；

- **谁批准**（§49）：**院长任审判长/独任审判员→审判委员会**；**审判人员→院长**；**其他人员→审判长/独任审判员**；-> **院长审自己找审委会，法官找院长，其他人找审判长**

- **程序节奏**（§48 II、§50）：申请后**3日内**决定；**决定前**被申请人**暂停**参与本案（需采取紧急措施的除外）；不服决定可**复议一次**，**复议期间不停止**参与本案工作，复议3日内出结果。

#### 大白话讲解

甲公司经理开庭前打听到：独任审理的**王法官是乙公司老板的表弟**（近亲属）——这正踩中§47第(一)项"是本案当事人近亲属"的红线，王法官本该**自行回避**；他不主动走，甲公司**口头或书面申请**他回避都行。

接下来最容易考的三连问：

**第一问：谁来决定王法官走不走？**王法官是**独任审判员**，但他不是院长——所以按§49，他属于"审判人员"，回避**由院长决定**。只有当**院长自己**坐上审判长或独任审判员的位置时，才轮到**审判委员会**决定（自己不能批自己）。如果甲公司申请的是书记员回避，那就由审判长/独任审判员决定。口诀：**院长审自己找审委会，法官找院长，其他人找审判长**（题卡293的A项陷阱）。

**第二问：等决定的这几天，王法官还办不办案？**§48 II说得很清楚：**决定作出前，暂停参与本案**——但如果案件急需采取保全等**紧急措施**，可以先办了再说。假设院长3日内驳回了申请，甲公司不服**申请复议**（只能复议一次），**复议期间王法官照常工作、不停止**——"决定前停、复议中不停"，两个阶段方向相反，选项对调一下就是坑。

**第三问：如果王法官该回避没回避、案子照判了怎么办？**两条救济路都通：
- ①甲公司上诉后，二审法院查明此节，属于"严重违反法定程序"，**裁定撤销原判、发回重审**（§177①(四)+解释§323(二)）；

- ②如果判决已生效，"依法应当回避的审判人员没有回避"是**法定再审事由**（§211(七)），甲公司可申请再审。一个瑕疵，两头都能翻案。

顺带把**证人**钉死：乙公司的会计目睹了交货过程，虽然他是乙公司的人、明显偏向乙，甲公司也**不能申请他"回避"**——证人不可替代，"凡是知道案件情况的单位和个人都有义务作证"，利害关系只让法官在**采信时打折扣**，不能把人换掉（题卡341）。

#### 一句话闭环记忆

> 🎯 **一眼判**：回避对象="能换的人"（审判人员+助书技翻鉴勘），**证人不能换故不回避**；决定主体**院长审自己找审委会、法官找院长、其他人找审判长**；节奏**3日决定、决定前暂停（紧急措施除外）、复议一次、复议期间不停止**；应回避未回避=**二审发回+再审事由**双保险。

### 第三步：判"开不开门"——涉商业秘密要不要公开审？

> **秘密隐私法定关门，离婚商秘申请关门，宣判永远开门**

#### 概述

公开审判是原则，不公开是两条完全不同的轨道：

- **依法不公开（当然不公开）**：涉及**国家秘密**、**个人隐私**或者法律另有规定的——不需要任何人申请，法院**必须**关门审（§137 I）；

- **依申请可不公开**：**离婚案件**、涉及**商业秘密**的案件——必须有**当事人申请**，且法院是"**可以**"不公开，有裁量权（§137 II）；

- **公开的配套**：公开审理的案件应当**公告**当事人姓名、案由和开庭时间地点（§139 II）；

- **底线**：无论审理阶段开不开门，**宣告判决一律公开**（§151）——"不公开审理"绝不等于"秘密判决"。

#### 大白话讲解

乙公司律师提出：本案对账单里夹着乙公司的**客户名单和定价体系（商业秘密）**，请求不公开审理。法院怎么处理？

先分轨：商业秘密**不在"依法不公开"清单里**（那个清单只有国家秘密、个人隐私、法律另有规定）——所以本案**不是自动关门**，而是走第二条轨道：**乙公司提出了申请**+案件确涉商业秘密→法院**可以**决定不公开审理。注意两个字眼：一要"**申请**"（没人申请就照常公开），二是"**可以**"（法院还能斟酌，不是申请了就必须关门）。

对照着记：如果本案换成**离婚案件**，同样要**当事人申请**才可以不公开——命题人最爱写"离婚案件应当不公开审理"，把"依申请可以"偷换成"依法应当"，一眼判错。反过来，如果案卷里出现的是**国家秘密**或者**个人隐私**（比如涉及未成年人性侵隐私的民事赔偿），那就**不用任何人申请，法院必须不公开**。

最后无论哪种情形，审完了**宣判那一刻必须开门**：法院对本案即使全程不公开审理，判决书照样**公开宣告**（§151"一律公开宣告判决"）——"审理可以关门，宣判永远开门"，这是绝对项，没有例外。

| 情形 | 轨道 | 要不要申请 | 法院态度 |
|---|---|---|---|
| 国家秘密 / 个人隐私 / 法律另有规定 | 依法不公开 | 不需要 | **应当**不公开 |
| 离婚案件 / 涉商业秘密案件 | 依申请不公开 | **必须**当事人申请 | **可以**不公开（裁量） |
| 宣告判决 | —— | —— | **一律公开**，无例外 |

#### 一句话闭环记忆

> 🎯 **一眼判**：**"秘密隐私法定关门（应当），离婚商秘申请关门（可以）"**——见"离婚/商业秘密案件应当不公开"或"不用申请即不公开"就是把两条轨道搅在一起，错；**宣判一律公开**，见"不公开宣判"必错。

### 第四步：判"审几次"——这个裁判还能不能上诉？

> **原则两审终审，小额特别督促公示，加最高法一审，五路一审终审**

#### 概述

§10确立**两审终审**：

地方法院一审判决、裁定，当事人不服可上诉一次，二审即终审。**简易程序也在两审终审之内**（§171可上诉）。真正的**一审终审例外是一张封闭清单**，法考按"丢一个就丢分"的标准考：

1. **小额诉讼**（§165）：基层法院审理**简单金钱给付**案件，标的额≤省级上年度就业人员年平均工资**50%**→**强制**适用、一审终审；**50%~2倍**→双方**约定**才适用；§166排除六类：人身关系财产确权／涉外／需评估鉴定或对诉前评估鉴定结果有异议／一方下落不明／提出反诉／其他不宜。救济不是上诉，而是对程序适用提**异议**（§169）或对生效裁判申请再审；

2. **特别程序**（§185）：选民资格、宣告失踪/宣告死亡、指定遗产管理人、认定行为能力、认定财产无主、**确认调解协议**、**实现担保物权**（§184列举）——全部一审终审；审判组织上**选民资格案件或重大疑难案件合议、其余独任**（与第一步呼应）；[[300-民诉-民诉法§184七类特别程序逐项释义+实务案例]]

3. **督促程序**：支付令不是判决，**不能上诉**；债务人的武器是15日内**书面异议**，异议成立→裁定终结督促程序、支付令自行失效（§228）；[[300-民诉-民诉法｜督促程序（支付令）完整释义+考点+案例（§228）]]
	- 支付令：无上诉 ；靠15日书面异议救济 
	- 异议成立：程序终结、文书失效、转诉讼 
	- 异议不成立/无异议：支付令生效、可强制执行 
	- 口头异议、超期异议：一律无效

4. **公示催告程序**：除权判决**不能上诉**；利害关系人有正当理由未及时申报的，自知道或应当知道判决公告之日起**1年内**可**另行起诉**（§234）；一般独任，但**宣告票据无效的判决应当合议**（解释§452）；
	1. 票据行使权利一般需要出示原件。票据遗失后，失票人无法凭原件收款，还面临被他人冒领风险。公示催告是法定救济程序：法院通知付款人止付、发布公告催告利害关系人申报；期满无人申报可申请除权判决宣告票据无效，失票人凭除权判决向付款人主张票款。
	2. 案例完整串讲（对应你之前的例子）甲持有银行承兑汇票不慎遗失。
		1. 若不申请公示催告：捡到票据的第三人到期去银行兑付，资金被拿走；甲无票据原件，银行拒绝付款，维权难度极大。
		2. 甲向票据支付地基层法院申请公示催告：
		    ① 法院受理→立刻通知承兑银行**停止支付**；
		    ② 发布不少于 60 日公告，寻找其他持票人；
		    ③ 公告期间无人申报权利，甲申请法院作出**除权判决（合议庭审理）**；
		    ④ 判决公告生效，该汇票法律上作废；甲持判决书，直接要求银行支付票面金额。

5. **最高人民法院的一审案件**（§21）：头顶没有更高审级，一审即终审。

#### 大白话讲解

回到主案：甲公司索要**8万元**、简易程序审结——简易程序**照样能上诉**，所以甲公司上诉到市中院完全没问题，"简易程序一审终审"是命题人造出来的假话（题卡209的B项）。

现在切到变体：假如甲公司只索要**1万元**货款，而该省上年度就业人员年平均工资是10万元——1万<10万×50%=5万，属于"简单金钱给付+标的额在50%以下"，县法院**必须**适用**小额诉讼程序**，判完**一审终审**，甲公司**不能上诉**。如果标的是**8万元**（在5万~20万这个"50%~2倍"档），则**只有甲乙双方约定**才能走小额程序；不约定就走普通的简易/普通程序、照常两审。再检查一遍排除清单：假如乙公司**提出反诉**、或者货款金额需要**鉴定**、或者乙公司**下落不明**——通通不能用小额程序（§166）。

再把另外几条"一审终审路"数全：

- 乙公司欠款铁证如山、没有其他债务纠纷？甲公司可以不起诉、直接申请**支付令**——支付令发出后乙公司要么15日内还钱、要么**书面异议**（异议成立支付令自行失效），但**永远谈不上"上诉"**；
- 甲公司丢了一张银行承兑汇票？申请**公示催告**，公告期满无人申报→法院判决**宣告票据无效**（除权判决）——这个判决**不能上诉**，真正的持票人只能凭正当理由在判决公告之日起**1年内另行起诉**；注意这个宣告票据无效的判决要**合议庭**作出（解释§452，又和第一步勾连）；
- 乙公司老板**下落不明满2年**？宣告失踪走**特别程序**，一审终审；双方在人民调解委员会达成调解协议后申请**司法确认**？也是特别程序，一审终审；
- 极端情形：案件由**最高人民法院**一审审理——判完就是终局，没有"上诉到联合国"一说。

数清单的方法：**"小额、特别、督促、公示、最高法一审"五个指头**，考试给你一串裁判问"哪些可以上诉"，先把五个指头过一遍，剩下的（普通程序判决、简易程序判决、可上诉裁定如不予受理/管辖权异议/驳回起诉）都在两审终审之内。

#### 一句话闭环记忆

> 🎯 **一眼判**：一审终审五指诀——**小额（≤50%强制、50%~2倍合意）、特别程序（含确认调解协议+实现担保物权）、督促（支付令只能异议）、公示催告（除权判决只能1年内另诉）、最高法一审**；**简易程序不在其中、照常可上诉**——清单丢一项、混进"简易"一项，都是丢分点。

## 六、 易混提示

*   **简易程序 vs 小额诉讼**：
    *   *简易程序*是普通程序的简化，**两审终审、可上诉**；*小额诉讼*才**一审终审**（且限基层法院简单金钱给付、有标的额门槛与§166排除清单）。二者都独任，但审几次完全不同。
*   **"依法不公开" vs "依申请不公开"**：
    *   *国家秘密、个人隐私*→依法**应当**不公开，无须申请；*离婚、商业秘密*→**当事人申请**+法院**可以**不公开。方向词（应当/可以）与触发词（无须申请/须申请）成对出现，拆开混搭即是错项。
*   **"决定前暂停工作" vs "复议期间不停止工作"**：
    *   回避申请提出后、决定作出**前**→**暂停**（紧急措施除外）；决定驳回后申请复议、复议**期间**→**不停止**。前停后不停，别对调。
*   **二审独任的"双方同意" vs 小额诉讼的"约定适用"**：
    *   都是当事人合意介入程序，但一个管**审判组织**（§41 II），一个管**审级/程序**（§165 II 的50%~2倍档），命题人爱互相嫁接（如"经双方同意二审可一审终审"——不存在）。
*   **审判组织不合法 vs 应回避未回避**：
    *   同属§211第(七)项再审事由、同属解释§323的"严重违反法定程序"，后果相同（二审发回+可再审），但事实形态不同——前者如"该合议未合议/人数偶数"，后者是人的问题。

## 七、 命题人最爱的 6 个陷阱

1.  **"普通程序审理的一审案件必须组成合议庭"** —— 错！2021修法后，基层法院基本事实清楚、权利义务关系明确的一审案件可**普通程序独任**（§40 II 后句）。
2.  **"二审一律合议 / 二审法院可径行指定独任"** —— 均错！中院对一审简易审结或不服裁定上诉的二审案件，事实清楚+权利义务明确+**经双方当事人同意**可独任；一方异议即转合议（§41 II），法院无权硬指定。
3.  **"合议庭审判长的回避由审判委员会决定"** —— 错！审委会只管**院长自己担任审判长或独任审判员**时的回避；普通审判长/审判员由**院长**决定，书记员等其他人员由**审判长或独任审判员**决定（§49）。
4.  **"复议期间被申请回避的人员应停止参与本案"** —— 错！**决定前**暂停（紧急措施除外，§48 II），**复议期间不停止**（§50），两阶段方向相反。
5.  **"离婚/商业秘密案件应当不公开审理""不公开审理的案件不公开宣判"** —— 均错！离婚、商业秘密是**依申请+可以**不公开（§137 II）；且无论是否公开审理，**一律公开宣告判决**（§151）。
6.  **"简易程序一审终审"或一审终审清单丢项** —— 错！简易程序可上诉（§171）；一审终审封闭清单=**小额诉讼+特别程序（含确认调解协议、实现担保物权）+督促程序+公示催告程序+最高法一审**，丢一个就丢分（§165、§185、§228、§234、§21）。
