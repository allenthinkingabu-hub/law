# 📐 证人/鉴定人出庭制度 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。这一节把"**谁该上法庭、谁能被强制、谁能不来、谁根本没资格作证**"一次讲透。命题人在这儿埋了三颗雷，几乎年年踩：
> ① **"有异议就必须让证人出庭"**——错，证人应当出庭要**三个条件同时满足**（有异议＋对定罪量刑有重大影响＋法院认为有必要），缺一不可；
> ② **"近亲属都能拒绝强制出庭"**——错，能免于强制到庭的**只有"配偶、父母、子女"三类**，兄弟姐妹（也是近亲属）照样能被强制；而且**"免于强制到庭"不等于"免除作证义务"**；
> ③ **"鉴定人不出庭跟证人一样看情况"**——错，**鉴定人经通知拒不出庭，鉴定意见直接绝对作废**（比证人狠）。
> 破解就三句话：**「证人出庭三要件缺一不可、警察目击也当证人」、「强制出庭配偶父母子女除外（≠近亲属、≠免作证）、拒证可训诫拘留」、「鉴定人拒不出庭鉴定绝对排、专家辅助人不是鉴定意见」**。
> 今天用**一张"三类主体出庭"决策树＋五大关卡**把这块制度钉死。

## 适用场景与解决问题

本模型覆盖 [[刑诉-刑事证据制度-深度报告]] 第三板块**证人/鉴定人出庭与资格保护类考点（考点10证人应当出庭三要件+警察作证+鉴定人拒不出庭、考点11强制出庭+配偶父母子女免强制、考点12专家辅助人、考点13证人资格与作证义务、考点14保护与补偿）**。凡题干出现"证人是否必须出庭""警察能否作证人""能否强制到庭""配偶/父母/子女/兄弟姐妹拒证""鉴定人不出庭""专家辅助人""谁能当证人""证人保护/作证补助"等，立即调用本模型。

- **证人应当出庭三要件（§192①）**：①公诉人、当事人或辩护人、诉讼代理人**对证言有异议**；②该证言**对定罪量刑有重大影响**；③**法院认为有必要出庭**——**三者缺一不可**（不是"有异议就必须出庭"）。
- **警察目击作证（§192②）**：人民警察就其**执行职务时目击的犯罪情况**作为证人出庭作证的，**适用证人出庭的规定**。
- **鉴定人拒不出庭（§192③）**：经法院通知，鉴定人**拒不出庭作证**的，鉴定意见**绝对不得作为定案根据**（比证人严）。
- **强制出庭与三类除外（§193①）**：证人经通知无正当理由不出庭的，法院**可以强制其到庭**，但**被告人的配偶、父母、子女除外**——注意是**这三类，不是全部近亲属**（兄弟姐妹仍可被强制）；且**免于强制到庭≠免除作证义务**。
- **拒证的处罚（§193②）**：无正当理由拒绝出庭或出庭后拒绝作证的，**予以训诫**；情节严重的，经**院长批准**，处**十日以下拘留**。
- **专家辅助人出庭（§197②）**：可申请法庭通知**有专门知识的人出庭**，就鉴定意见**提出意见**；其意见**不是鉴定意见、不属法定证据种类**，适用鉴定人的有关规定。
- **证人资格（§62）**：凡知道案情的人都有作证义务；**生理/精神有缺陷或年幼，不能辨别是非、不能正确表达的**，不能作证人（复合判断）；**单位不能作证人**。
- **保护与补偿（§64/§65）**：特殊保护（不公开身份等）限**危害国安、恐怖活动、黑社会、毒品**等重罪，对象含证人/鉴定人/被害人；证人作证**补助由司法机关业务经费列支**，用人单位**不得克扣其工资奖金福利**。

> **核心一句**：**「证人出庭三要件缺一不可、警察目击也当证人；强制出庭'配偶父母子女'除外（≠近亲属、≠免作证），拒证训诫拘留；鉴定人拒不出庭鉴定绝对排、专家辅助非鉴定；能不能作证看'辨是非＋正确表达'、单位不能作证人。」**

> 🔎 **法条已联网核实（2026-07-06 · 司法部 moj.gov.cn / 最高检 spp.gov.cn）**：刑诉法§192①（出庭三要件）、§192②（警察目击作证）、§193①（强制出庭·配偶父母子女除外）、§193②（训诫/院长批准拘留十日以下）、**§197②（有专门知识的人出庭就鉴定意见提意见——已核实确系§197第2款，上位报告"条号存疑"经本轮核验予以澄清）**、§62（证人资格）、§64/§65（保护与补偿）逐条核实无误。

> ⚠️ **易记错点（高频坑）**：①**证人应当出庭＝三要件缺一不可**，"有异议就必须出庭"是错的；②**免于强制到庭仅"配偶、父母、子女"三类**，**不是全部近亲属**（兄弟姐妹仍可强制），且**≠免除作证义务**；③**鉴定人拒不出庭→鉴定意见绝对排除**（证人拒不出庭其庭前证言不必然全废、但影响采信）；④**专家辅助人意见≠鉴定意见**、非法定证据种类；⑤**证人资格是"不能辨别是非且不能正确表达"复合判断**，未成年人能正确表达仍可作证；**单位不能作证人**；⑥**证人保护限四类重罪**，作证补助由**司法机关业务经费**列支、单位不得克扣工资。

## 一、 "三类主体出庭"决策树

```
                    【谁要出庭 / 谁能不来 / 谁没资格作证】
                              │
        ┌─────────────────────┼─────────────────────┐
     证人                   鉴定人                 有专门知识的人
        │                     │                    (专家辅助人)
  应当出庭三要件(§192①)?     经法院通知              申请法庭通知出庭(§197②)
   ①对证言有异议            拒不出庭?               就鉴定意见提意见
   ②对定罪量刑有重大影响     ┌──┴──┐               ·意见≠鉴定意见
   ③法院认为有必要          是→鉴定意见             ·非法定证据种类
   （三者缺一不可）           【绝对排除】(§192③)     ·适用鉴定人有关规定
        │                   否→可作定案根据
   ★警察目击执行职务的犯罪→按证人出庭(§192②)
        │
  经通知无正当理由不出庭 → 可【强制到庭】(§193①)
        └── 除外：被告人的【配偶、父母、子女】三类
              (≠全部近亲属；兄弟姐妹仍可强制；免强制≠免作证)
        │
  无正当理由拒绝出庭/出庭拒证 → 训诫；情节严重经院长批准→拘留≤10日(§193②)

   ┌─── 证人资格(§62)：知道案情者有作证义务；
   │      "不能辨别是非 且 不能正确表达"才不能作证；单位不能作证人
   └─── 保护(§64)限国安/恐怖/黑社会/毒品等重罪；补偿(§65)业务经费列支·单位不得克扣工资
```

> **一句话总诀**：**「证人出庭三要件、警察目击也算；强制到庭配偶父母子女除外（≠近亲属≠免作证）；鉴定人拒不出庭鉴定绝对排、专家辅助非鉴定；辨是非＋正确表达才有资格、单位不能作证。」**

## 三、 五大判定关卡（每关：字诀 + 先懂几个词 + 数字案例 + 🎯做题眼）

> 拿到一道出庭题，先分**证人 / 鉴定人 / 专家辅助人**三类主体，再逐关判：证人看三要件与强制除外，鉴定人看拒不出庭的绝对后果，另加资格与保护两关。

### 第一关：证人应当出庭三要件 + 警察作证 —— 盯死"三缺一"

> **教练提示**：一看到"一方对证言有异议"，绝大多数同学立刻判"那证人必须出庭"。命题人专卡这条——**光有异议不够**，还得"**对定罪量刑有重大影响**"且"**法院认为有必要**"，三个条件**缺一不可**。

> 证人应当出庭＝**有异议＋对定罪量刑有重大影响＋法院认为有必要**，三缺一不可；警察目击也当证人

- **先懂几个词**：
	- **应当出庭三要件（§192①）**
		- ①公诉人、当事人或辩护人、诉讼代理人**对证言有异议**；
		- ②该证言**对定罪量刑有重大影响**；
		- ③**法院认为有必要**——**三个同时满足**，
		证人才"应当出庭"；

	- **警察目击作证（§192②）**
		- 人民警察就其**执行职务时目击的犯罪情况**作证的，**适用证人出庭规定**（警察此时是"证人"身份）；
- 
	- **不满足三要件**
		- 证人可不出庭，其**庭前书面证言**经质证等仍可能采用（形式合法的前提下）。

- **判"证人是否必须出庭"**：
	- 三要件**全齐**→应当出庭；缺任一→不必然出庭。

- **判"警察作证"**：
	- 执行职务时**目击的犯罪**→按证人出庭。

- **被害人陈述与证人证言的身份并存（竞合）**

#### 大白话讲解

##### 🔍 对号入座表：证人要不要出庭

| 情形                       | 三要件        | 结论           |
| ------------------------ | ---------- | ------------ |
| 一方有异议＋对定罪量刑有重大影响＋法院认为有必要 | 三齐         | **应当出庭**     |
| 只是有异议，但证言无关紧要            | 缺"重大影响"    | 不必然出庭        |
| 有异议且重大，但法院认为无必要          | 缺"法院认为有必要" | 不必然出庭        |
| 巡逻民警当场目击抢劫               | 警察目击执行职务犯罪 | 按证人出庭（§192②） |

##### 💰 完整数字案例：三要件缺一（单选-13 相关）

> **案情**：辩护人对某证人的证言提出异议，但该证言仅涉及一个与定罪量刑无关的枝节；法院也认为无出庭必要。
>
> - 虽有"异议"，但**缺"对定罪量刑有重大影响"**、且法院认为无必要——**三要件不齐**；
> - 故该证人**不必然出庭**，其庭前证言经审查（形式合法）仍可作定案参考。
>
> 👉 "有异议"只是三张门票中的一张，凑不齐三张就进不了"必须出庭"的门。

#### 一句话闭环记忆

> 🎯 **一眼判**：证人**应当出庭＝三要件缺一不可**；警察**执行职务目击的犯罪**按证人出庭。把"一方有异议证人就必须出庭"的——**排除**。

### 第二关：强制出庭 + 配偶父母子女除外 —— 盯死"三类≠近亲属、≠免作证"

> **教练提示**：这是全章**最经典的坑**。一看到"近亲属可以拒绝出庭"，同学就点头。命题人专卡两处——能免于**强制到庭**的**只有"配偶、父母、子女"三类**（近亲属还含兄弟姐妹，兄弟姐妹照样能被强制）；而且这三类人**只是不被强制押来，作证义务并没免**。

>  强制到庭配偶父母子女除外（≠全部近亲属·兄弟姐妹仍强制）；免强制≠免作证；拒证训诫院长批准拘留

- **先懂几个词**：
	- **强制到庭（§193①）**
		- 证人经通知**无正当理由不出庭**的，法院**可以强制其到庭**；

	- **三类除外****被告人的配偶、父母、子女**可**免于被强制到庭**——注意"近亲属"在刑诉法含**配偶、父母、子女、同胞兄弟姐妹**，而免强制的**只有前三类**，**兄弟姐妹仍可被强制到庭**；

	- **免强制≠免作证**
		- 这三类人**不被强制押来**，但**作证义务依然存在**（只是不采取强制手段）；

	- **拒证处罚（§193②）**
		- 无正当理由**拒绝出庭或出庭后拒绝作证**的，**训诫**；情节严重的，经**院长批准**，处**十日以下拘留**。

- **判"能否强制"**：- 强制出庭排除的是 “**被告的**”
	- 强制出庭规则明确排除的是被告人的配偶、父母、子女，即不得强制"被告人"的近亲属出庭。
	- 一般证人无正当理由不来→可强制；**配偶/父母/子女除外**；**兄弟姐妹可强制**。

- **判"免强制的含义"**：仅免**强制到庭**，**不免作证义务**。

- **判"拒证后果"**： -  双重后果并行 处罚+证据单独评价
	- 训诫；情节严重经**院长批准**拘留≤10日。
	- 证人没有正当理由拒绝出庭或者出庭后拒绝作证，其证言不能与其他证据相互印证，或者存在其他不能排除的疑点的，该证人证言不得作为定案的根据

- 最**高法院司法解释明确规定，被告人近亲属拒绝出庭作证的，其庭前证言如果经查证属实**，并且有其他证据印证的，**可以作为定案根据**。不能仅因为近亲属行使了出庭豁免权就直接作废其庭前合法制作的笔录。




- 谁发出:
	- 强制证人到庭是由人民法院签发强制出庭令、依法强制其到庭，强制出庭的决定权与令状均归法院，

#### 大白话讲解

##### 🔍 对号入座表：谁能免于强制到庭

| 与被告人关系 | 是否近亲属 | 能否免于强制到庭 |
| --- | --- | --- |
| 配偶 | 是 | **可免强制** |
| 父母 | 是 | **可免强制** |
| 子女 | 是 | **可免强制** |
| 同胞兄弟姐妹 | 是（近亲属） | **不能免**（仍可强制） |
| 其他亲友/无关证人 | 否 | 不能免（可强制） |

##### 💰 完整数字案例：被害人之父 vs 被告人配偶（[[刑诉-证据-多选-35 · 伤害案中被害人亲属证人出庭免受强制例外与诉讼身份冲突|多选-35]]）

> **案情**：某伤害案，①**被告人的配偶**拒绝出庭作证；②**被害人的父亲**（不是被告人的父母）也不愿出庭。
>
> - ①被告人的**配偶**属"配偶、父母、子女"三类之一，**可免于强制到庭**（但作证义务仍在）；
> - ②"被害人的父亲"**不是被告人的配偶/父母/子女**，不属除外范围，**可被强制到庭**；
> - 关键看"是不是**被告人的**配偶/父母/子女"，而非"是不是某方的亲属"。
>
> 👉 免强制的锚点是"**被告人的**配偶、父母、子女"三类，别被"某某的亲属"带偏。

#### 一句话闭环记忆

> 🎯 **一眼判**：强制到庭**仅"被告人的配偶、父母、子女"三类免除**（**≠全部近亲属**、兄弟姐妹仍可强制）；**免强制≠免作证**；拒证训诫、情节严重经**院长批准**拘留≤10日。把"近亲属都可拒绝强制出庭""免强制就免作证"的——**排除**。

### 第三关：鉴定人拒不出庭 + 专家辅助人 —— 盯死"鉴定绝对排、辅助非鉴定"

> **教练提示**：一看到"鉴定人没出庭"，同学容易和证人一样"看情况"。命题人专卡这条——**鉴定人经通知拒不出庭，鉴定意见直接绝对作废**；另外专家辅助人（有专门知识的人）出庭提的意见，**不是鉴定意见**。

> 鉴定人拒不出庭→鉴定意见绝对排（§192③）；专家辅助人出庭提意见（§197②）·非鉴定意见

- **先懂几个词**：
	- **鉴定人拒不出庭（§192③）**
		- 经**人民法院通知**，鉴定人**拒不出庭作证**的，其鉴定意见**不得作为定案根据**（绝对排除，比证人严）；
		- 法院绝对不能强制鉴定人出庭。如果鉴定人拒不到庭，后果是其鉴定意见绝对排除（《刑诉法》第 192 条第 3 款），而非强行拘传（《刑诉解释》第 99 条
		- **无法出庭的正当理由及程序处理**：
			  - **鉴定人因故无法出庭**：如果鉴定人确有正当理由无法出庭，法院的常规处理方式是**延期审理**（而非中止审理，中止审理只适用于被告人重病等导致诉讼无法继续的重大客观障碍），或者重新鉴定。另行聘请鉴定人重新鉴定是裁量决定，非一律要求。

	- **专家辅助人出庭（§197②·已核实）**
		- 公诉人、当事人和辩护人、诉讼代理人可**申请法庭通知有专门知识的人出庭**，就**鉴定意见提出意见**，其出庭**适用鉴定人的有关规定**；

		-   **有专门知识的人（专家辅助人）**：公诉人、当事人和辩护人、诉讼代理人可以申请法庭通知有专门知识的人出庭，就鉴定人作出的鉴定意见提出意见（《刑诉法》§197②）。
		
		- **发问权限**：在法庭上，经法庭许可，有专门知识的人**可以向鉴定人发问**。
		
		- 专家辅助人数: 申请有专门知识的人出庭，不得超过二人。有多种类鉴定意见的，可以相应增加人数。

	- **辅助人意见的性质**＝**不是鉴定意见、不属法定证据种类**，作用是**帮助质证**（详见 [[刑诉-证据-鉴定意见审查模型]]）。

- **判"鉴定人拒不出庭"**：经通知拒不出庭→鉴定意见**绝对排除**。

- **判"专家辅助人"**：申请通知出庭就鉴定意见提意见；其意见**≠鉴定意见**。

- 有权申请重新鉴定 - 当事人（包括被害人、被告人等）及其法定代理人、辩护人、诉讼代理人对鉴定意见有异议的，均有权申请补充鉴定或者重新鉴定。

#### 一句话闭环记忆

> 🎯 **一眼判**：**鉴定人经通知拒不出庭→鉴定意见绝对排除**；**专家辅助人出庭提意见（§197②）但意见不是鉴定意见**。把"鉴定人不出庭鉴定照用""专家辅助人意见属鉴定意见"的——**排除**。

### 第四关：证人资格与作证义务 —— 盯死"辨是非＋正确表达""单位不能作证"

> **教练提示**：一看到"未成年人/有残疾的人"，同学容易一律判"不能作证"。命题人专卡这条——**能不能作证是"不能辨别是非'且'不能正确表达'的复合判断**，未成年人只要**能正确表达**照样能作证；另外**单位不能作证人**（证人只能是自然人）。

> # 证人资格＝辨是非＋正确表达（复合）；单位不能作证人；知道案情者有作证义务

- **先懂几个词**：
	- **作证义务（§62）**
		- **凡是知道案件情况的人**，都有作证义务；

	- **不能作证的人**＝**生理上、精神上有缺陷或者年幼**，**不能辨别是非、不能正确表达**的人——注意是**"不能辨别是非"且"不能正确表达"复合成立**才排除，**不是**一律以年龄/残疾排除；

	- **未成年人**＝只要**能正确表达**，即可作证（证明力另行审查印证）；

	- **单位**＝**不能作证人**（证人只能是知道案情的**自然人**）。

- **判"能否作证"**：辨是非＋正确表达→可作证；二者皆缺→不能作证；**单位不能作证人**。

- 证人身份与法定代理人身份在庭审程序中存在冲突（旁听与隔离限制），不能兼任。

- 刑诉未成年看开庭年龄，未满 18 一律要法定代理人，16 自立不算数，民事刑事两码事

- 我国法律规定，辩护律师向证人收集证据必须**征得证人同意**（§43），证人有权拒绝，并没有“协助律师取证”的法定义务。

#### 一句话闭环记忆

> 🎯 **一眼判**：证人资格＝**不能辨别是非"且"不能正确表达**才排除（未成年人能正确表达仍可作证）；**单位不能作证人**。把"未成年人一律不能作证""单位可作证人"的——**排除**。

### 第五关：证人保护与经济补偿 —— 盯死"四类重罪保护、补偿业务经费列支"

> **教练提示**：一看到"证人保护"，同学容易以为所有案件都能不公开身份。命题人专卡这条——**特殊保护（不公开身份等）只限危害国安、恐怖活动、黑社会、毒品等重罪**；作证补助**由司法机关业务经费列支**，**单位不得因作证克扣工资**。

>  特殊保护限国安/恐怖/黑社会/毒品等重罪（含证人鉴定人被害人）；补偿业务经费列支·单位不得克扣工资

- **先懂几个词**：
	- **特殊保护（§64）**
		- 对**危害国家安全、恐怖活动、黑社会性质组织、毒品**等犯罪案件的**证人、鉴定人、被害人**，本人或近亲属人身安全面临危险的，可采取**不公开真实姓名住址工作单位、不暴露外貌声音、禁止特定人接触、专门保护**等措施；

	- **经济补偿（§65）**
		- 证人因履行作证义务支出的交通、住宿、就餐等费用，**由司法机关业务经费列支给予补助**；证人是**有工作单位**的，用人单位**不得克扣其工资、奖金及其他福利待遇**。

- **判"能否特殊保护"**：限**四类重罪**（国安/恐怖/黑社会/毒品），**对象含证人/鉴定人/被害人**。

- **判"补偿"**：**司法机关业务经费**列支；单位**不得克扣工资**。

#### 一句话闭环记忆

> 🎯 **一眼判**：特殊保护限**国安/恐怖/黑社会/毒品**等重罪（含证人、鉴定人、被害人）；作证补助**司法机关业务经费列支**、单位**不得克扣工资**。把"任何案件都能不公开证人身份""作证补助由单位承担"的——**排除**。

## 五、 主观题万能说理模板

### 模板一：证人应当出庭与强制出庭
> "依刑诉法§192，证人应当出庭作证须同时具备：公诉人、当事人或辩护人、诉讼代理人**对证言有异议**、该证言**对定罪量刑有重大影响**、**人民法院认为有必要出庭**——三要件缺一不可；人民警察就其执行职务时目击的犯罪情况作证的，适用证人出庭规定。依§193，证人经通知无正当理由不出庭的，法院**可以强制其到庭，但被告人的配偶、父母、子女除外**（该除外仅限此三类，兄弟姐妹等其他近亲属仍可强制，且免于强制到庭并不免除其作证义务）；无正当理由拒绝出庭或作证的，予以训诫，情节严重的经院长批准处十日以下拘留。"

### 模板二：鉴定人出庭、证人资格与保护
> "依刑诉法§192第3款，鉴定人经人民法院通知**拒不出庭作证**的，鉴定意见**不得作为定案根据**；依§197第2款，当事人及辩护人等可申请通知**有专门知识的人出庭**就鉴定意见提出意见，该意见不属鉴定意见。依§62，凡知道案件情况的人均有作证义务，但生理、精神有缺陷或年幼、**不能辨别是非且不能正确表达**的人不能作证，单位亦不能作证人。依§64、§65，对危害国家安全、恐怖活动、黑社会性质组织、毒品等犯罪案件的证人、鉴定人、被害人可采取特殊保护措施；证人作证补助由**司法机关业务经费列支**，用人单位不得克扣其工资、奖金及福利。"
