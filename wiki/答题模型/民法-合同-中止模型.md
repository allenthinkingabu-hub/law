# 📐 中止履行 · 答题模型（两大场景 + 中止 / 终止 / 解除辨析中枢）

> **"中止"= 暂停、可恢复，合同关系仍存续**——和"终止 / 解除"（**消灭**合同）是两回事。本模型把合同编里两处"中止履行"场景 + 最易混的**中止 vs 终止 vs 解除**一次讲清；各场景的细节回链 home 模型（**谁用谁链接**）。
> **两大场景**：① **不安抗辩中止**（§527-528·先履行方自保）→ 细节见 [[民法-合同-履行抗辩权模型]]；② **公用事业中止**（§654/§656·欠费停供）→ 细节见 [[典型合同-多选-24]] / [[供用电合同]]。
> **适用真题**：[[典型合同-多选-18|多选18·不安抗辩中止]] · [[典型合同-多选-24|多选24·公用事业中止≠解除]] · [[合同通则-单选-16|单选16·不安抗辩]]
> 🔎 **法条核实（2026-06-13，[最高检官网民法典](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml)逐字核对全部 CONFIRMED）**：§527-528（不安抗辩中止）· §654 / §656（公用事业中止供应 + 催告 + 事先通知，[§654 释义](https://m.thepaper.cn/newsDetail_forward_30389986)）· §194（时效中止·别混）· §557（终止情形）· §563（解除情形）。

## 一、核心：中止 = 暂停，不是消灭

**一句话**：中止履行 = **暂时停止**自己（或供应方）的给付，**合同关系不灭**；阻碍消除 / 条件成就后**应当恢复**履行。它既不是"终止"（合同消灭），也不是"解除"（合同消灭的一种方式）。
- **考点价值**：法考最爱用"**解除 / 终止**"偷换"**中止**"——见"解除合同 / 终止合同"先警惕，再看是不是其实只能"中止"。

## 二、两大"中止履行"场景（一表分清）

| 维度 | ① 不安抗辩中止（§527-528） | ② 公用事业中止（§654 / §656） |
|---|---|---|
| 谁中止 | 双务合同**先履行方** | 供水 / 电 / 气 / 热**供应方** |
| 触发 | 有**确切证据**证明对方有 §527 四情形（经营严重恶化 / 抽逃逃债 / 丧失商誉 / 丧失或可能丧失履行能力） | 用户**逾期不付费**，经**催告**、合理期限内仍不付 |
| 前置程序 | 中止后**及时通知**对方 | **催告** + 中止前**事先通知**（两道关卡，缺一 = 违法中止） |
| 中止之后 | 对方**提供适当担保** → 恢复；合理期限内**未恢复且未担保** → **可解除** + 违约责任 | 用户**补交费用 + 违约金** → 供应方须**及时恢复**供应 |
| 能否解除 | **能**（升级为默示预期违约，落 §563②）→ 见 [[民法-合同-解除模型]] | **不能**（强制缔约 + 公益性，只能中止不能解除 / 终止） |
| 滥用 / 漏程序 | 无确切证据就中止 = **自己违约**（§527 末句） | 缺催告 / 事先通知就停供 = **供应方违约**（§577） |

### 场景①：不安抗辩中止（先履行方自保）—— 完整流程在 [[民法-合同-履行抗辩权模型]] 第三步
> **中止 → 通知 → 对方担保则恢复 / 合理期限未恢复未担保则解除（§528）**。这是"中止"链条里**唯一能走到解除**的一条。

### 场景②：公用事业中止（欠费停供）—— 完整变形题在 [[典型合同-多选-24]]
> **水电气热**四类：欠费 → **催告 → 事先通知 → 中止供应**；补费后**及时恢复**；**绝不能解除 / 终止**（强制缔约）。
> 🪤 物业费变形：物业服务人**不得**以停水 / 停电催费，只能**催告后诉讼 / 仲裁**（§944③）——物业费连"中止"都不行，比公用事业"可中止"更严。📐 详见 [[民法-合同-物业服务合同模型]]。

## 三、辨析：中止 ≠ 终止 ≠ 解除（命门）

| | **中止** | **终止**（§557） | **解除**（§562 / §563） |
|---|---|---|---|
| 对合同 | **暂停**，关系**存续** | 权利义务**消灭**（向将来） | 合同关系**消灭**（可能溯及 + 返还） |
| 能否恢复 | ✅ 条件成就即**恢复** | ❌ | ❌ |
| 典型触发 | 不安抗辩、欠费停供 | 履行完毕 / 抵销 / 提存 / 免除 / 混同 / 债务人死亡无人继承（§557） | 约定解除 / 法定解除（§563 五情形） |

> 一句话：**中止是"按暂停键"，终止 / 解除是"按结束键"。**

## 四、别混：还有一个"时效中止"（§194），中止的不是"履行"

- **诉讼时效中止**（§194）：时效期间**最后六个月内**，因不可抗力等障碍**不能行使请求权** → **时效期间暂停计算**，障碍消除之日起满六个月时效届满。
- ⚠️ 这里中止的是"**时效期间**"，**不是"履行"**——与本模型的"中止履行"是两套制度，名同实异，别张冠李戴。

## 五、命题人最爱的陷阱

1. **用"解除 / 终止"偷换"中止"** —— 公用事业欠费只能**中止供应**，不能解除 / 终止（§654）；见"解除合同 / 终止合同"先排查（[[典型合同-多选-24|多选-24]] 的 A、B）。
2. **公用事业中止漏程序** —— 缺**催告**或**事先通知**就停供 → **供应方违法、反担违约责任**。
3. **不安抗辩无确切证据就中止** —— **自己构成违约**（§527 末句）。
4. **不安抗辩中止 = 直接解除** —— 错！先**中止 + 通知**，等"合理期限未恢复且未担保"**才能解除**（§528）。
5. **以为中止 = 合同没了** —— 错！中止是暂停，合同**存续**，条件成就要**恢复**。
6. **把"时效中止 §194"当"中止履行"** —— 中止的对象不同（时效期间 vs 履行）。
