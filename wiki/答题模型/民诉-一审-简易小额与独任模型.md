# 📐 简易·小额·独任 · 完整答题模型（繁简分流三快道：简易程序 + 小额诉讼 + 普通程序独任制）

> **核心一句**：这是 2021 年民诉修法"繁简分流"的三条快车道——**简易程序**（基层法院审简单案，一人独任、三个月审结）、**小额诉讼**（更快的一锤定音：两档标的额、**一审终审**）、**普通程序独任制**（普通程序也能一人审）。考试主线是**「什么案能进快道 → 快道里怎么简化 → 什么时候必须退回慢道（转换与异议救济）」**；最毒陷阱是**把"一审终审不能上诉"偷换成"不能再审"**、**把"简转普单行道"倒着开成"普转简"**、**把小额两档的"必须适用"与"合意适用"混为一谈**、**把"简便方式传唤"当成"缺席判决也不用传票"**。
>
> 🔎 **《民事诉讼法》（2023年修正）核心条文速查**：
> - **第40条第2款【审判组织·独任】**：适用简易程序审理的民事案件，由审判员一人独任审理。**基层人民法院**审理的**基本事实清楚、权利义务关系明确**的第一审民事案件，**可以由审判员一人适用普通程序独任审理**。
> - **第41条第2款【二审独任·衔接】**：中级人民法院对第一审**适用简易程序审结**或者**不服裁定提起上诉**的第二审民事案件，事实清楚、权利义务关系明确的，**经双方当事人同意**，可以由审判员一人独任审理。
> - **第42条【不得独任六情形】**：涉国家利益社会公共利益 / 群体性纠纷可能影响社会稳定 / 群众广泛关注或社会影响较大 / 新类型或疑难复杂 / 法律规定应当合议 / 其他不宜独任。
> - **第43条【独任转合议与异议】**：审理中发现不宜独任的，**应当裁定转由合议庭**；当事人认为独任违法的，可以提出异议，法院应当审查——成立裁定转合议庭，不成立裁定驳回。
> - **第160条【简易程序适用范围】**：基层法院和它派出的法庭审理**事实清楚、权利义务关系明确、争议不大**的简单民事案件；前款以外的案件，**当事人双方也可以约定适用**简易程序。
> - **第161-163条【简化点】**：口头起诉；双方同时到庭可当即审理；简便方式传唤、送达、审理；独任审理并**不受第139条（开庭三日前通知）、第141条（法庭调查顺序）、第144条（法庭辩论顺序）限制**。
> - **第164条【简易审限】**：立案之日起**三个月**内审结；特殊情况经**本院院长批准**可延长**一个月**。
> - **第165条【小额两档】**：标的额为各省、自治区、直辖市**上年度就业人员年平均工资百分之五十以下**的简单金钱给付案件→**适用小额诉讼的程序审理，实行一审终审**；**超过百分之五十但在二倍以下**的→当事人双方**也可以约定**适用。
> - **第166条【小额禁用清单】**：人身关系、财产确权 / 涉外 / 需要评估鉴定或对诉前评估鉴定结果有异议 / 一方当事人下落不明 / 当事人提出反诉 / 其他不宜。
> - **第167-169条【小额运行与转换】**：可一次开庭审结并当庭宣判；审限**两个月**、院长批准延长一个月；发现不宜适用的→**适用简易程序的其他规定审理或者裁定转为普通程序**；当事人异议→审查，成立同前处理、不成立裁定驳回。
> - **第170条【简转普】**：审理中发现不宜适用简易程序的，**裁定转为普通程序**。
> - **《民诉法解释》（法释〔2022〕11号修正）**：§256（"事实清楚/权利义务关系明确/争议不大"的界定）、§257（简易程序禁用七类清单）、§258（延长后审限累计不超四个月；转普审限自立案日起算）、§260（开庭后**不得普转简**）、§261（简便传唤方式；简便送达的开庭通知未经确认不得缺席判决）、§264（约定简易应在开庭前提出；§257清单案件约定不予准许）、§269（简易程序异议处理）、§271-272（小额一审终审；年均工资以**已公布的最近年度**为准）、§274（受理小额应告知一审终审等事项）、§275（小额举证期限一般不超七日）、§276（小额管辖异议裁定**一经作出即生效**）、§277（起诉不符合条件裁定驳回起诉、裁定即生效）、§278（反诉等致不符合条件的转换）、§279（小额异议**开庭前**提出）、§281（小额无规定的适用简易程序其他规定）、§424（小额再审两路径）。

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均已逐条 grep 本库存档的**官方全文**核验——民诉法条文核自 ssf.gov.cn 发布的《民事诉讼法》2023修正全文 PDF 文本（§40-43、§139/141/144、§160-170），民诉解释条文核自 ssf.gov.cn 发布的法释〔2022〕11号修正全文文本（§256-281、§424、§199），无一凭记忆写入。两点提示：①小额两档的基数是"各省、自治区、直辖市**上年度就业人员年平均工资**"（解释§272：以**已公布的最近年度**为准），各地数额逐年浮动，**切勿背任何固定金额**，考题一定会在题干给出当地年均工资数字；②真题卡 175 涉及的《简易程序若干规定》（法释〔2003〕15号）第八条系该真题卡内已核内容，本模型转述、未在本次另行核验，该卡本身已如实标注 MEDIUM 争议。
>
> ⚠️ **易记错点**：①**小额"一审终审"只堵上诉这条路，不堵再审**——且再审分两路径（解释§424）：按§207事由再审→合议庭审、再审判决**不得上诉**；以"不应按小额审理"为由再审→合议庭审、再审判决**可以上诉**；②**简转普是单行道**：简易可以转普通（§170），但已按普通程序审理的案件**开庭后不得转简易**（解释§260），小额"降档"也只能降为"简易程序其他规定"或普通程序（§169），没有任何"升档回小额"的通道；③**两档标准方向别记反**：50%**以下**是"**必须**适用"（法定强制，不问当事人意愿），超过50%但**二倍以下**才是"**合意**适用"；④**简便方式传唤合法 ≠ 缺席判决不用传票**——缺席判决必须以传票传唤为前提，仅电话/短信/邮件通知即缺席判决，构成§211(十)"未经传票传唤，缺席判决"的再审事由；⑤**普通程序独任的门槛是"基本事实清楚、权利义务关系明确"两项（§40 II），比简易程序少了"争议不大"**，且只属于**基层法院**；二审独任（§41 II）另须**双方当事人同意**，一审普通程序独任**不需要**当事人同意；⑥**独任异议与小额异议的救济长得像但归属不同**：独任异议依§43（成立转合议庭），小额异议依§169/解释§279（成立转简易其他规定或普通程序，且应**开庭前**提出），简易异议依解释§269（成立转普通程序）。

## 二、 三快道判别模型（进门 → 简化 → 降档 → 救济）

```
              【基层法院受理第一审民事案件】
                        │
   ▼ 第一问：能进哪条快道？（进门档位判断）
   │
   ├─ 简单金钱给付 + 标的额 ≤ 当地上年度年均工资50%
   │        └──→ 【小额诉讼】法定必须适用，一审终审（§165 I）
   ├─ 简单金钱给付 + 标的额在50%~2倍之间
   │        └──→ 双方约定 → 【小额诉讼】（§165 II）；不约定 → 简易/普通
   ├─ 事实清楚 + 权利义务关系明确 + 争议不大（解释§256界定）
   │        └──→ 【简易程序】（§160 I）；此外的案件双方也可约定简易（§160 II）
   │             但解释§257七类禁用清单（被告下落不明/发回重审/一方人数众多/
   │             再审程序/涉国家社会公共利益/第三人撤销之诉/其他）→ 约定也不准（§264 II）
   └─ 走普通程序的案件：基本事实清楚 + 权利义务关系明确
            └──→ 可【普通程序独任审理】（§40 II后段，仅基层法院）
                 但§42六情形（国益公益/群体性/广泛关注/新类型疑难/法定合议/其他）不得独任
                        │
   ▼ 第二问：快道里怎么简化？
   │
   ├─ 简易：口头起诉§161 / 简便传唤送达§162 / 不受§139·§141·§144限制§163
   │        / 独任审理 / 审限3个月+院长批准延1个月§164（累计≤4个月，解释§258）
   └─ 小额：一次开庭审结、当庭宣判§167 / 审限2个月+延1个月§168
            / 举证期限一般≤7日（解释§275）/ 文书可简化（解释§280）
            / 无规定的适用简易程序其他规定（解释§281）
                        │
   ▼ 第三问：什么时候必须降档？（转换是单行道）
   │
   ├─ 小额 → 发现不宜（反诉/下落不明/需评估鉴定等）
   │        → 适用简易程序其他规定审理 或 裁定转普通程序（§169、解释§278）
   ├─ 简易 → 发现不宜 → 裁定转为普通程序（§170），审限自立案日起算（解释§258 III）
   ├─ 独任 → 发现不宜 → 应当裁定转由合议庭审理（§43 I）
   └─ ❌ 反向禁止：普通程序开庭后不得转简易（解释§260）；已确认的事实
        转换后可不再举证质证（解释§278 III）
                        │
   ▼ 第四问：当事人不服怎么救？
   │
   ├─ 对适用简易有异议 → 成立裁定转普，不成立裁定驳回（解释§269）
   ├─ 对适用小额有异议 → 开庭前提出；成立转简易其他规定/普通程序，
   │                      不成立裁定驳回（§169 II、解释§279）
   ├─ 对独任有异议 → 成立裁定转合议庭，不成立裁定驳回（§43 II）
   ├─ 小额管辖异议 → 裁定一经作出即生效，不能上诉（解释§276）
   └─ 小额生效判决 → 不能上诉，但能向原审法院申请再审（解释§424）：
        ①按§207事由再审 → 合议庭审，再审判决不得上诉
        ②以"不应按小额审理"为由 → 合议庭审，再审判决可以上诉
```

> **一句话总诀**：**「进门看档位：50%以下必须小额、50%-2倍合意小额、简单案件走简易、普通程序也能独任（六不得除外）；道内看简化：简易3个月小额2个月，口头起诉简便传唤当庭宣判；转换单行道：小额降简易、简易转普通、独任转合议，普转简开庭后免谈；救济记双轨：异议开庭前提、管辖裁定即生效，一审终审堵上诉不堵再审——按事由再审不得上诉、按'不应小额'再审可以上诉」**

## 三、 三个高频干扰（一审终审≠不能再审 / 必须小额≠合意小额 / 简便传唤≠免传票缺席判决）

命题人极喜欢在"救济通道"和"档位方向"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **一审终审=终局无救济** | 小额诉讼实行一审终审，判决生效后当事人不得上诉，也不得申请再审。 | **❌ 说法错误！堵的是上诉，不是再审。**依解释§424，当事人以§207事由或以"不应按小额审理"为由向**原审法院**申请再审的，法院**应当受理**；裁定再审的**组成合议庭**审理。两条路径的再审判决能否上诉还不一样（按事由→不得上诉；按"不应小额"→可以上诉），这是命题人最爱的二级坑。 |
| **两档标准方向记反** | 标的额在年均工资50%以下的简单金钱给付案件，经双方当事人约定可以适用小额诉讼程序。 | **❌ 说法错误！50%以下是"必须"，不是"约定"。**§165 I：50%以下**法定强制适用**小额诉讼、一审终审，不以当事人合意为条件；**超过50%但二倍以下**才轮到"当事人双方**也可以约定**适用"（§165 II）。把"必须档"说成"合意档"（或反之）是标配错误选项。 |
| **简便传唤后直接缺席判决** | 简易程序中法院可以电话/短信/电子邮件通知开庭，被告经通知无正当理由不到庭的，法院可以缺席判决。 | **❌ 说法错误！缺席判决必须以传票传唤为前提。**§162允许简便方式传唤，但仅简便通知后即缺席判决，构成§211(十)"**未经传票传唤，缺席判决**"的法定再审事由；解释§261 II 更明确：简便方式送达的开庭通知，未经当事人确认或无其他证据证明已收到的，**不得缺席判决**。 |

## 四、 三快道对照表（简易 vs 小额 vs 普通程序独任，勿混条号）

简易程序（§160-164、§170）、小额诉讼（§165-169）、普通程序独任（§40 II、§42-43）三者都"快"，命题人常互换其规则：

| 事项       | 简易程序                                        | 小额诉讼                                          | 普通程序独任                                  |
| -------- | ------------------------------------------- | --------------------------------------------- | --------------------------------------- |
| 法院层级     | 仅基层法院及其派出法庭（§160）                           | 仅基层法院及其派出法庭（§165；海事法院可适用，解释§273）              | 仅基层法院（§40 II后段）                         |
| 适用条件     | 事实清楚+权利义务关系明确+争议不大（解释§256界定三要素）             | 前述简单案件且为**金钱给付**+标的额两档（50%以下必须/50%-2倍合意，§165） | **基本事实清楚+权利义务关系明确**（无"争议不大"要件）          |
| 合意空间     | 非简单案件可约定适用（§160 II），但§257清单不可约定（解释§264 II）  | 仅50%-2倍档可约定（§165 II），§166清单不可约定               | 无合意通道（一审独任不以当事人同意为条件；对比二审独任§41 II须双方同意） |
| 禁用清单     | 解释§257七类（下落不明/发回重审/人数众多/再审/国益公益/第三人撤销之诉/其他） | §166六类（人身关系财产确权/涉外/需评估鉴定/下落不明/反诉/其他）          | §42六类（国益公益/群体性/广泛关注/新类型疑难/法定合议/其他）      |
| 审限       | **3个月**+院长批准延1个月（§164；累计≤4个月，解释§258）        | **2个月**+院长批准延1个月（§168）                        | 普通程序审限（不因独任而缩短）                         |
| 审级救济     | 两审终审，可上诉                                    | **一审终审**，不可上诉，可再审（解释§424两路径）                  | 两审终审，可上诉                                |
| 不宜适用时的转换 | 裁定转为普通程序（§170），审限自立案日起算                     | 适用简易程序其他规定审理或裁定转普（§169、解释§278）                | 应当裁定转由合议庭审理（§43 I）                      |
| 当事人异议    | 解释§269：成立转普、不成立裁定驳回                         | §169 II/解释§279：**开庭前**提出；成立转简易其他规定或普通程序       | §43 II：成立转合议庭、不成立裁定驳回                   |

> ⚠️ **易混条号**：简易审限三个月是**§164**、小额审限两个月是**§168**，不可互换；简转普是**§170**、小额降档是**§169**、独任转合议是**§43**——三条"降档"条文各管一条道；小额管辖异议"裁定即生效"是**解释§276**，普通管辖异议裁定可上诉（§130、§171 II体系），两者是例外与原则的关系。

## 五、 万能三步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序合法性分析），按照以下三步进行涵摄：

*   🚗 **统一案例**：某省已公布的上年度就业人员年平均工资为 **8 万元**（→ 50% 档 = **4 万元**，2 倍档 = **16 万元**；此数字系题干给定，实务中以当地已公布的最近年度数据为基数，**勿背固定数额**）。老王在该省 A 县基层法院起诉老李，案情随三步逐层变化：①诉还借款 **3 万元**（事实清楚、有借条转账记录）；②变体诉 **6 万元**；③变体诉 **20 万元**且案情稍复杂。

### 第一步：走快道——什么案能进简易程序？怎么简化？只能简转普！

> **基层简单能进门，禁用清单约不动；口头起诉简便唤，三月审结单行道**

#### 概述

简易程序是三条快道的"底盘"，进门要过三道检查：

- **法院层级**：只有**基层法院和它派出的法庭**能用——中院一审再简单也不能简易；
- **案件性质**：**事实清楚 + 权利义务关系明确 + 争议不大**（解释§256给了操作化界定：陈述基本一致无须法院调查取证即可查明 / 能明确区分权利者与责任者 / 对是非责任标的无原则分歧）；
- **合意通道及其边界**：不属于简单案件的，**双方可以约定**适用简易程序（§160 II，应在**开庭前**提出，解释§264）；但落入解释§257**七类禁用清单**（起诉时被告下落不明、**发回重审**、一方人数众多、再审程序、涉国家社会公共利益、第三人撤销之诉、其他不宜）的，**约定也不予准许**。

进了门就享受简化套餐：**口头起诉**（§161）、双方同时到庭可**当即审理**（§161 II）、**简便方式**传唤送达审理（§162）、**独任审理**且不受开庭三日前通知（§139）、法庭调查顺序（§141）、法庭辩论顺序（§144）的限制（§163）、审限**三个月**、特殊情况经**本院院长批准**延长**一个月**（§164，延长后累计不得超过四个月，解释§258）。

出门只有一个方向：审理中发现不宜简易的，**裁定转为普通程序**（§170），审限从**立案之日**重新起算（解释§258 III）；反过来，**已按普通程序审理的案件开庭后不得转为简易**（解释§260）——单行道。

#### 大白话讲解

老王拿着借条和转账记录，到 A 县法院告老李还 **3 万元**借款。立案庭一看：借条清清楚楚、钱是微信转的有记录、老李也承认借了只是没钱还——这就是典型的"事实清楚、权利义务关系明确、争议不大"，进简易程序（先按住"小额"不表，第二步再说档位）。

进了简易程序，老王体验到一路绿灯：起诉可以**口头**说、书记员记笔录就行；法院给老李打个**电话**就算传唤了，不用非得寄传票才能开庭；开庭也不用死板地走"当事人陈述→证人作证→……"的法定顺序，法官问明白就行；而且**三个月**内必须审完（普通程序是六个月）。

但两个红线老王得知道：

**红线一（简便传唤≠免传票缺席判决）**：假如老李接了电话说"知道了"，开庭却没来——法官**不能**就这么缺席判决。缺席判决必须有**传票传唤**打底；只打了电话就缺席判决，老李日后可以拿§211(十)"未经传票传唤，缺席判决"申请**再审**，整个判决翻盘。

**红线二（禁用清单连合意都封）**：假如这案子曾被二审**发回重审**，老王老李商量"咱们图快，还走简易吧"——不行。发回重审位列解释§257禁用清单，**约定也不准**（解释§264 II），必须按第一审程序**另行组成合议庭**。

**转换方向表**，一眼看清单行道：

| 转换方向 | 能不能 | 依据 |
|---|---|---|
| 简易 → 普通（发现不宜简易） | ✅ 裁定转普，审限自立案日起算 | §170、解释§258 III |
| 普通 → 简易（开庭后） | ❌ 不得 | 解释§260 |
| 当事人对简易有异议 | 审查：成立转普 / 不成立裁定驳回 | 解释§269 |

#### 一句话闭环记忆

> 🎯 **一眼判**： 简易程序仅适用于**基层法院及其派出法庭一审案件**，中院及以上法院不得适用；适用情形分为法定适用与约定适用：法定适用需同时满足事实清楚、权利义务关系明确、争议不大；不属于简单案件的，双方当事人可于**开庭前约定适用简易程序**，但案件落入民诉解释第 257 条七类禁止清单，即便当事人合意，法院也不予准许。简易程序审理规则可依法简化：允许口头起诉，双方同时到庭可当即审理；可采用电话等简便方式传唤、送达、审理；审判员独任审理，不受普通程序开庭通知、法庭调查、辩论顺序限制；审限 3 个月，特殊情况经本院院长批准延长 1 个月，累计最长不超 4 个月。程序转换具有单向性：审理中发现不宜适用简易程序，**裁定转为普通程序**，审限自立案之日重新计算；案件已经按照普通程序开庭审理后，**不得转为简易程序**；当事人对适用简易程序提出异议，法院审查后异议成立裁定转普，异议不成立裁定驳回。重要易错要点：简便方式传唤不等于可以直接缺席判决，未经传票传唤、无证据证明当事人收到开庭通知，不得作出缺席判决，否则当事人可据此申请再审。

- 七类案件禁止适用简易程序 [[七类案件禁止适用简易程序]] :
	- 起诉时被告下落不明、发回重审、一方人数众多、再审案件、涉国家与社会公共利益、第三人撤销之诉、其他不宜适用情形
- 口头起诉：
	- 简易程序可口头起诉：无需提交书面起诉状，原告向法院口头陈述诉讼请求、事实理由；书记员记录形成笔录，经原告核对、签名或捺印后，笔录具备起诉状效力。普通程序不当然允许口头起诉；小额诉讼作为简易程序特殊类型，同样适用口头起诉规则.
- **纸质传票**：
	- 法院加盖公章的正式书面文书，核心用途：通知当事人、证人开庭时间、地点、案由、权利义务；依法完成合法传唤。一审普通程序、再审、发回重审、三撤、人数众多、起诉时被告下落不明等禁止简易程序案件. 普通程序规则：开庭 3 日前送达传票；若仅电话通知，不能直接缺席判决。简易、小额诉讼**允许电话、短信等简便方式传唤**，替代纸质传票。简易程序里法院可以打电话、发短信通知开庭，不用纸质传票。

**但是：法院必须拿出证据，证明被告实实在在看到、收到这条开庭通知。**

### 第二步：更快的一锤定音——小额诉讼两档标准 + 一审终审 + 禁用清单 + 异议救济

> **五折以下必须走，五折两倍合意有；一审终审堵上诉，清单异议再审留**

#### 概述

小额诉讼是简易程序里的"特快专列"（民诉解释的章名就叫"简易程序中的小额诉讼"），核心是四件事：

- **两档标准**（§165，基数=各省、自治区、直辖市**上年度就业人员年平均工资**，以已公布的最近年度为准，解释§272）：
	- 标的额 ≤ 年均工资 **50%** 的**简单金钱给付**案件 → **必须适用**小额诉讼（法定强制，不问意愿）；
	- 标的额**超过 50% 但在二倍以下** → **双方约定**才适用。
- **一审终审**：判决作出即生效，**不能上诉**——这是小额与简易的最大分水岭；
- **禁用清单**（§166 六类）：人身关系、财产确权 / **涉外** / 需要评估鉴定或对诉前评估鉴定结果有异议 / 一方当事人**下落不明** / 当事人提出**反诉** / 其他不宜——小额只收"简单金钱给付"这一种货；
- **转换与救济**：审理中发现不宜（含因增加变更诉请、反诉、追加当事人致超标，解释§278）→ **适用简易程序其他规定审理或裁定转普**（§169）；当事人异议应**开庭前**提出（解释§279）；**管辖异议裁定一经作出即生效**（解释§276）；生效判决**不能上诉但能再审**，且分两路径（解释§424）。

配套的程序运行规则：可**一次开庭审结、当庭宣判**（§167）；审限**两个月**+院长批准延一个月（§168）；举证期限一般**不超过七日**（解释§275）；受理时应**告知**当事人一审终审等事项（解释§274）；裁判文书可简化（解释§280）；没规定的适用简易程序其他规定（解释§281）。

#### 大白话讲解

回到统一案例：该省年均工资 **8 万元**，两个门槛线就是 **4 万**（50%）和 **16 万**（2 倍）。老王的诉求金额换三个档位试一遍：

| 老王诉请金额 | 落在哪档 | 程序结论 |
|---|---|---|
| **3 万元**（≤4万） | 50%以下档 | **必须**适用小额诉讼，一审终审——老王老李**都没有选择权** |
| **6 万元**（4万<6万≤16万） | 50%~2倍档 | 双方**约定**才能走小额；不约定就走简易/普通 |
| **20 万元**（>16万） | 超出2倍 | **不能**小额；若仍简单可走简易，否则普通程序 |

老王诉 3 万，法院适用小额诉讼：立案时就**告知**他"这案子一审终审、两个月审结"；举证期限只给 7 天；开一次庭、**当庭宣判**老李还钱。判决一下来**立即生效**——老李想上诉？**没有这条路**。

但案子中途可能"变质"，一变质就得**降档**：

- 开庭前老李突然**提出反诉**，要老王还他 8 万元货款——"当事人提出反诉"进了§166禁用清单，案件不再符合小额条件，法院应**适用简易程序的其他规定审理**（还超标或复杂的，**裁定转普通程序**），而且转换前双方已确认的事实**不用重新举证质证**（解释§278）；
- 或者老李开庭前**离家出走下落不明**——同样触发清单第(四)项，降档处理；
- 老李若认为"这案子根本不该按小额审"，要在**开庭前**提出异议（解释§279）：成立就降档，不成立裁定驳回。

判决生效后老李还有最后的救济——**再审**（向原审 A 县法院申请，法院应当受理），但要看他举的旗：

| 再审路径 | 审判组织 | 再审判决能否上诉 |
|---|---|---|
| 以§207再审事由（如未经传票传唤缺席判决） | 合议庭 | ❌ 不得上诉 |
| 以"**不应按小额诉讼审理**"（如标的超标）为由 | 合议庭 | ✅ **可以上诉** |

逻辑很好懂：第二条路径等于确认"这案子本就不该一审终审"，所以再审判决要把被剥夺的上诉权还给当事人。

还有一个冷门快刀：老李对**管辖**提异议，法院的裁定**一经作出即生效**（解释§276）——普通案件里管辖异议裁定可以上诉，小额里**不能**，这是命题人爱考的例外。

#### 一句话闭环记忆

> 🎯 **一眼判**：小额诉讼属于简易程序中的特殊程序，仅适用于基层法院及其派出法庭审理**事实清楚、权利义务明确、争议不大的简单金钱给付案件**，适用标准采取两档规则：标的额低于本省上年度就业人员年平均工资 50%**应当适用**；标的额超过 50% 且在 2 倍以内，**双方当事人约定方可适用**；超出 2 倍不得适用小额诉讼。人身关系、财产确权、涉外、需评估鉴定、一方下落不明、当事人提出反诉六类案件禁止适用小额诉讼。小额诉讼实行**一审终审，不得上诉**；管辖异议裁定一经作出立即生效，不允许上诉；当事人对适用小额诉讼程序有异议，应当在开庭前提出。审理中因诉请变更、追加当事人、反诉等情形不再符合小额条件，转为简易程序审理，确有必要可裁定转为普通程序，转换前双方确认事实无需重新举证质证。小额诉讼可一次开庭、当庭宣判；审限 2 个月，院长批准可延长 1 个月；举证期限一般不超过 7 日；受理案件时法院应当告知当事人一审终审相关事项，裁判文书允许简化。小额诉讼本身**一审终审，没有上诉通道**, 生效裁判救济依靠再审，并且小额诉讼再审统一由**原审基层法院另行组成合议庭审理**，不受上面通用再审规则约束,  再审后的上诉救济, 区分两条路径：以民事诉讼法第 207 条常规再审事由申请再审，再审裁判仍不得上诉；以不应适用小额诉讼为由申请再审，再审裁判可以上诉；法律无特别规定时，小额诉讼适用简易程序相关规则。

- 小额再审

### 第三步：普通程序也能一人审——独任条件 + 六不得 + 转合议

> **基层普通可独任，基本清楚权义明；六类案件必合议，发现不宜转过门**

#### 概述

2021 年修法前，"独任=简易程序"是铁律；修法后 §40 II 后段**新增**了普通程序独任制，把"审判组织"和"审理程序"解绑：

- **条件**（§40 II后段）：**基层法院**审理的、**基本事实清楚、权利义务关系明确**的第一审民事案件，可以由审判员一人**适用普通程序**独任审理——注意比简易程序的三要素**少了"争议不大"**，且**不需要当事人同意**；
- **六不得**（§42）：①涉及**国家利益、社会公共利益**；②涉及**群体性纠纷**，可能影响社会稳定；③人民群众**广泛关注**或者其他社会影响较大；④属于**新类型或者疑难复杂**；⑤**法律规定应当组成合议庭**（如选民资格案件、重大涉外案件等）；⑥其他不宜独任——这六类**只能合议**；
- **转合议与异议**（§43）：审理中发现不宜独任的，**应当裁定转由合议庭**审理；当事人认为独任违法的，可以提**异议**，法院审查——成立裁定转合议庭，不成立裁定驳回；
- **二审独任衔接**（§41 II）：中院对**一审简易程序审结**或**不服裁定上诉**的二审案件，事实清楚、权利义务关系明确，**经双方当事人同意**可独任——注意一审普通独任**不需要**同意、二审独任**需要**双方同意，这组对比是命题点。

#### 大白话讲解

第三个变体：老王诉老李 **20 万元**——超出小额 2 倍上限，而且老李对利息计算方法有争议、来回扯皮，"争议不大"说不上，进不了简易程序，只能走**普通程序**。

搁在 2021 年以前，普通程序必须**三个人组合议庭**。但现在 A 县法院一看：借款本金 20 万有借条有流水，**基本事实清楚**；谁是债权人谁是债务人一目了然，**权利义务关系明确**——只是利息争议大了点。符合 §40 II 后段，指定审判员一人**适用普通程序独任审理**：程序还是普通程序那一套（审限六个月、正常传票、完整的法庭调查辩论），只是审判席上从三个人变成一个人。**不用问老王老李同不同意。**

但换六种案子试试，一人审就不行了——比如这 20 万借款背后其实是**上百名村民的集资纠纷**（群体性、可能影响社会稳定），或者案件被媒体连续报道**全网关注**，或者涉及一项**从没判过的新型交易**：统统落入 §42 六不得清单，**必须合议庭**。

审到一半才发现不对怎么办？比如独任审理中媒体突然介入、案件社会影响骤然放大——法官**应当裁定转由合议庭**审理（§43 I），不是"可以"是"应当"。老李如果觉得"这案子这么复杂凭什么一个人审"，也可以向法院**提异议**：成立就转合议庭，不成立裁定驳回（§43 II）。

最后衔接一个二审彩蛋（详见二审程序模型，此处只挂钩）：这案子若走了简易程序审结、老李上诉到中院，中院发现事实清楚权利义务明确——**经老王老李双方同意**，二审也可以一人独任（§41 II）。对比着记：

| 独任场景 | 法院 | 是否需要当事人同意 |
|---|---|---|
| 简易程序独任（§40 II前段） | 基层 | 不需要（法定） |
| 普通程序独任（§40 II后段） | 基层 | **不需要** |
| 二审独任（§41 II） | 中院（限简易审结/不服裁定上诉的二审） | **需要双方同意** |

#### 一句话闭环记忆

> 🎯 **一眼判**：基层法院一审民事案件，满足**基本事实清楚、权利义务关系明确**，可由审判员一人适用普通程序独任审理；该条件不要求 “争议不大”，**无需当事人同意**。存在六类情形不得独任、必须合议：涉及国家利益与社会公共利益；群体性纠纷且可能影响稳定；群众广泛关注、社会影响较大；新类型或疑难复杂案件；法律明确应当组成合议庭；其他不宜独任情形。审理过程中发现案件不适宜独任的，**应当裁定转为合议庭审理**；当事人可对独任审理提出异议，异议成立裁定转合议，不成立裁定驳回。二审独任仅限中院审理一审简易审结案件、不服裁定上诉案件，事实清楚、权利义务明确的，**必须经过双方当事人同意**方可独任；一审简易独任、一审普通程序独任均不需要当事人同意。

- 法律明确应当组成合议庭

	- 选民资格案件
	- 第三人撤销之诉
	- 二审普通上诉案件
		- 基层法院普通程序独任审理民间借贷，被告不服上诉至中院。
	- 发回重审

- 其他不宜独任情形

## 六、 易混提示

*   **简易程序三要素 vs 普通程序独任两要素**：
    *   *简易程序*要"事实清楚+权利义务关系明确+**争议不大**"三项齐备（§160）；*普通程序独任*只要"**基本**事实清楚+权利义务关系明确"两项（§40 II后段）——争议大但事实基本清楚的案子，进不了简易，却可以普通程序独任。
*   **"必须小额" vs "合意小额" vs "合意简易"**：
    *   标的额≤50%→小额是**法定强制**；50%~2倍→小额靠**合意**；非简单案件走简易也靠**合意**（§160 II）——但所有合意都被各自的禁用清单封顶（§166 / 解释§257），清单内案件约定无效。
*   **三条"降档"通道勿互串**：
    *   小额降档→"适用**简易程序其他规定**审理或裁定转普"（§169）；简易降档→"裁定**转为普通程序**"（§170）；独任降档→"裁定**转由合议庭**"（§43）——考题常把"小额不宜"直接接"转普通程序"而跳过"简易其他规定"这个中间选项，或把独任问题错接程序转换。
*   **小额管辖异议裁定 vs 普通管辖异议裁定**：
    *   *小额*：裁定**一经作出即生效**，不能上诉（解释§276）；*普通/简易*：管辖异议裁定属可上诉裁定。同理小额中**裁定驳回起诉**也是一经作出即生效（解释§277）。
*   **一审普通独任 vs 二审独任**：
    *   一审普通程序独任**不需要**当事人同意；二审独任（§41 II）限于中院审理"一审简易审结或不服裁定上诉"的二审案件，且须**经双方当事人同意**。

## 七、 命题人最爱的 5 个陷阱

1.  **"小额诉讼一审终审，故当事人不得申请再审"** —— 错！一审终审只堵上诉；依解释§424，当事人可向**原审法院**申请再审（两路径均应受理、裁定再审的组成合议庭），且以"不应按小额审理"为由的再审判决**可以上诉**。
2.  **"标的额在年均工资50%以下的，经双方约定可适用小额诉讼"** —— 错！50%以下是**必须适用**（§165 I），无须也不容约定；**超过50%但二倍以下**才是约定档（§165 II）。方向反写是标配错误选项。
3.  **"发回重审的案件，征得双方当事人同意后可以适用简易程序审理"** —— 错！发回重审位列解释§257禁用清单第(二)项，当事人**约定也不予准许**（解释§264 II），应按第一审程序另行组成合议庭。
4.  **"简易/小额程序中法院电话（短信）通知开庭后被告未到庭的，可以缺席判决"** —— 错！简便方式传唤合法，但**缺席判决必须经传票传唤**；否则构成§211(十)再审事由（解释§261 II：简便送达的开庭通知未经确认不得缺席判决）。
5.  **"基层法院适用普通程序独任审理，应当经双方当事人同意"** —— 错！一审普通程序独任（§40 II后段）**不以当事人同意为条件**，只看"基本事实清楚、权利义务关系明确"+不落入§42六不得；须"双方当事人同意"的是**二审独任**（§41 II）。
