# 📐 二审裁判与调解 · 完整答题模型（三种出口与发回规则 + 调解/撤诉/新请求 + 终审效力）

> **核心一句**：[[民诉-二审-上诉提起与审理模型]]解决"案子怎么**上去**、审什么"，本模型解决"二审**怎么收尾**"，一条主线三站：**二审怎么判（§177三种出口＋发回一次为限）→ 判之前还能和吗、退吗、加吗（调解§179／撤上诉§180／撤起诉解释§336／新诉请反诉解释§326）→ 判完就终局（§182终审，救济只剩再审）**。最毒陷阱是**把"可改可发"的事实问题与"必须发回"的程序严重违法混为一谈**、**发回重审后再上诉还想"再次发回"**（§177 II明文封死）、**把"撤回上诉"（一审判决生效）与"撤回起诉"（连一审判决一并撤销）混为一谈**、**对二审新增诉请"发回重审"或"径行判决"**（正确答案永远是"调解不成告知另行起诉"）、**对错误的驳回起诉"裁定"喊发回重审**（裁定错了用"指令审理"，判决错了才谈发回）。
>
> 🔎 **核心条文速查**：
> - **民诉法§177【二审裁判方式】**：二审对上诉案件，经过审理，按下列情形分别处理：（一）原判决、裁定**认定事实清楚，适用法律正确**的，以判决、裁定方式**驳回上诉，维持**原判决、裁定；（二）原判决、裁定**认定事实错误或者适用法律错误**的，以判决、裁定方式依法**改判、撤销或者变更**；（三）原判决**认定基本事实不清**的，裁定撤销原判决，**发回**原审法院重审，**或者查清事实后改判**；（四）原判决**遗漏当事人或者违法缺席判决等严重违反法定程序**的，裁定撤销原判决，**发回**原审法院重审。**第二款**：原审法院对发回重审的案件作出判决后，当事人提起上诉的，二审**不得再次发回重审**。
> - **民诉法§178【对裁定的上诉】**：二审对不服一审裁定的上诉案件的处理，**一律使用裁定**。
> - **民诉法§179【二审调解】**：二审审理上诉案件，**可以进行调解**。调解达成协议，应当制作调解书，由审判人员、书记员署名，加盖法院印章。**调解书送达后，原审法院的判决即视为撤销**。
> - **民诉法§180【撤回上诉】**：二审判决宣告前，上诉人申请撤回上诉的，**是否准许，由二审法院裁定**。
> - **民诉法§182【终审】**：第二审人民法院的判决、裁定，**是终审的判决、裁定**。（配合§158：依法**不准上诉**或者超过上诉期没有上诉的判决、裁定，是**发生法律效力**的判决、裁定。）
> - **解释§323【严重违反法定程序的列举】**：下列情形可以认定为民诉法§177 I(四)的严重违反法定程序：（一）**审判组织的组成不合法**；（二）**应当回避的审判人员未回避**；（三）**无诉讼行为能力人未经法定代理人代为诉讼**；（四）**违法剥夺当事人辩论权利**。
> - **解释§324/§325/§327【三类"调解不成发回"】**：一审**已提出的诉请未作审理、判决**（漏判）→二审可依自愿原则调解，调解不成**发回重审**（§324）；**必须参加诉讼的当事人或有独三一审未参加**→同上（§325）；一审判**不准离婚**、二审认为应当判离→可与子女抚养、财产问题**一并调解**，调解不成**发回重审**（§327 I）。
> - **解释§326【二审新增诉请/反诉】**：二审中**原审原告增加独立的诉讼请求或者原审被告提出反诉**的，二审可依自愿原则就新增部分调解；调解不成的，**告知当事人另行起诉**。**双方当事人同意**由二审一并审理的，二审**可以一并裁判**。
> - **解释§335/§336/§337【撤上诉·撤起诉·和解】**：撤回上诉——一审判决**确有错误**，或当事人**恶意串通**损害国家利益、社会公共利益、他人合法权益的，**不应准许**（§335）；撤回起诉——原审原告申请撤回起诉，**经其他当事人同意，且不损害**国家利益、社会公共利益、他人合法权益的，**可以准许**；准许撤诉的，**应当一并裁定撤销一审裁判**；撤回起诉后**重复起诉的，不予受理**（§336）；和解——二审达成和解协议的，法院可**根据当事人的请求**审查并**制作调解书**送达；因和解申请撤诉、符合条件的**应予准许**（§337）。

>
> ⚠️ **易记错点**：①第（三）项事实不清是"**可改可发**"（发回**或**查清后改判，二选一），第（四）项程序严重违法是"**必须发回**"（条文没有"或改判"选项）——这一字之差是8-5的命门；②**发回重审以一次为限**（§177 II）——"就财产部分发回"也是再次发回，同样不行；③**撤回上诉≠撤回起诉**：撤上诉→一审判决**生效**；撤起诉→须**其他当事人同意＋不损三益**，准许后**一并裁定撤销一审裁判**，且**不得重复起诉**（解释§336）；④二审**新增诉请/反诉**的标准答案是"调解，不成**告知另行起诉**"——既不是发回重审（那是漏判§324的处理），也不能径行判决（吃掉一个审级），唯**双方同意**时可一并裁判；⑤一审**裁定**（不予受理/驳回起诉）错误的，二审用"**指令**立案受理/审理"（解释§330），不叫"发回重审"——**裁定用指令，判决才发回**；⑥发回重审后按**一审程序**审理：可变更增加诉请、可反诉（解释§251），但**不得适用简易程序**（解释§257(二)），管辖异议**不予审查**（解释§39 II）；⑦二审判决是**终审**判决，送达后不得再上诉，救济只剩**申请再审**（§211）——别在选项里给终审判决安排"再上诉"。

## 二、 判别模型（出口 → 和退加 → 终局）

```
              【一审判决/裁定已作出，上诉进入二审，二审审理完毕要收尾】
                            │
     ▼ 第一站：二审怎么判？（三种出口，民诉法§177 I，本模型重头）
     │
     ├─ 出口一【维持】：事实清楚+适用法律正确 → 驳回上诉，维持原判
     │   （事实/法律虽有瑕疵但裁判结果正确 → 纠正瑕疵后维持，解释§332）
     ├─ 出口二【改判】：认定事实错误 或 适用法律错误 → 依法改判、撤销或变更
     ├─ 出口三【发回】：
     │   ├─ (三)基本事实不清 → 撤销原判发回重审【或】查清事实后改判（可改可发）
     │   │   （基本事实=对裁判结果有实质性影响的事实，解释§333）
     │   └─ (四)严重违反法定程序 → 撤销原判、发回重审（必须发回，无改判选项）
     │       本条例示：遗漏当事人 / 违法缺席判决
     │       解释§323再列：审判组织不合法 / 应回避未回避 /
     │                     无诉讼行为能力人未经法代诉讼 / 违法剥夺辩论权
     ├─ 三类"调解不成→发回"（先调后发）：
     │   一审漏判诉请（解释§324）／必要当事人或有独三未参加（解释§325）／
     │   一审判不准离婚二审认为该离（解释§327，子女财产一并调解）
     ├─ 对裁定的上诉 → 一律用裁定（§178）；
     │   一审不予受理裁定错 → 撤销+指令立案受理；驳回起诉裁定错 →
     │   撤销+指令审理（解释§330，不叫发回重审）
     │   一审受理了不该受理的 → 二审径行撤销原裁判、驳回起诉（解释§328）
     └─ ⛔ 发回以一次为限：发回重审后一审又判、当事人再上诉 →
        二审不得再次发回，只能查清事实自行裁判（§177 II）
                            │
     ▼ 第二站：判之前，还能和吗？退吗？加吗？（§179/§180+解释§326/§335-337）
     │
     ├─ 调解（§179）：二审可调解 → 制作调解书 → 调解书送达后
     │   原审判决即视为撤销（调解书经双方签收生效，§100 III）
     ├─ 和解（解释§337）：达成和解协议 → 可依当事人请求制作调解书；
     │   因和解申请撤诉、符合条件的应予准许
     ├─ 撤回上诉（§180+解释§335）：判决宣告前申请，是否准许由二审裁定；
     │   一审确有错误/恶意串通损害三益 → 不应准许；准撤 → 一审判决生效
     ├─ 撤回起诉（解释§336）：其他当事人同意+不损害三益 → 可以准许；
     │   准许 → 一并裁定撤销一审裁判；此后重复起诉 → 不予受理
     └─ 新增诉请/反诉（解释§326）：可就新增部分调解 → 调解不成告知另行起诉；
        双方同意二审一并审理的 → 可以一并裁判（不得径行判决）
                            │
     ▼ 第三站：判完就终局（§182+§158+§211）
     │
     ├─ 二审判决、裁定=终审判决、裁定（§182），依法不准上诉的
     │   判决、裁定即生效判决、裁定（§158）→ 送达即告确定，不得再上诉
     ├─ 审限：对判决的上诉3个月（§183）；对裁定的上诉30日（解释§339）
     └─ 救济只剩再审轨道：当事人申请再审（§211事由清单）；
        法院系统自查提审/指令再审（§209）；检察监督另行展开
```

> **一句话总诀**：**「二审三出口：对的维持、错的改判、坏的发回；事实不清可改可发，程序严重违法必须发回，漏判漏人不准离婚先调解、调不成也发回；发回只有一次，第二轮上来必须自己判（§177）。判前三条退路：调解书送达原判销（§179），撤上诉一审生效、撤起诉连判带诉一起销且不得再告（解释§335/§336），新请求调不成另行起诉、双方点头才一并判（解释§326）。落槌即终局：二审是终审，不服只剩再审（§182+§211）」**

## 三、 高频干扰表（命题人最爱的偷换）

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **程序违法也"可改可发"** | "一审违法缺席判决/遗漏当事人，二审查清事实后可以直接改判，也可以发回重审。" | **❌ 错！** "可改可发"只属于第（三）项**基本事实不清**；第（四）项**严重违反法定程序**的法定处理只有一种——**裁定撤销原判、发回重审**（§177 I(四)），因为程序违法污染整个一审，改判会让当事人失去一个干净的审级。 |
| **再次发回重审** | "发回重审后一审再判仍有错误，当事人上诉，二审可以再次发回重审（或就部分问题再发回）。" | **❌ 错！** 原审对发回重审案件作出判决后当事人再上诉的，二审**不得再次发回重审**（§177 II）——"就财产部分发回"也是再次发回；二审只能查清事实**自行裁判**（离婚案还可再调解）。 |
| **撤上诉与撤起诉混同** | "二审中双方和解，原审原告申请撤回起诉，准许后一审判决发生法律效力。" | **❌ 错！** 撤回**上诉**才是一审判决生效；撤回**起诉**是把整个诉连根拔起——须其他当事人同意+不损害三益，准许时**应当一并裁定撤销一审裁判**，且撤回起诉后**重复起诉的不予受理**（解释§336）。 |
| **二审新增诉请发回或径行判决** | "二审中原审原告增加独立诉请（或被告提出反诉），二审应发回重审／应当一并审理判决。" | **❌ 错！** 新增诉请/反诉的处理是：可**调解**，调解不成**告知另行起诉**（解释§326）——发回重审是**一审漏判**（§324）和**漏必要当事人**（§325）的专属出口；径行判决剥夺审级利益，仅**双方同意**由二审一并审理时才可一并裁判。 |
| **对错误裁定"发回重审"** | "一审错误裁定驳回反诉，二审应撤销该裁定并发回重审。" | **❌ 错！** 发回重审针对的是**判决**；一审**驳回起诉裁定**错误的，二审"撤销原裁定的同时，**指令**第一审人民法院**审理**"，不予受理裁定错误的则"指令立案受理"（解释§330）——**裁定用指令，判决才发回**。 |
| **调解书生效后原判还在** | "二审调解书签收生效后，当事人反悔的，可申请对原一审判决强制执行。" | **❌ 错！** 二审调解书**送达后，原审判决即视为撤销**（§179），一审判决已不复存在，不能再执行；调解书经双方签收即生效（§100 III），生效调解书本身即为执行依据。 |
| **终审判决还能上诉** | "对二审判决不服的，可在15日内向上一级法院再提起上诉。" | **❌ 错！** 二审判决、裁定是**终审**判决、裁定（§182），送达即告确定生效——两审终审制下没有"三审"，救济只剩**申请再审**（§211）等审判监督渠道。 |

## 五、 万能三步答题模型

在法考答题中（客观题逐项判断按此顺序定位考点），按以下三步涵摄：

*   🚗 **统一案例**：老王起诉老李，请求赔偿房屋装修损失**20万元**并赔礼道歉。一审判决老李赔偿**12万元**，对赔礼道歉未作判决。老李不服，提起上诉。围绕这一个案子，三站剧情轮流上演。

### 第一步：出口诀——二审怎么判（三种出口＋发回规则）

> **对的维持错的改，事实可改可发、程序必须发回，发回只有一次**

#### 概述

二审审完，只有三种出口（民诉法§177 I），逐项对号：

- **出口一·维持**：原判**事实清楚、适用法律正确**→以判决/裁定**驳回上诉、维持原判**。事实或法律虽有**瑕疵**但**裁判结果正确**的，纠正瑕疵后照样维持（解释§332）——瑕疵≠错误。
- **出口二·改判**：原判**认定事实错误**或**适用法律错误**→依法**改判、撤销或变更**。
- **出口三·发回**，内部再分两档：
	- **(三)基本事实不清**（基本事实=对裁判结果有**实质性影响**的事实，解释§333）→裁定撤销原判**发回重审**，**或者查清事实后改判**——**可改可发**，二审有选择权；
	- **(四)严重违反法定程序**→裁定撤销原判、**发回重审**——**必须发回**，没有改判选项。清单两处凑齐：§177 I(四)本条例示**遗漏当事人、违法缺席判决**；解释§323再列**审判组织不合法、应回避未回避、无诉讼行为能力人未经法代诉讼、违法剥夺辩论权**。

另有三类"**先调解、调不成才发回**"的温和出口：一审**漏判**的诉请（解释§324）、**必要当事人或有独三**一审未参加（解释§325）、一审判**不准离婚**而二审认为应当判离（解释§327，子女抚养、财产问题一并调解；双方同意可由二审一并裁判）。

两条铁律收尾：①**发回以一次为限**——原审对发回重审案件作出判决后当事人再上诉的，二审**不得再次发回**（§177 II），只能自行判决；②**裁定错了不发回**——对裁定的上诉一律用**裁定**处理（§178），一审不予受理/驳回起诉的裁定错误的，二审撤销后**指令**一审立案受理/审理（解释§330）。

#### 大白话讲解

老李上诉后，二审法官翻卷，可能看到四种景象，各对一个出口：

| 二审看到的景象                            | 出口     | 处理                               |
| ---------------------------------- | ------ | -------------------------------- |
| 一审12万算得对、法条也引对了                    | 出口一    | 驳回上诉，维持原判（引错一个条文但结果对→纠正瑕疵后维持）    |
| 损失明明是8万，一审算成12万（事实错）；或事实对但赔偿标准引错法条 | 出口二    | 依法改判                             |
| 装修损失到底多少，一审根本没查清（基本事实不清）           | 出口三(三) | **可改可发**：要么发回让一审重查，要么二审自己查清后改判   |
| 一审开庭没传票传唤老李就缺席判决／审案的法官是老王的表哥没回避    | 出口三(四) | **必须发回**：裁定撤销原判、发回重审，没有"查清改判"的选项 |

再看两个特殊剧情。**剧情一（漏判）**：一审对"赔礼道歉"这项诉请压根没判——这是**一审已提出但漏判**的诉请，二审可以先组织调解，调不成就**该部分撤销原判、发回重审**（解释§324）；注意二审**不能自己动手判赔礼道歉**——老李只就赔偿数额上诉，二审主动判道歉就超出了上诉请求（多216的B项）。**剧情二（发回只有一次）**：假设案件已发回，一审重审后又判了12万，老李再上诉——这回二审**无论如何不能再发回**（§177 II），哪怕还想"就道歉部分再发回"也不行（那也是再次发回），只能查清事实**自己判**（多219的A、D项）。

最后一个易错角落：如果一审作出的不是判决而是**裁定**（比如错误地以"原告撤诉"为由裁定驳回了老李的反诉），二审的纠错动作是"撤销原裁定＋**指令**一审审理"（解释§330）——反诉从没被实体审过，谈不上"重审"，所以**裁定用指令，判决才发回**（单10的C、D项之辨）。

#### 一句话闭环记忆

> 🎯 **一眼判**：三出口对号——对的**维持**（瑕疵纠正后也维持）、错的**改判**、坏的**发回**；发回分两档——**事实不清可改可发，程序严重违法必须发回**；漏判、漏必要当事人、不准离婚该离＝**先调解、调不成发回**；**发回只有一次**，第二轮上来二审必须自己判；**裁定错了用指令，判决错了才发回**。

---

### 第二步：和退加诀——判之前还能和吗、退吗、加吗（调解／撤诉／新请求）

> **调解书送达原判销；撤上诉一审生效、撤起诉连根拔；新请求另行起诉**

#### 概述

二审宣判之前，当事人还有三类"改变剧本"的动作：

- **和——调解与和解**：二审**可以调解**（§179）；调解成了制作调解书，**调解书送达后，原审判决即视为撤销**（调解书经双方**签收**后即生效，§100 III——签收即送达完成，故"签收生效"与"送达后原判销"是同一时刻的两面）。当事人**自行和解**的，法院可**根据当事人请求**审查和解协议并制作调解书；因和解申请**撤诉**、符合条件的应予准许（解释§337）。
- **退——两种"撤"严格分流**：
	- **撤回上诉**（§180+解释§335）：上诉人在**判决宣告前**申请，是否准许由二审**裁定**；一审判决**确有错误**、或当事人**恶意串通**损害国家/社会公共/他人合法权益的，**不应准许**。准许撤回上诉的后果：二审程序终结，**一审判决生效**。
	- **撤回起诉**（解释§336）：原审**原告**申请，须**经其他当事人同意**且**不损害三益**，法院才可以准许；准许的，**应当一并裁定撤销一审裁判**（诉都没了，一审判决失去依托）；且原审原告撤回起诉后**重复起诉的，不予受理**——这是撤回起诉换来的"代价条款"。
- **加——新增诉请与反诉**（解释§326）：二审中**原审原告增加独立诉请**或**原审被告提出反诉**的，二审可依自愿原则就新增部分**调解**；调解不成，**告知当事人另行起诉**；**双方当事人同意**由二审一并审理的，才**可以一并裁判**——二审绝不能不经同意径行审判新请求，否则新请求"一审即终审"，剥夺审级利益。

#### 大白话讲解

**剧情一（调解）**：二审中法官主持调解，老王老李谈成"老李赔10万、分两期付"。调解书做好、双方**签收**——生效；同时一审那份"赔12万"的判决**自动作废**（视为撤销，§179）。老李事后反悔想"按一审判决只执行12万"或者再上诉？都没门——原判已销，调解书就是新的、也是唯一的执行依据。

**剧情二（两种"撤"，一字千里）**：还是二审中双方和解，"老李私下付8万了结"。接下来怎么收尾，差一个字天差地别：

| 动作 | 条件 | 后果 |
|---|---|---|
| 老李（上诉人）**撤回上诉** | 宣判前申请，二审裁定准许（一审确有错误/恶意串通损三益的不准，解释§335） | 二审终结，**一审"赔12万"的判决生效**——老王将来可以拿它执行！ |
| 老王（原审原告）**撤回起诉** | **老李同意**＋不损害国家/社会/他人利益 | 准许＋**一并裁定撤销一审判决**；老王以后**不得再就此重复起诉**（解释§336） |

所以和解协议约定"私了8万"时，聪明的老李该要求老王**撤回起诉**（把12万的判决连根拔掉），而不是自己**撤回上诉**（留着一审判决当悬顶之剑）。真题里"和解协议内容与原判决认定的事实不一致"能不能准许撤诉？**能**——那正是当事人处分自己权利，只要不损三益就不构成不准撤诉的事由（单222的B、C项）。双方一个撤上诉、一个撤起诉的，法院**都准**，并一并撤销一审判决（单223的A项）。

**剧情三（加新请求）**：二审中老王突然增加一项独立请求"老李还得赔家电损失5万"（或老李反诉"老王欠我租金"）。二审的处理三部曲：可以**调解**→调不成**告知另行起诉**→只有**双方都同意**由二审一并审理时才可一并裁判（解释§326）。对照记忆：**一审漏掉的**（赔礼道歉）→调解不成**发回重审**补审；**二审新加的**（家电5万）→调解不成**另案去告**——"漏掉的发回补，新加的另案告"（单213的A、B项之辨）。连"把'撤销婚姻'诉请改成'离婚'"这种变更，因为换了一个诉，也按**新增诉请**处理（多215的C项）。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审可调解，**调解书送达（签收）后原判自动销**（§179）；**撤上诉→一审判决生效；撤起诉→他方同意+不损三益→准许并一并撤销一审判决+不得重复起诉**（解释§335/§336）；二审**新增诉请/反诉→调解不成告知另行起诉**，双方同意才可一并裁判（解释§326）——漏掉的发回补，新加的另案告。

### 第三步：终局诀——判完就终局（终审生效＋救济只剩再审）

> **二审落槌即终审，上诉无门再审有道**

#### 概述

两审终审制的最后一块拼图：

- **终审**：二审的判决、裁定，**是终审的判决、裁定**（§182）；而"依法**不准上诉**……的判决、裁定，是**发生法律效力**的判决、裁定"（§158）——两条合读，二审裁判**送达即告确定、生效**，这就是通说"终审裁判送达即生效"的法条根基（法条本身没有"送达即生效"五个字，勿虚标原文）。
- **不得再上诉**：终审裁判之上没有第三审。当事人不服的，只能转入**审判监督**轨道：**申请再审**（§211列明的法定事由，如新证据足以推翻原判、基本事实缺乏证据证明、主要证据伪造等）；法院系统也可依§209提审或指令再审。再审是**非常救济**，不停止原裁判的执行（另入再审模型展开）。
- **审限顺带记**：对**判决**的上诉，二审应在立案之日起**3个月**内审结（院长批准可延长，§183）；对**裁定**的上诉，**30日**内作出终审裁定（解释§339）。

#### 大白话讲解

二审终审判决"老李赔10万"送达双方。老李还是不服："我要接着上诉到高院！"律师摇头："**没有第三次了**——二审就是终审（§182），判决送达那一刻已经生效，老王明天就能申请强制执行。你现在唯一的路是**申请再审**，但那不是'第三审'：得对上§211的法定事由清单（比如你手里有足以推翻原判的新证据），原则上在裁判生效后六个月内提出，而且申请再审**不影响老王先执行**这10万。"老李又问："那我拖着不领判决书行不行？"也不行——送达有送达的规则（留置、电子送达等照样完成送达），躲避签收挡不住生效。

一句话给这一站收口：**一审判决的生效要等15天上诉期过完；二审判决没有这道等待期——落槌（送达）即终局**。

#### 一句话闭环记忆

> 🎯 **一眼判**：二审裁判=**终审**裁判（§182），依法不准上诉即属生效裁判（§158）——**送达即确定生效，不得再上诉**；不服只剩**再审**一条非常轨道（§211事由清单，不停止执行）；审限：判决上诉**3个月**、裁定上诉**30日**。

## 六、 易混提示

*   **事实不清的发回 vs 程序违法的发回**：
    *   *(三)基本事实不清*→二审**可选择**发回或查清后改判；*(四)严重违反法定程序*→**只能发回**。共用一条底线：发回**均以一次为限**（§177 II）。
*   **法定径行发回 vs 调解型发回**：
    *   *§177 I(三)(四)*是二审径行裁定撤销、发回；*解释§324/§325/§327*（漏判/漏必要当事人/不准离婚应改离）是**先自愿调解、调解不成才发回**——选项里"直接发回"还是"调解不成发回"，一字之差定对错。
*   **一审漏判 vs 二审新增**：
    *   *一审已提出但漏判*的诉请→调解不成**发回重审**（§324）；*二审才新增*的独立诉请/反诉→调解不成**告知另行起诉**（§326）——"漏掉的发回补，新加的另案告"。
*   **撤回上诉 vs 撤回起诉**：
    *   *撤上诉*：上诉人单方申请、二审裁定准否，准撤后**一审判决生效**；*撤起诉*：原审原告申请、须**他方同意+不损三益**，准撤后**一并撤销一审裁判且不得重复起诉**（§336）。
*   **判决的纠错 vs 裁定的纠错**：
    *   *判决*错误→维持/改判/发回三出口（§177）；*裁定*（不予受理/驳回起诉）错误→撤销+**指令**立案受理/审理（解释§330），对裁定的上诉一律用**裁定**且30日审结（§178+解释§339）。
*   **二审调解书 vs 一审判决**：
    *   调解书**送达后原判视为撤销**（§179）——生效调解书是唯一执行依据，原一审判决不能"复活"执行。

## 七、 命题人最爱的 6 个陷阱

1.  **"一审违法缺席判决/遗漏当事人，二审可以查清事实后径行改判"** —— 错！严重违反法定程序（§177 I(四)）的法定出口**只有发回重审**；"可改可发"仅属于第(三)项基本事实不清。
2.  **"发回重审后一审再判仍有错，二审可以（就部分问题）再次发回"** —— 错！发回**以一次为限**（§177 II），部分发回也是再次发回；二审只能自行查清判决（离婚案可再调解）。
3.  **"二审中原审原告撤回起诉获准后，一审判决发生法律效力"** —— 错！那是**撤回上诉**的后果；撤回**起诉**获准的，**一并裁定撤销一审裁判**，且此后**重复起诉不予受理**（解释§336）。
4.  **"二审中新增独立诉请/反诉，二审应发回重审或径行一并判决"** —— 错！处理是**调解，调解不成告知另行起诉**；只有**双方同意**由二审一并审理时才可一并裁判（解释§326）。发回重审是留给**一审漏判**（§324）与**漏必要当事人**（§325）的。
5.  **"一审错误裁定驳回起诉（反诉），二审应撤销原裁定并发回重审"** —— 错！裁定的纠错是撤销＋**指令一审（立案受理／继续）审理**（解释§330）——裁定用指令，判决才发回。
6.  **"对二审判决不服可再上诉／二审调解书生效后仍可按原一审判决执行"** —— 错！二审裁判是**终审**裁判，送达即确定，救济只剩**再审**（§182+§211）；调解书送达后**原判已视为撤销**（§179），不可能再依原判执行。
