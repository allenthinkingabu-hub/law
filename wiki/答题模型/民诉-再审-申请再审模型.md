# 📐 申请再审 · 完整答题模型（对象与限制 + 期限与法院 + 十三项事由 + 再审利益）

> **核心一句**：申请再审是对**已经生效**的判决、裁定、调解书的**纠错救济**，不是第三审级。考试主线是**"什么裁判能再审 → 向哪个法院 → 六个月怎么起算 → 十三项事由对号 → 有没有再审利益"**五连问；最毒陷阱是**把"一审终审"当成"不能再审"（小额诉讼）**、**把一般事由和四类特殊事由的起算点搞混**、**把"管辖错误"塞进十三项事由**、**让赢了官司的人也来申请再审**。
>
> 🔎 **《民事诉讼法》（2023修正，2024-01-01施行）核心条文速查**：
> - **第210条【申请再审的对象与法院】**（单款）：当事人对已经发生法律效力的判决、裁定，认为有错误的，可以向**上一级人民法院**申请再审；**当事人一方人数众多或者当事人双方为公民**的案件，也可以向**原审人民法院**申请再审。当事人申请再审的，**不停止判决、裁定的执行**。
> - **第211条【十三项再审事由】**：新证据足以推翻(一)、基本事实缺乏证据证明(二)、主要证据伪造(三)、主要证据未经质证(四)、书面申请调查收集证据未调查收集(五)、适用法律确有错误(六)、审判组织不合法或应回避未回避(七)、无诉讼行为能力人未经法代代为诉讼／应当参加的当事人因不可归责事由未参加(八)、剥夺辩论权利(九)、未经传票传唤缺席判决(十)、遗漏或超出诉讼请求(十一)、据以裁判的法律文书被撤销或变更(十二)、审判人员贪污受贿徇私舞弊枉法裁判(十三)。
> - **第212条【调解书再审】**：提出证据证明**调解违反自愿原则**或者**调解协议的内容违反法律**的，可以申请再审；审查属实的，应当再审。
> - **第213条【婚姻负面清单】**：对已生效的**解除婚姻关系**的判决、调解书，**不得申请再审**。
> - **第215条【审查】**：法院自收到再审申请书之日起**三个月内**审查，符合规定裁定再审，不符合裁定驳回；因当事人申请裁定再审的案件由**中级以上法院审理**，但当事人选择向基层法院申请再审的除外。
> - **第216条【期限】**：判决、裁定**生效后六个月内**提出；有第211条**第(一)、(三)、(十二)、(十三)项**情形的，自**知道或者应当知道之日**起六个月内提出。
> - **第217条【中止执行】**：决定再审的案件裁定中止原判决、裁定、调解书的执行，但追索赡养费、扶养费、抚养费、抚恤金、**医疗费用**、劳动报酬等案件，**可以不中止执行**。
> - **第218条【再审审理程序】**：原生效裁判系**一审**作出→按一审程序审理，所作裁判**可以上诉**；系**二审**作出→按二审程序，所作裁判**生效**；上级法院**提审**→按二审程序，生效。审理再审案件**应当另行组成合议庭**。
> - **《民诉法解释》（法释〔2022〕11号修正）**：§377（双方分别向原审和上一级申请、不能协商一致→**原审受理**）、§378（**非讼程序**案件不得申请再审）、§379（不予受理、驳回起诉裁定**可以**申请再审）、§381（驳回后再申请／对再审裁判申请／检察院处理后又申请→**不予受理**，前两项告知可找检察院）、§382（调解书再审=生效后**六个月**）、§385II+§386（再审新证据须**责令说明逾期理由**且理由限**客观原因**）、§424（**小额诉讼**裁判向**原审法院**申请再审）、§276（小额诉讼**管辖异议裁定一经作出即生效**）。
> - 官方全文：[民诉法2023 PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [民诉解释（flk.npc.gov.cn 国家法律法规数据库检索"最高人民法院关于适用《中华人民共和国民事诉讼法》的解释"）](https://flk.npc.gov.cn/) · [民诉解释全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)

> ⚠️ **诚实标注**：①以上民诉法§13/§165/§166/§169/§209-§222/§250、民诉解释§276-§277/§373-§400/§420-§424 均已在本地官方全文（ssf.gov.cn 版民诉法2023、民诉解释2022）中**逐条 grep 核到原文**。②**条号新旧对照陷阱**：民诉解释制定于2022年（基于2021版民诉法），其条文内部引用的"民事诉讼法第二百零六条/第二百零七条/第二百零八条"均为**旧条号**，对应**2023现行版第210/211/212条**（整体+4偏移）；读解释原文时务必换算，切勿把解释里的"207条"当成现行207条（现行207条是"申请实现担保物权"）。③"再审利益""再审审查听证"在民诉法和民诉解释中**无逐字明文**，系学理＋诚信原则（§13）＋审判监督实践的命题人立场（真题卡227/228即按此命题，其中228卡标注 answer_confidence: MEDIUM）。④各真题卡"来源"中的"20XX金题-X-X-XX"编号系题库自带标注、未经独立核验，本模型出处只认题库文件。
>
> ⚠️ **易记错点**：①**"一审终审"≠"不能再审"**——小额诉讼判决不能上诉，但可以以法定事由（或"不应按小额审理"为由）向**原审法院**申请再审（解释§424）；②**六个月的两种起算**——一般事由自裁判**生效**起算，仅第(一)(三)(十二)(十三)项【新证据、伪造、文书被撤销、枉法裁判】自**知道或应当知道**起算，"剥夺辩论权""未经传票传唤"等程序事由**不在**特殊起算之列；③**管辖错误不是再审事由**（2012年修法已删除），十三项清单里没有它；④**调解书的救济只有再审一条路**（违反自愿/内容违法+六个月内），没有"撤销调解书之诉"，也没有"确认调解书无效之诉"；⑤申请再审**不停止执行**（§210），裁定再审后才**中止执行**（§217），且追索医疗费用等案件可以不中止；⑥"三个月"是**法院审查期限**（§215），"二年"是**申请执行期间**（§250），都不是申请再审期限。

## 二、 判别模型（对象 → 法院 → 期限 → 事由 → 利益）

```
        【生效裁判出炉：判决 / 裁定 / 调解书】
                       │
   ▼ 第一关：这个裁判"能不能"申请再审？（对象+负面清单）
   │
   ├─ 生效判决、裁定（含不予受理/驳回起诉裁定·解释§379）──→ 可以（§210）
   ├─ 生效调解书 ──→ 可以，但门槛更高：须举证"违反自愿 或 内容违法"（§212）
   ├─ 解除婚姻关系的判决、调解书 ──→ ❌ 不得再审（§213；财产分割部分可审·解释§380）
   ├─ 特别程序/督促/公示催告/破产等非讼案件 ──→ ❌ 不得再审（解释§378）
   ├─ 驳回再审申请后再次申请 / 对再审判决裁定申请 / 检察院处理后又申请
   │        ──→ ❌ 不予受理，前两种告知找检察院（解释§381）
   └─ 小额诉讼判决（一审终审）──→ ✅ 仍可再审，向原审法院（解释§424）
                       │
   ▼ 第二关：向哪个法院申请？（§210 + 解释§377/§424）
   │
   ├─ 原则：向上一级法院（233题：双方是公司→只能找上一级）
   ├─ 例外可选原审：一方人数众多 或 双方均为公民
   ├─ 双方分别向原审+上一级申请、协商不成 ──→ 原审法院受理（229/230题）
   └─ 小额诉讼 ──→ 向原审法院
                       │
   ▼ 第三关：期限过了没有？（§216 + 解释§382）
   │
   ├─ 一般事由：裁判生效之日起 6 个月
   ├─ 特殊起算【(一)新证据 (三)伪造 (十二)文书被撤销 (十三)枉法裁判】：
   │        自知道或应当知道之日起 6 个月
   ├─ 调解书：生效后 6 个月（解释§382）
   └─ 混淆项：3个月=法院审查期限（§215）；2年=申请执行期间（§250）
                       │
   ▼ 第四关：有没有十三项法定事由？（§211，分四组记）
   │
   ├─ 证据组(一)~(五)：新证据/基本事实缺证/伪造/未质证/申请调查未调查
   ├─ 实体组(六)(十一)(十二)：法律适用错误/遗漏超出诉请/依据文书被撤销
   ├─ 程序组(七)~(十)：审判组织·回避/无行为能力人未代理·应参加未参加/
   │                    剥夺辩论权/未经传票传唤缺席判决
   ├─ 行为组(十三)：审判人员贪污受贿、徇私舞弊、枉法裁判
   └─ ❌ 管辖错误：不在清单内（362题A项陷阱）
                       │
   ▼ 第五关：申请人有没有"再审利益"？守不守诚信？（学理+§13）
   │
   ├─ 全部胜诉+曾主张维持原判 ──→ 无再审利益，驳回（227题）
   ├─ 对不利部分未上诉，二审因对方上诉维持 ──→ 命题人立场：无再审利益，驳回（228题）
   └─ 自己隐匿证据、躲避送达，事后以"未送达/新证据"申请 ──→ 违反诚信，不予受理（226题）
                       │
   ▼ 通关后：审查与审理
   │
   ├─ 审查：3个月内裁定再审或驳回（§215）；可询问当事人、组织听证；
   │        新证据须责令说明逾期理由，理由限客观原因（解释§385II/§386）
   ├─ 裁定再审 → 中止执行（追索医疗费用等可不中止·§217）
   └─ 审理：原一审生效→按一审程序·可上诉；原二审生效/提审→按二审程序·生效；
            一律另行组成合议庭（§218）
```

> **一句话总诀**：**「判决裁定敞开审、调解书举证审、婚姻非讼不再审；找法院原则上一级、双方公民可回原审、分头申请归原审、小额只回原审；期限六个月、四类特殊从知道起算；事由十三项、管辖错误不在场；赢家没有再审份、耍赖诚信一票否」**

## 三、 高频干扰选项

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **一审终审=不能再审** | 小额诉讼实行一审终审，判决不得申请再审。 | **❌ 错！**一审终审只是**不能上诉**；当事人以§211事由或"不应按小额审理"为由**向原审法院**申请再审的，法院应当受理（解释§424）。360题D即此坑。 |
| **起算点偷换** | 以"剥夺辩论权/未经传票传唤"申请再审，自知道之日起六个月。 | **❌ 错！**特殊起算仅限第**(一)(三)(十二)(十三)**项四类；程序组事由一律自**裁判生效**起算（§216）。232题甲8个月后申请即超期。 |
| **管辖错误混入事由** | 原审管辖错误的，当事人可以申请再审。 | **❌ 错！**十三项清单中**没有管辖错误**；管辖问题的救济是管辖异议+对管辖裁定上诉（362题A）。 |
| **给调解书造新救济** | 调解书显失公平可申请撤销／可起诉确认调解书无效。 | **❌ 错！**调解书救济**只有再审**（违反自愿或内容违法，§212），且限生效后六个月（解释§382）；不存在撤销之诉、确认无效之诉（231题A/D）。 |
| **数字混搭** | 申请再审期限为三个月／一年／二年。 | **❌ 错！**申请再审=**6个月**（§216）；3个月是法院**审查**期限（§215）；2年是**申请执行**期间（§250）（361题）。 |
| **申请即停止执行** | 当事人申请再审的，停止原判决的执行。 | **❌ 错！**申请再审**不停止执行**（§210末句）；**裁定再审后**才中止执行，且追索赡养费、医疗费用、劳动报酬等案件**可以不中止**（§217，176题D）。 |
| **谁先申请谁的法院管** | 双方分别向原审和上一级申请再审的，由最先受理的法院/上一级法院受理。 | **❌ 错！**双方为公民（或一方人数众多）分别向原审和上一级申请、**协商不成的由原审法院受理**（解释§377，229/230题）。 |

## 四、 相邻制度对照

**（1）上诉 vs 申请再审 vs 申请检察监督（三级救济链）**

| 事项 | 上诉 | 申请再审 | 申请检察建议/抗诉（§220） |
|---|---|---|---|
| 针对对象 | **未生效**的一审判决、裁定（仅限可上诉裁定） | **已生效**判决、裁定、调解书 | 法院**驳回再审申请**／**逾期未裁定**／**再审裁判有明显错误** |
| 期限 | 判决15日、裁定10日 | 6个月（四类特殊事由自知道起算） | 法律未设申请期限；检察院3个月内审查，**不得再次申请** |
| 是否需要法定事由 | 不需要（不服即可上诉） | 需要（§211十三项 / §212调解书两事由） | 需要（先穷尽再审申请这条路） |
| 效力 | 阻断生效，引起二审 | 不停止执行；裁定再审后中止执行 | 抗诉→法院30日内裁定再审（§222） |
| 定位 | 审级内常规救济 | 生效后特殊救济（非独立审级，360题A） | 救济链的最后一环 |

**（2）判决/裁定 vs 调解书 再审门槛对照**

| 事项 | 生效判决、裁定 | 生效调解书 |
|---|---|---|
| 法条 | §210+§211 | §212 |
| 事由 | 十三项法定事由 | 仅两项：**调解违反自愿原则**／**调解协议内容违反法律**，且须**提出证据证明** |
| 期限 | §216六个月（含特殊起算） | 生效后六个月（解释§382），**无**特殊起算的明文优待 |
| 负面清单 | 解除婚姻关系判决不得再审（§213） | 解除婚姻关系调解书同样不得再审（§213） |
| 检察监督 | §211情形可抗诉/检察建议（§219） | 仅**损害国家利益、社会公共利益**时检察院才出手（§219） |

## 五、 万能五步答题模型

*   🚗 **统一案例**：甲（公民）诉乙（公民）民间借贷，请求还款10万元。A区法院一审判决乙偿还8万元、驳回甲其他诉讼请求。双方均未上诉，判决于2026年1月10日生效。此后围绕这份生效判决，甲、乙各有算盘。

### 第一步：判对象——这份裁判"够格"被再审吗？

> **判裁调解能申请，婚姻非讼再审免**

#### 概述

申请再审的大门只对**已经发生法律效力**的裁判敞开，且不同文书门槛不同：

- **生效判决、裁定**：认为有错误即可申请（§210）；**不予受理、驳回起诉的裁定**也可以（解释§379）；
- **生效调解书**：门槛更高——必须**提出证据证明**"调解违反自愿原则"或"调解协议内容违反法律"（§212）；
- **负面清单**（申请了也白申请）：
	- **解除婚姻关系**的判决、调解书（§213）——离婚了就不能通过再审"复婚"，但**财产分割部分**仍可依§211审查，未处理的夫妻共同财产则另行起诉（解释§380）；
	- **非讼程序**案件：特别程序、督促程序、公示催告程序、破产程序等（解释§378）；
	- **再审申请被驳回后再次申请**、**对再审判决/裁定申请**、**检察院已作不建议/不抗诉决定后又申请**——不予受理，前两种法院告知可向检察院申请检察建议或抗诉（解释§381）；
- **小额诉讼判决**：一审终审、不能上诉，但**可以**向原审法院申请再审（解释§424）——"一审终审"关掉的是上诉的门，不是再审的门。

#### 大白话讲解

判决生效后，乙琢磨着翻案，先得看看手里这份文书"能不能"再审：

- 本案是**普通生效判决**——门是开的，乙只要有法定事由就能申请。
- 假如当年这案子是**调解结案**：乙就不能只喊"我反悔了"，必须**拿出证据**证明当时被胁迫（违反自愿）或者调解内容违法，才够格申请。
- 假如这是甲乙的**离婚判决**：身份关系部分**永远关门**——不能靠再审把"离了"改成"没离"；但如果争的是判决里已分割的房子，财产部分还能审。
- 假如这是一个**支付令**（督促程序）或者宣告失踪（特别程序）：非讼案件**不得申请再审**。
- 假如这是**小额诉讼**判的：乙不能上诉，但**能回原审A区法院申请再审**——360题的坑"小额诉讼判决不得申请再审"就错在这里。

对号入座表：

| 文书类型 | 能否申请再审 | 门槛/去处 |
|---|---|---|
| 生效判决、裁定（含不予受理/驳回起诉裁定） | ✅ | §211十三项事由 |
| 生效调解书 | ✅ 但更难 | 举证"违反自愿/内容违法"（§212） |
| 解除婚姻关系的判决、调解书 | ❌ | §213；财产分割部分除外（解释§380） |
| 非讼程序案件（特别/督促/公示催告/破产） | ❌ | 解释§378 |
| 再审裁判、被驳回后重复申请 | ❌ 不予受理 | 解释§381→转向检察院 |
| 小额诉讼判决 | ✅ | 向原审法院（解释§424） |

#### 一句话闭环记忆

> 🎯 **一眼判**：判决裁定敞开审、调解书举证审、婚姻非讼再审裁判不再审、小额诉讼回原审——先验"对象够不够格"，不够格连事由都不用看。

### 第二步：判法院——向谁递再审申请书？

> **原则上一级，双公民可原审，分头申请归原审**

#### 概述

§210 把再审管辖分成"原则+例外"：

- **原则**：向**上一级**人民法院申请再审；
- **例外**（二选一自由）：**当事人一方人数众多**或**当事人双方为公民**的案件，**也可以**向原审法院申请；
- **冲突规则**（解释§377）：符合例外条件的案件，双方**分别**向原审法院和上一级法院申请、**不能协商一致**的，由**原审法院**受理；
- **小额诉讼**：只向**原审法院**申请（解释§424）；
- 配套：因当事人申请裁定再审的案件由**中级以上法院审理**，但当事人选择向基层法院申请再审的除外（§215II）。

#### 大白话讲解

甲、乙都是自然人（公民），这案子是A区法院一审生效——乙有两个选项：**向上一级B市中院**申请，或者**回原审A区法院**申请，随他挑（176题C项"只能向二审法院"就错在没看见这个例外）。

**变体一（233题场景）**：如果甲乙换成**甲公司、乙公司**——不是"双方为公民"，例外关闭，乙公司**只能向上一级B市中院**申请，不能回A区法院。

**变体二（229/230题场景）**：甲跑去B市中院申请，乙同时回A区法院申请，俩人各不相让——先让他们**协商**；协商不成，**由原审A区法院受理**。不是中院优先、不是谁先立案归谁、也不用上级指定。

**变体三（183题场景）**：如果本案是小额诉讼判的——乙只能回**原审A区法院**申请再审，跑去中院就走错门了。

| 场景 | 向哪申请 |
|---|---|
| 双方为公民／一方人数众多 | 上一级 或 原审，二选一 |
| 其他案件（如双方为公司） | 只能上一级 |
| 双方分头申请（原审+上一级）协商不成 | 原审法院受理（解释§377） |
| 小额诉讼裁判 | 原审法院（解释§424） |

#### 一句话闭环记忆

> 🎯 **一眼判**：先看当事人身份——双方公民/一方人数众多才有"回原审"选项；分头申请谈不拢，一律归原审；小额诉讼只认原审；公司打官司，再审找上级。

### 第三步：判期限——六个月从哪天起算？

> **一般生效起算六个月，新伪撤枉从知道**

#### 概述

§216 只有一个数字（六个月），但有**两种起算点**：

- **一般事由**：自判决、裁定**发生法律效力之日**起六个月内；
- **四类特殊事由**——第211条**第(一)项新证据、第(三)项主要证据伪造、第(十二)项据以裁判的法律文书被撤销或变更、第(十三)项审判人员枉法裁判**：自**知道或者应当知道之日**起六个月内；
- **调解书**：生效后六个月内（解释§382）；
- 超期的后果：法院**径行裁定驳回**，不再审查事由是否成立（解释§393II"超过法定申请再审期限……应当裁定驳回再审申请"）。

三个易混数字：**6个月=申请再审期限（§216）；3个月=法院审查期限（§215）；2年=申请执行期间（§250）**。

#### 大白话讲解

判决2026年1月10日生效，乙的"再审倒计时"怎么算？

- 乙想拿**"开庭时法院不让我充分辩论"**（第九项·剥夺辩论权，程序组）说事：这是**一般事由**，从1月10日生效日起算6个月，**7月10日**就是死线。如果乙拖到9月才申请（生效8个月后），**超期，直接驳回**，法院连"你到底有没有被剥夺辩论权"都不看了——这正是232题里甲公司的翻车现场。
- 乙如果在2026年5月20日才**发现一份足以推翻原判的新证据**（第一项，特殊事由）：从**5月20日知道之日**起算6个月，到11月20日都来得及——虽然距判决生效早已过了6个月。232题里乙公司"2个月前发现新证据"没超期，就是这个道理；但别忘了配套动作——法院还要**责令乙说明逾期提供证据的理由**（解释§385II），且理由必须是**客观原因**（解释§386）。
- 假如当年是**调解结案**、乙主张受胁迫（231题场景）：受胁迫=违反自愿，本可再审，但期限是**调解书生效后6个月**——石某拖到1年后才喊胁迫，**超期，再审无门**；后遗症新花的4万元手术费是调解没处理的**新账**，另案起诉去。

**特别提醒**：特殊起算的四项口诀"**新、伪、撤、枉**"（新证据/伪造/文书被撤销/枉法裁判）——注意"未经传票传唤""剥夺辩论权"这些**程序组事由不在其中**，命题人最爱把它们伪装成"自知道起算"。

#### 一句话闭环记忆

> 🎯 **一眼判**：一律六个月；"新伪撤枉"四项从**知道**起算，其余（含全部程序事由）从**生效**起算；超期=径行驳回不看事由；3个月是审查、2年是执行，都不是再审期限。

### 第四步：判事由——十三项清单对号入座

> **证据五实体三，程序四加行为一，管辖错误不沾边**

#### 概述

§211十三项事由按"错在哪"分四组记：

| 分组 | 项号 | 内容 |
|---|---|---|
| **证据组** | (一)~(五) | 新证据足以推翻；基本事实缺乏证据证明；主要证据**伪造**；主要证据**未经质证**；书面申请调查收集证据而法院未调查收集 |
| **实体组** | (六)(十一)(十二) | 适用法律确有错误；**遗漏或超出**诉讼请求；据以裁判的法律文书被**撤销或变更** |
| **程序组** | (七)~(十) | 审判组织不合法/应回避未回避；无诉讼行为能力人未经法代代为诉讼、应当参加的当事人因不可归责事由未参加；**剥夺辩论权利**；**未经传票传唤，缺席判决** |
| **行为组** | (十三) | 审判人员审理**该案件**时贪污受贿、徇私舞弊、枉法裁判（须经生效刑事法律文书或纪律处分决定确认——解释§392） |

清单是**封闭**的：**管辖错误不在其中**（2012年修法删除）；"未经质证"以当事人未被给予质证机会为准——**拒绝发表**质证意见的不算（解释§387）。

#### 大白话讲解

乙翻遍案卷找再审理由，逐项对号：

- **"当年开庭，法院只用电话通知我，我没到庭就被缺席判决了"**——简易程序用电话等**简便方式传唤**本身合法，但**缺席判决必须以传票传唤为前提**；只打电话就缺席判决=第(十)项"未经传票传唤，缺席判决"，**成立**（176题B）。
- **"我发现甲提交的借条是伪造的"**——第(三)项，**成立**，而且从知道之日起算6个月（第三步已述）。
- **"这案子本该D区法院管，A区法院管错了"**——**清单里没有管辖错误**，不成立（362题A）。管辖问题当年就该提管辖异议、对裁定上诉，过了村没这店。
- **反面教材（226题场景）**：如果乙当年**自己藏起关键账簿**、法院责令提供拒不提供，又**躲得法院联系不上**只能公告送达——公告送达**合法**，缺席判决**没毛病**，不构成第(十)项；那本自己藏的账簿现在"找到了"也**不是新证据**（主观原因逾期，不符合解释§386的客观原因要件）；再拿这两条申请再审，**违反诚信原则，不予受理**。

#### 一句话闭环记忆

> 🎯 **一眼判**：十三项＝证据五（新证据/缺证/伪造/未质证/未调查）＋实体三（法律错/遗漏超出/依据文书被撤）＋程序四（组织回避/未参加/剥辩论/无传票缺席判）＋行为一（枉法裁判）；见"管辖错误"必错；自己造成的"未送达/新证据"被诚信原则一票否决。

### 第五步：判再审利益——这个人配申请再审吗？

> **裁判于我不利才有份，赢家反口诚信拦**

#### 概述

事由齐了、期限没过，还有最后一道人的关口——**再审利益**：申请再审的当事人必须是**因生效裁判受不利益**的一方。这在民诉法中无逐字明文，是学理＋诚信原则（§13"民事诉讼应当遵循诚信原则"）支撑的**命题人立场**，近年反复入题：

- **全部胜诉方**申请再审：判决对他有利，**无再审利益**——尤其他还在二审亲口主张过"维持原判"，事后反口更违反诚信，**裁定驳回**（227题）；
- **部分败诉但未上诉方**：对被驳回部分当时不上诉（视为接受），二审因对方上诉维持原判后才申请再审——命题人立场：**无再审利益，驳回**（228题，学理有争议，答案卡标注 MEDIUM，考试按命题人立场走）；
- **配套程序点**：审查再审申请时法院**可以询问当事人**（§214、解释§395），争议大的案件可**组织听证**（审判监督实践通行做法，无逐字法条）；对方当事人在审查期间也申请再审的，**列为再审申请人一并审查、审查期限重新计算**（解释§396）。

#### 大白话讲解

回到统一案例算细账：一审判乙还甲8万元、驳回甲多要的2万元，双方都没上诉。

- **乙**（被判还钱的人）：判决让他掏8万，**受不利益**，有再审利益——事由、期限过关就能审。
- **甲**呢？他要10万只判了8万，被驳回2万那部分**他当时没上诉**。现在甲以"事实认定错误"申请再审想把2万找回来——命题人立场：该上诉时不上诉等于接受，**再审不是上诉的补票窗口**，无再审利益，**驳回**（228题）。
- **升级版（227题场景）**：假如一审甲**全胜**（10万全判了），乙上诉，甲还在二审说"一审判得对，请维持"，二审维持原判。事后甲又以"利息算错了、我该拿更多"申请再审——赢家+亲口认可判决+反口，**无再审利益＋违反诚信，驳回**。"院长同意""对方同意"都救不了他：再审靠**法定事由**启动，不靠谁点头。

#### 一句话闭环记忆

> 🎯 **一眼判**：判决对你**不利**才有再审利益；全胜方、对不利部分未上诉方申请再审=驳回；再审审查可询问、可听证；再审不是"后悔药"，更不是没上诉的"补票口"。

## 六、 易混考点辨析

*   **"一审终审" vs "不得申请再审"**：
    *   小额诉讼判决、二审判决都是"生效即终审"，但**都可以申请再审**；真正"不得申请再审"的只有：解除婚姻关系裁判（§213）、非讼案件（解释§378）、再审裁判本身（解释§381）。
*   **小额诉讼的两个"即生效"**：
    *   小额诉讼**管辖异议裁定**一经作出即生效、不能上诉（解释§276）；**判决**一审终审、不能上诉但可向原审申请再审（解释§424）。再审后所作裁判：以§211事由再审的**不得上诉**；以"不应按小额审理"为由再审的**可以上诉**（解释§424两款之别）。
*   **申请再审"不停止执行" vs 裁定再审"中止执行"**：
    *   §210：**申请**阶段不停止执行；§217：**裁定再审**后中止原裁判执行——但追索赡养费、扶养费、抚养费、抚恤金、医疗费用、劳动报酬等案件**可以不中止**。
*   **再审按什么程序审（§218）**：
    *   原生效裁判是**一审**作出（如原审A区法院自己再审）→按**一审程序**，新裁判**可上诉**；原生效裁判是**二审**作出、或**上级法院提审**（如中院把区法院的一审生效判决提上来）→按**二审程序**，新裁判**即生效**。一律**另行组成合议庭**。
*   **再审申请的"诉"的性质**：
    *   请求撤销、改判生效裁判＝请求法院**变动既有裁判状态**＝**形成之诉（变更之诉）**，不是单纯的确认之诉或给付之诉（225题）。
*   **民诉解释旧条号 vs 民诉法2023新条号**：
    *   解释原文里的"民诉法第206/207/208条"＝现行**第210/211/212条**（解释基于2021版起草，整体+4）；做题引法条一律以2023版新条号为准。

## 七、 命题陷阱清单

1.  **"小额诉讼判决不得申请再审"** —— 错！一审终审只堵上诉，不堵再审；向原审法院申请（解释§424，360题D、183题）。
2.  **"以剥夺辩论权/未经传票传唤为由申请再审，自知道之日起算六个月"** —— 错！特殊起算仅限"新、伪、撤、枉"四项（§216），程序事由自生效起算；生效8个月后再提=超期径行驳回、不审查事由（232题）。
3.  **"原审管辖错误可以申请再审"** —— 错！管辖错误不在十三项清单（362题A）。
4.  **"调解书显失公平可申请撤销/可诉请确认无效"** —— 错！调解书救济只有再审一途（违反自愿或内容违法+生效后6个月），超期只能认；调解未处理的新损害可另行起诉（231题）。
5.  **"双方分别向原审和上一级申请再审，由上一级/最先受理的法院受理"** —— 错！协商不成由**原审法院**受理（解释§377，229/230题）。
6.  **"双方为公司的案件也可以向原审法院申请再审"** —— 错！"可选原审"仅限一方人数众多或**双方为公民**；公司只能向上一级（§210，233题）。
7.  **"胜诉方发现判决瑕疵也可申请再审／对方同意即可再审"** —— 错！无再审利益应驳回；再审以法定事由启动，不因院长同意、对方同意而启动（227/228题）。
8.  **"自己保管拒不提供的证据，事后'找到'构成再审新证据"** —— 错！主观原因逾期不是新证据（解释§386），加上躲避送达再喊"未送达"，违反诚信原则不予受理（226题）。
9.  **"申请再审即停止执行／裁定再审后医疗费案件也必须中止执行"** —— 双错！申请不停止执行（§210）；裁定再审后中止，但医疗费用等六类可不中止（§217，176题D）。
10. **"上级法院提审按一审程序审理、所作判决可上诉"** —— 错！提审和对二审生效裁判的再审都按**二审程序**、裁判即生效；只有原一审法院对自家一审生效裁判再审才按一审程序、可上诉（§218，233题）。
