# 📐 证据种类与形式 · 完整答题模型（八种法定种类 + 三对理论分类 + 书证提出命令 + 证人 + 鉴定与专家辅助人）

> **核心一句**：证据题先问**"这是八种里的哪一种"**（形式定性），再问**"它在本案中扮演什么角色"**（本证/反证、直接/间接、原始/传来三对独立维度），然后按证据形式各走各的特别规则——**书证走"原件+公文推定+提出命令"，人证走"资格+出庭+保证书"，专业意见走"鉴定人刚性出庭 vs 专家辅助人视为当事人陈述"**。最毒陷阱是**电子数据与视听资料的划界**（原生数字信息如短信/微信/交易记录/数码照片＝电子数据；录音录像资料本体是视听资料，存储在电子介质中的**适用电子数据的规定**）、**把"复印件"说成没有证据能力**、**把证人资格与年龄/行为能力挂钩**、**把鉴定人拒不出庭的后果说成"仅影响证明力"**（实为不得作为认定根据+退费）、**把专家辅助人意见当成第九种证据**（视为当事人陈述）。
>
> 🔎 **核心条文速查**：
> - **《民事诉讼法》（2023修正）第66条【八种证据种类】**：证据包括：（一）**当事人的陈述**；（二）书证；（三）物证；（四）视听资料；（五）电子数据；（六）证人证言；（七）鉴定意见；（八）勘验笔录。证据必须**查证属实**，才能作为认定事实的根据。
> - **第73条【原件原物】**：书证应当提交**原件**，物证应当提交**原物**；提交确有困难的，可以提交复制品、照片、副本、节录本。外文书证必须附中文译本。
> - **第75条【证人资格】**：凡是知道案件情况的**单位和个人**，都有义务出庭作证；**不能正确表达意思的人，不能作证**。
> - **第76条【出庭例外】**：经法院许可，因①健康原因②路途遥远交通不便③自然灾害等不可抗力④其他正当理由不能出庭的，可以通过书面证言、视听传输技术或者视听资料等方式作证。第77条【证人费用】：由**败诉一方**当事人负担。
> - **第79条【鉴定启动】**：当事人可就专门性问题申请鉴定，由**双方协商**确定鉴定人，协商不成的由**法院指定**；当事人未申请而法院认为需要的，应当委托鉴定。
> - **第81条【鉴定人拒不出庭】**：当事人对鉴定意见有异议或法院认为必要的，鉴定人**应当出庭**；经通知**拒不出庭**的，鉴定意见**不得作为认定事实的根据**，支付鉴定费用的当事人**可以要求返还鉴定费用**。
> - **第82条【专家辅助人】**：当事人可以申请法院通知**有专门知识的人**出庭，就鉴定意见或者专业问题提出意见。
> - **《民诉法解释》（法释〔2022〕11号修正）§112【书证提出命令】**：书证在**对方当事人控制之下**的，负举证责任方可在举证期限届满前**书面申请**责令提交；对方**无正当理由拒不提交**的，法院可以**认定申请人所主张的书证内容为真实**。§113：以妨碍对方使用为目的**毁灭书证**的，可**罚款、拘留**。§114【公文书证推定】：国家机关等在职权范围内制作的文书记载事项**推定为真实**，有相反证据足以推翻的除外。§116【定义条款】：视听资料包括录音资料和影像资料；电子数据指通过电子邮件、网上聊天记录、博客、手机短信、电子签名、域名等形成或**存储在电子介质中的信息**；**存储在电子介质中的录音、影像资料，适用电子数据的规定**。§119-120【保证书】：证人作证前应签署保证书（无/限制民事行为能力人除外）；**拒绝签署的不得作证**并自担费用。§122-123【专家辅助人】：可申请**一至二名**出庭；其意见**视为当事人的陈述**；可对质；**不得参与专业问题之外的法庭审理活动**。
> - **《民事诉讼证据规定》（法释〔2019〕19号）§14**：电子数据五类清单（网络平台信息/通信信息/**电子交易记录**等记录信息/文档图片音频视频等电子文件/其他数字化信息）。§15：视听资料提供**原始载体**；电子数据提供原件，一致副本、直接来源的打印件**视为原件**。§47：应当提交书证的五种情形（曾引用/为对方利益制作/对方有权查阅获取/**账簿、记账原始凭证**/其他）。§48：拒不提交→认定对方主张的**书证内容**为真实。§67：不能正确表达意思的人不能作为证人。§81：鉴定人拒不出庭→不得作为根据+**3日内裁定责令退还鉴定费**+申请**重新鉴定应当准许**。§91：公文书证**副本与正本具有相同证明力**。
> - 官方全文：[民诉法2023（ssf.gov.cn PDF，已核验）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条文号均已逐条 grep 本库已核验的官方全文（民诉法2023 ssf.gov.cn PDF转文本、民诉解释2022 ssf.gov.cn PDF转文本、证据规定2019全文），未凭记忆写入任何条号。**理论分类（本证/反证、直接/间接、原始/传来）系学理概念，法条并无定义条文，本模型不为其虚标条号**。特别提示：《证据规定》（2019）文内引用的"民事诉讼法第七十八条（鉴定人出庭）、第七十九条（有专门知识的人）"是**2017年旧法条号**，对应**2021/2023现行法的第81条、第82条**——引用时以现行法条号为准，勿被司法解释原文里的旧条号带偏。

> ⚠️ **易记错点**：①**电子数据 vs 视听资料要分两条线记**：短信、微信、电子交易记录、数码照片等**原生数字信息**依证据规定§14清单定性为**电子数据**；而"录音资料、影像资料"这一形态本身是**视听资料**（解释§116第1款），存储在电子介质中的录音影像**适用电子数据的规定**（第3款，系**准用规则条款**）——本库真题卡对"手机通话录音"存在两种定性口径（单366/单99按"录音＝视听资料"、多386按"数字化音视频归电子数据"），做题时**跟题眼与选项对比走**，唯一确定安全的是：录音带/录像带＝视听资料、微信记录/交易记录/数码照片＝电子数据；②**八种证据种类首位是"当事人的陈述"**，不是书证——排序题常考；③**复印件有证据能力**（可以作为证据提交），只是证明力须结合原件核对或其他证据审查，"复印件没有证据能力/当然没有证明力"都是错句；④**证人资格唯一消极条件＝不能正确表达意思**，与年龄、民事行为能力、利害关系统统无关；利害关系证人证言、与年龄智力不相当的未成年人证言只是"**不能单独定案**"，不是"没有证明力"；⑤**证人不适用回避、专家辅助人也不适用回避**——回避只管审判人员及参照适用的辅助人员（技术调查官参照适用回避）；⑥**鉴定人拒不出庭＝鉴定意见直接作废（不得作为认定根据）+退还鉴定费+重新鉴定应准许**，不是"由法官酌情判断证明力"；⑦**专家辅助人的意见"视为当事人的陈述"**——落入八种种类的第一种，不是独立的第九种证据，更不是鉴定意见。

| 4-4 证人制度 | ★★★ | 资格（不能正确表达意思除外）、单位作证、出庭义务与四项例外、保证书、费用败诉方负担。 |
| 4-5 鉴定意见与专家辅助人 | ★★★★ | 鉴定依申请为主；鉴定人拒不出庭→不得作为根据+退费；专家辅助人意见视为当事人陈述。 |

- **2026时间锚**：客观题9/12-13，主观题10/18。民诉证据章以2019证据规定+2022民诉解释为规则主体，2023民诉法修正未动证据章实体规则，条号沿用66-84。
- **命题常见场景**：借贷/买卖纠纷里给出一组证据（借条、转账凭证、录音、照片、收条复印件、证人、单方鉴定报告），逐项让你**双重定性**（种类+分类）；或设置"原件在对方手里/被毁灭""证人是8岁小孩/公司会计""鉴定人不来开庭""教授出庭发表意见"等桥段考特别规则。

## 二、 五步判别模型（认形式 → 辨性质 → 书证特权 → 人证 → 专业意见）

```
                【一份证据材料摆在面前】
                        │
   ▼ 第一步：认形式——八种法定种类里的哪一种？（民诉法§66）
   │
   ├─ 靠"记载的内容"证明 ──→ 书证（含公证书、诉前单方鉴定报告）
   ├─ 靠"外形/质量/规格"证明 ──→ 物证
   ├─ 数字化形式存储（短信/微信/转账记录/数码照片/电子音视频）──→ 电子数据
   ├─ 模拟介质录音录像（录音带/录像带）──→ 视听资料
   ├─ 当事人自己说的（含专家辅助人意见"视为"）──→ 当事人的陈述
   ├─ 案外知情人陈述 ──→ 证人证言
   ├─ 法定程序委托的专门性问题意见 ──→ 鉴定意见
   └─ 法院勘验记录 ──→ 勘验笔录
                        │
   ▼ 第二步：辨性质——三对理论分类（学理，独立三维度）
   │
   ├─ 本证/反证：看"谁对该事实负举证责任"（不看原告被告）
   ├─ 直接/间接：看"能否单独直接证明待证事实"（转账凭证=间接）
   └─ 原始/传来：看"是否第一来源"（复印件=传来，但可同时是直接证据）
                        │
   ▼ 第三步：书证特权与提出命令（民诉法§73 + 解释§112-114 + 证据规定§45-48）
   │
   ├─ 原件规则：书证交原件、物证交原物，确有困难可交复制品等
   ├─ 公文书证：记载事项推定为真实（可推翻）；副本=正本证明力
   ├─ 书证在对方控制下 → 举证期限届满前书面申请提出命令
   │      └─ 无正当理由拒不提交 → 认定申请人主张的书证内容为真实
   └─ 毁灭书证妨碍使用 → 罚款/拘留（解释§113）+可认定所证事实为真
                        │
   ▼ 第四步：人证——证人的资格、出庭与保证书（民诉法§75-77）
   │
   ├─ 资格：能正确表达意思即可（年龄/行为能力/利害关系均非门槛）
   ├─ 出庭为原则；健康/路途/不可抗力/正当理由 → 经许可书面/视频作证
   ├─ 保证书：拒签不得作证；无/限制行为能力人作证免签
   └─ 费用：败诉一方负担；利害关系证言不能单独定案
                        │
   ▼ 第五步：专业意见——鉴定 vs 专家辅助人（民诉法§79-82）
   │
   ├─ 鉴定启动：依申请为主（协商定人→法院指定）；依职权仅限法定情形
   ├─ 鉴定人拒不出庭：意见不得作为认定根据 + 退还鉴定费 + 重新鉴定应准许
   ├─ 诉前单方委托报告：不是鉴定意见，定性为书证，对方申请鉴定应准许
   └─ 专家辅助人：1-2名，意见视为当事人陈述，不回避、可对质、费用申请方担
```

> **一句话总诀**：**「陈书物视电、证鉴勘八种排好队；数字归电、模拟归视、内容归书、外形归物；本反看责任、直间看单独、原传看源头；原件公文推定真，控制不交认内容，毁灭书证罚拘留；能表达就能作证，拒签保证书免谈，费用败诉埋单；鉴定人不出庭意见作废还退费，专家辅助人开口算当事人陈述」**

## 三、 高频干扰表（定性题的五个惯性坑）

命题人最爱在"种类定性"和"能力/证明力"两个层面偷换概念：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **数码照片/微信记录归视听资料** | 数码相机照片、微信聊天记录、电子转账凭证属于视听资料。 | **❌ 均为电子数据。**数码照片是"数字化形式存储的图片"（证据规定§14第4项），聊天记录、电子交易记录在§14第2、3项清单内。视听资料的安全样本只剩录音带、录像带等**模拟介质**；电子介质中的录音影像则**适用电子数据的规定**（解释§116第3款准用，定性口径题库有分歧，跟题眼走）。 |
| **公证书是独立一类/物证** | 公证机构对购物过程出具的公证书属于视听资料或独立证据种类。 | **❌ 公证书以其记载内容证明事实，是书证**（且系对所公证过程的转述，属**传来**证据）；公证证明的事实法院应作为认定根据，有相反证据足以推翻的除外（民诉法§72）。 |
| **复印件没有证据能力** | 未提供原件核对的复印件不具有证据能力/当然没有证明力。 | **❌ 复印件有证据能力**，属传来证据可以提交；只是证明力须与原件核对或结合其他证据审查（民诉法§73允许"提交原件确有困难的"交复制品）。"能力"与"证明力"是两个层面。 |
| **传来证据＝间接证据** | 收条复印件是传来证据，所以只能是间接证据。 | **❌ 三对分类相互独立。**收条复印件虽是传来证据，但其内容单独即可直接证明"已还款"，仍是**直接证据**。 |
| **鉴定人不出庭只影响证明力** | 鉴定人经通知未出庭的，鉴定意见由法官酌情判断证明力。 | **❌ 刚性后果三件套**（民诉法§81+证据规定§81）：不得作为认定事实的**根据**+当事人可要求**退还鉴定费**（3日内裁定）+申请**重新鉴定应当准许**。 |

## 四、 相邻制度对照表（鉴定人 · 专家辅助人 · 证人 · 技术调查官）

四种"帮法庭搞清事实的人"，规则各不相同，命题人最爱互相嫁接：

| 事项 | 鉴定人 | 专家辅助人（有专门知识的人） | 证人 | 技术调查官 |
|---|---|---|---|---|
| 产生方式 | 双方协商→协商不成法院指定（民诉法§79） | 当事人申请、法院通知，**1-2名**（解释§122） | 知道案情即有作证义务（民诉法§75） | 法院配备的审判辅助人员 |
| 意见/陈述定性 | **鉴定意见**（八种之一） | **视为当事人的陈述**（解释§122第2款） | 证人证言（八种之一） | 不是证据，属技术咨询辅助 |
| 是否适用回避 | 适用（参照审判人员） | **不适用** | **不适用** | **参照适用**审判人员回避规定 |
| 出庭义务 | 有异议或法院认为必要→**应当出庭**，拒不出庭意见作废+退费（民诉法§81） | 经准许出庭发表意见、可对质，**不得参与专业问题之外的审理活动**（解释§123） | 出庭为原则，四类正当理由经许可可书面/视频作证（民诉法§76） | 随法庭需要参与 |
| 费用负担 | 拒不出庭退费；出庭费用按证人标准由败诉方担（证据规定§39） | **申请方负担**（解释§122第3款） | **败诉一方负担**，申请方先行垫付（民诉法§77） | 不由当事人负担 |

> ⚠️ **易混条号**：鉴定人拒不出庭是**民诉法§81**（证据规定原文引的"第七十八条"是旧号）；专家辅助人是**民诉法§82**+解释§122-123；证人保证书在**解释§119-120**（民诉法本体无保证书条文）。

## 五、 万能五步答题模型

在法考答题中，拿到证据类题目按以下五步逐项涵摄：

*   🚗 **统一案例**：甲诉乙返还借款**10万元**。在案证据：①乙签字的**借条原件**；②甲的**微信转账记录**（10万元）；③双方**手机通话录音**（乙说"下月还你"）；④乙提交**收条复印件**称已还**6万元**，并称原件由甲控制；⑤乙公司会计**丙**目睹交款，乙申请其出庭；⑥乙否认借条签名真实，笔迹**鉴定**被启动；⑦乙申请笔迹学**王教授**出庭对鉴定意见发表意见。

### 第一步：认形式——先把每份证据放进八种里的对应格子

> **陈书物视电证鉴勘，数字归电内容归书**

#### 概述

《民诉法》第66条把证据形式**封闭列举**为八种：**当事人的陈述、书证、物证、视听资料、电子数据、证人证言、鉴定意见、勘验笔录**——注意**当事人的陈述排在第一位**，且任何证据都必须**查证属实**才能作为认定事实的根据。定性只看两条线：

- **书证 vs 物证**：靠**记载的内容**证明事实→书证；靠**外形、质量、规格等物理属性**证明→物证。同一张借条，用内容证明借款是书证，用纸张年代证明伪造时间则当物证用。
- **电子数据 vs 视听资料**：网页、短信、即时通信、电子交易记录、数码照片、电子文档音视频等**原生数字信息**依证据规定§14五类清单归**电子数据**；**视听资料＝录音资料+影像资料**（解释§116第1款），录音带、录像带等模拟介质是其安全样本；**存储在电子介质中的录音、影像资料，适用电子数据的规定**（第3款，准用条款——种类定性口径题库有分歧，做题跟题眼走）。
- 勘验笔录 
	- 法院工作人员诉讼中实地查验现场、物证形成的客观记录，为勘验笔录；私人自行拍摄记录不属于勘验笔录。
		- **民事诉讼的【勘验笔录】**：法定制作主体**只能是法院工作人员**。公安、检察院在民事案件里无权制作民诉意义上的勘验笔录。
		- **刑事诉讼**：侦查阶段由**公安、检察院侦查人员**制作**勘验、检查笔录**（刑诉证据种类）。

#### 大白话讲解

把统一案例的证据摆上桌逐个"过安检"：

| 证据      | 定性                 | 为什么                                                                           |
| ------- | ------------------ | ----------------------------------------------------------------------------- |
| ①借条原件   | **书证**             | 靠"今借到甲10万元"这行字的**内容**证明借贷                                                     |
| ②微信转账记录 | **电子数据**           | 电子交易记录/通信信息，数字化存储（证据规定§14）                                                    |
| ③手机通话录音 | **视听资料（适用电子数据规定）** | 录音资料形态本体属视听资料（解释§116第1款）；因存储在手机（电子介质）中，规则上**适用电子数据的规定**（第3款准用）——两种口径真题卡都有，看题眼 |
| ④收条复印件  | **书证**             | 仍靠记载内容证明还款，复印件不改变种类                                                           |
| ⑤丙的当庭陈述 | **证人证言**           | 案外知情人陈述亲历事实                                                                   |
| ⑥笔迹鉴定书  | **鉴定意见**           | 法定程序委托形成的专门性问题意见                                                              |
| ⑦王教授的意见 | **视为当事人的陈述**       | 专家辅助人意见的法定拟制（解释§122第2款），归入第一种                                                 |

如果乙翻出一盘2005年的**录像带**拍下交款过程——那才轮到**视听资料**出场。命题人最常用的三个易错样本：**手机录音（电子数据）、数码照片（电子数据）、公证书（书证）**。

#### 一句话闭环记忆

> 🎯 **一眼判**：原生数字信息（短信/微信/交易记录/数码照片）→电子数据；录音带录像带→视听资料；电子介质里的录音影像→**适用电子数据规定**（定性看题眼）；再问"靠内容还是外形？"——内容→书证、外形→物证；专家辅助人开口＝当事人陈述，八种之外没有第九种。

### 第二步：辨性质——三对理论分类，三个独立维度各判各的

> **本反看责任，直间看单独，原传看源头**

#### 概述

理论分类是**学理概念，无法条定义**，判断标准三句话：

- **本证/反证**：看**谁对该待证事实负举证责任**——负举证责任一方提出的是本证，对方为动摇法官心证提出的是反证。**与原告被告身份无关**：被告主张"已还款"（权利消灭事实）时，他的收条就是**本证**。
	- 如何区分 本证和反正
		- 第一步：先确定**这件事实，法律规定谁来证明（谁承担举证责任）**
		- 第二步：
			- **负有举证责任的人拿出证据证明事实成立 = 本证**
			- **没有举证责任的人拿出证据，削弱、推翻这件事实 = 反证**

	- 当事人自认了的证据,不作为反正, 比如, 乙提供了已经还款了证据, [[民诉-证据-单选-371 · 借条收条的本证反证与自认]]
	
- **直接/间接**：看该证据**能否单独、直接证明待证事实**——**借条、收条能，是直接证据**；**转账凭证只证明"钱到了"、证不了"借贷合意"**，是间接证据，须与其他证据形成锁链才能定案。

- **原始/传来**：看是否**第一来源**——原件、原物为原始证据；复印件、转述、证书等为传来证据。

三对维度**相互独立、不能互相推导**：传来证据可以同时是直接证据（收条复印件），间接证据可以同时是本证（原告的转账凭证）。

#### 大白话讲解

还是那10万元官司，同一堆证据换三副眼镜看：

**第一副眼镜（本证/反证）**：甲主张"借贷关系成立"，对此负举证责任——他的借条、转账记录都是**本证**。乙主张"已还6万"，"还款"是债务**消灭**事实，由**乙**负举证责任——所以乙的收条复印件是乙的**本证**（不是反证！很多人看到"被告提的"就喊反证，错）。真正的反证是：甲反过来说"那笔6万是乙还别的欠款"，用于**动摇**乙的还款主张。

**第二副眼镜（直接/间接）**：借条写明"借到10万"，单独即可证明借贷——**直接证据**；微信转账记录只能证明"10万从甲流向乙"，到底是借款、货款还是赠与它说不清——**间接证据**（哪怕它是本证）。收条复印件内容直指"已还6万"——**直接证据**（哪怕它是传来证据）。

**第三副眼镜（原始/传来）**：借条**原件**＝原始证据；收条**复印件**＝传来证据——但注意，传来≠不能用、更≠间接，它只是证明力上需核对原件或结合其他证据。

三副眼镜彼此不打架：**收条复印件＝乙的本证＋直接证据＋传来证据**，三个标签同时成立。

#### 一句话闭环记忆

> 🎯 **一眼判**：谁民事证据三对理论分类属于**学理概念，法律无条文定义，三个维度相互独立、不可互相推导**。
> 	- ①区分本证、反证：依据待证事实举证责任归属，负有举证责任一方提交的证据为本证，无举证责任一方用以动摇心证的证据为反证，与原被告身份无关；被告主张权利消灭事实提交的证据属于本证。
> 	
> 	- ②区分直接证据、间接证据：依据证据能否**单独、直接证明待证事实**；可独立证明为直接证据，不能单独证明、需要证据链佐证为间接证据，转账凭证仅能证明款项交付，永远属于间接证据。
> 	
> 	- ③区分原始证据、传来证据：依据证据来源，第一手原件、原物为原始证据；复印件、转述材料为传来证据。传来证据可以是直接证据，间接证据也可以构成本证；典型示例：收条复印件属于**本证、直接证据、传来证据**，
> 	
> 	三重属性同时成立。判断口诀：本反看举证责任，直间看能否单独定案，原传看是否一手来源。

### 第三步：书证特权与提出命令——原件在谁手里？不交怎么办？

> **原件公文推定真，控制不交认内容，毁灭书证罚拘留**

#### 概述

书证有一套自己的特别规则：

- **原件规则**（民诉法§73）：书证交**原件**、物证交**原物**；确有困难可交复制品、照片、副本、节录本；外文书证必须附中文译本。电子数据的"原件"放宽：制作者制作的一致副本、直接来源的打印件**视为原件**（证据规定§15）。

- **公文书证推定**（解释§114）：国家机关或依法具有社会管理职能的组织在**职权范围内**制作的文书，记载事项**推定为真实**，有相反证据足以推翻的除外；其**副本与正本证明力相同**（证据规定§91）。

	- 案例:  甲、乙因房屋买卖纠纷诉讼。乙提交税务局出具的**完税凭证副本**（公文书证），证明房屋交易税费已经缴纳。 该完税凭证属于公文书证，**直接推定记载内容真实**；反面对比：甲拿出物业公司自行出具的欠款证明。物业公司不属于公权力管理机关，属于私文书证，**不适用推定真实**，由甲证明这份证明内容属实。

- **书证提出命令**（解释§112+证据规定§45-48）：书证在**对方控制下**的，负举证责任方可在**举证期限届满前书面申请**法院责令提交；第四十七条 下列情形，控制书证的当事人应当提交书证：[[民事诉讼证据若干规定第47条书证提出命令适用范围解析]]

	- （一）控制书证的当事人在诉讼中曾经引用过的书证；
	- （二）为对方当事人的利益制作的书证；
	- （三）对方当事人依照法律规定有权查阅、获取的书证；
	- （四）账簿、记账原始凭证；
	- （五）人民法院认为应当提交书证的其他情形。
	
-  对方**无正当理由拒不提交**→书证控制人拒不提交，法院推定申请人所称书证记载内容为真实；仅推定文书文字内容，不直接推定案件事实，不得采取强制措施。

- 两个条件必须同时达标，才能启动书证提出命令 
	- 书证确实由对方掌控+ 这份书证落入《证据规定》47 条五类法定范围。 ，**不能申请书证提出命令**；
- 保密提示：书证涉及商业秘密、隐私，提交后**不得公开质证**；
- 程序硬性条件：举证期限届满前**书面申请**。


- **书证妨碍**（解释§113+证据规定§48第2款）：以妨碍对方使用为目的**毁灭书证**的→**罚款、拘留**，并可认定对方主张**以该书证证明的事实**为真实。

	- **普通拒不提交书证（书证提出命令）**：法院**推定【书证里面记载的内容】属实**。
	- **恶意毁灭书证（书证妨碍）**：法院**直接推定【这本书证想要证明的案件事实】成立**。

- "假扮消费者取证"是知识产权维权中常见的**取证方式**，未严重侵害他人合法权益、未违反法律禁止性规定或严重违背公序良俗，**不属非法证据、不应排除**

- 公证书是公证机构就其所公证的磋商过程制作的**书面文书** , 传来证据

- 当事人为达成调解／和解而作出妥协、认可的事实，**不得在其后的诉讼中作为对其不利的根据**。故不能据此认定借条真实[[民诉-证据-多选-106 · 认定借条真实的四种情形]]

#### 大白话讲解

乙手里只有收条**复印件**，说原件当年交还了甲、现在**在甲控制之下**。乙该怎么办？——在举证期限届满前**书面**向法院申请"书证提出命令"，写明书证名称内容、待证事实及其重要性、甲控制该书证的根据。

法院责令甲提交后出现三种剧情：

- **剧情A（乖乖交出）**：原件与复印件一致，"已还6万"坐实，甲只能再要4万。
- **剧情B（无正当理由拒不提交）**：法院可**认定乙主张的收条内容（已还6万）为真实**。注意分寸——后果是"认定**书证内容**为真"，不是抓人，也不是整案判甲败诉。
- **剧情C（甲当庭把收条原件撕碎吞了）**：这是以妨碍使用为目的**毁灭书证**——法院可对甲**罚款、拘留**（解释§113），并可认定乙主张以该收条证明的**还款事实**为真实。

再加一个对照：若乙提交的是**税务机关出具的完税凭证**——这是**公文书证**，记载事项直接**推定为真实**，甲想推翻得自己拿出足以推翻的相反证据；而且公文书证的**副本和正本证明力一样**，不苛求原件。

#### 一句话闭环记忆

> 🎯 **一眼判**：书证交原件（困难可交复制品）；公文书证推定真、副本＝正本；原件在对方手里→举证期限届满前**书面申请**提出命令，拒不提交→**认书证内容为真**；毁灭书证→**罚款拘留＋认所证事实为真**——两档后果层层加码，别混。

### 第四步：人证——谁能当证人？必须来吗？不签保证书行吗？

> **能表达即能作证，拒签保证书免谈，费用败诉埋单**

#### 概述

- **资格**（民诉法§75）：凡知道案件情况的**单位和个人**都有义务出庭作证（单位也可作证，其证明材料须负责人及制作人签章+单位盖章，解释§115）；**唯一**消极条件是"**不能正确表达意思**"（证据规定§67同）。年龄、民事行为能力、与当事人的利害关系**都不是资格门槛**——8岁孩子只要能正确表达就能作证；证人也**不适用回避**。利害关系证人的证言、与年龄智力状况不相当的未成年人证言，只是**不能单独作为定案根据**。

- **出庭**（民诉法§76+解释§117）：出庭为原则，申请须在**举证期限届满前**提出；①健康原因②路途遥远交通不便③不可抗力④其他正当理由，经法院**许可**可用书面证言、**视听传输技术**或视听资料方式作证（双方同意+法院准许也可不出庭，证据规定§68）。作证不得宣读事先准备的书面材料，法院认为必要可安排证人**对质**。
- **保证书**（解释§119-120）：作证前签署并宣读保证书，**拒绝签署的不得作证**并自行承担相关费用；**无民事行为能力人和限制民事行为能力人作证除外**（免签）。
- **费用**（民诉法§77）：交通、住宿、就餐及误工损失由**败诉一方**负担；当事人申请的由申请人**先行垫付**。
- **身份辨析**：法院通知某人"到庭"，若是来**陈述其知道的案件事实**→证人；只有来主张/承担实体权利义务的才是当事人或第三人。

#### 大白话讲解

乙申请公司会计**丙**出庭。甲律师连抛四招，全被挡回：

- **"丙是乙的会计，有利害关系，应当回避！"**——错。证人**不适用回避**；利害关系只影响证明力（其证言**不能单独定案**），不剥夺资格。
- **"丙作证得经我方同意！"**——错。证人资格从不以对方同意为条件，只须乙在**举证期限届满前**申请、法院通知。
- **"当时在场的还有乙5岁的女儿，她肯定不能作证！"**——半对半错。标准不是"5岁/无行为能力"，而是**能否正确表达意思**；若她能清楚讲述看到的交款过程，就有资格，只是其证言若与年龄智力不相当则不能单独定案。而且她作证**不用签保证书**（无/限制行为能力人免签）。
- 丙开庭当天说"我在外地出差路太远，微信上把证词发给你们吧"——**不行**。路途遥远须经法院**许可**后以书面证言或**视听传输技术**方式作证，且成年证人须**签署保证书**（书面作证的签署、视频作证的签署并宣读）；如果丙耍脾气**拒签保证书→直接不得作证**，相关费用自己扛。
- 官司打完甲败诉——丙的车费、住宿费、误工费由**败诉的甲**负担（乙申请的，乙先垫付）。

反向辨析：法院通知案外人付某到庭说明"货款是否由他代收"——付某是来**陈述事实**的，身份是**证人**，不是无独立请求权第三人（他不主张权利、不承担义务）。

#### 一句话闭环记忆

> 🎯 **一眼判**：
> 	- 证人资格:证人资格唯一消极条件为**不能正确表达意思**，知晓案情的单位、个人均可作证；年龄、民事行为能力、与当事人存在利害关系不影响证人资格，
> 
> 	- 证人不适用回避制度
> 
> 	- 证人作证**不得以宣读事先准备的书面材料的方式**陈述 
> 	- 
> 	- 审判人员询问证人时其他证人不得在场；但**人民法院认为有必要的，可以要求证人之间进行对质**。
> 	
> 	- 利害关系证人、与智力年龄不匹配的未成年人证言仅不能单独作为定案依据。
> 
> 	- 出庭作证为原则，当事人申请证人出庭应当在举证期限届满前提出；具备健康原因、路途遥远交通不便、不可抗力、其他正当理由，经法院许可，可以书面证言、视听传输技术等方式作证；双方当事人同意且法院准许，证人也可不出庭。
> 	
> 	- 证人作证前应当签署并宣读保证书，拒绝签署保证书的不得作证、自行承担费用；无民事行为能力人、限制民事行为能力人作证免于签署保证书。未签保证书不影响作证.
> 	
> 	- 证人出庭产生的交通、住宿、就餐、误工损失由败诉方负担，当事人申请证人出庭的，由申请人先行垫付。
> 	
> 	- 区分身份标准：案外人到庭陈述亲身感知案件事实属于证人；只有主张或承担实体权利义务的主体，才属于当事人、第三人。速记口诀：能表达即能作证，拒签保证书免谈，费用败诉埋单。
> 	
> 	- 法院仅要求当事人本人到庭接受询问，代理人可正常出庭。负有举证责任一方本人拒不到庭，事实缺乏其他证据佐证的，法院对其主张事实不予认定；该规则≠缺席判决。
> 	
> 	- 法院已经合法传票传唤，一方当事人无正当理由不到庭 / 擅自退庭，法庭照常开庭审理，在一方不在场情况下作出实体判决。
> 	
> 	- 谁主张,谁举证

### 第五步：专业意见——鉴定谁启动？鉴定人不来怎么办？教授算什么人？

> **鉴定依申请协商定，拒不出庭作废退费，专家辅助视为陈述**

#### 概述

- **启动**（民诉法§79+解释§121）：以**当事人申请**为主（举证期限届满前提出），鉴定人由**双方协商**确定，协商不成**法院指定**；只有符合**依职权调查收集证据条件**（涉国家利益、公共利益、身份关系等）法院才依职权委托——普通合同纠纷里法院**不能**主动"应当依职权鉴定"。文书真伪有争议时，**主张文书真实并据以主张权利的一方**应申请鉴定，不申请的承担不利后果。
- **鉴定人拒不出庭三件套**（民诉法§81+证据规定§81）：当事人对鉴定意见有异议或法院认为必要→鉴定人**应当出庭**；经通知**拒不出庭**→①鉴定意见**不得作为认定事实的根据**②支付鉴定费的当事人可要求**返还**（法院**3日内裁定**责令退还）③当事人申请**重新鉴定的应当准许**。
- **单方委托报告**：一方**诉前自行委托**出具的"鉴定报告"不是法定程序形成的**鉴定意见**，以其记载内容作证据定性为**书证**，仍须质证；对方有足以反驳的理由并**申请鉴定的应予准许**。
- **专家辅助人**（民诉法§82+解释§122-123）：当事人可申请**一至二名**有专门知识的人出庭，对鉴定意见质证或就专业问题提意见；其意见**视为当事人的陈述**；**不适用回避**、费用**申请方负担**、双方专家辅助人可**对质**、**不得参与专业问题之外的法庭审理活动**。技术调查官则是**审判辅助人员**，回避**参照审判人员**。

#### 大白话讲解

乙咬定借条上的签名是伪造的。**谁去申请鉴定？**——甲。甲持借条主张10万元债权、依赖借条真实，**主张文书真实并据以主张权利的甲**应申请笔迹鉴定；甲不申请，就自己吞下"借条真实性存疑"的不利后果。法院也不能拍板"本院依职权鉴定"——民间借贷不涉国家利益、身份关系，不在依职权清单里。

鉴定人由**甲乙协商**选定；谈不拢，**法院指定**了鉴定机构，出具意见："签名系乙本人书写"。乙不服，申请鉴定人出庭接受质询，法院通知后**鉴定人嫌麻烦不来**——后果立竿见影：这份鉴定意见**不得作为认定事实的根据**（直接出局，不是"酌减证明力"）；掏了8000元鉴定费的甲可以要求**退费**，法院应在**3日内裁定**责令鉴定人退还；甲申请**重新鉴定，法院应当准许**。

如果甲提交的是**起诉前自己找机构做的笔迹报告**呢？那不是"鉴定意见"——没走双方协商/法院指定的法定程序，只能以其记载内容当**书证**用；乙拿出足以反驳的理由申请正式鉴定，法院**应予准许**。

最后，乙申请笔迹学**王教授**出庭"会诊"鉴定意见——王教授是**有专门知识的人（专家辅助人）**：人数限**1-2名**、举证期限届满前申请；他当庭发表的意见**视为乙（当事人）的陈述**，不是第九种证据、更不是鉴定意见；他**不用回避**（哪怕是乙的老同学，只影响意见分量）；出庭费用**乙自己掏**（不适用证人"败诉方负担"）；他可以和甲方的专家辅助人**当庭对质**，但专业问题之外的庭审环节他**必须闭嘴退场**。

#### 一句话闭环记忆

> 🎯 **一眼判**：民事诉讼专门性问题鉴定以当事人申请启动为主，申请应当在举证期限届满前提出；
> - 鉴定人先由双方协商选定，协商不成法院指定。仅在符合法院依职权调查取证法定情形时(案件涉及身份关系、国家公共利益、公益诉讼、恶意串通嫌疑、重要程序事项)，法院才可主动委托鉴定；普通财产纠纷(民间借贷、买卖、承揽)法院不得依职权启动鉴定。
> 
> - 对文书真伪存在争议，**主张文书真实并以此主张权利的一方负有申请鉴定义务，拒不申请承担举证不能后果**。
> 	- 当事人拿出**私文书（借条、合同、欠条）**，依靠这份文书想要让法院支持自己诉讼请求；法律要求此人证明文书真实。双方对文书真伪有争议，需要鉴定才能查清事实时，**由该方申请鉴定**. 单纯否认文书是假的另一方，只属于反驳，**没有申请鉴定义务**。
> 
> - 当事人对鉴定意见有异议或者法院认为有必要，鉴定人应当出庭；经法院通知拒不出庭的，鉴定意见不得作为定案依据，付费当事人有权要求退还鉴定费用，当事人申请重新鉴定的法院应当准许。
> 
> - **鉴定人的调查询问权**, 鉴定人在鉴定过程中可以询问当事人
> 
> - 当事人诉前单方委托机构出具的书面报告不属于法定鉴定意见，证据属性为书证，依法质证,法院对其真实性、关联性、合法性及证明力**进行审查**后，**确定其是否可以作为认定案件事实的根据**；对方有充分反驳理由并申请鉴定，法院应予准许。 
> 
> - 当事人可申请一至二名具有专门知识的人（专家辅助人）出庭，对鉴定意见质证、就专业问题发表意见；专家辅助人意见**视为当事人陈述**，不适用回避，出庭费用由申请人自行负担；双方专家辅助人可以对质，专家辅助人不得参与专业问题之外的庭审活动。技术调查官属于审判辅助人员，回避参照审判人员规则适用。审判人员可以对有专门知识的人进行询问；**经法庭准许**，当事人各自申请的有专门知识的人、以及出庭的鉴定人，可以就案件专业问题**相互对质/发问**


- 举证不能: 负有举证责任一方拒不申请鉴定导致事实无法查清，承担举证不能后果：法院不采信该书证，驳回其诉讼请求。

- **诉前单方委托报告**：没经过法院委托程序，仅一方私下委托机构出具，**不属于民诉法意义上的鉴定意见**，证据属性为**私文书证**。对方有充分反驳理由，申请法院委托正式鉴定，法院应当准许。 单方诉前报告与法院委托鉴定意见均可质证反驳；前者反驳理由成立即可准许重新鉴定；后者仅单纯不服结论不能重鉴，需证明存在法定严重瑕疵。

- **不适用回避**：回避制度约束**中立主体（法官、鉴定人、技术调查官）**；专家辅助人本来就代表一方当事人，不要求中立，不在回避适用主体范围内。

- 技术调查官：**法院指派、中立辅助法官，必须遵守回避**。

速记口诀：**鉴定依申请协商定，拒不出庭作废退费，专家辅助视为陈述**

## 六、 易混提示

*   **电子数据 vs 视听资料**：
    *   看**载体**不看内容——数字化存储（手机录音、数码照片、微信语音）一律电子数据；模拟介质（录音带、录像带）才是视听资料（解释§116第3款）。
*   **证据能力 vs 证明力**：
    *   复印件、利害关系证言、瑕疵证据都**有证据能力**（能进法庭），问题只出在**证明力**层面（须核对/不能单独定案）。"没有证据能力"与"不能单独作为定案根据"是两句完全不同的话。
*   **本证/反证 vs 原告/被告**：
    *   被告对自己主张的**权利消灭事实**（已还款）负举证责任，其收条是**本证**；只有针对**对方负举证责任的事实**进行动摇的才是反证。
*   **鉴定意见 vs 单方委托报告 vs 专家辅助人意见**：
    *   法定程序委托→**鉴定意见**；诉前自行委托→**书证**；专家辅助人当庭发言→**视为当事人的陈述**——三种"专业意见"落进三个不同格子。
*   **书证提出命令的两档后果**：
    *   拒不提交→认定**书证内容**为真实（解释§112）；毁灭书证→罚款拘留＋可认定**所证事实**为真实（解释§113+证据规定§48第2款）——"内容为真"与"事实为真"层级不同，且只有毁灭才挨罚。

## 七、 命题人最爱的 7 个陷阱

1.  **"数码照片/微信记录/电子转账凭证属于视听资料"** —— 错！均为**电子数据**（证据规定§14清单）；而"手机录音是视听资料还是电子数据"题库两口径并存——记牢确定项：录音带录像带＝视听资料，电子介质录音影像**适用电子数据的规定**（解释§116第3款）。
2.  **"复印件没有证据能力/当然没有证明力"** —— 错！复印件是**传来证据**，有证据能力，可与原件核对或结合其他证据采信；且其内容直指待证事实时仍是**直接证据**。
3.  **"被告提交的证据是反证"** —— 错！看**举证责任**不看诉讼地位：被告对"已还款"这一消灭事实负举证责任，其收条是**本证**。
4.  **"对方拒不执行书证提出命令的，法院应对其拘留/判其败诉"** —— 错！拒不提交的后果是**认定申请人主张的书证内容为真实**（解释§112）；只有**毁灭书证**等妨碍行为才升级为罚款、拘留（解释§113）。
5.  **"无民事行为能力人不能作证；证人与一方有利害关系的应当回避"** —— 双错！资格唯一门槛是**能否正确表达意思**（民诉法§75）；证人**不适用回避**，利害关系证言只是**不能单独定案**。
6.  **"鉴定人经通知未出庭的，其鉴定意见由法院结合其他证据判断证明力"** —— 错！刚性后果：**不得作为认定事实的根据**+退还鉴定费（3日内裁定）+重新鉴定应当准许（民诉法§81+证据规定§81）。
7.  **"专家辅助人的意见属于鉴定意见/独立的法定证据种类；专家辅助人应当回避"** —— 双错！其意见**视为当事人的陈述**（解释§122第2款），归入八种之首；专家辅助人**不适用回避**（技术调查官才参照审判人员回避）。
