# 📐 遗失物 · 答题模型（轻量 · 定性 → 追物 → 算账）

> 凡"丢的 / 捡的 / 埋的东西，原主能不能要回、捡的人要不要赔 / 能不能要报酬"题，三步走：**① 定性（是不是遗失物）→ ② 追物链（原主能否要回物）→ ③ 算账链（拾得人赔偿与报酬）**。这是**记忆型考点的速查版**；完整法条逐条见概念页 [[遗失物]]；"遗失物作为善意取得例外"的那一面见 [[民法-物权-善意取得模型]] 第五步·闸③。
> 🔎 **法条已联网核实（2026-06-15 · 最高检 spp.gov.cn + 最高法 court.gov.cn）**：§312（回赎 / 有偿回赎）· §314（返还通知）· §316（妥善保管 + 毁损赔偿）· §317（费用 / 报酬 + 侵占丧失）· §318（满一年归国家）· §319（埋藏物 / 隐藏物 / 漂流物参照），全 CONFIRMED。⚠️ 易记错：**§316＝妥善保管+赔偿、§317＝报酬+侵占丧失**，别标反；埋藏物条号是 **§319**（非 §316）。
> **适用真题**：[[物权编-单选-08|单选-08·埋藏物§319→§312·原主可向无权处分人索赔]] · [[物权编-单选-09|单选-09·拾得人拒还→赔偿+丧失报酬]]。

## 一、核心考情

- **频率**：★★★★（[[物权编考点-深度报告]] 所有权 Row 2）。考点小而稳，**常与善意取得 §311 对比命题**（普通动产即时取得 vs 遗失物 2 年回赎）。
- **命题核心**：① 是不是"遗失物"（脱离物 vs 委托物，决定能否善意取得）；② 原主追回物的路径（2 年回赎 / 有偿回赎）；③ 拾得人的赔偿与报酬（§316/§317 易混 + 侵占丧失）。

## 二、万能三步

### 第一步：定性——是不是"遗失物"？（决定走哪套规则）

> **铁则**：看物**怎么脱离原主占有**——
> - **非基于原主意思**（丢失 / 被盗 / 遗忘 / 埋藏）＝**遗失物（脱离物）** → 受特别保护，**限制善意取得**。
> - **基于原主意思交出**（出租 / 出借 / 保管）＝**占有委托物** → 适用**普通善意取得**（§311），不进本模型。
> - 埋藏物 / 隐藏物 / 漂流物 → **§319 参照**遗失物；**赃物**通说亦准用。

🚗 **同一台相机、脱离方式不同、结局相反**：借出去的相机被借用人卖掉＝委托物（买家可**善意取得**）；丢在出租车上的相机被司机卖掉＝遗失物（原主 **2 年可回赎**）。

### 第二步：追物链——原主能不能把"物"要回来？

| 情形 | 原主能否追回 | 依据 |
|---|---|---|
| 物还在拾得人 / 无权处分人手里 | **能**，直接请求返还 | §314 |
| 遗失物已被卖给**善意**受让人 | **能**，自知道 / 应知受让人起 **2 年内**回赎 | §312 |
| 受让人是**拍卖 / 经营者**处购得 | 能，但须**先付受让人所付的费用**、再向无权处分人追偿（有偿回赎）| §312 |
| （对照）普通**委托物**被善意取得 | **不能**（已善意取得），只能找无权处分人赔 | §311 |

🔑 与善意取得的分水岭就在这：**普通动产即时失权、遗失物给 2 年缓冲**。

### 第三步：算账链——拾得人 vs 原主（钱与责任）

> 拾得人**不取得所有权**（满一年无人认领才归国家 §318），围绕三件事算账：
- **义务**：返还 + 及时通知 / 送交（§314）、送交前**妥善保管**（§316）。
- **报酬 / 费用**：原主领取时付**必要费用**；有**悬赏**的按承诺给报酬（§317）。
- **🔴 侵占丧失**：拾得人**拒不返还（侵占）→ 丧失**费用与报酬请求权（§317）。
- **🔴 毁损赔偿**：因**故意或重大过失**致遗失物毁损灭失 → **赔偿**（§316）；**一般过失不赔**。

🚗 捡到手链拒不还、还弄丢了 → ① 故意/重大过失毁损 **要赔**（§316）② 侵占 **丧失** 500 元悬赏（§317）＝单选-09 答 B。

## 三、命题人最爱的陷阱

1. **遗失物当普通动产**——以为善意买家即时取得 → 错！原主 **2 年可回赎**（§312）。
2. **§316 / §317 标反**——§316＝妥善保管 + 毁损赔偿；§317＝费用报酬 + 侵占丧失。
3. **拒还还想要报酬**——侵占 → **丧失**报酬（§317），单选-09 的题眼。
4. **一般过失也要赔**——错！只有**故意 / 重大过失**毁损才赔（§316）。
5. **埋藏物引 §316**——错！埋藏物 / 隐藏物 / 漂流物参照遗失物是 **§319**。
6. **拍卖 / 经营者购得也能无偿追回**——错！须**有偿回赎**（先付费后追偿，§312）。

## 四、真题演练

### 范例①：[[物权编-单选-08]]（2015-3-6 · 答 **A**）——埋藏物 §319→§312
甲祖父埋藏的瓷瓶（甲继承），丙挖出后市价卖给善意丁。**埋藏物经 §319 参照遗失物 §312** → 丁不能确定善意取得，甲可向无权处分人丙**请求损害赔偿**（§312 一支）→ **A 对、D 错**。（同时是 [[民法-物权-善意取得模型]] 范例④——遗失物正是善意取得的例外。）

### 范例②：[[物权编-单选-09]]（2017-3-6 · 答 **B**）——拾得人拒还
乙拾得甲的手链、拒不返还、后玩耍时弄丢。**① §316**：拒还后弄丢＝故意 / 重大过失致灭失 → **赔偿**；**② §317**：侵占（拒不返还）→ **丧失** 500 元悬赏报酬 → **B（赔偿 + 无权要 500）**。

## 📐 口诀

> **脱离物（丢 / 盗 / 埋）受特别保护，委托物（租 / 借）才即时善意取得；**
> **遗失物原主 2 年可回赎（§312），拍卖 / 经营者购得先付费后追偿；**
> **拾得人不取得所有权，满一年无人认领归国家（§318）；**
> **善保管、及时还——拒不还（侵占）丧失报酬（§317），故意 / 重大过失毁损要赔（§316）。**
