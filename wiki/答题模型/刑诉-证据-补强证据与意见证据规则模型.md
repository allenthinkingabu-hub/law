# 📐 补强证据规则与意见证据规则 · 答题模型

> **教练开场白**
> 同学们好！我是你们的刑诉法考教练。这一节两条规则都是客观题的"送分＋埋雷"双面点：**补强证据规则**（口供不能单打独斗）和**意见证据规则**（证人只能讲事实、不能下判断）。
> 大多数同学的惯性是：一看被告人认罪了就觉得"能定罪了"；一看证人说得头头是道就全盘采信。命题人正是拿这两个惯性挖坑——**只有口供再详细也不能定罪**；证人**再像那么回事的"推测/评论"也要排除**。
> 破解就两句话：**「口供补强——孤证（口供）不定案，补强证据得独立、够格、担保口供真」、「意见证据——证人只说亲眼看的事实，猜测评论推断一律排除，但符合生活经验的判断除外」**。
> 今天用**两条规则各一套字诀＋数字案例＋做题眼**把它们钉死。

## 适用场景与解决问题

本模型覆盖 [[刑诉-刑事证据制度-深度报告]] 第一板块**考点8（补强证据规则）与考点9（意见证据规则）**。凡题干出现"只有被告人供述能否定罪""补强证据需具备什么条件""共犯口供互相印证能否定罪""证人的猜测/评论/推断能否采信""民警认为/推测……"等，立即调用本模型。

- **补强证据规则（§55①前段）**：**只有被告人供述、没有其他证据的，不能认定有罪**；**没有被告人供述，但其他证据确实、充分的，可以认定有罪**。口供是"必须补强"的证据。
- **补强证据的要件**：①补强证据**自身须具有证据能力**（底线，非法/无资格证据不能充当补强）；②须有**独立来源**（不能是口供的同源重复）；③须能**担保口供的真实性**、对犯罪事实有印证作用。
- **意见证据规则（法释〔2021〕1号§88）**：证人的**猜测性、评论性、推断性**证言**不得作为证据使用**，但**根据一般生活经验判断符合事实的除外**；处于明显**醉酒、中毒、麻醉**等不能正常感知或表达状态的证人证言，也不得作为证据使用。

> **核心一句**：**「口供再多也是'一' —— 必须有独立、够格的补强证据担保才定案；证人只报'我亲眼所见的事实'，一旦变成'我猜/我认为/我推断'就排除（除非是普通生活经验能坐实的判断）。」**

## 一、 两条规则决策树

```
   ┌────────────────── 补强证据规则（§55①） ──────────────────┐
   │  全案证据里"被告人供述"占什么位置？                       │
   │        │                                                   │
   │  只有口供、无其他证据 ──────► 不能定罪                     │
   │  有口供 + 补强证据 ──► 补强证据是否 ①有证据能力            │
   │                              ②独立来源 ③担保口供真实?      │
   │                              全满足 → 可定案                │
   │  无口供 + 其他证据确实充分 ──► 可以定罪                    │
   │  ⚠️共犯供述之间：仅共犯互相印证、无其他证据 → 仍不能定罪   │
   └────────────────────────────────────────────────────────────┘

   ┌────────────────── 意见证据规则（§88） ────────────────────┐
   │  证人这句话是"陈述事实"还是"下判断"？                      │
   │        │                                                   │
   │  亲身感知的事实（我看见/听见…） ──────► 可采                │
   │  猜测/评论/推断（我觉得/我认为/应该是…） ──► 排除          │
   │        └── 例外：根据一般生活经验判断符合事实 → 可采        │
   │  明显醉酒/中毒/麻醉、不能正常感知或表达 ──► 排除(§88①)     │
   └────────────────────────────────────────────────────────────┘
```

> **一句话总诀**：**「口供必补强（独立·够格·担保真）；证人只报事实，猜测评论推断排除、生活经验判断除外」**。

## 二、 黑话 → 人话 对号入座表

| 黑话术语 | 翻成人话 | 对号入座（一句话定位） |
| :--- | :--- | :--- |
| **补强证据规则** | 光有被告人认罪不算数，还得有**别的证据**来"托底" | 只有口供→不能定罪；口供＋独立物证/证言→可定 |
| **补强证据** | 那份用来给口供"托底"的、**够格又独立**的证据 | 独立目击证言、现场物证；不能是口供的复述件 |
| **独立来源** | 补强证据不能跟口供是**同一个源头** | 讯问笔录的复印件不能补强口供本身 |
| **共犯供述互相印证** | 几个同案被告人的口供互相对上 | 只有共犯口供、无其他证据→**仍不能定罪** |
| **意见证据** | 证人不报事实、却在**下结论、发议论、瞎猜** | "我觉得是他干的""这门锁应该是被人撬的" |
| **猜测/评论/推断** | 没亲眼看、靠脑补的判断 | 民警"认为血迹是人为改动"（没看到→推断，排除） |
| **一般生活经验例外** | 普通人凭常识就能坐实的判断 | "他走路东倒西歪，像是喝多了"（经验判断，可采） |

## 三、 两大判定关卡（字诀 + 数字案例 + 🎯做题眼）

### 第一关：补强证据规则 —— 盯死"口供不能单打独斗"

**1. 核心逻辑（极简字诀）**
> **「只有口供不定罪，补强须独立·够格·担保真；无口供但证据充分照样定」**

**2. 大白话讲解（完整数字案例）**
> 甲被控盗窃并作了认罪供述。①若**全案只有甲的口供**、再无其他证据——**不能定罪**（§55①）；②要给口供"托底"的补强证据必须**自身够格**（有证据能力，非法证据不能当补强）、**独立来源**（不能是这份口供的复印/复述）、且能**担保口供真实**（如独立目击者、现场物证与口供细节吻合）——三者齐备才可定案（单选-17）；③反过来，**即便甲拒不认罪（无口供）**，只要其他证据**确实、充分**，照样**可以定罪**。至于几个**共犯**的口供互相对得上——通说认为仅凭共犯供述之间互相印证、别无其他证据，**仍不能定罪**（此细分表述属学理通说，真题实证尚待验证，谨慎记忆）。

**3. 一句话闭环记忆 + 🎯做题眼**
> **一眼判**：口供＝必须补强的"半成品"；补强证据要**独立＋够格＋担保真**；无口供≠不能定罪（证据充分即可）。
> 🎯做题眼：把"只有被告人供述就能定罪"或"补强证据无须具备证据能力"的——**排除**；把"没有口供就不能定罪"的——也**排除**（证据确实充分即可）。

### 第二关：意见证据规则 —— 盯死"证人报事实，不下判断"

**1. 核心逻辑（极简字诀）**
> **「证人只讲亲眼所见的事实；猜测评论推断排除，生活经验判断除外」**

**2. 大白话讲解（完整数字案例）**
> 强奸案／洗钱案里，出庭人员的话要过筛：①普通证人说"我看见甲当晚从乙家出来"——**陈述事实，可采**；②民警说"我**认为**现场血迹是**人为改动**的"——这是没有亲眼所见的**推断性意见**，**排除**（多选-30）；③但证人说"他当时走路东倒西歪、满嘴酒气，**像是喝多了**"——这是**根据一般生活经验就能坐实的判断**，属**例外，可采**（多选-21）。此外，处于明显**醉酒、中毒、麻醉**、不能正常感知表达的证人，其证言也要排除。

**3. 一句话闭环记忆 + 🎯做题眼**
> **一眼判**：证人的话是"我看见的事实"还是"我推断的结论"——结论性的猜测/评论/推断排除，**除非**是生活经验一望即知的判断。
> 🎯做题眼：把"民警/证人的推测、认定"当有效证据采信的——**排除**；把"符合一般生活经验的判断"也一律排除的——**也错**（那是法定例外）。

## 四、 命题大坑速查表

| 命题大坑（陷阱） | 命题人忽悠套路 | ⚖️ 架构师正解与做题秒杀眼 |
| :--- | :--- | :--- |
| **口供万能坑** | "被告人已详细认罪，可以定罪。" | **只有口供不能定罪**（§55①）；必须有独立、够格的补强证据。 |
| **无供不能定坑** | "没有被告人供述就不能定罪。" | 错！**其他证据确实充分即可定罪**（§55①后段）。 |
| **补强不够格坑** | 拿口供的复印件/同源材料当补强。 | 补强须**独立来源＋自身有证据能力**，同源复述不算补强。 |
| **共犯印证坑** | "几名共犯口供互相印证，可定罪。" | 仅共犯供述互相印证、无其他证据→**仍不能定罪**（通说）。 |
| **推断采信坑** | 民警"认为/推测"某情节，当证据用。 | 猜测/评论/**推断性意见排除**（§88）。 |
| **例外一刀切坑** | 把"走路东倒西歪像喝多了"也排除。 | **符合一般生活经验的判断是法定例外，可采**。 |

## 五、 主观题万能说理模板

### 模板一：补强证据规则
> "依补强证据规则（§55①），只有被告人供述、没有其他证据的，不能认定被告人有罪；没有被告人供述，但其他证据确实、充分的，可以认定有罪。用以补强口供的证据必须**自身具有证据能力**、具有**独立于口供的来源**，并能**印证、担保口供的真实性**。本案[某材料]因[缺乏证据能力／与口供同源／不能印证]，不能作为有效补强，故仅凭现有口供不能定案。"

### 模板二：意见证据规则
> "依意见证据规则（法释〔2021〕1号§88），证人应就其**亲身感知的事实**作证，其**猜测性、评论性、推断性**的证言不得作为证据使用；但**根据一般生活经验判断符合事实的除外**。本案[某人]关于'[推断内容]'的陈述系其主观推断、非亲历事实，应予排除；而其关于'[生活经验判断]'的陈述符合一般生活经验，可以采信。"

## 六、 典型考题演练

### 1. 补强证据的要件（[[刑诉-证据-单选-17 · 补强证据资格要件与独立来源审查规则|单选-17]]）
- **模型应用**：第一关。补强证据**首先自身须具有证据能力**（底线），并须独立来源、担保口供真实。**答案 A。**

### 2. 证人资格与补强综合（[[刑诉-证据-多选-12 · 证人资格与补强证据规则综合|多选-12]]）
- **模型应用**：第一关。孤证（口供）仍需补强；亲耳所闻非传闻，具证人资格。**答案 BCD。**

### 3. 意见证据的生活经验例外（[[刑诉-证据-多选-21 · 意见证据推定主观明知的排除例外|多选-21]]）
- **模型应用**：第二关。根据一般生活经验判断符合事实的推断可采信，不属被排除的猜测。**答案 B。**

### 4. 民警推断的排除（[[刑诉-证据-多选-30 · 强奸案中意见证据排除与事实判断例外|多选-30]]）
- **模型应用**：第二关。民警"认为系人为改动"属推断性意见，未亲见→排除。**答案 A。**
