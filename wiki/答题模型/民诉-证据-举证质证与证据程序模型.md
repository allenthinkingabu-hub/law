# 📐 举证质证与证据程序 · 完整答题模型（举证期限与逾期分层 + 法院调查收集 + 证据保全 + 质证认证与排非）

> **核心一句**：证据程序是一条"**限期交证 → 迟交付代价 → 自己拿不到找法院（调查收集）→ 怕灭失先保全 → 当庭对质、排非认证**"的流水线。考试核心在于**逾期举证的"分层后果"（不予采纳 / 采纳＋训诫 / 采纳＋训诫罚款）**、**依职权五项清单与依申请"客观原因"的界限**、**证据保全的诉前/诉中条件与担保**、**"未经质证不得认定"与非法证据排除三标准**；最毒陷阱是**把"涉基本事实的逾期证据"说成一律不予采纳**、**把"没时间收集"当"客观原因"**、**把涉密证据"不得公开质证（依职权）"与"不公开审理（须申请）"混为一谈**、**把"未经对方同意的私录"当然当成非法证据**。
>
> 🔎 **核心条文速查**（法条均经本地权威全文逐条 grep 核验）：
> - **《民事诉讼法》（2023年修正）第68条【及时举证与逾期后果】**：当事人应当**及时提供证据**；法院确定证据及其期限；期限内提供确有困难的，可**申请延长**；**逾期提供**的，法院应当**责令其说明理由**；拒不说明理由或者理由不成立的，法院根据不同情形可以**不予采纳**该证据，或者**采纳该证据但予以训诫、罚款**。
> - **《民事诉讼法》第67条第2款【法院调查收集】**：当事人及其诉讼代理人因**客观原因不能自行收集**的证据，或者**人民法院认为审理案件需要**的证据，人民法院**应当调查收集**。
> - **《民事诉讼法》第84条【证据保全】**：第1款（诉中）——在**证据可能灭失或者以后难以取得**的情况下，当事人可以在诉讼过程中申请保全证据，法院也可以**主动**采取保全措施；第2款（诉前）——**因情况紧急**，利害关系人可以在起诉或申请仲裁前向**证据所在地、被申请人住所地或者对案件有管辖权**的法院申请；第3款——其他程序**参照适用第九章保全**的有关规定。
> - **《民事诉讼法》第71条【质证与涉密证据】**：证据应当**在法庭上出示**，并由**当事人互相质证**；涉及国家秘密、商业秘密和个人隐私的证据应当保密，需要在法庭出示的，**不得在公开开庭时出示**。
> - **《民诉法解释》（法释〔2022〕11号修正）**：§94（客观原因三情形＋举证期限届满前**书面**申请）、§95（无关联/无意义/无必要不予准许）、§96（依职权调查**五项清单**＋清单外**依申请**）、§97（调查须**两人以上**共同进行）、§98（证据保全举证期限届满前书面提出＋可能致他人损失的**责令担保**）、§99（举证期限审理前准备阶段确定、可协商经准许；一审普通≥**15日**、二审新证据≥**10日**；反驳/补正证据可再定期限不受限）、§100（延期申请须**届满前书面**提出、延长的期限适用于其他当事人）、§101（逾期责令说明理由；**客观原因逾期或对方未异议视为未逾期**）、§102（**分层后果**：故意/重大过失→不予采纳，但涉基本事实应当采纳＋训诫罚款；非因故意/重大过失→采纳＋训诫；逾期致对方增加必要费用可赔）、§103（**未经质证的证据不得作为认定案件事实的根据**；准备阶段认可＋庭审说明视为质证过；涉密不得公开质证）、§104（围绕**真实性、合法性、关联性**质证并就证明力辩论）、§105（**认证**：逻辑推理＋日常生活经验法则，公开判断理由和结果）、§106（**非法证据三标准**：严重侵害他人合法权益 / 违反法律禁止性规定 / 严重违背公序良俗）。
> - **《民事诉讼证据规定》（法释〔2019〕19号）**：§25-§29（证据保全的申请书内容、届满前提出、限制流通措施**应当责令担保**、最小影响原则、保全错误赔偿、诉前保全后移交受诉法院）、§51（举证期限可协商；简易程序≤15日、小额诉讼一般≤7日）、§59（逾期罚款数额的考量因素）、§60（准备阶段或法院调查、询问中**发表过质证意见**的视为质证过）。
> - 官方全文：[民诉法2023全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf) · [国家法律法规数据库](https://flk.npc.gov.cn/)

> ⚠️ **诚实标注（条号核验说明）**：本模型全部条号均对照本地权威全文（ssf.gov.cn 民诉法2023 PDF 转存文本、民诉解释2022全文、证据规定2019全文）逐条 grep 核对，非凭记忆书写。**两处高危点特别说明**：①《证据规定》§25、§26 原文引用的是"民事诉讼法**第八十一条**"——这是 2019 年制定时对应的**旧条文号**，2023年修正后证据保全已是**第84条**，做题时以现行§84为准，见到"§81证据保全"要能识别是旧编号；②民诉法§68 只写了"不予采纳，或者采纳但训诫、罚款"的**概括后果**，"故意/重大过失 vs 非因故意/重大过失"以及"与案件基本事实有关的应当采纳"这套**精细分层**规定在**解释§102**，二者是"总—分"关系，引用时不可张冠李戴。
>
> ⚠️ **易记错点**：①**逾期举证不是"一律不予采纳"**——与案件基本事实有关的，即便故意/重大过失逾期也**应当采纳**，只是要挨训诫、罚款；②延长举证期限的申请必须在**期限届满前**提出，届满后再申请不符合规定；③依职权调查限于**五项清单**，清单之外一律**依申请**，而申请的门槛是"**客观原因**取不到"——"没时间、嫌麻烦"是主观懈怠不算；④诉前证据保全的管辖是**证据所在地、被申请人住所地或对案件有管辖权的法院**三选一（比诉前财产保全多一个"证据所在地"）；⑤证据保全的担保是"**可能对他人造成损失的**"才**应当责令**提供，不是一律担保；⑥**未经质证的证据不得作为认定案件事实的根据**是铁律，但有"视为质证过"的两个例外（准备阶段认可＋庭审说明；准备阶段/调查询问中发表过质证意见）；⑦涉密证据**不得公开质证**是法院**依职权**的"应当"（§71），与"不公开审理须**当事人申请**"（§137离婚/商业秘密案件）是两套规则；⑧私自录音**不因"未经对方同意"当然排除**，只看是否触碰§106三条红线——"剪辑存疑"影响的是**证明力**不是证据能力。

## 二、 证据程序流水线判别模型（限期 → 迟交 → 调取 → 保全 → 质证认证）

```
              【起诉受理后，审理前的准备阶段】
                          │
   ▼ 第一关：举证期限怎么定？（解释§99 + 证据规定§51）
   │
   ├─ 当事人协商 + 法院准许 ──→ 可以（天数不受法定下限约束）
   ├─ 法院指定 ──→ 一审普通程序 ≥15日；二审新证据案件 ≥10日
   │              （简易 ≤15日；小额一般 ≤7日——证据规定§51）
   └─ 届满后申请反驳证据 / 补正瑕疵 ──→ 法院可酌情再定期限，不受下限约束
                          │
   ▼ 第二关：来不及交怎么办？逾期交了怎么罚？（民诉法§68 + 解释§100-102）
   │
   ├─ 期限内提供确有困难 ──→ 届满前书面申请延长；延长的期限适用于其他当事人
   ├─ 届满后才申请延长 ──→ ❌ 不符合规定
   └─ 逾期提供 ──→ 责令说明理由（解释§101）
        ├─ 客观原因逾期 / 对方未提异议 ──→ 视为未逾期
        ├─ 非因故意或重大过失 ──→ 应当采纳 + 训诫
        └─ 故意或重大过失 ──→ 原则不予采纳
             └─ 但与案件基本事实有关 ──→ 应当采纳 + 训诫、罚款（§102 I）
                          │
   ▼ 第三关：自己拿不到的证据找谁？（民诉法§67 II + 解释§94-97）
   │
   ├─ 落入依职权五项清单（§96 I）──→ 法院应当主动调查收集
   │   （①国益公益 ②身份关系 ③公益诉讼 ④恶意串通可能 ⑤程序性事项）
   ├─ 清单之外 ──→ 一律依当事人申请（§96 II）
   │   └─ 门槛＝客观原因不能自行收集（§94）：国家部门保存无权调取 /
   │      涉国秘·商秘·隐私 / 其他客观原因；届满前书面申请
   └─ 无关联 / 无意义 / 无必要 ──→ 不予准许（§95）；调查须两人以上（§97）
                          │
   ▼ 第四关：证据要灭失怎么办？（民诉法§84 + 解释§98 + 证据规定§25-29）
   │
   ├─ 诉中：可能灭失或以后难以取得 ──→ 当事人申请（届满前书面）或法院主动
   ├─ 诉前：情况紧急 ──→ 利害关系人向"证据所在地 / 被申请人住所地 /
   │        对案件有管辖权"的法院申请（三选一）
   ├─ 担保：可能对他人造成损失的 ──→ 应当责令提供担保（非一律担保）
   └─ 方法：查封扣押录音录像复制鉴定勘验；选对持有人影响最小的措施；
      保全错误致损应赔偿；其他程序参照第九章财产保全
                          │
   ▼ 第五关：当庭怎么质证？法院怎么认证？（民诉法§71 + 解释§103-106）
   │
   ├─ 质证主体＝当事人互相质证（抗诉机关出席≠质证）
   ├─ 未经质证的证据 ──→ ❌ 不得作为认定案件事实的根据（§103 I）
   │   └─ 例外"视为质证过"：准备阶段认可＋庭审说明（§103 II）；
   │      准备阶段/调查询问中发表过质证意见（证据规定§60）
   ├─ 涉国秘·商秘·隐私 ──→ 不得公开质证（依职权"应当"，勿混§137申请不公开审理）
   ├─ 质证围绕真实性、合法性、关联性 + 证明力辩论（§104）
   ├─ 排非三标准（§106）：严重侵害他人合法权益 / 违反法律禁止性规定 /
   │   严重违背公序良俗 ──→ 过线才排除；私录未经同意 ≠ 当然排除
   └─ 认证（§105）：逻辑推理 + 日常生活经验法则，公开判断理由和结果
```

> **一句话总诀**：**「期限可商量、指定有下限（一审15二审10）；延期届满前、逾期分三层（客观视为未逾、无过采纳训诫、故意重过原则不采但涉基本事实必须采＋训诫罚款）；调取先看五清单、清单外靠申请、门槛是客观拿不到；保全诉中怕灭失、诉前加紧急、管辖三选一、致损才担保；质证是铁律、未质不认定、涉密不公开、排非看三线、认证讲心证公开」**

## 三、 两个高频干扰（逾期＝一律不采？ / 未经同意的私录＝非法？）

命题人极喜欢在"逾期后果的分层"和"排非标准"上挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **逾期证据一刀切排除** | 当事人未在举证期限内提交证据，又不属于"新的证据"，法院应不予采纳。 | **❌ 说法错误！要看是否涉案件基本事实。**依解释§102，故意/重大过失逾期原则上不予采纳，**但与案件基本事实有关的应当采纳**，同时训诫、罚款；非因故意/重大过失逾期的**应当采纳并训诫**。"是否新证据"与"逾期证据能否采纳"是两个层面，不能拿"非新证据"一刀切。 |
| **未经同意的私录是非法证据** | 未经对方同意私自录音侵犯他人权利，属非法证据，不具有证据能力。 | **❌ 说法错误！只看三条红线。**依解释§106，只有以**严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗**的方法形成或获取的证据才排除。偷录自己参与的谈话通常不过线，**具有证据能力**；"剪辑后存疑"影响的是**证明力**，不是证据能力。 |

## 四、 依职权调查 vs 依申请调查 · 诉前保全 vs 诉中保全（两组对照）

**对照一：法院调查收集证据的两条通道**（解释§94/§96，命题最爱换着考）

| 事项 | 依职权调查（法院主动） | 依申请调查 |
|---|---|---|
| 法律依据 | 民诉法§67 II 后段＋解释§96 I | 民诉法§67 II 前段＋解释§94 |
| 适用范围 | **五项清单**：国益公益 / 身份关系 / 公益诉讼（§58） / 恶意串通损害他人合法权益可能 / 依职权追加当事人·中止终结·回避等程序性事项 | **客观原因不能自行收集**：国家有关部门保存无权查阅调取 / 涉国秘·商秘·隐私 / 其他客观原因 |
| 是否需当事人申请 | 不需要，法院**应当**主动 | 必须申请，且在**举证期限届满前书面**提出 |
| 典型排除 | 清单之外法院不得自行出手（§96 II：应当依申请进行） | "没时间""嫌麻烦"是主观懈怠，不予准许；无关联/无意义/无必要的不予准许（§95） |
| 共同点 | 调查收集均须**两人以上**共同进行，调查材料由调查人、被调查人、记录人签名捺印或盖章（§97） | 同左 |

**对照二：证据保全的诉前与诉中**（民诉法§84）

| 事项 | 诉中证据保全（§84 I） | 诉前证据保全（§84 II） |
|---|---|---|
| 实体条件 | 证据可能灭失或以后难以取得 | 同左＋**因情况紧急** |
| 启动主体 | 当事人申请，法院**也可以主动** | 仅**利害关系人**申请（法院不主动） |
| 申请时点 | 举证期限**届满前书面**提出（解释§98 I） | 起诉或申请仲裁前 |
| 管辖法院 | 受诉法院 | **证据所在地、被申请人住所地或对案件有管辖权**的法院（三选一） |
| 担保 | 可能对他人造成损失的，**应当责令**提供担保（解释§98 II）；申请查封扣押等限制流通措施或可能致持有人损失的应当责令担保（证据规定§26） | 同左 |
| 后续衔接 | — | 诉前保全后向其他有管辖权法院起诉的，保全法院应依申请**移交**保全的证据（证据规定§29） |

> ⚠️ **易混条号**：民诉法证据保全现行是**§84**（2023修正），《证据规定》§25/§26 原文写的"第八十一条"是**旧编号**；诉前**财产**保全的管辖是"被保全财产所在地、被申请人住所地或对案件有管辖权的法院"（§104），诉前**证据**保全把第一项换成了"**证据所在地**"，别混。

## 五、 万能四步答题模型

在法考答题中（无论客观题选项判断，还是主观题程序合法性分析），按照以下四步进行涵摄：

*   🚗 **统一案例**：甲起诉乙返还借款**20万元**，法院指定**30日**举证期限。①乙辩称已还**8万元**、有甲出具的收条，但期限内没交，二审才找到提交；②甲主张的关键转账记录由**市场监管部门**保存、甲无权调取，甲另称"忙于生意没空收集"其余证据；③乙仓库门口的**监控录像7天自动覆盖**，眼看要没了；④甲还**私自录了**乙承认借款的谈话录音，剪辑后提交，乙拒不发表质证意见。

### 第一步：限期交证——举证期限怎么定、怎么延？

> **期限可商指定有底，延期要赶届满前**

#### 概述

举证期限是法院给当事人划的"交证据截止日"，规则有三层：

- **怎么定**：审理前的准备阶段确定；可以**当事人协商＋法院准许**（协商的天数不受法定下限约束），也可以法院**指定**——指定的，一审普通程序**不得少于15日**，当事人提供新的证据的二审案件**不得少于10日**（解释§99）；简易程序**不超过15日**、小额诉讼一般**不超过7日**（证据规定§51）。
- **怎么延**：期限内提供确有困难的，**在届满前**向法院提出**书面**申请；理由成立的应当准许并通知其他当事人，**延长的期限适用于其他当事人**；理由不成立的不予准许（民诉法§68 II、解释§100）。
- **一个宽松口**：期限届满后，对**已经提供的证据**申请提供**反驳证据**、或对证据来源/形式**瑕疵进行补正**的，法院可酌情**再次确定期限**，且不受"15日/10日"下限约束（解释§99 III）。

#### 大白话讲解

法院立案后给甲乙发了举证通知书："30天内把证据都交上来。"这30天怎么来的？两种可能：一是甲乙自己商量"我们25天就够"，法院点头认可——**协商的天数法律不管下限**，25天、20天都行；二是法院直接指定——指定就有底线，一审普通程序**最少15天**，不能今天通知明天截止。

到第28天，乙发现有份对账单在外地分公司，来不及取。怎么办？**赶在第30天之前**给法院递一份**书面**延期申请。法院一看理由成立，批了延长10天——注意，这延长的10天**不是乙的专属福利**，甲也跟着多10天。

反过来，如果乙拖到第35天（届满后）才想起来申请延长——**晚了**，届满后申请延长不符合规定，法院驳回没商量。

| 要素拆解 | 本案对应 | 是否合规 |
|---|---|---|
| 协商确定25天期限＋法院准许 | 甲乙协商、法院认可 | ✅ 合规（协商不受15日下限约束） |
| 法院指定30天（一审普通） | ≥15日 | ✅ 合规 |
| 届满前书面申请延长 | 第28天申请 | ✅ 应当准许（理由成立时），且延长适用双方 |
| 届满后才申请延长 | 第35天申请 | ❌ 不符合规定 |

#### 一句话闭环记忆

> 🎯 **一眼判**：期限**可协商**（经准许、天数自由）；法院**指定有下限**（一审15、二审新证据10、简易≤15、小额≤7）；**延期申请必须届满前书面提**——见"届满后申请延长"直接判错。

---

### 第二步：迟交的代价——逾期举证的分层后果

> **客观视为未逾期，无过采纳加训诫，故意重过原则不采，涉基本事实必采罚**

#### 概述

逾期交证据不是"一律作废"，而是一套**四层流水线**（民诉法§68＋解释§101/§102）：

1. **先问理由**：逾期提供的，法院**应当责令说明理由**，必要时要求提供相应证据；
2. **客观原因豁免**：因**客观原因**逾期，或者**对方当事人未提异议**的——**视为未逾期**，完全没事；
3. **非因故意或重大过失**：法院**应当采纳**，但对当事人**予以训诫**；
4. **故意或重大过失**：原则上**不予采纳**——**但该证据与案件基本事实有关的，应当采纳**，并依民诉法§68、§118 I **训诫、罚款**（罚款数额结合过错程度、诉讼迟延情况、诉讼标的金额确定——证据规定§59）。

另有一条"补偿条款"：一方因对方逾期举证**增加的交通、住宿、就餐、误工、证人出庭**等必要费用，可以要求对方赔偿（§102 III）。

#### 大白话讲解

乙手里那张"已还8万元"的收条，一审期限内没交，二审才找到提交。甲当场反对："过期了，法院别收！"法院怎么走流程？

**第一步先问乙**："为什么迟交？"乙答："一审时真找不到，搬家翻箱倒柜二审才翻出来。"

**然后分层定性**：

- 如果乙是**客观原因**（比如收条一直被第三人扣着刚要回来），或者**甲压根没提异议**——视为未逾期，正常质证采纳；
- 本案乙"一审没找到、二审找到了"——**非因故意或重大过失**，法院**应当采纳**这张收条，同时**训诫**乙一顿："下次早点找！"
- 假设换个剧本：乙一审时收条就在手里，故意压着不交想搞二审突袭——**故意逾期**，原则上不予采纳。**但是**，这张收条证明"20万里已还8万"，直接关系**借款是否部分清偿**这一**案件基本事实**——不采纳就可能判错案。所以法院**仍然应当采纳**，只是要对乙**训诫＋罚款**（程序上罚你，实体上不冤枉你）。罚多少？看乙的过错程度、拖延了多久、案子标的多大。
- 甲因为乙迟交收条多跑了一次法庭，多花的车费、误工费，可以要乙赔。

**一张表看清四层**：

| 逾期情形 | 后果 | 记忆点 |
|---|---|---|
| 客观原因逾期 / 对方未提异议 | 视为未逾期 | 完全豁免 |
| 非因故意或重大过失 | **应当采纳＋训诫** | 罚轻 |
| 故意或重大过失＋与基本事实无关 | 不予采纳 | 唯一真正"作废"的情形 |
| 故意或重大过失＋**与基本事实有关** | **应当采纳＋训诫、罚款** | 实体优先、程序制裁 |

#### 一句话闭环记忆

> 🎯 **一眼判**：逾期四层——**客观豁免、无过采纳训诫、故意重过原则不采、涉基本事实必须采纳＋训诫罚款**。见"涉还款/涉合同真伪的证据因逾期一律不予采纳"直接判错；采纳与否**不取决于对方同意**、也不看"是否新证据"。

---

### 第三步：自己拿不到找法院——依职权与依申请的界限

> **五项清单法院主动，清单之外凭申请，门槛只认客观拿不到**

#### 概述

当事人举证是原则，法院取证是**补充**。法院出手只有两条通道（民诉法§67 II）：

- **依职权（主动出手）**：仅限解释§96 I 的**五项清单**——
  1. 涉及可能损害**国家利益、社会公共利益**的；
  2. 涉及**身份关系**的；
  3. 涉及民诉法§58 **公益诉讼**的；
  4. 当事人有**恶意串通损害他人合法权益可能**的；
  5. 涉及依职权**追加当事人、中止诉讼、终结诉讼、回避**等**程序性事项**的。
  清单之外，法院调查收集**应当依照当事人的申请进行**（§96 II）。
- **依申请（当事人递条子）**：门槛是"**因客观原因不能自行收集**"（解释§94）——证据由**国家有关部门保存、当事人无权查阅调取**的；涉及**国家秘密、商业秘密、个人隐私**的；其他客观原因。申请须在**举证期限届满前书面**提出；与待证事实**无关联、无意义、无必要**的不予准许（§95）。
- **程序要求**：法院调查收集证据，应当由**两人以上**共同进行（§97）。

#### 大白话讲解

甲有两笔证据自己搞不定，都想让法院帮忙，法院的答复截然不同：

**第一笔**：证明乙收款的备案材料存在**市场监管部门**档案里，甲去调、人家说"个人无权查阅"。这就是典型的"**证据在国家机关手里、当事人无权调取**"——**客观原因**，甲在举证期限届满前递**书面申请**，法院**应当**去调。

**第二笔**：甲说"我最近忙生意，没空去收集别的证据，法院替我跑跑腿吧"。法院白眼一翻："**没时间是你自己的事**，不是客观拿不到——不准。"举证是甲自己的责任，法院不是甲的跑腿员。

**再看法院什么时候不用等申请、自己就动手**：审理中法院发现甲乙这场官司可能是**串通演戏**、想借判决坑案外人丙——这落在五项清单第4项"**恶意串通损害他人合法权益可能**"，法院**应当主动**调查收集证据，谁也不用申请。同理，案子涉及**亲子关系**（身份关系）、涉及**国家利益**、或者要不要**追加当事人/回避**这类程序事项，法院都自己查。

| 情形 | 通道 | 结论 |
|---|---|---|
| 备案材料在市场监管部门、甲无权调取 | 依申请（§94 I ①） | 届满前书面申请，法院应当调取 |
| 甲"忙于生意没空收集" | 不属客观原因 | ❌ 不予准许 |
| 甲乙有恶意串通损害丙的可能 | 依职权（§96 I ④） | 法院应当主动调查 |
| 清单外的普通证据 | §96 II | 法院只能依申请，不得主动 |

#### 一句话闭环记忆

> 🎯 **一眼判**：依职权只认**五项清单**——"**国益公益、身份关系、公益诉讼、恶意串通、程序事项**"；清单外**一律依申请**，申请只认"**客观**拿不到"（国家部门保存无权调取是标配案型）——见"没时间/不方便/嫌麻烦"直接判不属客观原因。

---

### 第四步：怕灭失先保全，当庭对质排非认证

> **灭失保全紧急诉前，管辖三选一致损才担保；未质不认定，排非看三线，心证要公开**

#### 概述

这一步是流水线的收尾，两块内容：

**（1）证据保全（民诉法§84＋解释§98＋证据规定§25-29）**：
- **诉中**：证据**可能灭失或以后难以取得**的，当事人可在举证期限**届满前书面**申请，法院**也可以主动**采取；
- **诉前**：在"可能灭失或难以取得"之上再加"**因情况紧急**"，利害关系人在起诉/仲裁前向**证据所在地、被申请人住所地或对案件有管辖权**的法院申请（三选一）；
- **担保**：保全**可能对他人造成损失**的，法院**应当责令**申请人提供担保（不是一律担保）；
- **方法与限度**：查封、扣押、录音、录像、复制、鉴定、勘验等，并制作笔录；应选择对证据持有人**利益影响最小**的措施；申请保全**错误**造成财产损失的应当赔偿；其他程序**参照财产保全**（第九章）。

**（2）质证与认证（民诉法§71＋解释§103-106）**：
- 证据应当**在法庭上出示**，由**当事人互相质证**；**未经质证的证据，不得作为认定案件事实的根据**——铁律；
- "视为质证过"两个例外：审理前准备阶段**认可**的证据经审判人员庭审中**说明**；准备阶段或法院**调查、询问过程中发表过质证意见**（证据规定§60）；
- **涉密证据不得公开质证**（依职权的"应当"）；质证围绕**真实性、合法性、关联性**并就证明力辩论（§104）；
- **排非三标准**（§106）：**严重侵害他人合法权益 / 违反法律禁止性规定 / 严重违背公序良俗**——过线才排除；
- **认证**（§105）：法院运用**逻辑推理和日常生活经验法则**判断证明力，并**公开判断的理由和结果**（心证公开）。

#### 大白话讲解

**先说保全**：乙仓库门口的监控录像能证明货物交付情况，但系统**7天自动覆盖**——再不动手证据就没了。

- 如果甲**已经起诉**：在举证期限届满前给受诉法院递书面申请"把录像保全下来"；就算甲不申请，法院发现了也**可以主动**保全。
- 如果甲**还没起诉**、录像明天就要覆盖（**情况紧急**）：甲作为利害关系人，可以在起诉前向**录像所在地（乙仓库所在地）**、**乙住所地**或**将来对案件有管辖权**的法院申请——三个法院随便挑一个。
- 要不要担保？法院看：复制一份录像**不会给乙造成什么损失**——不责令担保；假如保全方式是把乙的服务器**整机扣押**、影响乙营业——**应当责令**甲提供担保。保全方式上，能"复制"就不"扣押"，选**对乙影响最小**的。万一甲保全错了、给乙造成损失，甲要赔。

**再说质证**：开庭了，甲把私自录的谈话录音（剪辑版）拿出来，乙气呼呼**拒绝发表质证意见**。三个问题当庭见分晓：

- **这录音能不能用（证据能力）？** 看§106三条红线：甲录的是**自己参与**的谈话，没严重侵害谁的权益、没违反禁止性规定、不违公序良俗——**能用**。"未经乙同意"不是排除理由。
- **剪辑了怎么办？** 剪辑让真实性存疑——这砍的是**证明力**（法院信几分），不是证据能力（能不能进法庭）。法院会结合收条、转账记录等其他证据综合判断。
- **乙拒绝质证，录音是不是就"未经质证"不能认定了？** 不是。法院**组织了质证程序**、乙有机会发表意见而自己放弃，不等于"未经质证"（对照：解释§387——原审中拒绝发表质证意见的，不属于"未经质证"）。真正的"未经质证"是法院**根本没组织**质证就拿去定案——那才踩了§103的铁律，构成再审事由。
- 最后**认证**：法官不能拍脑袋，要按逻辑推理和生活经验判断"录音＋借条＋转账记录"能否形成完整链条，并在判决书里**公开说理**——为什么信、信几分，写明白。

#### 一句话闭环记忆

> 🎯 **一眼判**：保全口诀——**诉中"可能灭失"即可、诉前还须"情况紧急"；诉前管辖"证据所在地/被申请人住所地/有管辖权法院"三选一；"可能致他人损失"才责令担保**。质证认证口诀——**未经质证不得认定（但"准备阶段认可＋说明"“发表过意见”视为质证过、"拒绝质证"不算未经质证）；排非只认三条线，私录未经同意不当然排；涉密不公开质证是依职权"应当"；认证靠逻辑经验＋公开心证**。

## 六、 易混提示

*   **"不得公开质证"（§71/§103） vs "不公开审理"（§137）**：
    *   *涉密证据不公开出示/质证*是法院**依职权**的"应当"，不以当事人申请为条件；*离婚案件、涉商业秘密案件不公开审理*须**当事人申请**且法院"可以"（离婚/商秘）——一个管"证据出示环节"，一个管"整个庭审"。
*   **证据能力 vs 证明力**：
    *   *证据能力*（能不能进法庭）看§106三条红线；*证明力*（可不可信、信几分）看真实性、完整性——"剪辑存疑""视听资料有疑点不能单独定案"都在证明力层面。
*   **"未经质证" vs "拒绝质证"**：
    *   *法院未组织质证*就定案→违反§103铁律，构成再审事由；*当事人有机会却拒绝/未发表质证意见*→不属"未经质证"（解释§387）。
*   **诉前证据保全管辖 vs 诉前财产保全管辖**：
    *   证据保全＝**证据所在地**/被申请人住所地/有管辖权法院；财产保全＝**被保全财产所在地**/被申请人住所地/有管辖权法院——第一项不同。
*   **民诉法§68 vs 解释§102**：
    *   §68 是"不予采纳或采纳＋训诫罚款"的**概括授权**；§102 才是"故意重过/非故意重过/涉基本事实"的**精细分层**——引用条文别张冠李戴。

## 七、 命题人最爱的 5 个陷阱

1.  **"逾期提交且不属新证据的，法院一律不予采纳"** —— 错！与案件基本事实有关的逾期证据**应当采纳**（辅以训诫、罚款）；非因故意或重大过失逾期的也应当采纳＋训诫（解释§102）。
2.  **"当事人没时间收集证据，可申请法院调查收集"** —— 错！依申请调查的门槛是"**客观原因**不能自行收集"（国家部门保存无权调取等），"没时间"是主观懈怠；且清单外法院不得主动出手（解释§94/§96）。
3.  **"举证期限届满后仍可申请延长举证期限"** —— 错！延期申请必须在**届满前**书面提出（民诉法§68 II、解释§100）；届满后只有"反驳证据/瑕疵补正"可获酌情再定期限。
4.  **"申请证据保全的一律应当提供担保"** —— 错！只有保全**可能对他人造成损失**（或采取查封扣押等限制流通措施）的，法院才**应当责令**担保（解释§98 II、证据规定§26）。
5.  **"未经对方同意的偷录录音属非法证据应予排除" / "涉商业秘密的证据须当事人申请才不公开出示"** —— 双错！排非只认§106三条红线，私录不当然排除；涉密证据**不得公开质证**是法院依职权的"应当"（§71），须申请的是§137的"不公开**审理**"。
