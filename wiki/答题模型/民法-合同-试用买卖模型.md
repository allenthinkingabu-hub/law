# 📐 试用买卖 · 答题模型（认定 → 定期 → 推定 → 风险费用）

> 凡"试用买卖"题，按这四步走。**核心四件事**：①**认定**（约定试用期 + 买受人享"买不买"选择权）② **试用期谁定**（约定 → §510 → 出卖人；无 6 个月法定值）③ **视为购买**（期满未表示 / 期内付款·出卖·出租·设担保）④ **风险 + 使用费**（风险归出卖人 · 使用费无约定不付）。
> **姊妹模型** → [[民法-合同-分期付款买卖模型]]（同属买卖合同特别类型）。
> **适用真题**：[[典型合同-单选-02|C2-单选-02·使用费]] · [[典型合同-多选-02|C2-多选-02·试用期+视为购买]] · [[典型合同-单选-21|C2-单选-21·四判断]]
>
> 🔎 **法条已联网核实（2026-06-11，最高检 spp.gov.cn 买卖合同章全文 + 第638条释义双源 CONFIRMED）**：试用买卖＝《民法典》**§637-§640**（共 4 条）。§637 试用期确定 · §638 视为购买 · §639 使用费 · §640 风险。
> ⚠️ **纠错提示**：本 wiki 旧文件曾普遍误记为"§638-§641"——**§641 是所有权保留**（§641-643），不属试用买卖。本模型及配套页已按核实编号统一更正。

## 一、核心考情

- **频率**：试用买卖是 [[买卖合同]] ★★★★ 高频特别类型，客观题单选/多选常出 1 道，类型双机构点名，常作"经典陷阱行"。
- **命题核心**：围绕"**这到底算不算购买**"（视为购买的触发）+ "**试用期内的风险/费用归谁**"出题，全是"看着对、其实错"的混淆陷阱，不考纯记忆。
- **四大必考点**：①试用期未约定怎么定（**出卖人**，非"6 个月"）②视为购买的**两类触发** ③试用期风险归**出卖人** ④使用费无约定**不付**。

## 二、万能四步模型

### 第一步：认定——是不是"试用买卖"？

**铁则**：试用买卖＝当事人**约定试用期间**，买受人在期内**先试用、再决定买不买**的附条件买卖（§637）。本质是"**以买受人认可为生效条件**"的买卖——买卖**尚未确定生效**。
- 三个识别特征：①约定试用期 ②买受人对"是否购买"享**单方选择权** ③标的物已交付买受人**占有 + 可使用**。
- 易混区分：试用 vs [[保管合同|保管]]——试用**占有且可使用**；保管**不可使用**。

**老王小李例子**
- ✅ 是：老王商场告示"家电试用 20 天、满意再付款"，小李搬回家试用 → 试用买卖。
- ❌ 不是：小李把电器寄放老王处、不得使用 → 保管合同，不是试用买卖。

### 第二步：试用期怎么定？（约定 → §510 → 出卖人）

**铁则（§637）**：试用期由**当事人约定**；没约定 / 约定不明，依 §510 仍不能确定的 → **由出卖人确定**。
- ⚠️ **没有"6 个月"法定值**——6 个月是别的制度（如保证期间）的数字，硬塞进试用买卖就是陷阱；也**不是**由买受人确定。

**老王小李例子**
- 老王小李没约定试用期、事后也协商不拢 → 由**老王（出卖人）**确定，既非"自动 6 个月"，也非买受人小李说了算。

### 第三步：视为购买了吗？（§638 两类触发 + 两种不买）

**铁则（§638）**——出现下列任一，**视为购买 / 视为同意购买**：
- Ⅰ **期满未表示**：试用期届满，买受人对买不买**未作表示** → **视为购买**。
- Ⅱ **期内以行为表明**：试用期内① **支付部分价款** ② **出卖** ③ **出租** ④ **设立担保物权** → **视为同意购买**（行使了只有所有权人才有的处分 / 收益权）。

**不构成购买**：试用期内**明确拒绝**，或**期满前退回**标的物 → 行使选择权拒买，无须付款。

**老王小李例子**
- ✅ 视为购买：小李试用期满没吭声（Ⅰ）；或试用期内先付了部分款 / 把机器转租给老张（Ⅱ）。
- ❌ 不购买：小李试用期内明确说"不要了"并退回 → 拒绝购买。
- 🪤 **期满后才退**：期满那一刻已"视为购买"，**第二天再退**，老王有权**拒绝受领**（买卖已成立）。

### 第四步：试用期内的风险 + 使用费（§640 + §639）

**铁则**：
- **风险（§640）**：试用期内标的物**毁损、灭失的风险由出卖人承担**——因为买受人认可前**所有权仍属出卖人**，买受人**不必支付价款**。
- **使用费（§639）**：对使用费**没约定 / 约定不明** → 出卖人**无权请求**（无约定不付）。

**老王小李例子**
- 风险：试用期内机器遭意外火灾毁损（非小李过错）→ 风险归**老王**，小李**不付**价款。
- 使用费：没约定使用费，小李试用 20 天后退回 → 老王**不能**要 100 元使用费。

### ⚠️ 易混提示（一句话防混）

- **试用期 vs [[检验期]]（§621-623）**：试用期决定"**买不买**"；检验期决定"**已买的合不合格**"——两个层面，别混。
- "未对质量提异议" ≠ "视为购买"——质量异议是检验期的事；视为购买看"是否表示购买 / 期满未表示"。

## 三、命题人最爱的 5 个陷阱

1. **"未约定试用期 = 6 个月 / 买受人定"** —— 错！无法定值，由**出卖人**确定（§637）。（[[典型合同-多选-02|多选-02]] 的 A、B 反向考）
2. **"未对质量提异议 = 视为购买"** —— 错！混淆了试用期与检验期；视为购买看"期满未表示 / 付款·出租等行为"。（[[典型合同-单选-02|单选-02]] D、[[典型合同-多选-02|多选-02]] D）
3. **"试用期内付款 / 出租只是用一下，不算买"** —— 错！支付价款 / 出卖 / 出租 / 设担保 = **视为同意购买**（§638 Ⅱ）。（[[典型合同-单选-21|单选-21]] A、C）
4. **"试用期内东西坏了，买受人付钱"** —— 错！风险归**出卖人**，买受人不付价款（§640）。（[[典型合同-单选-21|单选-21]] D，正确答案）
5. **"试用要交使用费 / 期满后还能退"** —— 错！使用费无约定**不付**（§639）；且**期满未表示已视为购买**，事后退货商家有权拒收（§638 Ⅰ）。（[[典型合同-单选-02|单选-02]]、[[典型合同-单选-21|单选-21]] B）

## 四、真题演练（套四步模型）

### 范例①：[[典型合同-单选-02|C2-单选-02]]（试用 20 天退回，商场索 100 元使用费）→ **A**
- **第一 / 三步**：小李**期满前退回** = 明确拒绝购买，不构成视为购买。
- **第四步**：使用费**无约定** → 老王无权请求（§639）→ **不付使用费**。
- → **A** ✅。（B 错：试用期由出卖人定，非买受人；C 无法律依据；D 把"退回"误当"视为购买"。）

### 范例②：[[典型合同-多选-02|C2-多选-02]]（未约定试用期，期满未达成购买协议）→ **BC**
- **第二步**：未约定 → **出卖人**确定（B 对）；无"6 个月"（A 错）。
- **第三步**：期满未表示 → **视为购买**（C 对）；"未对质量异议 = 购买"是混淆（D 错）。
- → **BC** ✅。

### 范例③：[[典型合同-单选-21|C2-单选-21]]（四个判断选"不正确"）→ **D**
- A 期内付部分价款 = 视为同意购买（§638 Ⅱ）→ 真。
- B 期满未表示已视为购买，第二天退货商场可拒收（§638 Ⅰ）→ 真。
- C 期内出租 = 行使所有权权能 = 视为同意购买（§638 Ⅱ）→ 真。
- D 试用期风险归**出卖人**，火灾毁损买受人**不付**价款（§640）→ **错**，故选 **D** ✅。

## 📐 口诀

> **"试用先试后挑买：期定靠卖家，6 个月是诈；期满不吭声、付款出租设押＝买定了；东西没买先烧了，风险使用费都赖卖家。"**
