# 📐 侵权责任 · 总论模型（先定归责 → 套四要件 → 数人分担 → 免责减责 + 8 类特殊侵权速查）

> **核心一句**：侵权题永远先问两件事——**①归责原则是哪一种（过错 / 过错推定 / 无过错）②谁是责任主体**；这两样一定，要件、举证、免责全跟着走。本模型是侵权的"**归责调度台**"。**交叉口让位专题页**：竞合（一行为又违约又侵权）→ [[民法-合同-责任竞合模型]]；精神损害边界 → [[精神损害赔偿]]；三大责任顶层对比 → [[民事责任体系]]。
> 🔎 **三处务必内化**：
> ① **"三原则"里，过错推定不是独立第三类**——过错责任 §1165Ⅰ（**原告举证**过错）/ 过错推定 §1165Ⅱ（**举证倒置**、本质仍是过错、**仅法定情形**）/ 无过错 §1166（**法定主义**，法无明文不适用）。
> ② **归责定举证**——过错责任受害人证过错；过错推定加害人**自证无过错**；无过错不问过错（只剩法定免责抗辩）。**最大失分点 = 把特殊侵权的归责原则记反**（医疗是过错不是无过错；脱落坠落是过错推定不是无过错）。
> ③ **无过错 ≠ 绝对责任**——仍有**法定**免责事由（如受害人故意）；且 **§1186 公平分担不是归责原则**，是"双方都无过错时**依照法律的规定**由双方分担损失"（2021 收紧，不再是兜底）。

## 一、核心考情（含考频 + 机构研判免责）

> ⚠️ **考频免责声明**：司法部自 2018 年法考改革起，官方**仅公布大纲、合格分数线、成绩，从不公开历年真题原题及任何"考点频次"统计**。下列"高频 / 必考"均系机构 / 法学院清单**公认口径**，**非官方一手数据**，不得伪造频次。

- **考频定性**：民法全卷 ≈48 分（全卷之最），**侵权责任编是债法两大支柱之一、机构公认民法里仅次于合同的高频高分块**——客观题常年多题，**主观题几乎必考一道侵权请求权分析**。
- **三大必考维度**：①**归责原则**识别（过错 / 推定 / 无过错——头号考点也是头号陷阱）②一般侵权**四要件** + 数人侵权**连带 / 按份 / 补充** ③**8 类特殊侵权**各自的归责 / 主体 / 免责。
- **考查形态**：客观题以案例选择为主（给情节问归责 / 谁担责 / 能否免责）；主观题作请求权基础分析主线。
- ⚠️ **真题存量提示**：**本库以合同真题为主，侵权真题暂缺、待补**；目前仅 [[合同通则-多选-17]]（录像带）作"竞合擦边"。回填侵权历年 / 机构真题后挂第六部分。

## 二、归责三原则对照表（侵权第一关）

> 拿到任何侵权题，先翻这张表定归责；**法无"推定 / 无过错"明文 → 一律回到过错责任 §1165Ⅰ**。

| 归责原则 | 条文 | 谁举证过错 | 典型适用 | 免责口径 |
|---|---|---|---|---|
| **过错责任** | §1165Ⅰ | **受害人**证加害人有过错 | 一般侵权（打人 / 撞坏物 / 一般场所安保 §1198 / 限制行为能力学生 §1200 / 承揽定作人 §1193 / 机动车之间） | 证明自己无过错 |
| **过错推定** | §1165Ⅱ（**须法定**） | **加害人自证无过错**（倒置） | 医疗三情形 §1222 / 动物园 §1248 / 脱落坠落 §1253 / 堆放 §1255 / 林木 §1257 / 施工地下设施 §1258 / 无行为能力学生 §1199 | 自证尽责 / 无过错即免 |
| **无过错** | §1166（**须法定**） | 不问过错 | 产品 §1202 / 机动车对行人（交强险） / 环境 §1229 / 高度危险 §1236 / 饲养动物 §1245 / 监护人 §1188 / 用人单位 §1191 | **仅法定免责**（如受害人故意） |

## 三、万能五步模型

### 第〇步（前置过滤）：先定"归责原则"

**铁则**：先判这题落在哪一类——
- 法律有**过错推定 / 无过错**明文（产品 / 机动车 / 医疗 / 环境 / 高危 / 动物 / 物件 / 监护 / 用人 / 教育机构…）→ 按其**特殊归责**（见第二表 + 第五部分速查）；
- **没有**明文 → 一般侵权，走**过错责任 §1165Ⅰ**（受害人举证）。
- ⚠️ 过错推定、无过错都是**法定主义**，法无规定**不得**适用；别把一般侵权当无过错。

> 🏠 **实际案例**（待补侵权真题，暂以通用例）：邻居装修砸坏你家墙 = 一般侵权**过错责任**（你证他有过错）；楼上花盆坠落砸人 = §1253 **过错推定**（占有人自证无过错才免）；产品缺陷致伤 = §1202 **无过错**（不问生产者过错）。

### 第一步：一般侵权"四要件"（过错责任的骨架）

**铁则**：四要件齐备才成立——① **加害行为**（作为 / 不作为；不作为须有**作为义务**）② **损害**（人身 §1179 / 财产 §1184 / 精神 §1183）③ **因果关系**（相当因果）④ **过错**（故意 / 过失）。
- **无过错责任**省略"④过错"要件（只需 ①②③ + 落入法定情形）；**过错推定**则把"④过错"的举证倒置给加害人。
- **预防性责任 §1167**（停止侵害 / 排除妨碍 / 消除危险）：**不要过错、不要已发生损害**，行为"危及"他人安全即可请求。

### 第二步：数人侵权——连带 / 按份 / 补充（责任形态独占线）

**铁则**（五分法 + 补充责任）：
- **共同侵权 §1168**（共同故意 / 行为关联共同）→ **连带**；
- **教唆 / 帮助 §1169Ⅰ**（对**完全**行为能力人）→ **连带**；教唆 / 帮助**无 / 限制**行为能力人 §1169Ⅱ → 教唆帮助人担责 + 监护人按**过错**担"**相应责任**"（**非连带**）；
- **共同危险 §1170**（致害人不明）→ **连带**；**能确定**具体侵权人 → 该人单独担、余者免；
- **叠加分别侵权 §1171**（无意思联络，各自**足以致全损**）→ **连带**；
- **分别侵权 §1172**（无意思联络，各自**部分原因力**）→ **按份**（定不了份额 → **平均**）；
- **补充责任**：安保 §1198 / 教育机构第三人致害 §1201——**第三人是主责**，义务人未尽责担"**相应的补充责任**"（顺位在后）+ **可向第三人追偿**（2021 新增追偿权）。
- ⚠️ **§1171 连带 vs §1172 按份**分水岭 = 各自是否"**足以致全损**"；**补充责任 ≠ 连带 ≠ 按份**。

> 🏠 **实际案例**（[[合同通则-多选-17]]，竞合擦边）：乙、丙**无意思联络分别**烧毁同一录像带、各为**部分原因力** → **§1172 按份**（不是连带）。该题主轴是竞合，详见 [[民法-合同-责任竞合模型]]。

### 第三步：责任主体特殊——"谁来赔"（替代 / 补充）

**铁则**（最常考主体）：
- **监护人 §1188**：无 / 限制行为能力人致害 → 监护人**无过错**责任（尽到监护职责只**减轻、不免除**）；有财产的**先从本人财产**付，不足部分监护人补。
- **用人单位 §1191 / 个人劳务 §1192**：工作人员 / 提供劳务方因**执行工作**致**他人**损害 → 单位 / 接受劳务方**无过错**替代担责；**追偿**限工作人员有**故意或重大过失**。提供劳务方**自己受伤** → 按**双方各自过错**（可过失相抵）。
- **承揽 §1193**：定作人**原则不担责**；仅"**定作 / 指示 / 选任**"有**过错**才担"相应责任"（过错责任）。
- **网络 §1194-1197**：§1195 避风港（通知 + 必要措施；未及时仅就**损害扩大部分**连带）/ §1196 反通知 / §1197 红旗规则（"**知道或应当知道**"未采措施 → 连带）。
- **教育机构**：无行为能力人 §1199 = **过错推定**（机构自证尽责才免）/ 限制行为能力人 §1200 = **过错**（原告举证）/ 第三人致害 §1201 = 机构未尽管理职责担"**相应补充责任**" + 追偿。
- ⚠️ **§1199（无 → 推定）vs §1200（限制 → 过错）别记反**；§1188 监护**无过错（只减轻）** vs §1169Ⅱ / 教育机构监护**过错（可免）** 别混。

### 第四步：免责与减责事由（抗辩）

**铁则**：
- **完全免责**：受害人**故意** §1174；不可抗力 §180；正当防卫 §181（过当部分仍担）；紧急避险 §182（险情引起人担、自然原因则避险人**适当补偿**）；**自甘风险 §1176**（自愿参加风险文体活动，其他参加者**非故意 / 重大过失**不担）；**自助行为 §1177**（合法权益受损 + 情况紧迫 + 不能及时获公力救济 → 必要范围内扣留 + **立即报官**）。
- **减轻**：**过失相抵 §1173**（受害人对损害发生 / 扩大**有过错** → **减轻、非免除**）；见义勇为受益人 §183 适当补偿。
- ⚠️ 受害人**故意** = 免责（§1174）；受害人**过失** = 减轻（§1173）——**效果不同**。无过错责任里通常只有"受害人故意 / 重大过失"等**法定**事由能抗辩。

### 第五步：8 类特殊侵权速查表（归责 / 主体 / 免责一表打尽）

> 用法：题干一出现"产品 / 车祸 / 看病 / 污染 / 爆炸 / 动物 / 楼上掉东西 / 雇员闯祸"，直接查这张表定**归责 + 主体 + 免责**。

| # | 类型（条文） | 归责原则 | 责任主体 | 免责 / 要点 |
|---|---|---|---|---|
| 1 | **产品** §1202-1207 | 生产者**无过错** / 销售者**过错**（被侵权人**可任选**请求，内部按过错追偿） | 生产者 / 销售者 | 免责见《产品质量法》§41 三事由；§1207 惩罚性须**明知缺陷 + 死亡 / 严重健康损害** |
| 2 | **机动车** §1208-1217 | 机动车间**过错**；对行人 / 非机动车**过错推定 + 交强险无过错兜底** | 使用人（与所有人分离时所有人**有过错担相应责任**；挂靠 §1211 / 拼装报废 §1214 **连带**） | §1217 好意同乘**应当减轻**（限非营运 + 无偿；**故意 / 重大过失**不减） |
| 3 | **医疗** §1218-1228 | **过错**责任；§1222 三情形**过错推定**（违规 / 隐匿拒供病历 / 篡改销毁病历） | **医疗机构**（非医务人员个人） | §1224 三免责（患方不配合 / 紧急已尽责 / 限于当时医疗水平） |
| 4 | **环境生态** §1229-1235 | **无过错** | 排污 / 破坏生态者 | §1230 **因果关系举证倒置**（被告证不存在）；§1232 惩罚性须**违法 + 故意 + 严重后果** |
| 5 | **高度危险** §1236-1244 | **无过错** | 营运 / 占有 / 使用人 | 免责**分层**：航空器 §1238 **仅受害人故意**；核设施 §1237 战争等 + 受害人故意；§1239/§1240 受害人故意**或**不可抗力（重大过失**减轻**）；§1244 故意 / 重大过失**突破限额** |
| 6 | **饲养动物** §1245-1251 | **无过错**（动物园 §1248 **过错推定**） | 饲养人 / 管理人 | 抗辩递减：§1245 受害人故意 / 重大过失可减免 → §1246 违规未拴绳**仅故意且只减轻** → **§1247 禁养烈性犬零免责**（受害人故意亦不免） |
| 7 | **建筑物 / 物件** §1252-1258 | **过错推定**（§1253 脱落坠落 / §1255 堆放 / §1257 林木 / §1258 施工地下设施）；§1252 **倒塌塌陷** = 建设 + 施工单位**连带** | 所有人 / 管理人 / 使用人 | **§1254 高空抛物**：难定具体人 → 可能加害人给予"**补偿**"（非赔偿）+ 追偿；物业未尽安保另担责 |
| 8 | **责任主体类**（监护 §1188 / 用人 §1191 / 网络 §1197 / 安保 §1198 / 教育 §1199-1201） | 见**第三步**（无过错 / 过错 / 过错推定 / 补充各异） | 监护人 / 用人单位 / ISP / 经营者 / 教育机构 | 详见第三步 |

## 四、责任主体权利归位（别张冠李戴）

| 主体 | 地位 / 能干什么 |
|---|---|
| **被侵权人** | 请求停止侵害等（§1167，不要过错 / 损害）+ 损害赔偿（须按归责举证）；数加害人时可向**连带**人任一全额主张、向**按份**人各主张份额 |
| **加害人** | 按归责担责；无过错责任只能以**法定**事由抗辩；过错推定须**自证无过错** |
| **替代责任人**（用人单位 / 监护人 / 接受劳务方） | 对外**无过错**先赔；对内**追偿**（用人单位限工作人员**故意 / 重大过失**；监护可"减轻"不可免） |
| **补充责任人**（安保 / 教育机构 / ISP 部分情形） | **顺位在后**、在未尽义务范围内担"相应补充责任"，赔后**可向第三人追偿** |

> ⚠️ 主体陷阱：监护人无过错（只减轻）↔ 承揽定作人过错（原则不担）；用人单位**对外无过错、对内追偿限故意 / 重大过失**两层别压扁。

## 五、命题人最爱的 10 个陷阱（侵权归责是头号雷区）

1. **特殊侵权归责记反** —— 医疗是**过错**（非无过错）；脱落坠落 §1253 是**过错推定**（非无过错）；环境 §1229 是**无过错**。
2. **过错推定 / 无过错随意适用** —— 二者皆**法定主义**，法无明文 → 回过错责任。
3. **§1199（无 → 推定）↔ §1200（限制 → 过错）对调** —— 区分依据是**行为能力**，不是年龄绝对值。
4. **监护 §1188 "尽责即免责"** —— 错！**无过错**责任，尽责只**减轻、不免除**。
5. **§1171 连带 ↔ §1172 按份对调** —— 各自**足以致全损** = 连带；各自**部分原因力** = 按份。
6. **高空抛物 §1254 "全楼连带赔偿"** —— 错！难定具体人时是可能加害人"**补偿**"（非赔偿、非连带），能定则侵权人全赔。
7. **高危免责一律"故意 + 不可抗力"** —— 错！航空器 §1238 **仅受害人故意**；核设施 §1237 无"不可抗力"字样。
8. **禁养烈性犬 §1247 可因受害人故意免责** —— 错！**零免责**（绝对无过错）。
9. **用人单位追偿不限过错程度** —— 错！须工作人员**故意 / 重大过失**才可追偿。
10. **公平 §1186 当归责原则 / 万能兜底** —— 错！是双方无过错时"**依法**分担损失"，2021 已收紧、非兜底。

> 子主题细节另见：[[精神损害赔偿]]（§1183 三档）· [[民法-合同-责任竞合模型]]（§186 竞合择诉）· [[民事责任体系]]（三责任顶层对比）。
