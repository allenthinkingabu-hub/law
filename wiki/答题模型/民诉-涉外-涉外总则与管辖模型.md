# 📐 涉外民事诉讼 · 涉外总则与管辖答题模型（适用条约司法豁免语言代理 + 适当联系协议应诉专属 + 平行诉讼先受理 + 不方便法院）

> **核心一句**：涉外编（民诉法第四编）是**2023年修正的核心战场**，命题主线是**"识涉外因素 → 总则待遇（条约优先·司法豁免·中文审判·委托中国律师）→ 管辖怎么定（适当联系兜底、协议管辖不要求实际联系、应诉管辖、专属管辖扩张）→ 两国都在审怎么办（平行诉讼可受理·先受理可中止·不方便法院五要件）→ 外国判决认不认"**。最毒陷阱是**把2023新增的"适当联系"仍当成旧法"实际联系"**、**误以为涉外协议管辖仍需实际联系**、**把"平行诉讼中国不受理/驳回"当成规则**（恰恰相反，中国有管辖权就受理并继续审）、**把"境内有住所的外国人"也按30日上诉期/涉外送达对待**（应按国内15日待遇）。
>
> 🔎 **《民事诉讼法》（2023修正，2024-01-01施行）核心条文速查**（条号均以本地 ssf.gov.cn 官方全文 grep 核验）：
> - **§270【适用范围】**：在中国领域内进行涉外民事诉讼，适用本编规定；**本编没有规定的，适用本法其他有关规定**。
> - **§271【条约优先】**：中国缔结或参加的国际条约同本法有不同规定的，**适用该国际条约的规定，但中国声明保留的条款除外**。
> - **§272【司法豁免】**：对享有外交特权与豁免的外国人、外国组织或国际组织提起的民事诉讼，依照中国有关法律和缔结/参加的国际条约办理。
> - **§273【中国通用语言文字】**：法院审理涉外民事案件，**应当使用中国通用的语言、文字**。当事人要求提供翻译的，可以提供，**费用由当事人承担**。
> - **§274【委托中国律师】**：外国人、无国籍人、外国企业和组织在法院起诉、应诉，**需要委托律师代理诉讼的，必须委托中国的律师**。
> - **§275【境外授权委托书公证认证】**：境内无住所的外国当事人从境外寄交/托交的授权委托书，应当经**所在国公证机关证明**，并经**中国驻该国使领馆认证**，或履行有关条约规定的证明手续后，才具有效力。
> - **§276【特殊地域管辖 + 适当联系兜底】**：对境内无住所被告提起**除身份关系以外**的诉讼，合同签订地/合同履行地/诉讼标的物所在地/可供扣押财产所在地/侵权行为地/代表机构住所地在境内的，可由上述地点法院管辖（Ⅰ）；**除前款外，涉外民事纠纷与中国存在其他适当联系的，可以由法院管辖（Ⅱ）**。
> - **§277【协议管辖】**：涉外民事纠纷的当事人**书面协议选择中国法院管辖的，可以由法院管辖**。（无"实际联系"要求）
> - **§278【应诉管辖】**：当事人**未提出管辖异议，并应诉答辩或者提出反诉的，视为法院有管辖权**。
> - **§279【专属管辖三类】**：（一）境内设立的法人/其他组织的设立、解散、清算及其决议效力纠纷；（二）境内审查授予的知识产权有效性纠纷；（三）境内履行的中外合资经营企业合同、中外合作经营企业合同、中外合作勘探开发自然资源合同纠纷。
> - **§280【平行诉讼受理】**：同一纠纷一方向外国法院起诉、另一方向中国法院起诉，或一方既向外国又向中国起诉，**中国法院依本法有管辖权的，可以受理**；当事人订立**排他性选择外国法院管辖协议**且不违反专属管辖、不涉主权安全公共利益的，法院可裁定不予受理、已受理的裁定驳回起诉。
> - **§281【先受理规则】**：法院依§280受理后，当事人以**外国法院先于中国受理为由**书面申请中止的，**法院可以裁定中止诉讼**，但两情形除外：①协议选中国管辖或属中国专属管辖；②中国法院审理明显更为方便。外国法院未采取必要措施/未合理期限审结的，依申请恢复诉讼；外国判决已被中国全部/部分承认的，就已承认部分再起诉的不予受理、已受理驳回。
> - **§282【不方便法院原则】**：法院受理的涉外案件，被告提出管辖异议且**同时具备五要件**的，可裁定驳回起诉、告知向更方便的外国法院起诉：①基本事实不在境内发生、法院审理与当事人参诉均明显不方便；②无选择中国法院的协议；③不属中国专属管辖；④不涉中国主权安全公共利益；⑤外国法院审理更方便。
> - **§286【上诉期/答辩期】**：**境内无住所**的当事人不服一审的，上诉期**30日**，被上诉人答辩期30日。 · **§287【审限】**：涉外案件审限不受§152（普通程序6个月）、§183限制。
> - **民诉解释（2022）§526【委托本国人代理】**：外籍当事人可委托**本国人**为诉讼代理人，或委托**本国律师以非律师身份**代理；外国驻华使领馆官员受本国公民委托可**以个人名义**担任代理人，但诉讼中**不享外交/领事特权与豁免**。

> ⚠️ **诚实标注（条号核验说明）**：①民诉法§270–§282、§286–§287、§275 均已在本地 ssf.gov.cn 官方全文 grep 核到原文，条号为 **2023 修正后的新编号**（涉外编从第270条起），与深度报告第12章一致，可信度高。②民诉解释"委托本国人代理/使领馆官员个人名义代理"确切法源是**《民诉法解释》（法释〔2022〕11号）第526条**（本地全文核到原文），真题卡301/302 仅笼统写"民诉解释/第61条"，本模型据核验补正为§526。③**重要张力点**：《民诉解释》系2022年发布，**尚未同步2023民诉法修正**——其第529条谈涉外协议管辖时仍写"与争议有**实际联系**地点的外国法院"并援引**旧条号"第34条、第273条"**。而2023民诉法§277对**选择中国法院**的协议管辖已**删去"实际联系"要求**。做题以**民诉法§277（新法）**为准："涉外协议管辖不再要求实际联系"针对的是选择中国法院；解释529条的旧表述与旧条号不宜再作为答题依据，最终以官方 flk.npc.gov.cn / court.gov.cn 现行版本为准。④真题卡自带的年份编号（如"2014-3-84""2025金题-2-F-30"）题库标注**未经独立核验**，本模型不据以主张真题出处。

> ⚠️ **易记错点**：①**"适当联系"是2023新词，"实际联系"是旧词**——兜底管辖§276Ⅱ、认定外国法院无管辖§301（一）都用"适当联系"，命题人爱用"实际联系"旧表述设时效陷阱；②**涉外协议管辖§277选中国法院不要求实际联系**（旧法/旧解释才要求），但不等于"各类案件都能约定"——身份关系不能协议管辖；③**平行诉讼§280 的常态是"中国有管辖权就受理并继续审"**，不是不受理、不是中止、不是驳回；只有当事人以"外国先受理"申请、才可能走§281裁定中止（且有两项例外不中止）；④**"境内有住所的外国人"按国内待遇**：送达用国内方式、上诉期15日、审限不受6个月限——涉外送达§283/30日上诉期§286只针对**境内无住所**当事人；⑤**§274"须委托中国律师"针对的是委托'律师'**，当事人仍可委托**本国人以非律师身份**代理（解释§526），二者不矛盾；⑥**涉外审限不受6个月限制§287**，别套用普通程序6个月审限。

## 二、 五步判别模型（识涉外 → 总则待遇 → 定管辖 → 平行诉讼 → 认判决）

```
        【中国甲公司 vs J国乙公司：设备买卖合同在上海签订并交货，乙在华无住所，货款纠纷】
                                    │
   ▼ 第一步：是不是"涉外"案件？（主体/法律事实/标的三选一涉外）
   │   主体涉外(一方外国人/外国组织) / 法律关系发生地或标的在境外 → 属涉外，走第四编(§270)
   │   本编没规定的，回头适用本法其他规定(§270)；有条约按条约(§271，保留条款除外)
                  │
   ▼ 第二步：总则给什么"待遇"？（§272–§275、§286–§287、解释§526）
   │   ├─ 司法豁免：对方享外交特权豁免 → 依法律与条约办理(§272)
   │   ├─ 语言：法院用中文审判；要翻译可提供、费用自负；通晓中文可不译(§273)
   │   ├─ 代理：委托"律师"必须中国律师(§274)；但可委托本国人以非律师身份代理、
   │   │       使领馆官员受托可个人名义代理(解释§526)
   │   ├─ 授权书：境外寄交 → 所在国公证 + 中国驻该国使领馆认证/条约手续(§275)
   │   └─ 境内有无住所定待遇：无住所→涉外送达§283、上诉期30日§286；
   │       有住所→按国内待遇(国内送达、上诉期15日)；涉外审限一律不受6个月限(§287)
                  │
   ▼ 第三步：中国法院有没有管辖权？（2023大修四规则 §276–§279）
   │   ├─ 特殊地域：对境内无住所被告、除身份关系外，六连接点在境内即可管(§276 Ⅰ)
   │   │       (合同签订地/履行地/标的物所在地/可扣押财产所在地/侵权行为地/代表机构住所地)
   │   ├─ 适当联系兜底：与中国有"其他适当联系"即可管(§276 Ⅱ，2023新增，非"实际联系")
   │   ├─ 协议管辖：书面协议选中国法院即可，不要求实际联系(§277)；身份关系不能协议
   │   ├─ 应诉管辖：不提管辖异议且应诉答辩/提反诉 → 视为有管辖权(§278)
   │   └─ 专属管辖(§279，排除协议/应诉)：①境内法人设立解散清算及决议效力
   │           ②境内授予知识产权有效性 ③境内履行的中外合资/合作/合作勘探开发合同
                  │
   ▼ 第四步：两国都在审同一纠纷怎么办？（平行诉讼 §280 / 先受理 §281 / 不方便 §282）
   │   ├─ 平行诉讼常态：中国依本法有管辖权 → 可以受理并继续审(§280)
   │   │       不因外国已受理就不受理/中止/驳回；不算国内"重复起诉"
   │   ├─ 例外(排他性外国法院协议)：不违专属、不涉主权安全公益 → 可裁定不予受理/驳回(§280)
   │   ├─ 先受理规则：当事人以"外国先受理"申请中止 → 法院"可以"裁定中止(§281)；
   │   │       两例外不中止：①协议选中国/属中国专属 ②中国审理明显更方便
   │   │       外国久拖不审 → 依申请恢复；已被承认部分再诉 → 不予受理/驳回
   │   └─ 不方便法院(§282，五要件"同时"具备才驳回起诉)：
   │       基本事实不在境内且审理明显不便 + 无选中国协议 + 非专属 + 不涉主权安全公益 + 外国更方便
                  │
   ▼ 第五步：外国判决来了，认不认、执不执行？（§300–§302，引出下一模型）
       正在审同一纠纷 → 可裁定中止(§302)；已判/已承认 → 外国同案判决不予承认/驳回起诉
       ……详见 [[民诉-涉外-送达取证与判决仲裁承认模型]]
```

> **一句话总诀**：**「涉外先定性(主体/事实/标的涉外)，总则看待遇(条约优先、司法豁免、中文审判、律师须中国、境外授权公证认证、境内有住所按国内)；管辖记四招——适当联系兜底、协议不要实际联系、应诉视为有管、专属三类扩张；两国都审——平行诉讼中国有管就受理继续审，外国先受理才可中止(两例外)，不方便法院五要件同时具备才驳回；外国判决认不认，引下一模型」**

## 三、 高频干扰选项（时效错位 + 待遇混淆）

命题人最爱在"新旧措辞""境内有无住所""平行诉讼处理方式"三处挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **"实际联系"旧词冒充新法** | 涉外诉讼须与我国有"实际联系"才管辖；涉外协议管辖也要求所选法院与争议有实际联系。 | **❌ 时效错位。**2023修正后兜底管辖措辞是"**其他适当联系**"（§276Ⅱ），门槛比"实际联系"更宽；**选择中国法院的协议管辖§277已删去"实际联系"要求**。"实际联系"是旧法/2022解释529条（选择外国法院）的表述，勿套用到新法选中国法院的情形。 |
| **平行诉讼中国不受理/驳回** | 同一纠纷外国法院已受理，构成重复起诉，中国法院应不予受理或驳回起诉。 | **❌ 说法错误。**涉外平行诉讼**不是国内重复起诉**，中国依本法有管辖权的**可以受理并继续审理**（§280）；只有当事人以"外国先受理"申请，法院才"**可以**"裁定中止（§281，且协议选中国/专属/中国明显更方便时不中止），仍非"不受理/驳回"。 |
| **境内有住所的外国人也按涉外特殊待遇** | 只要当事人是外国人，就适用涉外送达、上诉期30日。 | **❌ 说法错误。**涉外送达§283、30日上诉期§286只针对**在境内没有住所**的当事人；外国人若**在境内有住所**（长期居住），送达用国内方式、上诉期**15日**，按国内待遇。 |
| **委托本国人＝违反"须委托中国律师"** | 外国当事人只能委托中国律师，不得委托本国人代理。 | **❌ 说法错误。**§274"须委托中国律师"针对的是委托"**律师**"；当事人可委托**本国人以非律师身份**代理、使领馆官员可个人名义代理（解释§526），二者不冲突。 |

## 四、 相邻制度对照（涉外管辖 vs 国内管辖 / 平行诉讼先受理 vs 不方便法院）

### 4.1 涉外管辖 vs 国内管辖（三处关键差异）

| 事项 | 国内管辖 | 涉外管辖（2023修正） |
|---|---|---|
| 协议管辖的"联系"要求 | §35 协议选择须限于**被告住所地、合同履行地/签订地、原告住所地、标的物所在地等与争议有联系**的地点 | **§277 书面协议选中国法院即可，不要求"实际联系"**（这是涉外的放宽） |
| 兜底管辖 | 无"适当联系"概括兜底，须落入法定连接点 | **§276Ⅱ 与中国有"其他适当联系"即可管**（概括兜底，2023新增） |
| 应诉管辖 | §35末段/司法解释亦有应诉管辖 | **§278 不提异议+应诉答辩/反诉→视为有管辖权**（涉外单列） |
| 专属管辖 | §34（不动产、港口作业、继承） | **§279 三类涉外专属（法人设立解散清算及决议效力、境内知识产权有效性、境内履行的中外合资/合作/合作勘探开发合同）——2023扩张** |

> ⚠️ **易混提示**：国内协议管辖§35**要求与争议有联系**，涉外协议管辖§277选中国法院**不要求实际联系**——方向相反，别记反。

### 4.2 平行诉讼先受理规则（§281）vs 不方便法院原则（§282）

| 事项 | 先受理规则 §281（"可中止"） | 不方便法院原则 §282（"驳回起诉"） |
|---|---|---|
| 触发 | 中国已受理后，当事人以**外国法院先于中国受理**为由书面申请 | 被告提出管辖异议，主张外国法院审理更方便 |
| 处理结果 | 法院**可以裁定中止诉讼**（不是驳回，只是"先等等"） | **五要件同时具备**才裁定**驳回起诉**、告知向更方便外国法院起诉 |
| 例外/门槛 | 不中止：①协议选中国或属中国专属 ②中国审理明显更方便 | 五要件缺一不可：基本事实不在境内且明显不便 + 无选中国协议 + 非专属 + 不涉主权安全公益 + 外国更方便 |
| 后续救济 | 外国久拖不审（未采取必要措施/未合理期限审结）→ 依申请**恢复诉讼** | 外国法院拒绝管辖/久拖不审 → 当事人再起诉，法院**应当受理** |

> ⚠️ **一眼分**：**"外国先受理"→ 走§281可裁定"中止"**（案子还在中国、只是暂停）；**"外国更方便"且五要件齐 → 走§282裁定"驳回起诉"**（案子彻底推给外国）。中止 ≠ 驳回。

## 五、 万能五步答题模型

> 🚗 **统一案例**：中国甲公司与 J 国乙公司在**上海**签订《设备买卖合同》，约定在上海交货；乙公司**在中国境内没有住所**。合同履行中因货款发生纠纷。乙公司先向 J 国法院起诉甲公司请求解除合同（A诉讼），甲公司随后向**合同签订地上海的中国法院**起诉乙公司请求支付货款（B诉讼）。乙公司在华聘请了律师，并从 J 国寄来一份授权委托书。

### 第一步：判是否涉外——本案是不是"涉外民事案件"？

> **主体事实标的，涉外一处即涉外**

#### 概述

进入第四编（涉外程序特别规定）的前提是案件"涉外"。判断标准是"**主体、法律事实、诉讼标的**"三者**只要有一处涉外**即可：一方或双方是外国人/无国籍人/外国企业和组织（主体涉外），或产生/变更/消灭民事关系的法律事实发生在境外（事实涉外），或诉讼标的物在境外（标的涉外）。一旦认定涉外，优先适用第四编；**本编没有规定的，适用本法其他有关规定（§270）**；中国缔结/参加的国际条约与本法不同的，**适用条约但保留条款除外（§271）**。

#### 大白话讲解

甲公司是中国公司，乙公司是 J 国公司——**一方当事人是外国企业，主体就涉外了**，本案毫无疑问是涉外民事案件，要按第四编的特别规则来。

但要记住第四编是"**特别规定**"，它只在涉外场景下加几条特殊规则（管辖、送达、语言、代理、审限等），**没特别规定的地方，照样用民诉法的普通规则**（比如证据规则、审判程序）。如果中国和 J 国之间有生效的双边司法协助条约，且条约与民诉法不一样，那就**优先按条约**（除非中国当初声明保留了那一条）。

#### 一句话闭环记忆

> 🎯 **一眼判**：主体/法律事实/标的**三选一涉外**即进第四编；本编没写的用普通规则（§270），有条约先用条约、保留条款除外（§271）。

---

### 第二步：判总则待遇——司法豁免、语言、代理、授权书、境内有无住所

> **豁免中文律师认证，境内有住所按国内**

#### 概述

涉外总则给当事人配了一套"特殊待遇"，考试高频五块：

- **司法豁免（§272）**：对方若是享有外交特权与豁免的外国人/组织/国际组织，依相关法律和条约办理（不能径行起诉审判）。
- **语言（§273）**：法院**用中文审判**；当事人要翻译可以提供、**费用自己承担**；当事人**通晓中文的可不译**，判决书**以中文为准**（外文译本不加盖法院印章）。
- **代理（§274 + 解释§526）**：需委托"**律师**"代理的**必须委托中国律师**；但当事人可委托**本国人以非律师身份**代理，外国驻华使领馆官员受本国公民委托可**以个人名义**代理（诉讼中不享外交/领事豁免）。
- **境外授权委托书（§275）**：从境外寄交/托交的授权委托书，须**所在国公证机关证明 + 中国驻该国使领馆认证**（或条约手续），才生效。
- **境内有无住所定待遇（§283/§286/§287）**：境内**无**住所→涉外送达、上诉期**30日**；境内**有**住所（长期居住）→按**国内待遇**（国内送达、上诉期**15日**）；涉外审限**一律不受6个月限制**。

#### 大白话讲解

乙公司不享外交豁免（普通外国公司），本案可以正常起诉审判（§272 不适用于它）。

**语言**：上海法院用中文开庭、出中文判决。如果乙公司的代表通晓中文，法院可以不提供翻译；如果要翻译，费用乙公司自己掏。判决书以中文为准，乙公司要外文译本可自行翻译，法院不给盖章的外文判决书。

**代理**：乙公司想请律师，那必须请**中国律师**（§274）；但乙公司也可以直接委托一个 J 国的本国人来当代理人（以非律师身份），这不违反§274。

**授权委托书**：乙公司从 J 国寄来的那份授权书，光有 J 国的字还不够——必须先经**J 国公证机关公证**，再经**中国驻 J 国使领馆认证**（或走中 J 条约手续），才在中国法院有效（§275）。这正是真题377"在法国居住的雷诺"那道题的考点：法国公证 + 中国驻法使领馆认证。

**境内有无住所**（本案关键变量）：本案乙公司**在华无住所**——所以对它要用涉外送达方式（§283），它的上诉期是**30日**（§286）。**但如果换个场景**：假设乙公司的实际控制人长期住在上海（境内有住所），那就按国内待遇——国内送达、上诉期**15日**。真题301"琼斯一直住在甲市B区"就是这个陷阱：他虽是美国人，但境内有住所，送达同国内、上诉期15日不是30日。无论哪种，涉外案件的**审限都不受6个月限制**（§287）。

#### 一句话闭环记忆

> 🎯 **一眼判**：司法豁免依法律条约办；中文审判、翻译自费、通晓可不译；委托"律师"须中国律师、但可委托本国人以非律师代理；境外授权书要"所在国公证+中国驻外使领馆认证"；**境内有住所按国内待遇（送达/上诉15日），无住所才30日**；涉外审限不受6个月限。

### 第三步：判管辖——中国法院对本案有没有管辖权？（2023大修四规则）

> **地域适当协议应诉，专属三类不可撼**

#### 概述

2023修正把涉外管辖做成了"**四层递进 + 一层专属**"：

1. **特殊地域管辖（§276Ⅰ）**：对境内无住所被告、**除身份关系外**的诉讼，**六个连接点**（合同签订地、合同履行地、诉讼标的物所在地、可供扣押财产所在地、侵权行为地、代表机构住所地）任一在境内，即可由该地法院管辖。
2. **适当联系兜底（§276Ⅱ）**：即便不落入六连接点，只要纠纷**与中国存在"其他适当联系"**，也可由中国法院管辖（2023新增，措辞是"适当联系"不是"实际联系"）。
3. **协议管辖（§277）**：当事人**书面协议选中国法院即可，不要求实际联系**；但身份关系纠纷不能协议管辖。
4. **应诉管辖（§278）**：当事人**不提管辖异议且应诉答辩或提反诉**，视为中国法院有管辖权。
5. **专属管辖（§279，排除协议/应诉）三类**：①境内法人/组织的设立、解散、清算及决议效力；②境内审查授予的知识产权有效性；③**境内履行**的中外合资经营/中外合作经营/中外合作勘探开发自然资源合同纠纷。

#### 大白话讲解

甲公司要在上海告乙公司，中国法院管不管得了？

- 走**特殊地域管辖（§276Ⅰ）**：乙公司在华无住所，但本案是买卖合同（非身份关系），**合同签订地在上海、合同履行地（交货地）也在上海**——两个连接点都在境内，上海法院**当然有管辖权**。真题298的A项、真题304/303"合同签订地中国法院有管辖权"讲的就是这一层。
- 就算合同不在上海签、不在上海交货，只要纠纷**与中国有"其他适当联系"**（比如财产、履行环节在境内），还能靠**§276Ⅱ适当联系兜底**兜住。注意这是2023的新词——命题人爱写"实际联系"来考时效（真题298 A项就是"实际联系"旧表述，按考查意旨仍算对，但要知道现行法是"适当联系"）。
- 如果甲乙在合同里**书面约定"由上海法院管辖"**，那按**§277**直接由上海法院管，**不需要再证明与上海有实际联系**（这是涉外协议管辖相对国内§35的放宽）。但如果这是离婚等身份关系纠纷，就**不能**这么约（真题298 B项"各类案件都能约定"错在"各类"）。
- 如果乙公司到庭后**不提管辖异议、直接应诉答辩**，就算原本管辖有争议，也**视为上海法院有管辖权（§278应诉管辖）**。
- 但有三类案子**锁死在中国专属管辖（§279）**，协议、应诉都撼不动：中外合资/合作/合作勘探开发合同（**在境内履行**的）就是其中一类。真题298 C项的陷阱是把"中外合资企业与其他主体的一切合同"都说成专属——错，专属的是**合资/合作合同本身**、且限**境内履行**。

#### 一句话闭环记忆

> 🎯 **一眼判**：涉外管辖四问——六连接点在境内吗（§276Ⅰ）？有其他"适当联系"吗（§276Ⅱ，非"实际联系"）？书面协议选了中国法院吗（§277，不要求实际联系）？应诉不提异议吗（§278）？以上均可管；但**三类专属（境内法人事项/境内知识产权有效性/境内履行的中外合资合作合同）§279锁死**，协议应诉撼不动。

### 第四步：判平行诉讼——两国都在审同一纠纷怎么办？

> **平行受理继续审，先受理可中止，不方便五件驳**

#### 概述

同一纠纷两国都在打，民诉法给了三条规则：

- **平行诉讼受理（§280）**：一方在外国起诉、另一方在中国起诉（或一方两头诉），**中国依本法有管辖权的，可以受理并继续审理**——不因外国已受理就不受理、不中止、不驳回，**也不算国内"重复起诉"**。例外：当事人订了**排他性选择外国法院管辖协议**，且不违反中国专属管辖、不涉主权安全公益的，中国法院可裁定不予受理、已受理的驳回起诉。
- **先受理规则（§281）**：中国受理后，当事人以"**外国法院先于中国受理**"为由书面申请中止的，**法院可以裁定中止诉讼**；但两情形**不中止**：①协议选中国管辖或属中国专属；②中国审理**明显更方便**。外国法院久拖不审的，依申请**恢复诉讼**；外国判决已被中国**承认**的，就已承认部分再起诉的不予受理/驳回。
- **不方便法院原则（§282）**：被告提管辖异议且**五要件同时具备**的，法院可裁定**驳回起诉**、告知向更方便外国法院起诉。

#### 大白话讲解

本案正是平行诉讼：乙公司先在 J 国告甲（A诉讼），甲随后在上海告乙（B诉讼）。上海法院怎么办？

**常态（§280）**：上海法院对 B 诉讼**有管辖权**（合同签订地、履行地都在上海），就**照样受理、继续审理**，**不因为 J 国法院先受理了 A 诉讼就不管**。这不是国内"重复起诉"，别用一事不再理去堵。真题304/303 的答案就是这条：中国有管辖权就受理并继续审（D/A对），既不是不受理、也不是驳回、也不是受理后中止。

**什么时候可能中止（§281）**：如果乙公司到上海法院来**主张"J 国法院先受理了，请中止"并书面申请**，上海法院**可以**裁定中止——但注意是"**可以**"不是"必须"，而且如果甲乙**约定过由中国法院管辖**、或本案**属中国专属管辖**、或**上海审理明显更方便**，那就**不中止**，继续审。如果 J 国法院受理后久拖不审，甲还能申请**恢复诉讼**。

**什么时候驳回（§282不方便法院）**：假设本案基本事实其实都发生在 J 国、证据人证都在 J 国，乙公司提管辖异议主张 J 国审更方便——只有当**五个要件同时满足**（基本事实不在境内且审理明显不便 + 没有选中国法院的协议 + 不属中国专属 + 不涉中国主权安全公益 + 外国法院更方便），上海法院才可以裁定**驳回起诉**、让甲去 J 国告。本案合同在上海签、在上海履行，基本事实在境内，**根本凑不齐五要件**，不能驳回。

> ⚠️ **中止 ≠ 驳回**：§281"外国先受理"→ 案子留在中国只是暂停（中止）；§282"外国更方便且五要件齐"→ 案子彻底推给外国（驳回起诉）。命题人爱把两者混用。

#### 一句话闭环记忆

> 🎯 **一眼判**：平行诉讼常态——中国有管辖权就**受理并继续审**（§280，非重复起诉、不中止不驳回）；当事人以"**外国先受理**"申请 → 法院**可裁定中止**（§281，协议选中国/专属/中国明显更方便三种不中止）；只有**不方便法院五要件同时具备**才**驳回起诉**（§282）。

### 第五步：判外国判决——认不认、执不执行？（引出下一模型）

> **同案在审可中止，已判外国判决不认**

#### 概述

平行诉讼的下游问题是：如果 J 国先判了、拿到中国来申请承认执行，中国认不认？核心规则：

- **正在审理同一纠纷（§302）**：当事人申请承认执行的外国判决，与中国**正在审理**的属同一纠纷的，中国法院**可以裁定中止诉讼**；外国判决**符合承认条件**的裁定承认、并**驳回**中国这边已中止的起诉，**不符合**承认条件的不予承认、**恢复**中国诉讼。
- **已判/已承认（§281末款、§300）**：中国已就同一纠纷作出判决、或已承认第三国判决的，对外国就同一纠纷的判决**不予承认执行**（§300（四））；已被承认部分再起诉的不予受理/驳回（§281）。

#### 大白话讲解

回到本案：如果上海法院已经就货款纠纷**作出判决**，这时乙公司拿着 J 国法院对**同一纠纷**的判决来中国申请承认执行——中国法院**不予准许/不予承认**（避免和本国判决打架）。这正是真题303 C项的考点：中国已判，瑞典（外国）同一纠纷判决申请承认执行**不予准许**。反过来，如果中国这边还**正在审**、J 国判决先来了，中国**可以先裁定中止**，看 J 国判决符不符合承认条件再决定。

承认执行外国判决的**具体条件、审查程序、不予承认的五种情形、送达取证方式、涉外仲裁裁决承认执行**等，属于第25–27章（§283–§304）的内容——详见下一模型。

#### 一句话闭环记忆

> 🎯 **一眼判**：外国判决与中国**正在审**同一纠纷 → **可裁定中止**（§302）；中国**已判/已承认** → 外国同案判决**不予承认执行**（§300（四）/§281）；具体承认执行规则见 [[民诉-涉外-送达取证与判决仲裁承认模型]]。

## 六、 易混考点辨析

- **"适当联系" vs "实际联系"**：
  - 2023新法兜底管辖§276Ⅱ、认定外国法院无管辖§301（一）用"**适当联系**"；"实际联系"是旧法/2022解释529条（选择外国法院）的旧词。选**中国法院**的协议管辖§277已**不要求实际联系**。
- **涉外协议管辖 vs 国内协议管辖**：
  - 涉外§277选中国法院**不要求实际联系**（放宽）；国内§35协议须选**与争议有联系**的地点。方向相反。
- **平行诉讼"可中止"§281 vs 不方便法院"驳回起诉"§282**：
  - 前者因"外国先受理"申请、**可裁定中止**（案子留中国）；后者五要件同时具备、**驳回起诉**（案子推给外国）。中止≠驳回。
- **境内无住所（30日/涉外送达）vs 境内有住所（15日/国内待遇）**：
  - 上诉期30日、涉外送达只针对**境内无住所**当事人；外国人在境内**有住所**的按国内待遇（15日、国内送达）。
- **委托"律师"须中国律师§274 vs 委托本国人以非律师代理解释§526**：
  - 委托的若是"律师"，必须中国律师；但当事人可另委托**本国人以非律师身份**代理，二者不冲突。

## 七、 命题人最爱的 6 个陷阱

1. **"涉外诉讼/涉外协议管辖须与我国有'实际联系'"** —— 时效错位！新法兜底管辖是"**适当联系**"（§276Ⅱ），选中国法院的协议管辖§277**已删去实际联系要求**。
2. **"当事人可约定各类涉外案件的管辖法院"** —— 错在"各类"！**身份关系纠纷不能协议管辖**（§276Ⅰ"除身份关系以外"、§277体系解释）。
3. **"中外合资企业的一切合同纠纷都专属我国法院管辖"** —— 偷换范围！专属的是**境内履行的中外合资/合作/合作勘探开发合同本身**（§279（三）），不是合资企业的所有合同。
4. **"同一纠纷外国已受理，中国构成重复起诉应不受理/驳回"** —— 错！涉外平行诉讼**不是国内重复起诉**，中国有管辖权就**受理并继续审**（§280）；只有以"外国先受理"申请才**可裁定中止**（§281），仍非不受理/驳回。
5. **"外国人当事人一律适用涉外送达、上诉期30日"** —— 错！只针对**境内无住所**当事人；外国人在境内**有住所**的按国内待遇（国内送达、上诉期15日、审限不受6个月限）。
6. **"外国当事人只能委托中国律师，不得委托本国人"** —— 错！§274"须委托中国律师"针对委托"**律师**"；可另委托**本国人以非律师身份**代理、使领馆官员以个人名义代理（解释§526，不享外交/领事豁免）。
