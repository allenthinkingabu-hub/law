# 📐 转租 · 答题模型（万能四步）

> 凡"转租 / 擅自转租 / 次承租人"题，按这四步走，一步不跳。**核心一句话**：转租把"两个人"变成"三方两合同"，胜负全在 **合同相对性**——出租人和次承租人 **没有合同**，凡把这两人当成"互相有租金 / 违约请求权"的选项，几乎都是错的（这就是目标真题 [[典型合同-单选-09|Q09]] 的 D）。
> **母模型** → [[民法-合同-租赁模型]]（转租是其"板块二"，本页是放大镜）。**姊妹** → [[民法-合同-一物多卖模型]]（多重租赁履行顺序可参照）· [[民法-合同-解除模型]]（擅自转租生解除权）。
> **适用真题**：[[典型合同-单选-09|C2-单选-09·擅自转租命门]] · [[典型合同-多选-05|C2-多选-05·口头+经同意转租]] · [[典型合同-单选-28|C2-单选-28·一房二租+转租]] · [[典型合同-多选-27|C2-多选-27·擅自转租+视为同意]] · [[典型合同-多选-28|C2-多选-28·经同意转租+毁房]]
>
> 🔎 **法条已联网核实（2026-06-12，HIGH）**：现行依据＝《民法典》合同编 **§716**（转租：经同意 / 擅自解除权 / 致损担责）+ **§717**（超期部分对出租人无约束）+ **§718**（知道或应知 6 个月未异议→视为同意）+ **§719**（次承租人代偿权）+ 相对性总则 §465 Ⅱ；解除后腾退＝§235（返还原物）、占用费＝§122 / §985（不当得利）；多重租赁顺序＝《城镇房屋租赁合同司法解释》(法释〔2009〕11号，2020 修正)**第五条**（原第六条）。逐字原文经[最高检官网民法典合同编](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml) + [最高法公报民法典](http://gongbao.court.gov.cn/Details/74143ea5b6d1d47f82d6759fc6ef17.html)双重核对。
> ⚠️ **§719 易记错**：原文是"但是**转租合同对出租人不具有法律约束力的除外**"——不是"对次承租人不利的除外"。

## 一、核心考情

- **频率**：转租是 [[租赁合同]] 板块的固定考点，★★★★，单选 / 多选常出 1 道，主观题房产纠纷常涉；最爱与"知道未异议视为同意""买卖不破租赁""一房二租"串考。
- **命题核心**：永远围绕"**三方两合同 + 合同相对性**"——故意把出租人和次承租人摆在一起，看你会不会拒绝在二者之间架设"租金 / 违约"请求权；再叠加"擅自转租后果"的细节陷阱。
- **三大必考点**：①**经不经同意**（明示 / §718 默示 / 约定禁止）②**相对性三方图**（谁能向谁主张什么）③**擅自转租后果**（解除权 ≠ 转租合同无效）。

## 二、万能四步模型

### 第一步：先认定"是不是转租 + 经不经同意"

**铁则**：转租＝承租人在**保留自己承租人地位**的前提下，把租赁物（或其一部）转给第三人（次承租人）使用收益。先定性、再判"同意"——同意与否决定走"合法转租"还是"擅自转租"两条线：
- **明示同意**：出租人事先 / 事后书面或口头同意 → 合法转租。
- **§718 默示同意（推定同意）**：出租人**知道或应当知道**承租人转租，但在 **6 个月内未提异议** → **视为同意**。一旦视为同意，擅自转租的解除权即被堵死，转回合法转租轨道。
- **约定禁止转租**：合同约定"不得转租"仍有效，但其法律后果**仅是出租人取得解除权**（违约 + §716 解除），**不使转租合同当然无效**（见第三步）。
- **不是转租**：承租人把整个**租赁合同地位概括转让**给第三人（自己退出）＝**租赁权转让**，不是转租，需出租人同意，承租人脱离合同。

**老王小李例子**（出租人＝老王，承租人＝小李，次承租人＝老张）
- ✅ 合法：老王口头答应小李把房转租给老张 → 经同意转租。
- ✅ 视为同意：小李没打招呼就转租老张，老王上门收水费早看见老张住着、**半年没吭声** → §718 视为同意，老王**丧失**解除权。
- ⚠️ 约定禁止 ≠ 转租无效：合同写明"不得转租"，小李仍转租老张 → 老王**可解约**，但小李与老张的转租合同**本身有效**。

### 第二步：画"三方法律关系图"判相对性 ★全题命门

**铁则**（§716 第 1 款"承租人与出租人之间的租赁合同继续有效" + §465 Ⅱ 相对性）：转租后形成**两个独立合同**，原承租人**不脱离**原合同：

```
        ┌──────────── 原租赁合同（§716，继续有效）────────────┐
   出租人(老王) ◄────────────────────────────────► 承租人(小李)
        │                                              │
        │   ✗ 无合同关系（合同相对性·§465Ⅱ）            │ 转租合同
        │   只剩 物权 / 侵权 这两条"非合同"通道           │（独立有效）
        ▼                                              ▼
   次承租人(老张) ◄──────────────────────────────────┘
```

- **出租人 ↔ 承租人**：原租赁合同**继续有效**，承租人仍是当事人、仍按原约付租、仍对租赁物担责。
- **承租人 ↔ 次承租人**：转租合同，**独立有效**，租金、违约责任在二者间结算。
- **出租人 ↔ 次承租人**：**无合同关系**！→ 出租人**不能**基于租赁合同向次承租人要租金、不能让次承租人担"违约"责任；次承租人通常也不能越过承租人直接向出租人主张转租合同上的权利。出租人对次承租人只剩 **物权（腾退 / 返还）** 与 **侵权（致损赔偿）** 两条"非合同"通道。

**老王小李例子**
- 小李转租老张，月租老王 1000、老张给小李 1500 → 老王**只能向小李**收 1000（按原约），**不能向老张**要租金；那 1500 是老张给小李的，差价 500 也归小李（见陷阱③）。
- 老王要找老张，只能走"你无权占有→腾退""你把墙砸了→侵权赔偿"，**不能走"违约"**。

### 第三步：擅自转租的后果（解除权 ≠ 转租合同无效）

**铁则**（§716 第 2 款 + §717）：承租人**未经同意**擅自转租的——
- ✅ **出租人取得法定解除权**（形成权，§716"出租人可以解除合同"）；但受 **§718 限制**（知道 6 个月未异议→视为同意，解除权消灭）。
- ❌ **转租合同本身原则上仍有效**，**不当然无效**！擅自转租只是给出租人一把"解除原租赁"的钥匙，并不否定承租人与次承租人之间转租合同的效力（区分"转租合同效力"与"出租人解除权"两个层面）。
- **§717 超期限制**（经同意转租也适用）：转租期限**超过承租人剩余租期**的，**超过部分**的约定对出租人**不具约束力**（不是全部无效，仅超期部分；当事人另有约定除外）——"无人能转让大于自己的权利"。

**老王小李例子**
- 小李擅自转租老张 → 老王**可解除**与小李的原租赁（**[[典型合同-单选-09|Q09]] 的 A 对**）；但若老王知道后半年没异议 → §718 解除权没了。
- 转租合同照样有效：哪怕擅自，小李与老张的转租合同**有效**，老张交了钱有权使用，直到老王行使解除权使本权链条断裂。
- §717 超期：小李对老王还剩 1 年租期，却转租老张 3 年 → **超出的 2 年**对老王无约束力。

### 第四步：责任与请求权配置（谁能向谁主张什么）

**铁则**（把第二步的"三方图"落到具体请求权）：

| 主张方 → 相对方                     | 能不能主张              | 请求权基础                                                                                |
| ----------------------------- | ------------------ | ------------------------------------------------------------------------------------ |
| 出租人 → **承租人**                 | ✅ 要租金、要赔偿（含次承租人致损） | 原租赁合同（§716 第 1 款：第三人致损，**承租人**对出租人赔偿，赔后可向次承租人追偿）                                     |
| 出租人 → **次承租人**（要**租金 / 违约**）  | ❌ **不能**           | 无合同关系（§465 Ⅱ 相对性）——租金应由次承租人付给**承租人**                                                 |
| 出租人 → **次承租人**（要**腾退 / 占用费**） | ✅ 能（解除 / 到期后）      | 解除后次承租人占有失据＝无权占有 → **物权请求权返还原物**（§235）+ **占用费**按市场租金（**不当得利** §122 / §985）           |
| 出租人 → **次承租人**（致损）            | ✅ 能（侵权，非违约）        | 无合同→**侵权**（次承租人毁损租赁物，对出租人是侵权责任，不是违约）                                                 |
| 次承租人 → 出租人（**代付欠租阻却解除**）      | ✅ 例外（合法转租时）        | **§719 代偿权**：承租人拖欠租金，次承租人可代付租金 + 违约金，充抵自己对承租人的应付租金、超付向承租人追偿（**转租合同对出租人无约束力的擅自转租除外**） |

**对应 [[典型合同-单选-09|Q09]] 的 B/C/D**：
- **B 对**——丙（次承租人）练飞镖损坏墙面，依 §716 第 1 款，由**乙（承租人）对甲负责**赔偿；甲找乙要赔，是合同责任（乙赔后可向丙追偿）。
- **C 对**——甲解除与乙的租赁后，乙的承租权（本权）消灭，丙继续占有**失去本权依据**＝无权占有；甲基于**所有权/物权请求权（§235）** 可要丙搬出。
- **D 错（本题选 D）**——甲与丙**无合同关系**，依相对性甲**不能**向丙请求"租金"；租金是丙交给乙的事。

**老王小李例子**
- 老张把墙砸了 → 老王找**小李**赔（§716），小李赔完再找老张追偿；老王也可直接以**侵权**找老张（两条路）。
- 老王解约后老张赖着不走 → 老王基于**所有权**要老张**腾退** + 按市场租金主张**占用费**（不当得利），但**不能**按租赁合同向老张"收租"。
- 合法转租中小李欠老王租金、老王要解约 → 老张可**代小李把租金垫上**（§719），保住自己的转租利益。

## 三、命题人最爱的 5 个陷阱

1. **出租人能向次承租人"要租金"** —— ❌ 错！二者**无合同**（相对性），租金是次承租人付给**承租人**；出租人对次承租人只能要**腾退 + 占用费（物权 / 不当得利）**，不能要租金（**[[典型合同-单选-09|Q09]] 的 D**，万能命门）。
2. **擅自转租＝转租合同无效** —— ❌ 错！擅自转租**仅生出租人解除权**（§716 Ⅱ），**转租合同在承租人与次承租人间仍有效**（只是不能对抗出租人的解除权）；且若出租人知道 6 个月未异议，连解除权都没了（§718）。（[[典型合同-多选-27|多选-27]] 的"转租合同无效"项即此型，错）
3. **转租差价归出租人** —— ❌ 错！经同意转租，承租人**仍按原约**向出租人付租，**转租差价归承租人**（原租赁关系不因转租而改变）。（[[典型合同-多选-05|多选-05]] 的"按高价向承租人收"项即此型，错）
4. **出租人能要次承租人担"违约"责任** —— ❌ 错！无合同→只能走**侵权**（致损）或**物权**（腾退）；次承租人毁房对出租人是**侵权**，对承租人才可能是违约。（[[典型合同-多选-05|多选-05]] 的 D、[[典型合同-多选-28|多选-28]] 的定性即此型）
5. **忽略 §718"知道 6 个月未异议视为同意"** —— ❌ 漏！出租人**知道 / 应当知道**转租而 6 个月内不提异议 → **视为同意**，擅自转租"漂白"成合法转租，解除权消灭。（[[典型合同-多选-27|多选-27]] 的"未置可否"即此型）

## 四、真题演练（套四步模型）

### 范例①：[[典型合同-单选-09|C2-单选-09]]（甲租乙、乙擅自转租丙，丙练飞镖损墙，选"不正确"）→ **D**
1. **第一步**：乙**擅自**转租（未经甲同意）→ 走擅自转租线。
2. **第二步（相对性图）**：甲↔乙原租赁有效；乙↔丙转租；**甲↔丙无合同**——这是判 D 的钥匙。
3. **第三步**：甲对乙取得**解除权**（§716）→ **A 对**。
4. **第四步**：丙致损，由**乙对甲负责**（§716 第 1 款）→ **B 对**；解除后丙占有失据，甲基于**所有权**可要丙**腾退**（§235）→ **C 对**；甲丙无合同，甲**不能向丙要租金**（相对性）→ **D 错**。
→ "不正确"的是 **D** ✅

### 范例②：[[典型合同-多选-05|C2-多选-05]]（冯口头租张 2 年、张经冯同意转租翁，选"不正确"）→ ⚠️ 民法典 **ABD**
- **第一步（A 项属母模型"形式期限"板块）**：⚠️**新旧法分水岭**——旧《合同法》§215"口头长期租**一律**不定期"→ A 对、不选 → **旧法答案 BD**；民法典 §707 须"**无法确定期限**"才不定期，本题期限"2 年"明确 → A"不定期"**错**、应选 → **现行 ABD**（详见 [[民法-合同-租赁模型]]）。
- **第二步（相对性）**：经同意转租，冯仍按**原约 1000** 向张收租、**转租差价归张** → B"按 1200 向张收"**错**（陷阱③）；冯↔翁**无合同** → D"要翁担违约"**错**（陷阱④，应走侵权 / 物权）。
- **第四步**：翁拆墙，冯找**张**赔（§716）→ C 对。
→ "不正确"：民法典 **ABD**（旧《合同法》下为 **BD**）✅

### 范例③：[[典型合同-单选-28|C2-单选-28]]（孙先租并交付王=已占有；又租李，李经孙同意转租陈）→ **C**
- **多重租赁顺序**（参 [[民法-合同-一物多卖模型]]）：王**已合法占有** → 优先（司法解释**第五条**：合法占有 ＞ 备案 ＞ 成立在先）。
- **第二/三步**：孙对李**履行不能** → 李可**解除 + 索赔**（**C 对**）；A 错（李未占有，无权要王搬）；B 错（陈是次承租人，更无权）；D 错（陈↔孙**无合同**，陈只能找李——相对性，陷阱①）。
→ **C** ✅

### 范例④：[[典型合同-多选-27|C2-多选-27]]（甲＝**承租人**，与出租人**乙**约定"不得擅自转租"；甲未经乙同意转租给**丙**3 年；出租人乙收水费发现住的非甲却"未置可否"；1 年后乙将房卖与**丁**，选"不正确"）→ **ABCD**
- **第一步**：甲违反约定**擅自**转租，但出租人乙**知道转租满 6 个月未提异议** → §718**视为同意**（陷阱⑤），乙的解除权消灭。
- **第三步**：B"甲丙转租合同无效"**错**——擅自转租**仅（曾）生解除权、转租合同本身有效**（陷阱②）；况已视为同意。
- 其余各项（含**买卖不破租赁**：乙卖房给丁不影响甲的租赁）依相对性 / 物权逐一证伪（详见题页）。
→ "不正确"为 **ABCD** ✅

### 范例⑤：[[典型合同-多选-28|C2-多选-28]]（乙经甲同意装修并转租丙；丙擅改承重结构致损）→ **CD**
- **第一步**：经同意转租（合法）。
- **第四步（定性是题眼）**：对出租人甲而言——丙（次承租人）对甲是**侵权**（无合同，陷阱④）；承租人乙对甲是**违约**（§716 第 1 款致损负责）。两种责任性质不同，混淆即错。
→ **CD** ✅

## 📐 口诀

> **"转租一来变三方，两个合同各自忙；原租继续承租人在，差价归他不归房东。**
> **房东找客只两招——腾退占用费（物权 / 不当得利），砸了墙是侵权账，要租金、要违约？没合同，免谈。**
> **擅自转租给解约，但转租合同照样有效不作废；房东知道半年不吭声，§718 当你点了头。**
> **次承租人欠租代垫保自己（§719），转租超了剩余期，超的部分管不着房东（§717）。"**
