# 📐 犯罪论总纲 · 导航模型（定罪流水线总入口）

> **教练开场白**
> 同学们好！我是你们的刑法法考教练。一拿到案情，绝大多数同学上来就盯着"这构成什么罪"，直接奔罪名去——结果在主观题里东扯一句、西补一句，踩分点漏一半。但命题人最爱在 **"审查顺序"** 上挖坑：你跳过客观直接谈主观、把"责任阻却"当成"违法阻却"、好不容易定了罪却忘了追问形态/共犯/罪数。今天我们不学新考点，而是把已经建好的 **7 个犯罪论模型串成一条流水线**，装上一个总开关——**先客观后主观、先定罪后修正**，拿到任何案件都知道"下一步该调哪个模型"。

## 适用场景与解决问题

本模型是犯罪论的 **顶层调度入口**，不重复教学、只负责"拿到案件 → 按什么顺序、在哪个岔路口调用哪个子模型"。它解决 7 个模型各自为战、缺一根脊椎的问题（对应 [[刑法总论-犯罪论考点-深度报告]] 的两阶层主干）：

1. **定审查顺序**：一条 master 流水线把"客观违法阶层 → 主观有责阶层 → 修正形态"焊死，杜绝跳层、漏层。
2. **快速路由**：一张"一眼判·路由总表"，案情里冒出什么信号，立刻知道跳哪个子模型。
3. **补上接缝**：四个模型之间最容易漏判的"衔接点"（主观题埋雷区）。

> **核心一句**：拿到案件先拆"谁的哪个行为、初步对应什么罪"，再走两阶层——**第一阶层客观违法**（危害行为→因果→结果，有无违法阻却）调①②；**第二阶层主观有责**（责任能力→故意过失/认识错误→责任阻却）调⑥③；阶层齐全、犯罪成立后，再问三个**修正**追问——停半道了吗（④未完成）、不止一人吗（⑤共犯）、牵涉几个罪吗（⑦罪数）；**违法阻却出罪在第一阶层、责任阻却出罪在第二阶层，二者绝不能混**。

> 🔎 **体系口径已锁定（2026-06-28）**：本总纲以 **两阶层（客观违法阶层 + 主观有责阶层）** 为主轴，与下属 7 个子模型、[[刑法总论-犯罪论考点-深度报告]] 完全一致，也是法考主观题"先客观后主观"的官方审查顺序。柏浪涛 2026 版改采"改良四要件"编排，**结论一致、仅顺序不同**（详见本页第六节"口径声明"）。本总纲只做**路由**、不新增任何 §条主张——所有法条已在各子模型逐条联网核实，此处不再重复核验。

> ⚠️ **三个最致命的顺序坑**：①**违法阻却 ≠ 责任阻却**——正当防卫/紧急避险在第一阶层出罪（行为客观上就不违法）；责任年龄不够、违法性认识不能、期待不可能在第二阶层出罪（行为违法但不怪他）。②**有因果 ≠ 要担责**——因果关系定在客观阶层，定完还要回主观阶层问故意/过失，否则 §16 意外事件照样无罪。③**定完罪 ≠ 答完题**——单个犯罪成立只是中点，形态/共犯/罪数三个修正追问，主观题一个不能漏。

## 一、 为什么需要总纲：7 个模型是一条流水线上的 7 个工位

你已经有 7 台精密的"单工位机器"，每台都能把一个板块判到底。但它们平躺在货架上，彼此不知道先后——这就是你感觉"散、不成体系"的根源。

**单选题**只考一个工位（"这是不是不作为犯？""这算未遂还是中止？"），所以单模型够用。但 **主观题（卷四）和综合案例**是把一个案情**串过 3~5 个工位**：一刀砍下去，要同时问"有没有因果（①）、是不是防卫过当（②）、他够不够责任年龄（⑥）、停手了没有（④）、还有没有同伙（⑤）、最后定几个罪（⑦）"。没有总纲，你就只能"想到哪答到哪"；有了总纲，你按流水线一站一站走，**踩分点一个都不漏**。

```
散件（你现在的样子）                    机器（装上总纲之后）
┌──┐ ┌──┐ ┌──┐                         拿到案情
│①│ │②│ │③│  ……每台都好               │
└──┘ └──┘ └──┘                          ▼ 总纲调度
┌──┐ ┌──┐ ┌──┐                    ①→②→⑥→③→④→⑤→⑦
│④│ │⑤│ │⑥│  ……但不知先后            （先客观·后主观·再修正）
└──┘ └──┘ └──┘                          │
   ┌──┐                                  ▼
   │⑦│                              罪名+形态+角色+罪数
   └──┘
```

## 二、 犯罪论总定罪流水线（master 决策树）

> 这是脊椎。任何刑法案件，都从顶上"拿到案情"进，一站一站往下走；每个岔路口标注了**调哪个子模型**。

```
拿到案情
   │
   ▼ 第0步【拆解】一案多行为先拆行为、多人先拆人，各自列出"初步罪名假设"
   │            （别把数人数行为搅成一锅，每条行为各跑一遍流水线）
   │
   ▼ 第一阶层【客观违法（不法）】问："客观上做了坏事吗？这事违法吗？"
   │   ├─ 1.1 有危害行为吗？(作为/不作为·实行行为性·§13但书显著轻微出罪) ─→ 📐①
   │   ├─ 1.2 行为与结果有因果/可客观归责吗？(介入因素三步:异常度→关联度→原因力) ─→ 📐①
   │   │        └ 结果没发生 or 因果被阻断 → 记一笔，留到修正形态问"未遂还是既遂"(④)
   │   └─ 1.3 有违法阻却事由吗？(正当防卫§20/紧急避险§21/被害人承诺) ─────────→ 📐②
   │            ├ 阻却成立 → 行为不违法 → 【出罪·流程结束】
   │            └ 阻却不成立(含防卫过当/避险过当) → 客观违法 ✅，进第二阶层
   │
   ▼ 第二阶层【主观有责（责任）】问："能怪他吗？该让他为这违法行为负责吗？"
   │   ├─ 2.1 有责任能力吗？(年龄§17/精神§18/原因自由行为/单位§30-31) ─────────→ 📐⑥
   │   │        └ 无责任能力(未达年龄/无刑事责任能力) → 【出罪·不负刑责】
   │   ├─ 2.2 有故意/过失吗？(§14故意/§15过失/§16意外) + 认识错误怎么处理 ─────→ 📐③
   │   │        └ 既无故意也无过失 → §16意外事件 → 【出罪】；过失但法无明文 → 不罚
   │   └─ 2.3 有责任阻却吗？(违法性认识可能性/期待可能性·门槛极高) ───────────→ 📐③
   │            ├ 责任阻却成立 → 【出罪】
   │            └ 阻却不成立 → 责任 ✅ → 【单个犯罪成立】，进修正形态
   │
   ▼ 修正形态【犯罪成立后，三个"修正"追问，主观题逐一过】
   │   ├─ M1 停在半道了吗？(着手前=预备/预备中止;着手后=未遂/中止;不能犯出罪) ─→ 📐④
   │   ├─ M2 不止他一个人吗？(正犯/共犯·主从胁教·实行过限·脱离·身份) ───────→ 📐⑤
   │   └─ M3 牵涉几个罪？(想象竞合/法条竞合/结果加重=不并罚；实质数罪=§69并罚) ─→ 📐⑦
   │
   ▼ 输出结论：罪名 + 形态(既未中) + 共犯角色 + 罪数处断
              → 量刑情节衔接刑罚论侧（📐 [[刑法-总论-刑罚裁量模型]] 等）
```

**三句话记住主干**：
- **客观先行**：先把"行为—因果—结果—有无阻却"在客观阶层走完，再碰主观。
- **主观断后**：责任能力→故意过失→责任阻却，任一缺位就出罪，别急着定罪。
- **修正收尾**：罪一旦成立，机械地追问"形态？共犯？罪数？"——这三问是主观题的固定踩分位。

## 三、 一眼判 · 路由总表（看到信号 → 跳哪个模型）

> 考场上来不及想体系，靠"信号词"条件反射。案情里只要冒出左列字眼，立刻跳右列模型。

| 案情里冒出这个信号 | 它是哪一层的问题 | 跳哪个模型 |
|---|---|---|
| 没动手／旁观／有义务不救／先前行为制造危险 | 客观·危害行为 | 📐① |
| 中间插了火灾／车祸／第三人／被害人自己跳河逃命／特殊体质 | 客观·因果归责 | 📐① |
| 还手／反击／见义勇为／避险／被害人同意／打了正在行凶的人 | 客观·违法阻却 | 📐② |
| 没满 14/16/18 岁／精神病／喝醉／吸毒致幻／"公司/单位"实施 | 主观·责任能力 | 📐⑥ |
| 想杀甲打中乙／白糖当砒霜／误把人当野猪／以为不犯法 | 主观·认识错误/罪过 | 📐③ |
| 还没得手／中途收手／已送医抢救／工具不管用／对象不在 | 修正·未完成形态 | 📐④ |
| 两人以上／望风／放风／教唆别人／递刀帮忙／事后退出 | 修正·共同犯罪 | 📐⑤ |
| 一个动作触犯数罪名／为一目的串数罪／数个独立罪怎么判 | 修正·罪数 | 📐⑦ |

> 💡 一道综合题往往同时点亮 **好几行**——这恰恰是它要你串模型的信号。点亮几行，就按流水线顺序把对应模型逐个跑一遍。

## 四、 四个"接缝"：模型之间最容易漏判的衔接点

单个模型管不到模型之间的缝。这四处是命题人埋雷的重灾区，也是深度报告自己点名"还没覆盖的连接"。

| # | 接缝 | 坑在哪 / 怎么判 | 牵动模型 |
|---|---|---|---|
| 1 | **因果 ↔ 形态** | 介入因素**阻断**因果时，别顺手写"既遂"——结果不归属于他，往往是**未遂**。例：刺一刀本可救活，介入罕见山体滑坡致死 → 因果阻断 → 故意杀人**未遂**，不是既遂。 | ①→④ |
| 2 | **认识错误 ↔ 共犯** | 实行犯发生**打击错误/对象错误**时，教唆犯、帮助犯怎么归责？要把"实行犯按法定符合说定什么"先定下来，再看共犯在共谋范围内是否一并担责。 | ③↔⑤ |
| 3 | **违法阻却 ↔ 责任** | **防卫过当/避险过当是"跨层"现象**：第一阶层**不**阻却违法（仍是违法行为），但第二阶层**减轻或免除**责任。别在客观阶层就把它当无罪放走。 | ②→③ |
| 4 | **责任年龄 ↔ 共犯** | 14~16 岁只对八类罪负责，且看**"罪行非罪名"**；他与成年人共同犯罪时，"谁定罪、定什么"要把责任年龄筛一遍——低龄人对盗窃不担责，转化抢劫往往不适用（对应真题单选-49、单选-50）。 | ⑥↔⑤ |

> 主观题的高分差距，常常就差在这四条缝有没有判到。判完单模型，回头扫一眼"我这道题点亮了哪几个工位、它们之间有没有上面四种缝"。

## 五、 综合案例 · 串模型走一遍（链式调用演示）

> 单选题只点一个工位；下面这道"主观题式"案情一次点亮 5 个工位（①④⑤⑥⑦），正好演示流水线怎么跑。**重点不是背结论，而是看每一步'调了哪个模型'。**

**【案情】** 甲（15 周岁）与乙（20 周岁）共谋入户**盗窃**。某夜二人撬门入户，甲在门口望风、乙入室翻找财物。屋主丙突然回家撞见，乙为抗拒抓捕，掏出随身水果刀朝丙胸部猛刺一刀后二人逃走。丙重伤倒地，邻居报警；救护车送医途中遭遇**罕见暴雨引发的山体滑坡**，丙连同救护车被埋身亡。事后查明：乙那一刀本可经救治存活，丙的死亡系滑坡所致。问甲、乙的刑事责任。

**→ 上总纲流水线，逐站调模型：**

**第0步 拆解**：两人（甲、乙）、核心行为＝盗窃 + 乙的当场暴力。初步罪名假设：盗窃→可能转化抢劫（§269）+ 故意杀人。**两人各跑一遍。**

**【乙·成年实行犯】**

| 站点      | 调用  | 判断                                                                                                                     | 小结           |
| ------- | --- | ---------------------------------------------------------------------------------------------------------------------- | ------------ |
| 客观·行为因果 | 📐① | 入户盗窃被发现、为抗拒抓捕当场使用暴力 → §269 **转化抢劫**客观面成立。刺刀本可救活，介入"罕见山体滑坡"——三步法：**异常度极高+独立+对死亡起决定作用 → 阻断因果**。乙的行为与"死亡"无刑法因果，仅与"重伤"有因果。 | 死亡不归属于乙      |
| 客观·违法阻却 | 📐② | 丙未实施任何不法侵害，乙是侵害方 → **无**正当防卫/避险空间。                                                                                     | 客观违法成立       |
| 主观·责任能力 | 📐⑥ | 乙 20 周岁、精神正常 → 完全责任能力。                                                                                                 | 担责主体 ✅       |
| 主观·罪过   | 📐③ | 朝胸口猛刺一刀 → 至少**间接故意**杀人。                                                                                                | 故意 ✅         |
| 修正·形态   | 📐④ | 死亡因介入而**阻断**（接缝1！）→ 故意杀人不能既遂 → **故意杀人未遂**；抢劫已致丙**重伤**（实害）。                                                             | 杀人未遂 + 抢劫致重伤 |
| 修正·罪数   | 📐⑦ | 同一"刺刀"行为同时该当 抢劫（致人重伤的加重情节）与 故意杀人（未遂）→ 属**想象竞合 vs 结果加重**的判断（回⑦定型），从一重处断、不数罪并罚。                                          | 一行为、从一重      |

→ **乙**：成立抢劫罪（入户、致人重伤）与故意杀人罪（未遂）的想象竞合，从一重处断。

**【甲·15 周岁望风者】**

| 站点 | 调用 | 判断 | 小结 |
|---|---|---|---|
| 主观·责任能力 | 📐⑥ | 甲 15 周岁（已满 14 不满 16）→ 仅对**八类罪**负责，且看**"罪行非罪名"**。 | 责任年龄受限 |
| 修正·共犯 | 📐⑤ | 甲乙共谋的是**盗窃**；乙临场掏刀升级为暴力，属**实行过限**，甲事前无共谋、不知情 → 甲**不对转化抢劫/杀人**担责（接缝2、接缝4！）。 | 过限不及于甲 |
| 责任年龄×共犯结算 | 📐⑥×⑤ | 甲自身只参与了**盗窃**；而盗窃**不在八类罪**内 → 已满 14 不满 16 的甲**对盗窃不负刑事责任**。 | 甲不构成犯罪（可治安处罚） |

→ **甲**：因责任年龄 + 实行过限，对全案**不负刑事责任**。

> **复盘**：这一道题，光靠任何单个模型都答不全——它考的就是"流水线 + 接缝"。总纲的价值，就是让你**机械地把 ①④⑤⑥⑦ 逐站跑到，不漏任何一个踩分位**。（个别结论涉学说/实务分歧处，已在对应子模型详述，此处只演示路由。）

## 六、 口径与体系：两阶层 vs 改良四要件（锁定声明）

法考答题前必须**锁死一套体系**，全卷统一，不能半句两阶层半句四要件。本库统一锁 **两阶层**，理由：与现有 7 个子模型、深度报告一致，且贴合主观题"先客观后主观"的官方审查顺序。

| 体系 | 怎么切犯罪 | 故意/过失放哪 | 与本总纲关系 |
|---|---|---|---|
| **两阶层（本库锁定）** | 客观违法阶层 + 主观有责阶层 | 主观有责阶层（责任要素） | ✅ 主轴，本总纲流水线即按此排 |
| 三阶层 | 构成要件该当性→违法性→有责性 | 构成要件（目的论）或有责性（古典） | 把"客观违法"再细分两层，结论同 |
| 改良四要件（柏浪涛 2026） | 客体·客观方面·主体·主观方面 | 主观方面 | 编排不同、**结论一致**，可平移 |

> **一句话**：三套体系**结论高度一致，只是把同样的判断点摆放顺序不同**。考场上任选其一从头用到尾即可；本库一律用两阶层，遇到子模型里"违法/有责"的措辞即按本总纲的阶层定位对号入座。
