# 📐 责任竞合 · 答题模型（违约 / 侵权竞合——择一 + 精神损害边界）

> **核心一句**：责任竞合是一棵"**择诉决策树**"——一个行为同时长出**违约 + 侵权**两个请求权（§186），受损方**只能告一个**；难点是"**告哪个划算**"（举证 / 赔偿范围 / 精神损害 / 时效）和"**能不能附带精神损害**"（§996 人格权 vs §1183 特定物）。概念母页 → [[违约与侵权竞合]]；精神损害边界 → [[精神损害赔偿]]；违约一侧细算 → [[民法-合同-违约责任模型]]。
> 🔎 **三处务必内化**：
> ① **§186 在总则编第八章「民事责任」，不是合同编！** 两个"第八章"别混：**总则编第八章 = 民事责任**（§176-§187，含 §186 竞合）；**合同编第八章 = 违约责任**（§577 起）。旧《合同法》§122 已升格为 **§186**（措辞改为"损害对方**人身权益、财产权益**…**有权选择**请求其承担违约责任或侵权责任"，删去"依照本法/其他法律"）。
> ② **择一不并用**——同一损害只能选违约 _或_ 侵权，不能"既要违约金又要侵权赔"（防双重受偿）。**唯一的"附带"特例是 §996**：选**违约之诉**时，若违约**损害人格权**，可一并请求精神损害赔偿（这不算"并用两个责任"）。
> ③ **精神损害两条路别串**：违约之诉**只有"损害人格权"才赔**（§996，人格权编）；侵权之诉是"**人身权益**"（§1183Ⅰ）或"**故意/重大过失**侵害**具有人身意义的特定物**"（§1183Ⅱ）；**一般过失毁损特定物，两条路都要不到**。"故意/重大过失"**只是 §1183Ⅱ 的要件**，勿搬到 §996 / §1183Ⅰ。

## 一、核心考情（含考频 + 机构研判免责）

> ⚠️ **考频免责声明**：司法部自 2018 年法考改革起，官方**仅公布大纲、合格分数线、成绩，从不公开历年真题原题及任何"考点频次"统计**。下列"中高频 / ★"均系机构 / 法学院清单研判，**非官方一手数据**，不得伪造频次。可溯源定性：**中国政法大学（法大）备考"必考清单"点名"责任竞合"**（单一来源点名，置信中等）。

- **命题核心**：制造"一个行为既违约又侵权"的局面（修车出人命、保管烧毁特定物、婚车毁婚礼），考你：**能不能同时主张**（不能，§186 择一）、**告哪个**、**能否要精神损害**、**多人侵权怎么分**。
- **三大必考维度**：①§186 **择一选择权**（谁选、能否并用）②**§996 / §1183 精神损害边界**（人格权 vs 特定物 vs 一般财产）③**违约严格责任 vs 侵权过错责任**的归责 / 举证 / 赔偿范围差异 + 多层侵权 §1171/§1172。
- **考查形态**：客观题以选项辨析为主（"能否同时主张""能否要精神损害""法人能否要"）；主观题作请求权选择分析的一环。
- **真题存量提示**：本库目前**仅 1 道**以"责任竞合 + 精神损害"为核心的真题（[[合同通则-多选-17]] 录像带题），见第六部分；其余多在违约 / 侵权各自专题。

## 二、违约之诉 vs 侵权之诉 全景对照（竞合时"选哪个"的底表）

> 选诉前先把两条路的差异摆平——**时效相同（都 3 年），真正分野在归责举证、赔偿范围、精神损害**。

| 维度 | 违约之诉 | 侵权之诉 |
|---|---|---|
| **归责原则** | **严格责任**（§577，不问过错） | **过错责任**（§1165Ⅰ）/ 过错推定（§1165Ⅱ）/ 法定无过错（§1166） |
| **举证** | 守约方只证"违约 + 损害"，违约方证免责 | 一般由受害人证**过错**（过错推定时倒置） |
| **赔偿范围** | 受**可预见封顶**（§584，"订约时""违约方"预见） | **全部损失**，原则上不受可预见限制 |
| **精神损害** | **仅"损害人格权"**可（§996） | 人身权益（§1183Ⅰ）/ 故意·重大过失侵害特定物（§1183Ⅱ） |
| **诉讼时效** | **3 年**（§188） | **3 年**（§188）——⚠️**相同，别臆造差异** |
| **管辖** | 合同履行地 / 被告住所地 | 侵权行为地 / 被告住所地 |

## 三、万能四步模型

### 第〇步（前置过滤）：先确认"是竞合，不是别的"

**铁则**：竞合三要件 → ①**同一行为** ②同时满足违约（有合同关系 + 违约）与侵权（侵害**固有 / 人身权益**）构成 ③落入 §186"损害对方**人身权益、财产权益**"。
**什么"不是"竞合（负面清单，最易设套）**：
- **缔约过失 vs 违约 = 互斥、不竞合**（合同成立**前** vs **后**，时间不重叠）；**缔约过失 vs 侵权 = 可能竞合**（磋商中违反保护义务致人身伤害）→ 细分 [[民法-合同-缔约过失责任模型]]。
- **纯违约**（只损履行利益、未侵固有权益）→ 不竞合，直接走 [[民法-合同-违约责任模型]]。
- 三大责任（缔约过失 / 违约 / 侵权）如何总分 → [[民事责任体系]]。

> 🏠 **实际案例**（[[合同通则-多选-17]]）：乙（婚庆公司）保管甲的婚礼录像带，被第三人丙抽烟失火烧毁——乙对甲**既违约**（没保管好）**又不作为侵权**（未尽防火义务）= 典型竞合。

### 第一步：§186 择一——告违约 or 告侵权（本模型核心独占）

**铁则**：
- §186：受损方**有权选择**请求违约责任 **或** 侵权责任，**择一、不并用**（同一损害不能两头要，防重复受偿）。
- **选择权人 = 受损害方**（不是法院、不是加害方）。
- ⚠️ **程序细节别绝对化**："法院**必须**释明""可在二审**随意**变更为另一请求权"等**无统一明文**（属民诉法 / 司法解释 + 实践争议）；一般起诉时选、变更受举证期限 / 审级限制。**勿臆造程序条号**。

> 🏠 **实际案例**（[[合同通则-多选-17]]）：甲可选"对乙违约""对乙侵权""对丙侵权"——**三者开放择一**；C 项"**只能**…"把选择权写死 → 错。

### 第二步：选哪个划算？——四把尺（本模型核心独占）

**铁则**（按"对己有利"挑）：
- **怕证不了对方过错** → 选**违约**（严格责任 §577，不问过错，举证更轻）。
- **损失超过"订约时可预见"** → 选**侵权**（全部损失，不受 §584 可预见封顶）。
- **想要精神损害** → 看损害的是**人格权**（违约 §996 可）还是**特定物**（只能侵权 §1183Ⅱ）——见第三步。
- **时效**：违约 / 侵权**都 3 年**（§188），**不构成选择理由**（别在时效上臆造区别）。

⚠️ 违约一侧的归责 / 赔偿 / 违约金细算 → [[民法-合同-违约责任模型]]，本模型不重抄 §584/§585。

### 第三步：能不能附带"精神损害"？——三档边界（引 [[精神损害赔偿]]）

**铁则**（口诀：**人格权两诉皆可，特定物仅侵权且须故意/重大过失，一般财产都不可**）：
- **违约之诉**：仅当违约**损害对方人格权** + **严重**精神损害 → 可请求（**§996，人格权编**）；纯财产 / 一般标的物毁损在违约之诉**不赔**精神损害。
- **侵权之诉 · 人身权益**：侵害**自然人**人身权益 + 严重 → 可请求（§1183Ⅰ）；⚠️**主体限自然人，法人 / 非法人组织无**精神损害赔偿请求权。
- **侵权之诉 · 特定物**：**故意或重大过失**侵害**具有人身意义的特定物**（遗照 / 婚礼录像 / 骨灰盒）+ 严重 → 可请求（§1183Ⅱ）；**一般过失不赔**。
- ⚠️ "故意 / 重大过失"**只是 §1183Ⅱ 特定物的要件**，§996 / §1183Ⅰ **不**以过错程度为要件；§1183 别写成 §1182（财产损失获利计算）。详尽边界表 → [[精神损害赔偿]]，本模型只放精简结论。

> 🏠 **实际案例**（[[合同通则-多选-17]]）：录像带是**物、只损财产权** → **违约之诉 §996 要不到**（A 错）；改走**侵权**，丙系**重大过失**（抽烟失火）毁"具有人身意义的特定物" → **§1183Ⅱ 可要**（B 对，故官方/机构答案由 AB **勘误为 B**）；若丙仅**一般过失**，则 §996、§1183Ⅱ **两条路都要不到**（对照例答 D）。

### 第四步：多人 / 第三人侵权怎么分？（引侵权编）

**铁则**：
- **第三人原因致违约**：违约方**仍先对守约方承担违约责任**（§593），再向第三人追偿；受损方**不能对第三人主张违约**（无合同关系），对第三人**只能侵权**。
- **数人分别侵权三分法**：
  - 各自**部分原因力**、结合才致同一损害 → **按份**（§1172；能定份额按份，定不了**平均**）；
  - 各自行为**都足以致全部损害** → **连带**（§1171，叠加 / 无意思联络的累积因果）；
  - **共同**实施（意思联络或关联共同）→ **连带**（§1168）。
- ⚠️ **§1171（连带）vs §1172（按份）分水岭** = 各自原因力**是否"足以致全损"**（足以→连带；只是部分→按份）。别和共同侵权 §1168 混。

> 🏠 **实际案例**（[[合同通则-多选-17]]）：乙、丙**无意思联络、分别侵害**同一录像带，各为部分原因力 → **§1172 按份**（不是连带）；而对甲而言，乙的责任先经**违约**（§593 第三人原因不免乙的违约责任）。

## 四、当事人权利归位（主体别张冠李戴）

| 谁 | 能干什么 |
|---|---|
| **受损害方** | **选择权人**（§186 择一告违约 / 侵权）；选违约之诉时若损人格权可附带精神损害（§996）；对**第三人只能侵权**（无合同关系） |
| **违约方 / 直接相对人** | 承担受损方所选的那一种责任；**第三人原因致违约仍先担违约责任**（§593），再向第三人追偿 |
| **第三人** | 对受损方负**侵权责任**，**不负违约责任**；数人分别侵权按 §1171（连带）/ §1172（按份）分担 |

> ⚠️ 主体陷阱：**选择权是"受损害方"的**（非法院、非加害方）；法院释明**无硬性统一规则**；精神损害门槛一律是"**严重**"。

## 五、命题人最爱的 10 个陷阱

1. **§186 当合同编条文** —— 错！在**总则编第八章「民事责任」**（合同编第八章是"违约责任"）。
2. **"可同时主张违约 + 侵权"** —— 错！§186 **择一不并用**（防重复受偿）。
3. **违约之诉随便要精神损害** —— 错！**仅"损害人格权"**（§996）。
4. **一般过失毁特定物能要精神损害** —— 错！§1183Ⅱ 须**故意 / 重大过失**。
5. **把"故意 / 重大过失"搬到 §996 / §1183Ⅰ** —— 错！那只是 §1183Ⅱ"特定物"的要件。
6. **法人 / 公司主张精神损害** —— 错！§1183 主体**限自然人**。
7. **违约 / 侵权诉讼时效不同** —— 错！**都 3 年**（§188）；区别在归责 / 举证 / 赔偿范围，不在时效。
8. **§1171 连带 ↔ §1172 按份 对调** —— 各自**足以致全损** = 连带（§1171）；各自**部分原因力** = 按份（§1172）。
9. **受损方找第三人要违约责任** —— 错！对第三人**只能侵权**（无合同），§593 由违约方先担再追偿。
10. **§1183 写成 §1182** —— §1182 是侵害人身权益的**财产损失 / 获利**计算，别串号。

> 子主题细节陷阱另见：[[精神损害赔偿]]（边界表）· [[民法-合同-违约责任模型]]（违约一侧）· [[民法-合同-缔约过失责任模型]]（缔约过失边界）。
