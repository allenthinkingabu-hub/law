# 📐 期间、送达与强制措施 · 完整答题模型（期间计算＋七种送达＋妨害诉讼强制措施＋诉讼费用）

> **核心一句**：这是民诉程序的"后勤保障"板块，主线是**「算日子（期间）→ 送文书（七种送达）→ 治捣乱（强制措施）→ 谁掏钱（费用）」**四步。最毒陷阱是**把"假日后第一日"偷换成"节假日次日"**、**把"代理人拒收"当成留置送达**、**忘了电子送达须经同意且2021年后判决裁定调解书也能电子送**、**把公告送达仍记成旧法60日（现行30日）**、**记不清罚款"个人10万以下、单位5万-100万（有下限）"与"复议不停止执行"**。
>
> 🔎 **《民事诉讼法》（2023修正）核心条文速查**：
> - **第85条【期间计算】**：期间包括法定期间和法院指定的期间；以时、日、月、年计算，**开始的时和日不计算在期间内**；届满最后一日是法定休假日的，以**假日后的第一日**为届满日期；期间**不包括在途时间**，诉讼文书在期满前交邮的，不算过期。
> - **第86条【顺延申请】**：因不可抗拒的事由或者其他正当理由耽误期限的，在**障碍消除后的十日内**可以申请顺延期限，**是否准许由法院决定**。
> - **第87条【送达回证】**：送达必须有送达回证，受送达人在回证上的**签收日期为送达日期**。
> - **第88条【直接送达】**：应当直接送交受送达人；公民本人不在交**同住成年家属**签收；法人/组织由法定代表人、主要负责人或**负责收件的人**签收；有诉讼代理人的**可以**送交代理人；指定代收人的送交代收人。
> - **第89条【留置送达】**：受送达人**或其同住成年家属**拒收的，可以①邀请基层组织或所在单位代表到场见证＋注明拒收事由日期，把文书留在住所；②也可以把文书留在住所并**采用拍照、录像等方式记录送达过程**，即视为送达。
> - **第90条【电子送达】**：**经受送达人同意**，可采用能够确认其收悉的电子方式送达；通过电子方式送达的**判决书、裁定书、调解书**，受送达人提出需要纸质文书的，法院**应当提供**；以送达信息**到达受送达人特定系统的日期**为送达日期。
> - **第91条【委托送达·邮寄送达】**：直接送达有困难的，可以委托其他法院代为送达，或者邮寄送达；邮寄送达的，以**回执上注明的收件日期**为送达日期。
> - **第92-94条【转交送达】**：军人经所在部队**团以上单位的政治机关**转交；被监禁的经监所转交；被采取强制性教育措施的经该机构转交；转交机关必须**立即**交受送达人签收，签收日为送达日。
> - **第95条【公告送达】**：受送达人**下落不明**，或者用本节其他方式**无法送达**的，公告送达；自发出公告之日起，**经过三十日**即视为送达；应当在案卷中记明原因和经过。
> - **第112条【拘传】**：对**必须到庭的被告**，经**两次传票传唤**，无正当理由拒不到庭的，可以拘传。
> - **第113-117条【妨害诉讼行为及制裁】**：违反法庭规则可**训诫、责令退出法庭或罚款、拘留**；六类严重妨害行为（伪造毁灭重要证据、妨碍作证、处分查封扣押冻结财产、侮辱殴打司法人员等、暴力阻碍执行职务、拒不履行生效裁判）可罚款、拘留，构罪追刑责；**虚假诉讼**（当事人恶意串通§115Ⅰ、单方捏造基本事实§115Ⅱ、执行中恶意串通逃避履行§116）应**驳回其请求**并罚款、拘留，构罪追刑责；协助义务单位拒不协助的可罚款，仍不履行可拘留。
> - **第118条【数额与期限】**：罚款**个人10万元以下**，**单位5万元以上100万元以下**；拘留**15日以下**，交公安机关看管，认错改正可提前解除。
> - **第119条【批准与复议】**：**拘传、罚款、拘留必须经院长批准**；拘传用拘传票，罚款拘留用决定书；不服的可向**上一级法院**申请**复议一次**，**复议期间不停止执行**。
> - **第120条【决定权专属】**：对妨害民事诉讼的强制措施**必须由人民法院决定**；非法拘禁他人或非法私自扣押他人财产追索债务的，追究刑责或予以拘留、罚款。
> - **第121条【诉讼费用】**：当事人应按规定交纳案件受理费，财产案件另交其他诉讼费用；**确有困难的可申请缓交、减交或者免交**；收取办法**另行制定**。
> - **《民诉法解释》（2022修正）**：§125（次时/次日起算）、§130（法人签收人＋留置见证代表范围）、§131（到院拒签视为送达；住所地外直接送达拒签拍照录像视为送达）、§132（可向代理人送达；指定代理人为代收人时适用留置）、§133（**调解书应直接送达本人，不适用留置送达**）、§134（受托法院10日内代送）、§135（电子送达媒介与日期认定）、§136（同意电子送达在**送达地址确认书**中确认）、§138-139（公告方式与应载事项）、§140（**简易程序不适用公告送达**）、§141（定期宣判拒签判决书裁定书视为送达）、§174（**必须到庭的被告**＝负有赡养、抚育、扶养义务和不到庭无法查清案情的被告；对必须到庭才能查清基本事实的**原告**也可拘传）、§177（**训诫、责令退出法庭由合议庭或独任审判员决定**）、§181（紧急情况可先拘留后立即报院长补办批准）、§183（罚款拘留可单独可合并）、§184（同一行为**不得连续**罚款拘留）、§185（复议**3日内提出**、上级法院**5日内**作出决定）。

> ⚠️ **诚实标注（条号核验说明）**：本模型全部民诉法条号（§85-95、§112-121）与民诉解释条号（§125、§130-141、§174-187）均已逐条 grep 本库存档的官方全文核验：民诉法据 [2023修正全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2023/11/14/1701622126444477-1701622126462201.pdf)，民诉解释据 [2022修正全文PDF（ssf.gov.cn）](https://www.ssf.gov.cn/portal/rootfiles/2022/05/31/1655612237313322-1655612237326712.pdf)，另可查 [国家法律法规数据库](https://flk.npc.gov.cn/)。**两处易被旧资料误导的点已按原文订正**：①公告送达为"经过**三十日**即视为送达"（2021修法由60日改为30日，原文已核）；②判决书、裁定书、调解书**可以**电子送达（2021新规，§90明文）。**本地无全文、未逐条核验的**：《诉讼费用交纳办法》（国务院2006年制定）本库无官方全文存档，"败诉方负担为原则、胜诉方自愿承担的除外"等具体规则（通说指向该办法第29条）**条号未经本地原文核验**，本模型只呈现民诉法§121本体＋通说规则并如实标注；官方文本可查 [gov.cn](https://www.gov.cn/)。

> ⚠️ **易记错点**：①**开始的时和日不算入**，从次时/次日起算（解释§125）——"送达之日起15日"从送达**次日**起算；②节假日顺延只看**届满的最后一日**，期间**中间**的假日照常计算；且顺延到"**假日后第一日**"，不是"节假日次日"（连续长假时两者不同）；③"交邮不过期"保护的是**当事人寄给法院**（看邮戳），"邮寄送达"是**法院寄给当事人**（看**回执收件日**），方向千万别反；④留置送达的拒收对象**仅限受送达人本人或同住成年家属**——**诉讼代理人**当面拒收判决书，注明即为送达，定性仍是**直接送达**；**调解书不适用留置送达**（解释§133）；⑤电子送达**须经受送达人同意**（送达地址确认书确认），2021年后**判决书、裁定书、调解书也能电子送达**（要纸质的应提供）；⑥公告送达是**最后手段**（下落不明或其他方式均无法送达），期间**30日**（不是60日），**简易程序不适用**公告送达；⑦拘传对象不只是被告——**必须到庭才能查清基本事实的原告**也可拘传（解释§174Ⅱ）；⑧罚款**单位有下限**（5万元以上100万元以下），个人只有上限（10万元以下）；拘留**15日以下**；⑨**拘传、罚款、拘留须院长批准**，但**训诫、责令退出法庭只需合议庭/独任审判员决定**；⑩复议向**上一级法院**、**一次**、**不停止执行**——与回避复议（不停止参与）、保全复议（不停止执行）同一句式，别混成"复议期间暂停"。

## 二、 四步判别模型（算日子 → 送文书 → 治捣乱 → 谁掏钱）

```
              【一件民事案件从收文书到结账的"后勤线"】
                              │
   ▼ 第一步：算日子（期间，§85-86）
   │
   ├─ 期间种类：法定期间（上诉期15日等，法律定）／指定期间（法院酌定、可变更）
   ├─ 起算：开始的时和日不计算在内 → 从次时/次日起算（解释§125）
   ├─ 届满：最后一日是法定休假日 → 顺延至假日后第一日（中间假日照算）
   ├─ 在途：期间不含在途时间，期满前交邮（看邮戳）不算过期
   └─ 耽误：不可抗拒事由/正当理由 → 障碍消除后10日内申请顺延，准否由法院定
                              │
   ▼ 第二步：送文书（七种送达，§87-95，一律要送达回证§87）
   │
   ├─ ①直接送达（§88，首选）：本人→同住成年家属→法人负责收件人→代理人→代收人
   ├─ ②留置送达（§89）：本人/同住成年家属拒收 → 见证＋注明 或 拍照录像；调解书不适用
   ├─ ③电子送达（§90）：须经同意；判决裁定调解书也可（2021新规）；到达特定系统日生效
   ├─ ④委托送达（§91）：委托其他法院代送（受托法院10日内送，解释§134）
   ├─ ⑤邮寄送达（§91）：直接送达有困难；回执收件日为送达日
   ├─ ⑥转交送达（§92-94）：军人（团以上政治机关）/被监禁/强制性教育措施者
   └─ ⑦公告送达（§95，最后手段）：下落不明或其他方式无法送达；满30日视为送达；
      简易程序不适用（解释§140）
                              │
   ▼ 第三步：治捣乱（对妨害民诉的强制措施，§112-120，只能由法院决定）
   │
   ├─ 拘传（§112＋解释§174）：必须到庭的被告（赡养/抚育/扶养＋不到庭无法查清案情）
   │   经两次传票传唤无正当理由拒不到庭；特定原告同样可拘传；须拘传票＋院长批准
   ├─ 训诫/责令退出法庭（§113）：违反法庭规则 → 合议庭/独任审判员决定即可（解释§177）
   ├─ 罚款/拘留（§113-117）：六类妨害行为＋虚假诉讼（§115恶意串通/单方捏造→驳回请求＋罚拘）
   │   ├─ 数额期限（§118）：个人罚款10万以下；单位5万以上100万以下；拘留15日以下
   │   ├─ 批准（§119）：拘传、罚款、拘留必须经院长批准（紧急可先拘后补批，解释§181）
   │   └─ 救济（§119＋解释§185）：不服→上一级法院复议一次，复议不停止执行
   │      （3日内提出、5日内决定）；同一行为不得连续罚拘（解释§184）
   └─ 底线（§120）：任何单位个人不得非法拘禁他人/私自扣押财产追债 → 追刑责或拘留罚款
                              │
   ▼ 第四步：谁掏钱（诉讼费用，§121）
   │
   ├─ 交什么：案件受理费＋财产案件的其他诉讼费用（办法另行制定——国务院交纳办法）
   ├─ 谁负担：败诉方负担为原则（交纳办法规则，本地无全文、通说表述）
   └─ 交不起：确有困难 → 申请缓交、减交、免交（司法救助）
```

> **一句话总诀**：**「算日子：始日不算入、假日后第一日、交邮看邮戳、耽误十日申顺延；送文书：直接为先、拒收留置（本人家属才留置）、电子须同意、公告三十日兜底；治捣乱：拘传两传票、训诫退庭合议定、罚拘院长批、复议一次不停止，个人十万单位五到百万、拘留十五日；谁掏钱：受理费照交、败诉方买单、困难缓减免」**

## 三、 三个高频干扰（假日落点 / 留置对象 / 电子送达范围）

命题人极喜欢在"字眼相近、规则相反"的地方挖坑：

| 干扰类型 | 命题人常见说辞（陷阱） | 法律真实（依据与法理） |
|---|---|---|
| **"节假日次日"偷换"假日后第一日"** | 期间届满日恰逢节假日的，顺延至节假日的次日。 | **❌ 说法错误！**§85Ⅲ：以**法定休假日后的第一日**为届满日。连续长假（如春节7天）时"节假日次日"仍在假期里，与"假日后第一日"并不相同；且顺延只看**届满最后一日**，期间中间的假日照常计算。 |
| **代理人拒收＝留置送达** | 诉讼代理人当面拒绝签收判决书，送达人注明拒收并由见证人签名，构成留置送达。 | **❌ 定性错误！**留置送达（§89）的拒收对象**仅限受送达人本人或其同住成年家属**。向诉讼代理人当面送交属**直接送达**（§88），代理人拒签、注明即为送达，形式上有"注明＋见证"也不改变直接送达的定性。另记：**调解书不适用留置送达**（解释§133）。 |
| **判决书不能电子送达 / 电子送达不需同意** | 电子送达便捷高效，法院可径行采用；但判决书、裁定书、调解书事关重大，不得电子送达。 | **❌ 两头都错！**§90：电子送达**须经受送达人同意**（在送达地址确认书中确认，解释§136）——"径行采用"错；2021修法后**判决书、裁定书、调解书均可电子送达**，受送达人要纸质的应当提供——"不得电子送达"是旧法记忆，也错。 |

## 四、 七种送达方式总对照（适用条件 × 生效时点）

送达题的本质是"对号入座"，把七种方式的**适用条件**和**生效时点**并排背：

| 送达方式（条文） | 适用条件 | 送达生效时点 |
|---|---|---|
| 直接送达（§88） | 首选方式；本人→同住成年家属→法人/组织负责收件人→诉讼代理人→指定代收人 | 送达回证上的**签收日期**（代理人当面拒收：注明即为送达） |
| 留置送达（§89） | **本人或同住成年家属拒收**（调解书除外，解释§133） | 见证＋注明拒收事由留下文书，或留下文书＋**拍照录像**记录过程，**即视为送达** |
| 电子送达（§90） | **经受送达人同意**（送达地址确认书确认）；判决裁定调解书亦可（2021新规） | 送达信息**到达受送达人特定系统的日期**（与法院系统显示不一致时，以受送达人证明的到达日为准，解释§135） |
| 委托送达（§91） | 直接送达有困难，委托**其他法院**代送（受托法院10日内送，解释§134） | 受送达人在送达回证上的**签收日期** |
| 邮寄送达（§91） | 直接送达有困难（受送达人在外地但**地址可知**的典型场景） | **回执上注明的收件日期**（不是寄出日期） |
| 转交送达（§92-94） | 军人（所在部队**团以上单位政治机关**）；被监禁（监所）；被采取强制性教育措施（该机构） | 转交机关**立即**转交后，送达回证上的**签收日期** |
| 公告送达（§95） | **最后手段**：下落不明，或用其他方式均无法送达；**简易程序不适用**（解释§140） | 自发出公告之日起**经过30日**视为送达（发出日以最后张贴/刊登日为准，解释§138） |

> ⚠️ **易混提醒**：邮寄送达"回执收件日"与当事人"交邮不过期（邮戳日）"是**两个方向**的规则——法院寄出看**回执**，当事人寄出看**邮戳**；委托送达与转交送达都是"借手"，但受托的是**法院**（委托送达）、转交的是**部队/监所/教育机构**（转交送达），别混。

## 五、 万能四步答题模型

在法考答题中（客观题选项判断为主），按照以下四步进行涵摄：

*   🚗 **统一案例**：老王诉老李借款纠纷，标的10万元。一审判决老李败诉，判决书于**5月6日**送达老李，上诉期15日。老李之子小李是其诉讼代理人。庭审期间老李的朋友大张曾大闹法庭，老李所在小区物业公司曾拒绝协助法院调查。

### 第一步：算日子——期间从哪天起算、到哪天届满、耽误了怎么办？

> **始日不算次日起，假日届满顺一天，交邮邮戳保平安，耽误十日申顺延**

#### 概述

期间是程序权利的"保质期"，考点集中在四个刻度：

- **种类**：法定期间（法律直接规定，如上诉期15日）与法院**指定期间**（如指定补正期限）——指定期间由法院酌定、可以变更，法定期间相对刚性但**并非绝对不可动**；

- **起算**：期间**开始的时和日不计算在期间内**，以日/月/年计算的从**次日**起算（§85Ⅱ＋解释§125）；

- **届满**：最后一日是法定休假日的，以**假日后的第一日**为届满日（§85Ⅲ）——只看届满那天，期间中间的假日照常算；

- **在途与耽误**：期间不含在途时间，文书**期满前交邮**（看邮戳）不算过期（§85Ⅳ）；因**不可抗拒的事由或其他正当理由**耽误期限的，**障碍消除后10日内**可申请顺延，**准否由法院决定**（§86）。

#### 大白话讲解

老李5月6日收到败诉判决书，上诉期15日怎么数？

**第一刀：5月6日（送达当天）不算**——从**5月7日**开始数第1天，数满15天，**5月21日**是最后一天。

**第二刀：看5月21日是不是法定休假日**——假设当年5月21日恰逢端午节假期第一天（假期21-23日），那么届满日**不是5月22日（"次日"仍在假期里）**，而是顺延到**假日后的第一日5月24日**。命题人最爱写"顺延至节假日次日"，遇到连续假期这句就露馅。再注意：如果假期出现在5月7日-20日**中间**，照常计入15天，**不扣除**。

**第三刀：老李人在外地怎么办？**——5月24日（届满日）当天，老李把上诉状**交给邮局**，邮戳5月24日，法院5月28日才收到。过期了吗？**没有**——"诉讼文书在期满前交邮的，不算过期"，看**邮戳**不看法院收到日。

**第四刀：真耽误了怎么办？**——假设老李5月18日突发重病住院昏迷，6月1日出院（障碍消除），他可以在**6月1日起10日内**（6月11日前）向法院**申请顺延**上诉期；但注意两点：一是"10日"是**申请**的期限，二是**准不准由法院决定**，不是申请了就自动顺延。

| 要素拆解 | 本案对应 | 规则落点 |
|---|---|---|
| 起算 | 5月6日送达日不算，5月7日起算 | §85Ⅱ＋解释§125 次日起算 |
| 届满 | 5月21日逢假期，顺延至假日后第一日5月24日 | §85Ⅲ 非"节假日次日" |
| 在途 | 5月24日交邮邮戳为准，法院何时收到不影响 | §85Ⅳ 交邮不过期 |
| 耽误 | 昏迷住院，出院后10日内申请顺延，准否法院定 | §86 顺延申请 |

#### 一句话闭环记忆

> 🎯 **一眼判**：送达日不算、次日起算；届满逢假日顺到**假日后第一日**（中间假日照算）；当事人寄法院看**邮戳**；耽误了在**障碍消除后10日内**申请顺延、**准否法院说了算**。

### 第二步：送文书——七种方式怎么选、何时生效？

> **直接为先拒收留置，电子须同意，找不到人才公告**

#### 概述

送达的答题逻辑是一棵**优先级决策树**（每一步都要有**送达回证**§87）：

- **能当面就直接送**（§88）：本人不在交**同住成年家属**；法人找**负责收件的人**；有代理人**可以**送代理人；指定了代收人送代收人；

- **当面拒收就留置**（§89）：但拒收的必须是**本人或同住成年家属**——两条路：请基层组织/单位代表**见证＋注明**，或**拍照录像**记录过程；**调解书不适用留置**（解释§133，调解讲自愿，人家不要就等于反悔）；

- **同意了可以电子送**（§90）：须在**送达地址确认书**中确认同意；2021年后**判决裁定调解书也能电子送**（要纸质应提供）；生效看**到达特定系统之日**；

- **直接送有困难**：委托其他法院**代送**或**邮寄**（回执收件日生效，§91）；

- **特殊人群转交**（§92-94）：军人（团以上政治机关）、被监禁者（监所）、被强制性教育者（该机构）；

- **实在找不到人才公告**（§95）：下落不明或其他方式**均**无法送达；满**30日**视为送达；**简易程序不适用**公告送达（解释§140，需要公告说明案子已不"简易"）。

#### 大白话讲解

法院要给老李送各种文书，一年里遇到五个场景，每个场景对一种方式：

**场景一（直接送达）**：书记员上门，老李不在家，他同住的成年儿子小李签收了传票——**直接送达完成**，小李签收那天就是送达日。后来法院电话通知老李来取判决书，老李让诉讼代理人小李去取，小李看到败诉**当场拒签**，送达人员在回证上注明拒收、见证人签名——注意！这**还是直接送达**（注明即为送达），**不是留置送达**，因为留置的拒收对象只能是"本人或同住成年家属"，代理人不在此列。

**场景二（留置送达）**：书记员向老李**本人**送开庭传票，老李把门一摔拒收。书记员有两条路：①请居委会工作人员到场**见证**，在回证上注明拒收事由和日期，把传票放老李家；②不用找见证人，把传票放下，**掏出手机拍照录像**记录全过程——两条路都**即视为送达**。但如果送的是**调解书**，老李拒收就不能留置——调解书拒收等于反悔，调解不生效。

**场景三（电子送达）**：老李在**送达地址确认书**上勾选了"同意电子送达"并填了邮箱。法院把裁定书发到该邮箱，系统显示**5月6日发送成功**——5月6日即送达（如果老李能证明实际5月8日才到达他的邮箱系统，以5月8日为准）。没有这份"同意"，法院**不能**径行电子送达。

**场景四（邮寄送达）**：老李去外地出差一年多没回家，但邻居知道他在外地的地址——他**不是下落不明**，法院应**邮寄送达**到外地地址，以**回执上注明的收件日期**为送达日期（不是寄出日）。

**场景五（公告送达）**：老李彻底失联，手机停机、亲友都不知去向，各种方式全试过送不到——**下落不明**，法院公告送达，公告发出（报纸刊登/公告栏张贴，以最后刊登张贴日为准）起**经过30日**视为送达。注意两个尾巴：旧法60日**已改30日**；如果案件正适用**简易程序**，需要公告就说明案子不简单了，**简易程序不适用公告送达**。

#### 一句话闭环记忆

> 🎯 **一眼判**：选送达方式看三问——**人在不在**（在→直接，拒收且是本人/家属→留置）、**同不同意**（同意→电子，判决调解书也能电子送）、**找不找得到**（地址可知→邮寄看回执；下落不明→公告满30日）；特殊身份走转交；调解书不留置、简易程序不公告。

---

### 第三步：治捣乱——妨害诉讼的行为配什么措施、谁批准、怎么救济？

> **拘传两传票，训诫退庭合议定，罚拘院长批，复议一次不停止**

#### 概述

强制措施是法院维持诉讼秩序的"工具箱"，五件工具从轻到重：**拘传、训诫、责令退出法庭、罚款、拘留**。考点四层：

- **拘传**（§112＋解释§174-175）：对象是**必须到庭的被告**（＝负有**赡养、抚育、扶养义务**和**不到庭就无法查清案情**的被告）＋**必须到庭才能查清基本事实的原告**；程序是**经两次传票传唤＋无正当理由拒不到庭**，用**拘传票**，拘传前先说明后果、批评教育；

- **训诫、责令退出法庭**（§113）：针对违反法庭规则的人，由**合议庭或独任审判员决定**即可（解释§177），**不需院长批准**；

- **罚款、拘留**：适用于违反法庭规则情节重者（§113）、六类妨害行为（§114：伪造毁灭重要证据/妨碍作证/处分查封扣押冻结财产/侮辱殴打司法人员等/暴力阻碍执行职务/拒不履行生效裁判）、**虚假诉讼**（§115：恶意串通型＋单方捏造型→**驳回其请求**＋罚拘＋构罪追刑责；§116：执行中恶意串通逃避履行）、拒不协助的单位（§117：先罚款、仍不履行可拘留）；**数额期限**（§118）：罚款**个人10万元以下、单位5万元以上100万元以下**（单位有下限！），拘留**15日以下**、交公安机关看管、认错改正可提前解除；

- **批准与救济**（§119-120＋解释）：**拘传、罚款、拘留必须经院长批准**（紧急可先拘后立即报院长补批，解释§181）；不服罚款拘留的，**收到决定书3日内**向**上一级法院**申请**复议一次**，上级法院**5日内**作出决定，**复议期间不停止执行**；罚款拘留可单独可合并，但**同一行为不得连续**罚拘（解释§184）；强制措施**只能由法院决定**，私人非法拘禁、扣押财产追债的反被追责（§120）。

#### 大白话讲解

这个案子审理和执行过程中冒出四个"捣乱的"，法院逐一开药：

**捣乱者一（老李本人——拘传？）**：老李经两次传票传唤拒不到庭。能拘传他吗？**要看案由**——本案是借款纠纷，老李不是"负有赡养、抚育、扶养义务"的被告，如果不到庭也能查清案情，就**不能拘传**，缺席判决即可；反过来，若这是老李他爹告老李**索要赡养费**的案子，老李就是"必须到庭的被告"，两次传票传唤拒不到庭，法院可**经院长批准、发拘传票**拘他到庭。再补一刀：如果**原告**必须到庭才能查清基本事实却两传不到，**同样可以拘传**（解释§174Ⅱ）——"拘传只能对被告"是陷阱句。

**捣乱者二（大张——大闹法庭）**：老李的朋友大张旁听时鼓噪起哄、未经准许录像直播庭审。审判长当庭**训诫**并**责令其退出法庭**——这两样**合议庭/独任审判员自己就能决定**，不用报院长。大张不服气继续哄闹、砸了法庭话筒，情节升级，法院对其**罚款8万元＋拘留10日**——罚款拘留**可以合并适用**，但必须**经院长批准**、用**决定书**；个人罚款上限**10万元**，8万合法；拘留上限**15日**，10日合法。

**捣乱者三（物业公司——拒不协助）**：法院向小区物业调查取证，物业公司拿"内部规定"当挡箭牌拒绝协助。法院可对**单位罚款5万元以上100万元以下**——假如法院开出**120万元**罚单，就**超过了法定上限**，物业公司可以此为由，在**收到决定书3日内**向**上一级法院申请复议一次**；但注意，**复议期间罚款照样执行，不停止**。

**捣乱者四（老李与小舅子——虚假诉讼）**：老李眼看要败诉，与小舅子**恶意串通**虚构一笔"借款"提起诉讼，企图稀释责任财产。法院查明后应**驳回其请求**，并对二人**罚款、拘留**，构成虚假诉讼罪的**移送追究刑事责任**——注意动作组合是"驳回请求＋罚拘＋刑责"三件套，不是"不予受理"。

**底线**：老王等不及，雇人把老李关起来逼债——**任何单位和个人都无权私自采取强制措施**，非法拘禁他人追索债务的，反过来**追究刑事责任**或予以拘留、罚款（§120）。

#### 一句话闭环记忆

> 🎯 **一眼判**：拘传＝**必须到庭的被告（赡养抚育扶养＋查案需要）＋特定原告**，两次传票是前提；**训诫/退庭→合议庭定，拘传/罚款/拘留→院长批**；数额"**个人十万以下、单位五到百万、拘留十五日**"；救济"**3日提复议、上级5日定、一次、不停止执行**"；虚假诉讼＝驳回请求＋罚拘＋刑责。

### 第四步：谁掏钱——诉讼费用谁交、谁最终负担、交不起怎么办？

> **受理费先交，败诉方买单，困难缓减免**

#### 概述

诉讼费用考点最薄，三句话（§121）：

- **交什么**：案件**受理费**人人要交；**财产案件**另按规定交纳其他诉讼费用；具体标准由**另行制定**的办法规定（即国务院《诉讼费用交纳办法》）；

- **谁负担**：**败诉方负担为原则**（部分败诉按比例分担；胜诉方自愿承担的除外）——⚠️ 该细则出自《诉讼费用交纳办法》，本库**无该办法官方全文存档，具体条号未经本地核验**，此处按通说呈现；

- **交不起**：交纳确有困难的，可以按照规定向法院申请**缓交、减交或者免交**——这就是诉讼费层面的**司法救助**，三个字"缓、减、免"。

#### 大白话讲解

老王起诉时先向法院**预交**了案件受理费2300元（10万元标的按办法计算的大致量级，具体以交纳办法为准）。案子审完老李败诉——这2300元**由败诉的老李负担**，判决主文最后一项"案件受理费××元由被告负担"写的就是这个；如果老王的10万元诉请只支持了5万，费用就**按胜败比例**各担一半上下。

另一头，老李他爹想告老李要赡养费，但老人只有低保、拿不出受理费——他可以向法院申请**缓交**（先立案后交）、**减交**（少交一部分）甚至**免交**（一分不交），这就是"司法救助"，保证"打不起官司"的人也进得了法院大门。

**记忆锚**：预交看**原告**（起诉时垫付），负担看**判决**（败诉方买单），困难看**救助**（缓→减→免）。

#### 一句话闭环记忆

> 🎯 **一眼判**：受理费**原告先垫、败诉方终担**（比例败诉按比例担）；交不起就申请**缓、减、免**三级司法救助——费用规则细节在国务院《诉讼费用交纳办法》，民诉法本体只有§121一条。

## 六、 易混提示

*   **"交邮不过期" vs "邮寄送达回执生效"**：
    *   *当事人寄给法院*：期满前**交邮（邮戳）**即不过期（§85Ⅳ）；*法院寄给当事人*：以**回执收件日**为送达日（§91）——谁寄的按谁的规则。
*   **留置送达 vs 直接送达中的"拒收注明"**：
    *   *留置*只针对**本人/同住成年家属**拒收（§89）；*代理人*当面拒收判决书，注明即为送达，定性是**直接送达**（§88）——两者外观都有"注明"，看**拒收的人是谁**。
*   **训诫、责令退出法庭 vs 拘传、罚款、拘留的批准权限**：
    *   前两样**合议庭/独任审判员**决定即可（解释§177）；后三样**必须经院长批准**（§119）——轻措施当庭定，重措施院长批。
*   **复议"不停止执行"家族**：
    *   罚款拘留复议（§119）、保全/先予执行复议（§111）**均不停止执行**；回避复议期间被申请回避人员**不停止参与本案工作**（有例外）——民诉里"复议"几乎都不叫停，别脑补"暂停"。
*   **公告送达30日 vs 涉外/旧法期间**：
    *   国内公告送达**30日**（2021修法前为60日，§95已核原文"经过三十日"）——遇到"60日"选项先想是不是旧法残影。

## 七、 命题人最爱的 6 个陷阱

1.  **"期间届满日遇节假日，顺延至节假日次日"** —— 错！顺延至**法定休假日后的第一日**（§85Ⅲ）；连续长假时"次日"仍在假期内。且期间**中间**的假日照常计算、不扣除。
2.  **"法定期间一律不得顺延"** —— 错！因不可抗拒的事由或其他正当理由耽误的（含上诉期等法定期间），可在**障碍消除后10日内**申请顺延，准否由法院决定（§86）。
3.  **"诉讼代理人拒收判决书的，构成留置送达"** —— 错！留置送达的拒收对象仅限**本人或同住成年家属**（§89）；向代理人当面送交属**直接送达**，拒收注明即为送达。另：**调解书不适用留置送达**（解释§133）。
4.  **"电子送达高效便捷，法院可径行采用／判决书不得电子送达"** —— 双错！电子送达**须经受送达人同意**（§90，送达地址确认书确认）；2021修法后**判决书、裁定书、调解书均可**电子送达，要纸质的应当提供。
5.  **"受送达人出差在外无人签收，法院可径行公告送达"** —— 错！出差在外但**地址可知**的不是"下落不明"，应**邮寄送达**（回执收件日生效）；公告送达是**穷尽其他方式后的最后手段**，且满**30日**（非60日）才视为送达，简易程序不适用。
6.  **"对单位罚款没有下限／罚款拘留复议期间停止执行"** —— 双错！单位罚款为**5万元以上100万元以下**（有下限，个人为10万元以下）、拘留**15日以下**（§118）；不服的向**上一级法院**申请**复议一次**，**复议期间不停止执行**（§119）。
