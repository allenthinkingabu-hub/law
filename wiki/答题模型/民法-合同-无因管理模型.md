# 📐 无因管理 · 答题模型（万能四步）

> 凡"没人请、自己上手替别人办事"的题（喂猫 / 加固房屋 / 替还债 / 救人），按四步走：**定性 → 适法 → 算账 → 善后**。
> **核心一句话**：无因管理 90% 落在"构成"——三要件（他人事务 + 无义务 + 为他人意思），且**自利不否定、不以结果论**；构成后再分**适法 / 不适法**决定能要多少钱。
> **对照概念** → [[不当得利]]（"多拿了" vs 无因管理"帮了"）· [[民事责任体系]]（侵权 / 不当得利 / 无因管理 债因谱系）。
> **适用真题**：[[准合同-单选-02|C3-单选-02·三要件+排除→D]] · [[准合同-单选-03|C3-单选-03·不以结果论+费用vs补偿→C]] · [[合同通则-多选-25|C1-多选-25·母公司替还=无因管理→AB]] · [[合同通则-单选-57|C1-单选-57·有利益关联≠无因管理·D项反面]]。
>
> 🔎 **法条已联网核实（2026-06-15；§979-§984 全章 3 路 gov.cn + 6 条对抗式复核全 CONFIRMED；依吴训祥/金可可权威评注）**：依据＝无因管理 **§979-§984**（+ 见义勇为 §183/§184）。**核出全库 5 处条号错**（见文末顺手订正）。
> ⚠️ **三个最易记错**：①"受益限度内偿还"＝**§980**（不适法），不是 §979；②"及时通知"＝**§982**、"报告+转交财产"＝**§983**（别整体后移一条）；③"紧急救助免责"＝**§184**（见义勇为·总则编），§984 其实是"事后追认→适用委托"。

## 一、核心考情

- **频率**：★★★★（准合同侧最高频核心行）。233 + 法大双机构点名"三要件 + 必要费用偿还"。客观题单选常出，主观题债因分析入口。
- **命题核心**：①三要件"看着帮忙、其实不构成"陷阱（自利否定 / 结果论 / 违法违公德 / 有义务 / 道德宗教）；②必要费用 vs 损失补偿 vs 侵权赔偿 / §1252 混淆；③适法 / 不适法（§979II / §980）进阶。
- **三大必考点**：①三要件定性（+自利不否定+不以结果论）；②必要费用偿还（必偿+利息）vs 损失适当补偿（有限）+ 无报酬；③与不当得利 / 见义勇为 / 债务加入辨析。

## 二、万能四步模型

（老王＝管理人 / 邻居，小李＝受益人 / 本人）

### 第一步：三要件定性 —— 命门

**铁则**：三要件齐备才构成（§979 I）：

| 要件               | 内容           | 不构成（排除）                    |
| ---------------- | ------------ | -------------------------- |
| ① 管理**他人**事务     | 必须"他人"事务     | 纯为自己 / 误把自己事务当他人（误信管理）     |
| ② **无**法定 / 约定义务 | 无义务而管理       | 监护人 / 父母 / 保管人 / 合同义务人＝有义务 |
| ③ 为他人利益的**管理意思** | 主观为他人 + 客观利他 | 纯为自己利益                     |


两条反陷阱铁律：
- **自利不否定**：初衷兼有自利，只要同时为他人，仍构成（防自家失火帮邻居灭火）。法律不要求"纯洁利他"。
- **不以结果论**：管理是否成功（房子还是塌了）不影响成立。

四类排除（理由各异，主观题答理由别说错）：
- **违法 / 违背公序良俗**（替人赌博垫钱）→ 不予保护（§979II 但书延伸）
- **纯为自己 / 误信管理** → 欠缺"他人事务 / 管理意思"
- **有法定 / 约定义务**（监护人）→ 欠缺"无因"
- 履行**道德 / 宗教义务**（代还愿）→ 欠缺"求偿 / 管理意思"（视为赠与 / 好意施惠），**不是"有义务"**

**老王小李**
- ✅ 小李出差，老王自掏腰包喂猫一周 → 他人事务 + 无义务 + 为他人＝无因管理。
- ✅ 自利不否定：老王怕小李家漏水殃及自家，顺手堵了小李家的漏 → 仍构成。
- ❌ 老王是小李孩子的监护人照顾孩子 → 有义务。
- ❌ 老王替小李去庙里还愿 → 道德宗教事务。
- ❌ 老王帮小李赌博垫钱 → 违法。

### 第二步：适法性 —— 决定"能要多少钱"（§979II / §980）

**铁则**：
- **适法**（符合受益人真实意思 / 客观利益）→ 管理人享 §979 I **完整**请求权（必要费用+利息 + 损失适当补偿）。
- **不适法**（不符合受益人真实意思）→ 管理人**不享 §979 I 权利**（§979II）；但受益人**主张享有管理利益**的，仅在**得利范围内**偿还（**§980**）。
- **例外**：受益人真实意思**违法 / 违背公序良俗**的，逆其意思**仍属适法**（§979II 但书）——本人想自杀、你救他，仍是适法无因管理。

**老王小李**
- 适法：小李房子要塌、老王雇人加固 → 老王可要全部加固费。
- 不适法：小李明说"旧房要拆别管"、老王偏花钱修 → 只能在小李实际得利范围内要钱（§980）。
- 例外：小李闹自杀拒绝送医、老王强行送医 → 小李真实意思违背公序良俗，老王仍是适法无因管理。

### 第三步：算账 —— 两条独立请求权 + 别混入其他路径

**铁则**：

| 请求权 | 内容 | 法条 |
|---|---|---|
| **必要费用偿还** | 管理中**支出**的必要费用 + **利息** → 受益人**应当**偿还（确定、强制） | §979 I |
| **损失适当补偿** | 管理人**自身**因管理受的损失 → 受益人**适当**补偿（衡平、有限，非全额） | §979 I |
| **无报酬** | 管理人**不能**请求劳务报酬（民法典未设） | —— |

辨析（别当无因管理补偿）：
- **§1252 物件致损**：房屋倒塌压死鸡 → 建筑物倒塌侵权，**不是**无因管理补偿（C3-单选-03 D 项陷阱）。
- **不当得利**：受益人无法律根据得利 → 返还（路径不同，见 [[不当得利]]）。
- **见义勇为致害**：救助致受助人损害 → 救助人免责（§184）；救助人自己受损 → §183 受益人适当补偿 / 向侵权人索赔。

**老王小李**
- 老王喂猫花 300 元猫粮 → 必要费用，小李**应当**全额还 + 利息。
- 老王被猫抓伤花 200 元医药 → 损失，小李**适当**补偿（未必全赔）。
- 老王不能因"喂了一周"要"劳务费"。
- ❌ 老王加固小李房子、房子还是塌了砸到老王自家车 → 这部分是 §1252 / 侵权，不是 §979 补偿。

### 第四步：善后 —— 管理人义务 + 追认 + 致害归责（§981-§984 / §184）

**铁则**：

| 规则 | 要点 | 法条 |
|---|---|---|
| 适当管理 | 采取**有利于受益人**的方法；中断对受益人不利的、无正当理由**不得中断** | §981 |
| **通知 + 等待指示** | 能通知的应**及时通知**；不需紧急处理的应**等待指示** | §982 |
| **报告 + 转交财产** | 管理结束应**报告**情况；取得的财产应**及时转交**受益人 | §983 |
| **事后追认→适用委托** | 受益人**事后追认**的，**从管理开始时起**适用**委托合同**规定（管理人另有意思表示除外） | §984 |
| 致害归责 | 一般：管理人尽**善良管理人注意**（§981）；**紧急救助**致受助人损害：**免责**（一般过失也不担，§184） | §981 / §184 |

> ⚠️ 无因管理章**没有**"故意 / 重大过失才担责"的统一明文；该标准只在**紧急救助**（§184 / 学理）出现；§982 是**通知义务**不是过错责任（常见误标）。

**老王小李**
- 老王喂猫前能联系上小李就应**通知**；喂完应**报告**并把剩猫粮 / 小李的东西**还给**小李（§982 / §983）。
- 小李回来说"喂得好，我认了" → 事后追认，**从喂猫第一天起**按委托办（§984）。
- 老王火场救小李、一般过失中把小李拽伤 → **免责**（§184）。

## 三、命题人最爱的 7 个陷阱

1. **自利否定** —— "初衷为自己→不构成"错（自利不否定）。
2. **结果论** —— "没管成功→不成立"错（不以结果论）。
3. **违法违公德 / 道德宗教** —— 赌博垫钱 / 代还愿不构成（包装成"热心帮忙"）。
4. **有义务隐藏** —— 监护人 / 保管人 / 职务关系→有义务（用亲属 / 职务掩盖）。
5. **费用 vs 损失 vs 报酬** —— 必要费用全偿+利息；损失只"适当"补偿；**无报酬**。
6. **条号整体错位** —— 受益限度＝§980（非§979）；及时通知＝§982；报告转交＝§983；追认＝§984；紧急免责＝§184（非§984）。
7. **§1252 / 侵权混入** —— 倒塌致损是物件侵权、不是无因管理补偿（C3-单选-03 D）。

## 四、真题演练（套四步模型）

### 范例①：[[准合同-单选-02|C3-单选-02]]（哪个"可以构成无因管理"）→ **D**
A 违法违公德→排除；C 替考友还愿→道德宗教排除；B 主动代招待朋友的客人→朋友社交事务 / 无管理求偿意思（通行答案不构成）；**D 防自家受损+帮邻居修房→自利不否定+客观利他→构成**。→ **D** ✅

### 范例②：[[准合同-单选-03|C3-单选-03]]（台风加固房屋压死鸡）→ **C**
A "初衷自己→不构成"错（自利不否定）；B "没管成→不成立"错（不以结果论）；**C 构成（对）**；D 错——固房费是必要费用张某应付（§979I），压死鸡是 **§1252 建筑物倒塌侵权**（异路径，别混入无因管理补偿）。→ **C** ✅

### 范例③：[[合同通则-多选-25|C1-多选-25]]（母公司乙替甲还潘某2万）→ **AB**
B 乙与甲各独立法人、无义务、主动替还＝无因管理（§979）✅；A 代偿2万生清偿效力、甲尚欠1万✅；C（尚欠3万）错；D 讨薪扣车非自助行为（可走仲裁诉讼、缺紧迫性 §1177）。→ **AB** ✅

### 范例④（反面·定性命门）：[[合同通则-单选-57|C1-单选-57]] D 项
丙是乙公司**股东 + 介绍人**、有商业利益关联 → **不满足"无义务 + 纯为他人"** → **不构成无因管理**（该题正解 C＝债务加入 §552，D 错）。记：**有利益关联 / 有义务 → 不是无因管理**。

## 📐 口诀

> 无因管理四步走：**定性 → 适法 → 算账 → 善后**。
> 三要件：**他人事务 + 无义务 + 为他人意思**，缺一不成立；**自利不否定、不看成败**。
> 排除：违法违公德、纯为自己、有义务（监护人）、道德宗教（还愿）——都不算。
> 算账：**必要费用必偿（+利息），损失只适当补，管理人无报酬**；倒塌压鸡走 §1252、别混进来。
> 适法享全权，不适法只在受益限度内要钱（§980）；本人意思违法违公德的，逆之仍适法。
> 善后记死：**通知 §982、报告转交 §983、追认溯及适用委托 §984、紧急救助免责 §184**——别整体错一条。
