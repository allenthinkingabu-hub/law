# 法考非法证据排除调查全解析

我用**法考唯一标准答案、人话直白、带完整调查步骤**，一次性讲透：

# 一、「对非法证据当庭调查」是什么？

简单说：
**开庭时，被告 / 律师说：这份证据是打出来、骗出来、违规录的（非法取证）**
👉 法官**单独当庭查一遍这份证据合不合法**
👉 **不合法就直接废掉、不能用**

这一步叫：**非法证据当庭调查（排非调查）**

# 二、怎么调查？（法定固定 4 步，考试必考流程）

## 第 1 步：辩方启动 \+ 给线索

被告人 / 律师申请排除非法证据，**必须给线索 / 材料**
例：被刑讯、熬夜审讯、没录像、笔录造假、有伤、体检记录异常
（**无线索 = 直接驳回，不调查**）

## 第 2 步：法官判断要不要查

法官觉得**有疑问** → 启动当庭调查
法官觉得**完全没疑点、纯属瞎闹** → 直接驳回

## 第 3 步：控方举证（重点！举证责任在检察院）

检察院必须拿出材料**证明取证合法**，常用：

1. 讯问同步录音录像（当庭播放）

2. 入所体检表、提讯登记

3. 侦查人员出庭说明情况

4. 取证合法的情况说明

## 第 4 步：双方质证辩论 \+ 法官当庭裁定

控辩双方对「取证合不合法」辩论
法官**当庭立刻决定**：

- 合法：**保留证据，继续用**

- 非法：**直接排除、作废、本案彻底不能用**

# 三、两个超级核心考点（90% 考生错）

1. **排非是先查合法性、再查真实性**
开庭遇到非法证据，**优先调查合法性**，合法了再拿来质证判案

2. **一事不再查**
同一理由、无新线索，重复申请排非 → 法院**不再审查**

# 四、庭前会议 VS 当庭调查（你之前疑惑的点）

1. **庭前会议**：**提前沟通、归纳争议，不做最终裁定**

2. **当庭调查**：**正式审理、当庭拍板、有效力的最终结果**
✅ 会前聊过不算，**有争议开庭必须当庭调查**

检方证合法，当庭定废留。\*\*
