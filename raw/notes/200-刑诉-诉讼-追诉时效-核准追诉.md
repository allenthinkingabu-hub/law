# 一、先纠正题干那句话的两处错误（2026法考标准答案，依据《高检刑诉规则》第321条）
原话：**“在最高人民检察院核准追诉前，不得对苏某拘留和起诉”**
1. **不得起诉：这句话正确**
2. **不得拘留：这句话错误**
法条原文：须报请最高检核准追诉的案件，**核准之前侦查机关可以依法采取强制措施（拘留、逮捕、取保、监居都允许）**；**只有公诉权被冻结，强制措施不受限**。

## 一句话背诵口诀（左宁体系）
**核追诉：可强制，不停侦，不公诉。**

# 二、分两层讲清逻辑（故意杀人20年追诉期场景）
## 1. 起诉权严格锁死：没核准，绝对不能起诉
《高检刑诉规则》321条明确：**未经最高人民检察院核准，不得对案件提起公诉**。
- 公安侦查完移送检察院，检察院不能直接起诉；
- 必须层报最高检，拿到核准决定书后，才能向法院公诉；
- 最高检不核准：检察院直接作出不起诉，公安释放嫌疑人、撤销案件。

## 2. 强制措施完全放开：核准前可以拘留、逮捕
为什么允许先关人？
防止嫌疑人逃跑、毁灭证据，等最高检漫长核准周期结束后人跑掉，后续无法追责。
实操流程：
公安抓到苏某，确认杀人案已过20年追诉期→先刑事拘留/逮捕固定人身自由→同步层报检察院报请最高检核准追诉；核准期间持续侦查取证。

## 3. 你第二个疑问：过了追诉时效，原则上不再追诉
### 普通规则（刑法87、刑诉16条）
故意杀人最高刑死刑，追诉期20年；超过20年**原则不再追究**；一旦过时效，正常路径：撤案、不起诉、终止审理。

### 唯一例外突破：最高检核准追诉
只有同时满足4个条件，最高检才会核准继续追责：
1. 证据确凿，苏某实施杀人；
2. 罪名最高刑无期/死刑（故意杀人符合）；
3. 情节、后果特别严重、社会影响大，不追诉严重损害公平；
4. 嫌疑人到案配合调查。

### 两种结果
- 最高检**核准**：恢复完整追诉权，正常起诉、审判、判刑；
- 最高检**不予核准**：案件终结，立即释放苏某，不得再追责。

# 三、结合本题案例完整梳理
苏某故意杀人，案发超20年，已过追诉期限：
1. 公安抓获苏某 → **可以先行拘留**（强制措施合法）；
2. 公安继续侦查，移送同级检察院，层报最高检申请核准追诉；
3. 等待最高检答复期间，可继续关押苏某（逮捕也合法）；
4. 最高检未下核准文书前：**检察院绝对不能向法院公诉**；
5. 若最高检驳回核准：释放苏某，案件撤销，不再追究杀人刑责；
6. 若核准追诉：检察院依法提起公诉，法院正常审判定罪。

# 四、做题判断速记
❌ 错误表述：核准前不能拘留、不能起诉
✅ 正确表述：核准前可拘留（强制措施可用），**但绝对不能起诉**。
