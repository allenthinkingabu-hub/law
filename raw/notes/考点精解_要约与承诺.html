1是什么 / 易混先立定义，再钉死边界——客观题陷阱几乎全在"边界"上

是什么

要约

希望与他人订立合同的意思表示。两个要件：① 内容具体确定；② 表明经受要约人承诺，要约人即受约束。§472

承诺

受要约人同意要约的意思表示。原则以通知方式作出，到达要约人时生效。§479 · §484

要约生效 → 受要约人取得承诺资格 → 承诺生效＝合同成立（§483）
易混对照（五组高频陷阱）
要约内容具体确定 + 经承诺即受约束
vs
要约邀请希望他人向自己发要约（§473）
区分：是否满足要约两要件。法定要约邀请＝招标公告、招股说明书、债券募集办法、寄送的价目表、（一般）商业广告。陷阱：商业广告内容符合要约条件的＝要约；商品房销售广告中具体确定的说明、允诺，可视为要约。
撤回要约、承诺均可
vs
撤销仅限要约
区分：撤回＝在该意思表示生效前或同时到达（§475 / §485）；撤销＝在受要约人承诺前到达，且 §476 两种情形不可撤销。承诺不可撤销（一生效合同即成立）。
迟到承诺 · §486发出就晚 / 通常不能及时到达
vs
迟到承诺 · §487发出及时、通常能到，因其他原因迟到
§486＝新要约（要约人及时通知该承诺有效，才有效）；§487＝原则有效（要约人及时通知不接受，才失效）。口诀：怪受要约人→新要约；怪传递→有效
实质性变更→ 新要约（§488）
vs
非实质性变更→ 承诺有效（§489）
实质性＝标的、数量、质量、价款/报酬、履行期限/地点/方式、违约责任、争议解决方法。非实质性＝承诺有效、合同内容以承诺为准（除非要约人及时反对或要约禁止任何变更）。
合同成立事实判断：有没有合意
vs
合同生效法律评价：合意有无约束力
区分：承诺生效＝成立（§483）；依法成立即生效（§502），但附生效条件/期限（§158）、需经批准等情形例外——成立未必生效。
2怎么考、坑在哪命题角度 + 命题人最爱设的具体陷阱

命题角度

客观题（高频）：给场景判断某表示是要约还是要约邀请；判断合同是否成立 / 何时成立 / 何地成立；撤回撤销能否生效；承诺迟到或变更后的合同状态。
主观题（入口判断）：合同订立很少单独成大题，但常是大案例的第一环——先认定合同是否成立、何时成立，才能往下谈效力、履行、违约。所以它是主观案例的"入口"。

高频坑位
  • 把商业广告一律当要约邀请，漏掉"内容符合要约条件即构成要约"，尤其商品房销售广告中的具体允诺。
  • 混淆撤回 / 撤销的时间节点；误以为承诺也能撤销。
  • 迟到承诺不分 §486 / §487，一律按"新要约"或一律按"有效"。
  • 把非实质性变更误判为新要约（其实承诺有效、内容以承诺为准）。
  • 把"成立"与"生效"画等号——附生效条件的合同已成立但未生效；需批准的合同未批准则未生效，但报批义务条款独立有效。
  • 合同书成立时点：民法典为"签名、盖章或者按指印"任一即可（非旧法的签字＋盖章）；一方已履行主要义务且对方接受，亦成立（§490）。
  • 电子合同：网络发布的商品/服务信息符合要约条件的，对方提交订单成功时合同成立（不是付款时；另有约定除外，§491）。
3客观怎么答固定四步流程 + 关键词触发，把"判断"变成"反射"

四步流程

Step 1定性：这是要约还是要约邀请？抓两要件（具体确定＋受约束），再核是否属法定要约邀请、广告是否符合要约条件。
Step 2画时间轴：撤回 / 撤销 / 迟到——把各意思表示"到达"的先后排出来，默认到达主义。
Step 3判变更：承诺改了内容？实质性→新要约；非实质性→承诺有效、以承诺为准。
Step 4成立 / 生效两步走：先问成立（承诺生效没），再问生效（有无附条件、需批准）。两个问题分开答。
关键词触发表
价目表 / 招标公告 / 招股说明书→ 要约邀请
商品房销售广告里的具体说明、允诺→ 可视为要约
在承诺到达前 / 同时把要约撤回→ 撤回有效
承诺已作出，又想"撤销"→ 不行（承诺不可撤销）
发得及时、通常能到，因邮路延误迟到→ §487 原则有效
擅自改了价款 / 数量 / 履行方式→ 实质性变更＝新要约
合同附了"……时生效"的条件→ 已成立、未生效
4主观怎么答结论 + 大前提 + 涵摄，三者缺一不可——按点给分

答题结构

大案例里，第一步永远先答"合同是否成立、何时成立"，这是后续效力、履行、违约一切论证的前提。每一问都用「结论先行 → 援引法条（大前提）→ 事实涵摄（小前提）」展开。

入口判断 · 填空模板
甲发出的　行为　构成要约 / 要约邀请，因为　满足/不满足要约两要件　（《民法典》§472 / §473）。乙的回复构成承诺 / 新要约，理由是　一致 / 作出实质性变更　（§479 / §488）。依§483，承诺生效时合同成立，故合同于　某时点　成立。
〔如需区分生效〕合同虽已成立，但因　附生效条件 / 未经批准　，依§502 / §158，尚未生效。

两个得分关键

① 用法言法语、引准条号。主观题机考可查电子法条——把"背条文"降级为"会查会引"，但务必引对条号（如要约 §472、合同成立 §483、附条件 §158）。
② 踩点意识。阅卷按采分点给分：

采分点 ① 定性结论（要约/承诺/成立时点） 采分点 ② 法条依据 采分点 ③ 事实涵摄（把案情套进规则）

三者只写结论不引法条、或只抄法条不结合案情，都会丢分。宁可结构完整地写短，也别只下一个光秃秃的结论。

怎么用这张卡：四格结构（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）就是你处理每一个考点的固定模板。下一个考点（如合同效力、保全中的代位权/撤销权）照着这四格填，吃透速度会越来越快。
