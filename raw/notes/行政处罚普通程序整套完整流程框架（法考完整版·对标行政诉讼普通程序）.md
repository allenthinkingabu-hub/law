# 行政处罚普通程序整套完整流程框架（法考完整版·对标行政诉讼普通程序）

## 一、核心定性（对标之前考点）

1. **适用范围**：不适用当场简易程序的所有违法案件，是行政处罚**最完整、最严谨的兜底执法程序**，简易程序是它的简化版本。

2. **专属超级考点**
《行政处罚法》第 60 条规定：**普通程序法定办案总期限为立案之日起 90 日内作出处罚决定**，这是全行政法体系 \\*\\* 唯一允许部门规章另行细化、修改延期规则、扣除不计入期限（鉴定、听证、检验）\\*\\* 的程序；
除此之外，立案、调查、告知、法制审核、听证、决定、送达等所有步骤，均由法律锁定，规章无权改动。

3. **与行政诉讼的因果关联**：行政机关走完本套普通程序作出处罚决定书后，当事人不服，才会启动**行政诉讼一审普通程序**（司法审查）。

## 二、法定七大完整流程模块（法条原文拆解，顺序不可颠倒）

### 模块 1：案源核查与立案启动（《行政处罚法》第 54 条）

1. 行政机关通过投诉举报、巡查、上级交办、移送等获取违法线索，初步核查；

2. 符合违法构成要件、属于本机关管辖的，经负责人审批**正式立案**，制作立案审批文书；

3. 不予立案的，留存不予立案审批记录。

### 模块 2：双人调查取证（核心强制性环节，第 55、56 条）

1. **人数硬性要求**：必须**2 名以上持证执法人员**共同开展调查，单人调查属于程序重大违法；

2. 执法第一步：主动出示执法证件，当事人有权拒绝无证人员调查；

3. 取证方式：询问当事人、制作询问笔录、现场检查勘验、抽样取证；证据可能灭失的，经负责人批准**先行登记保存（7 日内必须作出处理）**；

4. 全程留痕，所有证据材料归入案卷。

### 模块 3：调查终结 \+ 法制审核（必考前置门槛，第 57、58 条）

1. 调查结束后，执法人员撰写案件调查终结报告，提交行政机关负责人审查；

2. **强制法制审核（必经）**
四类案件必须经过专职法制人员审核，**未经法制审核不得作出处罚决定**：
① 涉及重大公共利益；② 直接关系当事人重大权益（大额罚款、吊销证照、责令停产停业、行政拘留）；③ 案情复杂、涉多方法律关系；④ 法律法规规定应当审核的情形；

3. 审核发现证据不足、程序瑕疵、适用法律错误的，退回补充调查。

### 模块 4：事先告知 \+ 陈述申辩（绝对不能省略，第 44、45 条）

1. 作出处罚决定**之前**，书面告知当事人三大内容：
① 查实的违法事实；② 处罚对应的法律依据；③ 拟作出的具体处罚种类与幅度；

2. 同时告知法定权利：**陈述权、申辩权**；

3. 核心规则：行政机关必须复核当事人提出的事实与证据，理由成立应当采纳；**不得因当事人申辩加重处罚**（禁止不利变更）；

4. 程序红线：未履行告知义务、拒绝听取陈述申辩的，**行政处罚决定直接不成立**，可在行政诉讼中被法院判决撤销。

### 模块 5：听证程序（普通程序内嵌可选分支，第 63 条）

#### 1\. 应当告知听证的三类处罚（当事人可申请启动听证）

① 较大数额罚款；② 吊销许可证件、降低资质等级；③ 责令停产停业、责令关闭、限制从业。

#### 2\. 听证规则

- 当事人收到告知书**5 日内**书面申请听证；

- 听证由行政机关非本案调查人员主持，听证笔录作为作出处罚的参考依据；

- **听证不计入 90 日办案期限**（也是规章可细化扣除期限的内容）。

### 模块 6：负责人审查、集体讨论、作出最终处罚决定（第 57 条）

负责人根据调查、法制审核、申辩复核、听证结果，分 4 种法定结论：

1. 违法事实成立→作出正式行政处罚决定；

2. 违法轻微、可不予处罚→决定不予行政处罚；

3. 违法事实查不清、证据不足→不予行政处罚；

4. 涉嫌刑事犯罪→直接移送公安、司法机关追究刑事责任。

补充考点：**重大、复杂案件，必须负责人集体讨论决定**，不能由单个负责人拍板。

### 模块 7：处罚决定书送达 \+ 履行执行 \+ 救济指引（第 61、67 条）

1. **送达时限**：决定书当场宣告当场交付；当事人不在场的，**7 日内**参照民事诉讼送达规则邮寄 / 留置送达；电子送达需当事人确认同意；

2. 决定书法定必备内容：当事人信息、违法事实、法律依据、处罚内容、履行方式期限、**6 个月行政复议期限、6 个月行政诉讼起诉期限**；

3. 当事人按期履行；逾期不履行的，行政机关可加处罚款、拍卖财物、申请法院强制执行；

4. 当事人不服：两条救济路径：先复议、或直接提起**行政诉讼**（闭环衔接）。

## 三、大白话通俗拆解（三段式）

### 第一段：本质是什么

行政处罚普通程序 = **行政机关自己查办违法行为的全套内部执法流程**，属于**行政程序**；
行政诉讼普通程序 = **法院审查这份处罚是否合法的司法审判流程**，属于**司法诉讼程序**。一先一后，执法在前、司法监督在后。

### 第二段：唯一权限特例再强调

整套执法流程里，只有**90 天总办案期限**法律放开了口子，部委规章可以自己定行业多久结案、哪些时间不算在内；
立案、双人取证、法制审核、告知申辩、听证、送达这些步骤，规章一丁点都不能修改。

### 第三段：和行政诉讼最核心的区分

1. 行政处罚普通程序：主体是政府部门，适用《行政处罚法》，90 日办案期限规章可微调；

2. 行政诉讼一审普通程序：主体是法院，适用《行政诉讼法》，审理组织、审限、裁判类型全部法律锁死，规章完全无权触碰。
