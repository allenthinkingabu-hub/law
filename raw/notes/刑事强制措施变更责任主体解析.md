# 刑事强制措施变更责任主体解析

### 核心结论

强制措施的**采取、变更、解除**全程遵循「**谁办案、谁决定；一律公安执行**」的规则；拘留、逮捕的发起 / 审批主体不同，变更与解除权限也随办案阶段同步转移。其中刑事拘留的决定权限仅限公安与检察院，法院无刑事拘留决定权。

## 一、先分清：决定机关 vs 执行机关（基础考点）

1. **决定机关**：公安、检察院、法院，在各自办案阶段，都有权决定采取、变更、解除刑事强制措施

    - 刑事拘留决定权限：公安可对普通刑事案件自主决定；检察院仅对自身立案侦查的案件享有决定权；法院无刑事拘留决定权

    - 补充区分：司法拘留（妨害诉讼的惩戒措施）不属于刑事强制措施，仅法院有权作出，与刑事拘留性质完全不同

2. **执行机关**：刑事拘留、逮捕、取保候审、监视居住的实际执行（送看守所、放人、管控、解除手续落地），**一律由公安机关负责**

    - 例：法院决定逮捕 → 交公安执行送看守所；法院判缓刑当庭释放 → 公安办释放手续；检察院解除取保候审 → 公安出具解除文书、退还保证金；检察院决定刑事拘留 → 交公安送看守所羁押

## 二、分阶段的变更负责机关

### 1\. 侦查阶段（公安主办 / 检察院自侦案件自行主办）

- 拘留：普通刑事案件公安自主决定、自主执行，要变更 / 解除也由公安直接决定；检察院自侦的司法工作人员渎职案件，检察院可决定刑事拘留，交公安执行，变更、解除也由检察院自主决定

- 逮捕：公安侦查案件由公安提请、检察院审批批捕、公安执行；**公安后续要变更 / 释放 / 解除逮捕的，可自主决定，只需通知原批捕的检察院备案**，无需再经检察院批准

- 检察院可主动启动羁押必要性审查，建议公安变更，但最终变更、解除决定权仍在对应办案机关

### 2\. 审查起诉阶段（检察院主办）

- 案件移送检察院后，强制措施的采取、变更、解除（逮捕改取保、取保改监居、到期解除、补充决定拘留等）**统一由承办案件的捕诉部门决定**

- 所有强制措施的释放、执行、解除落地手续仍交公安办理

### 3\. 审判阶段（法院主办）

- 案件起诉到法院后，刑事强制措施的变更、解除由法院自主决定；法院无刑事拘留决定权，审判阶段需羁押被告人的直接作出逮捕决定

- 对应「一审分流」规则：判缓刑 / 无罪 / 免刑的释放、解除，都由法院作出决定，交公安执行

- 补充：法院对妨害诉讼的行为可作出司法拘留（非刑事强制措施），由法院司法警察执行

## 三、对应四条口诀的责任主体

- 发现不当就改（§96）：办案机关自己发现自己改，公检法都有纠错权

- 办案超期就放（§98）：哪个阶段超期，由该阶段的办案机关负责释放 / 变更

- 措施期满就解（§99）：哪个阶段办理的强制措施，到期由该机关决定解除

- 一审宣判分流：法院决定，公安执行

## 四、高频易错点

1. 逮捕的审批权 ≠ 变更 / 解除权：批捕归检察院，但侦查阶段公安要变更、解除逮捕，不用再找检察院批，只通知即可

2. 羁押必要性审查是检察院的监督程序，不是办案机关的正常变更、解除程序，二者不冲突

3. 法院可以直接决定逮捕被告人，不需要检察院批捕，但必须交公安执行；解除、释放同理，法院决定、公安执行

4. 法院无刑事拘留决定权，审判阶段需羁押直接适用逮捕；司法拘留属于妨害诉讼惩戒措施，不属于刑事强制措施，二者不得混淆

5. 检察院仅对自侦案件享有刑事拘留决定权，普通刑事案件刑事拘留由公安决定；所有刑事拘留的执行机关均为公安机关
