# 完整刑事案件全分类（2026法考，分「普通公诉大类」「法院自诉」「监察职务犯罪」「检自侦」「刑诉五大特别程序」「特殊管辖专门案件」六大板块，仅名称\+极简简介）

## 一、你已掌握四类基础追诉案件（侦查主体划分）

1. **普通公安机关侦查刑事案件**
简介：公安管辖绝大多数普通刑事犯罪（盗窃、诈骗、故意伤害、涉黑、毒品、交通肇事等），公安侦查→检起诉→法院审判完整公诉流程。

2. **监委管辖职务犯罪案件**
简介：公职人员贪污贿赂、滥用职权、玩忽职守等职务违法犯罪，监委调查移送检察院，适用留置、退回补充调查、不起诉上级复核专属规则。

3. **检察院自侦案件（司法工作人员职权犯罪）**
简介：诉讼监督中司法人员刑讯逼供、徇私枉法、非法搜查等 14 类罪名，检察院直接立案侦查，内部审查起诉。

4. **法院直接受理自诉案件**
简介：被害人自行起诉，分告诉才处理、轻微刑事案件、公诉转自诉三类，可调解、和解、反诉。

## 二、《刑诉法》法定五大特别程序案件（独立特殊流程，不属于上面四类基础案件）

1. **未成年人刑事案件诉讼程序**
简介：嫌疑人 / 被告人案发时未满 18 周岁，贯彻教育为主惩罚为辅，附社会调查、合适成年人、附条件不起诉、犯罪记录封存特有规则。

2. **当事人和解的公诉案件程序**
简介：民间纠纷侵犯人身财产 3 年以下、除渎职外 7 年以下过失犯罪，双方达成和解可从宽、不起诉，自诉不适用该特别程序。

3. **缺席审判程序案件**
简介：贪污贿赂、国安恐怖犯罪被告人境外潜逃，或被告人重病无法出庭、死亡（无罪再审），法院不到庭开庭审判，中院专属一审。

4. **逃匿 / 死亡人员违法所得没收程序**
简介：重大贪腐、恐怖犯罪嫌疑人通缉 1 年不到案或已死亡，单独向法院申请查封没收涉案赃款，不审人身刑事责任。

5. **依法不负刑责精神病人强制医疗程序**
简介：实施暴力危害公共 / 人身安全、鉴定完全无刑事责任能力，法院决定强制收治，属于保安处分非刑罚程序。

## 三、其他特殊专门管辖 / 细分案件（法考单独命题）

1. **单位犯罪案件**
简介：公司、企业实施犯罪，程序增设诉讼代表人出庭、查封单位财产、双罚制审理规则，依附公诉 / 自诉框架但有特殊庭审流程。

2. **涉外刑事案件**
简介：外国人犯罪、中国人境外针对我国 / 公民犯罪、国际条约管辖案件，适用涉外送达、限制出境、司法协助、翻译配套规则。

3. **国家安全机关侦查案件**
简介：危害国家安全、间谍类犯罪，国安行使等同公安侦查权，独立侦查移送检察院起诉。

4. **军队 / 军事司法互涉刑事案件**
简介：军人犯罪、军营内犯罪、军民共同犯罪，由军事检察院、军事法院专属管辖审理。

5. **死刑复核案件**
简介：一审判死刑立即执行，高院复核后报请最高法核准，独立复核程序，不属于一二审普通审判。

6. **法定刑以下量刑核准案件**
简介：一审判处低于法定最低刑，无减轻处罚情节，必须层报最高人民法院核准。

7. **认罪认罚案件（贯穿全流程细分类型）**
简介：所有公诉案件均可适用，签署具结书、速裁程序、量刑建议刚性采纳规则，可叠加普通公诉、监察、检自侦、未成年人案件。
