# 行政法附带审查：条件、流程与法考要点

# 一、一句话大白话定义（先吃透 “附带” 两个字）

**附带审查（一并审查）**：
你不能直接去法院起诉一份红头文件；只能在起诉**罚款、不予许可、查封、批复**这类**具体行政行为**的时候，顺带请求法院看一看：行政机关拿来处罚你的那份红头文件（规章以下规范性文件）合不合法。
关键词：**依附于具体行为、搭顺风车、不能单独告文件**。

举最简单例子：
区城管局依据《城区占道经营整治通知》罚你 600 元。

1. ❌ 错误：直接起诉 “撤销这份《整治通知》”→ 法院不受理

2. ✅ 正确：起诉 600 元罚款，同时申请法院**附带审查这份《整治通知》合法性**→ 合法启动附带审查

# 二、四大硬性启动条件（缺一不可，法考必背）

## 条件 1：依附性（核心：必须先有可诉的具体行政行为）

抽象文件本身不可诉，只有文件实实在在用到你身上、作出了对你有约束力的行政行为，才能顺带审文件。

## 条件 2：关联性

申请审查的文件，**必须就是本次行政行为直接依据**的那一份。无关的文件不能申请。

## 条件 3：审查对象严格划定（最容易挖坑）

### ✅ 可以附带审查：规章以下的其他规范性文件（俗称红头文件）

发文主体包含：

1. 国务院各部委发的**非规章类通知、意见、方案**；

2. 国务院直属机构（市监总局、税务总局）发的普通通知；

3. **部委管理的国家局全部文件**（国家药监局、国家数据局、民航局、铁路局，它们无权立规章，所有发文都是红头）；

4. 省、市、区县、乡镇政府及所有下属局办的通告、规定、临时文件；

5. 联合发文的多部门红头文件。

### ❌ 绝对不能附带审查（申请也没用）

1. 国务院**行政法规**；

2. **部门规章**（部委、海关总署、证监会、税务总局以 “令” 发布的规章）；

3. **地方政府规章**（省政府、设区市政府市长 / 省长令发布的规章）；

4. **国务院自己制定的规范性文件**（最高层级特殊排除）。

极简判断口诀：**看见 “条例、XX 令、总局令、省长市长签署令”= 立法文件，一律不审；通知 / 通告 / 暂行办法 / 指导意见 = 红头，可以审**。

## 条件 4：申请时间卡死（时效考点）

1. 原则：**一审开庭审理之前**书面提出；

2. 例外：有正当理由（开庭才第一次见到这份文件），最晚**一审法庭调查阶段**提出；

3. 绝对禁止：**二审上诉阶段、再审阶段，不能新增附带审查请求**，过期彻底丧失权利。

# 三、法院怎么审查、审查出不合法怎么处理（超级高频坑点）

## 1\. 审查哪几个维度（只审合法性，不审合理性）

1. 发文机关有没有权限（比如乡镇政府无权设定罚款）；

2. 文件制定程序是否违法；

3. 内容有没有抵触法律、行政法规、规章等上位法；

4. 是否凭空给老百姓增加义务、减损权利。

## 2\. 两种结果法定处理规则（重中之重）

### 结果 A：红头文件合法

法院认可这份文件作为执法依据，维持行政机关的处罚 / 许可决定。

### 结果 B：红头文件被认定不合法（考生 90% 踩坑在这里）

**法院没有权力撤销、废止、宣告这份红头文件无效**（司法不能直接废掉行政机关的文件），只能做三件事：

1. **本案不予适用**：本次判决不拿这份违法文件当依据，直接撤销对应的罚款、不予许可等行政行为；

2. 在判决书说理部分写明该文件违法；

3. 向发文机关发送**司法建议书**，建议对方修改或者废止该文件，同时抄送同级政府、上级主管机关、监察机关。

人话总结：**只管这一个案子不用它，管不了文件继续在全社会生效**。

# 四、法考完整出题角度 \+ 考频分析

## 1\. 考频星级：★★★★★ 行政法客观题每年必考 1 道（1\-2 分），主观题 2\-3 年考一次

### 客观题三大固定挖坑套路

1. **审查范围混淆**
错误选项：可以申请法院审查证监会出台的部门规章 → 错，规章不审；
正确：国家药监局发布的药店管理通知可以附带审查。

2. **法院权限陷阱**
错误选项：法院判决撤销违法的规范性文件 → 错，只能不予适用 \+ 发司法建议，不能撤销文件。

3. **申请时间陷阱**
错误：一审没提，二审上诉时申请附带审查 → 错，二审不许新增。

### 主观题设问模板（直接背踩分点）

设问：原告能否请求法院审查 XX 文件？法院审查后如何处置？
答题模板：
① 案涉文件属于规章以下规范性文件，可以在起诉具体行政行为时一并申请附带审查；
② 若法院认定文件不合法，不得作为被诉行政行为的合法依据，在裁判理由中予以阐明，并向制定机关发送司法建议书，建议修改或废止，法院无权直接撤销该规范性文件。

## 2\. 关联易混对比（复议附带审查 VS 诉讼附带审查）

两者审查范围、不能审查的文件完全一致，唯一区别：复议可以一并审查**国务院的规范性文件**，行政诉讼不行。

# 五、终极浓缩背诵口诀

1. 红头不能单独告，依附具体行为搭车瞧；

2. 法规规章全排除，只审下级普通通告；

3. 一审开庭前书面递，二审再审不许要；

4. 违法本案不适用，司法建议递上交，法院无权撤文件。
