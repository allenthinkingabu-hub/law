# ✅核心结论（2026法考必背｜《民法典》1245）

普通饲养动物（1245，无过错责任）的法定免责 / 减责理由只有一种：**证明损害是受害人故意或重大过失导致**，不是证明自己无过错。

> 对比区分：过错推定责任（1253 脱落坠落）—— 被告证明自己无过错，就可以免责；
> 无过错责任（1245 普通宠物伤人）—— 哪怕主人全程合规、拴绳、尽到全部看管义务（自己无过错），只要不是受害人故意 / 重大过失，主人依然要赔钱。

## 📖举例

张三养金毛，出门严格拴绳、戴好嘴套（张三完全无过错）。路人李四正常走路，金毛突然挣脱咬伤李四。

1. 张三就算拿出全部证据证明自己规范养狗、没有过错；

2. 李四没有逗狗、没有主动挑衅；

3. → **张三依旧要全额赔偿，不能免责**

## ✅什么时候才能免 / 减责？

只有拿出证据证明：**受害人故意挑逗、殴打狗狗（免责），或者受害人重大过失逗弄（减轻责任，过失相抵）**
例子：张三金毛拴在院内，李四翻墙进院子踢狗被咬 → 李四故意，张三可免责。
