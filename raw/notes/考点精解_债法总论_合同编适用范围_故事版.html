债法总论 / 合同编适用范围 整个债法的"地图" — 一个故事讲到底 + 大白话（框架性·低频）

定位：民法 › 合同编 › 通则 › 一般规定（§463–468，框架章，非"合同总则"操作性考点的同级）
贯穿全卡的故事

"债"听着玄，其实就是"谁该给谁点什么"——欠钱、欠货、欠个赔偿，都是债。老王和小李之间能生出债的方式有好几种：签了合同、撞坏了对方的车、帮对方垫了钱、多收了对方的钱。问题来了：民法典里没有专门的"债法总则"那一编，这些"非合同的债"该照哪套规则走？答案是——回到合同编通则。

这一格讲两件事：合同编的"门朝哪儿开"（适用范围），以及它怎么管到所有的债。一句话：民法典没单设债法总则，合同编通则兼任了这个职——它是整个债法的"总开关 / 地图说明"。本身考得少，但它定方位。

1是什么 / 易混先认"债是什么、从哪来"，再搞清合同编通则管多宽

是什么（债 + 它的"总则"在哪）

用故事说
债 = 一个人（债权人）有权要另一个人（债务人）做点什么（给钱、交货、出力、赔偿…）。它怎么来的？四个主要来源：合同、侵权、无因管理、不当得利。
它的"总则"在哪：民法典没单设"债编 / 债法总则"，所以债的共通规则（怎么履行、怎么保全、怎么转让、怎么消灭）都塞进了合同编通则。
大白话"债"就是"谁该给谁点啥"；民法典没单独的债法总则，共通规则统统塞进合同编通则——这一章就是它的"使用说明 + 门牌"。
易混对照 · 五组要分清
合同之债双方说好的
vs
非合同之债不是约定来的（另外三种）
用故事说（债的四大来源，一个故事四个版本）
合同：老王卖车给小李，小李欠车款 → 合同之债。
侵权：老王骑车撞坏小李的车 → 老王欠赔偿 ＝ 侵权之债。
无因管理：小李出差，老王没义务却帮他喂猫、垫了猫粮钱 → 小李欠这笔费用 ＝ 无因管理之债。
不当得利：小李转账手滑多转老王 1000 → 老王欠这 1000 ＝ 不当得利之债。
大白话说好的＝合同之债；没说好、因别的事冒出来的（撞了 / 帮了 / 多拿了）＝非合同之债。
这四个是"债的发生原因"，常作为案例里"债从哪来"的起点。其中无因管理（帮了、有为他人之意）和不当得利（多拿了、没合法根据）最容易混。
有专门规定照它自己那套
vs
没专门规定参照合同编通则（§468）
用故事说
老王撞坏车欠小李的赔偿之债，"怎么履行、能不能抵销"——侵权责任编没细说的，就回合同编通则借规则用。
大白话非合同的债，先找它自己那套（侵权找侵权编、无因/不当找准合同两章）；找不到、且性质不冲突，就回合同编通则借。
特别规定优先，通则兜底（性质排斥的除外）
有名合同法典点过名、有专章
vs
无名合同法律没专门规定的新型合同
用故事说
老王小李签的"二手车买卖"是有名合同（买卖有专章）；若两人签个法律没专门规定的新型合作约定 → 无名合同，适用合同编通则 + 参照最相类似的有名合同规则。
大白话法典点过名的合同，有专门章节；没点名的"新合同"，用通则 + 比着最像的那种有名合同来办。
对应：§467。别把无名合同当"无法可依"。
合同相对性原则上只约束签字的两人
vs
法定例外少数情形及于第三人
用故事说
老王和小李的买卖合同，只约束老王和小李；隔壁老张既不享有合同权利、也不担合同义务。例外：法律明文规定的情形（如代位权 / 撤销权及于第三人、买卖不破租赁等）。
大白话合同是"俩人之间的事"，原则上外人不沾；只有法律明文规定的少数情形才管到第三人。
对应：§465。合同相对性也是区分"债权（对人）vs 物权（对世）"的关键。
财产性合同合同编直接管
vs
身份关系协议身份法优先，通则只"参照"
用故事说
老王小李的买卖合同 → 直接用合同编。但两人若涉及结婚、收养、监护这类协议 → 先走婚姻家庭编 / 收养等身份法，合同编只在没规定时"根据性质参照"。
大白话买卖这种纯财产合同，合同编直接管；结婚收养这类"身份"协议，先用身份法，合同编只能"参照着用"。
对应：§464 第二款。
2怎么考、坑在哪低频框架考点 + 偶尔点状出现的雷

题目长什么样（先说实话）

命题角度 + 诚实定位
定位：这是框架性、低频考点。它的价值在"看懂债法地图"，不必当重点猛背——把"四大债因 + §468 这个接口 + 合同相对性"记牢就够。
客观题（低频、点状）：给个情形问"产生的是哪种债"、"非合同之债能否参照通则"、"无名合同怎么适用"、"合同管不管第三人"。
主观题：几乎不单独成题，但它是案例的前置定性——先认出"这是什么债、从哪来"，才好往下套规则。
坑位
  • 以为民法典有独立"债法总则"——没有，是合同编通则兼任。
  • 把非合同之债一律往合同编通则套——要先找它自己的专门规定，通则只是"兜底"且性质排斥的除外。
  • 把无名合同当"无法可依"——适用合同编通则 + 参照最相类似的有名合同。
  • 忽视合同相对性的法定例外（代位权 / 撤销权、买卖不破租赁等）。
  • 身份关系协议直接套合同编——应身份法优先，合同编只"根据性质参照"。
  • 混淆债的发生原因，尤其无因管理（帮了、有为他人意思）vs 不当得利（多拿了、无合法根据）。
3客观怎么答先认"债从哪来"，再决定照哪套规则

固定四步

第 1 步认债从哪来：约定的（合同）？还是撞了（侵权）/ 帮了（无因管理）/ 多拿了（不当得利）？
第 2 步找它自己的规则：合同→合同编；侵权→侵权责任编；无因 / 不当→准合同那两章。
第 3 步没专门规则时：该债的共通问题参照合同编通则（§468），但性质排斥的除外。
第 4 步特殊判断：无名合同→通则 + 参照最相类似；身份协议→身份法优先、通则参照；管不管第三人→记住合同相对性（及法定例外）。
关键词触发表（看到左边，先想右边）
"双方约定 / 签了协议"→ 合同之债
"造成损害 / 侵害他人权益"→ 侵权之债
"没义务、为他人管理事务"→ 无因管理之债
"没有合法根据获得利益、致他人损失"→ 不当得利之债
"法律没专门规定的新型合同"→ 无名合同（通则 + 参照最相类似）
"非合同之债怎么履行 / 抵销 / 转让没规定"→ 参照合同编通则（§468）
"结婚 / 收养 / 监护协议"→ 身份法优先，通则按性质参照
"合同管不管第三人"→ 原则相对性，仅法定例外及于第三人
4主观怎么答这块极少单独考，但它给案例"定性入口"

怎么下笔

这一块几乎不单独成题，但它提供大案例的"定性入口"——先认出债的种类和来源，后面才好套规则。每步"先给结论 → 搬出法条 → 套到案情里"。

套用故事的填空模板
本案中，某人与某人之间的关系，系因合同 / 侵权 / 无因管理 / 不当得利产生的债，应适用相应编 / 条。
〔非合同之债、共通问题且无专门规定时〕依《民法典》第 468 条，参照适用合同编通则的相关规定。
〔无名合同〕该合同属法律未明文规定的合同，依第 467 条，适用合同编通则并参照最相类似合同的规定。

两个得分关键

① 先把"哪种债、从哪来"这个定性写准。定性错，后面适用的法律全错。
② 适用顺序写清楚。"专门规定优先 → 没有则参照合同编通则（§468）"，别一上来就套通则。

给分点 ① 债的定性（哪种债、从哪来） 给分点 ② 适用的法律（专门规定优先；§468 / 467 的参照） 给分点 ③ 套案情

怎么用这张卡：四格（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）是处理每一个考点的固定套路。这张是"地图型"框架卡——它的作用是把其余债法考点（履行、保全、移转、消灭、各类典型合同、无因管理、不当得利）挂在一张图上，理解定位即可，不必当重点考点猛攻。
