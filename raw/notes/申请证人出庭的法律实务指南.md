# 申请证人出庭的法律实务指南

# 一、什么叫 “申请证人出庭”

公诉人、辩护人、被害人代理人**书面主动向法院提交材料**，请求法庭传唤某证人到庭当庭作证，这个行为就是**申请**。
对应规则：谁申请，谁先发问。

# 二、什么时候申请（法定时间节点）

1. **最优、常规时间**：庭前会议 / 举证期限届满前（开庭十日之前）提交书面申请书

2. 次选：开庭前 3 日之前提交，给法院时间送达证人出庭通知书

3. 例外：庭审中新发现关键证人，可当庭临时申请，但法官有权驳回或延期开庭

4. 法院依职权通知证人：**不需要任何人申请**，法官主动决定传唤证人，适用 “法官先发问” 特殊顺序

# 三、实务举例（两类场景对比，区分申请 / 法院依职权）

## 例 1：辩护人申请证人（适用：谁申请谁先发问）

甲涉嫌故意伤害，阅卷发现现场路人王某笔录说双方互相推搡，能证明被害人有过错、甲属防卫。
开庭前 7 天，辩护人向法院提交《证人出庭申请书》，列明王某身份、住址、证明内容。
法院审核同意，通知王某到庭。
庭审发问顺序：**辩护人先问王某，再由公诉人交叉发问**。

## 例 2：检察院（公诉人）申请证人

盗窃案，公诉人对被告人有利的邻居证言有异议，认为证言虚假。
开庭前书面申请该邻居出庭，法院准许。
庭审发问顺序：**公诉人先发问，后辩护人发问**。

## 例 3：法院依职权通知证人（无任何人申请，考点 D 项错误情形）

抢劫案，两份目击证人笔录完全矛盾，控辩双方都没申请证人出庭。
合议庭为查清事实，**主动依职权传唤目击证人到庭**，没有任何一方提交申请。
庭审发问顺序：**法官先发问，问完再轮公诉人、辩护人**，不适用公诉人优先发问。

# 四、法条依据

《刑诉解释》第 251 条：为查明案件事实、调查核实证据，人民法院可以依职权通知证人出庭
《刑诉解释》第 263 条：审判人员可以向证人发问；控辩双方申请证人出庭，由提请方先行询问。
