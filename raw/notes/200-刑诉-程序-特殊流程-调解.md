# 刑事调解自诉案件分析

## 第一步：知识点释义 \+ 2026 法考做题实操

### 核心要点
公权案件一律禁止法院调解结案，防止私权废掉国家追诉权。

刑事调解指法院居中主持自诉案件双方协商结案，**仅两类自诉可调解，公诉案件刑事部分一律禁止调解**；

1. 可调解自诉：①告诉才处理；②轻微刑事案件；

2. 绝对不可调解：公诉转自诉（刑诉 210 条第 3 项）；

3. 效力规则：签收调解书即终结案件，反悔未签收须判决\( 案子彻底结案、彻底结束，法院不再审理、不再判决、不能再反悔、不能再上诉\)； 二审自诉仍可调解，调解书生效一审裁判自动撤销；

4. 区分边界：公诉仅有**和解**（仅从轻量刑、不能结案）；附带民诉全部可调解；调解≠自行和解≠撤诉。

### 做题四步判断

1. 分案件类型：公诉刑事实体直接排除调解；

2. 区分三类自诉：看到 “公检不追究书面文书” 即公诉转自诉，不得调解；

3. 区分调解与和解：法院居中主持 = 调解；当事人私下协商 = 和解；

4. 看效力：调解能彻底终结刑事程序；公诉和解仅作为从宽情节。
命题陷阱：公诉案件刑事部分调解、公诉转自诉允许调解、和解等同于调解、未签收调解书案件终结。
