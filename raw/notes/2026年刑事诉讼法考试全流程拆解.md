# 2026年刑事诉讼法考试全流程拆解

以下拆解严格依据现行《刑事诉讼法》（2018修正版）、《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》（2021版）、《人民检察院刑事诉讼规则》（2019版）及《人民检察院 公安机关羁押必要性审查、评估工作规定》（2023年印发），覆盖公诉案件完整正常流程与高频异常分支，所有节点均为法考客观题核心考点，完全适配 2026 年考试体系。

整体主线：**立案 → 侦查 → 审查起诉 → 一审 → 二审 → 执行**，外加**特别程序**。四大核心模块（强制措施、刑事证据、认罪认罚、审判程序）按功能嵌入对应阶段节点。

---

## 一、立案阶段

### 正常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|案件受理|公安/检察院/国家安全机关/监狱等侦查机关（注：监察委适用监察法，在此非刑诉主体，但存在程序衔接）|有报案、控告、举报、自首等材料|属于本机关管辖范围|接收材料、登记备案、初步核查|完成材料初步核实|转入立案审查|
|立案审查|公安/检察院/国家安全机关/监狱等侦查机关|已受理案件|有犯罪事实嫌疑|审查是否符合立案标准|得出是否立案的结论|立案 / 不予立案|
|作出立案决定|公安/检察院/国家安全机关/监狱等侦查机关|审查完毕|有犯罪事实、需要追究刑事责任、属本机关管辖|制作立案决定书、启动侦查|立案决定书生效|进入侦查阶段|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|不予立案决定|公安 / 检察院|审查完毕|无犯罪事实、情节显著轻微不追责、不属本机关管辖|制作不予立案通知书，在 **7日内** 送达控告人|不予立案决定书生效|控告人复议 / 检察院立案监督|

## 二、侦查阶段（强制措施、刑事证据核心落地阶段）

### 正常流程节点

#### 1. 人身控制类（对应「强制措施」模块）

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|拘传|公 / 检 / 法各自决定并**自行执行**（注：检察院、法院由其司法警察执行，非公安统一执行）|犯罪嫌疑人未被羁押|需要强制到案接受讯问|出示拘传证，单次不超 12 小时，案情重大不超 24 小时；两次拘传间隔时间不得少于 12 小时；严禁变相拘禁|讯问完毕|释放 / 变更其他强制措施|
|取保候审|公 / 检 / 法决定，**公安机关执行**|犯罪嫌疑人未被羁押 / 已羁押需变更|可能判处管制拘役、有期以上无社会危险、羁押期满、重病怀孕|责令提供保证人**或者**交纳保证金（**二者只能选其一，不能并用**），告知义务，期限 12 个月|手续办理完毕|继续侦查 / 移送审查起诉|
|监视居住|公 / 检 / 法决定，**公安机关执行**|符合逮捕条件或取保条件但无保证能力|重病、怀孕、唯一扶养人、羁押期满、特殊案件需要|1. 应当在住处执行；无固定住处的，可在指定居所执行。<br>2. 涉嫌国安、恐怖犯罪在住处执行有碍侦查，经上一级公安/检察院批准，可在指定居所执行（**指定居所监视居住 24小时内通知家属**；折抵刑期：管制一日折抵一日，拘役/有期二日折抵一日）。期限 6 个月|手续办理完毕|继续侦查 / 移送审查起诉|
|刑事拘留|公安/检察院决定，**公安机关执行**|发现现行犯 / 重大嫌疑分子|具备 7 种法定紧急情形（现行犯、毁证、串供等）|1. 公安拘留期限：一般 3 日，特殊可延长 1-4 日，重大“三类人”（流窜、多次、结伙）可延长至 30 日。<br>2. 检察院自侦案件拘留期限：10 日，特殊可延长 1-4 日。<br>3. 24 小时内送看守所、讯问、通知家属（**仅限涉嫌国安、恐怖犯罪且有碍侦查时，可不通知家属**）。|拘留执行完毕|提请批准逮捕 / 释放 / 变更强制措施|
|逮捕执行|检察院批准/决定，或法院决定；**公安机关执行**|公安提请批捕/检察自侦决定/法院因审判决定|有证据证明有犯罪事实、可能判处徒刑以上、有社会危险性|1. 检察院应在收到提请批捕书后 **7日内** 作出决定。<br>2. 逮捕后 **24小时内** 必须进行讯问、通知家属（**逮捕没有任何“有碍侦查”不通知的例外，唯一例外为无法通知**）。|作出逮捕决定并执行完毕|继续侦查羁押 / 移送审查起诉|
|侦查羁押期限|侦查机关|逮捕之后|符合法定延期条件|1. 基础期限：**2个月**。<br>2. 一级延期：案情复杂经上一级检察院批准延长 **1个月**（共3个月）。<br>3. 二级延期：符合四类重大复杂案件（交通、边远、重大集团、过失）由省级检察院批准延长 **2个月**（共5个月）。<br>4. 三级延期：可能判处10年以上有期徒刑的，省级检察院可再批准延长 **2个月**（共7个月）。<br>5. 发现新罪重新计算，身份不明自查清之日起算。|侦查终结或期限届满|移送审查起诉 / 变更强制措施 / 释放|

#### 2. 取证与侦查类（对应「刑事证据」模块・收集环节）

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|讯问犯罪嫌疑人|侦查人员（不得少于2人）|已立案，嫌疑人到案|需核实案情、固定供述|1. 被拘留、逮捕的嫌疑人**应当在看守所内进行**。<br>2. 录音录像：可能判处无期、死刑或其他重大案件**应当**全程录音录像，其他案件**可以**录音录像。|讯问笔录制作完毕|继续其他侦查行为|
|询问证人 / 被害人|侦查人员（不得少于2人）|已立案，需收集言词证据|证人具备作证能力|1. 可以在现场进行，或到其单位、住处、**证人/被害人提出的地点进行**（不得由办案机关单方指定地点）。<br>2. 必要时可以通知其到公安机关/检察院提供证言。<br>3. **必须个别进行**。|询问笔录制作完毕|继续其他侦查行为|
|勘验检查 / 搜查 / 查封扣押|侦查人员|已立案，需收集实物证据|有侦查必要，持相关文书|1. 搜查须持搜查证，但执行逮捕/拘留时遇紧急情况可**无证搜查**。<br>2. 检查：嫌疑人拒绝检查的可以**强制检查**；**强制检查仅适用于嫌疑人，绝对不适用于被害人/证人**。<br>3. 扣押：与案件无关的财物，必须在 **3日内** 解除扣押退还原主。|证据固定完毕|继续其他侦查行为|
|技术侦查|公安/国家安全机关决定并执行；检察院决定并交由有关机关执行|已立案|危害国安、恐怖、毒品、重大贪污等法定重罪|严格审批，有效期 3 个月，可延长，每次延长不超过 3 个月；收集的材料**可以直接作为证据使用**，如危及安全等应采取保护措施或由审判人员庭外核实（**无需转化**）。|侦查措施执行完毕|继续侦查 / 侦查终结|
|辨认|侦查人员（不得少于2人）主持|已立案，需核实对象|有辨认必要|1. 混杂辨认：辨认人应分别进行，防止暗示。<br>2. 辨认犯罪嫌疑人：公安侦查案件被辨认人数不得少于 **7人**，检察院自侦案件不得少于 **10人**，照片均不得少于 **10张**。<br>3. 辨认物品/照片：均不得少于 **5件/张**。|辨认笔录制作完毕|继续侦查 / 侦查终结|

#### 3. 侦查终结

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|侦查终结|侦查机关（公安/检察院侦查部门）|侦查活动全部完成|犯罪事实清楚、证据确实充分|1. 公安机关制作起诉意见书，连同案卷证据移送同级检察院。<br>2. 检察院侦查部门制作起诉意见书，移送本院捕诉部门审查。|案件移送完毕|进入审查起诉阶段|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|撤销案件|侦查机关|侦查过程中发现不应追责|符合刑诉法第 16 条情形、不构成犯罪、嫌疑人死亡|制作撤销案件决定书，释放在押人员|撤销决定生效|程序终结|
|羁押必要性审查与评估|检察院（捕诉部门负责，执检等配合）/ 公安机关（办案部门评估，法制部门统一审核）|犯罪嫌疑人已被逮捕|依申请 / 依职权启动|1. 检察院在审查起诉阶段，对可能判处3年以下刑罚且未经审查的，**至少应当主动审查一次**。<br>2. 检察院在审查起诉阶段、公安在侦查阶段均可**直接决定**释放或变更强制措施；其余阶段可向办案机关提出建议。|作出审查结论/决定|维持羁押 / 释放 / 变更强制措施|
|退回补充侦查|公安机关执行|检察院退回补充侦查|事实不清、证据不足、漏罪漏人|1 个月内补充侦查完毕，以 **2次** 为限（每次补侦完毕，重新计算审查起诉期限）|补侦完毕重新移送|回到审查起诉阶段|

## 三、审查起诉阶段（认罪认罚从宽核心落地阶段）

### 正常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|案件受理|检察院案件管理部门|侦查机关移送审查起诉|属本院管辖，材料齐全|登记受理，分配承办检察官|案件分配完毕|进入案件审查|
|案件审查|检察院公诉部门（捕诉部门）|已受理案件|—|1. 审查期限为 **1个月**，重大复杂案件可延长 **半个月**。<br>2. 必须讯问嫌疑人，听取辩护人/值班律师、被害人意见。<br>3. 排除非法证据，形成处理意见。|审查完毕，形成处理意见|认罪认罚具结 / 提起公诉 / 不起诉|
|认罪认罚具结（对应「认罪认罚」模块）|检察院主持，**辩护人或者值班律师在场**|嫌疑人自愿认罪认罚|不属于无需签署具结书的法定例外|1. 告知权利和法律后果，听取意见。<br>2. 在**辩护人（如有）或值班律师（无辩护人时）在场下**签署具结书，提出量刑建议。<br>3. **无需签署具结书的法定例外**：(1)盲聋哑或尚未完全丧失辨认/控制能力的精神病人；(2)未成年人及其法定代理人/辩护人有异议。|具结书签署生效|提起公诉（随案移送具结书）|
|提起公诉|检察院|审查完毕|犯罪事实清楚、证据确实充分、依法应当追究刑事责任|制作起诉书，向法院移送案卷、证据、量刑建议。量刑建议原则上法院应当采纳，除非存在明显不当、违背意愿、不构成犯罪等法定例外。|起诉书提交法院|进入一审程序|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|法定不起诉|检察院|审查完毕|符合刑诉法第 16 条情形（无罪、过时效、特赦、自诉撤回、被告人死亡、其他免责）|制作不起诉决定书，公开宣布，送达当事人与侦查机关。在押嫌疑人必须立即释放。|不起诉决定生效|程序终结（被害人可申诉 / 自诉）|
|酌定不起诉|检察院|审查完毕|构成犯罪，但情节轻微，依照刑法规定不需要判处刑罚或者免除刑罚|制作不起诉决定书，送达各方。可对被不起诉人提出检察建议（行政处罚、没收财产等）。在押嫌疑人必须立即释放。|不起诉决定生效|程序终结（被不起诉人可申诉）|
|证据不足不起诉（存疑不起诉）|检察院|补充侦查后仍证据不足|退回补充侦查后仍证据不足|1. **二次补侦后仍证据不足的，应当不起诉**。<br>2. **一次补侦后若认为无补侦必要，经检察长批准，可以不起诉**。<br>3. 未经补充侦查，不得直接作出存疑不起诉决定。在押嫌疑人必须立即释放。|不起诉决定生效|程序终结（发现新证据可再起诉）|
|不起诉救济|检察院 / 法院|相关主体不服不起诉决定|公安复议复核、被害人申诉、被不起诉人申诉|1. **公安机关**：收到决定书后 **7日内** 申请 **复议**，复议被维持后 **7日内** 提请 **复核**（上一级检察院）。期间在押的被不起诉人**必须立即释放**。<br>2. **被害人**：收到决定书后 **7日内** 向 **上一级检察院** 提出申诉；维持的可以自诉。也可以不经申诉，**直接向法院提起自诉（公诉转自诉）**。<br>3. **被不起诉人**：**仅限对酌定不起诉不服**，可在收到决定书后 **7日内** 向 **同级检察院（作出决定的检察院）** 提出申诉，要求改变不起诉理由。|复查结论作出 / 法院受理自诉|维持原决定 / 重新起诉 / 自诉立案|

## 四、一审程序（审判程序、刑事证据核心考查阶段）

### 正常流程节点（对应「审判程序」模块）

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|庭前审查|法院立案庭|检察院提起公诉|起诉书有明确指控事实|形式审查，应当在 **7日内** 决定开庭审理（并非决定是否受理）。|作出开庭审理决定|受理后转入庭前准备|
|庭前会议|审判人员主持|证据较多、案情重大等情形|控辩一方申请或法院依职权启动|1. 梳理争点、处理回避、出庭证人名单、排非申请。<br>2. **不得作出实体处理（如定罪、量刑）**。对于排非申请，达成一致的可以不召集开庭质证，达不成一致的应在庭审中调查。|庭前会议结束，形成会议记录|进入开庭审理|
|开庭审理与非法证据排除|合议庭 / 独任庭|已完成庭前准备|案件符合开庭条件|1. 普通程序：开庭宣布→法庭调查→法庭辩论→最后陈述。<br>2. **非法证据排除**：法庭调查阶段进行排非。口头言词证据（供述、证言、陈述）系通过刑讯逼供、暴力、威胁等非法方法收集的，**绝对排除**；实物证据（物证、书证）违法收集严重影响司法公正且不能补正或合理解释的，**应当排除**。举证责任由公诉人承担。|庭审结束|转入评议宣判|
|评议与宣判|合议庭 / 独任庭|庭审结束|事实已查明|秘密评议，作出有罪 / 无罪判决；一律公开宣判。当庭宣判的应当在 5 日内送达判决书，定期宣判的宣判后立即送达。|判决书宣告并送达|判决生效 / 进入二审|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|延期审理|法院|庭审过程中出现法定事由|1. 需要通知新证人到庭、调取新物证、重新鉴定/勘验。<br>2. 检察人员建议补充侦查（以2次、每次1个月为限）。<br>3. 申请回避致庭审无法进行。|宣布延期，重新排期；**延期期间计入审限（补充侦查期间除外）**。|障碍消除|恢复庭审|
|中止审理|法院|审理中出现长期障碍|被告人重病无法出庭、脱逃；自诉人重病且无代理人；不可抗力。|裁定中止审理，暂停诉讼；**中止期间不计入审限**。|障碍消除|恢复审理|
|程序转换（简易 / 速裁转普通）|法院|适用简易 / 速裁程序审理中|被告人不认罪、行为不构成犯罪、事实不清等情形|裁定转为普通程序，审限重新计算。**本转换属于“单向通道”，普通程序绝对不能转换为简易/速裁程序**。|转换裁定生效|按普通程序重新审理|
|检察院撤诉|法院审查|判决宣告前|检察院申请撤诉，法院审查准许|法院裁定准许撤诉。**没有新的事实、证据，检察院重新提起公诉的，法院应当退回**。|裁定生效|程序终结|
|无罪判决|法院|审理后认定不构成犯罪|证据不足不能定罪、行为不构成犯罪|作出无罪判决。如果被告人在押，**应当立即释放**（即便检察院表示要抗诉，也必须先释放，不能继续羁押）。|判决宣告|判决生效 / 检察院抗诉|

## 五、二审程序

### 正常流程节点（对应「审判程序」模块）

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|上诉 / 抗诉提起|被告人 / 自诉人上诉，检察院抗诉|一审判决尚未生效|在上诉抗诉期内（判决 **10日**、裁定 **5日**）。自接到判决书、裁定书的**第二日起计算**。|提交上诉状 / 抗诉书|上诉抗诉期满|一审法院移送案卷至二审法院|
|全面审查|二审法院|受理上诉 / 抗诉案件|—|**全面审查原则**：不受上诉抗诉范围限制，全面审查一审判决认定的事实、适用法律和程序是否正确。|审查完毕|确定审理方式|
|二审审理|二审法院（合议庭）|案件受理完毕|应当开庭情形：1.事实证据有异议可能影响定罪量刑；2.被告人被判处死刑（含死刑立即执行、死缓）提起上诉；3.检察院抗诉；4.其他必要情形。|1. 开庭审理或书面审理。不开庭审理的**应当讯问被告人**，听取意见。<br>2. 严格适用**上诉不加刑原则**：仅限被告人方上诉的案件，不得以任何形式加重被告人刑罚。一审法院发回重审重新审判时同样适用该原则限制（除非有抗诉/自诉人上诉）。|审理结束|作出二审裁判|
|二审裁判|二审法院|审理完毕|—|四类结果：1.维持原判；2.直接改判（事实清楚，仅法律适用错误或量刑不当）；3.发回重审（事实不清/证据不足，或程序严重违法）。<br>特别强调：**发回重审以一次为限**，重审再上诉的二审法院必须依法自行裁判，不得再次发回。|裁判宣告送达|裁判生效 / 发回重审 / 死刑复核|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|撤回上诉 / 抗诉|二审法院审查|上诉抗诉期内 / 期满后|上诉人 / 检察院申请撤回，法院审查准许|裁定准许撤回。上诉期满后请求撤回上诉的，若一审判决确有错误，二审法院应不予准许，继续审理。|裁定生效|一审判决生效 / 二审程序终结|
|发回重审|二审法院|事实不清证据不足 / 一审程序违法|符合法定发回情形|裁定撤销原判，发回原审法院重新审判。**发回重审只能发生一次，绝对禁止二次发回**。|裁定生效|原审法院按一审程序重新审理（通常另行组成合议庭）|

## 六、执行阶段

### 正常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|交付执行|一审法院|判决 / 裁定已生效|被告人已在押 / 待交付|送达执行通知书、起诉书副本、判决书等执行文书，交付对应执行机关。|执行文书送达完毕|进入刑罚执行|
|刑罚执行与机关匹配|各执行机关|已接收执行文书与罪犯|判决生效|**执行机关精准匹配（法考必考）：**<br>1. **死刑立即执行**：**第一审人民法院**执行。<br>2. **死缓、无期徒刑、有期徒刑（剩余刑期＞3个月）**：**监狱**执行。<br>3. **有期徒刑（剩余刑期≤3个月）**：**看守所**代为执行。<br>4. **拘役**：公安机关（在**看守所**）执行。<br>5. **管制、缓刑、假释、暂予监外执行**：罪犯居住地**社区矫正机构**执行。<br>6. **剥夺政治权利**：**公安机关**执行（注：剥夺政治权利不属于社区矫正范围）。<br>7. **罚金、没收财产**：**第一审人民法院**执行。|刑罚执行完毕|释放 / 解除矫正，程序终结|

### 异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|死刑停止执行|最高法 / 执行法院|死刑命令下达，执行前|发现判决可能错误、怀孕、重大立功|立即停止执行，层报最高人民法院裁定。怀孕的**必须依法改判**；其余情形查明后由最高法决定继续执行或改判。|最高法作出继续执行 / 改判裁定|继续执行 / 改判|
|暂予监外执行|交付执行的法院（交付前） / 省级监狱管理局（交付后监狱罪犯） / 设区市以上公安机关（看守所罪犯）|刑罚执行中 / 即将交付|有严重疾病需要保外就医（**自伤自残、有社会危险性除外**）；怀孕或正在哺乳自己婴儿的妇女；生活不能自理且不致危害社会|决定/批准暂予监外执行，移交罪犯居住地的社区矫正机构执行。|决定生效并移交完毕|社区矫正执行|
|减刑、假释|中级以上人民法院|刑罚执行中|执行机关（监狱/看守所/社区矫正机构）提出建议，罪犯符合减刑/假释法定条件|法院组成合议庭审理，作出减刑或假释裁定（假释裁定生效前应予公示）。|裁定生效|继续执行 / 假释释放（交社区矫正）|

## 七、特别程序（2026年法考高频考查点）

### 正常/异常流程节点

|动作名称|负责主体|前置条件|准入条件|核心动作|准出条件|后置流向|
|---|---|---|---|---|---|---|
|附条件不起诉（未成年人）|检察院|未成年嫌疑人涉嫌侵犯人身/财产/社会管理秩序罪|可能判处 **1年有期徒刑以下** 刑罚，符合起诉条件，但有悔罪表现|1. 检察院设定 **6个月以上1年以下** 的考验期进行监督考察。<br>2. 必须听取公安、被害人及未成年人监护人意见；未成年人或其监护人有异议的，**不得适用**。|考验期满且未违反相关规定|作出不起诉决定 / 考验期违法提起公诉|

|公诉案件当事人和解|公 / 检 / 法|双方达成和解协议并已履行/提供担保|1. 民间纠纷引起侵犯人身、财产权利犯罪，可能判处 **3年以下徒刑** 的案件。<br>2. 除渎职犯罪外的过失犯罪，可能判处 **7年以下徒刑** 的案件。<br>（**排除 5年内故意犯罪的累犯或再犯**）|审查和解的自愿性与合法性，制作和解协议书。检察院可提出从宽建议或酌定不起诉，法院可依法从宽处罚。|和解协议审查通过并移送/判决|酌定不起诉 / 判决从宽|
