# 二、核心定义（2026法考通说）
1. **本证**：**对待证事实负有结果意义证明责任**的一方，拿出证据证明该事实成立。
2. **反证**：**对待证事实不承担结果意义证明责任**的一方，拿出证据，动摇、否定该事实。

⚠头号红线（选择题最高频陷阱）：
❌**不能按照原告/被告划分！原告也可以提交反证，被告也可以提交本证！**

# 三、考场标准化三步判断法（直接默写套用）
1. **第一步：锁定【这份证据想要证明哪一个具体待证事实】**
>严禁把整个案件混在一起，必须单一事实单独判断。
2. **第二步：运用民诉解释91条，确定【谁对这个事实承担结果意义证明责任】**
3. **第三步：比对证据提交人**
- 提交人 = 承担证明责任一方 → **本证**
- 提交人 ≠ 承担证明责任一方 → **反证**

# 四、配套案例（甲起诉乙归还借款10万元）
事实1：**借贷关系成立（有无借款）**
👉甲承担该项事实证明责任
1.甲提交借条（证明存在借款）→本证
2.乙拿出聊天记录，证明转账是赠与、不存在借款→反证

事实2：**借款已经清偿（乙主张已经还钱）**
👉乙承担该项事实证明责任（权利消灭事实）
1.乙提交还款转账凭证（证明已经还清）→**本证（被告提交的本证！）**
2.甲举证该转账是双方其他往来，不是还款→**反证**

# 五、区分的法律意义（选择题选项常考）
1. **本证**：需要达到法定证明标准（高度可能性/排除合理怀疑）；达不到标准，承担不利后果。
2. **反证**：**不需要达到证明标准**；只需要让待证事实陷入**真伪不明**，就可以成功抵消对方本证。

# 六、高频易错坑汇总
1. ❌错误：被告拿出证据一律是反证
✅正解：被告提出积极抗辩（清偿、时效届满），对该抗辩事实承担证明责任，提交证据属于**本证**。
2. ❌错误：反证就是单纯否认
✅正解：单纯口头否认不需要提交证据；反证是**拿出实质性证据进行反驳**。
3. ❌错误：一份证据要么本证要么反证，固定不变
✅正解：依托**待证事实**。同一文书，用来证明A事实是本证；用来证明B事实可能是反证。

# 七、一句话考场速记口诀
先找证据证明啥事实；
再定谁要对事实举证；
举证责任人拿出证据为本证；
其他人拿证据反驳就是反证。

# 自测练习题（检验掌握程度）
甲起诉乙侵权赔偿。乙拿出机票，证明事发当日不在本地（不存在侵权行为）。
问：机票属于本证还是反证？
答案：**反证**
解析：侵权行为是否存在，由原告甲承担证明责任；乙不负该事实举证责任，拿出证据反驳，属于反证。
