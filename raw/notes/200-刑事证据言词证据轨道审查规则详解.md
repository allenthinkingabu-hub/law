# 刑事证据言词证据轨道审查规则详解

# 一、什么是「言词证据轨道」

## 定义

法考内部通俗叫法：
一份证据**核心内容是人主观陈述、主观判断**，无论载体是纸质笔录、录音、录像，统一适用**言词证据专属审查、采信、排除规则**，这套统一适用规则体系，就叫走「言词证据轨道」。
核心判断标准：**看内容内核，不看外在载体**。

## 核心逻辑

内核是人表达 → 走言词轨道；
内核是客观物品 / 设备自动留存痕迹 → 走实物证据轨道。

# 二、完整知识图谱（层级结构化）

## 顶层：刑事证据两大平行轨道（二分法总分类）

```Plain Text
全部刑事证据
├─ 轨道1：言词证据轨道（人作出的陈述、判断）
└─ 轨道2：实物证据轨道（客观物质、设备自动留存记录）
```

## 第一层：言词证据轨道下全部法定证据种类（四类）

```Plain Text
言词证据轨道
├ 1.证人证言（询问笔录、询问同步录音录像）
├ 2.被害人陈述（询问笔录、询问同步录音录像）
├ 3.被告人供述和辩解（讯问笔录、讯问同步录音录像）
└ 4.鉴定意见（鉴定人专业主观判断）
```

补充：侦查机关问话录制的音视频，只是记录陈述的载体，不改变分类，依然归入本条轨道。

## 第二层：言词证据轨道专属强制规则（只要进这条轨道，全部适用）

### 1\. 取证形式要求

1. 笔录必须经陈述人核对确认签字；未核对签字→直接排除

2. 讯问 / 询问需个别进行；多人同录属于严重违法

3. 不通晓语言、聋哑人必须配备翻译，否则排除

### 2\. 庭审规则

1. 满足出庭三要件的证人、鉴定人应当出庭；

2. 证人无正当理由拒不出庭可强制到庭；鉴定人拒不出庭直接废掉鉴定意见，不得拘传；

3. 所有言词证据必须当庭出示、质证，查证属实才能作为定案依据，不能直接使用。

### 3\. 证明力特殊规则

1. 补强证据规则：被告人供述、年幼 / 精神缺陷证人证言，孤证不能定案，需要其他证据印证；

2. 存在传闻证据问题：转述他人陈述的证言，证明力削弱；

3. 有利被告人的量刑类言词事实，适用优势证据标准，无需排除合理怀疑。

### 4\. 瑕疵与排除规则

1. 轻微文书瑕疵（侦查人员漏签名、时间笔误）：可补正、出具合理解释后采信；

2. 严重程序违法（刑讯、胁迫、未核对签字）：绝对排除，无法补救。

## 第三层：与实物证据轨道核心区分（同级对比）

|维度|言词证据轨道|实物证据轨道（物证、书证、现场监控、勘验笔录、电子数据）|
|---|---|---|
|内容来源|人的主观陈述、专业判断|物品、设备客观自动留存，无主观口述|
|载体影响|录音录像不改变分类，仍属言词|现场监控天然属于视听资料 / 电子数据|
|补强规则|适用补强规则，孤证不能定案|无补强要求，真实完整即可单独定案|
|签字要求|陈述人必须签字，否则排除|无当事人签字强制要求|

# 三、结合你之前考点举例

盲人齐某听到被害人呼救、公安讯问同步录像：
内容是人说的话 → 归入**言词证据轨道**，不能按视听资料简单直接采信，要适用证人证言全套审查规则。

# 四、速记口诀

但凡内容是人亲口说，录视频写笔录都算言词轨道；
机器自动拍下现场画面，才走实物证据那一套。

# 五、实物证据轨道｜完整体系（对称配套版）

## 定义

法考统一配套概念：**证据核心内容是客观物质痕迹、设备自动留存数据、现场客观记录**，不受人的主观陈述、主观判断影响，统一适用**实物证据专属审查、鉴真、排除规则**，这套独立规则体系，即为「实物证据轨道」。
核心判断标准：**看客观载体与天然属性，与人的事后口述无关**。

## 核心逻辑

机器/现场天然留存、客观存在的载体 → 走实物轨道；
人为事后口述、主观判断的内容 → 走言词轨道。

## 顶层：刑事证据两大平行轨道（复用总分类）

```Plain Text
全部刑事证据
├─ 轨道1：言词证据轨道（人作出的陈述、判断）
└─ 轨道2：实物证据轨道（客观物质、设备自动留存记录）
```

## 第一层：实物证据轨道下全部法定证据种类（五类）

```Plain Text
实物证据轨道
├ 1.物证（作案工具、赃物、痕迹、伤情实物等）
├ 2.书证（合同、账本、单据、书面文件等原始载体）
├ 3.勘验/检查/辨认/侦查实验笔录（客观现场记录）
├ 4.视听资料（案发自动监控、行车记录仪、现场原始录音）
└ 5.电子数据（聊天记录、转账记录、后台日志、原始数据）
```

关键区分：只有**案发时设备自动生成**的音视频、数据属于实物轨道；侦查问话同步录像属于记录人陈述，归言词轨道。

## 第二层：实物证据轨道专属强制规则（全程适用）

### 1\. 取证与鉴真核心要求（轨道第一重点）

1. **保管链条完整**：提取、扣押、封存、流转全程可追溯，需制作笔录、清单，侦查人员、持有人、见证人签字。

2. **原件原物优先**：不便提取原物的，可制作照片、复制品、刻录件，必须注明“与原件原物一致”并签字确认。

3. **电子数据专属鉴真**：原始介质封存、哈希值校验、全程录屏，防止数据篡改、删减。

4. 无保管链条、来源不明、无法说明获取过程，直接丧失证据能力。

### 2\. 庭审规则（与言词轨道核心差异）

1. **无出庭义务**：实物证据本身无需“出庭”，无需任何人强制到庭接受质询。

2. **当庭出示原物/原件**：控辩双方仅对载体真实性、来源合法性、是否篡改进行质证。

3. 无需个别取证、无需翻译、无需当事人核对签字，完全区别于言词证据。

### 3\. 证明力特殊规则（法考高频考点）

1. **无补强证据规则**：真实、合法、完整的单一实物证据，可**单独定案**（孤证有效）。

2. **无传闻证据瑕疵**：客观载体记录的内容，不存在转述失真、证明力弱化问题。

3. 证明标准统一：定罪、从重、从宽事实，均需达到证据确实、充分，无优势证据例外。

### 4\. 瑕疵与排除规则（绝对区分言词证据）

1. **可补正瑕疵**：清单漏签、时间笔误、标注简略、未当场封存（可出具情况说明、补正手续后采信）。

2. **绝对排除情形**：来源完全无法查证、保管链条断裂无法合理解释、载体被篡改/删减/伪造、复制品无法与原物原件核对。

## 第三层：两大轨道终极对比（完整版）

|维度|言词证据轨道|实物证据轨道|
|---|---|---|
|内容来源|人的主观陈述、专业判断|物品、设备客观自动留存，无人为主观口述|
|载体影响|问话录音录像仍属言词，载体不改变属性|案发自动音视频、数据天然属于实物证据|
|补强规则|适用补强规则，孤口供、弱势证言不能单独定案|无补强要求，真实完整即可单独定案|
|签字核心要求|陈述人必须核对签字，未签字直接排除|无当事人签字要求，侧重见证人、流转签字|
|出庭规则|证人可拘传、鉴定人不出庭废证据|无需任何人强制出庭，仅当庭出示载体|
|排除核心逻辑|程序违法、未核对、非法取证直接排除|来源不明、篡改、保管链断裂才排除|

# 六、两大轨道终极做题口诀

人说的话、事后记录，一律走言词，要签字、要补强、要出庭；
机器自录、现场实物，一律走实物，看来源、看保真、可孤证。
