# 法条依据

《民事诉讼法》第 41 条、第 207 条、第 212 条、第 213 条、第 215 条
全国人大法条链接：[https://flk\.npc\.gov\.cn/detail?id=ff8081818a21dc13018b425303b7086d](https://flk.npc.gov.cn/detail?id=ff8081818a21dc13018b425303b7086d)

## 一、通俗定义

**民事再审（审判监督程序）**
是针对**已经生效**的判决、裁定、调解书的**纠错救济程序**。
不是普通一二审常规程序，是**事后监督、特殊纠错**，目的纠正原审事实、证据、法律、程序重大错误。

> 重点区分：
> 一审、二审 = 常规正常审理程序
> 再审 = 生效后**非常规纠错程序**，不改变两审终审基本制度
> 
> 

## 二、硬性核心考点（法考必背）

1. **审判组织铁规**：再审、发回重审**一律另行组成合议庭**，**绝对禁止独任审理**（无任何例外）。

2. **启动主体**：当事人申请再审、法院依职权再审、检察院抗诉 / 检察建议再审。

3. **禁止再审范围**：**解除婚姻关系的生效判决、调解书**，不得申请再审。

4. **审理层级规则**：

    - 原一审生效 → 再审按**一审程序**审理，裁判可上诉；

    - 原二审生效、上级提审 → 再审按**二审程序**审理，裁判终审、不可上诉。

5. **审查期限**：法院收到再审申请，**3 个月内审查完毕**，裁定再审或驳回。

## 三、案例直观理解

案例 1（正常再审）
甲乙民间借贷，二审判决生效后，甲发现原审关键证据系伪造、足以推翻原判 → 甲可向法院申请再审，法院**另行组成合议庭**开庭纠错。

案例 2（绝对不能再审）
甲乙诉讼离婚，法院判决离婚且已生效 → 哪怕不服，**不得申请再审**（身份关系不可逆）。

案例 3（审级适用）
案件一审生效未上诉，进入再审 → 按一审程序审，判决后**还能上诉**；
案件二审终审后启动再审 → 按二审程序审，**不能上诉**。

## 四、考场一句话背诵

再审是生效裁判纠错监督程序，**一律合议庭、禁止独任**；离婚身份案禁再审；原一审再审可上诉、原二审 / 提审再审终审。

## 五、配套考点

1. 再审**不停止原判决执行**（除非法院裁定中止执行）；

2. 再审不属新诉，**不改变原审审级性质**；

3. 发回重审必须**更换审判人员**，原合议庭 / 独任法官全部回避。
