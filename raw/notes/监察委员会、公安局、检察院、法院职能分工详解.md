# 监察委员会、公安局、检察院、法院职能分工详解

## 一、监委全称

**监察委员会**，最高层级叫**国家监察委员会**，地方分省、市、县三级监委；纪委与监委一套人马合署办公，日常简称监委。

## 二、四家机关核心职能分工（法考专用）

### 1\. 监察委员会（监委）

只管**所有行使公权力的公职人员**（公务员、村干部、国企 / 医院学校管理人员等）

1. 查：贪污、受贿、挪用公款、滥用职权、玩忽职守等**职务违法、职务犯罪**；

2. 手段：谈话、查询冻结、搜查、**留置**（替代原检察院反贪部门的刑事拘留）；

3. 收尾：轻微违法给予政务处分；构成犯罪的，全部**移送检察院审查起诉**；

4. 关键点：没有起诉权、审判权、逮捕执行权，调查终结必须移交检察院进入刑事诉讼流程。

### 2\. 公安局（公安）

管**普通主体的刑事犯罪 \+ 治安违法**

1. 侦查：盗窃、诈骗、故意伤害、杀人、贩毒等绝大多数普通刑事案件；

2. 强制措施：刑事拘留、取保候审、监视居住；

3. 唯一执行机关：所有逮捕（检察院批捕 / 法院决定）、送看守所羁押全部由公安执行；

4. 治安职能：行政拘留、户籍管理、交通管理等行政职能。

### 3\. 人民检察院（法律监督机关）

核心职能：**公诉 \+ 诉讼监督 \+ 少量自侦**

1. 审查起诉：公安、监委移送的案件，统一由检察院阅卷、讯问，决定起诉 / 不起诉；

2. 逮捕审批：公安侦查的普通案件报捕，检察院审查作出批捕 / 不批捕决定；

3. 自侦范围：仅限司法人员渎职侵权类犯罪，贪污贿赂类已划转监委；

4. 监督职能：羁押必要性审查、监督公安侦查活动、监督法院审判、监督监狱执行。

### 4\. 人民法院（唯一审判机关）

核心职能：**开庭审判、定罪量刑**

1. 逮捕决定权：审判阶段被告人有逃跑、串供风险，法院可直接作出逮捕决定；

2. 无抓捕执行权：法院决定逮捕后，文书交公安机关执行，法警仅负责法庭内押解；

3. 最终裁判权：有罪 / 无罪判决、刑期确定、缓刑 / 实刑宣告均由法院作出；

4. 配套职能：司法拘留、民事 / 行政案件强制执行。

## 三、四机关刑事案件管辖范围明细

### 1\. 监察委员会管辖案件（公职人员职务犯罪）

监委管辖六大类公职人员职务违法和职务犯罪，覆盖所有行使公权力人员的职务相关犯罪：

- 贪污贿赂类：贪污罪、受贿罪、挪用公款罪、行贿罪、巨额财产来源不明罪等

- 滥用职权类：滥用职权罪、故意泄露国家秘密罪、报复陷害罪等

- 玩忽职守类：玩忽职守罪、过失泄露国家秘密罪、失职致使在押人员脱逃罪等

- 徇私舞弊类：徇私舞弊减刑假释罪、徇私舞弊不移交刑事案件罪等

- 重大责任事故类：公职人员履职不当导致的重大责任事故相关犯罪

- 其他职务侵权类：公职人员利用职权实施的侵犯公民人身权利、民主权利犯罪

> 考点提示：公职人员利用职务便利实施的贪污贿赂、渎职类犯罪，原则上由监委立案调查；司法工作人员相关渎职侵权犯罪，检察院也可管辖，存在管辖交叉。
> 
> 

### 2\. 人民检察院自侦案件

检察院仅保留两类侦查权，绝大多数职务犯罪已划转监委：

- **司法工作人员渎职侵权类（核心管辖）**：司法工作人员（公安民警、法官、检察官、监管场所人员等）利用职权实施的 14 类犯罪，包括刑讯逼供罪、暴力取证罪、虐待被监管人罪、徇私枉法罪、民事行政枉法裁判罪、私放在押人员罪等。

- **机动侦查权（兜底例外）**：公安机关管辖的国家机关工作人员利用职权实施的重大犯罪案件，确需检察院直接受理的，经省级以上检察院决定，可由检察院立案侦查。

### 3\. 公安机关管辖案件

绝大多数普通刑事犯罪由公安机关立案侦查，是刑事侦查的主力：

- 侵犯财产类：盗窃、诈骗、抢夺、抢劫、职务侵占、挪用资金等

- 侵犯人身权利类：故意杀人、故意伤害、强奸、非法拘禁（非公职职权类）、绑架等

- 危害公共安全类：交通肇事、危险驾驶、放火、爆炸等

- 破坏市场经济秩序类：非法经营、信用卡诈骗、合同诈骗等

- 妨害社会管理秩序类：寻衅滋事、聚众斗殴、毒品犯罪、赌博罪等

### 4\. 人民法院直接受理案件（自诉案件）

无需公安侦查、检察院公诉，被害人可直接向法院起诉：

- 告诉才处理的案件：侮辱、诽谤、暴力干涉婚姻自由、虐待、侵占

- 被害人有证据证明的轻微刑事案件

- 公诉转自诉案件：被害人有证据证明应当追责，而公安、检察院不予追究的案件

## 四、完整案件流程串记

- 监委管辖职务犯罪链条：公职人员受贿 → 监委留置调查 → 移送检察院审查起诉 → 检察院提起公诉 → 法院开庭审判

- 公安管辖普通刑事链条：公民盗窃 → 公安侦查刑拘 → 提请检察院批捕 → 侦查终结移送起诉 → 检察院公诉 → 法院判决

- 检察院自侦案件链条：司法工作人员渎职侵权 → 检察院立案侦查 → 检察院决定逮捕（公安执行） → 侦查终结移送审查起诉 → 检察院公诉 → 法院开庭审判

- 法院自诉案件链条：被害人遭遇自诉罪名 → 自行收集固定证据 → 直接向法院提交自诉材料 → 法院立案审理 → 法院作出判决
