好，把之前核实过的每一条法条依据都揉进来，按"**流程名称 + 一句话（谁·做什么·为了什么）**"的格式给你整理成一套完整体系。核对后实际是**13个动作点**（比我上次说的"12"多了一个——之前把"公诉人讯问"和"审判人员补充讯问"算重了，这次按法条自身的条文划分拆细拆准，一步一个清晰主体）。

# 📋 法庭调查完整流程体系（13步·2026现行）

| #      | 流程名称              | 一句话：谁·做什么·为了什么                                                                                                                                      | 依据                          |
| ------ | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| **1**  | **宣读起诉书/自诉状**     | **公诉人**（自诉案件为**自诉人**）宣读指控内容，目的是**正式亮明控诉的具体事实和罪名**，让庭审有明确的审理对象                                                                                       | §240前                       |
| **2**  | **审判长询问异议**       | 审判长当庭问被告人对指控事实、罪名有无异议，目的不是"决定走哪个程序"（程序早就定了），而是"复核被告人的态度是否和庭前一致"——一旦发现被告人当庭翻供、不认罪、或认罪认罚是违背意愿的，**法庭必须把已经在走的简易/速裁程序，转回普通程序重新审理**                       | §240后                       |
| **3**  | **被告人、被害人陈述**     | **被告人、被害人**就案件事实分别陈述自己的说法，目的是让**双方当事人的原始版本先摆上桌**，作为后续讯问、举证的基础                                                                                       | §241                        |
| **4**  | **公诉人讯问被告人**      | **公诉人**就指控事实讯问被告人，被害人方可补充发问、辩护人可发问，目的是**控方主导核实被告人对指控事实的具体交代**                                                                                       | §242                        |
| **5**  | **控辩双方发问被害人**     | **公诉人、辩护人**经审判长准许，向被害人发问，目的是**核实被害人陈述的细节、检验其可信度**                                                                                                   | §244                        |
| **6**  | **审判人员补充讯问（官补讯）** | **法官**在控辩双方问完后，就还存疑的事实**补充讯问**被告人或发问被害人，目的是**居中裁判者补漏定案**，不主导追诉、只查清疑点                                                                                | §245                        |
| **7**  | **询问证人、鉴定人**      | **证人、鉴定人**出庭作证/说明鉴定意见，控辩双方发问，目的是**用"活的"言词证据固定案件事实，接受质证检验**                                                                                          | §246起                       |
| **8**  | **出示证据（举证）**      | **控辩双方**出示物证、宣读书证、播放视听资料/电子数据，目的是**把"死的"实物证据摆上台面，供质证核验**（人证物证先后不强制，按案情组织）                                                                           | §267起                       |
| **9**  | **质证**            | **控辩双方**就已出示的证据的真实性、关联性、合法性互相质疑、说明、辩驳，目的是**检验证据能不能用、该给多大分量**                                                                                        | §267起                       |
| **10** | **排非穿插（浮动插入点）**   | **辩护方**对某份证据的取证合法性提出异议，**控方**就合法性举证说明，**法庭**当庭裁决排除与否，目的是**在"该证据"被质证前先把关合法性**，非法的直接清出局，不给它进入质证的机会 -> 排非这个动作在13步流程表里没有固定的门牌号，它是"哪份证据被质疑非法，就插到那份证据出场之前 | 排非时机规则（先行于该证据质证，兜底可挪至第13步前） |
| **11** | **申请新证据/重新鉴定勘验**  | **控辩双方**申请通知新证人到庭、调取新证据、申请重新鉴定或勘验，须说明信息和理由，目的是**补齐案件的证据漏洞**，法庭认为必要应当同意                                                                              | §273                        |
| **12** | **休庭调查核实证据**      | **合议庭**对证据有疑问的，可以宣布休庭，自行进行调查核实（可勘验、检查、查封、扣押、鉴定、查询、冻结），目的是**法庭自己主动查清存疑的证据，不完全依赖控辩双方举证**                                                              | 证据调查核实规则                    |
| **13** | **宣布法庭调查结束**      | **审判长**宣布法庭调查阶段结束，目的是**收尾证据环节、转入法庭辩论**，庭审从"查事实"进入"辩是非"                                                                                              | 自然衔接                        |
|        |                   |                                                                                                                                                     |                             |

## 一句话总闭环

**13步分四段走**：**①亮指控**（1-2）→ **②摆事实**（3-6，被告人被害人陈述+多轮讯问发问）→ **③摆证据**（7-9，人证物证出示质证，排非浮动穿插其中）→ **④查漏补缺**（11-12，新证据+休庭核实）→ **⑤收尾**（13，转法庭辩论）。**记忆主线：先讲"是什么事"，再讲"证据摆出来对不对"，最后"补漏、收尾"。**
