# 刑事诉讼一审普通程序整套框架（法考通用完整版）

**核心总定位（三科统一对标）**：刑事一审普通程序是刑诉**最完整、最标准、兜底通用**审判流程，所有重罪、复杂案件、不认罪案件、死刑案件必须适用；整套流程、审理组织、期限、规则均由《刑事诉讼法》法定锁定，**法规、规章均无权改动**，是简易程序、速裁程序的基础蓝本。

**三科程序总区分（必背）**：行诉、民诉只有普通\+简易；**刑诉独有三套程序：普通、简易、速裁**。

## 一、专业法条版：刑诉一审普通程序 6 大固定模块（法定完整流程）

### 模块1：庭前审查（公诉案件立案前置）

法院对检察院提起公诉的案件进行**书面形式审查**，仅做形式审查，不实质审查证据是否充分。

开庭标准：起诉书有明确指控犯罪事实、附有案卷材料及证据，**应当决定开庭审判**。

特殊处理：无管辖权、属于法定不追责情形、被告人不在案等，依法**退回检察院**，不得直接驳回起诉。

### 模块2：庭前准备（法定硬性时间与流程）

1. **审理组织固定**：必须组成**3人以上单数合议庭**，**绝对禁止独任审理**（独任仅适用于简易、速裁程序）。

2. **送达时限**：开庭**10日前**将起诉书副本送达被告人、辩护人（刑诉独有10日，区别民诉、行诉5日）。

3. **庭前会议**：审判人员可召集控辩双方，梳理争议焦点、处理回避、管辖、非法证据排除等程序性问题，不审理实体定罪量刑。

4. **开庭通知**：开庭**3日前**送达开庭通知，公开审理案件提前公告案由、开庭时间、地点。

### 模块3：开庭审理（法定五阶段，顺序不可颠倒、不可删减）

为刑诉普通程序专属完整庭审流程，简易可简化、速裁直接跳过调查辩论，普通程序必须全部走完。

1. **开庭预备**：书记员查明到庭情况、宣布法庭纪律；审判长核对当事人身份、告知回避权、庭审权利义务。

2. **法庭调查（核心环节）**：公诉人宣读起诉书 → 被告人陈述 → 被害人陈述 → 控辩双方举证、质证 → 讯问、询问证人、鉴定人 → 核查全案证据。**所有定案证据必须当庭质证**。

3. **法庭辩论**：公诉人发表公诉意见 → 被害人及代理人发言 → 被告人自行辩护 → 辩护人辩护 → 控辩双方互相辩论。

4. **被告人最后陈述（绝对保留权利）**：任何刑事案件、任何程序，**最后陈述权不可剥夺、不可省略**（速裁、简易程序也必须保留）。

5. **庭审调解禁止**：刑事公诉案件**一律不适用调解**（区别民诉全调解、行诉有限调解）；仅自诉案件、附带民事诉讼可调解。

> 审理原则：以公开开庭为原则，涉及国家秘密、个人隐私绝对不公开；未成年人案件应当不公开。

### 模块4：合议庭评议

庭审结束后，合议庭闭门秘密评议，按照**少数服从多数**原则作出裁判，少数意见记入评议笔录。疑难复杂案件可提请审委会讨论，审委会决定合议庭必须执行。

### 模块5：一审法定裁判结果

1. 有罪判决：事实清楚、证据确实充分，依法定罪量刑；

2. 无罪判决：依法认定无罪、证据不足不能定罪（疑罪从无）；

3. 裁定终止审理：出现法定不追究刑事责任情形。

### 模块6：审限与上诉收尾（法考高频数字）

1. **法定审限**：立案之日起 **3 个月**；重大复杂案件经批准可延长 3 个月。

2. **上诉期限**：刑事判决书 **10 日内**、裁定书 **5 日内**向上一级法院上诉（区别民诉、行诉15日）。

3. 检察院可依法提起二审抗诉。

## 二、大白话通俗拆解

### 1\. 整体定位

刑诉一审普通程序 = 刑事案件**最全、最严谨的标准版审判流程**。只要案件重、案情复杂、被告人不认罪、可能判重刑，一律走这套完整流程，不能简化、不能跳过步骤，最大程度保障刑事审判公正。

### 2\. 三科普通程序核心对比（终极打通）

1. **行诉普通程序**：6个月审限、被告举证、有限调解、无速裁程序；

2. **民诉普通程序**：6个月审限、谁主张谁举证、全程可调解、无速裁程序；

3. **刑诉普通程序**：3个月审限、控方举证、公诉案件不调解、独有速裁简易程序、起诉书10日送达、上诉10日。

### 3\. 核心坑点人话总结

1. 刑诉普通程序**必须合议庭**，无独任审理；

2. 公诉刑案**绝对不能调解**，和民诉、行诉本质区别；

3. 被告人**最后陈述权神圣不可剥夺**，所有程序通用；

4. 刑诉时间节点全部短于民诉、行诉，数字单独记忆。
