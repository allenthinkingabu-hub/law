# 2026法考·刑事二审完整全流程（法条依据+做题要点，Markdown）
法条总来源：《刑事诉讼法》2018修正（2026现行），官方链接：http://gongbao.court.gov.cn/Details/b772fbc86b46cdf2eddda464ef3325.html
配套细化：《刑诉解释》《人民检察院刑事诉讼规则》

## 总框架五阶段
1. 二审程序启动（上诉/抗诉）
2. 一审法院移送案卷
3. 二审庭前准备（合议庭、全面审查）
4. 二审审理（开庭/不开庭两套流程）
5. 合议庭评议+二审裁判（四类处理结果）

## 一、阶段1：二审程序启动（刑诉227、228、229、230）
### 1. 上诉（当事人启动）
1. 主体
    - 独立上诉权：被告人、自诉人、附带民诉当事人、法定代理人
    - 附条件上诉：辩护人、近亲属，**必须经被告人同意**
    - 被害人：**无上诉权**，收到判决书后**5日以内**，有权请求检察院提出抗诉；**检察院自收到请求后5日以内，应当作出是否抗诉的决定并答复请求人**（第229条，双向5日，别只记一头）
2. 期限：判决10日、裁定5日，次日起算
3. 方式：书面上诉状 / 口头上诉（书记员记录）
4. 两条提交路径
    - 路径A：向**原审一审法院**提交（主流）
    - 路径B：直接向**二审法院**提交；二审3日内转交一审法院送达对方、检察院
5. 上诉撤回规则（法考高频坑）
    - 上诉期内撤回：法院**应当准许**
    - 上诉期满后撤回：二审审查，原判无误可准许；原判有错不准撤回
    - **死刑立即执行上诉，在第二审开庭后、宣告裁判前申请撤回上诉的，应当不予准许，继续按上诉案件审理**（《刑诉法解释》第305条+2010年最高法/最高检批复，独立考点，非泛泛而谈）

### 2. 抗诉（检察院启动，二审抗诉）
1. 主体：一审**同级检察院**（下抗上）
2. 条件：一审裁判确有错误；必须书面抗诉书，禁止口头
3. 期限：同上诉（判决10日、裁定5日）
4. 标准流程
    1）向原审法院交抗诉书，**抄送上级检察院**
    2）原审期满3日内移送案卷、抗诉书给二审，副本送达当事人
    3）上级检察院终局审查：
        - 抗诉正确：出具支持抗诉意见书，二审出庭
        - 抗诉不当：**上级检察院向同级二审法院撤回抗诉**（第221条），书面通知下级；**下级检察院无权自行撤回抗诉**
    4）**救济环节（原文档遗漏，补齐）**：**下级检察院如果认为上级检察院撤回抗诉不当的，可以提请复议**；上级检察院应当复议，并将复议结果通知下级检察院——这是"抗诉撤回"这条线唯一的救济出口，别当成"上级说撤就撤、下级完全没话说"
5. 抗诉撤回：期内撤回应当准许；期满撤回法院可裁定准许

## 二、阶段2：一审法院移送案卷（刑诉231、232）
1. 当事人走原审上诉：一审**3日内**移送全部案卷、证据、上诉状至二审，副本送达同级检察院、对方当事人
2. 检察院抗诉：抗诉期满3日内移送案卷；抗诉书抄送上级检
3. 当事人直接向二审上诉：二审3日内转交一审完成送达程序

## 三、阶段3：二审庭前准备（刑诉233、234）
### 1. 强制规则：二审**一律合议庭，禁止独任**（你之前A选项考点核心）
- 合议庭仅审判员组成，不能有人民陪审员
- 无论开庭、不开庭，必须合议庭审理

### 2. 核心原则：全面审查原则（刑诉233）
不受上诉/抗诉范围限制，全案事实、证据、定罪、量刑、程序、附带民事全部审查；共犯部分上诉，全案一并审查。

### 3. 开庭前置准备（应当开庭案件）
1. 确定开庭日期，通知同级检察院阅卷；检察院阅卷1个月，不计审限
2. 送达开庭通知给当事人、辩护人、诉讼代理人
3. 四类**必须开庭**案件（口诀：死、抗、事实异议、兜底），官方原文：
    1）被告人、自诉人及其法定代理人**对第一审认定的事实、证据提出异议，可能影响定罪量刑**的上诉案件
    2）被告人**被判处死刑**的上诉案件
    3）**检察院抗诉**的案件
    4）**其他应当开庭审理的案件**（兜底，如出现新事实新证据、量刑情节未确认、法律适用争议大等）

## 四、阶段4：二审审理（两套流程：开庭 / 不开庭）
### （一）模式1：开庭审理流程（应当开庭案件）
1. 开庭地点：二审法院，也可案发地、原审法院所在地
2. 出庭义务：抗诉/开庭公诉案件，同级检察院**必须派员出庭**
3. 庭审环节（简化版，不照搬一审冗长流程）
    1）法官核对身份、告知权利
    2）上诉人宣读上诉状 / 检察员宣读抗诉书
    3）法庭调查：围绕上诉/抗诉争议事实举证质证
    4）法庭辩论：上诉人、辩护人→检察员/自诉人依次辩论
    5）**被告人最后陈述（不可省略）**
4. 休庭，合议庭评议

### （二）模式2：不开庭审理流程（仅事实清楚、无事实争议案件）
法条硬性三步缺一不可：
1. 合议庭全体阅卷，梳理全案证据、程序、法律问题
2. **必须讯问被告人**（《刑诉法解释》第324条明确的强制规定，**不能省略**，这是不开庭审理的法定动作，不是可选项）
3. 主动听取辩护人、被害人、诉讼代理人、检察员书面/口头意见
4. 全部意见收集完毕，合议庭书面评议，不开法庭调查、辩论

## 五、阶段5：合议庭评议+二审裁判（刑诉236、238，法考核心区分）
### 1. 四类裁判结果+适用情形（做题必背）
1. **维持原判（裁定）**：事实清楚、证据充分、适用法律正确、量刑适当
2. **应当改判（判决）**：事实证据无误，但法律适用错误 / 量刑不当；不受上诉不加刑约束时可加重刑罚
3. **可改判、可发回**：事实不清、证据不足；**事实不清发回仅限1次**，二次上诉仍不清必须改判
4. **应当发回重审（裁定，无次数限制）**：一审存在法定严重程序违法（应公开不公开、应回避未回避、剥夺辩护/最后陈述权、审判组织不合法等）
5. **配套细节**：一审法院对发回重审的案件，**应当另行组成合议庭**审理（第239条）；若二审合议庭曾审理过本案前一次二审、案件发回重审后又上诉回到同一二审法院的，**原二审合议庭不受审级回避限制，可以继续审理**

### 2. 关键配套规则：上诉不加刑（俗称加刑看上诉，刑诉237）
1. 仅被告人一方上诉、无抗诉/自诉人上诉：二审**任何刑罚不得加重**（主刑、罚金、撤销缓刑、延长考验期、总刑期全部禁止加重）
2. 存在检察院抗诉 / 自诉人上诉：不受不加刑限制，可依法加重
3. 仅被告上诉发回重审：无新犯罪事实、检察院未补充起诉，原审仍不得加刑

### 3. 二审审限（刑诉243）
1. 普通上诉/抗诉：受理后**2个月**内审结
2. 可能判处死刑的案件、附带民事诉讼的案件、以及**符合第158条规定四类情形之一**的（**交通不便的边远地区案件、重大犯罪集团案件、犯罪涉及面广取证困难的案件、其他情况特殊需要延长的案件**——不是笼统的"偏远重大复杂"），经**省/自治区/直辖市高级人民法院批准或决定**，可以延长**2个月**
3. 因特殊情况还需延长的，**报请最高人民法院批准**；最高法院自己受理的上诉抗诉案件审限由最高法院自行决定
4. 检察院阅卷1个月，不计入审限（⚠️ 此条常见于教辅资料，但本次未查到可直接引用的独立条文出处，建议使用前自行核实）

## 六、全流程做题速记要点（2026法考答题逻辑）
1. 先区分启动方式：上诉（口头/书面、双路径）vs抗诉（仅书面、下抗上、上级可撤回）；
2. 审判组织秒杀：二审无独任，所有案件必须合议庭；
3. 审理方式区分：死、抗、事实有异议强制开庭；事实清楚可不开庭，但必须讯问被告人；
4. 裁判区分口诀：法律量刑错应当改，程序违法应当发，事实不清可改可发，全部正确维持；
5. 加刑判断：只有被告上诉不加刑，有抗诉/自诉上诉可加刑；
6. 陷阱避雷：
    - 事实不清发回仅1次、程序违法发回无次数；
    - 抗诉只能上级向二审法院撤回，下级无权自行撤回，但**下级可以对"撤回不当"提请复议**（原文档遗漏点，重点记）；
    - 被害人请求抗诉是"双5日"——**被害人请求5日 + 检察院答复也是5日**，别只记一头；
    - 死刑立即执行案件，**开庭后、宣判前**申请撤回上诉，法院不予准许，这是独立的强制性规则，别当成一般撤回规则处理。
