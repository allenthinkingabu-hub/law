# 行政诉讼驳回诉讼请求四种场景通俗解析

# 一、整段大白话通俗拆解

核心总原则：**原告打官司想要的结果，法院没法支持，全部一刀切判：驳回诉讼请求**，分四种场景逐个翻译：

## 场景 1：老百姓起诉行政机关不作为，但起诉的理由本身站不住脚

### 人话

你告政府 “该干活不干活”，但法律上政府本来就没有义务给你办这件事，政府没做错，法院驳回。

### 案例

张三要求住建局给自己老家老宅出具历史房屋产权证明，但根据规定，住建局根本没有开具这类历史老宅确权证明的法定职责。张三执意起诉住建局行政不作为。法院审理后认为被告不存在不作为，判决驳回张三的诉讼请求。

## 场景 2：起诉政府不给发证，打官司过程中政府已经把证件补发到位，但原告依然不肯撤诉

### 人话

矛盾已经被政府实际解决了，你的诉求客观上已经实现，官司继续打没有任何意义，你非要纠缠，法院直接驳回。

### 案例

个体户李四申请营业执照，市场监管局迟迟未核发，李四起诉行政不作为。一审开庭过程中，市场监管局当场审核通过并送达了营业执照。法官劝导李四撤诉，但李四赌气坚持不撤。法院最终判决驳回其诉讼请求。

## 场景 3：行政机关当初作出的行政行为本身完全合法，只是后来法律法规修订，该行为对应的事项被新法废止了

### 人话

政府当年办事完全合规、程序内容都没问题，只是事后法律改了，这个行政行为后续不能继续用了，不能倒回去认定当年行为违法，驳回原告诉求。

### 案例

早年商务局依法核准某企业成品油零售经营许可，该许可作出时完全符合当时法律。诉讼期间国家出台新规，取消了该项行政审批事项，许可证后续失效。企业起诉要求确认当初许可违法，法院认定原行政行为合法，仅因新法废止不溯及既往，判决驳回。

## 场景 4：原告起诉要求法院确认行政行为无效，法官明确告知你诉讼请求提错了，应该改成撤销 / 确认违法，但原告拒不更改

### 人话

法律有严格的起诉口径：确认无效有极其严苛的法定条件，很多案子只能提撤销之诉。法官好心释明让你变更诉讼请求，你固执不改，法院直接驳回。

### 案例

王五被公安局罚款 200 元，王五直接起诉请求**确认该处罚决定无效**。法院开庭释明：该处罚只是轻微程序瑕疵，达不到 “重大且明显违法” 的无效标准，建议变更为请求确认行政行为违法。王五坚决不同意变更诉求。法院按照原诉求审理后，判决驳回王五的诉讼请求。

# 二、终极背诵极简版

1. 告错了（政府没义务办事）→ 驳回

2. 事已经办完了还赖着打官司 → 驳回

3. 当年合法，只是后来法律改了 → 驳回

4. 诉求类型选错，法官提醒还不改 → 驳回

# 补充小考点（法考容易混淆）

驳回诉讼请求 VS 驳回起诉

- **驳回起诉**：压根不符合起诉资格、告错被告、不属于行政诉讼受案范围（程序问题，还没审实体）

- **驳回诉讼请求**：案子正常开庭审理完了，实体上你的主张不成立（上面四种全部属于实体审理后的结果）
