# 一、法条原文（2026现行，《刑事诉讼法》第288条）
官方链接：http://gongbao.court.gov.cn/Details/b772fbc86b46cdf2eddda464ef3325.html
## 两类**法定可以走公诉刑事和解**的案件
### 第一类：民间纠纷+人身/财产轻罪（3年以下）
1. 起因：邻里、婚恋、债务、琐事等**民间纠纷**；
2. 罪名：刑法第四章（侵犯人身民主权利：故意伤害、侮辱、非法拘禁轻伤等）、第五章（侵犯财产：盗窃、诈骗、故意毁坏财物、敲诈勒索数额较大等）；
3. 刑期上限：**可能判3年以下有期徒刑、拘役、管制**；
4. 举例：邻里打架轻伤、小额盗窃、情侣纠纷故意伤害。
5. 民间纠纷型故意案超 3 年不可和解；过失案（非渎职）7 年内仍可和解。


### 第二类：过失犯罪（**渎职罪除外**），7年以下
1. 犯罪形态：纯过失（交通肇事、重大责任事故等）；
2. 排除红线：**所有渎职犯罪一律不能和解**（滥用职权、玩忽职守等直接排除）；
3. 刑期上限：可能判处7年以下；
4. 举例：普通交通肇事致人重伤、工地过失致人死亡。

## 三大硬性必备条件（两类案件全部要满足）
1. 嫌疑人/被告人**真诚悔罪**；
2. 赔偿、道歉，**取得被害人谅解**；
3. 被害人**自愿和解**，无胁迫、利诱。

## 绝对不能适用刑事和解的情形（法考高频坑）
1. 渎职类犯罪（滥用职权、玩忽职守、徇私枉法等）；
2. 被告人**五年内有故意犯罪前科**，无论轻重一律禁止；
3. 法定禁止类重罪：雇凶伤害、黑社会、寻衅滋事、聚众斗殴、多次性侵、恐怖/危害国家安全犯罪；
4. 不属于民间纠纷的故意重罪（抢劫、强奸、绑架、贩毒等）。

# 二、区分两个极易混淆概念（做题必分清）
1. **法定刑事和解（特别程序）**：仅限上面两类案件，公检法主持签和解协议书，可不起诉、大幅从宽；渎职完全无资格。
2. **私下赔偿谅解（仅量刑情节）**：任何案件都能赔钱拿谅解，包括渎职，但**不属于刑诉法的和解程序**，只能轻微从轻，不能不起诉、不能适用和解优待。

## 配套案例
1. 甲因借钱纠纷殴打乙致轻伤（民间纠纷、3年以下）→ 可以刑事和解；
2. 甲交通肇事致1人死亡（过失、7年以下、非渎职）→ 可以刑事和解；
3. 民警滥用职权致群众重伤（渎职）→ 不能走刑事和解，赔钱只算酌定从轻；
4. 5年前曾盗窃，本次又民间纠纷轻伤 → 五年内有故意前科，禁止和解。

# 三、法考做题三步判断法
1. 先看罪名：渎职、涉黑、寻衅滋事、强奸抢劫、五年内有故意前科 → 直接排除和解；
2. 剩余案件二选一：民间纠纷+4/5章3年以下 / 过失非渎职7年以下；
3. 同时满足悔罪、赔偿谅解、被害人自愿，才成立刑事和解。

# 刑事合计的流程

## 一、核心法条（2026法考唯一依据）
《刑事诉讼法》第289、290条
1. 第289条：公/检/法听取意见，审查和解自愿、合法，**主持制作和解协议书**（机关不盖章）。
2. 第290条（和解后分阶段处理）：
- 公安：移送起诉时**出具从宽处理建议**，无权撤案；
- 检察院：可提从宽量刑建议；情节轻微无需判刑，**可不起诉**；
- 法院：审理后**依法从宽处罚**（从轻、减轻、缓刑）。

## 二、完整流程（极简版，考场背诵）
1. **协商达成谅解**
嫌疑人/被告人悔罪、赔偿、赔礼道歉，被害人自愿谅解；公检法可主持调解协商。
2. **司法机关审查+制作和解协议**
办案机关核查无胁迫、不违法，当场制作和解协议书，双方签字。
3. **分阶段从宽处置**
- 侦查阶段：公安移送案卷，附和解材料+从宽建议书；
- 审查起诉：检察院可不起诉，或公诉时附从宽量刑建议；
- 审判阶段：法院采纳和解情节，从轻、减轻、宣告缓刑。

## 三、关键考点一句话
和解≠撤案；仅检察院可不起诉，公安只能提从宽建议；全程必须司法机关审查并出具书面和解协议才有效。
