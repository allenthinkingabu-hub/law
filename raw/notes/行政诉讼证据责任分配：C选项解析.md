# 行政诉讼证据责任分配：C选项解析

# 单独解析 C 选项

## 一、结论：C 选项**表述正确**

### 法条依据

《行政诉讼证据规定》第 4 条：公民、法人或者其他组织向人民法院起诉时，**应当提供其符合起诉条件的相应证据材料**。
原告资格（自身与被诉土地变更许可行为存在利害关系）属于法定起诉条件第一项，依法由**原告 50 户居民自行承担举证责任**。

### 本案直白拆解

50 户临近居民主张规划局变更土地用途的许可侵害自身采光、环境、房屋价值等相邻权，想要成为合格原告起诉，就必须拿出证据证明两点：

1. 自己是案涉地块周边利害关系人；

2. 被诉许可行为客观上会对自身合法权益产生实际影响。
这部分基础事实，法律要求由起诉方（原告）举证，不由被告市规划局兜底证明。

# 二、纠正你的核心误区：行政诉讼≠全部都由政府举证

## 1\. 被告（行政机关）固定举证范围（举证责任倒置核心）

被告只干一件事：**证明被诉行政行为本身合法**
也就是本案中市规划局要举证：土地性质变更许可程序合规、材料齐全、法律依据充分，许可没有违法。
即便原告拿不出任何证明行政行为违法的证据，只要被告无法自证许可合法，被告依然败诉。

## 2\. 法律强制要求原告必须举证的 3 类情形（法考必背）

1. **证明自身起诉符合法定条件**（C 选项就是这一条）
包括：原告主体资格、存在被诉行政行为、管辖法院正确等；
例外：如果被告主张原告超期起诉，**超期事实由被告举证**。

2. **起诉行政机关不作为案件**
原告要证明自己曾经向机关提交过申请（依职权履职除外）。

3. **附带行政赔偿 / 补偿请求**
原告要举证自己遭受了多少财产、人身损失。

## 3\. 一句话划分边界

- **行政行为合不合法 → 被告（政府）全包举证**

- **能不能告、有没有申请、亏了多少钱 → 原告自己举证**
