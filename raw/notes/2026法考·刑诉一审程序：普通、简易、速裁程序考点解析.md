# 2026法考·刑诉一审程序：普通、简易、速裁程序考点解析

# 一、考点定性、知识点、要点、做题方法（2026 法考・刑诉一审程序）

## 1\. 是否为法考考点

核心高频必考点，客观单选 / 多选年年考，主观案例常结合程序转化、开庭流程设问。

## 2\. 核心知识点

一审三类审理程序：**普通程序（标准完整程序）、简易程序（简化）、速裁程序（简上加简）**，三者仅基层法院可适用简易 / 速裁，中院及以上只能普通程序；区分核心：适用条件、庭审简化程度、审判组织、审限、禁止适用情形。

### 3\. 三者开庭流程核心差异（配案例）

#### （1）普通程序（所有法院通用）

1. 审判组织：**3 人合议庭**，不能独任；

2. 庭审环节：完整走完法庭调查（讯问、举证、质证、证人出庭）→法庭辩论→被告人最后陈述，环节不可省略；

3. 公诉人：必须出庭；

4. **送达**：起诉书副本**至迟在开庭10日以前**送达被告人及其辩护人；传票、通知书**至迟在开庭3日以前**送达（§187）；

5. **审限**：**受理后2个月以内宣判，至迟不得超过3个月**（重大复杂案件另有逐级延长机制）（§208）；

6. 宣判：可当庭、可择期；
案例：故意杀人、集资诈骗重大案件，被告人不认罪，全程完整举证质证，开庭半天至数日。

#### （2）简易程序（仅基层）

适用条件：事实清、证据足、**仅认罪、不认罚也可**、同意简易；3 年以上可适用。

1. 审判组织：3 年以下可独任 / 合议庭；超 3 年**必须合议庭**；

2. 庭审：简化讯问、举证质证，**法庭调查、辩论环节可简化，但不能完全取消**；必须听取最后陈述；

3. 公诉人：应当出庭；

4. **送达**：**不受**普通程序"至迟开庭10日前"的送达期限限制，可以更灵活、缩短（§216）；

5. **审限**：**20日**；可能判处**3年以上**有期徒刑的，可延长至**1个半月**（§220）；

6. 宣判：鼓励当庭，不强制；
案例：盗窃 5000 元，被告人认罪但不愿签署认罪认罚具结书，法院适用简易，快速举证，只围绕量刑辩论。

#### （3）速裁程序（仅基层，限制最严）

适用条件：基层、**可能 3 年以下、认罪认罚、同意速裁**；

1. 审判组织：**一律审判员 1 人独任**，无合议庭；

2. 庭审简化：**一般不进行法庭调查、法庭辩论**，仅听取辩护人意见、被告人最后陈述；开庭 5\-10 分钟结束；

3. 公诉人：可不出庭；

4. **送达**：同样**不受**送达期限限制（§224）；

5. **审限**：**10日**；可能判处**1年以上**有期徒刑的，可延长至**15日**（§225）；

6. 强制规则：**应当当庭宣判**；文书大幅简化；
案例：危险驾驶，血液酒精 160mg，自愿认罪认罚，赔偿谅解，速裁开庭只问量刑意见，当庭宣判拘役 1 个月。

### 4\. 完整考点要点

1. 适用层级：简易、速裁仅限基层法院；中院、高院、最高院一律普通程序；

2. 硬性门槛区分：速裁必须**认罪认罚 \+ 3 年以下**；简易只要求认罪，无 3 年上限；普通程序无认罪要求；

3. 禁止适用清单（高频坑）

    - 简易禁止：盲聋哑、精神病、重大影响、部分被告人不认罪、无罪辩护；

    - 速裁额外禁止：未成年人、未达成附带民诉和解；

4. 庭审核心区分：普通全流程；简易可简化调查辩论；速裁直接跳过调查辩论；

5. 程序转化：简易 / 速裁审理中发现不适宜，**应当转为普通程序**，不可退回更简化程序；

6. 独任制边界：速裁全独任；简易仅 3 年以下可独任；普通无独任。

### 5\. 满分做题三步法

第一步：先看法院层级，中院以上直接锁定普通程序；
第二步：核对两个关键条件：是否认罪认罚、预估刑期是否 3 年以下；
第三步：匹配庭审规则：有无法庭调查辩论、是否必须当庭宣判、审限时长，排除错误选项。

### 高频错题陷阱

1. 误以为中院可以适用简易 / 速裁；

2. 混淆简易、速裁认罪要求（速裁必须认罚）；

3. 认为速裁需要完整法庭调查；

4. 忘记简易 3 年以上必须合议庭、速裁全部独任；

5. 速裁未当庭宣判判错。

# 四、内容概括（言简意赅）

普通、简易、速裁是一审三类审理程序，依据《刑诉法》183、214、222 条，简易、速裁仅基层可用，速裁要求最严（3 年以下 \+ 认罪认罚、独任、跳过调查辩论、必须当庭宣判），简易仅需认罪、可保留庭审环节，普通程序全法院适用、完整庭审 \+ 合议庭；做题先区分法院层级，再核对认罪认罚、刑期条件，结合开庭简化、审限、宣判规则排除陷阱。
