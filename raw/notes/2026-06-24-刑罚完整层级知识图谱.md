# 刑罚完整层级知识图谱（刑法法定，无编造）

## 上级大类：刑罚（全部处罚手段）

### 同级两大分支：主刑｜附加刑

## 一、上级概念：刑罚

法院对罪犯适用的刑事处罚，分两类平行同级：主刑、附加刑。

## 二、同级概念1：主刑（只能单独判，不能叠加多个主刑）

下级5种（由轻到重）：
1. 管制
2. 拘役
3. 有期徒刑
4. 无期徒刑
5. 死刑

## 三、同级概念2：附加刑（可**附加在主刑后面**，也能**独立单独判**）

下级4种法定附加刑：
1. 罚金
2. 剥夺政治权利
3. 没收财产
4. 驱逐出境（仅外国人适用）

# 核心考点短句

1. 主刑：一案只能判1个；附加刑：可单独用、也可搭配主刑一起用。
2. 举例单独适用附加刑：轻微虚开增值税发票，只判罚金5000元，不判任何坐牢主刑。
3. 搭配适用：抢劫判5年有期徒刑，并处罚金2000元。

# 极简层级树

```
刑罚（上级）
├─ 主刑（同级）：管制、拘役、有期、无期、死刑
└─ 附加刑（同级）：罚金、剥夺政治权利、没收财产、驱逐出境
    特性：可独立适用、可附加适用
```
