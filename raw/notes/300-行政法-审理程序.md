# 300-行政法-审理程序

## 一、 第一步：纯逻辑大白话情景故事化背诵段落

案子立上之后在法庭里到底怎么开庭、怎么审、谁必须到场以及诉讼中官府认错怎么处理，全看一审审理程序的五大铁律：

**审理组织与方式实行普通与简易两套模式**：
- 重大疑难案件走**普通程序，必须由3人以上单数组成合议庭（审判员或审判员加陪审员，立案起6个月审结）**；

 - 简单案件走**简易程序，由基层法院法官一人独任审理，审限绝对锁死45天不得延长**！
	- **简易程序只收四类简单案（考场四宝）**：政府信息公开、当场开的罚单、2000元以下的行政给付、以及双方当事人白纸黑字同意简易审理的案件；电话短信简便传唤开庭；**中途一旦发现案情复杂争议大，法院直接裁定转为普通程序合议庭审理, 转为普通程序的，审限自“立案之日起”计算（6个月）**！
	- 行政行为是**当场作出**的:
		- 当场作出行政行为，就是行政工作人员**在违法现场、事发当场，不回去立案、不内部层层审批，直接当场开出处罚决定书 / 行政文书**，一手取证、一手下决定。
	- 各方当事人同意的可适用简易程序;
	- 发回重审和二审案件不得适用简易程序
	- 并非“应当”当庭宣判

**法庭上的三大专属行政规则（考场必考命脉）**：

- 第一是**行政机关负责人必须出庭应诉（告官必须见官）**：机关一把手或副职必须出庭，**绝对禁止只委托外部律师一人出庭当甩手掌柜**；重大公共利益和群体性事件一把手必须亲自出庭！

- 第二是**原则不停止执行与先予执行救济**：打官司期间原行政决定**原则上照常执行不停止**；但老百姓快吃不上饭要救命钱的（抚恤金、低保金、工伤医疗费），**原告可以申请先予执行，免交担保，对裁定不服可申请复议一次**！

- 第三是**诉讼中行政机关自我纠错改变决定（最高法解释第80条超级考眼）**：官府开庭发现自己错了主动改决定，**原告满意申请撤诉的法院裁定准许撤诉；原告不同意的，法院直接对改变后的新决定继续审理；原告要求确认旧决定违法的，法院一并审理裁判**！

被告改变被诉具体行政行为 [[《行政诉讼撤诉规定》第3条与第4条核心内容解析]]
分两大类：直接属于改变、法律拟制（视为）改变
- （1）直接属于改变（第 3 条）行政机关主动动手修改原行政行为本身：
	- 改主要事实、核心证据；
	- 改法律依据且影响定性；
	- 撤销 / 部分撤销 / 变更处理结果。

- （2）视为改变（第 4 条，法律推定算改变）行政机关没有直接修改原决定书，但通过后续行为实质消解了原行政行为效力，司法解释直接规定等同于改变原行为，共 3 种：
	- 诉讼中履行不作为的法定职责；
	- 作出补救、补偿措施；
	- 行政裁决案件中

## 二、 第二步：故事模型的考场实战运用法（考法透视与破题秒杀算法）

### 1. 命题人怎么考？（题型套路与设问形态）

在法考客观题中，一审审理程序是考查法庭实操、程序转换与撤诉规则的高频考区（3星必考），命题人通常通过以下 **4 种标准设问形态** 设坑：
*   **套路一：简易程序适用范围与审限陷阱（独任 vs 延长）**
    *   *出题特征*：交警当场罚款 200 元或者申请政府信息公开案件，法院适用简易程序由一名法官独任审理，45日内未能审结申请延长 15 日。
    *   *设问陷阱*：故意声称“简易程序经院长批准可以延长审限”或“简易程序可以由一名陪审员独任审理”。
    *   *考场破局*：**简易程序一人独任45天绝对不得延长！陪审员不能独任；审限不够或案情复杂只能裁定转普通程序**！
*   **套路二：行政机关负责人出庭应诉（一把手 vs 仅委托律师）**
    *   *出题特征*：区环保局责令某化工厂停产搬迁引发诉讼，区环保局指派法规科工作人员和一名外聘律师出庭，局长及副局长均未到庭。
    *   *设问陷阱*：声称“行政机关委托了具有代理资格的律师和工作人员出庭，符合行政诉讼出庭应诉规定”。
    *   *考场破局*：**告官必须见官！行政机关负责人（正职或副职）必须出庭应诉，不得仅委托律师出庭**！
*   **套路三：先予执行的适用范围与担保要求（抚恤金低保金 vs 免担保）**
    *   *出题特征*：原告起诉民政局要求发放最低生活保障金，申请法院裁定先予执行，民政局主张原告必须提供等额财产担保。
    *   *设问陷阱*：声称“申请先予执行必须由原告提供担保，否则法院裁定驳回申请”。
    *   *考场破局*：**先予执行救命钱免交担保！抚恤金、低保金先予执行无需提供担保，对裁定不服可申请复议一次**！
*   **套路四：诉讼中行政机关改变原行为与原告撤诉准许**
    *   *出题特征*：诉讼期间被告城管局自行撤销了原罚款决定并作出退款决定，原告不同意撤诉坚持要法院判决原罚款违法。
    *   *设问陷阱*：声称“因被告已撤销被诉行为，诉讼标的已不存在，法院应当裁定终结诉讼或裁定驳回起诉”。
    *   *考场破局*：**原告不撤诉继续审！原告不同意撤诉的，法院对改变后的行为继续审理，并对原行为一并裁判，绝不能裁定驳回起诉**！

### 2. 基于第一步，考场怎么答？（故事提取与选项秒杀算法）

读完题干后，眼睛扫描题干事实特征词，大脑直接调用第一步故事中的对应句子，按以下 **三步算法极速定项**：

*   **第 1 步·看案情与程序类型 ➔ 匹配简易程序四宝（信息公开、当场处罚、给付2000、双方同意）**
    *   看到题干“闯红灯当场罚款 / 政府信息公开未答复 / 2000元以下给付” ➔ **调用故事句**：“简易程序四类案，一人独任审理，45天审限不得延长！” ➔ **直接秒选：适用简易程序合法（秒杀多选-129、多选-130、单选-115）**！
    *   看到题干“简易程序案情复杂 / 审限不足” ➔ **调用故事句**：“发现不宜适用的，裁定转为普通程序合议庭审理！” ➔ **直接秒选：裁定转为普通程序（秒杀多选-131）**！
*   **第 2 步·审法庭出庭与保全 ➔ 锁定负责人出庭与先予执行复议**
    *   看到题干“行政机关仅委托律师出庭 / 负责人未到庭” ➔ **调用故事句**：“行政机关主要负责人或副职必须出庭应诉，禁止仅委托律师！” ➔ **直接秒杀：判定出庭主体违法**！
    *   看到题干“抚恤金低保金申请先予执行” ➔ **调用故事句**：“先予执行免交担保，对裁定不服可申请复议一次！” ➔ **直接秒选：免担保＋复议一次**！
*   **第 3 步·盯诉中改变决定 ➔ 抓原告同意撤诉裁定准许、原告不同意继续审理**
    *   看到题干“诉讼中行政机关撤销旧决定作新决定，原告申请撤诉” ➔ **调用故事句**：“原告满意申请撤诉的，法院裁定准许撤诉！” ➔ **直接秒选：裁定准许撤诉（秒杀单选-116）**！
    *   看到题干“诉中改变行政行为原告不同意撤诉” ➔ **调用故事句**：“原告不同意的对新决定继续审，对旧决定一并审理裁判！” ➔ **直接秒杀：继续审理新行为（秒杀单选-117、多选-134、单选-128）**！

## 三、 第三步：2026 现行官方法条依据与官方检索地址

### 1. 现行核心法条依据
*   **《中华人民共和国行政诉讼法》（2017修正）第 3 条、第 56 条、第 82 条、第 83 条、第 84 条（出庭应诉与简易程序）**：
    *   **被诉行政机关负责人应当出庭应诉。不能出庭的，应当委托行政机关相应的工作人员出庭**（第3条第3款）。
    *   诉讼期间，不停止行政行为的执行。但有下列情形之一的，裁定停止执行：（一）被告认为需要停止执行的；（二）原告或者利害关系人申请停止执行，人民法院认为该行政行为的执行会造成难以弥补的损失，并且停止执行不损害国家利益、社会公共利益的；（三）人民法院认为该行政行为的执行会给国家利益、社会公共利益造成重大损害的；（四）法律、法规规定停止执行的（第56条）。
    *   人民法院审理下列第一审行政案件，认为事实清楚、权利义务关系明确、争议不大的，可以适用简易程序：（一）**被诉行政行为是依法当场作出的**；（二）**案件涉及款额二千元以下的**；（三）**属于政府信息公开案件的**。除前款规定以外的第一审行政案件，**当事人各方同意适用简易程序的，可以适用简易程序**（第82条）。
    *   **适用简易程序审理的行政案件，由审判员一人独任审理，并应当在立案之日起四十五日内审结**（第83条）。
    *   人民法院在审理过程中，**发现案件不宜适用简易程序的，裁定转为普通程序**（第84条）。
*   **《最高人民法院关于适用〈中华人民共和国行政诉讼法〉的解释》（2018施行）第 80 条、第 81 条（诉讼中改变行政行为处理）**：
    *   被告在诉讼期间改变被诉行政行为，原告申请撤诉的，人民法院应当进行审查并**裁定是否准许撤诉**。
    *   **原告不申请撤诉的，人民法院应当对改变后的行政行为进行审理。原告起诉请求确认原行政行为违法的，人民法院应当就原行政行为是否违法一并进行裁判**（第80条）。
