# 刑事诉讼调解流程详解

# 统一依据

《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》（法释〔2021〕1 号）

## 一、自诉案件调解流程（仅告诉才处理、轻微自诉可调解；公诉转自诉禁止调解，第 328 条）

1. 法庭居中协商，双方自愿达成协议；

2. 法院出具**刑事调解书**，盖章；当庭付清赔偿可只做笔录不制调解书；

3. 双方**签收调解书立即生效**；签收前反悔，法院直接开庭下判决；

4. 效力后果：自诉人放弃追究被告人刑事责任，**刑事程序彻底终结**；被告人强制措施立即解除；

5. 不履行赔偿：凭调解书申请强制执行；同一事实不得再提自诉。

法条：第 328、330 条

## 二、附带民事诉讼调解流程（公诉 / 自诉附民均可，检察院提起附民除外，第 190 条）

1. 法庭调解赔偿，协议不受法定物质损失限制，可包含精神补偿；

2. 达成一致：制附民调解书；当场付清可仅做笔录签字生效；

3. 签收生效；签收前反悔，刑、民一并判决；

4. 效力区分：

    - 民事赔偿：调解书可强制执行；

    - 刑事部分**独立审理、正常定罪量刑**，调解仅作为从轻量刑情节，不消灭刑事责任。

法条：第 190、191、192 条

# 极简对比速记（2026 法考）

1. **自诉调解**：调解书签收→刑事追责消灭，案子结案；

2. **附民调解**：只解决赔钱，刑事照常判，仅量刑从轻。
