# 300-行政法-强制措施与强制执行的区分

## 一、 第一步：纯逻辑大白话情景故事化背诵段落

官府动用强制力到底属于行政强制措施还是行政强制执行，全看动手的时间点是查案事前预防还是结案事后要账：

**行政强制措施是案子没定性前的临时控制动作（查案中的临时保全与防患未然）**：
为了制止现场违法、防止销毁证据、防止危险扩大，官府在**调查处理阶段**采取的临时控制手段；
**五大法定强制措施：扣人（限制人身自由）、封门（查封财物场所）、搬走（扣押财物）、锁账户（冻结存款汇款）、以及临时检疫检验**！
**权限铁律：关人与冻结只能由法律设定（绝对法律保留），规章和红头文件连一毛钱强制措施都不能设**！

**行政强制执行是案子定性后老百姓赖账不干的强迫实现动作（结案后的强制要账）**：
处罚或决定已经生效产生了具体义务，但老百姓**到期死活不履行**，行政机关强迫其实现义务；
**五大法定强制执行：加收滞纳金每日3%（间接罚）、从银行划拨转账（直接划款）、把查封物品拿去拍卖变现（直接变现抵税）、强拆违建恢复原状（直接拆除）、以及替你清理排污雇人代履行（代履行花你的钱）**！
**权限铁律：强制执行必须且只能由法律设定，法规规章全部无权设定**！
**执行底线：不得夜间和法定节假日强行执行，严禁采取断水、断电、断气等逼迫手段**！

## 二、 第二步：故事模型的考场实战运用法（考法透视与破题秒杀算法）

### 1. 命题人怎么考？（题型套路与设问形态）

在法考客观题中，强制措施与强制执行的区分是整个行政强制法第一高频混淆考区（5星顶级必考 · T0-10 核心），命题人通常通过以下 **4 种标准设问形态** 设坑：
*   **套路一：行为性质定性混淆（查封/扣押/冻结 vs 划拨/拍卖/代履行）**
    *   *出题特征*：市监局查封涉案假药仓库、冻结嫌疑账户；税务局直接通知银行划拨存款、将扣押车辆予以拍卖。
    *   *设问陷阱*：故意声称“冻结存款属于行政强制执行，将扣押车辆拍卖属于行政强制措施”。
    *   *考场破局*：**冻结是锁住账户属于强制措施，划拨转走与拍卖变现属于强制执行**！
*   **套路二：设定权限层级对比（绝对法律保留 vs 规章零设定权）**
    *   *出题特征*：省政府规章设定扣押违规工具；或者某部委规章设定冻结涉嫌非法集资的银行账户。
    *   *设问陷阱*：声称“地方政府规章可以在上位法范围内设定查封扣押”或“部委规章有权设定冻结措施”。
    *   *考场破局*：**限制自由和冻结只能法律设！规章和红头文件连任何强制措施和执行都不能设**！
*   **套路三：拆除违建的性质界定（限期拆除决定 vs 强制拆除违建）**
    *   *出题特征*：自然资源局作出《限期拆除违法建筑决定书》，逾期未拆后城管局组织挖掘机推平违建。
    *   *设问陷阱*：声称“责令限期拆除决定属于行政强制措施，挖掘机强拆属于行政处罚”。
    *   *考场破局*：**限期拆除决定是基础行政决定，后面的强拆属于排除妨碍恢复原状的行政强制执行**！
*   **套路四：代履行的适用范围与实施底线**
    *   *出题特征*：行政机关对不缴纳罚款的当事人采取代履行；或者在凌晨 2 点强行对居民住宅断电断水实施强拆。
    *   *设问陷阱*：声称“代履行适用于一切不履行金钱给付义务的案件”或“紧急情况下行政机关可以夜间采取断电执行”。
    *   *考场破局*：**代履行只适用于排除妨碍、恢复原状及环境污染治理等可替代行为！严禁夜间、节假日及断水断电强制执行**！

### 2. 基于第一步，考场怎么答？（故事提取与选项秒杀算法）

读完题干后，眼睛扫描题干事实特征词，大脑直接调用第一步故事中的对应句子，按以下 **三步算法极速定项**：

*   **第 1 步·看行为发生时间与动作 ➔ 区分“过程临时控制” vs “事后强迫履约”**
    *   看到题干“现场带离盘问 / 查封假酒 / 扣押车辆 / 冻结涉案账户” ➔ **调用故事句**：“扣人、封门、搬走、锁账户，通通是查案中的行政强制措施！” ➔ **直接秒选：行政强制措施（秒杀单选-70、单选-71、单选-72）**！
    *   看到题干“逾期不交加处 3% 滞纳金 / 划扣银行存款 / 拍卖扣押物 / 强拆违建 / 雇人代清垃圾” ➔ **调用故事句**：“加处罚款、划拨款项、拍卖变现、强拆违建、代履行，属于行政强制执行！” ➔ **直接秒选：行政强制执行（秒杀多选-73、多选-74）**！
*   **第 2 步·审设定主体 ➔ 抓“人身自由与冻结仅限法律”、“规章零设定权”**
    *   看到题干“规章或红头文件设定查封扣押 / 冻结” ➔ **调用故事句**：“规章和红头文件连一毛钱强制措施和执行都不能设！” ➔ **直接秒杀：设定违法（秒杀单选-74、多选-72）**！
    *   看到题干“行政法规或地方性法规设定限制人身自由或冻结账户” ➔ **调用故事句**：“关人与冻结只能由法律设定，绝对法律保留！” ➔ **直接秒杀：设定无效**！
*   **第 3 步·盯执行底线与代履行 ➔ 抓禁止夜间断水断电、代履行可替代性**
    *   看到题干“夜间强拆 / 采取停水停电停气逼迫履行” ➔ **调用故事句**：“严禁夜间和法定节假日执行，严禁断水断电！” ➔ **直接秒杀：程序严重违法**！
    *   看到题干“对金钱给付义务适用代履行” ➔ **调用故事句**：“金钱债务走划拨与拍卖，代履行只管修路补绿清垃圾等可替代行为！” ➔ **直接秒杀：代履行适用错误**！

## 三、 第三步：2026 现行官方法条依据与官方检索地址

### 1. 现行核心法条依据
*   **《中华人民共和国行政强制法》（2012施行）第 2、9、10、12、13、43 条（强制措施与执行全景规范）**：
    *   行政强制措施，是指行政机关在行政管理过程中，为制止违法行为、防止证据损毁、避免危害发生、控制危险扩大等情形，依法对公民的人身自由实施**暂时性限制**，或者对公民、法人或者其他组织的财物实施**暂时性控制**的行为（第2条第2款）。
    *   **行政强制措施的种类**：（一）限制公民人身自由；（二）查封场所、设施或者财物；（三）扣押财物；（四）冻结存款、汇款；（五）其他行政强制措施（第9条）。
    *   **尚未制定法律，且属于国务院行政管理职权事项的，行政法规可以设定除本法第九条第一项、第四项和应当由法律规定的行政强制措施以外的其他行政强制措施。尚未制定法律、行政法规，且属于地方性事务的，地方性法规可以设定本法第九条第二项、第三项的行政强制措施。法律、法规以外的其他规范性文件不得设定行政强制措施**（第10条）。
    *   **行政强制执行的种类**：（一）加处罚款或者滞纳金；（二）划拨存款、汇款；（三）拍卖或者依法处理查封、扣押的场所、设施或者财物；（四）排除妨碍、恢复原状；（五）代履行；（六）其他强制执行方式（第12条）。
    *   **行政强制执行由法律设定**（第13条）。
    *   **行政机关不得在夜间或者法定节假日实施行政强制执行**。但是，情况紧急的除外。**行政机关不得对居民生活采取停止供水、供电、供热、供燃气等方式迫使当事人履行相关行政决定**（第43条）。
