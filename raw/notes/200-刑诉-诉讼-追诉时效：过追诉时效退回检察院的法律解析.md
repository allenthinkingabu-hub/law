# 法考追诉时效：过追诉时效退回检察院的法律解析

我用**法考精准、极简、不绕弯**的方式给你讲透，完全对应你文档那句「**过追诉时效→退回检察院**」。

# 一、什么是「过追诉时效」

简单一句话：
**犯罪发生太久，超过了法律规定的「可以抓人、起诉、判刑」的最长有效期。**

法律默认：
时间太久、证据灭失、社会关系恢复、没必要再追责 → **不再追究刑事责任**。

# 二、追诉时效四档（直接背）

- 最高刑＜5 年 → 过**5 年**不追

- 最高刑＜10 年 → 过**10 年**不追

- 最高刑 10 年以上 → 过**15 年**不追

- 死刑 / 无期 → 过**20 年**不追 ,故意杀人追诉期 20 年：原则上过期不再追诉；唯一例外，报最高检核准才能继续追究，不是一过 20 年就绝对免责。

# 三、为什么法院要「退回检察院」？（对应你文档考点）

法院庭前审查时发现：
**这个案子早就过期了，法律上不能判刑、不能追责。**

检察院还硬起诉过来，属于**违法起诉**。
所以法院处理规则：
**还没开庭＝直接退回检察院**
（已经开庭了才发现＝终止审理）

# 四、全阶段处理口诀（必考）

- 侦查阶段过期 → **撤案**

- 审查起诉过期 → **不起诉**

- **庭前阶段过期 → 退回检察院（你现在记的这条）**

- 审理中过期 → **终止审理**

# 五、两个例外（不过期）

1. **立案后逃避侦查** → 永久不过期

2. **被害人控告、公检法该立案不立案** → 永久不过期

只要题干：**案发多年、远超对应年限、无逃避侦查**
→ 就是「过追诉时效」
→ 庭前发现：**退回检察院**
