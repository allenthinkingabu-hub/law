# 刑事管辖之级别管辖详解

# 一、管辖整体概念（刑诉）

刑事管辖 = 划分两件事：

1. **立案管辖（职能管辖）**：公安、检察院、法院、监察委谁来立案侦查 / 直接受理；

2. **审判管辖**：案件起诉到法院后，**哪一级、哪个地区、何种专门法院**一审审理。

你提问的「基层管辖」属于**审判管辖 → 级别管辖**分支。

# 二、级别管辖（纵向：四级法院分工，含基层法院详解）

法条：《刑诉法》第 20～23 条

## 1\. 基层人民法院（核心：你要的基层管辖）

法条原文：**基层人民法院管辖第一审普通刑事案件，但是依照本法由上级人民法院管辖的除外**。

### 完整解读

1）管辖范围：绝大多数轻罪、常规普通刑事案件（盗窃、故意伤害轻伤、诈骗、诽谤自诉等）；
2）排除情形：只要属于中院、高院、最高法一审范围，基层一律无权管；
3）简易 / 速裁程序硬性门槛：**必须基层法院一审**，中院及以上不能适用简易、速裁；
4）审理组织规则：

- 预估刑期≤3 年：可独任（1 名法官）；

- 预估刑期＞3 年：必须合议庭合议。

## 2\. 中级人民法院（口诀：危恐无死）

一审必归中院：
①危害国家安全、恐怖活动；
②可能判处无期、死刑；
③违法所得没收、缺席审判两类特殊案件。

## 3\. 高级人民法院

全省、自治区、直辖市范围内**重大刑事案件**一审。

## 4\. 最高人民法院

全国性重大刑事案件一审。

## 级别管辖三大核心规则

1. **上可审下**：上级法院可主动提审下级案件；

2. **下不可审上**：基层绝对不能审理法定归中院及以上的案件；

3. **就高不就低**：一人多罪、共同犯罪，只要一罪 / 一人归中院，全案统一中院审理。

# 三、地域管辖（横向：同级法院谁来审）

法条第 25 条

1. **原则**：犯罪地法院优先（犯罪行为实施地、犯罪结果发生地都算犯罪地）；

2. **补充**：被告人居住地更适宜审理，可由居住地管辖；

3. **多法院都有管辖权**：由**最初受理法院**审判；必要时移送主要犯罪地法院；

4. 管辖冲突、管辖不明 → 走**指定管辖**，上级法院指定某一法院审理。

# 四、专门管辖

专门法院专属案件，不和普通基层 / 中院争抢：

1. 军事法院：现役军人、军内在编职工犯罪；

2. 铁路运输法院：铁路沿线、列车上发生犯罪；

3. 海事法院、知识产权法院等对应专属案件。

# 六、做题判断流程（快速锁定是否基层管辖）

1. 第一步级别筛选：是否危恐无期死刑？是→中院，**不能基层**；

2. 第二步程序判断：要走简易 / 速裁 → 必须基层法院；

3. 第三步地域匹配：确定犯罪地 / 居住地基层法院；

4. 兜底：不属于中院、高院、最高法的普通犯罪，一律基层管辖。

# 七、高频考点一句话总结

基层管辖是普通刑事案件默认一审法院；简易、速裁程序**唯一合法审理法院**；只要案件法定归中院及以上，基层无管辖权，不能适用简化程序。
