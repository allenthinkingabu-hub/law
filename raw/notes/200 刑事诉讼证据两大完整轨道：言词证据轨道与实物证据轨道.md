# 刑诉证据两大完整轨道：言词证据轨道、实物证据轨道

## 总前提

判断标准：**看证据核心内容，不看载体**

1. 内容是**人的主观陈述、专业判断** → 走【言词证据轨道（人证轨道）】

2. 内容是**客观物品、机器自动留存信息、客观现场记录** → 走【实物证据轨道（物证轨道）】
两条轨道从**侦查取证→审查起诉→庭审质证→采信定案**全程规则完全分开，流程步骤独立。

# 一、轨道 1：言词证据轨道（完整全流程步骤）

包含四类：证人证言、被害人陈述、被告人供述辩解、鉴定意见；讯问 / 询问同步录音录像也归这条轨道。

## 步骤 1：侦查取证阶段（专属取证方式）

1. 取证手段：讯问、询问、组织鉴定、辨认

2. 强制程序要求（缺一容易直接排除）

    - 必须**个别问话**，不能多人一起询问；

    - 未成年人讯问 / 询问，法定代理人 / 合适成年人到场；

    - 聋哑、不通晓当地语言，必须配翻译；

    - 全程可同步录音录像（录像仅证明取证程序合法，不能替代笔录）；

    - 笔录做完必须交当事人阅读、核对、签字捺印。

3. 违法后果：刑讯、威胁、引诱、欺骗获取的言词证据，**直接非法排除**。

## 步骤 2：审查起诉阶段（检察院审核）

1. 核对笔录签字、同步录像完整性；

2. 审查取证地点、时长是否存在疲劳审讯；

3. 核查前后多份笔录有无重大矛盾；

4. 有疑点退回公安补充取证，或提前通知证人、鉴定人预备出庭。

## 步骤 3：庭审阶段（核心专属流程，法考高频）

### 3\-1 出庭规则（轨道独有）

1. 证人：满足出庭三要件（有异议、对定罪量刑重大、法院认为必要）应当出庭；无正当理由拒不出庭**可强制拘传**，庭前证言无法核实排除；

2. 鉴定人：有异议 \+ 法院认为必要应当出庭；**不得拘传**，拒不出庭直接排除整份鉴定意见。

### 3\-2 当庭出示质证

笔录、同步录像当庭播放，控辩双方针对**陈述真实性、取证合法性**交叉发问。

### 3\-3 补强规则（实物轨道无此规则）

- 仅有被告人供述，无其他证据印证，**不能单独定罪**；

- 年幼、精神缺陷证人证言，证明力弱，需其他证据印证。

## 步骤 4：法庭采信、定案规则

1. 轻微瑕疵（侦查人员漏签名、时间笔误）：可补正、出具说明后采信；

2. 严重程序瑕疵（未核对签字、无翻译、刑讯）：**绝对排除，无法补救**；

3. 仅靠单份言词孤证，无实物证据印证，不能作为唯一定案依据。

## 一句话走完轨道流程

讯问 / 询问取证（保证签字、录像、个别询问）→ 检察院核查笔录矛盾 → 开庭通知证人 / 鉴定人出庭接受质询 → 审查是否需要补强印证 → 合法且有印证才可采信定案。

# 二、轨道 2：实物证据轨道（完整全流程步骤）

包含：物证、书证、勘验 / 检查 / 侦查实验笔录、视听资料、电子数据（监控、行车记录仪等现场自动录像）。

## 步骤 1：侦查取证阶段（专属取证方式）

1. 取证手段：搜查、扣押、提取、现场勘验、封存原始电子设备；

2. 核心要求：**完整保管链条**（鉴真规则）

    - 必须制作提取笔录、扣押清单，侦查人、持有人、见证人三方签字；

    - 原物原件优先；不便提取才可拍照、复制，注明与原件一致；

    - 电子数据封存原始介质，记录哈希校验值，防止篡改。

3. 违法后果：仅来源不明、保管断裂无法合理解释才排除；单纯手续漏签属于瑕疵，可补正。

## 步骤 2：审查起诉阶段

1. 核对提取清单、封存记录、保管流转记录；

2. 核对复制品、照片是否能还原原物特征；

3. 痕迹、物证及时委托鉴定，对接言词证据形成印证。

## 步骤 3：庭审阶段（专属流程，和言词轨道区分）

1. **无强制出庭主体**，不需要物品、监控 “出庭”，当庭出示原物 / 原件、播放原始视频即可；

2. 无需补强规则：只要来源完整、真实，**单独一份监控、凶器即可直接定罪**；

3. 质证只审查三点：来源是否清晰、有无篡改、与案件是否有关联。

## 步骤 4：法庭采信、定案规则

1. 笔录漏签字、标注不清等小瑕疵：补签字、出具情况说明即可采信；

2. 绝对排除情形：无任何提取笔录、保管链条断裂、被篡改且无法合理解释、复制品无法和原物核对；

3. 无需其他证据辅助，真实完整的实物证据可单独定案。

## 一句话走完轨道流程

现场勘验 / 扣押封存，制作完整提取清单 \+ 见证人签字 → 检察院核查保管链条完整性 → 法庭出示原物、原始视频核对真伪 → 来源清晰无篡改直接采信，孤证亦可定案。

# 三、两大轨道核心流程对比速记

|流程环节|言词证据轨道|实物证据轨道|
|---|---|---|
|取证核心要求|必须当事人核对签字、个别问话、禁止刑讯|完整保管链条、见证人、原物原件优先|
|出庭义务|证人可拘传、鉴定人拒不出庭直接废意见|无物品出庭要求，无需强制任何人到庭|
|孤证效力|孤口供、弱势证言不能单独定罪|真实完整可单独作为定案依据|
|排除规则|未签字、无翻译、刑讯一律绝对排除|仅来源断裂、篡改无法解释才排除|
|载体影响|哪怕录视频，仍走言词一套流程|现场监控天然属于实物轨道|
