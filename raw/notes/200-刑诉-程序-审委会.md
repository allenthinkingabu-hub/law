# 2026年刑事诉讼法审委会制度详解

# 一、核心法条（2026 现行有效）

1. **《刑事诉讼法》第 185 条**（基础法条）
合议庭开庭审理并且评议后，应当作出判决。对于疑难、复杂、重大的案件，合议庭认为难以作出决定的，由合议庭提请院长决定提交审判委员会讨论决定。审判委员会的决定，合议庭应当执行。

2. **配套硬性强制报审规则（最高法审委会制度意见）**
中院、高院拟判处死刑立即执行；本院生效裁判有错再审、检察院再审抗诉、拟判无罪、法定刑以下量刑 / 免罚案件，**应当提交审委会**。

3. **《人民法院组织法》第 37 条**：审委会是法院内部最高审判组织，只讨论法律适用、再审启动、审判重大事项，不开庭审理案件。

# 二、审委会完整知识图谱（法考全覆盖）

## 1\. 主体定位

法院内部最高审判组织；不参与庭审、不质证、不接触当事人，仅内部书面评议。

## 2\. 法定提交流程（四阶不可逆，命题核心坑）

案件疑难 / 复杂 / 重大 → 合议庭评议后自认无法定夺 → **合议庭提请** → **院长决定是否提交** → 审委会讨论表决 → 合议庭必须遵照审委会结论下判
禁止情形：合议庭无权直接报送、院长不能跳过合议庭直接报审委会。

## 3\. 两类案件划分（必考区分 “可以 / 应当”）

1）可以提交（裁量型）：普通疑难重大、合议庭分歧大、新类型案件，走上面流程报审；
2）应当提交（强制型）：拟判死立执、本院再审、检察院再审抗诉、拟无罪、降格量刑 / 免罚，无选择空间必须报审。

## 4\. 表决与效力规则

审委会评议少数服从多数；决议效力高于合议庭意见，合议庭无拒绝执行权利；少数意见记入审委会笔录，不写入判决书。

## 5\. 易混边界

独任庭审理疑难案件，同样适用 “提请院长报审委会” 流程；一审、二审、再审、死刑复核案件均可报审委会。

# 四、一段式内容概括 \+ 做题判断方法

依据《刑诉法》第 185 条，审委会是法院内部最高审判组织，不开庭审理；疑难复杂重大案件合议庭难以决断时，需由合议庭提请院长，经院长决定后方可提交审委会讨论，审委会作出的决定合议庭必须执行；拟判死刑立即执行、再审、抗诉等案件依法应当报审委会，其余普通重大案件仅可裁量报审；做题时紧盯三步法定流程（合议庭提请→院长审批→审委会决议），区分 “应当提交” 与 “可以提交” 两类案件，牢记审委会不开庭、合议庭不得违背审委会裁判意见。
