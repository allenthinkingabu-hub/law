# 2026法考刑事诉讼法程序违法核心考点解析

# 一、考点定性、知识点、场景、做题要点（2026 法考，刑诉）

## 1\. 是否为法考核心考点

是刑诉**高频必考点**，客观单选 / 多选、主观案例二审、再审设问常年考查。

## 2\. 核心知识点

程序违法：公检法办案违反《刑事诉讼法》法定流程、制度、权利保障规则；分为**严重程序违法（刚性制裁）、轻微程序瑕疵（可补正）**；二审遇一审严重程序违法，**应当撤销原判、发回重审**，不受事实实体对错影响。

### 法条总依据

1. 程序法定原则：《刑诉法》第 3 条第 2 款

2. 二审程序违法发回重审：《刑诉法》第 238 条（2023 修正现行有效）
官方法条链接：[http://www\.sdcourt\.gov\.cn/lyjnfy/396881/613978/24063098/index\.html](http://www.sdcourt.gov.cn/lyjnfy/396881/613978/24063098/index.html)

## 3\. 法定 5 大类严重程序违法场景（第 238 条）

1. 违反公开审判：应公开不公开、涉密 / 未成年案件违规公开、限制旁听

2. 违反回避制度：应回避未回避、违法驳回回避申请、发回后原合议庭继续审理

3. 剥夺 / 限制当事人法定诉讼权利，且可能影响公正审判：不告知辩护权、不提供法援、剥夺最后陈述、禁止质证、不告知上诉权、非法拒绝调取证据

4. 审判组织组成不合法：合议庭人数错误、人民陪审员适用违规、独任审超范围

5. 其他严重程序违法：应当排非而拒不排除非法证据、剥夺辩护律师阅卷会见权、庭审关键证据未质证直接定案

## 4\. 完整考点要点 \+ 做题步骤

### 核心规则

1. 严重程序违法：二审**应当**发回，不受发回次数限制；事实不清发回仅限 1 次，二者区分是高频陷阱

2. 轻微程序瑕疵（笔录笔误、文书小疏漏）：不发回，法院当庭补正即可

3. 程序违法独立效力：哪怕实体事实、证据完全正确，只要属于 238 条五类情形，必须撤销原判发回，不能改判、不能维持

4. 再审程序：原审存在严重程序违法，法院应当启动再审（《刑诉法》第 253 条）

### 满分做题三步法

第一步：定性区分：轻微瑕疵 / 法定五类严重程序违法；
第二步：匹配法条：属于 238 条情形→直接锁定 “应当撤销、发回重审”；仅事实不清→可发回 / 可改判；
第三步：规避陷阱：程序违法发回无次数限制；事实不清发回仅一次；程序违法不能直接改判。

### 高频错题陷阱

1. 混淆 “程序违法发回” 与 “事实不清发回” 的次数限制；

2. 认为实体正确就不用纠正程序违法；

3. 轻微文书笔误错误认定为程序违法、主张发回；

4. 程序违法情形下误选 “改判、维持原判”。

# 四、内容概括（言简意赅）
