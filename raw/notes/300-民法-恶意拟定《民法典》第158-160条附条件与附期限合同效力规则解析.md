# 二、分两层清晰结论，纠正模糊理解

## 1、区分合同是【附生效条件】还是【附解除条件】，拟制后果完全不同

### 情形 1：合同约定**附生效条件**（条件成就合同才生效）

一方为自身利益**不正当阻止条件成就** → 依据 159 条视为条件已成就 → **合同直接生效**，守约方可主张对方履行、承担违约责任。
举例：甲乙约定 “乙考上证书，甲卖房”，甲故意销毁考试报名材料阻止乙考试，视为条件成就，房屋买卖合同生效，甲必须卖房。

### 情形 2：合同约定**附生效条件**，一方**不正当促成条件成就**

视为条件不成就 → **合同不生效**，恶意方无权要求履行合同。
举例：约定 “乙离职则甲卖房”，乙贿赂公司辞退自己，属于恶意促成，视为条件未成就，合同不生效，甲不用卖房。

### 情形 3：合同是【附解除条件】（合同本来已生效，条件成就才失效）

- 恶意阻止解除条件成就：视为条件已成就 → 合同失效；

- 恶意促成解除条件成就：视为条件不成就 → 合同继续有效。

## 2、核心关键限制（考场必踩陷阱）

1. **159 条恶意拟制只适用于附条件，附期限完全不适用**
期限是必然到来的客观时间，人为无法阻止、加速，不存在 “拟制提前 / 延后到期”，无论怎么恶意操作，只能等时间自然届至，不会发生效力拟制。

2. 拟制生效有两个硬性前提，缺一不可：
①合同属于**附条件**（不是附期限）；
②行为人同时满足「为自己获利 \+ 手段不正当」双要件，单纯客观阻碍不算恶意拟制。

3. 前置基础：合同本身必须已经成立、满足 143 条有效三要件，仅差条件未成就；若合同本身违法、主体不适格，即便拟制条件成就，合同依旧无效。

# 三、考场速记短句

附生效条件：恶意阻止→拟制条件成就→合同生效；恶意促成→拟制条件不成就→合同不生效；附期限不存在任何恶意拟制。
