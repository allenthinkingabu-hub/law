你是想让我把"被告人的诉讼权利"这几个具体权利列出来吧？我按刑诉法体系给你列全，这些就是诉讼代表人**享有**、被害单位/附带民事诉讼原告单位**也部分共享**的那些具体权利。

## 被告人（及诉讼代表人代为行使）的诉讼权利清单

| 权利 | 具体内容 |
|---|---|
| **辩护权** | 自行辩护、委托辩护人（可以拒绝不认可的律师） |
| **申请回避权** | 认为审判人员、检察人员、侦查人员、书记员、鉴定人、翻译人员与本案有利害关系的，可申请回避 |
| **陈述与申辩权** | 对指控事实和罪名有无异议时可以陈述、申辩 |
| **发问权** | 经法庭准许，可以向证人、鉴定人发问 |
| **举证质证权** | 可以出示证据、对控方证据进行质证 |
| **参加庭前会议权** | 就回避、证人名单、非法证据排除等发表意见 |
| **上诉权** | 不服一审判决、裁定，可以提起上诉（不加刑保障） |
| **最后陈述权** | 评议前独立必经、**不可剥夺**的陈述机会 |
| **申请重新鉴定/勘验权** | 对鉴定意见有异议的，可以申请补充鉴定或者重新鉴定 |
| **拒绝强迫自证其罪的权利** | 不得强迫任何人证实自己有罪 |

## 被害人一方（被害单位、附带民事诉讼原告单位）的诉讼权利，是**不完全等同**的另一套

被害人一方不是"被告人权利"的镜像复制，核心几项是：

| 权利 | 具体内容 |
|---|---|
| **委托诉讼代理人权** | 自案件移送审查起诉之日起可以委托 |
| **陈述权** | 就案件情况向公安、检察、法院陈述 |
| **申请回避权** | 与被告人一样享有 |
| **申请抗诉权** | 对一审判决不服的，**没有独立上诉权**，只能请求检察院抗诉（这是与被告人上诉权的**关键区别**，常考陷阱） |
| **提起附带民事诉讼权** | 因犯罪行为遭受物质损失的 |
| **参与法庭调查、辩论权** | 可以对证据发表意见、参与量刑辩论（前几轮讲过的量刑辩论顺序里，被害人排在被告人辩护人**之前**发言） |

**一句话区分记忆**：被告人有**上诉权**，被害人**没有独立上诉权、只能申请抗诉**——这是两套"诉讼权利"清单里最容易被拿来出题的核心差异点。
