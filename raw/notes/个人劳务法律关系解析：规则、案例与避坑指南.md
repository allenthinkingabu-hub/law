# 个人劳务法律关系解析：规则、案例与避坑指南

# 一、什么是【个人劳务】（大白话）

**个人劳务 = 个人找个人干活，不是公司招工、不签劳动合同、不交社保**
两边都是自然人（普通人），一方出钱 / 受益（接受劳务方，俗称雇主），一方出力干活（提供劳务方，工人）。

> 区分：公司聘请员工 → 劳动关系（走工伤保险、§1191）；
> 个人之间临时帮忙、雇人 → 个人劳务（§1192）
> 
> 

✅典型：雇家政阿姨上门打扫、雇个人装修、临时找人搬家；
❌不属于：去物业公司上班、工厂打工（单位用工，劳动关系）

> 帮工：属于个人劳务同类模型，**无偿**！邻里之间免费帮忙，不收工钱（比如免费帮邻居搬家）
> 
> 

# 二、表格整套规则拆解 \+ 实例（大白话）

> 法条：《民法典》第 1192 条
> 两套场景一定要分开：①干活伤到外人；②干活自己受伤
> 
> 

## 场景 1：提供劳务，伤到外面第三人（对外侵权）

规则：**接受劳务方（雇主）承担无过错替代责任**
大白话：工人干活闯祸伤到别人，对外由雇主赔钱；就算雇主管理很规范、没有任何过错，对外照样赔。
内部：工人有**故意 / 重大过失**，雇主赔完之后，可以回头找工人追偿。

👉例子：甲（业主，接受劳务）临时雇乙（个人）擦玻璃。乙擦窗失手，工具掉落砸伤楼下路人丙。

1. 对外：路人丙直接找甲赔钱，甲就算反复提醒乙注意安全（甲无过错），依然要赔（无过错替代）

2. 内部：如果乙故意扔工具、严重违规操作（重大过失），甲赔完丙，可以起诉乙，向乙追偿。

## 场景 2：提供劳务，干活时**自己受伤**

规则：**双方按照各自过错分担损失（过失相抵）**
大白话：工人自己摔伤，不再雇主全包！法官分别看双方谁有错，按过错比例分摊医药费。

👉例子：甲雇乙擦外墙玻璃，甲没有提供安全绳索；乙图省事，不系安全带，失足坠落摔伤。
甲过错（没给防护装备），乙过错（违规不防护），法院划分比例：甲承担 40%，乙自己承担 60%。

## 补充：无偿帮工（无工钱的个人劳务）

规则：帮工人受伤，由受益人给予**合理补偿**
👉例子：乙免费帮邻居甲搬家（不收钱，帮工），搬柜子扭伤腰。甲作为受益人，给乙适当补偿。

# 三、法考必背一句话区分

1. 个人劳务 → 工人伤到外人：雇主对外兜底（无过错替代），工人重大过失可内部追偿

2. 个人劳务 → 工人自己受伤：看双方过错，按比例分摊（过失相抵）

3. 无偿帮工：帮工人受损，受益人合理补偿

# 四、高频避坑

❌误区：只要雇了人干活，工人受伤老板全赔
✅正解：仅限【对外伤别人】老板兜底；**工人自己受伤，各自看过错分摊**！
❌误区：个人劳务 = 劳动关系
✅正解：一方是公司才是劳动；两边都是自然人临时用工，才是个人劳务。
