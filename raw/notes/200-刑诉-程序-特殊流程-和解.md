# 2026法考刑事诉讼特别程序和解制度知识点解析

## 第一步：知识点释义 \+ 2026 法考做题实操

### 核心要点

和解分两类：
- 1\. 公诉案件特别程序和解（专属）；
- 2\. 自诉自行和解。公诉和解是公检法全阶段当事人自愿协商、办案机关审查出具和解协议，**仅作为从宽量刑情节，不能直接终结刑事程序**；自诉和解可撤诉结案。
公诉和解硬性四要件：

①案件范围：民间纠纷四 / 五章 3 年以下轻罪、非渎职 7 年以下过失犯罪；

②被告人真诚悔罪、赔偿 / 道歉获被害人谅解；

③双方自愿；

④五年内无故意犯罪前科。

5,和解可以作为从宽处罚的情节，但不等于判无罪。无论自诉还是公诉，达成和解都不必然导致无罪判决

6,自诉案件的当事人在宣告判决前，可以自行和解或者由自诉人撤回自诉

**绝对排除：涉黑、寻衅滋事、渎职、五年内故意犯罪**。




区分边界：调解 = 法院居中、仅两类自诉可用、可结案；和解 = 当事人自主协商，公诉仅从宽、自诉可撤诉；撤诉仅自诉宣判前可行。

### 做题判断四步

1. 分案件：公诉只走和解、禁止调解；三类自诉均可和解，仅公诉转自诉禁调解；

2. 核对范围：不符合民间纠纷 / 罪名 / 刑期、五年内有故意前科，直接排除公诉和解；

3. 区分效力：公诉和解仅从轻，不能撤案、不能终止审判；自诉和解可撤诉；

4. 区分主体：无法院居中只是双方协商 = 和解；法院主持 = 调解。
命题陷阱：公诉和解可直接撤诉、公诉转自诉能调解、五年内故意犯罪仍可和解、和解等同于调解。

## 第二步：考情、考频、分数

考频：S 级高频，特别程序核心考点，每年客观多选必考，主观案例程序改错、量刑情节高频设问；
分值：客观 2 分，主观 1–3 分；
命题核心：混淆公诉和解与自诉和解、混淆和解与调解、漏记适用范围与禁止情形、混淆二者法律效力。
