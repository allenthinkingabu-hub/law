# 一、知识点释义 + 2026法考做题实操

**认罪认罚从宽制度**：犯罪嫌疑人、被告人自愿如实供述自己的罪行，承认指控的犯罪事实，愿意接受处罚的，可以依法从宽处理。贯穿**侦查—审查起诉—审判**全流程，核心动作是签署"**认罪认罚具结书**"，核心法律效果是量刑上"**可以从宽**"、程序上可适用简易/速裁程序。

**做题抓手——先分清"认罪"≠"认罚"**：
- 只认罪、不接受量刑建议（不认罚）→ **不适用**认罪认罚从宽的程序性优惠（不能签具结书走速裁）
- 认罪+认罚（签具结书、同意量刑建议）→ 从宽处理，且**法院一般应当采纳**检察院的量刑建议

**核心考点：法院不是无条件采纳量刑建议**。存在法定除外情形（依据《刑诉法》第201条）：
① 被告人的行为不构成犯罪或者不应当追究刑事责任的；
② 被告人违背意愿认罪认罚的；
③ 被告人否认指控的犯罪事实的；
④ 起诉指控的罪名与审理认定的罪名不一致的；
⑤ 其他可能影响公正审判的情形。

出现以上任一情形，法院可以**依法审理后判决**，不受量刑建议约束；量刑建议明显不当的，检察院可以调整，调整后仍明显不当的，法院照样可以直接判。

# 三、知识图谱

```
上级：刑事诉讼法 → 基本原则（与"证据裁判原则""无罪推定"同级并列）
  │
  └── 认罪认罚从宽制度（《刑诉法》第15条确立为基本原则）
       │
       ├─ 同级（并列的贯穿全程程序机制/相邻易混考点）
       │    ├─ 坦白（被动到案后如实供述，不要求"认罚"）
       │    ├─ 自首（主动投案+如实供述，只发生在侦查阶段被抓获前）
       │    └─ 不起诉裁量权（检察机关处分权，可与认罪认罚结合，但制度目的不同）
       │
       └─ 下级（认罪认罚制度自身的实施环节，层层递进）
            ├─ 具结书签署环节（侦查/审查起诉阶段，须辩护人或值班律师在场）
            ├─ 量刑建议提出与调整规则
            ├─ 法院采纳规则（一般应当采纳＋第201条五项除外）
            └─ 程序适用分流：
                 ├─ 简易程序（不要求"认罚"，仅需事实清楚+对适用无异议）
                 └─ 速裁程序（要求认罪+认罚+同意适用+可能判三年以下）
```

# 四、一段话概括及做题方法

认罪认罚从宽是贯穿全程的基本原则（《刑诉法》§15），做题先判断题干是否同时满足"认罪+认罚"两个要件——缺一个就不能适用该制度的程序优惠；再看是否涉及量刑建议采纳，遇到"法院必须无条件采纳量刑建议"这类表述直接判错，因为§201列了五项除外情形（不构罪/违背意愿/否认事实/罪名不一致/其他影响公正审判的情形），检察院还可以调整量刑建议，调整后仍不当法院可径行判决；最后注意区分认罪认罚、坦白、自首、简易程序、速裁程序这几个易混概念，坦白/自首不要求"认罚"，简易程序不要求"认罚"，只有速裁程序和认罪认罚从宽绑定最紧（认罪+认罚+同意适用+刑期三年以下）。
