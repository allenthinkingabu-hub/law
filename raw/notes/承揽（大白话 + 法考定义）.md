# 承揽（大白话 \+ 法考定义）

## 法条依据

《民法典》第 770 条：承揽合同是承揽人按照定作人的要求完成工作，交付工作成果，定作人支付报酬的合同。承揽包括加工、定作、修理、复制、测试、检验等工作。
官方地址：[http://www\.npc\.gov\.cn/zgrdw/npc/xinwen/2020](http://www.npc.gov.cn/zgrdw/npc/xinwen/2020)‑05/28/content\_561349\.htm

## 大白话解释

**定作人提要求，最后验收成品给钱；承揽人自己决定怎么做、什么时候干，自带工具、自主安排，独立交出一个 “完工成果”。核心：买【干活结果】，不是买【你的劳动过程】。**

### 典型承揽例子

1. 找师傅定制不锈钢防盗窗（交付做好的窗户）

2. 送手机到维修店修屏幕（交付修好的手机）

3. 找摄影师拍摄婚纱照（交付成片照片）

4. 找装修包工队整装（交付完工的装修房屋）

## 核心特征（用来区分个人劳务 / 雇佣，法考重中之重）

1. ✅ 看重**最终成果**：没做出合格成品，可以不给钱；

2. ✅ **高度独立**：承揽人自己安排工期、操作方式，不受对方全程指挥管控；

3. ✅ 大多自备工具设备；

4. ✅ 风险自担：干活过程摔伤、砸到人，原则承揽人自己负责（§1193）

## 对比区分（极易混淆）

- **承揽：买结果** → 定做衣柜，做好交付才算完成，师傅怎么锯木头你不管

- **个人劳务（雇佣）：买过程** → 雇工人帮你搬运家具，全程听你指挥，按干活时长结算

## 法考一句话速记

承揽求成果，干活自主管；出事自己担，定作有错才赔偿。

> 拓展侵权规则回顾：承揽人致人损害 / 自身受伤，**原则自担；定作人仅在定作、指示、选任有过错，承担相应责任**。
