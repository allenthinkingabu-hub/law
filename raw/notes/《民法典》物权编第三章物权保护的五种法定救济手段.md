# 《民法典》物权编第三章物权保护的五种法定救济手段

这是《民法典》物权编第三章 “物权的保护” 里的**5 种法定救济手段**（对应第 234\-238 条），核心作用是：当你的物权（所有权、用益物权等）出现归属争议、被侵占、被妨害、被毁损时，通过不同路径把权利恢复到正常状态，或填补已产生的损失。

### 五种保护方法的含义与用途

1. **确认物权（§234）**

    - 作用：解决 “物归谁、权利范围多大” 的名分争议。

    - 场景：比如房产登记存疑、物品所有权争执不下，向法院起诉确认权利归属，是其他救济的前提。

    - 性质：确认之诉，不属于给付型的 “真物权请求权”。

2. **返还原物（§235）**

    - 作用：把被他人无权占有的物拿回来，恢复你的占有控制。

    - 场景：物品被强占、拾得人拒不归还、合同到期后占有人不腾退等。

    - 性质：**真・物权请求权**，只看 “对方是不是无权占有”，不问对方有没有过错。

3. **排除妨害 / 消除危险（§236）**

    - 排除妨害：清除已经存在的阻碍，让你能正常行使物权。比如邻居堆杂物堵你家门、违建挡你采光，要求对方清理拆除。

    - 消除危险：针对尚未发生、但明确存在的隐患，提前预防损害。比如隔壁危墙即将倒塌、水管渗漏即将泡坏你家墙面，要求对方加固维修。

    - 性质：**真・物权请求权**，核心是保障物权正常行使，面向将来消除侵害 / 风险。

4. **恢复原状（§237）**

    - 作用：物被毁损后，要求对方通过修理、重作、更换，把物修复到受损前的状态。

    - 场景：车辆被撞坏、房屋墙面被砸裂，要求修好复原。

    - 性质：法考主流按债权请求权认定，针对 “物的物理损坏” 的修复救济。

5. **损害赔偿（§238）**

    - 作用：物权受侵害造成财产损失时，用金钱填补损失，是兜底救济。

    - 场景：物品彻底损毁无法修复、因妨害产生额外开支等，要求对方赔钱。

    - 性质：典型债权请求权，一般要求侵权方有过错、有实际损失。

### 核心区分逻辑

- 前三类（返还、排除妨害、消除危险）是**物权请求权**：目标是 “让物权回到圆满状态”，不问过错、不要求有实际损失。

- 后两类（恢复原状、损害赔偿）是**债权类救济**：目标是 “填补已经发生的损失”，通常以过错和损害为前提。

- 五种方式可单独使用，也可根据案情叠加并用（§239）。
