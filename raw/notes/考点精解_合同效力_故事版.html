合同效力 这桩买卖在法律上"算不算数" — 一个故事讲到底 + 大白话

定位：民法 › 合同编（与总则编·民事法律行为效力相通）› 合同的效力（有效 / 无效 / 可撤销 / 效力待定）
贯穿全卡的故事

还是 老王 卖电动车给 小李 这桩事。上一张卡看的是"谈没谈成（成立）"，这张看的是——这桩买卖在法律上"算不算数、算多少数"。视不同情况，它会落进四种状态。（老王 15 岁的儿子 小宝 待会儿也会上场。）

合同效力问的不是"成没成立"，而是成立之后，法律认不认、约束力多大。四种状态：有效（正常算数）／ 无效（根本不算数）／ 可撤销（暂时算数、能反悔）／ 效力待定（悬着、等人拍板）。

1是什么 / 易混四种状态先分清，难点全在"这个该归哪一种"的边界上

是什么（四种状态）

用故事说
老王如实介绍车况，小李自愿购买，价钱也公道 → 这桩买卖有效，该交车交车、该付钱付钱。其余三种，都是"出了点状况"才会落进去。
大白话合同效力＝这桩买卖"算不算数"。算数＝有效；根本不算＝无效；暂时算、能反悔＝可撤销；还悬着、等人点头＝效力待定。
易混对照 · 五组高频陷阱
无效自始就不算数，谁都能说
vs
可撤销暂时算数，吃亏方能反悔
用故事说
无效：老王为躲债主，跟小李"假装"把车卖了过户（其实根本没真卖）→ 双方演戏，合同无效。
可撤销：老王把泡过水的车谎称"无事故"，把小李骗了 → 小李可以去法院把这桩买卖撤掉。
大白话无效＝根本不算数、谁都能说、时间再久也救不活；可撤销＝暂时算数，亏的那方想撤就去法院撤、不想撤就接着算。
最大的坑：欺诈、胁迫是可撤销，不是无效！别凭直觉以为"骗人/逼人的合同当然无效"。§148 · §150
可撤销合同已生效，吃亏方握"反悔权"
vs
效力待定合同还没生效、悬着，等人追认
用故事说
可撤销：小李被老王骗了——买卖已经成了，小李有"反悔权"可以撤。
效力待定：老王 15 岁的儿子小宝，背着老王把车卖了 → 这桩买卖悬着，要等老王（法定代理人）点头（追认）才有效。
大白话可撤销＝"已经成了、能反悔"；效力待定＝"还没成、等人拍板"。
撤销看吃亏方；追认看监护人 / 被代理人
一个人坑你欺诈 / 胁迫 → 可撤销
vs
俩人合伙演戏 / 串通坑外人 → 无效
用故事说
老王骗小李（一个人坑一个人）→ 小李可撤销。
老王和小李合谋做一份假买卖合同，去坑老王的债主（俩人串通坑外人）→ 无效。
大白话一个人坑你 → 你能撤；俩人合伙坑外人 / 演戏给别人看 → 直接无效。
对应：通谋虚伪表示无效 §146；恶意串通损害他人无效 §154。
无权处分卖了不属于自己的东西 → 合同有效
vs
无权代理冒名替别人签 → 效力待定
用故事说
无权处分：老王把跟邻居借来的、不属于自己的车卖给小李 → 这买卖合同有效；老王交不出车，是他违约的问题，不是合同无效。
无权代理：有人冒充小李、替小李签了买车合同 → 效力待定，等小李本人追认。
大白话卖别人的东西＝合同照样有效（交不了是违约）；冒名替别人签＝悬着，等本人点头。
民法典的重要变化：旧法曾把无权处分的合同当"效力待定"，现在是有效。§597（无权处分·合同有效）· §171（无权代理）
重大误解看错了、把 A 当 B
vs
欺诈 / 胁迫 / 显失公平被骗、被逼、吃大亏
用故事说（撤销要趁早——这是"除斥期间"）
重大误解：小李把 A 型号看成 B 型号买错了 → 想撤，只有 90 天。
被骗 / 吃亏：小李三个月后才发现被老王骗 → 还在 1 年 内，能撤；被逼的，1 年从"脱离胁迫那天"起算。
大白话想撤趁早：看错 90 天，被骗 / 吃亏 / 被逼 1 年；兜底——不管知不知道，事情发生满 5 年 就彻底没戏。
注意：重大误解 90 日；其余 1 年（自知道或应当知道撤销事由起；胁迫自胁迫终止起）；绝对期间自行为发生起 5 年。§152
2怎么考、坑在哪题目长什么样 + 命题人最爱埋的雷

题目长什么样

命题角度
客观题：给你一个场景（老王小李之间出了点状况），问这买卖是有效 / 无效 / 可撤销 / 效力待定？谁有撤销权或追认权？多久之内能撤？
主观题：大案子里，得先定合同效力是哪种状态，才能往下谈交不交货、赔不赔。常和无权代理、无权处分、善意取得串着考。
高频坑位
  • 把欺诈、胁迫当"无效"——其实是可撤销。
  • 把"卖了不属于自己的东西"（无权处分）当无效或效力待定——民法典下合同有效，交不出货是违约。
  • 把"违反法律强制规定"一律当无效——只有违反效力性强制规定才无效，管理性强制规定不必然无效。
  • 以为可撤销合同能自己单方"通知撤销"——不行，必须请求法院或仲裁机构撤销。
  • 除斥期间记混：重大误解 90 天、其余 1 年、绝对 5 年。
  • 把限制行为能力人的合同一律当无效——纯获利益的、与其年龄智力相适应的有效，其余效力待定；只有无民事行为能力人（如 8 岁）签的才一律无效。
  • 把效力待定里"善意相对人的撤销权"和"可撤销合同的撤销权"混为一谈——两个不同的撤销权。
3客观怎么答按"能力 → 意思 → 内容"三道闸定状态

固定四步

第 1 步看能力：当事人是完全 / 限制 / 无民事行为能力？无能力 → 无效；限制 → 多为效力待定。
第 2 步看意思真不真：有欺诈 / 胁迫 / 重大误解 / 显失公平？→ 可撤销。双方通谋演戏 / 恶意串通？→ 无效。
第 3 步看内容合不合法：违反效力性强制规定、违背公序良俗？→ 无效。
第 4 步定状态 + 配套：定了状态后，问谁有权（撤销权人 / 追认权人）、时间窗（除斥期间）、怎么行使（撤销要走法院 / 仲裁）。
关键词触发表（看到左边，先想右边）
一方"骗、隐瞒真相"→ 可撤销（欺诈）
一方"逼、威胁"→ 可撤销（胁迫）
"看错了、把 A 当 B"→ 可撤销（重大误解·90 天）
"趁人之危、明显不公平"→ 可撤销（显失公平）
双方"假装签约 / 串通坑外人"→ 无效
"违反效力性强制规定 / 违背公序良俗"→ 无效
无民事行为能力人（如 8 岁）签的→ 无效
15、16 岁背着家长签大额合同→ 效力待定（待追认）
"卖了不属于自己的东西"→ 合同有效（可能违约）
"冒名替别人签"→ 效力待定（无权代理）
4主观怎么答先定效力状态，再谈履行与责任——按点给分

怎么下笔

大案子里，第一步永远先定"合同效力是哪种状态"，定不下来，后面交货、赔偿全没法谈。每问按"先给结论 → 搬出法条 → 套到案情里"写。

套用故事的填空模板
本案中，　某人　的　某行为　，构成欺诈 / 胁迫 / 重大误解 / 通谋虚伪 / 无权代理…，依《民法典》第　X　条，该合同有效 / 无效 / 可撤销 / 效力待定。
〔若可撤销〕受损害方　某人　有权请求人民法院或者仲裁机构予以撤销，并应自知道撤销事由起　一年（重大误解九十日）　内行使（§152）。
〔若效力待定〕该合同经法定代理人 / 被代理人追认前不发生效力，善意相对人在追认前有撤销权（§145 / §171）。

两个得分关键

① 先把"状态"这个结论钉死。状态错了，后面全盘皆错；状态对了，再依次写法条、套案情。
② 撤销的"行使方式"是踩分点。可撤销务必写"请求人民法院或仲裁机构撤销"，别写成"通知对方撤销"——这是常见失分点。

给分点 ① 效力状态结论（有效 / 无效 / 可撤销 / 效力待定） 给分点 ② 法条依据 给分点 ③ 套案情 + 谁有权、向谁行使、多久内

怎么用这张卡：四格（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）就是处理每一个考点的固定套路。做错的真题，把对应的"坑"或易混回填到 ①格，再进错题本按遗忘曲线重做。
