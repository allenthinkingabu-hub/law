# 一、核心一句话考点（适配速裁集中开庭笔记，直接并入文档）

不同被告人、仅罪名相同的同类独立案件，**不能直接并案审理**；并案审理有严格法定范围，单纯同罪名、不同行为人不属于可并案情形。
区分关键：**速裁集中开庭逐案审理 ≠ 并案审理**，二者完全不同，考试高频混淆坑点。

## 二、并案审理法定条件（法条原文，六机关规定第 3 条）

公检法全阶段统一可并案 4 类情形，缺一不可：

1. 一人犯数罪（同一被告人多起犯罪）

2. 共同犯罪（多人一起作案，事实相互绑定）

3. 共犯另外单独实施其他犯罪

4. 多名被告人犯罪存在事实关联，合并审理更便于查清事实

### 补充法院审判并案细化（《2021 刑诉解释》24、220 条）

1. 同一被告人多起同种犯罪，**一般应当并案**；

2. 分案起诉的共同 / 关联犯罪，法院认为合并有利查清事实，才可并案；

3. 仅单纯同类、互不关联、不同被告人（如多人各自醉驾、单独小额盗窃），无事实牵连，**禁止并案**。

## 三、并案审理 vs 速裁「集中开庭、逐案审理」（法考必背区分图谱）

| 对比项    | 并案审理              | 速裁集中开庭逐案审理            |
| ------ | ----------------- | --------------------- |
| 案件关系   | 合并成**一个案件**，一份判决书 | 保持**独立多个案件**，一案一份判决   |
| 被告人关系  | 同一人 / 共同犯罪 / 事实关联 | 多名互不相识、无事实牵连的独立被告人    |
| 庭审模式   | 多名被告人同时在庭，一起举证辩论  | 轮流到庭，上一人退庭再传唤下一人，互不碰面 |
| 适用程序   | 普通 / 简易均可，无程序限制   | **仅限速裁程序**，简易、普通无此权限  |
| 法律效果   | 合并定罪量刑，一案终局       | 分别单独定罪、单独宣判，案件互不影响    |
| 核心底层逻辑 | 事实绑定，必须合并查清       | 仅集约司法资源，案件实体完全独立      |

## 四、法理：为何单纯同类不同被告人不能并案？

1. 每个被告人独立享有质证、辩护、最后陈述权利；互不关联案件合并同庭，容易出现证言互相干扰、权利冲突；

2. 犯罪事实、证据、量刑情节完全独立，合并审理无查清事实的必要性；

3. 刑诉不照搬民诉普通共同诉讼规则，**刑事不允许仅以 “罪名相同” 合并审理**。

## 五、考试经典陷阱

2. 错误表述：速裁集中开庭属于并案审理
✅正确：二者程序本质完全区分，选项同时出现时直接区分判断；

3. 挖坑结论：“同类不同被告人案件可并案” 一律错误。
