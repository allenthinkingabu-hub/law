# 刑事拘留多维度表格

## 拘留

| 维度 | 内容 |
|------|------|
| **决定机关与执行** | 公安/检察院决定，公安机关执行 |
| **对象/拘留理由** | 发现现行犯/重大嫌疑情形 |
| **拘留情形总数** | 县存7种 |
| **第一类期限** | 拘留期3日，特殊可延长1-4日（重大/三类罪...） |
| **第二类期限** | 检察保目侦查条件拘留期限：10日，特殊可延长1-4日 |
| **程序与通知** | 24小时内送看守所、讯问、通知家属（仅限涉嫌国安、恐怖犯罪且有侵犯隐私可不通知家属） |

## 核心维度解析

- **拘留权力**：公安与检察机关双权限（各有决定权）
- **拘留对象**：仅限现行犯与重大嫌疑分子
- **拘留期限**：一般3日，检察条件下10日，均可延长1-4日
- **程序保障**：24小时送所、讯问、通知家属（含例外情形）
