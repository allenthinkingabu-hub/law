**辩护职能**是刑事诉讼**三大基本职能**之一，简单说就是——**"站在被告人一边，反驳控诉、维护被告人合法权益"的那股力量**。

## 先看三大职能的"三角结构"

刑事诉讼说到底是三股力量在博弈：

```
                审判职能（法院·居中裁判）
                       ▲
                      / \
                     /   \
          控诉职能  /     \  辩护职能
        （公诉人/  ◄─────► （被告人+
          自诉人）  对抗    辩护人）
```

- **控诉职能**：指控你有罪（检察院/自诉人）；
- **辩护职能**：反驳指控、说你无罪或罪轻（被告人+辩护人）；
- **审判职能**：居中听双方、最后裁判（法院）。

**核心原理**：三职能**分离**、**控辩平等对抗**、**审判居中**——法官不能下场帮控方，这样才公正。

## 辩护职能干什么（内容）

针对控方的指控，**提出有利于被告人的事实、证据和理由**，去**反驳、削弱、推翻指控**：

| 辩护类型 | 干什么 |
|---|---|
| **无罪辩护** | 我根本没犯罪 |
| **罪轻辩护** | 就算有罪，也是轻罪/情节轻 |
| **程序性辩护** | 你取证违法（如申请排除非法证据） |
| **量刑辩护** | 有自首、立功、认罪认罚等，请从轻 |

## 谁行使辩护职能

| 方式 | 谁 |
|---|---|
| **自行辩护** | 犯罪嫌疑人、被告人**本人** |
| **委托辩护** | 自己请的**辩护律师**等 |
| **法律援助辩护** | 法院/机关**指派**的律师（针对盲聋哑、未成年、可能判无期死刑等强制辩护情形） |

## 一句话闭环

**辩护职能＝刑诉三角里"替被告人说话、对抗控诉"的那一极**：由**被告人本人＋辩护人**行使，通过**无罪/罪轻/程序/量刑**四类辩护反驳指控；它与**控诉**平等对抗、由**审判**居中裁断——**控辩审三分离，法官不下场**，是公正审判的底层结构。
