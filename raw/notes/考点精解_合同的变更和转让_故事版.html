合同的变更和转让 债能不能转给别人 — 一个故事讲到底 + 大白话（高频）

定位：民法 › 合同编 › 通则 › 合同的变更和转让（核心：债权转让 · 债务转移 · 合同概括转让）
贯穿全卡的故事

还是 老王 借钱给 小李 的事（老王是债权人、小李是债务人）。这回的主题是：债能不能转给别人？——老王能不能把"小李欠我的钱"这个权利转给 老张？小李能不能让 老张 来替自己还这笔债？答案都是"能"，但规则不一样，关键差别就一个词。

转让分两大类：把"收钱的权利"转给别人 ＝ 债权转让（只需通知债务人）；把"还钱的义务"转给别人 ＝ 债务转移（必须债权人同意）。再加上"整个合同地位打包转" ＝ 概括转让（带着义务，所以也要对方同意）。

1是什么 / 易混一个词定生死："通知 vs 同意"——这是全章命门

是什么

用故事说
债权转让：老王把"小李欠我 10 万"这个债权转给 老张 → 以后小李向老张还。老王只要通知小李就行，不用小李点头。§545 · §546
债务转移：小李把"欠老王 10 万"这个债务转给 老张 → 以后老张替小李还。这必须经老王同意。§551
（合同变更：双方协商一致可改合同内容；变更内容约定不明的，推定为未变更。§543 · §544）
大白话转"收钱的权利"＝债权转让（通知一声即可）；转"还钱的义务"＝债务转移（必须债主点头）。
易混对照 · 五组高频陷阱
债权转让只需"通知"债务人
vs
债务转移必须经"债权人同意"
用故事说（全章最经典的对比）
债权转让：老王把对小李的债权转给 老张 → 通知小李即可，不用小李同意；未通知则对小李不生效。
债务转移：小李要把对老王的债务转给 老张 还 → 必须经老王同意；未同意则对老王不生效。
大白话债权转让"通知就行"，债务转移"必须同意"。
收钱的权利 → 通知；还钱的义务 → 同意
为什么不一样：债权转给谁，对小李"还给谁都一样、负担没变"，通知即可；债务转给谁，直接关系老王能不能收回（新债务人有没有钱），所以必须债主同意。
金钱债权·约定禁让不得对抗"任何第三人"
vs
非金钱债权·约定禁让不得对抗"善意第三人"
用故事说（§545，容易以为"约定禁让=绝对不能转"）
老王小李约定"这笔借款债权不得转让"，老王仍把它转给 老张：借款是金钱债权 → 老张照样取得，约定管不住外人；若是非金钱债权 → 只有老张恶意（知道有禁让约定）才受约定限制。
大白话就算合同写了"不许转"，钱债照样能转（管不住外人）；非钱债只有"明知不许还接手"的人才受限制。
从权利跟着走担保等随主债权转给受让人
+
防御武器也跟着债务人的抗辩 / 抵销可对受让人主张
用故事说（债权转让后的连带效果）
老王对小李的债权有抵押担保 → 转给 老张 后，抵押权一并归老张，且不因未办登记 / 未转移占有而受影响（§547）。同时，小李原来能对老王主张的抗辩（如货有瑕疵）、符合条件的抵销，现在能对老张主张（§548 · §549）。
大白话债权转给老张，担保等"好处"跟着走；但小李原来能对老王用的"挡箭牌"（抗辩、抵销）照样能对老张用——债务人不能因为债权转手就吃亏。
债务转移（免责承担）原债务人"脱离"，新债务人替代
vs
债务加入（并存承担）原债务人"不脱离"，第三人加入连带
用故事说
债务转移：小李把债转给 老张，小李脱身，以后老王只找老张 → 须老王同意（§551）。
债务加入：老张主动跟老王说"小李的债我也一起还"，老王没明确拒绝 → 老张和小李一起对老王负连带债务（小李没脱身，§552）。
大白话债务转移＝换人（原债务人走人，要债主同意）；债务加入＝添人（原债务人还在，多一个连带还钱的）。
门槛为何不同：债务加入对债权人有利（多个责任人），所以宽松（主动加入 / 表示 + 债权人未明确拒绝即可）；债务转移可能让债权落空，所以严格（必须债权人同意）。
单纯转让只转权利 或 只转义务
vs
合同概括转让权利义务整个打包转
用故事说
老王把自己在某长期供货合同里的整个地位（既有收款权利、也有供货义务）一并转给 老张 → 因为带着义务，须经对方（小李）同意；适用债权转让 + 债务转移的规则。§555 · §556
大白话只转权利＝债权转让（通知）；只转义务＝债务转移（同意）；权利义务整个打包转＝概括转让（带着义务，所以也得对方同意）。
2怎么考、坑在哪题目长什么样 + 命题人最爱埋的雷

题目长什么样

命题角度
客观题（高频）：判断是债权转让还是债务转移（要通知还是要同意）；约定禁让能不能转、对抗谁；从权利 / 抗辩 / 抵销转不转；债务转移 vs 债务加入；概括转让要件。
主观题：案例里先认"转的是权利还是义务、程序对不对（通知 / 同意齐没齐）"，才能定转让有没有效、谁该向谁履行。
高频坑位
  • 债权转让也要债务人"同意"——错，只需通知；债务转移才需债权人同意。
  • 债权转让没通知债务人就认为对债务人生效——未通知对债务人不生效（但让与人和受让人之间有效）。
  • 约定禁止转让＝绝对不能转——金钱债权约定禁让不得对抗任何第三人（照样转）；非金钱债权不得对抗善意第三人。
  • 以为债权一转，债务人的抗辩 / 抵销就没了——抗辩、符合条件的抵销可向受让人主张。
  • 把债务加入当债务转移——加入是原债务人不脱离、连带；转移是原债务人脱离、替代。
  • 债务转移后，新债务人拿原债务人对债权人的债权去抵销——不行（§553，可主张原债务人的抗辩，但不得抵销）。
  • 概括转让（含义务）忘了要"对方同意"——光通知不够。
  • 从权利（担保）随债权转移，以为要重新办登记 / 占有才转——不因未办登记 / 未转移占有而受影响（§547）。
3客观怎么答先认转的是啥 → 查程序 → 看附随效果

固定四步

第 1 步认转的是啥：转"收钱的权利"→ 债权转让；转"还钱的义务"→ 债务转移；权利义务整个打包 → 概括转让。
第 2 步查程序：债权转让 → 通知债务人（未通知对债务人不生效）；债务转移 / 概括转让 → 债权人（对方）同意（未同意不生效）；债务加入 → 第三人主动 + 债权人未明确拒绝即可。
第 3 步看附随（债权转让）：从权利、抗辩、抵销跟着走；约定禁让 → 金钱债权不对抗任何人、非金钱债权不对抗善意第三人。
第 4 步看抗辩抵销（债务方）：新债务人可主张原债务人的抗辩；但不得用原债务人的债权抵销。
关键词触发表（看到左边，先想右边）
"把债权 / 应收款转给别人"→ 债权转让（通知债务人即可）
"没通知债务人"→ 对债务人不生效
"把债务 / 欠款转给别人来还"→ 债务转移（须债权人同意）
"债权人没同意"→ 债务转移对债权人不生效
"第三人主动说也一起还、债权人没拒绝"→ 债务加入（连带债务）
"约定不得转让的金钱债权，仍转了"→ 受让人取得（约定不对抗第三人）
"债权附带的担保"→ 随债权一并转移（不因未登记 / 未占有受影响）
"债务人原来能对原债权人用的抗辩"→ 可向受让人主张
"权利义务一并打包转"→ 合同概括转让（须对方同意）
4主观怎么答先定"转权利还是义务、程序齐不齐"——按点给分

怎么下笔

案例里先认"转的是权利还是义务、程序齐不齐（通知 / 同意）"，再定效力和谁向谁履行。每步"先给结论 → 搬出法条 → 套到案情里"。

套用故事的填空模板
本案中，老王 / 小李将债权 / 债务转让给 老张。
〔债权转让〕依《民法典》第 546 条，债权转让经通知债务人后对债务人生效；本案已 / 未通知，故对小李生效 / 不生效，从权利及抗辩、抵销一并随转（§547–549）。
〔债务转移〕依第 551 条，债务转移须经债权人同意；老王已 / 未同意，故有效 / 不生效。
〔概括转让〕权利义务一并转让须经对方同意（§555），并适用债权转让、债务转移的规则。

两个得分关键

① 把"转权利 / 转义务 + 通知 / 同意"这个定性与程序写准。程序要件（通知 or 同意）是这章最核心的采分点，错了直接定性错。
② 别漏附随效果。债权转让要带出"从权利随转、抗辩 / 抵销可对受让人主张"；债务转移要点出"新债务人可主张原债务人抗辩、但不得抵销"。

给分点 ① 定性（债权转让 / 债务转移 / 债务加入 / 概括转让） 给分点 ② 程序要件（通知 or 同意）+ 法条 给分点 ③ 套案情 + 附随效果（从权利 / 抗辩 / 抵销）

怎么用这张卡：四格（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）是处理每一个考点的固定套路。做错的真题，把对应的"坑"或易混回填到 ①格，再进错题本按遗忘曲线重做。本章命门就一句："债权转让通知、债务转移同意"，先把它焊死。
