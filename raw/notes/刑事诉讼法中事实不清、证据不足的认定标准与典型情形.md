# 刑事诉讼法中事实不清、证据不足的认定标准与典型情形

# 一、法条依据

《刑事诉讼法》第 236 条第 1 款第（三）项：原判决事实不清楚或者证据不足的，可以在查清事实后改判；也可以裁定撤销原判，发回原审人民法院重新审判。

# 二、事实不清定义

一审对**犯罪是否发生、行为人、行为过程、危害结果、主观心态、涉案数额、因果关系**等核心定罪量刑事实，没有查清、证据残缺、互相矛盾，无法唯一锁定案件真相，就叫**事实不清、证据不足**。
核心：支撑定罪量刑的关键事实没有查明，现有证据不能形成完整闭环。

# 三、典型情形 \+ 案例

## 1\. 作案主体没查清

案情：入户盗窃，监控只拍到模糊人影，无法确认是不是被告人；一审直接定罪。
事实不清：到底谁实施犯罪这一核心事实未查清。

## 2\. 犯罪过程、手段存疑

案情：指控被告人持刀伤人，被告人辩称是对方先动手防卫，伤情鉴定仅写受伤，未核实谁先动手、工具来源，一审直接定故意伤害。
事实不清：案发起因、行为先后、防卫情节未查清。

## 3\. 涉案数额、后果无法确定

案情：诈骗指控金额 80 万，仅有被害人单方陈述，无转账记录、聊天记录佐证，一审直接按 80 万量刑。
事实不清：犯罪数额这一量刑核心事实证据缺失、无法确认。

## 4\. 因果关系断裂、无法证实

案情：被害人受伤倒地，无法证明伤情是被告人殴打造成还是自身摔倒导致，一审直接归责被告人。
事实不清：危害结果与被告人行为之间因果关系未查清。

## 5\. 证据相互矛盾，事实无法唯一确定

案情：证人 A 说被告人在场，证人 B 说被告人不在场，无其他补强证据，一审采信有罪证言定罪。
事实不清：关键证人证言冲突，案件事实存疑。

# 四、做题区分关键点

1. 事实不清 = 案件客观真相没查清、关键证据缺失 / 矛盾；

2. 法律适用错误 = 事实完全查清，只是定性、量刑法条用错；

3. 程序违法 = 事实没问题，但一审审理流程违规（漏人、剥夺辩护权等）；

4. 处理规则：事实不清二审有两种选择 —— 查清直接改判 / 发回一审重审。
