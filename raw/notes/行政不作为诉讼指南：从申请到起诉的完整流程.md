# 行政不作为诉讼指南：从申请到起诉的完整流程

# 一、大白话一句话翻译

法律规定：公安局、教育局、镇政府这些行政机关，天生就有义务保护你的人身安全、私人财产、上学读书的权利。
**你书面正式去找它要求办事，它拖着不处理、拒绝处理、超期不答复，就叫官府懒政不作为，你可以直接起诉它。**

核心前置条件（法考必考点）：
必须**先主动向机关提交书面履职申请**，对方不理睬，才算不作为；没申请过直接起诉，法院会驳回。

# 二、分三类真实场景举例（直接对标考试）

## 1、保护人身安全类（主管机关：公安局）

### 例子 1（最高法公报经典案例）

店铺半夜遭小偷撬门盗窃，老板连续两次拨打 110 报警，辖区派出所迟迟不出警、不到现场制止，最终店内大量商品被盗。
老板书面要求公安局履行人身、财产保护职责，公安仍不处理 → 行政不作为，可以起诉公安并索要赔偿。

### 例子 2

长期遭受他人上门骚扰、恐吓、家暴，多次到派出所报案要求制止侵害、出具告诫书，民警推诿不立案、不调查、不处置 → 公安不作为。

## 2、保护财产权益类（主管：镇政府、自然资源局、市场监管局等）

### 例子 1

村委会私自违法拆了你家院墙、侵占宅基地，你书面申请镇政府出面制止违建、责令村委会恢复原状，镇政府收到材料后石沉大海，既不调查也不下达处理文书 → 镇政府财产保护不作为。

### 例子 2

邻居违规建房占用公共过道，遮挡你房屋采光通风，向自然资源局书面投诉要求查处违法建筑，部门半年没有任何核查和答复 → 行政不作为。

## 3、保护受教育权利类（主管：教育局 / 教体局）

### 例子 1

孩子被学校违规劝退、无故停课，家长向县教育局提交书面申请，要求主管部门责令学校恢复孩子学籍、保障义务教育就读，教育局收下材料后一直拖延不核查、不给书面处理结果 → 教育局不作为。

### 例子 2

学生因考试不及格被大学退学，向市教委提交申诉申请，教委超期完全不予答复，不履行对高校学籍管理的监督职责 → 属于不履行保护受教育权的法定职责。

# 三、法考做题极简判断公式

1. 主体：行政机关（公安、教育局、镇政府、市监局等）

2. 前提：**你已经书面申请过让它保护人身 / 财产 / 上学权利**

3. 结果：机关拒绝、拖延、逾期不答复、不实质处理
满足三条 = 可诉的行政不作为案件。
