要约与承诺 合同订立的第一个考点 — 一个故事讲到底 + 大白话

定位：民法 › 合同编 › 合同总则 › 合同的订立（要约 → 承诺 → 合同成立）
贯穿全卡的故事

老王有辆二手电动车想卖，小李想买，俩人微信聊。这张卡里所有概念，都用他俩这桩买卖来讲。

合同怎么"谈成"的，说穿了就两步：一个人开口"5000 卖你，要不要？"（这叫要约），另一个人回"要！"（这叫承诺）——"要"字一出口，合同就成立了。这就是 §483 那句话的意思。

1是什么 / 易混定义谁都会背，得分全在"边界"——这几组最容易绕晕

是什么（先把两个词坐实）

用故事说
老王私信："我这车 5000，你要就给你。" —— 这叫 要约（正式开价）。它得满足两点：① 说清楚了（车、价钱都明确）；② 你一点头，他就得认账。§472
小李回："要！" —— 这叫 承诺（接话说"我同意"）。§479
大白话老王开价（要约）→ 小李说"要"（承诺）→ "要"字出口那一刻，合同成立。
易混对照 · 五组高频陷阱
要约正式开价，你点头就成交
vs
要约邀请只是招呼你来谈
用故事说
老王发朋友圈："有辆电动车想出，有意私聊。" → 只是招呼大家来谈，你回"我要了"也成不了交，他还能挑人、再谈价 = 要约邀请。
老王私信你："这车 5000，你要就给你。" → 正式开价，你点头就成 = 要约。
大白话你回一句"我同意"，合同能不能当场就成？能 = 要约；还得他再点头 = 要约邀请。
坑：广告写得特别死也算开价——比如售楼广告白纸黑字承诺"送 20 平米花园"，就当成要约，开发商赖不掉。招聘启事、寄给你的价目单，则都是邀请。
撤回话还没送到，就喊停
vs
撤销话送到了、对方还没接，反悔
用故事说
撤回：老王刚把"5000 卖你"发出去就后悔，赶在小李看到之前补一句"刚那条作废"。
撤销：消息小李已经看到了、但还没回"要"，这时老王说"算了不卖了"。
大白话小李一旦回了"要"，合同就成立了；这时老王再反悔不是反悔，是 毁约、得赔钱。所以"要"（承诺）泼出去就收不回。
注意：撤销有限制——老王当初要是说了"三天内答复有效"，这三天里就不能中途反悔。§475 · §476 · §485
回晚了 · 情况 A怪你自己拖
vs
回晚了 · 情况 B怪路上耽误
用故事说（老王说："5000 卖你，周五前答复有效。"）
A：小李拖到周六才回"要" → 怪他自己晚了。合同不算成立，这句"要"反而变成小李反过来求购，轮到老王决定卖不卖。§486
B：小李周四就回了"要"，正常周五能到，结果微信抽风、周六才弹到老王手机上 → 怪传送。合同算成立，除非老王立刻说"晚了，不认了"。§487
大白话怪你自己 → 不算数（变你反过来求人）；怪路上耽误 → 算数（除非对方马上喊停）。
口诀：怪自己＝新要约；怪传送＝有效
改了核心＝还价（重新开价）
vs
小修小补＝算答应
用故事说
老王："5000。"　小李："4800 我就要。" → 改了价钱（核心），这不是答应，是小李重新开价，得老王再点头。
老王："5000。"　小李："行 5000，不过你周六送过来呗？"（原来没提送货，只是小要求）→ 没动核心，算答应了，合同成立，按小李说的来。
大白话动了核心 = 还价；鸡毛蒜皮 = 算答应。
哪些算"核心"：价钱、数量、质量、啥时候交/在哪交/怎么交、违约怎么赔、有纠纷找谁。§488 · §489
成立说定了（事实）
vs
生效法律真能照约定办了
用故事说
老王说："等我下月搬完家，这车才卖你。"小李答应了 → 俩人 说定了（成立），可这合同得等"老王搬完家"这个条件兑现，才 生效。
大白话成立 = "说定了"；生效 = "这事法律真能照约定办了"。多数买卖同时发生，偶尔说定后还得等个条件才生效。
§502：依法成立的合同，原则上成立就生效；附条件/附期限、需审批的，是例外。
2怎么考、坑在哪题目长什么样 + 命题人最爱埋的雷

题目长什么样

命题角度
客观题：给你一段老王小李这样的对话，问——这是开价还是招呼（要约/邀请）？合同成立没？啥时候成立？老王能不能反悔？小李回晚了算不算？
主观题：大案子里，得先判断"合同成立没、啥时候成立"，才能往下谈该不该赔、怎么赔。所以这块是大题的入口。
高频坑位
  • 把广告一律当"招呼"，漏了写得特别死的广告（售楼承诺）＝正式开价。
  • "撤回"和"撤销"的时间点搞混；以为小李那句"要"也能收回。
  • 小李回晚了，不分"怪自己"还是"怪传送"这两种情况。
  • 把"周六送过来呗"这种小修小补，误当成还价（其实算答应）。
  • 把"成立"当成"生效"——附了条件的：说定了但还没生效；要审批的：没批就没生效，但"该去办审批"这个义务还得履行。
  • 签书面合同：现在签名、盖章、按手印，有一个就成（老规矩要又签又盖）；一方已经把主要的事干了、对方也收了，也算成。§490
  • 网购：网店挂的商品信息够具体的，你"提交订单成功"那一刻合同就成立（不是付款时）。§491
3客观怎么答四步走，把"判断"练成"条件反射"

固定四步

第 1 步先定性：老王这话是开价还是招呼？抓两点——说清楚没？你点头他认不认账？
第 2 步画时间线：撤回 / 撤销 / 回晚——把"谁的话啥时候到对方手里"排出来。默认送到了才算数。
第 3 步看还价没：小李改了核心没？改了 = 重新开价；没改 = 算答应。
第 4 步成立 / 生效分两问：先问成立没（小李回"要"了吗），再问生效没（有没有附条件、要不要审批）。
关键词触发表（看到左边，秒选右边）
价目单 / 招聘启事 / 招标公告→ 只是招呼（要约邀请）
售楼广告里白纸黑字的具体承诺→ 算开价（要约）
对方看到之前撤回→ 行（撤回有效）
已经回了"要"再想撤→ 不行（承诺收不回）
按时回的、路上耽误才迟到→ 原则算数
把价钱 / 数量改了→ 重新开价（新要约）
写了"……才生效"→ 说定了，但还没生效
4主观怎么答先给结论 → 搬法条 → 套到案子里，三样缺一扣分

怎么下笔

大案子里，第一句永远先答"合同成立没、啥时候成立"——这是后面赔不赔、怎么赔的前提。每问都按"先给结论 → 搬出法条 → 套到案情里"写。

套用故事的填空模板
老王发的　那句话　，是开价（要约）/ 只是招呼（要约邀请），因为　满不满足两要件　（§472 / §473）。小李回的　那句　，是答应（承诺）/ 因为改了核心算重新开价（新要约）（§479 / §488）。依§483，小李说"要"那一刻合同成立，所以合同在　某时点　成立。
〔要分生效就再补一句〕合同虽说定了，但因为　附了条件 / 还没审批　，依§502 / §158，目前还没生效。

两个得分关键

① 说"行话"、引对条号。主观题机考可以查电子法条——不用死背，但务必引准（要约 §472、合同成立 §483 这些）。
② 踩点意识。阅卷是按点给分的，下面三样都得写到：

给分点 ① 结论（是要约/承诺/啥时候成立） 给分点 ② 法条依据 给分点 ③ 套案情（把老王小李的事代进规则）

只下结论不引法条、或只抄法条不结合案子，都丢分。宁可结构完整地写短，也别甩一个光秃秃的结论。

怎么用这张卡：四格（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）就是处理每一个考点的固定套路。下一个考点照着这四格、配一个自己的小故事填，会越来越快。
