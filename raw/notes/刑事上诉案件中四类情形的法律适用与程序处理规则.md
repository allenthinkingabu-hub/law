# 刑事上诉案件中四类情形的法律适用与程序处理规则

# 一、四类情形底层法理 \+ 立法原理（分两组对比）

## 第一组：法律适用错误、量刑不当 → 应当直接改判

### 核心原理：**事实基础完好，法院不用重新查证，二审法院有能力直接纠正法律问题**

1. 案件事实、证据全部查清无争议，只是法官对法条、罪名、量刑尺度理解错了；

2. 法律解释、定罪量刑属于**法院法律裁量权**，二审法院同样具备完整法律裁判权限，不用退回一审重新开庭查事实；

3. 节约司法资源：事实不用重新质证、取证，二审直接换法条、改罪名、调刑期即可结案，没必要发回拖延程序。
举例：一审证据足以证明抢劫，错定寻衅滋事。事实清清楚楚，二审直接改抢劫罪，无需发回一审重新审案子。

## 第二组 1：事实不清、证据不足 → 可改判、可发回

### 核心原理：**事实是裁判根基，事实残缺，二审无法凭空定案**

1. 犯罪时间、手段、金额、被害人陈述、物证存在漏洞，证据链条断裂；

2. 查清案件事实依赖一审法庭调查：讯问被告人、证人出庭、当庭质证、调取侦查卷宗补充证据，这些庭审查证工作**专属一审程序**；

3. 二审是事后审，不具备完整事实调查条件：不能重新传唤证人、重新现场勘验、重新补充侦查取证；

4. 例外：如果案卷证据材料已经足够，二审能自行查清事实，也可以直接改判；事实漏洞大、证据缺失，优先发回一审补查。

## 第二组 2：一审严重程序违法 → 应当发回重审，绝对不能直接改判

### 核心原理：**程序正义不可修复，原审整个审理过程无效，判决根基作废**

1. 公开审判、回避、辩护权、质证权是当事人法定基本权利；一旦一审严重违反，本次庭审从根源上不合法，所有质证、陈述、采信证据全部失去效力；

2. 权利损害**无法通过二审改判弥补**：比如应当回避法官全程审案、剥夺被告人辩护权，哪怕实体判得完全正确，庭审过程本身违法；

3. 救济方式只能推倒重来：发回一审，更换合议庭、重新走合法完整庭审流程，重新保障当事人全部诉讼权利；

4. 关键区分：程序瑕疵能补正，但**严重程序违法不可逆**，二审再怎么改判也修复不了已经被侵害的诉讼权利。
举例：一审审判长是被害人亲戚应当回避却没回避，整个庭审全部无效，必须发回重新审理，二审不能直接改判结案。

# 二、一句话总逻辑区分

1. 只错法律、事实没问题：二审能直接用法条纠错→**直接改判**；

2. 事实证据有漏洞：需要一审开庭查证→**发回（或查清后改判）**；

3. 审理流程严重违法：庭审整体失效、权利受损无法补救→**必须发回重审**。

# 三、配套法条支撑

1. 《刑事诉讼法》第 236 条：原判认定事实正确，但适用法律、量刑错误，应当改判；事实不清证据不足，可查清改判或发回；

2. 《刑事诉讼法》第 238 条：一审存在法定严重程序违法，应当撤销原判，发回原审法院重新审判。
