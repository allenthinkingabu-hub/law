# 一、庭前会议是什么

**开庭前的预审协调会（庭前准备程序）** 法官开庭前，召集公诉人、律师、当事人，**只处理程序问题、归纳争议**，**不判罪、不量刑、不审事实**。

法条依据：刑诉法第 182 条

# 二、核心用途（唯一作用）

**扫清庭审障碍、防止开庭卡顿、提速庭审** 专门解决：开庭时容易中断、扯皮、拖延的程序性问题

# 三、具体能干嘛（考试必考范围）

1. 管辖异议
    
2. 回避申请
    
3. 非法证据排除申请
    
4. 确定出庭证人、鉴定人名单
    
5. 证据开示、归纳案件争议焦点
    
6. 附带民事调解
    
7. 申请不公开审理等程序事项
    

# 四、超级核心考点（90% 考生踩坑）

## ❌ 庭前会议 **绝对不能做**

1. **不能定罪**
    
2. **不能量刑**
    
3. **不能审理实体事实**
    
4. **不能作出最终裁判结果**
    

## ✅ 庭前会议 **只能做**

**了解情况、听取意见、整理程序争议、归纳焦点**

# 五、启动规则（必考）

1. **可以召开**：普通复杂案件、证据多、争议大
    
2. **应当召开**：辩护人申请 \_\_ 排非（非法证据排除）\_\_ 且提供线索材料 → 必须开庭前会议
    

# 六、参会人员

审判人员 + 公诉人 + 辩护人 + 当事人 **注意：不是必须全部到场，法官召集即可**

# 七、一句话终极秒杀口诀

**庭前会议只管程序、不管实体；** **只整理争议、不判案、不量刑；** **排非申请必开会。**

# 八、排非专属必考规则：撤回的排非证据不得复用（高频陷阱）

## 1. 法定法条依据（满分标准答案）

《最高法刑诉解释》第131条：**在庭前会议中，人民检察院可以撤回有关证据。撤回的证据，没有新的理由，不得在庭审中出示。**

## 2. 场景人话解读（彻底看懂）

辩护人在庭前会议针对某一份证据申请非法证据排除，检察院自知这份证据取证程序有瑕疵、大概率会被法院当庭依法排除、作废失效。

为了避免当庭被法官正式裁定「证据非法、予以排除」，检察院会**主动在庭前会议撤回这份证据**（相当于主动作废、放弃使用）。

这条规则就是专门堵漏洞：**禁止检察院玩“庭前撤回避险、庭审偷偷复用”的规避手段**。

## 3. 真实做题案例（一模一样考场原题）

张三盗窃案，辩护人在庭前会议提出：本案讯问笔录无同步录音录像，属于非法证据，申请排除。

检察院自知取证有瑕疵，大概率排非成功，于是在庭前会议中**主动撤回该份讯问笔录**。

✅**合法情形**：后续庭审中，无新的合法理由，检察院绝对不能再拿出这份笔录举证、质证、作为定罪依据。

❌ **违法/做题错误情形**：庭审中检察院又拿出该笔录使用，属于程序违法，法庭应当禁止。

## 4. 唯一例外（考场必考）

只有检察院**发现全新的合法理由、新证据、新线索**，能够证明该证据取证合法，才可以在庭审中重新出示；无新理由一律永久作废、不得复用。

## 5. 对称考点（辩方对等规则）

辩护人如果在庭前会议主动撤回排非申请，**无新线索、新材料，庭审不得再次申请排非**，控辩双方双向约束。

## 6. 极简秒杀口诀

**检方庭前撤证据，无新理由禁复用；规避排非行不通，一经撤回即作废。**

## 7、终极核心区分（法考必考易错点）

**法条依据：《最高法刑诉解释》第131条**

**一、辩护方（律师/被告人）权限：只能撤申请，不能撤证据**

辩护方在庭前会议中，仅有权**撤回【非法证据排除的申请】**，**绝对无权撤回、撤销案件证据**（撤回证据是检方专属权利）。

后果：辩方撤回排非申请后，**无新线索、新材料**，庭审中不得再次就同一证据申请非法证据排除。

**二、控方（检察院）权限：只能撤证据，不能撤排非申请**

检察院在庭前会议中，仅有权**撤回【涉案证据本身】**，无权撤回辩方提出的排非申请。

后果：检方撤回证据后，**无新合法理由**，庭审中不得再次出示、复用该份证据。

## 8、双向对照秒杀口诀

**检方撤证据、禁复用（需新理由）；辩方撤申请、禁重提（需新线索）；辩方终身无权撤证据。**
