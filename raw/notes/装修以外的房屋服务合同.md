# 法考精准释义（紧扣民诉解释§28、2026最新裁判规则）

## 1、核心区分逻辑

- **装修合同 = 装饰装修施工合同**，属于**建设工程类** → 强制适用**不动产专属管辖**

- **装修以外房屋服务合同** = **不涉及施工、改造、装修的纯房屋配套服务合同** → **不沾建工、不触发不动产专属管辖**，走**普通合同管辖**

## 2、具体包含哪些（考试标准答案）

✅ **装修以外的房屋服务合同：**

1. 物业服务合同（物业保洁、安保、小区管理）

2. 房屋居间 / 中介合同（卖房、租房中介费纠纷）

3. 房屋托管、代管服务合同

4. 房屋保洁、家电维修、家政服务

## 3、考场秒杀区分

- 带**施工、装修、改造、改建** → 建工类 → **专属管辖**

- 纯**服务、管理、中介、托管** → 普通服务合同 → **普通地域管辖**

## 4、一句话背诵

**动手装修施工 = 专属管辖；不动房子只做服务 = 普通管辖。**
