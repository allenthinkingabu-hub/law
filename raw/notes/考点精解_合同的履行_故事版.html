合同的履行 把答应的事做到位 — 一个故事讲到底 + 大白话（高频·重点）

定位：民法 › 合同编 › 通则 › 合同的履行（核心：三大抗辩权 · 情势变更 · 第三人履行 · 约定不明填补）
贯穿全卡的故事

履行，说白了就是"把答应的事按约定做到位"——老王该交的货按时按质交，小李该付的钱如数付。听起来简单，可一旦冒出"谁先谁后、对方靠不靠谱、中途情况大变、能不能让别人来做"这些状况，就有一串规则和"拒绝 / 中止"的武器要用。这张卡就讲这些。

两层意思：全面履行（按约定做全、做好，还要尽通知 / 协助 / 保密等附随义务）+ 出状况时的三件武器——抗辩权（对方没做好我可拒绝 / 中止）、情势变更（情况剧变可请求变更或解除）、第三人履行的几种结构。

1是什么 / 易混履行的底子 + 五组最容易绕晕的对比（三大抗辩权是重头）

是什么（履行的底子）

用故事说
全面履行：老王按约定把货做全、做好、按时按质按地点交，还要顺带尽到通知 / 协助 / 保密这些附随义务（诚信原则）。§509
约定不明怎么办：先补充协议；补不成按合同条款 / 交易习惯；还不行套法定填补规则——付钱地点在"收钱方"那边、价格按订立时履行地市价、期限不明可随时履行但要给对方准备时间。§510 · §511
大白话履行就是"把答应的事按约定做全做好"；哪儿没说清，先商量补，补不成有一套默认规则兜底。
易混对照 · 五组高频陷阱
同时履行抗辩权双方债务"没先后"
vs
先履行抗辩权双方债务"有先后"
用故事说
同时：约定"一手交钱一手交货"（没说谁先）→ 老王在小李付钱前可拒绝交货，小李在老王交货前可拒绝付钱。§525
先履行：约定"老王先发货、小李收货后 7 天付款"（有先后）→ 老王没发货就来要钱，小李（后履行方）可拒绝。§526
大白话没说谁先谁后 → 同时履行抗辩（你不动我也不动）；说好了谁先 → 先履行抗辩（该先的没做，后做的就能拒绝）。
先履行抗辩权我是"后履行方"，前面没做好我拒绝
vs
不安抗辩权我是"先履行方"，看对方要垮我先停
用故事说（方向相反，最容易混）
先履行抗辩：老王该先发货却没发 → 小李（后）拒绝付款。
不安抗辩：老王该先发货，但发货前拿到确切证据——小李公司经营严重恶化 / 转移财产逃债 → 老王（先）可先中止发货、要求小李提供担保；小李合理期限内不恢复也不担保，老王可解除合同。§527 · §528
大白话后履行方拒绝＝先履行抗辩（"轮到我了、但你前面没做好"）；先履行方喊停＝不安抗辩（"我本该先做，但看你要垮"）。一个拒绝、一个喊停，方向相反。
后方拒绝＝先履行抗辩；先方喊停＝不安抗辩
注意：不安抗辩要"确切证据"，没证据就中止＝自己违约；中止后对方不恢复、不担保 → 可解除。
情势变更无法预见、非商业风险的剧变，继续履行明显不公
vs
商业风险正常市场涨跌、可预见的盈亏
用故事说
老王、小李签好钢材买卖后：钢价正常涨了 20% → 商业风险，老王照常供。若因突发情形使基础条件无法预见地剧变、继续履行明显不公平 → 情势变更：老王可先与小李重新协商，谈不拢再请求法院 / 仲裁变更或解除。§533
大白话能预见的、正常涨跌 → 自己扛（商业风险）；没法预见、剧变到明显不公平 → 先协商，不成再请法院变更 / 解除（情势变更）。
民法典的变化：情势变更不再排除"不可抗力"，所以不可抗力导致的基础条件剧变也可能算情势变更（二者可能竞合）；且务必先重新协商，不能自己直接解除。
向第三人履行 · 第三人不能告只能债权人去告（§522 ①）
vs
向第三人履行 · 第三人能告真正利他合同（§522 ②）
用故事说（老王=债务人，小李=债权人，约定货送给丙）
第三人不能告：一般情况货没送好 → 老王对小李担违约责任，丙不能自己告（§522 ①）。
第三人能告：若法律 / 约定让丙可直接请求老王交付、丙也没及时拒绝 → 货没送好，丙可以直接请求老王担违约责任（§522 ②）。
大白话看第三人有没有"自己告债务人"的权利：一般没有（只能债权人告）；只有约定 / 法律给了直接请求权的，第三人才能自己告。
由第三人履行（§523）约定让别人来做，出事债务人担责
vs
第三人代为清偿（§524）有利害关系的人主动替还，债权转给他
用故事说
由第三人履行：老王（债务人）和小李约定"由丙来交货" → 丙没交好，小李找老王负责。
代为清偿：老王欠小李钱不还，丙（对此有合法利益，如丙是担保人）主动替老王还了 → 还完后，小李对老王的债权转给丙，丙回头找老王追偿。
大白话"约定让别人来做" → 出事还是债务人担责；"有利害关系的人主动替你还" → 还完债权就转给他，他回头找你要。
2怎么考、坑在哪题目长什么样 + 命题人最爱埋的雷

题目长什么样

命题角度
客观题（高频）：给个履行场景，判断该用哪种抗辩权、能不能拒绝 / 中止；是情势变更还是商业风险；第三人结构里谁能告谁、谁担责；约定不明时履行地点 / 价款怎么定。
主观题：案例里先定"该不该履行、能不能拒绝或中止、出事谁担责"——抗辩权和情势变更是高频落点。
高频坑位
  • 三大抗辩权用错——没顺序用同时履行抗辩；有顺序、后履行方拒绝用先履行抗辩；先履行方因对方要垮而喊停用不安抗辩。
  • 不安抗辩没"确切证据"就中止——自己反而违约。
  • 把正常市场涨跌当情势变更——那是商业风险；情势变更要"无法预见 + 明显不公平"。
  • 情势变更直接自己解除——不行，要先重新协商，不成再请求法院 / 仲裁变更或解除。
  • 向第三人履行时，以为第三人都能告债务人——只有真正利他合同（有直接请求权）的第三人才能告，否则只能债权人告。
  • 由第三人履行（§523，约定、责任在债务人）和第三人代为清偿（§524，主动、清偿后债权转移）搞混。
  • 约定不明的履行地点搞反——给付货币在"接受货币一方"所在地（收钱方），不是付钱方。
  • 提前 / 部分履行——债权人原则上可拒绝，但不损害其利益的除外；增加的费用由债务人负担。
3客观怎么答抗辩权三连判 → 看变化 → 理第三人 → 约定不明走填补

固定四步

第 1 步抗辩权三连判：双方债务有没有先后顺序？无 → 同时履行抗辩；有 → 再分："该先的没做好"（后履行方 → 先履行抗辩）还是"先履行方怕对方垮、有确切证据"（先履行方 → 不安抗辩）。
第 2 步看变化的性质：可预见 / 正常波动 → 商业风险（照常履行）；无法预见 + 明显不公 → 情势变更（先协商 → 请求法院 / 仲裁变更或解除）。
第 3 步理第三人结构：是"向第三人履行"（看第三人有无直接请求权）、"由第三人履行"（责任在债务人）、还是"第三人代为清偿"（主动 + 合法利益，清偿后债权转移）。
第 4 步约定不明走填补：§510 补充协议 → §511 法定规则（货币在收钱方、价按订立时履行地市价、期限不明可随时履行但给准备时间）。
关键词触发表（看到左边，先想右边）
"没说先后、本应同时"→ 同时履行抗辩权
"约定了先后，该先的没做（好）"→ 先履行抗辩权（后履行方）
"我该先做，但有确切证据对方要黄（经营恶化 / 转移财产 / 丧失信誉）"→ 不安抗辩权（可中止；不恢复不担保可解除）
"没确切证据就中止"→ 自己违约
"正常市场涨跌 / 可预见"→ 商业风险（照常履行）
"无法预见 + 继续履行明显不公平"→ 情势变更（先协商 → 请法院变更 / 解除）
"约定向第三人交付、第三人有直接请求权"→ 第三人可自己告
"约定由第三人来履行"→ 出事债务人担责（§523）
"有合法利益的第三人主动替还"→ 还后债权转给他（§524）
"给付货币、地点不明"→ 接受货币一方（收钱方）所在地
4主观怎么答先定"能不能拒绝 / 中止、谁担责"——按点给分

怎么下笔

案例里先定"该不该履行、能不能拒绝或中止、出事谁担责"。抗辩权和情势变更是最常见的落点。每步"先给结论 → 搬出法条 → 套到案情里"。

套用故事的填空模板
本案中，甲乙互负债务，无 / 有先后履行顺序。
〔抗辩权〕因对方未履行 / 有确切证据对方丧失履行能力，依《民法典》第 525 / 526 / 527 条，某方享有同时 / 先 / 不安履行抗辩权，有权拒绝 / 中止履行〔不安的：中止后对方未恢复且未担保的，依 §528 可解除〕。
〔情势变更〕合同成立后基础条件发生无法预见、非商业风险的重大变化，继续履行明显不公平，依 §533，受不利方可请求重新协商，协商不成请求人民法院或仲裁机构变更或解除。

两个得分关键

① 把"哪种抗辩权 / 是否情势变更 / 第三人结构"这个定性写准。定性错，后果全错。
② 写清后果和程序。抗辩权要写明是"拒绝"还是"中止"（不安可发展到解除）；情势变更必须写"先协商，不成再请求法院 / 仲裁变更或解除"，别漏了协商这步。

给分点 ① 定性（哪种抗辩权 / 情势变更 / 第三人结构） 给分点 ② 法条依据 给分点 ③ 套案情 + 后果与程序

怎么用这张卡：四格（是什么/易混 → 怎么考、坑 → 客观答 → 主观答）是处理每一个考点的固定套路。做错的真题，把对应的"坑"或易混回填到 ①格，再进错题本按遗忘曲线重做。本章是高频重点，三大抗辩权的区分务必练到条件反射。
