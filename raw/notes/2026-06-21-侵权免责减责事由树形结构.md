# 知识图谱：上位概念——民事侵权免责、减责事由
## 顶层（0级）
民事侵权责任抗辩事由（分两大同级分支：免责事由、减责事由）
## 一级（同级两大板块）
### 一、免责事由（完全不用赔）
1. 正当理由类
    - 正当防卫
    - 紧急避险
    - 自甘风险
      - 下位：一般自甘风险；故意自陷风险
    - 受害人同意（有效被害人承诺）
    - 自助行为
2. 外来客观事由
    - 不可抗力
    - 第三人原因（部分场景构成不真正连带，非免责）

### 二、减责事由（减轻赔偿，不能全免）
1. 过失相抵（受害人有一般过失）
2. 无偿提供劳务一方轻微过失
3. 其他法定减轻情节

## 层级精简树形结构

```
0级：民事侵权抗辩事由
├─ 一级：免责事由（全额免除责任）
│  ├─ 正当防卫
│  ├─ 紧急避险
│  ├─ 自甘风险
│  │   ├─ 一般自甘风险
│  │   └─ 故意自陷风险
│  ├─ 受害人同意
│  ├─ 自助行为
│  └─ 不可抗力
└─ 一级：减责事由（仅减轻责任）
   ├─ 过失相抵（受害人过错）
   └─ 法定特殊减轻情形
```

## 应试区分要点
1. 故意自陷风险属于**自甘风险下位特殊类型**，效果直接全部免责；
2. 过失相抵只是减责，无法完全免除侵权人赔偿义务。
