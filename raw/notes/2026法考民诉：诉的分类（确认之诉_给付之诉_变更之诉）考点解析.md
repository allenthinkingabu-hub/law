# 2026法考民诉：诉的分类（确认之诉/给付之诉/变更之诉）考点解析

# 一、考点定位 \& 考频（2026 法考民诉）

**考点：诉的分类（确认之诉 / 给付之诉 / 变更之诉（形成之诉））**

1. 考频：**客观题每年必考（1 道单选 / 多选），属于民诉入门核心理论题，极易挖坑；主观题偶尔在案例设问判断诉的类型。**

2. 核心判定规则（法考统一标准）：**只看原告实体诉讼请求；仅诉讼案件适用，非讼程序（特别程序、支付令、公示催告）不适用诉的分类。**

3. 术语说明：**变更之诉 = 形成之诉，二者同义，考卷两种表述都会出现。**

# 二、三类诉标准定义 \+ 典型例子

1. **确认之诉**
原告请求法院确认**双方民事法律关系存在 / 不存在、有效 / 无效**；只需要法院 “下定论”，不要求对方履行义务。
✅例子：确认合同无效、确认存在亲子关系
❌坑：单纯请求确认 “事实”（确认对方违约、确认侵权事实）不属于确认之诉。

2. **给付之诉（三类诉里最常见）**
原告请求法院判令被告**履行义务**（给钱、交付物品、作出 / 停止行为）。
✅例子：偿还货款、停止侵害、赔礼道歉。

> 重要逻辑：给付之诉中往往附带法律关系确认，但**只要核心诉求是要求对方履行义务，一律定性给付之诉**。
> 
> 

3. **变更之诉（形成之诉）**
双方认可**现有法律关系客观存在**，原告请求法院判决**改变、消灭现存法律关系**。
✅例子：离婚、撤销股东会决议、变更抚养费数额、解除合同之诉。

# 四、考场高频陷阱（背诵重点）

1. ❌误区：只要出现 “撤销判决、改变裁判”= 形成之诉
✅正解：形成之诉只能变更**民事法律关系**；撤销法院生效裁判属于程序救济，不属于变更之诉。

2. ❌误区：判决里有确认内容 = 确认之诉
✅正解：以原告**最终实体请求**作为唯一判断标准。

3. 前置红线：特别程序、督促、公示催告等**非讼案件，不存在诉的分类**。
