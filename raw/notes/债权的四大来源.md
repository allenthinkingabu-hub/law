# 一、侵权 = 债权的四大来源之一（侵权之债）
债权分四类：合同、侵权、无因管理、不当得利。
别人违法侵害你的人身、财产，你产生的索赔权利，就叫**侵权债权**。

## 大白话
你享有物权（手机是你的），别人故意摔碎你手机；
你不能直接去抢对方财物抵债，**只能请求对方赔钱**，这个“要钱赔偿”的权利，就是侵权债权。

# 二、核心特点
1. **法定之债，不用提前签合同**
哪怕互不认识，只要损害他人权益，自动产生赔偿义务。
2. 属于**相对权**
只能找侵权行为人索赔，不能约束无关第三人。
3. 属于普通无担保债权
对方没给你抵押、质押做赔偿担保的话，一旦对方破产，侵权赔偿债权只能最后排队分钱。

# 三、法考常见侵权例子
1. 财产侵权：砸车、损毁厂房、私自处分他人财物
2. 人身侵权：打人、侮辱诽谤、交通事故致人受伤
3. 特殊侵权：高空抛物、宠物伤人、产品质量致人损害

# 四、物权 vs 侵权债权联动（必考点）
1. 物权（绝对权）：你拥有物品，对抗所有人；
2. 他人侵害你的物权 → 诞生**侵权债权**：你有权请求加害人赔偿损失；
3. 区分：
- 物权请求权（返还原物、排除妨害）：不用对方有错，只要东西被侵占就能主张；
- 侵权损害赔偿债权：必须对方有过错+造成损失，才能要钱。

# 极简总结
侵权行为会产生**侵权之债**，属于债权；只有索赔效力，没有优先受偿的物权保障。
