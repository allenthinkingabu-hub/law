# 民事诉讼法第127条分流指路牌详解

## 法条依据

《民事诉讼法（2023 修正）》**第 127 条**，讲义所称 “分流指路牌”，就是本条：起诉不归本院民事审理时，法院指引当事人去往正确救济渠道。

## 概念一句话

**分流指路牌（第 127 条）：法院收到诉状，发现不属于本院民事案件受理路径，指引当事人走正确救济途径，一般不直接作出不予受理裁定。**

## 五类核心分流情形 \+ 简洁案例（匹配你讲义列举内容）

1. **属于行政案件 → 告知提起行政诉讼**
案例：起诉自然资源局撤销土地登记，原告立民事案。法院指引：提起行政诉讼。

2. **存在有效书面仲裁协议 → 告知申请仲裁**
案例：买卖合同明确约定争议交由 XX 仲裁委，原告直接向法院起诉。法院指引：去仲裁机构。

3. **应由其他行政机关处理 → 告知向有关机关申请解决**
案例：单位内部职工职级、人事任免纠纷，提起民事诉讼。法院指引：向人社局 / 单位主管部门申诉。

4. **不属于本院管辖 → 告知向有管辖权法院起诉**
案例：房屋不动产纠纷，原告向外地基层法院起诉。法院指引：向不动产所在地法院起诉。

5. **已有生效裁判又重复起诉 → 告知申请再审（撤诉裁定除外）**
案例：借贷纠纷法院已经作出生效判决，当事人再次就同一欠款起诉。法院指引：申请再审。
