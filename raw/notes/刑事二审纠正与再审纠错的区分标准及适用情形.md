# 刑事二审纠正与再审纠错的区分标准及适用情形

# 一、核心区分标准（一句话定界）

1. **二审纠正**：针对**一审未生效裁判**（已经上诉 / 抗诉进入二审程序），二审程序内直接改判纠错；

2. **再审（审判监督程序）**：针对**已经生效的裁判**（上诉期满无人上诉、二审终审完毕），只能走再审事后纠错。

## 底层法理

一份裁判一旦上诉期满无人救济，即产生既判力，**二审无权改动生效文书**；只有未生效、正在二审程序中的内容，才能二审直接改判。

# 二、应当走【二审纠正】的全部情形（可在二审直接改判）

## 情形 1：刑事部分上诉 / 抗诉，刑事本身有错（未生效）

1. 一审事实清楚，但罪名认定错误、量刑畸轻 / 畸重 → 二审**应当直接改判**（二审纠正）《刑诉法 236》

2. 一审事实不清、证据不足，二审能查清事实 → 查清后直接改判（二审纠正）

3. 检察院抗诉一审量刑畸轻，二审期间检察院申请撤回抗诉：法院审查确属畸轻，**不准撤回抗诉，继续二审直接加重改判**（典型二审纠正）
例：甲诈骗 50 万一审判 3 年，检察院抗诉，二审检方想撤抗；法院不准撤，二审直接改 7 年。

## 情形 2：刑附民案件，刑事、民事均上诉（两部分都未生效）

当事人既上诉刑事、又上诉附带民事，两部分都未生效。
二审查出刑事有错、或民事赔偿计算错误，**均可在本案二审一并改判纠正**。

## 情形 3：上诉期满后撤诉，原判确有错误，法院不准撤诉、继续二审纠错

被告人上诉期满后申请撤回上诉，二审查明原判轻罪重判、事实不清、无罪判有罪：
不予准许撤诉，继续二审审理、直接改判纠正。

## 情形 4：共同犯罪仅部分被告人上诉，全案未生效

甲乙共同犯罪，仅甲上诉、乙未上诉，无抗诉；
二审全面审查发现乙量刑畸重（仅有被告上诉，受上诉不加刑，不能加重，但可查清事实、纠正定性错误；若有检察院抗诉，则可直接加重乙刑罚，属于二审纠正）。

## 情形 5：一审漏罪、漏同案犯，正确操作发回一审重审后，一审重新判决再次上诉

漏罪 / 漏人不能在原二审直接改判，但发回重审后的新一审判决，再次上诉后，新二审可一并审理、改判纠正。

# 三、只能走【再审（审判监督程序）】的全部情形（二审不能直接改）

## 大类 1：刑附民一部分上诉、另一部分无人上诉，期满自动生效

### 子情形 1：仅刑事上诉，附带民事无人上诉（民事生效）

二审全面审查发现附带民事赔偿计算、责任划分错误
→ 民事部分已生效，**二审无权改，必须单独对民事启动再审纠正**《刑诉解释 330》
口诀：刑上民错，民事再审。

### 子情形 2：仅附带民事上诉，刑事无人上诉（刑事生效）

二审审理民事上诉时，发现一审刑事定罪、量刑错误
→ 刑事裁判已生效，不能在二审直接改刑事，**启动再审，刑民合并再审审理**《刑诉解释 331》

## 大类 2：上诉期满，当事人撤诉且法院准许撤诉，一审整体生效

被告人上诉期满申请撤诉，二审查明原判事实、法律、量刑均正确，裁定准许撤诉。
撤诉后一审判决全部生效；后续发现案件有错，**只能走再审**，二审程序已经终结，无法回头纠正。

## 大类 3：无任何上诉、抗诉，上诉期满一审自动全部生效

1. 被告人不上诉、检察院不抗诉，10 天上诉期满，一审刑事、附民全部生效；

2. 事后发现定罪错误、量刑畸轻畸重、证据造假、程序违法；
→ 无二审程序可走，只能申诉、检察院再审抗诉，启动审判监督程序纠错。

## 大类 4：二审已经作出生效终审判决

二审维持、二审改判、二审发回后一审再次宣判且无上诉；所有终审裁判均生效。
后续发现新证据、原审枉法裁判、证据伪造等，**唯一渠道再审**。

## 大类 5：死立执二审开庭后被告人撤诉被准许，裁判生效

死刑立即执行二审开庭前撤诉可准许，准许后一审裁判生效；后续有错只能再审。

## 大类 6：漏罪、漏同案犯，原二审直接改判属于程序违法，无法二审纠正

一审漏罪、漏同案犯，二审不能直接追加改判（违反两审终审），原二审程序无法纠错；只能发回一审重审；若二审违法直接改判，后续发现该程序错误，需再审撤销二审判决。

# 四、对比速记表

|区分维度|二审纠正|再审（审判监督程序）|
|---|---|---|
|针对裁判状态|一审判决**未生效**，已进入二审程序|一审 / 二审裁判**已生效**（上诉期满无救济、二审终审完毕）|
|纠错时机|上诉、抗诉审理过程中即时纠错|判决执行阶段、终审结束后事后补救|
|能否直接改判|可以，本案二审文书直接改|二审程序已关闭，只能另立再审案纠错|
|典型场景|检察院抗诉畸轻、不准撤回抗诉，二审加重改判；刑民均上诉，一并改判|只上诉刑事、附带民事无人上诉；全案无人上诉期满生效；二审终审后翻案|
|程序地位|正常第二审救济程序|特殊事后纠错兜底程序|

# 五、做题易混陷阱总结

1. 陷阱 1：仅刑事上诉，二审发现附带民事赔偿错 → 不能二审改，只能再审；

2. 陷阱 2：检察院抗诉量刑畸轻，想撤回抗诉，法院不准撤、二审直接加刑 → 典型二审纠正；

3. 陷阱 3：上诉期满撤诉、法院准许撤诉，一审生效 → 以后有错只能再审；

4. 陷阱 4：只有被告人上诉，同案未上诉被告人量刑畸轻 → 受上诉不加刑，二审不能加重，只能等生效后再审纠正。
