# 民事与刑事诉讼二审审判模式对比分析

# 一、基础概念

1. **当事人主义（民事二审典型）**：审判范围严格限于当事人上诉请求，法院只审双方有争议部分，没提的问题法院不主动管，审判边界由当事人划定。

2. **职权主义（我国刑事诉讼特色）**：法官有权不受当事人诉求约束，依职权主动查清全案事实、纠正全部错误，审判不受当事人主张范围束缚。

# 二、对应法条

《刑事诉讼法》第 233 条：二审应当全面审查，不受上诉或者抗诉范围的限制。

# 三、逐句拆解逻辑

1. 上诉、抗诉范围是控辩双方不服、要求改判的内容，属于当事人的诉求边界；

2. 刑事二审不局限这个边界，法院主动查清一审全部事实、证据、定罪、量刑、程序，哪怕控辩双方完全没提出异议的错误，法院也要主动核查；

3. 这种**法院主动扩大审查范围、依职权查明案件全部真相**的制度设计，就是职权主义审判模式的直接体现。

# 四、对比案例直观区分

## 案例 1 刑诉二审（职权主义・全面审查）

甲乙共同伤人，仅甲上诉，只说自己量刑太重，对乙的刑期、主从犯划分完全没意见。
二审法院依职权主动全案审查，发现一审错把主犯乙认定为从犯，哪怕没人对乙提出异议，法院也要查清该错误，只是受上诉不加刑约束不能加重乙刑罚。法院主动突破当事人诉求范围办案，是职权主义特征。

## 案例 2 民事诉讼二审（当事人主义）

两人借款纠纷，原告一审主张本金 \+ 利息，上诉只不服利息计算方式，对本金无异议。二审只审理利息争议，本金部分当事人没异议，法院不会主动核查本金是否存在认定错误。

# 五、做题考点总结

命题固定逻辑：

1. 刑事二审全面审查 = 职权主义；

2. 民事二审仅围绕上诉请求审理 = 当事人主义；

3. 答题话术：二审不受上诉抗诉范围限制、依职权完整核查全案，体现刑事诉讼职权主义审判特征。
