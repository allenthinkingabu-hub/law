# 300-行政法-原告资格与被告确定

## 一、 第一步：纯逻辑大白话情景故事化背诵段落

在行政诉讼中，谁有权当原告告官、以及到底该把哪个行政机关推上被告席，全看切身利害关系与公权力行使的终极归属：

原告:
- **原告资格认定的核心是利害关系**：只要行政行为损害了自己的合法权益（包括邻居建房挡光侵犯相邻权、公平竞标人被非法排除），就有权当原告；

- **人死了近亲属（配偶父母子女祖孙兄弟姐妹）顶上当原告，公司关门了权利承受单位当原告**；
-  中外合资合作企业受了委屈而企业自己不告的，**出资方可以自己的名义独立起诉当原告**！

被告: 

而**被告的确定遵循谁主事谁当被告的六大黄金法则（考场必考秒杀核心）**：

- 第一则是**复议维持双被告铁律**：
	- 复议机关决定维持原行政行为的，**作出原行政行为的机关和复议机关必须当共同被告**！原告只告一个的，**法院释明追加，原告拒绝追加的法院直接依职权强行追加为共同被告，绝不能驳回起诉**！
	- 复议机关**驳回复议申请 / 驳回复议请求**视为复议维持、构成双被告，但**以复议申请不符合受理条件为由驳回的除外**。例如: **程序上因为过期、超范围、申请人不适格驳回 = 不算维持，单独告复议机关**。 [[行政法-单选-157 · 化工厂超标排污复议超时诉被告举证]]

- 第二则是**复议改变看复议机关**：复议机关改了主要事实、改了依据、撤销重作或确认违法的，**复议机关自己单独当被告**！

- 第三则 复议不作为,被告规则（自由二选一，**不能一起告**）
	- 你不服**最开始的原处罚 / 原行政行为** → 告**原行政机关**
	- 你不服**复议机关躺着不干活、不履行复议职责** → 告**复议机关**

- 第四则是**委托找委托、授权自己当**：
	- 行政机关委托别人办事的，**委托机关是被告（受托组织绝不当被告）**；
	- 法律法规明确授权给组织的，**被授权组织自己当被告**！

- 第五则是**派出所越权找公安局**：派出所在法定权限内办案自己当被告，**一旦超越法定授权（如罚款超额拘留人），立刻穿透由设立它的县公安局当被告**！

- 第六则是**临时机构内设科室找靠山**：办公室、执法科、临时拆迁指挥部盖章作决定的，**由背后的设立机关当被告**；机关被撤销撤并的，**由接盘继承职权的机关当被告（无接盘侠由作出撤销决定的机关当被告）**！

- 第七则是两个以上行政机关作出联合行政行为的，共同作出行政行为的行政机关是“共同被告”。原告漏诉被告的，法院应当告知追加；原告同意追加的，追加为共同被告（环保局与水利局为共同被告）,例外, 同样是共同被告,  复议维持共同被告 = 强制追加


举证责任: [[行政诉讼证据责任分配：C选项解析]]
- **被告行政行为合法性 = 政府举证（倒置）**, **证明被诉行政行为本身合法**
- **原告自己的起诉资格、自己的损失 = 原告举证（谁主张谁举证）**

股份制企业发起行政诉讼
股份制企业的股东大会、股东会、董事会认为行政行为侵犯企业经营自主权的，可以以企业名义提起诉讼  [[股份制公司在行政、民事、刑事诉讼的原告被告指定]]

## 二、 第二步：故事模型的考场实战运用法（考法透视与破题秒杀算法）

### 1. 命题人怎么考？（题型套路与设问形态）

在法考客观题中，原告资格与被告确定是考查频次最高、综合性最强的必考大专题（4星半核心），命题人通常通过以下 **4 种标准设问形态** 设坑：
*   **套路一：复议维持下遗漏被告的法院处理（告知追加 vs 依职权追加 vs 驳回起诉）**
    *   *出题特征*：区环保局罚款，市环保局复议维持，原告起诉时只列区环保局为被告。
    *   *设问陷阱*：声称“原告未将复议机关列为被告起诉条件不符，法院应裁定驳回起诉”或“原告不同意追加的法院不得强制追加”。
    *   *考场破局*：**复议维持必须双被告！原告漏告的先告知追加；原告同意就追加，原告不同意法院直接依职权追加复议机关为共同被告，绝不能驳回起诉**！
*   **套路二：委托执法 vs 法律授权 vs 临时指挥部**
    *   *出题特征*：区政府设立“旧城改造临时指挥部”强拆，或者市监局委托消协盖章发通报。
    *   *设问陷阱*：声称“临时指挥部或受托组织是对外实施行为的直接主体，应列为被告”。
    *   *考场破局*：**临时机构与受托组织无独立主体资格，一律抓背后设立机关和委托机关当被告**！
*   **套路三：派出机构授权边界与越权责任**
    *   *出题特征*：派出所作出拘留 10 日决定或处以 1000 元罚款（超出治安法 500 元法定授权限额）。
    *   *设问陷阱*：声称“以派出所名义盖章作出，无论是否越权被告均为派出所”。
    *   *考场破局*：**派出所法定权限内自己当，一旦越权（超 500 元或作出拘留）被告直接穿透为县公安局**！
*   **套路四：投资方与相邻权人独立原告资格**
    *   *出题特征*：规划局给甲发施工许可挡住了乙的采光，或者合资企业被处罚但合资公司不起诉，外方投资者单独起诉。
    *   *设问陷阱*：声称“采光受损属于民事侵权不具备行政原告资格”或“出资人非行政相对人无权起诉”。
    *   *考场破局*：**利害关系即可当原告！相邻采光受损人具有原告资格；企业不起诉出资人可以自己名义起诉**！

### 2. 基于第一步，考场怎么答？（故事提取与选项秒杀算法）

读完题干后，眼睛扫描题干事实特征词，大脑直接调用第一步故事中的对应句子，按以下 **三步算法极速定项**：

*   **第 1 步·看原告身份 ➔ 识别原告资格扩张（相邻权、近亲属、出资人）**
    *   看到题干“规划许可导致邻居采光通风受损” ➔ **调用故事句**：“相邻权受损具备直接利害关系，有权当原告！” ➔ **直接秒选：原告资格合法（秒杀单选-95）**！
    *   看到题干“公民死亡 / 合资企业不起诉出资人起诉” ➔ **调用故事句**：“人死近亲属顶上，企业不告出资人以自己名义告！” ➔ **直接秒选：具备原告资格（秒杀单选-96、单选-98）**！
*   **第 2 步·审复议结论 ➔ 抓维持双告、改变复议单独告**
    *   看到题干“经过复议维持原处罚 / 改变依据维持结果” ➔ **调用故事句**：“复议维持双被告，原机关和复议机关为共同被告，漏告依职权追加！” ➔ **直接秒选：共同被告，法院应追加（秒杀单选-89、单选-92、多选-211）**！
    *   看到题干“复议机关撤销原决定 / 变更处罚额度 / 确认违法” ➔ **调用故事句**：“复议改变看复议机关，复议机关单独当被告！” ➔ **直接秒杀：复议机关为被告（秒杀单选-93、单选-94、多选-103、多选-106）**！
*   **第 3 步·盯组织属性 ➔ 区分委托、授权、派出所与临时机构**
    *   看到题干“行政机关委托其他组织办事” ➔ **调用故事句**：“委托找委托，委托行政机关是被告！” ➔ **直接秒选：委托机关为被告（秒杀单选-100）**！
    *   看到题干“临时拆迁指挥部 / 内设机构盖章 / 转报审批” ➔ **调用故事句**：“内设科室临时机构找靠山，设立机关当被告！” ➔ **直接秒选：设立机关为被告（秒杀单选-90、单选-91、多选-98）**！

## 三、 第三步：2026 现行官方法条依据与官方检索地址

### 1. 现行核心法条依据
*   **《中华人民共和国行政诉讼法》（2017修正）第 25 条、第 26 条（原告资格与被告确定全规则）**：
    *   **行政行为的相对人以及其他与行政行为有利害关系的公民、法人或者其他组织，有权提起诉讼**。有权提起诉讼的公民死亡，其**近亲属**可以提起诉讼。有权提起诉讼的法人或者其他组织终止，承受其权利的法人或者其他组织可以提起诉讼（第25条）。
    *   公民、法人或者其他组织直接向人民法院提起诉讼的，**作出该行政行为的行政机关是被告**。
    *   **经复议的案件，复议机关决定维持原行政行为的，作出原行政行为的行政机关和复议机关是共同被告；复议机关改变原行政行为的，复议机关是被告**。
    *   两个以上行政机关作出同一行政行为的，**共同作出行政行为的行政机关是共同被告**。
    *   行政机关委托的组织所作的行政行为，**委托的行政机关是被告**。
    *   行政机关被撤销或者职权变更的，**继续行使其职权的行政机关是被告**；没有继续行使其职权的行政机关的，**作出撤销决定的行政机关是被告**（第26条）。
*   **《最高人民法院关于适用〈中华人民共和国行政诉讼法〉的解释》（2018施行）第 13、14、17、26、136 条（被告追加与主体细化）**：
    *   **原告起诉应当列复议机关为共同被告而未列的，人民法院应当告知原告追加；原告不同意追加的，人民法院应当将复议机关列为共同被告**（第26条）。
    *   中外合资企业、中外合作企业的合营各方、合作各方，认为行政行为侵犯企业合法权益，**在企业不起诉的情况下，可以以自己的名义提起诉讼**（第17条）。
    *   行政机关的内设机构或者派出机构超出法定授权范围作出行政行为，**当事人不服提起诉讼的，应当以实施该行为的行政机关或者设立该派出机构的行政机关为被告**（第14条）。
