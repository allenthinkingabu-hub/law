# 刑事诉讼法第41条辩护律师证据调取权详解

# 一、核心法条（2026 现行有效，官方链接）

1. 《刑事诉讼法》第 41 条（题干原文法条）
链接：[http://www\.npc\.gov\.cn/zgrdw/npc/xinwen/2018\-11/05/content\_2065631\.htm](http://www.npc.gov.cn/zgrdw/npc/xinwen/2018-11/05/content_2065631.htm)
原文：辩护人认为在侦查、审查起诉期间公安机关、人民检察院收集的证明犯罪嫌疑人、被告人无罪或者罪轻的证据材料未提交的，有权申请人民检察院、人民法院调取。

2. 配套司法解释
《刑诉解释》第 57 条：含监察机关收集未移送无罪 / 罪轻证据，律师可书面申请法院向检察院调取，调取后及时通知律师阅卷；不予调取书面说明理由。
《人民检察院刑事诉讼规则》第 50 条：审查起诉阶段律师申请调取公安未移交无罪罪轻证据，检察院应当审查调取或书面释明不调取理由。

# 二、辩护律师获取案件材料完整四大途径（法考必区分）

## 途径 1：会见通信（侦查阶段即可）

1. 时间：侦查阶段委托律师后就能会见；

2. 获取信息：向嫌疑人核实案情、听取陈述、了解办案机关掌握的线索；

3. 局限：**看不到书面案卷、证据原件**，仅口头信息；

4. 限制：会见不被监听，核实证据只能自审查起诉之日起。

## 途径 2：阅卷权（最基础、常规取证方式）《刑诉法》第 40 条

1. 启动节点：**移送审查起诉之日起**，侦查阶段绝对不能阅卷；

2. 主体区分：辩护律师阅卷无需许可；普通辩护人必须经检 / 法许可；

3. 范围：全部诉讼文书、有罪 / 罪重证据；**不含侦查机关已收集但隐匿未移送的无罪、罪轻证据**（题干法条专门解决该缺口）；

4. 禁止查阅：合议庭评议记录、审委会讨论记录等内部不公开材料。

## 途径 3：申请调取隐匿无罪 / 罪轻证据（题干对应专属权利，考试核心）

### 适用场景

公安、监察、检察院在侦查 / 调查、审查起诉阶段已经收集到无罪、罪轻证据，但故意不随案移送卷宗，律师阅卷看不到。

指公安、检察院、监察机关在侦查 / 调查、审查起诉中，已经合法收集固定、能够证明被告人无罪、罪轻、从轻、减轻、免除处罚，但刻意不移送、不入卷、律师阅卷看不到的隐匿证据。

### 分阶段操作规则

1. **审查起诉阶段**：向检察院申请，检察院应当向公安 / 监察调取，拿到后 3 日内告知律师查阅复制；无相关证据则书面说明理由；

2. **审判阶段**：向法院书面申请、提供线索，法院通知检察院移交，调取后允许律师阅卷；

3. 覆盖主体：新增监察机关调查收集未移送证据也适用本条规则；

4. 权利效果：调取到的证据，律师享有完整阅卷、摘抄、复制权，等同于卷宗内原有证据。

### 和普通阅卷核心区别

阅卷只能拿到**已经移送**的证据；本条专门弥补**已收集、未移送**证据的获取渠道，是阅卷权的补充救济。

**通俗核心释义（2026法条精准解读）**：《刑诉法》第41条调取的是**公、检、监察已经到手、固定收集完毕，却故意不移送、不入卷的无罪、罪轻旧证据**。这类证据律师阅卷看不到、无法自行获取，法律专门赋予律师书面申请调取的救济权利，仅用于查漏补缺，不涉及全新证据侦查。

## 途径 4：自行调查取证 \+ 申请检法调取新证据（《刑诉法》43 条）

1. 普通证人 / 单位：律师持手续、经对方同意可自行取证；

2. 被害人一方证人：必须先经检 / 法许可 \+ 证人双重同意才能取证；

自行取证困难：可申请检察院、法院主动收集全新证据，与 “调取已收集未移送证据” 是两项独立权利，不能混淆。

**41条与43条终极做题区分（必考核心）**：
1\. **第41条**：调【旧证据】——办案机关已收集、隐匿未移送，查漏补缺、完善卷宗；
2\. **第43条**：调【新证据】——办案机关从未收集、卷宗全无，属于全新调查取证；
口诀：**已收未移走41，全新空白走43**。

# 三、本条申请调取权关键细节（命题高频陷阱）

1. 申请对象分阶段：审查起诉找检察院；审判阶段找法院；

2. 申请形式：必须书面，写明证据线索、存放机关、证明作用；

3. 办案机关义务：符合条件**应当调取**；不予调取必须书面说明理由（口头答复违法）；

4. 证据范围：仅限无罪、罪轻、减轻、免除处罚类证据，不含有罪、罪重证据；

5. 覆盖机关：公安、检察院自侦、监察机关三类办案主体收集未移送的证据均可申请调取。

# 四、2026 法考考情、考频、分值分析

1. 考频等级：S 级高频必考，辩护权专题每年客观题必出，常结合阅卷权、调查取证权对比考查；

2. 分值比重：客观单选 1 分、多选 2 分，年均稳定 1–2 分；主观案例程序合法性判断隐性 1–2 分；占刑诉总分 42 分 4%～7%；

3. 命题挖坑点：
① 混淆阅卷权与本条调取权，误以为阅卷能看到全部无罪罪轻证据；
② 侦查阶段律师申请调取隐匿证据（错，仅审查起诉、审判阶段可行）；
③ 法院 / 检察院口头拒绝调取申请（违法，必须书面说明理由）；
④ 把本条 “调取已收集未移送证据” 混同于申请法院重新调查新证据。

# 五、一段式概括 \+ 做题判断方法

依据《刑事诉讼法》第 41 条及配套司法解释，辩护律师获取案件材料共有会见通信、审查起诉后阅卷、申请调取办案机关已收集但未移送的无罪罪轻证据、自行 / 申请司法机关调取新证据四类渠道；题干法条赋予律师专项救济权利，针对公安、监察、检察院已收集却隐匿不移送的无罪、罪轻证据，审查起诉阶段向检察院、审判阶段书面向法院申请调取，办案机关符合条件必须调取并允许律师查阅复制，不予调取应书面释明理由；做题核心区分：卷宗内证据走阅卷，已收集未移送的无罪罪轻证据走本条申请调取，全新未收集证据走调查取证申请，侦查阶段无阅卷、无本条调取申请权限。
