# 行政诉讼一审普通程序【终极完整版框架｜法考精修版】

**核心定性（三科对标\+规章权限终极考点）**：行政诉讼一审普通程序，是行政诉讼**级别最高、步骤最全、规则最严、兜底通用**的法定审判程序，适用于所有复杂、重大、疑难行政案件，是简易程序的完整基础模板。整套程序的审理组织、庭审步骤、举证规则、审限、裁判类型均由《行政诉讼法》**法律强制锁定**，**部门规章、行政法规、红头文件一律无权修改**。

**唯一特例区分**：只有行政处罚普通程序的90日办案期限，法律授权规章可另行规定；**所有诉讼程序规则，规章绝对无权改动**。

- **行政诉讼、民事诉讼、刑事诉讼 所有一审、二审、再审程序**，全部属于**法律保留事项**。
- 审理组织、庭审流程、举证规则、裁判类型、审理期限、上诉期限，**全部由《诉讼法》直接写死**。
- 行政法规、部门规章、红头文件，**没有任何授权、没有任何资格去修改、变通、细化诉讼程序**。

**前置必考区分**：行政诉讼一审**只有普通、简易两类程序，无速裁程序**（刑诉独有速裁、民诉独有小额程序，行诉无）。

## 一、专业法条完整版：行政诉讼一审普通程序 6 大法定模块（零漏洞、可默写）

### 模块1：起诉与立案审查（程序启动前置）

**1\. 法定起诉四要件（缺一不可）**：
①原告与被诉行政行为具有利害关系；
②有明确被告（行政机关/授权组织）；
③有具体诉讼请求、事实与理由；
④属于行政诉讼受案范围\+受诉法院管辖。

**2\. 立案审查时限与后果**：法院接收材料后**7日内**完成审查：符合条件→依法立案并通知当事人；不符合条件→裁定不予立案；原告对不予立案裁定**有权上诉**。

**3\. 特殊规则**：立案审查为形式审查，不实体审证据；起诉原则书面，书写困难可口头起诉；诉讼期间**不停止原行政行为执行**（法定例外情形除外）。

1. 原告提交起诉状、利害关系证据、被诉行政行为文书；

2. 法院 7 日内决定立案 / 裁定不予立案；不予立案原告可上诉。

### 模块2：庭前准备阶段（全硬性时间\+专属行政规则）

本阶段所有时限、流程法定，不可省略、不可变通，是行政诉讼程序违法高频考点。

1. **送达诉状（立案5日内）**：法院立案起5日内，将起诉状副本、应诉通知书送达被告行政机关，正式启动应诉程序。

2. **被告举证\+答辩（收到副本15日内｜行政核心考点）**：被告必须15日内提交**作出行政行为的全部证据、法律依据、规范性文件、答辩状**。
**超级考点**：被告逾期举证、无正当理由逾期提交证据，视为**没有证据**，直接认定行政行为证据不足、违法。
**特色规则**：被告不提交答辩状，不影响法院审理。

3. **送达答辩状（收到答辩5日内）**：法院收到被告答辩材料后5日内，将答辩状副本送达原告，保障原告质证准备权利。

4. **审理组织法定（普通程序专属）**：必须组建**3人以上单数合议庭**（审判员单独组成/审判员\+陪审员组成），**绝对禁止独任审理**。独任审理仅适用于简易程序，普通程序独任审理构成重大程序违法，判决可撤销。合议庭组成后3日内告知当事人，保障回避申请权。

5. **开庭排期通知（开庭3日前）**：开庭3日前传票通知当事人、代理人，通知书通知证人、鉴定人、勘验人；公开审理案件提前公告案由、当事人、开庭时间地点。

6. **诉讼请求固定规则**：起诉状送达被告后，原告**原则上不得新增、变更诉讼请求**，防止诉讼突袭、拖延审理。

7. **庭前会议（可选）**：复杂案件可召开庭前会议，梳理争议焦点、处理回避、管辖异议、证据交换、非法证据排除，仅解决程序问题，不审理实体裁判。

1. 立案**5 日内**法院向被告（行政机关）送达起诉状副本；

2. 被告收到副本**15 日内**必须提交：作出行政行为全部证据、依据的规范性文件、答辩状（行政机关举证责任核心）；

3. 法院收到答辩状**5 日内**送达原告；

4. 强制组成**合议庭：3 人以上单数**（审判员 \+ 陪审员 / 纯审判员），不得独任审理（独任只属于简易程序）；

5. 开庭**3 日前**传票通知当事人，通知书通知证人、鉴定人；

6. 诉状送达原告后，原则上不准新增诉讼请求。

### 模块3：开庭审理（四阶段法定闭环、顺序不可颠倒、不可删减）

行政诉讼一审普通程序**必须完整走完四阶段**，无任何简化权限，区别于简易程序的可简化规则。审理核心：**只审查行政行为合法性，原则不审查合理性**（明显不当例外）。

1. **法庭调查（定事实、定证据｜核心环节）**：固定顺序：原告陈述诉求及事实理由→被告答辩、陈述行政行为作出过程→双方依次举证、交叉质证→法院核查证据真实性、合法性、关联性。
**行政专属规则**：被告对行政行为合法性承担**举证责任**，原告仅需证明利害关系、行为存在即可。未经当庭质证的证据，不得作为定案依据。

2. **法庭辩论（聚焦合法性）**：双方围绕五大合法性要件辩论：**职权合法、事实清楚、证据确凿、适用法律正确、程序合法**；仅可针对明显不当的裁量瑕疵展开辩论，不得随意评判行政自由裁量合理性。

3. **最后陈述**：原、被告、第三人依次做最后总结陈述，固定最终攻防意见。

4. **有限调解规则（行诉独有大坑）**：**原则禁止调解**！仅三类案件可调解：行政赔偿、行政补偿、行政协议案件。**行政行为合法性本身绝对不能调解、不能私了**。

> 审理公开原则：以公开开庭为原则；涉及国家秘密、个人隐私**法定不公开**；商业秘密、案件隐私可依申请不公开。

1. 法庭调查：原告陈述→被告答辩→双方举证、交叉质证（行政机关举证为王）；

2. 法庭辩论：围绕行政行为 \\*\\* 合法性（证据、法律、程序、职权、裁量）\\*\\* 辩论；

3. 最后各方陈述；

4. 有限调解：仅行政赔偿、补偿、行政协议案件可以调解，被诉行政行为合法性本身不许调解。

### 模块4：合议庭评议与裁判形成

庭审终结后，合议庭**闭门秘密评议**，全程不公开、留完整评议笔录。裁判规则：**少数服从多数**，多数意见为最终裁判结论，少数不同意见必须记入笔录。疑难、重大案件可提交审判委员会讨论，审委会作出的决定，合议庭必须执行，不得擅自更改。

合议庭闭门讨论，少数服从多数形成裁判意见，全程留评议笔录。

### 模块5：一审六大法定判决类型（法考主观题必背、全覆盖）

法院根据行政行为合法性审查结果，只能作出以下六类法定判决，无其他裁判形式：

1. **驳回原告诉讼请求判决**：行政行为证据确凿、适用法律正确、程序合法、职权合法，完全合规。

2. **撤销判决（可责令重作）**：五类违法情形可撤销：证据不足、适用法律错误、程序违法、超越职权、滥用职权；新增：行政行为**明显不当**（合理性瑕疵特例）。撤销后可责令被告重新作出行政行为，但不得作出基本相同行为。

3. **履行判决**：针对行政不作为、拖延履职、拒绝履职，判令被告限期履行法定职责；需被告裁量的，判令重新处理。

4. **给付判决**：针对行政机关拒不支付抚恤金、社保待遇、补偿金、补助金等金钱给付义务。

5. **确认违法/确认无效判决**：程序轻微违法不撤销、撤销无意义、行为已实施完毕→确认违法；行为重大明显违法（无主体资格、无依据）→确认无效。

6. **变更判决（极窄适用）**：**仅限行政处罚明显畸重**，法院可直接改判减轻处罚；**绝对不能加重处罚**（禁止不利变更原则）。

1. 驳回原告诉讼请求：行政行为完全合法；

2. 撤销判决（可责令重作）：证据不足、适用法律错误、程序违法、越权、滥用职权、明显不当；

3. 履行判决：行政机关不作为、不履行法定职责；

4. 给付判决：不支付抚恤金、社保、补偿金等；

5. 确认违法 / 确认无效判决；

6. 变更判决：仅行政处罚明显畸重可直接变更。

### 模块6：一审审限、宣判与上诉收尾（全考点补全）

1. **法定审限**：一审普通程序自**立案之日起6个月内审结**；特殊重大复杂案件需延长的，必须报请高级人民法院批准，基层法院、中院无权自行延期。

2. **上诉期限**：当事人不服一审**判决书15日内**、一审**裁定书10日内**，向上一级人民法院提起二审上诉。期满不上诉，一审裁判生效。

3. **宣判规则**：分为当庭宣判、定期宣判；当庭宣判的10日内送达文书，定期宣判的当场送达。宣判一律公开进行。

4. **程序终局**：一审普通程序审结后，可结案方式：判决、裁定、准许撤诉、按撤诉处理。

1. 一审普通程序法定审限：**立案之日起 6 个月**，需延长报高院批准；

2. 当事人不服一审判决书**15 日内**向上一级法院提起二审上诉。

## 二、大白话深度拆解（打通做题逻辑、彻底不混淆）

### 1\. 整体定位

行政诉讼一审普通程序，就是**老百姓告政府的标准完整版打官司流程**，全程由法律锁死所有细节，没有任何简化、变通空间。核心逻辑：**法院只审政府行为合不合法，不随便干预政府正常行政裁量**，只在政府越权、违法、程序出错、处罚畸重时纠错。

### 2\. 和行政处罚普通程序做对比（打通你之前考点）

1. **行政处罚普通程序（行政机关自我办案）**：大框架法定不可改，但**90日办案期限**允许部门规章另行规定延期、不计入期限，是唯一规章可插手的行政程序。

2. **行政诉讼一审普通程序（法院司法审判）**：属于国家司法审判制度，**全程、全部规则、全部期限均由法律专属设定**，行政法规、部门规章、各类规范性文件，**一律无权改动、无权细化、无权变通**。

### 3\. 最核心两个坑点人话翻译

1. **审理组织大坑**：普通程序=3人以上合议庭（法定标配）；独任法官=简易程序，普通程序独任审理直接构成程序违法，判决可撤销。

2. **审理标准大坑**：常规只审**合法性**（职权、事实、证据、程序、法律适用）；仅行政处罚明显不当，可审合理性、可变更判决，其余行政行为合理性法院不干预。

3. **举证责任大坑**：行诉举证责任倒置，被告行政机关自证清白，被告逾期举证直接败诉，区别于民诉谁主张谁举证。

4. **调解大坑**：行诉严格限缩调解范围，绝大多数案件禁止调解，和民诉全程可调解、刑诉公诉案件禁止调解形成鲜明三科对比。
