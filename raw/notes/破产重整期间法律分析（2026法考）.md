# 破产重整期间法律分析（2026法考）

# 一、对你原句的法条判断（2026 法考）

> 原句：**“重整期间（重整计划还没批准，还在经营阶段）：适用破产费用、共益债务规则”**
> 
> 

✅**大体正确，但要做精准修正**

1. 法条：**破产费用、共益债务的触发时点是【破产申请受理之后】，不是 “重整期间” 才开始适用**。
案件一旦法院受理破产（之后才裁定进入重整），从受理那一刻起就产生破产费用、共益债务，**重整期间当然继续适用该套规则**。

2. 「重整期间」定义（《破产法》72 条）：**法院裁定重整之日 → 法院裁定批准重整计划（重整程序终止）**。
👉这个阶段就是重整计划草案制作、分组表决、等待法院审批的阶段；**担保物权暂停行使这一套特殊保护规则，仅在重整期间生效**。

3. ⚠️关键坑：**一旦法院裁定批准重整计划，重整程序终止，「重整期间直接结束」，进入【重整计划执行期间】**。

> 执行期间新发生债务，**不再属于共益债务**，不再享受 “随时清偿”。
> 
> 

# 二、重整完整生命周期（法条串联，法考背诵版）

## 阶段 1：破产申请受理 → 法院裁定重整

- 受理破产那一刻起：产生破产费用、共益债务，适用 43 条随时清偿规则。

- 还没进入**重整期间**；只是破产案件受理。

## 阶段 2：【重整期间（重整保护期）】《破产法 72 条》

> 起点：法院**裁定债务人重整**；终点：法院裁定批准重整计划（重整程序终止）
> 
> 

- 工作：管理人 / 债务人制作重整计划草案（6 个月，可延期 3 个月）、分组表决草案；企业继续经营。

- 特殊规则（**仅本阶段有效**）：
①担保物权暂停行使；
②管理人为继续营业可以借款，可以新设抵押；该借款参照共益债务，随时清偿；
③出资人不得分红；董监高股权转让受限；

- 两种出局结局：
1）草案表决通过，法院裁定**批准重整计划 → 重整程序终止，重整期间结束，进入阶段 3**；
2）草案做不出来 / 经营继续恶化：法院裁定终止重整程序，**宣告债务人破产，转入破产清算**。

## 阶段 3：【重整计划执行期间】《破产法 89‑90 条》

> ⚠️**已经不属于重整期间！重整程序已经终止**
> 
> 

1. 重整计划生效，**由债务人自己执行，管理人只负责监督**，管理人把财产交还给债务人。

2. 按照重整计划约定分期还钱、债转股、延期清偿，**不是法院一批准就一次性全部还钱**。

3. 旧债权：按照重整计划方案清偿；

4. **本阶段新发生债务：不属于共益债务，不享受随时清偿**。

5. 两条走向：

- 走向 A：**重整计划全部执行完毕**→法院裁定重整案件终结；
👉关键后果：保证人之后代偿债务，**不能向重整后的债务人追偿（民法典担保制度解释 23 条第 3 款）**。

- 走向 B：债务人不执行、执行不能；法院**裁定终止重整计划的执行，宣告破产，转入清算**。
👉关键后果：回到普通破产清算，保证人代偿后可以正常追偿。

# 三、考场做题 3 条黄金区分（必背）

1. **重整期间 ≠ 重整计划执行期间**

- 重整期间：草案、表决、待法院审批；担保暂停行使；新营业借款参照共益债务随时清偿。

- 执行期间：计划已经法院批准，债务人落地履约；担保不再暂停行使；新债不是共益债务。

2. 破产费用、共益债务：**自破产申请受理时就产生，重整期间当然适用；但重整计划执行期间新发生债务不属于共益债务**。

3. 重整计划被法院批准，**只是 “重整程序终止”，不等于案件全部了结，还要走完漫长的执行期**。

# 四、极简时间轴口诀

> 受理破产，费益即生；
> 裁定重整，进入保护期；
> 法院批计划，重整程序止，进入执行期；
> 执行完毕案件终；执行失败转清算。
> 
>
